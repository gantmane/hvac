Газовые двигатели с искровым зажиганием (spark ignition gas engines) доминируют в приложениях ТЭЦ малой и средней мощности благодаря широкой доступности природного газа, благоприятной экономике и чистым характеристикам сгорания. Эти двигатели преобразуют газообразное топливо в электроэнергию с КПД 35–42 % при одновременном производстве рекуперируемой тепловой энергии из выхлопных газов, рубашки охлаждения и вспомогательных контуров. Возможность работы на магистральном природном газе, биогазе из очистных сооружений или свалочном газе обеспечивает топливную гибкость, недостижимую у дизельных двигателей. Требования к проектированию регламентируются ASHRAE Handbook HVAC Systems and Equipment, EN 12831 и СП 60.13330.2020.

## Стратегии сгорания

Газовые двигатели используют два принципиально различных подхода к организации горения, каждый из которых обеспечивает свой компромисс между КПД, выбросами и сложностью управления.

### Сгорание с обеднённой смесью (Lean-burn)

Двигатели с обеднённой смесью работают при значительном избытке воздуха: 150–200 % от стехиометрии, что соответствует коэффициенту эквивалентности $\varphi = 0{,}50$–$0{,}65$ (или $\lambda = 1{,}5$–$2{,}0$). Разбавление снижает пиковую температуру сгорания примерно с 2800 К до 2200 К, резко подавляя образование теплового NOₓ.

Полное сгорание обеднённой смеси требует высокоэнергетических систем зажигания:
- предкамерное зажигание (prechamber ignition): богатая смесь поджигается в малой предкамере, а горящие струи инициируют горение в основной камере с обеднённой смесью; обеспечивает устойчивое воспламенение при $\lambda$ до 2,0;
- плазменное зажигание (plasma ignition): высокоэнергетический электрический разряд расширяет объём зоны зажигания и образует свободные радикалы.

Электрический КПД крупных двигателей с обеднённой смесью достигает 38–42 %. Выбросы NOₓ — 0,06–0,10 кг/ГДж без очистки выхлопа.

### Стехиометрическое горение с TWC

Стехиометрические двигатели поддерживают $\lambda = 1{,}00 \pm 0{,}02$ посредством управления по замкнутому контуру с датчиком кислорода. Точное соотношение воздух/топливо позволяет использовать трёхкомпонентный каталитический нейтрализатор (TWC — Three-Way Catalyst), в котором одновременно протекают реакции:

{{< formula display="true" >}}
2\,\text{CO} + 2\,\text{NO} \rightarrow 2\,\text{CO}_2 + \text{N}_2
{{< /formula >}}

{{< formula display="true" >}}
\text{C}_x\text{H}_y + \text{NO} \rightarrow \text{CO}_2 + \text{H}_2\text{O} + \text{N}_2
{{< /formula >}}

Эффективность преобразования TWC превышает 98 % в узкой рабочей полосе. Материалы накопления кислорода на основе оксидов церия-циркония расширяют эту полосу до ±2 % по $\lambda$. Электрический КПД стехиометрических двигателей несколько ниже — 32–38 % — из-за более высокой теплопередачи и меньшего показателя адиабаты смеси. Данная конфигурация применяется в регионах с жёсткими нормами по NOₓ (< 0,03 кг/ГДж).

## Гибкость по видам топлива

### Природный газ

Магистральный природный газ содержит 90–98 % метана с примесями этана, пропана и инертных разбавителей. **Число метана** (methane number, MN) количественно оценивает стойкость к детонации: чистый метан принят за MN = 100. Типичный магистральный газ имеет MN = 70–95. Высшие углеводороды и водород снижают MN, требуя запаздывания зажигания и снижения КПД.

**Индекс Воббе** (Wobbe Index) характеризует взаимозаменяемость газообразных топлив:

{{< formula display="true" >}}
WI = \frac{H_u}{\sqrt{SG}}
{{< /formula >}}

где $H_u$ — низшая теплота сгорания; $SG$ — удельный вес относительно воздуха. Топлива с близким индексом Воббе обеспечивают схожие тепловые потоки при постоянном давлении и взаимозаменяемы без изменения настроек оборудования. Природный газ в трубопроводных системах России имеет $WI \approx 13$–$15$ МДж/м³.

### Биогаз

Биогаз из анаэробного сбраживания содержит 55–65 % метана и 35–45 % CO₂. НТС составляет 6,3–7,4 МДж/м³ против 10,6 МДж/м³ для природного газа. Снижение теплоты сгорания требует:
- увеличения проходных сечений топливной системы;
- уменьшения выходной мощности на 20–30 % при неизменном рабочем объёме.

Загрязнители биогаза, требующие удаления:
- H₂S должен быть снижен ниже 100–200 ppm для предотвращения коррозии клапанов и катализаторов;
- силоксаны — ниже 5–10 мг/м³ для предотвращения кремниевых отложений на клапанах и поверхностях камеры сгорания;
- влага должна быть осушена до точки росы $\leq -10$ °C при рабочем давлении;
- твёрдые частицы — фильтрация до 5 мкм для защиты форсунок.

### Свалочный газ

Свалочный газ содержит 40–60 % метана с повышенным содержанием N₂ из-за инфильтрации воздуха, что снижает теплоту сгорания и увеличивает изменчивость состава. Управление по замкнутому контуру с измерением теплоты сгорания топлива на входе компенсирует эту переменность.

## Управление составом топливовоздушной смеси

Система управления поддерживает горение в целевых диапазонах, несмотря на изменения состава топлива, условий окружающего воздуха и износа двигателя. Датчики массового расхода воздуха, датчики расхода топлива и широкополосные датчики кислорода в выхлопе обеспечивают управление по замкнутому контуру с точностью ±1–2 %.

Оптимизация угла опережения зажигания (spark timing) балансирует КПД и выбросы. Датчики детонации (knock sensors) обеспечивают защитное запаздывание зажигания при возникновении детонации.

## Турбонаддув и управление воздухозарядкой

Турбонаддув повышает удельную мощность путём рекуперации энергии выхлопа для сжатия впускного воздуха. Температура нагнетаемого воздуха после компрессора при адиабатном сжатии:

{{< formula display="true" >}}
T_2 = T_1 \left(\frac{P_2}{P_1}\right)^{(\gamma-1)/\gamma}
{{< /formula >}}

**Пример.** Сжатие воздуха от $P_1 = 101{,}4$ кПа до $P_2 = 207$ кПа при $T_1 = 300$ К:

{{< formula display="true" >}}
T_2 = 300 \cdot \left(\frac{207}{101{,}4}\right)^{0{,}286} = 300 \cdot 1{,}277 = 383\ \text{К} = 110\ °C
{{< /formula >}}

Промежуточный охладитель снижает эту температуру до 40–60 °C, увеличивая плотность заряда на 15–25 % и улучшая запас по детонации. Эффективность промежуточного охладителя:

{{< formula display="true" >}}
\varepsilon_\text{IC} = \frac{T_\text{in} - T_\text{out}}{T_\text{in} - T_\text{coolant}} = 0{,}70 \text{–} 0{,}85
{{< /formula >}}

Тепло, отведённое в теплоноситель промежуточного охладителя (3–8 % расхода топлива), представляет дополнительный низкопотенциальный ресурс рекуперации.

## Интеграция рекуперации тепла

Газовые двигатели производят тепловую энергию в нескольких потоках. Рекуперируемая мощность выхлопных газов:

{{< formula display="true" >}}
\dot{Q}_\text{exh} = \dot{m}_\text{exh} \cdot c_p \cdot (T_\text{in} - T_\text{out})
{{< /formula >}}

**Пример расчёта.** Двигатель мощностью 1000 кВт: $\dot{m}_\text{exh} = 8200$ кг/ч, $T_\text{in} = 454$ °C, $T_\text{out} = 149$ °C, $c_p = 1{,}088$ кДж/(кг·К):

{{< formula display="true" >}}
\dot{Q}_\text{exh} = \frac{8200}{3600} \cdot 1{,}088 \cdot (454 - 149) = 756\ \text{кВт}
{{< /formula >}}

Рубашка охлаждения при 88–99 °C обеспечивает 20–25 % расхода топлива. Пластинчатый теплообменник передаёт это тепло в систему горячего водоснабжения объекта, поддерживая подачу охлаждающей жидкости 82–93 °C и обратку 91–99 °C.

Суммарная рекуперация тепла из выхлопа и рубашки достигает 50–55 % расхода топлива. Совокупный КПД когенерации:

{{< formula display="true" >}}
\eta_\text{CHP} = \eta_e + \eta_\text{thermal} = 36\ \% + 50\ \% = 86\ \%
{{< /formula >}}

## Контроль выбросов

Образование теплового NOₓ по механизму Зельдовича:

{{< formula display="true" >}}
\dot{n}_\text{NOx} \propto \exp\!\left(-\frac{E_a}{R\, T}\right) \cdot [\text{O}_2] \cdot [\text{N}_2]
{{< /formula >}}

Системы SCR вводят аммиак или мочевину в выхлоп выше по потоку от катализатора:

{{< formula display="true" >}}
4\,\text{NO} + 4\,\text{NH}_3 + \text{O}_2 \rightarrow 4\,\text{N}_2 + 6\,\text{H}_2\text{O}
{{< /formula >}}

{{< formula display="true" >}}
2\,\text{NO}_2 + 4\,\text{NH}_3 + \text{O}_2 \rightarrow 3\,\text{N}_2 + 6\,\text{H}_2\text{O}
{{< /formula >}}

Снижение NOₓ на 80–95 % обеспечивает выбросы менее 0,03 кг/ГДж. Катализатор SCR требует температуры выхлопа выше 260 °C для надлежащей работы.

Каталитические окислители преобразуют CO и несгоревшие углеводороды с эффективностью 90–98 % при температурах выхлопа выше 232–260 °C.

## Практические рекомендации

{{< table title="Типовые показатели газовых когенерационных двигателей" >}}
| Параметр | Двигатель lean-burn | Стехиометрический двигатель |
|---|---|---|
| Электрический КПД | 38–42 % | 32–38 % |
| Выбросы NOₓ (без SCR) | 0,06–0,10 кг/ГДж | — |
| Выбросы NOₓ (с TWC) | — | < 0,02 кг/ГДж |
| Суммарный КПД когенерации | 80–88 % | 78–85 % |
| Применение | Мощность > 500 кВт; норма < 0,10 кг/ГДж | Мощность < 500 кВт; норма < 0,03 кг/ГДж |
{{< /table >}}

**Выбор стратегии сгорания:**
- Если нормативное требование по NOₓ — менее 0,03 кг/ГДж, выбирайте стехиометрический двигатель с TWC.
- Если требование — менее 0,06 кг/ГДж, достаточен lean-burn без SCR.
- При более жёстких нормах к lean-burn добавляется SCR.

**Топливная стратегия для биогаза:** при переходе с природного газа на биогаз требуется переходник топливной системы, перекалибровка дозирующего клапана и проверка числа метана для корректировки угла опережения зажигания.
