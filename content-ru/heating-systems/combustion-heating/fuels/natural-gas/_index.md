Природный газ является основным топливом для жилых, коммерческих и промышленных систем сгорания в России, Европе и Северной Америке. Это ископаемое топливо состоит преимущественно из метана с переменным содержанием тяжёлых углеводородов. По сравнению с мазутом и углём природный газ обеспечивает более высокую достижимую эффективность (до 98 % у конденсационных котлов), минимальные выбросы твёрдых частиц и серы, упрощённое обслуживание. Нормативная база: ASHRAE Handbook HVAC Systems, ASHRAE 90.1, EN 303-1, EN 12831, NFPA 54/ANSI Z223.1, СП 60.13330.2020.

## Состав природного газа

Состав газа зависит от геологического источника и степени подготовки.

{{< table title="Типичный состав природного газа" >}}
| Компонент | Объём, % | Диапазон, % | Влияние на свойства |
|---|---|---|---|
| Метан CH₄ | 85–97 | 70–99 | Основной источник теплоты |
| Этан C₂H₆ | 1–7 | 0–20 | Повышает теплотворность |
| Пропан C₃H₈ | 0–2 | 0–8 | Повышает энергетическую плотность |
| Бутан C₄H₁₀ | 0–0,5 | 0–2 | Незначительный вклад |
| Азот N₂ | 0,5–5 | 0–15 | Инертный разбавитель, снижает теплотворность |
| CO₂ | 0,1–2 | 0–5 | Инертный, снижает теплотворность |
{{< /table >}}

Более высокое содержание метана обеспечивает более чистое горение и меньшее отложение углерода. Тяжёлые углеводороды увеличивают энергетическую плотность, но требуют скорректированного коэффициента избытка воздуха.

Региональный состав газа влияет на подбор горелочных устройств. При перемещении оборудования из одного района газоснабжения в другой может потребоваться замена жиклёров или перенастройка регулятора давления.

## Теплотворная способность

### Высшая теплотворная способность (ВТС / HHV)

ВТС включает скрытую теплоту конденсации водяного пара в продуктах горения:

- Типичный диапазон для трубопроводного газа: 37,3–38,9 МДж/м³ при 15,6 °C и 101,3 кПа
- Используется при тарификации коммунальными предприятиями и в рейтингах оборудования по ASHRAE для Северной Америки
- Типовое расчётное значение: 38,2–38,5 МДж/м³

### Низшая теплотворная способность (НТС / LHV)

НТС не включает энергию конденсации пара; водяной пар остаётся в газообразном состоянии. LHV ≈ HHV × 0,90. Применяется в европейских нормах (EN 303, EN 12831) и российских стандартах (СП 60.13330).

Конденсационные котлы утилизируют разницу между HHV и LHV, достигая КПД свыше 95 % по LHV (более 90 % по HHV).

## Число Воббе (Wobbe Index)

Число Воббе (WI) характеризует взаимозаменяемость газовых потоков: два газа с одинаковым WI при одном и том же давлении сопла горелки обеспечивают одинаковый тепловой ввод без регулировки.

{{< formula display="true" >}}
WI = \frac{HHV}{\sqrt{SG}}
{{< /formula >}}

где $HHV$ — высшая теплотворная способность, МДж/м³; $SG$ — удельный вес (относительно воздуха).

Стандартные диапазоны для трубопроводного природного газа:

- Трубопроводный газ: 48,7–51,6 МДж/м³
- Допустимое отклонение для взаимозаменяемости: ±4 %
- Расчётное значение для проектирования горелок: 50,2 МДж/м³

Коммунальные газовые компании поддерживают WI в узких пределах по всей территории обслуживания, обеспечивая стабильную работу газовых приборов.

## Удельный вес и потери давления в газопроводе

Удельный вес SG сравнивает плотность газа с плотностью воздуха при идентичных условиях. Влияет на потери давления в распределительных сетях, расход через жиклёр и смешивание с воздухом горения.

{{< table title="Удельный вес природного газа" >}}
| Состав | SG |
|---|---|
| Чистый метан | 0,554 |
| Трубопроводный газ | 0,58–0,70 |
| Типовое расчётное значение | 0,60 |
{{< /table >}}

Зависимость потерь давления от удельного веса:

{{< formula display="true" >}}
\Delta P \propto SG
{{< /formula >}}

Жиклёры оборудования подбираются под конкретный удельный вес газа: для более тяжёлого газа требуется меньший диаметр жиклёра при том же давлении подачи и тепловом вводе.

## Характеристики горения

### Стехиометрия

Уравнение полного горения метана:

{{< formula display="true" >}}
\text{CH}_4 + 2\,\text{O}_2 \rightarrow \text{CO}_2 + 2\,\text{H}_2\text{O} + 37{,}6\,\text{МДж/м}^3
{{< /formula >}}

Требования к воздуху для горения:
- Теоретический расход: 9,57 м³ воздуха/м³ природного газа
- Типовой избыток воздуха: 10–50 % в зависимости от типа горелки
- Продукты горения при стехиометрии: 11,1 м³/м³ газа

### Характеристики пламени

{{< table title="Характеристики пламени природного газа" >}}
| Параметр | Значение |
|---|---|
| Температура воспламенения | 482–593 °C |
| Скорость ламинарного пламени | 0,37–0,46 м/с |
| Адиабатическая температура пламени | ~ 1 982 °C |
| Нижний предел воспламеняемости | 5 % по объёму |
| Верхний предел воспламеняемости | 15 % по объёму |
{{< /table >}}

Широкий диапазон воспламеняемости (5–15 %) обеспечивает стабильное горение. Горелки работают между нижним пределом (бедная смесь, риск отрыва пламени) и верхним пределом (богатая смесь, неполное горение).

## Система газоснабжения: давление и подбор счётчиков

### Классы давления в системе газораспределения

{{< table title="Классы давления газораспределительных сетей" >}}
| Класс | Давление |
|---|---|
| Низкое (NG pipeline, low pressure) | 1,5–1,75 кПа (15–17,5 мбар) |
| Среднее | 3,4–34,5 кПа |
| Высокое | 69–414 кПа, требуется районный регулятор |
{{< /table >}}

Газ из трубопровода поддерживает стабильный состав и теплотворность круглогодично. Одоризация меркаптаном (этантиол) — 0,45 кг на 280 м³ газа — обеспечивает обнаружение утечек органолептически.

### Подбор газового счётчика

Газовые счётчики измеряют объёмный расход при фактических условиях давления и температуры. Коммунальные предприятия применяют коэффициенты давления и температуры для пересчёта в стандартные кубометры.

**Диафрагменные счётчики** (diaphragm meters) для жилых и малых коммерческих объектов:
- Номинальные мощности: 2,95; 4,25; 6,80; 10,7 м³/ч
- Потеря давления: 1,25 кПа при номинальной производительности

**Ротационные счётчики** (rotary meters) для коммерческих и промышленных объектов:
- Диапазон: 17–850+ м³/ч
- Меньшая потеря давления: 0,75–1,25 кПа

**Порядок подбора:**

1. Суммировать номинальные тепловые вводы всех подключённых газовых приборов.
2. Применить коэффициент одновременности 0,7–0,9 при наличии нескольких независимых потребителей.
3. Перевести суммарный тепловой ввод в объёмный расход: $\dot{V} = Q / HHV$ (м³/ч).
4. Выбрать счётчик с номинальной производительностью ≥ расчётный расход.
5. Проверить потерю давления счётчика и убедиться, что минимальное рабочее давление у приборов обеспечивается.

**Пример.** Газовый котёл 200 кВт + газовый водонагреватель 30 кВт, HHV = 38,2 МДж/м³, коэффициент одновременности 0,85:

{{< formula display="true" >}}
\dot{V} = \frac{(200 + 30) \times 0{,}85 \times 3{,}6}{38{,}2} = 18{,}5\,\text{м}^3/\text{ч}
{{< /formula >}}

Выбирают ротационный счётчик производительностью 25 м³/ч.

## Сжиженный природный газ (СПГ / LNG)

СПГ обеспечивает резервное топливо или основное снабжение там, где трубопроводная инфраструктура отсутствует. Криогенное хранение при −161 °C уменьшает объём в 600 раз по сравнению с газообразным состоянием.

Ключевые компоненты системы: вакуумно-изолированный резервуар, испаритель (воздушный или водяной), катушка повышения давления, система одоризации при испарении.

Состав СПГ — высокое содержание метана (> 95 %) из-за удаления тяжёлых углеводородов при сжижении — даёт HHV 37,3–37,5 МДж/м³. При переходе с трубопроводного газа на СПГ может потребоваться регулировка горелки.

## Экологические преимущества

Природный газ производит наименьшие выбросы на единицу выработанного тепла среди ископаемых топлив.

{{< table title="Удельные выбросы на 1 ГДж входной мощности" >}}
| Загрязняющее вещество | Природный газ | Мазут № 2 | Уголь |
|---|---|---|---|
| CO₂, кг | 53 | 73 | 93 |
| NOx, кг | 0,041 | 0,127 | 0,209 |
| SO₂, кг | 0,0005 | 0,259 | 1,18 |
| Твёрдые частицы, кг | следы | 0,023 | 0,95 |
{{< /table >}}

Ключевые экологические преимущества:
- На 28 % меньше CO₂ по сравнению с мазутом, на 43 % меньше по сравнению с углём.
- Практически нулевое содержание серы — исключены выбросы SO₂, прекурсоры кислотных дождей.
- Минимальные выбросы твёрдых частиц снижают воздействие на здоровье и упрощают техническое обслуживание дымоходов.

Высокое молярное соотношение H/C (4:1 для метана против 2:1 для угля) означает, что при горении образуется больше воды и меньше CO₂ на единицу энергии — фундаментальное химическое преимущество.

Конденсационные котлы на природном газе достигают AFUE (annual fuel utilization efficiency) 92–98 %, дополнительно снижая удельные выбросы CO₂ на доставленный кДж тепла.

## Нормативная база

- **ASHRAE Handbook HVAC Systems and Equipment** — расчётные методы систем сгорания;
- **ASHRAE 90.1** — стандарт энергетической эффективности зданий, минимальный AFUE;
- **EN 303-1** — котлы с горелками с принудительной тягой;
- **EN 12831-1** — расчёт тепловой нагрузки зданий;
- **EN 15316-4-1** — оценка тепловых характеристик систем отопления;
- **NFPA 54/ANSI Z223.1** — Национальный кодекс топливного газа (США);
- **СП 60.13330.2020** — отопление, вентиляция и кондиционирование воздуха;
- **СП 89.13330.2016** — котельные установки;
- **СП 42-101-2003** — общие положения по проектированию и строительству газораспределительных систем.
