Передвижные перегородки в выставочных залах создают динамические граничные условия, которые бросают вызов традиционным предположениям проектирования HVAC. Система должна поддерживать тепловой комфорт, акустическую развязку и качество воздуха независимо от конфигурации перегородок, избегая перекрестного загрязнения между зонами.

## Физические принципы взаимодействия перегородок и HVAC

Передвижные перегородки вводят переменные граничные условия, которые влияют на три связанных процесса переноса:

**Теплопередача через границы перегородок**

Тепловое сопротивление через перегородки зависит от конструкции и конфигурации воздушного зазора. Для типичных airwall перегородок:

$$R_{partition} = \frac{1}{h_i} + \sum \frac{L_i}{k_i} + \frac{1}{h_o}$$

где $h_i$ и $h_o$ — коэффициенты конвекции внутри и снаружи (обычно 8–10 Вт/м²·К для неподвижного воздуха), $L_i$ — толщины материалов, $k_i$ — теплопроводности.

U-фактор для качественных airwall систем находится в диапазоне 0,3–0,6 Вт/м²·К, что требует учета межзонной теплопередачи при расчетах нагрузок.

**Целостность границы давления**

Поддержание перепадов давления через перегородки предотвращает акустический кроссток через плену. Перепад давления, требуемый для преодоления утечек перегородок:

$$\Delta P = C \cdot Q^n$$

где $C$ — коэффициент расхода (зависит от качества герметизации перегородки), $Q$ — объемный расход воздуха через утечки, $n$ — показатель потока (0,5 для турбулентного потока, 0,65–1,0 для ламинарного потока через плотные уплотнения).

**Пути передачи звука**

Передача звука происходит через три механизма:
1. Прямая передача через массу перегородки (управляется массовым законом)
2. Обходная передача через потолочную плену
3. Передача по воздуховодам между зонами

## Стратегии распределения воздуха для гибких помещений

### Размещение подачи воздуха относительно перегородок

Интервал сетки подающих выходов должен соответствовать всем конфигурациям перегородок. Критический параметр проектирования:

$$S_{max} = \frac{X}{throw}$$

где $S_{max}$ — максимальный интервал выходов, $X$ — интервал сетки перегородок, throw измеряется до терминальной скорости (25,4 м/мин для занятых зон согласно ASHRAE Standard 55).

| Сетка перегородок | Рекомендуемый интервал выходов | Тип диффузора | Требуемый выброс |
|----------------|---------------------------|---------------|-------------------|
| 3,05 м | 2,4–2,7 м | 4-сторонний | 3,7 м при 25,4 м/мин |
| 6,1 м | 4,6–5,5 м | Перфорированный | 6,1 м при 25,4 м/мин |
| 9,15 м | 6,1–7,6 м | Линейная щель | 9,1 м при 25,4 м/мин |

**Критерии выбора диффузора:**

- Использовать диффузоры с широким углом распыления (4-сторонние или перфорированные) для минимизации требований к расстоянию выброса
- Избегать высокоскоростных индукционных диффузоров, создающих шум и сквозняки возле перегородок
- Указывать низкие рейтинги NC (NC 30–35) для акустически чувствительных конфигураций

### Варианты конфигурации возвратного воздуха

Три основных подхода решают вопрос гибкости возвратного воздуха:

```mermaid

    A --> D[Гибридный трансфер/воздуховод]
```

**Возврат с воздуховодом на зону**

Отдельные возвратные воздуховоды для каждой конфигурации перегородки устраняют кроссток в плене. Размещение возвратной решетки:

- Размещать возвраты напротив подающих выходов для надлежащей циркуляции воздуха
- Минимум 1,5 м от путей перегородок, чтобы избежать "мертвых зон"
- Размер для скорости 1,5–2,0 м/с для минимизации генерации шума

**Возврат через общую плену с перегородками**

Акустические перегородки в пространстве плены снижают передачу через фланги. Требуемые потери при вставке перегородки:

$$IL_{required} = STC_{partition} - STC_{system} + 5$$

где $IL_{required}$ — потери при вставке в дБ, $STC_{partition}$ — рейтинг перегородки, $STC_{system}$ — целевая производительность системы. Коэффициент 5 дБ учитывает неопределенность.

## Управление границами зон

### Стратегии управления давлением

Поддержание нейтрального или слегка положительного давления в каждой зоне предотвращает межзонное загрязнение:

$$Q_{supply} - Q_{return} = Q_{exfiltration}$$

Для смежных зон с закрытой перегородкой:

$$\Delta P_{zone} = \frac{\rho}{2} \left( \frac{Q_{net}}{C_d A_{leak}} \right)^2$$

где $\rho$ — плотность воздуха, $C_d$ — коэффициент расхода (0,6–0,65 для герметизирующих перегородок), $A_{leak}$ — эффективная площадь утечки.

Целевые перепады давления:
- Смежные зоны (перегородка закрыта): 0–2,5 Па
- Объединенное пространство: < 1 Па для минимизации усилия на дверь согласно ASHRAE 62.1

### Размещение датчиков для переконфигурируемых зон

Датчики температуры и качества воздуха должны обеспечивать точное управление для всех конфигураций:

**Стратегия размещения:**

1. Устанавливать датчики на постоянные стены, не на путях перегородок
2. Использовать усредняющие алгоритмы, когда несколько датчиков обслуживают одну зону
3. Размещать датчики на 1,2–1,8 м выше пола, вдали от потоков подачи воздуха
4. Минимум один датчик на возможную конфигурацию зоны

**Логика управления для переменных зон:**

## Требования к акустической развязке

ASHRAE Standard 189.1 рекомендует минимум STC 50 для сборок перегородок в конференц-залах. Система HVAC не должна снизить этот рейтинг более чем на 5 дБ.

**Критические элементы проектирования:**

| Компонент | Влияние STC | Стратегия смягчения |
|-----------|-----------|---------------------|
| Утечки в плене | –15 до –25 дБ | Облицованные перегородки, отдельные возвраты |
| Передача по воздуховоду | –10 до –15 дБ | Шумоглушители воздуховода между зонами |
| Шум терминального устройства | –5 до –10 дБ | Размещение VAV вдали от линий перегородок |
| Шум диффузора | –3 до –8 дБ | Низкоскоростные диффузоры (NC 30–35) |

### Расчет размера шумоглушителя воздуховода

Для критических акустических приложений требование потерь при вставке шумоглушителя:

$$IL = NC_{source} - NC_{target} + 10 \log_{10}\left(\frac{A_{room}}{\alpha \cdot S}\right)$$

где $A_{room}$ — поглощение помещения, $\alpha$ — средний коэффициент поглощения, $S$ — площадь поверхности помещения. Логарифмический член учитывает эффект помещения (обычно 5–10 дБ).

## Балансировка потоков воздуха и наладка

Проверять производительность системы для всех конфигураций перегородок:

1. **Базовый тест:** Измерить потоки воздуха при полностью открытых перегородках
2. **Тест отдельной зоны:** Закрыть каждую перегородку и проверить:
   - Подача воздуха соответствует проекту (±10%)
   - Возврат воздуха поддерживает баланс давления
   - Управление температурой отвечает в течение 15 минут
3. **Акустическая проверка:** Генерировать розовый шум на 85 дBA в одной зоне, измерить NIC (Noise Isolation Class) в смежной зоне
4. **Картирование давления:** Подтвердить перепады давления < 2,5 Па между закрытыми зонами

## Рекомендации по проектированию

**Критические факторы успеха:**

- Согласовать сетку диффузоров с планировкой путей перегородок во время разработки проекта
- Указать датчики положения перегородки, интегрированные с BAS для автоматической переконфигурации зон
- Обеспечить отдельные пути возврата или надлежащие облицованные возвраты через плену для требований STC > 45
- Рассчитать межзонную теплопередачу, используя фактические U-факторы перегородок, не адиабатические предположения
- Проверить все конфигурации перегородок, не только полностью открытые и полностью закрытые состояния

**Типичные режимы отказа, которых следует избегать:**

- Подающие выходы, расположенные на линиях путей перегородок, создают "мертвые зоны" в некоторых конфигурациях
- Недостаточная емкость возвратного воздуха при объединении пространств создает отрицательное давление и проблемы с работой двери
- Термостаты, установленные на подвижных путях перегородок, теряют соединение питания
- Недостаточно мощные шумоглушители воздуховода обеспечивают неадекватные потери при вставке на низких частотах (125–250 Гц)

Эти принципы гарантируют гибкую производительность HVAC, которая поддерживает комфорт, акустическую конфиденциальность и энергетическую эффективность во всех пространственных конфигурациях.
