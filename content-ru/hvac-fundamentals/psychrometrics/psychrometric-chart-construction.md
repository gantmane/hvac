Психрометрическая диаграмма — не произвольный график, а точное аналитическое представление уравнений состояния влажного воздуха при постоянном барометрическом давлении. Понимание математических основ построения диаграммы позволяет создавать собственные диаграммы для нестандартных условий (высота, промышленные процессы), обнаруживать ошибки в коммерческих диаграммах и разрабатывать компьютерные психрометрические библиотеки.

## Историческая справка

### Диаграмма Мольера (h–x диаграмма)

Немецкий инженер Рихард Мольер (Richard Mollier) в 1923 году предложил диаграмму, в которой по горизонтальной оси откладывается влагосодержание x (или d — в немецкой традиции), а по наклонной оси — удельная энтальпия h. Косоугольная система координат обеспечивает, что линии h = const параллельны оси энтальпии, что упрощает чтение диаграммы.

Уравнение прямой h = const в системе координат (x, h):

{{< formula display="true" >}}
h = h_0 = \text{const}\quad\Rightarrow\quad\text{горизонтальные прямые на h-оси}
{{< /formula >}}

Угол наклона оси x к оси h в диаграмме Мольера: 135° (h-x диаграмма «Мольер-ИРТА»).

### Диаграмма ASHRAE (t_db–W диаграмма)

В американской практике (и в данной документации) используется диаграмма в прямоугольных координатах:
- Ось X: температура по сухому термометру t_db
- Ось Y: коэффициент влажности W

Линии постоянной энтальпии и влажного термометра наклонены под углом к осям. Эта система более удобна для HVAC-расчётов, так как ось t_db непосредственно читается с термометра.

## Математические уравнения линий диаграммы

### Кривая насыщения (φ = 100 %)

Кривая задаётся параметрически через температуру по сухому термометру t:

{{< formula display="true" >}}
W_s(t) = \frac{0{,}6220 \cdot p_{ws}(t)}{p - p_{ws}(t)}
{{< /formula >}}

Давление насыщения p_ws(t) по уравнению Хайланда–Вексера или Магнуса:

{{< formula display="true" >}}
p_{ws}(t) = 0{,}61094 \cdot e^{17{,}625t/(t+243{,}04)}
{{< /formula >}}

Для построения таблицируют пары (t, W_s(t)) в диапазоне, например, −10 до +50 °C с шагом 0,5 °C.

{{< table title="Опорные точки кривой насыщения (уровень моря)" >}}
| t, °C | p_ws, кПа | W_s, г/кг |
|---|---|---|
| −10 | 0,260 | 1,60 |
| 0 | 0,611 | 3,78 |
| 5 | 0,873 | 5,42 |
| 10 | 1,228 | 7,66 |
| 15 | 1,705 | 10,64 |
| 20 | 2,338 | 14,67 |
| 25 | 3,169 | 19,97 |
| 30 | 4,246 | 27,05 |
| 35 | 5,628 | 36,32 |
| 40 | 7,384 | 48,90 |
{{< /table >}}

### Линии постоянной относительной влажности (φ = const)

{{< formula display="true" >}}
W(t, \varphi) = \frac{0{,}6220 \cdot \varphi \cdot p_{ws}(t)}{p - \varphi \cdot p_{ws}(t)}
{{< /formula >}}

Для каждого значения φ (10 %, 20 %, ... 90 %) строится набор точек (t, W(t,φ)). Линии φ = const изогнуты, поскольку p_ws(t) экспоненциально зависит от t.

### Линии постоянной температуры по влажному термометру (t_wb = const)

Для каждого t_wb линия определяется как геометрическое место точек (t_db, W), удовлетворяющих уравнению психрометра:

{{< formula display="true" >}}
W(t_{db}) = W_s(t_{wb}) - \frac{c_{pa}}{h_{fg}(t_{wb}) + c_{pv} \cdot t_{wb}} \cdot (t_{db} - t_{wb})
{{< /formula >}}

Это уравнение прямой в координатах (t_db, W) с отрицательным наклоном:

{{< formula display="true" >}}
k_{t_{wb}} = -\frac{c_{pa}}{h_{fg}(t_{wb}) + c_{pv} \cdot t_{wb}} \approx -\frac{1{,}006}{2501 + 1{,}86 \cdot t_{wb}}\quad[\text{кг/кг/°C}]
{{< /formula >}}

При t_wb = 20 °C: k ≈ −1,006/2538 = −3,96 × 10⁻⁴ кг/(кг·°C) = **−0,396 г/(кг·°C)**

### Линии постоянной энтальпии (h = const)

Из уравнения:

{{< formula display="true" >}}
h = 1{,}006 \cdot t_{db} + W \cdot (2501 + 1{,}86 \cdot t_{db}) = \text{const}
{{< /formula >}}

Выражаем W как функцию t_db:

{{< formula display="true" >}}
W(t_{db}) = \frac{h - 1{,}006 \cdot t_{db}}{2501 + 1{,}86 \cdot t_{db}}
{{< /formula >}}

Это уравнение **не является линейным** по t_db. Однако для практических целей в диапазоне −10…+50 °C линии h = const можно считать прямыми с наклоном:

{{< formula display="true" >}}
\frac{dW}{dt_{db}} \approx \frac{-(1{,}006 + 1{,}86 \cdot W_{\text{ср}})}{2501 + 1{,}86 \cdot t_{\text{ср}}}
{{< /formula >}}

При W_ср = 12 г/кг, t_ср = 20 °C: dW/dt ≈ −(1,006+0,0224) / 2538 ≈ **−4,05 × 10⁻⁴ кг/(кг·°C)**

Линии h = const практически параллельны линиям t_wb = const — расхождение < 2 % в зоне HVAC.

### Линии постоянного удельного объёма (v = const)

{{< formula display="true" >}}
v = \frac{0{,}287042 (t_{db}+273{,}15)(1+1{,}6078 W)}{p} = \text{const}
{{< /formula >}}

Выражаем W:

{{< formula display="true" >}}
W(t_{db}) = \frac{p \cdot v}{0{,}287042 \cdot (t_{db}+273{,}15)} - \frac{1}{1{,}6078} = \frac{pv}{0{,}287042(t+273{,}15)} - 0{,}6220
{{< /formula >}}

Это убывающая гипербола в координатах (t_db, W). Линии v = const имеют положительный наклон: при росте t_db при постоянном v требуется снижение W (по формуле). Нет — проверим знак: при t_db↑, знаменатель растёт, W снижается → линии v=const имеют отрицательный наклон.

**Пример для v = 0,850 м³/кг при p = 101,325 кПа:**

| t_db, °C | W, г/кг |
|---|---|
| 10 | (101,325 × 0,850)/(0,287 × 283,15) − 0,622 = 85,63/81,26 − 0,622 = 1,053 − 0,622 = **0,431** → 0 |
| 20 | 85,63 / 84,74 − 0,622 = 1,010 − 0,622 = **0,388** → ≈ 0 |

При v = 0,850 м³/кг линия проходит вблизи W ≈ 0 г/кг при t_db = 10–20 °C. Для практических диаграмм v изменяется от ~0,77 до ~0,97 м³/кг в зоне HVAC.

## Алгоритм численного построения диаграммы

### Процедура для диаграммы t_db–W

```
1. Задать: p, диапазон t_db = [t_min, t_max], диапазон W = [0, W_max]
2. Кривая насыщения:
   Для t от t_min до t_max шагом Δt = 0.5°C:
     p_ws = Magnus(t)
     W_s = 0.622 * p_ws / (p - p_ws)
     Нанести точку (t, W_s)
3. Линии φ = const (для φ = 10, 20, ..., 90%):
   Для каждого φ:
     Для t от t_min до t_max шагом Δt:
       W = 0.622 * φ * p_ws(t) / (p - φ * p_ws(t))
       Нанести (t, W)
4. Линии t_wb = const (для t_wb = 5, 10, 15, ..., 35°C):
   Для каждого t_wb:
     W_s_wb = 0.622 * p_ws(t_wb) / (p - p_ws(t_wb))
     k = -1.006 / (2501 + 1.86 * t_wb)
     Для t от t_wb до t_max шагом Δt:
       W = W_s_wb + k * (t - t_wb)
       Нанести (t, W) если W >= 0
5. Линии h = const (для h = -10, 0, 10, ..., 100 кДж/кг):
   Для каждого h:
     Для t от t_min до t_max шагом Δt:
       W = (h - 1.006*t) / (2501 + 1.86*t)
       Нанести (t, W) если 0 <= W <= W_max
6. Линии v = const (для v = 0.78, 0.82, ..., 0.96 м³/кг):
   Для каждого v:
     Для t от t_min до t_max шагом Δt:
       W = p*v / (0.287042*(t+273.15)) - 0.622
       Нанести (t, W) если W >= 0
```
