## Общие положения

Паропроницаемость — способность материала пропускать водяной пар путём диффузии под действием градиента парциального давления. Это фундаментальное свойство определяет:

- скорость диффузионной миграции влаги через ограждающие конструкции;
- риск конденсации в холодных зонах многослойной стены;
- потенциал высыхания конструкции после намокания;
- вклад диффузии пара в скрытую нагрузку систем кондиционирования;
- долговечность несущих элементов из органических материалов.

Стандарты: **ASTM E96** (США), **EN 12086** / **ISO 12572** (Европа), **ГОСТ 25898** (Россия), **ASHRAE Fundamentals**, гл. 26.

## Физика диффузии пара

### Первый закон Фика

Стационарный поток водяного пара через плоский слой:

{{< formula display="true" >}}
g = -\delta_p\,\frac{\partial p_v}{\partial x}
{{< /formula >}}

где:
- {{< formula >}}g{{< /formula >}} — плотность потока пара, кг/(м²·с);
- {{< formula >}}\delta_p{{< /formula >}} — коэффициент паропроницаемости материала, кг/(м·с·Па);
- {{< formula >}}\partial p_v / \partial x{{< /formula >}} — градиент парциального давления пара, Па/м.

В интегральной форме для слоя толщиной {{< formula >}}d{{< /formula >}}:

{{< formula display="true" >}}
g = \delta_p\,\frac{\Delta p_v}{d} = M\,\Delta p_v
{{< /formula >}}

где {{< formula >}}M = \delta_p / d{{< /formula >}} — паропропускание (permeance), кг/(м²·с·Па).

### Коэффициент сопротивления паропроницанию μ

В европейской практике используется безразмерный коэффициент {{< formula >}}\mu{{< /formula >}} — отношение паропроницаемости стоячего воздуха к паропроницаемости материала:

{{< formula display="true" >}}
\mu = \frac{\delta_{p,\text{воздух}}}{\delta_{p,\text{материал}}}
{{< /formula >}}

где {{< formula >}}\delta_{p,\text{воздух}} = 1{,}93\times10^{-10}{{< /formula >}} кг/(м·с·Па) при 20 °C. Чем выше {{< formula >}}\mu{{< /formula >}}, тем хуже паропроницаемость.

Эквивалентная толщина слоя воздуха:

{{< formula display="true" >}}
s_d = \mu\,d
{{< /formula >}}

где {{< formula >}}d{{< /formula >}} — толщина слоя, м. Величина {{< formula >}}s_d{{< /formula >}} [м] характеризует паросопротивление независимо от материала.

### Связь единиц SI и американских

Единица паропропускания в американской системе — **перм** (perm):

{{< formula display="true" >}}
1\;\text{перм (US)} = 5{,}72\times10^{-11}\;\text{кг/(м}^2\text{·с·Па)}
{{< /formula >}}

Обратная величина — паросопротивление (vapor resistance), пермин⁻¹.

## Методы испытания

### ASTM E96 — метод стакана

Стандарт США для измерения паропропускания. Два варианта: мокрый стакан (wet cup) и сухой стакан (dry cup).

**Мокрый стакан (wet cup method):**
- Стакан заполнен водой или насыщенным солевым раствором (высокая RH).
- Образец герметично закрывает стакан.
- Система кондиционируется в камере с низкой RH (~50 %).
- Поток пара: из стакана через образец наружу.
- Определяет паропропускание при высоком среднем влагосодержании.

**Сухой стакан (dry cup method):**
- Стакан содержит осушитель (силикагель, низкая RH).
- Внешняя RH ~50 %.
- Поток пара: снаружи через образец в стакан.
- Определяет паропропускание при низком среднем влагосодержании.

Разница между мокрым и сухим стаканом значима для материалов с зависящей от влажности паропроницаемостью (OSB, гипсокартон). По ASHRAE Fundamentals следует использовать значение, соответствующее ожидаемым условиям.

### EN 12086 / ISO 12572 — европейский метод

Аналогичная чашечная методика с более жёсткими требованиями к контролю условий. Результат — μ-значение; допускается несколько условий испытания (А: 0/50 %, Б: 23/50 % и 23/93 %). Условие Б–нижнее (23/50 %) соответствует сухому стакану, Б–верхнее (23/93 %) — мокрому.

### ГОСТ 25898

Российский стандарт, применяющий аналогичный чашечный метод. Результат выражается через коэффициент паропроницаемости {{< formula >}}\delta_p{{< /formula >}} в мг/(м·ч·Па). Пересчёт: {{< formula >}}\delta_{p,\text{мг/(м·ч·Па)}} = \delta_{p,\text{кг/(м·с·Па)}} \times 3{,}6\times10^6{{< /formula >}}.

## Расчёт многослойных конструкций

### Последовательное соединение слоёв

Общее паросопротивление:

{{< formula display="true" >}}
R_{v,\text{total}} = \sum_i \frac{d_i}{\delta_{p,i}} = \sum_i s_{d,i}
{{< /formula >}}

Паропропускание сборки:

{{< formula display="true" >}}
M_\text{assembly} = \frac{1}{R_{v,\text{total}}}
{{< /formula >}}

Слой с наибольшим {{< formula >}}s_d{{< /formula >}} определяет паросопротивление сборки.

### Расчёт плотности потока пара

{{< formula display="true" >}}
g = \frac{\Delta p_v}{R_{v,\text{total}}}
{{< /formula >}}

Парциальное давление на внутренней границе любого слоя:

{{< formula display="true" >}}
p_{v,i} = p_{v,\text{нар}} + g \cdot \sum_{j=1}^{i} s_{d,j}
{{< /formula >}}

## Численный пример: расчёт паросопротивления стеновой сборки

**Условие.** Стена: гипсокартон 12,5 мм (без краски) + каменная вата 150 мм + OSB 11 мм + WRB + вентилируемый зазор + фиброцементный сайдинг. Зимние условия: внутри 21 °C / 50 % RH; снаружи −15 °C / 80 % RH.

**Давления насыщенного пара:**
- При 21 °C: {{< formula >}}p_{sat,\text{вн}} = 2502{{< /formula >}} Па.
- При −15 °C: {{< formula >}}p_{sat,\text{нар}} = 165{{< /formula >}} Па.

**Парциальные давления:**
- {{< formula >}}p_{v,\text{вн}} = 0{,}50 \times 2502 = 1251{{< /formula >}} Па.
- {{< formula >}}p_{v,\text{нар}} = 0{,}80 \times 165 = 132{{< /formula >}} Па.
- {{< formula >}}\Delta p_v = 1251 - 132 = 1119{{< /formula >}} Па.

**Паросопротивления слоёв (s_d):**

| Слой | Толщина, мм | μ | s_d, м |
|---|---|---|---|
| ГКЛ без краски | 12,5 | 8 | 0,10 |
| Каменная вата | 150 | 1,2 | 0,18 |
| OSB 11 мм | 11 | 40 | 0,44 |
| WRB (Tyvek) | — | — | {{< formula >}}\approx{{< /formula >}} 0,02 |

{{< formula display="true" >}}
R_{v,\text{total}} = 0{,}10 + 0{,}18 + 0{,}44 + 0{,}02 = 0{,}74\;\text{м}
{{< /formula >}}

**Паропропускание сборки:**

{{< formula display="true" >}}
M_\text{assembly} = \frac{\delta_{p,\text{воздух}}}{R_v} = \frac{1{,}93\times10^{-10}}{0{,}74} = 2{,}6\times10^{-10}\;\text{кг/(м}^2\text{·с·Па)}
{{< /formula >}}

В единицах US: {{< formula >}}M = 2{,}6\times10^{-10} / 5{,}72\times10^{-11} = 4{,}5{{< /formula >}} перм — **класс III**.

**Плотность потока пара:**

{{< formula display="true" >}}
g = M_\text{assembly} \times \Delta p_v = 2{,}6\times10^{-10} \times 1119 = 2{,}9\times10^{-7}\;\text{кг/(м}^2\text{·с)} \approx 25\;\text{г/(м}^2\text{·сутки)}
{{< /formula >}}

**Проверка точки росы.** OSB находится при температуре (приближённо) −5 °C; {{< formula >}}p_{sat}(-5\,°C) = 401{{< /formula >}} Па. Давление пара на наружной грани OSB:

{{< formula display="true" >}}
p_{v,\text{OSB}} = p_{v,\text{нар}} + g \cdot (s_{d,\text{WRB}} + s_{d,\text{OSB}}) \cdot \frac{1}{\delta_{p,\text{воздух}}}
{{< /formula >}}

Упрощённо через доли паросопротивления: пар на наружной грани OSB = 132 + 1119 × (0,02 + 0,44)/0,74 ≈ 132 + 696 = 828 Па.

Поскольку 828 Па > 401 Па (насыщение при −5 °C), возникает риск конденсации на наружной поверхности OSB. **Вывод:** для данного климата необходим пароизолятор класса II на внутренней стороне (или интеллектуальный пароизолятор), снижающий {{< formula >}}p_v{{< /formula >}} у OSB ниже {{< formula >}}p_{sat}{{< /formula >}}.

## Зависимость паропроницаемости от влажности

Паропроницаемость многих материалов нелинейно зависит от влагосодержания. Для OSB и деревянных материалов {{< formula >}}\delta_p{{< /formula >}} при высокой RH может быть в 5–10 раз выше, чем при низкой. Это лежит в основе работы **интеллектуальных пароизоляторов** (smart vapour retarders):

- Зимой (низкая RH изнутри и снаружи): {{< formula >}}\delta_p{{< /formula >}} мала → паровой барьер.
- Летом (высокая RH снаружи при кондиционировании): {{< formula >}}\delta_p{{< /formula >}} возрастает → паропроницаемость улучшается → высыхание в сторону помещения.

## Взаимодействие с системами HVAC

**Вклад в скрытую нагрузку.** Диффузия пара через ограждение — менее 5 % от общей скрытой нагрузки кондиционирования в типичном жилом строительстве (утечка воздуха переносит влагу в 50–100 раз больше). Тем не менее в герметичных зданиях с механической вентиляцией (MVHR) диффузионная составляющая становится значимой.

**Управление влажностью помещения.** Паронепроницаемая наружная облицовка в сочетании с паропроницаемым внутренним отделочным слоем может препятствовать высыханию ограждения в сторону помещения летом (климатические зоны 1–3А). Проектирование должно обеспечивать путь высыхания.

**Давление в помещении.** Положительное давление в здании усиливает диффузионный поток пара наружу (благоприятно в зонах 5–8). Отрицательное давление усиливает поток внутрь (проблематично с паронепроницаемой наружной облицовкой в зонах 1–3).

## Проектные принципы

### Асимметрия паропропускания

Базовый принцип: низкое паропропускание на стороне высокого давления пара, высокое — на стороне высыхания.

- **Холодный климат (зоны 5–8):** пароизолятор класса I–II на внутренней (тёплой) стороне; паропроницаемая наружная обшивка (> 5 перм).
- **Жаркий влажный климат (зоны 1–3А):** паропроницаемая внутренняя отделка; пароизолятор или паронепроницаемая наружная облицовка при необходимости.
- **Смешанный климат (зоны 4–5А):** умеренное паропропускание с обеих сторон (класс III); интеллектуальные пароизоляторы.

### Недопустимые конфигурации

- Паровые барьеры ({{< formula >}}s_d > 1500{{< /formula >}} м) с обеих сторон конструкции — влага при строительстве не может испариться.
- Паровой барьер на тёплой стороне в жарко-влажном климате — конденсация при кондиционировании.

### Приоритет управления жидкой водой

Диффузия пара — второстепенный механизм. Проникновение дождевой воды, капиллярный подсос и конденсация переносят в десятки–сотни раз больше влаги. Гидроизоляция, дренажные зазоры и капиллярные разрывы обязательны независимо от паропроницаемости слоёв.

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — коэффициенты паропроницаемости, классификация, расчётные методы.
- **ASHRAE 160** — критерии расчётного анализа контроля влаги; выбор класса пароизолятора по климатической зоне.
- **ASTM E96** — методы испытания паропропускания (мокрый и сухой стакан).
- **ISO 12572** — чашечный метод определения паропроницаемости строительных материалов.
- **EN 12086** — гигротермальные свойства строительных материалов; μ-значение.
- **EN ISO 7783** — паропропускание покрытий и покрытий для наружных стен.
- **ГОСТ 25898** — паропроницаемость и сорбционное увлажнение строительных материалов.
- **СП 50.13330.2017** — тепловая защита зданий (нормируемое сопротивление паропроницанию).
- **СП 23-101-2004** — проектирование тепловой защиты зданий (расчёт конденсации в толще ограждений).
