# Расчёт нормативных расходов воздуха для инженеров HVAC

Стандарт ASHRAE 62.1 определяет минимальные нормы вентиляции для поддержания приемлемого качества воздуха в помещении. Правильные расчёты обеспечивают соответствие нормативным требованиям и предотвращают избыточные энергозатраты на вентиляцию.

## Расход приточного воздуха для зоны

**Процедура расчёта нормативного расхода:**

$$V_{oz} = R_p \times P_z + R_a \times A_z$$

Где:
- $V_{oz}$ = расход приточного воздуха для зоны (л/с)
- $R_p$ = норма приточного воздуха на человека (л/с/чел)
- $P_z$ = численность людей в зоне
- $R_a$ = норма приточного воздуха на площадь (л/с/м²)
- $A_z$ = площадь пола зоны (м²)

**Типовые значения (согласно таблице 6-1 стандарта 62.1):**

| Тип помещения | R_p (л/с/чел) | R_a (л/с/м²) |
|------|---|----------|
| Офисное помещение | 5 | 0.06 |
| Переговорная | 5 | 0.06 |
| Классная комната | 10 | 0.12 |
| Торговый зал | 7.5 | 0.12 |
| Ресторан (зона питания) | 7.5 | 0.18 |
| Спортивный зал | 20 | 0.06 |

## Расход приточного воздуха для системы

**Многозонные рециркуляционные системы:**

$$V_{ot} = \frac{\sum{(R_p \times P_z \times D)} + \sum{(R_a \times A_z)}}{E_z}$$

Где:
- $D$ = коэффициент разнообразия занятости (не все помещения одновременно полностью заняты)
- $E_z$ = эффективность распределения воздуха в зоне

**Эффективность распределения воздуха в зоне:**
- Приток с потолка, вытяжка с пола: $E_z = 1.0$
- Приток с пола, вытяжка с потолка: $E_z = 1.2$ (вентиляция вытеснением)
- Плохое перемешивание: $E_z = 0.8$

## Эффективность вентиляции

**Эффективность вентиляции системы** учитывает неравномерность распределения приточного воздуха по зонам:

$$E_v = \frac{V_{ot}}{V_{oa}}$$

Где $V_{oa}$ = фактический расход приточного воздуха

**Метод наихудшей зоны:**

$$E_v = \frac{V_{oz,min}/V_{dz,min}}{\max(V_{oz}/V_{dz})}$$

Обычно $E_v = 0.6-0.8$ для систем VAV

## Вентиляция с управлением по уровню CO₂

**Установившаяся концентрация CO₂:**

$$C_s = C_o + \frac{N \times G}{V_{oz} \times \rho_{air}}$$

Где:
- $C_s$ = установившаяся концентрация CO₂ (ppm)
- $C_o$ = концентрация CO₂ в наружном воздухе (обычно 400-450 ppm)
- $N$ = количество людей
- $G$ = скорость выделения CO₂ одним человеком (~0.0052 л/с при метаболической скорости 0.3 л/мин)

**Цель:** Поддерживать уровень < 1000-1200 ppm в занятых помещениях

## Энергетическое воздействие

**Годовые энергозатраты на нагрев вентиляционного воздуха:**

$$Q_{heat} = 1.08 \times CFM_{OA} \times HDD_{65} \times 24$$

**Годовые энергозатраты на охлаждение вентиляционного воздуха:**

$$Q_{cool} = 1.08 \times CFM_{OA} \times CDD_{65} \times 24$$

**Типовые данные:** Вентиляция составляет 20-40% от общего энергопотребления HVAC в коммерческих зданиях

## Практическое применение

1. **Офисное здание:** Минимум 5 л/с/чел + 0.06 л/с/м²
2. **Школы:** 10 л/с/чел + 0.12 л/с/м² (дети имеют более высокий метаболизм)
3. **DCV:** Снижение приточного воздуха при отсутствии людей (экономия 20-40% энергии вентиляции)
