Явное охлаждение (sensible cooling) — процесс снижения температуры воздуха без изменения его влагосодержания. Это возможно только при условии, что температура поверхности охлаждающего элемента остаётся выше точки росы воздуха, исключая конденсацию влаги. На психрометрической диаграмме — горизонтальная линия влево (W = const, t_db снижается, φ растёт).

## Условие сухого охлаждения

Явное охлаждение без осушения реализуется при:

{{< formula display="true" >}}
t_{\text{surface}} > t_{dp,\text{вх}}
{{< /formula >}}

Если температура поверхности ниже t_dp, начинается конденсация и процесс переходит в охлаждение с осушением (wet coil). Граница между режимами:

{{< formula display="true" >}}
t_{\text{surface}} = t_{dp} \Rightarrow \text{начало конденсации}
{{< /formula >}}

## Термодинамика процесса

### Уравнение теплового баланса

{{< formula display="true" >}}
Q_s = \dot{m}_a \cdot c_{pa} \cdot (t_1 - t_2)
{{< /formula >}}

В объёмных единицах:

{{< formula display="true" >}}
Q_s\,[\text{кВт}] = 1{,}2 \cdot \dot{V}\,[\text{м}^3/\text{с}] \cdot (t_1 - t_2) = \frac{\dot{V}\,[\text{м}^3/\text{ч}] \cdot \Delta t}{3000}
{{< /formula >}}

### Изменение свойств при явном охлаждении

{{< table title="Изменение психрометрических свойств при явном охлаждении" >}}
| Свойство | Изменение | Значение |
|---|---|---|
| t_db | Снижается | Прямой результат охлаждения |
| W | Неизменно | Нет конденсации, нет удаления влаги |
| t_dp | Неизменно | Зависит только от W |
| φ | Увеличивается | p_ws(t_db) снижается при p_v = const |
| h | Снижается | Δh = c_pa × Δt |
| v | Снижается | v ∝ T |
{{< /table >}}

**Предел явного охлаждения:** при достижении φ = 100 % (когда t_db достигает t_dp) начинается конденсация. Дальнейшее охлаждение требует осушения.

## Физика теплообменника при сухом охлаждении

### Уравнение LMTD

Для сухого теплообменника «воздух–хладоноситель» в противотоке:

{{< formula display="true" >}}
Q_s = U \cdot A \cdot \text{LMTD}
{{< /formula >}}

{{< formula display="true" >}}
\text{LMTD} = \frac{(t_{a,1} - t_{fl,2}) - (t_{a,2} - t_{fl,1})}{\ln\!\left(\dfrac{t_{a,1} - t_{fl,2}}{t_{a,2} - t_{fl,1}}\right)}
{{< /formula >}}

### Метод NTU–ε

Для компактных теплообменников удобен метод числа единиц переноса (NTU — number of transfer units):

{{< formula display="true" >}}
\varepsilon = \frac{Q_{\text{факт}}}{Q_{\max}} = \frac{C_{\min}(t_2 - t_1)}{C_{\min}(t_{fl,\text{вх}} - t_{a,\text{вх}})}
{{< /formula >}}

{{< formula display="true" >}}
\text{NTU} = \frac{U \cdot A}{C_{\min}},\quad C = \dot{m} \cdot c_p
{{< /formula >}}

Для противоточного теплообменника:

{{< formula display="true" >}}
\varepsilon = \frac{1 - \exp\!\left[-\text{NTU}\,(1 - C^*)\right]}{1 - C^* \exp\!\left[-\text{NTU}\,(1 - C^*)\right]},\quad C^* = \frac{C_{\min}}{C_{\max}}
{{< /formula >}}

## Типы установок явного охлаждения

### Свободное охлаждение (free cooling / economizer)

При низкой температуре наружного воздуха охладители систем кондиционирования (ЦОД, промышленные здания) могут переключаться на прямое охлаждение наружным воздухом без включения компрессора.

**Условие активации air-side экономайзера (энтальпийный метод):**

{{< formula display="true" >}}
h_{OA} < h_{RA} - \Delta h_{\text{гистерезис}}
{{< /formula >}}

Дополнительное условие для исключения высокой влажности:

{{< formula display="true" >}}
t_{dp,OA} < 15{,}5\;°\text{C}\quad(\text{по ASHRAE 90.1-2022})
{{< /formula >}}

### Ночное дорадиационное охлаждение

Здания с тяжёлыми конструкциями (большая тепловая масса) охлаждаются ночью прохладным наружным воздухом:

{{< formula display="true" >}}
Q_{\text{предохл}} = \rho_a \cdot c_a \cdot \dot{V} \cdot (t_{RA} - t_{OA,\text{ночь}})
{{< /formula >}}

Накопленный «холод» снижает пиковую нагрузку на охлаждение в дневные часы.

### Прецизионное охлаждение ЦОД (CRAC/CRAH)

В ЦОД при поддержании строгих температурных допусков используются прецизионные кондиционеры. Принцип — явное охлаждение без осушения при поддержании t_dp в помещении < 15 °C:

{{< table title="Параметры прецизионного охлаждения (ASHRAE TC9.9 класс A1)" >}}
| Параметр | Диапазон |
|---|---|
| t_db поступающего воздуха | 15–32 °C |
| t_dp поступающего воздуха | 5,5–15 °C |
| Целевая t_db на выходе | 18–27 °C |
| Допускаемый диапазон φ | 20–80 % |
{{< /table >}}

## Расчётный пример: сухой охладитель

**Задание:** охладить 8 000 м³/ч воздуха с t_db1 = 30 °C, φ1 = 45 % до t_db2 = 20 °C без изменения влагосодержания. Хладоноситель — вода 16/20 °C.

**Проверка условия сухого охлаждения:**

- W1: p_ws(30°C) = 4,246 кПа; p_v = 0,45 × 4,246 = 1,911 кПа
- W1 = 0,622 × 1,911 / (101,325 − 1,911) = **11,96 г/кг**
- t_dp1 = 243,04 × ln(1,911/0,611) / (17,625 − ln(1,911/0,611)) = **17,0 °C**
- Температура поверхности секции: **16 °C** (температура воды на входе)

Условие: 16 °C < 17,0 °C → поверхность ниже точки росы. **Режим сухого охлаждения невозможен.** Для сухого охлаждения до 20 °C при данных условиях требуется t_surface > 17 °C, то есть температура воды > 17 °C.

**Скорректируем:** вода 18/22 °C. Теперь t_surface ≈ 18 °C > t_dp = 17 °C → режим сухого охлаждения возможен.

{{< formula display="true" >}}
Q_s = \frac{8000 \times (30-20)}{3000} = \mathbf{26{,}7\;\text{кВт}}
{{< /formula >}}

{{< formula display="true" >}}
\dot{V}_w = \frac{26{,}7}{4{,}19 \times 4} = \mathbf{1{,}59\;\text{л/с}}
{{< /formula >}}

{{< formula display="true" >}}
\text{LMTD} = \frac{(30-22)-(20-18)}{\ln(8/2)} = \frac{6}{\ln 4} = \frac{6}{1{,}386} = \mathbf{4{,}33\;\text{K}}
{{< /formula >}}

Площадь поверхности при U = 40 Вт/(м²·К):

{{< formula display="true" >}}
A = \frac{26\,700}{40 \times 4{,}33} = \mathbf{154\;\text{м}^2}
{{< /formula >}}

**Состояние воздуха на выходе:** t_db2 = 20 °C, W2 = 11,96 г/кг (сохраняется), φ2 = p_v / p_ws(20°C) = 1,911 / 2,338 = **81,7 %**.

## Граничный случай: приближение к точке росы

При охлаждении до температур, близких к точке росы, необходимо контролировать, не пересёкся ли процесс с кривой насыщения:

{{< formula display="true" >}}
t_{db,2,\min} = t_{dp,\text{вх}} + \delta\quad(\delta > 0)
{{< /formula >}}

Рекомендуемый зазор δ ≥ 1 °C для исключения случайной конденсации из-за неравномерности потока и нестационарных режимов.
