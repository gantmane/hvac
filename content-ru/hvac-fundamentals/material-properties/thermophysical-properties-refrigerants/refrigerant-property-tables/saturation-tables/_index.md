## Обзор

Таблицы насыщения — основной справочный материал для анализа парокомпрессионного холодильного цикла. Они содержат термодинамические свойства хладагента в состоянии равновесия жидкой и паровой фаз при единственной независимой переменной (температуре или давлении). Состояние насыщения соответствует точке на куполе фазового равновесия: слева — переохлаждённая жидкость, справа — перегретый пар.

В системах ОВК и холодоснабжения таблицы насыщения применяются для: расчёта холодопроизводительности испарителя ($Q = \dot{m} \cdot h_{fg}$), определения рабочих давлений по заданным температурам кипения и конденсации, анализа качества хладагента в двухфазной зоне, диагностики негерметичности по сопоставлению давления/температуры на нагнетании и всасывании. Стандартные таблицы основаны на уравнениях состояния NIST REFPROP v10 и публикуются в ASHRAE Handbook — Fundamentals, Ch. 30.

## Физические основы

### Уравнение Клаузиуса-Клапейрона

Зависимость давления насыщения от температуры описывается дифференциальным уравнением Клаузиуса-Клапейрона:

{{< formula display="true" >}}
\frac{dp_{\text{sat}}}{dT} = \frac{h_{fg}}{T \cdot v_{fg}}
{{< /formula >}}

где $h_{fg} = h_g - h_f$ — удельная теплота испарения (скрытая теплота), кДж/кг; $v_{fg} = v_g - v_f$ — разность удельных объёмов пара и жидкости, м³/кг; $T$ — абсолютная температура, К. Уравнение показывает, что давление насыщения возрастает нелинейно (приблизительно экспоненциально) с температурой — отсюда необходимость таблиц или уравнения Антуана для быстрых расчётов.

### Уравнение Антуана для практических расчётов

Аппроксимация кривой насыщения:

{{< formula display="true" >}}
\lg_{10} p_{\text{sat}} = A - \frac{B}{C + T}
{{< /formula >}}

где $A$, $B$, $C$ — эмпирические константы, специфичные для каждого хладагента; $p_{\text{sat}}$ в кПа; $T$ в °C. Точность 0,5–2 % в рабочем диапазоне (от −40 до +60 °C для большинства HFC).

### Теплота испарения

{{< formula display="true" >}}
h_{fg} = h_g - h_f = (u_g - u_f) + p_{\text{sat}}(v_g - v_f)
{{< /formula >}}

Теплота испарения уменьшается с ростом температуры и обращается в ноль в критической точке. Это определяет снижение холодопроизводительности при повышении температуры конденсации.

## Методика расчёта и интерполяция

### Линейная интерполяция

При значении аргумента между табулированными точками:

{{< formula display="true" >}}
y = y_1 + \frac{x - x_1}{x_2 - x_1}(y_2 - y_1)
{{< /formula >}}

**Пример.** R-134a при $T = 5$ °C: найти $p_{\text{sat}}$ и $h_g$.

Из T-таблицы: при 0 °C — $p_1 = 292{,}7$ кПа, $h_{g1} = 479{,}0$ кДж/кг; при 10 °C — $p_2 = 414{,}4$ кПа, $h_{g2} = 490{,}7$ кДж/кг.

$$p_{\text{sat}}(5) = 292{,}7 + \frac{5-0}{10-0}(414{,}4 - 292{,}7) = 292{,}7 + 60{,}9 = 353{,}6 \text{ кПа}$$
$$h_g(5) = 479{,}0 + 0{,}5 \times (490{,}7 - 479{,}0) = 484{,}9 \text{ кДж/кг}$$

### Логарифмическая интерполяция давления

Поскольку $p_{\text{sat}}$ зависит от $T$ приближённо экспоненциально, логарифмическая интерполяция точнее при больших шагах:

{{< formula display="true" >}}
\ln p = \ln p_1 + \frac{T - T_1}{T_2 - T_1}(\ln p_2 - \ln p_1)
{{< /formula >}}

Точность метода: ±0,3–0,5 % в диапазоне 10–20 °C, против ±1–2 % для линейной интерполяции по $p$.

## Численный пример: расчёт цикла

**Задача.** Холодильная машина на R-410A. Испаритель: $T_{\text{исп}} = -5$ °C, перегрев 10 К. Конденсатор: $T_{\text{конд}} = 45$ °C. Массовый расход: $\dot{m} = 0{,}10$ кг/с. Найти холодопроизводительность и давления.

**Решение.** Из T-таблицы R-410A (интерполяция для −5 °C и 45 °C):

Испаритель ($T = -5$ °C):
$$p_{\text{исп}} = 933{,}5 + \frac{-5-0}{-10-0}(933{,}5 - 1160{,}0) \cdot (-1) \approx 820 \text{ кПа}$$
$$h_{fg}(-5\text{ °C}) \approx 391 \text{ кДж/кг}$$
$$h_g(-5\text{ °C}) \approx 556 \text{ кДж/кг}$$

Конденсатор ($T = 45$ °C):
$$p_{\text{конд}} \approx 2110 + \frac{45-40}{50-40}(2533 - 2110) = 2321 \text{ кПа}$$
$$h_f(45\text{ °C}) \approx 262 \text{ кДж/кг}$$

Холодопроизводительность:

{{< formula display="true" >}}
Q_{\text{исп}} = \dot{m}(h_g - h_f) = 0{,}10 \times (556 - 262) = 29{,}4 \text{ кВт}
{{< /formula >}}

Степень сжатия: $\pi = p_{\text{конд}} / p_{\text{исп}} = 2321 / 820 \approx 2{,}83$.

## Применение в системах ОВК

**Диагностика системы.** Сопоставление измеренного давления нагнетания с $p_{\text{sat}}(T_{\text{конд}})$ из таблицы выявляет неконденсируемые газы (воздух, азот): если $p_{\text{факт}} > p_{\text{sat}}(T)$ — система загрязнена. Аналогично — давление всасывания указывает на нехватку заряда или перегрузку испарителя.

**Выбор давлений при проектировании.** Давление испарения выбирают из таблицы по заданной температуре кипения ($T_{\text{кип}} = T_{\text{воздуха}} - \Delta T_{\text{прибл}}$, где $\Delta T_{\text{прибл}} = 5$–10 К). Давление конденсации — из $T_{\text{конд}} = T_{\text{охл. среды}} + \Delta T_{\text{кон}} = T_{\text{НВ}} + 10$–15 К.

**Расчёт заряда.** Масса хладагента в системе:

{{< formula display="true" >}}
m_{\text{заряд}} = \frac{V_{\text{жидк}}}{v_f} + \frac{V_{\text{пар}}}{v_g} + m_{\text{ресив}} + m_{\text{трубопр}}
{{< /formula >}}

где $v_f$ и $v_g$ берутся из таблиц при рабочих температурах соответствующих участков.

## Стандарты и нормативы

- **ASHRAE Handbook — Fundamentals (2021), Ch. 30** — таблицы свойств хладагентов R-134a, R-410A, R-32, R-290, R-717 и др.
- **NIST REFPROP v10 (NIST Standard Reference Database 23)** — эталонная база уравнений состояния.
- **ISO 817:2014** — обозначение и классификация хладагентов.
- **ASHRAE 34-2022** — классификация безопасности и чистота хладагентов.
- **IAPWS-IF97** — свойства воды и водяного пара (абсорбционные и паровые циклы).
- **СП 60.13330.2020** — проектирование систем ОВК; расчётные значения параметров хладагентов.
- **ГОСТ 28547-2014** — хладагенты фторуглеродные; нормы чистоты и идентификации.

## Практические рекомендации

1. Для прецизионных расчётов (проектирование, аттестация) применяйте NIST REFPROP v10 или CoolProp вместо ручной интерполяции: точность ±0,1–0,3 % против ±1–2 % для линейной интерполяции из печатных таблиц.

2. Проверяйте опорное состояние перед использованием таблиц из разных источников: ASHRAE устанавливает $h_f = 0$ кДж/кг при −40 °C для R-134a, IIR — при 0 °C.

3. Для смесей R-407C, R-448A, R-449A таблицы насыщения содержат отдельные строки для bubble/dew точек. Давление испарителя задаётся по bubble point, перегрев отсчитывается от dew point.

4. Линейная интерполяция давления корректна при $\Delta T \leq 5$ К; для бо́льших интервалов используйте логарифмическую интерполяцию.
