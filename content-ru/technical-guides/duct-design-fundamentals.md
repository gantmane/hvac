# Основы проектирования воздуховодов для инженеров HVAC

Проектирование системы воздуховодов балансирует требования к подаче воздуха, потерям давления, контролю шума и стоимости. Правильный подбор размеров обеспечивает достаточный воздушный поток во все зоны при минимизации энергопотребления вентилятора и затрат на строительство.

## Методы проектирования воздуховодов

### Метод равного трения

Наиболее распространенный метод: поддерживает постоянное падение давления на единицу длины по всей системе.

**Процедура:**
1. Выберите удельное падение давления: обычно 0.08-0.15 "вод. ст./100 фут
2. Подберите размер главного воздуховода для общего расхода CFM при выбранном удельном падении давления
3. Подберите размер ответвлений воздуховодов при том же удельном падении давления для их расхода CFM
4. Рассчитайте общее падение давления = удельное падение давления × эквивалентная длина

**Преимущества:** Простота, широкое применение, доступны таблицы подбора размеров воздуховодов
**Недостатки:** Не оптимизирован по энергопотреблению; все пути имеют разное статическое давление

### Метод восстановления статического давления

Подбирает размеры воздуховодов для поддержания постоянного статического давления на каждом ответвлении.

**Принцип:** Снижение скорости в downstream воздуховоде преобразует скоростное давление обратно в статическое давление, компенсируя потери на трение.

$$P_{s,downstream} = P_{s,upstream} - \Delta P_{friction} + \Delta P_{regain}$$

**Восстановление скорости:**

$$\Delta P_{regain} = \frac{\rho}{2}(v_1^2 - v_2^2)$$

**Преимущества:** Сбалансированная система, устранение регулирующих заслонок, экономия энергии
**Недостатки:** Сложные расчеты, большие размеры воздуховодов, более высокие первоначальные затраты

### Метод скорости

Подбирает размеры воздуховодов на основе максимально допустимых скоростей.

**Типичные пределы скорости:**
- Главные воздуховоды: 1,200-2,000 фут/мин
- Ответвления: 800-1,200 фут/мин
- Финальные ответвления: 600-900 фут/мин

**Преимущества:** Простой контроль шума
**Недостатки:** Отсутствие оптимизации по давлению

## Расчеты подбора размеров воздуховодов

**Площадь круглого воздуховода:**

$$A = \frac{\pi D^2}{4}$$

**Скорость:**

$$v = \frac{Q}{A} = \frac{CFM \times 144}{A_{in^2}}$$

**Число Рейнольдса:**

$$Re = \frac{v D}{\nu}$$

Для стандартного воздуха: $\nu = 1.63 \times 10^{-4}$ фут²/с

**Коэффициент трения** (турбулентный поток, гладкие воздуховоды):

$$f = \frac{0.25}{[\log_{10}(Re/7)]^2}$$

**Падение давления:**

$$\Delta P = f \frac{L}{D} \frac{v^2}{(4005)^2 \times 12.96} \text{ дюйм вод. ст.}$$

## Подбор вентилятора

**Общее давление системы:**

$$\Delta P_{total} = \Delta P_{supply} + \Delta P_{return}$$

**Статическое давление вентилятора:**

$$FSP = TSP - P_{v,discharge}$$

**Мощность вентилятора:**

$$hp = \frac{CFM \times FSP}{6,356 \times \eta}$$

Типичные КПД вентиляторов:
- С вперед загнутыми лопатками: 50-65%
- С назад загнутыми лопатками: 70-80%
- Профильные (airfoil): 80-85%

## Практическое применение

1. **Жилые здания:** Метод равного трения, 0.10 "вод. ст./100 фут
2. **Коммерческие низкие здания:** Метод равного трения, 0.08-0.12 "вод. ст./100 фут
3. **Высокие здания:** Восстановление статического давления для высоких шахт
4. **Системы VAV:** Восстановление статического давления или метод равного трения с контролем давления
