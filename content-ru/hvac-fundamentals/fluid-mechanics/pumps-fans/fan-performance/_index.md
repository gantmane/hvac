Правильная интерпретация характеристик вентилятора и умение строить кривую системы — обязательный навык инженера ОВК. Ошибка в определении рабочей точки ведёт к избыточному шуму, чрезмерному потреблению энергии или недостаточному воздухообмену.

## Давления вентилятора: определения

Применяется три вида давлений (AMCA 210, EN ISO 5801):

{{< formula display="true" >}}
\Delta P_{\text{полн}} = P_{\text{нагн,полн}} - P_{\text{всас,полн}} = (P_{\text{ст,нагн}} + P_{d,\text{нагн}}) - (P_{\text{ст,всас}} + P_{d,\text{всас}})
{{< /formula >}}

{{< formula display="true" >}}
\Delta P_{\text{ст}} = P_{\text{ст,нагн}} - P_{\text{ст,всас}} = \Delta P_{\text{полн}} - P_{d,\text{нагн}}
{{< /formula >}}

где `P_d = ρV²/2` — динамическое давление. **Статическое давление** — полезная работа, затраченная на преодоление сопротивления сети; **полное давление** включает также кинетическую энергию потока на выходе. При подключении вентилятора к воздуховодной системе (вход и выход подключены) используется полное давление; для вентиляторов с открытым выходом применяется статическое.

КПД по статическому давлению (наиболее часто используется в ОВК):

{{< formula display="true" >}}
\eta_{\text{ст}} = \frac{Q \cdot \Delta P_{\text{ст}}}{P_{\text{вал}}}
{{< /formula >}}

КПД по полному давлению:

{{< formula display="true" >}}
\eta_{\text{полн}} = \frac{Q \cdot \Delta P_{\text{полн}}}{P_{\text{вал}}}
{{< /formula >}}

## Законы вентиляторов (аффинные законы)

Для одного вентилятора при изменении частоты вращения (постоянная плотность воздуха):

{{< formula display="true" >}}
\frac{Q_2}{Q_1} = \frac{n_2}{n_1}, \quad \frac{\Delta P_2}{\Delta P_1} = \left(\frac{n_2}{n_1}\right)^2, \quad \frac{P_2}{P_1} = \left(\frac{n_2}{n_1}\right)^3
{{< /formula >}}

При изменении диаметра рабочего колеса (постоянная частота вращения):

{{< formula display="true" >}}
\frac{Q_2}{Q_1} = \left(\frac{D_2}{D_1}\right)^3, \quad \frac{\Delta P_2}{\Delta P_1} = \left(\frac{D_2}{D_1}\right)^2, \quad \frac{P_2}{P_1} = \left(\frac{D_2}{D_1}\right)^5
{{< /formula >}}

При изменении плотности воздуха (n = const, D = const):

{{< formula display="true" >}}
\frac{\Delta P_2}{\Delta P_1} = \frac{\rho_2}{\rho_1}, \quad \frac{P_2}{P_1} = \frac{\rho_2}{\rho_1}, \quad Q_2 = Q_1
{{< /formula >}}

**Поправка на плотность воздуха критически важна** для систем с высотой установки > 1000 м над уровнем моря или при высокой температуре приточного воздуха. Например, в Москве при T = 35 °C ρ = 1,145 кг/м³ вместо стандартных 1,200 кг/м³ при 20 °C. Давление вентилятора при той же скорости снизится на (1,145/1,200 − 1) × 100 = **−4,6 %**. При подборе вентилятора по каталогу (стандартные условия AMCA: 20 °C, 1,2 кг/м³, 101,3 кПа) необходимо скорректировать требуемое давление:

{{< formula display="true" >}}
\Delta P_{\text{кат}} = \Delta P_{\text{треб}} \cdot \frac{\rho_{\text{ст}}}{\rho_{\text{факт}}} = 650 \times \frac{1{,}200}{1{,}145} = 681 \text{ Па}
{{< /formula >}}

## Зона помпажа и нестабильной работы

Центробежный вентилятор с пологой напорной кривой может иметь в левой части «горб» — локальный максимум давления. Если характеристика системы пересекает кривую вентилятора в этой зоне (левее горба), возможна нестабильная работа — **помпаж**: чередование нормальной подачи и обратного потока с частотой 0,5–5 Гц. Симптомы: пульсирующий поток, громкий шум, вибрация.

Осевые вентиляторы имеют более выраженную зону срыва (stall): отрыв потока от лопасти при большом угле атаки (малый расход). Явление сопровождается резким ростом шума и вибрации.

**Правила предотвращения помпажа:**
- Рабочая точка должна иметь запас по расходу не менее 10–15 % от расхода в точке максимального давления
- Не следует применять центробежные вентиляторы с FC-лопатками (загнутые вперёд) в системах с переменным расходом
- При регулировании частоты вращения осевых вентиляторов ниже 50 % — проверить, не попадает ли рабочая точка в зону срыва

## Параллельная работа вентиляторов

При параллельном подключении двух вентиляторов к общей системе суммарная кривая Q-ΔP строится суммированием расходов при одинаковом давлении:

{{< formula display="true" >}}
Q_{\text{сумм}}(\Delta P) = Q_1(\Delta P) + Q_2(\Delta P)
{{< /formula >}}

Параллельная работа эффективна при пологой кривой системы (большой R_сист). Если кривая системы крутая, суммарный расход увеличивается незначительно (на 20–40 % вместо теоретических 100 %).

**Риск при параллельной работе:** при малых расходах (например, при остановке одного вентилятора) давление отсечки работающего вентилятора должно превышать давление, создаваемое системой при нулевом расходе. Иначе вентилятор будет работать в зоне нестабильности.

## Методы регулирования производительности

### Регулирование частоты вращения (ЧРП)

Наиболее энергоэффективный метод для систем с переменным расходом. Экономия мощности при снижении расхода до 60 %: P₂ = P₁ × (0,60)³ = 0,216 · P₁, то есть снижение потребления на **78 %**.

На практике полная кубическая зависимость реализуется только при чисто квадратичной характеристике системы (ΔP_стат = 0). При наличии статической составляющей (фильтры, охлаждающий/нагревательный теплообменник с фиксированными потерями) фактическая экономия меньше.

### Регулирование входными направляющими лопатками (IGV)

Входной закручивающий аппарат (ИЗА / inlet guide vanes) предварительно закручивает поток в направлении вращения рабочего колеса, снижая относительную скорость и давление. По законам подобия — аналог снижения частоты вращения, но с несколько меньшей точностью следования кривой подобия.

Преимущества IGV перед ЧРП: ниже стоимость, нет проблем с гармониками. Недостатки: дополнительные аэродинамические потери при полном открытии лопаток (K ≈ 0,05–0,15 от динамического давления); менее широкий диапазон регулирования (обычно 50–100 %).

### Дроссельные заслонки

Увеличивают R_сист, смещая рабочую точку влево по кривой вентилятора. Энергетически неэффективно. Применяется только для балансировки ветвей или временного ограничения расхода.

### Двухскоростные двигатели

Переключение числа пар полюсов (2/4 пары, частоты 50/25 Гц или 1500/750 об/мин). Грубое регулирование; применяется в системах с двумя фиксированными режимами (день/ночь, лето/зима).

## Числовой пример: экономия от ЧРП для приточного вентилятора AHU

**Условие.** Приточная установка офисного здания. Q_max = 12 000 м³/ч = 3,33 м³/с, ΔP_ст_max = 700 Па. Вентилятор BC с η_ст = 0,80 в BEP. Система работает с переменным расходом: 40 % рабочего времени при 100 % нагрузки, 40 % при 70 % и 20 % при 40 %.

**Мощность вентилятора при 100 % нагрузки:**

{{< formula display="true" >}}
P_{100} = \frac{Q \cdot \Delta P_{\text{ст}}}{\eta_{\text{ст}}} = \frac{3{,}33 \times 700}{0{,}80} = 2913 \text{ Вт} = 2{,}91 \text{ кВт}
{{< /formula >}}

С учётом η_двиг = 0,92 и η_ЧРП = 0,97: P_эл_100 = 2,91 / (0,92 × 0,97) = **3,26 кВт**.

**Режим 70 %** (Q₂ = 0,70 · Q₁, n₂/n₁ = 0,70):

{{< formula display="true" >}}
P_{\text{вал},70} = P_{\text{вал},100} \times (0{,}70)^3 = 2{,}91 \times 0{,}343 = 0{,}998 \text{ кВт}
{{< /formula >}}

P_эл_70 = 0,998 / (0,92 × 0,95) = **1,14 кВт** (η_ЧРП = 0,95 при частичной нагрузке).

**Режим 40 %** (n₂/n₁ = 0,40):

{{< formula display="true" >}}
P_{\text{вал},40} = 2{,}91 \times (0{,}40)^3 = 2{,}91 \times 0{,}064 = 0{,}186 \text{ кВт}
{{< /formula >}}

P_эл_40 = 0,186 / (0,92 × 0,90) = **0,225 кВт** (η_ЧРП = 0,90 при малой нагрузке).

**Взвешенная потребляемая мощность при ЧРП:**

{{< formula display="true" >}}
P_{\text{ср,ЧРП}} = 0{,}40 \times 3{,}26 + 0{,}40 \times 1{,}14 + 0{,}20 \times 0{,}225 = 1{,}304 + 0{,}456 + 0{,}045 = 1{,}80 \text{ кВт}
{{< /formula >}}

**Без ЧРП** (дроссельные заслонки, постоянная скорость): P_ср_дросс ≈ 0,85 × P_100 = 2,77 кВт (дросселирование уменьшает мощность незначительно).

**Экономия:** (2,77 − 1,80) / 2,77 = **35 %** среднегодового потребления. При 4000 часов работы в год: (2,77 − 1,80) × 4000 = **3880 кВт·ч/год**. При тарифе 6 руб./кВт·ч: экономия ≈ 23 300 руб./год.

## Удельная мощность вентилятора SFP

Показатель SFP (Specific Fan Power, Вт/(м³/с)) — стандартный критерий энергоэффективности вентиляционной установки по EN 13779, EN 16798-3 и ГОСТ Р ИСО 12569:

{{< formula display="true" >}}
\text{SFP} = \frac{P_{\text{эл, вент}}}{Q}
{{< /formula >}}

Нормативные значения EN 16798-3 для систем VAV:

{{< table title="Нормативные значения SFP по EN 16798-3" >}}
| Класс SFP | SFP, Вт/(м³/с) | Применение |
|---|---|---|
| SFP1 | ≤ 500 | Высокоэффективные системы; офисы А-класса |
| SFP2 | ≤ 750 | Стандартные офисы, гостиницы |
| SFP3 | ≤ 1250 | Промышленные помещения с умеренными требованиями |
| SFP4 | ≤ 2000 | Специальные применения |
| SFP5 | > 2000 | Не рекомендуется для новых зданий |
{{< /table >}}

Для рассматриваемого примера: SFP = 3260 / 3,33 = **979 Вт/(м³/с)** при максимальной нагрузке — класс SFP3. Для повышения до SFP2 необходимо либо снизить сопротивление системы, либо выбрать вентилятор с более высоким КПД (η_ст > 85 %).
