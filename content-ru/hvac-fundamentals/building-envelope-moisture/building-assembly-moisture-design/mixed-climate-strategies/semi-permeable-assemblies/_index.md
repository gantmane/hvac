## Что такое полупроницаемая конструкция

Полупроницаемой называют конструкцию, в которой паровой замедлитель принадлежит классу II (0,1–1,0 пермя) или классу III (1–10 пермей). В отличие от непроницаемого замедлителя Класса I (≤ 0,1 пермя, полиэтиленовая плёнка), эти материалы **допускают контролируемую диффузию пара** в обоих направлениях. Для смешанного климата, где поток пара сезонно меняет направление, это принципиальное преимущество: конструкция может высыхать как зимой (наружу), так и летом (внутрь).

Ключевые понятия:
- **пермь** (perm) — единица паропроницаемости, 1 пермь = 57,4 нг/(Па·с·м²) = 1 грэн/(ч·фут²·дюйм рт. ст.).
- **паросопротивление** $Z = d/\delta$ [м²·ч·Па/мг] — обратно паропроницаемости слоя.

## Классификация материалов по паропроницаемости

{{< table title="Классы паровых замедлителей по ASHRAE (Fundamentals 2021, гл. 26)" >}}
| Класс | Паропроницаемость | Паросопротивление $Z$, м²·ч·Па/мг | Типичные материалы |
|---|---|---|---|
| I (паронепроницаемый) | ≤ 0,1 пермя | ≥ 5740 | Полиэтилен 0,15 мм, алюмофольга, PIR с фольгой |
| II (полупаронепроницаемый) | 0,1–1,0 | 574–5740 | XPS 25–50 мм, крафт-бумага, некоторые EPS |

| Паропроницаемый | > 10 | < 57 | Минвата, диффузионные мембраны, неокрашенный ГКЛ |

## Класс II: умеренный контроль пара

### Материалы класса II

**XPS (экструдированный пенополистирол):**

| Толщина XPS | Паропроницаемость | $Z$, м²·ч·Па/мг |
|---|---|---|
| 25 мм | ~0,8 пермя | ~720 |
| 50 мм | ~0,4 пермя | ~1440 |
| 100 мм | ~0,2 пермя | ~2870 |

**Крафт-бумага** (приклеена к минвате): 0,3–0,5 пермя.

**EPS 30 мм, высокая плотность:** 0,7–0,9 пермя — граничный Класс II/III.

### Когда применять Класс II

Класс II обоснован в следующих ситуациях:

1. **Зона 5А (Москва, Казань)** без наружной непрерывной изоляции: значительный зимний поток требует более жёсткого контроля у OSB.
2. **Помещения с повышенной внутренней влажностью** (бассейны, бани, прачечные): ОВ > 60 % зимой.
3. **Реконструкция** существующих зданий с неизвестным составом конструкции — Класс II как «страховка».

**Ограничение:** Класс II без наружной паропроницаемой изоляции блокирует зимнее высыхание наружу. Если снаружи — PIR с фольгой (Класс I), изнутри — Класс II, конструкция становится «влажным мешком». Допустимо только если наружный замедлитель отсутствует или является паропроницаемой минватой.

## Класс III: стратегия для смешанного климата

### Материалы класса III

**Латексная краска на ГКЛ:**

{{< table title="Паропроницаемость систем окраски гипсокартона" >}}
| Система | Паропроницаемость | $Z$, м²·ч·Па/мг |
|---|---|---|
| ГКЛ без покрытия | 25–50 пермей | 11–23 |
| Грунтовка + 1 слой латекса | 5–8 пермей | 72–115 |
| Грунтовка + 2 слоя латекса | 3–5 пермей | 115–192 |
| Грунтовка + 3 слоя латекса | 1,5–3 пермя | 192–383 |
| Масляная краска 2 слоя | 0,4–0,9 пермя | 640–1435 |
{{< /table >}}

Стандартная отделка (2 слоя латекса): 3–5 пермей — Класс III, нижняя граница. Это наиболее распространённое решение для смешанного климата.

**OSB-обшивка 12 мм:** 1–2 пермя — Класс II/III. Выполняет двойную роль: конструктивный элемент и умеренный паровой замедлитель.

**EPS 30 мм без покрытия:** 3–5 пермей — Класс III, хорошо работает как наружная изоляция с умеренным паровым сопротивлением.

### Когда Класс III достаточен

Класс III достаточен при соблюдении одного из условий:

1. Наружная непрерывная изоляция обеспечивает $R_{\text{ext}}/R_{\text{total}} \geq 20\%$ (зона 3А) или $\geq 30\%$ (зона 5А).
2. Климатическая зона 3А–4А с умеренным зимним потоком.
3. Применяется умная мембрана (переменная проницаемость), которая зимой эквивалентна Классу II.

## Числовой пример: Казань, зона аналог 5А

### Климатические данные

| Параметр | Январь | Июль |
|---|---|---|
| Температура наружная, °C | −13 | +24 |
| Относительная влажность, % | 84 | 72 |
| $p_v$ наружная, Па | 176 | 2149 |

Внутри: +21 °C / 40 % зимой; +23 °C / 50 % летом.

$\Delta p_v^{\text{зима}} = 994 - 176 = +818$ Па (наружу).

$\Delta p_v^{\text{лето}} = 1281 - 2149 = -868$ Па (внутрь).

### Конструкция: каркас 150 мм + минвата + PIR 50 мм снаружи без фольги

| Слой | $Z_i$, м²·ч·Па/мг (зима) | $R_i$, м²·К/Вт |
|---|---|---|
| ГКЛ + 2 слоя латекса (Класс III) | 154 | 0,05 |
| Минвата в полости 150 мм | 268 | 4,17 |
| OSB 12 мм | 171 | 0,09 |
| PIR 50 мм без фольги (~2 пермя) | 1000 | 2,27 |
| Диффузионная ветрозащита | 5 | — |

$Z_{\text{total,зима}} = 154 + 268 + 171 + 1000 + 5 = 1598$ м²·ч·Па/мг

**Зимний поток:**

{{< formula display="true" >}}
g_{\text{зима}} = \frac{818}{1598} = 0{,}51~\text{мг/(м²·ч)}
{{< /formula >}}

Температура OSB (зима, $T_{\text{ext}} = -13$ °C):

$R_{\text{total}} = 0{,}13 + 4{,}17 + 0{,}09 + 2{,}27 + 0{,}13 = 6{,}79$ м²·К/Вт

$T_{\text{OSB}} = -13 + 34 \times (0{,}13 + 2{,}27) / 6{,}79 = -13 + 34 \times 0{,}354 = -13 + 12{,}0 = -1{,}0$ °C

$p_{\text{sat}}(-1{,}0~°C) = 563$ Па.

Давление пара у внутренней грани OSB:

$p_{v,\text{OSB}} = 994 - 0{,}51 \times (154 + 268) = 994 - 215 = 779$ Па

$779 > 563$ Па — риск конденсации на OSB! Давление пара у OSB превышает $p_{\text{sat}}$.

**Решение:** заменить ГКЛ + латекс на умную мембрану (зима: $Z = 800$):

$Z_{\text{total,зима}} = 800 + 268 + 171 + 1000 + 5 = 2244$ м²·ч·Па/мг

$g_{\text{зима}} = 818 / 2244 = 0{,}365$ мг/(м²·ч)

$p_{v,\text{OSB}} = 994 - 0{,}365 \times (800 + 268) = 994 - 390 = 604$ Па

$604 > 563$ Па — всё ещё граничный случай. Увеличим PIR до 60 мм:

$T_{\text{OSB}} = -13 + 34 \times (0{,}13 + 2{,}73) / 7{,}25 = -13 + 13{,}4 = +0{,}4$ °C

$p_{\text{sat}}(+0{,}4~°C) = 617$ Па.

$p_{v,\text{OSB}} = 994 - 0{,}365 \times (800 + 268) = 604$ Па < 617 Па — конденсации нет (с малым запасом).

**Вывод:** Для зоны 5А (Казань) при каркасной стене с минватой в полости 150 мм необходима умная мембрана изнутри + PIR не менее 60 мм снаружи (без фольги) для обеспечения безопасного влажностного режима OSB по критерию Класса III.

## Двустороннее высыхание: баланс за год

Для конструкции из примера выше проверим летнее высыхание:

$\Delta p_v^{\text{лето}} = -868$ Па (внутрь).

Умная мембрана летом: $Z = 40$ м²·ч·Па/мг.

$Z_{\text{total,лето}} = 40 + 268 + 171 + 1000 + 5 = 1484$ м²·ч·Па/мг

$g_{\text{лето}} = 868 / 1484 = 0{,}585$ мг/(м²·ч) (внутрь)

Поток летом направлен внутрь, через открытую умную мембрану. Полость высыхает в сторону помещения, где влага удаляется системой вентиляции.

Годовой баланс накопленной влаги в OSB:

- Зимний сезон (ноябрь–март, 5 мес.): $g_{\text{зима}} = 0{,}365$ мг/(м²·ч)

  Накопление: $0{,}365 \times 5 \times 30 \times 24 = 1314$ мг/м²

- Летний сезон (июнь–август, 3 мес.): $g_{\text{лето}} = 0{,}585$ мг/(м²·ч) (осушение)

  Осушение: $0{,}585 \times 3 \times 30 \times 24 = 1264$ мг/м²

Баланс: $1314 - 1264 = +50$ мг/м² за год — минимальное накопление, в пределах буферной ёмкости OSB (~4500 мг/м² при изменении СВ на 1 %).
