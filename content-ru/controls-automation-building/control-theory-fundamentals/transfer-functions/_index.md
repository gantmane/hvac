Передаточные функции обеспечивают мощный математический аппарат для анализа и проектирования систем управления без решения дифференциальных уравнений во временной области. Преобразуя уравнения системы в частотную область с помощью преобразований Лапласа, инженеры могут манипулировать сложными динамическими системами, используя алгебраические операции. Этот подход позволяет проводить систематический анализ устойчивости, характеризацию частотной характеристики и проектирование регуляторов для приложений HVAC.

## Основы преобразования Лапласа

Преобразование Лапласа преобразует функции во временной области в комплексную частотную область, упрощая математику дифференциальных уравнений. Для функции во временной области $f(t)$ преобразование Лапласа определяется как:

$$F(s) = \mathcal{L}\{f(t)\} = \int_0^\infty f(t) e^{-st} dt$$

Где $s = \sigma + j\omega$ представляет комплексную переменную частоты с вещественной частью $\sigma$ и мнимой частью $\omega$. Общие пары преобразования Лапласа, используемые в анализе управления, включают:

- Единичный скачок: $\mathcal{L}\{1\} = 1/s$
- Экспоненциальное затухание: $\mathcal{L}\{e^{-at}\} = 1/(s+a)$
- Производная: $\mathcal{L}\{df/dt\} = sF(s) - f(0)$
- Интеграл: $\mathcal{L}\{\int f dt\} = F(s)/s$

Свойства производной и интеграла преобразуют дифференциальные уравнения в алгебраические уравнения, значительно упрощая анализ. Для систем HVAC с нулевыми начальными условиями производные становятся простым умножением на $s$.

## Определение передаточной функции

Передаточная функция представляет отношение преобразования Лапласа выхода к преобразованию Лапласа входа при условии нулевых начальных условий:

$$G(s) = \frac{Y(s)}{U(s)}$$

Где $Y(s)$ — преобразованный выход и $U(s)$ — преобразованный вход. Это отношение полностью характеризует поведение системы «вход-выход» в частотной области.

Для первого порядка термального процесса, такого как нагревательный теплообменник, дифференциальное уравнение, связывающее входную температуру $T_{in}$ с выходной температурой $T_{out}$, имеет вид:

$$\tau \frac{dT_{out}}{dt} + T_{out} = K T_{in}$$

Применяя преобразования Лапласа при нулевых начальных условиях:

$$\tau s T_{out}(s) + T_{out}(s) = K T_{in}(s)$$

Решая для передаточной функции:

$$G(s) = \frac{T_{out}(s)}{T_{in}(s)} = \frac{K}{\tau s + 1}$$

Эта передаточная функция полностью описывает динамический ответ температуры теплообменника без повторного решения дифференциального уравнения для различных входов.

## Полюсы и нули

Передаточные функции могут быть выражены как отношения полиномов по $s$:

$$G(s) = K \frac{(s - z_1)(s - z_2)...(s - z_m)}{(s - p_1)(s - p_2)...(s - p_n)}$$

Нули $z_i$ — это значения $s$, которые обращают числитель в нуль. Полюсы $p_i$ — это значения, которые обращают знаменатель в нуль. Расположение полюсов и нулей в комплексной плоскости определяют устойчивость системы и её динамические характеристики.

Полюсы определяют режимы естественного ответа системы. Для системы первого порядка $G(s) = K/(\tau s + 1)$ единственный полюс находится в точке $s = -1/\tau$. Отрицательный вещественный полюс создает экспоненциальное затухание с постоянной времени $\tau$. Полюсы с положительными вещественными частями создают экспоненциально растущие ответы, указывающие на неустойчивость.

Системы второго порядка имеют два полюса, которые могут быть вещественными или комплексно-сопряженными. Комплексные полюсы создают колебательные ответы с частотой, определяемой мнимой частью, и скоростью затухания, определяемой вещественной частью. Коэффициент демпфирования $\zeta$ и естественная частота $\omega_n$ напрямую связаны с расположением полюсов:

$$s_{1,2} = -\zeta \omega_n \pm j\omega_n\sqrt{1-\zeta^2}$$

Нули влияют на форму и величину ответа, но не на фундаментальную устойчивость. Нуль в правой полуплоскости создает обратный ответ или перерегулирование, когда выход сначала движется в направлении, противоположном его конечному направлению.

## Характеристики ответа системы

Передаточная функция полностью определяет ответ системы на любой вход через теорему свёртки. Для ступенчатого входа величины $A$ выход составляет:

$$Y(s) = G(s) \cdot \frac{A}{s}$$

Обратное преобразование Лапласа дает временной ответ на ступень. Для системы первого порядка:

$$y(t) = AK(1 - e^{-t/\tau})$$

Установившееся усиление равно $K$, получаемое при оценке $G(s)$ в точке $s = 0$. Постоянная времени $\tau$ определяет, как быстро ответ достигает установившегося состояния. После времени $t = 3\tau$ ответ достигает 95% от своего конечного значения.

Системы второго порядка демонстрируют звон и перерегулирование в зависимости от коэффициента демпфирования. Недодемпфированные системы ($\zeta < 1$) колеблются перед стабилизацией. Критически демпфированные системы ($\zeta = 1$) достигают установившегося состояния без колебаний в минимальное время. Передемпфированные системы ($\zeta > 1$) приближаются к установившемуся состоянию медленно без колебаний.

## Представление запаздывания

Запаздывание или транспортная задержка представляет время между управляющим действием и его наблюдаемым эффектом. В системах HVAC запаздывание возникает при транспортировке жидкости по длинным трубопроводам, задержках отклика датчиков и времени движения исполнительного механизма. Запаздывание принципиально ограничивает производительность управления.

Передаточная функция для чистого запаздывания $\theta$ имеет вид:

$$G_d(s) = e^{-\theta s}$$

Этот экспоненциальный член не может быть выражен как отношение полиномов, усложняя аналитический анализ устойчивости. Аппроксимации с использованием аппроксимантов Паде преобразуют экспоненту в рациональные функции:

$$e^{-\theta s} \approx \frac{1 - \theta s/2}{1 + \theta s/2}$$ (аппроксимант Паде первого порядка)

Эта аппроксимация позволяет применять стандартные методы анализа, сохраняя разумную точность при $\omega \theta < 1$.

## Алгебра структурных схем

Структурные схемы представляют системы управления как взаимосвязи передаточных функций. Стандартные конфигурации включают последовательное (каскадное), параллельное (суммирующее) и обратнообратное расположение. Алгебра структурных схем обеспечивает правила упрощения сложных систем в эквивалентные одиночные передаточные функции.

Для систем в последовательном соединении общая передаточная функция равна произведению отдельных передаточных функций:

$$G_{total}(s) = G_1(s) \cdot G_2(s) \cdot G_3(s)$$

Для параллельных путей с суммированием общая передаточная функция равна сумме:

$$G_{total}(s) = G_1(s) + G_2(s)$$

Для цепи с отрицательной обратной связью с прямым путём $G(s)$ и путём обратной связи $H(s)$ передаточная функция замкнутого контура имеет вид:

$$\frac{Y(s)}{R(s)} = \frac{G(s)}{1 + G(s)H(s)}$$

Знаменатель $1 + G(s)H(s)$ называется характеристическим уравнением. Его корни определяют устойчивость замкнутого контура.

## Частотная характеристика

Подстановка $s = j\omega$ в передаточную функцию дает частотную характеристику, описывающую, как система реагирует на синусоидальные входы различных частот. Амплитуда $|G(j\omega)|$ указывает усиление на каждой частоте, а фаза $\angle G(j\omega)$ указывает временной сдвиг.

Для системы первого порядка $G(s) = K/(\tau s + 1)$:

$$|G(j\omega)| = \frac{K}{\sqrt{1 + (\omega\tau)^2}}$$

$$\angle G(j\omega) = -\arctan(\omega\tau)$$

На низких частотах ($\omega \ll 1/\tau$) усиление приближается к $K$, а фаза приближается к 0°. На высоких частотах ($\omega \gg 1/\tau$) усиление уменьшается как $1/\omega$, а фаза приближается к -90°. Угловая частота $\omega = 1/\tau$ создает усиление $K/\sqrt{2}$ и фазу -45°.

Диаграммы Боде отображают амплитуду (в децибелах) и фазу в зависимости от частоты (в логарифмической шкале). Эти графики позволяют быстро оценить полосу пропускания, резонансные пики и запасы по фазе без подробных расчетов.

## Примеры систем HVAC

Исполнительный механизм заслонки VAV обычно ведет себя как система первого порядка. Если исполнительный механизм имеет время хода 30 секунд, постоянная времени составляет приблизительно $\tau = 10$ секунд. Передаточная функция, связывающая командное напряжение с положением заслонки, имеет вид:

$$G(s) = \frac{K_{damper}}{10s + 1}$$

Где $K_{damper}$ преобразует напряжение в положение. Угловая частота равна $1/10 = 0,1$ рад/с или 0,016 Гц, указывая, что исполнительный механизм не может реагировать на сигналы управления быстрее, чем примерно один цикл в минуту.

Тепловая реакция помещения на тепловой вход может быть смоделирована как первый порядок с постоянной времени 15-30 минут в зависимости от конструкции. Эта медленная реакция позволяет консервативную настройку управления температурой:

$$G_{room}(s) = \frac{K_{thermal}}{1800s + 1}$$

Где постоянная времени 1800 секунд (30 минут) создает угловую частоту 0,00056 рад/с или 0,00009 Гц.

Охлажденный водяной теплообменник со значительным объемом воды и потоком воздуха создает ответ второго порядка с потенциалом колебаний, если регулирующий клапан модулируется слишком агрессивно. Передаточная функция может быть:

$$G_{coil}(s) = \frac{K}{\tau^2 s^2 + 2\zeta\tau s + 1}$$

Надлежащий авторитет клапана и настройка управления обеспечивают адекватное демпфирование ($\zeta > 0,7$) для предотвращения колебаний температуры.

## Передаточные функции регулятора

Регуляторы PID также имеют передаточные функции. Идеальный регулятор PID в s-области имеет вид:

$$G_c(s) = K_p + \frac{K_i}{s} + K_d s$$

Интегральный член $K_i/s$ имеет полюс в начале координат, обеспечивая бесконечное усиление при нулевой частоте для исключения установившейся ошибки. Дифференциальный член $K_d s$ линейно увеличивает усиление с частотой, обеспечивая упреждение по фазе, которое улучшает устойчивость.

Практические реализации PID включают фильтр на дифференциальном члене для ограничения высокочастотного усиления:

$$G_c(s) = K_p + \frac{K_i}{s} + \frac{K_d s}{\tau_f s + 1}$$

Где $\tau_f$ обычно составляет одну десятую постоянной времени дифференцирования, ограничивая усиление дифференцирования на высоких частотах для снижения усиления шума.
