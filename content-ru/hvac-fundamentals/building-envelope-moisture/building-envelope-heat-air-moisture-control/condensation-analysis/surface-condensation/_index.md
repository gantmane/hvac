Поверхностная конденсация (surface condensation) возникает, когда температура внутренней поверхности ограждающей конструкции опускается ниже температуры точки росы прилегающего воздуха. Это наиболее визуально заметная форма конденсации: влага образуется на стёклах, откосах, в углах и на других холодных участках ограждения. Длительное намокание поверхности создаёт условия для роста плесени, коррозии металлических элементов и деградации отделочных материалов.

Нормативная основа: ASHRAE 160, ISO 13788 (метод Глазера), ISO 10211 (тепловые мосты), NFRC 500 (остекление), СП 50.13330.

## Физический критерий и температура точки росы

Условие образования поверхностной конденсации:

{{< formula display="true" >}}
T_{\text{si}} \leq T_{\text{dp}} \implies \text{конденсация}
{{< /formula >}}

где T\_si — температура внутренней поверхности, °C; T\_dp — температура точки росы прилегающего воздуха, °C.

Температура точки росы рассчитывается по формуле Магнуса–Тетенса:

{{< formula display="true" >}}
T_{\text{dp}} = \frac{243{,}04 \cdot \left[\ln\!\left(\dfrac{\varphi}{100}\right) + \dfrac{17{,}625\,T_i}{243{,}04 + T_i}\right]}{17{,}625 - \ln\!\left(\dfrac{\varphi}{100}\right) - \dfrac{17{,}625\,T_i}{243{,}04 + T_i}}
{{< /formula >}}

## Температура внутренней поверхности и коэффициент fRsi

### Расчёт температуры поверхности

Для однородного сечения конструкции (установившийся режим):

{{< formula display="true" >}}
T_{\text{si}} = T_i - \frac{(T_i - T_e) \cdot R_{si}}{R_{\text{total}}}
{{< /formula >}}

где R\_si = 0,13 м²·K/Вт — сопротивление внутреннего поверхностного слоя при горизонтальном тепловом потоке (ISO 6946); R\_total — полное тепловое сопротивление конструкции, м²·K/Вт.

### Температурный коэффициент fRsi

Нормализованный показатель качества конструкции по ISO 13788:

{{< formula display="true" >}}
f_{Rsi} = \frac{T_{\text{si}} - T_e}{T_i - T_e} = 1 - \frac{R_{si}}{R_{\text{total}}}
{{< /formula >}}

Чем ближе f\_Rsi к 1, тем теплее внутренняя поверхность относительно перепада температур.

Минимально допустимый коэффициент:

{{< formula display="true" >}}
f_{Rsi,\min} = \frac{T_{\text{dp}} - T_e}{T_i - T_e}
{{< /formula >}}

Условие выполнено, если f\_Rsi,факт ≥ f\_Rsi,min.

|---|---|---|
| Горизонтальный (вертикальные поверхности) | 0,13 | 0,04 |
| Вверх (горизонтальные поверхности, полы) | 0,10 | 0,04 |

## Численный пример: стена в Москве, январь

### Исходные данные

Конструкция: кирпич 380 мм (λ = 0,58 Вт/(м·K)) + минвата 100 мм (λ = 0,038) + ГКЛ 12,5 мм (λ = 0,21). R\_total = 0,13 + 0,655 + 2,632 + 0,060 + 0,04 = **3,517 м²·K/Вт**.

Условия: T\_i = 20°C, φ\_i = 50%, T\_e = −26°C.

### Точка росы внутреннего воздуха

{{< formula display="true" >}}
T_{\text{dp}} = \frac{243{,}04 \cdot (0{,}541)}{17{,}084} = 7{,}7\ °\text{C}
{{< /formula >}}

### Температура поверхности

{{< formula display="true" >}}
T_{\text{si}} = 20 - \frac{46 \cdot 0{,}13}{3{,}517} = 20 - 1{,}70 = 18{,}3\ °\text{C}
{{< /formula >}}

### Температурный коэффициент

{{< formula display="true" >}}
f_{Rsi} = \frac{18{,}3 + 26}{46} = 0{,}963
{{< /formula >}}

Требуемый минимум:

{{< formula display="true" >}}
f_{Rsi,\min} = \frac{7{,}7 + 26}{46} = 0{,}733
{{< /formula >}}

Запас: 0,963 − 0,733 = **0,230**. Поверхностная конденсация отсутствует.

Запас по температуре: T\_si − T\_dp = 18,3 − 7,7 = **10,6°C** >> 2,8°C (проектная цель).

## Тепловые мосты

### Линейная теплопроводность ψ

Линейный тепловой мост (linear thermal bridge) характеризуется коэффициентом ψ (Вт/(м·K)), определяемым двухмерным анализом по ISO 10211:

{{< formula display="true" >}}
\psi = L_{2D} - \sum_j U_j \cdot l_j \quad \text{[Вт/(м·K)]}
{{< /formula >}}

где L\_2D — коэффициент теплового сцепления из 2D расчёта; U\_j — коэффициент теплопередачи j-го одномерного сечения; l\_j — его длина.

Дополнительные теплопотери через мост:

{{< formula display="true" >}}
Q_{\text{мост}} = \psi \cdot L \cdot (T_i - T_e) \quad \text{[Вт]}
{{< /formula >}}

### Минимальная температура поверхности в зоне моста

Для оценки fRsi в точке теплового моста используют точечную теплопроводность χ (Вт/K) или результаты численного расчёта. Практическое правило: у стального стержня в бетонной плите T\_si может быть на 6–12°C ниже поля стены.

{{< table title="Типичные тепловые мосты и снижение температуры поверхности" >}}
| Тип узла | ψ, Вт/(м·K) | Снижение T\_si, °C | Риск |
|---|---|---|---|
| Стальная стойка 150×1,5 мм в утеплителе | 0,8–1,2 | 6–10 | Высокий |
| Бетонная перемычка без теплоизоляции | 0,5–0,8 | 4–7 | Высокий |
| Балконная плита без термоизолятора | 0,3–0,8 | 3–8 | Высокий |
| Примыкание стена/кровля с наружной изоляцией | 0,05–0,15 | 0,5–1,5 | Низкий |
| Оконный блок в кирпичном откосе | 0,1–0,3 | 1–3 | Умеренный |
{{< /table >}}

### Влияние стальных стоек (steel stud framing)

Стальной профиль λ ≈ 50 Вт/(м·K) создаёт значительный мост через утеплитель полости. Эффективное R-значение сборки рассчитывается параллельными путями:

{{< formula display="true" >}}
\frac{1}{R_{\text{eff}}} = \frac{f_s}{R_{\text{stud}}} + \frac{1 - f_s}{R_{\text{cavity}}}
{{< /formula >}}

где f\_s — доля площади стоек (обычно 0,15–0,22). Стальная обшивка без наружного непрерывного утеплителя снижает R\_eff на 40–60% по сравнению с расчётным значением чистого поля.

## Конденсация на остеклении

### Температура центра стекла

{{< formula display="true" >}}
T_{\text{glass}} = T_i - (T_i - T_e) \cdot \frac{R_{si}}{1/U_{\text{cog}}}
{{< /formula >}}

где U\_cog — коэффициент теплопередачи центра стекла (centre of glazing), Вт/(м²·K).

### Рейтинг устойчивости к конденсации (CRF)

NFRC 500 определяет рейтинг CR (condensation resistance) как меру способности остеклённой конструкции поддерживать температуру поверхности выше точки росы:

{{< formula display="true" >}}
\text{CR} = 100 \cdot \left(1 - U_{\text{окно}} \cdot R_{si}\right)
{{< /formula >}}

CR варьируется от 0 до 100; CR ≥ 60 рекомендуется для холодного климата.

{{< table title="Сравнение типов остекления при T\_i = 20°C, φ\_i = 50%, T\_e = −26°C" >}}
| Тип остекления | U\_cog, Вт/(м²·K) | T\_glass,°C | CR | Конденсация? |
|---|---|---|---|---|
| Одинарное | 5,9 | 4,3 | 23 | Да (T\_dp = 9,3°C) |
| Двойное, воздух | 2,8 | 12,1 | 64 | Нет |
| Двойное, аргон, Low-e | 1,6 | 15,5 | 79 | Нет |
| Тройное, аргон, Low-e | 0,9 | 17,5 | 88 | Нет |
{{< /table >}}

## Критерии ASHRAE 160

ASHRAE 160 устанавливает критерии предотвращения роста плесени на внутренних поверхностях через скользящее среднее относительной влажности поверхности (surface relative humidity, SRH) за 30 суток:

{{< formula display="true" >}}
\overline{\varphi}_{\text{surf,30d}} = \frac{1}{30}\sum_{i=1}^{30} \varphi_{\text{surf},i} < 80\%
{{< /formula >}}

Относительная влажность поверхности:

{{< formula display="true" >}}
\varphi_{\text{surf}} = \frac{p_{\text{sat}}(T_{\text{si}})}{p_{\text{sat}}(T_i)} \cdot \varphi_i
{{< /formula >}}

Мгновенное значение φ\_surf < 100% (конденсация недопустима в любой момент).

Дополнительный критерий — индекс роста плесени M < 3 по модели VTT (Viitanen et al.), встроенной в ASHRAE 160 и инструменты WUFI.

## Углы и многомерный тепловой поток

Внутренние углы (пересечение двух наружных стен) испытывают двухмерный тепловой поток, снижающий температуру поверхности на 2–6°C относительно поля стены. Численный расчёт угла (ISO 10211) обязателен при f\_Rsi поля стены < 0,80.

Практические меры: непрерывная изоляция до линии угла, местное утолщение изоляционного слоя, улучшение циркуляции воздуха (устранение застойных зон за мебелью).

## Инфракрасная термография

Термографическое обследование (EN 13187 / ISO 6781) позволяет непосредственно измерить распределение температур на внутренних поверхностях и выявить зоны риска конденсации.

Требования к съёмке: перепад ΔT ≥ 10°C между внутренним и наружным воздухом, здание находится в отопительном режиме не менее 12 ч, коэффициент излучательности поверхности ε = 0,90–0,95.

{{< table title="Интерпретация тепловых аномалий" >}}
| Снижение T\_si относительно поля | Уровень риска | Вероятная причина |
|---|---|---|
| 1–2 K | Низкий | Нормальное рассеяние |
| 3–5 K | Умеренный | Незначительный тепловой мост |
| 5–8 K | Высокий | Значительный тепловой мост |
| > 8 K | Критический | Отсутствие изоляции или дефект |
{{< /table >}}

Запас от конденсации: T\_si,измер − T\_dp ≥ 1,7°C — приемлемо; < 1,0°C — требуется вмешательство.

## Стратегии предотвращения

### Тепловая защита

Увеличение R\_total снижает долю R\_si / R\_total и поднимает T\_si. Непрерывная наружная изоляция (continuous exterior insulation) устраняет тепловые мосты через стойки каркаса; минимальная доля наружного слоя — 30% от R\_total в климатических зонах 5–8.

### Контроль влажности в помещении

{{< table title="Рекомендуемая максимальная φ\_i для предотвращения поверхностной конденсации (T\_i = 20°C, при различных T\_e)" >}}
| T\_e, °C | Максимальная φ\_i (f\_Rsi = 0,85) | Максимальная φ\_i (f\_Rsi = 0,75) |
|---|---|---|
| −10 | 65% | 55% |
| −20 | 55% | 45% |
| −26 | 50% | 40% |
| −30 | 45% | 35% |
{{< /table >}}

Практические меры: вытяжная вентиляция кухонь и санузлов (ASHRAE 62.2), рекуперативная приточная вентиляция (ERV/HRV), осушение при избыточной влажности.

### Критические узлы детализации

**Примыкание стена–фундамент:** непрерывная изоляция через кромку обвязки плиты; отсутствие тепловых замыканий через металлические крепёжные элементы.

**Оконный проём:** изоляция в четверти откоса; непрерывный воздухозащитный слой по периметру рамы; рекомендованный CR остекления ≥ 60 для климата Москвы.

**Узел кровля–стена:** энергетическая ферма (raised-heel truss) для доведения изоляции до проектной толщины над верхней обвязкой стены; исключение «холодного угла».

**Балконная плита:** термовкладыш (structural thermal break insert) для разрыва теплопроводного контакта железобетонной плиты с наружным воздухом; снижает ψ с 0,5–0,8 до 0,05–0,15 Вт/(м·K).

## Верификация

**Расчётная:** THERM (LBNL) для 2D теплотехнического расчёта узлов по ISO 10211; WUFI Ornament или WUFI 2D для гигротермального анализа поверхности.

**Полевая:** термографическое обследование по EN 13187 в отопительный период; тест на воздухопроницаемость по EN 13829 (допустимо n₅₀ ≤ 3,0 ч⁻¹); контроль влажности поверхности в критических зонах.

{{< table title="Критерии приёмки" >}}
| Параметр | Цель | Приемлемо | Неприемлемо |
|---|---|---|---|
| f\_Rsi | ≥ 0,80 | ≥ 0,70 | < 0,60 |
| Запас T\_si − T\_dp | ≥ 2,8 K | ≥ 1,7 K | < 1,0 K |
| φ\_surf (30-сут среднее) | < 70% | < 80% | ≥ 80% |
| ψ тепловых мостов | < 0,10 Вт/(м·K) | < 0,20 | ≥ 0,30 |
| CR остекления | ≥ 70 | ≥ 60 | < 50 |
{{< /table >}}
