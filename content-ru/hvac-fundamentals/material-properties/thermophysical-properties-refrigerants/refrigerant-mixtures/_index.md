Смеси холодильных агентов содержат два или более компонента, подобранных для достижения требуемого сочетания энергоэффективности, экологических показателей (GWP, ODP) и профиля безопасности. Понимание термодинамики смесей обязательно для точного прогнозирования производительности систем, правильной заправки и управления утечками.

## Классификация смесей

Хладагентные смеси классифицируются по характеру фазового перехода в соответствии с ASHRAE Standard 34 и ISO 817.

### Зеотропные смеси (zeotropic blends)

Зеотропные смеси демонстрируют **температурный глайд** (temperature glide) при фазовом переходе: компоненты имеют различную летучесть, поэтому состав жидкой и паровой фаз меняется в процессе испарения и конденсации.

**Характерные особенности:**
- Температура кипения и конденсации при постоянном давлении не постоянна.
- Состав паровой фазы обогащён более летучим компонентом.
- Глайд {{< formula >}}\Delta T_{\text{глайд}} = T_{\text{росы}} - T_{\text{кипения}}{{< /formula >}} составляет 1–6 °C.
- При утечке пара состав оставшейся жидкости изменяется (фракционирование).
- Заправка обязательно проводится жидкостной фазой из баллона.

Обозначения по ASHRAE 34: серия 400 (R-407C, R-407A, R-417A и др.).

### Азеотропные смеси (azeotropic blends)

Азеотропные смеси при определённом составе ведут себя при фазовом переходе как однокомпонентное вещество: составы жидкой и паровой фаз совпадают.

**Характерные особенности:**
- Нулевой температурный глайд.
- Отсутствие фракционирования при утечках.
- Заправка возможна как жидкостью, так и паром без изменения состава.
- Упрощённый расчёт теплообменников — аналогичен чистому веществу.

Обозначения по ASHRAE 34: серия 500 (R-507A, R-500, R-502 и др.).

### Близкоазеотропные смеси

Промежуточный тип с глайдом менее 0,5 °C. R-410A (R-32/R-125, 50/50 % мас.) — наиболее распространённый пример. Практически ведёт себя как азеотроп, допускает доливку при небольших утечках.

## Температурный глайд: физический механизм

При испарении зеотропной смеси более летучий компонент (с более высоким давлением насыщения при данной температуре) испаряется преимущественно. Жидкость обогащается менее летучим компонентом, её температура кипения повышается. Суммарный подъём температуры по мере испарения при постоянном давлении — это и есть глайд.

{{< formula display="true" >}}
\Delta T_{\text{глайд}} = T_{\text{росы}}(P) - T_{\text{кипения}}(P)
{{< /formula >}}

{{< table title="Температурный глайд распространённых зеотропных смесей" >}}
| Хладагент | Состав, % мас. | Глайд при −5 °C (кипение) | Глайд при 40 °C (конденсация) |
|-----------|---------------|---------------------------|-------------------------------|
| R-407C | R-32/125/134a (23/25/52) | 6,1 °C | 4,4 °C |
| R-407A | R-32/125/134a (20/40/40) | 5,0 °C | 3,9 °C |
| R-417A | R-125/134a/600 (46,6/50/3,4) | 5,0 °C | 3,9 °C |
| R-404A | R-125/143a/134a (44/52/4) | 0,6 °C | 0,4 °C |
| R-410A | R-32/125 (50/50) | 0,2 °C | 0,1 °C |
{{< /table >}}

Источник: NIST REFPROP v10; ASHRAE Handbook Fundamentals, гл. 30.

### Влияние глайда на теплообменники

В **противоточном испарителе** температура хладагента повышается по ходу течения жидкости — профили температур хладагента и теплоносителя сближаются, что снижает среднелогарифмическую разность температур (LMTD, log mean temperature difference). Для точного расчёта необходимо использовать значения температуры точки кипения и точки росы раздельно.

В **прямоточном испарителе** глайд ухудшает теплообмен: в начале кипит более летучий компонент при низкой температуре, в конце — менее летучий при высокой, что увеличивает среднюю разность температур с теплоносителем.

Максимальное использование глайда достигается в геотермальных или водяных тепловых насосах с широким диапазоном температур теплоносителя (ΔT воды 5–15 °C) при противоточной схеме.

## Фракционирование

Фракционирование (fractionation) — изменение состава смеси вследствие предпочтительного фазового перехода одного из компонентов.

### Фракционирование при утечке

При утечке пара из системы с зеотропным хладагентом более летучий компонент предпочтительно улетучивается. Оставшийся заряд обогащается менее летучим компонентом; давление насыщения, COP и холодопроизводительность изменяются. Диагностика по диаграммам P–T перестаёт соответствовать исходным данным производителя.

{{< table title="Чувствительность к фракционированию при утечке пара" >}}
| Хладагент | Чувствительность | Действие при значительной утечке |
|-----------|-----------------|----------------------------------|
| R-407C    | Высокая | Полная дозаправка жидкостью |
| R-407A    | Высокая | Полная дозаправка жидкостью |
| R-417A    | Средняя | Полная дозаправка жидкостью |
| R-404A    | Низкая | Доливка допустима при малых утечках |
| R-410A    | Очень низкая | Доливка допустима |
{{< /table >}}

### Фракционирование в ресивере

В жидкостном ресивере более летучий компонент концентрируется в паровом пространстве. При длительной стоянке системы состав стабилизируется через равновесие. Пуск после длительной остановки может сопровождаться временным изменением состава хладагента.

## Расчёт свойств смесей

Термодинамические свойства смесей не определяются простым усреднением свойств компонентов из-за неидеального взаимодействия молекул.

### Уравнения состояния для смесей

NIST REFPROP v10 использует многопараметрические уравнения Гельмгольца с правилами смешивания:

{{< formula display="true" >}}
\alpha_r^{\text{смесь}}(\delta, \tau, \mathbf{x}) = \sum_i x_i \alpha_{r,i}(\delta_i, \tau_i) + \Delta \alpha_r(\delta, \tau, \mathbf{x})
{{< /formula >}}

где {{< formula >}}\Delta \alpha_r{{< /formula >}} — вклад бинарного взаимодействия с параметрами {{< formula >}}\beta_{ij}, \gamma_{ij}, F_{ij}{{< /formula >}}, определяемыми из экспериментальных данных. Точность REFPROP для R-407C, R-410A: ±0,5 % по плотности, ±1,0 % по производным свойствам.

### Точки кипения и росы

Для зеотропной смеси при заданном давлении {{< formula >}}P{{< /formula >}} и составе {{< formula >}}\mathbf{x}{{< /formula >}}:

- **Температура точки кипения** {{< formula >}}T_b{{< /formula >}} (bubble point): при этой температуре формируется первый пузырёк пара. Давление пара первого пузырька равно {{< formula >}}P{{< /formula >}}.
- **Температура точки росы** {{< formula >}}T_d{{< /formula >}} (dew point): при этой температуре конденсируется последняя капля. Состав жидкости при {{< formula >}}T_d{{< /formula >}} отличается от исходного.
- **Глайд**: {{< formula >}}\Delta T = T_d - T_b{{< /formula >}}.

### Расчёт энтальпии смеси

В двухфазной области энтальпия смеси определяется через паросодержание и составы фаз:

{{< formula display="true" >}}
h_{\text{смесь}} = (1 - x) h_l(\mathbf{x}_l,\, P) + x \cdot h_v(\mathbf{x}_v,\, P)
{{< /formula >}}

где {{< formula >}}\mathbf{x}_l{{< /formula >}} и {{< formula >}}\mathbf{x}_v{{< /formula >}} — составы жидкой и паровой фаз (различны для зеотропных смесей). Это означает, что понятие "качество" для смесей требует указания состава, а не только единственного значения {{< formula >}}x{{< /formula >}}.

## Нормативная классификация по ASHRAE 34

ASHRAE Standard 34 присваивает смесям:
- Обозначения серии 400 — зеотропные смеси.
- Обозначения серии 500 — азеотропные смеси.
- Допуски состава: обычно ±2 % мас. на каждый компонент.
- Класс безопасности: A1, A2L, A2, B1, B2L, B2 — по токсичности и горючести.

## Практические требования к заправке

Для зеотропных смесей (R-407C, R-407A, R-417A):

1. Заправка строго из **жидкостного порта** баллона.
2. Допустимо переворачивание баллона (при наличии указаний производителя).
3. После значительной утечки — полная дозаправка: остаток откачать, заправить новой жидкостью.
4. Проверка заряда: измерить давление и температуру в двух точках (точка кипения и точка росы) и сравнить с диаграммами P–T–x производителя.
