Объекты переработки орехов требуют специализированных холодильных систем и контроля окружающей среды для управления тепловыми нагрузками от операций обжарки, предотвращения окислительного прогоркания и поддержания качества продукта на этапах бланширования, покрытия и упаковки. Высокое содержание масла в орехах делает контроль температуры и влажности критическим для продления срока хранения.

## Требования к охлаждению при обжарке

Системы охлаждения после обжарки должны быстро снижать температуру орехов со 140-175°C до температуры упаковки, предотвращая конденсацию влаги и миграцию масла.

### Проектирование системы охлаждения

**Охлаждение в кипящем слое:**
- Скорость воздуха: 150-250 м/мин через слой продукта
- Температура охлаждающего воздуха: 10-15°C
- Время охлаждения: 3-8 минут в зависимости от размера ореха
- Объем воздуха: 2000-3500 м³/ч на тонну орехов
- Отвод тепла: 350-450 кДж/кг для обжаренного арахиса
- Снижение температуры: 150°C до 30-35°C

**Ленточные конвейеры охлаждения:**
- Длина конвейера: 12-20 метров для адекватного времени пребывания
- Температура подаваемого воздуха: 12-18°C
- Скорость воздуха: 100-180 м/мин перпендикулярно направлению движения продукта
- Максимальная глубина слоя продукта: 25-50 мм
- Холодопроизводительность: 120-180 кВт на тонну/час пропускной способности

**Барабанные охладители:**
- Частота вращения барабана: 8-15 об/мин
- Поток охлаждающего воздуха: прямоточная или противоточная конфигурация
- Температура воздуха: 8-15°C для фазы быстрого охлаждения
- Коэффициент теплопередачи: 25-40 Вт/м²·K
- Время пребывания: 10-15 минут

## Холодное хранилище для предотвращения прогоркания

Охлаждаемое хранилище замедляет окисление липидов и продлевает срок хранения путем снижения активности ферментов и предотвращения деградации масла в высокожирных орехах.

### Требования к температуре хранения

**Хранение неочищенных орехов:**
- Температура: 0-4°C для древесных орехов, 2-7°C для арахиса
- Относительная влажность: 65-70% для предотвращения увлажнения ядра
- Циркуляция воздуха: 0,5-1,0 воздухообмена в час
- Длительность хранения: 12-18 месяцев при оптимальных условиях
- Тепло дыхания: 0,05-0,12 Вт/тонну (минимально по сравнению с нагрузками переработки)

**Хранение очищенных орехов:**
- Температура: -1 до 2°C для максимального срока хранения
- Относительная влажность: 55-65% для поддержания влажности 3-6%
- Скорость воздуха: <0,5 м/с для предотвращения высыхания поверхности
- Уровни кислорода: <2% для хранения в инертной атмосфере (премиум-продукты)
- Вместимость хранилища: 150-200 кг/м³ объемная плотность

**Замороженное хранилище (расширенный срок хранения):**
- Температура: -18 до -23°C
- Температура ядра продукта: минимум -18°C
- Скорость замораживания: медленное замораживание допустимо (без риска повреждения клеток)
- Длительность хранения: 24-36 месяцев без ухудшения качества
- Оттаивание: контролируемое при 4-8°C для предотвращения конденсации

|----------------|------------|-----------------|----------------------|---------------------|
| Холодное хранилище неочищенное | 2-4°C | 65-70% | 12-18 | 0,8-1,2 кВт/тонну |

## Охлаждение при бланшировании и покрытии

Тепловые процессы бланширования и нанесения покрытия создают тепловые нагрузки, требующие немедленного охлаждения для предотвращения переработки и поддержания адгезии покрытия.

### Системы охлаждения при бланшировании

**Водяное бланширование:**
- Температура бланширования: 95-100°C в течение 60-180 секунд
- Температура охлаждающей воды: 1-4°C
- Поток охлаждающей воды: 3-5 л/кг переработанных орехов
- Отвод тепла: 280-340 кДж/кг (только явное тепло)
- Холодопроизводительность чиллера: 80-120 кВт для производительности 1000 кг/ч
- Рециркуляция воды: 85-90% с непрерывным охлаждением

**Паровое бланширование:**
- Температура пара: 100-105°C (атмосферное давление)
- Температура после бланширования: 70-85°C
- Температура охлаждающего воздуха: 4-8°C
- Скорость воздуха: 200-300 м/мин для быстрого охлаждения поверхности
- Удаление влаги: 15-25% снижение во время охлаждения
- Холодильная нагрузка: 60-90 кВт на тонну/час пропускной способности

### Охлаждение при нанесении покрытия

**Шоколадное покрытие:**
- Температура ореха перед покрытием: 18-22°C (критическая для адгезии)
- Температура в туннеле охлаждения после покрытия: 8-12°C
- Длина туннеля охлаждения: 15-25 метров
- Скорость ленты: 2-5 м/мин
- Время охлаждения: 3-5 минут для кристаллизации оболочки
- Холодопроизводительность: 40-60 кВт на линию покрытия

**Йогуртное/конфетное покрытие:**
- Температура покрытия: 40-50°C
- Температура охлаждающего воздуха: 10-15°C
- Относительная влажность: 35-45% для предотвращения липкости поверхности
- Скорость воздуха: 150-250 м/мин
- Длительность охлаждения: 4-8 минут
- Нагрузка на осушение: 3-5 кг воды/час на одну линию

## Контроль влажности

Управление содержанием влаги предотвращает отделение масла, сохраняет хрупкость и обеспечивает адгезию покрытия в переработанных ореховых продуктах.

### Равновесие влажности

**Критические диапазоны влажности:**
- Обжаренные орехи: 1,5-3,0% влажности для оптимальной хрупкости
- Сырые неочищенные орехи: 6-9% влажности для стабильности хранения
- Бланшированные орехи: 2,5-4,5% после сушки
- Покрытые продукты: 2,0-3,5% в центре ореха
- Активность воды (aw): 0,20-0,40 для стабильных при хранении продуктов

### Системы осушения

**Осушение с использованием осушителей:**
- Точка росы технологического воздуха: -10 до -20°C
- Температура регенерации: 120-140°C
- Расход воздуха: 1500-2500 м³/ч на тонну/час производства
- Удаление влаги: 4-8 кг воды/час
- Энергопотребление: 2,8-3,5 кВт·ч/кг удаленной воды

**Холодильное осушение:**
- Температура испарителя: 0-3°C
- Температура подаваемого воздуха: 12-16°C
- Контроль относительной влажности: ±3% от заданного значения
- Холодопроизводительность охлаждающего змеевика: 45-70 кВт на зону обработки
- Коэффициент скрытого тепла: 0,35-0,50 (умеренная скрытая нагрузка)

**Условия в помещении упаковки:**
- Температура: 18-22°C
- Относительная влажность: 40-50%
- Воздухообмены: 10-15 в час с HEPA фильтрацией
- Избыточное давление: +10 Па относительно прилегающих помещений
- Точка росы: максимум 5-10°C

## Рассмотрения интеграции системы

**Применение рекуперации тепла:**
- Рекуперация тепла выхлопа обжарки: 40-60% энергии сгорания
- Тепло конденсатора холодильной установки: предварительный нагрев воды для бланширования до 40-50°C
- Тепло компрессора: отопление здания или генерация горячей воды
- Общее снижение энергии: 15-25% с интегрированной рекуперацией тепла

**Выбор холодильной системы:**
- Аммиак (R-717) для больших холодных хранилищ (>500 тонн емкости)
- R-404A или R-448A для приложений технологического охлаждения
- Вторичные контуры с гликолем для охлаждения воды бланширования
- Компрессоры с переменной скоростью для колеблющихся технологических нагрузок
- Конденсаторы с рекуперацией тепла для эффективности рекуперации тепла 60-80%

**Последовательность процесса:**
- Предварительное охлаждение обжаренных орехов перед покрытием предотвращает плавление покрытия
- Период стабилизации влажности (30-60 минут) перед упаковкой
- Выравнивание температуры в холодном хранилище перед отправкой
- Непрерывный мониторинг температуры ядра ореха во время обработки
