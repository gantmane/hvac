## Обзор

Перегретый пар (superheated vapor) — однофазное газообразное состояние хладагента при температуре выше температуры насыщения $T_{sat}$ при данном давлении $p$. Область перегрева охватывает все точки термодинамического цикла между выходом испарителя и выходом конденсатора: линию всасывания компрессора, процесс сжатия и начало конденсации.

Точное знание термодинамических свойств перегретых паров необходимо для:
- расчёта работы компрессора и КПД сжатия;
- проектирования теплообменников — испарителей с зоной перегрева и десупергрейтеров (desuperheater);
- настройки терморегулирующих вентилей (ТРВ) по степени перегрева;
- оценки температуры нагнетания и её влияния на долговечность масла.

Основные источники данных: ASHRAE Handbook — Fundamentals 2021, гл. 30; NIST REFPROP v10. Неопределённость по энтальпии для R-134a и R-32 составляет менее 0,5 % в диапазоне 0…+120 °C.

## Физические принципы

### Термодинамическая согласованность

В области перегрева все свойства взаимосвязаны через фундаментальное соотношение. Полный дифференциал удельной энтальпии:

{{< formula display="true" >}}
dh = c_p \, dT + \left[v - T\left(\frac{\partial v}{\partial T}\right)_p\right] dp
{{< /formula >}}

Аналогично для удельной энтропии:

{{< formula display="true" >}}
ds = c_p \frac{dT}{T} - \left(\frac{\partial v}{\partial T}\right)_p dp
{{< /formula >}}

Для идеального газа $\left(\frac{\partial v}{\partial T}\right)_p = R_m/p$ и скобочный член в выражении для $dh$ обращается в нуль. Реальные хладагенты демонстрируют отклонение от идеального газа, особенно при высоких давлениях и вблизи линии насыщения, — это учитывается в уравнениях состояния Хельмгольца, реализованных в REFPROP v10.

### Уравнение состояния в форме Гельмгольца

Безразмерная свободная энергия Гельмгольца:

{{< formula display="true" >}}
\alpha(\tau, \delta) = \alpha^0(\tau, \delta) + \alpha^r(\tau, \delta)
{{< /formula >}}

где $\tau = T_c / T$ — обратная приведённая температура, $\delta = \rho / \rho_c$ — приведённая плотность. Идеальная часть $\alpha^0$ описывает поведение идеального газа; остаточная часть $\alpha^r$ содержит взаимодействие молекул. Все термодинамические свойства получаются как частные производные $\alpha$ по $\tau$ и $\delta$.

### Степень перегрева

Степень перегрева (superheat, SH) — разность между фактической температурой и температурой насыщения при давлении всасывания:

{{< formula display="true" >}}
\Delta T_{SH} = T_{act} - T_{sat}(p)
{{< /formula >}}

Нормативные диапазоны по ASHRAE Handbook — Refrigeration 2022, гл. 2:
- 5…12 К — на выходе испарителя (контролируется ТРВ);
- 3…8 К — на входе в компрессор (теплоприток от окружающей среды в линии всасывания).

## Ключевые свойства в области перегрева

### Удельный объём

Удельный объём $v$ (м³/кг) растёт с температурой и убывает с давлением. Линейная аппроксимация от линии насыщения:

{{< formula display="true" >}}
v(T, p) \approx v_g^{sat}(p) + \left.\frac{\partial v}{\partial T}\right|_p \cdot (T - T_{sat})
{{< /formula >}}

Типовые значения для R-134a (NIST REFPROP v10):

{{< table title="Удельный объём перегретого пара R-134a (м³/кг)" >}}
| $T$, °C | $p$ = 400 кПа ($T_{sat}$ = −12,7 °C) | $p$ = 800 кПа ($T_{sat}$ = 31,3 °C) | $p$ = 1200 кПа ($T_{sat}$ = 46,3 °C) |
|---------|--------------------------------------|--------------------------------------|---------------------------------------|
| 0 | 0,0527 | — | — |
| 20 | 0,0556 | — | — |
| 40 | 0,0585 | 0,0268 | — |
| 60 | 0,0613 | 0,0285 | 0,0176 |
| 80 | 0,0641 | 0,0302 | 0,0189 |
| 100 | 0,0670 | 0,0318 | 0,0201 |
{{< /table >}}

### Удельная энтальпия

{{< formula display="true" >}}
h(T, p) = h_g^{sat}(p) + \int_{T_{sat}}^{T} c_p(T', p) \, dT'
{{< /formula >}}

При небольших степенях перегрева (ΔT < 30 К) допустима упрощённая формула:

{{< formula display="true" >}}
h(T, p) \approx h_g^{sat}(p) + \bar{c}_p(p) \cdot \Delta T_{SH}
{{< /formula >}}

где $\bar{c}_p$ — среднее значение теплоёмкости в диапазоне перегрева. Для R-134a $\bar{c}_p \approx 920$ Дж/(кг·К) при $p$ = 400 кПа; для R-32 $\bar{c}_p \approx 1040$ Дж/(кг·К) при $p$ = 600 кПа.

### Удельная энтропия

{{< formula display="true" >}}
s(T, p) = s_g^{sat}(p) + \int_{T_{sat}}^{T} \frac{c_p(T', p)}{T'} \, dT'
{{< /formula >}}

При идеальном изоэнтропном сжатии $s$ = const; на T-s диаграмме процесс сжатия идёт вертикально вверх. Реальный компрессор имеет изоэнтропный КПД (isentropic efficiency) $\eta_s = 0{,}70…0{,}85$, поэтому фактическая энтропия на выходе выше.

## Методы расчёта и интерполяция

### Двумерная линейная интерполяция

Свойства перегретого пара задаются на сетке $(p_j, T_i)$. При произвольных $p$ и $T$ применяется последовательная линейная интерполяция:

**Шаг 1.** Интерполяция по температуре при $p_{j}$ и $p_{j+1}$:

{{< formula display="true" >}}
f_j = f_{i,j} + \frac{T - T_i}{T_{i+1} - T_i}(f_{i+1,j} - f_{i,j})
{{< /formula >}}

{{< formula display="true" >}}
f_{j+1} = f_{i,j+1} + \frac{T - T_i}{T_{i+1} - T_i}(f_{i+1,j+1} - f_{i,j+1})
{{< /formula >}}

**Шаг 2.** Интерполяция по давлению:

{{< formula display="true" >}}
f(T, p) = f_j + \frac{p - p_j}{p_{j+1} - p_j}(f_{j+1} - f_j)
{{< /formula >}}

Для давления рекомендуется логарифмическая интерполяция ($\ln p$ вместо $p$), так как свойства изменяются более линейно по $\ln p$.

## Численный пример в системе СИ

**Условие.** Компрессор системы кондиционирования на R-134a всасывает пар при $p_1$ = 400 кПа и $T_1$ = 20 °C. Давление нагнетания $p_2$ = 1200 кПа. Изоэнтропный КПД компрессора $\eta_s$ = 0{,}78. Рассчитать:
1. степень перегрева на входе;
2. удельную работу компрессора;
3. фактическую температуру нагнетания.

**Решение.**

Шаг 1. Температура насыщения при $p_1$ = 400 кПа (из таблиц насыщения, NIST REFPROP v10):

{{< formula display="true" >}}
T_{sat}(400 \text{ кПа}) = -12{,}73 \text{ °C}
{{< /formula >}}

Степень перегрева:

{{< formula display="true" >}}
\Delta T_{SH} = 20 - (-12{,}73) = 32{,}73 \text{ К}
{{< /formula >}}

*Примечание: по нормативам ASHRAE рекомендуется 5…12 К; 32 К — нетипично высокое значение, соответствует плохой изоляции линии всасывания.*

Шаг 2. Начальное состояние (по таблице выше):

{{< formula display="true" >}}
h_1 = 422{,}47 \text{ кДж/кг}, \quad s_1 = 1{,}7727 \text{ кДж/(кг·К)}
{{< /formula >}}

Шаг 3. Изоэнтропный процесс ($s_{2s} = s_1 = 1{,}7727$ кДж/(кг·К)) при $p_2$ = 1200 кПа. Из таблиц перегрева при 1200 кПа (интерполяция по REFPROP v10):

{{< formula display="true" >}}
h_{2s} \approx 459{,}3 \text{ кДж/кг} \quad \text{при } s = 1{,}7727 \text{ и } p = 1200 \text{ кПа}
{{< /formula >}}

Шаг 4. Удельная работа компрессора:

{{< formula display="true" >}}
w_c = \frac{h_{2s} - h_1}{\eta_s} = \frac{459{,}3 - 422{,}47}{0{,}78} = \frac{36{,}83}{0{,}78} = 47{,}2 \text{ кДж/кг}
{{< /formula >}}

Шаг 5. Фактическая энтальпия нагнетания:

{{< formula display="true" >}}
h_2 = h_1 + w_c = 422{,}47 + 47{,}2 = 469{,}7 \text{ кДж/кг}
{{< /formula >}}

По таблицам перегрева при $p_2$ = 1200 кПа и $h_2$ = 469,7 кДж/кг температура нагнетания:

{{< formula display="true" >}}
T_2 \approx 83 \text{ °C}
{{< /formula >}}

Температура нагнетания 83 °C находится в допустимом диапазоне (не более 95 °C по условиям смазки компрессора). Высокая степень перегрева на входе увеличила температуру нагнетания на ~12 К по сравнению со стандартным перегревом 5 К.

## Применение в системах ОВК

### Линия всасывания

Теплоприток от окружающей среды к линии всасывания (suction line) увеличивает перегрев пара перед компрессором. Нежелательный теплоприток $Q_{SL}$ приводит к росту $\Delta T_{SH}$ и температуры нагнетания без полезного вклада в холодопроизводительность:

{{< formula display="true" >}}
Q_{SL} = \dot{m} \cdot (h_{comp,in} - h_{evap,out}) = \dot{m} \cdot c_p \cdot \Delta T_{SH,extra}
{{< /formula >}}

Линию всасывания необходимо теплоизолировать; рекомендуемое тепловое сопротивление изоляции — не менее 1,0 м²·К/Вт (СП 60.13330.2022, прил. Б).

### Контроль ТРВ по степени перегрева

Терморегулирующий вентиль (ТРВ / TXV) поддерживает заданный перегрев на выходе испарителя, сравнивая давление испарения (через капиллярную трубку) с температурой пара (через термобаллон). Уставка перегрева:

{{< formula display="true" >}}
\Delta T_{SH,set} = T_{bulb} - T_{sat}(p_{evap})
{{< /formula >}}

Типовое значение уставки: 5…8 К для непосредственного расширения (DX-системы).

### Влияние перегрева на COP

Избыточный перегрев (> 15 К) снижает COP из-за роста работы компрессора. Чрезмерное снижение перегрева (< 3 К) создаёт риск жидкостного удара. Оптимальная уставка определяется балансом между защитой компрессора и энергоэффективностью.

{{< table title="Влияние степени перегрева на параметры цикла R-134a (расчёт REFPROP v10)" >}}
| $\Delta T_{SH}$, К | $h_1$, кДж/кг | $T_2$, °C | $w_c$, кДж/кг | COP (отн.) |
|-------------------|--------------|-----------|--------------|-----------|
| 5 | 416,5 | 69 | 44,1 | 1,00 |
| 10 | 421,1 | 73 | 45,5 | 0,97 |
| 20 | 430,3 | 82 | 47,9 | 0,92 |
| 30 | 439,5 | 90 | 50,3 | 0,88 |
{{< /table >}}

*Условия: $p_{evap}$ = 400 кПа, $p_{cond}$ = 1000 кПа, $\eta_s$ = 0,78, переохлаждение 5 К.*

## Стандарты и нормативные источники

- **NIST REFPROP v10** — эталонная база данных термодинамических и транспортных свойств; неопределённость по энтальпии < 0,5 % для основных хладагентов.
- **ASHRAE Handbook — Fundamentals 2021, гл. 30** — таблицы свойств перегретого пара для R-134a, R-410A, R-32, R-22, аммиака и других агентов.
- **ASHRAE Handbook — Refrigeration 2022, гл. 2** — анализ холодильных циклов; рекомендации по степени перегрева и переохлаждения.
- **ASHRAE 34-2022** — классификация и безопасность хладагентов.
- **EN 378-2:2016** — безопасность холодильных систем; предельные температуры нагнетания.
- **СП 60.13330.2022** — нормативные требования к системам кондиционирования; тепловая изоляция трубопроводов.

## Практические рекомендации

1. **Не применяйте линейную аппроксимацию** $c_p \cdot \Delta T$ при степени перегрева выше 30 К — погрешность по энтальпии может достигать 3…5 %; используйте двумерную интерполяцию по таблицам REFPROP.
2. **Контролируйте температуру нагнетания** — предельное значение для большинства компрессоров составляет 90…100 °C; превышение деградирует масло и снижает ресурс компрессора.
3. **Учитывайте тепловой поток в линии всасывания** при размещении термобаллона ТРВ: монтировать на горизонтальном участке трубы перед компрессором, теплоизолируя трубу с учётом местных условий.
4. **Для R-32 и R-410A** температуры нагнетания выше, чем для R-134a при тех же условиях, — предельные значения по документации производителя компрессора.
5. **Смесевые хладагенты** (R-407C, R-410A) имеют свойства перегрева, близкие к чистым компонентам, но требуют уточнённого расчёта через REFPROP с явным заданием состава.
