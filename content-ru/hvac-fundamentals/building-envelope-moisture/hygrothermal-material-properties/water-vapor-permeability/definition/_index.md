## Физическая природа диффузии пара

Диффузия водяного пара через пористый строительный материал — молекулярный процесс, происходящий по трём параллельным механизмам:

1. **Газофазная диффузия** через взаимосвязанные поры и пустоты — доминирующий механизм в большинстве строительных материалов.
2. **Поверхностная диффузия** адсорбированных молекул воды вдоль внутренних поверхностей пор — значима при высокой относительной влажности.
3. **Циклы сорбции–десорбции** в гигроскопичных материалах — создаёт «эстафетный» перенос молекул.

Движущей силой является градиент парциального давления водяного пара {{< formula >}}\nabla p_v{{< /formula >}}, а не градиент общего давления воздуха.

## Закон Фика для диффузии пара

Установившийся поток водяного пара через однородный слой описывается первым законом Фика:

{{< formula display="true" >}}
g = -\delta_p\,\frac{\partial p_v}{\partial x}
{{< /formula >}}

где:
- {{< formula >}}g{{< /formula >}} — плотность потока пара, кг/(м²·с); положительное направление — в сторону убывания {{< formula >}}p_v{{< /formula >}};
- {{< formula >}}\delta_p{{< /formula >}} — коэффициент паропроницаемости материала, кг/(м·с·Па) — **интенсивное** свойство материала, не зависящее от толщины;
- {{< formula >}}\partial p_v / \partial x{{< /formula >}} — градиент парциального давления пара, Па/м.

Для слоя постоянной толщины {{< formula >}}d{{< /formula >}} при линейном профиле давления:

{{< formula display="true" >}}
g = \delta_p\,\frac{p_{v,1} - p_{v,2}}{d} = M\,\Delta p_v
{{< /formula >}}

где {{< formula >}}M = \delta_p / d{{< /formula >}} — паропропускание (permeance), кг/(м²·с·Па) — **экстенсивное** свойство, зависящее от толщины.

## Система обозначений и единицы измерения

### Коэффициент паропроницаемости δ_p

Фундаментальная характеристика материала в системе SI:

{{< formula display="true" >}}
[\delta_p] = \text{кг/(м·с·Па)}
{{< /formula >}}

Для воздуха при 20 °C: {{< formula >}}\delta_{p,\text{воздух}} = 1{,}93\times10^{-10}{{< /formula >}} кг/(м·с·Па).

### Коэффициент сопротивления паропроницанию μ

Безразмерный европейский показатель (EN 12086, ISO 12572):

{{< formula display="true" >}}
\mu = \frac{\delta_{p,\text{воздух}}}{\delta_{p,\text{материал}}}
{{< /formula >}}

Физический смысл: во сколько раз материал хуже пропускает пар, чем стоячий воздух той же толщины. Чем выше {{< formula >}}\mu{{< /formula >}}, тем ниже паропроницаемость.

**Типичные значения μ:**

| Материал | μ |
|---|---|
| Стоячий воздух | 1 |
| Каменная вата | 1,0–1,5 |
| Газобетон (AAC) | 5–10 |
| Гипсокартон | 8–20 |
| Хвойная древесина (поперёк волокон) | 20–50 |
| Кирпич обожжённый | 10–30 |
| Бетон обычный | 30–100 |
| OSB | 30–50 |
| XPS 50 мм | 80–250 |
| Полиэтиленовая плёнка | 50 000–150 000 |

### Эквивалентная толщина воздушного слоя s_d

Удобный параметр для характеристики паросопротивления слоя:

{{< formula display="true" >}}
s_d = \mu\,d\quad[\text{м}]
{{< /formula >}}

Физический смысл: паросопротивление слоя эквивалентно паросопротивлению стоячего воздуха толщиной {{< formula >}}s_d{{< /formula >}} м. Не зависит от материала — позволяет напрямую сравнивать разные слои.

### Паропропускание M и единица «перм»

В американской практике паропропускание измеряется в **пермах**:

{{< formula display="true" >}}
1\;\text{перм (US)} = 1\;\text{гран/(ч·фут}^2\text{·дюйм рт. ст.)} = 5{,}72\times10^{-11}\;\text{кг/(м}^2\text{·с·Па)}
{{< /formula >}}

Пересчёт: {{< formula >}}M\,[\text{перм}] = \frac{M\,[\text{кг/(м}^2\text{·с·Па)}]}{5{,}72\times10^{-11}}{{< /formula >}}.

## Аналогия с тепловыми свойствами

{{< table title="Параллель между тепловыми свойствами и свойствами паропереноса" >}}
| Тепловое свойство | Паровое свойство | Зависимость от толщины |
|---|---|---|
| Теплопроводность λ, Вт/(м·К) | Паропроницаемость δ_p, кг/(м·с·Па) | Не зависит |
| Термическое сопротивление R, м²·К/Вт | Паросопротивление s_d / δ_p, м²·с·Па/кг | Растёт с толщиной |
| Теплопередача U, Вт/(м²·К) | Паропропускание M, кг/(м²·с·Па) | Убывает с толщиной |
{{< /table >}}

**Пример.** XPS плотности 35 кг/м³, μ = 120; толщина 50 мм = 0,05 м:

{{< formula display="true" >}}
\delta_p = \frac{\delta_{p,\text{воздух}}}{\mu} = \frac{1{,}93\times10^{-10}}{120} = 1{,}61\times10^{-12}\;\text{кг/(м·с·Па)}
{{< /formula >}}

{{< formula display="true" >}}
s_d = 120\times 0{,}05 = 6\;\text{м}
{{< /formula >}}

{{< formula display="true" >}}
M = \frac{\delta_p}{d} = \frac{1{,}61\times10^{-12}}{0{,}05} = 3{,}22\times10^{-11}\;\text{кг/(м}^2\text{·с·Па)} \approx 0{,}56\;\text{перм}
{{< /formula >}}

Класс ASHRAE: **II** (0,1–1,0 перм).

## Паросопротивление и последовательное соединение

Паросопротивление слоя:

{{< formula display="true" >}}
R_v = \frac{s_d}{\delta_{p,\text{воздух}}} = \frac{\mu\,d}{\delta_{p,\text{воздух}}}\quad[\text{м}^2\text{·с·Па/кг}]
{{< /formula >}}

Для многослойной конструкции:

{{< formula display="true" >}}
R_{v,\text{total}} = \sum_i R_{v,i} = \frac{1}{\delta_{p,\text{воздух}}}\sum_i s_{d,i}
{{< /formula >}}

{{< formula display="true" >}}
M_\text{assembly} = \frac{1}{R_{v,\text{total}}}
{{< /formula >}}

Слой с наибольшим {{< formula >}}s_d{{< /formula >}} контролирует паропропускание всей сборки.

## Зависимость от влажности

Паропроницаемость многих строительных материалов нелинейно зависит от относительной влажности (влагосодержания). Это вызвано тем, что заполненные водой поры ускоряют поверхностную диффузию и сорбционно-десорбционный транспорт.

**Характерные примеры:**
- **OSB:** μ снижается с ~50 при низкой RH до ~10 при высокой RH (δ_p возрастает в 5 раз).
- **Древесина:** μ снижается с ~50 при 30 % RH до ~10 при 85 % RH.
- **Гипсокартон:** умеренная зависимость, μ изменяется от ~15 до ~8.

Этот эффект используется в **интеллектуальных пароизоляторах** (smart vapour retarders):
- Зимой при низкой RH — высокое μ (паровой барьер, предотвращает конденсацию).
- Летом при высокой RH — низкое μ (паропроницаемость повышается, возможно высыхание в сторону помещения).

Стандарт ASTM E96 рекомендует испытывать материалы в условиях, близких к рабочим. Различие между мокрым и сухим стаканом отражает именно эту нелинейность.

## Зависимость от температуры

Газофазная диффузия ускоряется с температурой приблизительно по закону Аррениуса:

{{< formula display="true" >}}
\delta_p(T) \approx \delta_p(T_0)\,\left(\frac{T}{T_0}\right)^{1{,}81}
{{< /formula >}}

Рост ~1–2 % на каждый °C. Для большинства расчётов ограждающих конструкций температурной зависимостью пренебрегают, используя стандартные данные при 23 °C.

## Методы испытания

### ASTM E96 (США)

Два метода для разных диапазонов паропропускания:

**Сухой стакан (dry cup, Procedure A):**
- Стакан с осушителем (0 % RH изнутри) + камера 50 % RH снаружи.
- Применяется для {{< formula >}}M > 1{{< /formula >}} перм.
- Рост массы стакана пропорционален потоку пара.

**Мокрый стакан (wet cup, Procedure B):**
- Стакан с водой (100 % RH изнутри) + камера 50 % RH снаружи.
- Применяется для {{< formula >}}M < 1{{< /formula >}} перм.
- Убыль массы пропорциональна потоку пара.

**Расчёт паропропускания:**

{{< formula display="true" >}}
M = \frac{G}{A\,\Delta p_v}
{{< /formula >}}

где {{< formula >}}G{{< /formula >}} — скорость передачи пара, кг/с; {{< formula >}}A{{< /formula >}} — площадь образца, м².

### ISO 12572 / EN 12086 (Европа)

Аналогичная чашечная методика. Результат — μ-значение. Два условия испытания:
- Условие A: 0 °C / 0–50 % (сухой диапазон).
- Условие B1: 23 °C / 0–50 % и B2: 23 °C / 50–93 % (совместно дают нелинейную зависимость).

### ГОСТ 25898

Российский стандарт. Результат — {{< formula >}}\delta_p{{< /formula >}} в мг/(м·ч·Па). Пересчёт в кг/(м·с·Па): умножить на {{< formula >}}2{,}78\times10^{-10}{{< /formula >}}.

## Численный пример: независимость δ_p от толщины

**Условие.** Имеется гипсокартон двух толщин: 12,5 мм и 25,0 мм. Измеренные паропропускания: {{< formula >}}M_1 = 20{{< /formula >}} перм и {{< formula >}}M_2 = 10{{< /formula >}} перм соответственно. Проверить постоянство μ.

**Расчёт μ:**

{{< formula display="true" >}}
\delta_{p,1} = M_1 \times d_1 = 20 \times 5{,}72\times10^{-11} \times 0{,}0125 = 1{,}43\times10^{-11}\;\text{кг/(м·с·Па)}
{{< /formula >}}

{{< formula display="true" >}}
\mu_1 = \frac{1{,}93\times10^{-10}}{1{,}43\times10^{-11}} \approx 13{,}5
{{< /formula >}}

{{< formula display="true" >}}
\delta_{p,2} = 10 \times 5{,}72\times10^{-11} \times 0{,}025 = 1{,}43\times10^{-11}\;\text{кг/(м·с·Па)}
{{< /formula >}}

{{< formula display="true" >}}
\mu_2 = \frac{1{,}93\times10^{-10}}{1{,}43\times10^{-11}} \approx 13{,}5
{{< /formula >}}

**Вывод.** μ = 13,5 — одинаково для обеих толщин. Паропроницаемость {{< formula >}}\delta_p{{< /formula >}} — интенсивное свойство, не зависящее от толщины образца. Паропропускание {{< formula >}}M{{< /formula >}} — экстенсивное: удвоение толщины вдвое снижает {{< formula >}}M{{< /formula >}} (удваивает паросопротивление).

## Инженерные применения

**Оценка риска конденсации.** Зная {{< formula >}}\delta_p{{< /formula >}} и граничные условия, рассчитывают профиль {{< formula >}}p_v(x){{< /formula >}} и сравнивают с {{< formula >}}p_{sat}(T(x)){{< /formula >}}. Если {{< formula >}}p_v > p_{sat}{{< /formula >}} — конденсация; позиция — метод Глейзера (ASHRAE, СП 23-101).

**Расчёт времени высыхания.**

{{< formula display="true" >}}
t_\text{dry} \approx \frac{w_\text{initial}\,\rho_0\,d}{M\,\Delta p_v}
{{< /formula >}}

**Выбор пароизолятора.** По классу ASHRAE (I, II, III), климатической зоне и конфигурации конструкции; подробнее — в разделе «Паропроницаемость строительных материалов».

**Оптимизация сборки.** Асимметричное паропропускание: низкое со стороны высокого давления пара, высокое — со стороны высыхания. Никогда не размещать материалы класса I с обеих сторон.

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — уравнения диффузии пара; таблицы δ_p и M для строительных материалов; классификация.
- **ASHRAE 160** — требования к анализу контроля влаги; выбор класса пароизолятора.
- **ASTM E96** — стандартный метод испытания паропропускания материалов (мокрый / сухой стакан).
- **ISO 12572** — чашечный метод определения паропроницаемости строительных материалов.
- **EN 12086** — определение μ-значения; два условия испытания.
- **EN ISO 7783** — паропропускание покрытий для наружных стен.
- **ГОСТ 25898** — паропроницаемость и сорбционное увлажнение строительных материалов.
- **СП 50.13330.2017** — тепловая защита зданий; нормируемое сопротивление паропроницанию.
- **СП 23-101-2004** — проектирование тепловой защиты; расчёт конденсации в толще ограждений (метод Глейзера).
