Расчеты нагрузки образуют основу проектирования систем ОВКВ, определяя мощность отопления и охлаждения, необходимую для поддержания комфорта в условиях проектирования. Точные расчеты нагрузки обеспечивают надлежащий размер оборудования, которое работает эффективно, отвечая потребностям занятых.

## Назначение и значение

### Почему расчеты нагрузки важны

Надлежащие расчеты нагрузки предотвращают:

**Проблемы передизменения**:
- Более высокая первоначальная стоимость оборудования
- Короткие циклы и износ
- Плохой контроль влажности
- Снижение эффективности при частичной нагрузке
- Более крупная электрическая инфраструктура

**Проблемы недоразмеров**:
- Невозможность поддержания комфорта
- Оборудование работает непрерывно
- Жалобы занятых
- Более высокие эксплуатационные расходы
- Преждевременный отказ оборудования

### Философия проектирования

Целевой размер оборудования составляет 95-100% рассчитанной нагрузки:
- Небольшое передизменение (5-10%) приемлемо для неопределенностей
- Избегайте накопления коэффициентов безопасности
- Рассмотрите будущую гибкость, где это оправдано

## Компоненты нагрузок

### Элементы охлаждающей нагрузки

| Компонент | Описание | Типовой % от общего |
|-----------|-------------|-------------------|
| Солнечное излучение (окна) | Радиация через остекление | 15-40% |
| Солнечное излучение (непрозрачное) | Поглощенная радиация на стенах/крыше | 5-15% |
| Передача | Кондукция через ограждение | 10-25% |
| Вентиляция | Наружный воздух чувствительный и скрытый | 15-30% |
| Инфильтрация | Неконтролируемая утечка воздуха | 5-15% |
| Люди | Чувствительное и скрытое тепло занятых | 5-20% |
| Освещение | Тепло от света | 10-25% |
| Оборудование | Подключенные нагрузки, моторы | 10-30% |

### Элементы нагрузки отопления

| Компонент | Описание | Типовой % от общего |
|-----------|-------------|-------------------|
| Передача | Потеря тепла ограждением | 50-70% |
| Вентиляция | Отопление наружного воздуха | 20-40% |
| Инфильтрация | Отопление утечек воздуха | 10-20% |
| Разогрев | Нагрузка на подъем утром | Переменная |

Примечание: Солнечное излучение и внутренние прибыли обычно игнорируются для проектирования отопления (консервативно).

## Методы расчета

### Методы ASHRAE

**Метод теплового баланса**:
- Наиболее точный, основанный на физике
- Требует компьютерное программное обеспечение
- Стандарт для коммерческих зданий

**Серия времени излучения (RTS)**:
- Упрощенная версия теплового баланса
- Подходит для ручных расчетов
- Хорошая точность для большинства приложений

**Метод передаточной функции**:
- Предварительно рассчитанные коэффициенты
- Используется в DOE-2 и производных
- Доказанная точность

### Жилые методы

**ACCA Manual J**:
- Стандарт для жилых помещений
- Требуется многими кодами
- Включает подробные процедуры

**ASHRAE жилые**:
- Процедуры справочника
- Совместимо с концепциями Manual J

### Коммерческие методы

**ACCA Manual N**:
- Процедуры коммерческих зданий
- Ссылки на методы ASHRAE

**Справочник ASHRAE — Основы**:
- Комплексная ссылка
- Подробные процедуры расчета
- Компиляция данных проектирования

## Ключевые расчеты

### Передача тепла передачей

$$Q_{trans} = U \times A \times \Delta T$$

Где:
- U = Общий коэффициент передачи тепла (Btu/ч·фт²·°F)
- A = Площадь поверхности (фт²)
- ΔT = Разница температур (°F)

### Прибыль солнечного тепла

$$Q_{solar} = A \times SHGC \times SC \times SHGF$$

Где:
- SHGC = Коэффициент прибыли солнечного тепла
- SC = Коэффициент затенения
- SHGF = Коэффициент прибыли солнечного тепла

### Вентиляция/инфильтрация

**Чувствительное**:
$$Q_s = 1.08 \times CFM \times \Delta T$$

**Скрытое**:
$$Q_l = 0.68 \times CFM \times \Delta W$$

| Источник | Прибыль тепла |
|--------|-----------|
| Люди | 250-450 Btu/ч чувствительное + скрытое |
| Освещение | 3.4 Btu/ч на ватт |
| Оборудование | Варьируется по типу |

## Инструменты программного обеспечения

### Коммерческое программное обеспечение

- **Carrier HAP**: Программа анализа по часам
- **Trane TRACE**: Комплексное моделирование
- **EnergyPlus**: Инструмент исследования DOE
- **eQUEST**: Интерфейс DOE-2

### Жилое программное обеспечение

- **Wrightsoft**: Расчеты Manual J
- **Программное обеспечение, одобренное ACCA**: Различные варианты
- **Инструменты производителя**: Специфичные для оборудования

### Выходы расчета

Стандартные отчеты включают:
- Нагрузки по комнатам
- Нагрузки сводной зоны
- Нагрузки на блок (здание)
- Данные размеров оборудования
- Анализ пикового времени

## Лучшие практики

### Точность ввода

- Используйте фактические детали конструкции
- Проверьте спецификации окон
- Подтвердите предположения о заполнении
- Учитывайте все внутренние нагрузки

### Условия проектирования

- Используйте надлежащие данные ASHRAE
- Сопоставьте условия с использованием здания
- Рассмотрите требования кодекса

### Проверка

- Просмотрите для разумности
- Проверьте Btu/фт² против эталонов
- Проверьте пиковое время
- Сравните зоны с ожиданиями

Расчеты нагрузки предоставляют основной базис для проектирования систем ОВКВ, обеспечивая надлежащий размер оборудования для эффективного поддержания комфорта при всех ожидаемых условиях операции.
