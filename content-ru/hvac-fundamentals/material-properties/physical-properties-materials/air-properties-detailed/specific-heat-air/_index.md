Удельная теплоёмкость при постоянном давлении c_p — ключевое свойство воздуха для расчётов чувствительного тепла в системах вентиляции и кондиционирования. Произведение ρ·c_p — объёмная теплоёмкость воздуха — входит в формулы тепловой нагрузки, подбора теплообменников и расчётов NTU.

## Термодинамические определения

Для идеального газа (сухой воздух выполняет это условие при HVAC-условиях):

{{< formula display="true" >}}
c_p = \left(\frac{\partial h}{\partial T}\right)_p, \quad c_v = \left(\frac{\partial u}{\partial T}\right)_v, \quad c_p - c_v = R_{уд} = 287{,}05\ \text{Дж/(кг·К)}
{{< /formula >}}

Показатель адиабаты (adiabatic index):

{{< formula display="true" >}}
\gamma = \frac{c_p}{c_v} = 1{,}400 \quad \text{при } T \approx 20\text{ °C}
{{< /formula >}}

В HVAC применяется исключительно c_p, поскольку все процессы обработки воздуха протекают при практически постоянном давлении. Применение c_v вместо c_p занижает тепловую нагрузку на 28% — грубая ошибка.

{{< /table >}}

Источник: ASHRAE Handbook Fundamentals 2021, гл. 33; NIST REFPROP.

Изменение c_p в диапазоне −40…+100 °C составляет менее 0,7% — в практических расчётах принимают **c_p = 1 005 Дж/(кг·К) = const**. Для T > 200 °C необходима полиномиальная аппроксимация.

**Полиномиальная корреляция** (T в К, диапазон 220–1 000 К, погрешность < 0,1%):

{{< formula display="true" >}}
c_p(T) = 1045 - 3{,}162\times10^{-4}\,T + 7{,}084\times10^{-7}\,T^2 - 2{,}705\times10^{-10}\,T^3 \quad \text{Дж/(кг·К)}
{{< /formula >}}

## Влажный воздух

Наличие водяного пара (c_p,пар ≈ 1 860 Дж/(кг·К)) увеличивает эффективную теплоёмкость смеси:

{{< formula display="true" >}}
c_{p,вл} = c_{p,сух} + d \cdot c_{p,пар} = 1{,}006 + 1{,}86\, d \quad \text{кДж/(кг·К)}
{{< /formula >}}

где d — влагосодержание (humidity ratio), кг воды/кг сухого воздуха.

{{< table title="c_p влажного воздуха при p = 101 325 Па" >}}
| T, °C | φ, % | d, г/кг | c_p,вл, кДж/(кг·К) | Превышение над сухим |
|-------|------|---------|---------------------|----------------------|
| 20 | 0 | 0,0 | 1,006 | 0% |
| 20 | 50 | 7,3 | 1,020 | 1,4% |
| 20 | 100 | 14,7 | 1,033 | 2,7% |
| 30 | 50 | 13,5 | 1,031 | 2,5% |
| 30 | 100 | 27,3 | 1,057 | 5,1% |
{{< /table >}}

Для стандартных расчётов тепловых нагрузок в офисах и жилых зданиях (φ ≤ 60%, T ≤ 26 °C) поправка менее 2% — пренебрежимо. В тропическом климате или технологических помещениях учёт влажности обязателен.

## Расчёт чувствительного тепла

**Базовая формула:**

{{< formula display="true" >}}
\dot{Q}_{чувств} = \dot{m}\, c_p\, \Delta T = \rho\, \dot{V}\, c_p\, \Delta T
{{< /formula >}}

При стандартных условиях (ρ = 1,204 кг/м³, c_p = 1,006 кДж/(кг·К)):

{{< formula display="true" >}}
\dot{Q}\ [\text{кВт}] = 1{,}21 \cdot \dot{V}\ [\text{м}^3/\text{с}] \cdot \Delta T\ [\text{К}]
{{< /formula>}}

Коэффициент 1,21 = 1,204 · 1,006 / 1 000 кВт·с/(м³·К). На высоте H = 1 500 м (ρ = 1,005 кг/м³): коэффициент = 1,005 · 1,006 / 1 000 = **1,011** — снижение на 16%.

{{< table title="Коэффициент чувствительного тепла при различных высотах (T = 20 °C)" >}}
| H, м | ρ, кг/м³ | ρ·c_p/1000, кВт·с/(м³·К) |
|------|----------|--------------------------|
| 0 | 1,204 | 1,211 |
| 500 | 1,147 | 1,154 |
| 1 000 | 1,093 | 1,099 |
| 1 500 | 1,041 | 1,047 |
| 2 000 | 0,991 | 0,997 |
{{< /table >}}

**Пример:** Система вентиляции офиса в Алматы (H = 850 м, T_лет = 35 °C). Подача 5 000 м³/ч = 1,389 м³/с. Охлаждение с T_н = 35 °C до T_пр = 16 °C. ρ = 91 600/(287,05 · 308,15) = 1,035 кг/м³.

Q = 1,035 · 1,007 · 1,389 · (35 − 16) = 1,041 · 1,389 · 19 = 27,4 кВт.

При применении стандартного коэффициента 1,21 без поправки: Q = 1,21 · 1,389 · 19 = 31,9 кВт — завышение на 16%.

## Адиабатный показатель и его применение

Показатель γ = c_p/c_v = 1,400 используется в расчётах:

**Скорость звука в воздуховоде:**

{{< formula display="true" >}}
c_{звук} = \sqrt{\gamma R_{уд} T} = \sqrt{1{,}4 \cdot 287{,}05 \cdot T}\ \text{[м/с, К]}
{{< /formula >}}

При T = 293 К (20 °C): c = √(1,4 · 287,05 · 293) = √117 820 = 343 м/с. Число Маха M = V/c < 0,3 для скоростей до 100 м/с — сжимаемостью пренебрегают.

**Изентропное сжатие в компрессоре:**

{{< formula display="true" >}}
T_2 = T_1 \left(\frac{p_2}{p_1}\right)^{(\gamma-1)/\gamma} = T_1 \left(\frac{p_2}{p_1}\right)^{0{,}286}
{{< /formula >}}

Для компрессора вентиляционной установки при π = p₂/p₁ = 1,01 (перепад 1 кПа): T₂/T₁ = 1,01^0,286 ≈ 1,00286 — нагрев на 0,83 К при 20 °C. В HVAC-вентиляторах нагрев воздуха незначителен.

## Применение в теплообменниках

В методе NTU-ε (number of transfer units) тепловая мощность потока C [Вт/К]:

{{< formula display="true" >}}
C = \dot{m}\, c_p = \rho\, \dot{V}\, c_p
{{< /formula >}}

Меньшее из двух значений C_min определяет максимально возможный теплообмен:

{{< formula display="true" >}}
\dot{Q}_{max} = C_{min} \cdot (T_{г,вх} - T_{х,вх})
{{< /formula >}}

Эффективность теплообменника: ε = Q_факт/Q_max. При точном c_p неопределённость ε не превышает 0,7% — для HVAC достаточно c_p = 1,006 кДж/(кг·К).
