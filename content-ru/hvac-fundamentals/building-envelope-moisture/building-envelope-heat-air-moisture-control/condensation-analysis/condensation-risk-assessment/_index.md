Оценка риска конденсации (condensation risk assessment) определяет вероятность образования влаги на поверхностях или внутри ограждающих конструкций в условиях, когда температура достигает точки росы прилегающего воздуха. Анализ объединяет психрометрию, расчёт теплопередачи и диффузионный расчёт переноса пара для прогнозирования конденсации при расчётных климатических условиях.

Надлежащая оценка предотвращает повреждение конструкций, рост плесени, деградацию теплотехнических характеристик и ухудшение качества воздуха. Нормативную основу составляют ASHRAE 160, ASHRAE Fundamentals гл. 25–27, ISO 13788 (метод Глазера), ISO 15026, EN 15026, СП 50.13330 и СП 131.13330.

## Физический критерий конденсации

Конденсация возникает, когда температура поверхности опускается ниже температуры точки росы прилегающего воздуха:

{{< formula display="true" >}}
T_{\text{пов}} \leq T_{\text{dp}} \implies \text{конденсация}
{{< /formula >}}

Температура точки росы (dew-point temperature) вычисляется через уравнение Магнуса–Тетенса:

{{< formula display="true" >}}
T_{\text{dp}} = \frac{243{,}04 \cdot \left[\ln\!\left(\frac{\varphi}{100}\right) + \dfrac{17{,}625\,T}{243{,}04 + T}\right]}{17{,}625 - \ln\!\left(\frac{\varphi}{100}\right) - \dfrac{17{,}625\,T}{243{,}04 + T}}
{{< /formula >}}

где T — температура воздуха по сухому термометру, °C; φ — относительная влажность, %.

Давление насыщенного пара (saturated vapour pressure):

{{< formula display="true" >}}
p_{\text{sat}}(T) = 610{,}78 \cdot \exp\!\left(\frac{17{,}27\,T}{T + 237{,}3}\right) \quad \text{[Па]}
{{< /formula >}}

## Температурный коэффициент fRsi

### Определение

Температурный коэффициент fRsi (temperature factor, ISO 13788) показывает, насколько температура внутренней поверхности приближается к температуре внутреннего воздуха относительно расчётного перепада:

{{< formula display="true" >}}
f_{Rsi} = \frac{T_{\text{si}} - T_{\text{e}}}{T_{\text{i}} - T_{\text{e}}}
{{< /formula >}}

где T\_si — температура внутренней поверхности, °C; T\_i — температура внутреннего воздуха, °C; T\_e — температура наружного воздуха, °C.

Минимально допустимый коэффициент для предотвращения конденсации:

{{< formula display="true" >}}
f_{Rsi,\min} = \frac{T_{\text{dp}} - T_{\text{e}}}{T_{\text{i}} - T_{\text{e}}}
{{< /formula >}}

Условие приемлемости: f\_Rsi,факт ≥ f\_Rsi,min.

### Расчёт по тепловому сопротивлению

Температура внутренней поверхности однородной конструкции:

{{< formula display="true" >}}
T_{\text{si}} = T_{\text{i}} - \frac{(T_{\text{i}} - T_{\text{e}}) \cdot R_{si}}{R_{\text{total}}}
{{< /formula >}}

где R\_si — сопротивление внутреннего поверхностного слоя, м²·K/Вт (принимается 0,13 м²·K/Вт по ISO 6946 для горизонтального теплового потока); R\_total — полное тепловое сопротивление конструкции, м²·K/Вт.

{{< table title="Минимальный fRsi по расчётным условиям (ASHRAE Fundamentals, СП 50)" >}}
| Расчётная зимняя T\_e | φ\_i | f\_Rsi,min |
|---|---|---|
| −5°C | 50% | 0,70 |
| −10°C | 45% | 0,72 |
| −15°C | 40% | 0,75 |
| −20°C | 40% | 0,78 |
| −25°C | 35% | 0,76 |
| −28°C | 35% | 0,80 |
{{< /table >}}

## Метод Глазера по ISO 13788

Метод Глазера (Glaser method) — установившийся диффузионный расчёт межслойной конденсации (interstitial condensation). Он рассматривает ежемесячный баланс потоков пара через конструкцию без учёта капиллярного переноса и буферной ёмкости материалов. Более точные нестационарные расчёты выполняются по ISO 15026 / EN 15026 с использованием программ типа WUFI.

### Распределение температур по слоям

Температура на границе слоёв m и m+1:

{{< formula display="true" >}}
T_m = T_{\text{i}} - \frac{(T_{\text{i}} - T_{\text{e}}) \cdot \sum_{k=1}^{m} R_k}{R_{\text{total}}}
{{< /formula >}}

### Линейное распределение давления пара

Давление пара на границе слоёв m и m+1:

{{< formula display="true" >}}
p_m = p_{\text{i}} - \frac{(p_{\text{i}} - p_{\text{e}}) \cdot \sum_{k=1}^{m} s_{d,k}}{S_d}
{{< /formula >}}

где p\_i, p\_e — парциальное давление пара внутри и снаружи, Па; s\_{d,k} = μ\_k · d\_k — эквивалентная диффузионная толщина слоя k, м (μ — коэффициент паропроницаемости материала, d — толщина слоя, м); S\_d — суммарная эквивалентная диффузионная толщина конструкции.

### Критерий конденсации в слое

На каждой расчётной границе проверяется:

{{< formula display="true" >}}
p_m > p_{\text{sat}}(T_m) \implies \text{конденсация на границе } m
{{< /formula >}}

### Скорость межслойной конденсации

{{< formula display="true" >}}
g_c = \frac{p_{\text{sat}}(T_m) - p_m}{s_{d,m}/\delta_0} \quad \text{[г/(м²·ч)]}
{{< /formula >}}

где δ\_0 = 1,85×10⁻¹⁰ кг/(м·с·Па) — коэффициент паропроницаемости воздуха.

## Численный пример: наружная стена в Москве

### Исходные данные

Конструкция (снаружи → внутрь):
1. Штукатурка цементная: d = 20 мм, λ = 0,93 Вт/(м·K), μ = 25
2. Кирпич керамический: d = 380 мм, λ = 0,58 Вт/(м·K), μ = 10
3. Минераловатная плита: d = 100 мм, λ = 0,038 Вт/(м·K), μ = 1
4. Гипсокартон: d = 12,5 мм, λ = 0,21 Вт/(м·K), μ = 8

Расчётные условия (январь, Москва, по СП 131.13330):
- T\_e = −26°C, φ\_e = 84% → p\_e ≈ 156 Па
- T\_i = +20°C, φ\_i = 50% → p\_i ≈ 1168 Па

Поверхностные сопротивления: R\_si = 0,13 м²·K/Вт, R\_se = 0,04 м²·K/Вт.

### Тепловые сопротивления слоёв

{{< table title="Тепловые сопротивления слоёв конструкции" >}}
| Слой | d, м | λ, Вт/(м·K) | R, м²·K/Вт |
|---|---|---|---|
| R\_si | — | — | 0,130 |
| Штукатурка | 0,020 | 0,93 | 0,022 |
| Кирпич | 0,380 | 0,58 | 0,655 |
| Минвата | 0,100 | 0,038 | 2,632 |
| Гипсокартон | 0,0125 | 0,21 | 0,060 |
| R\_se | — | — | 0,040 |
| **Итого** | | | **3,539** |
{{< /table >}}

Коэффициент теплопередачи: U = 1/3,539 = **0,282 Вт/(м²·K)**.

### Температура на границах

{{< formula display="true" >}}
T_m = 20 - \frac{(20 - (-26)) \cdot \Sigma R_m}{3{,}539} = 20 - 13{,}0 \cdot \Sigma R_m
{{< /formula >}}

{{< table title="Температуры на границах слоёв" >}}
| Граница | ΣR, м²·K/Вт | T, °C | p\_sat, Па |
|---|---|---|---|
| Внутр. поверхность | 0,130 | 18,3 | 2100 |
| Штукатурка / кирпич | 0,152 | 18,0 | 2063 |
| Кирпич / минвата | 0,807 | 9,5 | 1196 |
| Минвата / ГКЛ | 3,439 | −24,7 | 75 |
| Наружная поверхность | 3,499 | −25,5 | 69 |
{{< /table >}}

### Температурный коэффициент внутренней поверхности

{{< formula display="true" >}}
f_{Rsi} = \frac{18{,}3 - (-26)}{20 - (-26)} = \frac{44{,}3}{46} = 0{,}962
{{< /formula >}}

Минимальное требование для T\_e = −26°C, φ\_i = 50%:
T\_dp = 9,3°C → f\_Rsi,min = (9,3 + 26) / 46 = **0,768**.

Условие выполнено: 0,962 ≥ 0,768. Конденсация на внутренней поверхности отсутствует.

### Диффузионный расчёт (метод Глазера)

Эквивалентные диффузионные толщины: s\_d,шт = 0,5 м; s\_d,кирп = 3,8 м; s\_d,минв = 0,1 м; s\_d,гкл = 0,1 м; S\_d = 4,5 м.

{{< table title="Давление пара на границах и условие конденсации" >}}
| Граница | ΣS\_d, м | p\_пара, Па | p\_sat(T), Па | Конденсация? |
|---|---|---|---|---|
| Внутр. поверхность | 0 | 1168 | 2100 | Нет |
| Штукатурка / кирпич | 0,5 | 1056 | 2063 | Нет |
| Кирпич / минвата | 4,3 | 221 | 1196 | Нет |
| Минвата / ГКЛ | 4,4 | 198 | 75 | **Да** |
| Наружная поверхность | 4,5 | 156 | 69 | Нет |
{{< /table >}}

На границе «минвата / ГКЛ» p\_пара = 198 Па > p\_sat = 75 Па — межслойная конденсация. Вывод: гипсокартон необходимо перенести на тёплую сторону или заменить паронепроницаемым слоем снаружи минваты.

## Критерии стандарта ASHRAE 160

ASHRAE 160 «Criteria for Moisture-Control Design Analysis in Buildings» устанавливает критерии предотвращения роста плесени на основе скользящего среднего относительной влажности поверхности (surface relative humidity, SRH) за 30 суток.

### Индекс влажности поверхности

{{< formula display="true" >}}
\overline{\varphi}_{\text{surf,30d}} = \frac{1}{30} \sum_{i=1}^{30} \varphi_{\text{surf},i}
{{< /formula >}}

Критерий: φ\_surf,30d < 80%.

### Расчёт относительной влажности поверхности

{{< formula display="true" >}}
\varphi_{\text{surf}} = \frac{p_{\text{sat}}(T_{\text{si}})_{\text{факт}}}{p_{\text{sat}}(T_{\text{i}})} \cdot \varphi_{\text{i}}
{{< /formula >}}

### Индекс роста плесени (модель VTT)

ASHRAE 160 апеллирует к финской модели VTT (Viitanen et al.):

{{< formula display="true" >}}
M(t+\Delta t) = M(t) + \max\!\left(0,\; \frac{k_1 \cdot k_2}{7} \cdot \Delta t\right)
{{< /formula >}}

где M — индекс плесени (шкала 0–6); k\_1 — коэффициент интенсивности (функция φ и T); k\_2 — коэффициент восприимчивости материала; Δt — шаг времени, нед. Критерий приемлемости: M < 3 (видимый рост отсутствует).

{{< table title="Сводные критерии ASHRAE 160" >}}
| Параметр | Предел | Интервал усреднения |
|---|---|---|
| Относительная влажность поверхности | < 80% | Скользящее среднее за 30 сут |
| Относительная влажность поверхности | < 100% | Мгновенное значение |
| Индекс плесени M | < 3 | Годовой анализ |
| Влажность древесины | < 16% | Среднее за месяц |
{{< /table >}}

## Тепловые мосты и воздухопроницаемость

### Линейные тепловые мосты

Линейный тепловой мост (linear thermal bridge) снижает локальную температуру поверхности и требует отдельной оценки fRsi в критической точке:

{{< formula display="true" >}}
\psi = \frac{Q_{\text{мост}}}{\Delta T \cdot L}
{{< /formula >}}

где ψ — линейная теплопроводность, Вт/(м·K); L — длина моста, м. Температура поверхности в точке моста рассчитывается двухмерным методом конечных элементов по ISO 10211.

### Инфильтрация и эксфильтрация

Экфильтрация (exfiltration) — утечка тёплого влажного воздуха изнутри конструкции — существенно увеличивает поток пара и риск межслойной конденсации. Оценка выполняется по EN 13829 / ASTM E779 (испытание Blower Door). Скорость воздухообмена n₅₀ < 1,5 ч⁻¹ принята в пассивных домах как условие отсутствия конвективного переноса влаги.

## Ежемесячный анализ (упрощённый метод)

Ежемесячный метод по ISO 13788 оценивает баланс накопления (condensation season) и высыхания (drying season) влаги в конструкции.

Кумулятивное накопление за месяц конденсации:

{{< formula display="true" >}}
\Delta m_c = (g_{c,\text{вход}} - g_{c,\text{выход}}) \cdot \tau_m \quad \text{[г/м²]}
{{< /formula >}}

где g\_c — плотность потока пара на соответствующей границе, г/(м²·с); τ\_m — продолжительность месяца, с.

Критерии приемлемости по ISO 13788:
- Годовой баланс неотрицателен: Σ Δm\_c ≤ 0 (влага за год не накапливается).
- Максимальное накопление за сезон конденсации: Δm\_max ≤ 500 г/м² для большинства конструкций.

## Стратегии снижения риска

**При умеренном риске:** увеличить тепловое сопротивление, сместить изоляцию к наружной поверхности, улучшить герметизацию, снизить влажность в помещении.

**При высоком риске:** добавить непрерывную наружную изоляцию (continuous exterior insulation), устроить вентилируемый зазор или дренажный слой, применить плёнки с переменной паропроницаемостью.

**При неприемлемом риске:** полная переработка конструкции с обязательным двухмерным теплотехническим расчётом тепловых мостов по ISO 10211, устройство тепловых разрывов в узлах примыканий, верификация воздухонепроницаемости по EN 13829.
