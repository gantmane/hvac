Увлажнение — психрометрический процесс добавления водяного пара в воздушный поток с целью увеличения коэффициента влажности W. Метод увлажнения определяет путь процесса на психрометрической диаграмме, энергетические затраты и качество микроклимата. Для зимнего кондиционирования умеренного и холодного климата увлажнение является обязательным: наружный воздух при −15 °C несёт лишь 0,8–1,5 г/кг влаги, тогда как комфортные условия требуют 5–9 г/кг.

## Классификация методов увлажнения

{{< table title="Сравнение методов увлажнения воздуха" >}}
| Метод | Путь на диаграмме | Δt_db | Тип энергии | КПД по воде |
|---|---|---|---|---|
| Впрыск насыщенного пара | ↑ (почти вертик.) | +0,5–1,0 °C | Тепловая | 95–99 % |
| Адиабатическое распыление | ↙ по t_wb=const | −2…−8 °C | Давление воды | 70–85 % |
| Ультразвуковое распыление | ≈ адиабатическое | −1…−3 °C | Электр. < 5 Вт/(г/ч) | 90–95 % |
| Вращающийся диск (DPH) | Близко к адиабат. | −1…−4 °C | Электрическая | 80–90 % |
| Промывочная камера (spray chamber) | Вдоль t_wb=const | −3…−10 °C | Давление насоса | 80–98 % |
{{< /table >}}

## Паровое увлажнение

### Термодинамика

Впрыск насыщенного пара при давлении p_st добавляет к воздуху влагу и небольшое количество явного тепла. Изменение энтальпии:

{{< formula display="true" >}}
\Delta h = h_{\text{пар}}(p_{st}) \cdot \Delta W
{{< /formula >}}

Изменение t_db при паровом увлажнении:

{{< formula display="true" >}}
\Delta t_{db} = \frac{[h_{\text{пар}} - (c_{pv} \cdot t_{db,1} + h_{fg,0})] \cdot \Delta W}{c_{pa} + W_{\text{ср}} \cdot c_{pv}}
{{< /formula >}}

При паре 100 °C и воздухе 20 °C: {{< formula >}}\Delta t_{db} \approx 0{,}5\;°\text{C}{{< /formula >}} на 5 г/кг — пренебрежимо мало.

### Расчёт мощности парового увлажнителя

{{< formula display="true" >}}
\dot{m}_{\text{пар}} = \dot{m}_a \cdot \Delta W = \dot{m}_a \cdot (W_2 - W_1)\quad[\text{кг/с}]
{{< /formula >}}

{{< formula display="true" >}}
Q_{\text{hum}} = \dot{m}_{\text{пар}} \cdot h_{\text{пар}}(p_{st})\quad[\text{кВт}]
{{< /formula >}}

**Пример:** нагреть и увлажнить 10 000 м³/ч воздуха с W1 = 1,5 г/кг (зимний наружный) до W2 = 7,0 г/кг. Пар 100 кПа (h_пар = 2676 кДж/кг).

{{< formula display="true" >}}
\dot{m}_a = \frac{10\,000 \times 1{,}2}{3600} = 3{,}33\;\text{кг/с}
{{< /formula >}}

{{< formula display="true" >}}
\dot{m}_{\text{пар}} = 3{,}33 \times (0{,}0070 - 0{,}0015) = 0{,}01833\;\text{кг/с} = \mathbf{66\;\text{кг/ч}}
{{< /formula >}}

{{< formula display="true" >}}
Q_{\text{hum}} = 0{,}01833 \times 2676 = \mathbf{49{,}1\;\text{кВт}}
{{< /formula >}}

## Адиабатическое (испарительное) увлажнение

### Термодинамика

При испарении воды при температуре влажного термометра t_wb воздух поглощает скрытую теплоту, охлаждаясь при почти постоянной энтальпии:

{{< formula display="true" >}}
h_2 \approx h_1\quad (Q_{\text{потери}} \approx 0)
{{< /formula >}}

{{< formula display="true" >}}
t_{db,2} = t_{db,1} - \frac{h_{fg}(t_{wb}) \cdot \Delta W}{c_{pa} + W_{\text{ср}} \cdot c_{pv}}
{{< /formula >}}

Приближённо (при умеренных условиях):

{{< formula display="true" >}}
t_{db,2} \approx t_{db,1} - \frac{2454 \cdot \Delta W}{1{,}006 + 1{,}86\,W_{\text{ср}}}
{{< /formula >}}

Путь на диаграмме — вдоль линии t_wb = const, от левого-верхнего к нижнему-правому.

### КПД адиабатического увлажнения (степень насыщения)

{{< formula display="true" >}}
\eta_{\text{sat}} = \frac{W_2 - W_1}{W_s(t_{wb,1}) - W_1} = \frac{t_{db,1} - t_{db,2}}{t_{db,1} - t_{wb,1}}
{{< /formula >}}

{{< table title="Эффективность адиабатических увлажнителей" >}}
| Тип установки | η_sat, % |
|---|---|
| Промывочная камера с 1 рядом форсунок | 50–65 |
| Промывочная камера с 2 рядами форсунок | 70–85 |
| Испарительный мат (целлюлозный, 100 мм) | 70–80 |
| Испарительный мат (целлюлозный, 200 мм) | 85–95 |
| Высокоскоростной распылитель (atomizer) | 80–90 |
{{< /table >}}

### Расчётный пример

**Дано:** t_db1 = 35 °C, φ1 = 20 %, t_wb1 = 20 °C, расход 5 000 м³/ч, η_sat = 80 %.

- W1: p_ws(35°C) = 5,628 кПа; p_v = 0,20 × 5,628 = 1,126 кПа; W1 = 6,99 г/кг
- W_s(t_wb = 20°C): p_ws(20°C) = 2,338 кПа; W_s = 0,622 × 2,338 / (101,325 − 2,338) = 14,67 г/кг

{{< formula display="true" >}}
W_2 = W_1 + \eta_{\text{sat}} \cdot (W_s(t_{wb,1}) - W_1) = 6{,}99 + 0{,}80 \times (14{,}67 - 6{,}99) = \mathbf{13{,}13\;\text{г/кг}}
{{< /formula >}}

{{< formula display="true" >}}
t_{db,2} = t_{db,1} - \eta_{\text{sat}} \cdot (t_{db,1} - t_{wb,1}) = 35 - 0{,}80 \times 15 = \mathbf{23\;°\text{C}}
{{< /formula >}}

Расход воды:

{{< formula display="true" >}}
\dot{m}_{\text{вода}} = \frac{5000 \times 1{,}2}{3600} \times (0{,}01313 - 0{,}00699) = 1{,}667 \times 0{,}00614 = \mathbf{10{,}2\;\text{г/с}} = \mathbf{36{,}8\;\text{л/ч}}
{{< /formula >}}

## Ультразвуковое увлажнение

Ультразвуковые мембраны создают туман из мельчайших капель (D < 5 мкм), которые испаряются практически мгновенно. КПД по электроэнергии: ~ 3–7 Вт/(кг/ч увлажнения). Качество воды критически важно: загрязнения депонируются в помещении в виде «белой пыли».

Путь на диаграмме близок к адиабатическому, но чуть правее (капли несут небольшую явную теплоту при t_воды > t_wb).

## Требования к качеству воды

{{< table title="Требования к воде для увлажнителей по ASHRAE 62.1" >}}
| Параметр | Паровой увлажнитель | Адиабатический | Ультразвуковой |
|---|---|---|---|
| Жёсткость | < 17 мг-экв/л | < 5 мг-экв/л | < 1 мг-экв/л |
| TDS (растворённые в-ва) | < 200 мг/л | < 100 мг/л | < 10 мг/л |
| pH | 6,5–8,5 | 6,5–8,5 | 6–7 |
| Легионелла | Уничтожается паром | Риск при t < 60 °C | Риск при застое |
{{< /table >}}

Согласно ASHRAE Guideline 12-2000, в распылительных увлажнителях температура воды должна поддерживаться ≥ 60 °C (для уничтожения легионеллы) или поступать непрерывно из системы холодного водоснабжения с температурой < 20 °C при полном отсутствии застоя.

## Управление увлажнителями

### Стратегии управления

**ПИД по относительной влажности помещения:** наиболее распространённый метод. Датчик ОВ в обратном воздуховоде или зоне управляет паровым клапаном или форсунками.

**Каскадное управление:** внешний регулятор (OA-компенсация) формирует уставку для внутреннего контура.

**Ограничение по точке росы возвратного воздуха:** предотвращает конденсацию в воздуховодах:

{{< formula display="true" >}}
W_{\text{set,max}} = W_s(t_{dp,\text{limit}}) \approx W_s(16\;°\text{C}) = 11{,}4\;\text{г/кг}
{{< /formula >}}

### Контроль риска легионеллёза

Согласно ASHRAE 188-2018 «Legionellosis: Risk Management for Building Water Systems» и VDI 6022:
- Промывочные камеры и распылительные увлажнители — объекты повышенного риска
- Обязательный мониторинг и дезинфекция
- Паровые увлажнители — низкий риск
