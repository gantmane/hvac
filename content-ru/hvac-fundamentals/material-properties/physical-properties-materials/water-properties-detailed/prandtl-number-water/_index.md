## Определение и физический смысл

Число Прандтля (Prandtl number, Pr) — безразмерное отношение кинематической диффузии импульса к тепловой диффузивности:

{{< formula display="true" >}}
\Pr = \frac{\nu}{\alpha} = \frac{\mu c_p}{k}
{{< /formula >}}

где:
- $\nu = \mu/\rho$ — кинематическая вязкость, м²/с;
- $\alpha = k/(\rho c_p)$ — температуропроводность, м²/с;
- $\mu$ — динамическая вязкость, Па·с;
- $c_p$ — удельная теплоёмкость, Дж/(кг·К);
- $k$ — теплопроводность, Вт/(м·К).

Физически Pr определяет соотношение толщин гидродинамического и теплового пограничных слоёв:

{{< formula display="true" >}}
\frac{\delta_T}{\delta_v} \approx \Pr^{-1/3}
{{< /formula >}}

При $\Pr = 7$ (вода, 20 °C) тепловой пограничный слой составляет $\approx 52\%$ гидродинамического: тепловое сопротивление сосредоточено в тонкой пристеночной зоне, что и обеспечивает высокую конвективную теплоотдачу воды.

## Зависимость от температуры

Число Прандтля воды убывает с температурой в 6,5 раза в диапазоне 0–100 °C — главным образом из-за резкого снижения динамической вязкости. Это наиболее значимое изменение теплофизических свойств воды, важное для проектирования HVAC.

{{< table title="Число Прандтля воды в зависимости от температуры (ASHRAE Handbook — Fundamentals, гл. 30; NIST REFPROP v10)" >}}
| $t$, °C | Pr | Отклонение от 20 °C |
|:-:|:-:|:-:|
| 0 | 13,44 | +91 % |
| 10 | 9,40 | +34 % |
| 20 | 7,02 | — |
| 30 | 5,49 | −22 % |
| 40 | 4,49 | −36 % |
| 50 | 3,77 | −46 % |
| 60 | 3,25 | −54 % |
| 70 | 2,86 | −59 % |
| 80 | 2,55 | −64 % |
| 90 | 2,29 | −67 % |
| 100 | 2,07 | −71 % |
{{< /table >}}

**Инженерная аппроксимация** (погрешность ≤5 % при 5–95 °C):

{{< formula display="true" >}}
\Pr \approx 13{,}5 - 0{,}11\,t + 2{,}5 \times 10^{-4}\,t^2
{{< /formula >}}

Для расчётов с погрешностью менее 1 % следует использовать таблицы IAPWS-IF97 или NIST REFPROP v10.

## Применение в корреляциях теплоотдачи

Число Прандтля входит во все стандартные корреляции конвективной теплоотдачи, применяемые в HVAC.

**Турбулентный режим ($Re > 10\,000$) — уравнение Дитуса–Бёлтера:**

{{< formula display="true" >}}
Nu = 0{,}023\,Re^{0{,}8}\,\Pr^{n}, \quad n = 0{,}4 \text{ (нагрев)}, \; n = 0{,}3 \text{ (охлаждение)}
{{< /formula >}}

**Переходный режим ($2300 < Re < 10\,000$) — уравнение Хаузена:**

{{< formula display="true" >}}
Nu = 0{,}116\!\left(Re^{2/3} - 125\right)\Pr^{1/3}\!\left[1 + \left(\frac{d}{L}\right)^{2/3}\right]
{{< /formula >}}

**Ламинарный режим ($Re < 2300$) — уравнение Зидера–Тейта для начального участка:**

{{< formula display="true" >}}
Nu = 3{,}66 + \frac{0{,}065\,(d/L)\,Re\,\Pr}{1 + 0{,}04\,\left[(d/L)\,Re\,\Pr\right]^{2/3}}
{{< /formula >}}

Поскольку показатель степени при Pr равен 0,33–0,40, изменение Pr на 10 % даёт изменение $Nu$ на 3–4 %, а значит — на столько же меняется и коэффициент теплоотдачи $\alpha$.

## Влияние гликолевых растворов

Добавление гликоля существенно увеличивает Pr, снижая тепловую эффективность системы.

{{< table title="Сравнение числа Прандтля теплоносителей при 20 °C (ASHRAE Handbook — Fundamentals, гл. 31)" >}}
| Теплоноситель | Pr | $\delta_T / \delta_v$ | Изменение $\alpha$ vs. вода |
|---|:-:|:-:|:-:|
| Вода | 7,0 | 0,52 | — |
| 30 % этиленгликоль | 15,5 | 0,39 | −10…−15 % |
| 50 % этиленгликоль | 27,0 | 0,33 | −25…−30 % |
| 30 % пропиленгликоль | 18,5 | 0,37 | −12…−18 % |
| 50 % пропиленгликоль | 35,0 | 0,31 | −30…−35 % |
| Масло минеральное | 1050 | 0,10 | <−80 % |
| Жидкие металлы | 0,01 | 4,6 | доминирует $k$ стенки |
{{< /table >}}

При использовании гликолевых растворов следует увеличивать площадь теплообмена:
- 30 % ЭГ: площадь +12–18 %;
- 50 % ЭГ: площадь +35–45 %.

## Числовой пример. Коэффициент теплоотдачи в трубе при разных температурах

**Условие.** Вода течёт по стальной трубе $d = 50$ мм при скорости $w = 1{,}5$ м/с. Сравнить коэффициент конвективной теплоотдачи при $t = 10$ °C и $t = 80$ °C.

**Решение.**

Свойства воды (ASHRAE Handbook — Fundamentals, гл. 30):

{{< table title="Свойства воды при расчётных температурах" >}}
| Параметр | 10 °C | 80 °C |
|---|:-:|:-:|
| $\rho$, кг/м³ | 999,7 | 971,8 |
| $\mu$, мПа·с | 1,307 | 0,354 |
| $k$, Вт/(м·К) | 0,578 | 0,668 |
| $c_p$, кДж/(кг·К) | 4,193 | 4,196 |
| Pr | 9,40 | 2,23 |
{{< /table >}}

Число Рейнольдса:

{{< formula display="true" >}}
Re_{10} = \frac{\rho w d}{\mu} = \frac{999{,}7 \times 1{,}5 \times 0{,}05}{1{,}307 \times 10^{-3}} = 57\,400
{{< /formula >}}

{{< formula display="true" >}}
Re_{80} = \frac{971{,}8 \times 1{,}5 \times 0{,}05}{0{,}354 \times 10^{-3}} = 206\,000
{{< /formula >}}

Оба режима — турбулентный. Уравнение Дитуса–Бёлтера ($n = 0{,}4$, нагрев):

{{< formula display="true" >}}
Nu_{10} = 0{,}023 \times 57\,400^{0{,}8} \times 9{,}40^{0{,}4} = 0{,}023 \times 4\,815 \times 2{,}57 = 284
{{< /formula >}}

{{< formula display="true" >}}
Nu_{80} = 0{,}023 \times 206\,000^{0{,}8} \times 2{,}23^{0{,}4} = 0{,}023 \times 13\,760 \times 1{,}41 = 446
{{< /formula >}}

Коэффициент конвективной теплоотдачи:

{{< formula display="true" >}}
\alpha_{10} = \frac{Nu_{10} \cdot k_{10}}{d} = \frac{284 \times 0{,}578}{0{,}05} = 3\,283 \text{ Вт/(м²·К)}
{{< /formula >}}

{{< formula display="true" >}}
\alpha_{80} = \frac{Nu_{80} \cdot k_{80}}{d} = \frac{446 \times 0{,}668}{0{,}05} = 5\,959 \text{ Вт/(м²·К)}
{{< /formula >}}

**Вывод.** При одинаковой скорости потока теплоотдача воды при 80 °C в **1,81 раза** выше, чем при 10 °C. Это полностью определяется снижением числа Прандтля (с 9,40 до 2,23) и ростом числа Рейнольдса.

## Практические рекомендации для проектирования

**Системы холодной воды (4–10 °C).** Использовать Pr = 9–11. Коэффициент теплоотдачи на 8–12 % ниже, чем при стандартных условиях (20 °C); учитывать при расчёте теплообменников чиллеров.

**Системы горячей воды (70–90 °C).** Использовать Pr = 2,3–2,9. Коэффициент теплоотдачи на 15–20 % выше, что позволяет уменьшить площадь теплообменника.

**Оценка при температуре плёнки.** Когда разность температур стенка–жидкость превышает 10 °C, свойства следует определять при температуре плёнки:

{{< formula display="true" >}}
t_{\text{пл}} = \frac{t_{\text{стенка}} + t_{\text{жидк}}}{2}
{{< /formula >}}

Без этой коррекции погрешность расчёта $\alpha$ может достигать 5–8 %.

**Теплообменники с большим перепадом температур ($\Delta t > 30$ °C).** Метод LMTD с постоянными свойствами даёт погрешность 5–10 % по площади. Рекомендуется метод $\varepsilon$-NTU с оценкой свойств в нескольких точках.

**Гликолевые системы.** Определять свойства при минимальной ожидаемой рабочей температуре; при деградации гликоля (рост вязкости >50 % от паспортного значения) — заменить теплоноситель.

## Проверка теплообменника в поле

Последовательность верификации для работающего теплообменника:

1. Измерить температуры и расходы теплоносителей.
2. Определить Pr при измеренной температуре потока (не при 20 °C).
3. Рассчитать фактическую мощность: $\dot{Q} = \dot{m} c_p \Delta t$.
4. Сравнить с проектной кривой.
5. Отклонение более 10–15 % указывает на загрязнение поверхностей, завоздушивание или нарушение распределения потока.
