Равновесное влагосодержание (equilibrium moisture content, EMC) — масса воды в единице массы сухого гигроскопичного материала, когда материал находится в термодинамическом равновесии с окружающим воздухом при заданных температуре T и относительной влажности φ. В состоянии равновесия химические потенциалы воды в материале и в паровой фазе равны, чистый поток влаги через границу материал/воздух равен нулю.

EMC — ключевой входной параметр гигротермического моделирования (WUFI, Delphin) и расчёта паронакопления по методу Глейзера.

## Термодинамика равновесия

### Критерий равновесия

Термодинамическое равновесие между влагой в материале и паром в воздухе:

{{< formula display="true" >}}
\mu_{\text{пар}}(T, p_v) = \mu_{\text{жидк}}(T, p_c)
{{< /formula >}}

где μ — химический потенциал [Дж/моль], p_v — парциальное давление пара [Па], p_c — давление в поровой жидкости с учётом капиллярного (матричного) давления [Па].

Для капиллярных систем уравнение Кельвина:

{{< formula display="true" >}}
\ln \varphi = \ln \frac{p_v}{p_{sat}} = -\frac{2 \sigma M_w}{\rho_w R T r}
{{< /formula >}}

где r — радиус кривизны мениска [м], σ = 0,073 Н/м, M_w = 0,018 кг/моль, ρ_w = 1000 кг/м³.

### Температурная зависимость EMC

EMC уменьшается с повышением температуры при постоянном φ — следствие экзотермичности адсорбции воды. Для дерева эмпирическая коррекция:

{{< formula display="true" >}}
\text{EMC}(T) = \text{EMC}_{20} \cdot \left[1 - 0{,}001 \cdot (T - 20)\right]
{{< /formula >}}

При повышении температуры на 20 °C EMC снижается примерно на 2 %. Это важно для расчётов в климатах с широким диапазоном летних и зимних температур.

## Изотермы сорбции: математические модели

### Модель ГАБ (рекомендована ISO 12571)

{{< formula display="true" >}}
w(\varphi) = \frac{w_m \cdot C_{GAB} \cdot K_{GAB} \cdot \varphi}{(1 - K_{GAB} \cdot \varphi)(1 - K_{GAB} \cdot \varphi + C_{GAB} \cdot K_{GAB} \cdot \varphi)}
{{< /formula >}}

Параметры: w_m — монослойное влагосодержание, C_GAB — энергетическая константа монослоя, K_GAB — энергетическая константа полислоёв. Определяются нелинейной регрессией.

### Модель Освина (упрощённая)

{{< formula display="true" >}}
w(\varphi) = A \cdot \left(\frac{\varphi}{1 - \varphi}\right)^B
{{< /formula >}}

Параметры A и B специфичны для материала. Удобна для быстрого встраивания в расчёты, но менее точна при φ > 85 %.

### Модель Дента (для дерева)

Развитие ГАБ с различением двух типов вторичных молекул воды. Точнее воспроизводит S-образные изотермы целлюлозных материалов при φ > 60 %.

## Гистерезис сорбции

### Явление и механизм

Гистерезис сорбции (sorption hysteresis) — явление, при котором EMC при данном φ выше на кривой десорбции (высыхание), чем на кривой адсорбции (увлажнение). Причины:

**Эффект «чернильницы»** (ink-bottle effect): поры с широким телом и узким горлом заполняются при φ, соответствующем диаметру горла, но опустошаются только при φ, соответствующем диаметру тела. Таким образом, при увлажнении поры не заполняются, а при высыхании остаются заполненными до более низкого φ.

**Гистерезис угла смачивания:** угол смачивания при наступании мениска (adv.) > угла при отступании (rec.), что даёт разные уравнения Кельвина.

**Набухание целлюлозы:** при адсорбции вода входит в клеточные стенки и расширяет их, создавая новые поровые пространства; при десорбции структура не полностью возвращается в исходное состояние.

## Методы измерения EMC

### Метод насыщенных солевых растворов (ISO 12571)

Образцы выдерживают в эксикаторах над растворами солей с известной ОВ (при данной температуре) до достижения равновесия. Стандартные соли:

{{< table title="Насыщенные солевые растворы для создания стандартных ОВ (при 20 °C)" >}}
| Соль | ОВ, % | Точность, % |
|------|--------|------------|
| LiCl | 11,3 | ± 0,2 |
| MgCl₂ | 33,1 | ± 0,2 |
| NaBr | 57,6 | ± 0,3 |
| NaCl | 75,5 | ± 0,1 |
| KCl | 85,1 | ± 0,3 |
| KNO₃ | 93,9 | ± 0,5 |
{{< /table >}}

Равновесие считается достигнутым, когда изменение массы образца за 24 ч < 0,1 % от массы. Минимальное число образцов — 3 на каждую точку ОВ. Сухая масса определяется сушкой при (103 ± 2) °C до постоянной массы.

### Динамическая паровая сорбция (DVS)

Автоматизированная установка: образец 10–50 мг подвешен на микровесах в потоке газа с программно управляемой ОВ. Позволяет получить полную изотерму за 24–72 ч вместо 2–8 недель гравиметрического метода.

Ограничения: малый размер образца может не быть репрезентативным для неоднородных материалов (ОСП, газобетон). Для макропористых материалов предпочтителен гравиметрический метод по ISO 12571.

### ГОСТ 16483.7 — влажность древесины

Российский стандарт для определения влажности древесины весовым методом. Формула:

{{< formula display="true" >}}
w = \frac{m - m_0}{m_0} \times 100 \quad [\%]
{{< /formula >}}

где m — масса до сушки [г], m_0 — масса после сушки при (103 ± 2) °C [г].

## Числовой пример: расчёт EMC и оценка риска плесени

**Исходные условия:** наружная стена с деревянным каркасом (дерево хвойное). Зима: T_каркаса = −3 °C (температура в плоскости обшивки), ОВ_нар = 85 %.

Определяем EMC каркаса из изотермы сорбции при φ = 85 % и T = −3 °C:

По таблице при T = 20 °C: EMC(φ=85 %) ≈ 18,0 % (интерполяция между φ=80 % и φ=95 %).

Температурная коррекция на −3 °C:

{{< formula display="true" >}}
\text{EMC}(-3\text{°C}) = 18{,}0 \times [1 - 0{,}001 \times (-3 - 20)] = 18{,}0 \times 1{,}023 = 18{,}4\%
{{< /formula >}}

Критический EMC для роста плесени на дереве — 20 %. Расчётное значение 18,4 % < 20 % — риск минимален.

Если ОВ в этой плоскости поднимается до 92 % (дефект пароизоляции):

EMC(φ=92 %) ≈ 23 % > 20 % → **риск роста плесени**. Конструкция требует улучшения пароретардации или вентиляции.

## Применение EMC в гигротермическом анализе

### Ввод данных в WUFI

WUFI Pro использует изотерму сорбции (обе ветви) для расчёта гигроскопического накопления. Алгоритм на каждом временном шаге:
1. Рассчитывается локальная ОВ φ(x,t) из решения уравнений переноса.
2. По изотерме определяется w_eq(φ).
3. Разность (w − w_eq) управляет сорбцией / десорбцией.
4. Изменение w пересчитывает λ(w) и δ(φ) для следующего шага.

### Ёмкость влажностной буферизации MBC

{{< formula display="true" >}}
MBC = \frac{\partial w}{\partial \varphi} \cdot \rho_{\text{сух}} \cdot d \quad [\text{кг/м}^2]
{{< /formula >}}

где ∂w/∂φ — наклон изотермы сорбции в рабочей точке [1/(%ОВ)]. Для дерева при φ = 50–70 % ∂w/∂φ ≈ 0,10 %/% → MBC = 0,10 × 500 × 0,05 = 2,5 кг/м² (стойка 50 × 50 мм): это значительная буферная ёмкость.
