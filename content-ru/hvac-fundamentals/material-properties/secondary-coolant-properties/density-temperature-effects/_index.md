## Физические принципы

Плотность всех вторичных теплоносителей убывает с ростом температуры (тепловое расширение). В замкнутых гидронных системах это расширение должно компенсироваться расширительными баками (expansion tanks). Неправильный расчёт объёма бака приводит либо к срабатыванию предохранительного клапана (недостаточный объём), либо к кавитации насоса при низких температурах (избыточный объём).

Объёмный коэффициент теплового расширения:

{{< formula display="true" >}}
\beta = -\frac{1}{\rho}\left(\frac{\partial \rho}{\partial T}\right)_P
{{< /formula >}}

Изменение объёма жидкости в системе:

{{< formula display="true" >}}
\Delta V = V_{\text{сист}}\,\beta\,\Delta T
{{< /formula >}}

### Мембранный расширительный бак

Расчёт минимального объёма мембранного (диафрагменного) расширительного бака:

{{< formula display="true" >}}
V_{\text{бак}} = V_{\text{сист}} \cdot \frac{\Delta V_f}{\,1 - \dfrac{P_{\text{зап}} + 101{,}3}{P_{\text{макс}} + 101{,}3}\,}
{{< /formula >}}

где:
- $V_{\text{сист}}$ — объём жидкости в системе, л;
- $\Delta V_f$ — коэффициент объёмного расширения (из таблицы);
- $P_{\text{зап}}$ — давление зарядки азотной подушки, кПа изб.;
- $P_{\text{макс}}$ — максимально допустимое давление в системе, кПа изб.

## Числовые примеры

### Пример 1. Расчёт расширительного бака для гликолевой системы

**Условие.** Замкнутая система охлаждения, теплоноситель — 40 % ЭГ. Объём системы $V_{\text{сист}} = 3000$ л. Заполнение при температуре +10 °C, максимальная рабочая температура +70 °C, минимальная −15 °C. Давление зарядки бака $P_{\text{зап}} = 100$ кПа изб., максимальное давление системы $P_{\text{макс}} = 600$ кПа изб.

**Решение.**

Диапазон температур системы: $\Delta T = 70 - (-15) = 85$ °C.

Коэффициент $\beta$ для 40 % ЭГ: $\beta \approx 5{,}9 \times 10^{-4}$ /°C (интерполяция между 30 % и 50 %).

{{< formula display="true" >}}
\Delta V_f = \beta \cdot \Delta T = 5{,}9 \times 10^{-4} \times 85 = 0{,}0502
{{< /formula >}}

Знаменатель формулы:

{{< formula display="true" >}}
1 - \frac{100 + 101{,}3}{600 + 101{,}3} = 1 - \frac{201{,}3}{701{,}3} = 1 - 0{,}287 = 0{,}713
{{< /formula >}}

Объём бака:

{{< formula display="true" >}}
V_{\text{бак}} = 3000 \times \frac{0{,}0502}{0{,}713} = 3000 \times 0{,}0704 = 211 \text{ л}
{{< /formula >}}

Принимаем мембранный бак **250 л** (запас 18 %).

Для сравнения: водяная система того же объёма при аналогичном $\Delta T$ ($\Delta V_f = 0{,}036$) потребовала бы бак лишь **152 л**. Разница 65 % обусловлена более высоким $\beta$ у гликоля.

---

### Пример 2. Гидростатическое давление рассольной системы

**Условие.** Вертикальная система охлаждения ледового катка: высота трубопровода $h = 8$ м, теплоноситель — 20 % CaCl₂ ($\rho = 1183$ кг/м³). Определить дополнительное гидростатическое давление по сравнению с водяной системой.

**Решение.**

Гидростатическое давление на метр высоты:

{{< formula display="true" >}}
p_{\text{рассол}} = \rho_{\text{рассол}} \cdot g = 1183 \times 9{,}81 \times 10^{-3} = 11{,}60 \text{ кПа/м}
{{< /formula >}}

{{< formula display="true" >}}
p_{\text{вода}} = 998 \times 9{,}81 \times 10^{-3} = 9{,}79 \text{ кПа/м}
{{< /formula >}}

Дополнительное давление от более высокой плотности:

{{< formula display="true" >}}
\Delta P = (11{,}60 - 9{,}79) \times 8 = 1{,}81 \times 8 = 14{,}5 \text{ кПа} \approx 0{,}15 \text{ бар}
{{< /formula >}}

При проектировании насоса в системе с рассолом CaCl₂ необходимо добавлять поправку на плотность: напор насоса в метрах водяного столба умножается на коэффициент $\rho_{\text{рассол}}/\rho_{\text{вода}} = 1183/998 = 1{,}185$.

---

### Пример 3. Объём заправки при температуре монтажа

**Условие.** Система объёмом 3000 л заполняется раствором 40 % ЭГ при температуре монтажа +5 °C. Плотность при 20 °C: $\rho_{20} = 1047{,}8$ кг/м³. Определить необходимую массу гликолевого раствора.

**Решение.**

Плотность при +5 °C (поправочный коэффициент $f(5°C) \approx 1{,}012$):

{{< formula display="true" >}}
\rho_{5°C} = 1047{,}8 \times 1{,}012 = 1\,060{,}4 \text{ кг/м}^3
{{< /formula >}}

{{< formula display="true" >}}
m = \rho_{5°C} \times V_{\text{сист}} = 1060{,}4 \times 3{,}000 = 3181 \text{ кг}
{{< /formula >}}

При использовании значения при 20 °C ошибка составила бы $3143$ кг вместо $3181$ кг — занижение на **38 кг (1,2 %)**. Для крупных систем (>10 000 л) эта погрешность существенна при расчёте химии теплоносителя.

## Практические рекомендации

**Расширительный бак.** Рассчитывать на полный диапазон температур — от минимальной температуры монтажа до максимальной рабочей. Для гликолевых систем применять $\beta$ на 2–4 раза выше, чем для водяных; минимальный запас объёма бака — 10–15 %.

**Насосный агрегат.** Производительность насоса подбирается по объёмному расходу; напор в метрах водяного столба пересчитывается на реальный теплоноситель: $H_{\text{факт}} = H_{\text{воды}} \times \rho_{\text{воды}}/\rho_{\text{тепл}}$. Для рассолов CaCl₂ требуемый напор насоса в паскалях увеличивается на 15–25 % по сравнению с водяной системой.

**Контроль концентрации.** Плотность (ареометром) — простейший и быстрый способ проверки концентрации гликоля в поле. Для рефрактометра необходима температурная поправка.
