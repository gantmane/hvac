Приточная установка (air handling unit, AHU) — центральный элемент распределения кондиционированного воздуха в коммерческих и промышленных системах ОВК. Она обрабатывает смесь наружного (outdoor air, OA) и рециркуляционного (return air, RA) воздуха, обеспечивая заданные параметры температуры, влажности и чистоты. Правильное определение расчётных расходов, компоновки секций и конфигурации управления определяет как энергоэффективность системы за весь срок службы, так и тепловой комфорт в обслуживаемых помещениях.

## Компоновка секций приточной установки

Последовательность секций в корпусе AHU оптимизирует теплообмен, минимизирует суммарный перепад давления и обеспечивает удобный доступ для обслуживания. Типовая схема пути воздуха по конфигурации draw through:

**Конфигурации расположения вентилятора:**

- **Draw through (всасывающая схема)**: вентилятор расположен после теплообменников; воздух проходит через катушки и фильтры до вентилятора. Преимущества: наилучший контроль влажности (воздух перед вентилятором охлаждён, относительная влажность выше, риск уноса конденсата ниже); предпочтительна для установок производительностью > 5 м³/с.
- **Blow through (нагнетательная схема)**: вентилятор расположен перед теплообменниками. Преимущества: компактность; тепловыделение вентилятора (+1–3 К к температуре воздуха перед катушкой) требует небольшого увеличения расчётной холодопроизводительности.

## Расчёт расходов воздуха

### Подача воздуха по явной тепловой нагрузке

{{< formula display="true" >}}
\dot{V}_s = \frac{q_s}{\rho\,c_p\,\Delta T}
{{< /formula >}}

При стандартных условиях ($\rho = 1{,}2$ кг/м³, $c_p = 1{,}006$ кДж/(кг·К)):

{{< formula display="true" >}}
\dot{V}_s = \frac{q_s}{1{,}207\,\Delta T} \quad [\text{м}^3/\text{с, кВт, °C}]
{{< /formula >}}

где $q_s$ — явная тепловая нагрузка (кВт), $\Delta T$ — разность температур между воздухом в помещении и подаваемым воздухом (°C).

### Подача воздуха по скрытой нагрузке

{{< formula display="true" >}}
\dot{V}_l = \frac{q_l}{\rho\,h_{fg}\,\Delta W}
{{< /formula >}}

При стандартных условиях ($h_{fg} \approx 2{,}45$ МДж/кг):

{{< formula display="true" >}}
\dot{V}_l = \frac{q_l}{2\,940\,(W_r - W_s)} \quad [\text{м}^3/\text{с, кВт, кг/кг}]
{{< /formula >}}

где $q_l$ — скрытая нагрузка (кВт), $W_r$ — влагосодержание воздуха в помещении (кг/кг с.в.), $W_s$ — влагосодержание подаваемого воздуха (кг/кг с.в.).

Расчётный расход принимается как наибольшее из $\dot{V}_s$ и $\dot{V}_l$.

**Числовой пример.** Офисный этаж: явная нагрузка $q_s = 80$ кВт; скрытая нагрузка $q_l = 20$ кВт; температура помещения 24 °C, температура подачи 13 °C; $W_r = 0{,}0094$ кг/кг, $W_s = 0{,}0085$ кг/кг.

{{< formula display="true" >}}
\dot{V}_s = \frac{80}{1{,}207 \times 11} = 6{,}02\,\text{м}^3/\text{с}
{{< /formula >}}

{{< formula display="true" >}}
\dot{V}_l = \frac{20}{2\,940 \times (0{,}0094 - 0{,}0085)} = \frac{20}{2{,}646} = 7{,}56\,\text{м}^3/\text{с}
{{< /formula >}}

Расчётный расход: 7,56 м³/с (скрытая нагрузка является определяющей — типичная ситуация для жаркого влажного климата или при высокой плотности людей).

### Полная мощность охлаждающей катушки

{{< formula display="true" >}}
q_t = \rho\,\dot{V}\,(h_e - h_l)
{{< /formula >}}

где $h_e$ — энтальпия воздуха на входе в катушку (кДж/кг с.в.), $h_l$ — энтальпия на выходе. При стандартной плотности воздуха:

{{< formula display="true" >}}
q_t = 1{,}2\,\dot{V}\,(h_e - h_l) \quad [\text{кВт, м}^3/\text{с, кДж/кг}]
{{< /formula >}}

### Внешнее статическое давление (External Static Pressure, ESP)

Суммарное статическое давление, которое должен развивать вентилятор:

{{< formula display="true" >}}
ESP = \Delta P_{\text{фильтр}} + \Delta P_{\text{катушка}} + \Delta P_{\text{рекуп}} + \Delta P_{\text{канал}} + \Delta P_{\text{терминал}}
{{< /formula >}}

{{< table title="Типичные перепады давления по секциям AHU" >}}
| Секция | Начальный ΔP, Па | Расчётный ΔP (с запасом), Па |
|---|---|---|
| Фильтры MERV 8 (предфильтр) | 50–75 | 75–150 |
| Фильтры MERV 13 (финальные) | 100–150 | 150–300 |
| Охлаждающая катушка | 100–175 | 100–175 |
| Нагревательная катушка | 50–100 | 50–100 |
| Рекуператор энергии (ERV/HRV) | 150–300 | 150–300 |
| Каналы и фасонные части | 200–500 | 200–500 |
| Терминальные устройства VAV | 100–250 | 100–250 |
{{< /table >}}

## Сравнение конфигураций AHU

{{< table title="Сравнительная характеристика конфигураций приточных установок" >}}
| Конфигурация | Метод регулирования | Энергоэффективность | Контроль влажности | Область применения |
|---|---|---|---|---|
| Однозонная (single zone) | Вкл/выкл или ПИД температуры | Средняя | Хороший | Небольшие здания с равномерной нагрузкой |
| Многозонная (multizone) | Смешивание горячего/холодного | Низкая (потери смешивания) | Удовлетворительный | Устаревшие системы; сложность реконструкции |
| VAV | Изменение расхода воздуха + VFD | Отличная | Требует доогрева при min VAV | Крупные коммерческие здания |
| Двухканальная (dual duct) | Смешивание потоков в терминале | Низкая | Отличный | Лаборатории, спецобъекты с переменными нагрузками |
| DOAS + FCU/VAV | VAV для внутренней нагрузки; DOAS для вентиляции | Наилучшая | Отличный | Современные энергоэффективные здания |

### Однозонные системы

Однозонная AHU обслуживает единую тепловую зону (один датчик/термостат). Температура подаваемого воздуха модулируется регулирующим клапаном охлаждающей катушки. Простота управления и невысокая стоимость монтажа делают эту конфигурацию оптимальной для небольших объектов с однородной нагрузкой: торговые помещения, склады, одноэтажные офисы, небольшие гостиницы.

**Ограничение:** невозможность одновременного удовлетворения разнородных тепловых нагрузок нескольких зон без значительных энергетических потерь на смешивание охлаждённого и повторно нагретого воздуха.

### Системы VAV (Variable Air Volume)

VAV-система поддерживает постоянную температуру подаваемого воздуха (обычно 12–14 °C) при переменном расходе воздуха через терминальные устройства с регулируемыми заслонками (VAV boxes). Снижение расхода при частичной нагрузке обеспечивает кубическую экономию мощности привода вентилятора:

{{< formula display="true" >}}
\frac{\dot{W}_2}{\dot{W}_1} \approx \left(\frac{\dot{V}_2}{\dot{V}_1}\right)^3
{{< /formula >}}

Снижение расхода до 60 % от расчётного уменьшает мощность вентилятора до $0{,}6^3 = 0{,}216$ — то есть до 22 % от расчётной. ASHRAE 90.1-2022 обязывает оснащать VAV-системы с мощностью привода вентилятора более 0,5 кВт частотными преобразователями (variable frequency drive, VFD) и предусматривать экономайзерный режим (economizer mode) при климатических условиях, допускающих свободное охлаждение.

**Ключевая проблема VAV — баланс вентиляции при частичной нагрузке.** При снижении расхода до 30–40 % от расчётного подача наружного воздуха в зоны с минимальной нагрузкой может нарушать требования ASHRAE 62.1. Решения:
- Последовательность управления с двойным максимумом (dual maximum control sequence) — гибкое управление нижним пределом VAV по углекислому газу.
- Электрический или горячеводный доогреватель (reheat coil) в терминальном устройстве при минимальном VAV.
- Централизованная DOAS с независимым расходом наружного воздуха, не зависящим от положения VAV-заслонок.

### Многозонные и двухканальные системы

Многозонные AHU одновременно генерируют горячий и холодный потоки, смешиваемые на зональных заслонках непосредственно в корпусе установки; двухканальные системы распределяют раздельные горячий и холодный каналы по всему зданию с смешиванием в терминальных блоках. Обе конфигурации обеспечивают высокую гибкость зонального управления при значительных энергетических потерях на одновременный нагрев и охлаждение.

ASHRAE 90.1 ограничивает применение систем с постоянным расходом (constant volume, CV) при одновременном охлаждении и нагреве; они допустимы лишь для специальных объектов: лабораторий с вытяжными шкафами, операционных, чистых комнат с жёсткими требованиями к воздушному балансу.

### Системы DOAS (Dedicated Outdoor Air System)

Выделенная система подачи наружного воздуха DOAS разделяет функции вентиляции и кондиционирования. DOAS обрабатывает весь наружный воздух (подводя его до заданных параметров по температуре и влажности), тогда как внутренняя нагрузка снимается системой переменного расхода или фанкойлами (fan coil units, FCU). Энтальпийный рекуператор (energy recovery ventilator, ERV) в DOAS извлекает 60–85 % тепла из вытяжного воздуха, снижая нагрузку на охлаждение наружного воздуха.

## Требования нормативных документов

**ASHRAE 90.1-2022:**
- Электродвигатели вентиляторов мощностью > 5 кВт: КПД не ниже NEMA Premium (IE3 по МЭК 60034-30).
- Ограничение удельной мощности вентилятора (fan power limitation, FPL): 0,75–0,9 Вт/(м³/ч) в зависимости от класса статического давления системы.
- Экономайзерный режим: обязателен для систем охлаждения мощностью > 15,3 кВт в большинстве климатических зон (коды зон 1–8A по ASHRAE 90.1).
- Минимальный класс фильтра: MERV 8 по ASHRAE 52.2 для фильтрации наружного воздуха.

**SMACNA HVAC Air Duct Leakage Test Manual:**
- Утечка корпуса AHU: класс 2 или выше (≤ 0,3 м³/(ч·м²) при 100 Па давления).
- Тепловая изоляция корпуса: минимальный RSI 1,76 (R-10 в имперских единицах).

**СП 60.13330.2020:** нормирует параметры приточного воздуха, кратности воздухообмена, предельные концентрации загрязнителей по категориям помещений. Расчётные климатические параметры наружного воздуха — по СП 131.13330.2020.

## Критерии выбора оборудования

- **Запас мощности катушки:** проектировать охлаждающую катушку с запасом 115–125 % расчётной нагрузки для учёта возможного роста нагрузки и деградации теплообмена при загрязнении поверхностей.
- **Лицевая скорость на катушке:** 2,0–2,5 м/с — оптимальный диапазон; при превышении 2,5 м/с возможен унос капель конденсата (carry-over), требующий установки каплеуловителя (mist eliminator).
- **Диапазон регулирования вентилятора:** обеспечить стабильную работу при снижении расхода до 30–40 % от расчётного; ограниченный диапазон VFD или нестабильность рабочей точки на характеристике вентилятора — типичные причины помпажа.
- **Акустические характеристики:** уровень звуковой мощности на выходе нормируется по кривым NC (noise criteria); для офисных помещений — NC 35–45.
- **Доступ для обслуживания:** зазор не менее 0,9 м со стороны обслуживания (International Mechanical Code 2021); для HEPA-секций — не менее 1,2 м; для замены катушек — по фактическому габариту секции плюс не менее 0,3 м.
