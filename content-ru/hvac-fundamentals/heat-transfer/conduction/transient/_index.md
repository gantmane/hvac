Нестационарная теплопроводность описывает ситуацию, когда температурное поле изменяется как по координатам, так и по времени. В HVAC это важно при пуске и останове оборудования, при анализе тепловой инерции ограждающих конструкций, при расчёте часовых теплопотерь и систем аккумулирования теплоты.

## Общее уравнение нестационарной теплопроводности

Применяя первый закон термодинамики к элементарному объёму:

{{< formula display="true" >}}
\rho c_p \frac{\partial T}{\partial t} = \nabla \cdot (k \nabla T) + \dot{q}
{{< /formula >}}

Для одномерного случая с постоянными свойствами материала:

{{< formula display="true" >}}
\frac{\partial T}{\partial t} = \alpha \frac{\partial^2 T}{\partial x^2} + \frac{\dot{q}}{\rho c_p}
{{< /formula >}}

**Коэффициент температуропроводности** (thermal diffusivity):

{{< formula display="true" >}}
\alpha = \frac{k}{\rho c_p} \quad [\text{м}^2\text{/с}]
{{< /formula >}}

Физический смысл $\alpha$: отношение способности материала проводить теплоту ($k$) к его способности накапливать теплоту ($\rho c_p$). Высокое $\alpha$ — быстрый тепловой отклик.

| Материал | $k$, Вт/(м·К) | $\rho c_p$, кДж/(м³·К) | $\alpha \times 10^{6}$, м²/с |
|---|---|---|---|
| Медь | 401 | 3 450 | 116 |
| Алюминий | 237 | 2 430 | 97 |
| Сталь углеродистая | 50 | 3 510 | 14 |
| Бетон тяжёлый | 1,74 | 2 040 | 0,85 |
| Кирпич | 0,64 | 1 550 | 0,41 |
| Дерево (сосна) | 0,15 | 1 100 | 0,14 |
| Минвата | 0,040 | 46 | 0,87 |
| Воздух (20°С) | 0,0262 | 1,21 | 21,7 |
{{< /table >}}

## Безразмерные числа нестационарного анализа

### Число Био

{{< formula display="true" >}}
Bi = \frac{h L_c}{k}
{{< /formula >}}

где $L_c = V/A_s$ — характерная длина (объём тела, делённый на площадь поверхности). Число Био — отношение внешнего конвективного сопротивления к внутреннему кондуктивному:

- $Bi \ll 1$: внутреннее сопротивление ничтожно, температура однородна по объёму
- $Bi \gg 1$: внутреннее сопротивление определяет процесс, существуют значительные пространственные градиенты
- $Bi = 1$: оба сопротивления сопоставимы

### Число Фурье

{{< formula display="true" >}}
Fo = \frac{\alpha t}{L_c^2}
{{< /formula >}}

Физический смысл: отношение «проведённого» тепла к «накопленному». При $Fo > 0{,}2$ задача теплопроводности описывается первым членом ряда Фурье с погрешностью менее 2%.

## Метод сосредоточенной ёмкости (Lumped Capacitance)

При $Bi < 0{,}1$ внутренними градиентами температуры пренебрегают. Энергетический баланс:

{{< formula display="true" >}}
\rho c_p V \frac{dT}{dt} = -h A_s (T - T_\infty)
{{< /formula >}}

Разделяя переменные и интегрируя:

{{< formula display="true" >}}
\frac{T(t) - T_\infty}{T_i - T_\infty} = \exp\!\left(-\frac{t}{\tau}\right)
{{< /formula >}}

где **тепловая постоянная времени**:

{{< formula display="true" >}}
\tau = \frac{\rho c_p V}{h A_s} = \frac{\rho c_p L_c}{h} \quad [\text{с}]
{{< /formula >}}

При $t = \tau$ безразмерная температура снижается до $e^{-1} \approx 0{,}368$, при $t = 5\tau$ — до 0,007 (практически равновесие).

### Числовой пример: охлаждение медного патрубка

**Задача.** Медный фитинг массой 0,5 кг (медь: $\rho = 8933$ кг/м³, $c_p = 385$ Дж/(кг·К), $k = 401$ Вт/(м·К)) при начальной температуре $T_i = 150°$С помещают в поток воздуха ($T_\infty = 25°$С, $h = 50$ Вт/(м²·К)). Площадь поверхности $A_s = 0{,}015$ м², объём $V = 5{,}6 \times 10^{-5}$ м³.

Проверка метода:

{{< formula display="true" >}}
L_c = \frac{V}{A_s} = \frac{5{,}6 \times 10^{-5}}{0{,}015} = 3{,}73 \times 10^{-3} \;\text{м}
\quad\Rightarrow\quad
Bi = \frac{50 \times 3{,}73 \times 10^{-3}}{401} = 4{,}65 \times 10^{-4} \ll 0{,}1 \checkmark
{{< /formula >}}

Постоянная времени:

{{< formula display="true" >}}
\tau = \frac{8933 \times 385 \times 5{,}6 \times 10^{-5}}{50 \times 0{,}015} = \frac{192{,}5}{0{,}75} = 257 \;\text{с} \approx 4{,}3 \;\text{мин}
{{< /formula >}}

Время охлаждения до $T = 40°$С:

{{< formula display="true" >}}
t = -\tau \ln\!\frac{40 - 25}{150 - 25} = -257 \times \ln(0{,}12) = 257 \times 2{,}12 = 545 \;\text{с} \approx 9 \;\text{мин}
{{< /formula >}}

## Одномерная нестационарная теплопроводность при Bi > 0,1

При $Bi > 0{,}1$ необходимо учитывать пространственное распределение температуры. Аналитическое решение методом разделения переменных для бесконечной пластины ($-L \leq x \leq L$) начальной температуры $T_i$, помещённой в среду $T_\infty$:

{{< formula display="true" >}}
\theta^* = \frac{T(x,t) - T_\infty}{T_i - T_\infty} = \sum_{n=1}^{\infty} C_n \exp(-\zeta_n^2 Fo) \cos(\zeta_n x/L)
{{< /formula >}}

где $\zeta_n$ — корни уравнения $\zeta_n \tan\zeta_n = Bi$.

При $Fo > 0{,}2$ достаточно первого члена:

{{< formula display="true" >}}
\theta^* \approx C_1 \exp(-\zeta_1^2 Fo) \cos(\zeta_1 x/L)
{{< /formula >}}

**Диаграммы Хайслера** (Heisler charts) — графические решения для бесконечной пластины, бесконечного цилиндра и сферы. Входные параметры: $Bi$ и $Fo$; выходные — $\theta_0^*$ (безразмерная температура центра) и $\theta^*/\theta_0^*$ (поправка по положению).

## Полубесконечное тело

Полубесконечное тело ($x \geq 0$) — приближение, пригодное пока глубина теплового проникновения мала по сравнению с размерами тела.

**Критерий применимости**: физический размер $> 4\sqrt{\alpha t}$.

### Постоянная температура поверхности $T_s$

{{< formula display="true" >}}
\frac{T(x,t) - T_s}{T_i - T_s} = \mathrm{erf}\!\left(\frac{x}{2\sqrt{\alpha t}}\right)
{{< /formula >}}

Тепловой поток на поверхности:

{{< formula display="true" >}}
q''_s(t) = \frac{k(T_s - T_i)}{\sqrt{\pi \alpha t}}
{{< /formula >}}

### Конвективное граничное условие

При внезапном воздействии конвекции ($h$, $T_\infty$) на поверхность:

{{< formula display="true" >}}
\frac{T(x,t) - T_i}{T_\infty - T_i} = \mathrm{erfc}\!\left(\frac{x}{2\sqrt{\alpha t}}\right) - \exp\!\left(\frac{hx}{k} + \frac{h^2 \alpha t}{k^2}\right) \mathrm{erfc}\!\left(\frac{x}{2\sqrt{\alpha t}} + \frac{h\sqrt{\alpha t}}{k}\right)
{{< /formula >}}

### Числовой пример: прогрев грунта у здания

**Задача.** Начальная температура грунта $T_i = 0°$С. В начале отопительного сезона температура поверхности пола резко поднимается до $T_s = 15°$С. Найти температуру грунта на глубине $x = 0{,}5$ м через $t = 2$ суток. Параметры грунта: $\alpha = 0{,}5 \times 10^{-6}$ м²/с.

{{< formula display="true" >}}
\frac{x}{2\sqrt{\alpha t}} = \frac{0{,}5}{2\sqrt{0{,}5 \times 10^{-6} \times 172800}} = \frac{0{,}5}{2 \times 0{,}294} = 0{,}850
{{< /formula >}}

{{< formula display="true" >}}
\mathrm{erf}(0{,}850) = 0{,}7707
\quad\Rightarrow\quad
T = 15 - 15 \times 0{,}7707 = 3{,}4°\text{С}
{{< /formula >}}

## Тепловая масса ограждающих конструкций зданий

Способность строительных конструкций накапливать и отдавать теплоту определяет динамику внутреннего климата и пиковые нагрузки HVAC.

### Эффективная тепловая ёмкость

Для синусоидального суточного цикла нагрева глубина теплового проникновения:

{{< formula display="true" >}}
\delta_m = \sqrt{\frac{\alpha P}{\pi}} \approx \sqrt{\frac{\alpha \times 86400}{\pi}}
{{< /formula >}}

где $P = 86400$ с — период (24 ч).

{{< table title="Эффективная глубина теплового проникновения для суточного цикла" >}}
| Материал | $\delta_m$, мм |
|---|---|
| Бетон тяжёлый | 152 |
| Кирпич | 106 |
| Газобетон D500 | 101 |
| Гипсокартон | 70 |
| Дерево | 62 |
{{< /table >}}

### Коэффициент затухания

Отношение амплитуды колебаний внутренней температуры к амплитуде наружной:

{{< formula display="true" >}}
f = \frac{|T_{int,amp}|}{|T_{ext,amp}|}
{{< /formula >}}

Для тяжёлых конструкций: $f = 0{,}1$–$0{,}4$; для лёгких каркасных: $f = 0{,}6$–$0{,}9$.

### Фазовое запаздывание

Время от пика наружной температуры до пика внутренней:

{{< formula display="true" >}}
\phi \approx \frac{L}{\sqrt{\alpha \pi / P}} \quad [\text{с}]
{{< /formula >}}

Увеличение тепловой массы снижает пиковые нагрузки на охлаждение, но требует большей мощности системы HVAC для быстрого изменения внутренней температуры.

## Числовой пример: время прогрева трубопровода

**Задача.** Стальной трубопровод (DN50, наружный диаметр 60,3 мм, стенка 3,65 мм) при $T_i = 5°$С подключают к котлу. Вода при $T_\infty = 80°$С. Коэффициент конвекции воды $h = 2500$ Вт/(м²·К). Найти время, когда наружная поверхность трубы достигнет 75°С.

Характерная длина: $L_c = V/A_s = (\pi r_2^2 - \pi r_1^2) / 2\pi r_2 = (r_2^2 - r_1^2)/(2r_2)$.

$r_1 = 26{,}5$ мм, $r_2 = 30{,}15$ мм: $L_c = (30{,}15^2 - 26{,}5^2)/(2 \times 30{,}15) = 3{,}60$ мм.

{{< formula display="true" >}}
Bi = \frac{h L_c}{k_{steel}} = \frac{2500 \times 0{,}00360}{50} = 0{,}18 > 0{,}1
{{< /formula >}}

$Bi$ незначительно превышает 0,1, поэтому метод сосредоточенной ёмкости даёт погрешность около 5%, что приемлемо для практических расчётов.

{{< formula display="true" >}}
\tau = \frac{\rho c_p L_c}{h} = \frac{7850 \times 490 \times 0{,}00360}{2500} = 5{,}55 \;\text{с}
{{< /formula >}}

{{< formula display="true" >}}
t = -\tau \ln\!\frac{75 - 80}{5 - 80} = -5{,}55 \times \ln(0{,}067) = 5{,}55 \times 2{,}70 = 15 \;\text{с}
{{< /formula >}}

Стальная труба прогревается практически мгновенно.

## Численные методы решения нестационарных задач

### Метод конечных разностей (явная схема)

{{< formula display="true" >}}
\frac{T_i^{n+1} - T_i^n}{\Delta t} = \alpha \frac{T_{i+1}^n - 2T_i^n + T_{i-1}^n}{(\Delta x)^2}
{{< /formula >}}

**Критерий устойчивости** явной схемы: $Fo_{\Delta} = \alpha \Delta t / (\Delta x)^2 \leq 0{,}5$.

### Схема Кранка–Николсона (неявно-явная, безусловно устойчивая)

{{< formula display="true" >}}
\frac{T_i^{n+1} - T_i^n}{\Delta t} = \frac{\alpha}{2} \left[\frac{\delta^2 T^n}{(\Delta x)^2} + \frac{\delta^2 T^{n+1}}{(\Delta x)^2}\right]
{{< /formula >}}

Погрешность $O(\Delta t^2, \Delta x^2)$ — второй порядок по времени и пространству. Используется в программах энергетического моделирования EnergyPlus и TRNSYS.

### Применение в программах моделирования зданий

EnergyPlus (DOE, США) решает систему связанных нестационарных уравнений теплопроводности для многослойных ограждающих конструкций методом CTF (Conduction Transfer Functions). TRNSYS использует передаточные функции, вычисленные по конечно-разностной схеме.

## Тепловая инерция и классификация ограждений

Параметр тепловой инерции по СП 50.13330.2017:

{{< formula display="true" >}}
D = R_1 s_1 + R_2 s_2 + \ldots + R_n s_n
{{< /formula >}}

где $s_j$ — коэффициент теплоусвоения $j$-го слоя (Вт/(м²·К)), $s = \sqrt{k \rho c_p \omega_0}$, $\omega_0 = 2\pi/86400$ рад/с.

{{< table title="Классификация ограждающих конструкций по тепловой инерции (СП 50)" >}}
| Класс | $D$ | Характеристика |
|---|---|---|
| Малоинерционные | < 1,5 | Каркасные, легкие панели |
| Среднеинерционные | 1,5–4,0 | Типовой кирпич, бетон |
| Повышенноинерционные | 4,0–7,0 | Тяжёлый бетон, крупные стены |
| Высокоинерционные | > 7,0 | Массивный бетон |
{{< /table >}}
