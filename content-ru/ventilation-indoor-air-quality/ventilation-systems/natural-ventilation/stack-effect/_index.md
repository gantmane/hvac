## Обзор

Естественная вентиляция за счёт эффекта тяги использует силы плавучести, создаваемые разностью температур между внутренним и наружным воздухом, для создания естественных воздушных потоков через здания. Этот пассивный механизм вентиляции становится доминирующей движущей силой в высоких зданиях и вертикальных шахтах, где влияние ветра минимально.

Фундаментальный принцип основан на разнице в плотности тёплого внутреннего воздуха и более холодного наружного воздуха, создавая вертикальный градиент давления, который приводит в движение воздушный поток без механической помощи.

## Физика давления тяги

### Фундаментальная зависимость

Давление тяги развивается из-за гидростатической разницы давлений между столбами воздуха различных температур. Движущее давление на любой высоте:

$$\Delta P_s = \rho_o g h \left(1 - \frac{T_o}{T_i}\right)$$

Где:
- $\Delta P_s$ = давление тяги (Па)
- $\rho_o$ = плотность наружного воздуха (кг/м³)
- $g$ = ускорение свободного падения (9,81 м/с²)
- $h$ = вертикальная высота между отверстиями (м)
- $T_o$ = абсолютная температура наружного воздуха (К)
- $T_i$ = абсолютная температура внутреннего воздуха (К)

### Упрощённый расчёт

Для практических применений с небольшими разностями температур зависимость упрощается до:

$$\Delta P_s = C_s h \Delta T$$

Где:
- $C_s$ = коэффициент тяги ≈ 0,0342 Па/(м·К) при стандартных условиях
- $\Delta T$ = разность температур $T_i - T_o$ (К)

Это приближение справедливо для разностей температур до примерно 30 К.

## Расчёт воздушного потока

### Объёмный расход воздуха

Воздушный поток через отверстия, приводимые в движение эффектом тяги, подчиняется принципам истечения из отверстия:

$$Q = C_d A \sqrt{\frac{2 \Delta P_s}{\rho}}$$

Где:
- $Q$ = объёмный расход воздуха (м³/с)
- $C_d$ = коэффициент расхода (обычно 0,6–0,65 для отверстий с острыми кромками)
- $A$ = эффективная площадь отверстия (м²)
- $\rho$ = плотность воздуха (кг/м³)

### Комбинированные отверстия

Для зданий с входными и выходными отверстиями эффективная площадь становится:

$$A_{eff} = \frac{1}{\sqrt{\frac{1}{A_{inlet}^2} + \frac{1}{A_{outlet}^2}}}$$

Эта зависимость показывает, что меньшее отверстие определяет сопротивление потоку и ограничивает общий воздушный поток.

## Нейтральная плоскость давления

### Определение и расположение

Нейтральная плоскость давления (НПД) представляет собой горизонтальный уровень, на котором давление внутри и снаружи здания выравниваются. Выше этой плоскости внутреннее давление превышает наружное давление (экфильтрация), а ниже её наружное давление превышает внутреннее давление (инфильтрация).

Для одного замкнутого пространства с отверстиями в верхней и нижней части расположение НПД:

$$h_n = \frac{h}{1 + \sqrt{A_{bottom}/A_{top}}}$$

Где:
- $h_n$ = высота НПД над нижним отверстием (м)
- $h$ = общая высота между отверстиями (м)
- $A_{bottom}$ = площадь нижнего отверстия (м²)
- $A_{top}$ = площадь верхнего отверстия (м²)

### Следствия для проектирования

**Равные площади отверстий:** НПД расположена на середине высоты, создавая симметричное распределение давления.

**Неравные площади отверстий:** НПД смещается в сторону большего отверстия, влияя на градиенты давления и картины инфильтрации.

**Многоэтажные здания:** Каждый этаж испытывает различные зоны давления, требующие тщательного анализа для каждого уровня.

## Проектирование теплового дымохода

### Принцип работы

Тепловые дымоходы — это вертикальные шахты, предназначенные для максимизации эффекта тяги за счёт:

1. **Солнечной теплоты:** Поглощение солнечной радиации для повышения температуры воздуха
2. **Тепловой инерции:** Аккумулирование тепла для продления работы сверх дневного времени
3. **Оптимизации высоты:** Максимизация вертикального расстояния для развития давления
4. **Выбора площади:** Балансирование сопротивления потоку и требований к выпуску

### Параметры проектирования

**Высота дымохода:**
Более высокие дымоходы создают большие перепады давления. Минимальная высота 3–4 м обычно требуется для эффективной работы, оптимальная производительность достигается при 6–10 м для жилых приложений.

**Площадь поперечного сечения:**
Выбор размера следует принципам сохранения импульса и неразрывности. Для целевого расхода воздуха:

$$A_{chimney} = \frac{Q}{v_{design}}$$

Типичные скорости проектирования находятся в диапазоне 0,5–1,5 м/с для поддержания ламинарного потока и минимизации шума.

**Поглощаемость поверхности:**
Тёмные поверхности (α > 0,8) максимизируют солнечное теплоусвоение. Остеклённые дымоходы усиливают эффект теплицы, достигая повышения температуры на 15–25 К выше окружающей среды.

### Конфигурация солнечного дымохода

```
┌─────────────────┐
│   Выходное     │ ← Выпуск горячего воздуха
│   отверстие    │
├─────────────────┤
│                 │
│    Абсорбер     │ ← Тёмная поверхность, нагревается солнцем
│    поверхность  │   Температура: To + 15–25 K
│                 │
│   Воздушный     │ ← Поднимающийся тёплый воздух
│   канал         │   Скорость: 0,5–1,5 м/с
│                 │
│   Остекление    │ ← Прозрачное покрытие
│                 │   Эффект теплицы
│                 │
├─────────────────┤
│   Входное       │ ← Приём холодного воздуха
│   отверстие     │
└─────────────────┘
```

## Стратегии вентиляции атриумов

### Атриум как тепловой двигатель

Атриумы зданий функционируют как крупномасштабные тепловые дымоходы при надлежащем проектировании. Большой объём позволяет значительную тепловую стратификацию, с разностью температур 10–15 К между уровнями пола и крыши.

### Конфигурации проектирования

**Односторонний атриум:**
Отверстия на уровне земли и крыши создают прямой вертикальный путь воздушного потока. Подходит для умеренных климатов с постоянными разностями температур.

**Перекрёстная вентиляция атриума:**
Сочетает эффект тяги с вентиляцией, вызванной ветром, благодаря стратегическому размещению отверстий на противоположных фасадах.

**Сегментированный атриум:**
Несколько этажей с отдельными вентиляционными зонами, подключёнными к центральной шахте, позволяет независимый контроль при совместном использовании пропускной способности выпуска.

### Стратегия размещения отверстий

```
     Вентиляционные отверстия на крыше (выпуск)
            ↑
    ┌───────┴───────┐
    │               │
    │    Стратифи-  │  ← Горячий слой (Ti + 10–15 K)
    │    цированная │
    │    горячая    │
    │    зона       │
    ├───────────────┤
    │               │
    │    Смешанный  │
    │    объём      │  ← Промежуточные температуры
    │    атриума    │
    │               │
    ├───────────────┤
    │               │
    │    Холодная   │  ← Близко к окружающей температуре
    │    зона       │
    └───────┬───────┘
            ↓
    Входные отверстия на уровне земли
```

**Верхние выпускные отверстия:**
Расположены в пределах верхних 10–15% высоты атриума для захвата стратифицированного тёплого воздуха. Автоматический контроль реагирует на датчики температуры.

**Нижние входные отверстия:**
Позиционированы для подачи более холодного наружного воздуха или кондиционированного воздуха из соседних пространств. Затенение и стратегическая ориентация минимизируют солнечное теплоусвоение на входе.

**Промежуточные отверстия:**
Отверстия на уровне пола на различных высотах позволяют занятым помещениям получать доступ к градиенту давления без прямого соединения с зонами экстремальных температур.

## Эффект высоты здания

Давление тяги увеличивается линейно с высотой, что делает высокие здания особенно эффективными для вентиляции за счёт тяги:

- **Низкоэтажное (h < 10 м):** Эффект тяги минимален, доминирует ветер
- **Среднеэтажное (10–30 м):** Эффект тяги значителен, в сочетании с влиянием ветра
- **Высокоэтажное (h > 30 м):** Эффект тяги доминирует, требует стратегий сброса давления

Для зданий, превышающих 50 м, давления тяги могут достигать 50–100 Па, требуя тамбуров, раздвижных дверей или механического сброса давления для предотвращения чрезмерной инфильтрации и сложностей с открыванием дверей.

## Практические рекомендации по проектированию

**Поддержание разности температур:**
Естественная вентиляция требует постоянной разности температур внутри и снаружи. Эффективность снижается по мере приближения наружной температуры к установленной температуре внутри.

**Сезонная производительность:**
Эффект тяги меняет направление летом, когда наружные температуры превышают внутренние температуры, требуя альтернативных стратегий вентиляции или гибридных систем.

**Управление отверстиями:**
Автоматические заслонки или регулируемые вручную вентиляционные отверстия позволяют оптимизировать работу при различных условиях. Датчики, чувствительные к температуре, обеспечивают пассивный контроль.

**Интеграция с механическими системами:**
Гибридные подходы сочетают естественную вентиляцию за счёт тяги в благоприятных условиях с механическим резервом, оптимизируя энергопотребление при обеспечении круглогодичной производительности.

## Метрики производительности

Эффективное проектирование вентиляции за счёт тяги достигает:
- Кратность воздухообмена: 4–12 ACH в зависимости от геометрии здания и разности температур
- Перепады давления: 2–20 Па для жилых, до 50+ Па для высоких коммерческих зданий
- Энергосбережение: снижение энергии вентиляторов HVAC на 30–60% по сравнению с полностью механическими системами

Эти метрики требуют тщательной интеграции проектирования отверстий, геометрии здания и климатических стратегий управления для эффективного использования сил плавучести.
