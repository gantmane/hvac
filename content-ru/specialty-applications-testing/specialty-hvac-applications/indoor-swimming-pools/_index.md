Объекты с бассейнами в закрытых помещениях, или нататории, представляют собой уникальные задачи для систем ОВКВ, включая экстремальные нагрузки по влажности, агрессивные атмосферные условия и строгие требования к качеству воздуха для здоровья пловцов и защиты здания.

## Проблемы проектирования

### Генерация влажности

Испарение с поверхности бассейна создает значительную влажность:

$$W_{evap} = A \times (p_{sat,water} - p_{air}) \times K_{activity}$$

Где:
- A = площадь поверхности бассейна
- p = парциальное давление пара
- K = коэффициент активности (0,5–1,0)

**Скорости испарения**:
| Уровень активности | Испарение (кг/ч/м²) |
|------|------------|
| Спокойный бассейн | 0,02–0,03 |
| Частное использование | 0,03–0,04 |
| Публичный бассейн | 0,05–0,06 |
| Соревнования | 0,06–0,07 |
| Волновые бассейны | 0,14–0,19 |

### Проблемы с хлораминами

Хлорамины (связанный хлор) образуются при реакции хлора с органическими соединениями:

**Влияние на здоровье**:
- Раздражение глаз и дыхательных путей
- Триггеры астмы
- Снижение качества воздуха

**Стратегии контроля**:
- Достаточная вентиляция
- Локальный отсос у источника
- УФ-обработка воды в бассейне
- Правильная химия воды

### Коррозионная среда

Теплый, влажный и хлорированный воздух атакует:
- Стальные конструкции
- Электрооборудование
- Воздуховоды
- Отделочные материалы здания

## Требования к вентиляции

### Кратность воздухообмена

Рекомендации ASHRAE:

| Помещение | Мин. ACH | Наружный воздух |
|-------|-------|------------|
| Зона бассейна | 4–6 | 0,48 CFM/ft² (2,4 м³/ч/м²) |
| Зоны для зрителей | 4–8 | 15 CFM/чел (7,5 м³/ч/чел) |
| Раздевалки | 4–6 | 0,5 CFM/ft² (2,5 м³/ч/м²) |
| Душевые | 10–15 | 50 CFM/чел (25 м³/ч/чел) |

### Наружный воздух

Минимальный приток наружного воздуха для нататориев:
- ASHRAE 62.1: 0,48 CFM/ft² (2,4 м³/ч/м²) настилом бассейна
- Улавливание хлораминов у источника
- Предотвращение рециркуляции загрязнителей

### Распределение воздуха

**Приточный воздух**:
- Высокий уровень на стенах или потолке
- Направлен над поверхностью бассейна
- 0,13–0,25 м/с на поверхности бассейна (минимизирует испарение)

**Вытяжной воздух/Удаление**:
- Низкий уровень на стенах (у уровня настила)
- Улавливание тяжелых соединений хлорамина
- Несколько точек по периметру

## Температура и влажность

### Проектные условия

| Параметр | Зона бассейна | Зона зрителей |
|--|---|-----|
| Сухой термометр | 28–30°C | 24–26°C |
| Относительная влажность | 50–60% | 50–60% |
| Температура настила | 29–31°C | Н/Д |

### Взаимосвязь «вода-воздух»

Поддерживать температуру воздуха на 1–3°C выше температуры воды:
- Снижает скорость испарения
- Улучшает комфорт пловцов
- Предотвращает образование тумана

$$T_{air} = T_{water} + (1°C\ to\ 3°C)$$

### Контроль влажности

Целевая относительная влажность 50–60% для баланса:
- <50%: Чрезмерное испарение, дискомфорт пловцов
- >60%: Риск конденсации, проблемы с комфортом

## Системы осушения

### Осушители на хладагенте

Механическое осушение с рекуперацией тепла:

**Рабочий цикл**:
1. Воздух проходит через испаритель (охлаждается ниже точки росы)
2. Влага конденсируется и отводится
3. Воздух нагревается на конденсаторе
4. Часть тепла возвращается в воду бассейна

**Эффективность**:
- COP: 4–6 для осушения
- Рекуперация тепла в бассейн: 50–80% от удаленной скрытой теплоты

### Системы наружного воздуха

Использование наружного воздуха для осушения при благоприятных условиях:

$$m_{OA} = \frac{m_{moisture}}{W_{return} - W_{OA}}$$

**Эффективно при**:
- Влажностное отношение наружного воздуха < внутреннего
- Обычно при температуре наружного воздуха 10°C и ниже

### Десикантные системы

Десикантные колеса для специализированных применений:
- Требования к очень низкой влажности
- Рекуперация тепла из вытяжного воздуха
- Комбинация с системами на хладагенте

### Гибридные подходы

Комбинация методов для оптимизации:
- Наружный воздух при эффективности
- Механическое осушение при необходимости
- Рекуперация тепла тепловыми насосами
- Рекуперация энергии из вытяжного воздуха

## Компоненты системы ОВКВ

### Воздухообрабатывающие установки

Специализированные AHU для нататориев:
- Коррозионностойкое исполнение (нержавеющая сталь, алюминий, покрытые)
- Большая мощность приточного/вытяжного воздуха
- Интегрированное осушение
- Фильтрация высокого качества

### Воздуховоды

**Выбор материала**:
| Материал | Применение | Примечания |
|------|-----------|------------|
| Алюминий | Предпочтительный | Коррозионностойкий |
| Нержавеющая сталь | Высокая коррозия | Более высокая стоимость |
| Стекловолокно | Приточные воздуховоды | Без зон конденсации |
| ПВХ | Вытяжные воздуховоды | Для определенных применений |

**Избегать**: Оцинкованная сталь в атмосфере зоны бассейна

### Системы вытяжной вентиляции

Специализированная вытяжка бассейна:
- Коррозионностойкие вентиляторы
- Точки забора на низком уровне
- Выброс на крыше
- Отдельно от общей системы ОВКВ

## Энергоэффективность

### Рекуперация тепла

Несколько возможностей рекуперации тепла:

| Источник | Метод рекуперации | Применение |
|--|------|-----|
| Вытяжной воздух | Воздух-воздух теплообменник | Предварительный нагрев наружного воздуха |
| Тепло конденсатора | Десуперхитер | Нагрев воды бассейна |
| Осушитель | Рекуперация тепла | Отопление помещения/бассейна |

### Чехлы для бассейна

Снижение испарения в периоды отсутствия людей:
- Снижение испарения на 50–70%
- Автоматические чехлы для удобства
- Возможность снижения вентиляции при использовании чехла

### Стратегии управления

- Снижение режима при отсутствии людей
- Интеграция с чехлами бассейна
- Экономайзер наружного воздуха при эффективности
- Вентиляция по требованию

## Особые соображения

### Предотвращение конденсации

Предотвращение поверхностной конденсации:
- Поддержание температуры стен выше точки росы
- Хорошая теплоизоляция наружных стен
- Подогрев рам и остекления окон
- Движение воздуха над поверхностями

### Защита конструкций

Проектирование для долговечности:
- Пароизоляция со стороны теплого помещения
- Нержавеющие крепежные элементы
- Защитные покрытия
- Выбор материалов на всем протяжении

### Акустика

Бассейны усиливают звук:
- Звукопоглощающие материалы
- Глушители в воздуховодах
- Изоляция оборудования
- Учет фонового шума

Системы ОВКВ для бассейнов в закрытых помещениях требуют специализированного проектирования, учитывающего экстремальную влажность, качество воздуха и проблемы коррозии, обеспечивая при этом энергоэффективную работу для этих сложных объектов.
