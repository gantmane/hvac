Стандарты САПР устанавливают единые протоколы документации во всех командах проекта. Стандартизированные имена слоев, структуры файлов и соглашения о чертежах обеспечивают эффективную координацию между дисциплинами, снижают ошибки и облегчают ясность строительной документации.

## Национальный стандарт САПР (NCS)

Национальный стандарт САПР предоставляет основу для единой документации САПР в промышленности AEC. NCS интегрирует несколько стандартов, включая рекомендации AIA CAD Layer, систему единообразного рисования NIBS и стандарты вывода.

### Структура именования слоев

NCS использует восьмиполевой формат именования слоев:

```
D-AAAA-BBBB-C-DDD-EE-FF-G
```

**Определение полей:**
- **D** = Обозначение дисциплины
- **AAAA** = Основная группа (4 символа)
- **BBBB** = Подгруппа (4 символа)
- **C** = Статус
- **DDD** = Определяемое пользователем
- **EE** = Графические свойства
- **FF** = Обозначение материала
- **G** = Определяемое пользователем 2

### Обозначения механической дисциплины

| Обозначение | Описание |
|------------|----------|
| M | Механическое (общее) |
| M-HVAC | Системы HVAC |
| M-PLMB | Системы водопровода |
| M-FIRE | Системы пожаротушения |

### Обозначения поля статуса

| Статус | Описание | Свойства линии |
|--------|---------|----------------|
| E | Существующее, остается | Сплошная, средний вес |
| D | Существующее, подлежит сносу | Пунктирная, легкий вес |
| N | Новые работы | Сплошная, тяжелый вес |
| T | Временное | Штрих-точка, средний вес |
| F | Будущие работы | Пунктирная, легкий вес |

**Примеры применения:**
```
M-HVAC-DUCT-E-S    Существующий воздуховод подачи, остается
M-HVAC-DUCT-D-S    Воздуховод подачи, подлежит сносу
M-HVAC-DUCT-N-S    Новая установка воздуховода подачи
```

## Соглашения об именовании файлов

Единое именование файлов обеспечивает быструю идентификацию и снижает ошибки при управлении xref и компиляции листов.

### Структура именования файла чертежа

```
[Проект]-[Дисциплина][Тип листа][Номер листа]-[Редакция].dwg
```

**Пример:**
```
2024-001-MHVAC-101-R3.dwg
```

**Компоненты:**
- **2024-001** = Номер/идентификатор проекта
- **M** = Механическая дисциплина
- **HVAC** = Поддисциплина
- **101** = Номер листа
- **R3** = Редакция 3

### Коды типов листов

| Код | Тип листа |
|-----|-----------|
| T | Титульный лист |
| G | Общая информация |
| 0 | Общие планы |
| 1 | Планы этажей |
| 2 | Увеличенные планы |
| 3 | Разрезы |
| 4 | Фасады |
| 5 | Детали |
| 6 | Расписания |
| 7 | Диаграммы/Схемы |
| 8 | Поддержка спецификаций |
| 9 | Трехмерные представления |

### Именование файлов xref

Файлы внешних ссылок должны следовать параллельному именованию:

```
[Проект]-[Дисциплина]-[Тип содержимого].dwg
```

**Примеры:**
```
2024-001-M-EQUP.dwg        xref оборудования
2024-001-M-DUCT.dwg        xref воздуховода
2024-001-M-PIPE.dwg        xref трубопровода
2024-001-A-BASE.dwg        архитектурная база
2024-001-S-GRID.dwg        структурная сетка
```

### Организация вспомогательных файлов

**Структура каталога:**
```
/Корень проекта
  /Чертежи
    /Листы             Файлы компоновки листов
    /Xrefs             Файлы внешних ссылок
    /Детали            Файлы библиотеки деталей
  /Блоки
    /Оборудование      Блоки оборудования
    /Символы           Библиотека символов
    /Тип блока         Шаблоны титульного блока
  /Стандарты
    /Шаблоны           Шаблоны чертежей
    /Типы линий        Определения пользовательских типов линий
    /Шаблоны           Файлы шаблонов штриховки
    /Шрифты            Шрифты проекта
  /Выводы
    /PDF               Выход PDF
    /DWF               Выход DWF
```

## Управление внешней ссылкой (xref)

Xrefs обеспечивают модульное построение чертежей и сотрудничество между несколькими пользователями. Надлежащее управление xref имеет решающее значение для крупных проектов HVAC.

### Методы присоединения xref

**Присоединение против наложения:**

- **Присоединить**: Xref появляется в хост-чертеже и любых чертежах, которые ссылаются на хост
- **Наложить**: Xref появляется только в хост-чертеже, не в вложенных ссылках

**Рекомендации по использованию:**
- Используйте **Присоединить** для архитектурных чертежей, структурных сеток
- Используйте **Наложить** для содержимого, специфичного для дисциплины в композитных листах
- Избегайте циклических ссылок (A ссылается на B, B ссылается на A)

### Контроль слоя ссылки

**Соглашение об именовании слоя xref:**
```
[Имя файла Xref]|[Имя слоя]
```

**Пример:**
```
2024-001-A-BASE|A-WALL
2024-001-A-BASE|A-DOOR
```

**Управление состоянием слоя:**
- Создайте состояния слоев для разных целей просмотра (координация, вывод, представление)
- Сохраняйте состояния слоев в файлах листов для единообразного внешнего вида
- Используйте LAYMCUR для принудительной текущей установки слоя для создания сущности
- Применяйте LAYVPFRZ для замораживания слоев на слой видового экрана

### Управление путем xref

**Предпочитаются относительные пути:**
```
.\Xrefs\2024-001-A-BASE.dwg
```

**Типы путей:**
- **Полный путь**: Абсолютное местоположение (избегайте, нарушает портативность)
- **Относительный путь**: Относительно местоположения хост-чертежа (предпочтительно)
- **Без пути**: Тот же каталог, что и хост (приемлемо для небольших проектов)

**Лучшие практики:**
- Установите протоколы менеджера файлов ссылок (RFM)
- Используйте относительные пути проекта для командной среды
- Реализуйте Vault или ProjectWise для управления xref на уровне предприятия
- Перезагрузите xrefs в начале сеанса для захвата обновлений

## Стандарты блоков и библиотеки

Стандартизированные блоки обеспечивают единообразное представление и позволяют быстро обновлять листы.

### Соглашения об именовании блоков

```
[Категория]-[Тип]-[Размер/Спецификация]
```

**Примеры:**
```
EQUP-AHU-15000CFM
EQUP-RTU-10TON
EQUP-FCU-900CFM
EQUP-PUMP-5HP
TERM-VAV-REHEAT
TERM-VAV-COOLONLY
GRLL-SUPPLY-24X24
GRLL-RETURN-24X12
DIFF-ROUND-24
DIFF-SQUARE-24X24
```

### Стандарты атрибутов блока

**Требуемые атрибуты:**
- **TAG**: Идентификация оборудования (например, AHU-1, P-1)
- **TYPE**: Описание типа оборудования
- **SIZE**: Емкость или физический размер
- **MODEL**: Номер модели производителя (опционально)
- **NOTES**: Дополнительные спецификации

**Свойства атрибута:**
- Выравнивание: Центр посередине для тегов, влево для описаний
- Высота: 0,09" для тегов (масштабируется до 3/32" при 1"=1'), 0,0625" для примечаний
- Слой: M-HVAC-ANNO-IDEN для тегов, M-HVAC-ANNO-NOTE для описаний

### Динамические блоки

**Состояния видимости для оборудования:**
- Базовое представление (упрощенное для планов)
- Детальное представление (для увеличенных планов)
- Схематическое представление (для диаграмм)
- Показатели зазора обслуживания

**Параметрические функции:**
- Регулируемая длина для воздухообрабатывающих установок
- Переменные позиции входа/выхода
- Масштабируемые размеры решеток (6" приросты)
- Захватные точки растяжения для компонентов трубопровода

### Структура слоя блока

**Стратегия слоя 0:**
- Геометрия на слое 0 наследует свойства родительского слоя
- Позволяет одному определению блока появляться на нескольких слоях

**Исключения:**
- Пунктирные линии (просветы, будущие элементы) на определенных слоях
- Скрытые линии для внутренних функций оборудования
- Центральные линии для механического оборудования

## Стандарты вывода и выход

Единые стандарты вывода обеспечивают единообразный внешний вид документа и читаемость.

### CTB (зависит от цвета) в сравнении со STB (именованный)

**CTB (цветовая таблица):**
- Свойства вывода назначаются по цвету сущности
- 255 цветовых слотов сопоставляются с весами линий
- Устаревший стандарт, широко распространен

**STB (на основе стиля):**
- Свойства вывода назначаются по названным стилям
- Независимо от цвета отображения
- Большая гибкость, требует управления стилем

**Стандарт промышленности HVAC:** CTB остается доминирующим из-за установленных рабочих процессов и совместимости с унаследованными системами.

### Стандартная конфигурация CTB

| Цвет | Вес линии | Описание | Применение |
|------|-----------|---------|-----------|
| 1 (красный) | 0,25 мм | Легкая | Линии размеров, шаблоны штриховки |
| 2 (желтый) | 0,13 мм | Очень легкая | Скрытые линии, осевые линии |
| 3 (зеленый) | 0,35 мм | Средняя | Воздуховод подачи воздуха |
| 4 (голубой) | 0,35 мм | Средняя | Воздуховод возврата воздуха |
| 5 (синий) | 0,35 мм | Средняя | Воздуховод вытяжки воздуха |
| 6 (пурпурный) | 0,18 мм | Легкая | Провода управления |
| 7 (белый) | 0,50 мм | Тяжелая | Контуры оборудования, основной трубопровод |
| 8 (серый) | 0,13 мм | Очень легкая | Справочные чертежи фона |
| 9 (светлый серый) | 0,25 мм | Легкая | Существующие/сносимые элементы |
| 250-255 | 0,00 мм | Линия экрана | Непечатаемые цвета |

### Стандарты линий воздуховода

**Подача воздуха:**
- Цвет: Зеленый (3) или голубой (4)
- Вес линии: 0,35 мм
- Тип линии: Сплошная

**Возврат воздуха:**
- Цвет: Голубой (4) или синий (5)
- Вес линии: 0,30 мм
- Тип линии: Сплошная или HIDDEN2

**Вытяжка воздуха:**
- Цвет: Синий (5) или пурпурный (6)
- Вес линии: 0,30 мм
- Тип линии: Сплошная

**Наружный воздух:**
- Цвет: Зеленый (3)
- Вес линии: 0,35 мм
- Тип линии: Сплошная, с аннотацией "OA"

### Стандарты линий трубопровода

| Система | Цвет | Вес линии | Примечания |
|---------|------|-----------|-----------|
| Подача охлажденной воды | Синий (5) | 0,50 мм | Тяжелая линия |
| Возврат охлажденной воды | Синий (5) | 0,35 мм | Средняя линия |
| Подача горячей воды | Красный (1) | 0,50 мм | Тяжелая линия |
| Возврат горячей воды | Красный (1) | 0,35 мм | Средняя линия |
| Конденсаторная вода | Голубой (4) | 0,35 мм | Метки "CWS/CWR" |
| Конденсатный дренаж | Желтый (2) | 0,25 мм | Легкая линия |
| Хладагент | Пурпурный (6) | 0,30 мм | Метки "RL/SL" |
| Пар | Красный (1) | 0,50 мм | Метки "S/SC" |

### Стандарты установки страницы

**Размеры листов:**
- ARCH D (610 × 914 мм) - Стандарт для механических планов
- ARCH E (762 × 1067 мм) - Крупные проекты, композитные чертежи
- ARCH C (457 × 610 мм) - Детали, небольшие планы

**Стандарты масштаба:**
```
Планы этажей:        1:96 или 1:48
Увеличенные планы:   1:48 или 1:24
Помещения оборудования: 1:48 или 1:32
Разрезы:             1:48 или 1:32
Детали:              1:24, 1:12 или 1:4
Диаграммы:           Не в масштабе (NTS)
```

### Конфигурация видового экрана

**Установка модельного пространства:**
- Чертите в полном масштабе (1:1)
- Используйте единообразно десятичные футы или дюймы
- Установите MEASUREMENT на 0 (имперский) или 1 (метрический)

**Установка бумажного пространства:**
- Создайте видовые экраны для каждого вида
- Заблокируйте масштаб видового экрана после установки
- Заморозьте слои на видовой экран по мере необходимости
- Используйте слой MVIEW для объектов видового экрана (установите на непечатаемый)

## Стандарты текста и аннотации

Единые стандарты текста обеспечивают читаемость на всех наборах листов и выходных носителях.

### Стандарты высоты текста

| Применение | Высота модельного пространства | Высота бумажного пространства | Высота вывода |
|------------|--------------------------------|-------------------------------|---------------|
| Названия чертежей | 9,5 мм | 9,5 мм | 9,5 мм |
| Общие примечания | 3,2 мм | 3,2 мм | 3,2 мм |
| Теги оборудования | 4,8 мм | 4,8 мм | 4,8 мм |
| Текст размеров | Варьируется по масштабу | 2,4 мм | 2,4 мм |
| Выноски деталей | 4,8 мм | 4,8 мм | 4,8 мм |

**Вычисление высоты текста в модельном пространстве:**
```
Высота модельного пространства = Высота вывода × Коэффициент масштаба
```

**Пример для масштаба 1:48:**
```
Коэффициент масштаба = 48
Высота текста = 2,4 мм × 48 = 115 мм
```

### Стандарты шрифтов

**Основной шрифт:** Arial или SansSerif
- Четкий, читаемый без засечек
- Единообразный на платформах
- Соответствие ADA для доступности

**Альтернативные шрифты:**
- Romans.shx для рабочих процессов на основе SHX
- Century Gothic для современного внешнего вида
- Избегайте декоративных шрифтов в технических чертежах

### Стандарты размеров

**Параметры стиля размеров:**
- Стрелки: Закрытые заполненные, длина 2,3 мм
- Смещение линии расширения: 1,6 мм
- Расширение за линией размеров: 3,2 мм
- Текст над линией размеров
- Допуски: Как указано в требованиях проекта

**Механическое измерение:**
- Воздуховод: От осевой линии к осевой линии ветвей
- Трубопровод: От осевой линии к поверхности фланцев
- Оборудование: Общие размеры и критические зазоры
- Зазоры: Минимальное рабочее пространство в соответствии с кодом

## Механические специфические практики САПР

### Представление воздуховода

**Соглашения плана:**
- Одна линия для прямоугольного воздуховода ≤ 30 см в наименьшем размере
- Двойная линия для прямоугольного воздуховода > 30 см в наименьшем размере
- Одна линия с обозначением диаметра для круглого воздуховода
- Показать изменения размера воздуховода при переходах
- Указать изменения высоты стрелками вверх/вниз

**Аннотация воздуховода:**
```
Подача:    610×305 S @ 1180 м³/ч
Возврат:   762×510 R @ 1650 м³/ч
Вытяжка:   457×356 E @ 850 м³/ч
Наружный воздух: 406×254 OA @ 570 м³/ч
```

**Соглашения раздела:**
- Показать профиль воздуховода (прямоугольный или круглый)
- Указать изоляцию со штриховкой
- Размерить вертикальные зазоры
- Показать конструктивные конфликты

### Представление трубопровода

**Соглашения о линиях:**
- Варьируйте вес линии для указания направления потока (тяжелая = подача, легкая = возврат)
- Используйте разные цвета для каждой системы
- Представление одной линии типично для 5 см и меньше
- Двойная линия для более крупного трубопровода где требуется ясность

**Аннотация трубопровода:**
```
Охлажденная вода:   76 мм CHWS
Горячая вода:       51 мм HWS
Конденсат:          19 мм CD
Хладагент:          28,6 мм SL / 22,2 мм LL
```

**Символы клапанов:**
- Шаровой кран: Круг с диагональной линией
- Задвижка: Треугольник
- Обратный клапан: Стрела в круге
- Обратный клапан: Стрела в круге
- Регулирующий клапан: Ромб с аннотацией

### Представление оборудования

**Уровни детализации:**

**Малый масштаб (1:96):**
- Упрощенный прямоугольный контур
- Тег оборудования и данные паспорта
- Только основные точки соединения

**Средний масштаб (1:48):**
- Точный контур и основные функции
- Все точки соединения
- Расположение дверей доступа
- Показатели зазора обслуживания

**Большой масштаб (1:24 или больше):**
- Детальная компоновка компонентов
- Представление внутренних функций
- Расположения анкерных болтов
- Размерная точность

### Практики координации

**Интеграция трехмерного моделирования:**
- Экспортируйте двухмерные чертежи из трехмерной модели
- Поддерживайте связь, где возможно
- Используйте трехмерное для обнаружения столкновений
- Двухмерные чертежи остаются контрактными документами

**Координация дисциплины:**
- Наложите архитектурные xrefs для разметки помещений
- Ссылайтесь на структурную сетку и каркас
- Проверьте зазоры электрооборудования
- Координируйте переходы водопровода/пожаротушения

**Рабочие процессы обнаружения столкновений:**
- Запустите Navisworks или аналогичное программное обеспечение координации
- Решайте жесткие столкновения (физические конфликты)
- Устраняйте мягкие столкновения (нарушения зазоров)
- Задокументируйте разрешение в координационных чертежах

- Ежегодно пересматривайте стандарты

- Обновление для новых функций программного обеспечения
