Подача воздуха для горения должна обеспечивать достаточное количество кислорода для полного окисления топлива, предотвращая кислородный дефицит, сохраняя производительность горелки и отвечая требованиям нормативов. Правильное проектирование системы воздуха горения охватывает расчёт стехиометрической потребности, определение избыточного воздуха, подбор вентилятора или размеров приточных отверстий, учёт влияния высоты и температуры, интеграцию с вентиляцией здания согласно NFPA 31, NFPA 54, NFPA 86 и СП 60.13330. Недостаточный воздух для горения вызывает неполное сгорание (CO), нагар, снижение КПД и создаёт угрозу безопасности.

## Стехиометрическая потребность в воздухе

### Основные расчётные соотношения

**Природный газ (метан):**

{{< formula display="true" >}}
\text{CH}_4 + 2\,\text{O}_2 + 7{,}52\,\text{N}_2 \;\rightarrow\; \text{CO}_2 + 2\,\text{H}_2\text{O} + 7{,}52\,\text{N}_2
{{< /formula >}}

{{< formula display="true" >}}
A_s = 9{,}52\;\frac{\text{м}^3_{\text{воздух}}}{\text{м}^3_{\text{CH}_4}}
\quad=\quad
17{,}2\;\frac{\text{кг}_{\text{воздух}}}{\text{кг}_{\text{CH}_4}}
\quad=\quad
1{,}22 \times 10^{-4}\;\frac{\text{м}^3}{\text{кДж}}
{{< /formula >}}

**Дизельное топливо № 2 (No. 2 fuel oil, C₁₂H₂₃):**

{{< formula display="true" >}}
A_s = 97\;\frac{\text{м}^3}{\text{л масла}}
\quad=\quad
13{,}8\;\frac{\text{кг}}{\text{кг масла}}
\quad=\quad
2{,}09 \times 10^{-3}\;\frac{\text{м}^3}{\text{кДж}}
{{< /formula >}}

**Пропан:**

{{< formula display="true" >}}
\text{C}_3\text{H}_8 + 5\,\text{O}_2 \;\rightarrow\; 3\,\text{CO}_2 + 4\,\text{H}_2\text{O}
\qquad
A_s = 23{,}8\;\frac{\text{м}^3}{\text{м}^3\;\text{C}_3\text{H}_8}
{{< /formula >}}

### Избыточный воздух (excess air)

{{< formula display="true" >}}
A_{\text{факт}} = A_s \times (1 + EA)
\qquad
EA\,\% = \frac{A_{\text{факт}} - A_s}{A_s} \times 100
{{< /formula >}}

Связь с содержанием O₂ в дымовых газах:

{{< formula display="true" >}}
EA = \frac{O_2\,\%}{21 - O_2\,\%}
\qquad
O_2\,\% = \frac{21 \times EA}{1 + EA}
{{< /formula >}}

**Пример.** Измеренный O₂ = 3 %:

{{< formula display="true" >}}
EA = \frac{3}{21 - 3} = 0{,}167 = 16{,}7\,\%
{{< /formula >}}

{{< table title="Типичный избыточный воздух и целевые O₂ по типам горелок" >}}
| Тип горелки | EA, % | O₂, % |
|---|---|---|
| Атмосферная газовая | 40–50 | 6–8 |
| Силовая газовая | 10–20 | 1,5–3,5 |
| Газовая с предварительным смешением | 5–15 | 0,8–2,5 |
| Масляная форсунка (давление) | 20–30 | 3,5–5,0 |
| Ротационная масляная | 15–25 | 2,5–4,5 |
| Паровая распыляющая | 10–20 | 1,5–3,5 |
{{< /table >}}

## Расчёт объёмного расхода воздуха

### Общее требование

**Для газовых горелок:**

{{< formula display="true" >}}
\dot{V}_{\text{воздух}} = \frac{Q_{\text{вход}}}{HHV_{\text{газ}}} \times A_s \times (1 + EA)
{{< /formula >}}

Для природного газа ($HHV = 37$ МДж/м³, $EA = 15\,\%$):

{{< formula display="true" >}}
\dot{V}_{\text{воздух}} = Q_{\text{кДж/ч}} \times 1{,}40 \times 10^{-4}\;\frac{\text{м}^3}{\text{ч}}
{{< /formula >}}

**Для масляных горелок** (мазут № 2, $EA = 20\,\%$):

{{< formula display="true" >}}
\dot{V}_{\text{воздух}} = \dot{V}_{\text{л/ч}} \times 116\;\frac{\text{м}^3}{\text{л}}
{{< /formula >}}

**Пример.** Газовая горелка 29,3 МДж/ч, $EA = 15\,\%$:

{{< formula display="true" >}}
\dot{V}_{\text{воздух}} = 29\,300 \times 1{,}40 \times 10^{-4} = 4{,}10\;\frac{\text{м}^3}{\text{ч}} = 1{,}14\;\frac{\text{м}^3}{\text{мин}}
{{< /formula >}}

### Поправка на плотность воздуха

Стандартные условия: 15 °C, 101,3 кПа, сухой воздух ($\rho_{\text{ст}} = 1{,}225$ кг/м³).

{{< formula display="true" >}}
\dot{V}_{\text{факт}} = \dot{V}_{\text{ст}} \times \frac{T_{\text{факт}}}{T_{\text{ст}}} \times \frac{P_{\text{ст}}}{P_{\text{факт}}}
{{< /formula >}}

**Пример.** Стандартный расход 1 140 м³/ч при 15 °C, фактическая температура воздуха 37,8 °C:

{{< formula display="true" >}}
\dot{V}_{\text{факт}} = 1\,140 \times \frac{310{,}95}{288{,}15} = 1\,223\;\frac{\text{м}^3}{\text{ч}}
{{< /formula >}}

Вентилятор должен обеспечивать фактический м³/ч при рабочей температуре, а не стандартный.

### Поправка на высоту над уровнем моря

{{< formula display="true" >}}
\rho_{\text{h}} = \rho_{\text{УМ}} \times e^{-h/8850}
{{< /formula >}}

{{< table title="Влияние высоты на плотность воздуха и требуемый объёмный расход" >}}
| Высота, м | Относительное давление | Относительная плотность | Увеличение объёма, % |
|---|---|---|---|
| 0 (уровень моря) | 1,00 | 1,00 | 0 |
| 300 | 0,964 | 0,964 | +3,7 |
| 760 | 0,917 | 0,917 | +9,1 |
| 1 525 | 0,832 | 0,832 | +20,2 |
| 2 300 | 0,753 | 0,753 | +32,8 |
{{< /table >}}

Атмосферные горелки на высоте аспирируют меньше воздуха — необходима корректировка тепловой мощности или дедерейтинг (derating). Силовые горелки с вентилятором компенсируют снижение плотности увеличением объёмного расхода.

## Методы подачи воздуха горения

### Инфильтрационный воздух (атмосферные горелки)

**Требования NFPA 54 — стандартный метод (два отверстия):**

Верхнее отверстие — в пределах 30 см от потолка; нижнее — в пределах 30 см от пола. Минимальная площадь каждого отверстия:

{{< formula display="true" >}}
A_{\text{отв}} = \frac{Q_{\text{вход,\,ккал/ч}}}{2\,500}\;\text{см}^2
{{< /formula >}}

Для наружных воздуховодов (vertical outdoor duct) — одно на верх, одно на низ:

{{< formula display="true" >}}
A_{\text{воздуховода}} = \frac{Q_{\text{кДж/ч}}}{11\,720}\;\text{м}^2
{{< /formula >}}

**Пример.** Печь 29,3 МДж/ч, вертикальные воздуховоды:

{{< formula display="true" >}}
A_{\text{воздуховода}} = \frac{29\,300}{11\,720} = 2{,}50 \times 10^{-3}\;\text{м}^2 = 25\;\text{см}^2\;\text{на воздуховод}
{{< /formula >}}

### Принудительная подача воздуха (силовые горелки)

**Параметры вентилятора воздуха горения:**

Требуемое статическое давление:

{{< formula display="true" >}}
P_{\text{вент}} = P_{\text{горелка}} + P_{\text{воздуховод}} + P_{\text{вход/выход}} + P_{\text{фильтр}} + \delta
{{< /formula >}}

Типичные составляющие:
- перепад давления горелки: 100–150 Па (силовые горелки);
- потери в воздуховодах: 25–75 Па;
- вход/выход: 10–25 Па;
- фильтр (чистый/загрязнённый): 10–50 Па;
- запас $\delta$: 10–25 % суммы.

**Пример подбора вентилятора.** Горелка 29,3 МДж/ч; температура воздуха 26,7 °C; $EA = 15\,\%$:

{{< formula display="true" >}}
\dot{V}_{\text{ст}} = 29\,300 \times 1{,}40 \times 10^{-4} = 4{,}10\;\text{м}^3/\text{ч};\quad
\dot{V}_{\text{факт}} = 4{,}10 \times \frac{299{,}85}{288{,}15} = 4{,}27\;\text{м}^3/\text{ч}
{{< /formula >}}

{{< formula display="true" >}}
P_{\text{вент}} = (100 + 38 + 13) \times 1{,}20 = 181\;\text{Па}
{{< /formula >}}

Выбрать вентилятор: 4,3 м³/ч при 185 Па.

## Влияние температуры воздуха на КПД горения

### Влияние предварительного нагрева воздуха

Теплота, вносимая предварительно нагретым воздухом в систему:

{{< formula display="true" >}}
\Delta Q = \dot{m}_{\text{воздух}} \times C_p \times (T_{\text{воздух}} - T_{\text{ссылочная}})
{{< /formula >}}

Прирост КПД:

{{< formula display="true" >}}
\Delta\eta \approx \frac{\Delta Q}{Q_{\text{вход}}} \times 100\,\%
{{< /formula >}}

Приближение: ~1 % КПД на каждые 28 °C повышения температуры воздуха горения.

**Пример.** Горелка 29,3 МДж/ч; воздух нагрет с 15 °C до 93 °C; $\dot{m}_{\text{воздух}} = 23{,}2$ кг/мин:

{{< formula display="true" >}}
\Delta Q = 23{,}2 \times 1{,}006 \times (93 - 15) = 1\,819\;\frac{\text{кДж}}{\text{мин}} = 109\;\frac{\text{МДж}}{\text{ч}}
{{< /formula >}}

{{< formula display="true" >}}
\Delta\eta = \frac{109}{29{,}3} \approx 3{,}7\,\%
{{< /formula >}}

Рекуперативный предварительный нагрев воздуха горения экономически обоснован для систем мощностью > 60 МДж/ч при сроке окупаемости 2–5 лет.

### Проблемы холодного воздуха (< −7 °C)

- Снижение адиабатической температуры пламени — нарушение стабильности горелки.
- Конденсация влаги в газопроводе — риск замерзания.
- Увеличение гидравлического сопротивления из-за большей плотности холодного воздуха.
- Термический удар по огнеупорной футеровке при резком перепаде температур.

**Решения:** теплоизоляция воздуховода; смешение наружного воздуха с воздухом здания; предварительный нагрев при $T_{\text{нар}} < -18\,°C$.

## Подпиточный воздух (makeup air, MUA)

### Механизм депрессуризации здания

Воздух горения + дымовые газы покидают здание → давление внутри падает ниже атмосферного → возможна обратная тяга (backdraft) у атмосферных приборов.

Чистый объём вытяжки:

{{< formula display="true" >}}
\dot{V}_{\text{вытяжка}} = \dot{V}_{\text{воздух горения}} + \dot{V}_{\text{дымовых газов}} + \dot{V}_{\text{вытяжная вентиляция}}
{{< /formula >}}

Требование к подпиточному воздуху:

{{< formula display="true" >}}
\dot{V}_{\text{MUA}} = \dot{V}_{\text{вытяжка,\,суммарная}} - \dot{V}_{\text{инфильтрация}}
{{< /formula >}}

Консервативное проектирование: $\dot{V}_{\text{инфильтрация}} = 0$ — обеспечить 100 % подпиточного воздуха.

### Пример расчёта MUA

Котельная: горелка 29,3 МДж/ч + вытяжная вентиляция 1 180 м³/ч; воздух горения из здания.

{{< formula display="true" >}}
\dot{V}_{\text{дымовые газы}} \approx 1{,}1 \times \dot{V}_{\text{воздух горения}} = 1{,}1 \times 1\,140 = 1\,254\;\frac{\text{м}^3}{\text{ч}}
{{< /formula >}}

{{< formula display="true" >}}
\dot{V}_{\text{MUA}} = 1\,254 + 1\,180 = 2\,434\;\frac{\text{м}^3}{\text{ч}}
{{< /formula >}}

### Нагрев подпиточного воздуха

Мощность нагревателя MUA:

{{< formula display="true" >}}
Q_{\text{MUA}} = \dot{V}_{\text{MUA}} \times \rho_{\text{воздух}} \times C_p \times (T_{\text{подача}} - T_{\text{нар}})
{{< /formula >}}

**Пример.** MUA 1 888 м³/ч, нагрев с −18 °C до +21 °C:

{{< formula display="true" >}}
Q_{\text{MUA}} = \frac{1\,888}{3\,600} \times 1{,}225 \times 1\,006 \times 39 = 25{,}2\;\text{кВт}
{{< /formula >}}

### Управление давлением здания

- Датчик статического давления в помещении котельной.
- Уставка: −8 до −20 Па (лёгкое разрежение допустимо).
- Модулирующий клапан или частотный привод вентилятора MUA регулирует приток.
- Цель — предотвратить обратную тягу и обеспечить комфортные условия.

## Требования нормативов

{{< table title="Нормативные требования к воздуху для горения" >}}
| Норматив | Область применения | Ключевые требования |
|---|---|---|
| NFPA 31 | Жидкотопливное оборудование | Отверстия по стандартному методу или инженерный расчёт |
| NFPA 54 | Газовое оборудование | Стандартный метод, метод известной инфильтрации, инженерный расчёт |
| NFPA 86 | Промышленные печи | Принудительная подача; блокировка вентилятора с подачей топлива |
| EN 303 | Котлы для теплоснабжения | Требования к воздуху горения согласно типу горелки |
| СП 60.13330 | Системы теплоснабжения РФ | Размеры приточных отверстий, вентиляция котельных |
{{< /table >}}

**Алгоритм проверки соответствия:**

1. Рассчитать требование воздуха горения.
2. Определить метод подачи: инфильтрация, воздуховод к улице, принудительный.
3. Подобрать размеры отверстий или воздуховодов по применимому нормативу.
4. Убедиться в наличии подпиточного воздуха при необходимости.
5. Ввести в эксплуатацию и подтвердить адекватность воздуха анализом горения (O₂ в целевом диапазоне, CO < 100 ppm).
