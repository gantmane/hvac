## Определения термодинамических свойств

Энтальпия (enthalpy) и энтропия (entropy) — фундаментальные термодинамические свойства, без которых невозможен строгий анализ систем HVAC: паровые сети, холодильные циклы, психрометрические расчёты и энергетические балансы опираются именно на них.

### Энтальпия

Удельная энтальпия объединяет внутреннюю энергию и работу выталкивания (flow work):

{{< formula display="true" >}}
h = u + Pv
{{< /formula >}}

где:
- $h$ — удельная энтальпия, кДж/кг;
- $u$ — удельная внутренняя энергия, кДж/кг;
- $P$ — абсолютное давление, Па;
- $v$ — удельный объём, м³/кг.

В расчётах HVAC именно разность энтальпий $\Delta h$ определяет количество теплоты при нагреве, охлаждении, увлажнении и фазовых переходах. Применения:

- тепловые балансы котлов и теплообменников;
- возврат конденсата и рекуперация вторичного пара;
- подбор паровых конденсатоотводчиков (steam traps);
- расчёт мощности приводов турбин.

### Энтропия

Удельная энтропия характеризует степень молекулярного беспорядка и «деградацию» качества энергии:

{{< formula display="true" >}}
ds = \frac{\delta Q_{\text{обр}}}{T}
{{< /formula >}}

где $T$ — абсолютная температура, К; $\delta Q_{\text{обр}}$ — элементарная теплота обратимого процесса, кДж.

Анализ энтропии позволяет:

- локализовать основные источники необратимостей;
- оценить изэнтропийный КПД компонентов;
- провести эксергетический анализ (второй закон) системы;
- определить минимально возможную работу сжатия в холодильных машинах.

## Фазы воды и их свойства

### Недогретая (сжатая) жидкость

Жидкость при температуре ниже $T_{\text{нас}}$ для данного давления. Влиянием давления на энтальпию в диапазоне HVAC (до 3,5 МПа) можно пренебречь:

{{< formula display="true" >}}
h(T, P) \approx h_f(T)
{{< /formula >}}

Применения: системы холодной воды (2–10 °C), горячего водоснабжения (49–121 °C), питательная вода котла до экономайзера.

### Насыщенная жидкость и насыщенный пар

На линии насыщения температура и давление — зависимые параметры. Нижние индексы: $f$ — жидкость, $g$ — пар.

### Перегретый пар

Температура и давление — независимые свойства. Степень перегрева:

{{< formula display="true" >}}
\Delta t_{\text{перегрев}} = t_{\text{факт}} - t_{\text{нас}}(P)
{{< /formula >}}

Типичные значения: паровое отопление зданий — 3–8 °C; выход компрессора холодильной машины — 17–44 °C; входной пар турбины — 50–150 °C.

### Скрытая теплота испарения

{{< formula display="true" >}}
h_{fg} = h_g - h_f
{{< /formula >}}

$h_{fg}$ уменьшается с ростом температуры и обращается в ноль в критической точке (373,95 °C, 22 064 кПа).

### Степень сухости (качество пара)

В двухфазной области:

{{< formula display="true" >}}
x = \frac{m_{\text{пар}}}{m_{\text{жидк}} + m_{\text{пар}}}
{{< /formula >}}

Свойства влажного пара:

{{< formula display="true" >}}
h = h_f + x \cdot h_{fg}, \quad s = s_f + x \cdot s_{fg}
{{< /formula >}}

Минимально допустимые значения по области применения:

| Применение | $x_{\min}$ | Обоснование |

{{< /table >}}

## Уравнение Клапейрона–Клаузиуса

Описывает зависимость давления насыщения от температуры:

{{< formula display="true" >}}
\frac{dP}{dT} = \frac{h_{fg}}{T \cdot v_{fg}}
{{< /formula >}}

Приближённая интегрированная форма (применима в диапазоне HVAC):

{{< formula display="true" >}}
\ln\!\left(\frac{P_2}{P_1}\right) = \frac{h_{fg}}{R_v}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)
{{< /formula >}}

где $R_v = 461{,}5$ Дж/(кг·К) — удельная газовая постоянная водяного пара.

## Числовые примеры

### Пример 1. Расчёт расхода пара для паровой катушки

**Условие.** Паровая нагревательная катушка (steam heating coil) работает при давлении 172 кПа (изб.) насыщенным паром. Конденсат отводится при том же давлении в виде насыщенной жидкости. Тепловая нагрузка $Q = 290$ кВт.

**Решение.**

Из таблицы при $P_{\text{абс}} = 273{,}6$ кПа:

{{< formula display="true" >}}
h_g = 2728{,}8 \text{ кДж/кг}, \quad h_f = 581{,}8 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
h_{fg} = 2728{,}8 - 581{,}8 = 2147{,}0 \text{ кДж/кг}
{{< /formula >}}

Требуемый массовый расход пара:

{{< formula display="true" >}}
\dot{m} = \frac{Q}{h_{fg}} = \frac{290}{2147{,}0} = 0{,}135 \text{ кг/с} = 487 \text{ кг/ч}
{{< /formula >}}

Если конденсат дополнительно охлаждается до 93 °C ($h_2 = 389{,}5$ кДж/кг):

{{< formula display="true" >}}
\dot{m} = \frac{290}{2728{,}8 - 389{,}5} = \frac{290}{2339{,}3} = 0{,}124 \text{ кг/с} = 446 \text{ кг/ч}
{{< /formula >}}

Экономия расхода пара составляет **8,2 %** за счёт использования теплоты конденсата.

---

### Пример 2. Расчёт вторичного пара (flash steam)

**Условие.** Конденсат с давлением 700 кПа (абс) расширяется в вторичный сепаратор (flash vessel) до 103 кПа (абс). Расход конденсата $\dot{m} = 0{,}63$ кг/с.

**Решение.**

Энтальпии жидкости (ASHRAE Handbook — Fundamentals, гл. 30):

{{< formula display="true" >}}
h_{f1} = 697{,}0 \text{ кДж/кг} \; (700 \text{ кПа абс}), \quad
h_{f2} = 504{,}2 \text{ кДж/кг}, \; h_{fg2} = 2201{,}9 \text{ кДж/кг} \; (103 \text{ кПа абс})
{{< /formula >}}

Доля вторичного пара:

{{< formula display="true" >}}
x_{\text{flash}} = \frac{h_{f1} - h_{f2}}{h_{fg2}} = \frac{697{,}0 - 504{,}2}{2201{,}9} = 0{,}0876 \approx 8{,}8\%
{{< /formula >}}

Расход вторичного пара:

{{< formula display="true" >}}
\dot{m}_{\text{flash}} = 0{,}63 \times 0{,}0876 = 0{,}055 \text{ кг/с}
{{< /formula >}}

Рекуперируемая мощность:

{{< formula display="true" >}}
\dot{Q} = \dot{m}_{\text{flash}} \times h_{fg2} = 0{,}055 \times 2201{,}9 \approx 121 \text{ кВт}
{{< /formula >}}

### Пример 3. Потери эксергии на регулирующем клапане

**Условие.** Насыщенный пар при 700 кПа (абс) ($h_1 = 2754{,}0$ кДж/кг, $s_1 = 6{,}687$ кДж/(кг·К)) дросселируется до 103 кПа (абс). Расход $\dot{m} = 0{,}32$ кг/с. Температура окружающей среды $T_0 = 294$ К.

**Решение.**

Дросселирование — изэнтальпийный процесс: $h_2 = h_1 = 2754{,}0$ кДж/кг.

При 103 кПа абс $h_g = 2706{,}1$ кДж/кг $< h_2$, значит пар перегрет. По таблице перегретого пара при 103 кПа, 150 °C: $s_2 \approx 7{,}284$ кДж/(кг·К).

Выработка энтропии (entropy generation):

{{< formula display="true" >}}
\dot{S}_{\text{gen}} = \dot{m}(s_2 - s_1) = 0{,}32 \times (7{,}284 - 6{,}687) = 0{,}191 \text{ кВт/К}
{{< /formula >}}

Уничтожение эксергии (exergy destruction):

{{< formula display="true" >}}
\dot{X}_{\text{уничт}} = T_0 \cdot \dot{S}_{\text{gen}} = 294 \times 0{,}191 = 56 \text{ кВт}
{{< /formula >}}

**Вывод.** Замена дросселирующего клапана турбиной с $\eta_s = 0{,}75$ позволила бы получить $\approx 42$ кВт механической работы вместо её уничтожения.

## Психрометрические приложения

Энтальпия влажного воздуха (ASHRAE Handbook — Fundamentals, гл. 1):

{{< formula display="true" >}}
h_{\text{возд}} = 1{,}006\,t + W\,(2500{,}9 + 1{,}84\,t)
{{< /formula >}}

где $t$ — температура сухого термометра, °C; $W$ — влагосодержание, кг/кг с. в.
