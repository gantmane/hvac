## Обзор

R-32 (дифторметан, CH₂F₂) — синтетический хладагент класса HFC (гидрофторуглерод) с нулевым потенциалом разрушения озонового слоя (ODP = 0) и потенциалом глобального потепления GWP₁₀₀ = 675 (IPCC AR5). R-32 является одним из двух компонентов смеси R-410A (50/50 масс.% R-32/R-125) и самостоятельно применяется в новых кондиционерах и тепловых насосах класса энергоэффективности A++/A+++ (регламент ЕС 517/2014).

Высокая объёмная холодопроизводительность R-32 — около 30 % выше, чем у R-410A, — позволяет уменьшить диаметры трубопроводов и размеры компрессора. Критический недостаток — класс горючести A2L по ASHRAE 34-2022 (слабо воспламеняемый, LFL = 14,4 % об.), что требует специальных мер безопасности.

## Физические принципы

### Уравнение состояния

Термодинамические свойства R-32 рассчитываются из уравнения состояния формы Гельмгольца (Tillner-Roth, Yokozeki, 1997), реализованного в NIST REFPROP v10:

{{< formula display="true" >}}
\frac{A(T, \rho)}{RT} = \alpha^0(\tau, \delta) + \alpha^r(\tau, \delta)
{{< /formula >}}

Уравнение состояния обеспечивает погрешность по давлению насыщения менее 0,1 % и по плотности жидкости менее 0,05 % в рабочем диапазоне.

### Сравнение с R-410A

R-32 и R-410A работают при схожих давлениях, но R-32 имеет:
- Выше объёмную холодопроизводительность ($q_v$ ≈ 4200 кДж/м³ против ≈ 3200 кДж/м³ для R-410A при −10 °C);
- Выше температуру нагнетания (+5…8 К при аналогичных условиях);
- Меньший GWP (675 против 2088).

## Численный пример: расчёт холодильного цикла кондиционера

**Условие.** Сплит-система на R-32 с холодопроизводительностью 7 кВт. Испарение: $T_{evap}$ = −5 °C, перегрев 8 К. Конденсация: $T_{cond}$ = 45 °C, переохлаждение 5 К. $\eta_s$ = 0,78 (ротационный компрессор). Рассчитать: удельную холодопроизводительность, работу компрессора, COP и массовый расход.

**Данные REFPROP v10:**

Точка 1: $T_1$ = −5 + 8 = 3 °C, $p_1$ = $p_{sat}$(−5 °C) ≈ 746 кПа.

По таблице при 600 кПа, интерполируя на $T$ = 3 °C (перегрев ≈ 13 К относительно $T_{sat}$ = −9,9 °C):

{{< formula display="true" >}}
h_1 \approx 535{,}4 \text{ кДж/кг}, \quad s_1 \approx 2{,}205 \text{ кДж/(кг·К)}
{{< /formula >}}

Точка 3: $T_3$ = 45 − 5 = 40 °C, жидкость, $p_2$ = $p_{sat}$(45 °C).

Интерполируя между 40 °C и 50 °C в таблице насыщения:

{{< formula display="true" >}}
p_2 \approx 2323 + 0{,}5 \times (2919 - 2323) = 2621 \text{ кПа}
{{< /formula >}}

{{< formula display="true" >}}
h_3 = h_f(40°C) = 375{,}1 \text{ кДж/кг}
{{< /formula >}}

Изоэнтропный выход компрессора: $s_{2s}$ = 2,205 кДж/(кг·К), $p_2$ = 2621 кПа.

По таблице перегрева при 2000 кПа, $T$ ≈ 65 °C (интерполяция между 60 °C и 80 °C):

{{< formula display="true" >}}
h_{2s} \approx 590{,}1 \text{ кДж/кг}
{{< /formula >}}

**Работа компрессора:**

{{< formula display="true" >}}
w_{comp} = \frac{h_{2s} - h_1}{\eta_s} = \frac{590{,}1 - 535{,}4}{0{,}78} = \frac{54{,}7}{0{,}78} = 70{,}1 \text{ кДж/кг}
{{< /formula >}}

**Удельная холодопроизводительность:**

{{< formula display="true" >}}
q_{evap} = h_1 - h_4 = 535{,}4 - 375{,}1 = 160{,}3 \text{ кДж/кг}
{{< /formula >}}

**COP:**

{{< formula display="true" >}}
COP = \frac{q_{evap}}{w_{comp}} = \frac{160{,}3}{70{,}1} = 2{,}29
{{< /formula >}}

**Массовый расход:**

{{< formula display="true" >}}
\dot{m} = \frac{\dot{Q}_{evap}}{q_{evap}} = \frac{7000}{160{,}3 \times 10^3} = 0{,}0437 \text{ кг/с} = 157 \text{ кг/ч}
{{< /formula >}}

**Мощность компрессора:**

{{< formula display="true" >}}
\dot{W}_{comp} = \dot{m} \cdot w_{comp} = 0{,}0437 \times 70{,}1 = 3{,}06 \text{ кВт}
{{< /formula >}}

Проверка: $\dot{Q}_{evap} / \dot{W}_{comp}$ = 7 / 3,06 = 2,29 — совпадает с COP. Для сравнения: аналогичная система на R-410A даёт COP ≈ 2,6 при меньших температуре нагнетания (ниже на ~7 К) — это компромисс при выборе R-32.

## Требования безопасности (класс A2L)

R-32 классифицируется как A2L по ASHRAE 34-2022 и ISO 817:2014:
- **НПВ** (LFL) = 14,4 % об. в воздухе при 25 °C — значительно выше, чем у большинства горючих газов;
- Минимальная энергия воспламенения > 0,18 мДж (высокая);
- Скорость горения ~6,7 см/с при 25 °C — ниже порога класса 2 (10 см/с).

## Применение в системах ОВК

### Бытовые и коммерческие кондиционеры

R-32 является стандартным хладагентом для новых сплит-систем в Японии (с 2012 г.) и широко внедряется в Европе и Азии. Типовые заправочные массы:
- Сплит-система 2,5 кВт — 0,7…0,9 кг;
- Сплит-система 7 кВт — 1,2…1,5 кг;
- Мульти-сплит 14 кВт — 2,4…3,0 кг.

### Совместимость масла

R-32 требует только синтетических масел: POE (polyol ester) ISO VG 32 или 46. Минеральные масла и алкилбензолы несовместимы из-за плохой растворимости в R-32. Содержание влаги в масле — не более 50 ppm.

## Стандарты и нормативные источники

- **ASHRAE 34-2022** — классификация R-32 как A2L; данные о горючести и токсичности.
- **ISO 817:2014** — классификация и обозначение хладагентов.
- **EN 378-1:2016** — требования безопасности; ограничения заправки A2L.
- **ASHRAE 15-2022** — стандарт безопасности для холодильных систем.
- **ISO 5149-1:2014** — безопасность холодильных систем; A2L хладагенты.
- **NIST REFPROP v10** — уравнение состояния Tillner-Roth, Yokozeki (1997) для R-32.
- **Регламент ЕС 517/2014 (F-Gas)** — R-32 допускается при GWP < 750 для сплит-систем > 3 кВт.
- **ГОСТ 28547-2014** — технические условия; хранение и транспортировка.
- **СП 60.13330.2022** — нормы проектирования ОВК систем с горючими хладагентами.

## Практические рекомендации

1. **Температура нагнетания**: при $T_{cond}$ > 50 °C может превышать 95 °C — проверяйте ограничения конкретного компрессора и термическую стабильность масла.
2. **Степень заправки**: перезаправка R-32 критична — давление конденсации при $T_{cond}$ = 50 °C составляет 2,9 МПа (почти вблизи $p_c$ = 5,78 МПа); избыток хладагента резко повышает $p_{cond}$.
3. **Детектор утечки**: обязателен для установок с заправкой > 1 кг в жилых и торговых помещениях (EN 378-3:2016).
4. **Инструмент**: применяйте инструмент и фитинги, допущенные для давлений > 4,5 МПа (R-32 имеет $p_c$ = 5,78 МПа — выше, чем у R-410A = 4,93 МПа).
5. **Транспортная тара**: баллоны R-32 красного цвета по RAL 3000 (стандарт ЕС); никогда не используйте баллоны с неизвестным или смешанным содержимым.
