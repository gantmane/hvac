Изоэнтропы (isentropes) — линии постоянной удельной энтропии {{< formula >}}s{{< /formula >}} (кДж/(кг·К)) на диаграмме давление–энтальпия (P–h). Они представляют путь **обратимого адиабатного** (reversible adiabatic) процесса — идеального сжатия в компрессоре. Отклонение реального сжатия от изоэнтропного характеризует необратимости в компрессоре и количественно выражается через **изоэнтропный КПД** {{< formula >}}\eta_{is}{{< /formula >}}. Изоэнтропы используются также для определения идеальной работы расширения в детандерах (turboexpanders), хотя в большинстве ОВК-систем расширение необратимо (дросселирование).

## Физические принципы

Энтропия — функция состояния, характеризующая степень рассеяния тепловой энергии. Для обратимого адиабатного процесса:

{{< formula display="true" >}}
ds = 0 \quad \Rightarrow \quad s = \text{const}
{{< /formula >}}

Для необратимого реального процесса при аналогичных тепловых условиях:

{{< formula display="true" >}}
ds > 0
{{< /formula >}}

В двухфазной области энтропия смеси:

{{< formula display="true" >}}
s = s_f(P) + x \cdot s_{fg}(P), \quad s_{fg} = s_g - s_f
{{< /formula >}}

В области перегрева {{< formula >}}s = s(T, P){{< /formula >}} — табулируется по данным NIST REFPROP v10.

Для компрессора, сжимающего пар от {{< formula >}}(P_1, s_1){{< /formula >}} до {{< formula >}}P_2{{< /formula >}} по изоэнтропе ({{< formula >}}s_2 = s_1{{< /formula >}}), удельная работа идеального сжатия:

{{< formula display="true" >}}
w_{is} = h(P_2,\, s_1) - h(P_1,\, s_1) = h_{2s} - h_1
{{< /formula >}}

## Геометрия изоэнтроп на диаграмме P–h

В области перегретого пара изоэнтропы имеют наклон вверх-вправо и проходят круче, чем изотермы. Это следствие термодинамического тождества:

{{< formula display="true" >}}
\left(\frac{\partial P}{\partial h}\right)_s = \frac{1}{v} \cdot \frac{c_p - c_v}{c_p} \cdot \frac{1}{c_p}
{{< /formula >}}

В двухфазной области изоэнтропы имеют ещё более крутой наклон, пересекая горизонтальные изобары под большим углом. Это позволяет визуально различать изоэнтропы и изотермы.

На практике компрессоры работают в области перегрева: всасывание — перегретый пар, нагнетание — ещё более перегретый пар. Путь идеального сжатия 1→2s лежит вдоль одной изоэнтропы; реальный путь 1→2 отклоняется вправо и проходит через точку с большей энтальпией.

## Изоэнтропный КПД компрессора

Реальный компрессор потребляет больше работы, чем идеальный, из-за:

- внутренних утечек;
- трения в подшипниках и рабочих органах;
- теплообмена с корпусом;
- газодинамических потерь.

Изоэнтропный КПД (isentropic efficiency):

{{< formula display="true" >}}
\eta_{is} = \frac{w_{is}}{w_{\text{реал}}} = \frac{h_{2s} - h_1}{h_2 - h_1}
{{< /formula >}}

где {{< formula >}}h_{2s}{{< /formula >}} — энтальпия идеального нагнетания (по изоэнтропе), {{< formula >}}h_2{{< /formula >}} — реальная энтальпия нагнетания.

{{< table title="Типовые значения изоэнтропного КПД компрессоров" >}}
| Тип компрессора | {{< formula >}}\eta_{is}{{< /formula >}}, — | Источник |
|-----------------|---------|---------|
| Поршневой (reciprocating) | 0,72–0,82 | ASHRAE Handbook Fundamentals, гл. 38 |
| Спиральный (scroll) | 0,78–0,85 | ASHRAE Handbook Fundamentals, гл. 38 |
| Винтовой (screw) | 0,80–0,88 | ASHRAE Handbook Fundamentals, гл. 38 |
| Центробежный (centrifugal) | 0,82–0,92 | ASHRAE Handbook Fundamentals, гл. 38 |
{{< /table >}}

Реальная мощность компрессора:

{{< formula display="true" >}}
N_{\text{комп}} = \frac{\dot{m} \cdot w_{is}}{\eta_{is}}
{{< /formula >}}

## Расчёт холодопроизводительности и COP

Удельная холодопроизводительность:

{{< formula display="true" >}}
q_e = h_1 - h_4
{{< /formula >}}

Коэффициент производительности с учётом реального КПД компрессора:

{{< formula display="true" >}}
\text{COP} = \frac{q_e}{w_{\text{реал}}} = \frac{(h_1 - h_4) \cdot \eta_{is}}{h_{2s} - h_1}
{{< /formula >}}

Погрешность в определении COP при игнорировании {{< formula >}}\eta_{is}{{< /formula >}} составляет:

{{< formula display="true" >}}
\delta \text{COP} \approx \frac{1}{\eta_{is}} - 1
{{< /formula >}}

При {{< formula >}}\eta_{is} = 0{,}80{{< /formula >}} ошибка составляет 25 % — критично для сертификационных расчётов по ASHRAE 205 и энергетических паспортов оборудования.

## Численный пример — сжатие R-32 в спиральном компрессоре

**Условие:** R-32, всасывание при {{< formula >}}T_1 = 0{{< /formula >}} °C с перегревом 5 К ({{< formula >}}T_1 = 5{{< /formula >}} °C), {{< formula >}}P_1 = 801{{< /formula >}} кПа; нагнетание при {{< formula >}}P_2 = 2802{{< /formula >}} кПа (соответствует {{< formula >}}T_{\text{конд}} = 45{{< /formula >}} °C). Изоэнтропный КПД спирального компрессора {{< formula >}}\eta_{is} = 0{,}82{{< /formula >}}.

По NIST REFPROP v10 (ASHRAE Handbook Fundamentals, гл. 30):

- Точка 1 (всасывание): {{< formula >}}h_1 = 534{,}2{{< /formula >}} кДж/кг, {{< formula >}}s_1 = 2{,}208{{< /formula >}} кДж/(кг·К).
- Точка 2s (изоэнтропа при {{< formula >}}P_2{{< /formula >}}, {{< formula >}}s_{2s} = s_1{{< /formula >}}): {{< formula >}}h_{2s} = 578{,}5{{< /formula >}} кДж/кг, {{< formula >}}T_{2s} = 73{,}1{{< /formula >}} °C.

Идеальная работа сжатия:

{{< formula display="true" >}}
w_{is} = h_{2s} - h_1 = 578{,}5 - 534{,}2 = 44{,}3 \text{ кДж/кг}
{{< /formula >}}

Реальная работа:

{{< formula display="true" >}}
w_{\text{реал}} = \frac{w_{is}}{\eta_{is}} = \frac{44{,}3}{0{,}82} = 54{,}0 \text{ кДж/кг}
{{< /formula >}}

Реальная энтальпия нагнетания:

{{< formula display="true" >}}
h_2 = h_1 + w_{\text{реал}} = 534{,}2 + 54{,}0 = 588{,}2 \text{ кДж/кг}
{{< /formula >}}

Реальная температура нагнетания (из REFPROP при {{< formula >}}P_2 = 2802{{< /formula >}} кПа, {{< formula >}}h_2 = 588{,}2{{< /formula >}} кДж/кг): {{< formula >}}T_2 \approx 82{,}5{{< /formula >}} °C.

Степень давления: {{< formula >}}P_2/P_1 = 2802/801 = 3{,}50{{< /formula >}}. Повышение температуры нагнетания по сравнению с изоэнтропным (+9,4 К) — следствие необратимостей.

Для систем охлаждения холодильного агрегата мощностью {{< formula >}}Q_e = 10{{< /formula >}} кВт массовый расход:

{{< formula display="true" >}}
\dot{m} = \frac{Q_e}{q_e} = \frac{10{,}0}{146{,}3} = 0{,}0683 \text{ кг/с} = 245 \text{ кг/ч}
{{< /formula >}}

где {{< formula >}}q_e = h_1 - h_4{{< /formula >}} определяется отдельно из анализа испарителя. Потребляемая мощность компрессора:

{{< formula display="true" >}}
N_{\text{комп}} = \dot{m} \cdot w_{\text{реал}} = 0{,}0683 \times 54{,}0 = 3{,}69 \text{ кВт}
{{< /formula >}}

## Влияние перегрева всасывания на изоэнтропный путь

Увеличение перегрева всасывания {{< formula >}}\Delta T_{\text{пер}}{{< /formula >}} смещает точку 1 вправо по горизонтали. Изоэнтропа через новую точку 1 проходит через более высокие температуры нагнетания при том же {{< formula >}}P_2{{< /formula >}}. Одновременно снижается объёмная производительность компрессора (volumetric efficiency), поскольку пар на всасывании имеет меньшую плотность. Рекомендуемое значение перегрева всасывания: 5–11 К (компромисс между защитой компрессора от жидкостного удара и снижением производительности).

## Применение в тепловых насосах

В режиме обогрева тепловой насос работает при высоком давлении конденсации. При {{< formula >}}T_{\text{нар}} = -15{{< /formula >}} °C и {{< formula >}}T_{\text{конд}} = 50{{< /formula >}} °C для R-410A степень давления достигает 5–6, что существенно увеличивает {{< formula >}}w_{is}{{< /formula >}} и снижает COP. Изоэнтропный анализ позволяет определить точку смены цикла с субкритического на транскритический (актуально для CO₂/R-744) и оптимальное давление нагнетания.
