# Расчет статического давления в воздуховодах для инженеров HVAC

Точные расчеты падения давления обеспечивают правильный выбор вентилятора и энергоэффективное sizing воздуховодов. Недооценка приводит к недостаточному расходу воздуха; переоценка ведет к перерасходу энергии вентилятором и увеличению капитальных затрат.

## Компоненты общего давления

$$P_{total} = P_{static} + P_{velocity}$$

**Динамическое давление:**

$$P_v = \left(\frac{v}{4005}\right)^2 \text{ "w.g.}$$

**Статическое давление вентилятора:**

$$FSP = P_{s,discharge} - P_{s,suction}$$

## Потери давления на трение

**Уравнение Дарси-Вейсбаха:**

$$\Delta P_f = f \frac{L}{D} \frac{v^2}{(4005)^2 \times 12.96}$$

Где:
- $f$ = коэффициент трения (из диаграммы Мууди или уравнения Колбрука)
- $L$ = длина воздуховода (м)
- $D$ = гидравлический диаметр (м)
- $v$ = скорость (FPM)

**Для прямоугольных воздуховодов гидравлический диаметр:**

$$D_h = \frac{4ab}{2(a+b)} = \frac{2ab}{a+b}$$

**Альтернатива:** Используйте таблицу потерь на трение в воздуховодах (метод равного трения)
- Выберите удельное падение давления: 0.08-0.15 "w.g./100 фут
- Подберите размер воздуховода для заданного CFM при выбранном удельном падении

## Потери на фитингах

**Метод коэффициента местных сопротивлений:**

$$\Delta P_{fitting} = C \times P_v$$

Где $C$ = коэффициент потерь из базы данных ASHRAE Duct Fitting Database

**Распространенные фитинги:**

| Фитинг | Коэффициент потерь C |
|---------|-------------------|
| Колено 90°, R/D = 1.5 | 0.15-0.25 |
| Колено 90°, фасонное (mitered) | 0.8-1.3 |
| Тройник отводной, прямой | 0.10-0.15 |
| Тройник отводной, 90° | 0.9-1.8 |
| Заслонка, полностью открыта | 0.2-0.5 |
| Фильтр (чистый MERV 8) | 0.3-0.5 |

**Общее падение давления в системе:**

$$\Delta P_{total} = \Delta P_{straight} + \sum \Delta P_{fittings} + \Delta P_{equipment}$$

## Факторы влияния системы

**Распространенные причины влияния системы:**
1. Препятствия на входе/выходе вблизи вентилятора
2. Колена в пределах 3 диаметров воздуховода от вентилятора
3. Недостаточная длина воздуховода на входе в вентилятор
4. Неравномерный профиль скорости на входе в вентилятор

**Влияние:** Может увеличить требуемое давление вентилятора на 0.25-1.0 "w.g.

**Предотвращение:**
- Прямые участки воздуховода: 2.5D перед вентилятором, 5D после вентилятора
- Направляющие лопатки в коленах вблизи вентилятора
- Входные/выходные раструбы (bell mouths)

## Расчетные падения давления

**Целевое статическое давление:**
- Системы низкой скорости: 0.5-1.5 "w.g.
- Системы средней скорости: 1.5-3.0 "w.g.
- Системы высокой скорости: 3.0-6.0 "w.g.

**Распределение по компонентам:**
- Прямые участки воздуховода (40-50%)
- Фитинги (25-35%)
- Змеевик/фильтр (15-25%)
- Регулирующие клапаны/диффузоры (5-15%)

## Практическое применение

1. **Проектирование по равному трению:** Выберите 0.10 "w.g./100 фут, рассчитайте все воздуховоды с этим удельным падением
2. **Метод доступного статического давления:** Работайте в обратном направлении от мощности вентилятора
3. **Кривая системы:** Постройте график $\Delta P$ в зависимости от CFM для определения рабочей точки
