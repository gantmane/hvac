## Обзор

R-134a (1,1,1,2-тетрафторэтан, HFC-134a, CF₃CH₂F) — синтетический хладагент класса HFC, основной хладагент мирового парка систем кондиционирования воздуха и средне- и низкотемпературного холодоснабжения в период с начала 1990-х гг. Потенциал разрушения озонового слоя (ODP) = 0; прямой потенциал глобального потепления (GWP₁₀₀) = 1300.

В связи с высоким GWP в новых системах ЕС с 2011 г. (MAC) и с 2025 г. (стационарные установки) R-134a замещается на хладагенты четвёртого поколения (R-1234yf, R-1234ze(E)). Тем не менее R-134a остаётся самым широко применяемым хладагентом в действующем оборудовании, а его термодинамические таблицы — эталоном для сравнения характеристик новых хладагентов.

Данные настоящего раздела соответствуют NIST REFPROP v10 и ASHRAE Handbook — Fundamentals 2021, гл. 30. Погрешность по энтальпии — менее 0,5 %; по плотности — менее 0,2 %.

## Физические принципы и базовые параметры

Состояние R-134a однозначно определяется двумя независимыми интенсивными переменными (например, $T$ и $p$ в однофазной области; $p$ и $x$ в двухфазной). Фундаментальные соотношения:

## Численный пример: полный анализ цикла кондиционирования

**Условие.** Система кондиционирования помещений на R-134a. Стандартные условия испытания AHRI 210/240: испарение при $T_{evap}$ = 7 °C, конденсация при $T_{cond}$ = 54 °C. Перегрев на выходе испарителя 8 К, переохлаждение 5 К, $\eta_s$ = 0,78. Производительность испарителя 10 кВт. Рассчитать массовый расход хладагента, мощность компрессора и COP.

**Данные из таблиц REFPROP v10:**

Точка 1 (вход компрессора): $T_1$ = 7 + 8 = 15 °C, $p_1$ = 414,6 кПа.

По таблице при 400 кПа, $T$ = 15 °C (интерполяция между 0 °C и 20 °C):

{{< formula display="true" >}}
h_1 = 374{,}21 + \frac{15 - 0}{20 - 0}(386{,}37 - 374{,}21) = 374{,}21 + 9{,}12 = 383{,}3 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
s_1 = 1{,}7394 + \frac{15}{20}(1{,}7727 - 1{,}7394) = 1{,}7394 + 0{,}0250 = 1{,}7644 \text{ кДж/(кг·К)}
{{< /formula >}}

Точка 3 (выход конденсатора): $T_3$ = 54 − 5 = 49 °C, жидкость. Интерполяция между строками 40 °C и 50 °C:

{{< formula display="true" >}}
h_3 \approx 255{,}56 + 0{,}9 \times (271{,}61 - 255{,}56) = 255{,}56 + 14{,}45 = 270{,}0 \text{ кДж/кг}
{{< /formula >}}

Точка 4: $h_4 = h_3 = 270{,}0$ кДж/кг.

Изоэнтропный выход компрессора: $p_2$ = $p_{sat}$(54 °C). Интерполируя между 50 °C (1318,1 кПа) и 60 °C (1681,8 кПа): $p_2$ ≈ 1469 кПа.

При $s_{2s}$ = 1,7644 и $p_2$ = 1469 кПа (интерполяция по таблицам 1200 кПа и 1600 кПа):

{{< formula display="true" >}}
h_{2s} \approx 443{,}1 \text{ кДж/кг}
{{< /formula >}}

**Работа компрессора:**

{{< formula display="true" >}}
w_{comp} = \frac{h_{2s} - h_1}{\eta_s} = \frac{443{,}1 - 383{,}3}{0{,}78} = \frac{59{,}8}{0{,}78} = 76{,}7 \text{ кДж/кг}
{{< /formula >}}

**Холодопроизводительность:**

{{< formula display="true" >}}
q_{evap} = h_1 - h_4 = 383{,}3 - 270{,}0 = 113{,}3 \text{ кДж/кг}
{{< /formula >}}

**COP:**

{{< formula display="true" >}}
COP = \frac{q_{evap}}{w_{comp}} = \frac{113{,}3}{76{,}7} = 1{,}48
{{< /formula >}}

*Примечание: низкое значение COP обусловлено стандартными испытательными условиями AHRI 210/240 с большим перепадом температур (54 − 7 = 47 К); в типовых условиях эксплуатации ($T_{cond}$ ≈ 40 °C) COP составляет 3,0…3,5.*

**Массовый расход:**

{{< formula display="true" >}}
\dot{m} = \frac{\dot{Q}_{evap}}{q_{evap}} = \frac{10\,000}{113{,}3 \times 10^3} = 0{,}0883 \text{ кг/с}
{{< /formula >}}

**Мощность компрессора:**

{{< formula display="true" >}}
\dot{W}_{comp} = \dot{m} \cdot w_{comp} = 0{,}0883 \times 76{,}7 = 6{,}77 \text{ кВт}
{{< /formula >}}

### Интерполяция и рекомендации

- **Логарифмическая интерполяция по давлению**: при переходе между строками таблицы перегрева по давлению используйте $\ln p$ вместо $p$.
- **Согласованность базового состояния**: таблицы ASHRAE используют базовое состояние 0 °C, насыщ. жидкость ($h_f = 200$ кДж/кг, $s_f = 1{,}000$ кДж/(кг·К)); не смешивайте данные из источников с различными базами.
- **Проверка состояния**: перед выбором таблицы (насыщение, перегрев, переохлаждение) сравните $T$ с $T_{sat}(p)$ из таблицы насыщения по давлению.

## Стандарты и нормативные источники

- **NIST REFPROP v10** — эталонная база данных; уравнение состояния Tillner-Roth, Baehr (1994) для R-134a.
- **ASHRAE Handbook — Fundamentals 2021, гл. 30** — полные таблицы свойств.
- **ASHRAE Handbook — Refrigeration 2022, гл. 2** — анализ холодильных циклов.
- **ASHRAE 34-2022** — классификация A1; безопасность применения.
- **ISO 817:2014** — международный стандарт.
- **EN 378-1:2016** — безопасность холодильных систем в ЕС.
- **ГОСТ 28547-2014** — технические условия на хладагенты в РФ.
- **СП 60.13330.2022** — нормирование систем ОВК.
