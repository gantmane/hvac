## Физическая природа

Теплопроводность (thermal conductivity) $k$ — скалярная мера интенсивности молекулярного переноса тепла в веществе при единичном температурном градиенте. Для воды в жидкой фазе:

{{< formula display="true" >}}
q = -k\,\frac{dT}{dx}
{{< /formula >}}

где $q$ — плотность теплового потока, Вт/м²; $dT/dx$ — температурный градиент, К/м.

Теплопроводность воды **растёт** с температурой (в отличие от большинства органических жидкостей) — от 0,561 Вт/(м·К) при 0 °C до 0,679 Вт/(м·К) при 100 °C. Это обусловлено ростом молекулярной подвижности и увеличением среднего свободного пробега при разрушении водородных связей.

---

## Зависимость от температуры

Аппроксимация для жидкой воды при атмосферном давлении (погрешность ≤1,5 % в диапазоне 0–150 °C):

{{< formula display="true" >}}
k(t) = 0{,}5650 + 0{,}00190\,t - 6{,}80 \times 10^{-6}\,t^2 \quad \text{[Вт/(м·К)]}
{{< /formula >}}

Для повышенной точности (±0,5 %, до 200 °C) — полином IAPWS-IF97:

{{< formula display="true" >}}
k(t) = -0{,}8690 + 8{,}94 \times 10^{-3}\,t - 1{,}58 \times 10^{-5}\,t^2 + 8{,}08 \times 10^{-9}\,t^3
{{< /formula >}}

|:-:|:-:|:-:|
| 0 | 0,561 | −6,2 % |
| 10 | 0,580 | −3,0 % |
| 20 | 0,598 | — |
| 30 | 0,615 | +2,8 % |
| 40 | 0,631 | +5,5 % |
| 50 | 0,644 | +7,7 % |
| 60 | 0,654 | +9,4 % |
| 70 | 0,663 | +10,9 % |
| 80 | 0,670 | +12,0 % |
| 90 | 0,675 | +12,9 % |
| 100 | 0,679 | +13,5 % |
| 120 | 0,685 | +14,5 % |
| 150 | 0,691 | +15,6 % |
{{< /table >}}

**Влияние давления.** При рабочих давлениях гидронных систем HVAC (до 2,0 МПа изб.) поправка на давление не превышает 0,5 % — ею допустимо пренебречь.

## Влияние гликолевых растворов

Добавление гликоля существенно снижает теплопроводность, что напрямую уменьшает коэффициент теплоотдачи и требует увеличения площади теплообменника.

{{< table title="Теплопроводность водных растворов гликолей при 20 °C (ASHRAE Handbook — Fundamentals, гл. 31)" >}}
| Теплоноситель | Концентрация, % масс. | $k$, Вт/(м·К) | Снижение vs. вода |
|---|:-:|:-:|:-:|
| Вода | 0 | 0,598 | — |
| Этиленгликоль | 10 | 0,560 | −6,4 % |
| Этиленгликоль | 30 | 0,490 | −18,1 % |
| Этиленгликоль | 50 | 0,428 | −28,4 % |
| Пропиленгликоль | 10 | 0,552 | −7,7 % |
| Пропиленгликоль | 30 | 0,473 | −20,9 % |
| Пропиленгликоль | 50 | 0,406 | −32,1 % |
{{< /table >}}

Снижение теплопроводности на 28–32 % при 50 % концентрации гликоля в сочетании с ростом числа Прандтля приводит к необходимости увеличить площадь теплообменника на 35–45 % по сравнению с чистой водой.

## Связь с коэффициентом конвективной теплоотдачи

Теплопроводность входит в расчёт коэффициента конвективной теплоотдачи через число Нуссельта:

{{< formula display="true" >}}
\alpha = \frac{Nu \cdot k}{d_h}
{{< /formula >}}

где $d_h$ — гидравлический диаметр, м.

Следовательно, рост $k$ на 13,5 % при нагреве воды от 0 °C до 100 °C даёт пропорциональный рост $\alpha$ при прочих равных условиях (одинаковые Re и Pr).

## Загрязнения (fouling) и тепловое сопротивление

Слои загрязнений добавляют тепловое сопротивление, которое со временем начинает доминировать над конвективным. Полное термическое сопротивление теплообменника:

{{< formula display="true" >}}
\frac{1}{U} = \frac{1}{\alpha_i} + R_{f,i} + \frac{\delta_{\text{ст}}}{k_{\text{ст}}} + R_{f,o} + \frac{1}{\alpha_o}
{{< /formula >}}

{{< table title="Коэффициенты загрязнения для воды (TEMA, 10-е изд.)" >}}
| Тип воды | $R_f$, м²·К/Вт |
|---|:-:|
| Дистиллированная | 0,000 09 |
| Обработанная вода в контуре охлаждения | 0,000 18 |
| Необработанная вода охлаждающих башен | 0,000 35 |
| Городская вода, мягкая | 0,000 18 |
| Городская вода, жёсткая | 0,000 35 |
| Речная вода | 0,000 35–0,000 53 |
{{< /table >}}

Для сравнения: тепловое сопротивление плёнки воды толщиной 1 мм — $R = \delta/k = 0{,}001/0{,}598 = 0{,}00167$ м²·К/Вт. Слой накипи из жёсткой воды ($R_f = 0{,}00035$) составляет **21 %** от этого значения.

## Числовые примеры

### Пример 1. Расчёт коэффициента конвективной теплоотдачи в трубе охлаждённой воды

**Условие.** Охлаждённая вода течёт по трубе $d_i = 25$ мм. Подача — 7 °C, возврат — 12 °C, средняя температура — 9,5 °C. Скорость воды $w = 1{,}2$ м/с.

**Решение.**

Теплофизические свойства при 9,5 °C (NIST REFPROP):
- $\rho = 999{,}6$ кг/м³, $\mu = 1{,}34 \times 10^{-3}$ Па·с, $k = 0{,}583$ Вт/(м·К), $\Pr = 9{,}6$.

{{< formula display="true" >}}
Re = \frac{\rho\,w\,d_i}{\mu} = \frac{999{,}6 \times 1{,}2 \times 0{,}025}{1{,}34 \times 10^{-3}} = 22\,380 \quad (\text{турб. режим})
{{< /formula >}}

Уравнение Гниелинского ($f = (0{,}790\ln Re - 1{,}64)^{-2}$):

{{< formula display="true" >}}
f = (0{,}790 \times \ln 22\,380 - 1{,}64)^{-2} = 0{,}0259
{{< /formula >}}

{{< formula display="true" >}}
Nu = \frac{(f/8)(Re - 1000)\,\Pr}{1 + 12{,}7\sqrt{f/8}\,(\Pr^{2/3}-1)} = \frac{0{,}00324 \times 21\,380 \times 9{,}6}{1 + 12{,}7 \times 0{,}0569 \times 3{,}61} = \frac{664{,}7}{3{,}61} = 184
{{< /formula >}}

{{< formula display="true" >}}
\alpha = \frac{Nu \cdot k}{d_i} = \frac{184 \times 0{,}583}{0{,}025} = 4\,291 \text{ Вт/(м²·К)}
{{< /formula >}}

Если бы при расчёте использовалось $k$ при 20 °C (0,598 Вт/(м·К)) вместо 9,5 °C (0,583 Вт/(м·К)), результат завысил бы $\alpha$ на **2,6 %**.

---

### Пример 2. Система горячего водоснабжения

**Условие.** Горячая вода: подача 80 °C, возврат 60 °C, средняя температура 70 °C. Труба $d_i = 40$ мм, $w = 1{,}0$ м/с.

Свойства при 70 °C: $k = 0{,}663$ Вт/(м·К), $\mu = 0{,}404 \times 10^{-3}$ Па·с, $\Pr = 2{,}55$.

{{< formula display="true" >}}
Re = \frac{977{,}8 \times 1{,}0 \times 0{,}04}{0{,}404 \times 10^{-3}} = 96\,900
{{< /formula >}}

Уравнение Дитуса–Бёлтера ($n = 0{,}3$ при охлаждении жидкости):

{{< formula display="true" >}}
Nu = 0{,}023 \times 96\,900^{0{,}8} \times 2{,}55^{0{,}3} = 0{,}023 \times 6\,820 \times 1{,}34 = 210
{{< /formula >}}

{{< formula display="true" >}}
\alpha = \frac{210 \times 0{,}663}{0{,}040} = 3\,480 \text{ Вт/(м²·К)}
{{< /formula >}}

По сравнению с $\alpha = 4\,291$ Вт/(м²·К) в примере 1 (охлаждённая вода при 9,5 °C, $d = 25$ мм, $w = 1{,}2$ м/с): при горячей воде меньшее Pr (2,55 vs. 9,6) снижает Nu, несмотря на рост $k$ на 13,7 %. Конечный коэффициент теплоотдачи для горячей воды ниже из-за принципиально меньшей вязкости (лучший Re, но меньший Pr).

---

### Пример 3. Оценка деградации теплообменника из-за загрязнения

**Условие.** Пластинчатый теплообменник (ПТО) с $U_0 = 3500$ Вт/(м²·К) в состоянии «чистый». Оба контура — городская вода умеренной жёсткости, $R_f = 0{,}000 18$ м²·К/Вт с каждой стороны.

**Решение.**

{{< formula display="true" >}}
\frac{1}{U_f} = \frac{1}{U_0} + R_{f,i} + R_{f,o} = \frac{1}{3500} + 0{,}000\,18 + 0{,}000\,18 = 0{,}000\,286 + 0{,}000\,36 = 0{,}000\,646
{{< /formula >}}

{{< formula display="true" >}}
U_f = 1548 \text{ Вт/(м²·К)}
{{< /formula >}}

Деградация коэффициента теплопередачи: $1 - 1548/3500 = \mathbf{55{,}8\%}$. Это соответствует необходимости увеличить площадь поверхности ПТО в **2,26 раза** для обеспечения прежней мощности. Результат подчёркивает критическую важность водоподготовки и химической защиты контуров.

## Практические рекомендации для проектирования

**Выбор температуры для оценки $k$.** Использовать среднебалковую температуру теплоносителя ($t_{\text{ср}} = (t_{\text{вх}} + t_{\text{вых}})/2$). При $\Delta t > 30$ °C между стенкой и жидкостью применять поправку по температуре плёнки.

**Системы охлаждённой воды (5–12 °C).** Принимать $k = 0{,}571$–$0{,}583$ Вт/(м·К). Расчёт по значению при 20 °C завысит коэффициент теплоотдачи на 2–3 %.

**Системы горячего водоснабжения (60–85 °C).** $k = 0{,}654$–$0{,}673$ Вт/(м·К); рост теплопроводности на 10–13 % по сравнению с 20 °C.

**Гликолевые системы.** Снижение $k$ на 18–32 % при 30–50 % концентрации требует увеличения площади теплообменника. Оценивать $k$ при минимальной рабочей температуре (наихудший случай).

**Мониторинг загрязнения.** Отслеживать динамику коэффициента $U$ в эксплуатации. Снижение $U$ более 20 % от чистого значения — сигнал к очистке или замене пластин.
