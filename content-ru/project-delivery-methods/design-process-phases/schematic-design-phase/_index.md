Фаза эскизного проекта (SD) устанавливает фундаментальные концепции и подходы системы HVAC, которые будут определять проект на всех последующих фазах проектирования. Эта фаза преобразует требования собственника проекта (OPR) и архитектурные концепции в реальные стратегии HVAC, предоставляя достаточно технических деталей для поддержки сметы затрат и принятия проектных решений.

## Цели фазы и результаты

Фаза эскизного проекта производит:

- Описания концепции системы с сравнительным анализом
- Предварительные расчеты нагрузок (обычно точность 15-20%)
- Ведомости основного оборудования с производительностью
- Диаграммы распределения пространства для механических помещений
- Однолинейные эскизные диаграммы HVAC
- Предварительный анализ энергопотребления
- Кметные расчеты (точность ±25%)
- Документация по основам проектирования

Эти результаты позволяют собственнику оценить альтернативы систем, понять последствия первоначальных затрат и оценить операционные характеристики перед переходом к детальному проектированию.

## Разработка концепции системы

### Методология анализа нагрузок

Предварительные расчеты нагрузок во время эскизного проекта используют упрощенные методы, соответствующие концептуальному характеру фазы:

**Оценка нагрузки охлаждения:**
- Нагрузки оболочки: расчеты U·A·ΔT с использованием предполагаемых значений конструкций
- Внутренние выделения: предположения на основе площади (Вт/м² по типу помещения)
- Вентиляционные нагрузки: 1,1·CFM·ΔT + 4840·CFM·Δω
- Одновременное разнообразие: применение методов блочной нагрузки
- Коэффициенты безопасности: 10-15% для неопределенности выбора оборудования

**Оценка нагрузки нагревания:**
- Передача: U·A·ΔT для всех компонентов оболочки
- Инфильтрация: упрощенный метод смены воздуха или метод площади/периметра
- Увлажнение: если требуется, на основе вентиляционного воздуха и инфильтрации
- Нагрузки захвата: пропорциональные оценки на основе массы здания

Для расчетов блочной нагрузки во время фазы SD:

```
Q_total = Q_envelope + Q_internal + Q_ventilation + Q_infiltration

Where:
Q_envelope = Σ(U·A·CLTD) for walls, roof, glazing
Q_internal = (People·ΔT·1.1·CFM/person) + (Lights·W/m²·A) + (Equipment·W/m²·A)
Q_ventilation = 1.1·CFM_oa·ΔT + 4840·CFM_oa·Δω
```

Коэффициент 1,1 вытекает из ρ·c_p = 1,08 Btu/(hr·ft³·°F) для чувствительного тепла, а 4840 для скрытого тепла представляет произведение плотности воздуха, удельной теплоты парообразования и преобразование единиц.

### Критерии выбора системы

Выбор системы HVAC во время эскизного проекта оценивает несколько альтернатив по взвешенным критериям:

**Факторы производительности:**
- Способность теплового контроля (уровень зоны в сравнении с уровнем помещения)
- Доставка качества внутреннего воздуха (эффективность вентиляции)
- Акустическая производительность (соответствие критериям NC/RC)
- Точность контроля влажности (если критична)
- Потенциал стратификации температуры в помещении

**Экономические соображения:**
- Первоначальная стоимость (оборудование + монтаж + инфраструктура)
- Эксплуатационные расходы (энергия + обслуживание + замена)
- Анализ жизненного цикла за период оценки
- Поощрительные программы и скидки коммунальных служб
- Гибкость в будущем и возможность расширения

**Физические ограничения:**
- Доступное механическое пространство (машинные отделения, шахты, потолочные пленумы)
- Грузоподъемность конструкции для оборудования
- Требования координации архитектуры
- Ограничения площадки (размещение наружного оборудования, расположение жалюзи)
- Пути соответствия кодексу

**Операционные требования:**
- Доступность обслуживания и сложность
- Сложность системы управления
- Характеристики при частичной нагрузке
- Требования к резервированию
- Предположения об уровне навыков оператора

## Распределение пространства оборудования

### Определение размера механического помещения

Эскизный проект устанавливает площади машинных отделений с использованием методов на основе оборудования:

**Центральные машинные отделения:**
- Охлаждающая установка: 0,014-0,023 м²/кВ (включает охладители, насосы, расширительные баки, частотные преобразователи, зазоры)
- Котельная: 0,086-0,161 м²/ГДж (включает котлы, насосы, расширение, топливная система)
- Помещения приточно-вытяжных установок: планируйте 1,5х площадь оборудования для доступа к техническому обслуживанию
- Добавьте 20-30% циркуляционного и сервисного пространства сверх площадей оборудования

**Вертикальное распределение:**
- Механические шахты: размер для максимума напольных стояков подачи/вытяжки плюс 40% на будущее
- Типовой размер: 0,093-0,140 м² на 929 м² обслуживаемой площади в этаже
- Стояки подачи и вытяжки разделены отдельно для гибкости балансировки
- Координируйте расположение шахт со структурной сеткой колонн

**Доступ к оборудованию:**
- Размеры двери: минимум 1,83 м × 2,44 м для доступа в центральное отделение
- Пути удаления: проверьте путь от погрузочной платформы к машинным отделениям
- Такелажные положения: координируйте структурную поддержку для замены оборудования
- Зазоры: требования доступа для обслуживания ASHRAE Guideline 1.1

### Координация пространства потолка

Установите требования к глубине потолочного плениума:

```
Plenum Depth = Duct_depth + Pipe_depth + Electrical_depth + Clearance + Structure

Типовая система VAV:
- Стояк подачи: 0,61-0,91 м для основных (максимальное соотношение сторон 4:1)
- Стояк вытяжки/плениум: 0,46-0,61 м при воздухопроводах вытяжки
- Спринклерная система: 0,10-0,15 м ниже конструкции
- Электрика: 0,15-0,30 м для кабелепровода/кабельного лотка
- Минимальный зазор: 0,08-0,15 м между системами
Total: 0,91-1,22 м ниже конструкции до потолка
```

Координируйте с архитектурными планами отраженного потолка, чтобы определить зоны перегруженности и требуемые софиты.

## Выбор основного оборудования

### Определение производительности

Размер оборудования центральной установки с использованием блочных нагрузок с соответствующим разнообразием и коэффициентами безопасности:

**Производительность охладителя:**
```
Chiller kW = (Peak Block Load / Diversity) × Safety Factor

Where:
Diversity = 0,85-0,95 для нескольких зон
Safety Factor = 1,10-1,15 для неопределенности оценки нагрузки

Для резервирования: конфигурация N+1
Each chiller = Total Load / (N chillers) × 1,0
```

**Производительность котла:**
```
Boiler ГДж = Peak Heating Load + Pickup Load + Piping Loss

Pickup Load = 0,20-0,30 × Steady State Load (зависит от массы здания)
Piping Loss = 0,10-0,15 × Steady State Load
Для резервирования N+1: размер каждого = Total / (N котлов)
```

**Определение размера приточно-вытяжной установки:**
```
CFM (м³/ч) = Sensible Load / (1,08 × ΔT)

Where ΔT = 10-12°C для охлаждения (предположение эскизного проекта)
      ΔT = 22-39°C для нагревания

External Static Pressure = Filter + Coil + Duct + Terminal + Safety
Типовая оценка SD: 6,2-10 см вод. ст. всего
```

### Выбор типа оборудования

Документируйте предварительный выбор оборудования с ключевыми параметрами производительности:

**Охладители:**
- Тип: центробежные с водяным охлаждением, винтовые с воздушным охлаждением, магнитные подшипники и т.д.
- Эффективность при полной нагрузке: кВт/кВ охлаждения или COP
- Производительность при частичной нагрузке: IPLV или NPLV
- Тип хладагента и объем заряда
- Физические размеры и вес

**Котлы:**
- Тип: конденсационные, неконденсационные, жаротрубные, водотрубные
- Эффективность: КПД сгорания и AFUE
- Возможность модуляции
- Выбросы: уровни NOx, CO (если применимо)
- Тип топлива и расход

**Приточно-вытяжные установки:**
- Конфигурация: с всасыванием через фильтр, нагнетанием через фильтр, специальная
- Тип вентилятора: плениум, корпусной, AFMS
- Ряды теплообменников: охлаждение (обычно 6-8 рядов), нагревание (1-2 ряда)
- Тип фильтра: рейтинг MERV и перепад давления
- Конструкция корпуса: двойная стенка с изоляцией

## Разработка бюджета

### Методы смет затрат

Сметы затрат эскизного проекта используют параметрические методы:

**Оценка на основе площади:**
```
HVAC Cost = Area × ($/м² factor) × Location Multiplier × Escalation

Where $/м² varies by:
- Тип здания (офис: $215-323/м², больница: $484-700/м², лаборатория: $646-969/м²)
- Тип системы (VAV +$0, лучистая +$86-129/м², вытеснение +$54-86/м²)
- Климатическая зона (экстремальные климаты +10-20%)
```

**Метод компонентов системы:**
- Центральная установка: $/кВ охлаждения, $/ГДж нагревания
- Распределение: $/CFM (м³/ч) для воздухопроводов и устройств раздачи воздуха
- Концевые устройства: $/unit или $/CFM (м³/ч)
- Управление: % стоимости оборудования (12-18% обычно)
- Тестирование/наладка: 1-3% стоимости строительства

**Структура разбивки стоимости:**
- Оборудование: 40-50%
- Труд: 35-45%
- Материалы (трубопровод, воздухопровод, опоры): 10-15%
- Управление: 5-8%
- Тестирование и наладка: 2-4%

Применяйте географические индексы стоимости из RSMeans, Dodge или региональных данных.

### Анализ жизненного цикла затрат

Проведите упрощенный LCC для информирования выбора системы:

```
LCC = First Cost + PW(Operating Costs) + PW(Maintenance) - PW(Salvage)

Present Worth Factor = [(1 + i)^n - 1] / [i(1 + i)^n]

Where:
i = real discount rate (обычно 3-5%)
n = evaluation period (20-25 лет для HVAC)
```

Компоненты эксплуатационных расходов:
- Энергия: $/кВт·ч × годовое потребление × эскалация
- Платежи за спрос: $/кВт-месяц × пиковый спрос × 12
- Обслуживание: % первоначальной стоимости (обычно 2-4% годовых)
- Основные замены: приведенная стоимость замены оборудования в середине срока

Документируйте чувствительность к ключевым предположениям (эскалация стоимости энергии, ставка дисконтирования, срок службы оборудования).

## Анализ энергопотребления

### Энергетическое моделирование эскизного проекта

Предварительный анализ энергопотребления во время SD устанавливает базовую производительность и оценивает альтернативы:

**Подход к моделированию:**
- Одноблочные или ограниченные многозонные модели, соответствующие SD
- Оболочка: представительные узлы стены/крыши/остекления
- Освещение: предположения на основе площади (Вт/м²)
- Оборудование: плотность подключаемой нагрузки по типу помещения
- Занятость: пиковые и плановые предположения
- HVAC: тип системы с представительными коэффициентами полезного действия

**Базовая производительность:**
Установите индекс энергопотребления (EUI) в сравнении с эталонами:

```
EUI = Annual Energy Use (МДж) / Gross Floor Area (м²)

Типовые диапазоны по типу здания:
- Офис: 529-843 МДж/м²/год
- Розница: 632-1054 МДж/м²/год
- Школа: 580-896 МДж/м²/год
- Больница: 2110-3690 МДж/м²/год
```

**Индекс энергетической стоимости (ECI):**
```
ECI = Annual Energy Cost ($) / Gross Floor Area (м²)

Учитывает различные тарифные структуры и стоимость топлива
Более значимый, чем EUI для принятия решений собственником
```

### Стратегии энергосбережения

Оцените меры энергоэффективности (EEMs) с приростной экономической эффективностью:

**Высокопроизводительные системы HVAC:**
- Цикл экономайзера: свободное охлаждение, когда наружный воздух < температура рециркуляционного воздуха
- Рекупер энергии: чувствительная или полная рекуперация энергии (ERV)
- Системы переменного потока: частотный преобразователь на насосах, вентиляторах для эффективности при частичной нагрузке
- Высокоэффективное оборудование: охладители, котлы и двигатели премиум-класса

**Пассивные стратегии:**
- Оптимизация оболочки: изоляция, производительность остекления, тепловая масса
- Управление солнцем: затенение, ориентация остекления, внешние устройства
- Естественная вентиляция: где позволяет климат и программа
- Интеграция дневного света: уменьшенные нагрузки на освещение и тепловыделение

**Метрики экономической эффективности:**
```
Simple Payback = Incremental First Cost / Annual Energy Savings

If SPB < 7-10 лет → Обычно экономически эффективно
If SPB > 15 лет → Требует неэнергетического обоснования

Для программ поощрения рассчитайте:
Savings-to-Investment Ratio (SIR) = PW(Savings) / First Cost
SIR > 1,0 → Экономически эффективно в течение периода анализа
```

### Соответствие энергетическому кодексу

Проверьте соответствие предварительного проекта или превышение минимальных требований кодекса:

**Путь производительности (ASHRAE 90.1):**
- EUI предлагаемого здания ≤ EUI базового здания
- Модель обоих с использованием идентичных предположений, кроме мер HVAC/оболочки
- Документируйте процент лучше базовой линии (0%, 10%, 20%+ для сертификаций)

**Предписывающий путь:**
- Эффективность оборудования: минимальные COP, EER, AFUE, эффективность сгорания
- Экономайзеры: требуются для производительности охлаждения выше пороговых значений
- Изоляция воздухопровода/трубопровода: R-значения в соответствии с таблицей 6.8.3
- Управление: недельный перевод, мертвая зона, управление вентиляцией по требованию

Для проектов, нацеленных на сертификацию «зеленого» здания (LEED, Living Building Challenge, Passive House), установите целевые показатели энергопотребления во время SD:
- LEED: на 5-20% лучше, чем базовая линия ASHRAE 90.1
- Нулевая чистая энергия: целевые показатели EUI 211-369 МДж/м²/год (офис)
- Passive House: требование отопления и охлаждения 501 МДж/м²/год

## Эскизные чертежи HVAC

### Содержание и масштаб чертежей

Эскизные чертежи проекта графически передают концепции системы:

**Чертежи плана этажа (масштаб 1:100 или 1:50):**
- Основные расположения оборудования (приточно-вытяжные установки, вентиляционные установки, установки подачи приточного воздуха)
- Расположение машинных отделений с маршрутами доступа
- Маршруты первичного распределения воздухопровода/трубопровода (однолинейные)
- Расположения концевых устройств (коробки VAV, диффузоры в сетке эскиза)
- Указанные зоны управления
- Координация с архитектурными планами мебели/перегородок

**Однолинейные диаграммы:**
- Система потока от источника к конечному использованию
- Основное оборудование с метками производительности
- Последовательности управления, указанные схематически
- Отмечены факторы разнообразия и совпадения
- Условия давления/температуры в ключевых точках

**Диаграммы подъемов:**
- Вертикальное распределение систем подачи/вытяжки
- Оборудование, обслуживаемое в каждом этаже
- Размеры и расположения шахт
- Расположения изолирующих клапанов
- Положения расширения

**Планы механического помещения (масштаб 1:10):**
- Контуры оборудования с общими размерами производителя
- Зазоры обслуживания в соответствии с ASHRAE Guideline 1.1
- Двери доступа и маршруты удаления оборудования
- Канализационные трапы и подставки для уборки
- Расположения электрических панелей/управления

### Элементы координации

Указывают ключевые требования координации:

**Конструктивные:**
- Нагрузки оборудования (кПа или сосредоточенные нагрузки в кН)
- Расположения бордюров наружного оборудования
- Требования виброизоляции
- Размеры проникновения через полы/стены

**Архитектурные:**
- Расположения жалюзи и свободные площади
- Размеры дверей машинного отделения
- Требования к высоте потолка и софитам
- Требования к экранированию оборудования

**Электрические:**
- Смежность электрического помещения с машинными отделениями
- Предварительное напряжение и фаза (480 В/3ф, 208 В/3ф)
- Примерные подключенные нагрузки (кВт)
- Требования аварийного питания

**Сантехнические:**
- Подключения охлаждающей воды к градирням
- Водоснабжение для увлажнения/подпитки
- Дренаж конденсата теплообменников и дренаж оборудования
- Газопровод к котлам/генераторам

## Проверка и утверждение проекта

### Внутренняя проверка проекта

Проведите междисциплинарные проверки проекта для проверки:

**Целостность системы HVAC:**
- Расчеты нагрузок разумны для типа здания и климата
- Производительность оборудования адекватна с соответствующими коэффициентами безопасности
- Система распределения может уместиться в архитектурные ограничения
- Стратегии управления соответствуют операционным требованиям

**Междисциплинарная координация:**
- Конструктивные: нагрузки оборудования в пределах производительности, проникновения осуществимы
- Архитектурные: распределение пространства адекватно, эстетическая интеграция приемлема
- Электрические: доступность питания, совместимость напряжения, расположения панелей
- Сантехнические: подключения воды/дренажа осуществимы, нет конфликтов

**Соответствие кодексу и стандартам:**
- Соответствие энергетическому кодексу по пути производительности или предписания
- Вентиляционные ставки в соответствии с ASHRAE 62.1 или местным кодексом
- Зазоры механического кодекса и требования безопасности
- Интеграция пожарной/жизненной безопасности (управление дымом, противопожарные клапаны)

### Процесс проверки собственником

Представьте эскизный проект заинтересованным лицам собственника:

**Описание проекта:**
- Обоснование выбора системы с плюсами/минусами альтернатив
- Как система соответствует OPR и основам проектирования
- Операционные характеристики и последствия обслуживания
- Производительность энергопотребления в сравнении с целями

**Последствия стоимости:**
- Смета первоначальной стоимости с непредвиденными обстоятельствами
- Прогнозы годовых эксплуатационных расходов
- Сравнение жизненного цикла затрат, если представлены альтернативы
- Выявленные возможности переоценки стоимости

**Влияние на график:**
- Оборудование с длительным сроком поставки, требующее ранней закупки
- Требования к поэтапной реализации для занятых перестроек
- Требования координации коммунальных служб (модернизация услуг)

**Оценка риска:**
- Технические риски (непроверенные технологии, плотные сборки)
- Риски затрат (волатильность рынка, неполная информация)
- Риски расписания (разрешения, сроки поставки коммунальных служб)
- Предложенные стратегии смягчения

### Утверждение на проектирование разработки

Получите явное одобрение собственника на продолжение:

1. **Утверждение выбора системы:** Письменное признание типа(ов) системы HVAC

2. **Признание бюджета:** Согласие со сметой затрат и непредвиденными обстоятельствами

3. **Утверждение планирования пространства:** Признание размеров/расположений машинных отделений

4. **Производительность энергопотребления:** Подтверждение, что предварительный анализ энергопотребления соответствует целям проекта

5. **Утверждение критериев проектирования:** Одобрение документа основ проектирования

Это утверждение устанавливает направление проекта и предотвращает крупные изменения во время последующих фаз, которые становятся все более дорогостоящими в реализации.

## Переход к разработке проектирования

Подготовка к фазе разработки проектирования:

**Передача информации:**
- Окончательный выбор системы с документацией одобрения собственника

**Нерешенные вопросы:**
- Позиции, требующие дальнейшего изучения или анализа
- Проблемы координации, выявленные, но не решенные
- Соображения переоценки стоимости для фазы разработки
- Точки решения собственника, которые повлияют на работу разработки

**Объем разработки проектирования:**
- Более детальные расчеты нагрузок (комната за комнатой или зона за зоной)
