Расширенные поверхности (fins, рёбра) применяются там, где коэффициент конвекции с одной стороны теплообменной поверхности мал (обычно со стороны воздуха), и необходимо компенсировать это увеличением площади контакта с жидкостью. В HVAC это оребрённые катушки воздухоохладителей, конденсаторы, оребрённые фанкойлы, пластинчатые воздухонагреватели.

## Дифференциальное уравнение ребра

Рассмотрим ребро постоянного сечения $A_c$ [м²], периметром $P$ [м], длиной $L$ [м], коэффициентом теплопроводности $k$, коэффициентом конвекции $h$. Выделим элементарный срез $dx$:

{{< formula display="true" >}}
\frac{d^2\theta}{dx^2} - m^2 \theta = 0, \quad \theta = T - T_\infty, \quad m = \sqrt{\frac{hP}{kA_c}}
{{< /formula >}}

Параметр ребра $m$ [м⁻¹] физически характеризует интенсивность охлаждения ребра: при большом $m$ температура ребра быстро падает от основания к кончику.

Общее решение:

{{< formula display="true" >}}
\theta(x) = C_1 e^{mx} + C_2 e^{-mx}
{{< /formula >}}

Граничные условия: $\theta(0) = \theta_b = T_b - T_\infty$ (температура основания), различные варианты на кончике ребра ($x = L$): адиабатический кончик, постоянная температура, конвекция с кончика.

### Наиболее распространённый случай: адиабатический кончик

{{< formula display="true" >}}
\theta(x) = \theta_b \frac{\cosh[m(L-x)]}{\cosh(mL)}
{{< /formula >}}

Тепловой поток через основание ребра:

{{< formula display="true" >}}
Q_{fin} = \sqrt{hPkA_c} \; \theta_b \tanh(mL)
{{< /formula >}}

**Для ребра с конвекцией на кончике** применяют исправленную длину: $L_c = L + A_c/P$ (для прямоугольного ребра $L_c = L + t/2$, где $t$ — толщина ребра).

## КПД ребра

**КПД ребра (fin efficiency)** $\eta_f$ — отношение реального теплового потока к идеальному (если бы всё ребро находилось при температуре основания):

{{< formula display="true" >}}
\eta_f = \frac{Q_{fin}}{h A_{fin} \theta_b}
{{< /formula >}}

### Прямоугольное ребро постоянного сечения

{{< formula display="true" >}}
\eta_f = \frac{\tanh(m L_c)}{m L_c}
{{< /formula >}}

При $mL_c \leq 0{,}5$: $\eta_f \geq 0{,}96$ — ребро почти полностью эффективно.
При $mL_c = 1$: $\eta_f = 0{,}76$.
При $mL_c = 2$: $\eta_f = 0{,}48$ — ребро работает неэффективно.

### Числовой пример: алюминиевое ребро фанкойла

**Дано**: Алюминиевое ребро ($k = 205$ Вт/(м·К)), прямоугольное, толщина $t = 0{,}12$ мм, высота (длина) $L = 12$ мм, коэффициент конвекции воздуха $h = 60$ Вт/(м²·К).

{{< formula display="true" >}}
m = \sqrt{\frac{2h}{k t}} = \sqrt{\frac{2 \times 60}{205 \times 0{,}00012}} = \sqrt{\frac{120}{0{,}0246}} = \sqrt{4878} = 69{,}8 \;\text{м}^{-1}
{{< /formula >}}

{{< formula display="true" >}}
L_c = L + t/2 = 12 + 0{,}06 = 12{,}06 \;\text{мм} = 0{,}01206 \;\text{м}
{{< /formula >}}

{{< formula display="true" >}}
m L_c = 69{,}8 \times 0{,}01206 = 0{,}842
\quad\Rightarrow\quad
\eta_f = \frac{\tanh(0{,}842)}{0{,}842} = \frac{0{,}686}{0{,}842} = 0{,}815
{{< /formula >}}

КПД ребра 81,5% — типичное значение для оребрённых катушек.

### Треугольное ребро (линейно сужающееся к кончику)

{{< formula display="true" >}}
\eta_f = \frac{1}{mL} \cdot \frac{I_1(2mL)}{I_0(2mL)}
{{< /formula >}}

где $I_0$, $I_1$ — модифицированные функции Бесселя нулевого и первого порядков.

### Кольцевое (аннулярное) ребро трубчатого теплообменника

Для кольцевого ребра радиусами $r_1$ (труба) и $r_2$ (внешний), постоянной толщины $t$:

{{< formula display="true" >}}
\eta_f = \frac{2 r_1}{r_{2c}^2 - r_1^2} \cdot \frac{K_1(m r_1) I_1(m r_{2c}) - I_1(m r_1) K_1(m r_{2c})}{I_0(m r_1) K_1(m r_{2c}) + K_0(m r_1) I_1(m r_{2c})}
{{< /formula >}}

где $r_{2c} = r_2 + t/2$, $I_0, I_1, K_0, K_1$ — модифицированные функции Бесселя.

**Приближение** для $r_2/r_1 < 2$ (достаточно точно для большинства HVAC применений):

{{< formula display="true" >}}
\eta_f \approx \frac{\tanh(m L_e)}{m L_e}, \quad L_e = r_2 - r_1 + t/2
{{< /formula >}}

## Общая эффективность поверхности теплообменника

Для оребрённой поверхности с $N$ рёбрами, общей площадью $A_{tot}$ (рёбра + оголённые участки трубы):

{{< formula display="true" >}}
\eta_o = 1 - \frac{N A_{fin}}{A_{tot}}(1 - \eta_f)
{{< /formula >}}

Суммарный тепловой поток:

{{< formula display="true" >}}
Q_{tot} = h \cdot A_{tot} \cdot \eta_o \cdot (T_b - T_\infty)
{{< /formula >}}

### Пример: оребрённый воздухоохладитель

Медная труба Ø12,7 мм, алюминиевые кольцевые рёбра: шаг 2 мм, $r_1 = 6{,}35$ мм, $r_2 = 18{,}35$ мм, $t = 0{,}12$ мм. На 1 м трубы размещается $1000/2 = 500$ рёбер.

Площадь одного ребра: $A_{fin} = 2\pi(r_2^2 - r_1^2) = 2\pi(18{,}35^2 - 6{,}35^2) \times 10^{-6} = 1{,}932 \times 10^{-3}$ м².

Оголённая площадь трубы между рёбрами: $A_{bare} = \pi D (s - t) = \pi \times 0{,}01270 \times (0{,}002 - 0{,}00012) = 7{,}50 \times 10^{-5}$ м²/ребро.

$A_{tot} = 500 \times (1{,}932 \times 10^{-3} + 7{,}50 \times 10^{-5}) = 1{,}004$ м²/м трубы.

При $\eta_f = 0{,}82$: $\eta_o = 1 - (500 \times 1{,}932 \times 10^{-3})/(1{,}004) \times (1 - 0{,}82) = 1 - 0{,}173 = 0{,}827$.

## Эффективность ребра (fin effectiveness)

Помимо КПД, используют понятие **эффективности ребра** $\varepsilon_f$ — отношение теплового потока через ребро к потоку без ребра с той же площадью основания:

{{< formula display="true" >}}
\varepsilon_f = \frac{Q_{fin}}{h A_{base} \theta_b} = \frac{\sqrt{kP/hA_c} \tanh(mL)}{1}
{{< /formula >}}

Применение ребра оправдано при $\varepsilon_f > 2$. Для типичных алюминиевых рёбер в HVAC: $\varepsilon_f = 5$–$15$.

## Оптимальный шаг рёбер

### Вынужденная конвекция (каналы между рёбрами)

При заданных геометрических ограничениях оптимальный шаг рёбер $s$ минимизирует тепловое сопротивление:

{{< formula display="true" >}}
s_{opt} \approx 2{,}71 \left(\frac{\mu L}{0{,}623 \rho^2 c_p \Delta P}\right)^{0,25}
{{< /formula >}}

### Естественная конвекция (вертикальные рёбра)

{{< formula display="true" >}}
s_{opt} = 2{,}714 \left(\frac{L^3}{Ra_L}\right)^{0,25}
{{< /formula >}}

## Загрязнение рёбер и деградация производительности

Загрязнение (fouling) на поверхности рёбер эффективно снижает коэффициент конвекции и увеличивает сопротивление:

{{< formula display="true" >}}
\frac{1}{UA_{fouled}} = \frac{1}{UA_{clean}} + R_f
{{< /formula >}}

Для оребрённых катушек HVAC типичный коэффициент загрязнения $R_f = 0{,}0001$–$0{,}0003$ м²·К/Вт. Рекомендуется ежегодная чистка для сохранения производительности.

Контактное сопротивление между ребром и трубой $R_c$ оказывает существенный эффект при расширении ребра (press-fit fins). Пайка и механическое накатывание обеспечивают $R_c < 0{,}00005$ м²·К/Вт.
