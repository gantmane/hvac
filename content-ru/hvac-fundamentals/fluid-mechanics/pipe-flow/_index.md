Гидравлический расчёт трубопровода — фундамент проектирования гидронных систем, систем с хладагентом и газопроводов. Задача расчёта: для заданного расхода Q выбрать диаметр D так, чтобы скорость и потери давления находились в допустимых пределах, а затем по суммарным потерям подобрать насос.

## Классификация потока по числу Рейнольдса

{{< formula display="true" >}}
Re = \frac{\rho V D}{\mu} = \frac{V D}{\nu}
{{< /formula >}}

{{< table title="Режимы потока в круглых трубах" >}}
| Режим | Re | Коэффициент трения | Профиль скорости |
|---|---|---|---|
| Ламинарный | < 2300 | f = 64/Re (точно) | Параболический (Пуазейль) |
| Переходный | 2300–4000 | Непредсказуем | Нестабильный |
| Турбулентный (гладкая труба) | 4000–100 000 | f = 0,316 Re⁻⁰˙²⁵ (Блазиус) | Логарифмический |
| Турбулентный (любая шероховатость) | > 4000 | Диаграмма Муди / Коулбрук | Логарифмический |
{{< /table >}}

Для большинства HVAC-трубопроводов Re = 10 000–200 000 — уверенный турбулентный режим.

## Основное уравнение: Дарси-Вейсбах

{{< formula display="true" >}}
\Delta P_\text{лин} = \lambda\,\frac{L}{D}\,\frac{\rho\,V^2}{2}
{{< /formula >}}

В форме напора:

{{< formula display="true" >}}
h_L = \lambda\,\frac{L}{D}\,\frac{V^2}{2g}
{{< /formula >}}

Это уравнение универсально: оно применяется к жидкостям и газам, ламинарному и турбулентному потокам. Весь «секрет» — в правильном определении {{< formula >}}\lambda{{< /formula >}}.

## Определение коэффициента трения λ

### Ламинарный поток (Re < 2300)

{{< formula display="true" >}}
\lambda = \frac{64}{Re}
{{< /formula >}}

Абсолютно точное решение уравнения Навье–Стокса для параболического профиля Пуазейля. Шероховатость трубы значения не имеет.

### Турбулентный поток: уравнение Коулбрука–Уайта

{{< formula display="true" >}}
\frac{1}{\sqrt{\lambda}} = -2\lg\!\left(\frac{k_s}{3{,}7\,D} + \frac{2{,}51}{Re\sqrt{\lambda}}\right)
{{< /formula >}}

Уравнение неявное — требует итерации (3–5 шагов метода Ньютона). В качестве начального приближения удобно использовать λ₀ = 0,02.

### Явная аппроксимация Свами–Джейна (погрешность ≤ 2 %, ASHRAE рекомендует)

{{< formula display="true" >}}
\lambda = \frac{0{,}25}{\left[\lg\!\left(\dfrac{k_s}{3{,}7D} + \dfrac{5{,}74}{Re^{0{,}9}}\right)\right]^2}
{{< /formula >}}

Диапазон применимости: {{< formula >}}4\times10^3 < Re < 10^8{{< /formula >}}, {{< formula >}}10^{-6} < k_s/D < 10^{-2}{{< /formula >}}.

### Абсолютная шероховатость материалов труб

{{< table title="Абсолютная шероховатость k_s труб, применяемых в HVAC" >}}
| Материал | k_s, мм | Применение |
|---|---|---|
| Сталь электросварная новая (ГОСТ 10704) | 0,06 | Системы отопления, тепловые пункты |
| Сталь водогазопроводная (ГОСТ 3262) | 0,10 | ГВС, отопление |
| Сталь с внутренним полимерным покрытием | 0,01 | Системы охлаждённой воды |
| Медь тянутая (EN 1057) | 0,0015 | Хладагентные линии, ГВС |
| Чугун серый новый | 0,25 | Старые системы |
| ПВХ, ПЭ, ПП | 0,002 | Дренаж, вода, гликолевые контуры |
| Нержавеющая сталь (AISI 304/316) | 0,015 | Чистые помещения, пищевая промышленность |

{{< /table >}}

## Диаграмма Муди — графический метод

Диаграмма Муди (1944) — графическое представление уравнения Коулбрука. По оси X — число Рейнольдса Re, по Y — коэффициент трения λ, семейство кривых — параметр {{< formula >}}k_s/D{{< /formula >}}.

**Зоны диаграммы:**

1. Ламинарная зона (Re < 2300): λ = 64/Re — прямая линия с наклоном −1.
2. Переходная зона (2300–4000): полоса неопределённости, проектирования избегают.
3. Гладкостенный турбулентный режим (нижняя огибающая): шероховатость в вязком подслое — λ зависит только от Re.
4. Смешанный режим: λ зависит и от Re, и от k_s/D.
5. Полностью турбулентный шероховатый режим (плато): λ зависит только от k_s/D, не зависит от Re.

{{< formula display="true" >}}
\lambda_\text{шерох} = \left[2\lg\!\left(\frac{3{,}7D}{k_s}\right)\right]^{-2}\quad(\text{Re}\to\infty)
{{< /formula >}}

## Скоростной напор и динамическое давление

{{< formula display="true" >}}
q = \frac{\rho V^2}{2}
{{< /formula >}}

Скоростной напор {{< formula >}}V^2/(2g){{< /formula >}} и динамическое давление q — ключевые величины для расчёта местных сопротивлений. При V = 2 м/с для воды (ρ = 998 кг/м³): q = 998·4/2 = 1996 Па ≈ 2 кПа. Это немного по сравнению с потерями на трение в длинных трубопроводах, но может быть значимым в компактных узлах.

## Местные сопротивления

{{< formula display="true" >}}
\Delta P_\text{мест} = \zeta\,\frac{\rho V^2}{2}
{{< /formula >}}

Коэффициент сопротивления ζ зависит от геометрии фитинга и, в меньшей степени, от числа Рейнольдса. Метод «эквивалентной длины» — альтернативный подход: фитинг заменяется длиной трубы L_экв = ζ·D/λ.

| Колено 90°, радиус R = 2D | 0,9 | 45 |
| Колено 90°, R = 3D (пайка) | 0,6 | 30 |
| Колено 45° | 0,4 | 20 |

## Выбор диаметра: методика удельного перепада давления

Стандартная методика — задать удельный перепад давления R (Па/м) и найти диаметр:

{{< formula display="true" >}}
R = \frac{\Delta P}{L};\quad D = \left(\frac{8\lambda\,Q^2}{\pi^2 R/(\rho/2)}\right)^{1/5}
{{< /formula >}}

Из СП 60.13330 и ASHRAE рекомендации:
- Гидроника (отопление, охлаждение): R = 50–200 Па/м при скорости 0,5–2,5 м/с.
- Газопроводы низкого давления: R ≤ 5 Па/м.

## Полный расчёт участка трубопровода: числовой пример

**Задача.** Подобрать диаметр и рассчитать потери давления на подающем стояке системы отопления жилого дома в Москве.

**Исходные данные:**
- Тепловая нагрузка стояка: Q_т = 15 кВт
- Расчётная температура: 90/70 °C (ΔT = 20 °C)
- Длина стояка: L = 25 м
- Фитинги: 4 колена 90° (R = 2D), 2 тройника-ответвления

**Расчёт:**

Расход воды:

{{< formula display="true" >}}
G = \frac{Q_\text{т}}{c_p\,\rho\,\Delta T} = \frac{15000}{4187\times982\times20} = 1{,}826\times10^{-4}\text{ м}^3/\text{с} = 0{,}657\text{ м}^3/\text{ч}
{{< /formula >}}

При целевой скорости V = 1,0 м/с: {{< formula >}}D = \sqrt{4Q/(\pi V)} = \sqrt{4\times1{,}826\times10^{-4}/(\pi\times1{,}0)} = 0{,}01526\text{ м}{{< /formula >}}.

Принимаем DN15 (d_вн = 15,75 мм), стандартный стояк для квартиры.

Фактическая скорость: {{< formula >}}V = 4\times1{,}826\times10^{-4}/(\pi\times0{,}01575^2) = 0{,}94{{< /formula >}} м/с.

Температура 80 °C: ρ = 971 кг/м³, ν = 0,364·10⁻⁶ м²/с.

{{< formula display="true" >}}
Re = \frac{0{,}94\times0{,}01575}{0{,}364\times10^{-6}} = 40\,700
{{< /formula >}}

Труба стальная k_s = 0,10 мм, {{< formula >}}k_s/D = 0{,}10/15{,}75 = 6{,}35\times10^{-3}{{< /formula >}}.

По Свами–Джейну: λ ≈ 0,035.

Линейные потери: {{< formula >}}h_\text{лин} = 0{,}035\times(25/0{,}01575)\times(0{,}94^2/19{,}62) = 24{,}7{{< /formula >}} м × ρg = 235 кПа — это много! Проверим: 235/25 = 9,4 кПа/м — выходит за пределы нормы (0,05–0,20 кПа/м). Нужен диаметр DN20.

С DN20 (d_вн = 20,75 мм): V = 0,54 м/с, Re = 30 700, λ = 0,036, R = 2,3 кПа/м·0,02075 = (0,036×0,54²/2×971)/0,02075 = 247 Па/м. Итого h_лин = 247×25/1000 = 6,2 кПа.

Местные потери: 4×0,9 + 2×1,3 = 6,2; {{< formula >}}\Delta P_\text{мест} = 6{,}2\times971\times0{,}54^2/2 = 879{{< /formula >}} Па ≈ 0,9 кПа.

Итого на стояке: 6,2 + 0,9 = **7,1 кПа**.

## Трубопроводы хладагента: особенности расчёта

Линии хладагента рассчитываются по допустимой потере давления, пересчитанной в потерю температуры кипения/конденсации:

{{< table title="Критерии выбора диаметра линий хладагента (ASHRAE Ch. 2)" >}}
| Линия | Допустимая ΔP | Пересчёт в ΔT | Скорость |
|---|---|---|---|
| Нагнетание | ΔT_насыщ ≤ 2 °C | ≈ 0,02 кПа/кПа напора конденсации | 10–20 м/с |
| Жидкостная | Потеря ≤ 30 кПа | — | 0,5–1,5 м/с |
| Всасывающая | ΔT_насыщ ≤ 0,5 °C | ≈ 0,01 кПа/кПа давления испарения | 4–15 м/с |
{{< /table >}}

Подъём всасывающей паровой линии вертикально вверх требует скорости не ниже 4 м/с для транспорта масла в компрессор (правило ASHRAE: при непрерывном подъёме вверх V_мин = 4 м/с для R-410A при t_исп = +5 °C).
