## Введение

Упаковка замороженных продуктов служит основным барьером между продуктом и окружающей средой хранения, что напрямую влияет на расчеты холодильной нагрузки, миграцию влаги и сохранение качества продукции. Выбор материала упаковки влияет на скорость теплопередачи, потери сублимацией и эффективность холодильной системы.

Система упаковки должна сохранять структурную целостность и барьерные свойства в диапазоне температур от окружающей среды (+21°C) через быструю заморозку (-40°C до -73°C) до долгосрочного хранения (-12°C до -18°C).

## Требования к барьеру влажности

### Скорость передачи водяного пара (WVTR)

WVTR определяет скорость передачи водяного пара через материал упаковки в указанных условиях:

```
WVTR = (m × t) / (A × Δp)
```

Где:
- WVTR = скорость передачи водяного пара (г/м²·сут)
- m = масса переданного водяного пара (г)
- t = толщина материала (мм или мкм)
- A = площадь передачи (м²)
- Δp = разность давлений паров (Па)

### Требования WVTR по типам продуктов

| Категория продукта | Максимум WVTR @ 23°C, 50% ОВ | Типичный срок хранения |
|-------------------|-------------------------------|-------------------------|
| Мясо с высоким содержанием жира | <0,5 г/м²·сут | 6-12 месяцев |
| Нежирное мясо, птица | <1,0 г/м²·сут | 9-12 месяцев |
| Овощи | <2,0 г/м²·сут | 12-18 месяцев |
| Фрукты | <1,5 г/м²·сут | 12-24 месяца |
| Хлебобулочные изделия | <3,0 г/м²·сут | 6-12 месяцев |
| Мороженое | <0,3 г/м²·сут | 12-18 месяцев |

### Влияние температуры на WVTR

Проницаемость увеличивается с температурой в соответствии с соотношением Аррениуса:

```
P = P₀ × e^(-Ea/RT)
```

Где:
- P = проницаемость при температуре T
- P₀ = предэкспоненциальный множитель
- Ea = энергия активации (Дж/моль)
- R = универсальная газовая постоянная (8,314 Дж/моль·K)
- T = абсолютная температура (K)

WVTR обычно удваивается при увеличении температуры на 10°C. Упаковка должна тестироваться при фактических температурах хранения, а не при условиях окружающей среды.

## Барьерные свойства кислорода

### Скорость передачи кислорода (OTR)

Пропускание кислорода вызывает окислительное прогоркание жиров, деградацию цвета и потерю витаминов:

```
OTR = (V × t) / (A × Δp × τ)
```

Где:
- OTR = скорость передачи кислорода (см³/м²·сут·атм)
- V = объем переданного кислорода (см³)
- t = толщина материала (мкм)
- A = площадь (м²)
- Δp = разность парциального давления (атм)
- τ = время (сут)

### Классификация кислородного барьера

| Уровень барьера | Диапазон OTR (см³/м²·сут) | Типичные материалы | Применение |
|-----------------|---------------------------|-------------------|-----------|
| Отличный | <1 | EVOH, PVDC, алюминиевая фольга | Продукты с высоким содержанием жира, долгосрочное хранение |
| Очень хороший | 1-5 | Нейлон, PET | Продукты с средним содержанием жира |
| Хороший | 5-20 | PP, LDPE | Овощи с низким содержанием жира |
| Удовлетворительный | 20-100 | HDPE | Кратковременное хранение |
| Плохой | >100 | Немелованная бумага | Только внутренние обертки |

### Критические уровни кислорода

| Тип продукта | Критический уровень O₂ (%) | Влияние на срок годности |
|-------------|------------------------------|--------------------------|
| Свежее красное мясо | >0,5% | Деградация цвета |
| Птица | >2% | Начало прогоркания |
| Рыба, морепродукты | >1% | Ускорение окисления |
| Орехи | >0,5% | Ухудшение вкуса |
| Сушеные фрукты | >3% | Потеря цвета/вкуса |

## Предотвращение ожога при заморозке

### Механика сублимации

Ожог при заморозке результат сублимации кристаллов льда на поверхности продукта, когда градиенты давления пара превышают барьерную способность упаковки:

```
Скорость сублимации = k × A × (Pₛ - Pₐ) / d
```

Где:
- k = коэффициент массообмена (г/м²·Па·с)
- A = открытая площадь поверхности (м²)
- Pₛ = давление пара на поверхности продукта (Па)
- Pₐ = давление пара в среде хранения (Па)
- d = толщина пограничного слоя (м)

### Давление пара при замороженных температурах

| Температура | Давление пара | Движущая сила сублимации |
|------------|-----------------|--------------------------|
| -18°C | 125 Па | Базовый уровень |
| -23°C | 80 Па | Снижение на 36% |
| -29°C | 50 Па | Снижение на 60% |
| -34°C | 30 Па | Снижение на 76% |

Более низкие температуры хранения снижают движущую силу сублимации, но упаковка должна компенсировать колебания температуры во время хранения.

### Конструкция упаковки для предотвращения ожога при заморозке

**1. Минимизация свободного пространства**
- Сокращение объема воздуха между продуктом и упаковкой
- Максимальное рекомендуемое свободное пространство: 5-10% объема упаковки
- Использование вакуума или азотной промывки для неправильных форм

**2. Устранение воздушных карманов**
- Плотное прилегание упаковки к поверхности продукта
- Использование термоусадочных пленок с нагревом до 82-116°C
- Применение вакуума: -0,85 до -0,95 бар (избыточное давление)

**3. Конструкция с многослойным барьером**
- Наружный слой: механическая защита
- Средний слой: барьер газа/влаги (EVOH, PVDC)
- Внутренний слой: целостность теплового запечатывания (полиэтилен)

## Целостность упаковки при низких температурах

### Хрупкость материала и температура стеклования

Полимеры демонстрируют температуру стеклования (Tg), ниже которой они становятся хрупкими:

| Полимер | Температура стеклования | Начало хрупкости | Пригодность для замороженных |
|---------|------------------------|-------------------|------------------------------|
| LDPE | -90°C | Ниже -73°C | Отличная |
| HDPE | -90°C | Ниже -73°C | Отличная |
| PP | -15°C | Ниже -12°C | Плохая для криогенных |
| PET | 74°C | Никогда не хрупкий при замороженных | Отличная |
| Нейлон 6 | 49°C | Никогда не хрупкий при замороженных | Отличная |
| PVDC | -18°C | Ниже -12°C | Требуются пластификаторы |

### Ударная прочность при замороженных температурах

Ударная вязкость уменьшается с температурой:

```
Коэффициент ударной прочности = IS(T) / IS(23°C)
```

| Материал | 23°C | -18°C | -29°C | -40°C |
|----------|------|-------|-------|-------|
| LDPE | 1,00 | 0,95 | 0,90 | 0,85 |
| HDPE | 1,00 | 0,85 | 0,70 | 0,50 |
| PP | 1,00 | 0,60 | 0,30 | 0,15 |
| PET | 1,00 | 0,95 | 0,93 | 0,90 |
| Нейлон | 1,00 | 0,98 | 0,96 | 0,94 |

### Целостность теплового запечатывания

Прочность теплового запечатывания должна проверяться при температуре хранения:

**Минимальные требования к прочности запечатывания:**
- Легкие упаковки (<0,9 кг): ≥3,5 Н/см ширины
- Средние упаковки (0,9-4,5 кг): ≥5,3 Н/см ширины
- Тяжелые упаковки (>4,5 кг): ≥7,9 Н/см ширины

Режимы отказа запечатывания при низкой температуре:
- Отслоение: неадекватная начальная температура запечатывания
- Расслоение: несовместимые слои запечатывания
- Разрушение: чрезмерная хрупкость полимера запечатывания

## Тепловые свойства материалов упаковки

### Теплопроводность

Тепловое сопротивление упаковки влияет на время замораживания и холодильную нагрузку:

| Материал | Толщина (мм) | k (Вт/м·K) | RSI (м²·K/Вт) |
|----------|-------------|------------|--------------|
| Полиэтиленовая пленка | 0,05 | 0,34 | 0,00009 |
| Полиэтиленовая пленка | 0,1 | 0,34 | 0,00017 |
| Полипропилен | 0,05 | 0,15 | 0,00021 |
| PET | 0,013 | 0,16 | 0,00005 |
| Нейлон | 0,013 | 0,18 | 0,00004 |
| Картонная коробка | 0,5 | 0,09 | 0,0039 |
| Гофрированная коробка | 5 | 0,058 | 0,062 |
| Вспененный полистирол | 25 | 0,031 | 0,60 |

### Влияние на время замораживания

Модифицированное уравнение Планка для упаковки:

```
t = (ρL/ΔT) × [(Pa/h) + (Ra²/4k)]
```

Где:
- t = время замораживания (ч)
- ρ = плотность продукта (кг/м³)
- L = скрытая теплота плавления (кДж/кг)
- ΔT = разность температур (°C)
- P = тепловое сопротивление упаковки (м²·K/Вт)
- a = минимальное измерение продукта (м)
- h = коэффициент теплопередачи поверхности (Вт/м²·K)
- R = коэффициент формы (1 для бесконечной пластины, 2 для цилиндра, 3 для сферы)
- k = теплопроводность продукта (Вт/м·K)

Для типичной полиэтиленовой пленки тепловое сопротивление незначительно. Однако гофрированные наружные коробки могут увеличить время замораживания на 15-30%.

### Коэффициент теплового расширения

Упаковка должна компенсировать дифференциальное тепловое расширение:

| Материал | Линейный коэффициент расширения (м/м·°C × 10⁻⁵) |
|----------|--------------------------------------------------|
| LDPE | 10,0-20,0 |
| HDPE | 8,0-12,0 |
| PP | 5,0-9,0 |
| PET | 3,0-4,0 |
| Нейлон | 5,0-8,0 |
| Алюминий | 1,3 |
| Сталь | 0,6 |

Изменение размеров от 21°C до -29°C:

```
ΔL = L₀ × α × ΔT
```

Для 30-см упаковки из LDPE:
ΔL = 0,30 × (15×10⁻⁵) × (50°C) = 0,00023 м (незначительно)

## Критерии выбора материалов

### Однослойные пленки

**Полиэтилен (PE)**
- Типы: LDPE, LLDPE, HDPE
- WVTR: 0,4-1,2 г/м²·сут (0,05 мм)
- OTR: 5000-8000 см³/м²·сут
- Преимущества: отличная гибкость при низких температурах, хороший барьер от влаги, теплозапечатываемый
- Ограничения: плохой кислородный барьер, требуется толстая пленка для адекватной защиты
- Применение: обертки, мешки для продуктов, вторичная упаковка

**Полипропилен (PP)**
- WVTR: 0,3-0,5 г/м²·сут (0,05 мм)
- OTR: 2500-3500 см³/м²·сут
- Преимущества: большая прочность на разрыв, лучшая прозрачность чем PE
- Ограничения: хрупкий ниже -12°C, плохая ударная вязкость при низких температурах
- Применение: крышечные пленки, термоформованные лотки (используются выше -18°C)

**Полиэстер (PET)**
- WVTR: 1,5-2,0 г/м²·сут (0,013 мм)
- OTR: 50-100 см³/м²·сут
- Преимущества: отличная прочность на разрыв, размерная стабильность, прозрачность
- Ограничения: не теплозапечатываемый (требует покрытия), дорогой
- Применение: барьерный слой в ламинатах, лотки для микроволновой печи

### Многослойные коэкструдированные пленки

Типичная 5-слойная структура для высокобарьерной упаковки замороженных продуктов:

**Наружный слой (20%):** LDPE или LLDPE
- Механическая защита
- Способность теплового запечатывания
- Барьер от влаги

**Связующий слой (5%):** Адгезивный полимер
- Связывает несовместимые полимеры
- Сохраняет целостность ламината

**Барьерный слой (10%):** EVOH или PVDC
- Основной кислородный барьер
- Вторичный барьер от влаги

**Связующий слой (5%):** Адгезивный полимер

**Внутренний слой (60%):** LDPE или металлоценовый PE
- Слой теплового запечатывания
- Поверхность в контакте с пищей
- Основной барьер от влаги

Общая толщина пленки: 0,05-0,1 мм (50-100 мкм)

### Высокобарьерные материалы

**EVOH (Этиленвиниловый спирт)**
- OTR: 0,02-0,5 см³/м²·сут (отличный)
- WVTR: 8-15 г/м²·сут (плохой - должен быть защищен)
- Преимущества: выдающийся кислородный барьер, прозрачный
- Ограничения: чувствителен к влаге (теряет барьер во влажном состоянии), дорогой
- Типичная концентрация: 5-15% от общей толщины пленки
- Применение: красное мясо, морепродукты, продукты с высоким содержанием жира

**PVDC (Поливинилиденхлорид)**
- OTR: 0,5-2,0 см³/м²·сут (отличный)
- WVTR: 0,1-0,5 г/м²·сут (отличный)
- Преимущества: отличный комбинированный барьер от влаги и кислорода
- Ограничения: сложность обработки, экологические проблемы, выделение HCl при высоких температурах
- Применение: обработанное мясо, сыр, некоторые замороженные продукты
- Толщина покрытия: 1-3 фунт/стопка

**Металлизированные пленки**
- OTR: <0,1 см³/м²·сут (отличный)
- WVTR: <0,1 г/м²·сут (отличный)
- Преимущества: превосходный барьер, барьер света, экономичный
- Ограничения: не прозрачный, чувствителен к проколам, несовместим с микроволновой печью
- Металлизация: вакуумное напыление алюминия (200-500 Å)
- Применение: кофе, закуски, долгосрочное хранение замороженных продуктов

**Алюминиевая фольга**
- OTR: 0 (абсолютный барьер)
- WVTR: 0 (абсолютный барьер)
- Преимущества: полный барьер газу, влаге, свету и запахам
- Ограничения: дорогой, подвержен трещинам при изгибе, не прозрачный
- Типичная толщина: 0,009-0,025 мм
- Применение: премиум замороженные блюда, мороженое в палочках

### Жесткие и полужесткие контейнеры

**Термоформованные лотки**
- Материалы: PP, PET, CPET, PS
- Толщина стенки: 0,25-0,75 мм
- Преимущества: защита продукта, совместимость с микроволновой печью, удержание формы
- Крышечное запечатывание: теплозапечатанная гибкой пленкой (OTR/WVTR определяется крышечкой)
- Применение: замороженные блюда, морепродукты, приготовленные блюда

**Контейнеры методом впрыска**
- Материалы: PP, HDPE
- Толщина стенки: 0,5-1,5 мм
- Преимущества: переиспользуемый, высокая ударная вязкость, складируемость
- Ограничения: плохой кислородный барьер при отсутствии покрытия
- Применение: мороженое, замороженные овощи в больших объемах

**Картонные коробки с покрытием**
- Основа: SBS (отбеленный сульфатный картон) или CUK (немелованный крафт с покрытием)
- Покрытие: PE, воск или дисперсия полимера
- Толщина: 0,3-0,6 мм (12-24 pt)
- WVTR: 5-20 г/м²·сут (зависит от покрытия)
- Преимущества: печатаемость, жесткость, привлекательность для потребителя
- Применение: замороженные овощи, приготовленные блюда, мороженое

## Упаковка под вакуумом

### Требования к уровню вакуума

Содержание остаточного кислорода определяет стабильность продукта:

| Уровень вакуума | Остаточное давление | Остаточный O₂ | Пригодность продукта |
|-----------------|-------------------|---------------|----------------------|
| Низкий | 500-700 мбар | 50-70% | Минимальная выгода |
| Средний | 100-200 мбар | 10-20% | Кратковременное замороженное хранение |
| Высокий | 10-50 мбар | 1-5% | Расширенное замороженное хранение |
| Глубокий | <5 мбар | <0,5% | Премиум продукты, долгосрочное |

### Оборудование для вакуумной упаковки

**Камерные вакуумные машины**
- Продукт помещается внутри камеры
- Камера эвакуируется до установленной точки
- Запечатывание выполняется под вакуумом
- Воздух возвращается в камеру
- Достижимый вакуум: 1-50 мбар
- Время цикла: 20-60 секунд
- Применение: высокостоимостные продукты, упаковки учреждений

**Внешние (сопловые) вакуумные машины**
- Сопло вводится в отверстие упаковки
- Воздух эвакуируется из упаковки
- Запечатывание выполняется после вывода сопла
- Достижимый вакуум: 50-200 мбар
- Время цикла: 3-10 секунд
- Применение: высокоскоростное производство, потребительские упаковки

### Требования к пленке для вакуумной упаковки

**Прочность на прокол**
- Критична для продуктов с костями
- Измеряется по ASTM D1709 (тест падения снаряда)
- Минимум: 0,9 кг для без костей, 1,8 кг для с костями

**Запечатывание при загрязнении**
- Мясной сок, жиры и частицы продукта могут нарушить запечатывание
- Используйте текстурированные или канальные запечатывающие планки
- Применяйте двойное или тройное запечатывание
- Минимальная ширина запечатывания: 3 мм для гладких продуктов, 5 мм для загрязненных

**Свойства усадки**
- Пленки нагреваются после упаковки для приравнивания к продукту
- Температура усадки: 82-116°C (водяная ванна или горячий воздушный туннель)
- Свободная усадка: 40-60% в направлении машины, 20-40% в поперечном направлении
- Напряжение усадки: не должно сжимать деликатные продукты

## Упаковка с модифицированной атмосферой (MAP)

### Состав газа для замороженных продуктов

Хотя замораживание останавливает микробный рост, MAP обеспечивает дополнительную защиту при температурных сбоях и распределении:

| Тип продукта | O₂ | CO₂ | N₂ | Цель |
|-------------|-----|-----|-----|-------|
| Красное мясо | 0% | 20-30% | 70-80% | Сохранение цвета, предотвращение окисления |
| Птица | 0% | 25-35% | 65-75% | Предотвращение окисления |
| Морепродукты | 0% | 40-60% | 40-60% | Подавление активности ферментов |
| Хлебобулочные изделия | 0% | 50-70% | 30-50% | Предотвращение плесени при оттаивании |
| Фрукты | 2-5% | 5-15% | 80-90% | Поддержание баланса дыхания |

### Оборудование для газовой промывки

**Системы непрерывного потока**
- Газ вводится при прохождении продукта
- Упаковка запечатывается немедленно
- Использование газа: 1,5-3× объем упаковки
- Скорость линии: 30-120 упаковок/минута
- Остаточный O₂: 2-5%

**Компенсированные вакуумные системы**
- Упаковка эвакуируется (50-200 мбар)
- Газ возвращается под атмосферное давление
- Цикл повторяется 2-3 раза
- Использование газа: 4-8× объем упаковки
- Остаточный O₂: <1%
- Время цикла: 30-90 секунд

### Пропускание газа и срок годности упаковки

Срок службы упаковки до достижения O₂ критического уровня:

```
t = (Vc × [O₂]crit) / (OTR × A × [O₂]atm)
```

Где:
- t = срок службы упаковки (сут)
- Vc = свободный объем упаковки (см³)
- [O₂]crit = критическая концентрация кислорода (%)
- OTR = скорость передачи кислорода (см³/м²·сут)
- A = площадь поверхности упаковки (м²)
- [O₂]atm = атмосферный кислород (21%)

Пример: упаковка 1000 см³, OTR = 1 см³/м²·сут, A = 0,05 м², [O₂]crit = 2%

t = (1000 × 0,02) / (1 × 0,05 × 0,21) = 1905 сут (5,2 года)

Это предполагает постоянное хранение при замороженных температурах. Тепловой сбой ускоряет пропускание.

## Вторичная упаковка

### Коробки и обертки

**Функции:**
1. Механическая защита при обработке
2. Дополнительный барьер от влаги
3. Отображение маркетинга и информации
4. Комплектование для паллетизации

**Соображения конструкции коробок:**

**Вес основы материала:**
- Легкие продукты (<0,45 кг): 18-24 pt SBS
- Средний вес (0,45-2,3 кг): 24-28 pt SBS
- Тяжелые продукты (>2,3 кг): 28-36 pt SBS или E-гофр

**Устойчивость к влаге:**
- Покрытие PE: 10-20 фунт/стопка на сторону
- Восковое покрытие (устаревшее): 15-25 фунт/стопка
- Барьер от водяного пара: WVTR 2-8 г/м²·сут

**Тепловые свойства:**
- Тепловое сопротивление коробки: 0,003-0,006 м²·K/Вт на 0,5 мм
- Ограничивает теплопередачу во время замораживания на 5-15%
- Обеспечивает изоляцию во время временных температурных перепадов

### Мастер-коробки (гофрированные)

**Выбор волнистости:**

| Тип волнистости | Толщина (мм) | Прочность сжатия | Высота стопки |
|-----------------|------------|-----------------|--------------|
| E-волн | 1,6 | Хорошая | <1,8 м |
| B-волн | 3,2 | Очень хорошая | <3 м |
| C-волн | 4,8 | Отличная | <4,6 м |
| BC-волн | 8 | Превосходная | >4,6 м |

**Требования к прочности разрыва:**

```
Прочность разрыва (кПа) = (Вес коробки × Высота стопки × 5,5) / Площадь коробки
```

Для коробки 11,3 кг, высота стопки 3,7 м, площадь 0,26 м²:
Прочность разрыва = (11,3 × 3,7 × 5,5) / 0,26 = 342 кПа (использовать доску 190 кПа/см²)

**Деградация от влаги:**
- Гофрированный теряет 50% прочности при насыщении
- Восковое или полимерное покрытие необходимо для замороженного хранилища
- Покрытие добавляет 10-20% к стоимости, но существенно необходимо для окружения морозильника

## Последствия для HVAC и системы охлаждения

### Влажностная нагрузка от упаковки

Неадекватная упаковка увеличивает холодильную нагрузку через сублимацию:

**Расчет нагрузки от сублимации:**

```
Q_сублимация = ṁ_пар × h_сублимация
```

Где:
- Q_сублимация = тепловая нагрузка (кВт)
- ṁ_пар = массовый расход сублимированного пара (кг/ч)
- h_сублимация = скрытая теплота сублимации (1346 кДж/кг при -18°C)

Для 4536 кг продукта с плохой упаковкой, теряющей 0,5% веса/месяц:

ṁ_пар = (4536 × 0,005) / (30 × 24) = 0,0314 кг/ч

Q_сублимация = 0,0314 × 1346 = 42,3 кВт (0,012 т холодопроизводительности)

Хотя мало на упаковку, это накапливается во всех холодильных помещениях. Морозильник объемом 2830 м³ с емкостью 9 млн кг, испытывающий 0,5% месячную потерю веса, требует дополнительно 59 кВт холодопроизводительности.

### Образование инея на испарителях

Сублимированная влага из плохо упакованных продуктов отлагается на катушках испарителя:

**Скорость накопления инея:**

```
ṁ_иней = (ṁ_пар × A_хранилище) / V_хранилище
```

Для помещения с быстрым оборотом и плохой упаковкой:
- Генерирование пара: 0,023 кг/ч на 283 м³
- Помещение объемом 28300 м³: 2,27 кг/ч накопление инея
- Месячный иней: 1636 кг (без учета оттаивания)

**Влияние цикла оттаивания:**
- Увеличенная частота оттаивания: 6 до 8 циклов/день
- Расширенная продолжительность оттаивания: 20 до 30 минут на цикл
- Штраф энергии: увеличение на 50-100% энергии оттаивания
- Повышение температуры продукта во время оттаивания: дополнительно 1-2°C

### Эффект теплоемкости упаковки

Упаковка способствует тепловой массе, требующей охлаждения во время замораживания:

```
Q_упаковка = m_упак × c_p,упак × ΔT
```

Для 0,9 кг продукта в 0,045 кг полиэтиленовой упаковке:

Q_упаковка = 0,045 × 2300 × (21 - (-12)) = 3,4 кДж

Это представляет 2-5% дополнительной нагрузки в сравнении с самим продуктом. Для высокопроизводительного быстрого морозильника, обрабатывающего 4536 кг/ч:

Дополнительная нагрузка = 0,03 × 4536 кг/ч × (ΔH_продукта + ΔH_упаковки)

Это составляет 8,8-17,6 кВт дополнительной холодопроизводительности в зависимости от типа продукта и упаковки.

### Конденсация упаковки при распределении

Когда замороженные продукты движутся через погрузочные доки и распределение:

**Начало конденсации:**

Конденсация образуется, когда температура поверхности упаковки ниже точки росы окружающего воздуха:

```
T_поверхность < T_роса = T_окр - ((100 - ОВ) / 5)
```

При 27°C и 60% ОВ:
T_роса = 27 - ((100-60)/5) = 19°C

Замороженная упаковка при -18°C немедленно подвергается конденсации при воздействии на окружающий воздух. Влага накапливается на наружных коробках, деградируя структуру и потенциально вызывая отказ этикетки.

**Решения:**
1. Минимизируйте время воздействия: <5 минут в переходных зонах
2. Используйте герметичную термоусадочную обертку для поддонов
3. Сохраняйте погрузочные доки при 7-13°C и <60% ОВ
4. Предварительно охладите контейнеры перед загрузкой

### Взаимодействие окружения хранилища

Проницаемость упаковки влияет на содержание влаги в условиях равновесия в хранилище:

Для проницаемой упаковки в хранилище -12°C при 90% ОВ:

**Содержание влаги в условиях равновесия внутри упаковки:**

```
ОВ_внутренний = ОВ_внешний × (P_нас,хранилище / P_нас,продукт)
```

Если поверхность продукта при -13°C и воздух хранилища при -12°C:

ОВ_внутренний = 0,90 × (80 Па / 88 Па) = 0,82 (82% ОВ внутри упаковки)

Это создает градиент влаги, способствующий сублимации от продукта к упаковке к окружению хранилища.

## Сохранение качества через упаковку

### Окислительная стабильность

Связь между воздействием кислорода и деградацией качества:

```
Q_оставшееся = Q_начальное × e^(-k×[O₂]×t)
```

Где:
- Q_оставшееся = оставшийся параметр качества (цвет, вкус, содержание витаминов)
- k = константа скорости реакции (варьируется в зависимости от продукта и температуры)
- [O₂] = концентрация кислорода (%)
- t = время (сут)

Для замороженного говяжьего фарша при -18°C:
- k_цвет = 0,15 сут⁻¹·%⁻¹ (деградация цвета)
- k_вкус = 0,08 сут⁻¹·%⁻¹ (развитие прогоркания)

При 5% остаточного кислорода после 6 месяцев:
Сохранение цвета = e^(-0,15×5×180) = 0,08 (8% остается, серьезно деградировано)

При 0,5% остаточного кислорода (высокобарьерная упаковка):
Сохранение цвета = e^(-0,15×0,5×180) = 0,23 (23% остается, приемлемо)

### Сохранение витаминов

Чувствительные к кислороду витамины (A, C, E) деградируют в соответствии с кинетикой первого порядка:

| Витамин | Продукт | k при -18°C (сут⁻¹) | Период полураспада (сут) |
|---------|---------|----------------------|--------------------------|
| Витамин C | Овощи | 0,001-0,005 | 140-700 |
| Витамин A | Морковь | 0,0008 | 865 |
| Витамин E | Орехи | 0,0012 | 578 |
| Витамин B1 | Мясо | 0,0015 | 462 |

Высокобарьерная упаковка (OTR <1 см³/м²·сут) сохраняет витамины в 3-5× дольше, чем низкобарьерные альтернативы.

### Стабильность цвета

Окисление миоглобина в мясных продуктах:

**Оксимиоглобин (яркий красный) → Метмиоглобин (коричневый)**

Скорость пропорциональна доступности кислорода и температуре:

```
Скорость = k₀ × [O₂] × e^(-Ea/RT)
```

При -12°C скорость деградации цвета 10-20× медленнее, чем при 0°C, но барьер от кислорода в упаковке остается критичным для хранения свыше 6 месяцев.

## Тестирование и обеспечение качества

### Тестирование целостности упаковки

**Тест разрыва (ASTM D3078):**
- Измеряет прочность запечатывания и сопротивление упаковки внутреннему давлению
- Инфляция воздуха до точки отказа
- Минимум: 105 кПа для гибких упаковок, 207 кПа для полужестких

**Тест отслаивания запечатывания (ASTM F88):**
- Количественно определяет прочность теплового запечатывания
- Ширина полосы запечатывания: 25,4 мм, скорость теста: 254 мм/мин
- Минимальные значения указаны ранее в разделе теплового запечатывания

**Тест проникновения красителя:**
- Упаковка заполняется цветным раствором (метиленовый синий)
- Наблюдается на утечку в течение 24 часов
- Прошел/не прошел: нет видимого красителя вне упаковки

**Обнаружение утечки вакуумом:**
- Упаковка погружена в воду под вакуумом
- Пузырьки воздуха указывают на утечки
- Чувствительность: обнаруживает отверстия >10 мкм

### Стандарты тестирования пропускания

**ASTM F1249:** Скорость передачи водяного пара
- Метод модулированного инфракрасного датчика
- Температура контролируемая: 23°C, 38°C
- Влажность контролируемая: 0% до 100% ОВ
- Точность: ±2% от показания

**ASTM D3985:** Скорость передачи кислорода
- Метод кулометрического датчика
- Диапазон температур: 10-40°C
- Относительная влажность: 0-100%
- Предел обнаружения: 0,001 см³/м²·сут

**ASTM F1307:** Скорость передачи кислорода (альтернатива)
- Метод газовой хроматографии
- Более высокая производительность чем D3985
- Предел обнаружения: 0,01 см³/м²·сут

### Ускоренное тестирование срока годности

Имитация теплового сбоя:

**Метод Q10:**
На каждое увеличение на 10°C (18°F) скорости реакции удваиваются:

```
ASF = Q₁₀^((T_тест - T_хранилище)/10°C)
```

Где ASF = коэффициент ускорения

Тестирование при -12°C вместо -23°C:
ASF = 2^((-12-(-23))/10) = 2^1,1 = 2,14

6 месяцев при -12°C имитируют 13 месяцев при -23°C

**Предостережение:** Физические изменения (рекристаллизация, миграция влаги) могут не следовать зависимости Q10. Проверьте ускоренное тестирование против реальных исследований.

   - Используйте вакуум или газовую промывку для неправильных продуктов
   - Рассмотрите термоусадочные пленки для конформируемости

4. **Подход многоуровневого препятствия:**
   - Комбинируйте высокобарьерную упаковку с низкой температурой хранения
   - Используйте MAP или вакуум в дополнение к барьерным пленкам
   - Применяйте вторичную упаковку для механической защиты

5. **Проверяйте в условиях реальной эксплуатации:**
   - Тестируйте при фактической температуре хранения, а не при условиях окружающей среды
   - Включайте цикл замораживания-оттаивания в протокол тестирования
   - Контролируйте на протяжении предполагаемого срока хранения

### Проектирование для эффективности системы HVAC

1. **Сократите нагрузку сублимации:**
   - Укажите WVTR, соответствующий длительности хранения
   - Рассчитайте вклад сублимации в холодильную нагрузку
   - Учитывайте проницаемость упаковки в выборе размера системы

2. **Минимизируйте тепловую массу:**
   - Используйте самую тонкую упаковку, соответствующую требованиям защиты
   - Избегайте избыточной вторичной упаковки
   - Рассмотрите теплоемкость упаковки в выборе размера быстрого морозильника

3. **Предотвратите конденсацию во время обработки:**
   - Спроектируйте упаковку для дренирования конденсата
   - Используйте герметичную пленку поддонов
   - Скоординируйте с управлением температурой помещения

4. **Поддерживайте эффективный макет хранилища:**
   - Стандартизируйте размеры упаковки для оптимального использования пространства
   - Спроектируйте для потока воздуха вокруг упаковок (избегайте полной блокировки)
   - Разрешите сканирование штрихкода без обработки упаковки

Система упаковки является составной частью конструкции системы замороженного хранения пищевых продуктов, напрямую влияя на холодильную нагрузку, качество продукта и эффективность деятельности. Надлежащий выбор материала на основе количественных требований к барьеру и производительности при низких температурах обеспечивает сохранение продукта и оптимизацию работы системы HVAC.
