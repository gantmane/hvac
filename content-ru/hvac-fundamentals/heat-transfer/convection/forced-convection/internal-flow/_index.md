Внутреннее течение — базовый элемент почти всех тепловых сетей HVAC: трубопроводы горячего и холодного водоснабжения, системы охлаждённой воды, холодильные контуры, воздуховодные системы. Ключевое отличие от внешнего обтекания — пограничный слой ограничен стенками канала и после входного участка достигает полностью развитого состояния.

## Области развития потока

### Гидродинамический входной участок

На входе в трубу профиль скорости равномерный. Пограничный слой нарастает от стенки к центру. Длина до полного развития профиля скорости:

{{< formula display="true" >}}
\frac{L_{h,lam}}{D} = 0{,}05 \, Re \quad\text{(ламинарный)}
\qquad
\frac{L_{h,turb}}{D} \approx 10\text{–}60 \quad\text{(турбулентный)}
{{< /formula >}}

### Тепловой входной участок

Если тепловая граница начинается одновременно с гидродинамической:

{{< formula display="true" >}}
\frac{L_{t,lam}}{D} = 0{,}05 \, Re \cdot Pr = Gz
\qquad
\frac{L_{t,turb}}{D} \approx 10\text{–}60
{{< /formula >}}

**Число Граэца** $Gz = Re \cdot Pr \cdot D/L$ характеризует степень гидродинамического развития теплового потока.

На входном участке локальный $Nu$ выше, чем в развитом потоке. Для длинных труб ($L/D > 40$) влиянием входа пренебрегают.

## Ламинарное течение (Re < 2300)

### Полностью развитое течение

{{< formula display="true" >}}
Nu_D = 3{,}66 \quad\text{(пост. температура стенки } T_s\text{)}
\qquad
Nu_D = 4{,}36 \quad\text{(пост. тепловой поток } q''\text{)}
{{< /formula >}}

В ламинарном режиме $h$ обратно пропорционален диаметру: $h = Nu \cdot k / D$. При уменьшении диаметра $h$ растёт.

### Корреляция для входного участка ламинарного течения (Зидер–Тейт)

{{< formula display="true" >}}
Nu_D = 1{,}86 \left(\frac{Re \cdot Pr \cdot D}{L}\right)^{1/3} \left(\frac{\mu_b}{\mu_s}\right)^{0,14}
{{< /formula >}}

**Применима при**: $Gz = Re \cdot Pr \cdot D/L > 10$; $0{,}48 < Pr < 16\,700$; $0{,}0044 < \mu_b/\mu_s < 9{,}75$.

## Турбулентное течение (Re > 4000)

### Уравнение Диттуса–Бёлтера (1930)

{{< formula display="true" >}}
Nu_D = 0{,}023 \, Re_D^{0,8} Pr^n, \quad n = 0{,}4 \;\text{(нагрев)}, \; n = 0{,}3 \;\text{(охлаждение)}
{{< /formula >}}

Применима при: $Re > 10\,000$; $0{,}7 < Pr < 160$; $L/D > 10$. Погрешность ±25%.

### Уравнение Гнилинского (1976) — рекомендованное

{{< formula display="true" >}}
Nu_D = \frac{(f/8)(Re_D - 1000) Pr}{1 + 12{,}7\sqrt{f/8}\,(Pr^{2/3} - 1)}
{{< /formula >}}

Коэффициент трения (гладкая труба, уравнение Петухова):

{{< formula display="true" >}}
f = (0{,}790 \ln Re_D - 1{,}64)^{-2}
{{< /formula >}}

Применима при: $3000 < Re < 5 \times 10^6$; $0{,}5 < Pr < 2000$. Погрешность ±10%.

### Уравнение Зидера–Тейта (большой перепад температур)

{{< formula display="true" >}}
Nu_D = 0{,}027 \, Re_D^{0,8} Pr^{1/3} \left(\frac{\mu_b}{\mu_s}\right)^{0,14}
{{< /formula >}}

Применима при: $Re > 10\,000$; $0{,}7 < Pr < 16\,700$; $L/D > 10$.

### Сравнение корреляций

{{< table title="Сравнение корреляций для турбулентного внутреннего течения" >}}
| Корреляция | Диапазон Re | Диапазон Pr | Погрешность | Область применения |
|---|---|---|---|---|
| Диттус–Бёлтер | > 10 000 | 0,7–160 | ±25% | Быстрые оценки, вода/воздух |
| Гнилинский | 3000–5·10⁶ | 0,5–2000 | ±10% | Основная расчётная корреляция |
| Зидер–Тейт | > 10 000 | 0,7–16 700 | ±20% | Масла, вязкие жидкости |
| Петухов | 10⁴–5·10⁶ | 0,5–2000 | ±6% | Высокоточные расчёты |
{{< /table >}}

## Числовой пример 1: система охлаждённой воды (chiller)

**Задача.** Стальная труба DN80 (наружный диаметр 88,9 мм, внутренний 82,5 мм). Охлаждённая вода 7°С, расход 4 л/с.

Свойства воды при 7°С: $\rho = 999{,}8$ кг/м³, $\mu = 1{,}386 \times 10^{-3}$ Па·с, $k = 0{,}578$ Вт/(м·К), $Pr = 10{,}0$.

{{< formula display="true" >}}
A_c = \frac{\pi D^2}{4} = \frac{\pi \times 0{,}0825^2}{4} = 5{,}346 \times 10^{-3} \;\text{м}^2
{{< /formula >}}

{{< formula display="true" >}}
V = \frac{4 \times 10^{-3}}{5{,}346 \times 10^{-3}} = 0{,}748 \;\text{м/с}
{{< /formula >}}

{{< formula display="true" >}}
Re = \frac{999{,}8 \times 0{,}748 \times 0{,}0825}{1{,}386 \times 10^{-3}} = \frac{61{,}72}{1{,}386 \times 10^{-3}} = 44\,540 \quad\text{(турбулентный)}
{{< /formula >}}

{{< formula display="true" >}}
f = (0{,}790 \ln 44\,540 - 1{,}64)^{-2} = (8{,}37)^{-2} = 0{,}01428
{{< /formula >}}

{{< formula display="true" >}}
Nu_D = \frac{(0{,}01428/8)(44\,540 - 1000) \times 10{,}0}{1 + 12{,}7\sqrt{0{,}01428/8}(10^{2/3}-1)} = \frac{7{,}76 \times 10^{-3} \times 43\,540 \times 10}{1 + 12{,}7 \times 0{,}04225 \times 3{,}636}
{{< /formula >}}

{{< formula display="true" >}}
Nu_D = \frac{3378}{1 + 1{,}951} = \frac{3378}{2{,}951} = 1145
{{< /formula >}}

{{< formula display="true" >}}
h_i = \frac{1145 \times 0{,}578}{0{,}0825} = 8022 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

## Некруглые сечения воздуховодов

### Гидравлический диаметр

{{< formula display="true" >}}
D_h = \frac{4 A_c}{P_{вет}}
{{< /formula >}}

{{< table title="Гидравлический диаметр для типовых форм воздуховодов" >}}
| Форма | Формула $D_h$ |
|---|---|
| Круглый диаметром $D$ | $D$ |
| Прямоугольный $a \times b$ | $2ab/(a+b)$ |
| Квадратный со стороной $a$ | $a$ |
| Кольцевой $D_o - D_i$ | $D_o - D_i$ |
| Плоский щелевой (ширина $b$, зазор $a \ll b$) | $2a$ |
{{< /table >}}

### Пример: воздуховод 400×250 мм

$D_h = 2 \times 400 \times 250 / (400 + 250) = 200\,000 / 650 = 307{,}7$ мм.

### Ламинарный поток в прямоугольных каналах

При $Re < 2300$ число Нуссельта зависит от отношения сторон (аналитические решения):

{{< table title="Nu для ламинарного течения в прямоугольных каналах" >}}
| $a/b$ | $Nu$ ($q'' = \text{const}$) | $Nu$ ($T_s = \text{const}$) |
|---|---|---|
| 1,0 | 3,61 | 2,98 |
| 2,0 | 4,12 | 3,39 |
| 3,0 | 4,79 | 3,96 |
| 4,0 | 5,33 | 4,44 |
| 6,0 | 6,05 | 5,14 |
| 8,0 | 6,49 | 5,60 |
{{< /table >}}

## Числовой пример 2: воздуховод приточной системы

**Задача.** Прямоугольный воздуховод 500×300 мм. Приточный воздух 18°С, скорость 5 м/с. Найти $h$ при условии постоянного теплового потока от стенок.

Свойства воздуха при 18°С: $\rho = 1{,}213$ кг/м³, $\mu = 1{,}81 \times 10^{-5}$ Па·с, $k = 0{,}0257$ Вт/(м·К), $Pr = 0{,}711$.

$D_h = 2 \times 500 \times 300 / (500 + 300) = 375$ мм.

{{< formula display="true" >}}
Re = \frac{1{,}213 \times 5{,}0 \times 0{,}375}{1{,}81 \times 10^{-5}} = \frac{2{,}274}{1{,}81 \times 10^{-5}} = 125\,600 \quad\text{(турбулентный)}
{{< /formula >}}

{{< formula display="true" >}}
f = (0{,}790 \ln 125\,600 - 1{,}64)^{-2} = (9{,}13)^{-2} = 0{,}01201
{{< /formula >}}

{{< formula display="true" >}}
Nu = \frac{(0{,}01201/8)(125\,600 - 1000) \times 0{,}711}{1 + 12{,}7\sqrt{0{,}01201/8}(0{,}711^{2/3}-1)} = \frac{1{,}501 \times 10^{-3} \times 124\,600 \times 0{,}711}{1 + 12{,}7 \times 0{,}0387 \times (-0{,}231)}
{{< /formula >}}

{{< formula display="true" >}}
Nu = \frac{133{,}0}{1 - 0{,}113} = \frac{133{,}0}{0{,}887} = 150{,}0
{{< /formula >}}

{{< formula display="true" >}}
h = \frac{150{,}0 \times 0{,}0257}{0{,}375} = 10{,}3 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

Типичное значение для приточного воздуховода при стандартных скоростях.

## Концентрическое кольцевое пространство (двутрубный теплообменник)

Гидравлический диаметр кольцевого зазора: $D_h = D_o - D_i$.

Для ламинарного течения числа Нуссельта отличаются в зависимости от того, какая из труб нагревается:

{{< table title="Nu для ламинарного течения в кольцевом канале (постоянный тепловой поток)" >}}
| $D_i/D_o$ | $Nu_i$ (нагрев внутренней трубы) | $Nu_o$ (нагрев внешней трубы) |
|---|---|---|
| 0 | 4,36 | — |
| 0,2 | 5,74 | 4,86 |
| 0,4 | 6,58 | 5,10 |
| 0,6 | 7,37 | 5,26 |
| 1,0 | 8,23 | 8,23 |
{{< /table >}}
