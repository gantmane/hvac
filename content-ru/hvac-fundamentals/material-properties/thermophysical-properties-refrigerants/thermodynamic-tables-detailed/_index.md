## Обзор

Таблицы термодинамических свойств — основной справочный инструмент при анализе холодильных циклов, выборе оборудования и расчёте производительности систем ОВК. Таблицы содержат экспериментально верифицированные данные по удельному объёму, энтальпии, энтропии и плотности хладагентов в диапазонах, соответствующих реальным условиям эксплуатации.

Современные цифровые базы данных — NIST REFPROP v10 и CoolProp — вычисляют свойства из фундаментальных уравнений состояния формы Гельмгольца и являются предпочтительными инструментами для проектных расчётов. Печатные таблицы (ASHRAE Handbook — Fundamentals 2021, гл. 30) остаются удобным справочником для быстрых оценок.

## Категории таблиц свойств

### Таблицы насыщения

Таблицы насыщения (saturation tables) содержат свойства при равновесии жидкость–пар. Организуются двумя способами:

**По температуре** — строки соответствуют фиксированным значениям $T_{sat}$; давление насыщения $p_{sat}$ определяется однозначно через кривую давления пара.

**По давлению** — строки соответствуют фиксированным $p_{sat}$; температура насыщения рассчитывается из уравнения состояния.

Каждая строка содержит:

{{< table title="Типовой состав строки таблицы насыщения" >}}
| Переменная | Символ | Единица | Описание |
|-----------|--------|---------|---------|
| Температура насыщения | $T_{sat}$ | °C | Температура равновесия |
| Давление насыщения | $p_{sat}$ | кПа | Давление равновесия |
| Уд. объём жидкости | $v_f$ | м³/кг | Жидкая фаза, $x = 0$ |
| Уд. объём пара | $v_g$ | м³/кг | Паровая фаза, $x = 1$ |
| Энтальпия жидкости | $h_f$ | кДж/кг | Насыщ. жидкость |
| Теплота парообразования | $h_{fg}$ | кДж/кг | $h_g - h_f$ |
| Энтальпия пара | $h_g$ | кДж/кг | Насыщ. пар |
| Энтропия жидкости | $s_f$ | кДж/(кг·К) | Насыщ. жидкость |
| Энтропия парообразования | $s_{fg}$ | кДж/(кг·К) | $s_g - s_f$ |
| Энтропия пара | $s_g$ | кДж/(кг·К) | Насыщ. пар |
{{< /table >}}

### Таблицы перегретого пара

Таблицы перегретого пара (superheated vapor tables) организованы по давлению: для каждого фиксированного $p$ приводятся $v$, $h$, $s$ как функции температуры $T > T_{sat}(p)$. Применяются для расчёта состояния пара на входе и выходе компрессора.

### Таблицы переохлаждённой жидкости

Таблицы переохлаждённой (compressed) жидкости необходимы для точного расчёта энтальпии на выходе конденсатора при значительном переохлаждении. Ввиду малой сжимаемости жидкой фазы допустима аппроксимация:

{{< formula display="true" >}}
h(T, p) \approx h_f(T) + v_f(T) \cdot [p - p_{sat}(T)]
{{< /formula >}}

Для большинства инженерных расчётов поправочный член $v_f \cdot \Delta p$ не превышает 1 кДж/кг и пренебрегается.

## Методы интерполяции

### Одномерная линейная интерполяция

Для свойства $f$ при промежуточном значении аргумента $x$ между строками таблицы $x_1$ и $x_2$:

{{< formula display="true" >}}
f(x) = f_1 + \frac{x - x_1}{x_2 - x_1}(f_2 - f_1)
{{< /formula >}}

Точность линейной интерполяции: менее 0,5 % при шаге таблицы 5 К для $h$ и $s$.

### Логарифмическая интерполяция по давлению

Поскольку свойства хладагентов более линейны по $\ln p$, чем по $p$, для интерполяции по давлению рекомендуется:

{{< formula display="true" >}}
f(p) = f_1 + \frac{\ln p - \ln p_1}{\ln p_2 - \ln p_1}(f_2 - f_1)
{{< /formula >}}

Особенно актуально при больших диапазонах давлений (p₂/p₁ > 2).

### Двумерная интерполяция для таблиц перегрева

При произвольных $p$ и $T$ выполняется последовательная интерполяция:

**Шаг 1.** Интерполяция по $T$ при $p_1$ и $p_2$ (ближайших строках таблицы):

{{< formula display="true" >}}
f_{p_1} = f_{T_1,p_1} + \frac{T - T_1}{T_2 - T_1}(f_{T_2,p_1} - f_{T_1,p_1})
{{< /formula >}}

{{< formula display="true" >}}
f_{p_2} = f_{T_1,p_2} + \frac{T - T_1}{T_2 - T_1}(f_{T_2,p_2} - f_{T_1,p_2})
{{< /formula >}}

**Шаг 2.** Интерполяция по $\ln p$:

{{< formula display="true" >}}
f(T, p) = f_{p_1} + \frac{\ln p - \ln p_1}{\ln p_2 - \ln p_1}(f_{p_2} - f_{p_1})
{{< /formula >}}

### Расчёт свойств двухфазной смеси

Для двухфазной области (quality $x$, степень сухости пара):

{{< formula display="true" >}}
h = h_f + x \cdot h_{fg}, \quad s = s_f + x \cdot s_{fg}, \quad v = v_f + x \cdot v_{fg}
{{< /formula >}}

Качество определяется из уравнения:

{{< formula display="true" >}}
x = \frac{h - h_f}{h_{fg}} = \frac{s - s_f}{s_{fg}}
{{< /formula >}}

Качество должно находиться в диапазоне 0 ≤ $x$ ≤ 1; значение $x$ > 1 означает перегрев, $x$ < 0 — переохлаждение.

## Цифровые базы данных

### NIST REFPROP v10

REFPROP (Reference Fluid Thermodynamic and Transport Properties) — эталонная программа НИСТ (National Institute of Standards and Technology, США) для расчёта свойств чистых веществ и смесей. Реализует высокоточные уравнения состояния формы Гельмгольца:

{{< formula display="true" >}}
\alpha(\tau, \delta) = \alpha^0(\tau, \delta) + \alpha^r(\tau, \delta), \quad \tau = T_c/T, \quad \delta = \rho/\rho_c
{{< /formula >}}

Все термодинамические свойства вычисляются через частные производные $\alpha$:

{{< formula display="true" >}}
p = \rho R T \left(1 + \delta \frac{\partial \alpha^r}{\partial \delta}\right), \quad h = RT\left(\tau \frac{\partial \alpha}{\partial \tau} + \delta \frac{\partial \alpha}{\partial \delta} + 1\right)
{{< /formula >}}

Возможности REFPROP v10: более 150 чистых хладагентов; произвольные смеси с заданием состава; транспортные свойства (вязкость, теплопроводность); поверхностное натяжение; метастабильные состояния; оценки неопределённости.

### CoolProp

CoolProp — свободная библиотека с открытым исходным кодом, реализующая аналогичные уравнения состояния. Интерфейсы: Python, MATLAB, C++, Excel, JavaScript. Точность близка к REFPROP и достаточна для большинства инженерных расчётов.

## Численный пример: анализ четырёх точек цикла

**Условие.** Система на R-134a: $T_{evap}$ = 0 °C, перегрев 8 К, $T_{cond}$ = 40 °C, переохлаждение 5 К, $\eta_s$ = 0,78. Определить COP и удельную холодопроизводительность.

**Точка 1** — вход компрессора: $T_1$ = 0 + 8 = 8 °C, $p_1$ = 292,82 кПа.

По таблице перегрева при 200 кПа интерполируем на 8 °C (приближение, поскольку 292,82 ≠ 200; используем REFPROP):

{{< formula display="true" >}}
h_1 = 399{,}1 \text{ кДж/кг}, \quad s_1 = 1{,}728 \text{ кДж/(кг·К)}
{{< /formula >}}

**Точка 3** — выход конденсатора: $T_3$ = 40 − 5 = 35 °C, жидкость при $p_2$ = 1017,0 кПа:

{{< formula display="true" >}}
h_3 \approx h_f(35°C) \approx 243{,}6 \text{ кДж/кг} \quad \text{(линейная интерп. по таблице насыщения)}
{{< /formula >}}

**Точка 4** — после дросселя: $h_4$ = $h_3$ = 243,6 кДж/кг.

**Точка 2s** — изоэнтропный выход компрессора: $s_{2s}$ = 1,728 кДж/(кг·К), $p_2$ = 1017,0 кПа. По таблице перегрева при 800 кПа (ближайшее): интерполируя $s$ → $h_{2s}$ ≈ 434,0 кДж/кг. Поправка на разницу давлений 800→1017 кПа даёт $h_{2s}$ ≈ 431,5 кДж/кг.

**Работа компрессора:**

{{< formula display="true" >}}
w_{comp} = \frac{h_{2s} - h_1}{\eta_s} = \frac{431{,}5 - 399{,}1}{0{,}78} = \frac{32{,}4}{0{,}78} = 41{,}5 \text{ кДж/кг}
{{< /formula >}}

**Холодопроизводительность:**

{{< formula display="true" >}}
q_{evap} = h_1 - h_4 = 399{,}1 - 243{,}6 = 155{,}5 \text{ кДж/кг}
{{< /formula >}}

**COP:**

{{< formula display="true" >}}
COP = \frac{q_{evap}}{w_{comp}} = \frac{155{,}5}{41{,}5} = 3{,}75
{{< /formula >}}

## Практические рекомендации

1. **Определяйте область состояния** перед выбором таблицы: сравните $T$ с $T_{sat}(p)$ — если $T > T_{sat}$, используйте таблицы перегрева; если $T < T_{sat}$, то переохлаждённая жидкость.
2. **Для давлений и температур насыщения** — они зависимы. Задание обоих независимо означает двухфазное состояние с неопределённым качеством $x$ — уточняйте $x$.
3. **Рассчитывайте качество** из $x = (h - h_f)/h_{fg}$; при $x < 0$ или $x > 1$ — ошибка в начальном предположении.
4. **Согласуйте единицы**: таблицы ASHRAE — кПа, кДж/кг; полевые манометры — бар или psi; всегда пересчитывайте.
5. **Базовое состояние** для энтальпии и энтропии произвольно; разности между точками цикла не зависят от выбора базы — убедитесь, что все точки взяты из одной таблицы (одного источника).

## Стандарты и нормативные источники

- **NIST REFPROP v10** — эталонная база данных; уравнения состояния для более чем 150 хладагентов; рекомендована ASHRAE как основной инструмент.
- **ASHRAE Handbook — Fundamentals 2021, гл. 30** — полные таблицы насыщения и перегрева для основных хладагентов.
- **ASHRAE Handbook — Refrigeration 2022, гл. 2** — методология анализа циклов с использованием таблиц свойств.
- **ASHRAE 34-2022** — классификация хладагентов; диапазоны применения.
- **ISO 817:2014** — международный стандарт классификации и свойств хладагентов.
- **EN 378-1:2016** — безопасность холодильных систем; требования к диапазонам рабочих параметров.
- **ГОСТ 28547-2014** — хладагенты. Технические условия; нормы чистоты.
- **СП 60.13330.2022** — проектирование систем ОВК; нормативные параметры хладагентов.
