Теплофизические свойства пищевых продуктов зависят непосредственно от химического состава. Так как продукты представляют собой смеси воды, жира, белка, углеводов, клетчатки и золы, их теплофизические свойства можно прогнозировать из массовых долей и свойств отдельных компонентов.

## Массовые доли компонентов

Состав любого продукта удовлетворяет материальному балансу:

**X_w + X_f + X_p + X_c + X_a = 1.0**

Где:
- X_w = массовая доля воды (безразмерная)
- X_f = массовая доля жира (безразмерная)
- X_p = массовая доля белка (безразмерная)
- X_c = массовая доля углеводов (безразмерная)
- X_a = массовая доля золы (безразмерная)

Для расчётов ASHRAE клетчатка обычно объединяется с углеводами. Некоторые источники указывают общее содержание сухих веществ:

**X_s = X_f + X_p + X_c + X_a = 1 - X_w**

## Модели прогноза теплофизических свойств

### Удельная теплоёмкость выше точки замерзания

Для незамёрзших продуктов (T > T_f) удельная теплоёмкость рассчитывается как средневзвешенное значение:

**c_p = 4.19X_w + 1.55X_p + 1.68X_c + 1.42X_f + 0.84X_a**

Где c_p в кДж/(кг·К) при температурах выше начальной точки замерзания.

Это уравнение предполагает:
- Вода вносит 4.19 кДж/(кг·К)
- Белок вносит 1.55 кДж/(кг·К)
- Углеводы вносят 1.68 кДж/(кг·К)
- Жир вносит 1.42 кДж/(кг·К)
- Зола вносит 0.84 кДж/(кг·К)

### Удельная теплоёмкость ниже точки замерзания

Для замёрзших продуктов (T < T_f) удельная теплоёмкость включает эффект связанной воды, которая остаётся незамёрзшей:

**c_p = 1.55X_p + 1.68X_c + 1.42X_f + 0.84X_a + 2.05X_ice + 4.19X_uw**

Где:
- X_ice = массовая доля льда (замёрзшей воды)
- X_uw = массовая доля незамёрзшей воды (связанной воды)
- X_ice + X_uw = X_w

Удельная теплоёмкость льда составляет 2.05 кДж/(кг·К), значительно ниже чем у жидкой воды 4.19 кДж/(кг·К).

### Энтальпия выше точки замерзания

Энтальпия незамёрзшего продукта относительно эталона −40°C:

**H = 9.79 + 405X_w + c_p(T - T_ref)**

Где:
- H = энтальпия (кДж/кг)
- T = температура продукта (°C)
- T_ref = −40°C (эталонная температура)
- 9.79 = вклад энтальпии сухих веществ при −40°C
- 405 = энтальпия воды при 0°C относительно −40°C

Для практических приложений с эталоном 0°C:

**H = c_p × T**

### Энтальпия ниже точки замерзания

Для замёрзших продуктов энтальпия включает скрытую теплоту плавления:

**H = c_pf(T - T_f) - 335X_ice**

Где:
- c_pf = удельная теплоёмкость замёрзшего продукта
- T_f = начальная точка замерзания (°C)
- 335 = скрытая теплота плавления воды (кДж/кг)
- X_ice = доля воды, замёрзшей при температуре T

|-----------|-----------------------------------|--------------------------|------------------|
| Вода (жидкая) | 4.19 | 0.60 | 998 |
| Лёд | 2.05 | 2.22 | 917 |
| Белок | 1.55 | 0.18 | 1320 |
| Жир | 1.42 | 0.18 | 925 |
| Углеводы | 1.68 | 0.20 | 1550 |
| Клетчатка | 1.84 | 0.18 | 1300 |
| Зола (минералы) | 0.84 | 0.33 | 2420 |

## Прогноз теплопроводности

### Параллельная модель (верхний предел)

**k = k_wX_w + k_pX_p + k_cX_c + k_fX_f + k_aX_a**

Эта модель предполагает распространение тепла параллельно слоям компонентов.

### Последовательная модель (нижний предел)

**1/k = X_w/k_w + X_p/k_p + X_c/k_c + X_f/k_f + X_a/k_a**

Эта модель предполагает распространение тепла перпендикулярно слоям компонентов.

### Модель эффективной среды

Для большинства продуктов параллельная модель переоценивает, а последовательная модель недооценивает. ASHRAE рекомендует эмпирические модели:

**Незамёрзшие продукты:**
**k = 0.25 + 0.40X_w + 0.16X_f + 0.19X_p + 0.17X_c + 0.33X_a**

**Замёрзшие продукты:**
**k = 0.25 + 1.23X_ice + 0.40X_uw + 0.16X_f + 0.19X_p + 0.17X_c + 0.33X_a**

Обратите внимание на резкое увеличение теплопроводности при замерзании воды (теплопроводность льда = 2.22 Вт/м·К против 0.60 Вт/м·К для воды).

## Прогноз плотности

Плотность продукта можно оценить из плотностей компонентов, используя объёмное соотношение:

**1/ρ = X_w/ρ_w + X_p/ρ_p + X_c/ρ_c + X_f/ρ_f + X_a/ρ_a**

Где ρ — объёмная плотность в кг/м³.

Для замёрзших продуктов подставьте плотность льда (917 кг/м³) для доли замёрзшей воды:

**1/ρ_f = X_ice/ρ_ice + X_uw/ρ_w + X_p/ρ_p + X_c/ρ_c + X_f/ρ_f + X_a/ρ_a**

Пористость необходимо учитывать для продуктов с ячеистой структурой и воздушными промежутками:

**ρ_apparent = (1 - ε)ρ_solid**

Где ε = пористость (объёмная доля воздуха).

## Температуропроводность

Температуропроводность влияет на скорость изменения температуры во время охлаждения или замерзания:

**α = k/(ρc_p)**

Где:
- α = температуропроводность (м²/с)
- k = теплопроводность (Вт/м·К)
- ρ = плотность (кг/м³)
- c_p = удельная теплоёмкость (Дж/кг·К)

Типичные значения для продуктов:
- Продукты с высокой влажностью (незамёрзшие): 1.2–1.5 × 10⁻⁷ м²/с
- Продукты с высокой влажностью (замёрзшие): 8–10 × 10⁻⁷ м²/с
- Продукты с низкой влажностью: 1.0–1.2 × 10⁻⁷ м²/с
- Продукты с высоким содержанием жира: 0.8–1.0 × 10⁻⁷ м²/с

## Эффекты содержания воды

Содержание воды — доминирующий фактор, влияющий на теплофизические свойства продукта:

### Высокое содержание воды (>70% влажности)
- Высокая удельная теплоёмкость (>3.5 кДж/кг·К)
- Умеренная теплопроводность (0.45–0.55 Вт/м·К)
- Резкие изменения свойств при замерзании
- Большие требования скрытой теплоты
- Примеры: салат, огурцы, помидоры, нежирная рыба

### Умеренное содержание воды (40–70% влажности)
- Умеренная удельная теплоёмкость (2.5–3.5 кДж/кг·К)
- Переменная теплопроводность в зависимости от других компонентов
- Значительные эффекты замерзания
- Примеры: мясо, картофель, яблоки, морковь

### Низкое содержание воды (<40% влажности)
- Низкая удельная теплоёмкость (<2.5 кДж/кг·К)
- Низкая теплопроводность (<0.40 Вт/м·К)
- Минимальные эффекты замерзания
- Примеры: орехи, сухофрукты, сыр, хлебобулочные изделия

## Эффекты содержания жира

Жир имеет отличительные теплофизические характеристики:

1. **Более низкая удельная теплоёмкость**: 1.42 кДж/(кг·К) против 4.19 для воды
2. **Более низкая теплопроводность**: 0.18 Вт/м·К
3. **Отсутствие фазового переходу** в нормальном диапазоне холодильных температур
4. **Более низкая плотность**: 925 кг/м³

Продукты с высоким содержанием жира (>20% жира):
- Пониженные требования к охлаждению
- Более низкая теплопроводность
- Более однородные свойства в диапазоне температур
- Примеры: сливочное масло, сыр, жирное мясо, орехи

## Эффекты углеводов и белков

Эти компоненты имеют промежуточные свойства:

**Белок:**
- Удельная теплоёмкость: 1.55 кДж/(кг·К)
- Теплопроводность: 0.18 Вт/м·К
- Обычно в мясе (15–25%), рыбе (15–20%)

**Углеводы:**
- Удельная теплоёмкость: 1.68 кДж/(кг·К)
- Теплопроводность: 0.20 Вт/м·К
- Преобладают в зёрнах, фруктах, овощах

Соотношение белка к углеводам влияет на депрессию начальной точки замерзания через коллигативные свойства.

## Эффекты содержания золы

Содержание минералов (зола) имеет минимальный прямой тепловой эффект:

- Обычно <5% по массе в большинстве продуктов
- Удельная теплоёмкость: 0.84 кДж/(кг·К)
- Более высокая теплопроводность: 0.33 Вт/м·К
- Очень высокая плотность: 2420 кг/м³

Основное значение в депрессии точки замерзания и расчёте связанной воды.

## Процедура расчёта

Для расчётов холодильных нагрузок с использованием данных о составе:

**Шаг 1: Получение данных о составе**

Из базы данных USDA, спецификаций продуктов или лабораторного анализа:
- X_w (доля воды)
- X_f (доля жира)
- X_p (доля белка)
- X_c (доля углеводов)
- X_a (доля золы)

Проверка: X_w + X_f + X_p + X_c + X_a = 1.0

**Шаг 2: Расчёт удельной теплоёмкости**

Для незамёрзшего продукта:
c_p = 4.19X_w + 1.55X_p + 1.68X_c + 1.42X_f + 0.84X_a

**Шаг 3: Расчёт теплопроводности**

k = 0.25 + 0.40X_w + 0.16X_f + 0.19X_p + 0.17X_c + 0.33X_a

**Шаг 4: Расчёт плотности**

1/ρ = X_w/998 + X_p/1320 + X_c/1550 + X_f/925 + X_a/2420

**Шаг 5: Расчёт температуропроводности**

α = k/(ρc_p)

**Шаг 6: Для замёрзших продуктов**

Расчёт начальной точки замерзания:
T_f = −0.5X_s / X_w (упрощённое уравнение)

Определение доли льда при температуре хранения T:
X_ice ≈ X_w × (T_f − T) / (T_f + 1.8)

Пересчёт свойств с использованием долей льда и незамёрзшей воды.

## Пример расчёта: Говяжий фарш

Заданный состав (массовые доли):
- X_w = 0.60 (60% воды)
- X_p = 0.19 (19% белка)
- X_f = 0.20 (20% жира)
- X_c = 0.00 (0% углеводов)
- X_a = 0.01 (1% золы)

**Удельная теплоёмкость (незамёрзший):**
c_p = 4.19(0.60) + 1.55(0.19) + 1.68(0.00) + 1.42(0.20) + 0.84(0.01)
c_p = 2.514 + 0.295 + 0 + 0.284 + 0.008
**c_p = 3.10 кДж/(кг·К)**

**Теплопроводность (незамёрзший):**
k = 0.25 + 0.40(0.60) + 0.16(0.20) + 0.19(0.19) + 0.17(0.00) + 0.33(0.01)
k = 0.25 + 0.24 + 0.032 + 0.036 + 0 + 0.003
**k = 0.561 Вт/(м·К)**

**Плотность:**
1/ρ = 0.60/998 + 0.19/1320 + 0.00/1550 + 0.20/925 + 0.01/2420
1/ρ = 0.000601 + 0.000144 + 0 + 0.000216 + 0.000004
1/ρ = 0.000965
**ρ = 1036 кг/м³**

**Температуропроводность:**
α = 0.561 / (1036 × 3100)
**α = 1.75 × 10⁻⁷ м²/с**

Для холодильной нагрузки от 20°C до 2°C:
Q = m × c_p × ΔT = m × 3.10 × 18 = 55.8m кДж

Где m — масса в кг.

## Точность и ограничения

**Точность прогноза:**
- Удельная теплоёмкость: ±5% для большинства продуктов
- Теплопроводность: ±10–15% (зависит от структуры)
- Плотность: ±2–3%
- Энтальпия: ±5%

**Ограничения:**
1. Модели предполагают однородные смеси
2. Реальные продукты имеют ячеистую структуру и анизотропию
3. Содержание воздуха (пористость) не включено в основные модели
4. Температурная зависимость свойств компонентов упрощена
5. Эффекты связанной воды требуют дополнительных корреляций

**Улучшенная точность требует:**
- Экспериментального измерения для критичных приложений
- Учёта структуры продукта и пористости
- Температурозависимых корреляций свойств
- Рассмотрения истории обработки (повреждение замерзанием, обезвоживание)

## Приложения в проектировании холодильных систем

Понимание эффектов состава позволяет:

1. **Расчёты нагрузок для конкретных продуктов** без обширных данных о свойствах
2. **Прогноз времени охлаждения/замерзания** с использованием температуропроводности
3. **Оптимизацию условий хранения** на основе чувствительности свойств
4. **Анализ энергии** для различных смесей продуктов
5. **Контроль качества** через проверку свойств
