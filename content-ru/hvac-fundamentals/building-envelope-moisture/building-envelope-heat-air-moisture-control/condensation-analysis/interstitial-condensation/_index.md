Межслойная (интерстициальная) конденсация (interstitial condensation) возникает, когда водяной пар, диффундирующий сквозь ограждающую конструкцию, достигает слоя, где температура падает ниже точки росы местной паровоздушной смеси. Влага накапливается в скрытых зонах стен, кровель и перекрытий, оставаясь незамеченной до появления признаков биокоррозии, набухания или повреждения несущих элементов.

Нормативная основа анализа: ISO 13788 (метод Глазера), ISO 15026 / EN 15026 (нестационарное моделирование), ASHRAE 160, ASHRAE Fundamentals гл. 25, СП 50.13330.

## Физика диффузии пара

Поток водяного пара через слой материала подчиняется первому закону Фика (Fick's first law):

{{< formula display="true" >}}
g = \delta_p \cdot \frac{\Delta p}{\Delta x} \quad \text{[кг/(м²·с)]}
{{< /formula >}}

где δ\_p — коэффициент паропроницаемости материала, кг/(м·с·Па); Δp — разность парциального давления пара, Па; Δx — толщина слоя, м.

На практике используют эквивалентную диффузионную толщину (equivalent air layer thickness):

{{< formula display="true" >}}
s_d = \mu \cdot d \quad \text{[м]}
{{< /formula >}}

где μ — безразмерный коэффициент сопротивления паропроницанию (μ-value); d — толщина слоя, м. Суммарная диффузионная толщина конструкции S\_d = Σ s\_{d,k}.

Конденсация в точке x:

{{< formula display="true" >}}
p_v(x) \geq p_{\text{sat}}(T(x)) \implies \text{конденсация}
{{< /formula >}}

## Метод Глазера (ISO 13788)

Метод Глазера — установившийся диффузионный расчёт, применяемый помесячно с усреднёнными условиями. Он не учитывает капиллярный перенос, буферную ёмкость материалов и нестационарные эффекты, поэтому считается консервативным (пессимистическим) методом первого уровня. Для более точного анализа используют WUFI (EN 15026 / ISO 15026).

### Алгоритм расчёта

**Шаг 1. Исходные данные** для каждого месяца: T\_i, φ\_i, T\_e, φ\_e.

**Шаг 2. Профиль температур** (одномерный, установившийся):

{{< formula display="true" >}}
T_m = T_i - \frac{(T_i - T_e) \cdot \sum_{k=1}^{m} R_k}{R_{\text{total}}}
{{< /formula >}}

**Шаг 3. Профиль давления насыщенного пара** на каждой границе: p\_sat(T\_m) — по формуле Магнуса–Тетенса.

**Шаг 4. Профиль давления пара** (линейное распределение по диффузионной толщине):

{{< formula display="true" >}}
p_m = p_i - \frac{(p_i - p_e) \cdot \sum_{k=1}^{m} s_{d,k}}{S_d}
{{< /formula >}}

**Шаг 5. Проверка**: если p\_m > p\_sat(T\_m) — конденсация на границе m. Давление пара в плоскости конденсации фиксируется равным p\_sat(T\_m); профиль давления пересчитывается с учётом плоскости конденсации.

**Шаг 6. Скорость накопления влаги** в плоскости конденсации c:

{{< formula display="true" >}}
g_c = \frac{p_i - p_{\text{sat}}(T_c)}{S_{d,\text{внутр}} / \delta_0} - \frac{p_{\text{sat}}(T_c) - p_e}{S_{d,\text{нар}} / \delta_0} \quad \text{[г/(м²·с)]}
{{< /formula >}}

где δ\_0 = 1,85×10⁻¹⁰ кг/(м·с·Па) — паропроницаемость воздуха; S\_{d,внутр} и S\_{d,нар} — диффузионная толщина слоёв по обе стороны плоскости.

**Шаг 7. Ежемесячный баланс влаги:**

{{< formula display="true" >}}
\Delta m_k = g_c \cdot \tau_k \quad \text{[г/м²]}
{{< /formula >}}

**Шаг 8. Критерии приемлемости по ISO 13788:**
- Годовой баланс Σ Δm\_k ≤ 0 (влага за год не накапливается).
- Максимальное накопление за сезон конденсации Δm\_max ≤ 500 г/м².

## Численный пример: наружная стена в Москве

### Конструкция (снаружи → внутрь)

1. Штукатурка цементная: d = 20 мм, λ = 0,93 Вт/(м·K), μ = 25
2. Кирпич керамический: d = 510 мм, λ = 0,58 Вт/(м·K), μ = 10
3. Минераловатная плита: d = 100 мм, λ = 0,038 Вт/(м·K), μ = 1
4. Пароизоляция полиэтилен: d = 0,15 мм, μ = 100 000
5. Гипсокартон: d = 12,5 мм, λ = 0,21 Вт/(м·K), μ = 8

### Расчётные условия (январь, Москва, СП 131.13330)

T\_i = +20°C, φ\_i = 50% → p\_i = φ\_i · p\_sat(20°C) = 0,50 · 2338 = **1169 Па**

T\_e = −26°C, φ\_e = 84% → p\_e = 0,84 · p\_sat(−26°C) = 0,84 · 73 = **61 Па**

R\_si = 0,13 м²·K/Вт, R\_se = 0,04 м²·K/Вт.

### Тепловые сопротивления и температуры

{{< table title="Тепловые сопротивления и температуры на границах" >}}
| Граница | ΣR, м²·K/Вт | T, °C | p\_sat, Па |
|---|---|---|---|
| Внутр. поверхность (после R\_si) | 0,13 | 18,3 | 2104 |
| Штукатурка / кирпич | 0,152 | 18,0 | 2063 |
| Кирпич / минвата | 1,031 | 7,5 | 1037 |
| Минвата / полиэтилен | 3,663 | −22,4 | 89 |
| Полиэтилен / ГКЛ | 3,663 | −22,4 | 89 |
| ГКЛ / наружн. воздух | 3,723 | −23,1 | 82 |
| Наружная поверхность | 3,763 | −26,0 | 61 |
{{< /table >}}

R\_total = 3,763 м²·K/Вт.

### Диффузионные толщины и давления пара

{{< table title="Эквивалентные диффузионные толщины и давления пара" >}}
| Граница | Σs\_d, м | p\_v, Па | p\_sat, Па | Конденсация? |
|---|---|---|---|---|
| Внутр. поверхность | 0 | 1169 | 2104 | Нет |
| Штукатурка / кирпич | 0,5 | 1163 | 2063 | Нет |
| Кирпич / минвата | 5,6 | 1039 | 1037 | **На грани** |
| Минвата / полиэтилен | 5,7 | 1027 | 89 | **Да** |
| Полиэтилен / ГКЛ | 20,7 | 63 | 89 | Нет |
| ГКЛ / наружн. воздух | 20,8 | 62 | 82 | Нет |
{{< /table >}}

S\_d = 20,8 м (доминирует полиэтиленовая пароизоляция s\_d = 15 м).

### Вывод

На границе «минвата / полиэтилен» p\_v = 1027 Па >> p\_sat = 89 Па — интенсивная межслойная конденсация. Пароизоляция расположена неверно: она находится с холодной стороны теплоизоляции и задерживает влагу в толще конструкции.

**Решение:** переместить пароизоляцию на тёплую сторону (между кирпичом и минватой изнутри, или устроить её непосредственно за ГКЛ). После переноса s\_d,внутр >> S\_{d,нар} — поток пара к плоскости минваты многократно снижается.

Скорость конденсации при неправильном расположении (оценка):

{{< formula display="true" >}}
g_c \approx \frac{1169 - 89}{(5{,}7/\delta_0)} - \frac{89 - 61}{(15{,}1/\delta_0)} \approx 34 - 0{,}3 = 33{,}7\ \text{г/(м²·сут)}
{{< /formula >}}

За январь (31 сут): накопление ≈ 1045 г/м² — существенно превышает допустимый предел 500 г/м² по ISO 13788.

## Сезонный анализ и баланс влаги

Метод Глазера применяется для всех 12 месяцев. В «тёплые» месяцы (лето) направление диффузии меняется — наступает сезон высыхания (drying season). Годовой баланс:

{{< formula display="true" >}}
\sum_{k=1}^{12} \Delta m_k \leq 0
{{< /formula >}}

В случае положительного годового баланса влага накапливается от года к году — конструкция неприемлема.

## Стратегии проектирования

### Размещение пароизоляции по климатическим зонам

**Холодный климат (зоны 5–8 по ASHRAE, климат Москвы и севернее):** пароизоляция класса I–II — на тёплой (внутренней) стороне теплоизоляции. Обеспечивает s\_d,внутр >> s\_{d,нар}.

**Жаркий влажный климат (зоны 1–2):** пароизоляция изнутри не рекомендуется — возможна обратная диффузия летом. Применяют паропроницаемые внутренние материалы.

**Смешанный климат (зоны 3–4):** «умные» паробарьеры (variable permeance retarder) — меняют μ в зависимости от влажности. При φ < 50% μ-value высокий (зима, защита от диффузии изнутри), при φ > 70% — низкий (лето, высыхание).

### Непрерывная наружная изоляция

Добавление наружного слоя ЭППС или минваты повышает температуру на старой «холодной» границе, поднимая p\_sat выше p\_v. Правило: доля теплового сопротивления наружной изоляции R\_{нар} / R\_total должна обеспечивать T\_обшивка > T\_dp,внутр.

{{< formula display="true" >}}
\frac{R_{\text{нар}}}{R_{\text{total}}} \geq 1 - \frac{T_{\text{dp}} - T_e}{T_i - T_e}
{{< /formula >}}

### Вентилируемые полости

Вентилируемый зазор за облицовкой позволяет удалять влагу из конструкции конвективным потоком. Необходимый воздухообмен в полости:

{{< formula display="true" >}}
g_{\text{уд}} = Q_{\text{вент}} \cdot \Delta\omega \cdot \rho_{\text{возд}} \geq g_c
{{< /formula >}}

где Δω — разность влагосодержания воздуха в полости и наружного воздуха, г/кг.

## Нестационарное гигротермальное моделирование

Метод Глазера не учитывает:
- буферную ёмкость гигроскопических материалов;
- капиллярный перенос влаги;
- солнечную инсоляцию и суточные циклы;
- перенос влаги через воздушные утечки.

Для конструкций с высоким риском, нестандартными материалами или сложной геометрией применяют нестационарное моделирование (HAM — Heat, Air, Moisture transport) по EN 15026 / ISO 15026. Инструменты: WUFI Pro (Fraunhofer IBP), DELPHIN (Universität Dresden), HygIRC (NRC Canada).

Входные данные для HAM-модели: часовые климатические файлы (TMY / ASHRAE Climate Design Data), изотермы сорбции, кривые жидкостного переноса, начальные условия влажности в конструкции.

## Полевая верификация

**Инфракрасная термография (EN 13187):** выявляет тепловые аномалии — зоны потенциальной конденсации и тепловые мосты. Проводится при ΔT > 10°C между внутренним и наружным воздухом.

**Тест на воздухопроницаемость (EN 13829 / ASTM E779):** n₅₀ ≤ 3,0 ч⁻¹ для жилых зданий; ≤ 1,5 ч⁻¹ для пассивных домов. Герметичный контур воздухозащитного слоя критичен для предотвращения конвективного переноса влаги — он на порядки эффективнее пароизоляции.

**Датчики влажности в конструкции:** ёмкостные датчики RH или резистивные датчики влажности древесины (для W > 7%) устанавливают на критических границах (граница «тепло/холод»). Критерий: RH < 80% на границе в скользящем среднем за 30 сут по ASHRAE 160.
