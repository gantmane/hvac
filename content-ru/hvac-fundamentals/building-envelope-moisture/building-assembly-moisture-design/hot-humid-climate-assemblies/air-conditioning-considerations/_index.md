Системы кондиционирования в жарко-влажном климате создают специфические влажностные риски для ограждающих конструкций: охлаждённые внутренние поверхности притягивают водяной пар из горячего и влажного наружного воздуха. Этот механизм — «обратная диффузия пара» (inward vapour drive) — прямо противоположен зимней проблеме холодного климата. Неправильно спроектированная или завышенная по мощности система кондиционирования становится причиной конденсата, плесени и преждевременного разрушения конструкций.

Нормативная база: ASHRAE 160-2016, ASHRAE 55-2020, ASHRAE 62.1-2022, ASHRAE Fundamentals гл. 25–27, ISO 13788:2012.

## Физика процесса: движущая сила переноса пара

### Расчёт парциального давления пара

Давление насыщенного пара при температуре T (°C) по формуле Магнуса–Тетенса:

{{< formula display="true" >}}
P_{sat}(T) = 610{,}78 \cdot \exp\!\left(\frac{17{,}27\,T}{T + 237{,}3}\right) \quad \text{[Па]}
{{< /formula >}}

**Расчёт для типичных летних условий (Сочи / Хьюстон):**

Наружный воздух: T_o = 32 °C, RH_o = 75 %:

{{< formula display="true" >}}
P_{v,out} = 0{,}75 \times 610{,}78 \cdot \exp\!\left(\frac{17{,}27 \times 32}{32 + 237{,}3}\right) = 0{,}75 \times 4822 = 3616\ \text{Па}
{{< /formula >}}

Кондиционируемый воздух: T_i = 24 °C, RH_i = 50 %:

{{< formula display="true" >}}
P_{v,in} = 0{,}50 \times 610{,}78 \cdot \exp\!\left(\frac{17{,}27 \times 24}{24 + 237{,}3}\right) = 0{,}50 \times 2983 = 1492\ \text{Па}
{{< /formula >}}

{{< formula display="true" >}}
\Delta P_v = 3616 - 1492 = 2124\ \text{Па}
{{< /formula >}}

Перепад давлений пара 2124 Па направлен снаружи внутрь и создаёт постоянный диффузионный напор в течение 4–5 летних месяцев.

### Солнечная диффузия (solar-driven inward vapour drive)

При нагреве солнцем тёмной кирпичной или оштукатуренной стены её поверхностная температура достигает 50–65 °C. При этом влагосодержание в порах поверхностного слоя резко возрастает, создавая дополнительный напор пара внутрь — даже если наружный воздух относительно сух.

{{< formula display="true" >}}
T_{surface} = T_{amb} + \frac{\alpha \cdot I_{sol}}{h_o}
{{< /formula >}}

где α — коэффициент поглощения солнечного излучения (0,3–0,9); I_sol — плотность солнечного потока (Вт/м²); h_o — коэффициент теплоотдачи наружной поверхности (25 Вт/(м²·K)).

При T_amb = 32 °C, α = 0,8, I_sol = 600 Вт/м²: T_surface = 32 + 0,8 × 600 / 25 = **51,2 °C**. P_sat(51,2 °C) ≈ 13 000 Па — давление насыщенного пара на поверхности в 8,7 раза выше, чем в кондиционируемом интерьере.

## Температура внутренних поверхностей при кондиционировании

### Расчёт температуры внутренней поверхности стены

{{< formula display="true" >}}
q = \frac{T_o - T_i}{R_{total}}, \quad T_{si} = T_i + q \cdot R_{si}
{{< /formula >}}

где R_si = 0,12 (м²·K)/Вт для вертикальных поверхностей.

**Пример:** стена с R_total = 2,7 (м²·K)/Вт при T_o = 32 °C, T_i = 24 °C:

{{< formula display="true" >}}
q = \frac{32 - 24}{2{,}7} = 2{,}96\ \text{Вт/м}^2, \quad T_{si} = 24 + 2{,}96 \times 0{,}12 = 24{,}4\ °C
{{< /formula >}}

Точка росы при T_i = 24 °C, RH = 50 % составляет T_dp = 13 °C. Запас = 24,4 − 13 = **11,4 °C** — риска нет.

### Критические сценарии конденсации

{{< table title="Риск конденсации на внутренних поверхностях при кондиционировании" >}}
| Место | T поверхности, °C | T_dp внутри, °C | Риск |
|---|---|---|---|
| Типичная утеплённая стена | 23–24 | 13 | Низкий |
| Поверхность у диффузора воздухораспределения | 19–21 | 13 | Средний |
| Тепловой мост (стальная стойка) | 18–20 | 13 | Высокий |
| Неутеплённая бетонная балка | 17–19 | 13 | Высокий |
| Внутри конструкции (при паробарьере снаружи) | переменная | 27 (наружная T_dp) | Высокий |
{{< /table >}}

Критическая ситуация возникает при агрессивном охлаждении (T_i < 21 °C) или высокой внутренней RH > 60 %.

## Диффузия пара через конструкцию: расчёт профиля

По закону Фика диффузионный поток пара:

{{< formula display="true" >}}
g = \frac{\Delta P_v}{R_v} = \frac{\Delta P_v}{\sum_i \frac{d_i}{\mu_i}}
{{< /formula >}}

где d_i — толщина слоя (м), μ_i — коэффициент паропроницаемости (нг/(м·с·Па)).

**Профиль давления пара в стене** (изнутри → наружу при летних условиях):

{{< formula display="true" >}}
P_{v,x} = P_{v,i} + \frac{R_{v,x}}{R_{v,total}} \cdot (P_{v,o} - P_{v,i})
{{< /formula >}}

**Конденсация происходит в точке x, если температура T_x < T_dp,x** — температуры точки росы, соответствующей P_{v,x}.

**Пример расчёта для стены с внутренним ПЭ-паробарьером:**

Стена (снаружи → внутрь): кирпичная облицовка → воздушный зазор 25 мм → фанера 12 мм (R_v_fанеры = 0,027 Па·м²·с/нг) → стекловата 140 мм (R_v_ваты ≈ 0,003) → ПЭ-плёнка (R_v_ПЭ = 0,033) → ГКЛ 12,7 мм.

На внутренней грани фанеры (снаружи): P_v ≈ P_v,o − ΔP_v × R_v,наружн/R_v,total. При наличии ПЭ-барьера изнутри давление пара у фанеры стремится к наружному значению 3616 Па. Соответствующая T_dp = 27 °C. Температура фанеры = 24,25 °C < T_dp = 27 °C — **конденсация неизбежна**. Это главный аргумент против внутренних паробарьеров в жарко-влажном климате.

## Требования к классам паробарьеров (ASHRAE 160)

{{< table title="Классы паробарьеров по ASHRAE 160 и их применение в жарко-влажном климате" >}}
| Класс | Паропроницаемость | Материалы | Применение в КЗ 1–2 |
|---|---|---|---|
| I (непроницаемый) | ≤ 0,6 нг/(м²·с·Па) | ПЭ плёнка, фольга | Изнутри — неприемлемо |
| II (полунепроницаемый) | 0,6–6 нг/(м²·с·Па) | Крафт-бумага | Изнутри — только при высокой RH и анализе |
| III (полупроницаемый) | 6–60 нг/(м²·с·Па) | Латексная краска | Изнутри — допустимо |
| Проницаемый | > 60 нг/(м²·с·Па) | Неокрашенный ГКЛ | Изнутри — предпочтительно |
{{< /table >}}

**Вывод ASHRAE 160 для КЗ 1–2:** рекомендуется класс III или более проницаемый изнутри. Класс I изнутри создаёт ловушку влаги при летней обратной диффузии.

## Требования к осушению: расчёт нагрузок

### Полная нагрузка по удалению влаги

{{< formula display="true" >}}
\dot{m}_{total} = \dot{m}_{infil} + \dot{m}_{vent} + \dot{m}_{internal} + \dot{m}_{diff}
{{< /formula >}}

**1. Инфильтрация:** m_infil = ρ · Q_infil · (ω_o − ω_i), кг/ч

**2. Вентиляция:** m_vent = ρ · Q_vent · (ω_o − ω_i); при Q_vent = 47 л/с (дом 150 м²), ω_o = 0,0165 кг/кг, ω_i = 0,0093 кг/кг:

{{< formula display="true" >}}
\dot{m}_{vent} = 1{,}2 \times 0{,}169 \times (0{,}0165 - 0{,}0093) = 0{,}00146\ \text{кг/с} = 5{,}3\ \text{кг/ч}
{{< /formula >}}

**3. Внутренние источники:** жители 40–80 г/ч·чел.; приготовление пищи 600–1200 г/ч; ванна/душ 200–400 г/ч на событие.

**4. Диффузия через стены:** m_diff = A_wall · ΔP_v / R_v,total; для конструкции с R_v = 0,06 Па·м²·с/нг и площадью стен 200 м²: m_diff = 200 × 2124 / (0,06 × 10⁹) ≈ 0,007 кг/ч — незначительно при правильных конструкциях.

### Коэффициент чувствительного тепла (SHR)

{{< formula display="true" >}}
SHR = \frac{Q_{sens}}{Q_{sens} + Q_{lat}}
{{< /formula >}}

В жарко-влажном климате SHR здания = 0,65–0,75. Стандартный сплит-кондиционер: SHR = 0,70–0,80. Если SHR здания < SHR оборудования — оборудование не успевает осушать воздух, RH растёт.

**Оборудование с повышенным осушением:** SHR = 0,55–0,70; достигается снижением температуры испарителя или режимом работы на пониженной скорости вентилятора.

## Последствия завышенного оборудования

Завышенный по мощности кондиционер охлаждает помещение быстро и выключается — короткий цикл работы означает:

- Термостат достигает уставки раньше, чем змеевик успевает сконденсировать достаточно влаги
- После выключения конденсат со змеевика испаряется обратно в воздух
- RH в помещении 60–75 % при комфортной температуре — идеальные условия для плесени
- Частые пуски компрессора — повышенный износ и энергопотребление

**Правило:** оборудование не должно превышать расчётную нагрузку более чем на 15–25 %. Расчёт нагрузки по ASHRAE Manual J (для жилых зданий) или ASHRAE 90.1 (коммерческие) — не «на глаз».

## Стратегии осушения

**ERV (энтальпийный рекуператор):** восстанавливает чувствительную (60–80 %) и скрытую (50–70 %) теплоту; снижает нагрузку влаги от вентиляции на 50–70 %; обязателен при QV_vent > 20 л/с для жилых зданий.

**DOAS (выделенная система наружного воздуха):** отдельный воздухообрабатывающий агрегат обрабатывает 100 % наружного вентиляционного воздуха; осушает до точки росы 7–10 °C; подаёт нейтральный воздух; основные фанкойлы или VRF работают только со скрытой/явной нагрузкой помещения.

**VRF с режимом осушения:** инверторный компрессор работает на пониженной мощности с длинными циклами; SHR снижается до 0,60–0,65; совместим с многозональными системами.

**Переохлаждение + повторный нагрев:** охлаждение до 10–12 °C → удаление влаги → повторный нагрев до 15–18 °C электронагревателем или рекуперацией тепла конденсации. Высокая эффективность осушения при повышенных общих энергозатратах — применяется в музеях, архивах, чистых комнатах.

**Управление по RH:** комнатный термостат с интегрированным гигрометром поддерживает RH = 45–55 % как приоритет; при превышении RH включает осушение независимо от температуры.

|---|---|---|---|
| Жилое | 60 % | 45–55 % | 11,6–15,4 °C |
| Офисное | 60 % | 40–50 % | 10,0–13,0 °C |

## Интеграция с воздухораспределением

**Температура подаваемого воздуха:** 10–13 °C — высокая осушающая способность; 13–16 °C — меньше переохлаждения, экономия энергии. Оптимум зависит от SHR здания.

**Расположение диффузоров:** холодный воздух не должен направляться непосредственно на наружные стены и углы — локальное охлаждение поверхности ниже T_dp вызывает конденсат. Рекомендуется подача через потолочные щелевые диффузоры с горизонтальным броском.

**Воздухозаборники:** верхние воздухозаборники в кухнях и ванных перехватывают влажный воздух у источника; нижние воздухозаборники в жилых комнатах удаляют осевший влажный воздух.

## Утепление тепловых мостов

Тепловые мосты (стальные стойки, бетонные балки, алюминиевые рамы) создают локально холодные поверхности.

**Температура на стальной стойке** (R_steel = 0,18 (м²·K)/Вт в стене с R_total = 2,7):

{{< formula display="true" >}}
T_{steel,si} = T_i + (T_o - T_i) \cdot \frac{R_{si}}{R_{steel,total}} = 24 + 8 \times \frac{0{,}12}{0{,}30} = 27{,}2\ °C
{{< /formula >}}

27,2 °C > 13 °C — риска нет при стандартных условиях. Но при T_i = 20 °C (агрессивное охлаждение) и RH = 65 % (T_dp = 14,4 °C): T_steel,si = 20 + 12 × (0,12 / 0,30) = 24,8 °C — запас сокращается до 10 °C. При металлической балке без утепления R_beam = 0,09 (м²·K)/Вт: T_beam,si = 20 + 12 × (0,12 / 0,21) = 26,9 °C — всё ещё выше T_dp, но при более жёстких условиях риск возникает.

**Решение:** непрерывный наружный утеплитель — наиболее эффективный способ устранения всех тепловых мостов каркаса.

## Контроль соответствия ASHRAE 160

Критерий ASHRAE 160-2016 для ограждающих конструкций: вероятность роста плесени оценивается по гигротермической модели (WUFI, EnergyPlus, MOISTURE-EXPERT). Допустимо применение упрощённого метода при условии:

- RH поверхности < 80 % (30-дневное скользящее среднее)
- Наружный контроль паров с паропроницаемостью ≤ 6 нг/(м²·с·Па)
- Внутренняя отделка с паропроницаемостью ≥ 30 нг/(м²·с·Па)
- Система механического осушения поддерживает RH_i ≤ 55 %

Несоответствие любому из четырёх пунктов требует расчётного анализа WUFI.

## Практический чек-лист

**Проектирование:**
- Расчёт нагрузки ASHRAE Manual J / 90.1 — не оценочный метод
- SHR оборудования ≤ SHR здания + 0,05
- Без ПЭ-паробарьеров или облицовок с фольгой изнутри
- ERV при Q_vent > 20 л/с

**Строительство:**
- Проверить наружный контроль паров на непрерывность
- Изоляция воздуховодов R ≥ 1,4 (м²·K)/Вт
- Воздухопроницаемость оболочки < 2,4 ACH50 (испытание дверью-вентилятором)

**Эксплуатация:**
- Мониторинг RH — датчик в центре жилой зоны
- Уставка по RH 50 % (не только по температуре)
- Ежегодная проверка ERV и чистка теплообменника
