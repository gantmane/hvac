# Кровельные системы холодного климата

Кровля — наиболее уязвимый узел ограждающих конструкций в холодном климате. Через потолок проходит около 25–35 % тепловых потерь здания, а интенсивный восходящий поток тёплого влажного воздуха создаёт максимальный риск конденсации в кровельном пироге. Дополнительную сложность вносят ледяные плотины (ice dams) — следствие неравномерного прогрева кровельного покрытия снаружи. Правильное проектирование кровельной системы требует одновременного решения задач теплозащиты, воздухонепроницаемости и влагозащиты.

## Физика переноса влаги в кровле

Зимой при $T_i = 20$ °C / $\varphi_i = 50\%$ давление пара внутри $p_{vi} \approx 1169$ Па, снаружи при $T_e = -26$ °C (Москва) $p_{ve} \approx 62$ Па. Перепад $\Delta p_v = 1107$ Па — максимальная движущая сила для диффузии изнутри наружу.

Перенос влаги с утечками воздуха через отверстия в воздушном барьере:

{{< formula display="true" >}}
\dot{m}_v = \rho_a \cdot Q \cdot \Delta W = 1{,}2 \cdot Q \cdot (W_i - W_e), \quad \text{кг/с}
{{< /formula >}}

**Пример:** утечка $Q = 1$ л/с ($= 10^{-3}$ м³/с) при $W_i = 0{,}0072$ кг/кг и $W_e = 0{,}0003$ кг/кг за отопительный сезон $t = 5000$ ч:

{{< formula display="true" >}}
m_v = 1{,}2 \times 10^{-3} \times (0{,}0072 - 0{,}0003) \times 5000 \times 3600 \approx 149 \;\text{кг}
{{< /formula >}}

149 кг воды, попавших в кровельный пирог через одну щель — катастрофический объём. Вывод: **воздушная непроницаемость потолочного уровня критичнее пароизоляции**.

## Вентилируемая кровля (чердак)

### Принцип работы

Чердачное пространство вентилируется наружным воздухом. Температура воздуха на чердаке близка к наружной → кровельная обшивка не прогревается от тепла здания → снег не подтаивает снизу → ледяные плотины не образуются. Влага, проникающая с утечками воздуха, удаляется вентиляционным потоком.

### Требования к вентиляции чердака

По СП 50.13330.2020 (п. 8.8) и ASHRAE Handbook of Fundamentals:

{{< table title="Требования к вентиляционным проёмам чердака" >}}
| Параметр | СП 50.13330 | ASHRAE / IRC |
|---|---|---|
| Площадь вентпроёмов / площадь перекрытия | 1 / 500 | 1 / 150 (или 1 / 300 при 50/50 карниз / конёк) |
| Размещение проёмов | Карниз + конёк | Карниз + конёк (равномерно) |
| Высота вентзазора под покрытием | ≥ 50 мм | ≥ 25 мм |
| Защита от снегозаноса | Сетка ≤ 3 мм | Экранирование |
{{< /table >}}

### Конструкция вентилируемого чердака

**(снизу вверх):** потолочная отделка → пароизоляция ($s_d \geq 50$ м) → перекрытие → утеплитель (на перекрытии) → чердачное пространство (вентилируемое) → стропила → кровельная обшивка → гидроизоляционный подстилающий слой → кровельное покрытие.

|---|---|---|---|
| Москва | 4943 | 6,2 | 250 |
| Санкт-Петербург | 4682 | 6,0 | 240 |

### Пароизоляция чердачного перекрытия

Плёнка укладывается поверх несущих конструкций перекрытия до засыпки утеплителя. Нахлёст ≥ 200 мм, проклейка специализированной лентой. Все стыки с конструкциями стен, проходки воздуховодов и электропроводки герметизируются акустическим герметиком + лента.

**Недопустимо:** оставлять отверстия вокруг встроенных светильников типа «даунлайт» без специальных герметичных корпусов — каждый встроенный светильник без герметизации эквивалентен отверстию ~5 см² в воздушном барьере.

## Невентилируемая кровля (кондиционируемое чердачное пространство)

### Принцип работы

Теплоизоляция располагается у кровельной обшивки (по стропилам или непосредственно на обшивке). Чердачное пространство включается в тепловой контур здания. Кровельная обшивка остаётся холодной (близка к наружной температуре) — риск конденсации определяется соотношением $R_{rigid} / R_{total}$.

### Требование к доле твёрдой теплоизоляции

Для предотвращения конденсации на нижней грани кровельной обшивки:

{{< formula display="true" >}}
\frac{R_{rigid}}{R_{total}} \geq \frac{T_i - T_{dp,i}}{T_i - T_e}
{{< /formula >}}

**Пример (Москва):** $T_i = 20$ °C, $\varphi_i = 55\%$ → $T_{dp} = 10{,}7$ °C; $T_e = -26$ °C.

{{< formula display="true" >}}
\frac{R_{rigid}}{R_{total}} \geq \frac{20 - 10{,}7}{20 + 26} = \frac{9{,}3}{46} = 0{,}202
{{< /formula >}}

При $R_{total} = 8{,}0$ м²·К/Вт: $R_{rigid,min} = 0{,}202 \times 8{,}0 = 1{,}6$ м²·К/Вт → ЭППС ($\lambda = 0{,}033$): толщина ≥ 53 мм, принимаем 60 мм.

{{< table title="Минимальное R твёрдой изоляции у обшивки в невентилируемой кровле (холодный климат)" >}}
| Город | T_e, °С | R_rigid мин. при φ=55 %, м²·К/Вт | Толщина ЭППС λ=0,033, мм |
|---|---|---|---|
| Москва | –26 | 1,6 | 55 |
| Санкт-Петербург | –20 | 1,4 | 47 |
| Новосибирск | –37 | 1,9 | 63 |
| Екатеринбург | –34 | 1,8 | 59 |
{{< /table >}}

### Конструкции невентилируемой кровли

**Вариант А: Напыляемая ПУ-пена (SPF) по нижней грани стропил**

**(снаружи → внутрь):** покрытие → подстилающий слой → обшивка → стропила + ПУ-пена cc-SPF, $d \geq 120$ мм ($R \approx 6{,}0$ м²·К/Вт) → по необходимости дополнительная минвата между обрешёткой → потолочная отделка.

cc-SPF ($\mu \approx 50–100$) выполняет функции воздушного и парового барьера одновременно. Отдельная пароизоляционная плёнка не требуется.

**Вариант Б: Жёсткая теплоизоляция поверх стропил (тёплая кровля)**

**(снаружи → внутрь):** покрытие → подстилающий слой → контробрешётка (вентзазор) → кровельная обшивка → жёсткая пена (ЭППС или ПИР) ≥ $R_{rigid,min}$ → стропила + минвата → пароизоляция → потолок.

Жёсткая пена удерживает кровельную обшивку в тёплой зоне, что исключает конденсацию. Нижняя пароизоляция ограничивает диффузию из жилого пространства.

**Вариант В: Смешанная система (часть $R$ — жёсткая пена, часть — волокнистый утеплитель)**

Требование: $R_{SPF+rigid} / R_{total} \geq$ значению из таблицы выше. Минеральная вата в полости стропил — без замедлителя пара, жёсткая пена сверху — достаточный барьер.

## Предотвращение ледяных плотин

Ледяные плотины возникают, когда верхняя часть крыши нагревается теплом из здания (из-за недостаточной изоляции или утечек воздуха), снег подтаивает, вода стекает вниз к холодному карнизу и замерзает.

**Решение — две меры совместно:**

1. **Достаточная теплоизоляция** перекрытия/ската (по нормам выше) — устраняет тепловой поток снизу.
2. **Непрерывный воздушный барьер** на потолочном уровне — предотвращает тепловой поток утечками воздуха. Утечки воздуха переносят в 5–10 раз больше тепла, чем диффузия, и являются главной причиной образования плотин в хорошо изолированных домах.

**Дополнительные меры:** водозащитный подстилающий слой (ice and water shield) по СП 17.13330, ширина ≥ 600 мм от карниза; подогреваемый кабель в водостоке (временная мера, не устраняет причину).

## Гигротермический анализ кровли (пример, Санкт-Петербург)

Конструкция: невентилируемая кровля, ПИР 80 мм ($\lambda = 0{,}026$, $\mu = 150$) + минвата 200 мм ($\lambda = 0{,}036$, $\mu = 1$) + пароизоляция класса I снизу.

Параметры: $T_i = 20$ °C, $\varphi_i = 50\%$, $T_e = -20$ °C (январь СПб), $\varphi_e = 84\%$.

{{< formula display="true" >}}
T_{OSB} = 20 - 40 \times \frac{R_{in}}{R_{total}}
{{< /formula >}}

$R_{in} = 0{,}10 + 0{,}08 + 5{,}56 + 3{,}08 = 8{,}82$ м²·К/Вт; $R_{ПИР} = 0{,}08/0{,}026 = 3{,}08$ м²·К/Вт; $R_{total} = 8{,}82 + 3{,}08 = 11{,}90$ м²·К/Вт.

$T_{OSB} = 20 - 40 \times (8{,}82/11{,}90) = 20 - 29{,}6 = -9{,}6$ °C. Давление насыщения при $-9{,}6$ °C $\approx 293$ Па.

Паросопротивление: $s_{d,пл} = 50$ м $\gg$ $s_{d,минвата} = 0{,}2$ м $\ll$ $s_{d,ПИР} = 80 \times 0{,}15 \times 150/1000 = 1{,}8$ м. Пароизоляция берёт на себя >95 % перепада давления пара → $p_v$ у ПИР ≈ 13 Па $\ll p_{sat} = 293$ Па → **конденсация отсутствует**.

## Воздушный барьер кровли: требования и материалы

{{< table title="Материалы воздушного барьера на потолочном уровне" >}}
| Материал | Воздухопроницаемость при 75 Па | Применение |
|---|---|---|
| Полиэтиленовая плёнка 0,2 мм | < 0,02 л/(с·м²) | Основной барьер под утеплитель |
| Гипсокартон герметизированный | 0,1–0,2 л/(с·м²) | При наличии всех примыканий на герметике |
| cc-SPF ≥ 50 мм | < 0,01 л/(с·м²) | Монолитный барьер по стропилам |
| Самоклеящаяся мембрана | < 0,02 л/(с·м²) | Высококачественный вариант, сложные примыкания |
{{< /table >}}

**Критические точки герметизации:** примыкание потолка к стенам (верхняя обвязка), проходки воздуховодов, электрических кабелей, сантехники, встроенные светильники, проходы дымоходов.

## Нормативная база

- **СП 50.13330.2020** — тепловая защита зданий; нормируемые значения $R_{req}$ для перекрытий.
- **СП 17.13330.2017** — кровли; требования к конструктивным решениям.
- **СП 23-101-2004** — проектирование тепловой защиты; расчёт паропроницаемости.
- **ASHRAE Standard 160-2016** — критерии анализа влагозащиты.
- **ISO 13788:2012** — гигротермические характеристики: метод Глазера.
- **ISO 6946:2017** — тепловое сопротивление и теплопередача компонентов ограждения.
