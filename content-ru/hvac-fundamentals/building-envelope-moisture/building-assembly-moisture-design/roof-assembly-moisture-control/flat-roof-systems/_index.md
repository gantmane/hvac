Плоские и малоуклонные кровли (уклон менее 1:6, т.е. менее 9,5°) формируют уникальный класс задач управления влажностью. Ограниченный дренаж создаёт риск застоя воды; гидроизоляционная мембрана подвергается термическому циклированию; водяной пар может мигрировать как снизу вверх (зима), так и сверху вниз (лето в кондиционируемых зданиях). Правильная конструкция требует анализа парового напора, размещения пароизоляции и обеспечения потенциала высыхания.

## Классификация конструкций плоских кровель

### Традиционная конструкция (CRA)

Слои снизу вверх: несущее основание (железобетон, профнастил, дерево) → пароизоляция (при необходимости) → плитный утеплитель → защитная плита (при необходимости) → гидроизоляционная мембрана → балласт или покрытие.

Мембрана находится сверху утеплителя и подвергается полному термическому циклированию: летом поверхность битумной мембрана может нагреться до +80 °C, зимой — охладиться до −30 °C. Правильное положение пароизоляции критично для предотвращения межслойного конденсата.

### Инвертированная (защищённая) кровля PMR/IRMA

Слои снизу вверх: несущее основание → гидроизоляционная мембрана → утеплитель (только XPS) → дренажный слой → балласт (щебень, плиты, грунт).

Мембрана защищена от термических нагрузок и УФ — срок службы возрастает. Пароизоляция, как правило, не требуется: мембрана у тёплого основания не достигает точки росы. Основное ограничение — только XPS как утеплитель (закрытая пористость, устойчив к намоканию).

**Тепловая поправка для PMR.** Дождевая вода охлаждает утеплитель и смещает тепловую нейтральную ось. Эффективное тепловое сопротивление:

{{< formula display="true" >}}
R_\mathrm{eff} = R_\mathrm{nom} \times k_c, \quad k_c = 0{,}85 \div 0{,}90
{{< /formula >}}

По ASHRAE 90.1 при демонстрации соответствия нормативному R применяется R_eff, а не R_nom.

### Гибридная (компактная) конструкция

Утеплитель разделён между зонами ниже и выше мембраны. Мембрана работает при умеренных температурах; возможна установка пароизоляции (ниже мембраны) при необходимости.

{{< table title="Сравнение конструкций плоских кровель" >}}
| Параметр | Традиционная CRA | Инвертированная PMR | Гибридная |
|---|---|---|---|
| Пароизоляция | Требуется в холодном климате | Не требуется | По расчёту |
| Утеплитель | PIR, XPS, EPS, SPF | Только XPS | PIR ниже, XPS выше |
| Термоцикл мембраны | Полный | Минимальный | Снижен |
| Обнаружение протечек | Сложно | Относительно просто | Умеренно |
| Нагрузка на основание | Умеренная | Высокая (балласт) | Умеренная |
{{< /table >}}

## Пароизоляция: выбор и размещение

### Направление парового потока

Паровой поток сезонно меняет направление:

- **Зима (холодный климат):** давление пара внутри > снаружи → поток вверх (из помещения наружу) → риск конденсации на нижней поверхности холодной мембраны.
- **Лето (кондиционируемое здание):** давление пара снаружи > внутри → поток вниз → риск конденсации на несущем основании, если мембрана непроницаема.

### Критерий размещения пароизоляции: метод соотношения R

Для предотвращения конденсации на поверхности пароизоляции необходимо, чтобы она оставалась выше точки росы внутреннего воздуха. Требуемое соотношение термических сопротивлений:

{{< formula display="true" >}}
\frac{R_\mathrm{above}}{R_\mathrm{total}} > \frac{T_\mathrm{int} - T_{dp}}{T_\mathrm{int} - T_\mathrm{ext}}
{{< /formula >}}

**Числовой пример (Москва, расчётный январь):** T_int = 21 °C, ОВ = 50% → T_dp = 10 °C; T_ext = −26 °C; R_total = 5,3 м²·К/Вт.

{{< formula display="true" >}}
\frac{R_\mathrm{above}}{5{,}3} > \frac{21 - 10}{21 - (-26)} = \frac{11}{47} = 0{,}234
\quad \Rightarrow \quad R_\mathrm{above} > 1{,}24 \text{ м}^2\text{·К/Вт}
{{< /formula >}}

Пароизоляция должна располагаться так, чтобы выше неё (в сторону улицы) находилось не менее R = 1,24 м²·К/Вт утеплителя.

### Температура на произвольном интерфейсе

{{< formula display="true" >}}
T_i = T_\mathrm{ext} + \frac{R_i}{R_\mathrm{total}} \cdot (T_\mathrm{int} - T_\mathrm{ext})
{{< /formula >}}

где R_i — сумма тепловых сопротивлений от наружной поверхности до интерфейса i.

## Материалы утеплителей для плоских кровель

{{< table title="Характеристики утеплителей для плоских кровель" >}}
| Тип утеплителя | R на 25 мм, м²·К/Вт | Паропроницаемость, перм | Применимость |
|---|---|---|---|
| Полиизоциануратная плита (PIR) | 1,06–1,15 | 1–3 | CRA (не PMR) |
| XPS | 0,88 | 0,5–1,0 | CRA и PMR |
| EPS тип II | 0,70–0,74 | 2–4 | CRA (с защитной плитой) |
| Распыляемая ПУ-пена (SPF) | 1,06–1,15 | 0,4–0,8 | CRA (монолит) |
| Минеральная вата (жёсткая плита) | 0,44–0,53 | > 30 | CRA |
{{< /table >}}

**Примечание по PIR.** Тепловое сопротивление полиизоцианурата снижается при низких температурах. При расчётах для холодного климата применяют R = 0,70–0,88 м²·К/Вт на 25 мм вместо паспортного.

### Конусная (таpered) теплоизоляция

Конусная изоляция обеспечивает уклон не менее 2% (6,4 мм/м) к водосборным воронкам. Рекомендуемый уклон — 4% (12,7 мм/м) для критических зон.

Время дренажа воды (Manning):

{{< formula display="true" >}}
t = \frac{L \cdot n}{60 \cdot S^{0{,}5}}
{{< /formula >}}

где L — длина пути (м), n = 0,016 (для гладкой мембраны), S — уклон (м/м).

При L = 25 м, S = 0,02: t = (25 × 0,016) / (60 × 0,141) = 0,047 мин. Дренаж быстрый, застоя нет.

## Анализ межслойного конденсата (метод Глазера)

### Алгоритм

1. Построить температурный профиль через слои конструкции.
2. Рассчитать давление пара на каждом интерфейсе (линейная интерполяция по диффузионному сопротивлению).
3. Определить насыщенное давление пара при температуре каждого интерфейса.
4. Там, где фактическое давление пара > p_sat(T) — плоскость конденсации.

**Давление пара на интерфейсе i:**

{{< formula display="true" >}}
p_{v,i} = p_{v,\mathrm{int}} - \frac{Z_i}{Z_\mathrm{total}} \cdot (p_{v,\mathrm{int}} - p_{v,\mathrm{ext}})
{{< /formula >}}

где Z_i — диффузионное сопротивление от внутренней поверхности до интерфейса i (м²·ч·Па/мг по СП 23-101 или GPH·in по ASHRAE).

### Числовой пример: традиционная CRA кровля, Москва

**Условия:** T_int = 22 °C, ОВ 55% → p_v,int = 1 450 Па, T_dp = 12,5 °C; T_ext = −22 °C, ОВ 85% → p_v,ext = 92 Па.

**Конструкция (снизу вверх):**

| Слой | Толщина, мм | R, м²·К/Вт | Паропроницаемость, нг/(м²·с·Па) |
|---|---|---|---|
| ЖБ основание | 200 | 0,10 | 5 |
| Пароизоляция (полиэтилен) | 0,2 | 0 | 0,3 |
| PIR плита | 150 | 1,35 × 6 = 8,10 | 2 |
| Защитная плита (ЦСП) | 10 | 0,07 | 8 |
| Мембрана EPDM | 1,5 | 0 | 1,2 |

R_total = 0,10 + 8,10 + 0,07 + 0,17 (поверхности) = 8,44 м²·К/Вт.

Температура верхней поверхности PIR (под мембраной):

{{< formula display="true" >}}
T = -22 + \frac{0{,}17}{8{,}44} \times (22 - (-22)) = -22 + 0{,}89 = -21{,}1 \ ^\circ\mathrm{C}
{{< /formula >}}

Температура нижней поверхности PIR (над пароизоляцией):

{{< formula display="true" >}}
T = -22 + \frac{0{,}17 + 8{,}10}{8{,}44} \times 44 = -22 + 43{,}1 = +21{,}1 \ ^\circ\mathrm{C}
{{< /formula >}}

Пароизоляция на +21,1 °C — выше точки росы 12,5 °C. Конденсации нет. Пароизоляция расположена правильно.

**Если пароизоляцию убрать:** пар достигает PIR/мембрана-интерфейса при −21 °C. p_sat(−21 °C) ≈ 103 Па << p_v,int 1 450 Па → конденсация неизбежна.

## Дренаж и управление водой

### Расчёт пропускной способности водосборных воронок

{{< formula display="true" >}}
Q = \frac{A \cdot i}{1{,}73 \times 60}
{{< /formula >}}

где Q — расход (л/мин), A — площадь водосбора (м²), i — интенсивность дождя (мм/ч) для расчётного ливня (100-летний, 60-мин). Для Москвы i ≈ 80–100 мм/ч.

**Пример:** площадь 500 м², i = 90 мм/ч:

{{< formula display="true" >}}
Q = \frac{500 \times 90}{1{,}73 \times 60} = \frac{45\,000}{103{,}8} = 433 \text{ л/мин}
{{< /formula >}}

Типичная кровельная воронка DN100 обеспечивает 200–300 л/мин → необходимо 2 воронки или DN150.

### Аварийный (резервный) дренаж

Обязателен при наличии парапетов и внутренней дренажной системы. Переливной борт размещается на 50 мм выше входа основной воронки. Пропускная способность — не менее основной системы. Вариант: стоки в стенке парапета, ширина b:

{{< formula display="true" >}}
b = \frac{Q}{2{,}5 \cdot H^{0{,}5}}
{{< /formula >}}

где H = 100 мм (расчётный напор), Q в л/мин.

## Лучшие практики и контроль качества

### Детали проходок и примыканий

- Высота напускной части (фартука) ≥ 200 мм от поверхности кровли (СП 17.13330).
- Примыкание к парапету: мембрана заведена на стену ≥ 250 мм с механическим креплением и герметиком.
- Проходки оборудования: заводские патрубки с конусным основанием; поддоны под оборудованием подняты выше отметки мембраны.
- Угловые галтели (fillets) радиусом ≥ 50 мм в зонах примыканий для предотвращения расслоения мембраны.

### Контроль качества при монтаже

- Влагосодержание несущего основания перед укладкой: ≤ 4% для бетона, ≤ 15% для деревянного основания.
- Испытание сварных швов: зондирование 100% швов, разрушающий тест на отрыв на каждые 150 м² (усилие ≥ 45 Н/25 мм).
- Электронное обнаружение протечек (Electronic Leak Detection, ELD) по ASTM D7877 — рекомендуется для инвертированных кровель и зелёных крыш.
- Инфракрасная термография после первого отопительного сезона: выявляет зоны влажного утеплителя.
