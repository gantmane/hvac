Материалы кладки (masonry materials) образуют критически важную категорию компонентов строительной оболочки. Их характеристики — высокая тепловая масса, переменная теплопроводность и выраженная чувствительность к влаге — непосредственно влияют на теплопотери, расчёт нагрузок HVAC и долгосрочную энергоэффективность здания. К материалам кладки относятся кирпич, бетон нормального и лёгкого класса, бетонные блоки (CMU, concrete masonry unit), природный камень, цементный раствор и штукатурка.

## Законы теплопроводности и влияние влаги

Теплопроводность (k, Вт/м·К) определяет плотность стационарного теплового потока через однородный материал согласно закону Фурье:

{{< formula display="true" >}}
q = -k \, A \, \frac{\mathrm{d}T}{\mathrm{d}x}
{{< /formula >}}

где q — тепловой поток (Вт), A — площадь поперечного сечения (м²), dT/dx — градиент температуры (К/м).

Влага принципиально меняет теплопроводность кладки: теплопроводность воды (~0,60 Вт/м·К) примерно в 25 раз превышает теплопроводность воздуха (~0,025 Вт/м·К). Проникновение влаги в пористые структуры увеличивает k тем значительнее, чем выше пористость материала.

## Кирпичные материалы

### Рядовой кирпич (строительный)

Рядовой кирпич производится преимущественно для конструктивных целей. По сравнению с лицевым он имеет меньшую плотность и более высокую пористость.

{{< table title="Теплофизические свойства рядового кирпича" >}}
| Свойство | Значение | Условия |
|---|---|---|
| Теплопроводность k | 0,40–0,70 Вт/м·К | Сухие условия |
| Плотность ρ | 1 600–1 920 кг/м³ | — |
| Удельная теплоёмкость c | 840–920 Дж/кг·К | При 20 °C |
| Температуропроводность α | 0,30–0,45 × 10⁻⁶ м²/с | Сухой |
| Водопоглощение | 10–15 % по массе | При насыщении |
{{< /table >}}

При содержании влаги 5 % по объёму теплопроводность возрастает на 30–50 %; при насыщении (15–20 % по объёму) значение k удваивается.

**Конструктивные соображения:**
- Применяется в многослойных стеновых системах с обязательным воздушным зазором и дренажом.
- Растворные швы (7–15 % площади стены) создают тепловые мосты.
- Тепловое запаздывание стены 200 мм — 6–10 часов.

### Лицевой кирпич

Производится с жёстким контролем плотности и низкой пористостью для наружных фасадов.

{{< table title="Теплофизические свойства лицевого кирпича" >}}
| Свойство | Значение |
|---|---|
| Теплопроводность k | 1,20–1,40 Вт/м·К |
| Плотность ρ | 2 000–2 240 кг/м³ |
| Удельная теплоёмкость c | 900–1 000 Дж/кг·К |
| Водопоглощение | 3–8 % по массе |
{{< /table >}}

Более высокая k требует дополнительной изоляции в климатических зонах 4 и выше по классификации ASHRAE Standard 90.1.

## Бетонные материалы

### Бетон нормального веса

Состоит из портландцемента, воды, песка и крупного заполнителя (гравий, щебень). Теплопроводность существенно зависит от типа заполнителя.

{{< table title="Теплопроводность бетона в зависимости от заполнителя (ASHRAE Handbook Fundamentals, Ch. 26)" >}}
| Заполнитель | k, Вт/м·К | Плотность, кг/м³ |
|---|---|---|
| Известняк | 1,40–1,70 | 2 240–2 320 |
| Гранит | 1,90–2,20 | 2 320–2 400 |
| Песчаник | 1,30–1,60 | 2 160–2 240 |
| Базальт | 1,70–2,00 | 2 320–2 400 |
{{< /table >}}

Удельная теплоёмкость бетона нормального веса — 880–1 050 Дж/кг·К. Каждый прирост содержания влаги на 1 % повышает k приблизительно на 5–8 %.

### Лёгкий бетон

В качестве заполнителя используют керамзит, расширенный сланец, шлак. Меньшая плотность снижает теплопроводность при сохранении конструктивной несущей способности.

{{< table title="Зависимость теплопроводности лёгкого бетона от плотности" >}}
| Плотность, кг/м³ | k, Вт/м·К | Типичное применение |
|---|---|---|
| 1 440 | 0,40–0,50 | Неконструктивный изолирующий бетон |
| 1 600 | 0,55–0,70 | Кровельные плиты |
| 1 760 | 0,70–0,85 | Конструктивный лёгкий бетон |
| 1 920 | 0,85–1,00 | Высокопрочный лёгкий бетон |
{{< /table >}}

Преимущества: масса на 20–30 % меньше, чем у бетона нормального веса; пониженные тепловые мосты через конструктивные элементы. Ограничения: стоимость на 15–25 % выше; меньшая тепловая масса снижает эффективность пассивного охлаждения.

## Бетонные блоки CMU

Бетонный блок (CMU) — универсальный конструктивный материал. Воздушные ядра существенно влияют на теплопроизводительность.

{{< table title="Сравнение теплопроизводительности вариантов CMU (блок 200 мм)" >}}
| Конфигурация | k эфф., Вт/м·К | Плотность, кг/м³ | R-значение, м²·К/Вт |
|---|---|---|---|
| Полностью залитый раствором | 0,90–1,20 | 2 080–2 240 | 0,14–0,18 |
| Пустотелый (незаполненные ядра) | 0,60–0,80 | 1 440–1 600 | 0,26–0,35 |
| Вставки EPS | — | — | 0,88–1,23 |
| Заполнение перлитом | — | — | 0,53–0,70 |
| Заполнение вермикулитом | — | — | 0,44–0,62 |
{{< /table >}}

Перемычки CMU создают тепловые мосты: стандартная двухперемычечная конструкция — 25–30 % теплового мостостроения; применение вставок EPS снижает потери через перемычки на 40–60 %.

### Влияние влаги на CMU

{{< table title="Теплопроводность CMU при различном содержании влаги" >}}
| Содержание влаги | Увеличение k | Эксплуатационное состояние |
|---|---|---|
| 0 % (печная сушка) | Базовое | Расчётное |
| 2–4 % (равновесие) | +15–25 % | Нормальное |
| 6–8 % (влажный климат) | +35–50 % | Требует дренажа |
| 10–15 % (насыщение) | +75–100 % | Аварийное |
{{< /table >}}

Растворные швы составляют 7–15 % площади стены и создают тепловые мосты. Раствор типа N (меньше цемента) имеет меньшую k, чем раствор типа S.

## Тепловая масса и временной сдвиг нагрузок

Тепловая масса кладки характеризуется объёмной теплоёмкостью (volumetric heat capacity) ρ·c:

{{< table title="Объёмная теплоёмкость материалов кладки" >}}
| Материал | ρ·c, МДж/м³·К | Класс тепловой массы |
|---|---|---|
| Рядовой кирпич | 1,34–1,77 | Высокий |
| Лицевой кирпич | 1,80–2,24 | Очень высокий |
| Бетон нормального веса | 1,97–2,52 | Очень высокий |
| Лёгкий бетон | 1,21–1,92 | Умеренный–высокий |
| CMU (залит раствором) | 1,75–2,24 | Высокий |
| CMU (пустотелый) | 1,21–1,34 | Умеренный |
| Природный камень | 2,03–2,50 | Очень высокий |
{{< /table >}}

Тепловая постоянная времени стены:

{{< formula display="true" >}}
\tau = \frac{\rho \, c \, L^2}{k}
{{< /formula >}}

Для стены 200 мм из кладки τ составляет 6–14 часов, что обеспечивает смещение пиковой охлаждающей нагрузки на 4–12 часов и снижение пика на 20–40 % (ASHRAE Handbook Fundamentals, Ch. 18).

## Числовой пример: расчёт эффективного R-значения стены CMU 200 мм

Стена состоит из трёх параллельных тепловых путей: ядро CMU (60 % площади), перемычки CMU (25 %), растворные швы (15 %).

Данные:
- R ядра (EPS-вставка) = 1,76 м²·К/Вт
- R перемычки = 0,18 м²·К/Вт
- R раствора = 0,14 м²·К/Вт

По методу параллельных путей:

{{< formula display="true" >}}
U_{\text{эфф}} = \frac{A_1}{R_1} + \frac{A_2}{R_2} + \frac{A_3}{R_3}
= \frac{0{,}60}{1{,}76} + \frac{0{,}25}{0{,}18} + \frac{0{,}15}{0{,}14}
= 0{,}341 + 1{,}389 + 1{,}071 = 2{,}801 \; \text{Вт/(м}^2\text{·К)}
{{< /formula >}}

{{< formula display="true" >}}
R_{\text{эфф}} = \frac{1}{U_{\text{эфф}}} = \frac{1}{2{,}801} \approx 0{,}36 \; \text{м}^2\text{·К/Вт}
{{< /formula >}}

Эффективное R-значение почти в 5 раз ниже, чем R ядра, — тепловое мостостроение через перемычки и раствор доминирует. Вывод: непрерывная наружная изоляция обязательна для соответствия требованиям ASHRAE 90.1 в климатических зонах 4–8.

## Управление влагой в ограждающих конструкциях из кладки

Материалы кладки реализуют следующие механизмы переноса влаги:
1. **Капиллярный подсос** — доминирующий механизм для пористых материалов.
2. **Диффузия водяного пара** — вторичный механизм во внутренних условиях.
3. **Конденсация на поверхности** — при падении температуры поверхности ниже точки росы.
4. **Внутристеновая конденсация** — при неправильном размещении пароизоляции.

Критическое влагосодержание, выше которого теплопроизводительность резко снижается (IAPWS-IF97; ASHRAE Handbook Fundamentals, Ch. 26):

{{< table title="Критическое содержание влаги материалов кладки" >}}
| Материал | Критическое MC, % по массе | Рост k при критическом MC |
|---|---|---|
| Рядовой кирпич | 5–8 | +40–60 % |
| Лицевой кирпич | 3–5 | +30–45 % |
| Бетон | 4–6 | +35–50 % |
| CMU | 6–10 | +50–75 % |
| Известняк | 2–4 | +25–40 % |
{{< /table >}}

**Ключевые стратегии контроля влаги:**
- Полость 50–100 мм с дренажными отверстиями снижает миграцию влаги во внутренний слой на 80–95 %.
- Наружная изоляция поддерживает массивную стену выше точки росы и исключает тепловое мостостроение.
- Пароизоляция устанавливается на тёплой стороне; в климатических зонах 6–8 требуется плёнка ПЭ.
- Дренажная плоскость за облицовкой снижает влажность кладки на 50–70 %.

## Риск конденсации на внутренней поверхности стены

Температура внутренней поверхности:

{{< formula display="true" >}}
T_{\text{пов}} = T_{\text{вн}} - \frac{T_{\text{вн}} - T_{\text{нар}}}{R_{\text{общ}} \cdot h_i}
{{< /formula >}}

где h_i = 8,3 Вт/м²·К (коэффициент теплоотдачи внутренней поверхности вертикальных стен, ASHRAE Handbook Fundamentals, Ch. 26).

Если T_пов < T_точки_росы при расчётных условиях — риск образования конденсата и плесени; требуется дополнительная изоляция.

## Контроль качества при строительстве

Критические параметры, требующие полевой проверки:
- Толщина растворного шва: 9,5–12,7 мм.
- Процент заполнения ядер CMU раствором (при необходимости).
- Непрерывность изоляции на проходках (pipes, ducts).
- Шаг дренажных отверстий: 610–810 мм по оси.

Частые дефекты:
- Неполные растворные швы — снижение R на 10–20 %.
- Влажная кладка в оболочке — рост теплопотерь на 30–60 % до высыхания.
- Отсутствие дренажной плоскости — хроническое накопление влаги.
