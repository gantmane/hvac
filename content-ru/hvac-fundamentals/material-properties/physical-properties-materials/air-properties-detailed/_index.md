Воздух — основной рабочий теплоноситель в системах вентиляции и кондиционирования. Его термофизические свойства входят в расчёты числа Рейнольдса, коэффициентов конвективной теплоотдачи, потерь давления в воздуховодах и производительности вентиляторов. Все свойства зависят от температуры; плотность и кинематическая вязкость дополнительно зависят от давления и высоты над уровнем моря.

## Стандартные условия и уравнение состояния

Сухой воздух в рабочем диапазоне HVAC (−40 °C…+100 °C, p ≤ 0,5 МПа) описывается уравнением состояния идеального газа с погрешностью менее 0,1%:

{{< formula display="true" >}}
\rho = \frac{p}{R_{уд}\, T}, \quad R_{уд} = 287{,}05\ \text{Дж/(кг·К)}, \quad T\ \text{в К}
{{< /formula >}}

**Стандартный воздух ASHRAE:** T = 20 °C, p = 101 325 Па, ρ = 1,204 кг/м³, φ = 0% (сухой).

На больших высотах давление снижается по барометрической формуле:

{{< formula display="true" >}}
p(H) = 101{,}325 \cdot \exp\!\left(-\frac{H}{8434}\right) \text{ кПа}
{{< /formula >}}

где H — высота над уровнем моря, м. На H = 1 500 м: p ≈ 84,6 кПа, ρ ≈ 1,004 кг/м³ — на 17% ниже уровня моря. Это напрямую снижает холодопроизводительность и генерацию давления вентилятором.

## Плотность

Плотность воздуха уменьшается с ростом температуры (тепловое расширение) и ростом высоты (падение давления). При p = 101 325 Па:

{{< table title="Плотность сухого воздуха при p = 101 325 Па" >}}
| T, °C | T, К | ρ, кг/м³ |
|-------|------|----------|
| −40 | 233,2 | 1,514 |
| −20 | 253,2 | 1,395 |
| 0 | 273,2 | 1,293 |
| 10 | 283,2 | 1,247 |
| 20 | 293,2 | 1,204 |
| 30 | 303,2 | 1,165 |
| 40 | 313,2 | 1,128 |
| 60 | 333,2 | 1,060 |
| 80 | 353,2 | 1,000 |
| 100 | 373,2 | 0,946 |
{{< /table >}}

Скорость изменения: −0,34% на 1 °C вблизи 20 °C. Повышение температуры на 20 °C снижает ρ на 6,8% — пропорционально уменьшается статическое давление вентилятора и потери на трение при том же объёмном расходе.

**Пример — плотность воздуха на высоте 2 000 м, T = 25 °C:**
p = 101 325 · exp(−2000/8434) = 101 325 · 0,787 = 79 742 Па
ρ = 79 742 / (287,05 · 298,15) = 0,932 кг/м³ — на 22,6% ниже стандартного.

## Динамическая вязкость

Динамическая вязкость (dynamic viscosity) μ газа возрастает с температурой — в отличие от жидкостей — вследствие увеличения частоты и интенсивности межмолекулярных столкновений.

Формула Сазерленда (Sutherland, 1893):

{{< formula display="true" >}}
\mu(T) = \mu_0 \left(\frac{T}{T_0}\right)^{3/2} \frac{T_0 + S}{T + S}
{{< /formula >}}

где μ₀ = 1,716 × 10⁻⁵ Па·с при T₀ = 273,15 К, S = 110,4 К — константа Сазерленда для воздуха. Погрешность < 0,5% в диапазоне −60…+300 °C.

{{< table title="Динамическая и кинематическая вязкость воздуха при p = 101 325 Па" >}}
| T, °C | μ, мкПа·с | ν = μ/ρ, мм²/с |
|-------|-----------|----------------|
| −40 | 15,17 | 10,02 |
| −20 | 16,18 | 11,61 |
| 0 | 17,16 | 13,27 |
| 20 | 18,13 | 15,06 |
| 40 | 19,08 | 16,92 |
| 60 | 20,01 | 18,89 |
| 80 | 20,92 | 20,92 |
| 100 | 21,81 | 23,05 |
{{< /table >}}

Кинематическая вязкость ν = μ/ρ используется непосредственно в числе Рейнольдса Re = V·D/ν. При нагреве воздуха от 20 °C до 80 °C ν возрастает на 39% — значительный рост при расчёте Re и коэффициентов теплоотдачи в горячих воздуховодах.

## Теплопроводность

Теплопроводность (thermal conductivity) воздуха мала (λ ≈ 0,026 Вт/(м·К) при 20 °C), поэтому неподвижный воздух является хорошим теплоизолятором. Эффективная теплопередача достигается только за счёт вынужденной конвекции.

Степенная аппроксимация (погрешность < 1% при −40…+200 °C):

{{< formula display="true" >}}
\lambda(T) = 2{,}42 \times 10^{-2} \left(\frac{T}{293{,}15}\right)^{0{,}82}\ \text{Вт/(м·К)}
{{< /formula >}}

{{< table title="Теплопроводность воздуха при p = 101 325 Па" >}}
| T, °C | λ, мВт/(м·К) |
|-------|--------------|
| −40 | 20,9 |
| −20 | 22,3 |
| 0 | 23,7 |
| 20 | 25,1 |
| 40 | 26,6 |
| 60 | 28,0 |
| 80 | 29,4 |
| 100 | 30,7 |
{{< /table >}}

Источник: ASHRAE Handbook Fundamentals 2021, гл. 33.

## Удельная теплоёмкость

Удельная изобарная теплоёмкость (specific heat at constant pressure) c_p воздуха практически постоянна в диапазоне температур HVAC:

{{< table title="Удельная теплоёмкость сухого воздуха" >}}
| T, °C | c_p, Дж/(кг·К) |
|-------|----------------|
| −40 | 1 005 |
| 0 | 1 005 |
| 20 | 1 006 |
| 60 | 1 009 |
| 100 | 1 012 |
| 200 | 1 025 |
{{< /table >}}

Для инженерных расчётов HVAC принимают c_p = 1 005 Дж/(кг·К) = 1,005 кДж/(кг·К).

**Расчёт чувствительного тепла:**

{{< formula display="true" >}}
\dot{Q} = \dot{m}\, c_p\, \Delta T \approx 1{,}2\, \dot{V}\, \Delta T\ \text{ [кВт, м³/с, К]}
{{< /formula >}}

Коэффициент 1,2 = ρ · c_p = 1,204 · 1,005 / 1 000 = 1,210 Вт·с/(м³·К). Для воздуха 30 °C: 1,165 · 1,006 / 1 000 = 1,172 — снижение на 3% по сравнению со стандартом.

**Пример:** Кондиционер подаёт V̇ = 5 000 м³/ч = 1,389 м³/с воздуха при T_в = 26 °C, T_пр = 13 °C.
Q_чувст = 1,204 · 1,006 · 1,389 · (26 − 13) = 1,212 · 1,389 · 13 = 21,9 кВт.

## Число Прандтля

Число Прандтля (Prandtl number) Pr — безразмерное соотношение вязкостной и тепловой диффузий:

{{< formula display="true" >}}
\mathrm{Pr} = \frac{\mu \, c_p}{\lambda} = \frac{\nu}{a}
{{< /formula >}}

где a = λ/(ρ c_p) — тепловая диффузия. Для воздуха Pr ≈ 0,71 во всём диапазоне HVAC — вязкостный и тепловой пограничные слои развиваются с практически одинаковой скоростью.

{{< table title="Число Прандтля воздуха при p = 101 325 Па" >}}
| T, °C | μ, мкПа·с | c_p, Дж/(кг·К) | λ, мВт/(м·К) | Pr |
|-------|-----------|-----------------|---------------|----|
| −20 | 16,18 | 1 005 | 22,3 | 0,729 |
| 0 | 17,16 | 1 005 | 23,7 | 0,728 |
| 20 | 18,13 | 1 006 | 25,1 | 0,727 |
| 40 | 19,08 | 1 007 | 26,6 | 0,723 |
| 60 | 20,01 | 1 009 | 28,0 | 0,721 |
| 100 | 21,81 | 1 012 | 30,7 | 0,718 |
{{< /table >}}

Постоянство Pr = 0,71–0,73 означает, что в корреляциях вида Nu = C·Re^m·Pr^n член Pr^n = const и включается в коэффициент C. Для труб (Dittus–Boelter): Nu = 0,023·Re^0,8·Pr^0,4 → при Pr = 0,71: Nu ≈ 0,0195·Re^0,8.

## Влияние влажности

Водяной пар (M = 18,015 г/моль) легче сухого воздуха (M = 28,965 г/моль), поэтому влажный воздух менее плотный.

**Плотность влажного воздуха:**

{{< formula display="true" >}}
\rho_{вл} = \frac{p}{R_{уд,сух}\,T} \cdot \frac{1}{1 + 0{,}6078\, x_v}
{{< /formula >}}

где x_v — мольная доля водяного пара = φ·p_s(T)/p; φ — относительная влажность; p_s(T) — давление насыщения.

При T = 25 °C, φ = 50%: p_s = 3 169 Па, x_v = 0,5 · 3 169/101 325 = 0,01564.
ρ_вл = (101 325/(287,05 · 298,15)) · 1/(1 + 0,6078 · 0,01564) = 1,1837 · 0,9907 = 1,172 кг/м³ — снижение на 0,9% по сравнению с сухим воздухом.

**Удельная теплоёмкость влажного воздуха:**

{{< formula display="true" >}}
c_{p,вл} = c_{p,сух} + d \cdot c_{p,пар} \approx 1{,}006 + 1{,}86\, d\ \text{ кДж/(кг·К)}
{{< /formula >}}

где d — влагосодержание (humidity ratio), кг/кг_сух.воздуха.

## Применение в расчётах HVAC

**Число Рейнольдса в прямоугольном воздуховоде:**

{{< formula display="true" >}}
Re = \frac{V \cdot D_h}{\nu}
{{< /formula >}}

где D_h = 4A/П — гидравлический диаметр, A — площадь сечения, П — периметр. При V = 6 м/с, D_h = 0,4 м, T = 20 °C (ν = 15,06 × 10⁻⁶ м²/с):
Re = 6 · 0,4 / (15,06 × 10⁻⁶) = 159 362 — развитый турбулентный режим (Re > 4 000).

**Потери давления на трение (уравнение Дарси–Вейсбаха):**

{{< formula display="true" >}}
\Delta p = \xi \cdot \frac{L}{D_h} \cdot \frac{\rho V^2}{2}
{{< /formula >}}

где ξ — коэффициент Дарси (friction factor), определяется из диаграммы Муди или уравнения Колбрука. При Re = 159 000, относительная шероховатость ε/D = 0,0009 (оцинкованная сталь): ξ ≈ 0,021. Для L = 10 м: Δp = 0,021 · (10/0,4) · (1,204 · 36/2) = 0,021 · 25 · 21,67 = 11,4 Па.
