Воздухонепроницаемые материалы (air-impermeable materials) образуют основной элемент системы воздушного барьера (air barrier system) в ограждающих конструкциях. Их задача — исключить неконтролируемую инфильтрацию и эксфильтрацию воздуха, которая является главным механизмом конвективного влагопереноса и тепловых потерь.

Критерий воздухонепроницаемости по ASHRAE 90.1: воздухопропускание L_a ≤ 0,02 л/(с·м²) при перепаде давления 75 Па (ASTM E2178).

## Критерии воздухонепроницаемости

### Нормативные пороговые значения

{{< table title="Нормативные критерии воздухопропускания по основным стандартам" >}}
| Объект нормирования | L_a при 75 Па, л/(с·м²) | Стандарт |
|--------------------|------------------------|---------|
| Материал воздушного барьера | ≤ 0,02 | ASHRAE 90.1, ASTM E2178 |
| Система воздушного барьера | ≤ 0,20 | ASTM E2357 |
| Оболочка здания | ≤ 2,0 | ASTM E779, ISO 9972 |
| Passivhaus | n_50 ≤ 0,6 ч⁻¹ | PHI стандарт |
{{< /table >}}

### Физика утечки воздуха

Поток воздуха через строительную конструкцию подчиняется степенному закону:

{{< formula display="true" >}}
Q = C \cdot \Delta P^n
{{< /formula >}}

Для воздухонепроницаемых материалов C → 0. При надлежащей герметизации стыков поток через материал пренебрежимо мал, и всё воздухопропускание системы определяется качеством узлов, проходок и стыков.

## Категории воздухонепроницаемых материалов

### Полиэтиленовые плёнки (ПЭ-плёнки)

Наиболее распространённый и экономичный воздухобарьер для каркасного строительства.

**Технические характеристики:**

{{< table title="Характеристики полиэтиленовых плёнок как воздушных барьеров" >}}
| Параметр | Значение |
|----------|---------|
| Материал | LDPE (ПЭНП) или LLDPE (ЛПЭНП) |
| Толщина | 0,15–0,20 мм (стены), 0,20–0,25 мм (полы по грунту) |
| L_a при 75 Па | < 0,0001 л/(с·м²) — практически нулевая |
| W (паропропускание) | 0,001–0,005 нг/(Па·с·м²) — класс I |
| Рабочий диапазон Т | от −40 °C до +60 °C (LDPE) |
| Стандарт | ГОСТ Р 55009, ASTM E1745 Type I |
{{< /table >}}

**Критические требования к монтажу:**

1. Перекрытие швов ≥ 150 мм с двусторонней проклейкой бутилкаучуковой лентой.
2. Все проходки (трубы, кабели, вентиляционные каналы) герметизируют саморасширяющимися манжетами или лентой.
3. Примыкания к плитам перекрытий, балкам — с дополнительными полосами шириной ≥ 100 мм.
4. Защита от УФ-излучения: нестабилизированная ПЭ-плёнка разрушается за 4–8 недель на открытом воздухе.
5. Конструктивная поддержка при вертикальном применении — крепление к обрешётке с шагом ≤ 600 мм.

**Ограничения:** уязвима к механическим повреждениям при монтаже электрики и сантехники; не компенсирует деформации конструкции (нет эластичности); класс I по паропроницаемости — блокирует летнее высыхание при неправильном применении.

### Экструдированный пенополистирол (ЭППС, XPS)

ЭППС с надлежащей заделкой стыков выполняет двойную функцию: тепловая изоляция + воздушный барьер.

{{< table title="Воздухопропускание ЭППС-системы в зависимости от обработки стыков" >}}
| Обработка стыков | L_a при 75 Па, л/(с·м²) | Применимость |
|-----------------|------------------------|-------------|
| Без заделки | 0,5–2,0 | Только утеплитель |
| Монтажная пена | 0,05–0,10 | Воздушный замедлитель |
| Мастика + пена | 0,01–0,02 | Воздушный барьер (граничный) |
| Двойной слой вразбежку | < 0,01 | Надёжный воздушный барьер |
{{< /table >}}

Применение: наружный непрерывный утеплитель (ЭППС) как воздушный барьер — признанный метод по ASHRAE 90.1 (таблица 5.8.1.5). В России применяется при устройстве фасадных систем с воздушным зазором (ФВС) и при наружном утеплении цокольных этажей.

### Жидкие воздухонепроницаемые мембраны

Жидкие мембраны (liquid-applied air barriers) наносятся кистью, валиком или распылением на основание с последующим отверждением.

**Типы материалов:**
- **Акриловые дисперсионные мембраны** — водная основа, ОВД ≥ 5 °C, толщина 0,5–1,5 мм, L_a < 0,02 л/(с·м²).
- **Силиконовые мембраны** — высокая паропроницаемость, устойчивость к УФ, диапазон T: −60 °C — +150 °C.
- **Полиуретановые мембраны** — высокая механическая прочность, эластичность ≥ 300 %, применение на кровлях.
- **Асфальтовые эмульсионные мембраны** — традиционный материал, класс I по паропроницаемости.

Преимущество жидких мембран — заполнение неровностей и исключение стыков на сплошной поверхности. Критично качество нанесения: минимальная мокрая толщина, равномерность, контроль краёв.

### Самоклеящиеся мембраны

Самоклеящиеся мембраны (self-adhered membranes) — рулонный материал на основе СБС-модифицированного битума или бутилкаучука с защитной плёнкой.

{{< table title="Характеристики самоклеящихся мембран" >}}
| Параметр | СБС-битум | Бутилкаучук |
|----------|-----------|------------|
| L_a при 75 Па | < 0,005 л/(с·м²) | < 0,001 л/(с·м²) |
| W (паропроп.) | 0,05–0,2 нг/(Па·с·м²) | 0,001–0,01 нг/(Па·с·м²) |
| Диапазон Т монтажа | ≥ +5 °C | ≥ −10 °C |
| Эластичность | 200–400 % | 400–800 % |
| Адгезия | к праймированной поверхности | универсальная |
{{< /table >}}

Применение: интегрированный воздухо-гидрозащитный барьер на обшивке каркасных стен, переходные зоны «стена — кровля», «стена — фундамент».

### Монолитный железобетон и кладка

Монолитный железобетон при отсутствии трещин является воздушным барьером (k_a < 10⁻¹² м²/(Па·с)). Кладочные стены из цельного кирпича при тщательном заполнении швов — воздушный замедлитель. Пустотелые блоки без штукатурки — воздухопроницаемы.

**Обязательные условия:** сплошная штукатурка или жидкая мембрана на внутренней или наружной поверхности кладки для достижения L_a < 0,02 л/(с·м²).

### Закрытопористый напыляемый ПУФ (ccSPF)

Закрытопористая напыляемая полиуретановая пена (closed-cell spray polyurethane foam, ccSPF) при слое ≥ 50 мм обеспечивает:
- L_a < 0,02 л/(с·м²) — воздушный барьер;
- μ = 50–200 — пароретардант (класс II);
- λ = 0,022–0,026 Вт/(м·К) — высокоэффективная изоляция.

ccSPF заполняет все зазоры в каркасе, исключая необходимость отдельного монтажа ПЭ-плёнки. Ограничение: высокая стоимость, требования к безопасности при нанесении.

## Числовой пример: оценка воздухопропускания системы

**Стена:** ОСП-3 12 мм как основание. Воздухопропускание ОСП без заделки стыков: L_a ≈ 0,5 л/(с·м²) при 75 Па — не соответствует критерию барьера.

**Вариант 1: Самоклеящаяся мембрана на ОСП**

Мембрана перекрывает поверхность ОСП и заклеивает стыки. L_a мембраны < 0,005 л/(с·м²). Система (мембрана + ОСП) — L_a < 0,01 л/(с·м²). Соответствует критерию ASHRAE 90.1.

**Вариант 2: Жидкая акриловая мембрана на ОСП**

Нанесение в 2 слоя общей сухой толщиной 0,8 мм. L_a системы < 0,02 л/(с·м²). Соответствует критерию.

**Оценка узлов проходки (1 розетка без герметизации):**

Щель ~3 мм × 150 мм = 4,5 × 10⁻⁴ м². При ΔP = 10 Па и скорости v ≈ 0,5 м/с:

{{< formula display="true" >}}
Q_{\text{щель}} = A_{\text{щель}} \cdot v = 4{,}5 \times 10^{-4} \times 0{,}5 = 2{,}25 \times 10^{-4} \text{ м}^3/\text{с}
{{< /formula >}}

Для стены 10 м²: пересчитанное воздухопропускание через щель = 2,25 × 10⁻⁴ × 1000 / 10 / 10 = 2,25 л/(с·м²) — в 113 раз выше допустимого! Герметизация каждой проходки обязательна.

## Выбор материала по условиям применения

{{< table title="Выбор воздухонепроницаемого материала по условиям применения" >}}
| Условие | Рекомендуемый материал | Обоснование |
|---------|----------------------|-------------|
| Деревянный каркас, холодный климат | ПЭ-плёнка 0,2 мм изнутри | Низкая стоимость, класс I |
| Каркас с наружной изоляцией | ЭППС с заклеенными стыками | Совмещение функций |
| Реконструкция, сложные узлы | Жидкая акриловая мембрана | Бесшовность |
| Кровля на бетоне | Самоклеящаяся СБС-мембрана | Надёжность узлов |
| Монолитный ж/б кркас | Штукатурка + жидкая мембрана | Ликвидация трещин |
| Высокие требования (Passivhaus) | ccSPF или ПЭ + мастика на всех узлах | Непрерывность |
{{< /table >}}

## Долговечность и деградация

{{< table title="Долговечность воздухонепроницаемых материалов" >}}

|----------|----------------------|--------------------------|
| ПЭ-плёнка (защищённая) | 50+ лет | Механические повреждения при монтаже |

{{< /table >}}
