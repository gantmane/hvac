## Обзор

Таблицы свойств хладагентов содержат табулированные термодинамические и транспортные свойства рабочих веществ, необходимые для анализа цикла парокомпрессионной холодильной машины, проектирования оборудования и диагностики систем. Правильное применение таблиц устраняет необходимость в прямых вычислениях уравнений состояния на этапе предварительного проектирования и полевых расчётов.

Исходной базой для большинства опубликованных таблиц служат уравнения состояния NIST REFPROP v10 (Reference Fluid Thermodynamic and Transport Properties Database) и данные ASHRAE Handbook — Fundamentals (2021), Ch. 30–31. Для смесей хладагентов дополнительно привлекаются модели GERG-2008 (для многокомпонентных систем) и IAPWS-IF97 (для воды/пара в абсорбционных циклах).

## Классификация таблиц по термодинамическому состоянию

Весь диапазон состояний хладагента в холодильном цикле охватывается тремя категориями таблиц.

**Таблицы насыщения.** Содержат свойства на кривой фазового равновесия жидкость–пар при условии, что температура и давление связаны однозначно (кривая Клаузиуса-Клапейрона). Каждая строка даёт свойства насыщенной жидкости (индекс $f$) и насыщенного пара (индекс $g$). Таблицы организованы либо по температуре ($T$-таблицы), либо по давлению ($P$-таблицы) как независимой переменной.

**Таблицы перегретого пара.** Содержат свойства пара при температурах, превышающих $T_{\text{sat}}(P)$. Организованы по разделам давления; внутри каждого раздела — приращения температуры. Необходимы для расчёта работы компрессора и проектирования нагнетательных трубопроводов.

**Таблицы переохлаждённой жидкости.** Содержат свойства жидкости при давлениях выше $P_{\text{sat}}(T)$. Изменение свойств жидкости с давлением мало, поэтому для большинства инженерных расчётов достаточна аппроксимация значениями насыщенной жидкости при фактической температуре плюс поправка на давление.

## Методы интерполяции

### Линейная интерполяция

Для свойства $y$ при значении аргумента $x$ между табулированными точками $(x_1, y_1)$ и $(x_2, y_2)$:

{{< formula display="true" >}}
y = y_1 + \frac{x - x_1}{x_2 - x_1}(y_2 - y_1)
{{< /formula >}}

**Пример.** R-134a при $P = 350$ кПа. Из P-таблицы: при 300 кПа — $T_{\text{sat}} = 0{,}7$ °C; при 400 кПа — $T_{\text{sat}} = 8{,}9$ °C.

$$T_{\text{sat}}(350) = 0{,}7 + \frac{350 - 300}{400 - 300}(8{,}9 - 0{,}7) = 0{,}7 + 0{,}5 \times 8{,}2 = 4{,}8 \text{ °C}$$

### Двойная интерполяция

Для свойств перегретого пара при промежуточных значениях давления и температуры одновременно:

**Шаг 1.** Интерполировать при обоих граничных давлениях по температуре.
**Шаг 2.** Интерполировать между результатами по давлению.

**Пример.** Энтальпия R-134a при $P = 350$ кПа, $T = 30$ °C:
- При $P = 300$ кПа: $h_1 = 460{,}0 + \frac{30-20}{40-20}(477{,}6-460{,}0) = 468{,}8$ кДж/кг
- При $P = 400$ кПа: $h_2 = 455{,}6 + \frac{30-20}{40-20}(473{,}2-455{,}6) = 464{,}4$ кДж/кг
- Финальная интерполяция: $h = 468{,}8 + \frac{350-300}{400-300}(464{,}4-468{,}8) = 466{,}6$ кДж/кг

## Численный пример: анализ холодильного цикла

**Задача.** R-134a. Испаритель: $T_{\text{исп}} = -20$ °C, перегрев 10 К. Конденсатор: $T_{\text{конд}} = 40$ °C, переохлаждение 5 К. Найти COP.

**Решение.** Из таблиц NIST REFPROP v10:

Точка 1 (вход компрессора, перегрев 10 К):
$$h_1 = h_g(-20\text{ °C}) + c_p \cdot 10 = 427{,}2 + 0{,}76 \times 10 = 434{,}8 \text{ кДж/кг}$$
$$s_1 = 1{,}7153 + c_p / T_{\text{sat}} \cdot 10 \approx 1{,}7474 \text{ кДж/(кг·К)}$$

Точка 2 (выход компрессора, изоэнтропное сжатие): из таблицы перегретого пара при $P_{\text{конд}} = 1017$ кПа и $s_2 = s_1$: $h_{2s} \approx 465{,}0$ кДж/кг.

При КПД компрессора $\eta_s = 0{,}72$:
$$h_2 = h_1 + (h_{2s} - h_1)/\eta_s = 434{,}8 + (465{,}0 - 434{,}8)/0{,}72 = 476{,}7 \text{ кДж/кг}$$

Точка 3 (выход конденсатора, переохлаждение 5 К): $T_3 = 40 - 5 = 35$ °C.
$$h_3 = h_f(35\text{ °C}) = \frac{239{,}8 + 269{,}3}{2} - 5 \times 1{,}39 \approx 247{,}6 \text{ кДж/кг}$$

Точка 4 (после ТРВ): $h_4 = h_3 = 247{,}6$ кДж/кг (изоэнтальпийный процесс).

{{< formula display="true" >}}
\text{COP} = \frac{h_1 - h_4}{h_2 - h_1} = \frac{434{,}8 - 247{,}6}{476{,}7 - 434{,}8} = \frac{187{,}2}{41{,}9} \approx 4{,}47
{{< /formula >}}

## Цифровые ресурсы свойств

**NIST REFPROP v10** — полная база данных с уравнениями состояния для 147+ чистых веществ и смесей; точность ±0,1 % для основных свойств в рабочем диапазоне; реализация в Fortran с Python/MATLAB интерфейсами (NIST Standard Reference Database 23).

**CoolProp** — библиотека свойств с открытым исходным кодом; реализует высокоточные уравнения состояния для 122 чистых и псевдочистых веществ; доступна для Python, C++, MATLAB, Excel; LGPL-лицензия.

**EES (Engineering Equation Solver)** — интегрированная среда с встроенными функциями свойств хладагентов; удобна для параметрических исследований и оптимизации.

## Стандарты и нормативы

- **ASHRAE Handbook — Fundamentals (2021), Ch. 30, 31** — таблицы свойств хладагентов, методы расчёта и интерполяции.
- **NIST REFPROP v10** — базовый эталон для свойств рабочих веществ в технике.
- **ISO 817:2014** — обозначение и классификация хладагентов.
- **ASHRAE 34-2022** — классификация безопасности хладагентов и смесей.
- **IAPWS-IF97** — промышленные свойства воды и водяного пара (для абсорбционных и паровых циклов).
- **СП 60.13330.2020** — проектирование систем ОВК; ссылочные данные по хладагентам.

## Практические рекомендации

**Проверяйте опорное состояние.** Таблицы ASHRAE и IIR (Международный институт холода) используют разные опорные точки для энтальпии. Не смешивайте значения из разных источников без пересчёта.

**Контролируйте пределы интерполяции.** Избегайте экстраполяции за пределы табулированных диапазонов — уравнения состояния теряют точность вблизи критической точки и при очень низких давлениях.

**Смесевые хладагенты.** Для зеотропных смесей (R-407C, R-448A) таблицы насыщения содержат отдельные температуры bubble/dew. Не применяйте одну температуру насыщения для расчёта LMTD — это даёт систематическую ошибку в 10–30 %.

**Двухфазная область.** Свойства смеси жидкость–пар при качестве $x$:

{{< formula display="true" >}}
h = h_f + x \cdot h_{fg}, \quad v = v_f + x \cdot v_{fg}, \quad s = s_f + x \cdot s_{fg}
{{< /formula >}}

Точное определение $x$ критично для моделирования распределения потока в испарителе.
