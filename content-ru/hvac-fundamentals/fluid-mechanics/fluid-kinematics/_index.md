Кинематика жидкостей описывает характер движения потока без обращения к порождающим его силам. Для инженера ОВК кинематические понятия — инструментарий для анализа воздухораспределения в помещении, расчёта характеристик струи приточного воздуха, интерпретации данных CFD-моделирования и понимания поведения потока в разветвлённых трубопроводных сетях.

## Описания Лагранжа и Эйлера

**Лагранжев подход** отслеживает каждую «помеченную» частицу жидкости вдоль её траектории. Положение частицы: x = x(x₀, y₀, z₀, t) — функция начального положения и времени. Лагранжев подход естественен для задач трассирования (дымовые испытания, измерение инфильтрации трассирующим газом SF₆ по EN ISO 12569, возраст воздуха в помещении).

**Эйлеров подход** описывает свойства жидкости в фиксированных точках пространства. Поле скорости:

{{< formula display="true" >}}
\mathbf{V}(x, y, z, t) = u \,\mathbf{i} + v \,\mathbf{j} + w \,\mathbf{k}
{{< /formula >}}

Эйлеров подход — стандарт для расчётов ОВК: CFD-программы (Ansys Fluent, OpenFOAM, IDA ICE), балансовые уравнения теплообменников и насосных контуров, уравнение Навье–Стокса — все сформулированы в эйлеровых координатах.

**Субстанциональная (материальная) производная** — связь между подходами:

{{< formula display="true" >}}
\frac{D\mathbf{V}}{Dt} = \underbrace{\frac{\partial \mathbf{V}}{\partial t}}_{\text{нестацион.}} + \underbrace{(\mathbf{V} \cdot \nabla)\mathbf{V}}_{\text{конвектив.}}
{{< /formula >}}

Нестационарный член важен при пуске/останове вентиляционного оборудования и при переходных режимах в системах ВРН.

## Уравнение неразрывности

Закон сохранения массы для произвольного контрольного объёма:

{{< formula display="true" >}}
\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{V}) = 0
{{< /formula >}}

Для несжимаемой жидкости (ρ = const) — стандартное приближение для жидких теплоносителей и воздуха при скоростях < 50 м/с:

{{< formula display="true" >}}
\nabla \cdot \mathbf{V} = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z} = 0
{{< /formula >}}

**Практическое применение — уравнение сечений для трубопровода:**

{{< formula display="true" >}}
Q = V_1 A_1 = V_2 A_2 \quad \Rightarrow \quad \frac{V_2}{V_1} = \frac{A_1}{A_2} = \left(\frac{D_1}{D_2}\right)^2
{{< /formula >}}

При сужении с D₁ = 100 мм до D₂ = 65 мм скорость возрастает в (100/65)² = 2,37 раза. Если V₁ = 1,0 м/с, то V₂ = 2,37 м/с — необходимо проверить допустимость по нормам СП 60.13330 и отсутствие кавитации у насоса.

**Для газовых потоков** (вентиляция) с поправкой на изменение плотности:

{{< formula display="true" >}}
\dot{m} = \rho_1 V_1 A_1 = \rho_2 V_2 A_2 = \text{const}
{{< /formula >}}

При нагреве воздуха от 20 °C (ρ₁ = 1,20 кг/м³) до 40 °C (ρ₂ = 1,13 кг/м³) объёмный расход возрастает на ρ₁/ρ₂ = 1,062 — 6,2 %. При расчёте воздуховодов после нагревателя необходимо использовать расход при температуре после устройства.

## Типы линий тока

{{< table title="Классификация линий тока в кинематике жидкостей" >}}
| Тип линии | Определение | Применение в ОВК |
|---|---|---|
| Линия тока (streamline) | Линия, касательная к V в каждой точке в момент t | CFD-визуализация полей скоростей |
| Траектория (pathline) | Путь отдельной частицы со временем | Дымовые испытания, трассирование аэрозолей |
| Трассерная линия (streakline) | Лocus всех частиц, прошедших через точку | Дымовые испытания (непрерывный источник дыма) |
| Линия тока (timeline) | Линия, соединяющая все частицы из одного момента | Визуализация нестационарного потока |
{{< /table >}}

В стационарном течении все три типа совпадают. При нестационарном (пульсирующий поток, волна включения) — различаются. Дымовые испытания по EN 12599 (наладка вентиляционных систем) и ASHRAE 110 (испытание вытяжных шкафов) используют трассерные линии (непрерывный источник дыма) для визуализации зон застоя и рециркуляции.

## Завихрённость и потенциальный поток

Завихрённость (vorticity):

{{< formula display="true" >}}
\boldsymbol{\omega} = \nabla \times \mathbf{V} = \left(\frac{\partial w}{\partial y} - \frac{\partial v}{\partial z}\right)\mathbf{i} + \left(\frac{\partial u}{\partial z} - \frac{\partial w}{\partial x}\right)\mathbf{j} + \left(\frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}\right)\mathbf{k}
{{< /formula >}}

Завихрённость — мера вращения малого объёма жидкости. Высокая завихрённость — признак сдвиговых течений: вблизи стенок труб и воздуховодов, в следе за телами (карман Кармана), в вихрях после колен.

**Безвихревой (потенциальный) поток:** ω = 0 вне тонких сдвиговых слоёв. Описывается потенциалом скорости φ: **V** = ∇φ. Для несжимаемого потенциального течения ∇²φ = 0 (уравнение Лапласа) — возможны аналитические решения. Применяются для теоретического анализа поля вокруг обтекаемых тел.

## Уравнение Бернулли

Для стационарного течения идеальной несжимаемой жидкости вдоль линии тока:

{{< formula display="true" >}}
P + \frac{\rho V^2}{2} + \rho g z = \text{const}
{{< /formula >}}

Или в напорном виде (для жидкостей):

{{< formula display="true" >}}
\frac{P}{\rho g} + \frac{V^2}{2g} + z = H = \text{const}
{{< /formula >}}

Члены: `P/(ρg)` — пьезометрический напор; `V²/(2g)` — скоростной напор; `z` — геодезический напор; `H` — полный напор (константа вдоль линии тока при отсутствии потерь).

**Ограничения:** уравнение Бернулли без поправки на потери справедливо только для идеальной жидкости. Реальные системы требуют модифицированного уравнения:

{{< formula display="true" >}}
\frac{P_1}{\rho g} + \frac{V_1^2}{2g} + z_1 + H_{\text{насос}} = \frac{P_2}{\rho g} + \frac{V_2^2}{2g} + z_2 + h_{\text{потери}}
{{< /formula >}}

где H_насос — напор насоса, h_потери — суммарные потери на участке 1→2.

## Кинематика струи приточного воздуха

Вертикальная неизотермическая приточная струя (из потолочного диффузора) — ключевая задача воздухораспределения. Скорость на оси затопленной турбулентной струи убывает как:

{{< formula display="true" >}}
\frac{V_x}{V_0} = \frac{K_1 \sqrt{A_0}}{x}
{{< /formula >}}

где V₀ — скорость в сечении воздуховыпускного устройства (АВУ), A₀ — площадь выходного отверстия, x — расстояние от АВУ, K₁ — коэффициент стеснённости (зависит от типа АВУ, для решётки ≈ 5–8). Это закон затухания скорости по ASHRAE HF гл. 20 и ГОСТ Р ЕН 14240.

Формирование завихрений на свободном крае струи — первичный механизм захвата окружающего воздуха и перемешивания. Расход воздуха в сечении x:

{{< formula display="true" >}}
Q(x) = Q_0 \cdot \left(1 + K_2 \cdot \frac{x}{\sqrt{A_0}}\right)
{{< /formula >}}

При подаче 1000 м³/ч через диффузор площадью 0,04 м² (V₀ = 7,0 м/с) на расстоянии x = 2,0 м расход удваивается (K₂ ≈ 0,5): Q(2) = 1000 × (1 + 0,5 × 2,0/0,2) = 1000 × 6 = 6000 м³/ч. Большая часть этого расхода — рециркулируемый воздух помещения. При тепловой стратификации или наличии загрязнителей в нижней зоне это явление существенно влияет на эффективность воздухоудаления.

## Числовой пример: анализ скоростного профиля в воздуховоде

**Условие.** Прямоугольный воздуховод 400×400 мм, измеренные скорости в 9 точках равномерной сетки (3×3):

{{< table title="Измеренные скорости в сечении воздуховода, м/с" >}}
| — | Левая зона | Средняя зона | Правая зона |
|---|---|---|---|
| Верхняя зона | 3,2 | 4,1 | 3,4 |
| Средняя зона | 4,5 | 6,8 | 4,7 |
| Нижняя зона | 3,1 | 4,3 | 3,3 |
{{< /table >}}

**Средняя скорость** (равномерные веса для сетки 3×3 по EN 12599 — метод равных площадей):

{{< formula display="true" >}}
\bar{V} = \frac{3{,}2+4{,}1+3{,}4+4{,}5+6{,}8+4{,}7+3{,}1+4{,}3+3{,}3}{9} = \frac{37{,}4}{9} = 4{,}16 \text{ м/с}
{{< /formula >}}

**Расход:**

{{< formula display="true" >}}
Q = \bar{V} \cdot A = 4{,}16 \times 0{,}16 = 0{,}666 \text{ м}^3/\text{с} = 2397 \text{ м}^3/\text{ч}
{{< /formula >}}

**Коэффициент неравномерности:**

{{< formula display="true" >}}
\sigma = \frac{\sigma_V}{\bar{V}}, \quad \sigma_V = \sqrt{\frac{\sum(V_i - \bar{V})^2}{n}}
{{< /formula >}}

{{< formula display="true" >}}
\sum(V_i - \bar{V})^2 = (3{,}2-4{,}16)^2 + \ldots + (3{,}3-4{,}16)^2 = 0{,}922 + 0{,}002 + 0{,}582 + 0{,}122 + 6{,}912 + 0{,}292 + 1{,}122 + 0{,}022 + 0{,}742 = 10{,}72
{{< /formula >}}

{{< formula display="true" >}}
\sigma_V = \sqrt{10{,}72/9} = \sqrt{1{,}191} = 1{,}091 \text{ м/с}, \quad \sigma = 1{,}091/4{,}16 = 0{,}262 = 26{,}2\%
{{< /formula >}}

Коэффициент неравномерности 26 % — высокий. EN 12599 устанавливает предел 25 % для воздуховодных измерений (при большей неравномерности требуется более густая сетка). Высокое центральное значение (6,8 м/с) указывает на слаборазвитый профиль — скорее всего, сечение расположено слишком близко к повороту или вентилятору (расстояние от ближайшего фитинга должно быть не менее 10D по EN 12599).

## Турбулентность и кинетическая энергия турбулентности

В турбулентном потоке скорость в любой точке пульсирует:

{{< formula display="true" >}}
u = \bar{u} + u', \quad \text{где} \quad \overline{u'} = 0, \quad \overline{u'^2} \neq 0
{{< /formula >}}

Интенсивность турбулентности:

{{< formula display="true" >}}
Tu = \frac{\sqrt{\overline{u'^2}}}{\bar{U}_\infty}
{{< /formula >}}

В воздуховодах после прямых участков Tu ≈ 3–5 %; после повороте или за вентилятором Tu может достигать 10–20 %. Высокая Tu ускоряет ламинарно-турбулентный переход в пограничном слое, интенсифицирует теплоотдачу и повышает уровень шума.

Для расчёта турбулентных течений в CFD применяются модели турбулентности: k-ε (стандартная, реализуемая, RNG), k-ω SST, LES. Для задач воздухораспределения в помещении модель k-ε realizable — достаточная точность; для стратифицированных течений и при Ar > 1 рекомендуется k-ω SST.
