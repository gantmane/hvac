## Фундаментальные принципы

Изотерма сорбции — равновесная зависимость влагосодержания пористого строительного материала от относительной влажности окружающего воздуха при постоянной температуре. Это фундаментальная характеристика для расчёта:

- буферной ёмкости материала при переходных изменениях влажности;
- накопления влаги в ограждающих конструкциях (гигротермальное моделирование);
- потенциала высыхания после намокания;
- рисков конденсации, роста плесени и биодеградации;
- долговечности материала в заданном климате.

Стандарты испытаний: **ISO 12571**, ASTM C1498, EN 15026, ГОСТ 25898.

## Термодинамические механизмы сорбции

В пористом строительном материале одновременно действуют три механизма поглощения влаги, активирующиеся по мере роста относительной влажности.

### Поверхностная адсорбция (RH 0–50 %)

Молекулы воды образуют мономолекулярные и полимолекулярные слои на поверхностях пор через силы Ван-дер-Ваальса и водородные связи. Область описывается уравнением БЭТ (Brunauer–Emmett–Teller):

{{< formula display="true" >}}
w = \frac{w_m\,C\,\varphi}{(1-\varphi)\,[1+(C-1)\,\varphi]}
{{< /formula >}}

где {{< formula >}}w_m{{< /formula >}} — ёмкость монослоя, кг/кг; {{< formula >}}C{{< /formula >}} — константа, связанная с теплотой адсорбции. Уравнение БЭТ корректно до {{< formula >}}\varphi \approx 0{,}45{{< /formula >}}.

Расширенная форма — модель ГАБ (Guggenheim–Anderson–de Boer) — описывает весь гигроскопический диапазон:

{{< formula display="true" >}}
w = \frac{w_m\,C\,K\,\varphi}{(1-K\varphi)\,[1+(C-1)\,K\varphi]}
{{< /formula >}}

где {{< formula >}}K{{< /formula >}} — параметр мультислоя ({{< formula >}}K < 1{{< /formula >}}).

### Капиллярная конденсация (RH 50–98 %)

Вода конденсируется в порах, когда давление пара над вогнутым мениском падает ниже давления насыщения (эффект Кельвина). Критический радиус поры:

{{< formula display="true" >}}
r_c = -\frac{2\,\sigma\,V_m\,\cos\theta}{R\,T\,\ln\varphi}
{{< /formula >}}

где {{< formula >}}\sigma = 0{,}0728{{< /formula >}} Н/м при 20 °C; {{< formula >}}V_m = 1{,}8\times10^{-5}{{< /formula >}} м³/моль; {{< formula >}}\theta{{< /formula >}} — краевой угол смачивания.

**Пример.** При 20 °C и {{< formula >}}\varphi = 0{,}95{{< /formula >}}:

{{< formula display="true" >}}
r_c = -\frac{2\times 0{,}0728\times 1{,}8\times10^{-5}\times 1}{8{,}314\times 293\times\ln(0{,}95)} = \frac{2{,}621\times10^{-6}}{8{,}314\times 293\times 0{,}0513} \approx 2{,}1\times10^{-8}\;\text{м} = 21\;\text{нм}
{{< /formula >}}

Поры с радиусом менее 21 нм заполнятся конденсированной водой при RH = 95 %.

### Растворение гигроскопичных веществ (RH > DRH)

Для материалов, содержащих растворимые соли или другие гигроскопичные соединения, поглощение влаги резко возрастает при превышении точки делиресценции (deliquescence RH, DRH). Эффект описан в разделе «Равновесное влагосодержание материалов».

## Определение влагосодержания

Влагосодержание выражается в трёх форматах:

**По массе сухого вещества** (основной формат для древесины):
{{< formula display="true" >}}
w = \frac{m_\text{вода}}{m_\text{сух}} \times 100\,\%
{{< /formula >}}

**Объёмный** (предпочтителен для гигротермального моделирования):
{{< formula display="true" >}}
\theta = \frac{V_\text{вода}}{V_\text{total}},\quad \theta = \frac{w\,\rho_\text{dry}}{\rho_w}
{{< /formula >}}

**Степень насыщения:**
{{< formula display="true" >}}
S = \frac{V_\text{вода}}{V_\text{пор}} = \frac{\theta}{n}
{{< /formula >}}

где {{< formula >}}n{{< /formula >}} — пористость.

## Классификация изотерм (система Брунауэра–Эммета–Теллера)

Классификация БЭТ (1940) — стандартная система характеристики гигроскопичных материалов. Большинство строительных материалов относятся к типам II и IV.

### Тип I — Ленгмюровская изотерма

Крутой начальный подъём при низкой RH; плато при умеренной RH. Характерен для микропористых материалов (диаметр пор < 2 нм) — молекулярные сита, активированный уголь. В строительных материалах встречается редко, важен для десиккантных осушителей.

{{< formula display="true" >}}
w = \frac{w_m\,b\,\varphi}{1 + b\,\varphi}
{{< /formula >}}

### Тип II — S-образная изотерма

Постепенная S-образная кривая с точкой перегиба B (завершение монослоя). Наиболее распространённый тип для строительных материалов:

- древесина и изделия на её основе;
- гипсокартон;
- бетон, кладка, цементные раствор;
- волокнистая изоляция (каменная вата, целлюлоза).

Описывается моделью БЭТ или ГАБ. При высокой RH капиллярная конденсация в крупных порах вызывает ускоренный рост кривой.

### Тип III — Выпуклая изотерма

Выпуклая форма без точки перегиба; очень низкое поглощение при малой и умеренной RH. Характерен для гидрофобных материалов (неполярные полимеры, битумные материалы, синтетические мембраны). Эти материалы практически не буферизуют влагу и рассматриваются как гигроскопически инертные.

### Тип IV — Мезопористая изотерма с гистерезисом

Поведение типа II при низкой RH; плато при промежуточной RH; петля гистерезиса между адсорбцией и десорбцией. Характерен для мезопористых материалов (диаметр пор 2–50 нм):

- автоклавный газобетон (AAC);
- некоторые виды глиняного кирпича;
- кремнезёмные материалы.

Гистерезис обусловлен механизмом «чернильной бутылки»: заполнение через горлышко при адсорбции, опустошение через горлышко при более низком RH.

### Тип V — Мезопористая, слабое связывание

Комбинация черт типа III и IV; редко встречается в стандартных строительных материалах. Характерен для специально обработанных активированных углей.

## Гистерезис изотерм

Гистерезис — разница между кривыми адсорбции и десорбции при одном и том же значении RH — имеет принципиальное значение для динамических гигротермальных расчётов.

**Индекс гистерезиса (ИГ):**

{{< formula display="true" >}}
\mathrm{ИГ} = \frac{A_\text{des} - A_\text{ads}}{A_\text{des}} \times 100\,\%
{{< /formula >}}

где {{< formula >}}A_\text{des}{{< /formula >}} и {{< formula >}}A_\text{ads}{{< /formula >}} — площади под кривыми десорбции и адсорбции.

{{< table title="Типичные значения индекса гистерезиса" >}}
| Материал | ИГ, % |
|---|---|
| Древесина хвойная | 10–15 |
| Бетон | 15–25 |
| AAC (газобетон) | 25–35 |
| Обожжённый кирпич | 20–30 |
{{< /table >}}

При частичных циклах увлажнения–высыхания влагосодержание следует по кривым сканирования между главными огибающими. Для практических гигротермальных расчётов применяют три подхода:
1. Полная модель гистерезиса — максимальная точность.
2. Упрощённые кривые сканирования (линейная интерполяция) — рекомендуется для HVAC-проектирования.
3. Единая кривая десорбции — консервативная оценка.

## Численный пример: критический радиус поры и порог капиллярной конденсации

**Условие.** Определить, при каком значении RH начнётся капиллярная конденсация в порах диаметром 10 нм ({{< formula >}}r = 5\times10^{-9}{{< /formula >}} м) для полностью смачиваемой поверхности ({{< formula >}}\theta = 0°{{< /formula >}}) при T = 20 °C.

**Из уравнения Кельвина:**

{{< formula display="true" >}}
\ln\varphi = -\frac{2\,\sigma\,V_m}{R\,T\,r} = -\frac{2\times 0{,}0728\times 1{,}8\times10^{-5}}{8{,}314\times 293\times 5\times10^{-9}}
{{< /formula >}}

{{< formula display="true" >}}
\ln\varphi = -\frac{2{,}621\times10^{-6}}{1{,}218\times10^{-5}} = -0{,}2152
{{< /formula >}}

{{< formula display="true" >}}
\varphi = e^{-0{,}2152} = 0{,}806\quad\Rightarrow\quad \mathrm{RH} = 80{,}6\,\%
{{< /formula >}}

**Вывод.** В порах диаметром 10 нм капиллярная конденсация начинается уже при RH ≈ 81 %. Это объясняет резкое ускорение накопления влаги в мезопористых материалах (AAC, газобетон) при RH > 80 % и является физической основой типа IV изотермы с гистерезисом.

## Методы измерения

### Эксикаторный метод (ISO 12571)

**Принцип.** Образцы кондиционируют в закрытых ёмкостях над растворами насыщенных солей, поддерживающих строго фиксированную RH при постоянной температуре.

**Процедура:**
1. Образцы 10–50 г, толщина 5–10 мм; предварительное высушивание при 105 °C.
2. Размещение над солевыми растворами в герметичных эксикаторах.
3. Взвешивание через 7 суток; равновесие — {{< formula >}}\Delta m < 0{,}1\,\%{{< /formula >}} за 7 суток.
4. Повторение для каждого уровня RH.

{{< table title="Стандартные солевые растворы (ISO 12571, ASTM C1498)" >}}
| Соль | RH при 10 °C, % | RH при 23 °C, % | RH при 30 °C, % |
|---|---|---|---|
| LiCl | 11,2 | 11,3 | 11,3 |
| CH₃COOK | 24,4 | 23,1 | 22,5 |
| MgCl₂ | 33,5 | 33,1 | 32,4 |
| K₂CO₃ | 43,1 | 43,2 | 43,2 |
| Mg(NO₃)₂ | 57,4 | 54,4 | 51,4 |
| NaCl | 75,7 | 75,5 | 75,1 |
| KCl | 86,8 | 84,3 | 83,6 |
| K₂SO₄ | 98,2 | 97,3 | 96,7 |
{{< /table >}}

**Достоинства:** простота, экономичность, несколько образцов одновременно.
**Ограничения:** длительность (недели), дискретные точки RH.

### Динамическая сорбция пара (DVS)

Автоматизированная гравиметрическая методика:
- Масса образца 10–100 мг в микровесах.
- RH меняется ступенчато (шаг 5–10 %); точность ±0,5 % RH.
- Критерий равновесия: {{< formula >}}\mathrm{d}m/\mathrm{d}t < 0{,}002\,\%/\text{мин}{{< /formula >}}.
- Полная изотерма (адсорбция + десорбция) за 24–72 ч.

**Достоинства:** высокая точность, высокое разрешение, обе кривые гистерезиса.
**Ограничения:** малый размер образца (риск нерепрезентативности неоднородных материалов).

### Метод пластины давления (ASTM D6836)

Для надгигроскопического диапазона (RH > 95 %): насыщенный образец на пористой пластине, ступенчатое давление 1–1500 кПа. Эквивалентный диапазон RH 99,3–0,1 %. Позволяет построить кривую удержания влаги, сопрягаемую с гигроскопической изотермой.

## Применение в гигротермальном моделировании

### Требования к входным данным

WUFI и DELPHIN требуют:
1. Минимум 8–10 точек в диапазоне 0–98 % RH.
2. Обе кривые (адсорбция и десорбция) — или параметры гистерезиса.
3. Насыщение свободной водой {{< formula >}}w_f{{< /formula >}}.
4. Данные при двух температурах, если расчётный диапазон T > 20 °C.

Параметры уравнения Кюнцеля ({{< formula >}}w_f, a, b{{< /formula >}}) подгоняются по измеренным данным методом наименьших квадратов.

### Физические ограничения для контроля качества

- {{< formula >}}\mathrm{d}w/\mathrm{d}\varphi > 0{{< /formula >}} при всех {{< formula >}}\varphi{{< /formula >}} (монотонный рост).
- {{< formula >}}w(0) = 0{{< /formula >}}.
- {{< formula >}}w_\text{des}(\varphi) \geq w_\text{ads}(\varphi){{< /formula >}} при всех {{< formula >}}\varphi{{< /formula >}}.
- {{< formula >}}w(\varphi) < w_f{{< /formula >}} при {{< formula >}}\varphi < 1{{< /formula >}}.

### Влияние типа изотермы на проектирование HVAC

**Материалы с изотермой типа II (большинство стройматериалов).** Умеренная буферная ёмкость в рабочем диапазоне RH 40–80 %; рекомендуются для внутренних отделок помещений с контролируемым климатом.

**Материалы с изотермой типа IV (AAC, газобетон).** Высокая буферная ёмкость при RH > 80 %; необходимо учитывать двунаправленное высыхание; риск морозного разрушения при RH > 90 %.

**Материалы с изотермой типа III (гидрофобные).** Пренебрежимая буферная ёмкость; используются как пароизоляционные барьеры; не рекомендуются там, где требуется паропроницаемость.

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — изотермы сорбции для типовых материалов; гистерезис.
- **ASHRAE 160** — критерии расчётного анализа контроля влаги; требования к свойствам материалов.
- **ISO 12571** — определение гигроскопических свойств сорбции строительных материалов.
- **ASTM C1498** — стандартный метод измерения гигроскопических изотерм сорбции.
- **EN 15026** — оценка переноса влаги численным моделированием.
- **ГОСТ 25898** — паропроницаемость и сорбционное увлажнение строительных материалов.
- **СП 50.13330.2017** — тепловая защита зданий.
- **СП 23-101-2004** — проектирование тепловой защиты зданий.
