Термодинамическое состояние влажного воздуха при заданном барометрическом давлении однозначно определяется любыми двумя независимыми интенсивными переменными. Стандарт ASHRAE Handbook — Fundamentals, Ch. 1 выделяет семь взаимосвязанных психрометрических свойств: температуру по сухому термометру, температуру по влажному термометру, температуру точки росы, коэффициент влажности, относительную влажность, удельную энтальпию и удельный объём.

## Температура по сухому термометру

Температура по сухому термометру (dry-bulb temperature, t_db) — истинная термодинамическая температура смеси воздуха и водяного пара, измеренная датчиком, защищённым от влаги и лучистого теплообмена.

### Физическое определение

Термодинамически t_db — это температура, при которой смесь находится в равновесии, т. е. параметр уравнения Менделеева–Клапейрона для каждого компонента:

{{< formula display="true" >}}
p_a V = m_a R_a T_{\text{db}}, \quad p_v V = m_v R_v T_{\text{db}}
{{< /formula >}}

где {{< formula >}}R_a = 287{,}042{{< /formula >}} Дж/(кг·К), {{< formula >}}R_v = 461{,}52{{< /formula >}} Дж/(кг·К).

### Измерение и погрешности

{{< table title="Приборы для измерения t_db и их погрешности" >}}
| Прибор | Принцип | Типовая погрешность | Диапазон |
|---|---|---|---|
| Платиновый RTD (Pt100) | Изменение сопротивления | ±0,1–0,3 °C | −200…+600 °C |
| Термопара (тип K) | Термоэлектрический эффект | ±0,5–1,0 °C | −200…+1260 °C |
| Термистор NTC | Изменение сопротивления | ±0,1–0,2 °C | −40…+125 °C |
| Цифровой IC-датчик | Полупроводниковый | ±0,3–0,5 °C | −55…+125 °C |
{{< /table >}}

Требования к установке: датчик должен быть защищён радиационным экраном, скорость набегающего воздуха — не менее 0,5 м/с для минимизации радиационной ошибки (по ISO 7726).

|---|---|---|---|
| Офис, торговый зал | 24–26 | 20–22 | ASHRAE 55 |

{{< /table >}}

## Температура по влажному термометру

Температура по влажному термометру (wet-bulb temperature, t_wb) — это равновесная температура смоченной поверхности в контакте с движущимся воздухом. При стационарном состоянии тепло, поступающее к фитилю от воздуха конвекцией, равно теплу, расходуемому на испарение.

### Уравнение психрометра

Баланс тепла для смоченного фитиля:

{{< formula display="true" >}}
h_c (t_{db} - t_{wb}) = h_m \cdot \rho \cdot (W_s(t_{wb}) - W) \cdot h_{fg}(t_{wb})
{{< /formula >}}

Отсюда получается **уравнение психрометра** (психрометрическая формула):

{{< formula display="true" >}}
W = W_s(t_{wb}) - A_{\psi} \cdot (t_{db} - t_{wb})
{{< /formula >}}

где {{< formula >}}A_{\psi}{{< /formula >}} — психрометрическая постоянная, зависящая от скорости воздуха и конструкции прибора. При скорости воздуха > 3 м/с (аспирационный психрометр):

{{< formula display="true" >}}
A_{\psi} = 6{,}6 \times 10^{-4}\; [\text{K}^{-1}]
{{< /formula >}}

(значение, принятое в ASHRAE Handbook — Fundamentals, Ch. 1).

### Число Льюиса и термодинамическая температура влажного термометра

Строго говоря, температура, показываемая смоченным термометром (психрометрическая температура влажного термометра), совпадает с термодинамической температурой адиабатического насыщения только при числе Льюиса Le ≈ 1. Для смеси воздух–водяной пар:

{{< formula display="true" >}}
\text{Le} = \frac{\alpha}{D_{m}} = \frac{\lambda/(\rho c_p)}{\delta} \approx 0{,}85{-}0{,}95
{{< /formula >}}

Это незначительное отклонение от единицы объясняет, почему психрометрическая и термодинамическая температуры влажного термометра практически совпадают для HVAC-расчётов.

### Требования к измерению (ASHRAE 41.6)

- Скорость воздуха над фитилем: ≥ 3,5 м/с (аспирационный психрометр), ≥ 1,5 м/с (чашечный психрометр)
- Фитиль: чистая хлопчатобумажная ткань, смоченная дистиллированной водой
- Длина фитиля: не менее 25 мм
- Защита от лучистого теплообмена: обязательна

## Температура точки росы

Температура точки росы (dew-point temperature, t_dp) — температура, при охлаждении до которой водяной пар при постоянном давлении и постоянном влагосодержании начинает конденсироваться.

### Определение через давление насыщения

{{< formula display="true" >}}
p_v = p_{ws}(t_{dp})
{{< /formula >}}

Поскольку парциальное давление пара {{< formula >}}p_v{{< /formula >}} остаётся неизменным при охлаждении без изменения влагосодержания, точка росы является прямой мерой абсолютного содержания влаги.

### Расчёт точки росы через уравнение Магнуса

Для обратного определения t_dp из известного p_v:

{{< formula display="true" >}}
t_{dp} = \frac{243{,}04 \cdot \ln(p_v / 0{,}61094)}{17{,}625 - \ln(p_v / 0{,}61094)}\quad[°\text{C}]
{{< /formula >}}

Погрешность — менее 0,4 °C в диапазоне 0–60 °C.

### Приборы для прямого измерения точки росы

{{< table title="Гигрометры с охлаждаемым зеркалом (chilled mirror hygrometers)" >}}
| Параметр | Типовое значение |
|---|---|
| Погрешность | ±0,1–0,2 °C по точке росы |
| Диапазон | −75…+60 °C |
| Время отклика | 30–120 с |
| Применение | Эталонная калибровка, лаборатории |
{{< /table >}}

Гигрометр с охлаждаемым зеркалом (chilled mirror hygrometer) является первичным эталоном для измерения влажности согласно ISO 8222.

### Конденсация и расчёт критической поверхности

Конденсация на поверхности начинается при:

{{< formula display="true" >}}
T_{\text{surface}} < t_{dp}
{{< /formula >}}

Критическая температура поверхности связана с термическим сопротивлением ограждения:

{{< formula display="true" >}}
T_{\text{surface}} = T_{\text{inside}} - \frac{R_{\text{surface}}}{R_{\text{total}}} \cdot (T_{\text{inside}} - T_{\text{outside}})
{{< /formula >}}

Коэффициент температуры (temperature factor) для оценки риска конденсации:

{{< formula display="true" >}}
f_{Rsi} = \frac{T_{\text{surface}} - T_{\text{outside}}}{T_{\text{inside}} - T_{\text{outside}}} \geq f_{Rsi,\min}
{{< /formula >}}

Согласно EN ISO 13788, {{< formula >}}f_{Rsi,\min} = 0{,}70{{< /formula >}} для жилых зданий при φ_inside = 50 %.

## Коэффициент влажности

Коэффициент влажности (humidity ratio, W) — масса водяного пара, приходящаяся на 1 кг сухого воздуха:

{{< formula display="true" >}}
W = \frac{m_v}{m_a} = \frac{0{,}6220 \cdot p_v}{p - p_v}
{{< /formula >}}

### Взаимопересчёт с относительной влажностью

{{< formula display="true" >}}
W = \frac{0{,}6220 \cdot \varphi \cdot p_{ws}(t_{db})}{p - \varphi \cdot p_{ws}(t_{db})}
{{< /formula >}}

{{< formula display="true" >}}
\varphi = \frac{W \cdot p}{p_{ws}(t_{db}) \cdot (0{,}6220 + W)}
{{< /formula >}}

### Типовые значения

{{< table title="Коэффициент влажности W для характерных состояний воздуха" >}}
| Условие | t_db, °C | φ, % | W, г/кг |
|---|---|---|---|
| Очень сухой (пустыня) | 40 | 10 | 4,7 |
| Сухой наружный воздух (зима −10 °C) | −10 | 80 | 1,2 |
| Комфортный зимний внутренний | 22 | 40 | 6,6 |
| Комфортный летний внутренний | 24 | 50 | 9,3 |
| Приточный воздух после охл. секции | 13 | 90 | 8,4 |
| Влажный тропический | 35 | 80 | 29,0 |
{{< /table >}}

### Степень насыщения

Степень насыщения (degree of saturation, μ):

{{< formula display="true" >}}
\mu = \frac{W}{W_s(t_{db})}
{{< /formula >}}

Степень насыщения близка к относительной влажности, но не тождественна ей. Разница составляет менее 0,5 % при типичных HVAC-условиях.

## Относительная влажность

Относительная влажность (relative humidity, φ) — отношение парциального давления водяного пара к давлению насыщения при той же температуре:

{{< formula display="true" >}}
\varphi = \frac{p_v}{p_{ws}(t_{db})}
{{< /formula >}}

### Ёмкостные датчики относительной влажности

Ёмкостные сенсоры (capacitive RH sensors) являются наиболее распространёнными в HVAC. Принцип действия — измерение диэлектрической проницаемости гигроскопичного полимерного слоя.

{{< table title="Характеристики ёмкостных датчиков ОВ" >}}
| Параметр | Типовые значения |
|---|---|
| Погрешность (после калибровки) | ±1,5–3 % ОВ |
| Время отклика (63 %) | 15–30 с |
| Диапазон | 0–100 % ОВ |
| Гистерезис | < 1 % ОВ |
| Рекомендуемый интервал калибровки | 12–24 мес |
{{< /table >}}

### Влияние давления на показания

При изменении барометрического давления при постоянных t_db и W значение φ меняется:

{{< formula display="true" >}}
\varphi_2 = \varphi_1 \cdot \frac{p_1 \cdot (p_2 - \varphi_1 \cdot p_{ws})}{p_2 \cdot (p_1 - \varphi_1 \cdot p_{ws})}
{{< /formula >}}

Ёмкостные датчики измеряют φ без учёта давления (они реагируют на парциальное давление пара); при значительных отклонениях давления от калибровочного необходима поправка.

## Удельная энтальпия

Удельная энтальпия влажного воздуха h — тепловое содержание 1 кг сухого воздуха вместе с ассоциированным водяным паром:

{{< formula display="true" >}}
h = c_{pa} \cdot t_{db} + W \cdot (h_{fg,0} + c_{pv} \cdot t_{db}) = 1{,}006\,t_{db} + W\,(2501 + 1{,}86\,t_{db})
{{< /formula >}}

### Численный пример

Для воздуха при t_db = 24 °C, φ = 50 %:

1. {{< formula >}}p_{ws}(24°C) = 2{,}985{{< /formula >}} кПа
2. {{< formula >}}p_v = 0{,}50 \times 2{,}985 = 1{,}493{{< /formula >}} кПа
3. {{< formula >}}W = 0{,}6220 \times 1{,}493 / (101{,}325 - 1{,}493) = 0{,}00931{{< /formula >}} кг/кг = 9,31 г/кг
4. {{< formula >}}h = 1{,}006 \times 24 + 0{,}00931 \times (2501 + 1{,}86 \times 24) = 24{,}14 + 23{,}77 = 47{,}9{{< /formula >}} кДж/кг

### Энтальпия конденсата

При охлаждении ниже точки росы выделяющийся конденсат уносит часть тепла. Его энтальпия при температуре поверхности t_s:

{{< formula display="true" >}}
h_w(t_s) = c_{pw} \cdot t_s \approx 4{,}186 \cdot t_s\quad[\text{кДж/кг}]
{{< /formula >}}

Полный тепловой баланс охлаждающей секции с осушением:

{{< formula display="true" >}}
q_{\text{total}} = \dot{m}_a \bigl[(h_1 - h_2) - (W_1 - W_2) \cdot h_w(t_s)\bigr]
{{< /formula >}}

## Удельный объём

Удельный объём влажного воздуха (specific volume, v) — объём смеси, приходящийся на 1 кг сухого воздуха:

{{< formula display="true" >}}
v = \frac{R_a \cdot T}{p - p_v} = \frac{0{,}287042\,(t_{db} + 273{,}15)\,(1 + 1{,}6078\,W)}{p}
{{< /formula >}}

### Плотность влажного воздуха

Плотность влажного воздуха (масса смеси на единицу объёма):

{{< formula display="true" >}}
\rho = \frac{1 + W}{v}
{{< /formula >}}

При стандартных условиях (t_db = 20 °C, φ = 50 %, p = 101,325 кПа):
- v ≈ 0,841 м³/кг
- ρ ≈ 1,200 кг/м³

### Практическое применение

Удельный объём используется для пересчёта массового расхода в объёмный:

{{< formula display="true" >}}
\dot{V} = \dot{m}_a \cdot v
{{< /formula >}}

При высоте 1500 м (p ≈ 84,3 кПа) удельный объём при тех же t_db и W вырастает примерно на 20 %, что требует соответствующей коррекции производительности вентиляторов и расходов воздуха.
