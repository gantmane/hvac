Корреляции конвективного теплообмена — эмпирические или полуэмпирические выражения, связывающие безразмерное число Нуссельта с числами Рейнольдса и Прандтля (вынужденная конвекция) или Рэлея и Прандтля (естественная конвекция). Их получают из экспериментальных данных с помощью метода подобия и анализа размерностей. Применение корреляций вне диапазона применимости может давать погрешности 50% и более.

## Безразмерные параметры и их физический смысл

{{< table title="Безразмерные числа конвективного теплообмена" >}}
| Число | Определение | Физический смысл | Типичные значения в HVAC |
|---|---|---|---|
| $Re = VL/\nu$ | Инерционные силы / вязкие силы | Режим течения | $10^3$–$10^6$ |
| $Pr = \nu/\alpha$ | Импульсная диффузия / тепловая диффузия | Структура ПС | 0,7 (воздух), 7 (вода) |
| $Nu = hL/k$ | Конвекция / теплопроводность в жидкости | Интенсивность конвекции | 3–1000 |
| $Gr = g\beta\Delta T L^3/\nu^2$ | Архимедовы силы / вязкие силы | Естественная конвекция | $10^5$–$10^{10}$ |
| $Ra = Gr \cdot Pr$ | Плавучесть / тепловая диффузия | Режим ест. конвекции | $10^6$–$10^{11}$ |
| $St = h/(\rho V c_p)$ | Тепловой поток / тепловая ёмкость потока | Аналогия с трением | $10^{-4}$–$10^{-2}$ |
{{< /table >}}

## Оценка свойств жидкости

Большинство корреляций требуют вычисления безразмерных чисел при определённой **опорной температуре**:

- **Температура пленки** $T_f = (T_s + T_\infty)/2$: для внешних течений (обтекание пластины, цилиндра)
- **Средняя массовая температура** $T_b = (T_{in} + T_{out})/2$: для внутреннего течения
- При больших перепадах температур: дополнительная поправка на вязкость $(\mu_b/\mu_s)^{0,14}$

## Корреляции для внутреннего турбулентного течения в трубах

### Уравнение Диттуса–Бёлтера (1930)

{{< formula display="true" >}}
Nu_D = 0{,}023 \, Re_D^{0,8} \, Pr^n
{{< /formula >}}

- $n = 0{,}4$ при нагреве жидкости ($T_s > T_b$)
- $n = 0{,}3$ при охлаждении ($T_s < T_b$)

**Диапазон применимости**: $Re > 10^4$; $0{,}7 < Pr < 160$; $L/D > 10$; умеренная разность температур.  
**Погрешность**: ±25%.

### Уравнение Гнилинского (1976) — рекомендованное

{{< formula display="true" >}}
Nu_D = \frac{(f/8)(Re_D - 1000) Pr}{1 + 12{,}7 \sqrt{f/8} (Pr^{2/3} - 1)}
{{< /formula >}}

Коэффициент трения по Петухову (гладкая труба):

{{< formula display="true" >}}
f = (0{,}790 \ln Re_D - 1{,}64)^{-2}
{{< /formula >}}

**Диапазон применимости**: $3000 < Re < 5 \times 10^6$; $0{,}5 < Pr < 2000$; $L/D > 10$.  
**Погрешность**: ±10% — наиболее точная из простых корреляций.

### Корреляция Зидера–Тейта (переменная вязкость)

{{< formula display="true" >}}
Nu_D = 0{,}027 \, Re_D^{0,8} Pr^{1/3} \left(\frac{\mu_b}{\mu_s}\right)^{0,14}
{{< /formula >}}

Применяется при больших перепадах температур (масла, вязкие жидкости).

### Ламинарное течение ($Re < 2300$)

Полностью развитое течение при $Pr \cdot Re \cdot D/L < 10$:

{{< formula display="true" >}}
Nu_D = 3{,}66 \;\text{(постоянная температура стенки)}
\qquad
Nu_D = 4{,}36 \;\text{(постоянный тепловой поток)}
{{< /formula >}}

Для длины гидравлического входа: $L_h/D = 0{,}05 \, Re$ (ламинар), $L_h/D \approx 10$–60 (турбул.).

## Корреляции для внешнего обтекания

### Плоская пластина — ламинарный поток

{{< formula display="true" >}}
\overline{Nu}_L = 0{,}664 \, Re_L^{1/2} Pr^{1/3} \quad (Re_L < 5 \times 10^5)
{{< /formula >}}

### Плоская пластина — смешанный ламинарно-турбулентный поток

{{< formula display="true" >}}
\overline{Nu}_L = (0{,}037 \, Re_L^{4/5} - 871) Pr^{1/3} \quad (Re_{crit} = 5 \times 10^5)
{{< /formula >}}

### Одиночный цилиндр в поперечном потоке (корреляция Черчилля–Бернштейна, 1977)

{{< formula display="true" >}}
\overline{Nu}_D = 0{,}3 + \frac{0{,}62 \, Re_D^{1/2} Pr^{1/3}}{\left[1 + (0{,}4/Pr)^{2/3}\right]^{1/4}} \left[1 + \left(\frac{Re_D}{282\,000}\right)^{5/8}\right]^{4/5}
{{< /formula >}}

Применима для любых $Re$ при $Re \cdot Pr > 0{,}2$. Свойства при $T_f = (T_s + T_\infty)/2$.

### Корреляция Жукаускаса для одиночного цилиндра

{{< formula display="true" >}}
Nu_D = C \, Re_D^m Pr^{0,36} \left(\frac{Pr}{Pr_s}\right)^{1/4}
{{< /formula >}}

{{< table title="Коэффициенты C и m для цилиндра в поперечном потоке (Жукаускас)" >}}
| $Re_D$ | $C$ | $m$ |
|---|---|---|
| 1–40 | 0,75 | 0,40 |
| 40–1000 | 0,51 | 0,50 |
| 1000–200 000 | 0,26 | 0,60 |
| 200 000–10⁶ | 0,076 | 0,70 |
{{< /table >}}

## Корреляции для естественной конвекции

### Вертикальная пластина — корреляция Черчилля–Чу

{{< formula display="true" >}}
\overline{Nu}_L = \left\{0{,}825 + \frac{0{,}387 \, Ra_L^{1/6}}{\left[1 + (0{,}492/Pr)^{9/16}\right]^{8/27}}\right\}^2
{{< /formula >}}

Применима для всего диапазона $Ra_L$ от 10⁻¹ до 10¹². Погрешность ±15%.

### Горизонтальная нагретая пластина лицом вверх

{{< formula display="true" >}}
\overline{Nu}_L = 0{,}54 \, Ra_L^{1/4} \quad (10^4 < Ra < 10^7)
\qquad
\overline{Nu}_L = 0{,}15 \, Ra_L^{1/3} \quad (10^7 < Ra < 10^{11})
{{< /formula >}}

### Горизонтальная нагретая пластина лицом вниз

{{< formula display="true" >}}
\overline{Nu}_L = 0{,}27 \, Ra_L^{1/4} \quad (10^5 < Ra < 10^{10})
{{< /formula >}}

Характерная длина: $L = A_s / P$ (площадь / периметр).

### Горизонтальный цилиндр

{{< formula display="true" >}}
\overline{Nu}_D = \left\{0{,}60 + \frac{0{,}387 \, Ra_D^{1/6}}{\left[1 + (0{,}559/Pr)^{9/16}\right]^{8/27}}\right\}^2
{{< /formula >}}

Применима для $10^{-5} < Ra_D < 10^{12}$.

## Числовой пример: коэффициент конвекции воды в трубе

**Задача.** Вода ($T_b = 50°$С) течёт в медной трубе диаметром $D = 25$ мм со скоростью $V = 1{,}5$ м/с. Рассчитать $h$.

Свойства воды при 50°С: $\rho = 988$ кг/м³, $\mu = 548 \times 10^{-6}$ Па·с, $k = 0{,}644$ Вт/(м·К), $Pr = 3{,}55$.

{{< formula display="true" >}}
Re = \frac{\rho V D}{\mu} = \frac{988 \times 1{,}5 \times 0{,}025}{548 \times 10^{-6}} = \frac{37{,}05}{5{,}48 \times 10^{-4}} = 67\,600 \quad (\text{турбулентный})
{{< /formula >}}

{{< formula display="true" >}}
f = (0{,}790 \ln 67\,600 - 1{,}64)^{-2} = (0{,}790 \times 11{,}12 - 1{,}64)^{-2} = (7{,}14)^{-2} = 0{,}01962
{{< /formula >}}

{{< formula display="true" >}}
Nu_D = \frac{(0{,}01962/8)(67\,600 - 1000) \times 3{,}55}{1 + 12{,}7 \sqrt{0{,}01962/8}(3{,}55^{2/3} - 1)} = \frac{0{,}00245 \times 66\,600 \times 3{,}55}{1 + 12{,}7 \times 0{,}0495 \times 1{,}47}
{{< /formula >}}

{{< formula display="true" >}}
Nu_D = \frac{581}{1 + 0{,}923} = \frac{581}{1{,}923} = 302
{{< /formula >}}

{{< formula display="true" >}}
h = \frac{Nu \cdot k}{D} = \frac{302 \times 0{,}644}{0{,}025} = 7\,786 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

Это типичное значение для горячего водоснабжения при умеренной скорости.

## Поправки на изменение свойств жидкости

При значительном перепаде температур свойства жидкости у стенки и в ядре существенно отличаются. Поправка на вязкость:

{{< formula display="true" >}}
Nu = Nu_0 \left(\frac{\mu_b}{\mu_s}\right)^{0,11}
{{< /formula >}}

Для газов поправка минимальна; для масел и вязких жидкостей обязательна.

## Применение в задачах HVAC

### Трубопроводы системы отопления

Для расчёта теплопотерь секции трубопровода или выбора теплоизоляции:
1. Рассчитать $h_i$ для воды (Гнилинский)
2. Добавить тепловое сопротивление стенки трубы и изоляции (цилиндрическая геометрия)
3. Рассчитать $h_e$ для наружного воздуха (Черчилль–Чу для горизонтального цилиндра)
4. Найти суммарный $U$ и тепловой поток

### Воздухоохладители (охлаждающие катушки)

Для расчёта общего теплового потока катушки:
- Сторона воздуха: $h_o$ из корреляции для пучка труб или $j$-фактора (Рич, Ванг)
- Сторона хладагента/воды: $h_i$ из корреляции для внутреннего течения
- Общий $UA = 1/(1/h_i A_i + R_w + 1/(h_o A_o \eta_o))$
