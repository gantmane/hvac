Инфильтрация через дверные проемы представляет одну из наиболее значительных и изменчивых охлаждающих нагрузок в холодильных помещениях. Воздухообмен вводит как явное, так и скрытое тепло, а отложение влаги на испарительных катушках создает дополнительные операционные проблемы, повышая частоту разморозки и энергопотребление.

## Инфильтрация при открытии двери

### Базовое уравнение инфильтрации

Передача явного и скрытого тепла через открытый дверной проем зависит от разности плотности воздуха внутри и снаружи:

**Явное тепло:**
```
Qs = 0.221 × A × h × ρo × Fm × (1 - E) × Δh_явное
```

**Скрытое тепло:**
```
Ql = 0.221 × A × h × ρo × Fm × (1 - E) × Δh_скрытое
```

Где:
- Qs = прирост явного тепла, кДж/ч
- Ql = прирост скрытого тепла, кДж/ч
- A = площадь двери, м²
- h = высота двери, м
- ρo = плотность наружного воздуха, кг/м³
- Fm = коэффициент плотности (множитель расхода)
- E = эффективность защитного устройства (0–1,0)
- Δh_явное = разность энтальпии (явное), кДж/кг
- Δh_скрытое = разность энтальпии (скрытое), кДж/кг

### Коэффициент плотности (Fm)

Коэффициент плотности учитывает фактический воздухообмен на основе разности температур:

**Для температур выше -18°C:**
```
Fm = 0.8 × (1 - ρi/ρo)^0.5
```

**Для температур ниже -18°C:**
```
Fm = 1.1 × (1 - ρi/ρo)^0.5
```

Где:
- ρi = плотность внутреннего воздуха, кг/м³
- ρo = плотность наружного воздуха, кг/м³

| Разность температур (°C) | Коэффициент плотности (Fm) |
|--------------------------|---------------------------|
| 11 | 0.18 |
| 22 | 0.26 |
| 33 | 0.32 |
| 44 | 0.37 |
| 56 | 0.41 |
| 67 | 0.45 |
| 78 | 0.48 |

### Метод частоты открытия двери

Общая суточная инфильтрационная нагрузка зависит от режима использования двери:

```
Q_итого = Qs × t_открыто × n_открытий / 24
```

Где:
- Q_итого = средняя почасовая нагрузка, кДж/ч
- Qs = мгновенная инфильтрационная нагрузка, кДж/ч
- t_открыто = среднее время открытия двери за одно открытие, ч
- n_открытий = количество открытий двери в день

**Типичное время открытия двери:**

| Тип помещения | Среднее время открытия (сек) | Открытий в день |
|---------------|------------------------------|-----------------|
| Небольшой холодильный шкаф | 10–15 | 50–100 |
| Крупный холодильный шкаф | 15–30 | 100–200 |
| Дверь грузовой платформы распределительного центра | 300–600 | 20–40 |
| Дверь проезда склада | 30–60 | 100–300 |
| Дверь производственного цеха | 60–180 | 40–80 |

### Коэффициент использования дверей с интенсивным движением

Для дверей с интенсивным движением примените коэффициент использования для учета эффективности двери:

```
Q_расчет = Q_инфильтрация × УФ × КД
```

Где:
- УФ = коэффициент использования (1,0–1,5 для интенсивного трафика)
- КД = коэффициент двери (1,0 для ручной, 0,8 для автоматической, 0,6 для высокоскоростной)

## Уравнение Госнея-Олама

Уравнение Госнея-Олама обеспечивает более точное предсказание скорости инфильтрационного потока через вертикальные отверстия на основе перепада давления:

```
v = Cd × [2 × g × h × (ρo - ρi) / (ρo + ρi)]^0.5
```

Где:
- v = средняя скорость воздуха через отверстие, м/с
- Cd = коэффициент расхода (обычно 0,65–0,75)
- g = ускорение свободного падения, 9,81 м/с²
- h = высота отверстия, м
- ρo, ρi = плотность наружного и внутреннего воздуха, кг/м³

**Объемный расход:**

```
Q_объем = v × A × 3600 / 2
```

Где:
- Q_объем = объемный расход, м³/ч
- A = площадь отверстия, м²
- Коэффициент 2 учитывает двусторонний поток

**Массовый расход:**

```
ṁ = Q_объем × ρ_ср / 60
```

Где:
- ṁ = массовый расход, кг/мин
- ρ_ср = (ρo + ρi) / 2

### Значения коэффициента расхода

| Конфигурация отверстия | Коэффициент расхода (Cd) |
|------------------------|--------------------------|
| Неограниченное открытие двери | 0,70–0,75 |
| Дверь с порогом | 0,65–0,70 |
| Пластиковая завеса (50% покрытие) | 0,35–0,45 |
| Пластиковая завеса (75% покрытие) | 0,20–0,30 |
| Работающая воздушная завеса | 0,15–0,25 |
| Конфигурация тамбура | 0,10–0,20 |

## Эффективность воздушной завесы

Воздушные завесы снижают инфильтрацию, создавая высокоскоростной поток воздуха по дверному проему. Эффективность зависит от скорости воздуха, ширины покрытия и разности температур.

### Производительность воздушной завесы

**Коэффициент эффективности:**

```
E = 1 - (Q_факт / Q_без_завесы)
```

Где:
- E = эффективность (0–1,0)
- Q_факт = инфильтрация с воздушной завесой, кДж/ч
- Q_без_завесы = инфильтрация без защиты, кДж/ч

**Требуемая скорость воздуха:**

```
v_струя = K × [g × h × (ρo - ρi) / ρi]^0.5
```

Где:
- v_струя = скорость выхода воздушной завесы, м/с
- K = коэффициент скорости (1,5–2,0 для надлежащей производительности)
- Остальные переменные как определено выше

### Параметры проектирования воздушной завесы

| Применение | Скорость выхода (м/мин) | Объем воздуха (м³/ч на м ширины) | Эффективность (E) |
|-----------|------------------------|----------------------------------|-------------------|
| Холодильная камера (1–4°C) | 240–300 | 200–250 | 0,60–0,75 |
| Морозильная камера (-12 до 0°C) | 360–450 | 300–400 | 0,50–0,65 |
| Холодильное хранилище (-29°C) | 450–550 | 400–500 | 0,40–0,55 |
| Вход тамбура | 180–240 | 150–200 | 0,70–0,85 |

**Рециркулирующие воздушные завесы:**

Для нагреваемых воздушных завес (рециркуляция воздуха из холодильного помещения):

| Температура помещения (°C) | Температура выхода (°C) | Коэффициент снижения эффективности |
|-----------------------------|------------------------|-------------------------------------|
| 2 | 4–7 | 1,10 |
| -18 | -15 до -12 | 1,15 |
| -23 | -21 до -18 | 1,20 |
| -29 | -26 до -23 | 1,25 |

### Ограничения воздушной завесы

Эффективность воздушной завесы снижается при:
- Боковом ветре >60 м/мин (снижение эффективности на 20–40%)
- Высоте >3 м (снижение эффективности на 5% на каждый дополнительный метр)
- Ширине >3,7 м (используйте несколько устройств для более широких проемов)
- Продолжительном открытии двери >5 минут (эффективность падает до 40–50%)

## Системы пластиковых завес

Гибкие пластиковые завесы обеспечивают физический барьер, позволяя при этом проходу персонала и оборудования.

### Снижение инфильтрации пластиковой завесой

```
Q_завеса = Q_открыто × (1 - η_завеса) × F_перекрытие
```

Где:
- Q_завеса = инфильтрация с пластиковой завесой, кДж/ч
- Q_открыто = инфильтрация при открытой двери, кДж/ч
- η_завеса = коэффициент полезного действия пластиковой завесы
- F_перекрытие = коэффициент перекрытия (обычно 1,0–1,2)

### Эффективность пластиковой завесы

| Конфигурация полос | Покрытие (%) | Эффективность (η) | Эффективный Cd |
|--------------------|-------------|-------------------|-----------------|
| Стандартные полосы 20 см, 50% перекрытие | 90 | 0,60–0,70 | 0,35–0,40 |
| Стандартные полосы 20 см, 100% перекрытие | 95 | 0,70–0,80 | 0,25–0,30 |
| Широкие полосы 30 см, 50% перекрытие | 92 | 0,65–0,75 | 0,30–0,35 |
| Широкие полосы 30 см, 100% перекрытие | 97 | 0,75–0,85 | 0,20–0,25 |
| Изолированные полосы | 95 | 0,75–0,85 | 0,20–0,25 |
| Щеточные полосы (только края) | 30 | 0,20–0,30 | 0,60–0,65 |

### Конструктивные соображения пластиковой завесы

**Выбор ширины полос:**

| Ширина двери | Рекомендуемая ширина полос | Количество полос |
|-------------|--------------------------|------------------|
| 0,9–1,2 м | 20 см | 6–8 |
| 1,2–1,8 м | 20–25 см | 8–12 |
| 1,8–3 м | 25–30 см | 12–18 |
| 3–4,3 м | 30 см | 18–24 |

**Конфигурация перекрытия:**
- 50% перекрытие: расстояние между полосами = 0,5 × ширина полосы
- 100% перекрытие: расстояние между полосами = 0,33 × ширина полосы
- Краевые полосы: выступают на 15–20 см за пределы дверного проема

**Толщина материала:**

| Температура применения | Толщина полос | Материал |
|------------------------|---------------|----------|
| Холодильная камера (>0°C) | 2–3 мм | Стандартный ПВХ |
| Легкий морозильник (0–0°C) | 3–4 мм | ПВХ низкотемпературный |
| Морозильник (<0°C) | 4–5 мм | ПВХ полярный |
| Высокий трафик при любой температуре | 4–5 мм | Армированный ПВХ |

## Расчеты тамбура

Тамбуры создают буферную зону, которая значительно снижает прямую инфильтрацию между помещениями.

### Двухдверный тамбур

Инфильтрация через двухдверную систему тамбура:

```
Q_тамбур = Q_одиночная × F_тамбур
```

Где F_тамбур зависит от режима работы двери:

| Режим работы двери | Коэффициент тамбура (F_тамбур) |
|------------------|--------------------------------|
| Одна дверь всегда закрыта | 0,05–0,10 |
| Взаимоблокирующиеся двери | 0,10–0,20 |
| Двери иногда открываются одновременно | 0,30–0,50 |
| Высокоскоростной трафик (без координации) | 0,50–0,70 |

### Объем тамбура и смешивание

**Минимальный объем тамбура:**

```
V_мин = Q_объем × t_цикл × КБ
```

Где:
- V_мин = минимальный объем тамбура, м³
- Q_объем = объемный расход на открытие, м³/мин
- t_цикл = время цикла двери, мин (обычно 0,5–2,0 мин)
- КБ = коэффициент безопасности (1,5–2,0)

**Коэффициент смешивания:**

Для частичного смешивания воздуха в тамбуре:

```
Q_факт = Q_теор × [1 - (1 - e^(-N))]
```

Где:
- N = количество воздухообменов во время открытия двери
- e = основание натурального логарифма (2,718)

### Требования к проектированию тамбура

| Тип помещения | Минимальная глубина (м) | Ширина | Высота | Объем на ширину двери (м³/м) |
|--------------|----------------------|--------|--------|------------------------------|
| Холодильный шкаф | 1,2–1,8 | Дверь + 0,6 м | 2,1–2,4 | 0,8–1,4 |
| Складская платформа | 2,4–3,7 | Дверь + 0,9 м | 3–4,3 | 2,8–4,2 |
| Распределительный центр | 3–4,5 | Дверь + 1,2 м | 3,7–4,9 | 4,2–5,6 |
| Вход в морозильник | 1,8–3 | Дверь + 0,9 м | 2,4–3 | 1,7–2,8 |

**Кондиционирование тамбура:**

| Стратегия кондиционирования тамбура | Диапазон температуры | Влияние на энергию | Снижение инфильтрации |
|-------------------------------------|----------------------|-------------------|----------------------|
| Некондиционированный | Наружная температура | Минимальное | 80–85% |
| Подогреваемый только | 10–16°C | Низкое | 85–90% |
| Полукондиционированный | 16–21°C | Среднее | 90–95% |
| Полностью кондиционированный | 21–24°C | Высокое | 95–98% |

## Комбинированные методы инфильтрации через дверной проем

Для максимальной эффективности можно комбинировать несколько методов защиты:

```
Q_комб = Q_открыто × (1 - E_воздух) × (1 - E_завеса) × F_тамбур × F_работа
```

Где:
- E_воздух = эффективность воздушной завесы
- E_завеса = эффективность пластиковой завесы
- F_тамбур = коэффициент тамбура
- F_работа = операционный коэффициент (управление дверьми)

### Эффективность комбинированной защиты

| Комбинация защиты | Общая эффективность | Типичное применение |
|------------------|---------------------|---------------------|
| Только воздушная завеса | 60–75% | Холодильные камеры, умеренный трафик |
| Только пластиковая завеса | 70–85% | Низкоскоростной трафик |
| Воздушная завеса + пластиковая завеса | 85–92% | Морозильники, высокий трафик |
| Тамбур + воздушная завеса | 88–95% | Распределительные центры |
| Тамбур + пластиковая завеса | 90–94% | Холодильное хранилище |
| Полная система (все три) | 95–98% | Критическое низкотемпературное хранилище |

## Стратегии снижения инфильтрации

### Операционные средства управления

**Управление дверьми:**

1. **Автоматические закрыватели:** Снижают среднее время открытия на 30–50%
2. **Высокоскоростные двери:** Открытие/закрытие за 3–5 сек в сравнении с 15–30 сек
3. **График трафика:** Пакетизация открытий двери снижает общее время открытия
4. **Взаимоблокирующиеся двери тамбура:** Предотвращают одновременное открытие

**Производительность высокоскоростной двери:**

| Тип двери | Цикл открытия/закрытия (сек) | Снижение инфильтрации vs. стандартная |
|-----------|---------------------------|--------------------------------------|
| Стандартная ручная | 20–40 | Базовая (0%) |
| Стандартная с приводом | 15–25 | 20–30% |
| Высокоскоростная тканевая | 3–6 | 70–85% |
| Высокоскоростная жесткая | 5–8 | 65–80% |
| Сверхвысокоскоростная | 2–4 | 80–90% |

### Конструктивные стратегии

**Управление давлением:**

Поддерживайте незначительное положительное давление в помещениях, непосредственно прилегающих к холодильным помещениям:

```
ΔP = ρ × g × h × (To - Ti) / (Ti × 1000)
```

Где:
- ΔP = перепад давления, Па
- ρ = плотность воздуха, кг/м³
- g = 9,81 м/с²
- h = высота, м
- To, Ti = абсолютные температуры, К
- 1000 преобразует кг/м·с² в Па

**Рекомендуемые перепады давления:**

| Конфигурация соседнего помещения | Перепад давления (Па) | Метод |
|----------------------------------|----------------------|--------|
| Холодильная камера в окружающий воздух | +10–25 | Снижение выхлопа |
| Морозильник в холодильную камеру | 0–10 | Сбалансированный или слегка + |
| Грузовая платформа в морозильник | +25–40 | Подача воздуха на платформу |
| Коридор в холодильное помещение | +15–25 | Нагнетание воздуха в коридор |

### Физические барьеры

**Пороги и уплотнения:**

| Тип уплотнения | Снижение инфильтрации | Место установки |
|----------------|----------------------|------------------|
| Уплотнение нижнего порога | 5–10% | Основание двери |
| Краевые прокладки | 8–12% | Периметр двери |
| Магнитные уплотнения | 10–15% | Края двери (холодильные шкафы) |
| Надувные уплотнения | 15–25% | Двери платформы |
| Система полного периметра | 20–30% | Все края |

**Управление потоком трафика:**

```
n_эф = n_факт / F_пакет
```

Где:
- n_эф = эффективное количество открытий
- n_факт = фактическое количество открытий
- F_пакет = коэффициент пакетизации (1,0 для случайного, 0,3–0,7 для запланированного)

### Специальные применения

**Инфильтрация скоростной морозильной камеры:**

Для скоростных морозильных камер с быстрым движением воздуха:

```
Q_скоро = Q_стандартная × (1 + v_внутренн/150)
```

Где:
- Q_скоро = отрегулированная инфильтрационная нагрузка, кДж/ч
- v_внутренн = внутренняя скорость воздуха, м/мин
- 150 = коэффициент нормализации

**Холодильное хранилище со стеллажами:**

Препятствие от стеллажных систем рядом с дверями влияет на инфильтрацию:

| Расстояние от двери (м) | Плотность стеллажа | Коэффициент снижения потока |
|------------------------|-------------------|---------------------------|
| 0–1,5 | Высокая (>80% заполнено) | 0,70–0,80 |
| 0–1,5 | Средняя (50–80%) | 0,80–0,90 |
| 1,5–3 | Высокая | 0,85–0,92 |
| 1,5–3 | Средняя | 0,90–0,95 |
| >3 | Любая | 0,95–1,00 |

## Пример расчета нагрузки

**Задача:** Рассчитайте инфильтрационную нагрузку для дверцы морозильника при -12°C с наружными условиями 27°C ПВ, 19°C ПВ.

**Дано:**
- Дверь: 2,4 м в ширину × 3 м в высоту
- Среднее время открытия: 45 сек на открытие
- Частота: 100 открытий в день
- Защита: пластиковая завеса (80% эффективность)

**Решение:**

1. **Площадь двери:** A = 2,4 × 3 = 7,2 м²

2. **Свойства воздуха:**
   - Наружный: ρo = 1,18 кг/м³, ho = 61,9 кДж/кг
   - Внутренний: ρi = 1,41 кг/м³, hi = -5,5 кДж/кг (при -12°C, ~90% ОВ)

3. **Коэффициент плотности:**
   ```
   Fm = 1,1 × (1 - 1,41/1,18)^0.5 = 1,1 × 0,616 = 0,678
   ```

4. **Инфильтрация без защиты:**
   ```
   Q = 0,221 × 7,2 × 3 × 1,18 × 0,678 × (61,9 - (-5,5))
   Q = 0,221 × 7,2 × 3 × 1,18 × 0,678 × 67,4
   Q = 3,238 кДж на открытие двери
   ```

5. **С пластиковой завесой:**
   ```
   Q_факт = 3,238 × (1 - 0,80) = 648 кДж на открытие двери
   ```

6. **Средняя почасовая нагрузка:**
   ```
   Q_ср = 648 × 100 / 24 = 2,700 кДж/ч
   ```

7. **Расчетная нагрузка (с коэффициентом безопасности 25%):**
   ```
   Q_расчет = 2,700 × 1,25 = 3,375 кДж/ч
   ```

## Рекомендации по проектированию

1. **Всегда используйте защитные устройства** на дверных проемах холодильных помещений—незащищенные двери создают чрезмерные инфильтрационные нагрузки

2. **Выбирайте высокоскоростные двери** для применений с высоким трафиком (>50 открытий/день)

3. **Комбинируйте методы защиты** для морозильников ниже 0°C—отдельные методы редко обеспечивают адекватную защиту

4. **Устанавливайте воздушные завесы** со скоростью выхода ≥1,5 раз выше теоретической скорости инфильтрации

5. **Регулярно обслуживайте пластиковые завесы**—поврежденные или отсутствующие полосы исключают большую часть защитного эффекта

6. **Размеры тамбуров** рассчитывайте на основе фактических режимов трафика, а не минимальные требования норм

7. **Контролируйте время открытия двери** с логированием данных для проверки проектных предположений и выявления возможностей обучения

8. **Применяйте коэффициенты безопасности** 1,15–1,30 для критических применений или при неопределенных режимах использования
