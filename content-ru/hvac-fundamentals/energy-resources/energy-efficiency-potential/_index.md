Потенциал повышения энергоэффективности — количественно определяемая возможность снижения потребления энергии при сохранении или улучшении условий в здании. Системы ОВК доминируют в этом потенциале: на них приходится 40–50 % конечного потребления коммерческих зданий и 50–60 % жилых, а технический потенциал снижения при полной модернизации достигает 40–60 %. Реализация потенциала требует систематической оценки согласно ASHRAE 211, EN 16247 и ISO 50001.

## Иерархия потенциалов

### Технический потенциал

Максимально достижимое снижение при применении наилучших доступных технологий без ценовых ограничений. Для систем ОВК в зданиях со старым оборудованием:

- замена всего оборудования на модели максимальной эффективности;
- оптимизация ограждающих конструкций до предела, допустимого по конструктивным условиям;
- внедрение всех известных стратегий автоматизации и управления.

**Типичный технический потенциал:** 40–60 % снижения потребления HVAC.

### Экономический потенциал

Снижение потребления, достижимое мероприятиями, удовлетворяющими критериям экономической целесообразности.

**Стандартные критерии отбора:**
- простой срок окупаемости (SPP) менее 10 лет;
- чистая приведённая стоимость (NPV) > 0 при заданной ставке дисконтирования;
- коэффициент «сбережения–инвестиции» (SIR) > 1,0;
- стоимость сэкономленной энергии ниже текущей цены ресурса.

**Типичный экономический потенциал:** 60–75 % от технического, что соответствует 25–45 % снижения потребления ОВК.

### Рыночный потенциал

Реалистичное снижение с учётом барьеров: несовпадения стимулов арендатора и владельца, ограниченного доступа к финансированию, дефицита технической квалификации, нарушений работы здания при реализации.

**Типичный рыночный потенциал:** 40–60 % от экономического — или 10–30 % фактического снижения потребления на практике.

## Потенциал по типам систем

### Центральные водяные системы охлаждения

{{< table title="Мероприятия по центральным системам охлаждения" >}}
| Мероприятие | Снижение потребления | Срок окупаемости, лет | Сложность |
|---|---|---|---|
| Замена чиллера (стандартный → высокоэффективный) | 15–30 % | 8–15 | Высокая |
| Сброс температуры конденсаторной воды | 10–20 % | 2–4 | Низкая |
| Сброс температуры хладоносителя | 5–15 % | 1–3 | Низкая |
| Переменный первичный расход (VPF) | 10–25 % | 4–8 | Средняя |
| Водяной экономайзер / free cooling | 20–40 % | 5–10 | Средняя–высокая |
| ЧРП вентилятора градирни | 15–30 % | 3–6 | Средняя |
| ЧРП насосов | 20–50 % | 2–5 | Средняя |
| Оптимизация последовательности включения | 5–15 % | 1–2 | Низкая |
{{< /table >}}

Показатель эффективности чиллерной установки:

{{< formula display="true" >}}
\text{кВт/кВт}_{\text{охл}} = \frac{W_{\text{комп}} + W_{\text{насос}} + W_{\text{вент.гр}}}{Q_{\text{охл}}}
{{< /formula >}}

Мощность насоса пропорциональна кубу расхода (законы подобия — affinity laws):

{{< formula display="true" >}}
\frac{P_2}{P_1} = \left(\frac{Q_2}{Q_1}\right)^3
{{< /formula >}}

Снижение расхода на 20 % уменьшает потребляемую мощность насоса приблизительно на 49 %.

### Крышные кондиционеры (RTU)

{{< table title="Мероприятия по крышным кондиционерам" >}}
| Мероприятие | Снижение потребления | Срок окупаемости, лет | Сложность |
|---|---|---|---|
| Замена блока (10 EER → 16+ EER) | 25–40 % | 6–12 | Средняя |
| Наладка / ремонт экономайзера | 15–30 % | 2–4 | Низкая |
| ЧРП вентилятора приточного воздуха | 20–40 % | 3–6 | Средняя |
| Управление вентиляцией по потребности (DCV) | 15–25 % | 4–7 | Средняя |
| Продвинутые последовательности управления RTU | 20–35 % | 3–5 | Средняя |
| Ночной откат температуры | 10–20 % | 1–2 | Низкая |
| Сброс температуры нагнетания (SAT reset) | 8–15 % | 1–3 | Низкая |
{{< /table >}}

Интегральный коэффициент энергоэффективности IEER (Integrated Energy Efficiency Ratio):

$$\text{IEER} = 0{,}02 \cdot A + 0{,}617 \cdot B + 0{,}238 \cdot C + 0{,}125 \cdot D$$

где $A, B, C, D$ — коэффициент EER при 100 %, 75 %, 50 %, 25 % нагрузки соответственно. Современные высокоэффективные RTU достигают IEER ≥ 14.

### Котельные системы

{{< table title="Мероприятия по системам теплоснабжения" >}}
| Мероприятие | Снижение потребления | Срок окупаемости, лет | Сложность |
|---|---|---|---|
| Замена конденсационным котлом (80 % → 96 % КПД) | 15–30 % | 7–12 | Высокая |
| Управление с погодозависимым сбросом температуры | 10–20 % | 2–4 | Низкая |
| Оптимизация горения | 5–10 % | 2–3 | Низкая |
| Очистка теплообменника / экономайзера котла | 5–12 % | 1–2 | Низкая |
| Каскадирование нескольких котлов | 8–18 % | 3–5 | Средняя |
| Сброс температуры горячей воды | 10–20 % | 1–3 | Низкая |
{{< /table >}}

КПД котла связан с температурой уходящих газов и избытком воздуха:

$$\eta_{\text{котёл}} = 1 - \bigl(\eta_{\text{уг}} + \eta_{\text{охл}} + \eta_{\text{пр}}\bigr)$$

Конденсационный режим (температура обратного теплоносителя < 55 °С) позволяет утилизировать скрытую теплоту конденсации водяных паров, повышая КПД с 80–85 % до 92–98 %.

## Стандарты энергоаудита

### ASHRAE 211 — уровни энергоаудита

**Уровень I — предварительное обследование:** визуальный осмотр, анализ счетов коммунальных услуг за 2–3 года, сравнение EUI с эталонными значениями, выявление очевидных потерь энергии. Стоимость: 50–150 руб./м².

**Уровень II — энергетическое обследование и анализ:** детальная инвентаризация систем, разработка поузлового баланса, выявление и оценка мероприятий по энергосбережению (ECM — Energy Conservation Measures) с финансовым анализом. Инженерные расчёты: $Q = U \cdot A \cdot \Delta T$, КПД при рабочих условиях, годовое потребление по видам. Стоимость: 150–500 руб./м².

**Уровень III — детальное обследование:** субучёт потребления по системам, калиброванная энергетическая модель (критерии ASHRAE 14: MBE ≤ ±5 %, CV(RMSE) ≤ 15 % для месячных данных), финансовый анализ инвестиционного качества, план измерения и верификации (M&V). Стоимость: 500–2000 руб./м².

### EN 16247-2 (Европейский стандарт энергоаудита зданий)

Европейский аналог предусматривает четыре этапа: подготовка, сбор данных, обследование, отчётность. Обязателен для организаций, подпадающих под требования директивы EED (Energy Efficiency Directive) с потреблением выше 50 МВт·ч/год.

## Методы финансового анализа

### Простой срок окупаемости (SPP)

{{< formula display="true" >}}
\text{SPP} = \frac{C_{\text{инвест}}}{S_{\text{год}}}
{{< /formula >}}

Достоинства: простота; ограничения: не учитывает временну́ю стоимость денег и срок службы оборудования.

### Чистая приведённая стоимость (NPV)

{{< formula display="true" >}}
\text{NPV} = \sum_{t=1}^{n} \frac{S_t}{(1+r)^t} - C_{\text{инвест}}
{{< /formula >}}

где $S_t$ — экономия в год $t$; $r$ — ставка дисконтирования (3–8 % для госпроектов, 8–15 % для коммерческих); $n$ — расчётный период.

### Внутренняя норма доходности (IRR)

Ставка дисконтирования, при которой NPV = 0:

{{< formula display="true" >}}
0 = \sum_{t=1}^{n} \frac{S_t}{(1+\text{IRR})^t} - C_{\text{инвест}}
{{< /formula >}}

Решение: реализовать мероприятие при IRR > MARR (минимальная приемлемая норма доходности).

### Коэффициент «сбережения–инвестиции» (SIR)

{{< formula display="true" >}}
\text{SIR} = \frac{PV(S)}{C_{\text{инвест}}}
{{< /formula >}}

$\text{SIR} > 1{,}0$ — экономически целесообразно; $\text{SIR} > 2{,}0$ — высокоэффективное вложение.

### Числовой пример

**Условие.** ЧРП на насосе контура охлаждённой воды: $C_{\text{инвест}} = 420\,000$ руб.; $S_{\text{год}} = 95\,000$ руб. (экономия на электроэнергии). Ставка дисконтирования $r = 10\,\%$; срок службы $n = 15$ лет.

**Решение:**
$$\text{SPP} = \frac{420\,000}{95\,000} = 4{,}4\ \text{года}$$

$$\text{NPV} = 95\,000 \times \frac{(1+0{,}10)^{15} - 1}{0{,}10 \times (1+0{,}10)^{15}} - 420\,000 = 95\,000 \times 7{,}606 - 420\,000 = 722\,570 - 420\,000 = 302\,570\ \text{руб.}$$

$$\text{SIR} = \frac{722\,570}{420\,000} = 1{,}72$$

Мероприятие экономически целесообразно: NPV > 0, SIR = 1,72, срок окупаемости — 4,4 года.

## Взаимодействие мероприятий

Экономия от отдельных ECM не суммируется линейно из-за взаимодействия систем.

**Освещение ↔ охлаждение:** снижение теплопритока от освещения на 50 % уменьшает нагрузку на охлаждение на 30–45 % от этой величины (с учётом доли тепла, идущей в охлаждаемое пространство, и КПД чиллера).

**Ограждающие конструкции ↔ оборудование:** улучшение теплозащиты снижает расчётную нагрузку, что позволяет уменьшить мощность заменяемых агрегатов — дополнительная экономия на капитальных затратах 20–40 %.

**Управление ↔ другие мероприятия:** SAT reset и DCV решают частично пересекающиеся задачи; суммарная экономия при одновременном внедрении обычно на 10–20 % ниже суммы отдельных оценок.

## Верификация экономии (IPMVP)

Международный протокол измерения и верификации (IPMVP) определяет четыре варианта:

- **Вариант A (изоляция модификации, ключевые параметры):** часть параметров измеряется, часть — принимается по договорённости.
- **Вариант B (изоляция модификации, все параметры):** непрерывное или краткосрочное измерение всех релевантных параметров.
- **Вариант C (всё здание):** сравнение суммарного потребления до и после нормализованного на погоду и занятость.
- **Вариант D (калиброванная модель):** использование энергетической модели, откалиброванной к фактическим данным.

Нормализованная экономия:

{{< formula display="true" >}}
S_{\text{норм}} = (E_{\text{баз, скорр}} - E_{\text{отчёт}}) \pm \text{корректировки}
{{< /formula >}}

Типичные корректировки: нормализация по ГДО/ГДО_охл, изменения занятости, режима работы.
