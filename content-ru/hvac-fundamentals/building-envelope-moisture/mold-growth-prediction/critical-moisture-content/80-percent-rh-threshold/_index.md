Порог 80 % относительной влажности поверхности — основной количественный критерий риска роста плесени, принятый в ASHRAE 160, ISO 13788 и европейской строительной практике. Этот эмпирически обоснованный порог охватывает мезофильные виды плесени (Aspergillus, Penicillium, Cladosporium), ответственные за большинство проблем с качеством воздуха в зданиях, и обеспечивает практическую конструктивную цель с разумным запасом безопасности.

## Физическое обоснование порога 80 %

### Биологическая основа

Минимальная активность воды для прорастания грибков определяется их физиологическими потребностями:

- Ксерофильные виды (Wallemia sebi, Eurotium amstelodami): a_w,min = 0,65 — рост возможен при ОВ > 65 %.
- Мезофильные строительные плесени (большинство Aspergillus, Penicillium): a_w,min = 0,78–0,82 → минимум ОВ 78–82 %.
- Гидрофильные виды (Stachybotrys chartarum, Chaetomium globosum): a_w,min = 0,90–0,95.

Порог 80 % — консервативная граница, превышающая минимум для мезофильных видов и обеспечивающая 2–4 % запаса относительно типичного минимума 76–78 % ОВ при комнатной температуре.

### Термодинамическая интерпретация

При ОВ 80 % парциальное давление пара на поверхности составляет:

{{< formula display="true" >}}
P_v = 0{,}80 \times P_{sat}(T_{surface})
{{< /formula >}}

Это условие обеспечивает достаточную химическую активность воды для адсорбции на целлюлозных субстратах выше уровня монослоя, но остаётся ниже порога капиллярной конденсации (~95 % ОВ для большинства строительных материалов). Именно в диапазоне 80–95 % ОВ вода адсорбируется в многослойных плёнках на поверхности пор — доступная форма для метаболизма грибков.

## Расчёт поверхностной ОВ

Поверхностная ОВ отличается от объёмной ОВ воздуха из-за температурного градиента в пограничном слое и стеновом пироге.

### Основная формула

{{< formula display="true" >}}
RH_{surface} = \frac{P_{v,air}}{P_{sat}(T_{surface})} \times 100\,\%
{{< /formula >}}

где:
- P_v,air — парциальное давление пара в помещении, Па;
- P_sat(T_surface) — давление насыщения при температуре поверхности, Па.

### Уравнение Magnus для давления насыщения

{{< formula display="true" >}}
P_{sat}(T) = 611{,}2 \cdot \exp\!\left(\frac{17{,}67 \cdot T}{T + 243{,}5}\right),\quad \text{Па}, \quad T\,\text{в °C}
{{< /formula >}}

### Расчёт температуры поверхности

Температура внутренней поверхности определяется через тепловое сопротивление конструкции:

{{< formula display="true" >}}
T_{surface} = T_i - (T_i - T_e) \cdot \frac{R_{si}}{R_{total}}
{{< /formula >}}

где R_si — сопротивление теплопередаче от внутреннего воздуха до поверхности (включая конвекцию и излучение), R_total — суммарное тепловое сопротивление.

### Численный пример: типовая каркасная стена

**Исходные данные.** Внутри: T_i = 21 °C, RH_i = 45 %. Снаружи: T_e = −15 °C. Конструкция: ГКЛ 12,7 мм + стекловата 140 мм + OSB 11 мм + WRB + виниловый сайдинг.

RSI стены: R_si = 0,13 м²·К/Вт (внутренняя конвекция); R_GKL = 0,01 м²·К/Вт; R_wool = 3,89 м²·К/Вт; R_OSB = 0,09 м²·К/Вт; R_e = 0,04 м²·К/Вт.

R_total = 0,13 + 0,01 + 3,89 + 0,09 + 0,04 = 4,16 м²·К/Вт.

Температура внутренней поверхности ГКЛ:

{{< formula display="true" >}}
T_{surface} = 21 - (21 - (-15)) \cdot \frac{0{,}13}{4{,}16} = 21 - 36 \cdot 0{,}031 = 19{,}9\,°C
{{< /formula >}}

P_sat(19,9 °C) = 611,2 × exp(17,67 × 19,9 / (19,9 + 243,5)) = 2330 Па.

P_v,i = 0,45 × P_sat(21 °C) = 0,45 × 2487 = 1119 Па.

{{< formula display="true" >}}
RH_{surface} = \frac{1119}{2330} \times 100 = 48{,}0\,\%
{{< /formula >}}

Поверхность безопасна (ОВ 48 %). Критическая внутренняя ОВ, при которой поверхностная ОВ достигнет 80 %:

{{< formula display="true" >}}
RH_{i,crit} = \frac{0{,}80 \times 2330}{2487} = 74{,}9\,\%
{{< /formula >}}

При внутренней ОВ выше 75 % возникает риск плесени на поверхности этой стены при −15 °C снаружи.

### Тепловые мостики

В зонах стоечного каркаса (шаг 600 мм) температура поверхности ниже, чем в полевой зоне. Линейная теплопередача стойки ψ ≈ 0,06 Вт/(м·К). Понижение температуры поверхности над стойкой:

{{< formula display="true" >}}
\Delta T_{bridge} \approx \frac{\psi \cdot (T_i - T_e)}{h_i \cdot L} = \frac{0{,}06 \times 36}{7{,}7 \times 0{,}09} = 3{,}1\,°C
{{< /formula >}}

Поверхностная температура над стойкой: 19,9 – 3,1 = 16,8 °C. P_sat(16,8 °C) = 1913 Па.

{{< formula display="true" >}}
RH_{surface,bridge} = \frac{1119}{1913} \times 100 = 58{,}5\,\%
{{< /formula >}}

Пока безопасно, но критическая внутренняя ОВ для тепловых мостиков:

{{< formula display="true" >}}
RH_{i,crit,bridge} = \frac{0{,}80 \times 1913}{2487} = 61{,}5\,\%
{{< /formula >}}

При влажности внутри >62 % (типично в ванной, кухне без вытяжки) риск плесени возникает над стойками каркаса. По EN ISO 16000-32, именно тепловые мостики являются основными очагами плесени в жилых зданиях.

## Критерий ASHRAE 160: 30-дневное скользящее среднее

### Формула критерия

{{< formula display="true" >}}
\overline{RH}_{30d,i} = \frac{1}{720} \sum_{j=i-719}^{i} RH_{surface,j} \leq 80\,\%
{{< /formula >}}

для всех часов i, когда T_surface,i > 5 °C.

Смысл: не разовое превышение порога, а устойчивая во времени влажность поверхности. Кратковременные пики ОВ (дождь, готовка) без нарушения условий. Именно 30-суточная «пропитка» обеспечивает накопление биомассы, достаточной для видимого роста.

### Алгоритм постобработки результатов моделирования

```
Для каждого часа i (i = 720 ... N):
    Если T_surface[i] > 5°C:
        RH_avg = среднее(RH_surface[i-719 : i])
        Если RH_avg > 80%:
            Записать час i как "час отказа"
Итого часов отказа → оценка риска
```

**Оценочная шкала:**
- 0 ч — конструкция соответствует критерию.
- 1–9 ч/год — низкий риск (граничные условия).
- 10–100 ч/год — умеренный риск, пересмотреть конструкцию.
- >100 ч/год — высокий риск, требуется переработка.

## Параметр времени увлажнения (TOW)

Время увлажнения (time of wetness, TOW) — кумулятивная мера продолжительности превышения критической ОВ с учётом интенсивности. Обобщённая форма (EN ISO 9223, адаптация):

{{< formula display="true" >}}
TOW_{eff} = \sum_{j} t_{wet,j} \cdot k_j - \sum_{j} \frac{t_{dry,j}}{\tau_{recovery}}
{{< /formula >}}

где:
- t_wet,j — продолжительность j-го периода увлажнения, ч;
- k_j — коэффициент интенсивности: k = 0 при ОВ < 80 %; k = 0,5 при 80–90 %; k = 1,0 при >90 %;
- τ_recovery — характеристическое время восстановления (спорадическое высыхание), ~24–48 ч.

TOW_eff > 0 означает накопление риска; TOW_eff < 0 — достаточное высыхание между эпизодами увлажнения.

### Кумулятивная модель индекса плесени (упрощённая)

Приближённая версия VTT для инженерных расчётов:

{{< formula display="true" >}}
\frac{dM}{dt} = \frac{1}{7} \cdot \left(\frac{RH - 80}{20}\right)^2 \cdot f(T) \quad \text{при } RH > 80\,\%
{{< /formula >}}

где f(T) = 1,0 при 20–25 °C; снижается за пределами этого диапазона.

M > 1 → начало прорастания (видимого роста нет, но споры активны).

## Конструктивные допуски

Проектные целевые значения поверхностной ОВ устанавливаются ниже 80 % с запасом безопасности на неопределённость свойств материалов, качество монтажа и вариативность климатических нагрузок:

{{< table title="Рекомендуемые конструктивные целевые значения поверхностной ОВ" >}}
| Конструкция | Целевая максимальная ОВ | Коэффициент безопасности SF |
|---|---|---|
| Стеновая сборка (полевая зона) | 70 % | 1,14 |
| Стеновая сборка (тепловые мостики) | 65 % | 1,23 |
| Скатная кровля (обшивка снизу) | 65 % | 1,23 |
| Подземные стены | 60 % | 1,33 |
| Плоская кровля (внутренняя обшивка) | 65 % | 1,23 |
{{< /table >}}

{{< formula display="true" >}}
SF = \frac{RH_{threshold}}{RH_{design}} = \frac{80\,\%}{RH_{design}}
{{< /formula >}}

**Источники неопределённости, учитываемые запасом:**

- Теплопроводность материала: ±10–15 % от номинала.
- Воздушные плёнки (конвекция): ±20–25 %.
- Фактическая внутренняя ОВ: ±10 % от проектной.
- Качество монтажа теплоизоляции (сжатие, зазоры): переменное.
- Инфильтрация воздуха через стыки: высоко переменная.

## Требования к мониторингу

### Расположение датчиков

По EN ISO 16000-32 «Внутренняя среда — метод оценки условий, способствующих росту плесени на поверхностях», критические точки:

- Наружные углы ограждающих конструкций (минимальная температура поверхности).
- Откосы оконных проёмов.
- Поверхность обшивки (холодная сторона).
- Интерфейсы паросдерживающих слоёв.
- Зоны тепловых мостиков (стойки, ригели, плиты перекрытия).

### Спецификации датчиков

{{< table title="Требования к датчикам мониторинга плесени" >}}
| Параметр | Точность | Время отклика | Интервал записи |
|---|---|---|---|
| Температура воздуха/поверхности | ±0,3 °C | <2 мин | 15–60 мин |
| Относительная влажность | ±2 % ОВ | <5 мин | 15–60 мин |
| Влажность древесины | ±1 % MC | <1 мин | 1–24 ч |
{{< /table >}}

### Пороги срабатывания

{{< table title="Уровни предупреждения при мониторинге" >}}
| Уровень | Порог | Действие |
|---|---|---|
| Информация | ОВ >70 % более 72 ч | Регистрация, анализ тенденции |
| Предупреждение | ОВ >75 % более 48 ч | Проверка вентиляции, осушения |
| Действие | ОВ >80 % более 24 ч | Немедленное расследование |
| Критический | ОВ >85 % более 12 ч | Принудительное осушение, осмотр |
{{< /table >}}

### Долгосрочное отслеживание

Ежегодный анализ данных мониторинга выявляет:
- Постепенное ухудшение теплоизоляции (конденсация воды снижает λ).
- Изменения в эксплуатации: увеличение количества жильцов, новые источники влаги.
- Строительные дефекты (промерзание углов, протечки кровли).

Минимальный период мониторинга для принятия проектных решений — 1 полный год (охват зимнего и летнего режима).

### Сезонный анализ

**Зима (отопительный сезон):** Максимальный риск в холодном климате — паровая тяга изнутри, низкая температура поверхностей, низкая ОВ воздуха, но высокая поверхностная ОВ.

**Лето (сезон охлаждения):** Риск в жарком влажном климате при кондиционировании — паровая тяга снаружи внутрь, возможная конденсация на охлаждённых внутренних поверхностях.

**Межсезонье:** Нестабильные условия паровой тяги, накопление влаги в переходных зонах; особенно опасны периоды, когда ОВ выше критического, а осушение не работает.

Порог 80 % ОВ поверхности является физически обоснованным и практически применимым критерием. Его правильное использование требует расчёта поверхностной, а не объёмной ОВ, применения 30-дневного скользящего среднего по ASHRAE 160, и учёта тепловых мостиков как зон повышенного риска.
