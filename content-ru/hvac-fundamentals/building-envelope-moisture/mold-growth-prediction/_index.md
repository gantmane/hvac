Рост плесени — критический режим отказа ограждающей конструкции, влияющий как на долговечность здания, так и на здоровье людей. Качественный критерий «избегать конденсации» недостаточен: плесень растёт при влажности ниже точки росы, на поверхностях с температурой выше 0 °C, при устойчивой относительной влажности ≥80 % в течение нескольких суток. Количественное прогнозирование риска выполняется с помощью эмпирических моделей — VTT, изоплет и критериев ASHRAE 160.

## Четыре условия роста плесени

Прорастание и рост грибков требуют одновременного присутствия четырёх факторов. Устранение любого из них предотвращает биологическое повреждение.

### 1. Субстрат

**Органические материалы с высоким содержанием питательных веществ:**

{{< table title="Классификация субстратов по чувствительности к плесени (модель VTT)" >}}
| Класс чувствительности | Примеры материалов | Критический порог ОВ |
|---|---|---|
| Очень чувствительный (S1) | Заболонь сосны, бумажная облицовка ГКЛ | 80 % |
| Чувствительный (S2) | Необработанная древесина, фанера, OSB | 80 % |
| Средне устойчивый (S3) | Бетон, ячеистый бетон, целлюлоза обработанная | 85 % |
| Устойчивый (S4) | Обработанная древесина, минеральная вата | 90 % |
{{< /table >}}

Минеральные материалы (каменная вата, бетон, металл, стекло) не поддерживают прямой рост плесени. Однако органические загрязнения (пыль, строительный мусор) на их поверхности обеспечивают достаточно питательных веществ для грибков.

### 2. Температура

Большинство строительных плесеней (Penicillium, Aspergillus, Cladosporium) растут в диапазоне 4–38 °C с оптимумом 20–25 °C:

- <4 °C: рост прекращается, споры остаются жизнеспособными.
- 4–15 °C: медленная скорость роста.
- 15–30 °C: быстрый рост, ускоряется с температурой.
- >38 °C: рост подавлен; большинство строительных плесеней погибают при >55 °C.

ASHRAE 160 (раздел 5.1) использует 5 °C как минимальную температуру для включения часа в расчёт риска плесени.

### 3. Относительная влажность поверхности

Поверхностная ОВ, а не объёмная ОВ воздуха, определяет доступность влаги для грибков. Поверхностная ОВ рассчитывается через парциальное давление пара и давление насыщения при температуре поверхности:

{{< formula display="true" >}}
RH_{surface} = \frac{P_{v,air}}{P_{sat}(T_{surface})} \times 100\,\%
{{< /formula >}}

Холодная поверхность имеет более высокую поверхностную ОВ, чем окружающий воздух. Пример: воздух 21 °C / 50 % ОВ → p_v = 1243 Па. Поверхность стены 14 °C → p_sat = 1597 Па. RH_surface = 1243/1597 × 100 = 77,8 % — уже в зоне умеренного риска.

**Критические пороги ОВ по видам плесени:**

| Тип плесени | Минимум a_w | Минимум ОВ, % |
|---|---|---|
| Ксерофильные (Eurotium, Wallemia) | 0,65 | 65 |
| Мезофильные (большинство Aspergillus, Penicillium) | 0,80 | 80 |
| Hydrophilic (Stachybotrys, Chaetomium) | 0,90 | 90 |

Порог 80 % ОВ — консервативный критерий ASHRAE 160, охватывающий мезофильные виды, ответственные за большинство проблем с качеством воздуха в зданиях.

### 4. Продолжительность воздействия

Одноразовое превышение порога ОВ не вызывает роста плесени. Имеет значение время накопления:

| ОВ поверхности | Минимальная продолжительность для прорастания |
|---|---|
| 80–85 % | 7–14 суток |
| 85–90 % | 2–5 суток |
| 90–95 % | 24–48 часов |
| >95 % | 6–12 часов |

## Критическое содержание влаги и активность воды

Активность воды (water activity, a_w) — отношение ОВ к 100 в десятичном виде. Связь с равновесным содержанием влаги (EMC, equilibrium moisture content) в материале определяется изотермой сорбции.

{{< table title="EMC деревянных материалов при критических условиях" >}}
| Материал | EMC при 80 % ОВ, % | EMC при 90 % ОВ, % | Критический порог, % по массе |
|---|---|---|---|
| Хвойная древесина | 16–18 | 22–26 | >19 |
| OSB | 17–19 | 24–28 | >19 |
| Фанера | 16–18 | 23–27 | >19 |
| Бумажная облицовка ГКЛ | 1,5–2,5 | 6–10 | >1,5 |
| Целлюлоза (обработанная) | 18–22 | 28–35 | >20 |
| Минеральная вата | 0,2–0,4 | 0,8–1,5 | нет прямого роста |
{{< /table >}}

При EMC ≥19 % в хвойной древесине (соответствует ~80 % поверхностной ОВ) возникает риск белой и бурой гнили. Это традиционный строительный критерий «20 % по массе» с небольшим запасом.

## Модели прогнозирования роста плесени

### Системы изоплет (isopleths)

Изоплеты — кривые на диаграмме температура–ОВ, соответствующие одинаковым скоростям роста плесени. Предельная линия наименьшего изоплета (LIM, limit isopleth for mould) определяет минимальные условия для прорастания:

{{< table title="Критические ОВ прорастания (LIM) по температуре, субстрат класса S1" >}}
| T, °C | ОВ прорастания, % | ОВ для роста 1 мм/нед, % |
|---|---|---|
| 10 | 85 | 92 |
| 15 | 82 | 88 |
| 21 | 80 | 85 |
| 27 | 78 | 83 |
{{< /table >}}

Изоплеты рассчитаны для стационарных условий. Переменные условия среды (суточные/сезонные колебания ОВ) требуют динамического подхода — модели VTT.

### Модель роста плесени VTT

Разработана VTT Technical Research Centre of Finland. Описывает накопленный индекс плесени M (mould index) как функцию температуры, ОВ, чувствительности субстрата и времени воздействия.

**Шкала индекса плесени:**

{{< table title="Шкала индекса плесени VTT" >}}
| M | Описание | Визуальное наблюдение |
|---|---|---|
| 0 | Нет роста | Споры неактивны |
| 1 | Единичные, микроскопические | Невидимы |
| 2 | Умеренные, <10 % поверхности | Обнаруживаются микроскопией |
| 3 | Видимые, 10–30 % поверхности | Начало визуального обнаружения |
| 4 | Видимые, 30–70 % поверхности | Чётко различимы |
| 5 | Обильные, 70–100 % поверхности | Обширная колонизация |
| 6 | Очень плотные, >100 % исходного | Плотные слои роста |
{{< /table >}}

**Критерий отказа:** M > 3 (ASHRAE 160, приложение к модели VTT, VTT Research Report VTT-R-0455-05).

**Уравнение скорости роста (упрощённое):**

{{< formula display="true" >}}
\frac{dM}{dt} = \frac{1}{7} \exp\left[-0{,}68 \ln(RH - A) - 13{,}9 \frac{\ln(RH - A)}{T}\right] \cdot k_1 \cdot k_2
{{< /formula >}}

где:
- M — индекс плесени;
- t — время, сут;
- RH — поверхностная ОВ, %;
- T — температура, °C;
- A — критический порог ОВ для класса субстрата (80 % для S1–S2, 85 % для S3, 90 % для S4);
- k₁, k₂ — коэффициенты, зависящие от типа субстрата и режима.

**Снижение индекса при высыхании:**

{{< formula display="true" >}}
\frac{dM}{dt}_{decline} = \begin{cases} -0{,}032 & M \in [1{,}0;\,2{,}0] \\ -0{,}016 & M \in [2{,}0;\,6{,}0] \end{cases}
{{< /formula >}}

Продолжительные периоды высыхания снижают M, но не уничтожают споры. Споры сохраняют жизнеспособность десятилетиями.

**Применение:**
1. Извлечь почасовые T и RH_surface на критических интерфейсах из гигротермической симуляции.
2. Рассчитать dM/dt для каждого часа.
3. Интегрировать по времени → M(t).
4. Сравнить M с критерием отказа M > 3.

### Биогигротермальные (BHT) модели

Продвинутые модели (реализованы в WUFI Bio, DELPHIN с биомодулем) связывают тепловлажностный расчёт с биологической кинетикой:

{{< formula display="true" >}}
\frac{\partial B}{\partial t} = \mu(T, RH, S) \cdot B - d(T) \cdot B
{{< /formula >}}

где B — концентрация биомассы; µ — удельная скорость роста; d — скорость отмирания.

Функция скорости роста:

{{< formula display="true" >}}
\mu(T, RH, S) = \mu_{max} \cdot f_T(T) \cdot f_{RH}(RH) \cdot f_S(S)
{{< /formula >}}

Это позволяет учитывать взаимодействие теплопередачи, переноса влаги и биологической активности в единой расчётной модели.

## Стандарт ASHRAE 160

**ASHRAE Standard 160-2016: Criteria for Moisture-Control Design Analysis in Buildings** — основной документ для количественной проверки конструкций ограждающих конструкций по критерию плесени.

### Критерий отказа (раздел 5.1)

{{< formula display="true" >}}
\overline{RH}_{30d} = \frac{1}{720}\sum_{i=t-719}^{t} RH_{surface,i} \leq 80\,\%
{{< /formula >}}

для всех часов i, когда T_surface > 5 °C.

30-дневное скользящее среднее поверхностной ОВ не должно превышать 80 % при температуре выше 5 °C.

### Климатические нагрузки ASHRAE 160

- **Наружный климат:** Справочный год ASHRAE 160 — год с повышенной влажностью (не средний, а консервативный), аналог TMY3/TMY4 с отбором влажного года из 30-летней базы.
- **Внутренняя нагрузка:** График производства влаги в помещении: Q_moisture = 0,071 кг/(ч·чел) при расчётной плотности заселения.

### Алгоритм проверки

**Шаг 1.** Гигротермическое моделирование (WUFI, DELPHIN, MOISTURE-EXPERT) с почасовым климатическим файлом ≥3 лет.

**Шаг 2.** Извлечь T и RH на критических интерфейсах (поверхность обшивки, интерфейс паросдерживающего слоя).

**Шаг 3.** Для каждого часа i при T_i > 5 °C вычислить 30-дневное скользящее среднее RH (среднее 720 предшествующих часов).

**Шаг 4.** Если RH_avg,30d > 80 % — отказ в этот час.

**Шаг 5.** Оценка:
- 0 часов отказа — конструкция принята.
- <10 часов/год — низкий риск.
- 10–100 часов/год — умеренный риск, пересмотреть конструкцию.
- >100 часов/год — высокий риск, требуется переработка.

### ISO 13788

Европейский стандарт ISO 13788 «Гигротермические характеристики строительных компонентов и элементов — внутренняя температура поверхности, позволяющая избежать критической поверхностной влажности и межслойной конденсации» устанавливает упрощённый метод:

- Минимальный температурный фактор f_Rsi для предотвращения поверхностной плесени: f_Rsi = (T_si – T_e) / (T_i – T_e) ≥ f_Rsi,min.
- f_Rsi,min = 0,72 для жилых зданий при климатических зонах Европы.
- Метод Глейзера для проверки межслойной конденсации (упрощённый стационарный расчёт).

## Стратегии предотвращения роста плесени

### Контроль температуры поверхности

Температурный фактор (temperature factor) f_Rsi — ключевая конструктивная переменная:

{{< formula display="true" >}}
f_{Rsi} = \frac{T_{si} - T_e}{T_i - T_e}
{{< /formula >}}

Чем выше f_Rsi (стремится к 1,0), тем теплее внутренняя поверхность относительно наружной. Для предотвращения плесени при 21 °C / 45 % ОВ внутри (T_dp = 9,3 °C):

{{< formula display="true" >}}
T_{si,min} = T_{dp} + 2{,}5\,°C = 11{,}8\,°C \quad \text{(запас безопасности)}
{{< /formula >}}

**Конструктивные меры повышения f_Rsi:**
- Непрерывная наружная теплоизоляция (elimination of stud thermal bridges).
- Тепловые разрывы в узлах примыкания плит перекрытия.
- Местное утепление углов и откосов (зоны повышенного риска).

### Контроль относительной влажности

По ASHRAE 62.1 и ISO 7730:

- Зима: ОВ внутри 30–40 %; выше 45 % создаёт риск конденсации на окнах (двойное остекление).
- Лето (охлаждение): ОВ внутри 45–55 %.

Основные методы управления ОВ:
- Осушение (автономный или интегрированный в HVAC).
- Вентиляция с удалением источников влаги (кухня, ванная).
- Герметизация воздушного барьера для предотвращения инфильтрации влажного наружного воздуха.

### Выбор материалов

{{< table title="Замена стандартных материалов на устойчивые к плесени" >}}
| Зона применения | Стандартный материал | Устойчивая альтернатива |
|---|---|---|
| Стены подвала | ГКЛ с бумажной облицовкой | ГКЛ без бумаги или цементная плита |
| Стены ванной | Стандартный ГКЛ | ГКЛ влагостойкий (Knauf Green, Gyproc WR) |
| Подполье | Стекловата | ППУ закрытоячеистый или минеральная вата |
| Обшивка кровли | OSB | OSB с водостойкой обработкой или фанера |
{{< /table >}}

## Численный пример: расчёт индекса VTT

**Условие.** Холодный угол каркасной стены. Поверхностная ОВ 88 % в течение 30 дней (720 ч), T = 18 °C. Субстрат — OSB (класс S2, A = 80 %).

**Приближённый расчёт скорости роста** по упрощённой формуле VTT:

При RH = 88 %, T = 18 °C, A = 80 %:

ln(RH – A) = ln(88 – 80) = ln(8) = 2,08.

{{< formula display="true" >}}
\frac{dM}{dt} \approx \frac{1}{7} \exp\left[-0{,}68 \times 2{,}08 - 13{,}9 \times \frac{2{,}08}{18}\right] = \frac{1}{7} \exp[-1{,}414 - 1{,}606]
{{< /formula >}}

{{< formula display="true" >}}
\frac{dM}{dt} = \frac{1}{7} \exp(-3{,}02) = \frac{1}{7} \times 0{,}049 = 0{,}007\,\text{ед/сут}
{{< /formula >}}

За 30 суток: M = 0,007 × 30 = 0,21 — рост незначителен (M < 1, споры неактивны).

**Повышение ОВ до 92 % на 30 дней:**

ln(92 – 80) = ln(12) = 2,48.

{{< formula display="true" >}}
\frac{dM}{dt} = \frac{1}{7} \exp[-0{,}68 \times 2{,}48 - 13{,}9 \times \frac{2{,}48}{18}] = \frac{1}{7}\exp(-3{,}61) = \frac{0{,}027}{7} = 0{,}0039\,\text{ед/ч}
{{< /formula >}}

Ожидаемый результат: 0,0039 × 720 = 2,8 — приближается к критерию M = 3. При незначительном увеличении ОВ или длительности до 35 суток критерий будет превышен.

**Вывод.** ОВ 92 % на поверхности OSB в течение 30+ суток при 18 °C создаёт неприемлемый риск роста плесени по модели VTT. Требуется улучшение теплоизоляции угла для повышения поверхностной температуры.

## Мониторинг и контроль

**Размещение датчиков** (ASHRAE Fundamentals гл. 25):
- Поверхность обшивки (холодная сторона ГКЛ).
- Интерфейс паросдерживающего слоя.
- Угловые зоны и тепловые мостики.
- Откосы оконных проёмов.

**Параметры датчиков:**
- Точность T: ±0,3 °C; ОВ: ±2 %.
- Интервал записи: 15–60 минут.

**Пороги срабатывания:**
- Предупреждение: ОВ >75 % более 48 ч.
- Действие: ОВ >80 % более 24 ч.
- Критический: ОВ >85 % более 12 ч.

Прогнозирование роста плесени требует интегрированного анализа температуры поверхности, поверхностной ОВ, свойств субстрата и продолжительности воздействия с применением проверенных эмпирических моделей. Простое избегание конденсации — недостаточное условие; критерий ASHRAE 160 и модель VTT обеспечивают количественную верификацию конструкции.
