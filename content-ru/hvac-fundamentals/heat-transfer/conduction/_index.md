Теплопроводность — перенос тепловой энергии через вещество без макроскопического перемещения его частиц, только за счёт хаотического молекулярного движения, колебаний кристаллической решётки и движения свободных электронов в металлах. В задачах HVAC теплопроводность определяет тепловые потери через ограждающие конструкции зданий, сопротивление изоляции трубопроводов и стенок теплообменников.

## Закон Фурье: вывод и физический смысл

Жан Батист Жозеф Фурье в 1822 г. постулировал, что плотность теплового потока пропорциональна градиенту температуры и направлена противоположно ему:

{{< formula display="true" >}}
\mathbf{q}'' = -k \, \nabla T \quad [\text{Вт/м}^2]
{{< /formula >}}

В одномерном случае (ось $x$):

{{< formula display="true" >}}
q'' = -k \frac{dT}{dx}
{{< /formula >}}

Знак минус выражает второй закон термодинамики: тепловой поток направлен в сторону убывания температуры. Коэффициент теплопроводности $k$ [Вт/(м·К)] — интенсивная свойство вещества, зависящее от температуры, фазового состояния, пористости и влажности материала.

**Физическое значение знака и размерности.** Если $T_1 > T_2$ и координата $x$ направлена от горячей стороны к холодной, то $dT/dx < 0$ и $q'' > 0$ — поток тепла положителен (энергия уходит в направлении $x$).

### Трёхмерное уравнение теплопроводности

Для материала с внутренним тепловыделением $\dot{q}$ [Вт/м³]:

{{< formula display="true" >}}
\rho c_p \frac{\partial T}{\partial t} = \nabla \cdot (k \nabla T) + \dot{q}
{{< /formula >}}

В стационарном режиме ($\partial T / \partial t = 0$) без внутреннего тепловыделения это уравнение Лапласа: $\nabla^2 T = 0$.

## Теплопроводность плоской стенки

### Одиночный однородный слой

Интегрируя закон Фурье для постоянного $k$, плоской стенки толщиной $L$, площадью $A$ при граничных температурах $T_1$ и $T_2$:

{{< formula display="true" >}}
Q = k A \frac{T_1 - T_2}{L} \quad [\text{Вт}]
{{< /formula >}}

**Тепловое сопротивление** (по аналогии с законом Ома $I = \Delta V / R$):

{{< formula display="true" >}}
R_{cond} = \frac{L}{k A} \quad [\text{К/Вт}]
{{< /formula >}}

Удельное тепловое сопротивление на единицу площади (R-значение):

{{< formula display="true" >}}
R = \frac{L}{k} \quad [\text{м}^2\text{·К/Вт}]
{{< /formula >}}

Температурный профиль внутри однородного слоя линеен: $T(x) = T_1 - (T_1 - T_2) x/L$.

### Многослойная конструкция (последовательное соединение)

Для $n$ плоских слоёв, соединённых последовательно (нет теплового потока в обход):

{{< formula display="true" >}}
R_{tot} = \sum_{j=1}^{n} \frac{L_j}{k_j} + \frac{1}{h_i} + \frac{1}{h_e}
\quad \Rightarrow \quad
Q = \frac{T_i - T_e}{R_{tot}} \cdot A
{{< /formula >}}

Здесь $h_i$ и $h_e$ — коэффициенты суммарного поверхностного теплообмена (конвекция + излучение) на внутренней и наружной поверхностях. По ISO 6946:2017 для расчёта $U$-значения принимают: $R_{si} = 0{,}13$ м²·К/Вт (внутри), $R_{se} = 0{,}04$ м²·К/Вт (снаружи).

**Коэффициент теплопередачи (U-значение)**:

{{< formula display="true" >}}
U = \frac{1}{R_{tot}} \quad [\text{Вт/(м}^2\text{·К)}]
{{< /formula >}}

### Температуры на границах слоёв

Для проверки риска конденсации важно знать температуру каждой границы:

{{< formula display="true" >}}
T_j = T_i - Q \cdot \left(\frac{1}{h_i} + \sum_{l=1}^{j} \frac{L_l}{k_l}\right)
{{< /formula >}}

## Цилиндрическая геометрия (трубы, изоляция труб)

Для бесконечно длинного цилиндра с внутренним радиусом $r_1$ и внешним $r_2$, коэффициентом теплопроводности $k$, при постоянных температурах поверхностей $T_1$ и $T_2$ тепловой поток на единицу длины:

{{< formula display="true" >}}
q' = \frac{2\pi k (T_1 - T_2)}{\ln(r_2/r_1)} \quad [\text{Вт/м}]
{{< /formula >}}

Тепловое сопротивление на единицу длины:

{{< formula display="true" >}}
R'_{cyl} = \frac{\ln(r_2/r_1)}{2\pi k} \quad [\text{К·м/Вт}]
{{< /formula >}}

Для многослойной цилиндрической конструкции (труба + изоляция) сопротивления суммируются:

{{< formula display="true" >}}
R'_{tot} = \frac{\ln(r_2/r_1)}{2\pi k_{pipe}} + \frac{\ln(r_3/r_2)}{2\pi k_{ins}} + \frac{1}{2\pi r_3 h_e}
{{< /formula >}}

### Числовой пример: потери теплоты стальной трубы

Стальная труба DN100 (наружный диаметр 114,3 мм, стенка 4 мм), покрытая минватой $t = 60$ мм, $k_{ins} = 0{,}040$ Вт/(м·К). Температура теплоносителя 90°С, воздуха 20°С, $h_e = 10$ Вт/(м²·К).

Параметры: $r_1 = 53{,}15$ мм, $r_2 = 57{,}15$ мм, $r_3 = 117{,}15$ мм.

{{< formula display="true" >}}
R'_{steel} = \frac{\ln(57{,}15/53{,}15)}{2\pi \times 58} = \frac{0{,}073}{364{,}4} = 2{,}0 \times 10^{-4} \;\text{К·м/Вт}
{{< /formula >}}

{{< formula display="true" >}}
R'_{ins} = \frac{\ln(117{,}15/57{,}15)}{2\pi \times 0{,}040} = \frac{0{,}716}{0{,}2513} = 2{,}849 \;\text{К·м/Вт}
{{< /formula >}}

{{< formula display="true" >}}
R'_{conv} = \frac{1}{2\pi \times 0{,}11715 \times 10} = \frac{1}{7{,}36} = 0{,}136 \;\text{К·м/Вт}
{{< /formula >}}

{{< formula display="true" >}}
R'_{tot} = 2{,}985 \;\text{К·м/Вт}
\quad\Rightarrow\quad
q' = \frac{90-20}{2{,}985} = 23{,}5 \;\text{Вт/м}
{{< /formula >}}

На 100 м трубопровода суммарная тепловая потеря составит 2350 Вт.

## Критический радиус изоляции

Для одиночного цилиндрического трубопровода с наружной конвекцией суммарное сопротивление в зависимости от радиуса внешней поверхности изоляции $r_3$:

{{< formula display="true" >}}
R'_{tot}(r_3) = R'_{pipe} + \frac{\ln(r_3/r_2)}{2\pi k_{ins}} + \frac{1}{2\pi r_3 h_e}
{{< /formula >}}

Минимум $R'_{tot}$ достигается при **критическом радиусе**:

{{< formula display="true" >}}
r_{cr} = \frac{k_{ins}}{h_e}
{{< /formula >}}

При $r_3 < r_{cr}$ добавление изоляции **увеличивает** потери (рост площади поверхности доминирует над ростом сопротивления). При $r_3 > r_{cr}$ — наоборот. Для типичных условий HVAC: $k_{ins} = 0{,}040$ Вт/(м·К), $h_e = 10$ Вт/(м²·К): $r_{cr} = 4$ мм. Любая труба диаметром более 8 мм уже за критическим радиусом, поэтому изоляция всегда снижает потери.

## Сферическая геометрия

Тепловой поток через сферическую оболочку ($r_1 < r_2$):

{{< formula display="true" >}}
Q = \frac{4\pi k r_1 r_2 (T_1 - T_2)}{r_2 - r_1} \quad [\text{Вт}]
{{< /formula >}}

Тепловое сопротивление:

{{< formula display="true" >}}
R_{sph} = \frac{r_2 - r_1}{4\pi k r_1 r_2}
{{< /formula >}}

Применяется при расчёте теплопотерь через изолированные шаровые резервуары и оборудование.

## Двумерная и трёхмерная теплопроводность: тепловые мосты

Тепловые мосты (thermal bridges) — зоны конструкции с повышенным удельным тепловым потоком. Возникают в местах сквозного пересечения теплоизоляции металлическими и бетонными включениями: углы, примыкания, балконные плиты, крепёж.

### Линейный тепловой мост (ψ-значение)

По ISO 10211:2017 линейный коэффициент теплопередачи $\psi$ [Вт/(м·К)] учитывает дополнительный тепловой поток сверх одномерного расчёта:

{{< formula display="true" >}}
Q_{total} = U_{1D} \cdot A \cdot \Delta T + \psi \cdot l \cdot \Delta T
{{< /formula >}}

Дополнительные теплопотери через тепловой мост длиной $l$ на погонный метр:

{{< formula display="true" >}}
\Delta Q = \psi \cdot l \cdot \Delta T
{{< /formula >}}

**Типовые ψ-значения по EN ISO 14683**:

{{< table title="Линейные коэффициенты теплопередачи для типовых тепловых мостов" >}}
| Тип теплового моста | $\psi$, Вт/(м·К) | Метод расчёта |
|---|---|---|
| Балконная плита (жб) | 0,30–0,80 | Численный по ISO 10211 |
| Примыкание балконной плиты (отсечка XPS) | 0,05–0,15 | Численный |
| Угол наружный | −0,05…0 | Геометрический |
| Угол внутренний | +0,05…+0,10 | Геометрический |
| Сквозной анкер (нержавеющая сталь) | 0,008/шт | Точечный $\chi$ |
| Сквозной анкер (углеродистая сталь) | 0,04/шт | Точечный $\chi$ |
{{< /table >}}

### Минимальная температура на внутренней поверхности

По ISO 10211 температурный коэффициент $f_{Rsi}$ определяет минимальную температуру внутренней поверхности при тепловом мосте:

{{< formula display="true" >}}
f_{Rsi} = \frac{T_{si,min} - T_e}{T_i - T_e} \geq f_{Rsi,min}
{{< /formula >}}

При условиях Москвы ($T_i = 20°$C, $T_e = -26°$C, $\varphi_i = 55\%$, температура точки росы $T_{dp} \approx 10°$C): $f_{Rsi,min} = (10 - (-26))/(20 - (-26)) = 0{,}783$.

## Влажностный режим ограждений

Нестационарная диффузия водяного пара описывается уравнением, аналогичным уравнению теплопроводности. Критерий ISO 13788:2012 — отсутствие конденсации на внутренней поверхности, когда $T_{si} > T_{dp}$.

Сопротивление паропроницанию многослойной конструкции:

{{< formula display="true" >}}
R_\pi = \sum_{j} \frac{d_j}{\delta_j}
{{< /formula >}}

где $d_j$ — толщина слоя (м), $\delta_j$ — коэффициент паропроницаемости (мг/(м·ч·Па)).

## Нестационарная теплопроводность

Уравнение теплопроводности с зависимостью от времени:

{{< formula display="true" >}}
\frac{\partial T}{\partial t} = \alpha \frac{\partial^2 T}{\partial x^2}, \quad \alpha = \frac{k}{\rho c_p}
{{< /formula >}}

Коэффициент температуропроводности $\alpha$ [м²/с] определяет скорость выравнивания температуры.

{{< table title="Коэффициент температуропроводности строительных материалов" >}}
| Материал | $\alpha$, м²/с × 10⁻⁶ |
|---|---|
| Медь | 111 |
| Алюминий | 97 |
| Сталь | 14 |
| Бетон тяжёлый | 0,75 |
| Газобетон D500 | 0,38 |
| Минвата | 0,27 |
| Дерево (сосна) | 0,14 |
{{< /table >}}

### Метод сосредоточенной ёмкости (Bi < 0,1)

При $Bi = h L_c / k < 0{,}1$ (характерная длина $L_c = V/A_s$) внутренними градиентами можно пренебречь. Температура тела меняется по закону:

{{< formula display="true" >}}
\frac{T(t) - T_\infty}{T_i - T_\infty} = e^{-t/\tau}, \quad \tau = \frac{\rho c_p V}{h A_s}
{{< /formula >}}

**Число Фурье** $Fo = \alpha t / L_c^2$ — безразмерное время. При $Fo > 0{,}2$ достаточно удержать первый член ряда Фурье в решении задачи теплопроводности.
