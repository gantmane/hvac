Уравнения состояния (EOS, equation of state) — это математические модели, связывающие термодинамические свойства хладагентов в единую систему описания. Выбор модели определяет точность расчётов холодопроизводительности, КПД компрессора и поведения системы в переходных режимах. Современные инженерные пакеты NIST REFPROP v10 и CoolProp используют многопараметрические уравнения на основе свободной энергии Гельмгольца (Helmholtz free energy), обеспечивающие точность ±0,1 % в типовом рабочем диапазоне (ASHRAE Handbook Fundamentals, гл. 30).

## Физические принципы

Фундаментальное уравнение состояния связывает три переменных состояния:

{{< formula display="true" >}}
f(P,\, V,\, T) = 0
{{< /formula >}}

В явной форме через коэффициент сжимаемости {{< formula >}}Z{{< /formula >}} (compressibility factor):

{{< formula display="true" >}}
P = Z \frac{\rho R T}{M}
{{< /formula >}}

где {{< formula >}}\rho{{< /formula >}} — плотность (кг/м³), {{< formula >}}R = 8{,}314{{< /formula >}} Дж/(моль·К) — универсальная газовая постоянная, {{< formula >}}T{{< /formula >}} — абсолютная температура (К), {{< formula >}}M{{< /formula >}} — молярная масса (кг/моль). При {{< formula >}}Z = 1{{< /formula >}} получаем уравнение идеального газа; для реальных хладагентов {{< formula >}}Z \neq 1{{< /formula >}} и зависит от приведённых параметров {{< formula >}}T_r = T/T_c{{< /formula >}}, {{< formula >}}P_r = P/P_c{{< /formula >}}.

Все точные многопараметрические модели основаны на представлении через **свободную энергию Гельмгольца**:

{{< formula display="true" >}}
\alpha(\delta,\, \tau) = \alpha_0(\tau) + \alpha_r(\delta,\, \tau)
{{< /formula >}}

где {{< formula >}}\delta = \rho / \rho_c{{< /formula >}} — приведённая плотность, {{< formula >}}\tau = T_c / T{{< /formula >}} — обратная приведённая температура, {{< formula >}}\alpha_0{{< /formula >}} — вклад идеального газа, {{< formula >}}\alpha_r{{< /formula >}} — остаточный (residual) вклад. Все термодинамические свойства вычисляются через частные производные:

{{< formula display="true" >}}
P = \rho R T \left(1 + \delta \frac{\partial \alpha_r}{\partial \delta}\right)_\tau
{{< /formula >}}

{{< formula display="true" >}}
s = R \left(\tau \frac{\partial \alpha_0}{\partial \tau} + \tau \frac{\partial \alpha_r}{\partial \tau} - \alpha_0 - \alpha_r\right)
{{< /formula >}}

{{< formula display="true" >}}
h = R T \left(1 + \tau \frac{\partial \alpha_0}{\partial \tau} + \tau \frac{\partial \alpha_r}{\partial \tau} + \delta \frac{\partial \alpha_r}{\partial \delta}\right)
{{< /formula >}}

## Классификация уравнений состояния

### Вириальные уравнения (virial equations)

Вириальное разложение по молярному объёму {{< formula >}}V_m{{< /formula >}}:

{{< formula display="true" >}}
Z = 1 + \frac{B(T)}{V_m} + \frac{C(T)}{V_m^2} + \ldots
{{< /formula >}}

где {{< formula >}}B(T){{< /formula >}} — второй вириальный коэффициент (м³/моль), {{< formula >}}C(T){{< /formula >}} — третий. Применимы для паровой фазы при умеренных давлениях (до 10 МПа). Точность падает вблизи насыщения и критической точки.

### Кубические уравнения состояния

Кубические уравнения (cubic EOS) дают аналитическое решение и удобны для быстрых оценок, но имеют погрешность 5–15 % в плотной фазе.

**Редлих–Квонг (Redlich–Kwong, RK):**

{{< formula display="true" >}}
P = \frac{RT}{V_m - b} - \frac{a}{T^{0{,}5} V_m (V_m + b)}
{{< /formula >}}

**Соаве–Редлих–Квонг (Soave–Redlich–Kwong, SRK):**

{{< formula display="true" >}}
P = \frac{RT}{V_m - b} - \frac{a(T)}{V_m (V_m + b)}
{{< /formula >}}

с температурной функцией {{< formula >}}a(T) = a_c \left[1 + m(1 - \sqrt{T_r})\right]^2{{< /formula >}}, где параметр {{< formula >}}m{{< /formula >}} определяется через ацентрический фактор.

**Пенг–Робинсон (Peng–Robinson, PR):**

{{< formula display="true" >}}
P = \frac{RT}{V_m - b} - \frac{a(T)}{V_m^2 + 2bV_m - b^2}
{{< /formula >}}

Уравнение Пенг–Робинсон лучше воспроизводит плотности жидкой фазы, чем SRK, однако оба уравнения дают погрешность 5–10 % по плотности жидкости вблизи насыщения, что делает их непригодными для точного проектирования теплообменников.

### Уравнения Бенедикта–Вебба–Рубина (Benedict–Webb–Rubin, BWR)

Уравнение BWR и его модификация MBWR содержат до 32 коэффициентов и описывают обе фазы с погрешностью 0,5–2 %. Используются в исторических версиях REFPROP и ряде промышленных пакетов.

### Многопараметрические уравнения на основе функции Гельмгольца

Современный стандарт: остаточная часть {{< formula >}}\alpha_r(\delta, \tau){{< /formula >}} включает 20–50 членов степенных и экспоненциальных рядов, точно воспроизводящих критическое поведение:

{{< formula display="true" >}}
\alpha_r(\delta,\tau) = \sum_i n_i \delta^{d_i} \tau^{t_i} + \sum_j n_j \delta^{d_j} \tau^{t_j} e^{-\delta^{c_j}} + \sum_k n_k \delta^{d_k} \tau^{t_k} e^{-\eta_k(\delta-\varepsilon_k)^2 - \beta_k(\tau-\gamma_k)^2}
{{< /formula >}}

где {{< formula >}}n_i, d_i, t_i, c_j, \eta_k, \varepsilon_k, \beta_k, \gamma_k{{< /formula >}} — подобранные коэффициенты. NIST REFPROP v10 реализует эту форму для более чем 140 веществ, достигая точности ±0,1 % по плотности и ±0,5 % по производным свойствам.

### Вспомогательные (ancillary) уравнения

Для кривой насыщения используются компактные аппроксимации:

{{< formula display="true" >}}
\ln\frac{P_{\text{нас}}}{P_c} = \frac{T_c}{T} \sum_i N_i \theta^{n_i}, \quad \theta = 1 - \frac{T}{T_c}
{{< /formula >}}

{{< formula display="true" >}}
\frac{\rho_l}{\rho_c} = 1 + \sum_i N_i \theta^{n_i}
{{< /formula >}}

Эти уравнения обеспечивают быстрое начальное приближение для итерационных алгоритмов расчёта фазового равновесия.

## Численный пример — расчёт плотности R-32 при перегреве

**Условие:** R-32 (дифторметан, GWP = 675) при T = 60 °C = 333,15 К, P = 2,5 МПа. Требуется определить плотность, энтальпию и сравнить модели.

Критические параметры R-32: {{< formula >}}T_c = 351{,}26{{< /formula >}} К, {{< formula >}}P_c = 5{,}782{{< /formula >}} МПа, {{< formula >}}\rho_c = 424{{< /formula >}} кг/м³.

Приведённые параметры:

{{< formula display="true" >}}
\tau = \frac{T_c}{T} = \frac{351{,}26}{333{,}15} = 1{,}054, \quad P_r = \frac{P}{P_c} = \frac{2{,}5}{5{,}782} = 0{,}432
{{< /formula >}}

По данным NIST REFPROP v10 (уравнение Гельмгольца, ASHRAE Handbook Fundamentals, гл. 30):

{{< table title="Сравнение EOS для R-32 при 60 °C, 2,5 МПа" >}}
| Модель | {{< formula >}}\rho{{< /formula >}}, кг/м³ | {{< formula >}}h{{< /formula >}}, кДж/кг | Погрешность по {{< formula >}}\rho{{< /formula >}} |
|--------|---------|---------|------------|
| REFPROP v10 (эталон) | 88,7 | 548,2 | — |
| CoolProp (Гельмгольц) | 88,7 | 548,2 | <0,01 % |
| Пенг–Робинсон | 80,9 | 553,7 | −8,8 % |
| Идеальный газ | 66,7 | — | −24,8 % |
{{< /table >}}

Вывод: при умеренных степенях перегрева кубические уравнения дают погрешность ~9 % по плотности, что ведёт к недооценке работы компрессора и переоценке COP на 5–8 %.

## Расчёт работы идеального сжатия

При адиабатном изоэнтропном сжатии от состояния ({{< formula >}}P_1, s_1{{< /formula >}}) до давления {{< formula >}}P_2{{< /formula >}} удельная работа:

{{< formula display="true" >}}
w_{is} = h(P_2,\, s_1) - h(P_1,\, s_1)
{{< /formula >}}

Реальная работа с учётом изоэнтропного КПД {{< formula >}}\eta_{is}{{< /formula >}}:

{{< formula display="true" >}}
w_{\text{реал}} = \frac{w_{is}}{\eta_{is}}
{{< /formula >}}

Типовые значения {{< formula >}}\eta_{is}{{< /formula >}}: 0,75–0,82 — поршневые компрессоры; 0,80–0,88 — винтовые; 0,85–0,92 — центробежные (ASHRAE Handbook Fundamentals, гл. 38).

## Смеси хладагентов

Для смесей (R-407C, R-410A, R-32/R-134a/R-125) расчёт ведётся через правила смешивания (mixing rules). Остаточная энергия Гельмгольца смеси:

{{< formula display="true" >}}
\alpha_r^{\text{смесь}}(\delta, \tau, \mathbf{x}) = \sum_i x_i \alpha_{r,i}(\delta, \tau) + \Delta \alpha_r(\delta, \tau, \mathbf{x})
{{< /formula >}}

где {{< formula >}}\Delta \alpha_r{{< /formula >}} — вклад бинарного взаимодействия с параметрами {{< formula >}}\beta_{ij}, \gamma_{ij}{{< /formula >}}. Эти параметры определяются экспериментально и хранятся в базах данных REFPROP и CoolProp.

## Стандарты и нормативные требования

- **NIST REFPROP v10** — эталонная база данных; реализует многопараметрические EOS для ~140 чистых веществ и более 100 смесей.
- **ASHRAE Handbook Fundamentals, гл. 30–31** — справочные таблицы свойств и описание методологии.
- **ASHRAE Standard 34** — обозначение и классификация безопасности хладагентов; ссылки на EOS.
- **ISO 817** — номенклатура и маркировка хладагентов.
- **EN 378-1** — требования к расчётным моделям холодильных систем.
- **IAPWS-IF97** — стандарт для воды и водяного пара (применяется в тепловых насосах с водяным контуром).

## Практические рекомендации

Для предварительных оценок (погрешность 5–10 %) допустимо использовать уравнения Пенг–Робинсон или SRK. Для проектирования систем и сертификационных расчётов (SEER, COP, HSPF) следует применять только REFPROP v10 или CoolProp, обеспечивающих точность ±0,5 % для R-134a, R-410A, R-32 (согласно ASHRAE 205).

Вблизи критической точки ({{< formula >}}T_c = 101{,}1{{< /formula >}} °C для R-134a, {{< formula >}}T_c = 31{,}1{{< /formula >}} °C для CO₂) только многопараметрические уравнения Гельмгольца воспроизводят расходимость теплоёмкости и критические флуктуации; кубические EOS теряют 30–50 % точности.

Все расчёты, на которые ссылается техническая документация по EN 378 или СП 60.13330, должны использовать уравнения состояния, верифицированные в соответствии с ASHRAE Standard 34.
