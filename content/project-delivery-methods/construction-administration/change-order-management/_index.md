Change order management represents a critical administrative function in HVAC construction projects, requiring systematic processes for evaluating, pricing, documenting, and implementing modifications to the original contract scope.

## Change Order Types

### Owner-Directed Changes

**Scope Additions**
- Additional HVAC zones or equipment
- Increased capacity requirements
- Enhanced control functionality
- Additional filtration stages
- Expanded distribution systems

**Scope Deletions**
- Eliminated spaces or zones
- Reduced system capacity
- Value engineering substitutions
- Alternate equipment selections
- Simplified control sequences

**Design Modifications**
- Revised equipment locations
- Altered ductwork routing
- Modified piping configurations
- Changed control strategies
- Updated performance specifications

### Contractor-Initiated Changes

**Differing Site Conditions**
- Inadequate structural support for equipment
- Existing utilities conflicts
- Insufficient clearances
- Unforeseen obstructions
- Inaccessible installation locations

**Design Deficiencies**
- Missing coordination between trades
- Incomplete specifications
- Conflicting drawing information
- Unworkable installation details
- Inadequate equipment access provisions

**Constructability Issues**
- Installation sequence conflicts
- Equipment rigging limitations
- Temporary support requirements
- Access restrictions
- Coordination modifications

### Field-Directed Changes

**Construction Change Directives (CCD)**
- Immediate work authorization
- Pricing to be determined later
- Time impact estimated
- Documentation of necessity
- Owner authorization required

**Request for Information (RFI) Generated Changes**
- Clarification reveals scope gap
- Interpretation requires additional work
- Resolution necessitates modification
- Coordination exposes deficiency
