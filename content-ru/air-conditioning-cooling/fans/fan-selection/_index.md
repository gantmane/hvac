Правильный подбор вентилятора обеспечивает подачу расчётного расхода воздуха при минимальном потреблении электроэнергии, требуемом акустическом комфорте и надёжной многолетней эксплуатации. Методика включает анализ расхода и давления, учёт эффекта системы, анализ кривых производительности, расчёт мощности двигателя и оформление технической документации.

## Анализ воздушного потока

### Расчёт требуемого расхода

Расход воздуха определяют одним из трёх методов в зависимости от типа системы.

**Метод охлаждающей нагрузки (sensible cooling load):**

{{< formula display="true" >}}
Q_{\text{охл}} = \frac{\dot{q}_s}{\rho \cdot c_p \cdot \Delta T}
{{< /formula >}}

где $\dot{q}_s$ — явная тепловая нагрузка, Вт; $\rho = 1{,}20$ кг/м³; $c_p = 1005$ Дж/(кг·К); $\Delta T$ — разность температур приточного и вытяжного воздуха, К.

**Метод нормативной вентиляции (ASHRAE 62.1):**

{{< formula display="true" >}}
Q_{\text{OA}} = R_p \cdot P_z + R_a \cdot A_z
{{< /formula >}}

где $R_p$ — норма на человека, л/(с·чел); $P_z$ — число людей в зоне; $R_a$ — норма на площадь, л/(с·м²); $A_z$ — площадь зоны, м².

**Метод кратности воздухообмена:**

{{< formula display="true" >}}
Q = \frac{V_{\text{пом}} \cdot n}{3600}\ [\text{м}^3/\text{с}]
{{< /formula >}}

где $V_{\text{пом}}$ — объём помещения, м³; $n$ — кратность воздухообмена, ч⁻¹.

## Расчёт давления системы

### Суммарное аэродинамическое сопротивление

Полное расчётное давление складывается из сопротивлений воздуховодов, фитингов и элементов оборудования:

{{< formula display="true" >}}
\Delta P_{\text{сист}} = \Delta P_{\text{вод}} + \Delta P_{\text{фит}} + \Delta P_{\text{элем}}
{{< /formula >}}

{{< table title="Типичные аэродинамические сопротивления компонентов системы (ASHRAE Handbook — HVAC Systems)" >}}
| Компонент | Диапазон сопротивления, Па |
|---|---|
| Фильтр чистый класса EU4–EU7 | 60–125 |
| Фильтр загрязнённый (до замены) | 125–250 |
| Охлаждающая батарея (cooling coil) | 100–250 |
| Нагревательная батарея (heating coil) | 50–100 |
| Регулирующая заслонка (damper) | 12–50 |
| Шумоглушитель (sound attenuator) | 60–190 |
| Воздухораспределитель (diffuser) | 12–50 |
{{< /table >}}

### Коэффициент эффекта системы (System Effect Factor, SEF)

Неидеальная конфигурация воздуховодных соединений у входа или выхода вентилятора вызывает дополнительные потери давления, не отражённые в паспортной характеристике (AMCA 201). Эти потери суммируют с расчётным сопротивлением системы:

{{< formula display="true" >}}
\Delta P_{\text{факт}} = \Delta P_{\text{расч}} + \Delta P_{\text{SE}}
{{< /formula >}}

Основные источники потерь на эффект системы:
- резкий поворот (колено 90°) непосредственно у входного патрубка;
- вход из плenary-камеры без направляющего кольца (inlet cone);
- отсутствие прямого выходного участка — менее 2,5 эквивалентных диаметров;
- поворот на выходе в направлении, противоположном вращению рабочего колеса;
- механические препятствия у входного или выходного патрубка.

## Выбор типа вентилятора

{{< table title="Соответствие типа вентилятора области применения" >}}
| Применение | Рекомендуемый тип | Обоснование |
|---|---|---|
| Центральный кондиционер (AHU) | BC airfoil центробежный | Высокий КПД, широкий диапазон давлений, самоограничение мощности |
| Крышной кондиционер (RTU) | FC центробежный | Компактность, экономичная конструкция |
| Вытяжная вентиляция зданий | Трубчато-осевой (tube-axial) | Высокий расход при умеренном давлении, установка в воздуховод |
| Транспортировка материалов | Радиальный (radial blade) | Устойчивость к засорению частицами и волокнами |
| Конденсаторный агрегат (air-cooled condenser) | Пропеллерный (propeller) | Максимальный расход при минимальном давлении |
| Ограниченные габариты | Смешанного потока (mixed-flow) | Компактность при достаточном давлении |
{{< /table >}}

### Приоритет энергоэффективности

Для систем, к которым предъявляются требования ASHRAE 90.1 или ГОСТ Р EN 13779, предпочтительный порядок по убыванию КПД:

1. Centrifugal airfoil backward-curved — 80–88 %.
2. Centrifugal backward-inclined (плоские лопатки) — 75–82 %.
3. Vane-axial (осевой с направляющим аппаратом) — 70–82 %.
4. Mixed-flow (смешанного потока) — 70–80 %.

### Специальные исполнения

**Высокотемпературные среды:** рабочие колёса из легированной или жаропрочной стали, высокотемпературные подшипники, воздушная продувка вала (shaft cooling purge).

**Коррозионная среда:** конструкция из стеклопластика (FRP), покрытия из нержавеющей стали или горячего цинкования.

**Взрывоопасная атмосфера:** искробезопасное исполнение AMCA класс A, B или C, нейтральная смазка, неискрящие материалы рабочего колеса, аттестованные для опасных зон.

## Методика анализа кривых производительности

Последовательность подбора:

1. Рассчитать $Q_{\text{расч}}$ и $\Delta P_{\text{расч}}$.
2. Добавить запасы: $Q_{\text{пр}} = Q_{\text{расч}} \times 1{,}10$; $\Delta P_{\text{пр}} = (\Delta P_{\text{расч}} + \Delta P_{\text{SE}}) \times 1{,}20$.
3. Нанести расчётную точку на кривые производительности вентиляторов-кандидатов.
4. Убедиться, что точка находится в устойчивой зоне правее помпажа / срыва.
5. Проверить КПД в рабочей точке — не ниже 80 % от пикового.
6. Подтвердить мощность двигателя с учётом коэффициента запаса.

**Оптимальная рабочая точка:** 70–85 % от максимального расхода, с запасом по давлению от пикового значения не менее 15 %.

### Диапазон нагрузок для систем VAV

Для систем переменного объёма воздуха дополнительно проверяют:
- устойчивость при минимальном расходе — обычно 40–50 % от расчётного;
- отсутствие помпажа при минимальной частоте VFD;
- диапазон регулирования VFD — не менее 25–100 % от $N_{\text{ном}}$.

## Расчёт мощности

### Статическое давление вентилятора

Для схемы всасывания (draw-through, вентилятор на нагнетании):

{{< formula display="true" >}}
FSP = \Delta P_{\text{сист}}
{{< /formula >}}

Для схемы нагнетания (blow-through, вентилятор на всасывании — весь напор на выходе):

{{< formula display="true" >}}
FSP = \Delta P_{\text{после вентилятора}} + VP_{\text{вых}}
{{< /formula >}}

### Мощность на валу (Shaft Power / Brake Power)

{{< formula display="true" >}}
W_{\text{вал}} = \frac{Q \cdot FSP}{\eta_s}\ [\text{Вт}], \quad Q\ \text{в м}^3/\text{с},\ FSP\ \text{в Па}
{{< /formula >}}

Учёт потерь в передаче:
- ременный привод: $\eta_{\text{пр}} = 0{,}95$–$0{,}97$;
- прямой привод / гибкая муфта: $\eta_{\text{пр}} = 1{,}00$.

Подбор номинальной мощности двигателя:

{{< formula display="true" >}}
W_{\text{дв}} = \frac{W_{\text{вал}}}{\eta_{\text{пр}}} \times SF
{{< /formula >}}

где $SF$ — коэффициент запаса двигателя, обычно 1,10–1,15.

### Передаточное число ременной передачи

{{< formula display="true" >}}
N_{\text{вент}} = N_{\text{дв}} \cdot \frac{D_{\text{дв}}}{D_{\text{вент}}}
{{< /formula >}}

Стандартные синхронные скорости трёхфазных двигателей при 50 Гц: 3000, 1500, 1000, 750 об/мин.

## Полный пример подбора (СИ)

### Исходные данные

- Расход: $Q_{\text{расч}} = 15\,000$ м³/ч.
- Аэродинамическое сопротивление системы (воздуховоды + батареи + фильтры): $\Delta P_{\text{расч}} = 450$ Па.
- Потери на эффект системы (колено у входа): $\Delta P_{\text{SE}} = 50$ Па.
- Суммарное давление: $450 + 50 = 500$ Па.
- Назначение: центральный кондиционер VAV, схема draw-through.

### Проектная точка с запасами

{{< formula display="true" >}}
Q_{\text{пр}} = 15\,000 \times 1{,}10 = 16\,500\ \text{м}^3/\text{ч} = 4{,}58\ \text{м}^3/\text{с}
{{< /formula >}}

{{< formula display="true" >}}
P_{\text{пр}} = 500 \times 1{,}20 = 600\ \text{Па}
{{< /formula >}}

### Сравнение вентиляторов-кандидатов

{{< table title="Результаты анализа кривых вентиляторов-кандидатов (BC airfoil)" >}}
| Вариант | Тип | $N$, об/мин | $\eta_s$, % | $W_{\text{вал}}$, кВт | Примечание |
|---|---|---|---|---|---|
| A | BC airfoil | 1340 | 81 | 3,39 | Близко к BEP |
| B | BC airfoil | 1450 | 78 | 3,52 | Выше расчётных оборотов |
| C | BC airfoil | 1180 | 83 | 3,30 | Оптимальный КПД |
{{< /table >}}

### Расчёт мощности для варианта C

{{< formula display="true" >}}
W_{\text{вал}} = \frac{4{,}58 \times 600}{0{,}83} = 3313\ \text{Вт} \approx 3{,}31\ \text{кВт}
{{< /formula >}}

С учётом ременного привода ($\eta_{\text{пр}} = 0{,}96$) и коэффициента запаса ($SF = 1{,}15$):

{{< formula display="true" >}}
W_{\text{дв}} = \frac{3{,}31}{0{,}96} \times 1{,}15 = 3{,}97\ \text{кВт}
{{< /formula >}}

Выбирается стандартный двигатель 4,0 кВт (следующий ряд по IEC 60034-1 / ГОСТ Р МЭК 60034-1) с классом энергоэффективности не ниже IE3 по ASHRAE 90.1.

### Итоговый выбор

Вариант C: $\eta_s = 83\%$ — оптимальный КПД в рабочей точке; достаточный запас по скорости для подбора передаточного числа ременного привода; минимальное энергопотребление.

### Требования к сертификации AMCA

В спецификации на вентилятор указывают требуемые сертификаты:
- **AMCA 210** — аэродинамические характеристики (air performance);
- **AMCA 300** — акустические характеристики (sound power);
- **AMCA 204** — нормы вибрации.

### Конструктивные исполнения (AMCA 99-0098)

{{< table title="Основные конструктивные исполнения центробежных вентиляторов по AMCA" >}}
| Исполнение | Описание |
|---|---|
| Конструкция 1 | SWSI (одностороннее всасывание), подшипники на стойке |
| Конструкция 3 | SWSI, подшипники на корпусе вентилятора |
| Конструкция 4 | DWDI (двустороннее всасывание), подшипники на стойке |
| Конструкция 8 | Прямой привод |
{{< /table >}}

**Классы прочности (AMCA) по давлению и скорости:**
- Класс I — до 924 Па, скорость до 30,5 м/с;
- Класс II — до 1735 Па, скорость до 40,6 м/с;
- Класс III — до 2490 Па, скорость до 45,7 м/с;
- Класс IV — свыше 2490 Па.

## Нормативная база

{{< table title="Нормативные документы по подбору и испытанию вентиляторов" >}}
| Стандарт | Область применения |
|---|---|
| AMCA 210 / ASHRAE 51 | Лабораторные испытания, аэродинамические характеристики |
| AMCA 201 | Применение вентиляторов, учёт эффекта системы |
| AMCA 300 | Акустический рейтинг (sound power rating) |
| AMCA 204 / ISO 14694 | Нормы вибрации при монтаже |
| ASHRAE 90.1-2022 | Требования к энергоэффективности вентиляторов и приводов |
| СП 60.13330.2020 | Расчётные нормы HVAC в РФ |
{{< /table >}}

Систематический метод подбора вентилятора гарантирует соответствие выбранного оборудования расходно-напорным требованиям системы, работу в зоне высокого КПД на всём диапазоне нагрузок и многолетнюю надёжную эксплуатацию с минимальными затратами на электроэнергию и техническое обслуживание.
