Капиллярный перенос (capillary transport) — движение жидкой воды через поровую структуру пористых материалов под действием капиллярных сил. Этот механизм активен при контакте конструкции с грунтовой или дождевой водой и работает независимо от гравитации — вода способна подниматься вверх против действия тяжести. Для строительных конструкций капиллярный перенос опасен тем, что переносит значительно больше влаги, чем диффузия пара, причём в зону конструктивных элементов, где отсутствует прямой контакт с водой.

## Физические основы: поверхностное натяжение и смачивание

На границе раздела трёх фаз (твёрдое тело — жидкость — воздух) действуют три поверхностных натяжения. Краевой угол смачивания θ_c определяется уравнением Юнга:

{{< formula display="true" >}}
\gamma_{SA} = \gamma_{SL} + \gamma_{LA} \cos\theta_c
{{< /formula >}}

где γ_SA, γ_SL, γ_LA — натяжения на границах твёрдое–воздух, твёрдое–жидкость, жидкость–воздух.

При θ_c < 90° поверхность гидрофильна — вода смачивает и проникает в поры. При θ_c > 90° поверхность гидрофобна — вода выталкивается.

{{< table title="Краевой угол смачивания водой для типичных строительных материалов" >}}
| Материал | θ_c, ° | Характер |
|---|---|---|
| Кварцевое стекло | 5–15 | Полное смачивание |
| Бетон (необработанный) | 30–60 | Умеренное смачивание |
| Кирпич керамический | 40–70 | Умеренное смачивание |
| Сосна (торец) | 40–60 | Умеренное смачивание |
| Бетон с силан-обработкой | 110–130 | Гидрофобный |
| EPDM, ПЭ | > 100 | Гидрофобный |
{{< /table >}}

## Капиллярное давление и высота подъёма

Капиллярное давление в цилиндрической поре (уравнение Лапласа–Юнга):

{{< formula display="true" >}}
P_{cap} = \frac{2\gamma_{LA} \cos\theta_c}{r}
{{< /formula >}}

Высота равновесного капиллярного подъёма:

{{< formula display="true" >}}
h_{cap} = \frac{2\gamma_{LA} \cos\theta_c}{\rho_w g r}
{{< /formula >}}

где r — радиус поры, γ_LA = 0,0728 Н/м при 20 °C, ρ_w = 1000 кг/м³.

{{< table title="Капиллярный подъём в зависимости от радиуса пор (θ_c = 0°, T = 20 °C)" >}}
| r, мкм | P_cap, кПа | h_cap, м | Типичный материал |
|---|---|---|---|
| 0,1 | 1456 | 148 | Цементный гель, гидрат C-S-H |
| 1 | 145,6 | 14,9 | Мелкопористый кирпич |
| 5 | 29,1 | 3,0 | Тяжёлый бетон В25 |
| 10 | 14,6 | 1,5 | Обычный кирпич |
| 50 | 2,9 | 0,3 | Ячеистый бетон |
| 500 | 0,3 | 0,03 | Гравий 10 мм (граница капиллярности) |
{{< /table >}}

Из таблицы следует: бетон и кирпич с типичным r = 1–10 мкм способны поднимать воду на 1,5–15 м. Гравий r > 500 мкм — менее 30 мм: именно поэтому щебёночная подсыпка под плитой является эффективным капиллярным разрывом.

## Закон капиллярного поглощения (закон √t)

Кумулятивное водопоглощение сухим образцом при контакте с водой:

{{< formula display="true" >}}
i = A_w \cdot \sqrt{t}
{{< /formula >}}

где i — поглощённая масса воды на единицу площади (кг/м²), A_w — коэффициент водопоглощения (кг/(м²·√с)), t — время (с).

Физический смысл: поглощение замедляется со временем по мере увлажнения всё более глубоких и труднодоступных пор. Линейность в координатах (i, √t) — признак чисто капиллярного поглощения; отклонение указывает на начало заполнения крупных пор или насыщение.

{{< table title="Коэффициент водопоглощения A_w строительных материалов (ASTM C1585, EN 1925)" >}}
| Материал | A_w, кг/(м²·√ч) | Примечание |
|---|---|---|
| Тяжёлый бетон В25 | 0,3–1,5 | Зависит от В/Ц |
| Ячеистый бетон D500 | 1,5–4,0 | Высокая пористость |
| Кирпич керамический (нормальный) | 2,4–9,8 | Зависит от обжига |
| Кирпич силикатный | 3,0–10,0 | Обычно выше керам. |
| Цементный раствор | 1,5–6,0 | Основная зона утечки |
| Сосна, торец | 4,9–14,7 | Вдоль волокна |
| Сосна, пласть | 0,1–0,5 | Поперёк волокна |
| Сланцевая кровля | 0,01–0,05 | Низкопористый камень |
{{< /table >}}

## Закон Дарси для жидкостного переноса

При ненасыщенном переносе поток жидкой воды:

{{< formula display="true" >}}
q = -K(\theta) \cdot \frac{d\Psi}{dx}
{{< /formula >}}

где K(θ) — гидравлическая проводимость (м/с), нелинейно зависящая от влагосодержания θ (м³/м³); Ψ = ψ_cap + ψ_grav — суммарный водный потенциал (капиллярный + гравитационный). K(θ) изменяется на 6–8 порядков между насыщенным и воздушно-сухим состоянием — именно поэтому капиллярный перенос резко прекращается при высыхании материала.

Горизонтальное проникновение фронта смачивания:

{{< formula display="true" >}}
x = \sqrt{2 D_w \cdot t}
{{< /formula >}}

где D_w = D_w(θ) — влагодиффузивность (м²/с), типично 10⁻¹²–10⁻⁷ м²/с.

## Капиллярный подъём в фундаментных конструкциях

В стенах без гидроизоляции вода поднимается из грунта до равновесной высоты, определяемой балансом капиллярного давления и испарения с поверхности стены. Практическая высота поднятия сырости (rising damp):

{{< table title="Наблюдаемые высоты капиллярного поднятия в фундаментных стенах" >}}
| Материал | Высота поднятия, м |
|---|---|
| Плотный бетон | 0,1–0,5 |
| Кирпич керамический | 0,5–1,5 |
| Кирпич силикатный | 1,0–2,5 |
| Ячеистый бетон | 0,5–1,2 |
| Природный камень (гранит) | 0,1–0,3 |
| Природный камень (известняк) | 0,3–1,0 |
{{< /table >}}

При контакте кладки с засолённым грунтом гигроскопичность солей (хлориды, сульфаты) дополнительно удерживает влагу до φ = 65–85 % RH — конструкция остаётся постоянно влажной даже в сухую погоду.

## Численный пример: оценка капиллярного водопоглощения кирпичной кладки

**Условие.** Наружная кирпичная стена (кирпич нормальный, A_w = 5,0 кг/(м²·√ч)) подвергается дождю 15 мм/ч в течение 2 ч. Площадь открытой поверхности 20 м².

**Кумулятивное поглощение за 2 ч:**
{{< formula display="true" >}}
i(t) = 5{,}0 \cdot \sqrt{2} = 7{,}07 \text{ кг/м}^2
{{< /formula >}}

**Суммарное поглощение стеной:**
{{< formula display="true" >}}
m = 7{,}07 \times 20 = 141 \text{ кг воды}
{{< /formula >}}

**Дождевая нагрузка на ту же поверхность:** 0,015 × 20 × 2 = 0,6 м³ = 600 кг — то есть кирпич поглощает ≈ 24 % осадков, не считая стока.

**Глубина промачивания** (по горизонтали от поверхности, за 2 ч):

Типичная D_w для насыщенного кирпича: 5×10⁻⁸ м²/с.
{{< formula display="true" >}}
x = \sqrt{2 \times 5 \times 10^{-8} \times 7200} = \sqrt{7{,}2 \times 10^{-4}} = 0{,}027 \text{ м} = 27 \text{ мм}
{{< /formula >}}

При стене 120 мм (полкирпича) вода проникает примерно на 22 % толщины за 2 ч дождя. Через 8 ч: x ≈ 54 мм — более трети стены. Поэтому для климата Москвы (осадки в виде дождя 450–500 мм/год) облицовочный кирпич без воздушного зазора представляет серьёзный риск намокания конструктивного слоя.

## Капиллярный разрыв: методы и требования

Капиллярный разрыв (capillary break) — устройство, прерывающее непрерывность поровой структуры и исключающее капиллярный перенос. Три класса:

**1. Воздушный зазор.** Полный разрыв мениска. Минимальная ширина ≥ 6 мм (ASHRAE Fundamentals, гл. 27); при высоком давлении ветрового дождя — ≥ 25 мм (вентилируемый фасад). Требует дренажного отверстия снизу.

**2. Мелкозернистая подсыпка.** Щебень фракции 10–20 мм создаёт поры r > 500 мкм — h_cap < 30 мм. Толщина слоя ≥ 100 мм под плитой по грунту. По СП 50.13330.2017 (п. 8.13) и СП 29.13330.2011 (п. 5.3): гравийная или щебёночная подготовка обязательна под плитой в зоне контакта с грунтом.

**3. Гидрофобная мембрана (DPC — damp proof course).** Устанавливается горизонтально в кладке на высоте 150–200 мм от отмостки. Требования к материалу: водопоглощение < 0,1 кг/м² за 24 ч; паропроницаемость — как правило, минимальная (полиэтилен, битумные мембраны). Швы и примыкания проклеиваются герметиком; нахлёст ≥ 100 мм.

**4. Гидрофобная пропитка (силан/силоксан).** Увеличивает θ_c с 40° до 110–130°, снижает A_w на 70–95 %, сохраняет паропроницаемость. Глубина проникновения 3–10 мм; срок службы 5–15 лет. Применяется по ГОСТ Р EN 1504-2 или ASTM C67.

## Влияние влажности на теплопроводность

Теплопроводность пористых материалов возрастает при насыщении водой (λ_water ≈ 0,6 Вт/(м·К) >> λ_air ≈ 0,024 Вт/(м·К)):

{{< formula display="true" >}}
\lambda(w) = \lambda_0 (1 + b \cdot w)
{{< /formula >}}

где w — объёмное влагосодержание (м³/м³), b — коэффициент, кг/м³.

Для тяжёлого бетона при w = 5 %: λ_dry = 1,4 Вт/(м·К) → λ_wet ≈ 1,8 Вт/(м·К) (+29 %). Для ячеистого бетона D500 при w = 10 %: λ_dry = 0,15 → λ_wet ≈ 0,24 Вт/(м·К) (+60 %). Нормируемое значение λ_расч в СП 50.13330.2017 уже учитывает эксплуатационную влажность материала (условия А или Б) — для зон с избыточным увлажнением следует применять условие Б.

## Морозное разрушение и критическое насыщение

При замерзании воды в порах объём льда на 9 % больше объёма воды. Повреждение происходит при насыщении пор выше критического уровня S_cr:

{{< formula display="true" >}}
S_{cr} = 1 - \frac{\rho_{\text{лёд}}}{\rho_{\text{вода}}} \approx 0{,}91
{{< /formula >}}

Ниже S_cr = 0,91 вода при замерзании вытесняется в незаполненные поры без создания деструктивного давления. Выше — трещинообразование. Количество циклов замораживания-оттаивания, которые выдерживает бетон при полном насыщении, по ГОСТ 10060 нормируется марками F50–F500. Для наружных стен и фундаментов в Москве (среднее число переходов через 0 °C за сезон ≈ 50–70) требуется F100–F200 (СП 28.13330.2017).

## Методы измерения

- **ASTM C1585 / EN 1925:** Определение коэффициента A_w. Образцы с загерметизированными боковыми гранями контактируют с водой слоем 2–5 мм; взвешивание через 1, 5, 10, 20, 30, 60 мин, 2, 3, 4, 6, 24, 48 ч.
- **EN 12390-8:** Проникновение воды под давлением в бетон (500 кПа, 72 ч); глубина проникновения < 50 мм — водонепроницаемый бетон.
- **Кальций-карбидный метод (CM-метод):** Быстрое количественное определение влажности образца кладки in situ; точность ±0,5 % по массе.
- **ИК-термография (EN 13187):** Качественное выявление зон капиллярного намокания по температурным аномалиям испарения; применяется при ΔT_поверхность-воздух ≥ 3 °C.
