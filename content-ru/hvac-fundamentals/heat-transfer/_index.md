Теплопередача — физическая основа проектирования любой системы HVAC. Энергия перемещается от зоны высокой температуры к зоне низкой температуры тремя принципиально различными механизмами: **теплопроводностью** (кондукцией), **конвекцией** и **излучением** (радиацией). В реальных инженерных задачах все три механизма действуют одновременно; задача инженера — правильно учесть каждый из них и определить суммарный тепловой поток.

Настоящий раздел охватывает теплопередачу на уровне, достаточном для расчётов ограждающих конструкций, теплообменников, трубопроводных систем и лучистых систем отопления/охлаждения. Все расчётные методики соответствуют ASHRAE Handbook — Fundamentals (2021), гл. 4, ISO 6946:2017, ISO 10211:2017, СП 50.13330.2017.

## Три механизма теплопередачи

### Теплопроводность (кондукция)

Теплопроводность — перенос тепловой энергии через неподвижную среду вследствие хаотического движения молекул и (в металлах) свободных электронов. Фундаментальным законом является **закон Фурье**:

{{< formula display="true" >}}
q'' = -k \frac{dT}{dx} \quad [\text{Вт/м}^2]
{{< /formula >}}

Отрицательный знак выражает второй закон термодинамики: тепло течёт в сторону убывания температуры. Тепловой поток (Вт) через плоскую стенку площадью $A$ и толщиной $L$ при постоянном коэффициенте теплопроводности $k$:

{{< formula display="true" >}}
Q = k A \frac{T_1 - T_2}{L} \quad [\text{Вт}]
{{< /formula >}}

**Тепловое сопротивление** плоской стенки на единицу площади (удельное, м²·К/Вт):

{{< formula display="true" >}}
R = \frac{L}{k}
{{< /formula >}}

Для многослойной конструкции сопротивления суммируются последовательно: $R_\Sigma = R_1 + R_2 + \ldots + R_n$.

### Конвекция

Конвекция — перенос тепла между твёрдой поверхностью и движущейся жидкостью (газом или жидкостью). **Закон охлаждения Ньютона**:

{{< formula display="true" >}}
Q = h \cdot A \cdot (T_s - T_\infty) \quad [\text{Вт}]
{{< /formula >}}

где $h$ — коэффициент конвективного теплообмена (Вт/м²·К), $T_s$ — температура поверхности, $T_\infty$ — температура набегающего потока. Значение $h$ не является постоянной материала; оно зависит от режима течения, геометрии, свойств жидкости. Его определяют через безразмерное число Нуссельта:

{{< formula display="true" >}}
h = \frac{Nu \cdot k_f}{L}
{{< /formula >}}

Различают свободную (естественную) конвекцию, обусловленную архимедовыми силами в неоднородно нагретой жидкости, и вынужденную конвекцию, вызванную внешними механическими источниками (насос, вентилятор, ветер).

### Излучение

Тепловое излучение — перенос энергии посредством электромагнитных волн. Не требует промежуточной среды и интенсивно даже в вакууме. **Закон Стефана–Больцмана** для реального тела:

{{< formula display="true" >}}
E = \varepsilon \sigma T^4 \quad [\text{Вт/м}^2]
{{< /formula >}}

где $\varepsilon$ — степень черноты поверхности (0 < ε ≤ 1), $\sigma = 5{,}670 \times 10^{-8}$ Вт/(м²·К⁴). При умеренных перепадах температур излучение линеаризуют:

{{< formula display="true" >}}
h_r = 4 \varepsilon \sigma T_m^3
{{< /formula >}}

и суммируют с конвективным коэффициентом: $h_{tot} = h_c + h_r$.

## Комбинированная теплопередача и коэффициент U

Большинство инженерных задач требуют учёта нескольких механизмов. Суммарное термическое сопротивление ограждающей конструкции:

{{< formula display="true" >}}
R_0 = \frac{1}{h_i} + \sum_{j=1}^{n} \frac{L_j}{k_j} + \frac{1}{h_e} \quad [\text{м}^2\cdot\text{К/Вт}]
{{< /formula >}}

Коэффициент теплопередачи (U-значение):

{{< formula display="true" >}}
U = \frac{1}{R_0} \quad [\text{Вт/(м}^2\text{·К)}]
{{< /formula >}}

**Нормативные значения коэффициентов поверхностного теплообмена** (ISO 6946:2017):

{{< table title="Коэффициенты поверхностного теплообмена по ISO 6946" >}}
| Поверхность | Направление теплового потока | $h_i$, Вт/(м²·К) | $R_{si}$, м²·К/Вт |
|---|---|---|---|
| Внутренняя | Горизонтальный | 7,7 | 0,13 |
| Внутренняя | Восходящий | 10,0 | 0,10 |
| Внутренняя | Нисходящий | 5,9 | 0,17 |
| Наружная (зима) | Горизонтальный | 25,0 | 0,04 |
| Наружная (лето) | Горизонтальный | 25,0 | 0,04 |
{{< /table >}}

## Числовой пример: U-значение московской наружной стены

Расчётная зимняя температура Москвы (СП 50.13330.2017): $T_e = -26{°}$C, внутри $T_i = +20{°}$C, $\Delta T = 46$ К.

Конструкция (снаружи внутрь):

{{< table title="Слои московской наружной стены (толщина/теплопроводность)" >}}
| Слой | $L$, мм | $k$, Вт/(м·К) | $R$, м²·К/Вт |
|---|---|---|---|
| Наружный конвективный | — | — | 0,04 |
| Кирпич лицевой | 120 | 0,64 | 0,188 |
| ПЕНОПЛЭКС (XPS) | 140 | 0,032 | 4,375 |
| Газобетон D500 | 200 | 0,14 | 1,429 |
| Штукатурка ц/п | 20 | 0,76 | 0,026 |
| Внутренний конвективный | — | — | 0,13 |
| **Итого** | — | — | **6,188** |
{{< /table >}}

{{< formula display="true" >}}
U = \frac{1}{6{,}188} = 0{,}162 \;\text{Вт/(м}^2\text{·К)} \quad < \; U_{norm} = 0{,}18 \;\text{Вт/(м}^2\text{·К)} \; (\text{СП 50})
{{< /formula >}}

Тепловой поток через 1 м² стены при расчётных условиях:

{{< formula display="true" >}}
q = U \cdot \Delta T = 0{,}162 \times 46 = 7{,}5 \;\text{Вт/м}^2
{{< /formula >}}

## Нестационарная теплопередача

Когда температурное поле изменяется во времени, к закону Фурье добавляется член аккумуляции теплоты:

{{< formula display="true" >}}
\rho c_p \frac{\partial T}{\partial t} = k \nabla^2 T + \dot{q}
{{< /formula >}}

Характерные безразмерные числа нестационарного анализа:

- **Число Био** $Bi = hL_c/k$ — отношение внешнего конвективного сопротивления к внутреннему кондуктивному. При $Bi < 0{,}1$ допустим метод сосредоточенной ёмкости.
- **Число Фурье** $Fo = \alpha t / L_c^2$ — безразмерное время; $\alpha = k/(\rho c_p)$ — коэффициент температуропроводности.
