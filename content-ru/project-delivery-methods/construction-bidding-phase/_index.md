Этап торгов на строительство переводит проектные документы в строительные контракты, устанавливая основу для реализации проекта. Правильное управление этапом торгов обеспечивает наличие квалифицированных подрядчиков, конкурентные цены и четкие контрактные условия для монтажа систем HVAC.

## Подготовка тендерной документации

### Состав тендерного пакета

Полные тендерные пакеты HVAC включают:

**Контрактные документы**:
- Форма соглашения
- Общие условия
- Дополнительные условия
- Спецификации HVAC (Раздел 23)

**Набор чертежей**:
- Планы механических систем
- Таблицы оборудования
- Детали и разрезы
- Схемы управления

**Тендерные формы**:
- Форма базовой ставки
- Альтернативное ценообразование
- Единицы цены
- Резервы (allowances)

### Разделы спецификаций

Типичные разделы спецификаций HVAC:

| Раздел | Содержание |
|---------|---------|
| 230500 | Общие результаты работ |
| 230593 | Испытания, регулировка, балансировка |
| 230900 | Приборы и управление |
| 232100 | Гидравлические трубопроводы |
| 233100 | Воздуховоды и кожухи HVAC |
| 233600 | Воздушные терминальные устройства |
| 237200 | Воздухообрабатывающие установки |
| 238100 | Децентрализованная HVAC |

### Процесс добавлений

Выпуск добавлений для уточнения или изменения тендерной документации:

- Официальное распределение среди всех участников торгов
- Отслеживание подтверждения получения добавлений
- Срок для изменений до торгов
- Влияние на срок подачи заявок

## Предварительные мероприятия до торгов

### Квалификация участников

Оценка возможностей подрядчика:

**Финансовые**:
- Лимиты по обеспечению (bonding capacity)
- Страхование
- Финансовая отчетность
- Кредитные рекомендации

**Технические**:
- Опыт аналогичных проектов
- Квалификация персонала
- Возможности оборудования
- Показатели безопасности

**Административные**:
- Проверка лицензий
- Проверка рекомендаций
- Правовой статус
- Доступность рабочей силы

### Предварительное совещание

Обязательное или факультативное совещание для:

- Обзора объема проекта
- Ответов на вопросы подрядчиков
- Посещения объекта и доступа
- Уточнения графика
- Толкования документов

Протокол совещания записывается и распределяется среди всех участников торгов.

### Запрос информации (RFI)

RFI до торгов устраняют неясности в документации:

1. Подрядчик подает письменный вопрос
2. Инженер/архитектор проводит обзор
3. Ответ через добавление (для всех участников торгов)
4. Срок подачи RFI

## Подача заявок

### Требования к заявке

**Формат**:
- Запечатанный конверт/электронный
- Заполненная тендерная форма
- Подтверждение получения добавлений
- Тендерное обеспечение (обычно 5%)

**График**:
- Срок подачи (точное время)
- Публичное вскрытие (конкурентное)
- Период оценки
- Уведомление о присуждении

### Тендерное обеспечение

Тендерные облигации гарантируют обязательство подрядчика:

- 5-10% от суммы заявки типично
- Форма AIA Document A310
- Конфискация при отзыве заявки
- Возврат после заключения контракта

## Оценка заявок

### Критерии соответствующей заявки

Проверка соответствия заявок требованиям:

- Все формы заполнены
- Подтверждение добавлений
- Правильные подписи
- Включено обеспечение
- Своевременная подача

### Техническая оценка

Проверка на соответствие:

- Оборудование соответствует спецификациям
- Альтернативы правильно оценены
- Единицы цены разумны
- Квалификация приемлемая

### Анализ цен

| Оцениваемый элемент | Учет |
|-----------------|---------------|
| Базовая ставка | Основное сравнение |
| Альтернативы | Добавление/вычет согласно плану |
| Единицы цены | Сравнение с оценками |
| Резервы | Стандартные суммы |
| Общая стоимость | Полное сравнение |

### Самый низкий ответственный подрядчик

Присуждение обычно осуществляется самому низкому ответственному подрядчику:

**Критерии ответственности**:
- Техническая способность
- Финансовые возможности
- Прошлые результаты
- Соблюдение законодательства
- Доступные ресурсы

## Заключение контракта

### Уведомление о присуждении

Официальное уведомление включает:

- Принятая сумма заявки
- Срок контракта
- Требуемые материалы для согласования
- Обеспечительные облигации и платежные облигации
- Сертификаты страхования
- Срок подписания контракта

### Подписание контракта

Завершение контрактной документации:

- Подписанное соглашение
- Обеспечительная облигация (100%)
- Платежная облигация (100%)
- Сертификаты страхования
- Уведомление о начале работ

### Неудачные заявки

Уведомление неудачных участников:
- Возврат тендерных облигаций
- Предоставление таблицы ставок (если публичный проект)
- Ответы на запросы о разъяснении (если применимо)

## Особые соображения

### Предварительная квалификация

Для сложных систем HVAC:
- Предварительная квалификация до торгов
- Ограничение участников списком квалифицированных
- Детальная оценка возможностей
- Снижение нагрузки на оценку заявок

### Переговорная закупка

Альтернативы конкурентным торгам:
- Поставка по системе «проектирование-строительство» (Design-build)
- Управление строительством
- Переговоры с квалифицированным подрядчиком
- Выбор по наилучшей ценности

### Публичные vs. Частные проекты

**Публичные проекты**:
- Строгие конкурентные торги
- Самый низкий ответственный подрядчик
- Прозрачный процесс
- Определенные процедуры протеста

**Частные проекты**:
- Большая гибкость
- Учет отношений
- Возможность переговоров
- Потенциал более быстрого процесса

Этап торгов на строительство устанавливает критически важные отношения с подрядчиком и контрактные условия, регулирующие реализацию проекта, при этом правильные процедуры обеспечивают честную конкуренцию и отбор квалифицированных подрядчиков.
