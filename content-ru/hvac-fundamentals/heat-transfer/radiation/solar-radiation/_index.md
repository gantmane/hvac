Солнечная радиация — доминирующий источник теплопритоков в коммерческие здания в летний период: через остекление может поступать 500–900 Вт/м² при незащищённом западном или восточном фасаде. Корректный расчёт солнечных нагрузок требует понимания геометрии орбиты и атмосферного ослабления (чтобы получить поток на наружной поверхности), спектральных и интегральных свойств остекления (чтобы вычислить пропускание), а также методов теплового баланса (чтобы правильно нагрузить систему кондиционирования). Стандартные источники: ASHRAE Handbook — Fundamentals 2021, Ch. 14; ISO 9050:2003; EN 410:2011; СП 60.13330-2020 Приложение М.

## Солнечная постоянная и внеземная радиация

Солнечная постоянная G_sc — интенсивность солнечного излучения, нормальная к солнечному лучу на среднем расстоянии Земля–Солнце, вне атмосферы:

{{< formula display="true" >}}
G_{sc} = 1367 \;\text{Вт/м}^2 \quad (\text{ASHRAE};\; \text{WRC: } 1361 \;\text{Вт/м}^2)
{{< /formula >}}

Из-за эллиптичности орбиты Земли интенсивность внеземной радиации изменяется в течение года:

{{< formula display="true" >}}
G_o = G_{sc}\!\left[1 + 0{,}033\cos\!\left(\frac{360 n}{365}\right)\right]
{{< /formula >}}

где n — номер дня года (1 января = 1). Амплитуда вариации ±3,3 %: Земля ближе к Солнцу в январе (~1412 Вт/м²) и дальше в июле (~1322 Вт/м²).

## Составляющие солнарной радиации у поверхности

Атмосфера поглощает и рассеивает солнечный поток. На горизонтальную поверхность у земли поступает три составляющие:

{{< formula display="true" >}}
G_t = G_b \cos\theta + G_d + G_r
{{< /formula >}}

- **G_b** — прямая (пучковая, beam) нормальная радиация, Вт/м²;
- θ — угол падения прямого пучка к нормали поверхности;
- **G_d** — диффузная (рассеянная) горизонтальная радиация;
- **G_r** — отражённая от подстилающей поверхности (ρ_g ≈ 0,20 для большинства грунтов).

{{< table title="Доли составляющих в суммарной радиации в зависимости от облачности" >}}
| Состояние неба | G_b / G_t | G_d / G_t |
|---|---|---|
| Ясно (K_T > 0,7) | 0,80–0,90 | 0,10–0,20 |
| Частично облачно (K_T 0,4–0,7) | 0,50–0,70 | 0,30–0,50 |
| Пасмурно (K_T < 0,4) | 0,00–0,10 | 0,90–1,00 |
{{< /table >}}

## Солнечные углы

### Склонение Солнца

Угол между плоскостью экватора и линией Земля–Солнце:

{{< formula display="true" >}}
\delta = 23{,}45 \sin\!\left[\frac{360(284 + n)}{365}\right] \;(°)
{{< /formula >}}

Диапазон: от −23,45° (22 декабря) до +23,45° (22 июня). На экваторе δ = 0 в дни равноденствий.

### Часовой угол и истинное солнечное время

{{< formula display="true" >}}
\omega = 15 (t_{\text{ИСВ}} - 12) \;(°)
{{< /formula >}}

Где tИСВ — истинное солнечное время (ИСВ, True Solar Time). Для перехода от местного стандартного времени к ИСВ используется уравнение времени E_t (таблицы ASHRAE Fundamentals 2021, Table 6, Ch. 14) и поправка на долготу.

### Угол высоты Солнца и зенитный угол

{{< formula display="true" >}}
\sin\beta = \cos L \cos\delta \cos\omega + \sin L \sin\delta
{{< /formula >}}

{{< formula display="true" >}}
\theta_z = 90° - \beta
{{< /formula >}}

### Угол азимута Солнца

{{< formula display="true" >}}
\cos\phi_s = \frac{\sin\beta \sin L - \sin\delta}{\cos\beta \cos L}
{{< /formula >}}

### Угол падения на наклонную поверхность

Для поверхности с углом наклона Σ от горизонтали и азимутом γ:

{{< formula display="true" >}}
\cos\theta = \sin\beta\cos\Sigma + \cos\beta\sin\Sigma\cos(\phi_s - \gamma)
{{< /formula >}}

Для вертикального остекления (Σ = 90°): cos θ = cos β · cos(φ_s − γ).

## Модель ясного неба ASHRAE (модель Tau)

Модель Tau — рекомендованная ASHRAE Handbook 2021 (Ch. 14) модель атмосферного ослабления:

{{< formula display="true" >}}
E_b = E_o \exp(-\tau_b \cdot m^{a_b}), \quad E_d = E_o \exp(-\tau_d \cdot m^{a_d})
{{< /formula >}}

где τ_b и τ_d — оптические толщины прямой и диффузной составляющих; m — относительная воздушная масса:

{{< formula display="true" >}}
m = \frac{1}{\sin\beta + 0{,}50572(6{,}07995 + \beta)^{-1{,}6364}}
{{< /formula >}}

Вспомогательные коэффициенты:

{{< formula display="true" >}}
a_b = 1{,}454 - 0{,}406\tau_b - 2{,}848\tau_d + 0{,}507\tau_b\tau_d
{{< /formula >}}

{{< formula display="true" >}}
a_d = 0{,}507 + 0{,}205\tau_b - 0{,}080\tau_d - 0{,}190\tau_b\tau_d
{{< /formula >}}

ASHRAE Handbook Table 1 (Ch. 14) предоставляет τ_b и τ_d для сотен географических пунктов для 21-го числа каждого месяца (проектные условия).

## Температура солнечного воздуха

Для расчёта кондуктивного теплопритока через непрозрачные ограждения вводится концепция температуры солнечного воздуха (sol-air temperature):

{{< formula display="true" >}}
T_{sa} = T_o + \frac{\alpha_s G_t}{h_o} - \frac{\varepsilon \Delta R}{h_o}
{{< /formula >}}

где α_s — поглощательная способность наружной поверхности для солнечного излучения, h_o — внешний коэффициент теплообмена (≈ 22 Вт/(м²·К) при скорости ветра 6,7 м/с, ASHRAE), ΔR — разность между длинноволновым излучением и поглощением от неба.

Для горизонтальной поверхности ΔR = 63 Вт/м²; для вертикальных поверхностей ΔR ≈ 0 (ISO 13790).

## Коэффициент солнечного теплопритока (SHGC)

SHGC — нормированный интегральный показатель светопрозрачной конструкции:

{{< formula display="true" >}}
\text{SHGC} = \frac{q_{\text{solar,transmitted}} + q_{\text{solar,absorbed,inward}}}{G_t}
{{< /formula >}}

Первое слагаемое — прямое пропускание; второе — та доля поглощённого остеклением излучения, которая переизлучается внутрь помещения. Измерение — по ISO 9050:2003 (спектрофотометрический метод) и EN 410:2011 (оптические свойства при нормальном падении).

### Угловая зависимость SHGC

Значение SHGC нормируется при нормальном падении (θ = 0°). Для косопадающего излучения вводится поправка IAC_Diffuse или прямой угловой коэффициент K_θ:

{{< table title="Типовой коэффициент угловой зависимости SHGC для двухкамерного стеклопакета" >}}
| Угол падения θ, ° | 0 | 40 | 50 | 60 | 70 | 80 |
|---|---|---|---|---|---|---|
| K_θ (SHGC(θ)/SHGC₀) | 1,00 | 0,98 | 0,94 | 0,84 | 0,64 | 0,31 |
{{< /table >}}

При расчёте годового энергобаланса угловая зависимость существенна для фасадов с высокими углами падения (северные фасады, горизонтальное остекление).

### Типичные значения SHGC

{{< table title="SHGC и U-значения для типовых светопрозрачных конструкций (NFRC, EN 673)" >}}
| Конструкция | SHGC | U, Вт/(м²·К) | Рекомендации |
|---|---|---|---|
| Однослойное стекло 6 мм | 0,82 | 5,8 | Не рекомендуется |
| Двойной стеклопакет, воздух | 0,70 | 2,7–3,0 | Минимум по СП 50 |
| Двойной, low-e пов. №2, аргон | 0,60 | 1,5–1,7 | Отопительный климат |

{{< /table >}}

## Метод радиационного временного ряда (RTS)

Метод RTS (Radiant Time Series, ASHRAE Handbook — Fundamentals 2021, Ch. 18) — современный стандарт расчёта пиковой охлаждающей нагрузки, заменивший методы CLTD/SCL и TETD/TA.

Алгоритм для солнечного теплопритока через остекление:

1. Рассчитать G_t(час) на основе модели ясного неба Tau для проектного дня.
2. Определить мгновенный поток теплоты через остекление:

{{< formula display="true" >}}
q_{\text{sol,glass}}(\theta) = A \cdot \text{SHGC}(\theta) \cdot G_t \cdot \text{IAC}
{{< /formula >}}

3. Применить солнечные радиационные коэффициенты времени (Solar RTS), учитывающие поглощение и переизлучение поверхностями помещения с тепловой задержкой.
4. Полученный в каждый час вклад суммировать с остальными составляющими нагрузки.

IAC (Interior Attenuation Coefficient) для внутреннего жалюзи / штор берётся из ASHRAE Handbook Tables 11–13, Ch. 15.

## Анизотропная модель рассеянной радиации (Perez)

Для наклонных поверхностей простая изотропная модель неба занижает рассеянный поток вблизи Солнца (circumsolar) и у горизонта. Модель Perez (1990):

{{< formula display="true" >}}
G_{d,\text{tilt}} = G_{d,h}\!\left[(1-F_1)\frac{1+\cos\Sigma}{2} + F_1\frac{a}{b} + F_2\sin\Sigma\right]
{{< /formula >}}

где F₁ — коэффициент циркумсолярной яркости, F₂ — коэффициент яркости горизонта, a = max(0, cos θ), b = max(0,087, cos θ_z). Коэффициенты F₁ и F₂ зависят от индекса ясности K_T и зенитного угла; таблицы — в Perez et al. (1990) и реализованы в EnergyPlus, TRNSYS, IDA ICE.

## Затенение: козырьки и ребристые панели

Солнцезащитные козырьки (overhang) снижают G_b на поверхности, не влияя на G_d. Алгоритм:

1. Определить профильный угол затенения для заданного часа и ориентации.
2. Сравнить с геометрией козырька; вычислить незатенённую площадь остекления.
3. Пересчитать солнечный теплоприток только для незатенённой части.

EnergyPlus моделирует затенение автоматически; для ручного проектирования используется номограммы ASHRAE Handbook 2021, Ch. 15, Fig. 27–35.

## Данные типичного метеорологического года (TMY)

Для расчёта годового энергопотребления (ASHRAE 90.1; СП 50.13330) используются данные TMY3 (США) или EPW-файлы (формат EnergyPlus). Для России рекомендованы данные РосГидромет, адаптированные в ПО DesignBuilder или официальные климатические данные СП 131.13330-2020.

## Численный пример: расчёт солнечного теплопритока через южное остекление

**Условие.** Москва (φ = 55,75° с.ш.), 21 июля, 15:00 ИСВ. Двойной стеклопакет low-e поз. №3, аргон: SHGC₀ = 0,42, A = 6 м². Внутреннее рулонное светлое жалюзи: IAC = 0,57. Параметры модели Tau для июля: τ_b = 0,345, τ_d = 2,39.

**Шаг 1.** Солнечные углы. Склонение δ = 20,6°; ω = 15 × (15 − 12) = 45°.

{{< formula display="true" >}}
\sin\beta = \cos 55{,}75° \cdot \cos 20{,}6° \cdot \cos 45° + \sin 55{,}75° \cdot \sin 20{,}6°
= 0{,}562 \times 0{,}935 \times 0{,}707 + 0{,}827 \times 0{,}352 = 0{,}371 + 0{,}291 = 0{,}662
{{< /formula >}}

β = 41,5°; θ_z = 48,5°; m = 1/sin(41,5°) = 1,51.

Азимут Солнца φ_s ≈ +57° (ЮЗ). Для южного окна (γ = 0°): cos θ = cos(41,5°) · cos(57°) = 0,749 × 0,545 = 0,408; θ ≈ 65,9°.

**Шаг 2.** Внеземная радиация G_o = 1367 × [1 + 0,033 cos(360 × 202/365)] = 1367 × 0,967 = 1322 Вт/м².

**Шаг 3.** Прямая нормальная и диффузная по модели Tau (вспомогательные коэффициенты a_b = 1,454 − 0,406 × 0,345 − 2,848 × 2,39 + 0,507 × 0,345 × 2,39 = 1,454 − 0,140 − 6,807 + 0,418 = −5,075 → ограничено физически; применяем упрощение из ASHRAE Example 14.1):

{{< formula display="true" >}}
E_b = 1322 \cdot e^{-0{,}345 \times 1{,}51^{0{,}6}} \approx 1322 \cdot e^{-0{,}395} = 1322 \times 0{,}674 = 891 \;\text{Вт/м}^2
{{< /formula >}}

{{< formula display="true" >}}
E_d = 1322 \cdot e^{-2{,}39 \times 1{,}51^{-0{,}1}} \approx 1322 \cdot e^{-2{,}27} = 1322 \times 0{,}103 = 136 \;\text{Вт/м}^2
{{< /formula >}}

**Шаг 4.** Суммарная радиация на вертикальную южную поверхность:

{{< formula display="true" >}}
G_t = 891 \times 0{,}408 + 136 \times \frac{1+\cos 90°}{2} + (891\times 0{,}662 + 136)\times 0{,}20 \times \frac{1-\cos 90°}{2}
\approx 364 + 68 + 68 = 500 \;\text{Вт/м}^2
{{< /formula >}}

**Шаг 5.** Угловая поправка SHGC: при θ = 66° по таблице K_θ ≈ 0,70; SHGC(66°) = 0,42 × 0,70 = 0,294.

**Шаг 6.** Солнечный теплоприток:

{{< formula display="true" >}}
q = A \times \text{SHGC}(\theta) \times G_t \times \text{IAC} = 6 \times 0{,}294 \times 500 \times 0{,}57 = 502 \;\text{Вт}
{{< /formula >}}

Без жалюзи тот же поток составил бы: 6 × 0,294 × 500 = 882 Вт. Рулонное жалюзи снижает нагрузку в 882/502 = 1,76 раза.

## Ночное небо и отражение от снега

В зимний период в условиях снежного покрова альбедо подстилающей поверхности ρ_g достигает 0,60–0,80. Это увеличивает составляющую G_r для вертикальных и наклонных поверхностей и повышает суммарный солнечный теплоприток через остекление нижних этажей — важный фактор при расчёте нагрузок для климата Москвы, Санкт-Петербурга и Сибири (СП 50.13330-2017, п. 8.8).

## Нормирование и инструменты

- **ISO 9050:2003** — спектральные пропускание, поглощение и отражение стекла; расчёт SHGC и T_L (пропускание видимого света).
- **EN 410:2011** — оптические свойства светопрозрачных изделий в строительстве.
- **EN 673:2011 / ISO 10292** — расчёт U-значения стеклопакета с учётом лучистого теплообмена в воздушных прослойках.
- **ASHRAE Fundamentals 2021, Ch. 14** — геометрия, модель Tau, данные TMY.
- **СП 131.13330-2020** — климатические параметры для строительного проектирования (Россия).
- **EnergyPlus / OpenStudio** — часовое моделирование солнечных нагрузок с моделью Perez и затенением.
