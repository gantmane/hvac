ASHRAE 160 «Criteria for Moisture-Control Design Analysis in Buildings» — единственный действующий американский стандарт, устанавливающий количественные критерии проектирования ограждающих конструкций по условию предотвращения роста плесени. Стандарт принят в 2009 г., последняя редакция — 2021 г. В международной практике используется совместно с EN 15026 (динамическое гигротермическое моделирование) и ISO 13788 (упрощённый метод Глазера для базовой проверки).

## Область применения и философия

ASHRAE 160 применяется к жилым, коммерческим и институциональным зданиям всех климатических зон — как новому строительству, так и капитальной реновации. Стандарт базируется на принципе проектирования по характеристикам (performance-based design): вместо предписания конкретных узлов задаётся измеримый результат — поверхностная ОВ ниже критического порога в течение расчётного года.

**Метрика производительности:** 30-суточное скользящее среднее значение поверхностной ОВ ($\bar{\varphi}_{s,30}$) на чувствительных границах материалов при температуре поверхности $T_{surf} \geq 5\ °C$.

**Биологическое обоснование критерия 80 %.** Порог 80 % ОВ выбран с запасом ниже реальных минимумов прорастания (82–90 % для большинства строительных патогенов), чтобы компенсировать неопределённости модели и микроклиматические эффекты. При 30-суточном осреднении кратковременные пиковые события не нарушают соответствия.

## Основной критерий соответствия

{{< formula display="true" >}}
\bar{\varphi}_{s,30}(t) = \frac{1}{720}\sum_{i=0}^{719}\varphi_s(t - i) < 80\,\% \quad \text{при } T_{surf}(t) \geq 5\,°C
{{< /formula >}}

где $\varphi_s(t)$ — почасовое значение поверхностной ОВ; суммирование ведётся по последним 720 ч (30 сут × 24 ч/сут).

**Расширенная таблица пределов по температуре поверхности:**

{{< table title="Максимально допустимое 30-суточное среднее поверхностной ОВ по ASHRAE 160 §5" >}}
| $T_{surf}$, °C | Макс. $\bar{\varphi}_{s,30}$, % | Комментарий |
|---|---|---|
| < 5 | 100 | Биологическая активность ниже порога — критерий не применяется |
| 5–10 | 95 | Психрофильные виды активны при пониженных скоростях роста |
| 10–15 | 85 | Рост многих мезофилов замедлен, но возможен |
| 15–30 | 80 | Основной критерий для комфортных условий |
| > 30 | 80 | Ускоренный рост — критерий остаётся 80 % |
{{< /table >}}

## Нагрузка по влаге в помещении

ASHRAE 160 §5.1 задаёт расчётные условия внутреннего воздуха в зависимости от наружной температуры:

{{< table title="Расчётная внутренняя ОВ для жилых зданий по ASHRAE 160 §5.1" >}}
| Наружная температура, °C | Расчётная ОВ внутреннего воздуха, % |
|---|---|
| < −7 | 15 |
| −7 — −1 | 20 |
| −1 — 4 | 25 |
| 4 — 10 | 30 |
| > 10 | 35 |
{{< /table >}}

Дополнительная нагрузка от жильцов: 3,8 л/сут на человека. В коммерческих зданиях применяются условия ASHRAE 55 (40–60 % ОВ) с механическими системами поддержания.

## Методы демонстрации соответствия

ASHRAE 160 предусматривает три уровня анализа.

### Метод 1. Упрощённый предписывающий

Применяется для простых конструкций в климатах с умеренным влажностным риском (зоны 1–4 по ASHRAE 90.1). Условия:
- непрерывный воздухонепроницаемый слой;
- тепловая изоляция не ниже минимумов энергетического кода;
- пароизоляция расположена в соответствии с климатической зоной (со стороны высокого парциального давления пара);
- гидроизоляция и дренаж по нормативным требованиям.

Ограничение: не применяется для нестандартных конструкций, инновационных материалов и зон с высоким риском (климатические зоны 5–8 или влажный климат 1A–3A).

### Метод 2. Промежуточный расчёт

Стационарный расчёт распределения температуры → определение температуры поверхности на критических границах → расчёт поверхностной ОВ из условий воздуха. Применяется для стандартных узлов с известными теплофизическими свойствами.

### Метод 3. Нестационарное гигротермическое моделирование

Наиболее точный и универсальный метод. Обязателен для климатических зон 5–8, нестандартных конструкций и проектов с инновационными материалами.

**Программное обеспечение:** WUFI Pro (Fraunhofer IBP), DELPHIN (TU Дрезден), MOISTURE-EXPERT, hygIRC. Все эти инструменты реализуют стандарт EN 15026 «Hygrothermal performance of building components — Assessment of moisture transfer by numerical simulation».

**Требования к моделированию:**

{{< table title="Минимальные требования к нестационарному гигротермическому моделированию по ASHRAE 160" >}}
| Параметр | Требование |
|---|---|
| Продолжительность | Минимум 3 года (для учёта межгодовой изменчивости) |
| Климатические данные | Почасовые TMY3 (США) / IWEC (международные) |
| Включаемые воздействия | Прямая и рассеянная солнечная радиация, ветровые осадки |
| Начальная влажность | Строительная влажность материалов |
| Пространственная дискретизация | ≤ 5 мм на границах материалов |
| Временной шаг | ≤ 60 мин для постобработки; 1–15 мин для численного ядра |
{{< /table >}}

## Свойства материалов для моделирования

{{< table title="Требуемые гигротермические свойства материалов для расчёта по ASHRAE 160 / EN 15026" >}}
| Свойство | Единицы | Типичный диапазон |
|---|---|---|
| Теплопроводность | Вт/(м·К) | 0,020–2,0 |
| Плотность | кг/м³ | 30–2400 |
| Удельная теплоёмкость | Дж/(кг·К) | 800–2000 |
| Паропроницаемость | нг/(Па·с·м) | 0,01–1000 |
| Функция сорбции (изотерма) | кг/кг от ОВ | Индивидуальная |
| Капиллярный коэффициент (Dw) | м²/с | 10⁻¹⁰–10⁻⁶ |
{{< /table >}}

Классификация материалов по паропроницаемости (perm по США = нг/(Па·с·м²)):
- Класс I (vapour impermeable): < 0,1 perm — плёнки ПЭ, стеклянный пароизолятор;
- Класс II (vapour semi-impermeable): 0,1–1,0 perm — крафт-бумага, некоторые ЛКМ;
- Класс III (vapour semi-permeable): 1,0–10 perm — гипсокартон, OSB;
- Класс IV (vapour permeable): > 10 perm — минеральная вата без облицовки.

## Числовой пример. Проверка соответствия ASHRAE 160 для стены с внутренней изоляцией

**Условие.** Кирпичная стена с добавлением внутренней изоляции из минеральной ваты 100 мм + гипсокартон 12,5 мм. Климат — Москва (≈ ASHRAE Climate Zone 7). Внутренний воздух: $T_i = 21\ °C$, нагрузка по влаге согласно ASHRAE 160: при $T_e < -7\ °C$ — $\varphi_i = 15\%$; при $T_e = -1$–4 °C — $\varphi_i = 25\%$.

**Шаг 1. Определение критической поверхности.** Граница «кирпич — минеральная вата» (внутренняя поверхность кирпича) — первая конденсирующаяся поверхность при зимнем потоке пара изнутри.

**Шаг 2. Среднеянварское приближение.** $T_e = -9\ °C$ (средняя января для Москвы). Суммарное сопротивление стены $R_{total} = 0{,}13 + 0{,}77 + 2{,}60 + 0{,}04 = 3{,}54\ \text{м}^2\text{К/Вт}$ (внутреннее сопротивление + гипсокартон + минвата + кирпич; без наружного пограничного слоя для консервативности).

Температура на внутренней поверхности кирпича (за изоляцией, со стороны холода):

{{< formula display="true" >}}
T_{brick,in} = T_e + \frac{R_{brick,in}}{R_{total}} \cdot (T_i - T_e) = -9 + \frac{0{,}77}{3{,}54} \cdot 30 = -9 + 6{,}5 = -2{,}5\,°C
{{< /formula >}}

**Шаг 3. Поверхностная ОВ.** При $T_i = 21\ °C$, $\varphi_i = 15\%$ (условие ASHRAE 160): $T_{dp,i} \approx -3{,}5\ °C$. Поверхность при $T_{surf} = -2{,}5\ °C > T_{dp} = -3{,}5\ °C$ — конденсации нет. Поверхностная ОВ:

{{< formula display="true" >}}
\varphi_s = \frac{p_s(-3{,}5)}{p_s(-2{,}5)} \times 15\% \times \frac{p_s(21)}{p_s(-3{,}5)} = \frac{p_s(21) \times 0{,}15}{p_s(-2{,}5)}
{{< /formula >}}

{{< formula display="true" >}}
= \frac{2\,487 \times 0{,}15}{517} \approx 72\,\%
{{< /formula >}}

**Предварительный вывод:** при расчётных зимних условиях поверхностная ОВ на границе кирпич/вата составляет ~72 % < 80 %. Для окончательного подтверждения необходимо полное нестационарное моделирование (3 года) с учётом переходных сезонов — весна и осень дают более опасные условия при более высоком $\varphi_i$.

## Процедура проверки соответствия

**Этап 1. Идентификация критических поверхностей** — все границы материалов в зонах потенциальной конденсации, тепловые мосты.

**Этап 2. Получение климатических данных.** TMY3 (США), IWEC (международные), данные Росгидромета (Россия). Для Москвы допустимо использование IWEC-файла для Москвы-Шереметьево.

**Этап 3. Нестационарная симуляция.** Запуск WUFI или аналога с минимум 3 климатическими годами. Начальная влажность — по условиям строительства.

**Этап 4. Расчёт 30-суточного скользящего среднего** для каждой критической поверхности. Исключение периодов, когда $T_{surf} < 5\ °C$.

**Этап 5. Сравнение с критериями** из таблицы пределов. Ни один 30-суточный период не должен превышать установленный порог.

**Этап 6. Документирование.** Отчёт включает: описание конструкции и свойства материалов; источник климатических данных; метод расчёта; графики $\bar{\varphi}_{s,30}$ по времени для каждой критической поверхности; заявление о соответствии/несоответствии.

## Корректирующие меры при несоответствии

Типичные инженерные решения для приведения конструкции в соответствие:

- увеличение термического сопротивления для повышения $T_{surf}$;
- перемещение или добавление парозамедлителя;
- добавление вентилируемого зазора за наружной обшивкой;
- изменение паропроницаемости материалов (замена на «умный» парозамедлитель с переменным сопротивлением);
- снижение расчётной $\varphi_i$ через усиленную механическую вентиляцию.

После каждого изменения конструкции симуляция повторяется.

## Соотношение ASHRAE 160 и российских нормативов

СП 50.13330 «Тепловая защита зданий» использует метод Глазера (стационарный) для оценки риска конденсации — аналог ISO 13788. Этот метод не способен предсказать рост плесени. ASHRAE 160 и EN 15026 предоставляют более полную картину, учитывая:
- динамический влажностный отклик материалов (сорбция/десорбция);
- капиллярный перенос жидкой влаги;
- накопительный эффект за несколько сезонов.

При проектировании ответственных зданий (больницы, архивы, энергоэффективные дома пассивного уровня) рекомендуется применять оба стандарта параллельно: СП 50.13330 — для нормативного соответствия, ASHRAE 160 / EN 15026 — для инженерной верификации.
