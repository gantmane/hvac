## Область применения

Водные растворы хлорида кальция (calcium chloride, CaCl₂) — один из наиболее широко применяемых неорганических вторичных теплоносителей в промышленном холодоснабжении. Ключевые преимущества: низкая стоимость, доступность, возможность охлаждения до −51 °C (эвтектика). Основная область применения: ледовые катки, низкотемпературные склады (−20 …−40 °C), технологическое охлаждение пищевых производств.

Главный недостаток — высокая коррозивность, обусловленная ионами Cl⁻. Без надёжного ингибирования срок службы трубопроводов из углеродистой стали — менее года.

## Химические формы

{{< table title="Гидраты хлорида кальция" >}}
| Форма | Формула | $M$, г/моль | Применение |
|---|---|:-:|---|
| Безводный | CaCl₂ | 110,98 | Осушитель, первичное смешивание |
| Дигидрат | CaCl₂·2H₂O | 147,01 | Стандартная коммерческая форма |
| Тетрагидрат | CaCl₂·4H₂O | 183,04 | Продукт кристаллизации |
| Гексагидрат | CaCl₂·6H₂O | 219,07 | Кристаллизуется ниже 30 °C |
{{< /table >}}

Растворение безводной формы — сильно экзотермический процесс ($\Delta H_{\text{раств}} \approx -81$ кДж/моль). При заполнении системы необходимо медленное добавление соли с непрерывным перемешиванием и охлаждением.

## Депрессия точки замерзания

Эвтектика системы CaCl₂–H₂O: **29,9 % масс. при −51,0 °C** (твёрдые фазы — лёд + CaCl₂·6H₂O).

{{< table title="Температура замерзания и плотность растворов CaCl₂ (ASHRAE Handbook — Fundamentals, гл. 31)" >}}
| CaCl₂, % масс. | $t_{\text{зам}}$, °C | $\rho$ при 20 °C, кг/м³ |
|:-:|:-:|:-:|
| 5 | −3,0 | 1043 |
| 10 | −7,0 | 1087 |
| 15 | −12,5 | 1134 |
| 20 | −19,0 | 1183 |
| 25 | −28,0 | 1232 |
| 27 | −36,0 | 1252 |
| 29 | −45,0 | 1273 |
| 29,9 (эвтектика) | −51,0 | 1280 |
{{< /table >}}

**Практика выбора концентрации.** Концентрацию устанавливают на 3–5 % масс. выше минимально необходимой для обеспечения защиты от замерзания с запасом 5 °C. Для системы с рабочей температурой −35 °C: минимальная точка замерзания −40 °C соответствует ~28 % масс.; проектная концентрация — 28–29 % масс.

При эвтектической концентрации и −40 °C вязкость в 24 раза выше, чем при 20 °C — это определяет режим насоса и диаметры трубопроводов.

{{< table title="Теплопроводность растворов CaCl₂ при 20 °C" >}}

|:-:|:-:|
| 10 | 0,548 |
| 20 | 0,516 |

Снижение $k$ на 12 % от воды умеренно ухудшает теплообмен, но главный фактор деградации коэффициента теплоотдачи — рост числа Прандтля: Pr = 10–15 при 20 °C и Pr = 30–50 при −30 °C для концентрированных рассолов.

## Числовой пример. Расчёт насоса для ледового катка

**Условие.** Система охлаждения льда катка: $Q = 150$ кВт, рабочая температура рассола −8/−12 °C (средняя −10 °C), концентрация 20 % масс. CaCl₂. Трубопровод $d = 100$ мм, $L_{\text{экв}} = 300$ м.

**Свойства 20 % CaCl₂ при −10 °C** (ASHRAE Handbook — Fundamentals, гл. 31):
- $\rho = 1192$ кг/м³; $\mu = 6{,}10$ мПа·с; $c_p = 3{,}29$ кДж/(кг·К); $k = 0{,}510$ Вт/(м·К).

**Расход:**

{{< formula display="true" >}}
\dot{m} = \frac{Q}{c_p\,\Delta T} = \frac{150}{3{,}29 \times 4} = 11{,}4 \text{ кг/с}
{{< /formula >}}

**Скорость:**

{{< formula display="true" >}}
w = \frac{\dot{m}}{\rho A} = \frac{11{,}4}{1192 \times \pi (0{,}1)^2/4} = \frac{11{,}4}{9{,}36} = 1{,}22 \text{ м/с}
{{< /formula >}}

**Число Рейнольдса:**

{{< formula display="true" >}}
Re = \frac{1192 \times 1{,}22 \times 0{,}1}{6{,}10 \times 10^{-3}} = 23\,830 \quad (\text{турбулентный})
{{< /formula >}}

**Потери давления** ($\varepsilon = 0{,}046$ мм, $\lambda \approx 0{,}0255$):

{{< formula display="true" >}}
\Delta P = 0{,}0255 \times \frac{300}{0{,}1} \times \frac{1192 \times 1{,}22^2}{2} = 0{,}0255 \times 3000 \times 887 = 67\,900 \text{ Па} \approx 0{,}68 \text{ бар}
{{< /formula >}}

С запасом 1,3 для учёта пусковой вязкости и загрязнений: $\Delta P_{\text{расч}} = 0{,}88$ бар.

**Мощность насоса** ($\eta = 0{,}70$):

{{< formula display="true" >}}
W = \frac{(11{,}4/1192) \times 88\,000}{0{,}70} = 1{,}20 \text{ кВт}
{{< /formula >}}

## Коррозия и ингибирование

### Механизм коррозионного воздействия

Ионы Cl⁻ разрушают пассивную оксидную плёнку на поверхности металлов, вызывая питтинговую и щелевую коррозию. Высокая электропроводность рассола (до 15 С/м) ускоряет электрохимические процессы. Растворённый кислород — катодный деполяризатор; естественный pH рассола 5–6 (из-за растворения CO₂).

{{< table title="Скорость коррозии металлов в рассоле CaCl₂ без ингибиторов" >}}
| Материал | Скорость коррозии, мм/год | Оценка |
|---|:-:|---|
| Углеродистая сталь | 0,5–2,0 | Неприемлемо |
| Оцинкованная сталь | 0,2–0,8 | Неприемлемо |
| Медь | 0,02–0,08 | Допустимо только с ингибиторами |
| Нержавеющая сталь 304 | 0,01–0,05 | Подвержена питтингу |
| Нержавеющая сталь 316 | < 0,01 | Хорошая стойкость |
{{< /table >}}

### Современный ингибиторный пакет

{{< table title="Компоненты ингибиторного пакета для рассолов CaCl₂" >}}
| Ингибитор | Концентрация | Функция |
|---|:-:|---|
| Нитрит натрия (NaNO₂) | 2000–5000 ppm | Анодная пассивация, чёрные металлы |
| Молибдат натрия (Na₂MoO₄) | 500–1500 ppm | Дополнительный анодный ингибитор |
| Тетраборат натрия (Na₂B₄O₇) | 1000–3000 ppm | Буферизация pH, пассивация |
| Толилтриазол (TTA) | 50–200 ppm | Защита медных сплавов |
| Полиакрилаты | 100–500 ppm | Диспергатор отложений |
{{< /table >}}

**Целевой pH:** 7,5–9,0. При pH < 7,0 — немедленное добавление NaOH и расследование причины закисления.

**Контроль растворённого кислорода:** целевое содержание < 0,5 ppm. Закрытые системы с азотным завесом на расширительном баке; химическое связывание сульфитом натрия:

{{< formula display="true" >}}
2\,\text{Na}_2\text{SO}_3 + \text{O}_2 \rightarrow 2\,\text{Na}_2\text{SO}_4
{{< /formula >}}

Дозировка: 8 г Na₂SO₃ на 1 мг O₂ (с катализатором кобальта при низких температурах).

## Выбор материалов

{{< table title="Рекомендуемые материалы для систем с рассолом CaCl₂" >}}
| Узел | Рекомендуемый материал | Не допускается |
|---|---|---|
| Трубопроводы | Углеродистая сталь Sch 40 с ингибиторами | Оцинкованная сталь, алюминий |
| Теплообменник | Нержавеющая сталь 316 (пластинчатый) | Сталь 304, углеродистая сталь |
| Насос | Чугунный корпус, ротор SS 316 | Бронза, латунь |
| Расширительный бак | Сталь с эпоксидной облицовкой | Необлицованная сталь |
| Уплотнения/прокладки | EPDM, Viton (FKM), PTFE | Натуральный каучук, нитрил (NBR) |
{{< /table >}}

**Скорости течения:** минимум 0,6 м/с для предотвращения стагнационной коррозии; максимум 2,4 м/с для основных распределительных трубопроводов; для ледового катка — 0,6–0,9 м/с.
