Автоматическое оборудование для сжигания топлива — масляные форсунки (oil burners), газовые горелки (gas burners) и двухтопливные системы (dual-fuel burners) — обеспечивает управляемое, эффективное горение в котлах, промышленных нагревателях и системах теплоснабжения зданий. Современная технология горелок направлена на достижение высокого термического КПД (80–95 %), минимизацию выбросов (NOx < 9–60 ppm, CO < 50 ppm), безопасную работу через системы защиты пламени (flame safeguard) и поддержание оптимального соотношения воздух-топливо (air-fuel ratio) во всём рабочем диапазоне. Проектирование горелки требует анализа характеристик топлива, тепловой мощности, диапазона регулирования (turndown ratio), целевого КПД, соответствия нормативам выбросов и интеграции с системой управления зданием (BMS).

Нормативная база: ASHRAE Handbook — HVAC Systems and Equipment, ASHRAE 90.1, EN 303, EN 12831, EN 15316, СП 60.13330, NFPA 54, NFPA 86.

## Стехиометрия и избыточный воздух

### Реакции горения

**Природный газ (метан):**

{{< formula display="true" >}}
\text{CH}_4 + 2\,\text{O}_2 + 7{,}52\,\text{N}_2 \;\rightarrow\; \text{CO}_2 + 2\,\text{H}_2\text{O} + 7{,}52\,\text{N}_2
{{< /formula >}}

Стехиометрическое количество воздуха: $A_s = 17{,}2$ кг/кг CH₄ (по массе) или $9{,}52$ м³/м³ (по объёму).

**Дизельное топливо № 2 (No. 2 fuel oil, C₁₂H₂₃):**

{{< formula display="true" >}}
\text{C}_{12}\text{H}_{23} + 17{,}375\,\text{O}_2 \;\rightarrow\; 12\,\text{CO}_2 + 11{,}5\,\text{H}_2\text{O}
{{< /formula >}}

$A_s = 13{,}8$ кг/кг масла $\approx 97$ м³/л масла.

### Избыточный воздух (excess air)

Фактическое горение требует воздуха сверх стехиометрического:

{{< formula display="true" >}}
EA\,\% = \frac{A_{\text{факт}} - A_s}{A_s} \times 100
\qquad
O_2\,\% = \frac{21 \times EA}{100 + EA}
{{< /formula >}}

**Пример.** Газовая горелка, $EA = 15\,\%$:

{{< formula display="true" >}}
O_2\,\% = \frac{21 \times 15}{115} = 2{,}74\,\%
{{< /formula >}}

{{< table title="Типичный избыточный воздух по типам горелок (ASHRAE Handbook)" >}}
| Тип горелки | EA, % | O₂, % |
|---|---|---|
| Атмосферная газовая (atmospheric gas) | 40–50 | 6–8 |
| Силовая газовая (power gas) | 10–20 | 1,5–3,5 |
| Газовая с предварительным смешением (premix) | 5–15 | 0,8–2,5 |
| Масляная форсунка (pressure-atomizing) | 20–30 | 3,5–5,0 |
| Ротационная масляная (rotary cup) | 15–25 | 2,5–4,5 |
| Двухтопливная (dual-fuel) | 15–25 | 2,5–4,5 |
{{< /table >}}

## Расчёт КПД горения

### Потери в дымоходе (flue losses)

{{< formula display="true" >}}
\eta = 100\,\% - L_{\text{дымоход}} - L_{\text{излучение}} - L_{\text{неполное}}
{{< /formula >}}

Потеря через дымоход через CO₂:

{{< formula display="true" >}}
L_{\text{дымоход}} = K \cdot \frac{T_{\text{дымоход}} - T_{\text{воздух}}}{CO_2\,\%}
{{< /formula >}}

$K = 0{,}65$ для природного газа; $K = 0{,}54$ для дизельного № 2.

### Пример расчёта

Газовая горелка котла 3,5 МВт:
- $T_{\text{дымоход}} = 220\,°C$; $T_{\text{воздух}} = 15\,°C$; CO₂ = 9,2 %; CO = 40 ppm.

{{< formula display="true" >}}
L_{\text{дымоход}} = 0{,}65 \times \frac{220 - 15}{9{,}2} = 14{,}5\,\%
{{< /formula >}}

{{< formula display="true" >}}
L_{\text{неполное}} = 10{,}2 \times \frac{40}{9{,}2} = 0{,}04\,\%
{{< /formula >}}

{{< formula display="true" >}}
\eta = 100 - 14{,}5 - 0{,}7 - 0{,}04 = 84{,}8\,\%
{{< /formula >}}

Снижение O₂ с 5 % до 3 % (уменьшение EA с 31 % до 17 %) при той же температуре даёт прирост КПД около 1,5–2 %.

## Управление соотношением воздух-топливо

### Методы управления

**Позиционирование включение-выключение (on-off positioning).**
Жёсткая механическая связь между воздушной заслонкой и топливным клапаном; точность ±15–20 % оптимального соотношения. Применяется для малых горелок (< 30 кВт).

**Ступенчатое управление высокое-низкое (high-low-off).**
Два дискретных режима горения; низкая ступень — 30–50 % от высокой. Жилые и лёгкие коммерческие системы.

**Полное модулирование (full modulation).**
Непрерывная регулировка режима горения; механическая сцепка (linkage) или электронное позиционирование приводов; точность ±5–10 % по диапазону.

**Параллельное позиционирование (parallel positioning).**
Независимые электронные приводы на воздушной заслонке и топливном клапане; точность ±2–5 %; характерно для современных котлов мощностью > 300 кВт.

**Перекрёстное ограничение (cross-limiting).**
Воздух опережает при повышении нагрузки; топливо опережает при снижении — предотвращает образование опасной обогащённой смеси; обязательно для котлов > 30 кВт по NFPA 86.

### Управление с коррекцией по O₂ (oxygen trim control)

Замкнутая система поддерживает оптимальный избыточный воздух по сигналу циркониевого или электрохимического датчика O₂:

- **Целевое значение O₂:** 2,0–3,5 % для природного газа; 2,5–4,0 % для дизельного № 2.
- **Время отклика:** 10–30 с.
- **Точность поддержания:** ±0,2–0,5 % O₂.
- **Прирост КПД:** снижение EA с 30 % до 15 % при $T_{\text{дымоход}} = 230\,°C$ даёт порядка 2–3 % КПД.

## Системы защиты пламени (flame safeguard)

### Последовательность запуска (NFPA 86)

```
1. Предварительные проверки (interlock check) — 2–5 с
2. Предварительная продувка (prepurge) — минимум 4 воздухообмена (15–60 с)
3. Зажигание пилота (pilot ignition trial) — 4–10 с
4. Установление пилота (pilot flame proven) — 4–10 с
5. Открытие основного топливного клапана
6. Установление основного пламени (main flame trial) — 4–10 с
7. Деактивация зажигания; горелка переходит в рабочий режим
```

Время предварительной продувки:

{{< formula display="true" >}}
t_{\text{продувка}} = \frac{4 \times V_{\text{топка}}}{\dot{V}_{\text{воздух}}} \times 3600\;\text{(с)}
{{< /formula >}}

### Методы обнаружения пламени

{{< table title="Технологии детектирования пламени" >}}
| Метод | Принцип | Применение | Время отклика |
|---|---|---|---|
| УФ-сканер (UV scanner) | УФ-излучение пламени, 1 850–2 900 Å | Газ и масло, коммерческие/промышленные | 1–4 с |
| Ионизационный электрод (flame rod) | Электропроводность ионизированного пламени | Только газ, жилые/коммерческие | 1–2 с |
| CdS-ячейка (cadmium sulfide) | Видимый свет пламени | Жилые масляные горелки | 1–3 с |
| ИК-сканер (IR scanner) | ИК-излучение CO₂ пламени (4,3 мкм) | Крупные промышленные | 1–4 с |
{{< /table >}}

**Условия блокировки (interlock trip):**
- потеря пламени во время работы (немедленное отключение топлива, ручной сброс);
- отказ зажигания в течение периода испытания;
- пламя обнаружено при закрытых клапанах (ложный сигнал);
- низкое/высокое давление топлива;
- низкое давление воздуха горения;
- небезопасная тяга в дымоходе.

## Образование NOx и методы снижения

### Механизмы образования

**Тепловой NOx (thermal NOx)** — образуется при температуре > 1 540 °C по механизму Зельдовича; скорость удваивается примерно на каждые 50 °C выше порога.

**Топливный NOx** — окисление азота, содержащегося в топливе; значим для тяжёлых масел и угля.

**Быстрый NOx (prompt NOx)** — в обогащённых зонах пламени; незначительный вклад при сжигании природного газа.

### Первичные методы снижения NOx

**Рециркуляция дымовых газов (FGR, flue gas recirculation).**
Возврат 10–30 % дымовых газов в воздух горения снижает концентрацию O₂ и температуру пламени на 110–220 °C. Снижение NOx: 40–70 %.

{{< formula display="true" >}}
FGR\,\% = \frac{\dot{m}_{\text{рецирк}}}{\dot{m}_{\text{воздух}}} \times 100
{{< /formula >}}

**Ступенчатое горение (staged combustion).**
Первичная зона — обогащённая смесь; вторичный воздух подаётся ниже по потоку. Снижение NOx: 50–80 %.

**Конструкция низконоксной горелки (low-NOx burner).**
Внутренняя FGR, задержанное смешение (delayed mixing), распределённое горение (distributed combustion). Снижение NOx: 50–85 % относительно стандартных горелок.

### Вторичные методы (post-combustion)

**SCR (selective catalytic reduction).** Впрыск аммиака (NH₃) или мочевины (urea) перед слоем катализатора (315–427 °C); снижение NOx: 80–95 %. Применяется при требовании < 9 ppm.

**SNCR (selective non-catalytic reduction).** Впрыск восстановителя в зону высокой температуры (870–1 090 °C); снижение NOx: 30–50 %; менее затратно, чем SCR.

## Методология расчёта мощности горелки

### Требуемая тепловая мощность

{{< formula display="true" >}}
Q_{\text{горелка}} = \frac{Q_{\text{нагрузка}}}{\eta_{\text{система}}}
{{< /formula >}}

Мощность разогрева системы:

{{< formula display="true" >}}
Q_{\text{разогрев}} = \frac{M \cdot C_p \cdot \Delta T}{t_{\text{разогрев}} \times 3600}\;\text{(кВт)}
{{< /formula >}}

Итоговая мощность горелки с коэффициентом запаса $SF$:

{{< formula display="true" >}}
Q_{\text{горелка}} = \max\!\bigl(Q_{\text{нагрузка}},\;Q_{\text{разогрев}}\bigr) \times SF
{{< /formula >}}

$SF = 1{,}10$–$1{,}25$ для котлов; $1{,}15$–$1{,}30$ для промышленных нагревателей.

### Диапазон регулирования (turndown ratio)

{{< formula display="true" >}}
TD = \frac{Q_{\max}}{Q_{\min}} \;\geq\; \frac{Q_{\text{расчёт}}}{Q_{\text{лето}}}
{{< /formula >}}

Типичные требования: котлы — 4:1–10:1; технологические нагреватели — 3:1–8:1; конденсационные высокоэффективные системы — 10:1–25:1.

## Состав раздела

Данный раздел содержит детальное рассмотрение следующих тем:

1. **Масляные горелки (oil burners)** — форсунки высокого давления, ротационные, воздушного и парового распыления; теория распыления и расчёт размеров.
2. **Газовые горелки (gas burners)** — атмосферные, силовые, с предварительным смешением, низконоксные; анализ устойчивости пламени и смешения.
3. **Угольные горелки (coal burners)** — механические питатели (stokers), пылеугольное сжигание (PCC), псевдоожиженный слой (FBC).
4. **Двухтопливные горелки (dual-fuel burners)** — комбинированные конструкции, автоматическое переключение, экономический анализ.
5. **Системы управления горелкой (burner management systems)** — защита пламени, позиционирование, блокировки безопасности.
6. **Воздух горения (combustion air)** — расчёт потребности, вентиляторы, подпиточный воздух.
7. **Анализ дымовых газов (flue gas analysis)** — оптимизация КПД, непрерывный мониторинг выбросов (CEMS), диагностика.
8. **Снижение NOx** — системы FGR, SCR, SNCR; конструкции ультранизконоксных горелок.
