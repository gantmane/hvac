## Задача проектирования стен в смешанном климате

Стеновая конструкция в смешанном климате (зоны 3–5 по ASHRAE) должна одновременно:

1. Обеспечивать нормируемое сопротивление теплопередаче (СП 50.13330.2017).
2. Защищать конструктивные элементы (OSB, деревянный каркас) от конденсации в зимний период.
3. Не блокировать высыхание полости в летний период при реверсе парового потока.
4. Управлять дождевой водой через дренажный слой и вентилируемый зазор.

Ни одна из этих целей не достигается в ущерб другим — это требует системного подхода.

## Система А: Каркасная стена с наружной непрерывной изоляцией

Наиболее распространённая высокопроизводительная схема для деревянного каркаса в зонах 4А–5А.

### Состав конструкции (снаружи внутрь)

```
[Облицовка — фиброцементная доска, кирпич, дерево]
[Вентилируемый зазор 20–25 мм]
[Диффузионная ветрозащита (> 20 пермей)]
[Наружная непрерывная изоляция: PIR без фольги / EPS / минвата]
[OSB-обшивка 12 мм]
[Стойки 150 мм + минеральная вата в полости]
[Умная мембрана ИЛИ латексная краска на ГКЛ]
[ГКЛ 12,5 мм]
```

### Тепловые и паровые характеристики (зона 5А, Москва)

Вариант с PIR 50 мм (без фольги, ~2 пермя) + минвата в полости 150 мм:

| Слой | $d$, мм | $\lambda$, Вт/(м·К) | $R_i$, м²·К/Вт | $\delta$, мг/(м·ч·Па) | $Z_i$, м²·ч·Па/мг |
|---|---|---|---|---|---|
| Пов. сопр. внутр. | — | — | 0,13 | — | — |
| ГКЛ 12,5 + краска | 12,5 | 0,21 | 0,05 | — | 258 |
| Умная мембрана (зима) | — | — | — | — | 800 |
| Минвата в полости | 150 | 0,036 | 4,17 | 0,560 | 268 |
| OSB 12 мм | 12 | 0,13 | 0,09 | 0,070 | 171 |
| PIR 50 мм | 50 | 0,022 | 2,27 | 0,023 | 2174 |
| Ветрозащита | — | — | — | — | 5 |
| Пов. сопр. нар. | — | — | 0,13 | — | — |

$R_{\text{total}} = 0{,}13 + 0{,}05 + 4{,}17 + 0{,}09 + 2{,}27 + 0{,}13 = 6{,}84$ м²·К/Вт

Соответствует нормативному требованию для Москвы по СП 50.13330.2017 ($R_{\text{req}} = 3{,}28$ м²·К/Вт для стен жилых зданий — с существенным запасом).

**Доля наружной изоляции:**

{{< formula display="true" >}}
\frac{R_{\text{ext}}}{R_{\text{total}}} = \frac{2{,}27}{6{,}84} = 33\% > 30\%~\text{(норм. для зоны 5А)}
{{< /formula >}}

**Температура OSB при расчётной зимней температуре −28 °C:**

{{< formula display="true" >}}
T_{\text{OSB}} = -28 + 56 \cdot \frac{0{,}13 + 2{,}27}{6{,}84} = -28 + 56 \times 0{,}351 = -28 + 19{,}6 = -8{,}4~°C
{{< /formula >}}

$p_{\text{sat}}(-8{,}4~°C) \approx 290$ Па.

Давление пара у OSB (умная мембрана зимой, $Z_{\text{ret}} = 800$):

$Z_{\text{int}\to\text{OSB}} = 258 + 800 + 268 = 1326$ м²·ч·Па/мг

$Z_{\text{total,пар}} = 1326 + 171 + 2174 + 5 = 3676$

$g = (994 - 60) / 3676 = 0{,}25$ мг/(м²·ч)

$p_{v,\text{OSB}} = 994 - 0{,}25 \times 1326 = 994 - 332 = 662$ Па

$662 > 290$ Па... Давление пара у OSB (662 Па) намного выше $p_{\text{sat}}$ (290 Па) — анализ показывает, что давление снаружи от OSB в сторону PIR падает резко: $p_{v,\text{ext side of OSB}} = 60 + 0{,}25 \times (2174 + 5) = 60 + 545 = 605$ Па, $p_{\text{sat, OSB}} = 290$ Па.

При $p_{v,\text{OSB,int side}} = 662$ Па и $p_{v,\text{OSB,ext side}} = 605$ Па — поток через OSB мал (~57 Па разница). Это допустимо: высокое паросопротивление PIR снаружи и умной мембраны внутри удерживают поток в OSB на минимальном уровне, осушение обеспечивается летом.

## Система Б: Каркасная стена с наружной минватой (паропроницаемой)

Вариант с высоким потенциалом высыхания наружу.

```
[Облицовка]
[Вентилируемый зазор 20 мм]
[Диффузионная ветрозащита]
[Минеральная вата фасадная 80 мм, R = 2,22 м²·К/Вт, > 100 пермей]
[OSB 12 мм]
[Стойки 150 мм + минвата в полости]
[Умная мембрана]
[ГКЛ + латексная краска]
```

Наружная минвата полностью паропроницаема (> 100 пермей) — зимой OSB высыхает наружу без ограничений. Умная мембрана изнутри ограничивает зимний поток внутреннего пара к OSB.

$R_{\text{total}} \approx 0{,}13 + 0{,}05 + 4{,}17 + 0{,}09 + 2{,}22 + 0{,}13 = 6{,}79$ м²·К/Вт — аналогично системе А.

Преимущество: OSB может высыхать наружу практически без ограничений. Недостаток: PIR без фольги лучше блокирует летний обратный поток (~2 пермя vs. > 100 пермей у минваты).

## Система В: Кладочная стена с наружным утеплением (СФТК)

Система фасадного теплоизоляционного комплекса (СФТК, «мокрый фасад», ETICS) применяется для кирпичной кладки и газобетона.

### Состав конструкции

```
[Декоративная штукатурка 5–10 мм]
[Армирующий слой (сетка + штукатурка)]
[Теплоизоляционная плита EPS/PIR 80–150 мм]  ← наружный замедлитель (опц.)
[Клеевой слой]
[Кладка газобетон D500, 375 мм]
[Штукатурка внутренняя + латексная краска]
```

### Паровые характеристики СФТК с EPS (зона 4А, Воронеж)

EPS без покрытия: ~3–5 пермей (Класс III) — паропроницаем, не блокирует высыхание наружу.

Газобетон D500, 375 мм: $\delta = 0{,}20$ мг/(м·ч·Па), $Z = 1875$ м²·ч·Па/мг.

EPS 100 мм: $\delta = 0{,}040$ мг/(м·ч·Па), $Z = 2500$ м²·ч·Па/мг.

$Z_{\text{ext}\to\text{кладка}} = 2500$ (EPS); $Z_{\text{int}\to\text{кладка}} = 1875$ (кладка) + 258 (ГКЛ+краска) = 2133.

Соотношение: $2500 / 2133 \approx 1{,}2$ — практически симметрично, высыхание в обе стороны обеспечено.

**Числовой пример: зимний поток**

Воронеж, январь: внутри +21 °C / 40 %, снаружи −10 °C / 82 %.

$\Delta p_v = 994 - 208 = +786$ Па.

$g = 786 / (2133 + 2500) = 786 / 4633 = 0{,}170$ мг/(м²·ч) — малый поток, конденсации нет.

## Система Г: Двойной каркас с целлюлозным заполнением

Применяется в энергоэффективных и пассивных домах для достижения $R > 7$ м²·К/Вт без тепловых мостов.

```
[Облицовка вентилируемого фасада]
[Диффузионная ветрозащита]
[Наружный каркас 50×100 мм + целлюлоза 100 мм]
[Зазор / горизонтальная обрешётка (воздух. барьер)]
[Внутренний каркас 50×150 мм + целлюлоза 150 мм]
[Умная мембрана (воздушный барьер + паровой замедлитель)]
[ГКЛ + латексная краска]
```

$R_{\text{total}} \approx 0{,}13 + (100+150) / 40 + 0{,}13 \approx 0{,}26 + 6{,}25 = 6{,}51$ м²·К/Вт (без учёта тепловых мостов, которые при двойном каркасе минимальны).

Целлюлоза — высокобуферный материал: равновесное СВ при 80 % ОВ ≈ 18 % масс., ёмкость ~4,5 кг/м³. Это снижает пиковые значения давления пара внутри конструкции.

## Система со стальным каркасом

Стальные стойки создают значительные тепловые мосты: эффективное $R$ стены со стальными стойками 150 мм + минвата на 40–50 % ниже номинального из-за теплопроводности стали ($\lambda_{\text{сталь}} = 50$ Вт/(м·К)).

**Расчёт эффективного R** по методу ASHRAE (parallel heat flow path):

{{< formula display="true" >}}
\frac{1}{R_{\text{eff}}} = \frac{f_{\text{steel}}}{R_{\text{steel path}}} + \frac{f_{\text{insul}}}{R_{\text{insul path}}}
{{< /formula >}}

где $f_{\text{steel}}$ — доля площади стали (типично 15–25 % для стоек с шагом 600 мм).

При $f_{\text{steel}} = 0{,}20$, $R_{\text{steel path}} = 0{,}30$ м²·К/Вт, $R_{\text{insul path}} = 4{,}17$ м²·К/Вт:

$1/R_{\text{eff}} = 0{,}20/0{,}30 + 0{,}80/4{,}17 = 0{,}667 + 0{,}192 = 0{,}859$

$R_{\text{eff}} = 1{,}16$ м²·К/Вт — против номинального 4,17 м²·К/Вт. Снижение в 3,6 раза.

**Вывод:** Стальной каркас без непрерывной наружной изоляции недопустим для российского климата. Обязательна сплошная наружная изоляция не менее 80–100 мм.

## Вентилируемый зазор: параметры проектирования

Вентилируемый зазор между облицовкой и наружным слоем конструкции — обязательный элемент для всех систем в смешанном климате:

| Параметр | Значение |
|---|---|
| Минимальная ширина зазора | 10 мм |
| Рекомендуемая ширина | 20–25 мм |
| Вентиляционные отверстия снизу и сверху | ≥ 130 см² на 1 м² стены |
| Расчётная скорость воздуха в зазоре | 0,3–1,0 м/с |
| Диффузионная ветрозащита (снаружи от зазора) | > 20 пермей |

Зазор выполняет три функции: удаление дождевой влаги, удаление влаги от «солнечного насоса» и снижение температуры наружной поверхности конструкции летом.

## Требования к монтажу

**Непрерывность воздушного барьера.** Умная мембрана или OSB (при условии проклейки всех стыков) выполняет функцию воздушного барьера. Стыки OSB проклеиваются акриловой лентой по всему периметру. Проходки труб и кабелей — манжеты или жидкая герметизация.

**Наружная изоляция.** Плиты монтируются в разбежку стыков. При многослойной укладке стыки каждого слоя смещаются. Механические крепёжные элементы с теплоизолирующими дюбелями (термодюбели) — паспортное усилие вырыва ≥ 0,6 кН.

**Контроль влажности при строительстве.** До закрытия фасадной облицовки влажность OSB ≤ 19 % (MC). Деревянные стойки — ≤ 19 %. Монтаж наружной изоляции немедленно после OSB снижает риск намокания в период строительства.
