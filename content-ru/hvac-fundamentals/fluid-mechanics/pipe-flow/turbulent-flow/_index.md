Турбулентный поток — нормальное рабочее состояние трубопроводов и воздуховодов HVAC. Хаотичное трёхмерное движение жидкости с интенсивным поперечным перемешиванием определяет профиль скорости, теплоотдачу и, главное, потери давления. Понимание турбулентности не требует решения уравнений Навье–Стокса в полной форме: для инженерного расчёта достаточно диаграммы Муди и уравнения Коулбрука–Уайта.

## Физическая структура турбулентного потока

Вблизи стенки турбулентный пограничный слой состоит из трёх зон, разделяемых по безразмерной координатe {{< formula >}}y^+ = u_*\,y/\nu{{< /formula >}}, где {{< formula >}}u_* = \sqrt{\tau_w/\rho}{{< /formula >}} — скорость трения.

{{< table title="Зоны турбулентного пограничного слоя" >}}
| Зона | y⁺ | Закон скорости | Физика |
|---|---|---|---|
| Вязкий подслой | 0–5 | u⁺ = y⁺ | Молекулярная вязкость доминирует |
| Буферный (переходный) слой | 5–30 | — | Вязкость и турбулентность соизмеримы |
| Логарифмический слой | 30–500 | u⁺ = 2,5 ln y⁺ + 5,0 | Турбулентные напряжения доминируют |
| Внешний слой (ядро) | > 500 | Дефект скорости | Практически однороден |
{{< /table >}}

Логарифмический профиль:

{{< formula display="true" >}}
\frac{u}{u_*} = \frac{1}{\kappa}\ln\frac{y u_*}{\nu} + C
{{< /formula >}}

где {{< formula >}}\kappa = 0{,}41{{< /formula >}} — константа Кармана, C = 5,0 для гладкой стенки.

Интегрируя по сечению, получают формулу для среднего коэффициента трения Никурадзе (гладкие трубы):

{{< formula display="true" >}}
\frac{1}{\sqrt{\lambda}} = 2\lg(Re\sqrt{\lambda}) - 0{,}8
{{< /formula >}}

## Уравнение Коулбрука–Уайта: базовое для инженерного расчёта

Коулбрук и Уайт обобщили опыты Никурадзе на промышленные трубы с непроизвольной (случайной) шероховатостью и получили уравнение:

{{< formula display="true" >}}
\frac{1}{\sqrt{\lambda}} = -2\lg\!\left(\frac{k_s}{3{,}7\,D} + \frac{2{,}51}{Re\sqrt{\lambda}}\right)
{{< /formula >}}

Первый член в скобках отвечает за шероховатость, второй — за вязкость. Уравнение объединяет все режимы турбулентного потока:

- При малых Re (или малой шероховатости): второй член доминирует → гладкотрубный режим.
- При больших Re (или большой шероховатости): первый член доминирует → квадратичный закон (λ не зависит от Re).

### Итерационное решение

Начальное приближение: {{< formula >}}\lambda_0 = 0{,}02{{< /formula >}}. После 3–4 итераций:

{{< formula display="true" >}}
\lambda_{n+1} = \left[-2\lg\!\left(\frac{k_s}{3{,}7D} + \frac{2{,}51}{Re\sqrt{\lambda_n}}\right)\right]^{-2}
{{< /formula >}}

**Пример.** DN50, сталь k_s = 0,1 мм, Re = 80 000.

- Итерация 0: λ₀ = 0,02 → 1/√0,02 = 7,07. Правая часть: -2·lg(0,1/(3,7·50) + 2,51/(80000·√0,02)) = -2·lg(5,41·10⁻⁴ + 2,22·10⁻⁴) = -2·lg(7,63·10⁻⁴) = -2·(-3,117) = 6,234. λ₁ = 1/6,234² = 0,0257.
- Итерация 1: √0,0257 = 0,1603. Правая: -2·lg(5,41·10⁻⁴ + 1,96·10⁻⁴) = -2·lg(7,37·10⁻⁴) = 6,265. λ₂ = 0,0255.
- Сходимость: **λ = 0,0255**.

### Явная формула Свами–Джейна

{{< formula display="true" >}}
\lambda = \frac{0{,}25}{\left[\lg\!\left(\dfrac{k_s}{3{,}7D} + \dfrac{5{,}74}{Re^{0{,}9}}\right)\right]^2}
{{< /formula >}}

Диапазон: 4·10³ < Re < 10⁸, 10⁻⁶ < k_s/D < 10⁻². Погрешность ≤ 2 % по сравнению с Коулбруком. Удобна для таблиц и быстрых расчётов.

### Другие явные аппроксимации

Формула Черчилля (1977, погрешность < 0,2 % для всех Re):

{{< formula display="true" >}}
\lambda = 8\left[\left(\frac{8}{Re}\right)^{12} + (A+B)^{-1{,}5}\right]^{1/12}
{{< /formula >}}

{{< formula display="true" >}}
A = \left[2{,}457\ln\!\left(\frac{1}{(7/Re)^{0{,}9} + 0{,}27k_s/D}\right)\right]^{16},\quad
B = \left(\frac{37530}{Re}\right)^{16}
{{< /formula >}}

## Диаграмма Муди: интерпретация зон

{{< table title="Режимы потока на диаграмме Муди" >}}
| Зона | Признак | λ от Re | λ от k_s/D |
|---|---|---|---|
| Ламинарная (Re < 2300) | Прямая λ = 64/Re | Да | Нет |
| Гладкотрубный турбулентный | Нижняя огибающая | Да | Нет |
| Смешанный | Средняя часть | Да | Да |
| Полностью шероховатый | Горизонтальные плато | Нет | Да |
{{< /table >}}

Переход в «квадратичный закон» (λ = const) наступает при:

{{< formula display="true" >}}
Re > Re^* = 200\,D/k_s
{{< /formula >}}

Для стальной трубы DN80 (k_s = 0,1 мм): Re* = 200·80/0,1 = 160 000. При Re < 160 000 шероховатость влияет на λ через оба члена Коулбрука.

## Числовые примеры расчёта

### Пример 1. Стояк системы охлаждённой воды (Москва, офис)

**Условия:** подающий стояк системы кондиционирования, DN65, стальная труба с полимерным покрытием (k_s = 0,01 мм). Расход Q = 3,5 л/с, температура воды 7 °C. Длина участка L = 30 м, фитинги: 3 колена 90° (R = 2D, ζ = 0,9 каждое), 1 тройник-ответвление (ζ = 1,3).

Внутренний диаметр DN65 с покрытием: d_вн = 63 мм = 0,063 м.

{{< formula display="true" >}}
V = \frac{4Q}{\pi D^2} = \frac{4\times0{,}0035}{\pi\times0{,}063^2} = 1{,}124\text{ м/с}
{{< /formula >}}

При 7 °C: ρ = 999,7 кг/м³, ν = 1,41·10⁻⁶ м²/с.

{{< formula display="true" >}}
Re = \frac{1{,}124\times0{,}063}{1{,}41\times10^{-6}} = 50\,200
{{< /formula >}}

k_s/D = 0,01/63 = 1,59·10⁻⁴.

По Свами–Джейну: λ = 0,25/[lg(4,29·10⁻⁵ + 5,74/50200⁰·⁹)]² ≈ 0,0215.

Линейные потери:

{{< formula display="true" >}}
\Delta P_\text{лин} = 0{,}0215\times\frac{30}{0{,}063}\times\frac{999{,}7\times1{,}124^2}{2} = 2576\text{ Па}
{{< /formula >}}

Местные потери (ζ_сумм = 3·0,9 + 1,3 = 4,0):

{{< formula display="true" >}}
\Delta P_\text{мест} = 4{,}0\times\frac{999{,}7\times1{,}124^2}{2} = 2526\text{ Па}
{{< /formula >}}

**Итого: ΔP = 2576 + 2526 = 5102 Па ≈ 5,1 кПа.**

Удельный перепад: 5,1 кПа / 30 м = 170 Па/м — соответствует норме (≤ 200 Па/м по СП 60).

### Пример 2. Влияние возраста трубы на потери

Те же параметры, но труба стальная без покрытия, после 15 лет эксплуатации с увеличенной шероховатостью k_s = 0,8 мм (ржавчина, отложения):

k_s/D = 0,8/63 = 1,27·10⁻². По Свами–Джейну: λ ≈ 0,040. Линейные потери: 2576·(0,040/0,0215) = 4793 Па. Рост потерь вдвое — типичная ситуация при реконструкции.

## Скорость трения и безразмерные переменные

{{< formula display="true" >}}
u_* = \sqrt{\frac{\tau_w}{\rho}} = V\sqrt{\frac{\lambda}{8}}
{{< /formula >}}

{{< formula display="true" >}}
\tau_w = \frac{\lambda}{8}\rho V^2
{{< /formula >}}

Напряжение на стенке необходимо для расчёта эрозии трубы. При V = 3 м/с в стальной трубе DN50: τ_w = 0,025/8 · 998 · 9 = 28 Па. Для меди с пайкой (k_s = 0,0015 мм) τ_w ниже — медные трубы меньше подвержены коррозионно-эрозионному износу.

## Тепловые аналогии: связь Cf с теплоотдачей

Аналогия Рейнольдса (точна при Pr ≈ 1):

{{< formula display="true" >}}
St = \frac{Nu}{Re\,Pr} = \frac{\lambda}{8}
{{< /formula >}}

Аналогия Чилтона–Колберна (0,5 < Pr < 170):

{{< formula display="true" >}}
j_H = \frac{Nu}{Re\,Pr^{1/3}} = \frac{\lambda}{8}
{{< /formula >}}

Эти соотношения применяются при конструировании теплообменников и для проверки корреляций Nu. Наиболее точная для труб — корреляция Гниелинского (Re > 4000, 0,5 < Pr < 2000):

{{< formula display="true" >}}
Nu = \frac{(\lambda/8)(Re-1000)\,Pr}{1+12{,}7\sqrt{\lambda/8}(Pr^{2/3}-1)}
{{< /formula >}}

## Оптимизация скорости: энергетический компромисс

Увеличение скорости в трубопроводе снижает капитальные затраты (меньший диаметр), но повышает эксплуатационные (мощность насоса). Для систем с длительным временем работы (8000 ч/год) стоимость электроэнергии быстро превышает экономию на трубах. Оптимальная скорость, при которой суммарные затраты минимальны:

{{< formula display="true" >}}
V_\text{опт} \approx 1{,}5\sqrt{\frac{c_\text{э}\,C_\text{нас}}{C_\text{труб}}}
{{< /formula >}}

Для типичных российских условий V_опт = 1,5–2,5 м/с для крупных магистралей системы охлаждённой воды.

## Шум и эрозия: ограничения по скорости

Верхние ограничения по скорости связаны с:

- **Шумом:** скорость > 3 м/с вызывает заметный гидравлический шум в трубах; норматив — V ≤ 3 м/с для жилых помещений (СП 60).
- **Эрозией:** при высоких скоростях и низком pH корреляция коррозии-эрозии меди становится критичной; EN 12056-2 ограничивает скорость в медных трубах до 3 м/с при pH < 7.
- **Кавитационной эрозией:** в зонах местных сопротивлений (обратные клапаны, быстрозакрывающаяся арматура) ограничивают скорость перед клапаном.
