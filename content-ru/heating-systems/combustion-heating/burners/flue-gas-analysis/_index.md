Анализ дымовых газов измеряет продукты сгорания (O₂, CO₂, CO, NOx) и температуру дымохода для оценки термического КПД, диагностики неисправностей горелки и подтверждения соответствия нормативам выбросов. Комплексный анализ позволяет рассчитать КПД методом потерь в дымоходе (flue loss method, типичные результаты 80–92 %), оптимизировать соотношение воздух-топливо по целевым значениям O₂ (2–4 %), выявить неполное сгорание через CO (целевой уровень < 50 ppm) и отслеживать производительность для обнаружения загрязнения или нарушения настройки. Нормативная база: ASHRAE Standard 103, EN 303, СП 60.13330.

## Измеряемые параметры

### Температура дымохода

**Место отбора пробы:** ниже по ходу от теплообменника, не менее 8 диаметров воздуховода от выхода, по центральной линии дымохода, выше точки росы (> 120 °C для газа, > 150 °C для масла).

**Чистая температура дымохода** (релевантная для расчёта КПД):

{{< formula display="true" >}}
\Delta T_{\text{дымоход}} = T_{\text{дымоход}} - T_{\text{воздух}}
{{< /formula >}}

{{< table title="Типичные температуры дымохода по типам систем" >}}
| Тип системы | Температура дымохода, °C | Чистое превышение, °C |
|---|---|---|
| Конденсационный котёл (condensing) | 38–71 | 22–56 |
| Высокоэффективный котёл | 121–177 | 100–156 |
| Стандартный котёл | 177–260 | 156–232 |
| Промышленный нагреватель | 232–427 | 210–410 |
| Неудовлетворительная работа | > 316 | > 278 |
{{< /table >}}

**Приборы измерения температуры:**
- Термопара типа K: диапазон 0–1 100 °C, точность ±0,75 % или ±1 °C, время отклика 1–5 с — наиболее распространена для анализа горения.
- RTD (resistance temperature detector): точность ±0,3 °C, медленный отклик, лучшая долгосрочная стабильность.

### Кислород (O₂)

**Датчик диоксида циркония (zirconia O₂ sensor):** рабочая температура 315–815 °C; быстрый отклик 5–15 с; точность ±0,1–0,3 %; широко применяется для управления горением в замкнутом контуре.

**Электрохимический датчик:** рабочая температура 150–315 °C; отклик 10–30 с; точность ±0,2–0,5 %; типичен для портативных анализаторов.

Большинство анализаторов измеряют O₂ на **сухой основе** (dry basis — водяной пар удалён перед измерением).

**Интерпретация O₂:**
- 0–1,5 %: недостаточный воздух, высокий риск CO.
- 1,5–4,0 %: оптимальный диапазон для большинства горелок.
- 4–7 %: допустимо, но КПД снижен.
- > 7 %: избыточный воздух, значительные потери в дымоходе.

Расчёт избыточного воздуха по O₂:

{{< formula display="true" >}}
EA\,\% = \frac{O_2}{21 - O_2} \times 100
{{< /formula >}}

### Диоксид углерода (CO₂)

Стехиометрический CO₂ природного газа — 11,8 % (сухой базис). Фактический CO₂:

{{< formula display="true" >}}
CO_2\,\% = \frac{CO_{2,\max}}{1 + EA}
{{< /formula >}}

Ориентировочная связь O₂ и CO₂ для природного газа:

{{< formula display="true" >}}
O_2 + 0{,}5 \times CO_2 \approx 10{,}5\,\%
{{< /formula >}}

### Монооксид углерода (CO)

**Принцип измерения:**
- Электрохимический датчик: окисление CO на электроде; линейный отклик 0–2 000 ppm; точность ±5 % от показания или ±10 ppm; время отклика 30–60 с.
- NDIR (недисперсионный инфракрасный): поглощение на 4,6 мкм; точность ±1 %; применяется в лабораториях и CEMS.

**CO без воздуха (CO air-free)** — нормализованный показатель:

{{< formula display="true" >}}
CO_{\text{без воздуха}} = CO_{\text{измеренный}} \times \frac{21}{21 - O_2}
{{< /formula >}}

**Приемлемые уровни CO:**
- < 50 ppm: отличное горение.
- 50–100 ppm: допустимо для большинства применений.
- 100–400 ppm: требуется регулировка.
- > 400 ppm: аварийная ситуация — немедленная коррекция.

### Оксиды азота (NOx)

**Методы измерения:**
- Хемилюминесцентный анализатор (chemiluminescence): NO реагирует с озоном; высокая точность; применяется в CEMS; требует калибровочных газов.
- Электрохимический датчик: достаточен для полевых проверок; меньшая точность.

**Нормирование NOx на стандартный O₂:**

Нормативы, как правило, задают NOx при 3 % O₂:

{{< formula display="true" >}}
NOx_{@3\,\%\,O_2} = NOx_{\text{изм}} \times \frac{18}{21 - O_{2,\text{изм}}}
{{< /formula >}}

**Пример.** NOx измеренный 45 ppm при $O_2 = 5\,\%$:

{{< formula display="true" >}}
NOx_{@3\,\%\,O_2} = 45 \times \frac{18}{16} = 50{,}6\;\text{ppm}
{{< /formula >}}

## Расчёт КПД горения

### Метод потерь в дымоходе

{{< formula display="true" >}}
\eta = 100\,\% - L_{\text{дымоход}} - L_{\text{излучение}} - L_{\text{неполное}}
{{< /formula >}}

**Потеря через дымоход (flue gas loss)** — доминирующий вклад:

Через CO₂ (формула Зигерта):

{{< formula display="true" >}}
L_{\text{дымоход}} = K \times \frac{T_{\text{дымоход}} - T_{\text{воздух}}}{CO_2\,\%}
{{< /formula >}}

$K = 0{,}65$ для природного газа; $K = 0{,}54$ для дизельного № 2; $K = 0{,}63$ для пропана.

**Потеря неполного сгорания:**

{{< formula display="true" >}}
L_{\text{неполное}} \approx 10{,}2 \times \frac{CO_{\text{ppm}}}{CO_2\,\%}
{{< /formula >}}

**Потеря излучением и конвекцией:**
- малые жилые котлы (< 12 кВт): 2–4 %;
- коммерческие (3,5–35 кВт): 0,5–2 %;
- крупные промышленные (> 35 кВт): 0,2–1 %.

### Пример расчёта

Газовая горелка котла 2,5 МВт:

- $T_{\text{дымоход}} = 232\,°C$; $T_{\text{воздух}} = 21\,°C$.
- CO₂ = 9,0 %; CO = 60 ppm; потеря излучением 0,6 %.

{{< formula display="true" >}}
L_{\text{дымоход}} = 0{,}65 \times \frac{232 - 21}{9{,}0} = 15{,}2\,\%
{{< /formula >}}

{{< formula display="true" >}}
L_{\text{неполное}} = 10{,}2 \times \frac{60}{9{,}0} = 0{,}07\,\%
{{< /formula >}}

{{< formula display="true" >}}
\eta = 100 - 15{,}2 - 0{,}6 - 0{,}07 = 84{,}1\,\%
{{< /formula >}}

### Оптимизация по O₂

Компромисс между потерями в дымоходе и неполным сгоранием:

- Ниже O₂ → меньше потерь в дымоходе → выше КПД.
- Слишком низкий O₂ → CO растёт → потеря неполного сгорания увеличивается.

**Типичный оптимальный O₂:**
- природный газ: 2,5–3,5 %;
- дизельное № 2: 3,0–4,0 %;
- мазут № 6: 3,5–5,0 %.

**Чувствительность КПД:** ~1 % изменения КПД на каждые 22 °C изменения $T_{\text{дымоход}}$ или на каждый 1 % O₂ при типичных температурах 177–232 °C.

## Портативные анализаторы горения

### Состав типового анализатора

1. **Зонд отбора пробы** — нержавеющая сталь; встроенная термопара; спеченный металлический фильтр; длина 30–120 см.
2. **Кондиционирование пробы** — ловушка воды; фильтр частиц; насос пробы.
3. **Датчики** — O₂ (электрохимический), CO (электрохимический), NO/NO₂ (опция), температура (термопара K).
4. **Дисплей и процессор** — расчёт КПД в реальном времени; регистрация данных; вывод на принтер.

### Процедура измерения

1. Убедиться, что горелка работает в установившемся режиме (не менее 15–30 мин).
2. Проверить калибровку: O₂ на свежем воздухе должен показывать 20,9 %.
3. Ввести зонд по центральной линии дымохода.
4. Дождаться стабилизации показаний (60–120 с).
5. Зафиксировать: $T_{\text{дымоход}}$, $T_{\text{воздух}}$, O₂, CO, CO₂.
6. Рассчитать: чистое превышение температуры, EA, КПД.
7. Задокументировать: дата, время, мощность, тип топлива.

Для крупных дымоходов — не менее 3 точек (центр, 25 % и 75 % от диаметра); усреднить показания.

### Диагностическая интерпретация

{{< table title="Диагностика по показаниям анализатора горения" >}}
| Показание | Возможная причина | Корректирующее действие |
|---|---|---|
| O₂ > 5 % | Избыток воздуха; подсос воздуха в печи | Прикрыть воздушный дроссель; проверить герметичность |
| O₂ < 1,5 % | Недостаток воздуха; загрязнение дросселя | Увеличить воздух; проверить вентилятор |
| CO > 100 ppm | Плохое смешение; загрязнение теплообменника | Увеличить воздух; очистить теплообменник; проверить горелку |
| $T_{\text{дымоход}} > 260\,°C$ (газ) | Загрязнение теплообменника; завышенная мощность | Очистить теплообменник; проверить размер |
| $T_{\text{дымоход}} < 120\,°C$ (газ) | Избыток воздуха (разбавление); риск конденсации | Проверить EA; при необходимости снизить |
{{< /table >}}

## Системы непрерывного мониторинга выбросов (CEMS)

### Состав системы

1. **Система отбора пробы** — нагреваемая линия (120–170 °C) для предотвращения конденсации; зонд с фильтром; насос; компенсация давления.
2. **Кондиционирование газа** — охлаждающий конденсатор; фильтр частиц; расходомер.
3. **Газовые анализаторы:**
   - O₂: циркониевый или парамагнитный.
   - CO: NDIR.
   - NOx: хемилюминесцентный.
   - SO₂: NDIR (при необходимости).
4. **Система сбора данных (DAS)** — регистрация всех параметров; расчёт нагрузки выбросов; хранение данных (5 лет по нормативу); формирование отчётов.

### Обеспечение качества данных

**Ежедневная проверка нуля и верхнего предела (zero/span check):**
- Критерии приемлемости: дрейф < 5 % от диапазона.

**Проверка линейности** — ежеквартально; 3–5 калибровочных газов по диапазону.

**Аудит относительной точности (RATA, relative accuracy test audit):**

{{< formula display="true" >}}
RA = \frac{|\overline{CEMS} - \overline{\text{Референс}}|}{\overline{\text{Референс}}} \times 100\,\%
{{< /formula >}}

Норматив: $RA < 10\,\%$ (типичный предел; варьируется по загрязнителю и юрисдикции).

## Процедура регулировки горелки

### Оптимизация соотношения воздух-топливо на месте

1. Зафиксировать базовые значения O₂, CO, $T_{\text{дымоход}}$, КПД при текущих настройках.
2. Прикрыть воздушный дроссель на 5–10 %; ждать 2–3 мин стабилизации.
3. Фиксировать новые значения; повторять небольшими шагами.
4. Найти минимум O₂ при CO < 100 ppm — точка максимального КПД.
5. Проверить соотношение на низкой, средней и высокой мощности (модулирующие горелки).
6. При наличии O₂-триммера: активировать управление; задать целевой O₂; проверить стабильность ±0,3 %.
7. Зафиксировать финальные настройки в журнале технического обслуживания.

### Периодичность анализа горения

{{< table title="Рекомендуемая периодичность анализа горения" >}}
| Тип оборудования | Периодичность |
|---|---|
| Жилые котлы | 1 раз в год |
| Коммерческие котлы и печи | 1 раз в год (+ после каждого ТО) |
| Промышленные горелки > 300 кВт | 2 раза в год |
| Критическое оборудование | Ежеквартально |
| После капитального ремонта горелки | Обязательно |
{{< /table >}}

**Критерии приёмки:**
- КПД ≥ 80 % (стандартный котёл); ≥ 90 % (конденсационный).
- CO < 100 ppm (предпочтительно < 50 ppm).
- O₂ в диапазоне 2–5 % в зависимости от типа горелки и топлива.
- $T_{\text{дымоход}}$ соответствует типу оборудования.

**Замечание по безопасности.** Никогда не регулировать горелку для достижения O₂ < 1,5 % или CO > 100 ppm ради повышения КПД. Полное сгорание и безопасность — абсолютный приоритет над экономией энергии.
