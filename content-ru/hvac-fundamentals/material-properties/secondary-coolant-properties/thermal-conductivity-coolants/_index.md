## Физический смысл теплопроводности

Теплопроводность $\lambda$ (thermal conductivity) — транспортное свойство, определяющее скорость кондуктивного переноса тепла через объём жидкости. Закон Фурье для плоской геометрии:

{{< formula display="true" >}}
q = -\lambda A \frac{dT}{dx}
{{< /formula >}}

где $q$ — тепловой поток, Вт; $A$ — площадь сечения, м²; $dT/dx$ — температурный градиент, К/м.

В конвективных системах $\lambda$ входит в число Нуссельта и число Прандтля, определяя коэффициент конвективного теплообмена. Снижение $\lambda$ при добавлении антифриза — главная причина ухудшения теплоотдачи в гликолевых системах.

В жидких хладоносителях тепло переносится молекулярной трансляцией и колебательными модами полиатомных молекул. Сети водородных связей воды обеспечивают её аномально высокую теплопроводность ($\lambda = 0{,}598\ \text{Вт/(м·°C)}$ при 20 °C); гликоли с разветвлёнными молекулами нарушают эту сеть, снижая $\lambda$.

## Зависимость теплопроводности от температуры и концентрации

Температурная зависимость для большинства хладоносителей описывается линейным приближением:

{{< formula display="true" >}}
\lambda(T) = \lambda_0 \left[1 + \alpha (T - T_0)\right]
{{< /formula >}}

Для гликолевых растворов $\alpha \approx 0{,}001{-}0{,}003\ \text{°C}^{-1}$ — рост $\lambda$ с температурой около 0,1–0,3 % на °C. В рабочем диапазоне −40…+20 °C $\lambda$ изменяется на 6–18 %.

Концентрационная зависимость значительно сильнее: на 20–40 % у гликолей при типичных ОВиК-концентрациях.

## Влияние на число Прандтля и коэффициент теплоотдачи

### Число Прандтля

{{< formula display="true" >}}
Pr = \frac{c_p \mu}{\lambda}
{{< /formula >}}

Рост $\mu$ и снижение $\lambda$ с концентрацией гликоля резко увеличивают $Pr$:

{{< table title="Число Прандтля при 0 °C (ASHRAE Handbook Fundamentals Ch. 31)" >}}
| Жидкость | $Pr$ | Относит. от воды |
|:---------|-----:|:----------------:|
| Вода | 13 | 1,0 |
| 30 % EG | 32 | 2,5 |
| 40 % EG | 50 | 3,8 |
| 30 % PG | 45 | 3,5 |
| 40 % PG | 85 | 6,5 |
| 20 % NaCl | 21 | 1,6 |
{{< /table >}}

### Коэффициент конвективного теплообмена

По корреляции Дитуса–Бёлтера для турбулентного течения ($Re > 10\,000$):

{{< formula display="true" >}}
Nu = 0{,}023\,Re^{0{,}8}\,Pr^{0{,}4}
{{< /formula >}}

{{< formula display="true" >}}
h = \frac{Nu \cdot \lambda}{d}
{{< /formula >}}

Теплопроводность входит как в $Pr$, так и непосредственно в $h$, создавая составной эффект. При снижении $\lambda$ на 25 % и увеличении $Pr$ в 3,5 раза (например, 30 % PG при 0 °C):

{{< formula display="true" >}}
\frac{h_{\text{PG}}}{h_{\text{вода}}} = \frac{\lambda_{\text{PG}}}{\lambda_{\text{вода}}} \cdot \left(\frac{Pr_{\text{PG}}}{Pr_{\text{вода}}}\right)^{0{,}4}
{{< /formula >}}

Числа: $\frac{0{,}435}{0{,}571} \times (45/13)^{0{,}4} = 0{,}762 \times 1{,}62 \approx 1{,}23$ — парадокс: $h$ выше из-за роста $Pr$? Нет, потому что $Re$ для PG при том же расходе ниже из-за высокой $\mu$. С учётом фактического $Re$:

{{< formula display="true" >}}
\frac{h_{\text{PG}}}{h_{\text{вода}}} = \frac{\lambda_{\text{PG}}}{\lambda_{\text{вода}}} \cdot \left(\frac{Re_{\text{PG}}}{Re_{\text{вода}}}\right)^{0{,}8} \cdot \left(\frac{Pr_{\text{PG}}}{Pr_{\text{вода}}}\right)^{0{,}4}
{{< /formula >}}

При том же объёмном расходе $Re_{\text{PG}} / Re_{\text{вода}} = \mu_{\text{вода}} / \mu_{\text{PG}}$. Для 30 % PG при 0 °C: $\mu_{\text{PG}}/\mu_{\text{вода}} = 5{,}8/1{,}79 = 3{,}24$, поэтому $Re_{\text{PG}}/Re_{\text{вода}} = 0{,}308$:

{{< formula display="true" >}}
\frac{h_{\text{PG}}}{h_{\text{вода}}} \approx 0{,}762 \times 0{,}308^{0{,}8} \times 3{,}46^{0{,}4} \approx 0{,}762 \times 0{,}378 \times 1{,}62 \approx 0{,}47
{{< /formula >}}

Коэффициент теплоотдачи при 0 °C снижается до ~47 % от водяного при том же объёмном расходе. Для компенсации необходимо либо увеличивать расход, либо площадь поверхности теплообменника.

**При ламинарном течении** ($Re < 2\,300$): $Nu = 3{,}66$ (постоянная $T_w$) или $Nu = 4{,}36$ (постоянный $q$) — числа Рейнольдса и Прандтля не влияют; $h = Nu \cdot \lambda / d$ снижается прямо пропорционально $\lambda$.

## Коэффициент теплопередачи теплообменника

Общий коэффициент теплопередачи $U$ описывается моделью последовательных сопротивлений:

{{< formula display="true" >}}
\frac{1}{U} = \frac{1}{h_i} + \frac{\delta_{\text{ст}}}{\lambda_{\text{ст}}} + \frac{1}{h_o} + R_{\text{загр}}
{{< /formula >}}

{{< table title="Типичные коэффициенты теплопередачи U, Вт/(м²·°C) (ASHRAE Handbook Fundamentals Ch. 30)" >}}
| Тип теплообменника | Вода | 40 % гликоль | Снижение U |
|:-------------------|:----:|:------------:|:----------:|
| Пластинчатый (жидкость–жидкость) | 3 000–4 500 | 1 800–2 800 | 35–40 % |
| Кожухотрубный (жидкость–жидкость) | 850–1 400 | 550–900 | 30–35 % |
| Затопленный испаритель | 1 700–2 800 | 1 100–1 800 | 30–35 % |
| Воздухоохладитель (оребрённая труба) | 60–120 | 45–90 | 20–30 % |
{{< /table >}}

Снижение $U$ меньше снижения $\lambda$, так как при наличии газовой фазы (воздух, хладагент) доминирующее термическое сопротивление — на стороне газа или хладагента, а не жидкого хладоносителя.

## Численный пример: подбор площади теплообменника при замене воды на 40 % PG

**Условие.** Пластинчатый теплообменник (кожухотрубный, жидкость–жидкость). При работе с водой: $Q = 300\ \text{кВт}$, $U_{\text{вода}} = 1\,200\ \text{Вт/(м²·°C)}$, LMTD = 4,5 °C. Площадь поверхности:

{{< formula display="true" >}}
A_{\text{вода}} = \frac{Q}{U \cdot \text{LMTD}} = \frac{300\,000}{1200 \times 4{,}5} = 55{,}6\ \text{м}^2
{{< /formula >}}

**При переходе на 40 % PG при −5 °C:** оценим $U_{\text{PG}}$.

Из таблицы: снижение $U$ для кожухотрубного теплообменника при 40 % гликоле — 30–35 %. Принимаем снижение 32 %:

{{< formula display="true" >}}
U_{\text{PG}} = 1\,200 \times (1 - 0{,}32) = 816\ \text{Вт/(м}^2\text{·°C)}
{{< /formula >}}

Из-за снижения $c_p$ при 40 % PG расход увеличивается на ~12 %, что незначительно меняет LMTD. Принимаем LMTD = 4,3 °C (немного меньше из-за изменённых температурных профилей):

{{< formula display="true" >}}
A_{\text{PG}} = \frac{300\,000}{816 \times 4{,}3} = 85{,}5\ \text{м}^2
{{< /formula >}}

Площадь поверхности необходимо увеличить на $(85{,}5 - 55{,}6) / 55{,}6 = +54\ \%$. Это типичный результат для замены воды на 40 % PG в кожухотрубном теплообменнике при рабочей температуре около −5 °C.

**Вывод:** при выборе оборудования для гликольных систем следует использовать данные производителя с поправочными коэффициентами для конкретного хладоносителя, а не просто умножать водяные характеристики.

## Корреляции для расчёта

### Уравнение Дитуса–Бёлтера (Dittus–Boelter)

{{< formula display="true" >}}
Nu = 0{,}023\,Re^{0{,}8}\,Pr^{0{,}4}\quad (Re > 10\,000,\; 0{,}7 < Pr < 160)
{{< /formula >}}

### Уравнение Гнелинского (Gnielinski) — более точное

{{< formula display="true" >}}
Nu = \frac{(f/8)(Re - 1000)\,Pr}{1 + 12{,}7\sqrt{f/8}\,(Pr^{2/3} - 1)}\quad (3\,000 < Re < 5 \times 10^6)
{{< /formula >}}

где $f = (0{,}790\ln Re - 1{,}64)^{-2}$ — коэффициент гидравлического трения Пекле.

### Ламинарный режим

{{< formula display="true" >}}
Nu = 3{,}66\ \text{(постоянная } T_w\text{)};\quad Nu = 4{,}36\ \text{(постоянный } q\text{)}
{{< /formula >}}

В ламинарном режиме $h = Nu \cdot \lambda / d$ — снижается строго пропорционально $\lambda$; числа Re и Pr не влияют на $Nu$.

## Практические последствия для проектирования

**Выбор типа теплообменника.** Пластинчатые теплообменники создают высокую турбулентность при малых гидравлических диаметрах — это частично компенсирует рост $Pr$ и менее чувствительны к деградации $\lambda$ по сравнению с кожухотрубными.

**Скорость в трубках.** Для поддержания турбулентного режима при высоковязких растворах (40–50 % PG при низких температурах) следует проверять $Re$ при минимальной рабочей температуре и при необходимости увеличивать скорость или уменьшать диаметр труб.

**Расчёт LMTD.** При больших расходах гликоля (из-за малой $c_p$) разница входных/выходных температур со стороны хладоносителя уменьшается — LMTD может оказаться ниже, чем в водяном варианте, что дополнительно увеличивает потребную площадь.

## Ключевые выводы

1. Теплопроводность гликолевых растворов при рабочих концентрациях 30–40 % ниже водяной на 20–35 %; хлоридные рассолы снижают $\lambda$ лишь на 10–20 %.
2. Рост $Pr$ и снижение $Re$ из-за высокой вязкости совместно уменьшают коэффициент теплоотдачи до 40–55 % от водяного — при том же объёмном расходе и −5…0 °C рабочей температуре.
3. Площадь поверхности теплообменника при переходе на 40 % PG при температурах около 0 °C необходимо увеличить на 40–60 % по сравнению с водяным вариантом.
4. Корреляция Гнелинского точнее Дитуса–Бёлтера при $3\,000 < Re < 10\,000$ — переходная зона, характерная для гликолевых систем при низких температурах.
