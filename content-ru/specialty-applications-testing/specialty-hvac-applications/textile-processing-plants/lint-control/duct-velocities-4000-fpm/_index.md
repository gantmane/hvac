## Требования к минимальной скорости транспортировки

Частицы текстильного ворса требуют минимальной скорости в воздуховодах для предотвращения осаждения и накопления в вытяжных системах. Пороговое значение 20,3 м/с (4000 фут/мин) представляет собой общепринятый в отрасли минимум скорости транспортировки для воздушных потоков, содержащих ворс, в текстильных производственных помещениях.

### Определение критической скорости

Скорость транспортировки должна преодолевать силы гравитационного осаждения, действующие на частицы ворса. Минимальная скорость зависит от характеристик частиц:

**Зависимость скорости осаждения:**

$$V_{transport} = \frac{V_{settling}}{\sin(\theta)} \times SF$$

Где:
- $V_{transport}$ = Минимальная скорость транспортировки в воздуховоде (м/с)
- $V_{settling}$ = Конечная скорость осаждения частицы (м/с)
- $\theta$ = Угол воздуховода относительно горизонтали (градусы)
- $SF$ = Коэффициент запаса (обычно 1,5–2,0)

## Принципы поддержания скорости

### Учет потерь давления

Более высокие скорости приводят к экспоненциальному увеличению потерь давления в системе. Потери на трение регулируются уравнением Дарси-Вейсбаха:

$$\Delta P = f \times \frac{L}{D} \times \frac{\rho V^2}{2 \times 144}$$

Где:
- $\Delta P$ = Потеря давления (дюймы вод. ст.)
- $f$ = Коэффициент трения (безразмерный)
- $L$ = Длина воздуховода (футы)
- $D$ = Диаметр воздуховода (футы)
- $\rho$ = Плотность воздуха (фунт/фут³)
- $V$ = Скорость воздуха (фут/мин)

**Ключевая зависимость:** Удвоение скорости увеличивает потерю давления в четыре раза.

### Анализ энергопотребления

Требуемая мощность вентилятора масштабируется пропорционально кубу скорости:

$$HP = \frac{Q \times \Delta P}{6356 \times \eta_{fan}}$$

Где:
- $HP$ = Мощность на валу вентилятора (л.с.)
- $Q$ = Расход воздуха (CFM (м³/ч))
- $\Delta P$ = Общее давление в системе (дюймы вод. ст.)
- $\eta_{fan}$ = Общий КПД вентилятора (доля)

### Расчеты размеров

**Требуемая площадь воздуховода:**

$$A = \frac{Q}{V}$$

Где:
- $A$ = Поперечное сечение (м²)
- $Q$ = Расход воздуха (CFM (м³/ч))
- $V$ = Расчетная скорость (м/с)

**Диаметр круглого воздуховода:**

$$D = \sqrt{\frac{4A}{\pi}} = \sqrt{\frac{4Q}{\pi V}}$$

**Размеры прямоугольного воздуховода:**

Для соотношения сторон $AR = \frac{W}{H}$:

$$W = \sqrt{A \times AR}$$

$$H = \frac{A}{W}$$

**Правила проектирования:**
- Никогда не уменьшайте скорость по направлению движения воздушного потока
- Увеличивайте скорость на 5–10% на каждом ответвлении
- Поддерживайте минимальную скорость 20,3 м/с (4000 фут/мин) по всей системе
- Проектируйте вход коллектора с минимальной скоростью 22,9 м/с (4500 фут/мин)

### Предотвращение осаждения ворса

Критические факторы, предотвращающие накопление ворса:

1. **Ограничения горизонтальных участков:** Минимизировать длину горизонтальных воздуховодов. Предпочтительны вертикальные или наклонные секции.

2. **Конструкция колен:** Использовать колена с большим радиусом (R/D ≥ 2.0) для предотвращения осаждения при изменении направления.

3. **Мониторинг скорости:** Установить датчики скорости в критических точках для подтверждения проектных условий.

4. **Доступ для очистки:** Предусмотреть люки для очистки каждые 6 метров горизонтального участка и во всех низких точках.
