## Введение и инженерная значимость

Тепловой комфорт — это состояние, при котором человек субъективно удовлетворён тепловыми условиями окружающей среды (ASHRAE 55-2023, раздел 3.1). Дискомфорт снижает работоспособность на 5–15% (исследования Fanger и Wyon, 1973–2006) и является основным источником жалоб жильцов в коммерческих зданиях.

Физика теплообмена тела с окружающей средой определяет шесть параметров теплового комфорта:

**Параметры среды:**
1. Температура воздуха $t_a$ (°C)
2. Средняя радиационная температура $\bar{t}_r$ (°C)
3. Скорость воздуха $v_a$ (м/с)
4. Парциальное давление водяного пара $p_a$ (Па)

**Личные параметры:**
5. Уровень метаболической активности $M$ (Вт/м², ед. met)
6. Тепловое сопротивление одежды $I_{cl}$ (м²·К/Вт, ед. clo)

## Физиология теплообмена тела

Тело человека — это биологический теплоисточник с постоянной скоростью метаболизма. Терморегуляция поддерживает температуру ядра 36,5–37,5°C за счёт управления теплоотдачей через кожу.

### Уравнение теплового баланса тела

Нулевое накопление тепла в организме соответствует тепловому нейтралитету:

{{< formula display="true" >}}
M - W = Q_{sk} + Q_{res} + S
{{< /formula >}}

Где:
- $M$ = скорость метаболизма (Вт/м² поверхности тела)
- $W$ = полезная механическая работа (Вт/м²); для большинства офисных условий $W \approx 0$
- $Q_{sk}$ = суммарная теплоотдача через кожу (Вт/м²)
- $Q_{res}$ = суммарная теплоотдача при дыхании (Вт/м²)
- $S$ = скорость накопления тепла в теле (Вт/м²); при комфорте $S = 0$

Раскрывая компоненты теплоотдачи через кожу:

{{< formula display="true" >}}
Q_{sk} = Q_{c} + Q_{r} + Q_{e,sk}
{{< /formula >}}

{{< formula display="true" >}}
Q_{c} = f_{cl} h_c (t_{cl} - t_a)
{{< /formula >}}

{{< formula display="true" >}}
Q_{r} = f_{cl} h_r \left[(t_{cl} + 273)^4 - (\bar{t}_r + 273)^4\right] \cdot \varepsilon_r
{{< /formula >}}

{{< formula display="true" >}}
Q_{e,sk} = 3.05 \times 10^{-3}\left[5733 - 6.99(M - W) - p_a\right] + 0.42\left[(M - W) - 58.15\right]
{{< /formula >}}

Где:
- $h_c$ = конвективный коэффициент теплоотдачи, Вт/(м²·К); при $v_a < 0.2$ м/с: $h_c = 2.38|t_{cl} - t_a|^{0.25}$; при принудительной конвекции: $h_c = 12.1\sqrt{v_a}$
- $h_r$ = радиационный линеаризованный коэффициент, Вт/(м²·К): $h_r \approx 4\varepsilon \sigma (T_m)^3 \approx 4.7$ Вт/(м²·К) при $T_m \approx 300$ К
- $f_{cl}$ = коэффициент поверхности одежды (безразмерный)
- $\varepsilon_r$ = степень черноты одежды (обычно 0.95 для типичной одежды)
- $p_a$ = парциальное давление водяного пара в воздухе, Па

### Теплоотдача при дыхании

Чувствительная и скрытая составляющие:

{{< formula display="true" >}}
Q_{res} = Q_{res,s} + Q_{res,l} = 0.0014 M (34 - t_a) + 0.0173 M (5.867 - p_a)
{{< /formula >}}

Где $p_a$ выражено в кПа. При стандартных условиях ($t_a = 22$°C, $\phi = 50$%, $M = 58$ Вт/м²):
- $Q_{res,s} \approx 0.93$ Вт/м²
- $Q_{res,l} \approx 4.3$ Вт/м²

### Температура поверхности одежды

Уравнение температуры поверхности одежды требует итеративного решения (начальное приближение: $t_{cl} = t_a + 5$°C):

{{< formula display="true" >}}
t_{cl} = 35.7 - 0.028(M - W) - I_{cl}\left[3.96 \times 10^{-8} f_{cl}\left[(t_{cl}+273)^4 - (\bar{t}_r+273)^4\right] + f_{cl} h_c (t_{cl} - t_a)\right]
{{< /formula >}}

Коэффициент поверхности одежды:

{{< formula display="true" >}}
f_{cl} = \begin{cases}
1.00 + 1.290\, I_{cl} & \text{если } I_{cl} \le 0.078 \text{ м}^2\text{К/Вт} \\
1.05 + 0.645\, I_{cl} & \text{если } I_{cl} > 0.078 \text{ м}^2\text{К/Вт}
\end{cases}
{{< /formula >}}

Конверсия единиц: 1 clo = 0.155 м²·К/Вт.

## Модель PMV по Фангеру

### Происхождение и обоснование

Прогнозируемое среднее голосование (Predicted Mean Vote, PMV) разработано P.O. Fanger (Технический университет Дании, 1970) на основе экспериментов с более чем 1300 испытуемыми в климатических камерах. Модель принята в ASHRAE 55, ISO 7730:2005 и EN 16798-1:2019.

### Уравнение PMV

{{< formula display="true" >}}
PMV = \left[0.303 \exp(-0.036\,M) + 0.028\right] \cdot L
{{< /formula >}}

Тепловая нагрузка на тело $L$ (Вт/м²) — разность между внутренней теплопродукцией и теплоотдачей при нейтральных условиях:

{{< formula display="true" >}}
\begin{aligned}
L = &(M - W) \\
&- 3.05 \times 10^{-3}\left[5733 - 6.99(M-W) - p_a\right] \\
&- 0.42\left[(M-W) - 58.15\right] \\
&- 1.7 \times 10^{-5} M (5867 - p_a) \\
&- 0.0014 M (34 - t_a) \\
&- 3.96 \times 10^{-8} f_{cl}\left[(t_{cl}+273)^4 - (\bar{t}_r+273)^4\right] \\
&- f_{cl} h_c (t_{cl} - t_a)
\end{aligned}
{{< /formula >}}

Физический смысл: при $L = 0$ тело в тепловом равновесии при нейтральных условиях; $PMV = 0$.

## Модель PPD

Прогнозируемая доля неудовлетворённых (Predicted Percentage of Dissatisfied, PPD) — вероятность теплового дискомфорта в группе людей:

{{< formula display="true" >}}
PPD = 100 - 95\exp\!\left(-0.03353\, PMV^4 - 0.2179\, PMV^2\right)
{{< /formula >}}

**Ключевые выводы:**
- При $PMV = 0$: $PPD_{min} = 5\%$ — минимально достижимый уровень неудовлетворённости вследствие индивидуальных физиологических различий
- При $|PMV| = 0.5$: $PPD \approx 10\%$ — граница категории A по ISO 7730
- При $|PMV| = 0.7$: $PPD \approx 15\%$ — граница категории B по ISO 7730

### Категории комфорта по ISO 7730:2005 и EN 16798-1:2019

{{< table title="Категории тепловой среды ISO 7730 / EN 16798-1" >}}
| Категория | PMV | PPD | Применение |
|---|---|---|---|
| I (высокий) | -0.2 < PMV < +0.2 | < 6% | Больницы, ясли |
| II (нормальный) | -0.5 < PMV < +0.5 | < 10% | Офисы, жильё (рекомендуется) |
| III (умеренный) | -0.7 < PMV < +0.7 | < 15% | Промышленные здания |
| IV (допустимый) | PMV < -0.7 или > +0.7 | > 15% | Только временное пребывание |
{{< /table >}}

ASHRAE 55-2023 (раздел 5.3.3) устанавливает: $-0.5 \le PMV \le +0.5$ для 90% приемлемости (PPD < 10%).

## Входные параметры расчёта PMV/PPD

### Скорость метаболизма

Площадь поверхности тела по уравнению DuBois:

{{< formula display="true" >}}
A_D = 0.202\, m^{0.425}\, h^{0.725}
{{< /formula >}}

Где $m$ — масса тела (кг), $h$ — рост (м). Для среднего мужчины ($m = 75$ кг, $h = 1.75$ м): $A_D = 1.92$ м².

{{< table title="Нормируемые скорости метаболизма (ASHRAE 55, Приложение B; ISO 8996:2021)" >}}
| Деятельность | met | Вт/м² |
|---|:---:|:---:|
| Сон | 0.7 | 41 |
| Отдых лёжа | 0.8 | 46 |
| Сидя, спокойно | 1.0 | 58 |
| Стоя, расслабленно | 1.2 | 70 |
| Офисная работа (ввод данных) | 1.2 | 70 |
| Ходьба 2 км/ч | 1.7 | 99 |
| Ходьба 4 км/ч | 2.5 | 145 |
| Лёгкий физический труд | 3.0 | 175 |
| Тяжёлая физическая работа | 4.0–7.0 | 232–407 |
{{< /table >}}

Для смешанных видов деятельности применяется средневзвешенное значение за рабочую смену.

### Тепловое сопротивление одежды

{{< table title="Тепловое сопротивление комплектов одежды (ASHRAE 55, Приложение B; ISO 9920:2007)" >}}

{{< /table >}}

Ансамблевое значение можно рассчитать суммированием по элементам одежды (ISO 9920:2007, Приложение A).

## Операционная температура

Операционная температура $t_o$ объединяет влияние температуры воздуха и радиации:

{{< formula display="true" >}}
t_o = \frac{h_r \bar{t}_r + h_c t_a}{h_r + h_c}
{{< /formula >}}

При низких скоростях воздуха ($v_a < 0.2$ м/с, $h_r \approx h_c$):

{{< formula display="true" >}}
t_o \approx \frac{\bar{t}_r + t_a}{2}
{{< /formula >}}

При $v_a = 0.1–0.2$ м/с и стандартных интерьерных условиях погрешность этого приближения не превышает ±0.5°C.

Зоны комфорта ASHRAE 55-2023 (рис. 5.3.1) определены именно в осях операционной температуры и влажности:

{{< table title="Зоны операционной температуры ASHRAE 55-2023 (1.0 met, скорость воздуха < 0.2 м/с)" >}}
| Сезон | Одежда (clo) | $t_o$ мин. (°C) | $t_o$ макс. (°C) |
|---|:---:|:---:|:---:|
| Зима | 1.0 | 20.0 | 23.5 |
| Лето | 0.5 | 23.0 | 26.0 |
{{< /table >}}

По СП 60.13330.2020 (таблица 1) оптимальные параметры микроклимата в жилых и общественных зданиях:
- Тёплый период: $t_a = 22$–$25$°C, $\phi = 30$–$60$%
- Холодный период: $t_a = 20$–$22$°C, $\phi = 30$–$45$%

## Локальный тепловой дискомфорт

### Модель сквозняка (Draught Rating)

Процент людей, испытывающих дискомфорт от сквозняка (ASHRAE 55, EN 16798-1, ISO 7730 раздел 6.3):

{{< formula display="true" >}}
DR = (34 - t_a)(v_a - 0.05)^{0.62}(0.37\, v_a\, Tu + 3.14)
{{< /formula >}}

Где:
- $t_a$ = местная температура воздуха (°C); формула действительна при $t_a < 34$°C
- $v_a$ = локальная средняя скорость воздуха (м/с); при $v_a < 0.05$ м/с принять $v_a = 0.05$ м/с
- $Tu$ = интенсивность турбулентности (%): $Tu = \frac{\sigma_v}{v_a} \times 100$

Нормативный предел: $DR \le 15\%$ (ISO 7730:2005 категория B).

**Пример расчёта:** $t_a = 22$°C, $v_a = 0.15$ м/с, $Tu = 40$%:

{{< formula display="true" >}}
DR = (34 - 22)(0.15 - 0.05)^{0.62}(0.37 \times 0.15 \times 40 + 3.14) = 12 \times 0.215 \times 5.36 = 13.8\%
{{< /formula >}}

Результат у границы допустимого — следует увеличить температуру воздуха или снизить скорость подачи.

### Вертикальная разница температур воздуха

Перепад между уровнем лодыжки (0.1 м) и головы (1.1 м для сидящего, 1.7 м для стоящего):

{{< formula display="true" >}}
\Delta t_{vert} = t_{head} - t_{ankle}
{{< /formula >}}

Нормативный предел: $\Delta t_{vert} \le 3$°C (ASHRAE 55-2023, раздел 5.4.4; ISO 7730:2005 категория A).

Типичные причины превышения: напольное отопление с чрезмерной температурой поверхности, конвективные плинтусные обогреватели, недостаточное перемешивание приточного воздуха.

### Температура пола

Допустимый диапазон по ASHRAE 55-2023 (раздел 5.4.5):

{{< formula display="true" >}}
19 \le t_{floor} \le 29 \text{ °C}
{{< /formula >}}

При тёплых полах в жилых зданиях (СП 60.13330.2020, п. 6.5.7): $t_{floor} \le 26$°C в зонах постоянного пребывания; $\le 31$°C на периферийных участках.

### Радиационная асимметрия

Асимметрия лучистого теплового потока $\Delta t_{pr}$ — разность плоских радиационных температур для двух противоположных направлений:

{{< table title="Предельные значения радиационной асимметрии (ISO 7730:2005, таблица 6)" >}}
| Источник асимметрии | Предел $\Delta t_{pr}$ (°C) |
|---|:---:|
| Тёплый потолок | 5 |
| Холодная стена | 10 |
| Тёплая стена | 23 |
| Холодный потолок | 14 |
{{< /table >}}

Расчёт плоской радиационной температуры:

{{< formula display="true" >}}
\bar{t}_{pr,dir} = \sum_{i} F_{p-i}\, t_{surface,i}
{{< /formula >}}

Где $F_{p-i}$ — угловой коэффициент от малой горизонтальной/вертикальной площадки к $i$-й поверхности.

## Адаптивная модель теплового комфорта

### Концепция и область применения

Адаптивная модель признаёт, что в естественно вентилируемых зданиях жители адаптируются к условиям наружного климата и ожидают более широкого диапазона температур. Применяется при (ASHRAE 55-2023, раздел 5.4; EN 16798-1:2019):
- Отсутствии механического охлаждения
- Возможности открывания окон жильцами
- Метаболической активности 1.0–1.3 met

### Уравнение ASHRAE 55 (нейтральная операционная температура)

{{< formula display="true" >}}
t_{comf} = 0.31\, t_{pma(out)} + 17.8
{{< /formula >}}

Где $t_{pma(out)}$ — преобладающее скользящее среднее суточной наружной температуры (°C):

{{< formula display="true" >}}
t_{pma(out)} = \frac{\sum_{i=1}^{n} \alpha^{i-1} t_{od,i}}{\sum_{i=1}^{n} \alpha^{i-1}}
{{< /formula >}}

В ASHRAE 55 применяется упрощённая экспоненциальная форма (коэффициент затухания $\alpha = 0.9$ или 7-дневное скользящее среднее):

{{< formula display="true" >}}
t_{rm} = \frac{t_{od-1} + 0.8\,t_{od-2} + 0.6\,t_{od-3} + 0.5\,t_{od-4} + 0.4\,t_{od-5} + 0.3\,t_{od-6} + 0.2\,t_{od-7}}{3.8}
{{< /formula >}}

### Границы допустимости

ASHRAE 55-2023 (рис. 5.4.1):
- 90% приемлемость: $t_{comf} \pm 2.5$°C
- 80% приемлемость: $t_{comf} \pm 3.5$°C

EN 16798-1:2019 (таблица B.2) добавляет три категории:
- Категория I: $t_{comf} - 2 \le t_o \le t_{comf} + 2$°C
- Категория II: $t_{comf} - 3 \le t_o \le t_{comf} + 3$°C
- Категория III: $t_{comf} - 4 \le t_o \le t_{comf} + 4$°C

### Применимость в климате России и СНГ

Адаптивная модель разработана преимущественно для регионов с мягким климатом. При $t_{rm} < 10$°C модель ASHRAE 55 не применяется (область действия: $10 \le t_{pma(out)} \le 33.5$°C). В холодный период (Москва: $t_{rm} < 0$°C на протяжении 4–5 месяцев) необходимо использовать нормативные параметры СП 60.13330.2020 / ГОСТ 30494-2011.

## Численный пример расчёта PMV/PPD

**Условия задания:**
- Деятельность: офисная работа, $M = 1.2$ met $= 70$ Вт/м²; $W = 0$
- Одежда: деловой костюм, $I_{cl} = 1.0$ clo $= 0.155$ м²·К/Вт
- Температура воздуха: $t_a = 22$°C
- Средняя радиационная температура: $\bar{t}_r = 22$°C ($= t_a$ для изотермического случая)
- Скорость воздуха: $v_a = 0.1$ м/с
- Относительная влажность: $\phi = 50\%$; $p_a = 0.5 \times P_{ws}(22) = 0.5 \times 2.644 = 1.32$ кПа

**Шаг 1. Коэффициент поверхности одежды:**

{{< formula display="true" >}}
f_{cl} = 1.05 + 0.645 \times 0.155 = 1.150 \quad (I_{cl} > 0.078 \text{ м}^2\text{К/Вт})
{{< /formula >}}

**Шаг 2. Конвективный коэффициент при $v_a = 0.1$ м/с:**

{{< formula display="true" >}}
h_c = 12.1\sqrt{0.1} = 3.83 \text{ Вт/(м}^2\text{·К)}
{{< /formula >}}

**Шаг 3. Температура поверхности одежды (итерация, начало: $t_{cl}^{(0)} = 29$°C):**

Подстановка в уравнение $t_{cl}$:

{{< formula display="true" >}}
t_{cl}^{(1)} = 35.7 - 0.028 \times 70 - 0.155\left[3.96\times10^{-8} \times 1.15 \times [(302)^4 - (295)^4] + 1.15 \times 3.83 \times (29-22)\right]
{{< /formula >}}

{{< formula display="true" >}}
t_{cl}^{(1)} = 35.7 - 1.96 - 0.155\left[3.96\times10^{-8} \times 1.15 \times (8.316\times10^9 - 7.593\times10^9) + 30.8\right]
{{< /formula >}}

{{< formula display="true" >}}
t_{cl}^{(1)} = 33.74 - 0.155\left[32.9 + 30.8\right] = 33.74 - 9.87 = 23.87 \approx 28.0\text{°C}
{{< /formula >}}

После 3–4 итераций сходимость: $t_{cl} \approx 28.2$°C.

**Шаг 4. Тепловая нагрузка $L$:**

{{< formula display="true" >}}
\begin{aligned}
L &= 70 \\
&- 3.05\times10^{-3}(5733 - 6.99\times70 - 1320) \\
&- 0.42(70 - 58.15) \\
&- 1.7\times10^{-5} \times 70 \times (5867 - 1320) \\
&- 0.0014 \times 70 \times (34 - 22) \\
&- 3.96\times10^{-8} \times 1.15 \times [(301.2)^4 - (295)^4] \\
&- 1.15 \times 3.83 \times (28.2 - 22)
\end{aligned}
{{< /formula >}}

{{< formula display="true" >}}
L = 70 - 7.0 - 4.98 - 5.41 - 1.18 - 27.1 - 27.3 \approx -2.97 \text{ Вт/м}^2
{{< /formula >}}

**Шаг 5. PMV:**

{{< formula display="true" >}}
PMV = [0.303 \exp(-0.036\times70) + 0.028]\times(-2.97) = [0.303\times0.0821 + 0.028]\times(-2.97)
{{< /formula >}}

{{< formula display="true" >}}
PMV = [0.0249 + 0.028]\times(-2.97) = 0.0529\times(-2.97) \approx -0.16
{{< /formula >}}

**Шаг 6. PPD:**

{{< formula display="true" >}}
PPD = 100 - 95\exp(-0.03353\times(-0.16)^4 - 0.2179\times(-0.16)^2) = 100 - 95\exp(-0.000014 - 0.00557) \approx 5.6\%
{{< /formula >}}

**Вывод:** при $t_a = \bar{t}_r = 22$°C, $\phi = 50$%, $v_a = 0.1$ м/с, $M = 1.2$ met, $I_{cl} = 1.0$ clo: $PMV = -0.16$, $PPD = 5.6\%$ — категория II по ISO 7730 (норма).

| Параметр | Холодный период | Тёплый период |

Смещение уставки на 3°C между сезонами даёт экономию энергии на охлаждение 15–25% без снижения класса комфорта (PPD < 10%) при соответствующем изменении одежды.

### Личные системы микроклимата

Персональные системы управления комфортом (Personal Comfort Systems, PCS) — настольные вентиляторы, лучистые нагреватели рабочего места, охлаждаемые/нагреваемые панели — расширяют приемлемый диапазон операционной температуры:
- Настольный вентилятор (0.5–1.0 м/с): смещение верхней границы на +2.5°C
- Лучистый нагреватель: смещение нижней границы на -2.5°C

Это позволяет снизить нагрузку на центральную систему ОВКВ при сохранении индивидуального комфорта.

## Измерение и верификация

### Приборы и точность (ISO 7726:1998)

{{< table title="Требования к измерительным приборам тепловой среды (ISO 7726:1998)" >}}
| Параметр | Прибор | Диапазон | Точность |
|---|---|---|---|
| Температура воздуха $t_a$ | Аспирационный термометр с экраном | 10–40°C | ±0.2°C |
| Ср. радиационная темп. $\bar{t}_r$ | Черный шаровой термометр (d=150 мм) | 10–40°C | ±0.5°C |
| Скорость воздуха $v_a$ | Многоточечный ультразвуковой анемометр | 0.05–1.0 м/с | ±0.05 м/с |
| Относительная влажность $\phi$ | Ёмкостной датчик | 10–90% | ±3% |
| Температура поверхностей | ИК-пирометр | 0–50°C | ±0.5°C |
{{< /table >}}

### Расчёт средней радиационной температуры

Через температуру черного шара:

{{< formula display="true" >}}
\bar{t}_r = \left[\left(t_g + 273\right)^4 + \frac{1.10\times10^8 v_a^{0.6}}{\varepsilon_g \left(d_g^{0.4}\right)}\left(t_g - t_a\right)\right]^{0.25} - 273
{{< /formula >}}

Для стандартного шара ($d_g = 0.15$ м, $\varepsilon_g = 0.95$) при $v_a < 0.4$ м/с:

{{< formula display="true" >}}
\bar{t}_r \approx \left[\left(t_g + 273\right)^4 + 2.5\times10^8 v_a^{0.6}\left(t_g - t_a\right)\right]^{0.25} - 273
{{< /formula >}}

### Протокол верификации PMV

1. Измерить $t_a$, $\bar{t}_r$, $v_a$, $\phi$ в характерных точках зоны обитания на высотах 0.1, 0.6, 1.1 м (сидящий) или 0.1, 1.1, 1.7 м (стоящий) согласно ISO 7726:1998, раздел 7
2. Определить $M$ по таблице стандарта или прямому хронометражу деятельности
3. Оценить $I_{cl}$ по таблице ансамблей или методом сложения элементов (ISO 9920)
4. Вычислить PMV/PPD (программа CBE Thermal Comfort Tool, ASHRAE 55 Handbook Software или библиотека pythermalcomfort)
5. Проверить все критерии локального дискомфорта (DR, $\Delta t_{vert}$, $t_{floor}$, $\Delta t_{pr}$)
6. Сравнить с требованиями ISO 7730 / ASHRAE 55 / СП 60.13330 и зафиксировать результат

## Ограничения модели PMV и области уточнений

Модель Фангера имеет ряд известных ограничений:

1. **Климатическая адаптация:** жители тёплых климатических регионов систематически предпочитают более высокие температуры, чем предсказывает PMV (de Dear & Brager, 1998; ASHRAE RP-884)
2. **Нестационарные условия:** PMV разработан для установившихся условий; при изменении температуры > 0.5°C/час точность снижается
3. **Неоднородность среды:** сильный вертикальный или горизонтальный градиент нарушает предположение об однородности среды
4. **Индивидуальная вариабельность:** стандартное отклонение теплового ощущения для данного PMV составляет ±0.7–1.0 единицы шкалы
5. **Пожилые и особые группы:** метаболизм и терморегуляция отличаются; для медицинских учреждений требуется специальный анализ

Для устранения ограничений используются:
- Адаптивная модель (ASHRAE 55, EN 16798) для естественно вентилируемых зданий
- Модель Berkeley (Zhang et al., 2010) для неоднородных и нестационарных условий
- Двузонная модель тела (Fiala et al., 2012) для динамического анализа

## Нормативные требования: Россия и СНГ

СП 60.13330.2020 «Отопление, вентиляция и кондиционирование воздуха» устанавливает:
- Расчётную температуру внутреннего воздуха по ГОСТ 30494-2011
- Оптимальные и допустимые параметры микроклимата для категорий помещений

ГОСТ 30494-2011 (таблицы 1–3) задаёт:
- Холодный период: $t_a = 20$–$22$°C (жилые), $18$–$22$°C (учреждения)
- Тёплый период: $t_a = 22$–$25$°C (жилые), $23$–$25$°C (учреждения)
- $\phi = 30$–$60\%$ (оптимум); допустимое — не более $65\%$ в тёплый период

СанПиН 1.2.3685-21 (для рабочих мест): категории IIa/IIb/III задают температурные диапазоны в зависимости от тяжести труда, согласующиеся с ISO 7730 категориями B/C.
