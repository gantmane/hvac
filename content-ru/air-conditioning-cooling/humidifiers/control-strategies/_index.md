## Обзор

Стратегии управления увлажнителями — это совокупность алгоритмов и технических решений, обеспечивающих поддержание заданного уровня влажности в помещениях и системах вентиляции. Правильный выбор стратегии критичен для обеспечения теплового комфорта по ASHRAE 55-2023, предотвращения конденсации на ограждающих конструкциях, подавления роста микроорганизмов и повышения энергоэффективности системы ОВК. В холодном и умеренном климате (климатические зоны III–VI по СП 131.13330) увлажнители работают практически непрерывно в отопительный период, требуя сложных алгоритмов для предотвращения переувлажнения и конденсации. В жарком климате основная задача — недопущение избыточной влажности во время охлаждения.

## Физические основы управления влажностью

Управление увлажнением базируется на психрометрических зависимостях (psychrometric relationships). Относительная влажность (RH, relative humidity) связана с парциальным давлением пара и давлением насыщения:

{{< formula display="true" >}}
\varphi = 100 \cdot \frac{p_v}{p_{\text{sat}}(T)}
{{< /formula >}}

где $\varphi$ — относительная влажность, %; $p_v$ — парциальное давление водяного пара, Па; $p_{\text{sat}}(T)$ — давление насыщенного пара при температуре $T$, Па.

Температура точки росы $T_d$ для инженерных расчётов определяется по формуле Магнуса (Magnus approximation):

{{< formula display="true" >}}
T_d = \frac{b \cdot \ln\!\left(\dfrac{\varphi}{100}\right) + \dfrac{a \cdot T}{b + T}}{a - \ln\!\left(\dfrac{\varphi}{100}\right) - \dfrac{a \cdot T}{b + T}}
{{< /formula >}}

где $a = 17{,}27$, $b = 237{,}7$ °C — эмпирические константы для диапазона −40…+60 °C.

Критическое условие предотвращения конденсации: температура поверхности $T_{\text{пов}}$ должна быть выше точки росы приточного воздуха:

$$T_{\text{пов}} > T_d + \Delta T_{\text{гист}}$$

где $\Delta T_{\text{гист}} = 2$ °C — рекомендуемый гистерезис безопасности.

## Датчики и преобразователи влажности

Многоуровневый мониторинг обеспечивает корректную работу алгоритмов управления:

{{< table title="Типы датчиков влажности и их размещение" >}}
| Тип датчика | Место установки | Погрешность | Назначение |
|---|---|---|---|
| Ёмкостный полимерный (capacitive polymer) | Помещение, высота 1,0–1,5 м | ±2–3 % RH | Основная уставка влажности |
| Преобразователь в воздуховоде (duct transmitter) | Воздуховод за увлажнителем | ±2 % RH | Контроль выходной влажности |
| Датчик точки росы (dew point sensor) | Критичные поверхности, угол окна | ±0,5 °C $T_d$ | Защита от конденсации |
| Психрометр (aspirating psychrometer) | Смесительная камера | ±1,5 % RH | Диагностика и балансировка |
{{< /table >}}

Ёмкостные сенсоры на полимерной плёнке (Vaisala HMP серии, Honeywell HIH) обеспечивают погрешность ±2–3 % RH при времени отклика 10–20 с. Для критичных применений (микроэлектроника, фармацевтика) используют гигрометры с охлаждаемым зеркалом (chilled-mirror hygrometers) с погрешностью ±0,1–0,2 °C $T_d$.

## Пропорциональное модулирующее управление

Производительность увлажнителя регулируется пропорционально отклонению от уставки:

{{< formula display="true" >}}
G_{\text{увл}} = G_{\text{max}} \cdot \frac{\varphi_{\text{уст}} - \varphi_{\text{тек}}}{K_p}
{{< /formula >}}

где $G_{\text{max}}$ — номинальная производительность увлажнителя, кг/ч; $K_p$ — пропорциональная полоса (proportional band), % RH.

При $K_p = 10$ % и отклонении 5 % увлажнитель работает на 50 % мощности. Типовой диапазон $K_p$: 5–15 % RH. Добавление интегральной составляющей (PI-регулятор) устраняет статическое смещение; стандартное интегральное время — 5–10 мин. PID-управление применяется в критичных системах с быстрыми изменениями нагрузки (clean rooms, операционные).

**Преимущества:** плавное регулирование, колебания влажности ±1–3 %, отсутствие частых включений.  
**Требования:** увлажнитель с непрерывно модулируемой производительностью (электрический парогенератор с тиристорным управлением, форсунки с VFD).

## Двухпозиционное управление On/Off

Увлажнитель включается при $\varphi < \varphi_{\text{уст}} - \Delta\varphi$ и выключается при $\varphi > \varphi_{\text{уст}} + \Delta\varphi$:

Типовые уставки для жилых помещений (зимний период):
- Включение: 40 % RH
- Отключение: 50 % RH
- Гистерезис $\Delta\varphi$: 5–10 % RH

Минимальный интервал между включением и отключением — 10–15 мин: защищает запорный клапан или пускатель от частых коммутаций (short cycling). При гистерезисе менее 3 % система нестабильна. Метод применим для увлажнителей с фиксированной производительностью (напр., бытовые испарительные).

## Компенсация по температуре наружного воздуха (Outdoor Air Temperature Reset)

В холодный период воздух, инфильтрующийся через неплотности ограждающих конструкций, охлаждает внутренние поверхности. При высокой внутренней влажности на холодных поверхностях (углы окон, наружные стены) может образоваться конденсат. Алгоритм компенсации снижает уставку влажности при падении наружной температуры:

{{< formula display="true" >}}
\varphi_{\text{уст}}(T_{\text{нар}}) = \varphi_{\text{баз}} + k \cdot (T_{\text{уст,внутр}} - T_{\text{нар}})
{{< /formula >}}

где $\varphi_{\text{баз}} = 45$ % (базовая уставка), $k = 1{,}0$–$1{,}5$ %/°C (коэффициент компенсации), $T_{\text{уст,внутр}} = 20$ °C.

{{< table title="Рекомендуемые уставки влажности по наружной температуре (климат Средней России)" >}}
| Температура наружного воздуха, °C | Рекомендуемая уставка, % RH | Обоснование |
|---|---|---|
| ≤ −20 | 30–35 | Предотвращение конденсации на двойных окнах |
| −15…−5 | 35–40 | Инфильтрация холодного воздуха через неплотности |
| −5…0 | 40–45 | Переходный режим |
| > 0 | 45–55 | Зима/весна, умеренный риск |
{{< /table >}}

По EN 12098-11 в регионах с $T_{\text{нар,min}} < -15$ °C максимальная зимняя уставка не должна превышать 45 % RH без специального расчёта конденсации.

## Контроль точки росы поверхности (Surface Dew Point Control)

Датчик температуры поверхности монтируется в наиболее критичном месте: стык оконного переплёта с рамой, угол наружной стены. Алгоритм защиты:

{{< formula display="true" >}}
\Delta T_{\text{защ}} = T_{\text{пов}} - T_d \geq 2 \text{ °C}
{{< /formula >}}

Если $\Delta T_{\text{защ}} < 1$ °C — предупреждение, принудительное снижение уставки влажности. Если $\Delta T_{\text{защ}} < 0$ °C — аварийное отключение увлажнителя, включение режима осушения (dehumidification mode).

**Пример.** Комната 20 °C, относительная влажность 60 % — точка росы $T_d \approx 12$ °C. Угол наружной стены (термическое сопротивление R = 3 м²·°C/Вт, наружная температура −15 °C): температура поверхности $T_{\text{пов}} = 20 - (20 - (-15)) \times R_{\text{пов}} / R_{\text{стены}} \approx 14$ °C. При этом $\Delta T = 14 - 12 = 2$ °C — на грани срабатывания сигнализации. Вывод: в данном случае уставку следует снизить до 50 % RH.

## Сезонный сброс уставки (Seasonal Reset)

Автоматический переход между режимами:

- **Зимний режим (ноябрь–март):** $\varphi_{\text{уст}}$ = 40–45 %, активна компенсация по $T_{\text{нар}}$, датчики поверхности включены.
- **Летний режим (май–сентябрь):** увлажнитель заблокирован (summer lockout), система кондиционирования обеспечивает осушение.
- **Переходные месяцы (апрель, октябрь):** плавная коррекция уставки со скоростью $k = 0{,}5$–$1{,}0$ % RH в сутки; переход по среднесуточной наружной температуре (адаптивный алгоритм) предпочтительнее фиксированного календарного расписания.

Логика летнего блокирования (summer lockout):

```
ЕСЛИ T_нар > T_откл (15–18 °C) В ТЕЧЕНИЕ 5 суток подряд
ТО увлажнитель = ВЫКЛ
ИНАЧЕ управление в обычном режиме
```

## Применение в системах CAV и VAV

**Системы постоянного расхода воздуха (CAV, Constant Air Volume):** уставка влажности задаётся на уровне центрального кондиционера; датчик установлен в воздуховоде за увлажнителем и в помещении. Рекомендуется PI-управление с компенсацией по $T_{\text{нар}}$.

**Системы переменного расхода (VAV, Variable Air Volume):** при минимальном расходе воздуха (30–50 % номинала) производительность увлажнителя должна масштабироваться соответственно. Комбинированное управление: модуляция увлажнителя + управление VAV-клапанами. Минимальная производительность увлажнителя рассчитывается из условия поддержания уставки влажности при минимальном расходе воздуха и максимальной нагрузке по влажности.

{{< formula display="true" >}}
G_{\text{увл,min}} = \dot{V}_{\text{возд,min}} \cdot \rho_{\text{возд}} \cdot (\omega_{\text{уст}} - \omega_{\text{нар,max}})
{{< /formula >}}

где $\omega_{\text{нар,max}}$ — максимальное влагосодержание наружного воздуха в холодный период, кг/кг.

## Мониторинг и диагностика

Система управления непрерывно вычисляет запас до конденсации:

$$\Delta T = T_{\text{пов}} - T_d(\varphi_{\text{тек}}, T_{\text{комн}})$$

Диагностические признаки:
- Скачок $T_d$ более ±5 °C за 1 мин — неисправность датчика или пиковый выброс увлажнителя;
- Рост влагосодержания при отключённом увлажнителе — утечка или неплотность клапана;
- Расхождение показаний датчиков «вход/выход» кондиционера более 5 % RH — нарушение герметичности воздуховода.

## Практические рекомендации

**Типовые уставки по назначению помещения:**
- Жилые помещения, зима: 40–50 % RH
- Офисы: 40–60 % RH
- Музеи и архивы: 45–55 % RH (допуск ±3 %)
- Операционные (OR): 45–55 % RH, ASHRAE 170
- Серверные залы (data centers): 40–60 % RH, ASHRAE 90.4

**Частые ошибки проектирования:**
1. Уставка влажности выше 55 % зимой без расчёта конденсации на ограждающих конструкциях.
2. Отсутствие компенсации по наружной температуре в климате с $T_{\text{нар,min}} < -10$ °C.
3. Установка датчика влажности в зоне застоя воздуха, вблизи источников тепла или влажности (кухня, санузел, прямое солнечное облучение).
4. Игнорирование температуры поверхности критичных конструкций при расчёте максимально допустимой влажности.
5. Гистерезис On/Off менее 3 % RH — нестабильность управления, частые циклы запуска.

Рекомендуется калибровка датчиков влажности в начале каждого отопительного сезона с использованием поверенного переносного психрометра или гигрометра с точкой росы. Проверка целостности уплотнений воздуховодов исключает ложные показания датчиков на выходе кондиционера.
