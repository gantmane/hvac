## Отклонения реальных газов от идеального

### Что определяет «идеальный» газ

Идеальный газ — модель, в которой:
1. Молекулы не занимают собственного объёма (точечные частицы)
2. Между молекулами нет межмолекулярных взаимодействий (ни притяжения, ни отталкивания)

Следствие: {{< formula >}}Pv = RT{{< /formula >}} и {{< formula >}}u = u(T){{< /formula >}}, {{< formula >}}h = h(T){{< /formula >}} только.

### Факторы, вызывающие отклонение

1. **Молекулярный объём**: при высоких давлениях собственный объём молекул становится сравнимым с объёмом газа → объём реального газа больше идеального
2. **Силы притяжения (Ван-дер-Ваальс)**: при умеренных давлениях и температурах ниже инверсионной → объём меньше идеального
3. **Ассоциация молекул**: для полярных молекул (H₂O, NH₃, HFO) образование комплексов существенно изменяет вириальные коэффициенты

## Фактор сжимаемости

### Определение

{{< formula display="true" >}}
Z = \frac{Pv}{RT}
{{< /formula >}}

При Z = 1 — идеальный газ. Z < 1: преобладают силы притяжения. Z > 1: преобладают силы отталкивания (большой объём молекул).

### Обобщённые диаграммы сжимаемости

Принцип соответственных состояний (принцип Пицера): вещества с одинаковыми приведёнными параметрами {{< formula >}}T_r = T/T_{cr}{{< /formula >}}, {{< formula >}}P_r = P/P_{cr}{{< /formula >}} имеют приблизительно одинаковый Z.

{{< formula display="true" >}}
Z = Z(T_r, P_r, \omega)
{{< /formula >}}

где {{< formula >}}\omega{{< /formula >}} — ацентрический фактор Пицера (Pitzer acentric factor):

{{< formula display="true" >}}
\omega = -1 - \log_{10}\left(\frac{P_{sat}}{P_{cr}}\right)\bigg|_{T_r = 0{,}7}
{{< /formula >}}

| Хладагент | ω | T_cr, К | P_cr, МПа | Применение |
|---|---|---|---|---|
| R-134a | 0,327 | 374,2 | 4,059 | Автокондиционеры, малые чиллеры |
| R-32 | 0,277 | 351,3 | 5,782 | Сплит-системы, VRF |
| R-1234yf | 0,276 | 367,9 | 3,382 | Авто (замена R-134a) |
| R-744 (CO₂) | 0,225 | 304,1 | 7,377 | Тепловые насосы, магазины |
| R-717 (NH₃) | 0,253 | 405,4 | 11,33 | Промышленная холодильная техника |
| R-290 (пропан) | 0,152 | 369,9 | 4,251 | Малые системы |
{{< /table >}}

## Уравнение Ван-дер-Ваальса

Первое уравнение состояния, учитывающее реальные эффекты (1873):

{{< formula display="true" >}}
\left(P + \frac{a}{v^2}\right)(v - b) = RT
{{< /formula >}}

Член {{< formula >}}a/v^2{{< /formula >}} — поправка на межмолекулярное притяжение; b — поправка на собственный объём молекул (коволюм).

### Критические параметры через коэффициенты a, b

На критической изотерме: {{< formula >}}\left(\partial P/\partial v\right)_T = \left(\partial^2 P/\partial v^2\right)_T = 0{{< /formula >}}

{{< formula display="true" >}}
T_{cr} = \frac{8a}{27Rb}, \qquad P_{cr} = \frac{a}{27b^2}, \qquad v_{cr} = 3b
{{< /formula >}}

Отсюда критический коэффициент сжимаемости:

{{< formula display="true" >}}
Z_{cr} = \frac{P_{cr} v_{cr}}{R T_{cr}} = \frac{3}{8} = 0{,}375 \quad \text{(ВДВ, все вещества)}
{{< /formula >}}

Экспериментальные значения: Z_cr = 0,22–0,29 — ВДВ даёт завышенный Z_cr и неудовлетворительно описывает жидкостную фазу.

## Уравнение Пенга–Робинсона (PR)

Наиболее практически значимое кубическое уравнение состояния для инженерных расчётов хладагентов:

{{< formula display="true" >}}
P = \frac{RT}{v - b} - \frac{a(T)}{v(v+b) + b(v-b)}
{{< /formula >}}

{{< formula display="true" >}}
a(T) = a_c \cdot \alpha(T), \qquad a_c = 0{,}45724 \frac{R^2 T_{cr}^2}{P_{cr}}
{{< /formula >}}

{{< formula display="true" >}}
\alpha(T) = \left[1 + \kappa\left(1 - T_r^{0{,}5}\right)\right]^2, \qquad \kappa = 0{,}37464 + 1{,}54226\,\omega - 0{,}26992\,\omega^2
{{< /formula >}}

{{< formula display="true" >}}
b = 0{,}07780 \frac{RT_{cr}}{P_{cr}}
{{< /formula >}}

Критический коэффициент сжимаемости PR: {{< formula >}}Z_{cr} = 0{,}307{{< /formula >}} — ближе к экспериментальным данным, чем ВДВ.

### Вывод коэффициента сжимаемости из PR

Уравнение PR записывают в кубической форме по Z:

{{< formula display="true" >}}
Z^3 - (1 - B)Z^2 + (A - 3B^2 - 2B)Z - (AB - B^2 - B^3) = 0
{{< /formula >}}

где {{< formula >}}A = aP/(RT)^2{{< /formula >}}, {{< formula >}}B = bP/(RT){{< /formula >}}.

При T > T_cr: одно вещественное корень → однофазная область.
При T < T_cr: три вещественных корня → наибольший (Z_gas) и наименьший (Z_liq) физически реальны; средний нефизичен.

### Числовой пример: Z для R-32 при P = 2 МПа, T = 80 °C

Для R-32: T_cr = 351,3 К, P_cr = 5,782 МПа, ω = 0,277.

T_r = 353,15/351,3 = 1,005, P_r = 2,0/5,782 = 0,346.

{{< formula display="true" >}}
\kappa = 0{,}37464 + 1{,}54226 \times 0{,}277 - 0{,}26992 \times 0{,}277^2 = 0{,}37464 + 0{,}42721 - 0{,}02072 = 0{,}781
{{< /formula >}}

{{< formula display="true" >}}
\alpha = [1 + 0{,}781(1 - 1{,}005^{0{,}5})]^2 = [1 + 0{,}781(1 - 1{,}0025)]^2 \approx [1 - 0{,}00195]^2 \approx 0{,}996
{{< /formula >}}

По формулам для a_c, b и далее A, B → кубическое уравнение → Z ≈ 0,921 (вместо Z = 1 для идеального газа).

Погрешность идеального газа при данных условиях: {{< formula >}}(1 - 0{,}921)/1 = 7{,}9\%{{< /formula >}} — уже значимая для инженерных расчётов.

## Поправки к энтальпии и энтропии (departure functions)

Термодинамические свойства реального газа вычисляются добавлением «отклонений от идеального газа» (departure functions):

{{< formula display="true" >}}
h(T, P) = h^{ig}(T, P_{ref}) + \left[h(T, P) - h^{ig}(T, P)\right]
{{< /formula >}}

**Энтальпийное отклонение** из уравнения Пенга–Робинсона:

{{< formula display="true" >}}
h - h^{ig} = RT(Z - 1) - \frac{a(T) - T\,da/dT}{b\sqrt{8}} \ln\frac{v + (1+\sqrt{2})b}{v + (1-\sqrt{2})b}
{{< /formula >}}

где {{< formula >}}da/dT = a_c \frac{d\alpha}{dT} = -a_c \frac{\kappa\,\alpha^{0{,}5}}{T_{cr}^{0{,}5} T^{0{,}5}}{{< /formula >}}.

**Энтропийное отклонение:**

{{< formula display="true" >}}
s - s^{ig} = -R\ln\frac{P(v-b)}{RT} - \frac{da/dT}{b\sqrt{8}} \ln\frac{v + (1+\sqrt{2})b}{v + (1-\sqrt{2})b}
{{< /formula >}}

Эти выражения — основа для расчёта h и s в программах типа REFPROP при использовании кубических уравнений состояния.

## Критические явления и критическая точка

### Особенности вблизи критической точки

В окрестности критической точки (T → T_cr, P → P_cr):
- Изотермная сжимаемость {{< formula >}}\kappa_T \to \infty{{< /formula >}} → бесконечная чувствительность объёма к давлению
- Теплоёмкость {{< formula >}}c_p \to \infty{{< /formula >}} → огромное количество теплоты при малом изменении температуры
- Различие плотностей жидкости и пара исчезает: {{< formula >}}\rho_f \to \rho_g{{< /formula >}}
- Поверхностное натяжение → 0
- Интенсивное рассеяние света (критическая опалесценция)

### Следствие для HVAC

**Транскритические системы CO₂** (P > 7,377 МПа): вблизи псевдокритической точки (T ≈ 35 °C при P = 80–90 бар) c_p резко возрастает — газовый охладитель в этой зоне особенно эффективен с точки зрения теплопередачи. Это свойство используется при выборе рабочего давления транскритического цикла.

**Критическая флуктуация плотности** и **критическое замедление** (critical slowing down) затрудняют расчёты свойств кубическими уравнениями вблизи критической точки — там необходимы специализированные уравнения состояния (cross-over models, например в REFPROP).

## Принцип соответственных состояний: применение

### Вириальное уравнение Пицера

{{< formula display="true" >}}
Z = 1 + \frac{B' P}{RT} + \frac{C' P^2}{(RT)^2} + \cdots
{{< /formula >}}

Трёхпараметрическое приближение Пицера (второй вириальный коэффициент):

{{< formula display="true" >}}
\frac{B P_{cr}}{R T_{cr}} = B^{(0)}(T_r) + \omega B^{(1)}(T_r)
{{< /formula >}}

{{< formula display="true" >}}
B^{(0)} = 0{,}083 - \frac{0{,}422}{T_r^{1{,}6}}, \qquad B^{(1)} = 0{,}139 - \frac{0{,}172}{T_r^{4{,}2}}
{{< /formula >}}

Применимо при P_r < 0,5; погрешность < 3 % для неполярных веществ.

## Вириальное уравнение и смеси

Для смесей хладагентов (R-410A, R-407C, R-454B) вириальные коэффициенты вычисляются по правилам смешения:

{{< formula display="true" >}}
B_{mix} = \sum_i \sum_j y_i y_j B_{ij}
{{< /formula >}}

Перекрёстные коэффициенты {{< formula >}}B_{ij}{{< /formula >}} (i ≠ j) определяют из правил смешения Лоренца–Бертло или из уравнений состояния с параметрами бинарного взаимодействия.

Для систем HVAC с многокомпонентными хладагентами корректные свойства обеспечивает только REFPROP, а не упрощённые кубические уравнения.

## Жидкостная фаза: сжимаемость и тепловое расширение

Для жидкого хладагента важны:

**Изотермная сжимаемость:**

{{< formula display="true" >}}
\kappa_T = -\frac{1}{v}\left(\frac{\partial v}{\partial P}\right)_T \qquad [1/\text{Па}]
{{< /formula >}}

**Коэффициент объёмного расширения:**

{{< formula display="true" >}}
\beta = \frac{1}{v}\left(\frac{\partial v}{\partial T}\right)_P \qquad [1/\text{К}]
{{< /formula >}}

Для жидкого R-32 при 30 °C: β ≈ 3,2×10⁻³ К⁻¹, κ_T ≈ 8×10⁻⁴ МПа⁻¹.

Эти значения важны для:
- Расчёта объёма расширительного бака (гидравлического буфера)
- Оценки давления при нагреве жидкости в замкнутом объёме (например, в жидкостной линии при отключённой системе)

## Типичные ошибки при работе с реальными газами

1. **Применение идеального газа к насыщенному пару.** В двухфазной области закон идеального газа полностью неприменим. Используйте таблицы насыщения.
2. **Нераспознанная смена фаз.** При конденсации Z скачкообразно изменяется. Кубические уравнения дают два корня — необходимо корректно выбирать физически реальный.
3. **Игнорирование ω при расчёте Z для полярных молекул.** Для NH₃, H₂O, R-134a ацентрический фактор существенно отличается от нуля → нельзя пользоваться двухпараметрическими диаграммами Z(T_r, P_r).
4. **Экстраполяция кубических уравнений вблизи критической точки.** Кубические ЭС ненадёжны при {{< formula >}}|T_r - 1| < 0{,}05{{< /formula >}} — используйте REFPROP.
