Точный расчёт холодильной нагрузки (cooling load calculation) составляет основу проектирования систем HVAC. Существует несколько методов — от упрощённых ручных процедур до комплексного компьютерного анализа. Понимание возможностей и ограничений каждого метода позволяет выбрать оптимальный инструмент для конкретного проекта.

## Эволюция методов расчёта

Методы расчёта теплопоступлений последовательно совершенствовались для учёта нестационарных процессов теплопередачи:

1. **Методы стационарного состояния** — ранний упрощённый подход; устарели
2. **TETD/TA (1967)** — метод эквивалентной разности температур / осреднение по времени
3. **TFM (1972)** — метод передаточных функций (transfer function method)
4. **CLTD/CLF (1979)** — разность температур холодильной нагрузки / коэффициент холодильной нагрузки
5. **RTS (2001)** — метод временных рядов радиации (radiant time series)
6. **HBM (2001)** — метод теплового баланса (heat balance method)

## Метод теплового баланса (HBM)

### Физическая основа

Метод теплового баланса непосредственно применяет фундаментальные принципы теплопередачи, решая систему уравнений баланса энергии для всех поверхностей и воздуха помещения одновременно.

**Баланс тепла на поверхности (обобщённая форма):**

{{< formula display="true" >}}
q''_{\text{конв},i} + q''_{\text{SW},i} + q''_{\text{LW},i} + q''_{\text{конд},i} = 0
{{< /formula >}}

Где:
- $q''_{\text{конв}}$ — конвективный тепловой поток, Вт/м²
- $q''_{\text{SW}}$ — поглощённое коротковолновое (солнечное) излучение, Вт/м²
- $q''_{\text{LW}}$ — обмен длинноволновым инфракрасным излучением, Вт/м²
- $q''_{\text{конд}}$ — теплоток через конструкцию, Вт/м²

**Баланс тепла воздуха помещения:**

{{< formula display="true" >}}
\sum_{\text{поверх}} h_c \cdot A_s \cdot (T_s - T_{\text{возд}}) + Q_{\text{внутр}} + Q_{\text{инф}} + Q_{\text{сист}} = 0
{{< /formula >}}

Где $h_c$ — конвективный коэффициент теплоотдачи, Вт/(м²·К); $A_s$ — площадь поверхности, м²; $T_s$ и $T_{\text{возд}}$ — температуры поверхности и воздуха, °C.

### Преимущества и ограничения

**Преимущества**: наивысшая физическая строгость; применим к любой геометрии и конструкции; детальный учёт солнечного излучения и длинноволнового обмена; не требует предварительных таблиц.

**Ограничения**: высокая вычислительная сложность (требует ПО); необходимы детальные входные данные; для корректной интерпретации результатов требуется специализированная квалификация.

## Метод временных рядов радиации (RTS)

### Концепция

Метод RTS упрощает подход HBM, используя предварительно рассчитанные коэффициенты отклика для преобразования радиационных теплопоступлений в холодильные нагрузки. Рекомендован ASHRAE как основной метод для инженерных расчётов с 2001 г.

**Общая холодильная нагрузка:**

{{< formula display="true" >}}
Q_{\text{охл}}(t) = Q_{\text{конв}}(t) + \sum_{\theta=0}^{23} r_\theta \cdot Q_{\text{рад}}(t-\theta)
{{< /formula >}}

Где:
- $r_\theta$ — коэффициент временного ряда радиации для часа $\theta$ (radiant time factor, RTF)
- $Q_{\text{рад}}(t-\theta)$ — радиационное теплопоступление $\theta$ часов назад

### Коэффициенты временных рядов (RTF)

RTF распределяют радиационное теплопоступление во времени в зависимости от тепловых характеристик зоны:

{{< table title="Коэффициенты радиационного временного ряда (RTF) по типам зон" >}}
| Тип зоны | r₀ | r₁ | r₂–r₅ | Описание |
|---|---|---|---|---|
| Лёгкая | 0,50 | 0,20 | Быстро убывающий | Подвесной потолок, ковровое покрытие |
| Средняя | 0,35 | 0,25 | Постепенно убывающий | Стандартное коммерческое здание |
| Тяжёлая | 0,25 | 0,20 | Медленно убывающий | Массивная конструкция, бетон |
{{< /table >}}

### Временные ряды теплопроводности (CTS)

Коэффициенты временного ряда теплопроводности (conduction time series, CTS) учитывают эффект тепловой массы в непрозрачных конструкциях:

{{< formula display="true" >}}
q_{\text{стены}}(t) = \sum_{\theta=0}^{23} c_\theta \cdot (T_{\text{экв}}(t-\theta) - T_{\text{пом}})
{{< /formula >}}

Где $T_{\text{экв}}$ — эквивалентная наружная температура (sol-air temperature), учитывающая солнечное излучение на поверхность.

**Применение**: ручные расчёты (с таблицами); реализация в электронных таблицах; образовательные цели; быстрые оценочные расчёты.

## Метод передаточных функций (TFM)

### Математическая основа

TFM использует коэффициенты z-преобразования для связи текущих и прошлых теплопоступлений с текущими нагрузками:

{{< formula display="true" >}}
Q(t) = \sum_{n=0}^{N} v_n \cdot q(t - n\Delta) - \sum_{m=1}^{M} w_m \cdot Q(t - m\Delta)
{{< /formula >}}

Где $v_n$ — коэффициенты отклика на тепловой ввод; $w_m$ — коэффициенты отклика для предыдущих нагрузок; $q$ — теплопоступление; $Q$ — холодильная нагрузка.

### Функции теплопроводности (CTF)

Передаточные функции теплопроводности (conduction transfer functions, CTF) описывают тепловой отклик конструкции:

{{< formula display="true" >}}
q''_i(t) = \sum_{n=0}^{N} X_n T_{o,t-n} - \sum_{n=0}^{N} Y_n T_{i,t-n} + \sum_{n=1}^{N} \Phi_n q''_{i,t-n}
{{< /formula >}}

Где $X_n$, $Y_n$, $\Phi_n$ — коэффициенты CTF; $T_o$ и $T_i$ — наружная и внутренняя температуры. Метод реализован в программах DOE-2 и ряде коммерческих продуктов.

## Метод CLTD/CLF

### Разность температур холодильной нагрузки (CLTD)

Таблицы CLTD объединяют наружно-внутреннюю разность температур с эффектом тепловой массы:

{{< formula display="true" >}}
Q_{\text{стены/кровля}} = U \times A \times \text{CLTD}_{\text{корр}}
{{< /formula >}}

**Корректировка CLTD для условий, отличных от стандартных (ASHRAE 1979):**

{{< formula display="true" >}}
\text{CLTD}_{\text{корр}} = \text{CLTD} + (25{,}5 - T_{\text{пом}}) + (T_{\text{нв,ср}} - T_{\text{нв,расч}})
{{< /formula >}}

### Коэффициент холодильной нагрузки (CLF)

Значения CLF преобразуют мгновенные солнечные и внутренние теплопоступления в охлаждающие нагрузки:

{{< formula display="true" >}}
Q_{\text{солн}} = \text{SHGC} \times A \times \text{SC} \times \text{CLF}
{{< /formula >}}

{{< formula display="true" >}}
Q_{\text{освещ}} = W_{\text{освещ}} \times F_u \times F_s \times \text{CLF}
{{< /formula >}}

**Ограничения**: основаны на фиксированных типах конструкций; предварительно рассчитанные значения могут не соответствовать фактическим параметрам. Метод устарел и заменён RTS с 2001 г.; использовать только при явной необходимости.

## Расчётный пример (SI) — метод RTS

**Исходные данные**: офисная зона 500 м²; западная стена (бетон 250 мм), $U = 0{,}30$ Вт/(м²·К), $A = 120$ м²; Sol-air температура в 15:00: $T_{\text{экв}} = 48$ °C; внутренняя уставка: $T_{\text{пом}} = 24$ °C.

Для бетонной стены (тяжёлая зона) коэффициент CTS: $c_0 = 0{,}01$; $c_3 = 0{,}15$; $c_6 = 0{,}35$; $c_9 = 0{,}30$; $c_{12} = 0{,}12$; $c_{15} = 0{,}07$.

**Теплопоступление через стену в 15:00** (с учётом двух предыдущих значений $T_{\text{экв}}$):

{{< formula display="true" >}}
q_{\text{стены}}(15) = U \cdot A \cdot \sum_{\theta} c_\theta \cdot (T_{\text{экв}}(15-\theta) - T_{\text{пом}})
{{< /formula >}}

При доминирующем члене ($c_6$): $q \approx 0{,}30 \times 120 \times 0{,}35 \times (48 - 24) = 302$ Вт. Полный расчёт с 24 членами суммы даёт нагрузку 1050–1300 Вт в зависимости от профиля $T_{\text{экв}}$ в течение дня — на 30–40 % ниже мгновенного теплопоступления при стационарном расчёте (1440 Вт), что подтверждает значимость учёта тепловой массы.

## Реализация в расчётном программном обеспечении

- **EnergyPlus** — метод теплового баланса; открытый код; интегрирован в DesignBuilder, OpenStudio
- **DOE-2** — метод передаточных функций; применяется в Trane TRACE 3D Plus
- **Carrier HAP (Hourly Analysis Program)** — метод RTS; почасовое моделирование; широко распространён в проектировании
- **ASHRAE Load Calc** — справочная реализация метода RTS

## Практические рекомендации по выбору метода

**Применять тепловой баланс / специализированное ПО:**
- Сложные здания с нестандартными конструкциями
- Необходим почасовой энергетический анализ
- Высокие требования к точности (ЦОД, операционные)

**Применять RTS:**
- Ручные или табличные расчёты
- Стандартные коммерческие здания
- Быстрые итерации на ранних стадиях проектирования
- Образовательные и учебные цели

**Избегать CLTD/CLF:**
- Устаревший метод; заменён RTS в 2001 г.
- Применять только при прямом указании нормативного документа

### Коэффициенты запаса (safety factors)

После завершения расчёта нагрузок:
- Типовой запас при подборе оборудования: 10–15 %
- Учитывает неопределённость допущений и изменчивость внутренних нагрузок
- Не следует суммировать несколько коэффициентов запаса на разных этапах расчёта
- Чрезмерное завышение мощности (более 25 %) снижает эффективность на частичной нагрузке и ухудшает осушение воздуха

Нормативные документы: **ASHRAE Handbook — Fundamentals, глава 18**; **ASHRAE 183**; **СП 60.13330.2020**.
