Масляные горелки (oil burners) распыляют жидкое топливо в тонкие капли, смешивают аэрозоль с воздухом горения и воспламеняют смесь для создания контролируемого пламени. Качественное горение мазута требует: надлежащего распыления (средний диаметр Зотера (Sauter mean diameter, SMD) 20–80 мкм), достаточного смешивания топлива с воздухом, времени пребывания капель 0,05–0,15 с для испарения и сгорания, а также управления температурой пламени. Диапазон мощности масляных горелок — от небольших жилых форсунок (200–2 000 кВт) до крупных промышленных систем с паровым распылением (200–2 000 МВт). Нормативная база: ASHRAE Handbook HVAC Systems, EN 303-1, СП 89.13330.2016.

## Основы теории распыления

### Диаметр капли и площадь поверхности

Цель распыления — максимально увеличить площадь поверхности топлива для ускорения испарения и горения. Коэффициент увеличения площади поверхности при распылении:

{{< formula display="true" >}}
\frac{A_{\text{капли}}}{A_{\text{струи}}} = \frac{6 D}{d_{32}}
{{< /formula >}}

где $d_{32}$ — средний диаметр Зотера, мкм; $D$ — начальный диаметр струи, мкм.

**Пример.** Струя мазута диаметром 1 000 мкм, распылённая до SMD = 50 мкм:

$$\frac{A_{\text{капли}}}{A_{\text{струи}}} = \frac{6 \times 1\,000}{50} = 120$$

Площадь поверхности увеличивается в 120 раз, что обеспечивает быстрое испарение.

### Средний диаметр Зотера (SMD)

SMD — интегральная характеристика спектра капель, отражающая отношение объёма к площади поверхности:

{{< formula display="true" >}}
d_{32} = \frac{\sum n_i d_i^3}{\sum n_i d_i^2}
{{< /formula >}}

где $n_i$ — количество капель в $i$-м классе размера, $d_i$ — диаметр класса, мкм.

{{< table title="Целевой SMD для полного горения" >}}
| Вид топлива | Целевой SMD, мкм |
|---|---|
| Мазут № 2 (fuel oil No. 2) | 40–80 |
| Тяжёлый мазут № 6 (fuel oil No. 6) | 80–150 |
| Остаточные топлива (residual fuels) | 100–200 |
{{< /table >}}

### Время испарения капли

Скорость испарения подчиняется закону квадрата диаметра (d² law):

{{< formula display="true" >}}
d^2(t) = d_0^2 - k \, t
{{< /formula >}}

где $d_0$ — начальный диаметр капли, мм; $k$ — константа испарения, мм²/с; $t$ — время, с.

Полное время испарения: $t_{\text{исп}} = d_0^2 / k$.

Для мазута № 2 при 1 093 °C константа $k \approx 0{,}8$ мм²/с:
- капля 50 мкм: $t_{\text{исп}} = (0{,}05)^2 / 0{,}8 = 3{,}1$ мс
- капля 100 мкм: $t_{\text{исп}} = (0{,}10)^2 / 0{,}8 = 12{,}5$ мс

Требуемое время пребывания должно превышать $2{-}3 \times t_{\text{исп}}$, иначе горение будет неполным.

## Горелки с распылением под давлением

### Принцип работы

Топливо подаётся под давлением 690–2 070 кПа. В форсунке (нефтяной форсунке высокого давления) поток входит тангенциально в вихревую камеру, приобретает вращательную скорость и выходит через калиброванное отверстие со скоростью 46–91 м/с. Центробежная сила формирует полый конус аэрозоля; нестабильность поверхностного натяжения разрушает плёнку на капли. Типичный угол конуса 30–90°.

### Расход через форсунку

{{< formula display="true" >}}
\dot{m} = C_d \, A \sqrt{2 \rho \, \Delta P}
{{< /formula >}}

где $C_d = 0{,}75{-}0{,}85$ — коэффициент расхода; $A$ — площадь отверстия, м²; $\rho$ — плотность топлива, кг/м³; $\Delta P$ — перепад давления, Па.

Производительность форсунки масштабируется с давлением по корню квадратному:

{{< formula display="true" >}}
\dot{V}_2 = \dot{V}_1 \times \sqrt{\frac{P_2}{P_1}}
{{< /formula >}}

**Пример.** Форсунка 3,8 л/ч при 690 кПа при повышении давления до 1 035 кПа:

$$\dot{V}_{1035} = 3{,}8 \times \sqrt{\frac{1\,035}{690}} = 4{,}64\,\text{л/ч}$$

### SMD при распылении под давлением

Эмпирическая корреляция:

{{< formula display="true" >}}
d_{32} = 3{,}68 \times \frac{\sigma^{0{,}6} \, \dot{m}^{0{,}25}}{\rho_a^{0{,}25} \, \Delta P^{0{,}4}}
{{< /formula >}}

где $\sigma$ — поверхностное натяжение (дин/см); $\rho_a$ — плотность воздуха, г/см³; $\Delta P$ — перепад давления, бар.

SMD уменьшается с ростом давления по закону $d_{32} \propto \Delta P^{-0{,}4}$. Увеличение давления в 2 раза снижает SMD на ~24 %; увеличение расхода при постоянном давлении незначительно увеличивает SMD.

### Подбор размера форсунки

Требуемый расход форсунки:

{{< formula display="true" >}}
\dot{V}\,[\text{л/ч}] = \frac{Q_{\text{вых}}\,[\text{кВт}]}{HHV\,[\text{МДж/л}] \times \eta_{\text{горения}} \times 277{,}8}
{{< /formula >}}

Для мазута № 2 ($HHV = 46{,}4$ МДж/л, $\eta = 0{,}82$):

$$\dot{V} = \frac{Q\,[\text{кВт}]}{10\,630}$$

**Пример.** Требуемая мощность 1 465 кВт:

$$\dot{V} = \frac{1\,465 \times 3{,}6}{46{,}4 \times 0{,}82} = 13{,}8\,\text{л/ч}$$

Выбирают форсунку ближайшего большего стандартного размера — 14 л/ч.

## Ротационные чашечные горелки

### Принцип работы

Жидкое топливо подаётся в центр вращающейся чашки (rotary cup burner). Центробежная сила разгоняет плёнку масла к ободу (скорость обода 30–91 м/с при 1 500–6 000 об/мин). У обода плёнка дробится аэродинамическими силами первичного воздуха, подаваемого со скоростью 30–61 м/с. Механическая энергия вращения заменяет гидравлическое давление, что позволяет работать при давлении подачи топлива всего 34–345 кПа против 690–2 070 кПа у форсунок высокого давления.

### SMD при ротационном распылении

{{< formula display="true" >}}
d_{32} = 2{,}9 \,\sigma^{0{,}6} \left(\frac{\dot{m}}{\rho_a V_{\text{отн}}}\right)^{0{,}4} + 0{,}068 \left(\frac{\mu_l^2}{\rho_l \sigma}\right)^{0{,}25} D_{\text{чаши}}
{{< /formula >}}

где $V_{\text{отн}}$ — относительная скорость масла и воздуха, м/с; $\mu_l$ — динамическая вязкость масла, мПа·с; $D_{\text{чаши}}$ — диаметр чаши, см.

Более высокие обороты дают более тонкое распыление. SMD: 40–100 мкм для мазута № 2, 80–150 мкм для мазута № 6.

### Система воздухоснабжения

**Первичный воздух** (primary air): 20–40 % от суммарного, давление 50–250 Па, подаётся кольцеобразно вокруг чаши для аэродинамического дробления плёнки.

**Вторичный воздух** (secondary air): 60–80 % от суммарного, регулируется шиберами для управления соотношением воздух/топливо.

### Характеристики ротационных горелок

Коэффициент модуляции 4:1–8:1 достигается изменением давления подачи топлива при постоянных оборотах чаши и модуляцией воздушных шиберов. КПД горения 82–87 %, температура в дымоходе 149–232 °C. Применения: коммерческие котлы 3–28 МВт, промышленные печи 14–140 МВт.

## Горелки с воздушным распылением

### Принцип работы

В горелках с воздушным распылением (air-atomizing burners) топливо подаётся при низком давлении (34–207 кПа), а распыливающий воздух под давлением 207–690 кПа с высокой скоростью (122–244 м/с) дробит поток топлива. При внутреннем смешивании (internal mixing) воздух и топливо встречаются внутри корпуса форсунки; при внешнем смешивании (external mixing) — на выходе. Конфигурация Y-jet предусматривает отдельные каналы воздуха и топлива с боковым впуском воздушных струй.

Соотношение масс распыливающего воздуха к топливу (ALR, air-to-liquid ratio):

{{< formula display="true" >}}
ALR = \frac{\dot{m}_{\text{возд,распыл}}}{\dot{m}_{\text{топливо}}} = 0{,}05{-}0{,}30
{{< /formula >}}

Типовое значение — 0,10–0,15 кг воздуха на кг масла.

### SMD при воздушном распылении

{{< formula display="true" >}}
d_{32} = k \left(\frac{\sigma}{\rho_a V_{\text{отн}}^2}\right)^{0{,}5} \left(1 + \frac{1}{ALR}\right)
{{< /formula >}}

SMD уменьшается с ростом ALR и скорости воздуха. Типовые значения: 20–60 мкм — наилучшее распыление среди рассматриваемых типов горелок.

Коэффициент модуляции горелок с воздушным распылением достигает 10:1–20:1, поскольку оба параметра — давление топлива и давление распыливающего воздуха — могут регулироваться независимо. КПД горения 83–88 %.

## Горелки с паровым распылением

### Принцип работы

Паровое распыление применяется для тяжёлых остаточных масел (мазут № 5, № 6), которые необходимо предварительно подогревать до 82–121 °C для снижения вязкости. Пар под давлением 414–1 035 кПа дробит плёнку предварительно нагретого масла на капли за счёт передачи импульса. Потребление пара: 3–10 % от тепловой мощности горелки.

SMD для парового распыления: 50–150 мкм — крупнее, чем при воздушном распылении, но достаточно для тяжёлых топлив.

## Контроль горения и настройка

Правильная настройка масляной горелки требует анализа дымовых газов. Ключевые показатели:

- **CO₂**: 10–13 % по объёму при оптимальном горении;
- **O₂**: 2–5 % при избытке воздуха 10–25 % для коммерческих горелок;
- **CO**: < 100 ppm;
- **Число Бахараха (Bacharach smoke number)**: 0–1 для горелок на мазуте № 2 при нормальной эксплуатации.

Измерение КПД горения методом дымовых газов по ASHRAE Handbook:

{{< formula display="true" >}}
\eta_{\text{горения}} = 1 - \frac{Q_{\text{потери, дымоход}}}{Q_{\text{вход, топливо}}}
{{< /formula >}}

Потери в дымоходе:

{{< formula display="true" >}}
q_2 = \frac{(T_{\text{дымоход}} - T_{\text{воздух}}) \times (0{,}68 \times CO_2\,[\%] + \text{нмоль}) }{100}
{{< /formula >}}

Практически КПД горения определяют портативным анализатором дымовых газов, измеряющим O₂ или CO₂ и температуру дымохода.
