## Обзор требований к хранению

Хранение моркови требует точного контроля окружающей среды для поддержания качества в течение длительных периодов хранения. Основная проблема заключается в достижении высокого уровня относительной влажности при поддержании температуры вблизи точки замерзания без образования льда на продукте.

### Критические параметры хранения

| Параметр | Требование | Допуск |
|-----------|-------------|--------|
| Температура хранения | 0°C | ±0,5°C |
| Относительная влажность | 98-100% | -2% |
| Скорость воздуха над продуктом | 15-30 м/мин | ±5 м/мин |
| Продолжительность хранения (топированная) | 6-9 месяцев | Зависит от качества |
| Скорость дыхания при 0°C | 12-16 мг CO₂/кг·ч | Зависит от продукта |
| Чувствительность к этилену | Низкая | <10 мг/л |

### Критичность температурного режима

Морковь требует хранения при 0°C для минимизации дыхания, предотвращения прорастания и продления срока хранения. Отклонение температуры выше 2°C значительно повышает скорость дыхания и потерю влаги. Связь описывается следующим образом:

**Зависимость скорости дыхания от температуры:**

```
RR = RR₀ × Q₁₀^((T-T₀)/10)
```

Где:
- RR = Скорость дыхания при температуре T (мг CO₂/кг·ч)
- RR₀ = Базовая скорость дыхания при эталонной температуре T₀
- Q₁₀ = Температурный коэффициент (обычно 2,5-3,0 для моркови)
- T = Температура хранения (°C)
- T₀ = Эталонная температура (0°C)

При 0°C: 12-16 мг CO₂/кг·ч
При 5°C: 30-48 мг CO₂/кг·ч
При 10°C: 75-144 мг CO₂/кг·ч

## Операции предварительного охлаждения

### Системы гидроохлаждения

Гидроохлаждение обеспечивает быстрое охлаждение полевой моркови, снижая температуру продукта с 25-30°C до 2-4°C в течение 10-15 минут.

**Удаление тепла при гидроохлаждении:**

```
Q_hydro = m × c_p × ΔT / t_cool
```

Где:
- Q_hydro = Требуемая холодопроизводительность (кВ)
- m = Массовый расход продукта (кг/с)
- c_p = Удельная теплоемкость моркови (3,85 кДж/кг·К)
- ΔT = Температурный перепад (К)
- t_cool = Время охлаждения (с)

**Пример расчета:**

Для пропускной способности 5000 кг/ч:
- m = 5000 кг/ч = 1,39 кг/с
- ΔT = 25°C - 2°C = 23 К
- c_p = 3,85 кДж/кг·К

```
Q_hydro = 1,39 × 3,85 × 23 = 123 кВ
```

Добавить 30% на неэффективность системы:
**Общая холодопроизводительность = 160 кВ**

### Параметры конструкции гидроохладителя

| Параметр | Спецификация | Основание проектирования |
|-----------|---------------|--------------------------|
| Температура воды | 0-1°C | Поддерживается охлаждением |
| Расход воды | 15-25 л/мин на тонну продукта | Турбулентный контакт |
| Время контакта | 10-15 минут | Охлаждение ядра до 2-4°C |
| Скорость воды | 0,3-0,6 м/с | Поверхностная передача тепла |
| Концентрация хлора | 50-100 мг/л | Санитария |
| Коэффициент передачи тепла | 500-800 Вт/м²·К | Вода-продукт |

### Система охлаждения воды

Холодопроизводительность для охлаждения воды гидроохладителя:

```
Q_chill = m_water × c_p,water × ΔT_water + Q_product + Q_external
```

Где:
- m_water = Скорость циркуляции (кг/с)
- c_p,water = 4,18 кДж/кг·К
- ΔT_water = Повышение температуры через зону продукта (2-4 К)
- Q_product = Удаление тепла из продукта
- Q_external = Приток тепла из окружающей среды и тепло насоса

## Долгосрочное холодное хранение

### Конструкция помещения для хранения

**Требования к конструкции помещения:**

| Компонент | Спецификация | Цель |
|-----------|--------------|------|
| Толщина теплоизоляции | 150-200 мм полиуретана | Значение R 8-11 м²·К/Вт |
| Пароизоляция | Внешняя, герметичная | Предотвращение инфильтрации влаги |
| Теплоизоляция пола | 200-250 мм | Предотвращение поступления тепла из грунта |
| Герметичность воздуха | <0,5 ACH @ 50 Па | Минимизация инфильтрации |
| Тип двери | Изолированные двери холодильного хранилища | Минимизация поступления тепла |

### Системы контроля влажности

Достижение 98-100% ОВ требует специального оборудования:

**Переохлаждающие катушки высокой влажности:**

- Увеличенная площадь испарителя (в 3-4 раза больше стандартной)
- Температурный перепад катушки: максимум 2-3 К
- Расстояние между ребрами: 8-12 мм (больше стандартного)
- Электрическое или горячее газовое оттаивание (минимизация цикла)
- Обогреватели поддона: 100-150 Вт/м длины

**Расчет управления влажностью:**

Психрометрические свойства при условиях хранения:
- Сухой термометр: 0°C
- Относительная влажность: 99%
- Точка росы: -0,15°C
- Влагосодержание: 3,78 г/кг сухого воздуха
- Энтальпия: 9,56 кДж/кг сухого воздуха

**Температура поверхности катушки:**

Для поддержания 99% ОВ при 0°C с перепадом 2 К:
```
T_coil = T_db - TD = 0°C - 2°C = -2°C
```

Соответствующая ОВ поверхности катушки при -2°C = 99% при условиях в помещении.

### Системы увлажнения

Когда осушение охлаждением неизбежно, может потребоваться дополнительное увлажнение:

**Ультразвуковые увлажнители:**
- Производительность: 5-10 кг/ч на 100 м² площади пола
- Размер капель: 1-5 мкм
- Потребление электроэнергии: 0,15-0,25 кВ на кг/ч
- Качество воды: обратный осмос или деионизированная

**Центробежные распылители:**
- Производительность: 10-50 кг/ч на единицу
- Размер капель: 5-15 мкм
- Сжатый воздух: 5-7 бар
- Распределение: монтаж в воздуховод или в вентиляционные установки

## Расчеты холодильной нагрузки

### Общие компоненты холодильной нагрузки

**1. Нагрузка продукта (начальное охлаждение):**

Если продукт хранится в теплом состоянии:
```
Q_product,initial = m_product × c_p × (T_initial - T_storage) / t_pulldown
```

**2. Тепло дыхания продукта:**

```
Q_respiration = m_stored × RR × H_combustion / 3600
```

Где:
- m_stored = Общая хранящаяся масса (кг)
- RR = Скорость дыхания (мг CO₂/кг·ч)
- H_combustion = 16,7 кДж/г произведенного CO₂

Для 500 000 кг хранящейся моркови при 0°C:
```
Q_respiration = 500 000 × 0,014 × 16,7 / 3600 = 32,5 кВ
```

**3. Передача тепла через оболочку:**

```
Q_transmission = U × A × (T_ambient - T_storage)
```

Для площади стена/потолок 1000 м², U = 0,15 Вт/м²·К, окружающая среда 20°C:
```
Q_transmission = 0,15 × 1000 × (20 - 0) = 3,0 кВ
```

**4. Нагрузка инфильтрации:**

```
Q_infiltration = V × ACH × ρ × (h_outside - h_inside)
```

Для помещения 5000 м³, 0,3 ACH:
```
V_infiltration = 5000 × 0,3 / 24 = 62,5 м³/ч

Q_infiltration = 62,5 × 1,2 × (35 - 9,56) / 3600 = 0,53 кВ
```

**5. Внутренние нагрузки:**

| Источник нагрузки | Поступление тепла (кВ) |
|------------------|------------------------|
| Освещение (светодиод) | 5-10 Вт/м² площади пола |
| Движение электропогрузчиков | 2,5 кВ на час работы/день |
| Персонал | 200 Вт на человека |
| Открытие дверей | 10-15% от инфильтрации |
| Вентиляторы | Номинальная мощность двигателя + 15% |

**Общая расчетная нагрузка:**

```
Q_total = Q_product + Q_respiration + Q_transmission + Q_infiltration + Q_internal + Safety_factor

Q_total = 32,5 + 3,0 + 0,53 + 5,0 + 3,0 = 44 кВ

С коэффициентом безопасности 15%: 44 × 1,15 = 50,6 кВ
```

### Выбор холодильной системы

**Выбор испарителя:**

- Холодопроизводительность: 50,6 кВ при -2°C SST, 0°C в помещении
- Температурный перепад катушки: максимум 2 К
- Общая площадь поверхности: 250-300 м² (требование низкого перепада)
- Конфигурация вентилятора: 4-6 вентиляторов, двигатели EC
- Дальность выброса: 20-30 м
- Оттаивание: электрическое, 4 раза в день, 30 минут

**Выбор компрессора:**

Для системы R-404A:
- Температура испарения: -5°C
- Температура конденсации: 35°C (воздушное охлаждение)
- Требуемая холодопроизводительность: 50,6 кВ × 1,1 (потери) = 55,7 кВ
- Мощность компрессора: ~18 кВ
- Несколько компрессоров для регулирования мощности

## Распределение воздуха

### Требования по циркуляции

Надлежащая циркуляция воздуха предотвращает расслоение температуры и обеспечивает равномерное распределение влажности.

**Кратность воздухообмена:**

```
ACH = (60 × Q_evap) / (V_room × ρ_air × c_p,air × ΔT_acceptable)
```

Для равномерного распределения с максимальным перепадом 0,5°C:
```
ACH = (60 × 50,6) / (5000 × 1,2 × 1,006 × 0,5) = 1,00 объем помещения/час
```

**Скорость воздуха над продуктом:**

- Массовое хранение: 15-30 м/мин (0,25-0,50 м/с)
- Хранение в ящиках: 20-40 м/мин через ящики
- Слишком высокая: избыточная потеря влаги
- Слишком низкая: расслоение и горячие точки

### Размещение испарителя и воздушный поток

**Горизонтальный паттерн воздушного потока:**

Предпочтительно для помещений массового хранения:
- Испарители установлены на торцовой стене
- Воздухоотвод горизонтален поперек продукта
- Возвратный воздух с противоположного конца
- Высота потолка: 6-8 м
- Дальность выброса: 25-35 м

**Распределение воздушного потока:**

| Зона | Скорость воздуха (м/мин) | Цель |
|------|--------------------------|------|
| Выброс из катушки | 150-250 | Начальный импульс |
| Середина помещения (уровень продукта) | 20-40 | Охлаждение поверхности |
| Зона возвратного воздуха | 50-100 | Сбор |
| Скорость перед катушкой | 120-180 | Передача тепла |

## Поддержание качества

### Предотвращение горечи

Развитие горьковатого вкуса результат стресс-индуцированных фенольных соединений и неправильного хранения:

**Стратегии предотвращения:**

1. **Быстрое охлаждение:** В течение 6-8 часов после уборки
2. **Стабильность температуры:** Максимальное отклонение ±0,5°C
3. **Исключение этилена:** <5 мг/л в атмосфере хранения
4. **Минимизация механических повреждений:** Аккуратная обработка
5. **Оптимальная зрелость при уборке:** Избегать перезревшей моркови

**Условия, вызывающие горечь:**

| Условие | Пороговое значение | Эффект |
|---------|-------------------|--------|
| Температура >4°C | Длительное воздействие | Синтез фенолов |
| Воздействие этилена | >10 мг/л | Стрессовый ответ |
| Низкая влажность <95% | Обезвоживание поверхности | Образование изокумарина |
| Физическое повреждение | Ушибы, порезы | Соединения раневого ответа |
| Повреждение от замерзания | Ниже -1°C ткань | Повреждение клеток, посторонние вкусы |

### Предотвращение белого налета

Белый налет (обезвоживание поверхности) возникает при потере влаги поверхностными клетками и их помутнении.

**Меры контроля:**

1. **Поддержание 98-100% ОВ:** Основной контроль
2. **Минимизация колебаний скорости воздуха:** Равномерная циркуляция
3. **Пленочная упаковка:** Индивидуальная или оптовая упаковка в пакеты
4. **Верхний лед:** Для оптовых ящиков (дополнительная влага)
5. **Минимизация циклирования температуры:** Стабильная холодовая цепь

**Расчет потери влаги:**

```
ML = k × A × (p_sat - p_actual) × t
```

Где:
- ML = Потеря влаги (кг)
- k = Коэффициент передачи массы (кг/м²·Па·ч)
- A = Площадь поверхности (м²)
- p_sat = Давление насыщенного пара на поверхности продукта (Па)
- p_actual = Давление пара воздуха (Па)
- t = Время (ч)

При 0°C, 98% ОВ по сравнению со 100% ОВ:
- p_sat = 611 Па
- p_actual,98% = 598 Па
- Δp = 13 Па (vs 0 Па при 100% ОВ)

Этот небольшой дефицит давления пара приводит к образованию белого налета.

### Предотвращение прорастания

Развитие проростков требует контроля температуры:

- Хранение при 0°C: Минимальное прорастание в течение 6-9 месяцев
- 2-4°C: Прорастание начинается через 3-4 месяца
- >5°C: Быстрое инициирование прорастания

**Метаболический покой:**

Поддерживается низкой температурой, подавляющей активность меристемы. Одобренные на большинстве рынков химические ингибиторы прорастания для моркови отсутствуют.

## Упаковка и обращение

### Пленочная упаковка

Перфорированная полиэтиленовая пленка создает модифицированную атмосферу:

**Спецификации пленки:**

| Параметр | Значение | Цель |
|-----------|---------|------|
| Толщина | 25-50 мкм | Удержание влаги |
| Перфорация | 0,5-2% площади | Газообмен |
| Материал | LDPE или LLDPE | Гибкость при 0°C |
| Передача O₂ | 5000-8000 см³/м²·день | Поддержка дыхания |
| Передача CO₂ | 25 000-40 000 см³/м²·день | Предотвращение накопления |

**Развитие модифицированной атмосферы:**

Внутри герметичных мешков в равновесии:
- O₂: 1-5%
- CO₂: 5-10%
- Баланс: N₂

Это снижает скорость дыхания на дополнительные 20-30%.

### Хранение в ящиках и верхний лед

**Конфигурация ящика:**

- Вместимость ящика: 400-600 кг
- Размеры: 1,2 × 1,0 × 0,9 м
- Высота штабеля: 3-5 ящиков (с адекватной грузоподъемностью пола)
- Основание поддона: вентилируемое для воздушного потока

**Верхний лед:**

Измельченный лед, нанесенный на верхнюю поверхность ящиков:

- Норма внесения льда: 5-10 кг на ящик
- Размер частиц льда: 5-15 мм
- Частота: еженедельно или при необходимости
- Цель: дополнительная влажность, небольшое охлаждение
- Управление стоком: требуются напольные сливы

**Нагрузка от таяния льда:**

```
Q_ice = m_ice × H_fusion / t_melt
```

Для скорости таяния льда 50 кг/час:
```
Q_ice = 50 × 334 / 3600 = 4,6 кВ
```

Это добавляет к холодильной нагрузке, но обеспечивает отличный контроль влажности.

## Производство молодой моркови

### Требования помещения обработки

Производство молодой моркови требует отдельных помещений обработки с различным контролем окружающей среды.

**Условия в помещении обработки:**

| Параметр | Спецификация |
|-----------|-------------|
| Температура | 4-10°C |
| Относительная влажность | 85-95% |
| Воздухообмены | 10-15 ACH (вентиляция) |
| Создание давления в помещении | Положительное (+10 Па) |
| Уровень санитарии | Качество пищевой обработки |

### Система промывки хлором

**Спецификации промывочной воды:**

- Концентрация хлора: 50-150 мг/л (поддерживается)
- pH: 6,5-7,5
- Температура воды: 2-4°C
- Время контакта: 1-2 минуты
- ORP (окислительно-восстановительный потенциал): 650-750 мВ

**Охлаждение промывочной воды:**

Для производства 20 000 кг/день:

```
Q_wash = m_water × c_p × (T_initial - T_target) + Q_product_cooling
```

Если температура воды повышается на 3°C за проход:
```
Q_wash = 5 кг/с × 4,18 × 3 = 62,7 кВ
```

Плюс охлаждение продукта: ~40 кВ
**Итого: 102,7 кВ холодопроизводительность**

### Операции очистки и нарезания

**Абразивная очистка:**

- Оборудование: Роторные машины для очистки
- Абразивный материал: Барабаны с карбидным покрытием
- Водяной спрей: Непрерывное ополаскивание
- Генерация тепла: 10-15 кВ на линию
- Поток отходов: 20-30% от входного количества

**Нарезание и формирование:**

- Оборудование: Промышленные ножи/формовочные машины
- Целевой размер: 5-8 см длина, 8-10 мм диаметр
- Выход: 70-80% от полноразмерной моркови
- Генерация тепла: 5-10 кВ на линию

### Хранение молодой моркови

**Параметры хранения:**

| Параметр | Требование |
|-----------|-----------|
| Температура | 0-4°C |
| Относительная влажность | 95-98% |
| Максимальное хранение | 30 дней |
| Упаковка | Герметичные пакеты, MAP |
| Уровень O₂ | 3-5% |
| Уровень CO₂ | 5-8% |

Молодая морковь имеет большую площадь поверхности и более скоропортящаяся, чем целая морковь, требуя более строгого контроля.

## Системы мониторинга и управления

### Мониторинг температуры

**Размещение датчиков:**

- Температура ядра продукта: Беспроводные зонды в нескольких ящиках
- Температура воздуха: Возвратный воздух (контрольная точка)
- Воздух на выходе: Проверка производительности
- Поверхность катушки: Управление оттаиванием
- Окружающая среда: Справочное измерение

**Логирование данных:**

- Интервал записи: 5-15 минут
- Пороги тревоги: ±1°C от установки
- Исторические тренды: Минимум 1 год хранения
- Удаленный доступ: Веб-мониторинг

### Мониторинг влажности

**Тип датчика:**

- Емкостные датчики ОВ (предпочтительно для высокой влажности)
- Точность: ±2% ОВ в диапазоне 98-100%
- Размещение: Возвратный воздух, уровень продукта
- Калибровка: Ежемесячная проверка по эталону

**Логика управления влажностью:**

```
IF RH < 98% AND coil_operating THEN
    Increase_coil_TD (reduce compressor capacity)
    OR
    Activate_humidifier
END IF

IF RH > 100% (condensation observed) THEN
    Reduce_coil_TD (increase cooling)
    Increase_air_circulation
END IF
```

### Автоматическое управление оттаиванием

**Инициирование оттаивания:**

- На основе времени: каждые 6-8 часов
- На основе спроса: пороговое давление дифференциала катушки
- Продолжительность: максимум 20-30 минут
- Завершение: датчик катушки при 8-12°C

**Нагрузка от оттаивания:**

```
Q_defrost = P_heater × t_defrost × n_cycles × n_coils / 24
```

Для нагревателей 15 кВ, оттаивание 30 мин, 4 цикла/день, 2 катушки:
```
Q_defrost,avg = 15 × 0,5 × 4 × 2 / 24 = 2,5 кВ средняя
```

Эта постоянная нагрузка должна быть включена в холодопроизводительность.

## Экономические соображения

### Анализ стоимости хранения

**Операционные затраты (на кг хранящегося продукта):**

| Компонент затрат | Значение |
|------------------|---------|
| Электроэнергия (охлаждение) | 0,008-0,012 $/кг |
| Труд (погрузка, мониторинг) | 0,003-0,006 $/кг |
| Материалы упаковки | 0,015-0,025 $/кг |
| Техническое обслуживание | 0,002-0,004 $/кг |
| Потери продукта (2-5%) | 0,010-0,025 $/кг |
| **Итого** | **0,038-0,072 $/кг** |

### Меры по повышению энергоэффективности

**Оптимизация системы:**

1. **Компрессоры переменной производительности:** Снижение энергии на 20-30%
2. **Двигатели вентиляторов EC:** Снижение энергии вентиляторов на 40-50%
3. **Рекуперация тепла:** Горячее водоснабжение, обогрев здания
4. **Плавающее давление конденсации:** Снижение энергии компрессора на 10-15%
5. **Светодиодное освещение:** Снижение энергии на 60-70%
6. **Автоматические закрыватели дверей:** Снижение инфильтрации на 30-40%

**Коэффициент производительности:**

```
COP = Q_evap / W_compressor
```

При испарении -5°C, конденсация 35°C (R-404A):
```
COP = 2,2 - 2,5
```

С оптимизированной системой (плавающее давление, переменная скорость):
```
COP_optimized = 2,8 - 3,2 (улучшение на 25-30%)
```

## Безопасность и санитария

### Требования пищевой безопасности

**Критические контрольные точки HACCP:**

1. **Температура предварительного охлаждения:** Критический предел <4°C в течение 8 часов
2. **Температура хранения:** Критический предел 0±1°C непрерывно
3. **Концентрация хлора:** Критический предел 50-150 мг/л поддерживается
4. **Предотвращение перекрестного загрязнения:** Физическое разделение, санитария
5. **Отслеживаемость:** Кодирование партии, дата уборки

### Безопасность хладагента

**Аммиачные системы (при необходимости):**

- Обнаружение утечки: Сигнал при 25 мг/л, эвакуация при 150 мг/л
- Аварийная вентиляция: Производительность 30 ACH
- Средства индивидуальной защиты: SCBA, планы эвакуации
- Сброс давления: На безопасное место выброса

**Системы HFC/HFO:**

- Низкая токсичность, но требуют обнаружения утечки
- Адекватная вентиляция для плотности хладагента
- Мониторинг вытеснения O₂ в помещениях машин
