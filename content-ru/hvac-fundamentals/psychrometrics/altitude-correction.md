Барометрическое давление существенно снижается с высотой над уровнем моря, изменяя все психрометрические соотношения. Проектирование HVAC-систем для объектов на высоте более 300 м требует применения скорректированных психрометрических диаграмм и расчётных алгоритмов. Пренебрежение поправками на высоту приводит к ошибкам в расчёте нагрузок и неправильному выбору оборудования.

## Барометрическое давление и высота

### Уравнение стандартной атмосферы

{{< formula display="true" >}}
p = 101{,}325 \cdot \left(1 - 2{,}25577 \times 10^{-5} \cdot z\right)^{5{,}2559}\quad[\text{кПа},\; z\text{ в м}]
{{< /formula >}}

Альтернативная экспоненциальная аппроксимация (точность ±1 % при z < 3000 м):

{{< formula display="true" >}}
p \approx 101{,}325 \cdot \exp(-0{,}0001184 \cdot z)
{{< /formula >}}

## Влияние высоты на психрометрические свойства

### Коэффициент влажности при насыщении

При снижении давления W_s увеличивается при той же температуре:

{{< formula display="true" >}}
W_s(t, p) = \frac{0{,}6220 \cdot p_{ws}(t)}{p - p_{ws}(t)}
{{< /formula >}}

Так как p_ws(t) не зависит от давления (определяется только температурой), снижение p в знаменателе увеличивает W_s.

{{< table title="W_s при 21°C на различных высотах" >}}
| Высота, м | p, кПа | W_s(21°C), г/кг | Рост W_s |
|---|---|---|---|
| 0 | 101,325 | 15,73 | — |
| 500 | 95,46 | 16,78 | +6,7 % |
| 1000 | 89,88 | 17,94 | +14,1 % |
| 1500 | 84,55 | 19,22 | +22,2 % |
| 2000 | 79,50 | 20,67 | +31,4 % |
| 2500 | 74,68 | 22,33 | +41,9 % |
{{< /table >}}

### Относительная влажность

Для воздуха с неизменным W и t при снижении давления:

{{< formula display="true" >}}
\varphi(p_2) = \frac{W \cdot p_2}{p_{ws}(t) \cdot (0{,}6220 + W)}
{{< /formula >}}

Пример: воздух с W = 12 г/кг при t = 25 °C:
- На уровне моря: φ = 12 × 101,325 / (3,169 × 632,2) = **60,7 %**
- На высоте 2000 м: φ = 12 × 79,495 / (3,169 × 632,2) = **47,6 %**

При одинаковом абсолютном влагосодержании на высоте воздух «суше» по ОВ.

### Удельный объём

{{< formula display="true" >}}
v(p, T, W) = \frac{0{,}287042 \cdot T \cdot (1 + 1{,}6078 \cdot W)}{p}
{{< /formula >}}

При той же температуре и W: v обратно пропорционален p.

{{< formula display="true" >}}
\frac{v_{\text{высота}}}{v_{\text{уровень моря}}} = \frac{p_0}{p_{\text{высота}}}
{{< /formula >}}

На высоте 2000 м (p = 79,5 кПа): v возрастает в 101,325/79,495 = **1,275 раза** при тех же t и W.

### Плотность воздуха

{{< formula display="true" >}}
\rho = \frac{1 + W}{v} \approx \frac{p}{R_a T}
{{< /formula >}}

{{< table title="Плотность воздуха на различных высотах (t=20°C, φ=50%)" >}}
| Высота, м | p, кПа | v, м³/кг | ρ, кг/м³ |
|---|---|---|---|
| 0 | 101,325 | 0,841 | 1,200 |
| 500 | 95,46 | 0,893 | 1,131 |
| 1000 | 89,88 | 0,948 | 1,065 |
| 1500 | 84,55 | 1,008 | 1,000 |
| 2000 | 79,50 | 1,071 | 0,940 |
| 2500 | 74,68 | 1,141 | 0,883 |
{{< /table >}}

## Влияние высоты на оборудование HVAC

### Вентиляторы

Вентиляторы — объёмные машины: при данном объёмном расходе производительность по массе воздуха снижается пропорционально плотности.

**Поправочный коэффициент на высоту для вентиляторов:**

{{< formula display="true" >}}
k_{\text{выс}} = \frac{\rho_{\text{высота}}}{\rho_0} = \frac{p_{\text{высота}}}{p_0}
{{< /formula >}}

{{< formula display="true" >}}
\dot{m}_{a,\text{факт}} = k_{\text{выс}} \cdot \dot{m}_{a,0}
{{< /formula >}}

При неизменном объёмном расходе {{< formula >}}\dot{V}{{< /formula >}} на высоте 2000 м:
- Массовый расход: 0,940/1,200 = **78 % от уровня моря**
- Для поддержания того же массового расхода нужно увеличить {{< formula >}}\dot{V}{{< /formula >}} в 1/0,78 = 1,28 раза

**Потребляемая мощность электродвигателя вентилятора:**

{{< formula display="true" >}}
N_{\text{выс}} = N_0 \cdot k_{\text{выс}}
{{< /formula >}}

При заданном статическом давлении (Па) мощность снижается пропорционально плотности.

### Охлаждающие секции

Мощность охлаждения охлаждающей секции определяется через энтальпийную разницу:

{{< formula display="true" >}}
Q_{\text{total}} = \dot{m}_a \cdot (h_1 - h_2)
{{< /formula >}}

При снижении плотности {{< formula >}}\dot{m}_a{{< /formula >}} падает при фиксированном {{< formula >}}\dot{V}{{< /formula >}}, а значит, и мощность охлаждения снижается.

**Коэффициент мощности охлаждения:**

{{< formula display="true" >}}
\frac{Q_{\text{выс}}}{Q_0} = \frac{\dot{m}_{a,\text{выс}}}{\dot{m}_{a,0}} = k_{\text{выс}}
{{< /formula >}}

### Испарительное охлаждение на высоте

На высоте потенциал прямого испарительного охлаждения выше:

{{< formula display="true" >}}
\Delta t_{\text{макс}} = t_{db} - t_{wb}
{{< /formula >}}

При той же t_db и φ на высоте t_wb ниже (т.к. W_s выше → t_wb соответствует другой точке на диаграмме). Это делает испарительное охлаждение особенно эффективным в горных районах.

## Расчёт с поправкой на высоту: полный пример

**Объект:** торговый центр в Алма-Ате (высота ~820 м, p ≈ 92 кПа)

**Задание:** рассчитать мощность охлаждающей секции для летнего режима.

**Климатические данные (ТРY для Алматы):**
- t_db,расч = 32 °C, t_wb,расч = 21 °C (расчётные условия 0,4 %)
- p = 92,0 кПа (по уравнению стандартной атмосферы для z = 820 м)

**Свойства наружного воздуха:**

{{< formula display="true" >}}
W_{OA} = \frac{0{,}622 \cdot p_{ws}(21°C)}{p - p_{ws}(21°C)} = \frac{0{,}622 \times 2{,}487}{92{,}0 - 2{,}487} = \frac{1{,}547}{89{,}513} = \mathbf{17{,}28\;\text{г/кг}}
{{< /formula >}}

Для сравнения: на уровне моря W_OA при t_wb = 21 °C было бы 15,73 г/кг → **на 9,8 % выше**.

{{< formula display="true" >}}
h_{OA} = 1{,}006 \times 32 + 0{,}01728 \times (2501 + 1{,}86 \times 32) = 32{,}19 + 44{,}16 = \mathbf{76{,}35\;\text{кДж/кг}}
{{< /formula >}}

{{< formula display="true" >}}
v_{OA} = \frac{0{,}287042 \times 305{,}15 \times (1 + 1{,}6078 \times 0{,}01728)}{92{,}0} = \frac{90{,}29}{92{,}0} = \mathbf{0{,}981\;\text{м}^3/\text{кг}}
{{< /formula >}}

**Сравнение с расчётом на уровне моря (при тех же t_db, φ):**

На уровне моря при тех же метеоусловиях: v₀ = 0,892 м³/кг → на высоте v на **10 % больше**.

{{< formula display="true" >}}
\frac{\dot{m}_{a,\text{Алматы}}}{\dot{m}_{a,\text{уровень моря}}} = \frac{v_0}{v_{\text{Алматы}}} = \frac{0{,}892}{0{,}981} = \mathbf{0{,}909}
{{< /formula >}}

При фиксированном расходе вентилятора 20 000 м³/ч:

{{< formula display="true" >}}
\dot{m}_{a,\text{Алматы}} = \frac{20\,000}{3600 \times 0{,}981} = 5{,}67\;\text{кг/с}
{{< /formula >}}

**Мощность охлаждения:**

При тех же параметрах входа и выхода (условия помещения не меняются):

{{< formula display="true" >}}
Q_{\text{total}} = 5{,}67 \times (76{,}35 - 34{,}87) = 5{,}67 \times 41{,}48 = \mathbf{235{,}2\;\text{кВт}}
{{< /formula >}}

Для сравнения, на уровне моря при том же расходе: Q = 6,24 × 41,48 = **259 кВт** → разница 10 %.

## Практические рекомендации

1. При z > 300 м применяйте высотные психрометрические диаграммы или программные инструменты с поправкой на p
2. Производительность вентиляторов указывается производителями при ρ = 1,2 кг/м³ (уровень моря, 20 °C). На высоте требуется пересчёт
3. Холодильная мощность чиллеров пересчитывается: при снижении массового расхода воздуха через конденсатор на высоте COP ухудшается (требуется увеличение поверхности конденсатора)
4. Испарительные охладители на высоте имеют **большую** эффективность, чем на уровне моря при той же OA-влажности по ОВ
