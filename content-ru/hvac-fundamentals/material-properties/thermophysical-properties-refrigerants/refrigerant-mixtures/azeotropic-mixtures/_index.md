Азеотропная смесь (azeotropic mixture) — смесь двух или более компонентов, которая при кипении и конденсации ведёт себя как однокомпонентное вещество: жидкая и паровая фазы при равновесии имеют одинаковый состав. Это устраняет температурный глайд и фракционирование, упрощая проектирование теплообменников и обслуживание системы. Азеотропные смеси применяются как замена устаревшим хладагентам (R-22, R-502) при сохранении совместимости с существующим оборудованием.

## Физические принципы азеотропии

При смешивании двух компонентов с различными давлениями насыщения суммарное давление паров смеси может отклоняться от закона Рауля (Raoult's law), который для идеального раствора даёт:

{{< formula display="true" >}}
P_{\text{смесь}} = x_1 P_1^{\text{нас}} + x_2 P_2^{\text{нас}}
{{< /formula >}}

Азеотроп возникает, когда фактическое давление паров проходит через экстремум при определённом составе. Условие азеотропии:

{{< formula display="true" >}}
\gamma_1 x_1 P_1^{\text{нас}} = y_1 P_{\text{общ}}, \quad \gamma_2 x_2 P_2^{\text{нас}} = y_2 P_{\text{общ}}
{{< /formula >}}

{{< formula display="true" >}}
\text{При азеотропе:} \quad x_i = y_i \quad \text{для всех компонентов}
{{< /formula >}}

где {{< formula >}}\gamma_i{{< /formula >}} — коэффициент активности (activity coefficient), {{< formula >}}x_i{{< /formula >}} — мольная доля в жидкости, {{< formula >}}y_i{{< /formula >}} — в паре.

**Положительный азеотроп** (positive azeotrope): суммарное давление паров выше предсказываемого законом Рауля. Пример — пара R-32/R-125. Точка кипения азеотропа ниже, чем у каждого компонента в отдельности.

**Отрицательный азеотроп** (negative azeotrope): давление паров ниже расчётного. Менее распространён в холодильной технике.

**Ключевое следствие:** при кипении или конденсации состав паровой фазы совпадает с составом жидкой. Температура перехода при постоянном давлении не меняется — **глайд равен нулю**.

## Термодинамические характеристики

В отличие от зеотропных смесей, расчёт теплообменников для азеотропных смесей ведётся по единственному значению температуры насыщения — аналогично чистому веществу. Основные термодинамические соотношения:

{{< formula display="true" >}}
Q = \dot{m}(h_g - h_f) = \dot{m} \cdot h_{fg}
{{< /formula >}}

{{< formula display="true" >}}
T_{\text{исп}} = \text{const}, \quad T_{\text{конд}} = \text{const} \quad \text{при } P = \text{const}
{{< /formula >}}

{{< formula display="true" >}}
\text{COP} = \frac{Q_e}{W_{\text{комп}}} = \frac{h_1 - h_4}{h_2 - h_1}
{{< /formula >}}

## Термодинамические свойства R-507A

R-507A (R-125/R-143a, 50/50 % мас.) — наиболее применяемая азеотропная смесь нового поколения. Точный азеотроп при нормальных условиях; при изменении давления возникает незначительный глайд (<0,1 °C), что позволяет классифицировать его как практический азеотроп.

## Численный пример — цикл на R-507A

**Условия:** испарение −10 °C, конденсация +35 °C, перегрев всасывания 5 К, переохлаждение 5 К, {{< formula >}}\eta_{is} = 0{,}80{{< /formula >}}.

По NIST REFPROP v10:

- Точка 1 (всасывание, T = −5 °C, P_исп = 558 кПа):
  {{< formula display="true" >}}h_1 = 368{,}8 \text{ кДж/кг}, \quad s_1 = 1{,}710 \text{ кДж/(кг·К)}{{< /formula >}}

- Точка 2s (изоэнтропа, P_конд = 1554 кПа, s = 1,710):
  {{< formula display="true" >}}h_{2s} = 406{,}7 \text{ кДж/кг}{{< /formula >}}

- Реальная энтальпия нагнетания:
  {{< formula display="true" >}}h_2 = h_1 + \frac{h_{2s} - h_1}{\eta_{is}} = 368{,}8 + \frac{37{,}9}{0{,}80} = 416{,}2 \text{ кДж/кг}{{< /formula >}}

- Точка 3 (переохл. жидкость, T = 30 °C, P_конд = 1554 кПа):
  {{< formula display="true" >}}h_3 = 244{,}5 - 1{,}38 \times 5 = 237{,}6 \text{ кДж/кг}{{< /formula >}}
  где {{< formula >}}c_{pl}(30\,°\text{C}) \approx 1{,}38{{< /formula >}} кДж/(кг·К).

- Точка 4 (вход испарителя): {{< formula >}}h_4 = h_3 = 237{,}6{{< /formula >}} кДж/кг.

Показатели цикла:

{{< formula display="true" >}}
q_e = h_1 - h_4 = 368{,}8 - 237{,}6 = 131{,}2 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
w_{\text{реал}} = h_2 - h_1 = 416{,}2 - 368{,}8 = 47{,}4 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
\text{COP} = \frac{131{,}2}{47{,}4} = 2{,}77
{{< /formula >}}

Паросодержание на входе в испаритель:

{{< formula display="true" >}}
x_4 = \frac{237{,}6 - 172{,}6}{189{,}5} = \frac{65{,}0}{189{,}5} = 0{,}343
{{< /formula >}}

## Преимущества и ограничения азеотропных смесей

**Преимущества по сравнению с зеотропами:**

- Нулевой глайд позволяет использовать стандартные методики проектирования теплообменников без учёта профиля температур.
- Стабильный состав при утечках — не требует полной замены заряда.
- Применимы стандартные диаграммы P–T для диагностики без поправок на глайд.
- Допустима доливка без полной дозаправки жидкостью.

**Ограничения:**

- R-507A имеет высокий GWP = 3985 — попадает под регулирование по EU F-Gas Regulation (Регламент ЕС 517/2014) и находится под давлением фазового вывода.
- Замена R-507A — переход на R-452A (GWP = 2140) или R-454C (GWP = 148), однако они зеотропные — возвращает проблему глайда.
- R-508A (R-23/R-116) с GWP > 12 000 находится под запретом в большинстве приложений.

## Масло холодильного цикла

R-507A несовместим с минеральным маслом. Следует применять синтетическое полиэфирное масло (POE, polyol ester) с вязкостью, рекомендованной производителем компрессора. Типовые вязкости: 32–68 сСт при 40 °C. Смешиваемость POE с R-507A обеспечивает надёжный возврат масла к компрессору при скоростях потока >0,5 м/с в вертикальных всасывающих трубопроводах.
