В системах ОВК подавляющее большинство потоков воздуха при скоростях менее 30 м/с описывается несжимаемой моделью с погрешностью менее 1 %. Однако в ряде ключевых узлов сжимаемость определяет режим работы и безопасность: расширение хладагента через терморегулирующие клапаны (ТРВ/ЭРВ), критический расход через предохранительные клапаны холодильных систем, пневматические приводы арматуры, а также высокоскоростные воздуховоды (V > 25 м/с).

## Основные параметры сжимаемого потока

Число Маха — отношение скорости потока к местной скорости звука:

{{< formula display="true" >}}
\text{Ma} = \frac{V}{a}, \quad a = \sqrt{\gamma R T}
{{< /formula >}}

где `γ` — показатель адиабаты (`γ` = 1,40 для воздуха, `γ` ≈ 1,13–1,30 для паров хладагентов), `R` — удельная газовая постоянная, `T` — абсолютная температура, К.

Скорость звука в воздухе: `a = 20,05 √T`, м/с. При T = 293 К (20 °C): a = 343 м/с. При T = 333 К (60 °C): a = 366 м/с.

**Критерий значимости сжимаемости.** Относительная погрешность несжимаемой модели при Ma = M:

{{< formula display="true" >}}
\varepsilon \approx \frac{\text{Ma}^2}{4}
{{< /formula >}}

При Ma = 0,3 (V ≈ 103 м/с при 20 °C): ε ≈ 2,3 % — допустимо для большинства расчётов. При Ma = 0,1 (V ≈ 34 м/с): ε ≈ 0,25 % — несжимаемое приближение вполне точно. Типичные скорости в воздуховодах (5–12 м/с) соответствуют Ma = 0,015–0,035: сжимаемостью можно пренебречь полностью.

## Изоэнтропийный поток

Для адиабатического течения идеального газа через сужающийся канал без трения (изоэнтропийный процесс) соотношения полных параметров:

{{< formula display="true" >}}
\frac{T_0}{T} = 1 + \frac{\gamma - 1}{2}\text{Ma}^2
{{< /formula >}}

{{< formula display="true" >}}
\frac{P_0}{P} = \left(1 + \frac{\gamma - 1}{2}\text{Ma}^2\right)^{\gamma/(\gamma-1)}
{{< /formula >}}

{{< formula display="true" >}}
\frac{\rho_0}{\rho} = \left(1 + \frac{\gamma - 1}{2}\text{Ma}^2\right)^{1/(\gamma-1)}
{{< /formula >}}

При критических условиях (горловина канала, Ma = 1):

{{< formula display="true" >}}
\frac{T^*}{T_0} = \frac{2}{\gamma + 1} = 0{,}833 \quad (\gamma = 1{,}4)
{{< /formula >}}

{{< formula display="true" >}}
\frac{P^*}{P_0} = \left(\frac{2}{\gamma + 1}\right)^{\gamma/(\gamma-1)} = 0{,}528 \quad (\gamma = 1{,}4)
{{< /formula >}}

Критическое давление P* = 0,528 · P₀. Если давление за отверстием P₂ < 0,528 · P₁ (давление до отверстия), поток **запирается** — расход не зависит от P₂ и определяется только P₁ и T₁.

## Критический расход через отверстие

Расход идеального газа через калиброванное отверстие:

{{< formula display="true" >}}
\dot{m} = \alpha \cdot A \cdot P_1 \sqrt{\frac{\gamma}{R T_1}} \cdot \left(\frac{2}{\gamma+1}\right)^{(\gamma+1)/(2(\gamma-1))}
{{< /formula >}}

при P₂/P₁ ≤ P*/P₁ (критический режим). Здесь α — коэффициент истечения (α = 0,61–0,84 в зависимости от геометрии). При P₂/P₁ > P*/P₁ (докритический режим) используется модифицированное уравнение с поправочным множителем.

Для воздуха при стандартных условиях критический режим начинается при перепаде давления:

{{< formula display="true" >}}
\Delta P / P_1 = 1 - P^*/P_1 = 1 - 0{,}528 = 0{,}472
{{< /formula >}}

То есть при перепаде > 47,2 % от абсолютного давления до отверстия. Для системы с P₁ = 200 кПа (абс.): критический режим при ΔP > 94,4 кПа.

## Хладагент в контуре охлаждения

### Дросселирование в ТРВ/ЭРВ

Расширение жидкого хладагента через терморегулирующий вентиль — изоэнтальпийный (необратимый) процесс, при котором часть жидкости мгновенно испаряется («flash gas»). Степень мгновенного испарения x₀:

{{< formula display="true" >}}
x_0 = \frac{h_{f,\text{кон}} - h_{f,\text{исп}}}{h_{fg,\text{исп}}}
{{< /formula >}}

где `h_f,кон` — энтальпия насыщенной жидкости на выходе конденсатора, `h_f,исп` и `h_fg,исп` — энтальпия насыщенной жидкости и скрытая теплота испарения при давлении испарения.

**Пример для R410A:** конденсация при T_кон = 40 °C → h_f = 271,7 кДж/кг; испарение при T_исп = 5 °C → h_f = 220,7 кДж/кг, h_fg = 214,9 кДж/кг.

{{< formula display="true" >}}
x_0 = \frac{271{,}7 - 220{,}7}{214{,}9} = \frac{51{,}0}{214{,}9} = 0{,}237 = 23{,}7\%
{{< /formula >}}

На входе в испаритель смесь содержит 23,7 % пара по массе. Это снижает эффективный расход жидкого хладагента через испаритель и увеличивает скорость паровой фазы. При расчёте диаметра жидкостного трубопровода на участке ТРВ–испаритель необходимо учитывать двухфазный поток с повышенным объёмом.

### Скорости хладагента в трубопроводах

Для предотвращения разделения фаз и обеспечения возврата масла в компрессор нормируются минимальные скорости пара:

{{< table title="Рекомендуемые скорости хладагента в трубопроводах по ASHRAE Refrigeration" >}}
| Участок | Минимум | Рекомендуется | Максимум |
|---|---|---|---|
| Нагнетательный паропровод | 5 м/с | 8–12 м/с | 18 м/с |
| Всасывающий паропровод (горизонт.) | 4 м/с | 7–10 м/с | 20 м/с |
| Всасывающий паропровод (вертик. вверх) | 7 м/с | 10–15 м/с | 20 м/с |
| Жидкостный трубопровод | — | 0,5–1,5 м/с | 3 м/с |
{{< /table >}}

Минимальная скорость пара в вертикальных восходящих участках определяется из условия подъёма масляных капель против гравитации — аэродинамического захвата. При скорости ниже 4–7 м/с масло скапливается в низких точках и не возвращается в компрессор.

## Предохранительные клапаны холодильных систем

Расчёт проходного сечения предохранительного клапана (safety relief valve) холодильной системы выполняется по EN 13136 и ASHRAE 15:

{{< formula display="true" >}}
A = \frac{\dot{m}_{\text{треб}}}{C \cdot P_s \cdot K_d} \sqrt{\frac{T_s}{M}}
{{< /formula >}}

где:
- `ṁ_треб` — требуемая производительность клапана (кг/с), определяемая из расчёта теплопритока при пожаре или неисправности
- `C` — безразмерная функция от γ хладагента
- `P_s` — давление настройки (Pa абс.)
- `K_d` — коэффициент эффективного истечения (обычно 0,80–0,90 для сертифицированных клапанов)
- `T_s` — температура пара при давлении P_s (К)
- `M` — молярная масса хладагента (кг/кмоль)

**Пример для R410A:** для сосуда с хладагентом объёмом 150 л. P_s = 4,15 МПа (абс.) — давление настройки по EN 378 для R410A; γ = 1,17; M = 72,6 кг/кмоль; T_s = 338 К (65 °C при P_s). Требуемая производительность (по EN 13136 — теплоприток при пожаре): ṁ = F · A_сос^0,82, где F — фактор теплопритока и A_сос — площадь поверхности сосуда.

Расчёт подтверждает, что поток хладагента через клапан при давлении настройки — всегда **критический** (P₂ атм << 0,528 · P_s), что упрощает расчёт: расход определяется только P_s и T_s.

## Числовой пример: критический расход через ТРВ

**Условие.** ТРВ с пропускной способностью K_vs = 1,8 м³/ч по жидкому R32 при ΔP = 100 кПа. Перепад давления в реальных условиях ΔP = 1200 кПа (давление жидкости после конденсатора 2,5 МПа, давление испарения 1,3 МПа). Температура жидкости перед ТРВ: 35 °C.

**Проверка режима истечения.** R32: P_cr/P₀ ≈ 0,55 (γ ≈ 1,20). Критический перепад: ΔP_cr = P₀ · (1 − 0,55) = 2500 · 0,45 = 1125 кПа.

Так как ΔP_факт = 1200 кПа > ΔP_cr = 1125 кПа — **режим критического истечения** для паровой фазы. Для жидкой фазы сжимаемость пренебрежимо мала; расход жидкого хладагента рассчитывается по несжимаемой модели с поправкой на плотность:

{{< formula display="true" >}}
\dot{m} = K_{vs} \sqrt{\rho_{\text{ж}} \cdot \Delta P / \rho_{\text{воды}}}
{{< /formula >}}

Плотность жидкого R32 при 35 °C: ρ_ж ≈ 920 кг/м³.

{{< formula display="true" >}}
\dot{m} = \frac{1{,}8}{3600} \times \sqrt{\frac{920 \times 1{,}200{,}000}{1000}} = 5{,}0 \times 10^{-4} \times \sqrt{1{,}104{,}000} = 5{,}0 \times 10^{-4} \times 1051 = 0{,}525 \text{ кг/с}
{{< /formula >}}

Холодопроизводительность при этом массовом расходе и h_fg = 380 кДж/кг при T_исп = 5 °C: Q = ṁ · (1 − x₀) · h_fg = 0,525 × 0,78 × 380 = **155 кВт**.

## Воздуховоды высокого давления

Системы высокого давления (high-pressure ductwork) по ASHRAE используют скорости 15–30 м/с. При V > 30 м/с:

1. Потери давления рассчитываются с учётом плотности воздуха в каждой точке
2. Адиабатическая температура торможения повышает температуру у стенок канала (ΔT = V²/(2c_p) = 900/(2×1005) = 0,45 К при V = 30 м/с — незначительно)
3. Шум определяется не вихревым шумом арматуры (пропорциональным V⁶), а генерацией звука в поворотах и сужениях

**Числовой пример шума:** при удвоении скорости в воздуховоде уровень аэродинамического шума возрастает на 10 · 6 · lg(2) = **18 дБ**. Снижение скорости с 12 м/с до 8 м/с уменьшает шум на 10 · 6 · lg(12/8) = **10,5 дБ** — одна из самых эффективных мер борьбы с вентиляционным шумом.
