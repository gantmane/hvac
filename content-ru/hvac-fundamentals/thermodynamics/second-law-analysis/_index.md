## Энтропия как мера необратимости

Второй закон термодинамики утверждает, что в изолированных системах энтропия не убывает. Генерация энтропии {{< formula >}}\dot{\sigma}_{gen} \ge 0{{< /formula >}} — универсальная мера степени необратимости процесса:

- {{< formula >}}\dot{\sigma}_{gen} = 0{{< /formula >}}: обратимый (идеальный) процесс — теоретический предел
- {{< formula >}}\dot{\sigma}_{gen} > 0{{< /formula >}}: необратимый реальный процесс

Связь с деструкцией эксергии (теорема Гуи–Стодолы):

{{< formula display="true" >}}
\dot{Ex}_{destr} = T_0 \cdot \dot{\sigma}_{gen}
{{< /formula >}}

Таким образом, минимизация генерации энтропии равнозначна минимизации потерь работоспособности. Это — инженерный критерий термодинамического совершенства конструкции.

---

## Баланс энтропии для открытой системы

Для контрольного объёма в установившемся режиме:

{{< formula display="true" >}}
\dot{\sigma}_{gen} = \sum_{out} \dot{m}_e s_e - \sum_{in} \dot{m}_i s_i - \sum_j \frac{\dot{Q}_j}{T_j} \ge 0
{{< /formula >}}

Физический смысл каждого члена:
- {{< formula >}}\sum_{out} \dot{m}_e s_e - \sum_{in} \dot{m}_i s_i{{< /formula >}} — чистый вынос энтропии с потоками массы
- {{< formula >}}\sum_j \dot{Q}_j/T_j{{< /formula >}} — перенос энтропии с тепловыми потоками через границу

## Генерация энтропии в основных компонентах

### Адиабатный компрессор

Для адиабатного компрессора {{< formula >}}\dot{Q} = 0{{< /formula >}}:

{{< formula display="true" >}}
\dot{\sigma}_{gen,comp} = \dot{m}_r (s_2 - s_1)
{{< /formula >}}

Связь с изоэнтропным КПД:

{{< formula display="true" >}}
\eta_s = \frac{h_{2s} - h_1}{h_2 - h_1} \quad \Longrightarrow \quad h_2 = h_1 + \frac{h_{2s} - h_1}{\eta_s}
{{< /formula >}}

Поскольку в адиабатном процессе {{< formula >}}Q = 0{{< /formula >}}, первый закон даёт {{< formula >}}w_c = h_2 - h_1{{< /formula >}}, и избыточная работа сжатия по сравнению с идеальным полностью переходит в генерацию энтропии.

**Числовой пример.** Компрессор R-32: h₁ = 565,3 кДж/кг, s₁ = 2,243 кДж/(кг·К); при η_s = 0,78: h₂ = 633,4 кДж/кг, s₂ (из таблиц при P₂ = 2,556 МПа, h₂ = 633,4) = 2,302 кДж/(кг·К). Массовый расход ṁ = 0,215 кг/с.

{{< formula display="true" >}}
\dot{\sigma}_{gen,comp} = 0{,}215 \times (2{,}302 - 2{,}243) = 0{,}215 \times 0{,}059 = 0{,}0127 \text{ кВт/К}
{{< /formula >}}

{{< formula display="true" >}}
\dot{Ex}_{destr,comp} = T_0 \cdot \dot{\sigma}_{gen} = 303 \times 0{,}0127 = 3{,}85 \text{ кВт}
{{< /formula >}}

### Теплообменник (конденсатор или испаритель)

Для теплообменника без работы и при пренебрежении потерями давления:

{{< formula display="true" >}}
\dot{\sigma}_{gen,HX} = \dot{m}_h (s_{h,out} - s_{h,in}) + \dot{m}_c (s_{c,out} - s_{c,in}) \ge 0
{{< /formula >}}

Для двух потоков идеального газа при изобарном теплообмене:

{{< formula display="true" >}}
\dot{\sigma}_{gen,HX} = \dot{m}_h c_{p,h} \ln\frac{T_{h,out}}{T_{h,in}} + \dot{m}_c c_{p,c} \ln\frac{T_{c,out}}{T_{c,in}}
{{< /formula >}}

**Числовой пример: воздух–воздух рекуператор.**

Горячий воздух: ṁ_h = 0,5 кг/с, cp = 1,005 кДж/(кг·К), T_in = 80 °C (353 К), T_out = 40 °C (313 К).
Холодный воздух: ṁ_c = 0,5 кг/с, T_in = 20 °C (293 К), T_out = 60 °C (333 К).

{{< formula display="true" >}}
\dot{\sigma}_{gen} = 0{,}5 \times 1{,}005 \times \ln\frac{313}{353} + 0{,}5 \times 1{,}005 \times \ln\frac{333}{293}
{{< /formula >}}

{{< formula display="true" >}}
= 0{,}5025 \times (-0{,}1203) + 0{,}5025 \times 0{,}1282 = -0{,}0604 + 0{,}0644 = 0{,}0040 \text{ кВт/К}
{{< /formula >}}

{{< formula display="true" >}}
\dot{Ex}_{destr} = 293 \times 0{,}0040 = 1{,}17 \text{ кВт}
{{< /formula >}}

Чем меньше разность температур между потоками (чем ближе к «пинч»), тем ниже генерация энтропии.

### Расширительный клапан (дроссель)

Дросселирование при h = const, адиабатное:

{{< formula display="true" >}}
\dot{\sigma}_{gen,valve} = \dot{m}_r (s_4 - s_3) > 0
{{< /formula >}}

Для хладагентов {{< formula >}}s_4 > s_3{{< /formula >}} всегда — дросселирование необратимо. Удельная генерация энтропии зависит от перепада давления и рабочего вещества.

### Трубопровод с трением

Для несжимаемого потока в трубопроводе без теплообмена:

{{< formula display="true" >}}
\dot{\sigma}_{gen,pipe} = \frac{\dot{m} \Delta P_{friction}}{\rho T}
{{< /formula >}}

где {{< formula >}}\Delta P_{friction}{{< /formula >}} — потеря давления на трение (Па). Это уравнение обосновывает экономическую ценность снижения скорости потока в трубопроводах и каналах.

## Метод минимума генерации энтропии (EGM)

Метод минимума генерации энтропии (Entropy Generation Minimization, EGM, разработан Bejan, 1982) позволяет оптимизировать геометрию теплообменников и систем теплопередачи.

### Приложение к охлаждаемой стенке

Стенка с внутренним источником тепла q (Вт/м²) охлаждается конвективно с коэффициентом теплообмена h (Вт/(м²·К)):

{{< formula display="true" >}}
\dot{\sigma}_{gen} = \frac{q^2}{h T_w T_f}
{{< /formula >}}

Для минимизации {{< formula >}}\dot{\sigma}_{gen}{{< /formula >}} при ограниченной площади поверхности и заданном h необходима наименьшая разность температур — стремление к изотермности, которое реализуется через оребрение и интенсификацию теплообмена.

### Приложение к теплообменнику HVAC

Для теплообменника с числом единиц переноса NTU и отношением теплоёмкостей C_min/C_max = R:

{{< formula display="true" >}}
\dot{\sigma}_{gen,HX} \propto \dot{m} c_p \left[(1 + R) - 2\sqrt{R}\cdot\epsilon + \text{трение}\right]
{{< /formula >}}

Существует оптимальный NTU, минимизирующий суммарную генерацию энтропии (сумма термической и гидравлической составляющих). Увеличение NTU сверх оптимального снижает термическую генерацию энтропии, но увеличивает гидравлическую.

## Термодинамическое совершенство системы

### Определение

Термодинамическое совершенство (thermodynamic perfection) системы — отношение минимальной теоретически необходимой работы к фактически затраченной:

{{< formula display="true" >}}
\Pi = \frac{W_{rev}}{W_{actual}} = \frac{\text{COP}_{actual}}{\text{COP}_{Carnot}} = \eta_{II}
{{< /formula >}}

### Декомпозиция по компонентам

Общая эффективность второго закона системы выражается через компонентные:

{{< formula display="true" >}}
\eta_{II,system} = \prod_i \eta_{II,i}
{{< /formula >}}

(при последовательном включении компонентов с независимыми потоками эксергии). В реальности декомпозиция сложнее, но принцип остаётся: улучшение худшего компонента даёт наибольший прирост системной эффективности.

## Связь с законом Гесса и химической энтропией

В системах с горением (котлы, абсорбционные машины прямого нагрева) генерация энтропии при сгорании определяется:

{{< formula display="true" >}}
\dot{\sigma}_{gen,comb} = \frac{\dot{m}_{fuel} \cdot LHV}{T_{flame}} - \frac{\dot{Q}_{useful}}{T_{system}}
{{< /formula >}}

где LHV — низшая теплота сгорания (кДж/кг), T_flame — адиабатная температура горения (К). Из-за высокой T_flame (1800–2200 К) и низкой T_system (< 400 К) генерация энтропии при горении составляет 20–30 % от всей в системе с газовым котлом — отсюда принципиальное ограничение КПД котла по второму закону.

## Применение к диагностике систем

Измерение или расчёт генерации энтропии в условиях реальной эксплуатации позволяет:

1. **Выявить деградацию** компонента: при загрязнении конденсатора {{< formula >}}\dot{\sigma}_{gen,cond}{{< /formula >}} растёт на 20–50 % — диагностический признак.
2. **Оценить степень износа компрессора**: снижение η_s с 0,80 до 0,72 означает прирост генерации энтропии на 11 % при той же степени давления.
3. **Сравнить альтернативные схемы**: два проекта с одинаковым COP (первый закон) могут существенно различаться по распределению необратимостей — информация важна для надёжности и потенциала дальнейшей оптимизации.

## Часто задаваемые вопросы

**Можно ли снизить генерацию энтропии до нуля?** Нет. Идеальный обратимый процесс требует бесконечного времени (квазистатический процесс) и бесконечно большой площади теплообмена — практически недостижимо. Реальная инженерная задача — оптимизировать компромисс между уровнем необратимостей и стоимостью оборудования.

**Как связаны генерация энтропии и потребление электроэнергии?** Прямая связь через теорему Гуи–Стодолы: каждый ватт деструкции эксергии означает дополнительный ватт подводимой работы (при прочих равных условиях). Инвестиции в снижение необратимостей напрямую снижают счёт за электроэнергию.

**Применим ли анализ второго закона к системам с переменной нагрузкой?** Да, через усреднение по времени работы. Для систем с инвертором важно рассчитывать {{< formula >}}\dot{\sigma}_{gen}{{< /formula >}} при типичных точках нагрузки (25 %, 50 %, 75 %, 100 %), взвешенных по часам работы (стандарт EN 14825:2022).
