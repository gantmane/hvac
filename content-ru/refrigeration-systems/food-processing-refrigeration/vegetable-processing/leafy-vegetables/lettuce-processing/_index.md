## Обзор

Обработка салата представляет критические задачи охлаждения из-за высоких скоростей дыхания, чувствительности к этилену и быстрой деградации качества при температурах выше оптимальных. Объекты обработки требуют интегрированных систем охлаждения, включая вакуумное охлаждение, холодное хранилище и контролируемые помещения для свежей нарезки для поддержания качества продукта от поля до потребителя.

**Основные типы салата:**
- Айсберг (хрустящий): содержание влаги 96%, плотная структура
- Романо: содержание влаги 95%, удлиненные листья
- Листовой салат: содержание влаги 94–95%, рыхлая структура листьев
- Масляный салат (Бибб, Бостон): содержание влаги 95%, нежные листья

## Системы вакуумного охлаждения

Вакуумное охлаждение является стандартным методом быстрого охлаждения салата, удаляя полевое тепло в течение 20–30 минут по сравнению с 8–12 часами для обычного охлаждения принудительным воздухом.

### Принципы работы

Вакуумное охлаждение работает путем снижения атмосферного давления для снижения температуры кипения воды, вызывая испарительное охлаждение с поверхности ткани салата.

**Отношение давления к температуре:**

| Абсолютное давление (кПа) | Температура кипения (°C) | Скорость охлаждения |
|------------------------|-------------------|--------------|
| 101,3 (атмосферное) | 100 | Базовая |
| 4,58 | 30 | Быстрая |
| 2,34 | 20 | Очень быстрая |
| 0,87 | 5 | Максимально практическая |
| 0,61 | 0 | Целевая конечная |

**Уравнение скорости охлаждения:**

Скорость отвода тепла при вакуумном охлаждении:

```
Q = m × hfg × (ΔW/Δt)
```

Где:
- Q = скорость отвода тепла (кВт)
- m = массовый расход испарившейся воды (кг/с)
- hfg = скрытая теплота испарения при сниженном давлении (кДж/кг)
- ΔW = потеря веса (кг)
- Δt = время охлаждения (с)

**Типичные параметры цикла охлаждения:**

| Параметр | Значение | Примечание |
|-----------|-------|-------|
| Начальная температура продукта | 25–30°C | Полевая температура |
| Конечная температура продукта | 0–1°C | Целевая |
| Время цикла | 20–30 мин | Полный цикл |
| Скорость снижения давления | 0,5–0,7 кПа/мин | Контролируемая скорость |
| Конечное давление вакуума | 0,6–0,8 кПа | Абсолютное |
| Потеря веса | 2–4% | Зависит от продукта |
| Емкость камеры | 18–48 поддонов | Коммерческие установки |

### Спецификации оборудования вакуумного охлаждения

**Требования к конструкции камеры:**

- Объем камеры: 70–200 м³ для коммерческих операций
- Толщина стенки: 6–10 мм стали с ребрами жесткости
- Расчетное давление: полный вакуум (101,3 кПа дифференциальное)
- Коэффициент безопасности: минимум 4:1 на конструктивных элементах
- Тип герметизации двери: надувное резиновое уплотнение с двумя поверхностями герметизации
- Смотровые окна: закаленное стекло, минимум 50 мм толщины

**Системы вакуумного насоса:**

Конфигурация первичного вакуумного насоса использует двухступенчатую конструкцию:

1. **Ступень грубого вакуума:**
   - Тип: Роторно-лопастной или жидкостно-кольцевой
   - Производительность: 200–500 м³/ч при атмосферном давлении
   - Работает от 101,3 кПа до 13 кПа
   - Мощность: 15–30 кВт

2. **Ступень высокого вакуума:**
   - Тип: Паровой эжектор или бустерный насос
   - Производительность: 100–300 м³/ч при 1 кПа
   - Работает от 13 кПа до 0,6 кПа
   - Потребление пара: 200–400 кг/ч при 600–800 кПа

**Расчет нагрузки охлаждения:**

Общая нагрузка охлаждения на конденсатор вакуумного охлаждения:

```
Qcondenser = (m_water × hfg) + (m_product × cp × ΔT) + Q_infiltration
```

Типичные значения для партии 1000 кг салата:
- Испарившаяся вода: 30 кг (потеря веса 3%)
- Теплота испарения при 1°C: 2500 кДж/кг
- Явное тепло продукта: 1000 кг × 3,9 кДж/(кг·K) × 28 K = 109 200 кДж
- Общий отвод тепла: 184 200 кДж в течение 25 минут = 123 кВт в среднем

**Системы конденсатора:**

Конденсация пара предотвращает перегрузку вакуумного насоса:
- Тип конденсатора: кожухотрубный, затопленного типа
- Хладагент: R-134a, R-404A или аммиак (NH₃)
- Рабочая температура: -5 до -10°C
- Площадь поверхности: 50–150 м² в зависимости от производительности
- Температура подхода: 3–5 K

### Система предварительного смачивания

Салат требует предварительного смачивания перед вакуумным охлаждением для предотвращения чрезмерной потери влаги:

- Температура воды: 1–4°C (предотвращает термический шок)
- Применение: тонкое распыление или ванна для погружения
- Продолжительность: 30–60 секунд
- Покрытие: полное смачивание поверхности листьев
- Качество воды: питьевая, хлорированная при 50–100 ppm

**Контроль потери влаги:**

Потеря веса при вакуумном охлаждении:

```
WL = (Ti - Tf) / (hfg / cp)
```

Где:
- WL = дробная потеря веса
- Ti = начальная температура (°C)
- Tf = конечная температура (°C)
- hfg = скрытая теплота испарения (кДж/кг)
- cp = удельная теплоемкость салата (кДж/(кг·K))

Для салата: cp ≈ 3,9 кДж/(кг·K), hfg при 1°C ≈ 2500 кДж/кг

Ожидаемая потеря веса = (28°C) / (2500/3,9) = 0,044 = 4,4%

Предварительное смачивание добавляет 2–3% влаги, результирующая потеря составляет 1–2%.

## Требования к окружающей среде помещения обработки

Обработка свежей нарезки требует строгого контроля температуры и влажности для минимизации микробного роста и скоростей дыхания.

### Контроль температуры

**Температуры помещения обработки:**

| Зона обработки | Температура (°C) | Допуск (±K) | Назначение |
|----------------|------------------|----------------|---------|
| Приемка/осмотр | 4–7 | ±1,0 | Начальная обработка |
| Обрезка/удаление сердцевины | 2–4 | ±0,5 | Снижение дыхания |
| Мытье | 1–2 | ±0,5 | Критическая контрольная точка |
| Нарезка/шредирование | 1–4 | ±0,5 | Минимизация повышения температуры |
| Центрифужная сушка | 2–4 | ±1,0 | Отвод тепла оборудования |
| Упаковка | 2–4 | ±0,5 | Финальная обработка |
| Холодное хранилище | 0–1 | ±0,5 | Оптимальное хранилище |

**Проектирование системы охлаждения:**

Помещения обработки требуют высоких скоростей циркуляции воздуха с минимальной температурной стратификацией:

- Скорость циркуляции воздуха: 15–25 воздухообменов в час
- Температура подаваемого воздуха: -2 до 0°C
- Дифференциал подача-помещение: 3–4 K
- Скорость воздуха над продуктом: 0,3–0,5 м/с (предотвращает высыхание)
- Перепад температур испарителя: 4–6 K (предотвращает обледенение катушки)

**Компоненты нагрузки чувствительного охлаждения:**

```
Qtotal = Qproduct + Qequipment + Qpeople + Qinfiltration + Qtransmission + Qlight
```

Типичная разбивка нагрузки помещения обработки (500 м²):
- Охлаждение продукта: 45–55 кВт (доминирующая нагрузка)
- Тепло оборудования (двигатели, конвейеры): 25–35 кВт
- Присутствие персонала (20–30 рабочих): 8–12 кВт
- Инфильтрация (двери, движение): 15–20 кВт
- Передача (стены, потолок): 10–15 кВт
- Освещение (светодиод): 3–5 кВт

**Требуемая установленная мощность охлаждения: 125–160 кВт (коэффициент безопасности 20–25%)**

### Контроль температуры воды для мытья

Температура воды для мытья критически влияет на снижение микробов и дыхание продукта.

**Параметры системы мытья:**

| Параметр | Спецификация | Обоснование |
|-----------|--------------|-----------|
| Температура воды | 0–2°C | Минимизация дыхания |
| Температурный дифференциал | Макс 5 K ниже продукта | Предотвращение поглощения воды |
| Расход | 1500–3000 л/мин | Перемешивание и удаление |
| Время контакта | 60–120 секунд | Эффективность санитизации |
| Концентрация хлора | 50–200 ppm свободного Cl₂ | Снижение микробов |
| Контроль pH | 6,5–7,5 | Эффективность хлора |
| Замена воды | 100% каждые 2–4 часа | Управление органической нагрузкой |

**Проектирование системы охлажденной воды:**

Вода для мытья требует выделенного охлаждения:

- Тип охладителя: Пластинчатый теплообменник с вторичным контуром гликоля
- Производительность: 50–100 кВт в зависимости от производительности
- Концентрация гликоля: 25–30% пропиленгликоля (пищевой класс)
- Температура подачи гликоля: -4 до -2°C
- Контроль: ПИД-контроль температуры с точностью ±0,2°C

**Расчет тепловой нагрузки:**

```
Qwash = (m_water × cp,water × ΔT) / t + Qproduct + Qambient
```

Для системы 2000 л/мин:
- Теплоемкость воды: 2000 л/мин × 60 мин/ч × 4,18 кДж/(л·K) × 8 K повышение = 4 012 800 кДж/ч = 1115 кВт

Требование непрерывного охлаждения с рекуперацией тепла: 70–120 кВт

### Контроль влажности

Поддержание сверхвысокой влажности предотвращает потерю влаги с поверхностей нарезанных листьев.

**Целевые условия:**

- Относительная влажность: 98–100%
- Температура точки росы: 0,5–1,5°C (в пределах 0,5 K от температуры воздуха)
- Скорость воздуха: максимум 0,2–0,4 м/с (снижает испарительный потенциал)

**Методы контроля влажности:**

1. **Высокоэффективные испарительные катушки:**
   - Большая площадь лица (низкая лицевая скорость: 1,5–2,0 м/с)
   - Небольшой температурный дифференциал (4–5 K)
   - Частые циклы оттаивания (каждые 4–6 часов)

2. **Ультразвуковое увлажнение:**
   - Дополнение во время периодов низкой нагрузки
   - Производительность: 20–50 кг/ч водяного пара
   - Размер капель: 1–5 мкм (предотвращает поверхностное смачивание)
   - Качество воды: РО или дистиллированная (предотвращает минеральные отложения)

3. **Проектирование циркуляции воздуха:**
   - Несколько небольших воздухообработчиков в сравнении с одним большим блоком
   - Верхняя подача, возврат с низкой стенки
   - Предотвращает мертвые зоны и стратификацию

**Психрометрический контроль:**

Скорость удаления влаги из продукта:

```
m_evap = A × k × (Psurf - Pair) × MW / (R × T)
```

Где:
- A = площадь поверхности (м²)
- k = коэффициент массопередачи (м/с)
- Psurf = давление паров на поверхности листа (Па)
- Pair = давление паров в воздухе (Па)
- MW = молекулярная масса воды (18 г/моль)
- R = газовая постоянная (8,314 Дж/(моль·K))
- T = температура (K)

Для 1000 кг обработанного салата (площадь поверхности ≈ 200 м²):
При 2°C, Psurf = 705 Па (100% ОВ на поверхности листа)
При 2°C, 95% ОВ: Pair = 670 Па
Коэффициент массопередачи: 0,003 м/с

Скорость испарения = 200 × 0,003 × (705–670) × 18 / (8,314 × 275) = 0,165 кг/ч

Поддержание 98–100% ОВ снижает это до 0,01–0,03 кг/ч.

## Требования к хранению

Хранение после обработки поддерживает качество салата в течение 14–21 дня.

### Управление температурой

**Спецификации температуры хранилища:**

| Тип продукта | Температура (°C) | Максимальная продолжительность | Скорость потери качества |
|--------------|------------------|------------------|-------------------|
| Цельная головка айсберга | 0–1 | 21 день | 1–2% в день при 0°C |
| Цельный романо | 0–1 | 14–21 день | 2–3% в день при 0°C |
| Свежая нарезка микс | 0–1 | 7–14 дней | 4–6% в день при 0°C |
| Масляный салат | 0–1 | 7–10 дней | 5–7% в день при 0°C |

**Влияние температуры на дыхание:**

Скорость дыхания удваивается для каждого повышения на 10°C (Q10 = 2,0–2,5 для салата).

```
RR(T) = RR(0°C) × Q10^((T-T0)/10)
```

| Температура хранилища | Относительная скорость дыхания | Влияние на срок годности |
|--------------------|---------------------------|-------------------|
| 0°C (оптимально) | 1,0 × базовая | 100% (21 день) |
| 5°C | 1,5 × базовая | 60% (13 дней) |
| 10°C | 2,3 × базовая | 35% (7 дней) |
| 15°C | 3,5 × базовая | 20% (4 дня) |
| 20°C | 5,0 × базовая | 10% (2 дня) |

**Проектирование холодного хранилища:**

- Изоляция: 150–200 мм пенополиуретана (k = 0,022 Вт/(м·K))
- Пол: изолированный с нагревательными кабелями снизу для предотвращения замерзания грунта
- Распределение воздуха: верхняя подача, возврат на уровне пола
- Температурная однородность: ±0,5 K по всему объему
- Система охлаждения: Прямое расширение или затопленный аммиак

**Нагрузка охлаждения для хранилища 1000 м² (высота 4 м):**

- Нагрузка продукта: 200 000 кг емкость × 60 Вт/тонну = 12 кВт
- Передача: 1460 м² × 0,25 Вт/(м²·K) × 25 K = 9,1 кВт
- Инфильтрация: 3 дверей причала × 8 кВт каждая = 24 кВт
- Освещение: 1000 м² × 8 Вт/м² = 8 кВт
- Движение погрузчика: 4 единицы × 5 кВт среднее = 20 кВт

**Требуемая общая мощность: 75–85 кВт (включая коэффициент безопасности)**

### Требования к относительной влажности

Салат требует максимальной влажности для предотвращения увядания из-за высокого соотношения поверхности к объему.

**Спецификации влажности:**

- Целевая ОВ: 98–100%
- Местоположение измерения: Высота продукта, несколько датчиков
- Точность контроля: ±2% ОВ
- Калибровка датчика: Ежемесячная проверка по мокрому термометру психрометра

**Предотвращение потери влаги:**

Скорость потери влаги салатом:

```
dM/dt = -k × A × (RH_sat - RH_air) × M
```

При 0°C, 95% ОВ против 98% ОВ:
- 95% ОВ: потеря влаги = 0,15% в день
- 98% ОВ: потеря влаги = 0,06% в день
- 100% ОВ: потеря влаги ≈ 0% (риск конденсации)

**Методы упаковки для сохранения влажности:**

1. **Перфорированные полиэтиленовые пакеты:**
   - Площадь перфорации: 0,1–0,3% от общей площади
   - Создает модифицированную атмосферу
   - Поддерживает 95–100% ОВ внутри упаковки

2. **Верхний лед:**
   - Применяется к картонным коробкам при транспортировке
   - Обеспечивает непрерывную влагу
   - Соотношение лед-продукт: 0,15–0,20 кг льда на кг салата
   - Снижение нагрузки охлаждения: 15–20% благодаря тепловой массе

## Профилактика ржавых пятен

Ржавые пятна (ферментативное потемнение средних жилок) — основной дефект качества, ограничивающий срок хранения салата.

### Чувствительность к этилену

Салат чрезвычайно чувствителен к этилену. Воздействие этилена вызывает окисление фенольных соединений, вызывающее появление ржавых пятен в течение 3–5 дней при 5°C.

**Пороговое значение этилена и реакция:**

| Концентрация этилена | Продолжительность воздействия | Видимые пятна |
|-----------------------|-------------------|------------------|
| < 0,1 ppm | 21 день | Нет |
| 0,1–0,5 ppm | 14 дней | Следовые (5–10% голов) |
| 0,5–1,0 ppm | 7 дней | Умеренные (30–50%) |
| 1,0–2,0 ppm | 3 дня | Сильные (70–90%) |
| > 2,0 ppm | 1 день | Полные (100%) |

**Критический контрольный предел: < 0,5 ppm этилена в атмосфере хранилища**

### Источники этилена и контроль

**Источники производства этилена:**

1. **Эндогенные (самопроизводство салатом):**
   - Салат айсберг: 2–5 мкл/(кг·ч) при 0°C
   - Романо: 3–7 мкл/(кг·ч) при 0°C
   - Свежая нарезка: 8–15 мкл/(кг·ч) при 0°C (ответная реакция на повреждение)

2. **Экзогенные (внешние источники):**
   - Созревающие фрукты (яблоки, помидоры): 10–100 мкл/(кг·ч)
   - Выхлоп погрузчика: 50–500 ppm в облаке
   - Поврежденный продукт: 5–10× нормального производства
   - Разлагающееся органическое вещество: переменная, высокая концентрация

**Технологии удаления этилена:**

| Технология | Скорость удаления | Операционная стоимость | Эффективность |
|-----------|--------------|----------------|---------------|
| Активированный уголь | Низкая | Низкая | Снижение на 20–40% |
| Перманганат калия | Средняя | Средняя | Снижение на 60–80% |
| Каталитическое окисление | Высокая | Высокая | Снижение на 95–99% |
| Озоновая обработка | Высокая | Средняя | Снижение на 90–95% |
| УФ-С фотокаталитическое | Высокая | Средняя–высокая | Снижение на 90–98% |

**Рекомендуемая система: Каталитическое окисление**

Операционные параметры:
- Катализатор: Платина или палладий на основе оксида алюминия
- Рабочая температура: 150–200°C
- Реакция: C₂H₄ + 3O₂ → 2CO₂ + 2H₂O (полное окисление)
- Эффективность преобразования: 95–99% при расчетной скорости потока
- Перепад давления: 100–250 Па на катализаторном слое
- Скорость рециркуляции воздуха: 2–4 объема помещения в час
- Мощность вентилятора: 1–3 кВт на 1000 м³ объема хранилища

**Расчет размера системы:**

Скорость производства этилена для хранилища 200 000 кг:
```
Производство этилена = 200 000 кг × 5 мкл/(кг·ч) = 1 000 000 мкл/ч = 1,0 л/ч
```

При 0°C, 101,3 кПа: 1,0 л/ч = 0,00125 кг/ч

Для поддержания < 0,5 ppm в хранилище 4000 м³:
- Максимально допустимый этилен: 4000 м³ × 0,5 мг/м³ = 2000 мг = 2,0 г
- Время пребывания: 2,0 г / 0,00125 кг/ч = 1,6 часа

Требуемая циркуляция воздуха: 4000 м³ / 1,6 ч = 2500 м³/ч минимум

### Взаимодействие температуры и атмосферы

Тяжесть ржавых пятен увеличивается экспоненциально с температурой:

```
Spotting_rate = k × e^(Ea/RT) × [C2H4]
```

Где:
- k = константа скорости
- Ea = энергия активации (50–60 кДж/моль для полифенолоксидазы)
- R = газовая постоянная
- T = абсолютная температура (K)
- [C2H4] = концентрация этилена

**Взаимодействие температуры-этилена:**

| Температура | 0,5 ppm C2H4 | 1,0 ppm C2H4 | 2,0 ppm C2H4 |
|-------------|--------------|--------------|--------------|
| 0°C | 14–21 день видимого образования | 7–10 дней | 3–5 дней |
| 5°C | 5–7 дней | 3–4 дня | 1–2 дня |
| 10°C | 2–3 дня | 1–2 дня | < 1 дня |

**Вывод: Обязательны как контроль температуры (0–1°C), так и контроль этилена (< 0,5 ppm).**

## Хранение и упаковка в модифицированной атмосфере

Модифицированная атмосфера (МА) продлевает срок хранения салата путем снижения дыхания и ферментативного потемнения.

### Оптимальный состав газа

**Спецификации целевой атмосферы:**

| Параметр | Цельная головка | Свежая нарезка | Обоснование |
|-----------|-----------|-----------|-----------|
| Концентрация O₂ | 1–3% | 2–5% | Подавление дыхания |
| Концентрация CO₂ | 0–2% | 5–15% | Подавление микробного роста |
| N₂ (баланс) | 95–99% | 80–93% | Инертный наполнитель газа |
| Этилен | < 0,1 ppm | < 0,1 ppm | Предотвращение пятен |
| Температура | 0–1°C | 0–2°C | Критический контроль |

**Физиологические пределы:**

- Минимальный O₂: 1% (ниже этого: анаэробное дыхание, неприятные запахи)
- Максимальный CO₂: 15–20% (выше этого: повреждение ткани, коричневое пятно)
- Взаимодействие температуры-газа: Газовая толерантность снижается при более высоких температурах

### Помещения хранилища в модифицированной атмосфере

Крупномасштабное хранилище МА для салата цельной головки:

**Проектирование помещения:**

- Герметичная конструкция: сварные стальные панели с непрерывными прокладками герметизации
- Скорость утечки: < 2% объема помещения за 24 часа при 250 Па дифференциала
- Сброс давления: пружинный клапан, установленный на 100–150 Па
- Впрыск газа: несколько портов для равномерного распределения
- Мониторинг: датчики O₂, CO₂, температуры в нескольких местоположениях

**Система управления газом:**

1. **Генерация азота:**
   - Система PSA (адсорбция при колебаниях давления)
   - Чистота: 95–99% N₂
   - Производительность: 20–50 м³/ч в зависимости от размера помещения и скорости утечки
   - Рабочее давление: 600–800 кПа

2. **Впрыск CO₂:**
   - Жидкий CO₂ с испарителем
   - Контроль потока: 0,1–5,0 кг/ч регулируемое
   - Температура впрыска: уравновешена к температуре помещения

3. **Мониторинг O₂ и контроль:**
   - Датчик циркониевого диоксида или парамагнитный
   - Точность: ±0,1% O₂
   - Время отклика: < 30 секунд
   - Автоматический впрыск N₂ для поддержания уставки

**Начальное создание атмосферы:**

Начальное установление атмосферы для помещения 500 м³:

```
N₂_required = V × (21% - target_O₂%) / (100% - N₂_purity)
```

Для помещения 500 м³, целевой 2% O₂, генератор 98% N₂:
- Требуемый N₂: 500 × (21 – 2) / (100 – 98) = 4750 м³
- При 50 м³/ч: 95 часов для начального создания атмосферы
- Практический подход: установка продукта в течение 2–3 дней по мере стабилизации атмосферы

### Упаковка в модифицированной атмосфере (MAP)

Свежая нарезка салата требует индивидуального контроля МА в упаковке.

**Спецификации упаковочной пленки:**

| Тип пленки | Проницаемость O₂ | Проницаемость CO₂ | Селективность | Применение |
|-----------|-----------------|------------------|-------------|-------------|
| ОПП (ориентированный полипропилен) | 1500–3000 см³/(м²·день·атм) | 6000–12 000 | 4:1 | Низкое дыхание |
| ЛПЭ (полиэтилен низкой плотности) | 5000–8000 см³/(м²·день·атм) | 25 000–35 000 | 5:1 | Среднее дыхание |
| Микроперфорированный БОПП | 8000–15 000 см³/(м²·день·атм) | 35 000–60 000 | 4:1 | Высокое дыхание |
| Xtend® (специальная МА) | 3000–5000 см³/(м²·день·атм) | 15 000–25 000 | 5:1 | Продленный срок годности |

Проницаемость измеряется при 23°C, 0% ОВ, дифференциал давления 1 атм.

**Моделирование атмосферы упаковки:**

Равновесная атмосфера развивается через баланс дыхания и проницаемости:

```
d[O₂]/dt = (PO₂ × A × ΔP) / (x × V) - RRO₂ × m / V
```

Где:
- [O₂] = концентрация кислорода в упаковке (%)
- PO₂ = проницаемость кислорода (см³/(м²·день·атм))
- A = площадь поверхности упаковки (м²)
- ΔP = дифференциал давления (атм)
- x = толщина пленки (м)
- V = свободный объем упаковки (л)
- RRO₂ = скорость дыхания кислорода (см³/(кг·ч))
- m = масса продукта (кг)

**Пример расчета:**

Упаковка нарезанного салата 250 г:
- Размеры упаковки: 20 см × 15 см × 5 см
- Площадь пленки: 0,07 м²
- Толщина пленки: 50 мкм
- Свободный объем: 1,0 л
- Проницаемость пленки для O₂: 5000 см³/(м²·день·атм)
- Скорость дыхания салата при 2°C: 15 мг CO₂/(кг·ч) = 10 см³ O₂/(кг·ч)

При равновесии:
```
(5000 × 0,07 × 0,21) / (0,00005 × 1,0) = (10 × 0,25) / 1,0
73,5 см³ O₂/день = 2,5 см³ O₂/день (потребление в упаковке)
```

Целевая концентрация O₂ 3–5% требует пленки с проницаемостью 1500–2500 см³/(м²·день·атм).

**Методы модификации упаковки:**

1. **Пассивная MAP:**
   - Выбор пленки создает равновесную атмосферу
   - Без промывки газом
   - Атмосфера развивается в течение 1–3 дней
   - Экономично для стандартного срока годности

2. **Активная MAP:**
   - Упаковка промывается газовой смесью перед герметизацией
   - Типичная смесь: 3% O₂, 10% CO₂, 87% N₂
   - Немедленный контроль атмосферы
   - Используется для премиум-продуктов, продленный срок хранения

3. **Газопоглощающие пакетики:**
   - Железные поглотители O₂: снижают O₂ до < 0,1%
   - Поглотители этилена: перманганат калия на силикагеле
   - Контроль влаги: силикагель или молекулярные сита
   - Используются в комбинации с пленками MAP

## Оборудование для обработки свежей нарезки

Обработка свежей нарезки требует специализированного оборудования, предназначенного для санитизации и контроля температуры.

### Оборудование для обрезки и удаления сердцевины

**Системы удаления сердцевины:**

- Тип: Пневматический или гидравлический таран с трубчатым ножом
- Диаметр сердцевины: 30–50 мм регулируемое
- Скорость цикла: 30–60 голов в минуту на станцию
- Извлечение сердцевины: система вакуума удаляет сердцевины
- Температура: Оборудование покрыто циркулирующим охлажденным гликолем (1–2°C)

**Удаление внешних листьев:**

Ручное или полуавтоматизированное:
- Температура рабочей поверхности: 2–4°C (охлажденная нержавеющая сталь)
- Утилизация: пневматическая транспортировка отходов в сборочную камеру
- Производительность: 10–15 голов на рабочего в минуту

### Системы нарезки и шредирования

**Спецификации шредера:**

| Компонент | Спецификация | Назначение |
|-----------|--------------|---------|
| Тип ножа | Ротационный круговой, 300–600 мм диаметр | Чистые срезы, минимальное потемнение |
| Материал ножа | Нержавеющая сталь 440C | Коррозионная стойкость, удержание кромки |
| Скорость ножа | 200–400 об/мин | Оптимальная скорость резания |
| Размер среза | 12–50 мм регулируемое | Спецификация продукта |
| Скорость подачи | 500–2000 кг/ч | Производительность |
| Мощность двигателя | 3–7,5 кВт | Система привода |
| Санитизация | Шарики CIP, вода 80–85°C | Автоматизированная очистка |

**Контроль температуры:**

Оборудование генерирует фрикционное тепло, требующее охлаждения:
- Повышение температуры ножа: 5–10°C во время работы
- Метод охлаждения: рубашка охлажденной воды в корпусе ножа
- Теплоноситель: 30% пропиленгликоль при температуре подачи -2°C
- Отвод тепла: 5–10 кВт на производительность 1000 кг/ч

**Повышение температуры продукта:**

```
ΔT_product = (P_motor × η_heat) / (ṁ × cp)
```

Для двигателя 5 кВт, 70% передачи тепла к продукту, производительность 1000 кг/ч:
- ΔT = (5 кВт × 0,70) / (0,278 кг/с × 3,9 кДж/(кг·K)) = 3,2 K

Повышение температуры должно быть противодействовано охлажденными поверхностями оборудования.

### Системы мытья

**Конструкция моечного бака:**

- Объем бака: 500–2000 л на линию
- Материал: Нержавеющая сталь 304 или 316
- Конфигурация: Противоток, продукт движется в противоположном направлении потоку воды
- Перемешивание: Барботаж воздухом или механические лопасти
- Температура воды: 1–2°C поддерживается теплообменником
- Время пребывания: 60–120 секунд

**Впрыск санитайзера:**

- Хлор: 50–200 ppm свободного хлора (раствор гипохлорита натрия)
- Альтернатива: Диоксид хлора (2–5 ppm), надуксусная кислота (40–80 ppm)
- Контроль pH: Впрыск кислоты (лимонная или соляная) для pH 6,5–7,0
- Мониторинг ОВП: 650–750 мВ окислительно-восстановительный потенциал
- Автоматическое дозирование: Пропорциональные контроллеры поддерживают уставки

**Требования к качеству воды:**

- Мутность: < 1 ЕМФ (требует частой замены)
- Общее растворенное вещество: < 500 мг/л
- Колиформные бактерии: 0 КОЕ/100 мл
- Органическая нагрузка: Замена воды при превышении мутности 5 ЕМФ

### Системы центрифужной сушки

**Спецификации центрифуги:**

| Дренаж | Напольный слив, 50–100 л/партия | Сбор воды |

**Непрерывные сушилки с конвейерной лентой:**

Альтернатива для высокопроизводительных операций:
- Ширина ленты: 600–1200 мм

**Контроль температуры:**

Центрифуга генерирует фрикционное тепло:
- Повышение температуры барабана: 3–5°C за цикл без охлаждения

### Оборудование для упаковки

**Системы горизонтального потокового обертывания:**

- Тип: Горизонтальное потоковое обертывание с промывкой газом
- Скорость: 40–120 упаковок в минуту
- Ширина пленки: 300–600 мм
- Температура герметизации: 120–180°C (в зависимости от материала)
- Промывка газом: 3% O₂, 10% CO₂, 87% N₂ при 20–40 л/мин
- Тест герметичности: встроенная система обнаружения утечек

**Вертикальные систе мы формирования-наполнения-герметизации (VFFS):**

Для смесей салатов и нарезанного салата:
- Ширина рулона пленки: 300–500 мм
- Емкость наполнения: 100–500 г за упаковку
- Скорость: 30–80 упаковок в минуту
- Точность газового дозирования: ±2% от целевой концентрации
- Обнаружение металла: Встроенная система для безопасности пищевых продуктов

**Контроль окружающей среды вокруг упаковки:**

- Температура в помещении: 4–7°C (теплее обработки для предотвращения конденсации на пленке)
- Относительная влажность: 70–85% (предотвращает статическое электричество, сохраняет обработку пленки)
- Воздухообмены: 10–15 в час
- Фильтрация HEPA: ISO класс 7 (10 000 частиц/фут³) или выше

## Интеграция системы охлаждения

Полный объект обработки салата требует интегрированного подхода к охлаждению.

### Архитектура системы

**Многотемпературная система охлаждения:**

| Уровень температуры | Нагрузка (кВт) | Применение | Хладагент |
|------------------|-----------|-------------|-------------|
| -10°C испаритель | 150–200 | Конденсатор вакуумного охлаждения | R-404A, NH₃ |
| -5°C испаритель | 100–150 | Охлаждение воды для мытья | R-134a, NH₃ |
| 0°C испаритель | 200–300 | Холодные хранилища | R-404A, NH₃ |
| 2°C испаритель | 120–180 | Комнаты обработки | R-134a, NH₃ |

**Конфигурация центральной установки:**

- Хладагент: Аммиак (NH₃) для больших объектов (> 500 кВт общая)
- Тип системы: Насосная жидкость затопленная (затопленные испарители)
- Расположение компрессора: 3–4 винтовых компрессора (каждый 25–50% емкости)
- Управление емкостью: Регулируемые приводы частоты, разгрузка скользящего клапана
- Конденсация: Испарительный конденсатор или закрытый контур охладителя
- Промежуточный ресивер давления: -10°C для многоступенчатого сжатия

**Интеграция рекуперации тепла:**

- Перегрев: Рекуперация горячего газа для отопления объекта, горячей воды
- Потенциал рекуперации тепла: 15–25% от мощности охлаждения
- Применение: Нагрев гликоля для размораживания, ОВКВ здания, горячее водоснабжение

### Меры по повышению энергетической эффективности

**Технологии повышения эффективности:**

1. **Компрессоры с переменной скоростью:**
   - Энергосбережение 20–30% в сравнении с постоянной скоростью с горячим газовым байпасом
   - Снижает потери циклирования
   - Лучшее соответствие емкости нагрузке

2. **Контроль плавающего давления конденсации:**
   - Снижает давление конденсации при прохладных условиях окружающей среды
   - Улучшение эффективности компрессора 1–2% на 1°C снижение
   - Диапазон контроля: 20–35°C температура конденсации

3. **Контроль VFD вентилятора испарителя:**
   - Соответствие воздушного потока нагрузке охлаждения
   - Снижает энергию вентилятора на 30–50% при низкой нагрузке
   - Поддерживает эффективность катушки

4. **Переохлаждение:**
   - Выделенный охладитель после конденсатора
   - Переохлаждение 5–10 K увеличивает холодильный эффект на 2–4%
   - Критично для длинных жидкостных трубопроводов в объектах обработки

**Мониторинг производительности:**

- Отслеживание кВт/тонна охлаждения по уровню системы
- Целевые ориентиры: 0,65–0,85 кВт/тонна для систем +2°C, 0,95–1,15 кВт/тонна для -10°C
- Автоматизированный тренд выявляет деградацию производительности
- Ежемесячные энергетические отчеты направляют оптимизационные усилия

## Мониторинг качества и безопасности

Непрерывный мониторинг обеспечивает безопасность продукции и поддержание качества.

### Критические контрольные точки (HACCP)

**Мониторинг температуры:**

- Тип датчика: RTD (PT100 или PT1000), точность ±0,1°C
- Местоположение: Каждый этап обработки, комнаты хранилища (несколько точек)
- Интервал регистрации: 1–5 минутные интервалы
- Пределы сигнализации: ±1,0 K от уставки запускает предупреждение
- Хранение данных: минимум 2 года для нормативного соответствия

**Интеграция время-температура:**

Пределы воздействия времени-температуры продукта:

| Этап процесса | Максимальное время | Максимальная температура | Критический предел |
|---------------|--------------|---------------------|----------------|
| Приемка-удержание | 30 мин | 7°C | 1 час @ 10°C |
| Обработка | 2 часа | 4°C | 3 часа @ 7°C |
| Удержание после обработки | 1 час | 2°C | 2 часа @ 5°C |
| Холодное хранилище | Непрерывно | 1°C | 4 часа @ 5°C |

**Проверка санитизации:**

- АТФ (аденозинтрифосфат) мазки: < 150 RLU (относительные единицы света) на поверхностях контакта с пищей
- Счет аэробных пластин: < 100 КОЕ/см² на поверхностях оборудования
- Колиформные бактерии: 0 КОЕ на контактных с продуктом областях
- Частота тестирования: Ежедневно для производственного оборудования, еженедельно для хранилищ

### Прогноз срока хранения

**Моделирование деградации качества:**

Потеря качества салата следует кинетике первого порядка:

```
Q(t) = Q₀ × e^(-k×t)
```

Где:
- Q(t) = качество в момент времени t
- Q₀ = начальное качество
- k = константа скорости деградации (зависит от температуры)
- t = время

**Зависимость константы скорости от температуры:**

```
k(T) = k_ref × e^(Ea/R × (1/Tref - 1/T))
```

Для айсберга:
- k при 0°C: 0,033 день⁻¹ (срок годности 21 день до 50% качества)
- Ea: 55 кДж/моль
- k при 5°C: 0,066 день⁻¹ (срок годности 10,5 дня)
- k при 10°C: 0,132 день⁻¹ (срок годности 5,3 дня)

**Калькулятор срока годности:**

Совокупное воздействие температуры предсказывает оставшийся срок хранения:

```
Remaining % = 100 × e^(-Σ(ki × ti))
```

Пример: 2 дня при 0°C + 1 день при 5°C + 3 дня при 2°C:
- При 0°C: k = 0,033, воздействие = 0,033 × 2 = 0,066
- При 5°C: k = 0,066, воздействие = 0,066 × 1 = 0,066
- При 2°C: k = 0,044, воздействие = 0,044 × 3 = 0,132
- Общее воздействие: 0,264
- Оставшееся качество: 100 × e^(-0,264) = 76,8%
- Расчетные оставшиеся дни при 0°C: ln(0,5/0,768) / 0,033 = 12,2 дня

## Заключение

Системы охлаждения при обработке салата требуют прецизионного контроля температуры по всей холодной цепи от вакуумного охлаждения (целевой 0–1°C за 20–30 минут) через обработку свежей нарезки (2–4°C) до финального хранилища (0–1°C, 98–100% ОВ). Критические факторы успеха включают быстрое вакуумное охлаждение для удаления полевого тепла, непрерывное поддержание холодной цепи для минимизации дыхания (Q10 ≈ 2,0–2,5), контроль этилена ниже 0,5 ppm для предотвращения ржавых пятен и упаковка в модифицированной атмосфере (2–5% O₂, 5–15% CO₂) для продления срока хранения. Интеграция этих технологий обеспечивает срок хранения 14–21 дня для цельных голов и 7–14 дней для свежей нарезки при поддержании качества и норм безопасности пищевых продуктов.
