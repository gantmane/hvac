# Расчет тепловой нагрузки для инженеров HVAC

Точный расчет тепловой нагрузки предотвращает недостаточную мощность (неудовлетворительный комфорт) и избыточную мощность (циклирование, низкая эффективность). Данное руководство представляет методику ASHRAE для определения тепловой нагрузки в жилых и коммерческих зданиях.

## Компоненты теплопотерь

$$Q_{total} = Q_{transmission} + Q_{infiltration} + Q_{ventilation}$$

## Теплопотери через ограждающие конструкции

**Через ограждающие конструкции:**

$$Q = U \times A \times (T_{in} - T_{out})$$

Где:
- $U$ = коэффициент теплопередачи (кДж/(ч·м²·°C))
- $A$ = площадь поверхности (м²)
- $T_{in}$ = расчетная температура внутри помещения (обычно 20-22°C)
- $T_{out}$ = расчетная наружная температура при 99% или 99,6% обеспеченности

**Потери в грунте:**
- Стены подвала: использовать метод F-фактора
- Плиты по грунту: использовать F-фактор или C-фактор

## Теплопотери на инфильтрацию

**Метод кратности воздухообмена:**

$$Q_{inf} = 0.018 \times V \times ACH \times (T_{in} - T_{out})$$

Где:
- $V$ = объем здания (м³)
- $ACH$ = кратность воздухообмена в час

**Метод CFM:**

$$Q_{inf} = 1.08 \times CFM (м³/ч) \times \Delta T$$

**Типовые значения ACH:**
- Герметичная конструкция (ICF, SIPs): 0,15-0,25 ACH
- Средняя конструкция: 0,35-0,50 ACH
- Неудовлетворительная герметичность: 0,60-1,00 ACH

## Расчетные температуры

**Внутри помещения:** 20-22°C для отопления

**Наружные (ASHRAE 99,6%):**
- Чикаго, Иллинойс: -21,7°C
- Денвер, Колорадо: -18,9°C
- Атланта, Джорджия: -8,3°C
- Финикс, Аризона: 1,1°C

## Градусо-сутки

**Градусо-сутки отопления (база 18,3°C / 65°F):**

$$HDD = \sum (18,3 - T_{avg,daily})$$ для дней, когда $T_{avg} < 18,3$°C

**Годовая энергия:**

$$Energy = \frac{24 \times HDD \times UA_{building}}{\eta_{equipment}}$$

## Практическое применение

1. **Жилые здания:** использовать Manual J (ACCA)
2. **Коммерческие здания:** расчет по комнатам или по блокам
3. **Коэффициент запаса:** определять мощность оборудования, НЕ добавлять к рассчитанной нагрузке
