## Общие положения

Функция хранения влаги (moisture storage function) — равновесная зависимость между влагосодержанием материала и относительной влажностью или капиллярным давлением при постоянной температуре. Это фундаментальный входной параметр гигротермального моделирования (WUFI, DELPHIN), определяющий:

- прогноз накопления влаги в слоях конструкции;
- буферную ёмкость материала при колебаниях влажности воздуха;
- потенциал высыхания после намокания;
- риск роста плесени, морозного разрушения и биодеградации.

Стандарты измерения: **ISO 12571**, ASTM C1498, ГОСТ 25898.

## Изотермы сорбции

### Физические механизмы по диапазонам влажности

**Мономолекулярная адсорбция (0–20 % отн. вл.).** Молекулы воды образуют единый слой на поверхности пор через силы Ван-дер-Ваальса. Описывается уравнением Ленгмюра или БЭТ (Brunauer–Emmett–Teller):

{{< formula display="true" >}}
w = \frac{w_m\,C\,\varphi}{(1-\varphi)\,[1+(C-1)\,\varphi]}
{{< /formula >}}

**Полимолекулярная адсорбция (20–60 % отн. вл.).** Многослойная конденсация на начальном монослое. Материалы с высокой удельной поверхностью (волокнистая изоляция, автоклавный газобетон) накапливают значительный объём влаги в этом диапазоне.

**Капиллярная конденсация (60–95 % отн. вл.).** Вода конденсируется в мелких порах. Пороговый радиус поры определяется уравнением Кельвина:

{{< formula display="true" >}}
r = -\frac{2\,\sigma\,V_m}{R\,T\,\ln\varphi}
{{< /formula >}}

где {{< formula >}}\sigma = 0{,}0728{{< /formula >}} Н/м при 20 °C; {{< formula >}}V_m = 1{,}8\times10^{-5}{{< /formula >}} м³/моль.

**Надгигроскопический диапазон (>95 % отн. вл.).** Капиллярный подсос жидкой воды в крупные поры.

### Эмпирические модели

{{< table title="Уравнения аппроксимации изотерм сорбции" >}}
| Модель | Уравнение | Параметры | Применение |
|---|---|---|---|
| ГАБ (GAB) | {{< formula >}}w = \frac{w_m C k \varphi}{(1-k\varphi)[1+(C-1)k\varphi]}{{< /formula >}} | w_m, C, k | Древесина, органика |
| Кюнцель (WUFI) | {{< formula >}}w = w_f \frac{(b-1)\varphi^a}{b - \varphi^a}{{< /formula >}} | w_f, a, b | Универсальное (WUFI) |
| Ван Генухтен | {{< formula >}}\theta = \theta_r + \frac{\theta_s - \theta_r}{[1+(\alpha p_c)^n]^m}{{< /formula >}} | α, n, m, θ_r, θ_s | Надгигроскопический диапазон |
| Modified Oswin | {{< formula >}}w = A\left(\frac{\varphi}{1-\varphi}\right)^B{{< /formula >}} | A, B | Гипс, штукатурка |
{{< /table >}}

Модель Кюнцеля реализована в WUFI и обеспечивает хорошую аппроксимацию большинства строительных материалов тремя параметрами: {{< formula >}}w_f{{< /formula >}} — насыщение свободной водой; {{< formula >}}a{{< /formula >}} — параметр крутизны; {{< formula >}}b{{< /formula >}} — параметр смещения.

## Гистерезис сорбции

Влагосодержание при заданной относительной влажности различается в зависимости от истории нагружения: при адсорбции (увлажнение) кривая лежит ниже, чем при десорбции (высыхание). Гистерезис обусловлен:

- **эффектом чернильной бутылки** (ink-bottle effect) — капиллярная конденсация и испарение происходят при разных {{< formula >}}\varphi{{< /formula >}} в некилиндрических порах;
- различием краевых углов смачивания при продвижении и отступлении мениска;
- захватом воздуха при повторном смачивании пор.

Для большинства строительных материалов {{< formula >}}w_\text{des}/w_\text{ads} = 1{,}2{-}2{,}0{{< /formula >}} при одном и том же {{< formula >}}\varphi{{< /formula >}}.

В гигротермальных моделях обычно используется кривая десорбции как наиболее консервативная. Для детального анализа применяются сканирующие кривые, соединяющие главную петлю гистерезиса.

## Кривые капиллярного удержания

При {{< formula >}}\varphi > 95\,\%{{< /formula >}} функция хранения влаги задаётся через капиллярное давление:

{{< table title="Диапазоны давления и состояние влаги" >}}
| Давление p_c, Па | Состояние влаги | Механизм транспорта | Эквив. отн. вл. |
|---|---|---|---|
| 0–1 000 | Свободная вода | Капиллярный поток | > 99,3 % |
| 1 000–10 000 | Капиллярная вода | Капиллярный + паровой | 99,3–93 % |
| 10 000–100 000 | Фуникулярный режим | Ослабленный капиллярный | 93–47 % |
| > 100 000 | Гигроскопическая | Диффузия пара | < 47 % |
{{< /table >}}

Переход от капиллярного к паровому транспорту — около 93–95 % отн. вл. (10 000 Па).

## Дифференциальная влагоёмкость

Дифференциальная влагоёмкость (moisture capacity) — производная функции хранения по относительной влажности:

{{< formula display="true" >}}
\xi = \frac{\partial w}{\partial \varphi}\quad\text{[кг/кг на ед. }\varphi\text{]}
{{< /formula >}}

или в объёмном выражении:

{{< formula display="true" >}}
C_m = \frac{\partial\theta}{\partial\varphi}\quad\text{[м}^3\text{/м}^3\text{ на ед. }\varphi\text{]}
{{< /formula >}}

{{< formula >}}\xi{{< /formula >}} определяет:
- буферную ёмкость материала при переходных изменениях влажности воздуха;
- скорость перераспределения влаги при изменении граничных условий;
- требуемый временной шаг при численном моделировании.

Большинство материалов имеют пиковую влагоёмкость при 80–95 % отн. вл., где активна капиллярная конденсация.

## Численный пример: расчёт влагоёмкости и буферного времени

**Условие.** Слой глиняной штукатурки толщиной 20 мм ({{< formula >}}\rho_0 = 1600{{< /formula >}} кг/м³; {{< formula >}}w{{< /formula >}} при 50 % отн. вл. = 0,012 кг/кг; {{< formula >}}w{{< /formula >}} при 80 % отн. вл. = 0,028 кг/кг). Рассчитать:
1. Дифференциальную влагоёмкость {{< formula >}}\xi{{< /formula >}} в диапазоне 50–80 % отн. вл.
2. Изменение хранимой влаги на 1 м² при скачке RH от 50 до 80 %.
3. Практическое значение буферизации влаги (MBV).

**1. Влагоёмкость:**

{{< formula display="true" >}}
\xi = \frac{\Delta w}{\Delta\varphi} = \frac{0{,}028 - 0{,}012}{0{,}80 - 0{,}50} = \frac{0{,}016}{0{,}30} = 0{,}053\;\text{кг/кг на ед. }\varphi
{{< /formula >}}

**2. Хранимая влага на 1 м² при скачке RH:**

Объёмная влагоёмкость:
{{< formula display="true" >}}
\xi_v = \rho_0\,\xi = 1600\times 0{,}053 = 84{,}8\;\text{кг/(м}^3\text{ · ед. }\varphi\text{)}
{{< /formula >}}

Изменение хранимой влаги:
{{< formula display="true" >}}
\Delta m = \xi_v\,\Delta\varphi\,d = 84{,}8\times 0{,}30\times 0{,}020 = 0{,}51\;\text{кг/м}^2
{{< /formula >}}

**3. Практическое значение MBV** (moisture buffer value, г/(м²·% отн. вл.) по ISO 24353):

{{< formula display="true" >}}
\mathrm{MBV} = \frac{\Delta m}{\Delta\varphi[\%]} = \frac{510\;\text{г/м}^2}{30\;\%} = 17\;\text{г/(м}^2\text{·\%)}
{{< /formula >}}

Это значение существенно выше, чем у гипсокартона (MBV ≈ 5–7 г/(м²·%)), что подтверждает высокую буферную ёмкость глиняной штукатурки. Для суточных 8-часовых циклов с глубиной проникновения ~5 мм эффективный MBV составит около 2–4 г/(м²·%), что соответствует литературным данным.

## Параметры базы данных WUFI

WUFI требует следующие данные функции хранения влаги:

- **{{< formula >}}w_f{{< /formula >}}** — насыщение свободной водой (free water saturation), кг/м³ — максимальное влагосодержание при капиллярном насыщении.
- **{{< formula >}}w_{80}{{< /formula >}}** — влагосодержание при 80 % отн. вл., кг/м³.
- **Параметр формы {{< formula >}}b{{< /formula >}}** (5–15) уравнения Кюнцеля.

Процесс определения параметров:
1. Измерить изотерму сорбции (минимум 6 точек: 0, 30, 50, 75, 90, 95 % отн. вл.) по ISO 12571.
2. Определить {{< formula >}}w_f{{< /formula >}} испытанием капиллярного насыщения (EN ISO 15148 или вакуумное насыщение).
3. Подогнать уравнение Кюнцеля к измеренным данным МНК.
4. Верифицировать по независимым контрольным точкам.
5. Убедиться, что {{< formula >}}w_f < \varepsilon\,\rho_w{{< /formula >}} (не превышает общей пористости).

## Методы измерения

### Эксикаторный метод (ISO 12571)

Стандартная гравиметрическая методика:
1. Образцы кондиционируют над растворами насыщенных солей при постоянной температуре (23 °C).
2. Периодически взвешивают до достижения равновесия (изменение массы < 0,1 % за 7 суток).
3. Вычисляют влагосодержание: {{< formula >}}w = (m_\text{вл} - m_\text{сух})/m_\text{сух}{{< /formula >}}.

{{< table title="Растворы насыщенных солей для кондиционирования" >}}
| Соль | RH при 23 °C, % | Диапазон |
|---|---|---|
| LiCl | 11 | Нижний гигроскопический |
| MgCl₂ | 33 | Нижний гигроскопический |
| Mg(NO₃)₂ | 54 | Средний |
| NaCl | 75 | Верхний гигроскопический |
| KCl | 85 | Переходный |
| K₂SO₄ | 97 | Начало капиллярного |
{{< /table >}}

### Динамическая сорбция пара (DVS)

Автоматизированный метод с высоким разрешением: масса образца 10–100 мг; управление RH с точностью ±0,5 %; разрешение весов 0,1 мкг; полная изотерма за 24–72 ч. Одновременно получаются кривые адсорбции и десорбции.

### Метод пластины давления (ASTM D6836)

Для надгигроскопического диапазона:
1. Насытить образец на пористой керамической пластине.
2. Ступенчато прикладывать давление воздуха (1–1500 кПа).
3. Ждать дренажного равновесия (дни–недели).
4. Гравиметрически измерить влагосодержание.

Диапазон эквивалентной относительной влажности: 99,3 % (1 кПа) — 0,1 % (1500 кПа).

### Центрифугирование

Ускоренное определение кривых удержания: центробежная сила имитирует капиллярное давление. Скорость выполнения выше, чем у метода пластины (часы против недель), однако ограничена относительно проницаемыми материалами.

## Температурная зависимость

Функции хранения влаги зависят от температуры по трём причинам:

1. **Изменение поверхностного натяжения:** {{< formula >}}\sigma{{< /formula >}} снижается от 0,0758 Н/м при 0 °C до 0,0589 Н/м при 100 °C.
2. **Изостерическая теплота сорбции:** 2000–5000 Дж/моль выше теплоты испарения.
3. **Сдвиг капиллярной конденсации** по уравнению Кельвина с ростом температуры.

Для большинства расчётов в диапазоне −20 °C…+60 °C изотермы, измеренные при 23 °C, обеспечивают приемлемую точность. При экстремальных температурах применяют поправку через уравнение Клапейрона–Клаузиуса.

## Проектные рекомендации

### Использование высокобуферных материалов

Материалы с высокой влагоёмкостью {{< formula >}}\xi{{< /formula >}} в рабочем диапазоне относительной влажности:
- сглаживают переходные скачки влажности в помещении;
- снижают пиковые значения RH у поверхностей, уменьшая риск конденсации;
- ускоряют восстановление после намокания.

Рекомендуемое размещение: гигроскопичные материалы — со стороны помещения (деревянная обшивка, целлюлозная изоляция, глиняная штукатурка, известковая штукатурка).

### Контроль качества входных данных для моделирования

Перед использованием в WUFI или DELPHIN проверить:
- {{< formula >}}w_{80}{{< /formula >}} соответствует публикуемым диапазонам для данного типа материала;
- {{< formula >}}w_f{{< /formula >}} не превышает произведения пористости на плотность воды;
- кривая десорбции расположена выше кривой адсорбции во всём диапазоне;
- коэффициент капиллярного поглощения {{< formula >}}A_w{{< /formula >}} согласован с {{< formula >}}w_f{{< /formula >}} через соотношение {{< formula >}}A_w^2 \approx D_{w,s}\,w_\text{cap}\,\rho_0{{< /formula >}}.

Несогласованные данные приводят к систематическому завышению накопления влаги или занижению скоростей высыхания.

### Практические примеры применения

**Прогноз риска плесени.** Плесень инициируется при RH на поверхности > 80 % в течение ≥ 7 суток (ASHRAE 160). Материалы с высокой {{< formula >}}\xi{{< /formula >}} снижают пиковые значения RH на внутренних поверхностях.

**Оценка морозного разрушения.** Критическое насыщение {{< formula >}}S_\text{крит} = 0{,}9\,w_\text{cap}/(\varepsilon\,\rho_w){{< /formula >}}. Функция хранения влаги определяет, при каких граничных условиях достигается {{< formula >}}S_\text{крит}{{< /formula >}}.

**Расчёт времени высыхания.** Время перераспределения влаги зависит от {{< formula >}}\xi{{< /formula >}} и {{< formula >}}D_w{{< /formula >}} совместно. Высокая {{< formula >}}\xi{{< /formula >}} замедляет высыхание — это необходимо учитывать при выборе капиллярно-активных систем.

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — изотермы сорбции и данные влагоёмкости для типовых материалов.
- **ASHRAE 160** — критерии расчётного анализа контроля влаги.
- **ISO 12571** — гигроскопические свойства строительных материалов; определение изотерм сорбции.
- **ISO 12572** — паропроницаемость строительных материалов.
- **ASTM C1498** — гигроскопические изотермы сорбции методом динамической сорбции пара.
- **ASTM D6836** — характеристики удержания воды в пористых материалах.
- **EN ISO 15148** — коэффициент капиллярного поглощения.
- **ГОСТ 25898** — паропроницаемость и сорбционное увлажнение строительных материалов.
- **СП 50.13330.2017** — тепловая защита зданий.
- **СП 23-101-2004** — проектирование тепловой защиты зданий.
