Внешнее обтекание — поток жидкости или газа вокруг тела, где пограничный слой формируется вдоль поверхности, не заполняя всю область течения. Это принципиальное отличие от внутреннего течения в трубах, где профиль скорости ограничен стенками. В системах ОВК задачи внешнего обтекания определяют теплоотдачу в трубчато-рёберных теплообменниках, аэродинамическое сопротивление воздухозаборных шахт и корпусов оборудования, ветровые нагрузки на наружное оборудование.

## Классификация внешнего обтекания

{{< table title="Режимы внешнего обтекания по числу Рейнольдса (плоская пластина)" >}}
| Режим | Re_L | Характер пограничного слоя | Применение ОВК |
|---|---|---|---|
| Ламинарный | < 5×10⁵ | Тонкий, стабильный, низкий α | Ламели теплообменников, тонкие плавники |
| Переходный | 5×10⁵ – 4×10⁶ | Смешанный, нестабильный | Лопатки вентилятора, ребра AHU |
| Турбулентный | > 4×10⁶ | Толстый, перемешанный, высокий α | Трубы конденсатора, кожухи оборудования |
{{< /table >}}

Характерная длина L для пластины — длина в направлении потока; для цилиндра — диаметр D; для здания — горизонтальный габарит в направлении ветра.

## Развитие пограничного слоя

### Толщина пограничного слоя скорости

Ламинарный слой (Блазиус):

{{< formula display="true" >}}
\frac{\delta}{x} = \frac{5{,}0}{\sqrt{Re_x}}, \quad \delta^* = \frac{1{,}72 x}{\sqrt{Re_x}}, \quad \theta = \frac{0{,}664 x}{\sqrt{Re_x}}
{{< /formula >}}

Турбулентный слой:

{{< formula display="true" >}}
\frac{\delta}{x} = \frac{0{,}37}{Re_x^{1/5}}, \quad \delta^* = \frac{0{,}046 x}{Re_x^{1/5}}, \quad \theta = \frac{0{,}036 x}{Re_x^{1/5}}
{{< /formula >}}

где `δ*` — толщина вытеснения (displacement thickness), `θ` — толщина потери импульса (momentum thickness).

**Пример роста слоя.** Ребро воздухоохладителя из алюминия: глубина ребра L = 60 мм (от лобовой до тыльной кромки), фронтальная скорость V = 3,0 м/с. Re_L = 3,0 × 0,060 / (15,1×10⁻⁶) = 11 920 — ламинарный режим по всей длине ребра.

Толщина пограничного слоя в конце ребра:

{{< formula display="true" >}}
\delta(L) = \frac{5{,}0 \times 0{,}060}{\sqrt{11920}} = \frac{0{,}300}{109{,}2} = 2{,}75 \text{ мм}
{{< /formula >}}

Это примерно 1,5-кратное расстояние между соседними рёбрами при шаге p = 2 мм. Значит, за первым рядом труб пограничные слои от соседних рёбер **перекрываются** — течение становится квазиканальным. Это один из аргументов в пользу увеличения шага рёбер от рядов к рядам (variable-pitch fin design).

### Профили скорости

Ламинарный профиль хорошо описывается аппроксимацией Польгаузена (кубический полином):

{{< formula display="true" >}}
\frac{u}{U_\infty} = \frac{3}{2}\frac{y}{\delta} - \frac{1}{2}\left(\frac{y}{\delta}\right)^3
{{< /formula >}}

Турбулентный профиль — степенной закон (n = 7 для Re = 10⁵–10⁷):

{{< formula display="true" >}}
\frac{u}{U_\infty} = \left(\frac{y}{\delta}\right)^{1/7}
{{< /formula >}}

Турбулентный профиль значительно «полнее» ламинарного: доля потока, несущего более 90 % скорости, составляет 70 % от толщины слоя против 50 % для ламинарного. Это объясняет, почему турбулентный пограничный слой устойчивее к отрыву при неблагоприятном градиенте давления.

## Коэффициент трения и потери давления

### Местный и средний коэффициент трения

Местный коэффициент трения (Стантон–Болдуин):

{{< formula display="true" >}}
c_{f,x} = \frac{\tau_w}{\rho U_\infty^2 / 2}
{{< /formula >}}

Для ламинарного слоя: c_f,x = 0,664 / √Re_x

Для турбулентного слоя: c_f,x = 0,0592 / Re_x^(1/5)

Средний коэффициент трения по длине пластины:

{{< formula display="true" >}}
\bar{C}_f = \frac{0{,}074}{Re_L^{1/5}} - \frac{A}{Re_L}
{{< /formula >}}

где A = 742 при Re_cr = 5×10⁵ (поправка на ламинарный участок).

### Потери давления в плоских каналах теплообменника

В реальных теплообменниках ребра образуют плоские каналы высотой H (расстояние между листами ребра). Давление теряется на трение о стенки канала и формирует «хвосты» — вихри на кромке ребра. Суммарный перепад давления на воздушной стороне змеевика (по стандарту ASHRAE RP-1282):

{{< formula display="true" >}}
\Delta P_{\text{возд}} = \frac{G_{\text{max}}^2}{2\rho_1}\left[(1 + \sigma^2)\left(\frac{\rho_1}{\rho_2} - 1\right) + f \frac{A}{A_c} \frac{\rho_1}{\bar{\rho}}\right]
{{< /formula >}}

где `G_max` — массовый поток через минимальное сечение, кг/(м²·с); `σ = A_c/A_фронт` — степень открытия; `A/A_c` — отношение полной теплопередающей поверхности к минимальному сечению; `ρ₁`, `ρ₂` — плотности на входе и выходе; `ρ̄` — средняя плотность.

## Теплоотдача на плоской поверхности

### Средний коэффициент теплоотдачи

Средняя теплоотдача для смешанного (ламинарный + турбулентный) пограничного слоя:

{{< formula display="true" >}}
\overline{Nu}_L = (0{,}037 Re_L^{4/5} - A) \Pr^{1/3}
{{< /formula >}}

где A = 871 при Re_cr = 5×10⁵. Это уравнение используется для расчёта теплоотдачи в каналах между параллельными рёбрами теплообменника при значительной длине (глубина 50–150 мм).

### Аналогия Рейнольдса для турбулентного потока

Связь между трением и теплоотдачей в турбулентном пограничном слое:

{{< formula display="true" >}}
St = \frac{Nu_x}{Re_x \Pr} = \frac{c_{f,x}}{2 \Pr^{-2/3}} \quad \Rightarrow \quad Nu_x = \frac{c_{f,x}}{2} Re_x \Pr^{1/3}
{{< /formula >}}

Это «аналогия Колберна» (Chilton-Colburn j-factor). Она означает, что любая мера по увеличению трения (оребрение, гофрирование поверхности) пропорционально увеличивает теплоотдачу. j-фактор Колберна широко используется в справочниках по компактным теплообменникам (Kays & London, «Compact Heat Exchangers»):

{{< formula display="true" >}}
j = St \cdot \Pr^{2/3} = \frac{Nu}{Re \cdot \Pr^{1/3}}
{{< /formula >}}

## Отрыв потока и его последствия для ОВК

Отрыв (сепарация) пограничного слоя происходит при наличии положительного (неблагоприятного) градиента давления — давление нарастает по направлению течения. У тупых тел отрыв неизбежен; за точкой отрыва формируется «мёртвая зона» с рециркуляцией.

**Практические последствия:**

1. **Задняя поверхность ребра** при глубоком рёберном поле (> 60–80 мм): отрыв снижает местную теплоотдачу до 20–40 % от значения у передней кромки. Лувровые рёбра (louvred fins) решают эту проблему, «перезапуская» пограничный слой на каждом ламеле.

2. **Тыльная сторона кожухов наружных блоков**: зона сниженного давления создаёт дополнительное аэродинамическое сопротивление при установке в закрытых пространствах (атриумы, ниши). CFD-моделирование показывает, что суммарное сопротивление может превышать расчётное в 1,5–2,0 раза.

3. **Заборные шахты вентиляции**: при угловом входе (не перпендикулярном) образуются отрывные зоны, снижающие эффективное сечение на 20–40 %. Применение входных конфузоров с радиусом закругления r ≥ 0,15D снижает коэффициент потерь с 0,5 до 0,09.

## Числовой пример: оценка теплоотдачи наружной поверхности трубы

**Условие.** Одиночная медная труба наружного диаметра D = 22 мм в воздушном потоке V_∞ = 4,5 м/с (T_возд = 20 °C). Найти средний коэффициент теплоотдачи.

**Число Рейнольдса:**

{{< formula display="true" >}}
Re_D = \frac{V_\infty D}{\nu} = \frac{4{,}5 \times 0{,}022}{15{,}1 \times 10^{-6}} = \frac{0{,}099}{1{,}51 \times 10^{-5}} = 6556
{{< /formula >}}

**Число Нуссельта по Churchill & Bernstein:**

{{< formula display="true" >}}
\overline{Nu}_D = 0{,}3 + \frac{0{,}62 \times 6556^{0{,}5} \times 0{,}71^{1/3}}{[1 + (0{,}4/0{,}71)^{2/3}]^{1/4}} \left[1 + \left(\frac{6556}{282000}\right)^{5/8}\right]^{4/5}
{{< /formula >}}

Члены:
- 6556^0,5 = 80,97; 0,71^(1/3) = 0,893 → числитель: 0,62 × 80,97 × 0,893 = 44,8
- (0,4/0,71)^(2/3) = (0,563)^(0,667) = 0,676 → [1 + 0,676]^(1/4) = 1,676^0,25 = 1,136 → знаменатель: 1,136
- (6556/282000)^(5/8) = (0,02325)^0,625 = 0,0716 → [1 + 0,0716]^(4/5) = 1,0716^0,8 = 1,057

{{< formula display="true" >}}
\overline{Nu}_D = 0{,}3 + \frac{44{,}8}{1{,}136} \times 1{,}057 = 0{,}3 + 39{,}4 \times 1{,}057 = 0{,}3 + 41{,}7 = 42{,}0
{{< /formula >}}

**Коэффициент теплоотдачи:**

{{< formula display="true" >}}
\alpha = \frac{\overline{Nu}_D \cdot \lambda_{\text{возд}}}{D} = \frac{42{,}0 \times 0{,}0257}{0{,}022} = \frac{1{,}079}{0{,}022} = \mathbf{49{,}1 \text{ Вт/(м}^2\text{·К)}}
{{< /formula >}}

Это значение характеризует одиночную трубу. В реальном пучке (шахматное или коридорное расположение) для первого ряда α близко к этому значению, а для последующих рядов возрастает на 10–40 % из-за турбулентного следа предыдущих труб.
