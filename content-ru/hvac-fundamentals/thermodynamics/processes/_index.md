## Общая схема анализа процесса

Для любого термодинамического процесса необходимо установить:

1. **Ограничение** (что остаётся постоянным или нулевым)
2. **Начальное и конечное состояние** (два независимых свойства в каждой точке)
3. **Работу** по уравнению для закрытой системы {{< formula >}}W = \int P\,dV{{< /formula >}} или открытой системы {{< formula >}}W_s = -\int V\,dP{{< /formula >}}
4. **Теплообмен** из первого закона: {{< formula >}}Q = \Delta U + W{{< /formula >}} (закрытая) или {{< formula >}}Q = \Delta H + W_s{{< /formula >}} (открытая)
5. **Изменение энтропии** для оценки обратимости

## Изобарный процесс (isobaric process)

**Условие**: {{< formula >}}P = \text{const}, \; dP = 0{{< /formula >}}.

### Уравнения

Для идеального газа из {{< formula >}}Pv = RT{{< /formula >}} следует {{< formula >}}v/T = \text{const}{{< /formula >}}:

{{< formula display="true" >}}
\frac{V_2}{V_1} = \frac{T_2}{T_1}
{{< /formula >}}

Граничная работа:

{{< formula display="true" >}}
W_{boundary} = P(V_2 - V_1) = mR(T_2 - T_1)
{{< /formula >}}

Теплообмен (равен изменению энтальпии при P = const):

{{< formula display="true" >}}
Q = \Delta H = mc_p(T_2 - T_1)
{{< /formula >}}

Изменение внутренней энергии:

{{< formula display="true" >}}
\Delta U = mc_v(T_2 - T_1) = Q - W
{{< /formula >}}

### Применение в HVAC

Нагревательный и охлаждающий змеевики работают при атмосферном давлении или при постоянном давлении теплоносителя — типичный изобарный процесс. Энергетический баланс змеевика:

{{< formula display="true" >}}
\dot{Q} = \dot{m}_a (h_{a,out} - h_{a,in})
{{< /formula >}}

Для сухого воздуха при малом перепаде температур {{< formula >}}\dot{Q} \approx \dot{m}_a c_p \Delta T{{< /formula >}}.

**Числовой пример.** Объёмный расход воздуха через нагревательный змеевик: 2000 м³/ч при стандартных условиях (ρ = 1,20 кг/м³). Нагрев с 15 °C до 40 °C. Определить тепловую мощность.

{{< formula display="true" >}}
\dot{m}_a = \frac{2000}{3600} \times 1{,}20 = 0{,}667 \text{ кг/с}
{{< /formula >}}

{{< formula display="true" >}}
\dot{Q} = 0{,}667 \times 1{,}005 \times (40 - 15) = 16{,}7 \text{ кВт}
{{< /formula >}}

## Изотермный процесс (isothermal process)

**Условие**: {{< formula >}}T = \text{const}, \; dT = 0{{< /formula >}}.

### Уравнения

Для идеального газа: {{< formula >}}Pv = \text{const}{{< /formula >}}, {{< formula >}}P_1 V_1 = P_2 V_2{{< /formula >}}.

Работа (закрытая система):

{{< formula display="true" >}}
W = \int_{V_1}^{V_2} P\,dV = P_1 V_1 \ln\frac{V_2}{V_1} = mRT \ln\frac{P_1}{P_2}
{{< /formula >}}

Для идеального газа {{< formula >}}\Delta U = 0{{< /formula >}}, поэтому {{< formula >}}Q = W{{< /formula >}}.

### Применение в HVAC

Конденсация и испарение хладагента при постоянном давлении (и, следовательно, постоянной температуре насыщения) — приближённо изотермные процессы. Точнее: при скользящей температуре (temperature glide) смесевых хладагентов (R-410A, R-454B) это условие выполняется лишь приблизительно.

**Изотермное сжатие как идеал.** Теоретически изотермное сжатие требует минимальной работы:

{{< formula display="true" >}}
w_{isoth} = RT \ln\frac{P_2}{P_1}
{{< /formula >}}

Сравнение с изоэнтропным сжатием позволяет оценить экономию от промежуточного охлаждения многоступенчатых компрессоров.

## Изохорный процесс (isochoric / isometric process)

**Условие**: {{< formula >}}V = \text{const}, \; dV = 0{{< /formula >}}, следовательно {{< formula >}}W_{boundary} = 0{{< /formula >}}.

### Уравнения

{{< formula display="true" >}}
\frac{P_2}{P_1} = \frac{T_2}{T_1}
{{< /formula >}}

{{< formula display="true" >}}
Q = \Delta U = mc_v(T_2 - T_1)
{{< /formula >}}

### Применение в HVAC

Нагрев или охлаждение хладагента в герметичном закрытом сосуде (ресивер, балластная ёмкость). При нагреве ёмкости давление растёт пропорционально абсолютной температуре — это основа расчёта предохранительных клапанов по ГОСТ Р 52857-2007 и EN 13445.

## Изоэнтропный процесс (isentropic process)

**Условие**: {{< formula >}}s = \text{const}}{{< /formula >}} (обратимый адиабатный процесс: {{< formula >}}Q = 0{{< /formula >}}, {{< formula >}}\sigma_{gen} = 0{{< /formula >}}).

### Уравнения для идеального газа с постоянными теплоёмкостями

{{< formula display="true" >}}
P V^k = \text{const}, \qquad k = \frac{c_p}{c_v}
{{< /formula >}}

{{< formula display="true" >}}
\frac{T_2}{T_1} = \left(\frac{P_2}{P_1}\right)^{\!\frac{k-1}{k}} = \left(\frac{V_1}{V_2}\right)^{\!k-1}
{{< /formula >}}

Работа потока (открытая система):

{{< formula display="true" >}}
w_s = \frac{k}{k-1} R T_1 \left[\left(\frac{P_2}{P_1}\right)^{\!\frac{k-1}{k}} - 1\right]
{{< /formula >}}

Для реальных хладагентов изоэнтропное состояние определяется по таблицам: задаётся {{< formula >}}(P_2, s_2 = s_1){{< /formula >}}, из таблиц перегретого пара находится {{< formula >}}h_{2s}{{< /formula >}}.

### Изоэнтропный КПД компрессора

Реальный компрессор работает с необратимостями, поэтому:

{{< formula display="true" >}}
\eta_{s,comp} = \frac{w_{s,ideal}}{w_{s,actual}} = \frac{h_{2s} - h_1}{h_{2,actual} - h_1}
{{< /formula >}}

Типичные значения: поршневые компрессоры 0,75–0,82; спиральные 0,72–0,80; винтовые 0,75–0,85; центробежные 0,76–0,84 (ASHRAE Handbook — Refrigeration 2022, Chapter 37).

### Числовой пример: реальное сжатие R-32

**Условие.** Хладагент R-32 всасывается компрессором при P₁ = 0,852 МПа, t₁ = 5 °C (перегрев 5 К). Степень давления π = P₂/P₁ = 3,0. Изоэнтропный КПД η_s = 0,78. Найти температуру нагнетания и удельную работу сжатия.

По REFPROP для R-32: h₁ = 565,3 кДж/кг, s₁ = 2,243 кДж/(кг·К).

При P₂ = 0,852 × 3,0 = 2,556 МПа и s₂s = 2,243 кДж/(кг·К): h₂s = 618,4 кДж/кг, T₂s ≈ 62 °C.

{{< formula display="true" >}}
h_{2,actual} = h_1 + \frac{h_{2s} - h_1}{\eta_s} = 565{,}3 + \frac{618{,}4 - 565{,}3}{0{,}78} = 565{,}3 + 68{,}1 = 633{,}4 \text{ кДж/кг}
{{< /formula >}}

По таблицам при P₂ = 2,556 МПа и h₂ = 633,4 кДж/кг: T₂ ≈ 79 °C — реальная температура нагнетания.

Удельная работа сжатия: {{< formula >}}w = 633{,}4 - 565{,}3 = 68{,}1{{< /formula >}} кДж/кг.

## Политропный процесс (polytropic process)

**Условие**: {{< formula >}}Pv^n = \text{const}{{< /formula >}}, где n — политропный показатель.

### Частные случаи

{{< table title="Связь политропного показателя с типами процессов" >}}
| Значение n | Процесс | Постоянная величина |
|---|---|---|
| 0 | Изобарный | P |
| 1 | Изотермный | T (для идеального газа) |
| k = cp/cv | Изоэнтропный | s |
| ∞ | Изохорный | V |
| 1 < n < k | Реальное сжатие с теплоотводом | — |
{{< /table >}}

### Уравнения политропного процесса

{{< formula display="true" >}}
\frac{T_2}{T_1} = \left(\frac{P_2}{P_1}\right)^{\!\frac{n-1}{n}} = \left(\frac{v_1}{v_2}\right)^{\!n-1}
{{< /formula >}}

Работа потока (открытая система):

{{< formula display="true" >}}
w_s = \frac{n}{n-1} R T_1 \left[\left(\frac{P_2}{P_1}\right)^{\!\frac{n-1}{n}} - 1\right] \quad (n \neq 1)
{{< /formula >}}

Теплообмен:

{{< formula display="true" >}}
q = c_n (T_2 - T_1), \qquad c_n = c_v \frac{k - n}{1 - n}
{{< /formula >}}

### Определение n из экспериментальных данных

{{< formula display="true" >}}
n = \frac{\ln(P_2/P_1)}{\ln(v_1/v_2)}
{{< /formula >}}

Для поршневых компрессоров с водяным охлаждением обычно n = 1,20–1,28; для безмасляных воздушных компрессоров n ≈ 1,35 (ближе к адиабатному).

### Политропная эффективность (polytropic efficiency)

При многоступенчатом сжатии более информативна политропная эффективность:

{{< formula display="true" >}}
\eta_p = \frac{k-1}{k} \cdot \frac{n}{n-1}
{{< /formula >}}

Политропная эффективность не зависит от степени давления — в отличие от изоэнтропной. Применяется при сравнении центробежных компрессоров.

## Дроссельный процесс (throttling process)

**Условие**: {{< formula >}}h = \text{const}{{< /formula >}} (изоэнтальпийный процесс, isenthalpic). Адиабатный (Q = 0) и без совершения работы (W_s = 0).

### Первый закон для дроссельного устройства

{{< formula display="true" >}}
h_1 = h_2
{{< /formula >}}

Давление снижается: P₂ < P₁. Энтропия возрастает (необратимый процесс): s₂ > s₁.

### Коэффициент Джоуля–Томсона

Для реальных газов температура после дросселирования изменяется. Коэффициент Джоуля–Томсона (Joule–Thomson coefficient):

{{< formula display="true" >}}
\mu_{JT} = \left(\frac{\partial T}{\partial P}\right)_h = \frac{1}{c_p}\left[T\left(\frac{\partial v}{\partial T}\right)_P - v\right]
{{< /formula >}}

Для идеального газа {{< formula >}}\mu_{JT} = 0{{< /formula >}} (T не изменяется). Для хладагентов при рабочих давлениях μ_JT < 0 — температура **падает** при снижении давления (охлаждающий эффект дросселирования и является полезным в холодильном цикле).

### Расчёт деструкции эксергии при дросселировании

Потери эксергии (деструкция) при изоэнтальпийном дросселировании:

{{< formula display="true" >}}
\dot{E}x_{destr} = \dot{m} T_0 (s_2 - s_1) = \dot{m} T_0 \cdot \Delta s_{irr}
{{< /formula >}}

Это обосновывает замену расширительного клапана турбодетандером в крупных установках: возврат работы расширения повышает COP на 5–12 %.

### Применение в HVAC

{{< table title="Дроссельные устройства в системах HVAC" >}}
| Устройство | Принцип регулирования | Типичный ΔP, кПа | Применение |
|---|---|---|---|
| ТРВ (терморегулирующий вентиль) | Перегрев пара на выходе испарителя | 500–2000 | Сплит-системы, чиллеры |
| ЭРВ (электронный расширительный клапан) | Электронный контроль по перегреву и другим параметрам | 200–2500 | Инверторные системы, VRF |
| Капиллярная трубка | Фиксированное гидравлическое сопротивление | 200–1500 | Бытовые кондиционеры, малые холодильники |
| Поплавковый клапан | Уровень жидкости | 200–800 | Затопленные испарители |
| Перепускной клапан | Дифференциальное давление | 50–500 | Защита систем от избыточного давления |
{{< /table >}}

## Адиабатный процесс

**Условие**: {{< formula >}}Q = 0{{< /formula >}} (нет теплообмена с окружающей средой).

Из первого закона для открытой системы:

{{< formula display="true" >}}
w_s = h_1 - h_2
{{< /formula >}}

**Обратимый адиабатный** = изоэнтропный (рассмотрен выше).

**Необратимый адиабатный** (реальный компрессор): Q = 0, но σ_gen > 0, поэтому s₂ > s₁. Реальная работа больше изоэнтропной.

## Многоступенчатое сжатие с промежуточным охлаждением

При высоких степенях давления (π > 6) одноступенчатое сжатие неэффективно из-за высокой температуры нагнетания и роста необратимостей. Двухступенчатое сжатие с промежуточным охлаждением позволяет приблизиться к изотермному сжатию.

### Оптимальная промежуточная ступень давления

{{< formula display="true" >}}
P_{int} = \sqrt{P_1 \cdot P_2}
{{< /formula >}}

При этом работа каждой ступени одинакова (равнодольное разделение работы). Снижение общей работы сжатия по сравнению с одноступенчатым:

{{< formula display="true" >}}
\frac{w_{2-stage}}{w_{1-stage}} = \frac{2 \cdot \frac{n}{n-1} R T_1\left[\pi^{\frac{n-1}{2n}} - 1\right]}{\frac{n}{n-1} R T_1\left[\pi^{\frac{n-1}{n}} - 1\right]}
{{< /formula >}}

Для воздуха (n = 1,35) при π = 9 экономия составляет около 12–15 %.

## Типичные заблуждения

1. **«Дроссельный процесс сохраняет температуру».** Неверно. Для реальных хладагентов температура снижается. Только для идеального газа T₁ = T₂ при h₁ = h₂.
2. **«Изоэнтропный = адиабатный».** Изоэнтропный является частным случаем адиабатного (при условии обратимости). Реальные компрессоры могут быть практически адиабатными, но не изоэнтропными.
3. **«Политропный показатель — константа для данного газа».** n зависит от условий процесса (скорость, охлаждение) и является опытным параметром, а не свойством вещества.
