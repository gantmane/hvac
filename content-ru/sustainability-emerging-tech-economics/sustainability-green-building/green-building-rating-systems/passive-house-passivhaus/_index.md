## Обзор

Passive House (Passivhaus на немецком языке) представляет наиболее строгий добровольный стандарт энергетической эффективности в строительстве. Разработанный в институте Passive House в Дармштадте, Германия, этот стандарт достигает сокращения энергопотребления на отопление и охлаждение на 90% по сравнению с обычными зданиями за счет оптимизированной конструкции тепловой оболочки, исключительной герметичности и механической вентиляции с рекуперацией тепла.

Стандарт не зависит от климата и применяется глобально благодаря климатическим корректировкам в программном пакете Passive House Planning Package (PHPP).

## Критерии производительности

Сертификация Passive House требует соответствия строгим количественным пороговым значениям по множеству показателей:

### Пределы энергопотребления

| Критерий | Требование | Единицы |
|----------|-------------|-------|
| Годовое потребление на отопление | ≤ 15 | кВт·ч/(м²·год) |
| Годовое потребление на охлаждение | ≤ 15 | кВт·ч/(м²·год) |
| Тепловая нагрузка | ≤ 10 | Вт/м² |
| Первичное энергопотребление | ≤ 120 | кВт·ч/(м²·год) |
| Герметичность (ACH₅₀) | ≤ 0,6 | воздухообмены/час |
| Тепловой комфорт | ≥ 90% | часов/год |

**Примечание:** Все расчеты площади используют Treated Floor Area (TFA) — чистую площадь внутри кондиционируемого помещения.

### Расчет потребления на отопление

Удельное потребление на отопление рассчитывается по формуле:

```
Qₕ = (Qₜ + Qᵥ) - ηᵤ(Qₛ + Qᵢ)
```

Где:
- **Qₕ** = Годовое потребление на отопление (кВт·ч/год)
- **Qₜ** = Потери тепла передачей через оболочку (кВт·ч/год)
- **Qᵥ** = Потери тепла вентиляцией (кВт·ч/год)
- **Qₛ** = Солнечные теплопритоки через окна (кВт·ч/год)
- **Qᵢ** = Внутренние теплопритоки от людей и оборудования (кВт·ч/год)
- **ηᵤ** = Коэффициент использования теплопритоков (обычно 0,6–0,95)

### Первичное энергопотребление

Первичное энергопотребление из возобновляемых источников (PER) рассчитывается по формуле:

```
PER = Σ(Eᵢ × PEFᵢ)
```

Где:
- **Eᵢ** = Конечное энергопотребление для услуги i (отопление, охлаждение, горячее водоснабжение, приборы, вспомогательное потребление) (кВт·ч/год)
- **PEFᵢ** = Коэффициент первичной энергии для энергоносителя i
- PER не должно превышать 120 кВт·ч/(м²·год) для стандарта Classic

## Требования к тепловой оболочке

### Спецификации коэффициентов теплопередачи

Максимальные значения коэффициента теплопередачи (U-value) для компонентов Passive House:

| Компонент | Максимальный U-value | Типично достигаемый |
|-----------|----------------------|------------------|
| Стены | 0,15 Вт/(м²·К) | 0,10–0,12 Вт/(м²·К) |
| Крыша | 0,15 Вт/(м²·К) | 0,08–0,10 Вт/(м²·К) |
| Перекрытие на грунте | 0,15 Вт/(м²·К) | 0,10–0,12 Вт/(м²·К) |
| Окна (Uᵥ) | 0,80 Вт/(м²·К) | 0,60–0,75 Вт/(м²·К) |
| Остекление (Uₘ) | 0,60 Вт/(м²·К) | 0,50–0,55 Вт/(м²·К) |

## Требования к герметичности

### Стандарт испытаний дверью-вентилятором

Герметичность проверяется путём испытания нагнетанием давления согласно EN 13829 или ASTM E779:

**ACH₅₀ ≤ 0,6 воздухообменов в час при перепаде давления 50 Па**

Это соответствует приблизительно 0,03–0,05 ACH в естественных условиях.

**Расчёт скорости утечки воздуха:**

```
n₅₀ = (V₅₀ / Vₑₙᵥₑₗₒₚₑ) × 60
```

Где:
- **n₅₀** = Скорость воздухообмена при 50 Па (ACH₅₀)
- **V₅₀** = Измеренная скорость потока воздуха при 50 Па (м³/ч)
- **Vₑₙᵥₑₗₒₚₑ** = Объём внутри кондиционируемого помещения (м³)

### Критические детали герметичности

Непрерывный паробарьер должен быть обеспечен в:
- Всех проходах (электрических, сантехнических, HVAC)
- Проёмах окон и дверей
- Переходах оболочки (стена-крыша, стена-фундамент)
- Технических каналах и подвесных потолках

## Механическая вентиляция с рекуперацией тепла (MVHR)

### Требования к системе

Passive House требует постоянной сбалансированной вентиляции с высокоэффективной рекуперацией тепла:

| Параметр | Требование |
|----------|-------------|
| Эффективность рекуперации тепла (ηₕᵣ) | ≥ 75% (обычно 80–90%) |
| Электрическая эффективность | ≤ 0,45 Вт·ч/м³ |
| Минимальный воздухообмен | 0,3 ACH |
| Подача свежего воздуха | 30 м³/(ч·чел.) |

### Эффективность рекуперации тепла

Эффективность рекуперации явного тепла:

```
ηₕᵣ = (Tₛᵤₚₚₗᵧ - Tₒᵤₜdₒₒᵣ) / (Tᵢₙdₒₒᵣ - Tₒᵤₜdₒₒᵣ) × 100%
```

Пример: При температуре наружного воздуха –10°C, внутреннего 20°C и подаваемого 14°C:

```
ηₕᵣ = (14 - (-10)) / (20 - (-10)) = 24/30 = 80%
```

### Сокращение потерь тепла вентиляцией

Годовые потери тепла вентиляцией с рекуперацией:

```
Qᵥ = 0,33 × V̇ × HDD × (1 - ηₕᵣ)
```

Где:
- **V̇** = Скорость потока вентиляционного воздуха (м³/ч)
- **HDD** = Градусо-дни отопления (К·сут)
- **0,33** = Объёмная теплоёмкость воздуха (Вт·ч/(м³·К))

## Процесс сертификации

### Этапы проекта

**1. Этап проектирования**
- Энергетическое моделирование PHPP
- Оптимизация конструкции оболочки
- Расчёт размеров системы MVHR
- Анализ тепловых мостов
- Предварительная сертификация

**2. Этап строительства**
- Протоколы контроля качества
- Испытания герметичности (на середине строительства и окончательное)
- Проверка тепловизионной съёмкой
- Проверка правильности монтажа

**3. Сертификация**
- Окончательная подача PHPP
- Результаты испытания дверью-вентилятором ≤ 0,6 ACH₅₀
- Документирование фактических условий
- Выдача сертификата аккредитованным сертификатором

### Требования к моделированию PHPP

Пакет Passive House Planning Package (PHPP) требует детальных входных данных:
- Климатические данные (месячная температура, солнечное излучение, влажность)
- Геометрия здания и ориентация
- U-value всех компонентов оболочки
- Параметры окон (Uw, Ug, Uf, g-значение, Ψg)
- Каталог тепловых мостов (Ψ-значения)
- Спецификации системы вентиляции
- Эффективность системы отопления/охлаждения/ГВС
- Внутренние теплопритоки и расписание использования

## Классы Passive House

Три уровня сертификации соответствуют различным целям проекта:

| Класс | Первичное энергопотребление | Возобновляемое производство |
|-------|-------|----------|
| Classic | ≤ 120 кВт·ч/(м²·год) | Не требуется |
| Plus | ≤ 60 кВт·ч/(м²·год) | ≥ 60 кВт·ч/(м²·год) |
| Premium | ≤ 30 кВт·ч/(м²·год) | ≥ 120 кВт·ч/(м²·год) |

Все классы должны соответствовать одинаковым требованиям к потреблению на отопление/охлаждение и герметичности.

## Преимущества и вызовы

**Преимущества производительности:**
- Сокращение энергопотребления на отопление/охлаждение на 75–90%
- Исключение обычных систем HVAC во многих климатических зонах
- Превосходное качество внутреннего воздуха благодаря фильтруемой вентиляции
- Улучшенный тепловой комфорт с минимальной температурной стратификацией
- Устойчивость к колебаниям цен на энергоносители

**Вызовы при реализации:**
- Более высокие начальные затраты на строительство (премия 5–15%)
- Требует специализированного опыта в проектировании и строительстве
- Ограниченная доступность сертифицированных компонентов в некоторых регионах
- Более сложные конструктивные решения и контроль качества
- Требуется обучение пользователей для оптимальной эксплуатации

## Практические соображения

**Адаптация к климату:**
- Холодный климат: сосредоточиться на солнечных теплопритоках, минимизировать остекление с севера
- Жаркий климат: сократить остекление с юга, максимизировать затенение, потребление на охлаждение становится ограничивающим фактором
- Влажный климат: стратегии осушения, контроль влаги в оболочке

**Оптимизация затрат:**
- Простая, компактная форма здания уменьшает площадь оболочки
- Стратегическое размещение окон максимизирует пассивные солнечные теплопритоки
- Конструкция без тепловых мостов уменьшает требования к изоляции
- Оптимизация соотношения площади окон к стене (типично 20–30%)

Стандарт Passive House демонстрирует, что драматическое снижение энергопотребления достижимо благодаря интегрированному проектированию оболочки, прецизионному строительству и эффективным системам вентиляции, обеспечивая проверенный путь к зданиям с близким к нулевому энергопотреблением.
