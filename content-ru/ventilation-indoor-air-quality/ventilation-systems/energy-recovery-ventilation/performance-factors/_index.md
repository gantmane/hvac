## Основы эффективности

Производительность рекуператора энергии (ERV) количественно оценивается с помощью метрик эффективности, которые описывают способность устройства передавать явное и скрытое тепло между потоками воздуха. Эти метрики составляют основу для определения размера системы и анализа энергопотребления.

### Эффективность по явному теплу

Эффективность по явному теплу измеряет эффективность передачи температуры:

$$\epsilon_s = \frac{T_{supply} - T_{outdoor}}{T_{exhaust} - T_{outdoor}}$$

Где:
- $\epsilon_s$ = эффективность по явному теплу (безразмерная)
- $T_{supply}$ = температура воздуха подачи на выходе из ERV (°C)
- $T_{outdoor}$ = температура наружного воздуха на входе в ERV (°C)
- $T_{exhaust}$ = температура вытяжного воздуха на входе в ERV (°C)

Для режима отопления уравнение принимает вид:

$$\epsilon_s = \frac{T_{outdoor} - T_{supply}}{T_{outdoor} - T_{exhaust}}$$

### Эффективность по скрытому теплу

Эффективность по скрытому теплу количественно определяет способность передачи влаги:

$$\epsilon_l = \frac{W_{supply} - W_{outdoor}}{W_{exhaust} - W_{outdoor}}$$

Где:
- $\epsilon_l$ = эффективность по скрытому теплу (безразмерная)
- $W_{supply}$ = коэффициент влажности воздуха подачи на выходе из ERV (кг/кг)
- $W_{outdoor}$ = коэффициент влажности наружного воздуха на входе в ERV (кг/кг)
- $W_{exhaust}$ = коэффициент влажности вытяжного воздуха на входе в ERV (кг/кг)

### Полная эффективность

Полная эффективность учитывает как явную, так и скрытую передачу энергии:

$$\epsilon_t = \frac{h_{supply} - h_{outdoor}}{h_{exhaust} - h_{outdoor}}$$

Где:
- $\epsilon_t$ = полная эффективность (безразмерная)
- $h_{supply}$ = энтальпия воздуха подачи на выходе из ERV (кДж/кг)
- $h_{outdoor}$ = энтальпия наружного воздуха на входе в ERV (кДж/кг)
- $h_{exhaust}$ = энтальпия вытяжного воздуха на входе в ERV (кДж/кг)

## Протокол испытаний ASHRAE Standard 84

ASHRAE Standard 84-2020 устанавливает стандартизированные процедуры испытаний для воздухо-воздушных теплообменников. Этот стандарт обеспечивает согласованную отчётность о производительности между производителями.

### Условия испытаний

Стандартные условия оценки согласно ASHRAE 84:

| Параметр | Летнее условие | Зимнее условие |
|-----------|------------------|------------------|
| Наружная температура | 35°C | −15°C |
| Относительная влажность наружного воздуха | 40% | Не указана |
| Температура вытяжного воздуха | 24°C | 24°C |
| Относительная влажность вытяжного воздуха | 50% | 50% |
| Скорость на выходе | 3,05 м/с | 3,05 м/с |
| Баланс воздушных потоков | соотношение 1:1 | соотношение 1:1 |

### Измеренные метрики производительности

ASHRAE 84 требует измерения и отчётности по:

- Эффективности по явному теплу при различных расходах воздуха
- Эффективности по скрытому теплу (только для энтальпийных рекуператоров)
- Перепаду давления на обоих потоках воздуха
- Коэффициенту передачи вытяжного воздуха (EATR) для оценки перекрёстного загрязнения
- Потреблению мощности (если с приводом)

## Сравнительные данные производительности

Тип устройства ERV значительно влияет на характеристики производительности:

| Тип устройства | Эффективность по явному теплу | Эффективность по скрытому теплу | Перепад давления | Перекрёстное загрязнение |
|-------------|---------------|-------------|---------------|---------------------|
| Ротационное колесо | 75-85% | 70-80% | 99-197 Па | 1-5% EATR |
| Неподвижная пластина | 55-75% | 50-70% | 74-148 Па | <1% EATR |
| Тепловая труба | 45-65% | N/A | 49-123 Па | 0% EATR |
| Контурная схема | 50-65% | N/A | 123-247 Па | 0% EATR |
| Мембрана | 70-80% | 65-75% | 99-173 Па | <0,5% EATR |

Значения производительности при номинальном расчётном расходе воздуха с уравновешенными потоками.

## Соотношения перепада давления

Перепад давления через сердцевину ERV следует аэродинамическим принципам с зависимостью от расхода воздуха:

$$\Delta P = K \cdot \left(\frac{\dot{V}}{A}\right)^n$$

Где:
- $\Delta P$ = перепад давления (Па)
- $K$ = константа устройства (специфична для производителя)
- $\dot{V}$ = объёмный расход воздуха (м³/ч)
- $A$ = площадь выхода (м²)
- $n$ = показатель потока (обычно 1,8-2,0 для турбулентного потока)

### Влияние перепада давления на эффективность

Более высокие скорости на выходе снижают эффективность:

$$\epsilon_{actual} = \epsilon_{rated} \cdot \left(\frac{V_{rated}}{V_{actual}}\right)^{0.22}$$

Это соотношение демонстрирует типичное снижение производительности теплообменника на 22% в степени.

## Анализ перекрёстного загрязнения

Коэффициент передачи вытяжного воздуха (EATR) количественно определяет непредусмотренное смешивание:

$$EATR = \frac{C_{supply} - C_{outdoor}}{C_{exhaust} - C_{outdoor}}$$

Где:
- $C$ = концентрация газа-индикатора (млн⁻¹)
- Индексы указывают место измерения

ASHRAE 62.1 ограничивает EATR максимум 10% для приложений общей вентиляции. Критические среды требуют EATR < 1%.

### Перекрёстное загрязнение в зависимости от типа устройства

Механизмы физического разделения снижают загрязнение:

| Метод разделения | Типичный EATR | Пригодность применения |
|-------------------|--------------|-------------------------|
| Неподвижная пластина | <0,5% | Здравоохранение, лаборатории |
| Мембрана | <0,5% | Здравоохранение, общего назначения |
| Тепловая труба | 0% | Критические помещения |
| Контурная схема | 0% | Лаборатории, изоляция |
| Ротационное колесо (очистка) | 1-3% | Коммерческие, учреждения |
| Ротационное колесо (без очистки) | 3-5% | Общие коммерческие |

## Факторы деградации производительности

Эффективность ERV со временем снижается при различных условиях эксплуатации:

### Загрязнение и засорение

Накопление твёрдых частиц снижает эффективность поверхности теплопередачи. Соотношение коэффициента засорения:

$$\frac{1}{U_{actual}} = \frac{1}{U_{clean}} + R_f$$

Где:
- $U$ = общий коэффициент теплопередачи (Вт/(м²·К))
- $R_f$ = тепловое сопротивление засорения (м²·К/Вт)

Типичные скорости засорения: 0,00009-0,00035 (м²·К/Вт) в год в зависимости от фильтрации.

### Эффекты дисбаланса воздушных потоков

Неуравновешенные воздушные потоки снижают эффективность:

$$\epsilon_{imbalanced} = \epsilon_{balanced} \cdot \left(\frac{\dot{m}_{min}}{\dot{m}_{max}}\right)^{0.78}$$

Где:
- $\dot{m}_{min}$ = меньший массовый расход (кг/мин)
- $\dot{m}_{max}$ = больший массовый расход (кг/мин)

Поддерживайте баланс воздушных потоков в пределах 10% для оптимальной производительности.

### Образование инея

Зимняя эксплуатация при наружной температуре ниже −4°C создаёт риск накопления инея на холодных поверхностях. Иней снижает площадь прохода воздуха и эффективность. Стратегии профилактики:

- Предварительный нагрев наружного воздуха до минимум −4°C
- Байпас циркуляции при циклах оттаивания
- Модуляция скорости колеса (ротационные устройства)
- Ограничение температуры воздуха подачи

### Деградация уплотнений

Износ прокладок и уплотнений увеличивает утечку, повышая EATR и снижая эффективность. Рекомендуется ежегодный осмотр прокладок на предмет сжатия и целостности.

## Производительность в рабочей точке

Эффективность варьируется в зависимости от условий эксплуатации за пределами номинальных точек. Коэффициент коррекции для нестандартных условий:

$$\epsilon_{op} = \epsilon_{std} \cdot \left(\frac{NTU_{op}}{NTU_{std}}\right)^{0.78}$$

Где NTU (Число единиц передачи) представляет ёмкость теплообменника:

$$NTU = \frac{UA}{\dot{m} \cdot c_p}$$

Это соотношение позволяет прогнозировать производительность по всему рабочему диапазону, используя данные, указанные производителем.

## Практические соображения применения

Укажите требования к производительности ERV на основе:

- Минимально приемлемой эффективности при расчётном расходе воздуха
- Максимально допустимого перепада давления для бюджета энергии вентилятора
- Пределов EATR согласно требованиям кодекса применения
- Сезонного диапазона производительности для климатически-зависимой эксплуатации
- Доступа к техническому обслуживанию для периодической очистки и проверки уплотнений

Сертифицированные ASHRAE Standard 84 данные о производительности обеспечивают согласованное сравнение между производителями и устройствами для обоснованного выбора.
