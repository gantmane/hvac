Когда две или более реальных поверхности «видят» друг друга, между ними устанавливается обмен лучистыми потоками, зависящий от температур, излучательных свойств и взаимной геометрии. Для корректного описания этого обмена вводятся понятия радиозности и облучённости, а задача сводится к решению системы линейных уравнений — либо аналитически для простых случаев, либо численно для реальных помещений.

## Радиозность и облучённость

**Облучённость** G (irradiation, Вт/м²) — суммарный лучистый поток, падающий на единицу площади поверхности со всех направлений полусферы.

**Радиозность** J (radiosity, Вт/м²) — суммарный лучистый поток, покидающий единицу площади поверхности: собственное излучение плюс отражённая часть облучённости:

{{< formula display="true" >}}
J = \varepsilon \sigma T^4 + \rho G = \varepsilon \sigma T^4 + (1-\varepsilon) G
{{< /formula >}}

Чистый лучистый поток с поверхности i:

{{< formula display="true" >}}
q_i = J_i - G_i
{{< /formula >}}

Из определения радиозности и баланса энергии можно выразить чистый поток через разность между излучением чёрного тела и радиозностью:

{{< formula display="true" >}}
q_i = \frac{E_{bi} - J_i}{\dfrac{1-\varepsilon_i}{\varepsilon_i A_i}}
{{< /formula >}}

Величина (1 − εᵢ)/(εᵢAᵢ) играет роль «поверхностного сопротивления» в сетевой аналогии Операции (network analogy).

## Коэффициенты формы (view factors)

Коэффициент формы F_{i→j} — доля диффузного излучения, покидающего поверхность i и достигающего поверхности j:

{{< formula display="true" >}}
F_{i \to j} = \frac{1}{A_i} \iint_{A_i}\!\iint_{A_j} \frac{\cos\theta_i \cos\theta_j}{\pi r^2}\, dA_j\, dA_i
{{< /formula >}}

### Фундаментальные соотношения

**Взаимность:**

{{< formula display="true" >}}
A_i F_{i \to j} = A_j F_{j \to i}
{{< /formula >}}

**Суммирование** (для замкнутой оболочки из N поверхностей):

{{< formula display="true" >}}
\sum_{j=1}^{N} F_{i \to j} = 1
{{< /formula >}}

**Вогнутость:** для выпуклой поверхности F_{i→i} = 0; для вогнутой F_{i→i} > 0.

### Аналитические формулы для стандартных геометрий

{{< table title="Коэффициенты формы для геометрий, типичных в HVAC" >}}
| Геометрия | Условия | F₁₋₂ |
|---|---|---|
| Бесконечные параллельные плоскости | Любые A₁ = A₂ | 1,0 |
| Концентрические цилиндры (внутр. → внешн.) | r₁ < r₂ | 1,0 |
| Квадратная комната 1:1:1 (пол → потолок) | H = W = L | 0,20 |
| Прямоугольная комната 1:1:2 (пол → потолок) | H/W = 0,5 | 0,14 |
| Потолочная панель → пол (панель занимает 50 % потолка) | — | ≈ 0,30–0,45 |
| Две перпендикулярные полосы, общий край | w₁ = w₂ | 0,293 |
{{< /table >}}

Для произвольных прямоугольных поверхностей ASHRAE Fundamentals Ch. 4 и специализированные калькуляторы (например, ViewFactor.net) предоставляют аналитические двойные интегралы.

**Метод Хоттеля (перекрещённых шнуров)** для двумерных (бесконечно длинных) геометрий:

{{< formula display="true" >}}
A_1 F_{1-2} = \frac{(L_{AC} + L_{BD}) - (L_{BC} + L_{AD})}{2}
{{< /formula >}}

где L — длины перекрещённых и прямых шнуров между крайними точками двух поверхностей.

## Сетевая аналогия для систем серых диффузных поверхностей

Аналогия с электрической цепью позволяет наглядно решать задачи лучистого теплообмена. Каждый узел соответствует радиозности Jᵢ; «движущая сила» — разность Ebᵢ − Jᵢ или Jᵢ − Jⱼ; «сопротивления» — поверхностные и геометрические.

{{< diagram title="Сетевая аналогия лучистого теплообмена двух поверхностей" >}}
graph LR
    Eb1["E_b1 = σT₁⁴"] -- "(1-ε₁)/(ε₁A₁)" --> J1[J₁]
    J1 -- "1/(A₁F₁₂)" --> J2[J₂]
    J2 -- "(1-ε₂)/(ε₂A₂)" --> Eb2["E_b2 = σT₂⁴"]
    J1 -- "Q₁₋₂" --> J2
{{< /diagram >}}

Суммарное сопротивление и тепловой поток:

{{< formula display="true" >}}
Q_{1-2} = \frac{\sigma(T_1^4 - T_2^4)}{\dfrac{1-\varepsilon_1}{\varepsilon_1 A_1} + \dfrac{1}{A_1 F_{1-2}} + \dfrac{1-\varepsilon_2}{\varepsilon_2 A_2}}
{{< /formula >}}

### Частные случаи

**Два чёрных тела** (ε₁ = ε₂ = 1): поверхностные сопротивления исчезают, Q = A₁F₁₋₂σ(T₁⁴ − T₂⁴).

**Бесконечные параллельные плоскости** (F = 1, A₁ = A₂ = A):

{{< formula display="true" >}}
q_{1-2} = \frac{\sigma(T_1^4 - T_2^4)}{\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_2} - 1}
{{< /formula >}}

**Выпуклое тело, окружённое большой оболочкой** (A₂ ≫ A₁):

{{< formula display="true" >}}
Q_{1-2} \approx \varepsilon_1 A_1 \sigma (T_1^4 - T_2^4)
{{< /formula >}}

Вторая формула применима, например, к трубопроводу в большом техническом подполье: собственная излучательная способность трубы полностью определяет лучистые потери.

## Низкоэмиссионные покрытия и экраны

Добавление экрана с ε₃ между двумя параллельными плоскостями с ε₁ = ε₂:

{{< formula display="true" >}}
q_{\text{с экраном}} = \frac{\sigma(T_1^4 - T_2^4)}{\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_2} - 1 + \dfrac{1}{\varepsilon_{3a}} + \dfrac{1}{\varepsilon_{3b}} - 1}
{{< /formula >}}

При ε₃ = 0,05 и ε₁ = ε₂ = 0,90 добавление экрана снижает лучистый поток в ~20 раз. Именно на этом принципе работают:
- многокамерные стеклопакеты с low-e покрытием;
- фольгированные пароизоляционные мембраны с воздушным зазором;
- экраны вокруг тепловых трубопроводов в технических помещениях.

## Радиационные барьеры в ограждающих конструкциях

Фольгированный экран с ε = 0,05, обращённый в воздушный зазор шириной ≥ 25 мм, снижает лучистую составляющую теплопередачи через зазор:

{{< formula display="true" >}}
R_{\text{зазор}} = \frac{1}{h_r + h_c}, \quad h_r = \frac{4\sigma T_m^3}{\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_2} - 1}
{{< /formula >}}

При ε₁ = 0,05 (фольга) и ε₂ = 0,90 (утеплитель):

{{< formula display="true" >}}
h_r = \frac{4 \times 5{,}670 \times 10^{-8} \times 283^3}{\dfrac{1}{0{,}05} + \dfrac{1}{0{,}90} - 1} = \frac{0{,}516}{20,11} = 0{,}026 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

Без фольги (ε₁ = ε₂ = 0,90): hᵣ = 0,516 / 1,11 = 0,465 Вт/(м²·К). Снижение в 18 раз. С учётом конвекции в зазоре (hc ≈ 1,5 Вт/(м²·К)) итоговый эффект менее драматичен, но R-значение зазора всё равно возрастает с 0,16 до 0,55 м²·К/Вт — это соответствует дополнительной теплоизоляции ~70 мм минеральной ваты.

**Требования к эффективному применению радиационных барьеров** (ASHRAE Fundamentals Ch. 27; СП 50.13330-2017 Приложение Г):
1. Воздушный зазор ≥ 19 мм рядом с низкоэмиссионной поверхностью.
2. ε ≤ 0,10 после монтажа (загрязнение пылью повышает ε до 0,20–0,30).
3. Расположение с «воздушной стороны», а не в контакте с изолятором.
4. Учёт пароизоляционных свойств фольги в конструкции стены (недопустимость двусторонней пароизоляции).

## Излучение внутренних поверхностей помещения

Лучистый теплообмен всех внутренних поверхностей описывается системой уравнений для радиозностей Jᵢ при N поверхностях:

{{< formula display="true" >}}
J_i = \varepsilon_i \sigma T_i^4 + (1-\varepsilon_i) \sum_{j=1}^{N} F_{i \to j} J_j, \quad i = 1, \ldots, N
{{< /formula >}}

Для N = 4–6 поверхностей (зоны EnergyPlus) система решается прямым методом Гаусса. Для простых инженерных оценок применяется приближение средней температуры лучистого воздействия (MRT):

{{< formula display="true" >}}
q_{r,i} = h_{r,i} \cdot A_i \cdot (T_i - T_{\text{MRT}})
{{< /formula >}}

где hᵣ ≈ 5,5–6,0 Вт/(м²·К) при комнатных условиях.

## Тепловой комфорт: MRT и оперативная температура

Средняя температура лучистого воздействия (Mean Radiant Temperature, MRT):

{{< formula display="true" >}}
T_{\text{MRT}} = \left( \sum_{i} F_{p \to i} \cdot T_i^4 \right)^{1/4}
{{< /formula >}}

При малых перепадах температур (ΔT < 5 К) допускается линейная форма:

{{< formula display="true" >}}
T_{\text{MRT}} \approx \sum_i F_{p \to i} \cdot T_i
{{< /formula >}}

Оперативная температура по ASHRAE 55 / ISO 7730:

{{< formula display="true" >}}
T_o = \frac{h_c T_a + h_r T_{\text{MRT}}}{h_c + h_r}
{{< /formula >}}

При скоростях воздуха ≤ 0,2 м/с hc ≈ hᵣ, поэтому Tₒ ≈ (Tₐ + TMRT)/2.

### Асимметрия лучистой температуры

Дискомфорт возникает не только при низкой MRT, но и при её неравномерности. ASHRAE 55-2023 устанавливает предельные значения асимметрии лучистой температуры:

{{< table title="Допустимая асимметрия лучистой температуры (ASHRAE 55-2023)" >}}
| Направление | Предел, К | Характерный источник |
|---|---|---|
| Тёплый потолок | 5 | Высокотемпературные лучистые нагреватели |
| Холодная стена/окно | 10 | Одинарное остекление зимой |
| Холодный потолок | 14 | Некондиционируемое перекрытие |
| Тёплая стена | 23 | Солнечный нагрев стены, камин |
{{< /table >}}

Практическое следствие: однослойное остекление при T_нар = −10 °C даёт T_поверхности ≈ +5 °C. При T_воздуха = 22 °C пользователь у окна испытывает асимметрию ~17 К со стороны окна — выше предела в 10 К. Решение: низкоэмиссионный двухкамерный стеклопакет поднимает T_поверхности до ~17 °C, сокращая асимметрию до допустимых 5 К.

## Лучистые системы отопления и охлаждения

Суммарная теплоотдача лучистой панели включает конвективную и лучистую составляющие:

{{< formula display="true" >}}
q_{\text{total}} = q_r + q_c = h_r (T_p - T_{\text{MRT}}) + h_c (T_p - T_a)
{{< /formula >}}

{{< table title="Типовые параметры лучистых систем" >}}
| Тип системы | Температура поверхности, °C | h_total, Вт/(м²·К) | Доля лучистого потока |
|---|---|---|---|
| Тёплый пол (водяной) | 24–29 | 10–12 | 50–60 % |
| Потолочное отопление (панели) | 28–40 | 9–11 | 55–65 % |
| Потолочное охлаждение | 16–19 | 7–9 | 40–55 % |
| Высокотемпературный ИК-нагреватель | 200–1000 | — | >85 % |
{{< /table >}}

Ограничения по температуре поверхности пола (СП 60.13330, ASHRAE):
- Рабочая зона с постоянным пребыванием: ≤ 29 °C
- Периметровые зоны: ≤ 31 °C
- Ванные, плавательные бассейны: ≤ 33–35 °C

## Численный пример: теплоотдача потолочной лучистой панели

**Условие.** Потолочная панель водяного охлаждения: A_panel = 12 м², Tₚ = 17 °C (290 К). Помещение: Tₐ = 26 °C (299 К), T_MRT помещения без панели = 25 °C (298 К). Требуется определить охлаждающую мощность панели.

**Радиозный поток** (используем приближение «малое тело в большой оболочке», т. к. панель занимает малую часть потолка, ε_panel = 0,92):

{{< formula display="true" >}}
q_r = \varepsilon_p \sigma (T_{\text{MRT}}^4 - T_p^4)
= 0{,}92 \times 5{,}670 \times 10^{-8} \times (298^4 - 290^4)
{{< /formula >}}

{{< formula display="true" >}}
= 0{,}92 \times 5{,}670 \times 10^{-8} \times (7{,}886 \times 10^9 - 7{,}071 \times 10^9)
= 0{,}92 \times 46{,}2 = 42{,}5 \;\text{Вт/м}^2
{{< /formula >}}

**Конвективный поток** (естественная конвекция от охлаждаемого горизонтального потолка, hc ≈ 3,0 Вт/(м²·К)):

{{< formula display="true" >}}
q_c = h_c (T_a - T_p) = 3{,}0 \times (299 - 290) = 27{,}0 \;\text{Вт/м}^2
{{< /formula >}}

**Суммарная мощность панели:**

{{< formula display="true" >}}
Q_{\text{total}} = (q_r + q_c) \times A = (42{,}5 + 27{,}0) \times 12 = 834 \;\text{Вт}
{{< /formula >}}

Доля лучистой составляющей: 42,5 / 69,5 = 61 %. Это подтверждает, что лучистые панели отдают большую часть теплоты именно излучением — отсюда их преимущество: тепловой комфорт достигается при более высокой температуре воздуха, что снижает вентиляционные теплопотери.

**Проверка риска конденсации.** Точка росы воздуха при 26 °C и ОВ = 55 %: Tₛ ≈ 16,5 °C. Панель при 17 °C работает с запасом ~0,5 К — недостаточным при кратковременных пиках влажности. Рекомендуется минимальная уставка 18 °C или датчик точки росы с блокировкой подачи холодоносителя.

## Ночное радиационное охлаждение кровли

Эффективная температура ясного неба (приближение Сетиагарма):

{{< formula display="true" >}}
T_{\text{sky}} = T_a \left(0{,}711 + 0{,}0056 T_{dp} + 7{,}3 \times 10^{-5} T_{dp}^2\right)^{1/4}
{{< /formula >}}

где Tₐ и T_dp — в Кельвинах и °C соответственно. При ясном небе, Tₐ = 293 К, T_dp = 5 °C: T_sky ≈ 265 К (−8 °C). Кровельная поверхность с ε = 0,90 при T_roof = 293 К:

{{< formula display="true" >}}
q_{\text{net}} = \varepsilon \sigma (T_{\text{roof}}^4 - T_{\text{sky}}^4) = 0{,}90 \times 5{,}670 \times 10^{-8} \times (7{,}370 \times 10^9 - 4{,}916 \times 10^9) \approx 125 \;\text{Вт/м}^2
{{< /formula >}}

Такой поток способен охладить кровельную поверхность до температуры значительно ниже температуры воздуха, создавая риск конденсации и одновременно возможность пассивного ночного охлаждения здания в засушливых регионах.
