Реальные HVAC-задачи никогда не сводятся к двум изолированным поверхностям: в помещении одновременно «участвуют» пол, потолок, стены, окна, радиационные панели и жильцы. Корректный анализ таких систем требует метода замкнутых оболочек (enclosure method), в котором каждая поверхность связана с остальными через коэффициенты формы, а задача решается как система линейных уравнений относительно радиозностей. Этот раздел излагает строгую постановку и показывает, как она применяется в практических расчётах HVAC.

## Постановка задачи для N-поверхностной оболочки

Рассмотрим замкнутую оболочку из N серых диффузных непрозрачных поверхностей. Каждая поверхность i характеризуется: площадью Aᵢ, температурой Tᵢ, излучательной способностью εᵢ и матрицей коэффициентов формы Fᵢⱼ.

Облучённость поверхности i (суммарный поток, падающий на единицу её площади):

{{< formula display="true" >}}
G_i = \sum_{j=1}^{N} F_{i \to j} J_j
{{< /formula >}}

Радиозность поверхности i:

{{< formula display="true" >}}
J_i = \varepsilon_i \sigma T_i^4 + (1-\varepsilon_i) G_i = \varepsilon_i \sigma T_i^4 + (1-\varepsilon_i) \sum_{j=1}^{N} F_{i \to j} J_j
{{< /formula >}}

Чистый лучистый поток с поверхности i (положительный — потеря тепла):

{{< formula display="true" >}}
q_i = A_i (J_i - G_i) = \frac{\varepsilon_i A_i}{1-\varepsilon_i} (\sigma T_i^4 - J_i)
{{< /formula >}}

Последнее выражение справедливо только для ε ≠ 1; для чёрной поверхности Jᵢ = σTᵢ⁴ и qᵢ определяется напрямую из облучённости.

## Матричная форма системы уравнений

Подставляя выражение для Gᵢ в уравнение для Jᵢ, получаем систему N уравнений:

{{< formula display="true" >}}
J_i - (1-\varepsilon_i) \sum_{j=1}^{N} F_{i \to j} J_j = \varepsilon_i \sigma T_i^4, \quad i = 1, \ldots, N
{{< /formula >}}

В матричной форме:

{{< formula display="true" >}}
\mathbf{A}\,\mathbf{J} = \mathbf{b}
{{< /formula >}}

где Aᵢⱼ = δᵢⱼ − (1 − εᵢ)Fᵢⱼ, bᵢ = εᵢσTᵢ⁴.

Для N ≤ 6 (типичная зона EnergyPlus) система решается методом Гаусса или LU-разложением. После нахождения **J** тепловые потоки с каждой поверхности вычисляются по формуле выше.

**Условие замкнутости.** Если оболочка не полностью замкнута (например, открытое окно), добавляется «воображаемая» чёрная поверхность при температуре окружающей среды, поглощающая весь уходящий поток.

## Рефрактерные поверхности

Рефрактерная (переизлучающая, adiabatic) поверхность — поверхность с нулевым чистым тепловым потоком (qᵣ = 0): она поглощает столько же, сколько излучает. Физически это соответствует хорошо теплоизолированной стене или симметричной поверхности.

Из условия qᵣ = 0 следует Jᵣ = Gᵣ, то есть:

{{< formula display="true" >}}
J_r = \sum_{j=1}^{N} F_{r \to j} J_j
{{< /formula >}}

Рефрактерная поверхность не нагружается дополнительным тепловым сопротивлением в сети, но изменяет распределение потоков между остальными поверхностями. Её равновесная температура:

{{< formula display="true" >}}
T_r = \left(\frac{J_r}{\sigma}\right)^{1/4}
{{< /formula >}}

### Применение: нейтральная стена в трёхповерхностной оболочке

Рассмотрим замкнутое пространство из двух активных поверхностей (1 и 2) и одной рефрактерной (3). Эффективный поток от 1 к 2 с учётом перенаправления излучения через 3:

{{< formula display="true" >}}
Q_{1 \to 2} = \frac{\sigma(T_1^4 - T_2^4)}{\dfrac{1-\varepsilon_1}{\varepsilon_1 A_1} + \dfrac{1}{A_1 \mathcal{F}_{12}} + \dfrac{1-\varepsilon_2}{\varepsilon_2 A_2}}
{{< /formula >}}

где эффективный коэффициент формы:

{{< formula display="true" >}}
\mathcal{F}_{12} = F_{12} + \frac{F_{13} F_{32}}{1 - F_{33}}
{{< /formula >}}

(при F₃₃ = 0 для плоской или выпуклой рефрактерной поверхности).

## Радиационные экраны

Экран с малой излучательной способностью ε₃, размещённый между поверхностями 1 и 2 (параллельные плоскости):

{{< formula display="true" >}}
q_{12}^{\text{(с экраном)}} = \frac{\sigma(T_1^4 - T_2^4)}{\left(\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_2} - 1\right) + \left(\dfrac{1}{\varepsilon_{3a}} + \dfrac{1}{\varepsilon_{3b}} - 1\right)}
{{< /formula >}}

При N одинаковых экранах с ε_экр:

{{< formula display="true" >}}
q^{(N)} = \frac{\sigma(T_1^4 - T_2^4)}{\left(\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_2} - 1\right) + N\!\left(\dfrac{2}{\varepsilon_{\text{экр}}} - 1\right)}
{{< /formula >}}

{{< table title="Снижение лучистого потока при добавлении экранов (ε₁ = ε₂ = 0,90; ε_экр = 0,05)" >}}
| Число экранов N | Суммарное сопротивление | Поток q/q₀ | Снижение, % |
|---|---|---|---|
| 0 | 1,11 | 1,000 | — |
| 1 | 1,11 + 39,0 = 40,1 | 0,028 | 97,2 |
| 2 | 1,11 + 78,0 = 79,1 | 0,014 | 98,6 |
| 3 | 1,11 + 117 = 118 | 0,0094 | 99,1 |
{{< /table >}}

Равновесная температура одного экрана:

{{< formula display="true" >}}
T_3^4 = \frac{\dfrac{T_1^4}{\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_{3a}} - 1} + \dfrac{T_2^4}{\dfrac{1}{\varepsilon_{3b}} + \dfrac{1}{\varepsilon_2} - 1}}{\dfrac{1}{\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_{3a}} - 1} + \dfrac{1}{\dfrac{1}{\varepsilon_{3b}} + \dfrac{1}{\varepsilon_2} - 1}}
{{< /formula >}}

## Применение к помещению HVAC

### Шесть поверхностей прямоугольного помещения

В типовом расчёте теплового баланса помещения рассматривается оболочка из 6 поверхностей: пол (1), потолок (2), стены N/S/E/W (3–6). Для прямоугольного помещения L × W × H:

- F_{пол→потолок} вычисляется по формуле ASHRAE для параллельных прямоугольников;
- F_{пол→стена N} вычисляется по формуле для перпендикулярных прямоугольников с общим ребром;
- остальные — по правилам взаимности и суммирования.

**Инструменты.** EnergyPlus автоматически вычисляет матрицу Fᵢⱼ из геометрии IDF-модели методом лучевого трассирования (ray tracing); OpenStudio предоставляет визуализацию. Для ручного расчёта используются таблицы ASHRAE Fundamentals 2021, Ch. 4, Tables 3–7.

### Упрощённая модель MRT

Для быстрых оценок комфорта часто достаточно линейного приближения:

{{< formula display="true" >}}
T_{\text{MRT}} = \sum_i F_{p \to i} \cdot T_i
{{< /formula >}}

где Fₚ→ᵢ — коэффициент формы от человека к i-й поверхности. Для сидящего человека в типовом офисе:
- потолок: ≈ 0,18;
- пол: ≈ 0,18;
- каждая из 4 стен: ≈ 0,16.

### Влияние холодного окна на MRT

**Условие.** Комната 5 × 4 × 3 м. Стекло площадью 3 м² (одна стена, T_glass = 4 °C). Остальные поверхности: T = 20 °C. Требуется оценить MRT на расстоянии 0,5 м от окна.

Примерный коэффициент формы человек → окно при расстоянии 0,5 м: Fₚ→glass ≈ 0,18 (по таблицам ISO 7726).

{{< formula display="true" >}}
T_{\text{MRT}} \approx 0{,}18 \times 277 + (1 - 0{,}18) \times 293 = 49{,}9 + 240{,}3 = 290{,}2 \;\text{К} = 17{,}2 \;°\text{C}
{{< /formula >}}

При температуре воздуха 22 °C оперативная температура: Tₒ = (22 + 17,2)/2 = 19,6 °C. Дискомфорт очевиден несмотря на тёплый воздух. Замена на двухкамерный стеклопакет low-e (T_glass ≈ 17 °C):

{{< formula display="true" >}}
T_{\text{MRT}} \approx 0{,}18 \times 290 + 0{,}82 \times 293 = 52{,}2 + 240{,}3 = 292{,}5 \;\text{К} = 19{,}5 \;°\text{C}
{{< /formula >}}

Tₒ = (22 + 19,5)/2 = 20,75 °C — в пределах зоны комфорта ASHRAE 55.

## Численный пример: трёхповерхностная оболочка с рефрактерной стеной

**Условие.** Промышленная рабочая зона:
- Поверхность 1 (излучающая панель отопления): A₁ = 10 м², T₁ = 60 °C (333 К), ε₁ = 0,90.
- Поверхность 2 (рабочий стол / пол): A₂ = 10 м², T₂ = 15 °C (288 К), ε₂ = 0,85.
- Поверхность 3 (стены — рефрактерная): A₃ = 40 м², ε₃ = 0,90.

Коэффициенты формы (заданы геометрически): F₁₂ = 0,40, F₁₃ = 0,60, F₂₁ = 0,40, F₂₃ = 0,60, F₃₁ = 0,15, F₃₂ = 0,15, F₃₃ = 0,70.

**Шаг 1.** Вычислим Eb: Eb₁ = 5,670 × 10⁻⁸ × 333⁴ = 693 Вт/м²; Eb₂ = 5,670 × 10⁻⁸ × 288⁴ = 380 Вт/м².

**Шаг 2.** Поверхностные сопротивления:

{{< formula display="true" >}}
R_1 = \frac{1-\varepsilon_1}{\varepsilon_1 A_1} = \frac{0{,}10}{0{,}90 \times 10} = 0{,}0111 \;\text{м}^{-2}
{{< /formula >}}

{{< formula display="true" >}}
R_2 = \frac{1-\varepsilon_2}{\varepsilon_2 A_2} = \frac{0{,}15}{0{,}85 \times 10} = 0{,}0176 \;\text{м}^{-2}
{{< /formula >}}

**Шаг 3.** Эффективный коэффициент формы с учётом рефрактерной стены:

{{< formula display="true" >}}
\mathcal{F}_{12} = F_{12} + \frac{F_{13} F_{32}}{1 - F_{33}} = 0{,}40 + \frac{0{,}60 \times 0{,}15}{1 - 0{,}70} = 0{,}40 + 0{,}30 = 0{,}70
{{< /formula >}}

**Шаг 4.** Пространственное сопротивление:

{{< formula display="true" >}}
R_{12} = \frac{1}{A_1 \mathcal{F}_{12}} = \frac{1}{10 \times 0{,}70} = 0{,}143 \;\text{м}^{-2}
{{< /formula >}}

**Шаг 5.** Суммарный тепловой поток от панели к полу:

{{< formula display="true" >}}
Q_{1 \to 2} = \frac{693 - 380}{0{,}0111 + 0{,}143 + 0{,}0176} = \frac{313}{0{,}172} = 1820 \;\text{Вт}
{{< /formula >}}

Рефрактерные стены увеличили эффективный коэффициент формы с F₁₂ = 0,40 до ℱ₁₂ = 0,70 — соответствующий рост теплового потока в 0,70/0,40 = 1,75 раза. Это объясняет важность учёта отражения от стен при расчёте производительности высоких промышленных нагревателей.

## Лучистый теплообмен внутри воздуховодов

В металлических воздуховодах прямоугольного сечения при высоких температурах (> 90 °C) лучистая составляющая теплообмена между противоположными стенками становится значимой. Для длинного воздуховода ширина W × высота H (F₁₂ ≈ 1 для узких каналов):

{{< formula display="true" >}}
q_r \approx \frac{\sigma(T_{\text{горячая стенка}}^4 - T_{\text{холодная стенка}}^4)}{\dfrac{1}{\varepsilon_1} + \dfrac{1}{\varepsilon_2} - 1}
{{< /formula >}}

Для оцинкованного воздуховода (ε ≈ 0,25) при 120 °C (393 К) против 60 °C (333 К):

{{< formula display="true" >}}
q_r = \frac{5{,}670 \times 10^{-8}(393^4 - 333^4)}{\dfrac{1}{0{,}25} + \dfrac{1}{0{,}25} - 1} = \frac{5{,}670 \times 10^{-8} \times 1{,}169 \times 10^{10}}{7} = 94 \;\text{Вт/м}^2
{{< /formula >}}

При тех же условиях конвекция внутри воздуховода составляет порядка 20–30 Вт/(м²·К) × 30 К = 600–900 Вт/м², то есть лучистая составляющая ~94 Вт/м² добавляет 10–15 % — существенно при точном теплотехническом расчёте трубопроводов горячего воздуха в нагревательных системах.

## Камеры сгорания котлов

В топочной камере котла доминирует лучистый теплообмен: пламя и горячие газы излучают к охлаждаемым трубам и обмуровке. Задача решается как N-поверхностная оболочка с участием газового излучения CO₂ и H₂O (подробно — в разделе «Газовое излучение»). Ключевые факторы:

- **Температуры**: продукты сгорания 900–1400 °C, стенки труб 250–350 °C.
- **Материалы**: огнеупорная обмуровка ε ≈ 0,85 (рефрактерная), поверхность кипятильных труб ε ≈ 0,80.
- **Коэффициенты формы**: пламя → трубы F ≈ 0,3–0,7 в зависимости от геометрии экранирования.
- **Норматив**: расчёт теплонапряжённости топочной камеры выполняется по нормативному методу СТО 70238424.27.100.005-2008 (тепловой расчёт котлов) или ASME BPVC Section I для международных проектов.
