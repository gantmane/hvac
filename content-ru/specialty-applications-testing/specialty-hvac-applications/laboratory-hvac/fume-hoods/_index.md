Лабораторные вытяжные шкафы обеспечивают критически важную изоляцию химических паров, газов и частиц. Проектирование системы ОВКВ должно обеспечивать надлежащие скорости удаления, скорости воздуха на лицевой панели и баланс воздуха в помещении при оптимизации энергопотребления.

## Типы вытяжных шкафов

### Конвекционные (с постоянным расходом воздуха)

Фиксированный расход удаления независимо от положения створки:
- Простота эксплуатации
- Повышенное энергопотребление
- Скорость воздуха на лицевой панели варьируется в зависимости от положения створки
- Подходит для учебных лабораторий с ограниченным бюджетом

### С переменным расходом воздуха (VAV)

Удаление модулируется в зависимости от положения створки:
- Поддержание постоянной скорости воздуха на лицевой панели
- Значительная экономия энергии (40-60%)
- Более сложная система управления
- Стандарт для исследовательских лабораторий

### С вспомогательным воздухом (Add-Air)

Дополнительная подача воздуха к лицевой панели шкафа:
- Снижение потребления кондиционированного воздуха
- Не рекомендуется (проблемы с изоляцией)
- Запрещен многими учреждениями
- Только для существующих установок

### Без воздуховодов (фильтрованные)

Рециркуляция через угольный фильтр в помещение:
- Не требуется подключение к воздуховоду
- Ограниченная совместимость с химикатами
- Критически важен мониторинг насыщения фильтров
- Не подходит для всех применений

## Требования к скорости воздуха на лицевой панели

### Расчетная скорость воздуха на лицевой панели

Рекомендации ASHRAE и AIHA:

| Применение | Скорость на лицевой панели | Примечания |
|------|------|-----|
| Стандартные химикаты | 0,40-0,50 м/с | Наиболее распространенный |
| Высокая опасность | 0,50-0,60 м/с | Высоко токсичные материалы |
| Низкая опасность | 0,30-0,40 м/с | Вредные вещества |
| Перхлорная кислота | 0,50-0,60 м/с | Специальная система |
| Радиоизотопы | 0,50-0,63 м/с | Специализированные требования |

### Учет положения створки

Скорость воздуха на лицевой панели рассчитывается для рабочего проема:

$$V_{face} = \frac{Q_{exhaust}}{A_{opening}}$$

**Полностью открытая створка**: Максимальное удаление, расчетная скорость на лицевой панели
**Частично закрытая**: Сниженное удаление (VAV), поддерживаемая скорость на лицевой панели
**Полностью закрытая**: Минимальное удаление (байпасный воздух или щель)

## Проектирование системы удаления

### Индивидуальное удаление

Один вентилятор на каждый шкаф:
- Отсутствие перекрестного загрязнения
- Независимая работа
- Более высокие капитальные затраты
- Больше проходов через кровлю

### Коллекторное удаление

Несколько шкафов используют общую систему удаления:
- Более низкая стоимость
- Меньше проходов
- Разбавление концентрированных паров
- Требует тщательного проектирования

### Конфигурации систем

**Коллектор с постоянным объемом**:
- Байпасные заслонки на каждом шкафу
- Центральный вентилятор работает постоянно
- Возможно VAV для отдельных шкафов

**Коллектор с переменным объемом**:
- Общий расход удаления варьируется в зависимости от спроса
- Вентилятор(ы) с регулируемой скоростью
- Значительная экономия энергии
- Сложная система управления

### Выбор вентилятора удаления

| Критерий | Спецификация |
|------|------|
| Материал | Коррозионностойкий |
| Расположение | Предпочтительно на крыше (отрицательное давление в воздуховоде) |
| Резервирование | Рассмотреть резервный вентилятор |
| Производительность | Все шкафы при максимальной нагрузке |

### Проектирование дымовой трубы

Выпуск над крышей:
- Минимум 3 м над крышей
- Минимум 0,6 м над соседними заборами воздуха
- Достаточная скорость выхода (15,24 м/с и выше)
- Защита от дождя

## Баланс воздуха в помещении

### Подпиточный воздух

Подаваемый воздух должен уравновешивать удаление:

$$\dot{V}_{supply} = \dot{V}_{fume\ hoods} + \dot{V}_{general\ exhaust} - \dot{V}_{infiltration}$$

Поддерживать небольшое отрицательное давление относительно коридора.

### Частота воздухообмена

Частота воздухообмена в лаборатории (общая подача):

| Уровень риска | Минимальная частота ACH |
|------|------|
| Общая химия | 6-10 |
| Органическая химия | 8-12 |
| Высокая опасность | 10-15 |
| Учебная лаборатория | 6-8 |

### Распределение подаваемого воздуха

Позиционирование подачи для предотвращения нарушения работы шкафов:
- Поддерживать <0,25 м/с на лицевой панели шкафа
- Не направлять подачу непосредственно против шкафа
- Перфорированный потолок или высокий боковой выход

## Системы управления

### Управление шкафами VAV

Мониторинг и модуляция:
- Датчик положения створки
- Измерение скорости на лицевой панели
- Заслонка/клапан удаления
- Сигнализация при низкой скорости на лицевой панели

### Управление давлением в помещении

Отслеживание подачи при изменении удаления:
- Прямое управление давлением
- Отслеживание смещения
- Каскадное управление
- Время отклика, соответствующее требованиям

### Автоматизация здания

Требования интеграции с BAS:
- Мониторинг состояния шкафов
- Управление аварийными сигналами
- Мониторинг энергопотребления
- Расписание по присутствию

## Испытания производительности

### Метод ASHRAE 110

Стандартный протокол испытаний:
- **Испытание скорости на лицевой панели**: Измерение равномерности скорости
- **Визуализация потока**: Наблюдение за дымовыми паттернами
- **Испытание с трассирующим газом**: Количественная оценка изоляции (в соответствии с заводскими требованиями: <0,05 ppm; после установки: <0,10 ppm)

### Периодическая проверка

Минимальная годовая проверка:
- Измерение скорости потока воздуха на лицевой панели
- Визуальный осмотр
- Проверка сигнализации
- Калибровка датчика сдвижной створки

### Непрерывный мониторинг

Параметры в реальном времени:
- Скорость потока воздуха на лицевой панели или расход вытяжного воздуха
- Положение сдвижной створки
- Дифференциальное давление в помещении
- Статус сигнализации

## Энергоэффективность

### Преимущества VAV-вытяжных шкафов

Экономия энергии за счет VAV:

$$Savings = \sum \text{часов} \times (Q_{CV} - Q_{VAV}) \times \Delta h \times \text{Стоимость}$$

Типичное снижение энергопотребления, связанного с вытяжными шкафами, на 40–60%.

### Управление на основе присутствия

Дополнительное снижение при отсутствии персонала в лабораториях:
- Снижение скорости потока на лицевой панели (15–18 м/мин)
- Поддержание минимального количества воздухообменов
- Быстрый возврат к нормальному режиму при входе

### Управление створками

Программы поведения оператора:
- Закрывать створки при отсутствии использования
- Сигнализация при длительном полном открытии
- Обучение и повышение осведомленности
- Значительный потенциал экономии

### Рекуперация тепла

Для высоких объемов вытяжного воздуха:
- Змеевики с циркулирующим теплоносителем (без перекрестного загрязнения)
- Системы с тепловыми трубами
- Тепловые колеса (осторожно с загрязнителями)
- Анализ окупаемости инвестиций

## Специальные типы вытяжных шкафов

### Вытяжные шкафы для перхлорной кислоты

Специализированная система с:
- Конструкцией из нержавеющей стали
- Системой промывки
- Отсутствием подключения к коллектору
- Прямой вытяжкой

### Вытяжные шкафы для радиоизотопов

Фильтрация HEPA с:
- Фильтром в мешке (bag-in/bag-out)
- Повышенной скоростью потока на лицевой панели
- Опцией бокса с перчатками
- Специальной утилизацией отходов

### Проходные вытяжные шкафы

Размещение крупного оборудования:
- Повышенные объемы вытяжного воздуха
- Несколько вариантов створок
- Вытяжка на уровне пола

Эффективная интеграция HVAC для вытяжных шкафов обеспечивает безопасность персонала при управлении значительными энергозатратами этих критически важных устройств для удержания загрязнений посредством соответствующего проектирования системы и стратегий управления.
