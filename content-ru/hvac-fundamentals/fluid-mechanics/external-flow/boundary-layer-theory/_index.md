Концепция пограничного слоя, предложенная Людвигом Прандтлем в 1904 году, разделила область течения на две зоны: тонкую вязкую область у стенки (пограничный слой) и внешнюю практически невязкую зону. Это разделение позволяет применить упрощённые уравнения и получить практически полезные аналитические решения. Для инженера ОВК теория пограничного слоя — инструмент расчёта коэффициентов конвективной теплоотдачи в теплообменниках, оценки потерь давления на оребрённых поверхностях и выбора методов интенсификации теплообмена.

## Уравнения пограничного слоя Прандтля

Упрощение уравнений Навье–Стокса для тонкого пограничного слоя (условие δ/L << 1) даёт систему:

**Неразрывность:**

{{< formula display="true" >}}
\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} = 0
{{< /formula >}}

**Количество движения (x-проекция):**

{{< formula display="true" >}}
u \frac{\partial u}{\partial x} + v \frac{\partial u}{\partial y} = U_\infty \frac{dU_\infty}{dx} + \nu \frac{\partial^2 u}{\partial y^2}
{{< /formula >}}

**Энергия:**

{{< formula display="true" >}}
u \frac{\partial T}{\partial x} + v \frac{\partial T}{\partial y} = a \frac{\partial^2 T}{\partial y^2}
{{< /formula >}}

Ключевое упрощение: нормальный градиент давления `∂P/∂y = 0` — давление в пограничном слое определяется внешним потоком через уравнение Бернулли: `(1/ρ)(dP/dx) = −U_∞(dU_∞/dx)`.

При обтекании плоской пластины (dU_∞/dx = 0) системе соответствует решение Блазиуса для скорости. Решение Поглгаузена–Маккалока для теплового слоя при Pr > 0,6:

{{< formula display="true" >}}
Nu_x = 0{,}332 \, Re_x^{1/2} \Pr^{1/3}
{{< /formula >}}

## Ламинарно-турбулентный переход

Переход пограничного слоя от ламинарного к турбулентному определяется числом Рейнольдса Re_cr по текущей координате x. Для идеальной плоской пластины без возмущений Re_cr ≈ 5×10⁵.

**Факторы, снижающие Re_cr в реальных условиях ОВК:**

{{< table title="Влияние условий на критическое Re перехода" >}}
| Фактор | Влияние на Re_cr | Пример |
|---|---|---|
| Шероховатость поверхности | Снижение до 10⁴–10⁵ | Запылённые рёбра теплообменника |
| Турбулентность набегающего потока (Tu > 1 %) | Снижение до 10⁴–10⁵ | Поток после решётки вентилятора |
| Положительный градиент давления | Снижение | Расширяющийся канал |
| Отрицательный градиент давления | Повышение до 10⁷ | Сужающийся конфузор |
| Подогрев поверхности | Снижение (в воздухе) | Горячие трубы теплообменника |
| Охлаждение поверхности | Повышение (в воздухе) | Трубы испарителя |
{{< /table >}}

На практике в змеевиках AHU с запылёнными рёбрами и высокой турбулентностью перехода переход происходит при Re_x ≈ 5×10⁴ — в 10 раз раньше, чем на идеальной пластине. Это означает, что большая часть поверхности ребра находится в турбулентном режиме с повышенным α, что выгодно с точки зрения теплоотдачи.

## Структура турбулентного пограничного слоя

Турбулентный пограничный слой имеет выраженную многоуровневую структуру:

**Вязкий подслой** (y⁺ < 5): молекулярная вязкость доминирует над турбулентной; u⁺ = y⁺ (линейный закон). Теплообмен через этот слой — определяющее сопротивление.

**Буферный слой** (5 < y⁺ < 30): переходная зона.

**Логарифмический слой** (30 < y⁺ < 500): u⁺ = (1/κ)ln(y⁺) + B, где κ = 0,41 (постоянная Кармана), B = 5,0.

Безразмерные координаты: `y⁺ = y · u_τ / ν`, `u⁺ = u / u_τ`, где `u_τ = √(τ_w/ρ)` — скорость трения.

Практическое значение: при использовании CFD-программ (Ansys Fluent, OpenFOAM) толщина первой ячейки у стенки должна обеспечивать y⁺ ≤ 1 для разрешения вязкого подслоя (low-Reynolds turbulence models) или y⁺ = 30–300 для пристеночных функций. Неправильная разбивка сетки — частая причина ошибок в CFD-расчётах теплообменников.

## Теплоотдача в турбулентном пограничном слое

Связь между трением и теплоотдачей — аналогия Рейнольдса–Колберна:

{{< formula display="true" >}}
St = \frac{h}{\rho c_p U_\infty} = \frac{c_{f,x}}{2} Pr^{-2/3}
{{< /formula >}}

или через j-фактор:

{{< formula display="true" >}}
j_H = St \cdot Pr^{2/3} = \frac{c_{f,x}}{2}
{{< /formula >}}

Аналогия точна при Pr ≈ 1 и без отрыва потока. При Pr ≠ 1 применяется поправка Pr^(2/3). j-фактор приводится в каталогах теплообменников (Kays & London, HEDH) для различных типов поверхностей. При разработке нового змеевика сначала измеряется j(Re) экспериментально, затем эти данные используются в расчёте всего теплообменника.

## Управление пограничным слоем в компонентах ОВК

### Рассечённые (louvred) рёбра

Рёбра разрезаются поперёк направления потока через каждые 5–15 мм. После каждого разреза пограничный слой «стартует» заново с нулевой толщиной — максимальное значение α. КПД теплоотдачи возрастает в 2–3 раза по сравнению со сплошными рёбрами. Потери давления также растут, но в меньшей пропорции (в 1,5–2 раза). Рассечённые рёбра применяются в 80–90 % современных змеевиков кондиционеров и холодильников.

### Турбулизирующие вставки (wire insert / twisted tape)

В трубах теплообменника устанавливаются скрученные ленты или проволочные спирали. Вихревые потоки, возникающие за вставкой, разрушают вязкий подслой и повышают Nu в 1,5–3 раза. Цена — рост гидравлического сопротивления в 2–5 раз. Применяются в кожухотрубных теплообменниках с вязкими теплоносителями (гликоль) и при режимах с Re_кр < 10 000.

### Оребрение с переменным шагом

Шаг ребра уменьшают от первого ряда к последнему (variable-pitch design): 3,0 → 2,5 → 2,0 мм. Это компенсирует «утолщение» пограничного слоя по мере прохождения воздуха через пучок — α в задних рядах выравнивается с α в передних. Суммарная теплоотдача возрастает на 5–10 % при той же площади поверхности.

## Числовой пример: оценка перехода и α для ребра испарителя

**Условие.** Ребро испарителя домашнего кондиционера: алюминий, глубина 38 мм, шаг ребра 1,4 мм. Скорость воздуха в плоскости ребра V = 2,0 м/с; T_возд = 27 °C; T_ст = 8 °C (температура насыщения хладагента).

**Число Рейнольдса по длине ребра:**

{{< formula display="true" >}}
Re_L = \frac{2{,}0 \times 0{,}038}{15{,}7 \times 10^{-6}} = 4841
{{< /formula >}}

Re_L = 4841 << 5×10⁵ → ламинарный пограничный слой. Однако при шаге 1,4 мм пограничные слои двух соседних рёбер взаимодействуют — канальный режим, а не открытое обтекание.

**Средний Nu по Шмидту (для каналов теплообменника):**

{{< formula display="true" >}}
\overline{Nu}_L = 0{,}664 \cdot Re_L^{1/2} \cdot Pr^{1/3} = 0{,}664 \times 69{,}6 \times 0{,}89 = 41{,}1
{{< /formula >}}

(Pr воздуха при 17,5 °C = 0,71; Pr^(1/3) = 0,893)

{{< formula display="true" >}}
\alpha = \frac{41{,}1 \times 0{,}0257}{0{,}038} = \frac{1{,}056}{0{,}038} = \mathbf{27{,}8 \text{ Вт/(м}^2\text{·К)}}
{{< /formula >}}

**Поправка на охлаждение поверхности** (µ_стенки/µ_осн)^n для воздуха незначительна (воздух не сильно меняет вязкость в диапазоне 8–27 °C).

**Эффективность ребра:** L_ребра = 38/2 = 19 мм (одностороннее ребро), δ = 0,08 мм (алюминий, λ = 204 Вт/(м·К)):

{{< formula display="true" >}}
m = \sqrt{\frac{2 \times 27{,}8}{204 \times 0{,}00008}} = \sqrt{\frac{55{,}6}{0{,}01632}} = \sqrt{3408} = 58{,}4 \text{ м}^{-1}
{{< /formula >}}

mL = 58,4 × 0,019 = 1,11 → η_реб = tanh(1,11)/1,11 = 0,803/1,11 = **72,3 %**.

Суммарная эффективность поверхности (если 90 % поверхности — рёбра, 10 % — трубы):

{{< formula display="true" >}}
\eta_o = 1 - 0{,}90 \times (1 - 0{,}723) = 1 - 0{,}90 \times 0{,}277 = 1 - 0{,}249 = \mathbf{0{,}751}
{{< /formula >}}

Эффективный коэффициент теплоотдачи со стороны воздуха: α_эфф = 0,751 × 27,8 = **20,9 Вт/(м²·К)** — это значение включается в формулу суммарного U теплообменника.

## Применение в диагностике теплообменников

Обмерзание испарителя приводит к резкому увеличению шероховатости и блокировке каналов между рёбрами. В момент образования тонкого слоя льда (δ_лёд ≈ 0,2–0,5 мм) Ka поверхности возрастает в 2–3 раза, α на начальном этапе **растёт** (тонкий лёд не блокирует теплообмен, но увеличивает шероховатость). По мере нарастания льда щель между рёбрами сужается, скорость растёт, потери давления увеличиваются, а теплоотдача в итоге падает из-за перераспределения потока и сужения сечения.

Параметр диагностики: нарастание потерь давления на змеевике. При ΔP_факт > 1,5 × ΔP_чистый — испаритель требует оттайки. Это критерий, рекомендованный ASHRAE Refrigeration Handbook.
