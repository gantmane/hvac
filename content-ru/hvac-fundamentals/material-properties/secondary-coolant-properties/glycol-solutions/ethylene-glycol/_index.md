## Характеристика вещества

Этиленгликоль (ethylene glycol, EG) — 1,2-этандиол, двухатомный спирт с химической формулой C₂H₆O₂ (HOCH₂CH₂OH). Молярная масса 62,07 г/моль, регистрационный номер CAS 107-21-1.

**Свойства чистого EG при 20 °C:**

{{< table title="Физические свойства чистого этиленгликоля" >}}
| Свойство | Значение |
|:---------|:--------:|
| Плотность, кг/м³ | 1 113 |
| Динамическая вязкость, мПа·с | 16,1 |
| Удельная теплоёмкость, кДж/(кг·°C) | 2,382 |
| Теплопроводность, Вт/(м·°C) | 0,252 |
| Точка кипения при 101,3 кПа, °C | 197,3 |
| Точка замерзания, °C | −12,7 |
{{< /table >}}

В смеси с водой образует неидеальный раствор с минимальной точкой замерзания (эвтектикой) при концентрации ~60 % масс. Неограниченно смешивается с водой во всём диапазоне концентраций.

**Токсичность.** Пероральная LD₅₀ (крысы) — ~4 700 мг/кг. Сладкий вкус повышает вероятность случайного проглатывания. В организме метаболизируется до гликолевой и щавелевой кислот, вызывающих метаболический ацидоз и почечную недостаточность. Летальная доза для взрослого человека — около 100 мл. EG **запрещён** в системах питьевого водоснабжения и в установках переработки пищевых продуктов без специальной сертификации NSF.

| 10 | −3,9 | −1,7 |
| 20 | −8,9 | −4,4 |

| 30 | −15,6 | −9,4 |
| 35 | −20,6 | −13,3 |
| 40 | −25,6 | −17,8 |

| 50 | −37,8 | −30,0 |
| 55 | −43,9 | −37,2 |
| 60 | −48,3 (эвтектика) | −43,9 |
{{< /table >}}

> «Защита от разрушения» — температура, при которой образующаяся ледяная каша приобретает достаточную вязкость для прекращения циркуляции, предотвращая разрыв трубопровода, но не гарантируя незамерзания системы.

**Практические диапазоны концентраций:**

- 25–30 % масс. — отапливаемые машинные помещения, защита до −12 °C.
- 35–40 % масс. — наружные установки в умеренном климате, до −23 °C.
- 45–50 % масс. — холодный климат, крышные установки, солнечные коллекторы, до −37 °C.
- > 50 % масс. — редко оправдано: значительная деградация теплопередачи при минимальном приросте защиты.

## Численный пример: перевод системы с воды на 40 % EG

**Условие.** Система чиллера. Тепловая мощность $Q = 200\ \text{кВт}$, расчётный перепад температур $\Delta T = 6\ \text{°C}$, рабочая температура 5 °C. Требуется определить новый расход и корректировку мощности насоса.

**Шаг 1. Исходный расход воды:**

{{< formula display="true" >}}
\dot{m}_{\text{вода}} = \frac{Q}{c_{p,\text{вода}}\,\Delta T} = \frac{200}{4{,}182 \times 6} = 7{,}97\ \text{кг/с} \approx 28{,}7\ \text{м}^3/\text{ч}
{{< /formula >}}

**Шаг 2. Расход 40 % EG при 5 °C** ($c_p = 3{,}70\ \text{кДж/(кг·°C)}$, $\rho = 1\,045\ \text{кг/м}^3$):

{{< formula display="true" >}}
\dot{m}_{\text{EG}} = \frac{200}{3{,}70 \times 6} = 9{,}01\ \text{кг/с} \approx 31{,}0\ \text{м}^3/\text{ч}
{{< /formula >}}

Объёмный расход вырос на +8 %. Коэффициент расхода $\approx 1{,}08$.

**Шаг 3. Оценка изменения потерь давления** при $\mu_{\text{EG}} = 6{,}5\ \text{мПа·с}$, $\mu_{\text{вода}} = 1{,}5\ \text{мПа·с}$ (при 5 °C):

{{< formula display="true" >}}
\frac{\Delta p_{\text{EG}}}{\Delta p_{\text{вода}}} \approx \left(\frac{\mu_{\text{EG}}}{\mu_{\text{вода}}}\right)^{0{,}2} \times \left(\frac{\dot{V}_{\text{EG}}}{\dot{V}_{\text{вода}}}\right)^{1{,}75} = (4{,}33)^{0{,}2} \times (1{,}08)^{1{,}75} \approx 1{,}34 \times 1{,}14 \approx 1{,}53
{{< /formula >}}

**Шаг 4. Мощность насоса** ($N \propto \dot{V} \cdot \Delta p$):

{{< formula display="true" >}}
\frac{N_{\text{EG}}}{N_{\text{вода}}} = \frac{\dot{V}_{\text{EG}}}{\dot{V}_{\text{вода}}} \cdot \frac{\Delta p_{\text{EG}}}{\Delta p_{\text{вода}}} = 1{,}08 \times 1{,}53 \approx 1{,}65
{{< /formula >}}

Мощность насоса возрастёт приблизительно на 65 % — необходимо проверить размер двигателя.

## Тепловое расширение и размер расширительного бака

EG-растворы имеют более высокий коэффициент объёмного расширения, чем вода:

{{< table title="Относительное расширение от 4 °C до 93 °C" >}}
| Жидкость | Расширение объёма, % |
|:---------|:-------------------:|
| Вода | 3,5 |
| 20 % EG | 4,5 |
| 30 % EG | 5,0 |
| 40 % EG | 5,5 |
| 50 % EG | 6,2 |
{{< /table >}}

Объём расширительного бака (мембранного типа) рассчитывают с использованием скорректированного коэффициента расширения $\beta$ для конкретной концентрации EG. Типичное увеличение объёма бака по сравнению с чисто водяной системой — 15–20 %.

## Ингибиторы коррозии

Чистый EG без ингибиторов агрессивен к стали, меди и алюминию. Обязательно применение ингибированных составов.

{{< table title="Компоненты ингибирующих пакетов для систем EG" >}}
| Ингибитор | Функция | Целевой металл |
|:----------|:--------|:--------------:|
| Нитрит натрия | Пассивация | Чёрные металлы |
| Молибдат натрия | Анодная защита | Al, жёлтые металлы |
| Силикат натрия | Защитная плёнка | Алюминий |
| Бензотриазол / толилтриазол | Адсорбционная защита | Медь и сплавы |
| Бораты / фосфаты | Буфер pH 8,5–10,5 | Все металлы |
{{< /table >}}

Технология OAT (organic acid technology) — органические карбоксилаты с пониженной проводимостью и сроком службы 5–10 лет — предпочтительна в современных закрытых системах.

**Совместимость с полимерами:** EPDM — отличная; NBR (нитрил) — хорошая; неопрен — хорошая; натуральный каучук — неудовлетворительная; PVC, CPVC, PE (PEX) — приемлемые. Оцинкованную сталь следует исключать из контуров EG.

## Мониторинг и техническое обслуживание

**Контроль концентрации:** рефрактометр — полевой экспресс-метод (точность ±1 °C по точке замерзания); гидрометр — менее точен; лабораторное титрование — ±1 % масс. (арбитражный метод).

**Минимальная периодичность:** перед зимним сезоном; ежегодно; после каждой подпитки или ремонта.

**Критерии замены раствора:** pH < 7,0; резервная щёлочность < 50 % от исходной; изменение цвета (жёлтый → коричневый — признак окисления); наличие взвеси продуктов коррозии.

## Ограничения и запрещённые применения

- Системы питьевого водоснабжения — запрещено (NSF/ANSI 60).
- Теплообменники без двойной стенки в питьевых системах — запрещено.
- Предприятия по переработке пищевых продуктов — только при наличии специального допуска NSF.
- Системы, доступные детям или животным, — предпочтителен PG.

**Разрешённые применения:** замкнутые контуры ОВиК; промышленное технологическое охлаждение; системы снеготаяния с организованным сбором дренажа; солнечные тепловые контуры; системы аккумуляции льда.

## Ключевые выводы

1. EG — экономически эффективный хладоноситель для закрытых контуров с широким диапазоном рабочих температур; применение ограничено требованиями токсикологической безопасности.
2. При переходе системы с воды на 40 % EG мощность насоса возрастает ориентировочно на 50–75 %; необходима проверка размера двигателя.
3. Обязательное применение ингибированных составов; неингибированный EG вызывает интенсивную коррозию в системах со смешанной металлургией.
4. Расширительный бак требует увеличения объёма на 15–20 % по сравнению с водяной системой из-за более высокого коэффициента теплового расширения.
