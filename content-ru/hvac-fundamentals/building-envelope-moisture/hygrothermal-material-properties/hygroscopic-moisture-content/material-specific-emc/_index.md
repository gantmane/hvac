## Общие положения

Равновесное влагосодержание (EMC, equilibrium moisture content) — это влагосодержание, которое строительный материал устанавливает при термодинамическом равновесии с окружающим воздухом при заданных температуре и относительной влажности. Знание EMC необходимо для:

- прогнозирования накопления влаги в ограждающих конструкциях;
- расчёта гигрической буферной ёмкости помещения;
- оценки рисков биодеградации, деформаций и плесневого роста;
- подготовки входных данных для гигротермальных симуляций (WUFI, DELPHIN).

Функциональную связь между EMC и относительной влажностью описывает изотерма сорбции — нелинейная кривая при постоянной температуре. Форма кривой определяется структурой пор, химическим составом и поверхностными характеристиками материала. Стандарты испытаний: ISO 12571, ASTM C1498, ГОСТ 25898.

## Физика сорбции влаги

### Механизмы поглощения

Строительные материалы связывают влагу тремя последовательно активирующимися механизмами в зависимости от уровня относительной влажности.

**Мономолекулярная адсорбция (0–20 % отн. вл.).**
Молекулы воды образуют единый слой на внутренних поверхностях пор под действием сил Ван-дер-Ваальса и водородных связей. Описывается уравнением Ленгмюра:

{{< formula display="true" >}}
u_1 = \frac{u_m \cdot b \cdot \varphi}{1 + b \cdot \varphi}
{{< /formula >}}

где:
- {{< formula >}}u_1{{< /formula >}} — влагосодержание от мономолекулярной адсорбции, кг/кг;
- {{< formula >}}u_m{{< /formula >}} — влагосодержание монослоя, кг/кг;
- {{< formula >}}b{{< /formula >}} — константа энергии адсорбции, б/р;
- {{< formula >}}\varphi{{< /formula >}} — относительная влажность, доля единицы.

**Полимолекулярная адсорбция (20–90 % отн. вл.).**
На монослой наращиваются дополнительные слои воды. Применяется модель БЭТ (Brunauer–Emmett–Teller):

{{< formula display="true" >}}
u = \frac{u_m \cdot C \cdot \varphi}{(1 - \varphi)\bigl[1 + (C-1)\,\varphi\bigr]}
{{< /formula >}}

где {{< formula >}}C{{< /formula >}} — константа БЭТ, связанная с теплотой адсорбции, б/р.

**Капиллярная конденсация (>90 % отн. вл.).**
Вода конденсируется в мелких порах, когда давление пара над мениском падает ниже давления насыщенного пара над плоской поверхностью. Пороговый радиус пор определяется уравнением Кельвина:

{{< formula display="true" >}}
\ln\varphi = -\frac{2\,\sigma\,V_m\,\cos\theta}{R\,T\,r_c}
{{< /formula >}}

где:
- {{< formula >}}\sigma = 0{,}0728{{< /formula >}} Н/м — поверхностное натяжение воды при 20 °C;
- {{< formula >}}V_m = 1{,}8\times10^{-5}{{< /formula >}} м³/моль — молярный объём воды;
- {{< formula >}}\theta{{< /formula >}} — краевой угол смачивания, рад;
- {{< formula >}}R = 8{,}314{{< /formula >}} Дж/(моль·К) — универсальная газовая постоянная;
- {{< formula >}}T{{< /formula >}} — абсолютная температура, К;
- {{< formula >}}r_c{{< /formula >}} — критический радиус пор, м.

### Гистерезис сорбции

Влагосодержание при адсорбции (увлажнение) и при десорбции (высыхание) различается при одном и том же значении относительной влажности, образуя петлю гистерезиса. Для большинства строительных материалов разница составляет 1–5 % по влагосодержанию. Коэффициент гистерезиса:

{{< formula display="true" >}}
H_R = \frac{u_\text{des} - u_\text{ads}}{u_\text{des}} \times 100\,\%
{{< /formula >}}

Гистерезис имеет практическое значение при расчёте циклов увлажнения–высыхания в ограждающих конструкциях. Подробнее — в разделе «Гистерезис изотерм сорбции».

## Древесина

### Уравнение EMC

Древесина — наиболее гигроскопичный конструкционный материал в зданиях. EMC определяется по уравнению Симпсона (USDA Forest Products Laboratory), которое воспроизводится в ASHRAE Fundamentals, гл. 26:

{{< formula display="true" >}}
\mathrm{EMC} = \frac{1800}{W}\left[\frac{K_1 K_2 \varphi}{1 - K_1\varphi} + \frac{K_1 K_3 K_4 \varphi\bigl(1 + K_3 K_4 \varphi\bigr)}{1 + K_3 K_4 \varphi}\right]
{{< /formula >}}

где температурно-зависимые коэффициенты при {{< formula >}}T{{< /formula >}} в °C:

{{< formula display="true" >}}
W = 330 + 0{,}452\,T + 0{,}00415\,T^2
{{< /formula >}}

{{< formula display="true" >}}
K_1 = 0{,}805 + 0{,}000736\,T - 0{,}00000273\,T^2
{{< /formula >}}

{{< formula display="true" >}}
K_2 = 6{,}27 - 0{,}00938\,T - 0{,}000303\,T^2
{{< /formula >}}

{{< formula display="true" >}}
K_3 = 1{,}91 + 0{,}0407\,T - 0{,}000293\,T^2
{{< /formula >}}

| Очень плотные (гикори, бук) | 750–900 | 5,5 | 8,4 | 12,0 | 18,0 |

### Точка насыщения волокон (FSP)

Точка насыщения волокон (fiber saturation point, FSP) — влагосодержание, при котором клеточные стенки насыщены связанной водой, а свободная вода в полостях клеток ещё отсутствует. Это пороговое значение критично по трём причинам:

1. Усадка и разбухание древесины происходят только ниже FSP.
2. Механические свойства практически не изменяются выше FSP.
3. Риск биологического разрушения резко возрастает при превышении FSP.

Типичный диапазон: **FSP = 28–32 %** (по массе сухого вещества). Температурная поправка:

{{< formula display="true" >}}
\mathrm{FSP}(T) = \mathrm{FSP}(20\,°\!\mathrm{C})\,\bigl[1 - 0{,}0015\,(T - 20)\bigr]
{{< /formula >}}

### Влагосодержание: определение и пересчёт

Влагосодержание по массе сухого вещества (основной показатель для древесины):

{{< formula display="true" >}}
w_d = \frac{m_\text{вл} - m_\text{сух}}{m_\text{сух}} \times 100\,\%
{{< /formula >}}

Пересчёт к влажной основе:

{{< formula display="true" >}}
w_w = \frac{w_d}{1 + w_d/100}
{{< /formula >}}

### Целевые параметры климата для деревянных конструкций

- Мебель и чистовая отделка: 40–55 % отн. вл. → EMC 8–10 %.
- Несущий деревянный каркас: допустимый диапазон EMC 8–14 %.
- Паркетные полы: 35–50 % отн. вл. → EMC 6–9 %.
- Музыкальные инструменты: 45–55 % отн. вл. → EMC 8,5–10 %.

Максимально допустимое сезонное колебание EMC для предотвращения деформаций: ±2 %. При наклоне кривой сорбции dEMC/dRH ≈ 0,14 %/% отн. вл. (при 50 % отн. вл., 20 °C) допустимый диапазон изменения относительной влажности:

{{< formula display="true" >}}
\Delta\varphi_\text{max} = \frac{2\,\%}{0{,}14} \approx 14\,\%
{{< /formula >}}

Это соответствует поддержанию внутренней относительной влажности в диапазоне 40–55 %.

{{< /formula >}}

Типовые параметры: {{< formula >}}u_m = 0{,}008{-}0{,}025{{< /formula >}} кг/кг; {{< formula >}}C = 5{-}15{{< /formula >}}; {{< formula >}}k = 0{,}85{-}0{,}95{{< /formula >}}.

Коэффициент диффузии влаги в бетоне нелинейно зависит от влагосодержания:

{{< formula display="true" >}}
D_w(u) = D_0\,\exp\!\left(n\,\frac{u}{u_\text{sat}}\right)
{{< /formula >}}

где {{< formula >}}D_0 \approx 1\times10^{-12}{{< /formula >}} м²/с — справочный коэффициент; {{< formula >}}n = 6{-}10{{< /formula >}} для бетона.

### Цементный раствор

- Тип N (цемент:известь:песок = 1:1:6): EMC ≈ 4,0 % при 75 % отн. вл.
- Тип S (1:0,5:4,5): EMC ≈ 3,2 % при 75 % отн. вл.
- Тип M (1:0,25:3,5): EMC ≈ 2,8 % при 75 % отн. вл.

Раствор гигроскопичнее кирпича, что создаёт градиенты распределения влаги в кладочных сборках.

## Теплоизоляционные материалы

### Волокнистая изоляция

**Стекловата.** Практически негигроскопична: EMC < 0,1 % во всём диапазоне относительной влажности. Деградация теплозащиты происходит только при накоплении жидкой воды.

**Минеральная вата (каменная вата, МВЗО).** Слабогигроскопична: 0,2 % при 50 % отн. вл., 0,8 % при 90 % отн. вл. Гидрофобизирующая пропитка снижает поглощение.

**Целлюлозная эковата.** Существенно гигроскопична несмотря на антипиреновую обработку:

{{< table title="EMC целлюлозной изоляции (% по массе)" >}}
| Тип обработки | 50 % отн. вл. | 75 % отн. вл. | 90 % отн. вл. | Буферная ёмкость |
|---|---|---|---|---|
| Боратная | 11,0 | 16,5 | 24,0 | Высокая |
| Сульфатная | 12,5 | 18,0 | 26,0 | Очень высокая |
{{< /table >}}

Полиномиальная аппроксимация изотермы при 20 °C:

{{< formula display="true" >}}
\mathrm{EMC}_\text{cell} = 15{,}2\,\varphi + 8{,}7\,\varphi^2 + 5{,}1\,\varphi^3
{{< /formula >}}

### Пенная изоляция

- Напыляемая пена закрытой ячейки (SPF): EMC < 0,3 %, действует как пароизолятор (класс I по ASHRAE).
- Экструдированный пенополистирол (XPS): EMC ≈ 0,5 % при 75 % отн. вл.; {{< formula >}}D_w \approx 2\times10^{-12}{{< /formula >}} м²/с.
- Вспененный пенополистирол (EPS): EMC = 1,5–3,0 % при 75 % отн. вл. (зависит от плотности); открытые поры обеспечивают большее поглощение.
- Полиизоцианурат (PIR): ядро < 0,5 % EMC при 75 % отн. вл.; поведение определяется облицовкой.

## Гипсокартон

Гипсокартон (ГКЛ) умеренно гигроскопичен и обеспечивает значительную пассивную буферизацию влажности в помещениях.

{{< table title="EMC стандартного ГКЛ толщиной 12,5 мм, плотность 650 кг/м³" >}}
| Отн. влажность, % | EMC, % | Хранение влаги, кг/м² |
|---|---|---|
| 30 | 0,5 | 0,040 |
| 50 | 1,0 | 0,080 |
| 70 | 2,2 | 0,176 |
| 90 | 5,5 | 0,440 |
{{< /table >}}

Аппроксимация по Nordtest (ISO 24353):

{{< formula display="true" >}}
u = 0{,}0138\,\varphi - 0{,}00564\,\varphi^2 + 0{,}0614\,\varphi^3
{{< /formula >}}

Практическое значение буферизации влаги (MBV, moisture buffer value) по ISO 24353: **MBV = 1,0–1,4 г/(м²·% отн. вл.)** для 8-часовых циклов.

## Гигроскопические соли и делиресценция

Растворимые соли в материалах кладки поглощают влагу, как только относительная влажность превышает критическую точку делиресценции (deliquescence relative humidity, DRH).

{{< table title="DRH распространённых солей при 20 °C" >}}
| Соль | Формула | DRH, % |
|---|---|---|
| Хлорид кальция | CaCl₂ | 32 |
| Хлорид магния | MgCl₂ | 33 |
| Хлорид натрия | NaCl | 75 |
| Карбонат натрия | Na₂CO₃ | 87 |
| Нитрат калия | KNO₃ | 93 |
| Сульфат натрия | Na₂SO₄ | 93 |
{{< /table >}}

При превышении DRH соль переходит в раствор, и суммарное влагосодержание материала:

{{< formula display="true" >}}
u_\text{total} = u_\text{matrix} + u_\text{salt}
{{< /formula >}}

где {{< formula >}}u_\text{salt}{{< /formula >}} может превышать 10–20 % при RH > DRH.

## Функции хранения влаги

### Дифференциальная ёмкость хранения

Дифференциальная ёмкость хранения влаги (moisture storage capacity) определяет, сколько влаги накапливается на единицу изменения относительной влажности:

{{< formula display="true" >}}
\xi = \frac{\mathrm{d}u}{\mathrm{d}\varphi}
{{< /formula >}}

{{< table title="Ёмкость хранения влаги ξ, кг/кг на единицу φ" >}}
| Материал | 50 % отн. вл. | 80 % отн. вл. |
|---|---|---|
| Хвойная древесина | 0,16 | 0,35 |
| Гипсокартон | 0,012 | 0,055 |
| Рядовой кирпич | 0,030 | 0,085 |
| Бетон (обычный) | 0,025 | 0,070 |
| Целлюлозная эковата | 0,18 | 0,42 |
{{< /table >}}

### Объёмная ёмкость хранения

Для гигротермального моделирования необходима объёмная ёмкость:

{{< formula display="true" >}}
\xi_v = \rho_0\,\xi = \rho_0\,\frac{\mathrm{d}u}{\mathrm{d}\varphi}
{{< /formula >}}

где {{< formula >}}\rho_0{{< /formula >}} — плотность сухого материала, кг/м³.

## Численный пример: буферная ёмкость сборки внутренней перегородки

**Условие.** Перегородка состоит из деревянного каркаса из ели (толщина стойки 89 мм, шаг 400 мм) и двух слоёв ГКЛ по 12,5 мм с каждой стороны. Рассчитать эффективную буферную ёмкость при переходе относительной влажности от 40 до 60 % (при 20 °C).

**Данные материалов.**

- Ель: {{< formula >}}\rho_0 = 450{{< /formula >}} кг/м³; {{< formula >}}\xi = 0{,}16{{< /formula >}} кг/кг при 50 % отн. вл.
- ГКЛ: {{< formula >}}\rho_0 = 650{{< /formula >}} кг/м³; {{< formula >}}\xi = 0{,}012{{< /formula >}} кг/кг при 50 % отн. вл.

**Объёмная ёмкость хранения.**

{{< formula display="true" >}}
\xi_{v,\text{ель}} = 450 \times 0{,}16 = 72\;\text{кг/(м}^3\text{ · ед. }\varphi\text{)}
{{< /formula >}}

{{< formula display="true" >}}
\xi_{v,\text{ГКЛ}} = 650 \times 0{,}012 = 7{,}8\;\text{кг/(м}^3\text{ · ед. }\varphi\text{)}
{{< /formula >}}

**Глубина буферного проникновения** для суточного цикла ({{< formula >}}t = 86400{{< /formula >}} с), {{< formula >}}D_w = 5\times10^{-9}{{< /formula >}} м²/с для ели:

{{< formula display="true" >}}
\delta_p = \sqrt{\frac{D_w\,t}{\pi}} = \sqrt{\frac{5\times10^{-9} \times 86400}{\pi}} \approx 0{,}012\;\text{м} = 12\;\text{мм}
{{< /formula >}}

За 24 часа к буферизации подключаются только первые 12 мм каждого материала.

**Эффективная буферная ёмкость** на 1 м² перегородки (оба слоя ГКЛ — 2 × 12,5 мм; ель в пределах глубины проникновения — 2 × 12 мм из каркасной стойки):

{{< formula display="true" >}}
\mathrm{MBC}_\text{eff} = 2 \times 0{,}0125 \times 7{,}8 + 2 \times 0{,}012 \times 72 = 0{,}195 + 1{,}73 \approx 1{,}93\;\text{кг/(м}^2\text{ · ед. }\varphi\text{)}
{{< /formula >}}

**Изменение хранимой влаги** при скачке отн. вл. на 20 % (Δφ = 0,20):

{{< formula display="true" >}}
\Delta m = 1{,}93 \times 0{,}20 = 0{,}386\;\text{кг/м}^2
{{< /formula >}}

**Вывод.** Деревянный каркас обеспечивает около 90 % суточной буферной ёмкости перегородки. ГКЛ, несмотря на малую ξ, вносит значимый вклад благодаря полностью доступной глубине листа.

## Температурная зависимость EMC

EMC снижается с ростом температуры при постоянной относительной влажности — следствие уменьшения энергии адсорбции. Поправочная формула:

{{< formula display="true" >}}
\mathrm{EMC}(T_2) = \mathrm{EMC}(T_1)\,\bigl[1 - \alpha\,(T_2 - T_1)\bigr]
{{< /formula >}}

где {{< formula >}}\alpha = 0{,}01{-}0{,}02{{< /formula >}} °C⁻¹ для большинства строительных материалов.

**Пример для ели при 80 % отн. вл.:**

| T, °C | EMC, % |
|---|---|
| 10 | 16,5 |
| 20 | 15,0 |
| 30 | 13,5 |
| 40 | 12,2 |

## Критические пороги влагосодержания

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — изотермы сорбции и данные функций хранения влаги для типовых строительных материалов.
- **ASHRAE 160** — критерии расчётного анализа контроля влаги в зданиях.
- **ISO 12571** — определение гигроскопических свойств строительных материалов (изотермы сорбции).
- **ISO 12572** — паропроницаемость строительных материалов (чашечный метод).
- **ASTM C1498** — стандартный метод измерения гигроскопических изотерм сорбции.
- **ASTM D4933** — кондиционирование влаги древесины и древесных материалов.
- **ГОСТ 25898** — материалы и изделия строительные: методы определения паропроницаемости и влагопоглощения.
- **СП 50.13330.2017** — тепловая защита зданий.
- **СП 23-101-2004** — проектирование тепловой защиты зданий.

## Рекомендации по проектированию

### Выбор материалов по роли в управлении влагой

**Высокая буферная ёмкость:** ГКЛ (MBV 1,0–1,4), деревянные панели (MBV 2,0–2,5), целлюлозная эковата.

**Минимальное хранение влаги:** напыляемая пена закрытой ячейки, цементная плита во влажных зонах, негигроскопичные пароизоляционные плёнки.

### Входные данные для гигротермального моделирования

При подготовке входных данных для WUFI или DELPHIN необходимо задать:

1. Полные кривые адсорбции и десорбции (минимум 6 точек: 0, 30, 50, 75, 90, 95 % отн. вл.).
2. Функцию {{< formula >}}\xi(\varphi){{< /formula >}} или таблицу дискретных значений.
3. Температурную зависимость EMC.
4. Коэффициент жидкостного транспорта при высоком влагосодержании.

Источники данных: база материалов WUFI Pro, база DELPHIN, справочник ASHRAE Fundamentals, лабораторные испытания по ISO 12571 / ASTM C1498.

### Полевая оценка влагосодержания

**Деревянные конструкции:**
- Допустимый диапазон: 7–14 % EMC.
- Порог расследования: > 16 % EMC.
- Требуется вмешательство: > 20 % EMC.

**Кладка:**
- Нормальный диапазон: 1–5 % (гравиметрический).
- Повышенный: 5–10 %.
- Требует расследования: > 10 %.

### Стратегии управления EMC в зависимости от климата

**Влажный климат (климатические зоны ASHRAE 1–3).** Проектировать под постоянно высокое EMC наружных материалов. Обеспечивать возможность просыхания в обоих направлениях. Ограничивать гигроскопичные материалы изнутри, снижая нагрузку на систему кондиционирования.

**Сухой климат (зоны 3B, 4B, 5B).** Учитывать глубокую осушку зимой и связанную усадку. Предусматривать увлажнение для предотвращения пересушивания. Применять гигроскопичные материалы для пассивной стабилизации влажности.

**Смешанный климат (зоны 4A, 5A, 6).** Рассчитывать максимальный сезонный диапазон EMC. Проверять, что материалы выдерживают цикличные изменения влагосодержания. Реализовывать сезонные алгоритмы управления HVAC.
