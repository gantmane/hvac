## Общие положения

Коэффициент переноса жидкости (liquid water conductivity, {{< formula >}}D_w{{< /formula >}}) количественно описывает способность пористого строительного материала проводить жидкую влагу под действием градиента влагосодержания. Это свойство принципиально отличается от паропроницаемости ({{< formula >}}\delta_p{{< /formula >}}): оно характеризует движение воды именно в жидкой фазе через взаимосвязанные поровые каналы.

{{< formula >}}D_w{{< /formula >}} определяет:
- скорость перераспределения влаги внутри конструкции после намокания;
- потенциал высыхания при изменении граничных условий;
- эффективность капиллярных разрывов между слоями;
- вклад жидкостного механизма в суммарный поток влаги при высоком влагосодержании.

Параметр необходим для корректного гигротермального моделирования в WUFI, DELPHIN и аналогичных программах. Стандарты: EN ISO 15148, ISO 12572, ASHRAE Fundamentals, гл. 26.

## Физические механизмы

Движение жидкой воды в пористом материале определяется несколькими взаимосвязанными механизмами:
- градиенты капиллярного давления (всасывания) — преобладают при ненасыщенных условиях;
- плёночное течение вдоль стенок пор при малом влагосодержании;
- угловой поток в контактных зонах между частицами;
- гравитационный поток — значим в крупнопористых материалах.

Плотность жидкого потока задаётся диффузионным аналогом закона Фика:

{{< formula display="true" >}}
g_l = -D_w(w)\,\frac{\partial w}{\partial x}
{{< /formula >}}

где {{< formula >}}w{{< /formula >}} — объёмное влагосодержание, кг/м³; {{< formula >}}x{{< /formula >}} — пространственная координата, м.

## Зависимость от влагосодержания

{{< formula >}}D_w{{< /formula >}} — не константа, а функция {{< formula >}}w{{< /formula >}}, охватывающая несколько порядков величины в рабочем диапазоне:

{{< formula display="true" >}}
D_w(w) = D_{w,s}\,\left[\frac{w - w_h}{w_\text{cap} - w_h}\right]^n
{{< /formula >}}

где:
- {{< formula >}}D_{w,s}{{< /formula >}} — коэффициент при насыщении, м²/с;
- {{< formula >}}w_h{{< /formula >}} — гигроскопическое влагосодержание (при 80 % отн. вл.), кг/м³;
- {{< formula >}}w_\text{cap}{{< /formula >}} — влагосодержание при капиллярном насыщении, кг/м³;
- {{< formula >}}n{{< /formula >}} — эмпирический показатель (5–15).

Связь с капиллярной проводимостью {{< formula >}}K_l{{< /formula >}}:

{{< formula display="true" >}}
D_w = K_l\,\frac{\mathrm{d}\psi}{\mathrm{d}w}
{{< /formula >}}

где {{< formula >}}\psi{{< /formula >}} — матричный потенциал, Па.

Связь с A-значением (коэффициентом капиллярного поглощения):

{{< formula display="true" >}}
A_w^2 \approx D_{w,s}\,w_\text{cap}\,\rho_\text{dry}
{{< /formula >}}

### Теплоизоляционные материалы

- **Минеральная вата:** {{< formula >}}D_{w,s} = 1\times10^{-8}{-}1\times10^{-7}{{< /formula >}} м²/с; перенос жидкости преимущественно гравитационный, ограниченное капиллярное действие.
- **Целлюлозная эковата:** {{< formula >}}D_{w,s} = 5\times10^{-8}{-}3\times10^{-7}{{< /formula >}} м²/с; умеренное капиллярное перераспределение.
- **Пеностекло:** {{< formula >}}D_w \approx 0{{< /formula >}} (закрытые ячейки); перенос только через трещины.
- **EPS / XPS:** {{< formula >}}D_{w,s} < 1\times10^{-12}{{< /formula >}} м²/с; для практических целей непроницаемы.

## Температурная зависимость

{{< formula >}}D_w{{< /formula >}} возрастает с температурой из-за снижения динамической вязкости воды:

{{< formula display="true" >}}
D_w(T) = D_w(T_\text{ref})\,\frac{\mu(T_\text{ref})}{\mu(T)}
{{< /formula >}}

| T, °C | μ, мПа·с | Поправочный коэффициент (отн. 20 °C) |
|---|---|---|
| 0 | 1,79 | 1,79 |
| 10 | 1,31 | 1,31 |
| 20 | 1,00 | 1,00 |
| 30 | 0,80 | 0,80 |
| 40 | 0,65 | 0,65 |

Изменение ~10–15 % на каждые 10 °C температуры — значимо для сезонного анализа.

## Численный пример: оценка времени высыхания кирпичной кладки

**Условие.** Стена из рядового кирпича толщиной 100 мм насыщена после дождя до {{< formula >}}w = 150{{< /formula >}} кг/м³ (≈ {{< formula >}}w_\text{cap}{{< /formula >}}). После прекращения дождя начинается высыхание. Оценить характерное время перераспределения жидкой влаги к поверхности.

**Данные:** {{< formula >}}D_{w,s} = 2\times10^{-7}{{< /formula >}} м²/с; характерный размер {{< formula >}}L = 0{,}05{{< /formula >}} м (половина толщины при двустороннем высыхании); движущая сила {{< formula >}}\Delta w = 100{{< /formula >}} кг/м³ (от 150 до 50 кг/м³).

**Среднее значение {{< formula >}}D_w{{< /formula >}}** при {{< formula >}}w/w_\text{cap} = 0{,}65{{< /formula >}}:

{{< formula display="true" >}}
D_w = D_{w,s}\left(\frac{0{,}65 \cdot w_\text{cap} - w_h}{w_\text{cap} - w_h}\right)^n
{{< /formula >}}

Принимая {{< formula >}}w_h \ll w_\text{cap}{{< /formula >}}: {{< formula >}}D_w \approx 2\times10^{-7}\times(0{,}65)^{10} \approx 2\times10^{-7}\times 0{,}013 \approx 2{,}6\times10^{-9}{{< /formula >}} м²/с.

**Характерное время перераспределения:**

{{< formula display="true" >}}
t_\text{dry} \approx \frac{L^2}{D_w} = \frac{(0{,}05)^2}{2{,}6\times10^{-9}} = \frac{0{,}0025}{2{,}6\times10^{-9}} \approx 9{,}6\times10^5\;\text{с} \approx 11\;\text{суток}
{{< /formula >}}

**Вывод.** Жидкостное перераспределение влаги после намокания требует около 11 суток. Полное высыхание займёт дополнительное время за счёт диффузии пара. Это обосновывает принцип: наружная облицовка должна обеспечивать максимально быстрое высыхание — паропроницаемые покрытия и отсутствие паронепроницаемых барьеров со стороны высыхания.

## Гистерезис проводимости

Коэффициент {{< formula >}}D_w{{< /formula >}} различается при смачивании и высыхании при одном и том же {{< formula >}}w{{< /formula >}}:

{{< formula display="true" >}}
H_R = \frac{D_{w,\text{wetting}}}{D_{w,\text{drying}}} = 1{,}5{-}3{,}0
{{< /formula >}}

Это следствие различного характера заполнения–опустошения пор. Большинство гигротермальных моделей используют единую усреднённую кривую {{< formula >}}D_w(w){{< /formula >}}.

## Влияние солей

Растворённые соли изменяют {{< formula >}}D_w{{< /formula >}} через:
- увеличение вязкости раствора (снижение {{< formula >}}D_w{{< /formula >}});
- изменение поверхностного натяжения;
- деградацию структуры пор при кристаллизации (долгосрочное увеличение {{< formula >}}D_w{{< /formula >}} в кладке).

При умеренных концентрациях соли {{< formula >}}D_w{{< /formula >}} может увеличиться на 10–30 % по сравнению с чистой водой.

## Применение в гигротермальном моделировании

### Уравнение баланса влаги

{{< formula display="true" >}}
\frac{\partial w}{\partial t} = \frac{\partial}{\partial x}\left[D_w\,\frac{\partial w}{\partial x}\right] + \frac{\partial}{\partial x}\left[\delta_p\,\frac{\partial p_v}{\partial x}\right]
{{< /formula >}}

Первый член — жидкостный транспорт; второй — диффузия пара. При высоком {{< formula >}}w{{< /formula >}} доминирует первый.

### Связанный тепло-влажностный баланс

{{< formula display="true" >}}
\rho c\,\frac{\partial T}{\partial t} = \frac{\partial}{\partial x}\!\left[\lambda\,\frac{\partial T}{\partial x}\right] + L_v\,\frac{\partial}{\partial x}\!\left[D_w\,\frac{\partial w}{\partial x} + \delta_p\,\frac{\partial p_v}{\partial x}\right]
{{< /formula >}}

где {{< formula >}}L_v = 2{,}5\times10^6{{< /formula >}} Дж/кг — удельная теплота испарения. Испарение–конденсация влаги внутри конструкции перераспределяет тепловые потоки.

### Численная реализация (конечные разности)

{{< formula display="true" >}}
w_i^{n+1} = w_i^n + \frac{\Delta t}{\Delta x^2}\left[D_{i+1/2}\,(w_{i+1}^n - w_i^n) - D_{i-1/2}\,(w_i^n - w_{i-1}^n)\right]
{{< /formula >}}

Критерий устойчивости явной схемы:

{{< formula display="true" >}}
\Delta t \leq \frac{\Delta x^2}{2\,D_{w,\text{max}}}
{{< /formula >}}

## Неопределённость и контроль качества данных

**Изменчивость {{< formula >}}D_w{{< /formula >}} от партии к партии:**
- Глиняный кирпич: COV (коэффициент вариации) 30–50 %.
- Бетон: 40–70 %.
- Древесные материалы: 50–100 %.

**Источники неопределённости измерения:**
- Определение влагосодержания: ±5–10 %.
- Измерение потока: ±10–15 %.
- Геометрия образца: ±2–5 %.

Комбинированная неопределённость {{< formula >}}D_w{{< /formula >}}: ±25–40 % (улучшается до ±15–25 % с применением ЯМР и обратного анализа).

**Минимальный объём испытаний:** не менее 5 образцов на партию; не менее 4 уровней {{< formula >}}w{{< /formula >}}.

## Проектные рекомендации

### Выбор материалов по роли в конструкции

**Материалы с низким {{< formula >}}D_w{{< /formula >}}** (барьерная функция):
- внешние водозащитные мембраны ({{< formula >}}D_w < 10^{-11}{{< /formula >}} м²/с);
- капиллярные разрывы в фундаментных узлах;
- гидрофобные наружные штукатурки.

**Материалы с высоким {{< formula >}}D_w{{< /formula >}}** (перераспределение влаги к испарительной поверхности):
- внутренние капиллярно-активные слои (штукатурки, гипс);
- слои перераспределения влаги в многослойных конструкциях с управляемым высыханием.

### Размещение капиллярных разрывов

Для прерывания жидкостного транспорта необходимо отношение {{< formula >}}D_w{{< /formula >}} смежных слоёв не менее 100:1. Критические узлы:
- переход фундамент–стена;
- полость вентилируемого фасада;
- интерфейс кровля–стена;
- опирание балок перекрытия в кладке.

### Риск морозного разрушения

Высокая жидкостная проводимость в холодном климате увеличивает риск морозного разрушения. Критическое влагосодержание для замерзания:

{{< formula display="true" >}}
w_\text{крит} = 0{,}9\,w_\text{cap}
{{< /formula >}}

Выше этого порога расширение льда создаёт разрушающие напряжения. Стратегии снижения риска: гидрофобизация наружных слоёв, дренажные зазоры, быстрое весеннее высыхание.

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — коэффициенты жидкостного транспорта; данные для типовых материалов.
- **ASHRAE 160** — критерии расчётного анализа контроля влаги.
- **EN ISO 15148** — определение коэффициента капиллярного поглощения; связь с {{< formula >}}D_w{{< /formula >}}.
- **ISO 12572** — паропроницаемость (дополнение к данным по жидкостному транспорту).
- **EN 15026** — расчёт гигротермальных характеристик строительных компонентов.
- **СП 50.13330.2017** — тепловая защита зданий.
- **СП 23-101-2004** — проектирование тепловой защиты зданий.
- **ГОСТ 25898** — паропроницаемость и сорбционное увлажнение строительных материалов.
