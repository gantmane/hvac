## Введение

Проектирование воздуховодов представляет собой систематическое применение принципов механики жидкости к системам распределения воздуха. Цель состоит в доставке заданных расходов воздуха на каждое терминальное устройство при минимизации энергопотребления, стоимости строительства и акустических выбросов. Это требует балансировки конкурирующих ограничений: меньшие воздуховоды снижают стоимость материалов, но увеличивают потери давления и энергию вентилятора; большие воздуховоды снижают трение, но потребляют площадь здания и увеличивают начальную стоимость.

Процесс проектирования включает три фундаментальных этапа: выбор метода расчета, расчет потерь давления через все компоненты системы и проверку того, что скорости остаются в приемлемых пределах для контроля шума. Современное проектирование воздуховодов интегрирует термодинамику (теплопередача через стенки воздуховода), механику жидкости (потеря давления и распределение потока) и акустику (генерирование и затухание шума).

## Фундаментальные уравнения течения

Системы распределения воздуха работают в режиме турбулентного течения (число Рейнольдса > 4000) при стандартных условиях. Управляющие уравнения вытекают из принципов сохранения и эмпирических корреляций для коэффициентов трения.

### Уравнение неразрывности

Сохранение массы требует:

{{< formula display="true" >}}
$$\dot{m} = \rho A V = \text{const}$$
{{< /formula >}}

При постоянной плотности (предположение несжимаемого течения, справедливое для систем воздуховодов):

{{< formula display="true" >}}
$$Q = A_1 V_1 = A_2 V_2$$
{{< /formula >}}

где:
- $Q$ = объемный расход воздуха (м³/ч или м³/с)
- $A$ = площадь поперечного сечения (м²)
- $V$ = средняя скорость (м/ч или м/с)
- $\rho$ = плотность воздуха (кг/м³)
- $\dot{m}$ = массовый расход (кг/с)

### Уравнение Бернулли с потерями

Сохранение энергии вдоль линии тока с учетом трения и дополнительных потерь:

{{< formula display="true" >}}
$$\frac{P_1}{\rho} + \frac{V_1^2}{2} + gz_1 = \frac{P_2}{\rho} + \frac{V_2^2}{2} + gz_2 + h_L$$
{{< /formula >}}

Для горизонтальных воздуховодов с незначительным изменением высоты, выраженной в единицах давления:

{{< formula display="true" >}}
$$P_{s1} + P_{v1} = P_{s2} + P_{v2} + \Delta P_L$$
{{< /formula >}}

где:
- $P_s$ = статическое давление (Па)
- $P_v = \rho V^2/2$ = давление скорости (Па)
- $\Delta P_L$ = полная потеря давления (Па)

### Давление скорости

Компонент динамического давления, вытекающий из движения жидкости:

{{< formula display="true" >}}
$$P_v = \frac{\rho V^2}{2} = 0.602 V^2 \text{ (Па, стандартный воздух при 20°C)}$$
{{< /formula >}}

где $V$ — скорость в м/с.

## Методы расчета воздуховодов

Существуют три основных метода расчета систем воздуховодов, каждый имеет свои отличительные преимущества и применение.

### Метод равного трения

Метод равного трения поддерживает постоянную потерю давления на единицу длины по всей системе. Этот подход обеспечивает сбалансированное проектирование с предсказуемыми потерями давления и упрощает ручные расчеты.

**Процедура проектирования:**

1. Выбрать удельное трение на основе типа системы и ограничений по шуму
2. Рассчитать основной ствол при выбранном удельном трении
3. Рассчитать все ответвления при том же удельном трении
4. Расчитать динамические потери для всех фитингов
5. Балансировать систему с использованием заслонок или переразмерить секции

**Выбор удельного трения:**

Типичные удельные трения для различных приложений:

- Системы низкой скорости: 0.4-0.5 Па/м
- Жилые системы средней скорости: 0.5-0.75 Па/м
- Коммерческие системы: 0.75-1.2 Па/м
- Промышленные системы: 1.2-1.9 Па/м

Более низкие удельные трения снижают энергию вентилятора, но увеличивают размер воздуховода и стоимость. Оптимальное удельное трение минимизирует общую стоимость жизненного цикла (первоначальная стоимость + текущая стоимость затрат на эксплуатацию).

**Преимущества:**
- Просто применить вручную
- Сбалансированное распределение давления
- Минимальный расчет требуется
- Хорошо для предварительного расчета

**Недостатки:**
- Не минимизирует первоначальную стоимость или стоимость эксплуатации
- Требует заслонок для окончательной балансировки
- Статическое давление варьируется по системе
- Неоптимально для сложных систем

### Метод скорости

Метод скорости выбирает размеры воздуховодов на основе максимально допустимых скоростей для контроля шума и энергосбережения. Этот подход непосредственно решает акустические ограничения.

**Рекомендации максимальной скорости:**

{{< table >}}
| Применение | Основные воздуховоды | Ответвления | Финальные выводы |
|-------------|---------------------|------------|-----------------|
| Жилые дома | 3.5-4.5 м/с | 3.0-3.5 м/с | 2.5-3.0 м/с |
| Квартиры | 5.0-6.5 м/с | 3.5-5.0 м/с | 3.0-4.0 м/с |
| Частные офисы | 6.0-7.5 м/с | 4.0-6.0 м/с | 3.0-4.0 м/с |
| Открытые офисы | 7.5-10.0 м/с | 5.0-7.5 м/с | 4.0-6.0 м/с |
| Магазины розничной торговли | 7.5-11.0 м/с | 6.0-9.0 м/с | 5.0-7.5 м/с |
| Промышленные | 10.0-15.0 м/с | 7.5-11.0 м/с | 6.0-9.0 м/с |
{{< /table >}}

**Процедура проектирования:**

1. Выбрать максимальные скорости на основе применения и расположения
2. Рассчитать требуемую площадь: $A = Q/V$
3. Выбрать стандартный размер воздуховода, отвечающий требованию площади
4. Прогрессивно снижать скорость ниже по потоку
5. Рассчитать фактические потери давления
6. Рассчитать вентилятор для полного сопротивления системы

**Преимущества:**
- Прямое управление шумом
- Простой концептуальный подход
- Подходит для приложений с чувствительностью к шуму
- Не требует сложных расчетов

**Недостатки:**
- Не оптимизирует энергию или стоимость
- Может привести к переразмеренным воздуховодам
- Игнорирует восстановление статического давления
- Консервативный подход увеличивает первоначальную стоимость

### Метод восстановления статического давления

Метод восстановления статического давления использует преобразование давления скорости в статическое давление при снижении скорости. Этот подход поддерживает примерно постоянное статическое давление на каждом ответвлении, достигая самобалансирования без заслонок.

**Физический принцип:**

При снижении скорости воздуха в сокращающемся стволе кинетическая энергия преобразуется в статическое давление. Секция воздуховода имеет размер такой, чтобы увеличение статического давления от снижения скорости равнялось потере трения в этой секции:

{{< formula display="true" >}}
$$\Delta P_{v,\text{восст}} = \Delta P_{f,\text{сек}} + \Delta P_{\text{фит}}$$
{{< /formula >}}

**Расчет восстановления статического давления:**

Изменение давления скорости между сечениями:

{{< formula display="true" >}}
$$\Delta P_v = P_{v1} - P_{v2} = \frac{\rho}{2}(V_1^2 - V_2^2)$$
{{< /formula >}}

**Процедура проектирования:**

1. Рассчитать расход воздуха на каждой секции (кумулятивный с терминалов)
2. Выбрать скорость на выпуске вентилятора (обычно 7.5-12.5 м/с)
3. Рассчитать первую секцию для выбранной скорости
4. Рассчитать потерю трения в первой секции
5. Определить снижение скорости для достижения восстановления статического давления, равного потере трения
6. Рассчитать следующую секцию для сниженной скорости
7. Повторить для всех секций
8. Рассчитать динамические потери и проверить статическое давление на ответвлениях

**Преимущества:**
- Сбалансированное статическое давление на ответвлениях
- Минимальные требования заслонок
- Оптимизировано для низких затрат на эксплуатацию
- Самобалансирующееся проектирование

**Недостатки:**
- Сложные ручные расчеты
- Требует итерационного расчета размеров
- Чувствителен к точности коэффициента восстановления
- Сложно применять без программного обеспечения

### Сравнение методов

{{< table >}}
| Критерий | Равное трение | Скорость | Восстановление статического давления |
|----------|---------------|----------|---------------------------------------|
| Первоначальная стоимость | Средняя | Высокая | Низкая-средняя |
| Стоимость эксплуатации | Средняя | Средняя-высокая | Низкая |
| Сложность проектирования | Низкая | Очень низкая | Высокая |
| Требуется балансировка | Да | Да | Минимум |

| Оптимизация | Нет | Шум | Энергия |
| Лучшее применение | Простые системы | Чувствительные к шуму | Сложные, критичные по эффективности |
{{< /table >}}

## Расчет потерь давления

Полная потеря давления состоит из потерь трения в прямых секциях воздуховода и динамических потерь в фитингах, переходах и оборудовании.

### Потеря трения в прямых воздуховодах

Потеря трения результирует из вязкого касательного напряжения на стенке воздуховода и турбулентного обмена импульсом. Уравнение Дарси-Вейсбаха управляет потерей трения:

{{< formula display="true" >}}
$$\Delta P_f = f \frac{L}{D_h} \frac{\rho V^2}{2} = f \frac{L}{D_h} P_v$$
{{< /formula >}}

где:
- $f$ = коэффициент трения Дарси (безразмерный)
- $L$ = длина воздуховода (м)
- $D_h$ = гидравлический диаметр (м)
- $P_v$ = давление скорости (Па)

**Гидравлический диаметр:**

Для некруглых воздуховодов гидравлический диаметр представляет эквивалентный круглый диаметр для расчетов трения:

{{< formula display="true" >}}
$$D_h = \frac{4A}{P_w}$$
{{< /formula >}}

где:
- $A$ = площадь поперечного сечения
- $P_w$ = смоченный периметр

Для прямоугольных воздуховодов:

{{< formula display="true" >}}
$$D_h = \frac{4ab}{2(a+b)} = \frac{2ab}{a+b}$$
{{< /formula >}}

где $a$ и $b$ — размеры воздуховода.

**Коэффициент трения:**

Уравнение Коулбрука связывает коэффициент трения с числом Рейнольдса и относительной шероховатостью:

{{< formula display="true" >}}
$$\frac{1}{\sqrt{f}} = -2 \log_{10}\left(\frac{\epsilon/D_h}{3.7} + \frac{2.51}{Re\sqrt{f}}\right)$$
{{< /formula >}}

где:
- $\epsilon$ = абсолютная шероховатость (м)
- $Re = \rho V D_h / \mu$ = число Рейнольдса
- $\mu$ = динамическая вязкость

Это неявное уравнение требует итерационного решения. Для практического проектирования воздуховодов уравнение Альтшуля-Цала обеспечивает явное приближение:

{{< formula display="true" >}}
$$f = 0.11\left(\frac{\epsilon}{D_h} + \frac{68}{Re}\right)^{0.25}$$
{{< /formula >}}

**Шероховатость поверхности:**

Значения абсолютной шероховатости для распространенных материалов воздуховодов:

{{< table >}}
| Материал | Шероховатость $\epsilon$ (мм) |
|----------|---------------------------------------|
| Гладкие пластик, трубки с вытягиванием | 0.0015 |
| Оцинкованная сталь, спиральная намотка | 0.15 |
| Оцинкованная сталь, продольные швы | 0.15 |
| Стекловолокно | 0.9 |
| Гибкий воздуховод, полностью разогнут | 0.9-3.0 |
| Гибкий воздуховод, сжатый | 3.0-15.0 |
{{< /table >}}

**Метод диаграммы трения:**

Диаграммы трения ASHRAE включают уравнение Дарси-Вейсбаха со стандартными свойствами воздуха и предполагаемой шероховатостью ($\epsilon$ = 0.15 мм для оцинкованной стали). Диаграммы отображают:
- Расход воздуха $Q$ (м³/ч или л/с)
- Диаметр воздуховода или размеры (мм)
- Потеря трения (Па/м)
- Скорость $V$ (м/с)

**Корректировка для высоты и температуры:**

Потеря трения варьируется с плотностью воздуха. Для нестандартных условий:

{{< formula display="true" >}}
$$\Delta P_{f,\text{факт}} = \Delta P_{f,\text{стд}} \times \frac{\rho_{\text{факт}}}{\rho_{\text{стд}}}$$
{{< /formula >}}

Отношение плотности:

{{< formula display="true" >}}
$$\frac{\rho_{\text{факт}}}{\rho_{\text{стд}}} = \frac{P_{\text{факт}}}{P_{\text{стд}}} \times \frac{T_{\text{стд}}}{T_{\text{факт}}}$$
{{< /formula >}}

где давления абсолютные, а температуры абсолютные (Кельвин).

### Динамические потери в фитингах

Фитинги, переходы и оборудование создают турбулентность и отделение потока, что приводит к динамическим потерям давления. Эти потери количественно определяются коэффициентами потерь.

**Метод коэффициента потерь:**

{{< formula display="true" >}}
$$\Delta P_{\text{фит}} = C \times P_v$$
{{< /formula >}}

где:
- $C$ = коэффициент потерь (безразмерный)
- $P_v$ = давление скорости в контрольной точке

**Коэффициенты потерь для колен:**

**Коэффициенты потерь переходов:**

Плавные переходы (расширение или сужение):

Для расширений (увеличение площади):

{{< formula display="true" >}}
$$C = 2.6 \sin\left(\frac{\theta}{2}\right) \left[1 - \left(\frac{A_1}{A_2}\right)\right]^2$$
{{< /formula >}}

на основе скорости на входе $V_1$.

Для сужений (уменьшение площади):

{{< formula display="true" >}}
$$C = 0.5 \sin\left(\frac{\theta}{2}\right) \left[1 - \left(\frac{A_2}{A_1}\right)^2\right]$$
{{< /formula >}}

на основе скорости на выходе $V_2$.

где $\theta$ = включенный угол перехода.

Рекомендуемые углы переходов:
- Расширения: $\theta$ ≤ 20° (предпочтительно ≤ 15°)
- Сужения: $\theta$ ≤ 30° (предпочтительно ≤ 20°)

Абруптные переходы (без переходной секции):

| Конфигурация | Значение $C$ | Эталонная скорость |

| Абруптное расширение | $(1 - A_1/A_2)^2$ | Скорость на входе $V_1$ |
| Абруптное сужение | $0.5(1 - A_2/A_1)$ | Скорость на выходе $V_2$ |
{{< /table >}}

Потери выхода:

Все выпуски воздуховодов в окружающую среду:

{{< formula display="true" >}}
$$\Delta P_{\text{выход}} = 1.0 \times P_v$$
{{< /formula >}}

Полная потеря давления скорости (100% коэффициент потерь). Это применяется к решеткам подачи, диффузорам и вытяжным вентиляторам.

### Полная потеря давления системы

Полная потеря давления от выпуска вентилятора до терминального устройства равна сумме всех потерь трения и динамических потерь:

{{< formula display="true" >}}
$$\Delta P_{\text{полн}} = \sum_{i} \Delta P_{f,i} + \sum_{j} \Delta P_{\text{фит},j}$$
{{< /formula >}}

Для проектирования рассчитайте критический путь (самый длинный маршрут с самым высоким сопротивлением):

1. Определить путь от вентилятора к наиболее удаленному терминалу
2. Рассчитать потерю трения в каждой секции воздуховода
3. Суммировать все потери фитингов вдоль пути
4. Добавить потерю давления терминального устройства
5. Включить потери давления фильтра и теплообменника
6. Добавить коэффициент безопасности (10-15%) для неопределенности

Требование полного давления вентилятора:

{{< formula display="true" >}}
$$P_{t,\text{вент}} = \Delta P_{\text{критич.путь}} + P_{v,\text{выпуск}}$$
{{< /formula >}}

## Влияние соотношения сторон

Прямоугольные воздуховоды отклоняются от круглого поперечного сечения, влияя на потерю давления и стоимость строительства. Соотношение сторон $AR = a/b$ (более длинная сторона / более короткая сторона) количественно определяет это отклонение.

### Гидравлический диаметр в сравнении с эквивалентным диаметром

Для прямоугольных воздуховодов существуют два определения диаметра:

**Гидравлический диаметр** (для расчетов трения):

{{< formula display="true" >}}
$$D_h = \frac{2ab}{a+b}$$
{{< /formula >}}

**Эквивалентный диаметр** (круглый воздуховод с тем же трением и потоком):

{{< formula display="true" >}}
$$D_e = 1.30 \frac{(ab)^{0.625}}{(a+b)^{0.25}}$$
{{< /formula >}}

Для соотношений сторон 1-4, $D_e$ обеспечивает точную потерю трения при использовании с диаграммами трения круглых воздуховодов.

## Пределы скорости для контроля шума

Скорость воздуха генерирует шум посредством турбулентности и вибрации. Чрезмерная скорость создает нежелательные акустические выбросы.

### Механизмы генерирования шума

**Шум турбулентности:**

Флуктуации скорости в турбулентном потоке создают волны давления:

{{< formula display="true" >}}
$$L_W \propto 60 \log_{10}(V) + 10 \log_{10}(A)$$
{{< /formula >}}

где:
- $L_W$ = уровень звуковой мощности (дБ)
- $V$ = скорость воздуха (м/с)
- $A$ = площадь воздуховода (м²)

Удвоение скорости увеличивает шум примерно на 18 дБ.

**Шум фитингов:**

Колена, заслонки и ответвления создают сброс вихрей и отделение потока, генерируя дискретный частотный шум (обычно 500-2000 Гц).

**Шум терминального устройства:**

Решетки и диффузоры генерируют шум при расширении воздуха в занятое пространство. Шум коррелирует со скоростью выпуска и потерей давления.

### Стекловолоконный воздуховод

Жесткая стекловолоконная плита, изготовленная в прямоугольные воздуховоды.

**Свойства материалов:**

- Тепловое сопротивление: R-0.7 - R-1.4 м²·K/W (R-4 - R-8 на дюйм) за дюйм толщины
- Плотность: 48-96 кг/м³
- Огнестойкость: ASTM E84 Класс 1 (распространение пламени ≤ 25)

**Преимущества:**
- Встроенная тепловая изоляция
- Акустическое затухание (1-2 дБ/м типичный)
- Нижняя стоимость установки для определенных применений
- Не требуется внешней изоляции

**Недостатки:**
- Более низкий рейтинг давления (1-2 Па максимум)
- Более высокая шероховатость поверхности (увеличенное трение)
- Потенциальный выброс волокна (требуется герметичная подкладка в критических применениях)
- Чувствительность к влаге

**Соображения расчета:**

Потеря трения на 30-50% выше, чем оцинкованная сталь из-за шероховатости:

{{< formula display="true" >}}
$$\Delta P_{f,\text{стекловолокно}} \approx 1.3-1.5 \times \Delta P_{f,\text{оцинкованная}}$$
{{< /formula >}}

Используйте диаграммы трения для стекловолокна или применяйте коэффициент корректировки.

### Гибкий воздуховод

Гибкий воздуховод состоит из спирали из проволоки, поддерживающей полимерный фильм с внешней изоляцией.

**Материальная конструкция:**
- Внутреннее ядро: полимерный фильм (полиэстер, металлизированный полиэстер)
- Поддержка: спиральная спираль из пружинной стали
- Изоляция: стекловолокно (R-0.75 - R-1.4 м²·K/W)
- Пароизоляция: полимерный фильм куртка

**Потеря давления:**

Гибкий воздуховод показывает значительно более высокое трение, чем жесткий воздуховод:

{{< table >}}
| Условие | Множитель трения против жесткого |
|---------|--------------------------------|
| Полностью разогнут | 1.5-2.0x |
| 10% сжат | 2.0-3.0x |
| 20% сжат | 3.0-5.0x |
{{< /table >}}

**Требования к установке:**

Стандарты ASHRAE/SMACNA для гибкого воздуховода:

- Максимальная длина: 1.5 м на один пробег (минимизировать использование)
- Полное разгибание: Сжатие не допускается
- Интервал поддержки: 1.2 м максимум
- Повороты: Минимизировать изгибы, радиус ≥ 1.5 × диаметр
- Соединения: Защищены с помощью стяжных полос над бусинками

**Применения:**

Гибкий воздуховод служит в качестве терминального соединения между жестким воздуховодом и диффузорами:

- Соединения VAV-бокса к диффузорам
- Регулировки системы воздуховодов во время установки
- Временные установки
- Соединения изоляции вибрации

Не используйте гибкий воздуховод в качестве основного распределения из-за высокой потери трения.

### Требования к изоляции

**Применение внешней изоляции:**

Воздуховоды подачи холодного воздуха требуют изоляции для:
- Предотвращения конденсации (охлаждающие применения)
- Снижения теплопередачи (энергетическая эффективность)
- Снижения передачи шума (акустический барьер)

**Выбор толщины:**

{{< table >}}
| Расположение | Минимальное RSI | Типичная толщина |
|------------|-----------------|-----------------|
| Внутри обусловленного пространства | R-0.5 - R-0.7 | 13-25 мм |
| Необусловленное пространство (чердак, плена) | R-1.1 - R-1.4 | 38-51 мм |
| На улице | R-1.4 - R-1.9 | 51-76 мм |
| Ниже уровня земли | R-1.9 - R-2.6 | 76-102 мм |
{{< /table >}}

**Пароизоляция:**

Охлаждающие применения требуют пароизоляции на внешней поверхности для предотвращения проникновения влаги. Проницаемость пароретардера ≤ 0.02 перм.

**Возвратные воздуховоды:**

Возвратные воздуховоды обычно не требуют изоляции при расположении в обусловленном пространстве. Изолируйте возвратные воздуховоды в необусловленных пространствах для предотвращения конденсации и теплопередачи.

## Проектирование ответвлений

Ответвления значительно влияют на распределение давления и балансировку системы.

### Конфигурации ответвлений

**45° Y-образный (предпочтительный):**

Низкий коэффициент потерь, плавное разделение потока:

{{< formula display="true" >}}
$$C_{\text{отв}} = 0.30 + 0.20 \left(\frac{V_b}{V_m}\right)^2$$
{{< /formula >}}

где:
- $V_b$ = скорость ответвления
- $V_m$ = скорость основного воздуховода выше по потоку

**Коническая тройник (предпочтительная для 90°):**

Суженный вход снижает отделение:

{{< formula display="true" >}}
$$C_{\text{отв}} = 0.15 + 0.15 \left(\frac{V_b}{V_m}\right)^2$$
{{< /formula >}}

**90° тройник (избегать):**

Абруптное изменение направления потока создает высокую потерю:

{{< formula display="true" >}}
$$C_{\text{отв}} = 0.90 + 0.60 \left(\frac{V_b}{V_m}\right)^2$$
{{< /formula >}}

**Тройник типа bullhead (избегать):**

Поток разделяется на два противоположных ответвления, максимальная потеря:

{{< formula display="true" >}}
$$C_{\text{отв}} = 1.50 + 1.50 \left(\frac{V_b}{V_m}\right)^2$$
{{< /formula >}}

### Потеря основного воздуховода на ответвлениях

Основной воздуховод испытывает потерю при разделении потока на ответвлениях:

**Потеря прямого хода:**

{{< formula display="true" >}}
$$C_{\text{основн}} = C_0 \left[1 - \left(\frac{Q_b}{Q_m}\right)^2\right]$$
{{< /formula >}}

где:
- $Q_b$ = поток ответвления
- $Q_m$ = поток основного воздуховода выше по потоку
- $C_0$ = базовый коэффициент (0.10-0.30 в зависимости от конфигурации)

### Стратегия расчета ответвлений

**Метод равной скорости:**

Поддерживайте приблизительно равные скорости в основном воздуховоде и ответвлении:

{{< formula display="true" >}}
$$V_b \approx 0.8-1.0 \times V_m$$
{{< /formula >}}

Это минимизирует коэффициент потерь и балансирует статическое давление.

**Прогрессивное снижение:**

Снижайте скорость основного воздуховода ниже по потоку от каждого ответвления:
1. Рассчитать оставшийся расход после ответвления
2. Переразмерить основной воздуховод для 80-90% скорости выше по потоку
3. Ответвление видит сбалансированное статическое давление

**Расположение заслонки:**

Размещайте балансировочные заслонки на 0.75-1.5 м диаметра воздуховода ниже по потоку от ответвления для обеспечения повторного присоединения потока. Заслонки непосредственно на ответвлении увеличивают турбулентность и шум.

## Расчет и выпуск возвратного и вытяжного воздуха

Возвратные системы работают при более низком давлении и скорости, чем системы подачи.

### Пределы скорости возвратного воздуха

Допустимы более низкие скорости из-за:
- Менее критичной передачи шума (решетки в областях низкой чувствительности)
- Низкой доступности статического давления
- Больших сечений воздуховодов экономически целесообразны

Рекомендуемые максимальные скорости:

{{< table >}}
| Расположение | Основной возврат | Возврат ответвления | Вход решетки |
|------------|-----------------|-------------------|------------|
| Жилые | 4.0 м/с | 3.5 м/с | 3.0 м/с |
| Коммерческие офисы | 10.0 м/с | 7.5 м/с | 4.0 м/с |
| Магазины розничной торговли | 11.0 м/с | 9.0 м/с | 5.0 м/с |
| Промышленные | 12.5 м/с | 10.0 м/с | 6.0 м/с |
{{< /table >}}

### Пути возвратного воздуха

**Воздуховод возврата:**

Полностью проложенные системы возврата обеспечивают:
- Контролируемые пути потока воздуха
- Минимальная утечка
- Акустическая изоляция между пространствами
- Более высокая первоначальная стоимость

Размер, используя метод равного трения при 0.4-0.5 Па/м (ниже, чем подача).

**Возврат плоского воздуховода:**

Использование потолочного плоского воздуховода, полостей стен или приподнятых полов в качестве пути возвратного воздуха:

**Преимущества:**
- Нижняя первоначальная стоимость (отсутствие материала воздуховода)
- Более легкая установка
- Гибкость для будущих модификаций

**Недостатки:**
- Потенциальная передача запаха и загрязнения
- Ограничения кода в конструкции, предусматривающей рейтинг
- Утечка в наружное воздуховед (увеличенная нагрузка)
- Передача звука между пространствами

**Требования кода:**

Плоские пространства должны:
- Использовать кабели с рейтингом плоского воздуховода (CMP, FEP)
- Поддерживать рейтинг огнестойкости с надлежащими проникновениями
- Обеспечивать доступ для очистки
- Соответствовать требованиям MEC раздела 602

**Расчет размеров:**

Скорость плоского воздуховода не должна превышать 1.5× ограничений скорости воздуховода возврата для предотвращения чрезмерного шума от решеток и реестров.

### Расчет размеров системы выхлопа

Кухня, ванная и лабораторная системы выхлопа:

**Рекомендации по скорости:**

**Выхлоп с жиром:**

Кухонные выхлопные воздуховоды требуют специальных соображений:
- Минимальная скорость 7.5 м/с (предотвращение отложения жира)
- Углеродная сталь (не оцинкованная, покрытие деградирует)

### Пример 1: Жилая система принудительного воздуха

**Описание системы:**

Одноэтажный жилой дом площадью 223 м², нагрузка охлаждения 10.5 кВт (3 тонн).

**Параметры проектирования:**

- Расход подачи: $Q = 130$ м³/ч на кВт × 10.5 кВт ≈ 570 м³/ч
- Температура подаваемого воздуха: 13°C
- Температура возвратного воздуха: 24°C
- Расположение воздуховода: Необусловленный чердак
- Метод проектирования: Равное трение

**Шаг 1: Выбрать удельное трение**

Для жилой системы на чердаке: 0.5 Па/м

**Шаг 2: Расчет основного ствола**

При выпуске печи: $Q$ = 570 м³/ч

Из диаграммы трения при 0.5 Па/м и 570 м³/ч:
- Диаметр круглого воздуховода: 355 мм
- Скорость: 4.75 м/с
- Фактическое трение: 0.5 Па/м

Альтернативно, прямоугольный воздуховод:
- Используя $D_e = 1.30(ab)^{0.625}/(a+b)^{0.25} = 355$ мм
- Попытка 254 × 508 мм: $D_e = 1.30(129032)^{0.625}/762^{0.25} = 355$ мм ✓
- Соотношение сторон: 2.0 (приемлемо)

### Пример 2: Коммерческая система VAV

**Описание системы:**

Этаж офисного здания площадью 1115 м², мощность охлаждения 120 кВт.

**Параметры проектирования:**

- Пиковый расход подачи: 22400 м³/ч (130 м³/ч на кВт)
- Температура подаваемого воздуха: 13°C
- Распределение: 24 VAV-бокса, ~933 м³/ч каждый
- Расположение воздуховода: потолочный плоский воздуховод
- Метод проектирования: восстановление статического давления

**Шаг 1: Предварительный расчет основного воздуховода**

Выберите скорость выпуска: 10 м/с

Требуемая площадь:

{{< formula display="true" >}}
$$A = \frac{Q}{V} = \frac{22400}{10 \times 3600} = 0.62 \text{ м}^2 = 6200 \text{ см}^2$$
{{< /formula >}}

Круглый диаметр:

{{< formula display="true" >}}
$$D = \sqrt{\frac{4A}{\pi}} = \sqrt{\frac{4 \times 0.62}{\pi}} = 0.89 \text{ м} = 890 \text{ мм}$$
{{< /formula >}}

Используйте прямоугольный 914 × 1524 мм ($D_e$ = 890 мм, AR = 1.67).

**Шаг 2: Расчет по секциям (восстановление статического давления)**

Первая секция (вентилятор к первому VAV-боксу):
- Длина: 12 м
- Расход: 22400 м³/ч
- Скорость: 10 м/с
- $P_v = 60$ Па

Потеря трения при 914 × 1524 мм:
- Из диаграммы трения: 0.3 Па/м
- Потеря секции: 0.3 × 12 = 3.6 Па

После первого ответвления (933 м³/ч удалено):
- Оставшийся расход: 21467 м³/ч
- Целевая скорость для восстановления: решить для скорости, где восстановление = трение

Доступное восстановление:

{{< formula display="true" >}}
$$\Delta P_v = P_{v1} - P_{v2} = 60 - \left(\frac{V_2}{10}\right)^2 \times 60$$
{{< /formula >}}

С коэффициентом восстановления $R$ = 0.75:

{{< formula display="true" >}}
0.75 \Delta P_v = \Delta P_f$$
{{< /formula >}}

Целевое трение для следующей секции: 3.6 Па / 11 м × 100 = 0.33 Па/м

Из диаграммы трения при 21467 м³/ч и 0.33 Па/м:
- Диаметр: 840 мм
- Скорость: 9.5 м/с
- Проверить восстановление: $\Delta P_v = 60 - 54 = 6$ Па
- Восстановлено: 0.75 × 6 = 4.5 Па ≈ 4.0 Па (близко)

Продолжайте этот процесс для каждой секции, прогрессивно уменьшая диаметр и скорость.

**Шаг 3: Потери фитингов**

Основные фитинги в критическом пути:

|--------|------------|---------|-----------|
| Переход выпуска вентилятора | 0.15 | 60 | 9 |
| Колено 90°, с лопатками | 0.12 | 60 | 7 |
| Колено 90°, с лопатками | 0.12 | 54 | 6.5 |
| Ответвления конической тройник (×6) | 0.20 | 48 средне | 4.6 |
| VAV-бокс | 0.15 | 42 | 2.6 |

**Шаг 4: Полное давление**

При надлежащем проектировании восстановления статического давления потери трения приблизительно уравновешиваются восстановлением скорости. Полное системное давление определяется:
- Потери фитингов: 41.7 Па
- Остаточное трение (неполное восстановление): 10 Па
- Коэффициент безопасности: 10 Па

Полное системное давление: ~62 Па

Добавить фильтр (100 Па) и теплообменник (160 Па):

{{< formula display="true" >}}
$$P_{t,\text{вент}} = 62 + 100 + 160 = 322 \text{ Па}$$
{{< /formula >}}

При скорости выпуска 10 м/с:

{{< formula display="true" >}}
$$P_{v,\text{выпуск}} = 60 \text{ Па}$$
{{< /formula >}}

Полное давление вентилятора:

{{< formula display="true" >}}
$$FTP = 322 + 60 = 382 \text{ Па}$$
{{< /formula >}}

**Шаг 5: Соображения системы VAV**

При минимальном расходе (30% проекта):
- Основной расход воздуховода: 6720 м³/ч
- Скорость: 3.0 м/с (1/3 проекта)
- Потеря давления: $(3/10)^2$ = 0.09 × проект ≈ 6 Па
- Вентилятор движется назад на кривую, давление увеличивается
- VAV-боксы дроссельнуют для поддержания установки
- Управление вентилятором (VFD) снижает скорость для поддержания давления в воздуховоде

Расположение датчика статического давления: 2/3 расстояния в системе воздуховодов для поддержания адекватного давления на всех терминалах.

### Пример 3: Анализ гибкого выпуска

**Конфигурация:**

VAV-бокс к соединению потолочного диффузора с использованием гибкого воздуховода.

**Параметры:**

- Расход воздуха: 230 м³/ч
- Диаметр гибкого воздуховода: 254 мм
- Длина: 1.8 м (превышает рекомендацию 1.5 м, но обычный на практике)
- Потеря давления диффузора: 10 Па

**Альтернатива жесткого воздуховода:**

Жесткий круглый воздуховод 254 мм:
- Скорость: $V = 230 / (π × (254/1000)^2 / 4) = 4.6$ м/с
- Трение: 0.25 Па/м (из диаграммы)
- Потеря: 0.25 × 1.8 = 0.45 Па

**Гибкий воздуховод (полностью разогнут):**

Множитель трения: 2.0× жесткий воздуховод
- Трение: 0.5 Па/м
- Потеря: 0.5 × 1.8 = 0.9 Па

**Гибкий воздуховод (10% сжат до 1.62 м):**

Множитель трения: 3.0× жесткий воздуховод
- Эффективное трение: 0.75 Па/м
- Потеря: 0.75 × 1.62 = 1.2 Па

**Анализ влияния:**

Для 24 диффузоров в здании:

{{< table >}}
| Конфигурация | Потеря на выпуск | Итого потеря (24×) | Годовая стоимость энергии* |
|--------------|-----------------|------------------|------------------------|
| Жесткий воздуховод | 0.45 Па | 2.7 Па | Базовая |
| Гибкий (разогнут) | 0.9 Па | 5.4 Па | +$85/год |
| Гибкий (сжат) | 1.2 Па | 7.0 Па | +$135/год |
{{< /table >}}

*Предполагает 3000 часов эксплуатации/год, $0.15/кВ·ч, эффективность вентилятора 55%, эффективность двигателя 92%.

**Расчет стоимости энергии:**

Увеличение давления от гибкого воздуховода: $\Delta P$ = 5.4 - 2.7 = 2.7 Па

Увеличение мощности вентилятора:

{{< formula display="true" >}}
$$\Delta W = \frac{Q \times \Delta P}{3600 \times \eta_{\text{вент}} \times \eta_{\text{мот}}}$$
{{< /formula >}}

{{< formula display="true" >}}
$$\Delta W = \frac{5600 \times 2.7}{3600 \times 0.55 \times 0.92} = 0.23 \text{ кВ}$$
{{< /formula >}}

Годовая стоимость:

{{< formula display="true" >}}
$$\text{Стоимость} = 0.23 \text{ кВ} \times 3000 \text{ ч} \times \$0.15/\text{кВ·ч} = \$104/\text{год}$$
{{< /formula >}}

**Заключение:**

Минимизируйте использование гибкого воздуховода. Каждое соединение гибкого воздуховода 1.8 м стоит $100-135/год дополнительной энергии по сравнению с жестким воздуховодом. В течение 20-летнего жизненного цикла это представляет $2000-2700 за соединение при 3% дисконтной ставке.

## Передовые соображения по проектированию

### Прибыль и потеря тепла в воздуховоде

Температура воздуха изменяется при передаче тепла через стенки воздуховода. Это влияет на доставленную мощность и контроль влажности.

**Скорость теплопередачи:**

{{< formula display="true" >}}
$$\dot{Q} = U \times A_s \times (T_{\text{окр}} - T_{\text{воздух}})$$
{{< /formula >}}

где:
- $U$ = общий коэффициент теплопередачи (кВт/(м²·K))
- $A_s$ = площадь поверхности воздуховода (м²)
- $T_{\text{окр}}$ = температура окружающей среды (°C)
- $T_{\text{воздух}}$ = температура воздуха в воздуховоде (°C)

**Общий коэффициент теплопередачи:**

{{< formula display="true" >}}
$$U = \frac{1}{\frac{1}{h_i} + \frac{t_{\text{изл}}}{k_{\text{изл}}} + \frac{1}{h_o}}$$
{{< /formula >}}

Для типичного изолированного воздуховода на чердаке:
- Внутренний коэффициент пленки $h_i$ = 8.5 кВт/(м²·K)
- Теплопроводность изоляции $k_{\text{изл}}$ = 0.040 кВт/(м·K) (стекловолокно)
- Толщина изоляции $t_{\text{изл}}$ = 0.05 м = 50 мм
- Внешний коэффициент пленки $h_o$ = 11 кВт/(м²·K)

{{< formula display="true" >}}
$$U = \frac{1}{\frac{1}{8.5} + \frac{0.05}{0.040} + \frac{1}{11}} = \frac{1}{0.118 + 1.25 + 0.091} = 0.6 \text{ кВт/(м}^2\text{·K)}$$
{{< /formula >}}

**Изменение температуры:**

{{< formula display="true" >}}
$$\Delta T = \frac{\dot{Q}}{\rho \times c_p \times Q}$$
{{< /formula >}}

где:
- $\rho$ = плотность воздуха = 1.2 кг/м³
- $c_p$ = удельная теплоемкость = 1005 J/(кг·K)
- $Q$ = расход (м³/ч)

**Пример:**

Воздуховод диаметром 508 мм, длина 15 м на чердаке 49°C, подача холода 13°C, расход 567 м³/ч:

Площадь поверхности: $A_s = π × (508/1000) × 15 = 23.9$ м²

Теплопередача:

{{< formula display="true" >}}
$$\dot{Q} = 0.6 \times 23.9 \times (49 - 13) = 514 \text{ кВ}$$
{{< /formula >}}

Изменение температуры:

{{< formula display="true" >}}
$$\Delta T = \frac{514}{1.2 \times 1005 \times (567/3600)} = 4.5°C$$
{{< /formula >}}

Доставляемая температура воздуха: 13 + 4.5 = 17.5°C (значительно деградированная охлаждающая мощность).

**Смягчение:**

- Расположить воздуховоды в обусловленном пространстве
- Увеличить толщину изоляции (R-1.4 - R-1.9 м²·K/W минимум в необусловленных пространствах)
- Минимизировать длину воздуховода в экстремальных окружениях
- Рассмотрите захоронение воздуховода в чердачную изоляцию

### Утечка воздуховодов

Реальные системы воздуховодов пропускают воздух через швы, проникновения и поврежденные участки. Утечка снижает доставляемый расход воздуха и увеличивает энергопотребление.

**Классы утечки:**

ASHRAE 90.1 и IECC определяют классы утечки воздуховодов:

{{< table >}}
| Класс уплотнения | Максимальная утечка | Применение |
|-----------------|-----------------|----------|
| Класс уплотнения 48 | 48 м³/ч на м² @ 25 Па | Неуплотненные, устаревшие системы |
| Класс уплотнения 24 | 24 м³/ч на м² @ 25 Па | Стандартно уплотненные, минимум код |
| Класс уплотнения 12 | 12 м³/ч на м² @ 25 Па | Хорошо уплотненные системы |
| Класс уплотнения 6 | 6 м³/ч на м² @ 25 Па | Плотно уплотненные, лучшая практика |
{{< /table >}}

**Скорость утечки:**

{{< formula display="true" >}}
$$Q_{\text{утеч}} = C_L \times A_s \times \left(\frac{\Delta P}{25 \text{ Па}}\right)^{0.65}$$
{{< /formula >}}

где:
- $C_L$ = класс утечки (м³/ч на м² @ 25 Па)
- $A_s$ = площадь поверхности воздуховода (м²)
- $\Delta P$ = давление воздуховода (Па)

**Пример:**

Площадь поверхности воздуховода 93 м², класс уплотнения 12, работающий при 50 Па:

{{< formula display="true" >}}
$$Q_{\text{утеч}} = 12 \times 93 \times (50/25)^{0.65} = 12 \times 93 \times 1.57 = 1753 \text{ м}^3\text{/ч}$$
{{< /formula >}}

Для системы 4667 м³/ч это представляет 0.38% утечку.

**Влияние:**

- Снижение доставляемого расхода воздуха на терминалы
- Увеличение энергии вентилятора (более высокий расход на вентиляторе)
- Увеличение энергии на отопление/охлаждение (кондиционированный воздух потерян в необусловленном пространстве)
- Дисбаланс давления (отрицательное давление всасывает некондиционированный воздух)

**Тестирование:**

Тестирование утечки воздуховода согласно ANSI/RESNET/ICC 380:
- Подвергнуть систему давлению 25 Па
- Измерить расход воздуха, необходимый для поддержания давления
- Рассчитать утечку как м³/ч на м² поверхности воздуховода

Цель: ≤ 6 м³/ч на м² @ 25 Па для плотной конструкции.

## Резюме и процесс проектирования

### Комплексный рабочий процесс проектирования

1. **Расчет нагрузки и требования к расходу воздуха**
   - Рассчитайте нагрузку на отопление и охлаждение согласно методам ACCA Manual J или ASHRAE
   - Определить расход подачи: $Q = \text{Нагрузка} / (1.2 \times \Delta T)$
   - Установить требования расхода для каждого терминального устройства

2. **Предварительный макет**
   - Рисовать маршрутизацию воздуховодов на планах здания
   - Определить доступное пространство для установки воздуховодов
   - Расположить устройства подачи и возврата
   - Определить критический путь (самый длинный, самый высокий пробег сопротивления)

3. **Выбор метода расчета**
   - Равное трение: простые системы, ручное проектирование
   - Метод скорости: приложения, критичные по шуму
   - Восстановление статического давления: большие системы, приоритет энергетической эффективности

4. **Расчет основного воздуховода**
   - Выбрать начальную скорость или удельное трение
   - Рассчитать основной ствол воздуховода
   - Проверить соотношение сторон ≤ 4:1 предпочтительно, ≤ 8:1 максимум

5. **Расчет размеров ответвлений и выводов**
   - Рассчитать ответвления, используя выбранный метод
   - Прогрессивно снижать скорость ниже по потоку
   - Поддерживать пределы скорости для контроля шума

6. **Расчет потерь давления**
   - Рассчитать потерю трения для всех секций
   - Определить коэффициенты потерь фитингов
   - Суммировать потери вдоль критического пути
   - Добавить потери оборудования (фильтр, теплообменник, терминальные устройства)

7. **Проектирование системы возврата**
   - Рассчитать воздуховоды возврата при более низком удельном трении
   - Рассмотрите возврат плоского воздуховода, где применимо
   - Рассчитать потерю системы возврата

8. **Выбор вентилятора**
   - Суммировать потери подачи и возврата
   - Добавить коэффициент безопасности (10-15%)
   - Выбрать вентилятор для требуемого м³/ч при полном ESP
   - Проверить работу вентилятора на кривой производительности

9. **Детальное проектирование**
   - Указать материалы и толщину воздуховодов
   - Детальные переходы и фитинги
   - Расположить балансировочные заслонки
   - Указать требования к изоляции и уплотнению

10. **Проверка**
    - Проверить все скорости по пределам
    - Проверить соотношения сторон
    - Подтвердить доступное статическое давление на всех терминалах
    - Проверить наличие и доступ

### Ключевые принципы проектирования

**Минимизировать потерю давления:**
- Используйте плавные переходы (15-20° расширение, 20-30° сужение)
- Предпочитать ответвления Y 45° вместо тройников 90°
- Указать направляющие лопатки в прямоугольных коленах
- Минимизировать использование гибкого воздуховода (≤ 1.5 м, полностью разогнут)

**Поддерживать пределы скорости:**
- Выбрать скорости на основе критериев шума приложения
- Прогрессивно снижать скорость ниже по потоку
- Держать скорость терминального выпуска низкой (2.5-4.0 м/с)
- Рассмотрите акустическую облицовку для высокоскоростных воздуховодов

**Оптимизировать соотношение сторон:**
- Предпочитать квадратные или близкие к квадратным сечения (AR ≤ 2)
- Используйте плоские воздуховоды только где пространство требует (AR ≤ 8 максимум)
- Помните: каждое удвоение AR увеличивает потерю на 10-15%

**Обеспечить надлежащее уплотнение:**
- Указать класс уплотнения согласно ASHRAE 90.1
- Уплотнить все поперечные швы и продольные швы
- Используйте мастику или одобренные ленты (нет тканевой резервной трубки)
- Протестируйте утечку воздуховода в критических проектах

**Учитывать условия реального мира:**
- Включить коэффициенты безопасности (10-15%) для неопределенности
- Рассмотрите прибыль/потерю тепла в воздуховоде в необусловленных пространствах
- Указать достаточную изоляцию (R-1.1 - R-1.4 м²·K/W минимум в необусловленных пространствах)
- Проектировать для будущих модификаций и доступа

Этот комплексный подход к проектированию воздуховодов интегрирует физико-механические основы с практическими ограничениями строительства, доставляя эффективные, тихие и надежные системы распределения воздуха. Методы, основанные на физике, представленные здесь, позволяют инженерам понять поведение системы, оптимизировать конструкции и устранять проблемы производительности на протяжении жизненного цикла системы.
