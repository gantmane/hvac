## Обзор

Переохлаждённая (сжатая) жидкость — состояние хладагента при температуре ниже температуры насыщения для данного давления. В парокомпрессионном цикле это состояние реализуется в жидкостной магистрали между конденсатором и терморегулирующим вентилем (ТРВ / EEV). Степень переохлаждения ($\Delta T_{\text{sub}}$) — разность температуры насыщения и фактической температуры жидкости при рабочем давлении конденсатора.

Корректное определение энтальпии переохлаждённой жидкости критично: она является начальной точкой дроссельного процесса ($h_4 = h_3$) и непосредственно определяет холодопроизводительность испарителя ($q_0 = h_1 - h_4$). Недооценка переохлаждения на 5 К типично занижает $q_0$ на 2–4 % для HFC-хладагентов. Стандартные таблицы публикуются в ASHRAE Handbook — Fundamentals (2021), Ch. 30; точные значения рассчитываются с помощью NIST REFPROP v10.

## Физические основы

### Уравнение состояния сжатой жидкости

Для жидкой фазы влияние давления на удельный объём значительно меньше, чем влияние температуры (жидкости практически несжимаемы). Удельный объём:

{{< formula display="true" >}}
v(T, P) = v_f(T) + \left(\frac{\partial v}{\partial P}\right)_T (P - P_{\text{sat}}(T))
{{< /formula >}}

где $v_f(T)$ — удельный объём насыщенной жидкости при температуре $T$; $(\partial v / \partial P)_T < 0$ (жидкость сжимается с давлением, но незначительно). Для HFC-хладагентов изменение $v$ составляет ~0,05–0,3 % на 1 МПа дополнительного давления.

### Энтальпия переохлаждённой жидкости

Точное выражение:

{{< formula display="true" >}}
h(T, P) = h_f(T) + \left[v_f(T) - T\left(\frac{\partial v_f}{\partial T}\right)_P\right](P - P_{\text{sat}}(T))
{{< /formula >}}

Для практических расчётов вторым слагаемым в скобках пренебрегают (приближение несжимаемой жидкости):

{{< formula display="true" >}}
h(T, P) \approx h_f(T) + v_f(T) \cdot (P - P_{\text{sat}}(T))
{{< /formula >}}

Это приближение даёт ошибку не более 1–2 % при $\Delta P \leq 1000$ кПа, что приемлемо для большинства инженерных расчётов. Для высокоточных задач (точность ±0,1 %) используйте NIST REFPROP v10.

### Степень переохлаждения

{{< formula display="true" >}}
\Delta T_{\text{sub}} = T_{\text{sat}}(P_{\text{конд}}) - T_{\text{жидк}}
{{< /formula >}}

Где $T_{\text{sat}}(P_{\text{конд}})$ — температура насыщения при давлении конденсации (из таблиц насыщения), $T_{\text{жидк}}$ — измеренная температура жидкостной линии.

## Расчётные методы

### Двойная линейная интерполяция

При промежуточных значениях T и P:

{{< formula display="true" >}}
h(T, P) \approx h_{ij} + \frac{T - T_i}{T_{i+1} - T_i}(h_{i+1,j} - h_{ij}) + \frac{P - P_j}{P_{j+1} - P_j}(h_{i,j+1} - h_{ij})
{{< /formula >}}

где индексы $i$, $j$ соответствуют ближайшим меньшим табулированным значениям температуры и давления.

### Упрощённый расчёт энтальпии

Для полевых расчётов (точность ±1–2 %):

{{< formula display="true" >}}
h(T, P) \approx h_f(T) + v_f(T) \cdot [P - P_{\text{sat}}(T)]
{{< /formula >}}

При $\Delta P < 500$ кПа поправка $v_f \cdot \Delta P$ составляет 0,3–0,6 кДж/кг — в большинстве случаев её можно не учитывать, используя просто $h_f(T)$ из таблицы насыщения.

## Численный пример

**Задача.** Система на R-134a. Конденсатор работает при давлении $P_{\text{конд}} = 1017$ кПа ($T_{\text{sat}} = 40$ °C). Жидкость выходит из конденсатора при $T_3 = 35$ °C. Найти $h_3$, степень переохлаждения и прирост холодопроизводительности по сравнению с отсутствием переохлаждения.

**Решение.**

Степень переохлаждения:
$$\Delta T_{\text{sub}} = 40 - 35 = 5 \text{ К}$$

Энтальпия переохлаждённой жидкости:
$$h_f(35\text{ °C}) = h_f(30) + \frac{35-30}{40-30}[h_f(40) - h_f(30)] = 157{,}1 + 0{,}5 \times (181{,}1 - 157{,}1) = 169{,}1 \text{ кДж/кг}$$

Поправка на давление:
$$v_f(35\text{ °C}) \approx 0{,}000816 \text{ м³/кг}, \quad P_{\text{sat}}(35\text{ °C}) \approx 887 \text{ кПа}$$
$$\Delta h_P = 0{,}000816 \times (1017 - 887) = 0{,}11 \text{ кДж/кг}$$

{{< formula display="true" >}}
h_3 = 169{,}1 + 0{,}11 = 169{,}2 \text{ кДж/кг}
{{< /formula >}}

Для сравнения, без переохлаждения ($\Delta T_{\text{sub}} = 0$): $h_3 = h_f(40\text{ °C}) = 181{,}1$ кДж/кг.

Прирост холодопроизводительности (при $\dot{m} = 0{,}12$ кг/с):
$$\Delta Q = \dot{m}(h_{3,\text{без}} - h_{3,\text{с}}) = 0{,}12 \times (181{,}1 - 169{,}2) = 0{,}12 \times 11{,}9 = 1{,}43 \text{ кВт}$$

Базовая холодопроизводительность при $h_1 \approx 455$ кДж/кг:
$$Q_{\text{без}} = 0{,}12 \times (455 - 181{,}1) = 32{,}9 \text{ кВт}$$

Относительный прирост: $1{,}43 / 32{,}9 \approx 4{,}3$ %. Каждый кельвин переохлаждения R-134a добавляет ~0,85–0,9 % холодопроизводительности.

## Применение в системах ОВК

**Конденсатор.** Выход хладагента из конденсатора при небольшом переохлаждении (5–10 К) предотвращает вскипание в жидкостной магистрали до ТРВ, особенно при значительном перепаде высот (вертикальные стояки) или при высоком гидравлическом сопротивлении магистрали.

**Терморегулирующий вентиль (ТРВ/EEV).** Энтальпия на входе вентиля ($h_3$) берётся из таблиц переохлаждения. Качество хладагента после дросселирования:

{{< formula display="true" >}}
x_4 = \frac{h_4 - h_f(T_{\text{исп}})}{h_{fg}(T_{\text{исп}})}
{{< /formula >}}

где $h_4 = h_3$ (изоэнтальпийный процесс). Переохлаждение снижает $x_4$ и увеличивает долю жидкости, поступающей в испаритель.

**Подбор компрессора.** Степень переохлаждения не влияет на работу компрессора напрямую (точки 1 и 2 остаются теми же), но увеличивает удельную холодопроизводительность, что позволяет снизить массовый расход хладагента при той же тепловой нагрузке.

## Стандарты и нормативы

- **ASHRAE Handbook — Fundamentals (2021), Ch. 30** — таблицы переохлаждённой жидкости для R-134a, R-410A, R-32, R-717 и др.
- **NIST REFPROP v10** — точные расчёты свойств сжатой жидкости для 147+ веществ.
- **ISO 817:2014** — классификация хладагентов; ссылки на источники свойств.
- **EN 378-1:2016+A1** — требования к безопасности холодильных систем, включая расчёты давления.
- **СП 60.13330.2020** — проектирование систем ОВК; расчётные условия для жидкостных магистралей.

**Ошибки при работе с таблицами:**

1. Использование $h_f(T_{\text{конд}})$ вместо $h_f(T_{\text{жидк}})$ при наличии переохлаждения занижает $q_0$ и приводит к неправильному подбору компрессора.

2. Пренебрежение поправкой на давление оправдано при $\Delta P < 1000$ кПа (ошибка < 0,5 %), но при трансикритических циклах (R-744) или при $\Delta P > 2000$ кПа поправка обязательна.

3. Экстраполяция за пределы табулированного диапазона недопустима — при давлениях, близких к критическому ($P_r > 0{,}85$), свойства жидкости изменяются нелинейно и простые аппроксимации неприменимы.

Для критических расчётов используйте NIST REFPROP v10 или CoolProp; для полевых оценок — упрощённую формулу $h \approx h_f(T)$ с допустимой ошибкой < 1 %.
