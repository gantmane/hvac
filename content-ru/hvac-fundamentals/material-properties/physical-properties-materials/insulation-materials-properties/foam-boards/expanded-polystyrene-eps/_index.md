Вспененный полистирол (EPS, expanded polystyrene; в российской классификации — ВПС) — жёсткий теплоизоляционный материал, получаемый вспениванием полистирольных гранул паром с последующим спеканием. Готовое изделие представляет собой ячеистую структуру, в которой 95–98 % объёма занимает воздух. EPS широко применяется в системах HVAC благодаря сочетанию низкой теплопроводности (λ = 0,033–0,040 Вт/м·К), стабильных во времени RSI-значений, доступной стоимости и простоты обработки.

## Физические принципы теплоизоляции

Теплопередача в EPS происходит через три механизма:

{{< formula display="true" >}}
\lambda_{\text{эфф}} = \lambda_{\text{газ}} + \lambda_{\text{тв}} + \lambda_{\text{изл}}
{{< /formula >}}

где:
- λ_газ — теплопроводность воздуха в порах ≈ 0,025 Вт/м·К при 20 °C (основной вклад ~75–80 %);
- λ_тв — кондукция через полимерный каркас (~15–20 %);
- λ_изл — лучистая составляющая (пренебрежимо мала при T < 80 °C).

Поскольку ячейки EPS содержат воздух (не вспенивающий агент), теплопроводность стабильна в течение всего срока эксплуатации — в отличие от XPS и полиизо, которые подвергаются тепловому дрейфу при диффузии вспенивателя.

Коэффициент теплопередачи через слой EPS:

{{< formula display="true" >}}
U = \frac{\lambda}{d}
{{< /formula >}}

где λ — теплопроводность (Вт/м·К), d — толщина (м). Тепловое сопротивление: RSI = d/λ.

**Температурная зависимость λ EPS:**
- При −7 °C: λ ≈ 0,033 Вт/м·К.
- При 24 °C: λ ≈ 0,038 Вт/м·К.
- При 66 °C: λ ≈ 0,046 Вт/м·К.

## Паропроницаемость

EPS имеет **умеренную** паропроницаемость (μ-фактор = 20–40; паропроницаемость = 32–79 нг/(м²·с·Па)), что соответствует классу III (полупроницаемый паровой замедлитель по классификации ASHRAE Handbook, Ch. 26).

**Практический вывод:** при использовании EPS для изоляции холодных трубопроводов (T < 10 °C) и воздуховодов с охлаждённым воздухом необходим паробарьер на тёплой (наружной) стороне изоляции — полиэтиленовая плёнка 0,15 мм или алюминиевая фольга.

Водопоглощение при погружении (ASTM C272, 24 ч): 2–4 % по объёму — выше, чем у XPS, из-за частично открытой структуры между спечёнными гранулами.

## Числовой пример: расчёт толщины изоляции воздуховода

**Условие.** Приточный воздуховод в подвале здания (климатическая зона 4). Температура воздуха в воздуховоде T_вд = 13 °C; температура подвального помещения T_пом = 22 °C; относительная влажность φ = 65 % → T_точки_росы = 15,6 °C (по ASHRAE Psychrometric Chart 2017). Допустимый запас: 2 К.

**Шаг 1. Минимальная температура наружной поверхности изоляции:**

{{< formula display="true" >}}
T_{\text{пов}} = T_{\text{tp}} + \Delta T_{\text{зап}} = 15{,}6 + 2 = 17{,}6 \; °\text{C}
{{< /formula >}}

**Шаг 2. Тепловой поток через наружную плёнку воздуха (α_нар = 9 Вт/м²·К):**

{{< formula display="true" >}}
q = \alpha_{\text{нар}} \times (T_{\text{пом}} - T_{\text{пов}}) = 9 \times (22 - 17{,}6) = 39{,}6 \; \text{Вт/м}^2
{{< /formula >}}

**Шаг 3. Требуемое RSI изоляции:**

{{< formula display="true" >}}
RSI_{\text{тр}} = \frac{T_{\text{пов}} - T_{\text{вд}}}{q} = \frac{17{,}6 - 13}{39{,}6} \approx 0{,}116 \; \text{м}^2\text{·К/Вт}
{{< /formula >}}

**Шаг 4. Минимальная толщина EPS ВПС-25 (λ = 0,037 Вт/м·К):**

{{< formula display="true" >}}
d = RSI_{\text{тр}} \times \lambda = 0{,}116 \times 0{,}037 = 0{,}0043 \; \text{м} \approx 4{,}3 \; \text{мм}
{{< /formula >}}

**Шаг 5. Принятая толщина:** 25 мм (минимум по ASHRAE 90.1, Table 6.8.2 для воздуховодов при ΔT ≥ 11 К). При φ = 80 % (например, подвал без вентиляции): T_точки_росы ≈ 19,2 °C; требуемое RSI возрастает до 0,43 м²·К/Вт → принять d = 50 мм.

## Применение в системах HVAC

### Изоляция приточных воздуховодов

EPS применяется в виде листов или скорлупы, наклеиваемых на металлические воздуховоды. Крепление — полиуретановый клей или механические дюбели с широкими шайбами. Стыки проклеиваются алюминиевой лентой шириной ≥ 50 мм. Неплотные стыки создают тепловые мосты, снижающие эффективность на 15–25 %.

### Изоляция трубопроводов охлаждённой воды

Трубопроводы чиллерных систем (T = 7–12 °C) изолируются скорлупой EPS или плоскими плитами. Минимальная толщина по ASHRAE 90.1 (климатическая зона 4–5): 25–50 мм в зависимости от диаметра. Обязательна алюминиевая фольга или ПЭ-плёнка как паробарьер.

### Применение в кровельных системах

EPS используется как изоляционный слой в обычных и инверсионных кровельных системах. В инверсионной кровле EPS укладывается поверх гидроизоляции, балластируется гравием — влагостойкость EPS (2–4 % по объёму) достаточна при защите гравием.

## Типичные ошибки при проектировании

1. Применение начального λ без учёта рабочего диапазона температур — при T = 50–70 °C λ возрастает на 15–20 %.
2. Отсутствие паробарьера при изоляции холодных поверхностей — образование конденсата внутри материала.
3. Неплотная стыковка плит без проклейки — тепловые мосты снижают RSI системы на 15–25 %.
4. Применение ВПС-15 в местах механических нагрузок — недостаточная прочность (30–50 кПа).
