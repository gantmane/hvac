Физические свойства материалов определяют интенсивность теплопередачи через ограждающие конструкции, ёмкость аккумуляции энергии, допустимое давление в трубопроводах и компенсацию температурного расширения. Точные данные о свойствах необходимы для расчётов тепловых нагрузок, подбора изоляции, проектирования трубопроводных систем и энергетического моделирования. Настоящий раздел охватывает основные категории свойств с численными значениями, корреляциями и примерами применения.

## Теплопроводность

Теплопроводность (thermal conductivity) λ — интенсивная характеристика материала, связывающая плотность теплового потока с градиентом температуры через закон Фурье:

{{< formula display="true" >}}
q = -\lambda \, \nabla T, \quad [q] = \text{Вт/м}^2, \quad [\lambda] = \text{Вт/(м·К)}
{{< /formula >}}

Тепловое сопротивление плоского слоя толщиной δ:

{{< formula display="true" >}}
R = \frac{\delta}{\lambda}, \quad \left[\frac{\text{м}^2\text{·К}}{\text{Вт}}\right]
{{< /formula >}}

Для большинства металлов λ снижается с ростом температуры (рост числа фононных рассеяний на дефектах кристаллической решётки). Для изоляционных материалов λ возрастает с температурой из-за увеличения радиационного вклада в пористой структуре.

**Линейная аппроксимация** для ограниченного диапазона ΔT:

{{< formula display="true" >}}
\lambda(T) \approx \lambda_0 \left[1 + \beta (T - T_0)\right]
{{< /formula >}}

где β — температурный коэффициент, К⁻¹ (для конструкционной стали β ≈ −2×10⁻⁴ К⁻¹).

{{< table title="Теплопроводность материалов HVAC при T ≈ 20–25 °C" >}}
| Материал | λ, Вт/(м·К) | Примечание |
|----------|-------------|------------|
| Медь (Cu) | 385 | Трубопроводы ХВС/ГВС, холодильные системы |
| Алюминий (Al 1050) | 229 | Оребрение теплообменников |
| Углеродистая сталь (Fe) | 50 | Трубы, воздуховоды |
| Нержавеющая сталь 304 | 16,3 | Пищевые и медицинские системы |
| Чугун | 46–52 | Радиаторы, арматура |
| Бетон тяжёлый | 1,40–1,75 | Несущие конструкции |
| Кирпич керамический | 0,56–0,81 | Наружные стены |
| Дерево поперёк волокон | 0,09–0,18 | Деревянный каркас |
| Минеральная вата (MW) | 0,033–0,046 | Тепло- и звукоизоляция |
| Пенополистирол EPS | 0,033–0,040 | Фасадная теплоизоляция |
| Пенополиуретан PIR | 0,022–0,028 | Сэндвич-панели, скорлупы |
| Пенополиуретан SPF | 0,024–0,035 | Напыляемая изоляция |

| Вода при 20 °C | 0,598 | Теплоноситель |
{{< /table >}}

Источники: ASHRAE Handbook Fundamentals 2021, гл. 33; ГОСТ 28547.

**Пример — расчёт потока теплоты через ограждающую конструкцию:**

Стена: кирпич 0,25 м + минвата 0,10 м + газобетон 0,20 м. Температуры поверхностей: T₁ = −22 °C (снаружи), T₂ = +20 °C (внутри).

R_кирпич = 0,25/0,70 = 0,357 м²·К/Вт (λ кирпича ≈ 0,70 Вт/(м·К))
R_минвата = 0,10/0,040 = 2,500 м²·К/Вт
R_газобетон = 0,20/0,22 = 0,909 м²·К/Вт (λ газобетона D500 ≈ 0,22 Вт/(м·К))
R_total = 0,357 + 2,500 + 0,909 = 3,77 м²·К/Вт (без учёта поверхностных сопротивлений)

q = ΔT/R_total = (20 − (−22))/3,77 = 42/3,77 ≈ 11,1 Вт/м²

## Удельная теплоёмкость

Удельная изобарная теплоёмкость (specific heat capacity at constant pressure) c_p — количество теплоты, необходимое для нагрева 1 кг вещества на 1 К при постоянном давлении:

{{< formula display="true" >}}
c_p = \left(\frac{\partial h}{\partial T}\right)_p, \quad [c_p] = \text{Дж/(кг·К)}
{{< /formula >}}

Произведение ρ c_p — объёмная теплоёмкость (volumetric heat capacity), Дж/(м³·К) — определяет тепловую массу конструкции.

{{< table title="Удельная теплоёмкость и объёмная теплоёмкость материалов" >}}
| Материал | ρ, кг/м³ | c_p, Дж/(кг·К) | ρ·c_p, кДж/(м³·К) |
|----------|----------|-----------------|---------------------|
| Вода (20 °C) | 998 | 4 182 | 4 174 |
| Лёд (0 °C) | 917 | 2 090 | 1 917 |
| Бетон тяжёлый | 2 300 | 880 | 2 024 |
| Кирпич | 1 800 | 840 | 1 512 |
| Дерево (сосна) | 500 | 1 700 | 850 |
| Минеральная вата | 50 | 840 | 42 |
| Сталь | 7 850 | 490 | 3 847 |
| Алюминий | 2 700 | 900 | 2 430 |
| Медь | 8 960 | 384 | 3 440 |
{{< /table >}}

Для расчёта аккумуляции теплоты в нестационарных режимах:

{{< formula display="true" >}}
Q = m \, c_p \, \Delta T = \rho \, V \, c_p \, \Delta T
{{< /formula >}}

Высокая объёмная теплоёмкость бетона (≈ 2 МДж/(м³·К)) обеспечивает тепловую инерцию: нагрев плиты перекрытия 200 мм · 1 м² на 1 К требует Q = 2 024 · 0,2 · 1 = 405 кДж ≈ 0,11 кВт·ч.

## Тепловая диффузия

Тепловая диффузия (thermal diffusivity) a — скорость выравнивания температуры при нестационарном нагреве или охлаждении:

{{< formula display="true" >}}
a = \frac{\lambda}{\rho \, c_p}, \quad [a] = \text{м}^2/\text{с}
{{< /formula >}}

Чем выше a, тем быстрее материал реагирует на изменение граничной температуры. Число Фурье Fo = a·t/L² характеризует безразмерное время нестационарного теплообмена.

{{< table title="Тепловая диффузия материалов HVAC" >}}
| Материал | λ, Вт/(м·К) | ρ, кг/м³ | c_p, Дж/(кг·К) | a × 10⁷, м²/с |
|----------|-------------|----------|-----------------|----------------|
| Медь | 385 | 8 960 | 384 | 111,9 |
| Алюминий | 229 | 2 700 | 900 | 94,2 |
| Сталь | 50 | 7 850 | 490 | 13,0 |
| Бетон | 1,60 | 2 300 | 880 | 7,9 |
| Минеральная вата | 0,040 | 50 | 840 | 9,5 |
| Дерево | 0,14 | 500 | 1 700 | 1,6 |
| Вода | 0,598 | 998 | 4 182 | 1,43 |
{{< /table >}}

Металлические ребра оребрённых теплообменников (a ≈ 10⁻⁴ м²/с) выравнивают температуру вдоль ребра практически мгновенно по сравнению со временем теплообмена с воздухом.

## Механические свойства

Механические характеристики определяют допустимое давление в трубопроводах, расстановку опор и требования к компенсации температурного расширения.

### Предел прочности и предел текучести

{{< table title="Механические свойства трубопроводных материалов HVAC" >}}
| Материал | σ_y, МПа | σ_u, МПа | E, ГПа |
|----------|----------|----------|--------|
| Сталь конструкционная S235 | 235 | 360–510 | 210 |
| Нержавеющая сталь 304 | 215 | 505 | 193 |
| Медь труба EN 12735 | 200 | 250 | 125 |
| Алюминий 6061-T6 | 275 | 310 | 69 |
| Труба ПВХ | 45 | 52 | 3,3 |
| Труба HDPE PE100 | 25 | 26 | 0,9 |
{{< /table >}}

Модуль Юнга (Young's modulus) E определяет прогиб трубопровода между опорами. Максимальный пролёт горизонтальной трубы из условия ограничения прогиба f ≤ L/360:

{{< formula display="true" >}}
L_{max} = \left(\frac{384 \, E \, I \, f}{5 \, q_0}\right)^{1/4}
{{< /formula >}}

где I — момент инерции сечения трубы, q₀ — распределённая нагрузка (вес трубы с жидкостью), м²; Па.

### Коэффициент линейного теплового расширения

Коэффициент линейного теплового расширения (coefficient of linear thermal expansion) α_L определяет удлинение трубопровода при изменении температуры:

{{< formula display="true" >}}
\Delta L = \alpha_L \, L_0 \, \Delta T
{{< /formula >}}

{{< table title="Коэффициент линейного расширения трубопроводных материалов" >}}
| Материал | α_L, мкм/(м·К) | ΔL на 10 м при ΔT = 50 К, мм |
|----------|-----------------|-------------------------------|
| Сталь углеродистая | 12,0 | 6,0 |
| Нержавеющая сталь | 17,3 | 8,7 |
| Медь | 17,0 | 8,5 |
| Алюминий | 23,8 | 11,9 |
| ПВХ | 52 | 26,0 |
| HDPE | 120 | 60,0 |
| Бетон | 9–12 | 5,0 |
{{< /table >}}

**Пример:** Медный трубопровод ГВС длиной 15 м, T_хол = 15 °C, T_гор = 65 °C. ΔT = 50 К.
ΔL = 17,0 × 10⁻⁶ · 15 · 50 = 12,75 мм. Требуется П-образный компенсатор или аксиальный компенсатор с ходом ≥ 13 мм.

Трубы ПВХ и HDPE имеют расширение в 4–7 раз больше стальных — обязательна установка компенсаторов или скользящих опор.

## Влияние влажности на теплопроводность изоляции

Вода (λ = 0,598 Вт/(м·К)) проводит теплоту в 23 раза интенсивнее, чем воздух (λ = 0,026 Вт/(м·К)). Попадание влаги в пористую изоляцию вытесняет воздух и резко снижает сопротивление.

Эффективная теплопроводность влажной волокнистой изоляции оценивается по модели параллельных путей:

{{< formula display="true" >}}
\lambda_{eff} \approx \lambda_{dry} + S \cdot (\lambda_w - \lambda_{air})
{{< /formula >}}

где S — степень насыщения пор (объёмная доля воды). При S = 0,01 (1% пор заполнено водой) для минваты: Δλ ≈ 0,01 · (0,598 − 0,026) ≈ 0,006 Вт/(м·К) — рост на 13–18% от исходного значения.

Закрытоячеистый пенополиуретан (PIR, XPS) имеет поглощение влаги < 2% по объёму по EN 12086 — наиболее стабильная изоляция в условиях конденсации.

## Излучательность поверхностей

Излучательность (emissivity) ε управляет радиационной теплопередачей. Плотность теплового потока излучения поверхности:

{{< formula display="true" >}}
q_{rad} = \varepsilon \, \sigma \, T^4, \quad \sigma = 5{,}67 \times 10^{-8}\ \text{Вт/(м}^2\text{·К}^4\text{)}
{{< /formula >}}

{{< table title="Излучательность поверхностей материалов HVAC" >}}
| Поверхность | ε |
|-------------|---|
| Полированный алюминий | 0,04–0,06 |
| Алюминиевая фольга | 0,03–0,05 |
| Оцинкованная сталь новая | 0,22–0,28 |
| Оцинкованная сталь старая | 0,44 |
| Медь полированная | 0,03–0,05 |
| Окрашенная поверхность (любой цвет) | 0,90–0,95 |
| Кирпич | 0,93 |
| Бетон | 0,93 |
| Стекло | 0,84–0,90 |
{{< /table >}}

Алюминиевая фольга с ε ≈ 0,05 снижает радиационный теплообмен через воздушную прослойку на 85–90% по сравнению с неизлучающими поверхностями. Применяется в конструкциях кровельных систем и воздуховодов.
