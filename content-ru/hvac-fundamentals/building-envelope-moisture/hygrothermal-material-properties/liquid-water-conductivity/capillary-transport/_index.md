## Физические основы

Капиллярный перенос — движение жидкой воды через взаимосвязанную систему пор строительного материала под действием капиллярных сил. Этот механизм независим от диффузии пара и становится определяющим при наличии жидкой воды в порах: при проникновении дождевых осадков, капиллярном подсосе из грунта, перераспределении конденсата.

### Уравнение Юнга–Лапласа

Движущая сила — капиллярное давление (давление всасывания), возникающее на искривлённой границе раздела жидкость–газ в поре:

{{< formula display="true" >}}
p_c = \frac{2\,\gamma\,\cos\theta}{r}
{{< /formula >}}

где:
- {{< formula >}}p_c{{< /formula >}} — капиллярное давление, Па;
- {{< formula >}}\gamma = 0{,}0728{{< /formula >}} Н/м — поверхностное натяжение воды при 20 °C;
- {{< formula >}}\theta{{< /formula >}} — краевой угол смачивания ({{< formula >}}\theta < 90°{{< /formula >}} — гидрофильный материал);
- {{< formula >}}r{{< /formula >}} — эффективный радиус поры, м.

Меньший радиус поры — большее давление всасывания и выше максимальная высота капиллярного подъёма. Максимальная высота подъёма в капиллярной трубке:

{{< formula display="true" >}}
h = \frac{2\,\gamma\,\cos\theta}{\rho_w\,g\,r}
{{< /formula >}}

где {{< formula >}}\rho_w = 1000{{< /formula >}} кг/м³ — плотность воды; {{< formula >}}g = 9{,}81{{< /formula >}} м/с².

**Ориентировочные высоты капиллярного подъёма:**
- Высокообожжённый кирпич: 1,5–3,0 м
- Автоклавный газобетон: 3,0–6,0 м
- Лёгкий бетон: 0,3–0,6 м
- Плотный бетон: < 0,3 м

## Коэффициент капиллярного поглощения (A-значение)

### Определение

На начальной стадии поглощения накопленная масса воды пропорциональна квадратному корню времени (закон Лукаса–Уошберна):

{{< formula display="true" >}}
A_w = \frac{\Delta m}{S\,\sqrt{t}}
{{< /formula >}}

где:
- {{< formula >}}A_w{{< /formula >}} — коэффициент капиллярного поглощения (A-значение), кг/(м²·с^0,5);
- {{< formula >}}\Delta m{{< /formula >}} — масса поглощённой воды, кг;
- {{< formula >}}S{{< /formula >}} — площадь испытуемой поверхности, м²;
- {{< formula >}}t{{< /formula >}} — время от начала контакта с водой, с.

Стандарты испытания: **EN ISO 15148**, ASTM C1794, EN 1925 (природный камень).

### Методика испытания (EN ISO 15148)

1. Высушить образец при 105 °C до постоянной массы.
2. Загерметизировать все поверхности кроме испытуемой (эпоксидная смола или алюминиевая лента).
3. Поместить испытуемую поверхность в воду на глубину 5–10 мм.
4. Регистрировать массу через интервалы: 1, 2, 4, 8, 16, 32 мин; 1, 2, 4, 8, 24 ч.
5. Построить кривую {{< formula >}}\Delta m / S{{< /formula >}} в зависимости от {{< formula >}}\sqrt{t}{{< /formula >}} и определить {{< formula >}}A_w{{< /formula >}} по наклону линейного участка.

## Жидкостная диффузивность

Жидкостная диффузивность {{< formula >}}D_w{{< /formula >}} — зависящий от влагосодержания коэффициент переноса, выражающий движение жидкой воды под действием градиента объёмного влагосодержания:

{{< formula display="true" >}}
g_w = -D_w(w)\,\frac{\partial w}{\partial x}
{{< /formula >}}

где {{< formula >}}w{{< /formula >}} — объёмное влагосодержание, кг/м³.

Зависимость {{< formula >}}D_w{{< /formula >}} от {{< formula >}}w{{< /formula >}} экспоненциальная:

{{< formula display="true" >}}
D_w(w) = D_0\,\exp\!\left(b\,\frac{w}{w_\text{max}}\right)
{{< /formula >}}

где {{< formula >}}D_0{{< /formula >}} — диффузивность при низком влагосодержании; {{< formula >}}b = 6{-}12{{< /formula >}} — эмпирический коэффициент; {{< formula >}}w_\text{max}{{< /formula >}} — влагосодержание при насыщении.

{{< table title="Типичные диапазоны D_w, м²/с" >}}
| Материал | D_w при 80 % отн. вл. | D_w у насыщения |
|---|---|---|
| Плотный бетон | 1×10⁻¹²–1×10⁻¹¹ | 1×10⁻⁹–1×10⁻⁸ |
| Кирпичная кладка | 5×10⁻¹²–5×10⁻¹¹ | 5×10⁻⁹–5×10⁻⁸ |
| Известковый раствор | 1×10⁻¹¹–1×10⁻¹⁰ | 1×10⁻⁸–1×10⁻⁷ |
| Автоклавный газобетон | 5×10⁻¹¹–5×10⁻¹⁰ | 5×10⁻⁸–5×10⁻⁷ |
| Древесина | 1×10⁻¹³–1×10⁻¹² | 1×10⁻¹⁰–1×10⁻⁹ |
| Гипс | 1×10⁻¹¹–1×10⁻¹⁰ | 1×10⁻⁸–1×10⁻⁷ |
{{< /table >}}

{{< formula >}}D_w{{< /formula >}} может изменяться на 3–5 порядков величины между сухим состоянием и насыщением.

## Ненасыщенный поток

### Уравнение Ричардса

Управляющее уравнение для ненасыщенного переноса жидкой воды в пористой среде:

{{< formula display="true" >}}
\frac{\partial\theta}{\partial t} = \frac{\partial}{\partial x}\left[K(\theta)\left(\frac{\partial\psi}{\partial x} + \frac{\partial z}{\partial x}\right)\right]
{{< /formula >}}

где:
- {{< formula >}}\theta{{< /formula >}} — объёмное влагосодержание, м³/м³;
- {{< formula >}}K(\theta){{< /formula >}} — ненасыщенная гидравлическая проводимость, м/с;
- {{< formula >}}\psi{{< /formula >}} — матричный (капиллярный) потенциал, м;
- {{< formula >}}z{{< /formula >}} — высотная отметка, м (положительная вверх).

Для горизонтального одномерного потока, когда гравитационным членом можно пренебречь:

{{< formula display="true" >}}
\frac{\partial\theta}{\partial t} = \frac{\partial}{\partial x}\left[D(\theta)\,\frac{\partial\theta}{\partial x}\right]
{{< /formula >}}

### Режимы потока

**Капиллярно-доминирующий поток.** Характерен для тонкопористых материалов ({{< formula >}}r < 100{{< /formula >}} мкм): бетон, кирпич, штукатурка. Капиллярные силы значительно превосходят гравитацию — вода может двигаться вверх.

**Гравитационно-доминирующий поток.** Характерен для крупнопористых материалов ({{< formula >}}r > 1000{{< /formula >}} мкм): гравийные дренажные слои. Вода стекает вниз под действием гравитации.

**Смешанный поток.** Обе силы соизмеримы — наиболее распространённый случай в строительных конструкциях, требующий полного уравнения Ричардса.

### Закон Дарси для ненасыщенных сред

{{< formula display="true" >}}
q = -K(\theta)\,(\nabla\psi + \nabla z)
{{< /formula >}}

В форме массового потока:

{{< formula display="true" >}}
g_w = -\rho_w\,K(\theta)\,\left(\frac{\partial\psi}{\partial x} + \frac{\partial z}{\partial x}\right)
{{< /formula >}}

### Насыщенная гидравлическая проводимость

{{< table title="K_sat при полном насыщении" >}}
| Материал | K_sat, м/с | Класс проницаемости |
|---|---|---|
| Высокопрочный бетон | 1×10⁻¹²–1×10⁻¹⁰ | Крайне низкая |
| Обычный бетон | 1×10⁻¹¹–1×10⁻⁹ | Очень низкая |
| Обожжённый кирпич | 1×10⁻⁹–1×10⁻⁷ | Очень низкая–низкая |
| Кирпич силикатный | 1×10⁻⁸–1×10⁻⁶ | Низкая–средняя |
| Мелкий песок | 1×10⁻⁶–1×10⁻⁴ | Средняя |
| Гравий | 1×10⁻²–1×10⁻¹ | Очень высокая |
{{< /table >}}

Внутренняя проницаемость — независимое от жидкости свойство:

{{< formula display="true" >}}
k = \frac{K_\text{sat}\,\mu}{\rho_w\,g}
{{< /formula >}}

где {{< formula >}}\mu{{< /formula >}} — динамическая вязкость воды, Па·с.

## Кривые удержания влаги — модель Ван Генухтена

Соотношение между матричным потенциалом и объёмным влагосодержанием описывается моделью Ван Генухтена:

{{< formula display="true" >}}
\theta(\psi) = \theta_r + \frac{\theta_s - \theta_r}{\bigl[1 + (\alpha|\psi|)^n\bigr]^m}
{{< /formula >}}

где {{< formula >}}\alpha{{< /formula >}} — обратное значение давления входа воздуха, 1/м; {{< formula >}}n{{< /formula >}} — параметр распределения размеров пор; {{< formula >}}m = 1 - 1/n{{< /formula >}}; {{< formula >}}\theta_r{{< /formula >}}, {{< formula >}}\theta_s{{< /formula >}} — остаточное и насыщенное влагосодержания.

{{< table title="Параметры Ван Генухтена для строительных материалов" >}}
| Материал | α, 1/м | n | θr | θs |
|---|---|---|---|---|
| Бетон | 0,01–0,10 | 1,2–1,8 | 0,02–0,05 | 0,10–0,20 |
| Кирпич | 0,05–0,50 | 1,3–2,0 | 0,03–0,08 | 0,25–0,40 |
| Суглинок | 1–5 | 1,3–1,7 | 0,03–0,06 | 0,40–0,50 |
| Мелкий песок | 3–10 | 2,0–3,0 | 0,02–0,04 | 0,35–0,45 |
{{< /table >}}

Относительная гидравлическая проводимость по Муалему:

{{< formula display="true" >}}
K_r(S_e) = S_e^{1/2}\,\Bigl[1 - \bigl(1 - S_e^{1/m}\bigr)^m\Bigr]^2
{{< /formula >}}

где {{< formula >}}S_e = (\theta - \theta_r)/(\theta_s - \theta_r){{< /formula >}} — эффективное насыщение.

## Численный пример: проникновение дождевой воды в кирпичную стену

**Условие.** Стена из рядового кирпича ({{< formula >}}A_w = 0{,}15{{< /formula >}} кг/(м²·с^0,5)) подвергается дождю продолжительностью 2 часа ({{< formula >}}t = 7200{{< /formula >}} с). Оценить глубину фронта капиллярного увлажнения и суммарное поглощение воды.

**Суммарное поглощение воды на поверхность:**

{{< formula display="true" >}}
\frac{\Delta m}{S} = A_w\,\sqrt{t} = 0{,}15\times\sqrt{7200} = 0{,}15\times 84{,}9 = 12{,}7\;\text{кг/м}^2
{{< /formula >}}

**Глубина фронта увлажнения.** Объём поглощённой воды на 1 м² соответствует слою воды:

{{< formula display="true" >}}
d_\text{вода} = \frac{\Delta m / S}{\rho_w} = \frac{12{,}7}{1000} = 0{,}0127\;\text{м} = 12{,}7\;\text{мм}
{{< /formula >}}

При пористости кирпича {{< formula >}}\varepsilon = 0{,}20{{< /formula >}} и предположении, что фронт заполняет поры до капиллярного насыщения:

{{< formula display="true" >}}
x_f = \frac{d_\text{вода}}{\varepsilon} = \frac{0{,}0127}{0{,}20} = 63{,}5\;\text{мм}
{{< /formula >}}

**Вывод.** За 2 часа непрерывного дождя фронт капиллярного увлажнения проникает примерно на 64 мм вглубь кирпичной стены. Для стены толщиной 380 мм это означает, что влага не достигает внутренних слоёв при единичном событии, однако многократные события накапливают влагу. Это подтверждает важность наружной гидрофобизации или воздушного зазора.

## Проектные решения

### Защита от проникновения дождя

Нагрузка косого дождя на вертикальную стену:

{{< formula display="true" >}}
R_{dr} = U\,\cos\alpha\,r_h
{{< /formula >}}

где {{< formula >}}U{{< /formula >}} — скорость ветра, м/с; {{< formula >}}\alpha{{< /formula >}} — угол между направлением ветра и нормалью к стене; {{< formula >}}r_h{{< /formula >}} — интенсивность горизонтальных осадков, мм/ч.

**Стратегии защиты:**

1. **Гидрофобные поверхностные покрытия** (силаны, силоксаны) — снижают {{< formula >}}A_w{{< /formula >}} на 50–90 %, сохраняя паропроницаемость.
2. **Вентилируемые воздушные зазоры** 25–50 мм за наружной облицовкой — создают капиллярный разрыв, дренируют жидкую воду до глубокого проникновения.
3. **Материалы с низким A-значением** для наружных слоёв ({{< formula >}}A_w < 0{,}1{{< /formula >}} кг/(м²·с^0,5)).

### Капиллярный подсос из грунта

Эффективный капиллярный разрыв требует:
- горизонтальной гидроизоляционной мембраны (DPC — damp-proof course) или инъекционного барьера;
- слоя крупного гравия (150–300 мм) под монолитными плитами — разрыв капиллярных путей;
- геотекстильного разделительного слоя для предотвращения миграции мелких частиц в дренажный слой.

### Проектирование капиллярных разрывов в узлах

При переходе между материалами капиллярные давления не уравниваются автоматически. Если {{< formula >}}p_{c,1} \neq p_{c,2}{{< /formula >}} при одном и том же влагосодержании, на интерфейсе возможно накопление влаги. Решение:
- воздушный зазор (полный разрыв капиллярных путей);
- постепенный переход структуры пор (от мелких к крупным в направлении потока воды).

### Потенциал высыхания

{{< formula display="true" >}}
\frac{\partial w}{\partial t} = -\nabla g_w - E
{{< /formula >}}

где {{< formula >}}E{{< /formula >}} — скорость испарения, кг/(м³·с). Факторы, ускоряющие высыхание:
- высокий {{< formula >}}D_w{{< /formula >}} — быстрый транспорт влаги к испарительной поверхности;
- паропроницаемые наружные и внутренние отделки (μ-значение наружного слоя должно быть ниже внутреннего для климатических зон с зимней конденсацией);
- температура воздуха и скорость движения воздуха у поверхности.

## Методы лабораторной характеризации

**EN ISO 15148 / ASTM C1794** — испытание капиллярного поглощения (A-значение). Минимальный размер образца 100×100 мм; уплотнение боковых поверхностей; регистрация массы на интервалах {{< formula >}}\sqrt{t}{{< /formula >}}.

**Метод тарелки давления (pressure plate, ASTM D6836)** — определение кривой удержания влаги: образец насыщается, затем ступенчато прикладывается давление пор (0–1500 кПа), измеряется равновесное влагосодержание.

**Пермеаметр с постоянным / падающим напором (ASTM D2434, D5084)** — определение {{< formula >}}K_\text{sat}{{< /formula >}} из устойчивого расхода при известном гидравлическом градиенте.

**Метод мгновенного профиля (instantaneous profile method)** — измерение внутренних профилей влажности в процессе перераспределения (TDR, ЯМР, гамма-абсорбциометрия) с последующим определением {{< formula >}}D_w(\theta){{< /formula >}} методом обратной задачи.

**Полевая диагностика:**
- Ёмкостные влагомеры (глубина 0–40 мм).
- Микроволновые сканеры (до 300 мм глубины).
- Инфракрасная термография (выявление зон повышенного влагосодержания на поверхности).
- Кернование с гравиметрическим анализом.

- **ASTM C1794** — стандартный метод определения коэффициента водопоглощения при частичном погружении.
- **ASTM D2434 / D5084** — насыщенная гидравлическая проводимость.
- **ASTM D6836** — характеристики удержания воды.
- **СП 50.13330.2017** — тепловая защита зданий.
- **СП 23-101-2004** — проектирование тепловой защиты зданий.
- **ГОСТ 25898** — паропроницаемость и сорбционное увлажнение.
