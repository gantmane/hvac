## Обзор

R-410A — квазиазеотропная смесь (near-azeotrope mixture) гидрофторуглеродов: 50 % масс. R-32 (дифторметан, CH₂F₂) + 50 % масс. R-125 (пентафторэтан, CHF₂CF₃). Смесь разработана как замена R-22 в системах кондиционирования и теплоснабжения при нулевом ODP = 0. Потенциал глобального потепления GWP₁₀₀ = 2088 (IPCC AR5). По ASHRAE 34-2022 классифицируется как A1 (нетоксичный, негорючий).

R-410A доминировал на рынке бытовых и коммерческих кондиционеров в 2000–2020-х гг. С 2025–2030 гг. в ЕС (регламент 517/2014 F-Gas) R-410A вытесняется хладагентами с GWP < 750 (R-32, R-454B, R-466A). Тем не менее огромный установленный парк оборудования обеспечивает спрос на таблицы свойств R-410A для технического обслуживания ещё на десятилетие.

Примечание о характере смеси: R-410A является «практически азеотропной» смесью — температурный глиссинг (temperature glide) при фазовом переходе составляет менее 0,2 К, что для большинства инженерных расчётов позволяет обращаться с R-410A как с чистым веществом. Тем не менее при точных расчётах LMTD теплообменников необходимо учитывать этот эффект.

## Физические принципы: зеотропный характер смеси

Для чистого вещества фазовый переход при постоянном давлении происходит строго при постоянной температуре $T_{sat}(p)$. Для смеси хладагентов (зеотропа) температура кипения и конденсации при постоянном давлении изменяется: жидкость закипает при $T_{bubble}$ (пузырьковая точка), а пар полностью конденсируется при $T_{dew}$ (точка росы). Разница $T_{dew} - T_{bubble}$ — температурный глиссинг.

Для R-410A глиссинг столь мал (< 0,2 К), что обе температуры практически совпадают. Свойства насыщения в таблицах REFPROP указываются для средней точки (bubble point или dew point — уточняйте по источнику).

{{< formula display="true" >}}
T_{glide} = T_{dew}(p) - T_{bubble}(p) < 0{,}2 \text{ К для R-410A}
{{< /formula >}}

## Численный пример: расчёт рабочей точки кондиционера

**Условие.** Кондиционер на R-410A. Испарение: $T_{evap}$ = 0 °C, перегрев 6 К. Конденсация: $T_{cond}$ = 50 °C, переохлаждение 4 К. $\eta_s$ = 0,78. Производительность 12 кВт. Рассчитать COP, массовый расход и проверить давление нагнетания.

**Данные REFPROP v10:**

Точка 1: $T_1$ = 0 + 6 = 6 °C, $p_1$ = $p_{sat}$(0 °C) = 909,6 кПа.

По таблице перегрева при 800 кПа, $T$ = 6 °C (интерполяция 0→20 °C):

{{< formula display="true" >}}
h_1 \approx 404{,}8 + \frac{6}{20}(419{,}6 - 404{,}8) = 404{,}8 + 4{,}4 = 409{,}2 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
s_1 \approx 1{,}429 + \frac{6}{20}(1{,}473 - 1{,}429) = 1{,}429 + 0{,}013 = 1{,}442 \text{ кДж/(кг·К)}
{{< /formula >}}

Поправка на давление от 800 кПа до 909,6 кПа незначительна (< 1 кДж/кг), принимаем $h_1$ ≈ 409,2 кДж/кг.

Точка 3: $T_3$ = 50 − 4 = 46 °C, $p_2$ = $p_{sat}$(50 °C) = 3333,9 кПа.

Интерполируя $h_f$ между 40 °C и 50 °C:

{{< formula display="true" >}}
h_3 = 255{,}8 + 0{,}6 \times (282{,}9 - 255{,}8) = 255{,}8 + 16{,}3 = 272{,}1 \text{ кДж/кг}
{{< /formula >}}

Изоэнтропный выход: $s_{2s}$ = 1,442 кДж/(кг·К), $p_2$ = 3334 кПа.

По таблице при 3000 кПа, интерполируя по $s$:

При 3000 кПа и 50 °C: $s$ = 1,354; при 70 °C: $s$ = 1,401. Для $s$ = 1,442 > 1,401 → $T > 70$ °C. При 90 °C: $s$ = 1,445.

{{< formula display="true" >}}
T_{2s} \approx 70 + \frac{1{,}442 - 1{,}401}{1{,}445 - 1{,}401} \times 20 = 70 + 18{,}6 = 88{,}6 \text{ °C}
{{< /formula >}}

{{< formula display="true" >}}
h_{2s} \approx 443{,}3 + \frac{1{,}442 - 1{,}401}{1{,}445 - 1{,}401} \times (462{,}3 - 443{,}3) = 443{,}3 + 17{,}7 = 461{,}0 \text{ кДж/кг}
{{< /formula >}}

**Работа компрессора:**

{{< formula display="true" >}}
w_{comp} = \frac{h_{2s} - h_1}{\eta_s} = \frac{461{,}0 - 409{,}2}{0{,}78} = \frac{51{,}8}{0{,}78} = 66{,}4 \text{ кДж/кг}
{{< /formula >}}

**Холодопроизводительность:**

{{< formula display="true" >}}
q_{evap} = h_1 - h_4 = 409{,}2 - 272{,}1 = 137{,}1 \text{ кДж/кг}
{{< /formula >}}

**COP:**

{{< formula display="true" >}}
COP = \frac{137{,}1}{66{,}4} = 2{,}06
{{< /formula >}}

**Массовый расход:**

{{< formula display="true" >}}
\dot{m} = \frac{12\,000}{137{,}1 \times 10^3} = 0{,}0875 \text{ кг/с}
{{< /formula >}}

**Проверка давления нагнетания**: $p_2$ = 3,33 МПа — типовое значение для R-410A при $T_{cond}$ = 50 °C. Проектное расчётное давление компонентов системы должно быть не менее 4,5 МПа (превышение давления насыщения с запасом 1,2 по EN 378-2:2016).

## p-h Диаграмма R-410A

p-h диаграмма (диаграмма Молье, Mollier diagram) — основной инструмент графического анализа цикла. Ключевые параметры диаграммы для R-410A:
- Диапазон давлений: 0,1…5,5 МПа (логарифмическая шкала);
- Диапазон энтальпий: 80…500 кДж/кг;
- Критическая точка: $T_c$ = 72,1 °C, $p_c$ = 4,93 МПа, $h_c$ ≈ 350 кДж/кг.

На диаграмме отображаются: купол насыщения, изотермы, изоэнтропы (линии $s = const$ для процесса компрессии), изохоры ($v = const$) и линии качества пара.

## Стандарты и нормативные источники

- **NIST REFPROP v10** — уравнение состояния Lemmon (2003) для смеси R-32/R-125; точность по давлению насыщения < 0,2 %.
- **ASHRAE Handbook — Fundamentals 2021, гл. 30** — полные таблицы свойств R-410A.
- **ASHRAE Handbook — Refrigeration 2022, гл. 2** — методология расчёта циклов.
- **ASHRAE 34-2022** — классификация A1; состав смеси.
- **ISO 817:2014** — обозначение и безопасность.
- **EN 378-1:2016** — безопасность холодильных систем; допустимые давления.
- **Регламент ЕС 517/2014 (F-Gas)** — ограничения на новые установки с GWP > 2500 с 2020 г.; R-410A разрешён для обслуживания.
- **ГОСТ 28547-2014** — технические условия на хладагенты.
- **СП 60.13330.2022** — нормы проектирования ОВК; применение хладагентов.

## Практические рекомендации

1. **При утечке R-410A не дозаправляйте** систему чистым компонентом (R-32 или R-125) — состав смеси необратимо изменится; заправляйте только жидкой фазой из баллона.
2. **Давление нагнетания** при $T_{cond}$ > 55 °C превышает 4,0 МПа — проверяйте предельное давление компрессора и всех компонентов системы.
3. **Масло**: только POE ISO VG 32–46; при переходе с R-22 (минеральное масло) полностью промойте систему.
4. **Фитинги**: R-410A использует специальные разъёмы 1/2" со специальной резьбой (не совместимы с R-22/R-134a) — не допускайте применения нестандартного инструмента.
5. **При поиске утечек**: электронный детектор утечки; запрещено применение открытого огня или мыльного раствора при давлениях > 2 МПа — риск разрушения соединения.
6. **Документируйте заправочную массу** — перезаправка на 10 % сверх номинала увеличивает $p_{cond}$ на 3…5 % и снижает COP на 2…4 %.
