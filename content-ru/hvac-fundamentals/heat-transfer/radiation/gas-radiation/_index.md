В большинстве HVAC-задач лучистый теплообмен рассматривается между твёрдыми поверхностями через «прозрачный» промежуток. Однако в котлах, камерах сгорания, горелках и даже в горячих газовых трактах промышленной вентиляции это допущение неверно: молекулы CO₂ и H₂O — главные компоненты продуктов сгорания — интенсивно поглощают и испускают инфракрасное излучение в специфических спектральных полосах. Игнорирование газового излучения приводит к систематическому занижению теплопередачи в топочной камере на 20–50 %.

## Участвующие и неучаствующие газы

Молекулы, обладающие постоянным или индуцированным дипольным моментом, взаимодействуют с ИК-излучением через колебательно-вращательные переходы. К **участвующим газам** (participating media) относятся:

- **CO₂** — важнейший компонент продуктов сгорания любого углеродсодержащего топлива;
- **H₂O** — второй по значимости участник, особенно при сжигании природного газа;
- CO, SO₂, NH₃, CH₄ — существенны только в специальных случаях.

**Неучаствующие газы**: N₂, O₂, Ar, H₂. Они симметричны, не имеют дипольного момента и прозрачны для теплового ИК-излучения. Воздух (78 % N₂ + 21 % O₂) практически прозрачен — важное допущение, используемое во всех расчётах теплообмена в зданиях.

## Спектральные полосы поглощения

Газы поглощают и излучают не непрерывным спектром, а в дискретных полосах длин волн, соответствующих переходам между квантовыми уровнями молекул.

{{< table title="Основные полосы поглощения CO₂ и H₂O" >}}
| Газ | Полоса, мкм | Интенсивность | Перекрытие с CO₂ |
|---|---|---|---|
| CO₂ | 2,65–2,80 | Сильная | Совпадает с H₂O 2,7 мкм |
| CO₂ | 4,15–4,45 | Очень сильная | — |
| CO₂ | 13–17 | Сильная | — |
| H₂O | 2,55–2,84 | Сильная | Совпадает с CO₂ 2,7 мкм |
| H₂O | 5,6–7,6 | Очень сильная | — |
| H₂O | >12 | Вращательные полосы | — |
{{< /table >}}

Принципиальное следствие: газы «видят» только часть излучения поверхностей, а поверхности «видят» газ только в его полосах. Перекрытие полос CO₂ и H₂O при 2,7 мкм требует поправки на взаимное экранирование при расчёте суммарной степени излучения смеси.

## Коэффициент поглощения и закон Бугера–Ламберта–Бера

При прохождении монохроматического излучения через участвующую среду интенсивность убывает по экспоненциальному закону:

{{< formula display="true" >}}
I_\lambda(s) = I_\lambda(0) \exp(-\kappa_\lambda s)
{{< /formula >}}

где κ_λ — спектральный коэффициент поглощения (м⁻¹), s — путь в газе. Интегральная (суммарная) степень излучения слоя газа толщиной L:

{{< formula display="true" >}}
\varepsilon_g = 1 - \exp(-\kappa L)
{{< /formula >}}

Для реальных газов κ зависит от температуры, давления и состава; зависимость от длины волны делает задачу нелинейной.

## Степень излучения: метод Хоттеля

Классический инженерный метод Хоттеля (Hottel 1954) выражает полную степень излучения газа через единственный параметр — произведение парциального давления на среднюю длину пути (mean beam length):

{{< formula display="true" >}}
\varepsilon_{\text{CO}_2} = f(p_{\text{CO}_2} L,\; T_g), \quad \varepsilon_{\text{H}_2\text{O}} = f(p_{\text{H}_2\text{O}} L,\; T_g)
{{< /formula >}}

Для смеси CO₂ + H₂O с поправкой на спектральное перекрытие:

{{< formula display="true" >}}
\varepsilon_g = \varepsilon_{\text{CO}_2} + \varepsilon_{\text{H}_2\text{O}} - \Delta\varepsilon
{{< /formula >}}

Поправки на давление (при P_total ≠ 1 атм):

{{< formula display="true" >}}
\varepsilon_{\text{CO}_2}^{\text{корр}} = C_{\text{CO}_2} \cdot \varepsilon_{\text{CO}_2}, \quad C_{\text{CO}_2} = f\!\left(\frac{P_{\text{tot}} + p_{\text{CO}_2}}{2}\right)
{{< /formula >}}

{{< formula display="true" >}}
\varepsilon_{\text{H}_2\text{O}}^{\text{корр}} = C_{\text{H}_2\text{O}} \cdot \varepsilon_{\text{H}_2\text{O}}, \quad C_{\text{H}_2\text{O}} = f(P_{\text{tot}},\, p_{\text{H}_2\text{O}})
{{< /formula >}}

Поглощательная способность газа по отношению к излучению поверхности при температуре T_s:

{{< formula display="true" >}}
\alpha_{\text{CO}_2} = \varepsilon_{\text{CO}_2}\!\left(T_g, p_{\text{CO}_2} L \frac{T_s}{T_g}\right)\!\left(\frac{T_g}{T_s}\right)^{0{,}65}
{{< /formula >}}

{{< formula display="true" >}}
\alpha_{\text{H}_2\text{O}} = \varepsilon_{\text{H}_2\text{O}}\!\left(T_g, p_{\text{H}_2\text{O}} L \frac{T_s}{T_g}\right)\!\left(\frac{T_g}{T_s}\right)^{0{,}45}
{{< /formula >}}

## Средняя длина пути (mean beam length)

Средняя длина пути L — эффективный радиус полусферического объёма газа, эквивалентного по лучистому потоку реальной геометрии:

{{< formula display="true" >}}
L_0 = 3{,}6 \frac{V}{A_s}
{{< /formula >}}

Для реальных геометрий вводится поправочный множитель C ≈ 0,85–0,90:

{{< formula display="true" >}}
L = C \cdot L_0
{{< /formula >}}

{{< table title="Средняя длина пути для стандартных геометрий (C ≈ 0,88)" >}}
| Геометрия | Средняя длина пути L |
|---|---|
| Сфера диаметром D | 0,65 D |
| Бесконечный цилиндр диаметром D (боковая поверхность) | 0,95 D |
| Бесконечный цилиндр диаметром D (основание) | 0,65 D |
| Полубесконечный цилиндр диаметром D (основание) | 0,90 D |
| Бесконечный слой толщиной d | 1,80 d |
| Куб со стороной a | 0,66 a |
| Прямоугольный параллелепипед 1:1:4 | 0,82 × наименьший размер |
| Произвольный объём (приближение) | 3,6 V/As |
{{< /table >}}

## Модель взвешенной суммы серых газов (WSGG)

Метод Хоттеля теряет точность при CFD-расчётах с неоднородным полем температур. Современная альтернатива — модель взвешенной суммы серых газов (Weighted Sum of Gray Gases, WSGG):

{{< formula display="true" >}}
\varepsilon_g = \sum_{i=0}^{I} a_i(T) \left[1 - e^{-\kappa_i p L}\right]
{{< /formula >}}

где aᵢ(T) — температурно-зависимые весовые коэффициенты, κᵢ — коэффициент поглощения i-й «серой» компоненты. Суммирование ведётся по 3–4 серым газам и одному прозрачному (κ₀ = 0). Коэффициенты для смесей CO₂/H₂O при различных парциальных давлениях приведены в Smith, Shen & Friedman (1982) и Coppalle & Vervisch (1983); реализованы в Ansys Fluent, OpenFOAM и EnergyPlus.

## Чистый лучистый поток газ → поверхность

Для газа при T_g, излучающего на поверхность при T_s:

{{< formula display="true" >}}
q_{g \to s} = \sigma A_s \left(\varepsilon_g T_g^4 - \alpha_g T_s^4\right)
{{< /formula >}}

Для серого газа (α_g = ε_g):

{{< formula display="true" >}}
q = \varepsilon_g \sigma A_s (T_g^4 - T_s^4)
{{< /formula >}}

## Типичные составы продуктов сгорания

{{< table title="Парциальные давления CO₂ и H₂O в продуктах сгорания (λ = 1,1; P = 1 атм)" >}}
| Топливо | p_CO₂, атм | p_H₂O, атм | p_CO₂ + p_H₂O |
|---|---|---|---|
| Природный газ (метан) | 0,075–0,090 | 0,155–0,185 | 0,24–0,27 |
| Дизельное/мазутное топливо | 0,105–0,130 | 0,095–0,115 | 0,21–0,24 |
| Каменный уголь | 0,130–0,155 | 0,065–0,085 | 0,20–0,24 |
| Биогаз (60 % CH₄, 40 % CO₂) | 0,130–0,150 | 0,135–0,155 | 0,27–0,30 |
{{< /table >}}

Природный газ даёт наибольшее p_H₂O — важно для котлов с конденсацией, где лучистый теплообмен между газами и теплообменными поверхностями определяет перепад температур в конвективной части.

## Численный пример: степень излучения продуктов сгорания в топочной камере котла

**Условие.** Водогрейный котёл 1,5 МВт на природном газе. Топочная камера — параллелепипед 1,2 × 1,2 × 2,0 м. Температура газов в топке T_g = 1100 °C (1373 К). Температура стенок (экранные трубы) T_s = 300 °C (573 К). Состав продуктов сгорания: p_CO₂ = 0,082 атм, p_H₂O = 0,170 атм.

**Шаг 1.** Средняя длина пути:

{{< formula display="true" >}}
L_0 = 3{,}6 \times \frac{V}{A_s} = 3{,}6 \times \frac{1{,}2 \times 1{,}2 \times 2{,}0}{2(1{,}2 \times 1{,}2) + 4(1{,}2 \times 2{,}0)} = 3{,}6 \times \frac{2{,}88}{12{,}48} = 0{,}830 \;\text{м}
{{< /formula >}}

С поправкой: L = 0,88 × 0,830 = 0,730 м.

**Шаг 2.** Произведения pL:
- p_CO₂ · L = 0,082 × 0,730 = 0,0599 атм·м;
- p_H₂O · L = 0,170 × 0,730 = 0,1241 атм·м.

**Шаг 3.** Степени излучения при T_g = 1373 К (по диаграммам Хоттеля / корреляции Farag & Howell 1979):
- ε_CO₂ ≈ 0,065 (при p·L = 0,060 атм·м, T = 1373 К);
- ε_H₂O ≈ 0,130 (при p·L = 0,124 атм·м, T = 1373 К);
- Δε ≈ 0,005 (поправка на перекрытие при отношении p_H₂O/(p_CO₂ + p_H₂O) = 0,67).

{{< formula display="true" >}}
\varepsilon_g = 0{,}065 + 0{,}130 - 0{,}005 = 0{,}190
{{< /formula >}}

**Шаг 4.** Поглощательная способность при T_s = 573 К:

{{< formula display="true" >}}
\alpha_{\text{CO}_2} = \varepsilon_{\text{CO}_2}\!\left(T_g,\, 0{,}0599 \times \frac{573}{1373}\right) \times \left(\frac{1373}{573}\right)^{0{,}65} \approx 0{,}052 \times 1{,}89 = 0{,}098
{{< /formula >}}

{{< formula display="true" >}}
\alpha_{\text{H}_2\text{O}} = \varepsilon_{\text{H}_2\text{O}}\!\left(T_g,\, 0{,}1241 \times \frac{573}{1373}\right) \times \left(\frac{1373}{573}\right)^{0{,}45} \approx 0{,}100 \times 1{,}53 = 0{,}153
{{< /formula >}}

{{< formula display="true" >}}
\alpha_g = \alpha_{\text{CO}_2} + \alpha_{\text{H}_2\text{O}} - \Delta\alpha \approx 0{,}098 + 0{,}153 - 0{,}005 = 0{,}246
{{< /formula >}}

**Шаг 5.** Лучистый поток:

{{< formula display="true" >}}
q = \sigma A_s (\varepsilon_g T_g^4 - \alpha_g T_s^4)
= 5{,}670 \times 10^{-8} \times 12{,}48 \times (0{,}190 \times 1373^4 - 0{,}246 \times 573^4)
{{< /formula >}}

{{< formula display="true" >}}
= 5{,}670 \times 10^{-8} \times 12{,}48 \times (0{,}190 \times 3{,}561 \times 10^{11} - 0{,}246 \times 1{,}077 \times 10^{10})
{{< /formula >}}

{{< formula display="true" >}}
= 5{,}670 \times 10^{-8} \times 12{,}48 \times (6{,}77 \times 10^{10} - 2{,}65 \times 10^9)
= 5{,}670 \times 10^{-8} \times 12{,}48 \times 6{,}50 \times 10^{10}
\approx 46{,}0 \;\text{кВт}
{{< /formula >}}

Это составляет около 3 % от номинальной мощности котла — небольшая доля, что типично для высокоэффективных водогрейных котлов с хорошо экранированной топкой. В паровых котлах крупных ТЭС с ε_g ≈ 0,4–0,6 и значительно большими температурами газа лучистая составляющая достигает 40–60 % суммарной теплопередачи в топочной камере.

## Влияние сажи и несветящегося пламени

Твёрдые частицы сажи (soot) в диффузных пламенах ведут себя как серые тела с высокой излучательной способностью в широком спектре. Наличие сажи может увеличить эффективный ε_g с 0,20 до 0,60–0,80. Для нормированного расчёта степени излучения пламени используется модель Тьен (Tien 1968) или модели Фариса–Хоуэлла. Переход от несветящегося к светящемуся пламени при повышении C/H-соотношения в топливе — один из ключевых факторов, влияющих на тепловосприятие топочных экранов.

## Применение в системах HVAC

Непосредственная применимость газового излучения в HVAC ограничена промышленными и коммерческими системами:

1. **Водогрейные и паровые котлы.** Тепловой расчёт радиантной части выполняется по нормативным методикам (СТО 70238424.27.100.005; ASHRAE Handbook — HVAC Systems and Equipment Ch. 32) с обязательным учётом ε_g.

2. **Газовые инфракрасные нагреватели.** Светлый излучатель (трубчатый) — продукты сгорания внутри трубы излучают через стенку трубы; тёмный излучатель — газы сгорают в керамическом блоке, нагревая его поверхность. Расчёт — по ASHRAE Handbook Ch. 15.

3. **Прямоточные воздухонагреватели (direct-fired).** В прямоточных воздухонагревателях продукты сгорания смешиваются с воздухом; газовое излучение определяет коэффициент теплоотдачи в зоне смешения.

4. **Конденсационные котлы.** Высокое содержание H₂O в продуктах сгорания природного газа повышает лучистый теплообмен в конвективной части и смещает температуру точки росы продуктов сгорания вверх (~55–57 °C), что необходимо учитывать при расчёте минимально допустимой температуры обратного теплоносителя.
