Деревянные материалы составляют значительную долю строительных ограждающих конструкций и несущих систем в жилом и малоэтажном строительстве. Их теплофизические свойства существенно варьируются в зависимости от вида, направления волокон, плотности и влажности. Точная характеризация тепловых свойств древесины необходима для расчёта тепловых нагрузок, анализа тепловых мостов в каркасных конструкциях и управления влагопереносом.

## Основные закономерности теплопроводности

### Влияние плотности

Главный параметр, определяющий k древесины поперёк волокон:

{{< formula display="true" >}}
k_\perp = 0{,}04 + 0{,}00026 \, \rho \quad [\text{Вт/м·К}], \quad \rho \; \text{в кг/м}^3, \; MC = 12 \%
{{< /formula >}}

Диапазоны по плотностным группам:
- Лёгкие породы (ρ < 400 кг/м³): k⊥ = 0,10–0,13 Вт/м·К.
- Среднеплотные (400–600 кг/м³): k⊥ = 0,13–0,17 Вт/м·К.
- Тяжёлые (> 600 кг/м³): k⊥ = 0,17–0,23 Вт/м·К.

### Анизотропия: продольное и поперечное направления

Теплопроводность вдоль волокон (k‖) в 2,0–2,8 раза выше k⊥. Для расчётов теплопередачи через стены, полы и кровлю используют консервативные значения k⊥ (поперёк волокон).

### Удельная теплоёмкость

Для сухой древесины с учётом температурной зависимости (ASHRAE Handbook Fundamentals, Ch. 26):

{{< formula display="true" >}}
c_p(T) = 1030 + 3{,}9 \, T \quad [\text{Дж/кг·К}], \quad T \; \text{в °C}
{{< /formula >}}

Влажная древесина: c_p,мокрая = c_p,сухая + MC × c_p,воды, где MC — влажность в долях единицы, c_p,воды = 4 186 Дж/кг·К. Практические значения: при 6 % MC (кондиционированный интерьер) — 1 380 Дж/кг·К; при 12 % (экстерьер умеренного климата) — 1 500 Дж/кг·К.

## Инженерные деревянные материалы

### Фанера (plywood)

**Теплофизические свойства.** ρ = 450–650 кг/м³ (варьируется по виду и наличию пустот); k = 0,12–0,14 Вт/м·К перпендикулярно плоскости; перекрёстная слойность создаёт квазиизотропное поведение; c = 1 380 Дж/кг·К.

**Расчётные значения:** обшивка — k = 0,12 Вт/м·К; чистовой пол — k = 0,13 Вт/м·К.

### OSB (ориентированно-стружечная плита, oriented strand board)

**Теплофизические свойства.** ρ = 600–680 кг/м³; k = 0,13–0,14 Вт/м·К; c = 1 400 Дж/кг·К. Плотность выше, чем у фанеры аналогичной толщины. Чувствительность к влаге проявляется в разбухании кромок — критично в узлах с управлением влагой.

**Расчётные значения:** обшивка стены — k = 0,13 Вт/м·К, ρ = 640 кг/м³.

## Влияние влажности на теплофизические свойства

### Теплопроводность и влажность

Зависимость k от влажности (moisture content, MC):

{{< formula display="true" >}}
k(MC) = k_0 \bigl[1 + \alpha_w \cdot (MC/100)\bigr]
{{< /formula >}}

где α_w = 2,5–3,5 для большинства пород; k₀ — теплопроводность при 0 % MC.

Физическая причина: вода (k = 0,60 Вт/м·К) замещает воздух (k = 0,026 Вт/м·К) в структуре клеток.

{{< table title="Коэффициенты поправки k на влажность для расчётов теплопередачи" >}}
| Место применения | EMC, % | Множитель k |
|---|---|---|
| Отапливаемый интерьер | 6–8 | 1,20 |
| Неотапливаемый интерьер | 10–12 | 1,30 |
| Защищённый экстерьер | 12–15 | 1,35 |
| Открытый экстерьер | 15–20 | 1,50 |
{{< /table >}}

**Точка насыщения волокон (fibre saturation point, FSP)** — обычно 28–30 % для большинства пород. Выше FSP размерные изменения прекращаются, но теплопроводность продолжает расти; значителен эффект скрытого тепла.

### Температурная зависимость

Теплопроводность сухой древесины увеличивается с температурой: β = 0,002–0,003 К⁻¹. В диапазоне −20...+50 °C рост составляет 15–20 %. Этот эффект вторичен относительно влияния влажности; большинство расчётных норм используют эталонные значения при 20 °C.

## Числовой пример: расчёт теплопередачи через стену с каркасом

**Условие.** Стена из стоек SPF 50×150 мм с шагом 400 мм. Изоляция полости: k_изол = 0,038 Вт/м·К, толщина 140 мм, RSI = 140/0,038 = 3,68 м²·К/Вт. Доля каркаса — 20 %, доля полости — 80 %. Поверхностные плёнки: наружная — 0,17 м²·К/Вт, внутренняя — 0,12 м²·К/Вт.

**Путь каркаса:**

{{< formula display="true" >}}
R_{\text{кар}} = 0{,}17 + \frac{0{,}140}{0{,}12} + 0{,}12 = 0{,}17 + 1{,}167 + 0{,}12 = 1{,}457 \; \text{м}^2\text{·К/Вт}
{{< /formula >}}

**Путь полости:**

{{< formula display="true" >}}
R_{\text{пол}} = 0{,}17 + 3{,}68 + 0{,}12 = 3{,}97 \; \text{м}^2\text{·К/Вт}
{{< /formula >}}

**Эффективное U-значение (метод параллельных путей, ASHRAE 90.1):**

{{< formula display="true" >}}
U_{\text{эфф}} = 0{,}20 \times \frac{1}{1{,}457} + 0{,}80 \times \frac{1}{3{,}97} = 0{,}137 + 0{,}202 = 0{,}339 \; \text{Вт/(м}^2\text{·К)}
{{< /formula >}}

{{< formula display="true" >}}
R_{\text{эфф}} = \frac{1}{0{,}339} \approx 2{,}95 \; \text{м}^2\text{·К/Вт}
{{< /formula >}}

По сравнению с номинальным RSI полости 3,68 м²·К/Вт: снижение составляет 20 % за счёт тепловых мостов через стойки. Непрерывная наружная изоляция толщиной 40 мм (k = 0,038 Вт/м·К, RSI = 1,05 м²·К/Вт) компенсирует потери и увеличивает суммарное эффективное R до ~4,0 м²·К/Вт.

## Тепловые мосты и стратегии снижения

**Типичные места тепловых мостов:**
- Стойки и лаги, пронизывающие изоляцию.
- LVL-перемычки над проёмами окон и дверей.
- Краевые лаги (rim joist) и обвязочные доски.
- Пороги (sill plates) у фундамента.

**Стратегии снижения (ASHRAE Handbook Fundamentals, Ch. 26):**
- Непрерывная наружная изоляция толщиной 25–50 мм сокращает вклад мостов на 50–75 %.
- Продвинутый каркас (advanced framing): шаг 600 мм, одна верхняя обвязка, утеплённые перемычки.
- Тепловые разрывы из пластика или дерева в критических стыках.

**Коэффициенты каркаса (frame factors) для расчёта эффективного R (ASHRAE 90.1):**

| Конфигурация | Доля каркаса, % | Доля полости, % |
|---|---|---|
| 50×100 мм, шаг 400 мм | 15–20 | 80–85 |
| 50×150 мм, шаг 400 мм | 15–20 | 80–85 |

## Управление влагой в деревянных конструкциях

**Риск конденсации.** Деревянные элементы каркаса служат поверхностями конденсации при неверном размещении пароизоляции. Необходим анализ точки росы на каждом слое конструкции, особенно в климатических зонах 5–8.

**Подход к проектированию:**
1. Рассчитать профиль температуры через конструкцию при расчётных условиях.
2. Определить температуру точки росы на каждой границе слоёв.
3. Если T_фактическая < T_точки_росы — конденсация неизбежна.
4. Переместить пароизолятор на тёплую сторону или применить паропроницаемый (diffusion-open) подход в климате с переменным направлением диффузии.

**Гигротермальное моделирование** (ПО WUFI или аналоги): учёт накопления влаги в деревянных элементах в течение годового цикла, верификация долгосрочного риска биологического повреждения.

## Тепловая инерция деревянных конструкций

Лёгкий деревянный каркас обладает минимальной тепловой инерцией по сравнению с кладкой или бетоном.

Тепловая инерция на единицу площади:

{{< formula display="true" >}}
M = \rho \cdot c_p \cdot L
{{< /formula >}}

Каркасная стена 50×150 мм: M ≈ 3,5 кДж/(м²·К) по площади каркаса — пренебрежимо мало по сравнению с нагрузками кондиционируемого пространства. Следствия для HVAC:
- Быстрый отклик на запуск и выключение — более низкие нагрузки при восстановлении температуры по сравнению с массивными конструкциями.
- Меньшая эффективность для пассивного солнечного аккумулирования.
- Более короткие постоянные времени при переходном анализе.
