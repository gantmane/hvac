Изоэнтальпы (isenthalps) — линии постоянной удельной энтальпии на диаграмме давление–энтальпия (P–h diagram). На диаграмме lg P–h они ориентированы строго вертикально в двухфазной области и почти вертикально в однофазных областях, поскольку по определению при движении вдоль изоэнтальпы значение {{< formula >}}h{{< /formula >}} не изменяется, а давление может принимать любое значение. Главное практическое применение изоэнтальп — моделирование **дросселирования** (изоэнтальпийного расширения, isenthalpic expansion) в терморегулирующих вентилях (ТРВ) и капиллярных трубках.

## Физические основы

Удельная энтальпия (specific enthalpy) определяется как:

{{< formula display="true" >}}
h = u + Pv
{{< /formula >}}

где {{< formula >}}u{{< /formula >}} — удельная внутренняя энергия (кДж/кг), {{< formula >}}P{{< /formula >}} — давление (Па), {{< formula >}}v{{< /formula >}} — удельный объём (м³/кг).

При адиабатном дросселировании через ТРВ или капиллярную трубку выполняются условия:

- теплообмен с окружающей средой пренебрежимо мал: {{< formula >}}Q = 0{{< /formula >}};
- механическая работа не совершается: {{< formula >}}W = 0{{< /formula >}};
- кинетическая и потенциальная энергии не учитываются.

Из первого закона термодинамики следует:

{{< formula display="true" >}}
h_{\text{вход}} = h_{\text{выход}}
{{< /formula >}}

Давление падает значительно (например, с 1800 кПа до 350 кПа), а энтальпия остаётся неизменной. На диаграмме P–h процесс изображается вертикальным отрезком, движущимся **вниз** по изоэнтальпе от высокого давления к низкому.

Дросселирование — **необратимый** процесс: энтропия возрастает. На T–s-диаграмме точка состояния смещается вправо, а на P–h-диаграмме часть внутренней энергии жидкости расходуется на испарение — образуется двухфазная смесь.

## Геометрия изоэнтальп

### Вертикальные линии в двухфазной области

В двухфазной области давление и температура связаны однозначно через кривую насыщения. При фиксированной энтальпии {{< formula >}}h = \text{const}{{< /formula >}} и изменении давления вдоль купола степень сухости {{< formula >}}x{{< /formula >}} изменяется, но горизонтальная координата на оси {{< formula >}}h{{< /formula >}} остаётся прежней — изоэнтальпа строго вертикальна.

### Наклон в однофазных областях

В однофазных областях изоэнтальпа слегка отклоняется от вертикали из-за зависимости {{< formula >}}h{{< /formula >}} от давления у реального вещества:

{{< formula display="true" >}}
\left(\frac{\partial h}{\partial P}\right)_T = v - T\left(\frac{\partial v}{\partial T}\right)_P = v(1 - \beta T)
{{< /formula >}}

где {{< formula >}}\beta{{< /formula >}} — коэффициент объёмного теплового расширения (К⁻¹). Для жидкой фазы хладагентов {{< formula >}}\beta T \approx 0{,}1\text{–}0{,}3{{< /formula >}}, поэтому наклон невелик; для перегретого пара при высоком давлении — заметнее.

### Пересечения с куполом насыщения

Каждая изоэнтальпа пересекает линию кипения (bubble line, {{< formula >}}x = 0{{< /formula >}}) и линию росы (dew line, {{< formula >}}x = 1{{< /formula >}}) в двух точках. При дросселировании с высокого давления хладагент «входит» в купол через линию кипения и выходит за нижнюю часть купола в сторону более низких давлений, оставаясь в двухфазной области.

## Дросселирование через ТРВ: представление на диаграмме

Процесс в терморегулирующем вентиле изображается на диаграмме P–h следующим образом:

- **Точка 3** (вход ТРВ): переохлаждённая жидкость при давлении конденсатора {{< formula >}}P_{\text{конд}}{{< /formula >}}, энтальпия {{< formula >}}h_3{{< /formula >}}.
- **Точка 4** (выход ТРВ): двухфазная смесь при давлении испарителя {{< formula >}}P_{\text{исп}}{{< /formula >}}, энтальпия {{< formula >}}h_4 = h_3{{< /formula >}}.

Вертикальный отрезок 3→4 — изоэнтальпа. Степень сухости на выходе ТРВ:

{{< formula display="true" >}}
x_4 = \frac{h_4 - h_f(P_{\text{исп}})}{h_{fg}(P_{\text{исп}})} = \frac{h_3 - h_f}{h_g - h_f}
{{< /formula >}}

Чем глубже переохлаждение жидкости перед ТРВ, тем ниже {{< formula >}}h_3{{< /formula >}}, тем меньше {{< formula >}}x_4{{< /formula >}} и тем эффективнее используется площадь испарителя.

## Численный пример — дросселирование R-134a

**Условие:** R-134a поступает в ТРВ при конденсации 40 °C, переохлаждение 5 К (жидкость при 35 °C). Давление испарителя соответствует {{< formula >}}T_{\text{исп}} = -10{{< /formula >}} °C.

По NIST REFPROP v10 (ASHRAE Handbook Fundamentals, гл. 30):

{{< table title="Параметры состояний до и после ТРВ для R-134a" >}}
| Параметр | Вход ТРВ (точка 3) | Выход ТРВ (точка 4) |
|----------|-------------------|-------------------|
| Давление P, кПа | 1017 | 200,7 |
| Температура T, °C | 35 (переохл.) | −10 (нас.) |
| Энтальпия h, кДж/кг | 249,7 | 249,7 |
| Состояние | Переохл. жидкость | Двухфазная смесь |
{{< /table >}}

Свойства насыщения R-134a при −10 °C: {{< formula >}}h_f = 186{,}7{{< /formula >}} кДж/кг, {{< formula >}}h_g = 392{,}3{{< /formula >}} кДж/кг, {{< formula >}}h_{fg} = 205{,}6{{< /formula >}} кДж/кг.

Степень сухости на выходе ТРВ:

{{< formula display="true" >}}
x_4 = \frac{249{,}7 - 186{,}7}{205{,}6} = \frac{63{,}0}{205{,}6} = 0{,}306
{{< /formula >}}

Таким образом, 30,6 % хладагента по массе мгновенно испаряется при дросселировании (flash gas). Оставшиеся 69,4 % жидкости испаряются в испарителе, поглощая полезную теплоту из охлаждаемой среды.

Удельная холодопроизводительность (из испарителя):

{{< formula display="true" >}}
q_e = h_1 - h_4 = 395{,}8 - 249{,}7 = 146{,}1 \text{ кДж/кг}
{{< /formula >}}

где {{< formula >}}h_1 = 395{,}8{{< /formula >}} кДж/кг — энтальпия на выходе испарителя (перегрев 5 К при −10 °C).

## Влияние переохлаждения на паросодержание

Более глубокое переохлаждение жидкости снижает {{< formula >}}h_3{{< /formula >}}, уменьшает {{< formula >}}x_4{{< /formula >}} и увеличивает {{< formula >}}q_e{{< /formula >}}. Приращение холодопроизводительности на каждый градус переохлаждения:

{{< formula display="true" >}}
\frac{\partial q_e}{\partial \Delta T_{\text{пер.ох}}} = c_{pl} \approx 1{,}4\text{–}1{,}6 \text{ кДж/(кг·К)}
{{< /formula >}}

где {{< formula >}}c_{pl}{{< /formula >}} — теплоёмкость жидкого хладагента. Для R-134a при 35 °C {{< formula >}}c_{pl} \approx 1{,}46{{< /formula >}} кДж/(кг·К): каждый дополнительный градус переохлаждения прибавляет ~0,7 % к холодопроизводительности.

## Применение изоэнтальп в диагностике и проектировании

**Диагностика:** измеренные давление и температура жидкостной линии перед ТРВ определяют точку 3 на диаграмме. По изоэнтальпе {{< formula >}}h_4 = h_3{{< /formula >}} находят точку 4 при давлении испарителя — и, следовательно, паросодержание на входе в испаритель. Высокое {{< formula >}}x_4 > 0{,}35{{< /formula >}} сигнализирует об избыточном флэш-газе и снижении эффективности испарителя.

**Проектирование ТРВ:** суммарное падение давления при дросселировании должно соответствовать требуемому перепаду {{< formula >}}\Delta P = P_{\text{конд}} - P_{\text{исп}}{{< /formula >}}. Клапан выбирается по расходу хладагента {{< formula >}}\dot{m}{{< /formula >}} и перепаду давления с учётом кавитационного запаса.

**Системы VAV (Variable Air Volume):** при частичной нагрузке давление испарителя снижается. Изоэнтальпа {{< formula >}}h_3{{< /formula >}} пересекает более низкую изобару, что увеличивает {{< formula >}}x_4{{< /formula >}} и может привести к снижению COP — требуется динамическая регулировка перегрева через ТРВ или электронный расширительный вентиль (EXV).
