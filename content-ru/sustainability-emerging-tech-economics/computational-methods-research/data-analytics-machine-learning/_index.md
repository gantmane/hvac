## Обзор

Машинное обучение и аналитика данных трансформируют работу HVAC систем посредством автоматического распознавания закономерностей, предиктивного моделирования и непрерывной оптимизации. Эти вычислительные методы обрабатывают операционные данные зданий для выявления неэффективности, прогнозирования отказов оборудования и оптимизации энергопотребления без явного программирования для каждого сценария.

## Основы машинного обучения для HVAC

### Приложения контролируемого обучения

Алгоритмы контролируемого обучения обучаются на помеченных исторических данных для прогнозирования будущих результатов или классификации состояния системы.

**Задачи регрессии:**
- Прогнозирование энергопотребления на основе погодных условий, занятости и параметров системы
- Прогнозирование тепловой нагрузки с использованием внешних условий и характеристик здания
- Моделирование эффективности чиллера по данным рабочей точки
- Прогнозирование температуры и влажности для управления зоной

**Задачи классификации:**
- Классификация отказов оборудования (нормальная работа, тип отказа A, тип отказа B)
- Обнаружение занятости по паттернам CO2, температуры и датчиков движения
- Классификация комфорта (комфортно, слишком жарко, слишком холодно, сквозняк)
- Определение режима работы (отопление, охлаждение, экономайзер, смешанный режим)

### Приложения неконтролируемого обучения

Алгоритмы неконтролируемого обучения выявляют закономерности и структуры в непомеченных данных.

**Методы кластеризации:**
- Сегментация профиля нагрузки здания для стратегий регулирования спроса
- Группировка производительности оборудования для выявления выбросов
- Кластеризация паттернов занятости для оптимизации расписания
- Разработка энергетической сигнатуры из операционных данных

**Снижение размерности:**
- Анализ главных компонент (PCA) для снижения сложности данных датчиков
- Извлечение признаков из многомерных наборов данных системы автоматизации зданий
- Визуализация многовариантных соотношений производительности системы

### Анализ временных рядов

Методы временных рядов учитывают временной характер данных HVAC.

**Методы прогнозирования:**
- ARIMA (Авторегрессионное интегрированное скользящее среднее) для краткосрочного прогнозирования нагрузки
- Сезонная декомпозиция для определения тенденций и циклических паттернов
- Экспоненциальное сглаживание для прогнозирования спроса
- Многомерные временные ряды для одновременного прогнозирования нескольких переменных

**Распознавание паттернов:**
- Извлечение суточных, еженедельных и сезонных паттернов
- Обнаружение точек изменения для деградации оборудования
- Выявление аномалий во временных операционных данных

## Архитектуры глубокого обучения

### Рекуррентные нейронные сети (RNN)

RNN обрабатывают последовательные данные, поддерживая внутреннее состояние на каждом временном шаге.

**Приложения:**
- Многошаговое прогнозирование энергетической нагрузки
- Динамическое моделирование тепловой реакции здания
- Прогнозирование последовательного распространения отказов
- Оптимизация адаптивной стратегии управления

**LSTM сети:**
Сети долгой краткосрочной памяти решают проблему исчезающего градиента в стандартных RNN, позволяя выучить долгосрочные зависимости.

- Захватывают долгосрочные паттерны в энергопотреблении здания
- Моделируют задержанные тепловые реакции в зданиях с высокой тепловой массой
- Прогнозируют деградацию производительности оборудования за длительные периоды
- Выучивают сложные сезонные и годовые операционные циклы

**GRU сети:**
Управляемые рекуррентные блоки обеспечивают вычислительную эффективность с производительностью, сравнимой с LSTM.

### Сверточные нейронные сети (CNN)

CNN превосходны в распознавании пространственных паттернов и извлечении признаков.

**Приложения HVAC:**
- Анализ тепловых изображений для выявления дефектов оболочки здания
- Обнаружение отказов с использованием инфракрасной термографии
- Прогнозирование пространственного распределения температуры в больших зонах
- Распознавание паттернов энергопотребления здания на основе двумерных представлений данных

### Нейронные сети прямого распространения

Многослойные персептроны моделируют сложные нелинейные соотношения между входами и выходами.

**Варианты использования:**
- Оптимизация чиллерного оборудования с множественными взаимодействующими переменными
- Нелинейное прогнозирование теплового комфорта
- Отображение производительности оборудования в диапазонах работы
- Оценка виртуального датчика из косвенных измерений

## Ансамблевые методы

### Случайный лес

Случайные леса объединяют несколько деревьев решений для улучшения точности прогнозирования и снижения переобучения.

**Приложения HVAC:**
- Ранжирование важности признаков для драйверов энергопотребления
- Надежное обнаружение отказов с количественной оценкой неопределенности
- Прогнозирование производительности систем с переменным расходом хладагента (VRF)
- Оценка занятости из входов нескольких датчиков

**Преимущества:**
- Обрабатывает смешанные типы данных (непрерывные, категориальные)
- Устойчив к переобучению
- Предоставляет показатели важности признаков
- Требует минимальной настройки гиперпараметров

### Машины градиентного бустинга

Последовательные ансамблевые методы, которые итеративно улучшают точность прогнозирования.

**Приложения:**
- Высокоточное прогнозирование энергопотребления
- Прогнозирование деградации эффективности оборудования
- Прогнозирование оптимального времени запуска для предварительного охлаждения здания
- Оценка базовой линии регулирования спроса

## Машины опорных векторов (SVM)

SVM находят оптимальные границы решения в многомерных пространствах.

**Задачи классификации:**
- Двоичное обнаружение отказов (нормальная vs. ненормальная работа)
- Многоклассовое определение состояния оборудования
- Классификация уровня заряда хладагента
- Обнаружение режима работы воздухообрабатывающего агрегата

**Задачи регрессии (SVR):**
- Нелинейное моделирование кривой производительности оборудования
- Прогнозирование энергопотребления с ограниченными обучающими данными
- Надежная оценка при наличии выбросов

## Обнаружение и диагностика отказов (FDD)

### Основанное на правилах FDD

Традиционные подходы используют знания экспертов, закодированные как условные правила.

**Ограничения:**
- Требует обширных знаний в предметной области
- Сложно поддерживать по мере изменения систем
- Не может обнаруживать новые паттерны отказов
- Высокий уровень ложных сигналов при фиксированных пороговых значениях

### Машинное обучение FDD

Методы ML автоматически выучивают сигнатуры отказов из данных.

**Подходы:**

**Контролируемое FDD:**
- Обучение классификаторов на помеченных данных нормальной и аварийной работы
- Требует тестирования с внедрением отказов или исторических записей отказов
- Достигает высокой точности для известных типов отказов
- Сложности получения комплексных наборов данных об отказах

**Неконтролируемое FDD:**
- Моделирование нормальной работы и флаг отклонений как аномалии
- One-class SVM, изоляционные леса, автокодировщики
- Обучение без данных об отказах
- Может генерировать ложные срабатывания от новых, но нормальных условий

**Гибридное FDD:**
- Комбинирование физических моделей с ML для анализа остатков
- Использование моделей первых принципов для генерации признаков
- Применение ML к обнаружению тонкой деградации производительности

### Типичные отказы HVAC, обнаруживаемые ML

| Оборудование | Типы отказов | Методы ML |
|--------------|--------------|-----------|
| Чиллеры | Утечки хладагента, загрязнение, смещение датчика | Контролируемая классификация, обнаружение аномалий |
| AHU | Застревание заслонки, дрейф датчика, засоление фильтра | Деревья решений, случайные леса |
| VAV коробки | Утечка заслонки, застревание клапана перегрева | Кластеризация, SVM |
| Котлы | Проблемы сгорания, накипь, ошибки датчика | Нейронные сети, ансамблевые методы |
| Градирни | Отказ вентилятора, деградация заполнения, ошибки датчика | Обнаружение временных аномалий |

## Предиктивное обслуживание

### Модели прогнозирования отказов

Модели ML предсказывают время до отказа или вероятность отказа в пределах временного окна.

**Подходы:**

**Анализ выживаемости:**
- Модели пропорциональных рисков Кокса
- Оценка зависящей от времени вероятности отказа
- Включение цензурированных данных (оборудование еще работает)

**Основанное на классификации:**
- Прогнозирование отказа в течение следующих 30/60/90 дней
- Двоичная классификация с использованием операционных тенденций
- Разработка признаков из исторических паттернов деградации

**Основанное на регрессии:**
- Прогнозирование оставшегося полезного ресурса (RUL)
- Оценка времени до необходимого вмешательства
- Включение физических моделей деградации

### Признаки мониторинга состояния

**Анализ вибрации:**
- Обнаружение износа подшипников в двигателях, компрессорах, вентиляторах
- Определение дисбаланса и неправильного выравнивания
- Извлечение признаков в частотной области

**Показатели производительности:**
- Тенденции эффективности во времени
- Энергопотребление при стандартных условиях
- Деградация коэффициента производительности (COP)

**Операционные паттерны:**
- Увеличение частоты циклов
- Более длительное время работы для достижения уставок
- Повышенное энергопотребление при одинаковой нагрузке

### Оптимизация обслуживания

Планирование обслуживания на основе ML балансирует риск отказа против затрат на обслуживание.

**Цели оптимизации:**
- Минимизирование общей стоимости (обслуживание + простой + потери энергии)
- Максимизирование доступности оборудования
- Продление полезного срока службы через оптимальное время вмешательства
- Координирование обслуживания по нескольким системам

## Оптимизация энергии

### Прогнозирование нагрузки

Точное прогнозирование нагрузки позволяет проактивное управление и оптимизацию.

**Краткосрочное прогнозирование (1-24 часа):**
- Почасовое прогнозирование нагрузки отопления и охлаждения
- Нейронные сети с входами прогноза погоды
- Включение оптимального управления запуском/остановом
- Поддержка решений по использованию экономайзера

**Среднесрочное прогнозирование (1-7 дней):**
- Прогнозирование суточного пикового спроса
- Ансамблевые методы, объединяющие несколько моделей
- Информирование диспетчеризации систем накопления тепловой энергии
- Поддержка участия в программах регулирования спроса

**Долгосрочное прогнозирование (месяцы-годы):**
- Бюджетирование сезонного энергопотребления
- Планирование мощности для модернизации систем
- Развитие базовой линии для измерений и проверки

### Интеграция предиктивного управления (MPC)

Модели ML служат моделями установки в рамках MPC.

**Модели установки нейронной сети:**
- Выучивают сложную тепловую динамику здания
- Прогнозируют многошаговые температуры зоны
- Захватывают нелинейные характеристики производительности оборудования

**Гибридные физико-ML модели:**
- Модели физики пониженного порядка для известной динамики
- Модели ML для неопределенных параметров и возмущений
- Баланс интерпретируемости и точности

### Прогнозирование занятости

Алгоритмы ML прогнозируют паттерны занятости здания для управления вентиляцией по спросу и кондиционирования зон.

**Источники данных:**
- Количество подключений Wi-Fi
- Тенденции датчика CO2
- События датчиков движения и дверей
- Данные календаря и расписания
- Исторические паттерны занятости

**Приложения:**
- Снижение вентиляции в периоды низкой занятости
- Предварительное кондиционирование пространства перед занятостью
- Оптимизация координации освещения и нагрузок потребления
- Обеспечение значительной экономии энергии (15-30% в некоторых приложениях)

## Требования к данным и предварительная обработка

### Инфраструктура сбора данных

**Данные системы автоматизации здания (BAS):**
- Измерения датчиков (температура, давление, расход, мощность)
- Статус оборудования и команды
- Журналы тревог и событий
- Типичная выборка: интервалы 1-15 минут

**Данные счетчиков:**
- Энергопотребление всего здания и подсчетное
- Профили электрического спроса
- Потребление тепловой энергии (отопление/охлаждение)

**Внешние данные:**
- Измерения метеостанции
- Прогнозы погоды для предиктивных приложений
- Сигналы тарификации коммунальных услуг
- Расписания занятости

### Проблемы качества данных

**Пропущенные данные:**
- Отказы датчиков и сбои связи
- Стратегии импутации: прямое заполнение, интерполяция, оценка на основе модели
- Множественная импутация для количественной оценки неопределенности

**Выбросы и аномалии:**
- Дрейф датчика и ошибки калибровки
- Ошибки логирования и шум связи
- Стратегии обнаружения и удаления выбросов
- Различие истинных аномалий от проблем качества данных

**Временное выравнивание:**
- Синхронизация данных из нескольких источников
- Обработка различных частот выборки
- Учет задержек датчиков и управляющих контуров

### Разработка признаков

**Признаки на основе времени:**
- Час дня, день недели, месяц, сезон
- Индикаторы рабочего дня vs. выходные/праздники
- Время с момента запуска/остановки оборудования

**Признаки погоды:**
- Внешняя температура, влажность, солнечная радиация
- Градус-дни (отопление и охлаждение)
- Температура влажного термометра для производительности градирни
- Энтальпия для управления экономайзером

**Запаздывающие переменные:**
- Значения предыдущего временного шага для захвата динамики
- Скользящие средние и тенденции
- Скорость изменения температуры

**Специфичные для предметной области признаки:**
- Разности температур по теплообменникам
- Температуры подхода в градирнях
- Напор (разница температур) в чиллерах
- Показатели эффективности (COP, EER, кВт/кВт охлаждения)

## Валидация модели и развертывание

### Стратегии кросс-валидации

**Кросс-валидация временных рядов:**
- Соблюдение временного порядка данных
- Подходы с прокатываемым окном или расширяющимся окном
- Избежание утечки данных из будущего в прошлое

**Валидация по сезонам:**
- Обучение в течение одного года, валидация в следующем году
- Обеспечение обобщения модели на погодных условия
- Тестирование производительности во время экстремальных событий

### Показатели производительности

**Задачи регрессии:**
- Средняя абсолютная ошибка (MAE)
- Корневая средняя квадратичная ошибка (RMSE)
- Коэффициент вариации RMSE (CV-RMSE)
- R-квадрат для объясненной дисперсии

**Задачи классификации:**
- Точность, прецизионность, полнота, F1-оценка
- Коэффициент ложного срабатывания (критично для приложений FDD)
- Площадь под кривой ROC (AUC)
- Анализ матрицы неточностей

### Соображения развертывания

**Вычислительные ресурсы:**
- Развертывание на граничных устройствах vs. облачная обработка
- Требования к размеру модели и скорости вывода
- Обработка в реальном времени vs. пакетная обработка

**Обслуживание модели:**
- Обнаружение сдвига концепции (операции здания изменяются со временем)
- Расписание периодического переобучения
- Онлайн-обучение для непрерывной адаптации
- Мониторинг производительности и оповещения о деградации

**Интеграция с BAS:**
- Протоколы связи (BACnet, Modbus, OPC UA)
- Требования к задержке для приложений управления
- Соображения кибербезопасности для облачного подключения

## Появляющиеся тренды

**Трансферное обучение:**
- Предварительное обучение моделей на больших многозданных наборах данных
- Тонкая настройка для конкретных зданий с ограниченными данными
- Снижение требований к данным для новых развертываний

**Федеративное обучение:**
- Обучение моделей по нескольким зданиям без обмена сырыми данными
- Сохраняющее конфиденциальность совместное обучение
- Развитие обобщенных моделей из распределенных наборов данных

**Объяснимый ИИ (XAI):**
- SHAP (Шаплиевы добавочные объяснения) для важности признаков
- LIME (Локально интерпретируемые модельно-агностические объяснения)
- Повышение доверия и внедрения через интерпретируемость
- Поддержка устранения неполадок и валидации

**Подкрепленное обучение:**
- Выучивание оптимальных политик управления методом проб и ошибок
- Модельно-свободная оптимизация для сложных HVAC систем
- Адаптация в реальном времени к изменяющимся условиям
- Вызовы: безопасное исследование, эффективность выборки
