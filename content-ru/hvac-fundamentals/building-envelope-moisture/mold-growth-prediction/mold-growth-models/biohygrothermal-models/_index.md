Биогигротермические модели (biohygrothermal models) объединяют динамическое моделирование тепло- и влагопереноса в строительных конструкциях с кинетикой биологического роста. Это позволяет прогнозировать развитие плесени при нестационарных граничных условиях без упрощения до стационарного режима, обязательного для метода Глазера (ISO 13788).

## Связанная система дифференциальных уравнений

Биогигротермическая модель решает три взаимосвязанных уравнения для каждого пространственного узла конструкции.

### Уравнение теплопереноса

{{< formula display="true" >}}
\rho c_p \frac{\partial T}{\partial t} = \nabla(\lambda \nabla T) + L_v \frac{\partial u}{\partial t}
{{< /formula >}}

где $\rho$ — плотность, кг/м³; $c_p$ — удельная теплоёмкость, Дж/(кг·К); $\lambda$ — теплопроводность (зависит от влагосодержания), Вт/(м·К); $L_v = 2{,}5 \times 10^6$ Дж/кг — скрытая теплота испарения воды; $u$ — влагосодержание, кг/м³.

### Уравнение переноса влаги

{{< formula display="true" >}}
\xi\,\frac{\partial \varphi}{\partial t} = \nabla\!\left(D_\varphi\,\nabla\varphi + \delta_p\,\nabla(\varphi\, p_{sat})\right)
{{< /formula >}}

где $\xi = \partial u / \partial \varphi$ — влагоёмкость, кг/м³; $D_\varphi$ — коэффициент капиллярной диффузии, м²/с; $\delta_p$ — паропроницаемость, кг/(м·с·Па); $p_{sat}(T)$ — давление насыщенного пара, Па.

Суммарный поток влаги через сечение:

{{< formula display="true" >}}
g = -\delta_p\,\nabla(\varphi\,p_{sat}) - D_w\,\nabla u
{{< /formula >}}

где первое слагаемое — паровой диффузионный поток, второе — капиллярный жидкостный поток.

### Уравнение биологического роста

{{< formula display="true" >}}
\frac{dM}{dt} = f(T,\,\varphi,\,\text{субстрат},\,M)
{{< /formula >}}

Конкретный вид функции $f$ зависит от выбранной биологической модели (VTT, Седлбауэр, первичная биомассовая модель). Все три уравнения решаются одновременно численно — методом конечных объёмов или конечных элементов.

## Граничные условия

**Тепловое граничное условие поверхности** (конвекция + длинноволновое излучение + солнечная радиация):

{{< formula display="true" >}}
q_{surf} = \alpha_c\,(T_{air} - T_{surf}) + \varepsilon\,\sigma\,(T_{rad}^4 - T_{surf}^4) + \alpha_{sol}\,I_{sol}
{{< /formula >}}

**Влажностное граничное условие поверхности:**

{{< formula display="true" >}}
g_{surf} = \beta_x\,(p_{v,air} - \varphi\,p_{sat,surf})
{{< /formula >}}

где $\beta_x$ — коэффициент поверхностного переноса влаги, кг/(м²·с·Па). Типичные значения: $\beta_x = 2 \times 10^{-8}$–$8 \times 10^{-8}$ кг/(м²·с·Па) при естественной конвекции.

## VTT-модель в полной формулировке

VTT-модель (Hukka & Viitanen, 1999; Viitanen et al., 2010) — наиболее распространённая в инженерной практике. Полная формулировка включает три элемента.

**Критическая относительная влажность** (нижний предел роста) как функция температуры для класса SEN1:

{{< formula display="true" >}}
\varphi_{crit}(T) = -0{,}00267\,T^2 + 0{,}160\,T + 100 - k_{class}
{{< /formula >}}

где $k_{class}$ = 0 (SEN1), 5 (SEN2), 10 (RES1).

**Дифференциальное уравнение роста MI** при $\varphi_s > \varphi_{crit}$:

{{< formula display="true" >}}
\frac{dM}{dt} = \frac{1}{7\cdot\exp\!\bigl(-0{,}68\ln T - 13{,}9\ln\varphi + 0{,}14W - 0{,}33\,SQ + 66{,}02\bigr)}
{{< /formula >}}

**Дифференциальное уравнение спада MI** при $\varphi_s < \varphi_{crit}$:

{{< formula display="true" >}}
\frac{dM}{dt} = \begin{cases} -0{,}032 & M > 1 \\ 0 & M \leq 1 \end{cases}
{{< /formula >}}

**Ограничения VTT-модели:**
- откалибрована по данным для хвойной древесины (заболонь сосны/ели);
- применение к другим материалам требует корректировки коэффициентов $W$ и $SQ$;
- не включает гибель мицелия — MI может только снижаться, но не обнуляться.

## Кинетика прорастания спор

### Вероятностная модель прорастания

{{< formula display="true" >}}
P(t) = 1 - \exp\!\bigl(-k_{germ}\cdot t^n\bigr)
{{< /formula >}}

где $k_{germ}$ — константа скорости прорастания, сут⁻¹; $n = 1{,}5$–$2{,}5$ — параметр формы (Weibull).

### Температурная зависимость по закону Аррениуса

{{< formula display="true" >}}
k_{germ}(T) = k_{ref} \cdot \exp\!\left[-\frac{E_a}{R}\!\left(\frac{1}{T} - \frac{1}{T_{ref}}\right)\right]
{{< /formula >}}

где $E_a$ = 50–70 кДж/моль — энергия активации прорастания; $R = 8{,}314$ Дж/(моль·К); $T_{ref} = 293$ К (20 °C).

### Влажностная зависимость константы прорастания

{{< formula display="true" >}}
k_{germ}(\varphi) = \begin{cases} k_{max}\!\cdot\!\left(\dfrac{\varphi - \varphi_{min}}{\varphi_{opt} - \varphi_{min}}\right)^\alpha & \varphi < \varphi_{opt} \\ k_{max} & \varphi \geq \varphi_{opt} \end{cases}
{{< /formula >}}

где $\varphi_{min}$ — минимальная ОВ для прорастания (75–85 %); $\varphi_{opt}$ — оптимальная ОВ (95–100 %); $\alpha = 2$–4 — показатель чувствительности.

### Период задержки прорастания

{{< formula display="true" >}}
t_{lag} = t_0 \cdot \exp\!\bigl[A\,(\varphi_{crit} - \varphi) + B\,(T_{opt} - T)\bigr]
{{< /formula >}}

где $t_0$ — базовый период задержки при оптимуме (1–3 сут); $A$, $B$ — эмпирические коэффициенты; $T_{opt}$ ≈ 25–28 °C.

## Первичная модель роста биомассы

Для более детального анализа используется логистическая модель роста биомассы с функциями отклика на условия среды:

{{< formula display="true" >}}
\frac{dX}{dt} = \mu_{max} \cdot X \cdot \left(1 - \frac{X}{X_{max}}\right) \cdot f(T) \cdot f(a_w)
{{< /formula >}}

где $X$ — плотность биомассы, г/м²; $\mu_{max}$ — максимальная удельная скорость роста, сут⁻¹ (типично 0,1–0,5); $X_{max}$ — ёмкость субстрата, г/м² (5–50).

**Температурная функция отклика (модель кардинальной температуры, CMM):**

{{< formula display="true" >}}
f(T) = \frac{(T - T_{min})(T - T_{max})}{\bigl[(T_{opt} - T_{min})(T_{opt} - T_{max})\bigr] - (T_{opt} - T)^2}
{{< /formula >}}

При $T < T_{min}$ или $T > T_{max}$: $f(T) = 0$.

**Функция отклика на активность воды (модель Дэви, Davey, 1989):**

{{< formula display="true" >}}
f(a_w) = \exp\!\left[-\left(\frac{a_{w,min} - a_w}{k}\right)^2\right]
{{< /formula >}}

где $a_{w,min}$ — видовой минимум активности воды; $k \approx 0{,}1$–$0{,}2$ — параметр формы.

## Гистерезис сорбции в модели переноса влаги

Сорбционные кривые при адсорбции и десорбции различаются. В численной реализации это учитывается раздельными ветвями функции сорбции:

{{< formula display="true" >}}
u_{ads} = A_1\bigl(1 - e^{-B_1\,\varphi^{C_1}}\bigr), \quad u_{des} = A_2\bigl(1 - e^{-B_2\,\varphi^{C_2}}\bigr)
{{< /formula >}}

Гистерезис влияет на прогноз роста плесени: в фазе адсорбции (увлажнения) при данной $\varphi$ влагосодержание нарастает медленнее, чем убывает при десорбции, что влечёт более быстрое прорастание при повторном увлажнении после высыхания.

## Числовой пример. Расчёт кинетики прорастания спор Aspergillus versicolor

**Условие.** Угловая зона наружной стены: $T_{surf} = 14\ °C$, $\varphi_s = 82\%$. Вид — *A. versicolor*: $E_a = 55$ кДж/моль; при 20 °C $k_{ref} = 0{,}08\ \text{сут}^{-1}$; $\varphi_{min} = 78\%$, $\varphi_{opt} = 95\%$, $\alpha = 2$.

**Шаг 1. Константа прорастания при $T = 14\ °C$:**

{{< formula display="true" >}}
k_{germ}(14) = 0{,}08 \cdot \exp\!\left[-\frac{55\,000}{8{,}314}\!\left(\frac{1}{287} - \frac{1}{293}\right)\right]
= 0{,}08 \cdot \exp\!\bigl[-6614 \times (-7{,}16 \times 10^{-5})\bigr]
= 0{,}08 \cdot e^{0{,}474} \approx 0{,}126\ \text{сут}^{-1}
{{< /formula >}}

**Шаг 2. Влажностная коррекция при $\varphi = 82\%$:**

{{< formula display="true" >}}
k_{germ}(82\%) = 0{,}126 \cdot \left(\frac{82 - 78}{95 - 78}\right)^2 = 0{,}126 \cdot \left(\frac{4}{17}\right)^2 = 0{,}126 \times 0{,}055 \approx 0{,}0070\ \text{сут}^{-1}
{{< /formula >}}

**Шаг 3. Время до 50 % вероятности прорастания** (при $n = 2$):

{{< formula display="true" >}}
P = 0{,}5 \Rightarrow t = \left(\frac{\ln 2}{k_{germ}}\right)^{1/n} = \left(\frac{0{,}693}{0{,}007}\right)^{0{,}5} = (99)^{0{,}5} \approx 9{,}9\ \text{сут}
{{< /formula >}}

**Вывод:** При $T = 14\ °C$ и $\varphi_s = 82\%$ половина спор *A. versicolor* прорастёт за $\approx 10$ сут. По VTT-модели для SEN2 ($\varphi_{crit}(14) \approx 83\%$) условие $82 < 83$ означает, что рост MI не разрешён — пограничная ситуация. Такое состояние характерно для межсезонья, когда небольшое снижение температуры поверхности или рост $\varphi_i$ переведут систему в критическую зону.

## Вычислительная реализация

**Пространственная дискретизация.** Метод конечных объёмов с геометрически сгущающейся сеткой у границ материалов:
- минимальное расстояние между узлами: 0,5–2 мм у поверхностей;
- геометрическое отношение прогрессии: 1,2–1,5;
- максимальный размер элемента в объёме материала: 10–50 мм.

**Управление шагом по времени.** Адаптивный шаг:

{{< formula display="true" >}}
\Delta t_{new} = \Delta t_{old} \cdot \left(\frac{\varepsilon_{target}}{\varepsilon_{actual}}\right)^{1/(p+1)}
{{< /formula >}}

где $\varepsilon_{target} = 10^{-3}$–$10^{-2}$; $p$ — порядок схемы.

**Критерий сходимости** на каждой итерации:

{{< formula display="true" >}}
\|X^{(k+1)} - X^{(k)}\| < \varepsilon_{abs} + \varepsilon_{rel} \cdot \|X^{(k)}\|
{{< /formula >}}

где $\varepsilon_{abs} = 10^{-6}$, $\varepsilon_{rel} = 10^{-4}$; $X$ — вектор решения $(T, \varphi, M)$.

## Валидация и точность

{{< table title="Типичная точность биогигротермических моделей по результатам лабораторных испытаний" >}}
| Параметр | Точность | Условия валидации |
|---|---|---|
| Mold Index | ±1 единица | Климатические камеры, $T = 5$–30 °C, $\varphi = 75$–100 % |
| Время до начала роста | ±20 % | Контролируемые условия, хвойная древесина |
| Скорость роста | Коэффициент 2–3 | Переменные условия, смешанные субстраты |
| Равновесное влагосодержание | ±1–2 % от сухой массы | Лабораторные сорбционные измерения |
{{< /table >}}

Модели систематически недооценивают рост при оптимальных условиях и переоценивают при пограничных. Для проектных расчётов рекомендуется снижать критический порог ОВ на 5 п.п. и применять более чувствительный класс субстрата, чем ожидаемый.

## Применения биогигротермических моделей

Связанное тепло-влажностно-биологическое моделирование применяется при:
- оптимизации расположения утеплителя и пароизоляции в ограждающих конструкциях;
- выборе материалов для зон повышенного риска (хвойная древесина vs OSB vs пенополиуретан);
- оценке риска при модернизации существующих зданий (добавление внутренней изоляции);
- долгосрочной оценке долговечности ограждений в различных климатических зонах;
- анализе чувствительности к изменению климата (прогноз на горизонте 50 лет).
