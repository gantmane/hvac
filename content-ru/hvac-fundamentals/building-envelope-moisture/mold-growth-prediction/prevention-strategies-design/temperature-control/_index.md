Рост плесени требует относительной влажности у поверхности материала выше критического порога (RH_crit) в течение достаточного времени. Температура поверхности напрямую определяет RH у этой поверхности: при постоянном влагосодержании воздуха в помещении снижение температуры поверхности на 1 °C повышает относительную влажность у неё примерно на 3–5 %. Предотвращение конденсации и контроль RH у поверхностей — главная функция теплозащиты ограждающих конструкций с точки зрения защиты от плесени.

## Физика температуры поверхности

### Линейная модель

Для одномерного стационарного теплового потока через плоскую конструкцию температура внутренней поверхности T_si определяется:

{{< formula display="true" >}}
T_{si} = T_i - \frac{R_{si}}{R_{tot}} \cdot (T_i - T_e)
{{< /formula >}}

где R_si — термическое сопротивление внутренней приповерхностной зоны (м²·К/Вт), R_tot — полное термическое сопротивление конструкции (м²·К/Вт), T_i и T_e — расчётные внутренняя и наружная температуры (°C).

Значение R_si = 1/h_i, где h_i — коэффициент теплоотдачи внутренней поверхности. По СП 50.13330.2017 (таблица 4) для вертикальных поверхностей наружных стен h_i = 8,7 Вт/(м²·К), R_si = 0,115 м²·К/Вт.

### Температурный фактор f_Rsi

ISO 13788:2012 вводит безразмерный температурный фактор (temperature factor):

{{< formula display="true" >}}
f_{Rsi} = \frac{T_{si} - T_e}{T_i - T_e} = 1 - \frac{R_{si}}{R_{tot}}
{{< /formula >}}

Для рядового участка конструкции f_Rsi = 1 − R_si/R_tot. В тепловых мостиках (угловые зоны, стойки каркаса, балконные консоли) f_Rsi рассчитывается методом конечных элементов (двумерный или трёхмерный тепловой расчёт).

Критическое значение f_Rsi зависит от климатического района и нормируемой категории влажности помещения. По ISO 13788 (приложение Б) для умеренного климата при внутренних условиях 20 °C / 50 % ОВ требуется f_Rsi ≥ 0,70. При 20 °C / 60 % ОВ требуется f_Rsi ≥ 0,80.

### Связь R_tot с f_Rsi

{{< formula display="true" >}}
R_{tot}^{\min} = R_{si} \cdot \frac{1}{1 - f_{Rsi}^{\min}}
{{< /formula >}}

При f_Rsi^min = 0,75 и R_si = 0,115 м²·К/Вт:

{{< formula display="true" >}}
R_{tot}^{\min} = 0{,}115 \cdot \frac{1}{1 - 0{,}75} = 0{,}46\,\text{м}^2\text{·К/Вт}
{{< /formula >}}

Это минимум для рядового участка. Тепловые мостики могут снизить f_Rsi до 0,60–0,70 без дополнительных мер.

## Критические зоны тепловых мостиков

### Классификация тепловых мостиков

По ISO 10211 тепловые мостики делятся на линейные (linear thermal bridges, Ψ-значение, Вт/(м·К)) и точечные (point thermal bridges, χ-значение, Вт/К). Линейные мостики вносят наибольший вклад в общий тепловой поток и определяют f_Rsi в наиболее уязвимых зонах.

{{< table title="Типичные линейные тепловые мостики в жилых зданиях (приближённые значения Ψ)" >}}
| Тип мостика | Ψ, Вт/(м·К) | Снижение f_Rsi (ориентировочно) |
|---|---|---|
| Угловая зона наружных стен (кирпич, без CI) | 0,05–0,15 | −0,08 — −0,15 |
| Стальная стойка каркаса | 0,10–0,30 | −0,05 — −0,20 |
| Деревянная стойка каркаса @ 600 мм | 0,01–0,04 | −0,02 — −0,05 |
| Балконная плита без термовставки | 0,40–0,80 | −0,15 — −0,30 |
| Перемычка над окном (монолит) | 0,15–0,35 | −0,10 — −0,20 |
| Переход стена–фундамент без CI | 0,20–0,50 | −0,10 — −0,20 |
{{< /table >}}

### Угловая зона наружных стен

В угловой зоне тепловой поток двумерный: площадь наружной поверхности больше площади внутренней, что снижает T_si по сравнению с рядовым участком. Двумерный расчёт методом конечных элементов (программы THERM, BISCO, AnTherm) позволяет получить точные значения f_Rsi и Ψ.

Типичные значения для кирпичных стен без CI: f_Rsi угловой зоны = 0,65–0,75. С наружной CI 80 мм из пенополистирола (λ = 0,038 Вт/(м·К)): f_Rsi = 0,80–0,88.

### Стальной каркас

Сталь (λ ≈ 50 Вт/(м·К)) создаёт короткое замыкание через теплоизоляцию. Стойка 90×0,84 мм при шаге 600 мм снижает расчётное R-значение конструкции на 40–50 % по сравнению с полостной изоляцией без стоек. Единственное эффективное решение — наружная непрерывная изоляция (CI) толщиной ≥ 50 мм.

### Балконные консоли

Балконная железобетонная плита без термовставки даёт Ψ = 0,5–0,8 Вт/(м·К). При пролёте балкона 1,5 м и длине примыкания 5 м дополнительные тепловые потери составляют:

{{< formula display="true" >}}
Q_{bridge} = \Psi \cdot L \cdot (T_i - T_e) = 0{,}6 \cdot 5 \cdot 46 \approx 138\,\text{Вт}
{{< /formula >}}

Применение термовставки (Schöck Isokorb, Halfen HIT, аналоги) снижает Ψ до 0,05–0,15 Вт/(м·К), уменьшая потери в 4–10 раз.

## Непрерывная теплоизоляция

Непрерывная наружная теплоизоляция (continuous insulation, CI) — наиболее универсальная мера одновременного повышения f_Rsi рядовых участков и устранения линейных тепловых мостиков у стоек каркаса.

### Минимальная толщина CI для предотвращения конденсации

Для защиты обшивки (sheathing) от конденсации в холодном климате необходимо, чтобы температура на поверхности обшивки оставалась выше точки росы наружного воздуха во влажные переходные периоды. По методике ASHRAE Fundamentals 2021 (глава 27) минимальное термическое сопротивление CI (R_CI) для защиты обшивки:

{{< formula display="true" >}}
R_{CI}^{\min} = R_{si\_ext} \cdot \frac{T_{dp,e} - T_e}{T_i - T_{dp,e}}
{{< /formula >}}

где R_si_ext = 1/h_e = 1/23 ≈ 0,043 м²·К/Вт, T_dp,e — точка росы наружного воздуха в критический переходный период.

Практически для умеренного и холодного климата России нормируемое значение R_tot по СП 50.13330.2017 (таблица 3) для Москвы составляет не менее 3,13 м²·К/Вт для стен. CI 80 мм из ПСБ-С-35 (λ = 0,038 Вт/(м·К)) даёт R_CI = 2,1 м²·К/Вт, что в сочетании с рядовой конструкцией обеспечивает f_Rsi ≥ 0,80 даже в угловых зонах.

### Качество монтажа изоляции

По RESNET Standard 301 установка изоляции оценивается тремя классами:

- Grade I: зазоры и дефекты < 2 % площади — достигается полное нормативное R.
- Grade II: дефекты 2–5 % — снижение R на 5–10 %.
- Grade III: дефекты > 5 % — снижение R до 15 %.

Монтаж в действующем строительстве достигает Grade I только при систематическом контроле. Типичная ошибка: сжатая вата у нижней обвязки теряет 30–50 % R; зазор 20 мм в минвате создаёт локальный тепловой мост с λ = 0,025 Вт/(м·К) вместо 0,036.

## Числовой пример: подбор теплоизоляции для наружной стены в Москве

### Исходные данные

Наружная стена жилого здания в Москве: кирпичная кладка 380 мм + утеплитель (ПСБ-С-35) снаружи + штукатурка 15 мм. Требуется обеспечить f_Rsi ≥ 0,77 в угловой зоне при T_i = 20 °C, T_e = −26 °C, RH_i = 45 %.

Точка росы при 20 °C, 45 %: T_dp ≈ 20 − 55/5 = 9,0 °C.

Требуемая температура внутренней поверхности угловой зоны:
T_si ≥ T_dp + 2 = 11,0 °C (запас 2 °C).

Требуемый f_Rsi:

{{< formula display="true" >}}
f_{Rsi}^{\min} = \frac{T_{si} - T_e}{T_i - T_e} = \frac{11{,}0 - (-26)}{20 - (-26)} = \frac{37{,}0}{46} = 0{,}804
{{< /formula >}}

### Подбор толщины CI

Рядовой участок (одномерный расчёт):

- Кирпич λ = 0,81 Вт/(м·К), d = 0,38 м → R_кирп = 0,469 м²·К/Вт.
- Штукатурка λ = 0,87 Вт/(м·К), d = 0,015 м → R_шт = 0,017 м²·К/Вт.
- R_si = 0,115 м²·К/Вт, R_se = 0,043 м²·К/Вт.
- Без CI: R_tot = 0,115 + 0,469 + 0,017 + 0,043 = 0,644 м²·К/Вт — недостаточно (нормируемое 3,13 м²·К/Вт).

С CI из ПСБ-С-35 (λ = 0,038 Вт/(м·К)) толщиной d_CI:

{{< formula display="true" >}}
R_{tot} = 0{,}644 + \frac{d_{CI}}{0{,}038}
{{< /formula >}}

Для R_tot = 3,13 м²·К/Вт: d_CI = (3,13 − 0,644) × 0,038 = 0,095 м ≈ 100 мм.

Проверка f_Rsi рядового участка с CI 100 мм:

{{< formula display="true" >}}
f_{Rsi} = 1 - \frac{R_{si}}{R_{tot}} = 1 - \frac{0{,}115}{3{,}13} = 0{,}963 \quad \text{(рядовой участок)}
{{< /formula >}}

Угловая зона с двумерным расчётом (оценочно, коррекция −0,10 для кирпичного угла без CI в угловом слое):

{{< formula display="true" >}}
f_{Rsi}^{angle} \approx 0{,}963 - 0{,}10 = 0{,}863 > 0{,}804 \quad \checkmark
{{< /formula >}}

Вывод: CI 100 мм из ПСБ-С-35 обеспечивает f_Rsi ≥ 0,804 в угловой зоне и полностью соответствует требованиям СП 50.13330.2017 по нормируемому сопротивлению теплопередаче.

## Верификация температурного контроля

### Тепловизионный контроль

Инфракрасная термография (ISO 6781-3) выявляет холодные зоны при перепаде температур ≥ 10 °C. Типичная процедура: камера FLIR или аналог, обследование при устойчивых погодных условиях (ночь, отсутствие солнечного нагрева), сравнение с расчётными температурами поверхностей.

Приемлемый результат: все наблюдаемые температуры внутренних поверхностей ≥ T_dp + 2 °C. Аномалии, превышающие 2 °C по сравнению с расчётными значениями, указывают на дефект и требуют исправления до завершения отделки.

### Постоянный мониторинг

В зданиях с повышенным риском (помещения с высокой влажностью, сложная геометрия) рекомендуется установка датчиков температуры поверхности в критических зонах (угловые зоны, балконные примыкания, оконные откосы). Пороговая сигнализация: T_si < T_dp + 1 °C.

Датчики относительной влажности в объёме помещений обеспечивают контроль соответствия расчётным предположениям. При отклонении RH_i выше расчётного значения система управления зданием (BMS) повышает интенсивность вентиляции или включает осушение.
