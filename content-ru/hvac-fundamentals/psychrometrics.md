## Введение: область применения психрометрики

Психрометрика — раздел термодинамики, изучающий свойства смеси сухого воздуха и водяного пара. Инженер ОВКВ использует психрометрические расчёты для:

- определения тепловых и влажностных нагрузок;
- расчёта процессов в приточных установках (ПУ): нагревание, охлаждение, осушение, увлажнение, рекуперация;
- подбора производительности увлажнителей и осушителей;
- оценки рисков конденсации на ограждениях и воздуховодах;
- энергетического анализа систем с переменным расходом воздуха (VAV).

Стандартные источники: ASHRAE Handbook — Fundamentals (2021), главы 1 и 2; ГОСТ 4388 (психрометрические таблицы); EN 12792:2003 (терминология).

## Состав и модель влажного воздуха

Атмосферный воздух — это смесь идеальных газов. Стандартный сухой воздух на уровне моря (ИСО 2533):

{{< table title="Состав стандартного сухого воздуха (ИСО 2533:1975)" >}}
| Компонент | Молярная доля (%) | Молярная масса (г/моль) |
|---|:---:|:---:|
| Азот N₂ | 78.084 | 28.013 |
| Кислород O₂ | 20.946 | 31.999 |
| Аргон Ar | 0.934 | 39.948 |
| CO₂ и прочие | 0.036 | — |
| Молярная масса сухого воздуха $M_a$ | | **28.966** |
{{< /table >}}

Содержание водяного пара: 0–4% по объёму. Молярная масса воды $M_w = 18.015$ г/моль.

Отношение молярных масс:

{{< formula display="true" >}}
\varepsilon = \frac{M_w}{M_a} = \frac{18.015}{28.966} = 0.6220
{{< /formula >}}

## Закон Дальтона и парциальные давления

Полное давление влажного воздуха:

{{< formula display="true" >}}
P = P_{da} + P_w
{{< /formula >}}

Где $P_{da}$ = парциальное давление сухого воздуха, $P_w$ = парциальное давление водяного пара. На уровне моря $P = 101\,325$ Па (1 атм).

## Фундаментальные свойства влажного воздуха

### Влагосодержание (удельная влажность)

Масса водяного пара на единицу массы сухого воздуха:

{{< formula display="true" >}}
d = \varepsilon \frac{P_w}{P - P_w} = 0.6220 \frac{P_w}{P - P_w}
{{< /formula >}}

Единицы: г/кг или кг/кг сухого воздуха. Диапазон: 0 (сухой) — ≈40 г/кг (тропики).

Через относительную влажность:

{{< formula display="true" >}}
d = 0.6220 \frac{\varphi \cdot P_{ws}}{P - \varphi \cdot P_{ws}}
{{< /formula >}}

Где $\varphi$ — относительная влажность в долях, $P_{ws}$ — давление насыщения при данной температуре сухого термометра.

### Давление насыщения водяного пара

Уравнение Бака (Buck, 1981) — практически точная аппроксимация Магнуса для диапазона −40...+50°C:

{{< formula display="true" >}}
P_{ws}(t) = 0.61121 \exp\!\left(\frac{(18.678 - t/234.5)\cdot t}{257.14 + t}\right) \text{ кПа}
{{< /formula >}}

Где $t$ в °C. Погрешность: < 0.02% в диапазоне 0...50°C.

Официальная форма ASHRAE (ASHRAE Fundamentals 2021, ур. 5–6), уравнение Харди:

{{< formula display="true" >}}
\ln P_{ws} = \frac{C_1}{T} + C_2 + C_3 T + C_4 T^2 + C_5 T^3 + C_6 T^4 + C_7 \ln T
{{< /formula >}}

Где $T$ — абсолютная температура (К). Коэффициенты: $C_1 = -5.8002206\times10^3$, $C_2 = 1.3914993$, $C_3 = -4.8640239\times10^{-2}$, $C_4 = 4.1764768\times10^{-5}$, $C_5 = -1.4452093\times10^{-8}$, $C_6 = 6.5459673$ (диапазон 0...200°C).

Таблица значений для справки:

{{< table title="Давление насыщения водяного пара $P_{ws}$ при различных температурах" >}}
| $t$ (°C) | $P_{ws}$ (Па) | $t$ (°C) | $P_{ws}$ (Па) |
|:---:|:---:|:---:|:---:|
| -10 | 259.9 | 20 | 2338 |
| 0 | 611.2 | 25 | 3169 |
| 5 | 872.4 | 30 | 4243 |
| 10 | 1228 | 40 | 7383 |
| 15 | 1705 | 50 | 12349 |
{{< /table >}}

### Относительная влажность

{{< formula display="true" >}}
\varphi = \frac{P_w}{P_{ws}(t_{db})} \times 100\%
{{< /formula >}}

При насыщении: $\varphi = 100\%$, $P_w = P_{ws}$. Концепция: ОВ — это степень насыщения воздуха паром при данной температуре, а не абсолютное содержание воды.

### Температура точки росы

Температура, при которой воздух с данным влагосодержанием достигает насыщения при охлаждении при постоянном давлении:

{{< formula display="true" >}}
P_w = P_{ws}(t_{dp}) \quad \Rightarrow \quad t_{dp} = P_{ws}^{-1}(P_w)
{{< /formula >}}

Аппроксимация Лоренса для $0 \le t_{dp} \le 60$°C:

{{< formula display="true" >}}
t_{dp} = \frac{243.04 \cdot \ln(P_w / 610.78)}{17.269 - \ln(P_w / 610.78)}
{{< /formula >}}

Где $P_w$ в Па.

**Физический смысл:**
- $t_{dp} < t_{db}$ — ненасыщенный воздух
- $t_{dp} = t_{db}$ — насыщение ($\varphi = 100\%$)
- Охлаждение поверхности ниже $t_{dp}$ вызывает конденсацию

**Инженерное применение:** расчёт рисков конденсации на окнах, воздуховодах, трубопроводах холодного водоснабжения и в теплообменниках рекуператоров.

### Температура мокрого термометра (адиабатическая температура насыщения)

Определяется через процесс адиабатического насыщения — охлаждения воздуха испарением воды при постоянной энтальпии:

{{< formula display="true" >}}
h(t_{db},\, d) = h_s(t_{wb}) + \left[d - d_s(t_{wb})\right] \cdot c_{pw} \cdot t_{wb}
{{< /formula >}}

Где:
- $h_s(t_{wb})$ = энтальпия насыщенного воздуха при $t_{wb}$ (кДж/кг)
- $d_s(t_{wb})$ = влагосодержание насыщенного воздуха при $t_{wb}$ (г/кг)
- $c_{pw}$ = теплоёмкость жидкой воды ≈ 4.186 кДж/(кг·К)

Соотношение температур: $t_{dp} \le t_{wb} \le t_{db}$.

При насыщении ($\varphi = 100\%$): $t_{dp} = t_{wb} = t_{db}$.

### Удельная энтальпия

Полное теплосодержание влажного воздуха на 1 кг сухого воздуха (нулевая точка: 0°C для сухого воздуха и жидкой воды):

{{< formula display="true" >}}
h = c_{pa} t_{db} + d \cdot \left(r_0 + c_{pv} t_{db}\right)
{{< /formula >}}

Числовые значения: $c_{pa} = 1.006$ кДж/(кг·К), $c_{pv} = 1.860$ кДж/(кг·К), $r_0 = 2500.9$ кДж/кг.

{{< formula display="true" >}}
h \approx 1.006\, t_{db} + d \cdot (2500.9 + 1.860\, t_{db}) \quad [\text{кДж/кг с.в.}]
{{< /formula >}}

Упрощённая форма (погрешность < 0.2% при $d < 30$ г/кг):

{{< formula display="true" >}}
h \approx 1.006\, t_{db} + 2501\, d + 1.86\, d\, t_{db}
{{< /formula >}}

**Численный пример:** $t_{db} = 25$°C, $d = 10$ г/кг $= 0.010$ кг/кг:

{{< formula display="true" >}}
h = 1.006\times25 + 0.010\times(2500.9 + 1.860\times25) = 25.15 + 0.010\times2547.4 = 25.15 + 25.47 = 50.6 \text{ кДж/кг}
{{< /formula >}}

### Удельный объём

{{< formula display="true" >}}
v = \frac{R_a T}{P - P_w} = \frac{287.05 (t_{db} + 273.15)}{P - P_w} \quad [\text{м}^3/\text{кг с.в.}]
{{< /formula >}}

При стандартных условиях (25°C, 50% ОВ, $P = 101\,325$ Па):

{{< formula display="true" >}}
v = \frac{287.05 \times 298.15}{101325 - 1581} = \frac{85568}{99744} = 0.858 \text{ м}^3/\text{кг}
{{< /formula >}}

### Плотность влажного воздуха

{{< formula display="true" >}}
\rho = \frac{1 + d}{v} \quad [\text{кг влажного воздуха/м}^3]
{{< /formula >}}

При тех же условиях: $\rho = (1 + 0.010)/0.858 = 1.175$ кг/м³.

### Угловой коэффициент процесса

Направление любого процесса на I-d диаграмме задаётся угловым коэффициентом:

{{< formula display="true" >}}
\varepsilon = \frac{\Delta I}{\Delta d} \quad [\text{кДж/г}]
{{< /formula >}}

- Чистое нагревание: $\Delta d = 0$ → $\varepsilon \to \infty$ (вертикальная линия вверх)
- Адиабатическое увлажнение: $\Delta I = 0$ → $\varepsilon = 0$ (горизонтальная линия вправо)
- Охлаждение с осушением: $\varepsilon = \Delta I / \Delta d > 2501$ кДж/кг (линия ниже горизонтали)

## Психрометрические процессы ОВКВ

### Чувствительное нагревание

Нагреватель или нагревательный змеевик — без изменения влажности:

{{< formula display="true" >}}
d_2 = d_1; \quad Q_{s} = \dot{m}_{da}\,(h_2 - h_1) = \dot{m}_{da}\,c_{pa}\,(t_2 - t_1)
{{< /formula >}}

Упрощение: $c_{pa}(1 + 1.86\,d) \approx c_{pm}$ — удельная теплоёмкость влажного воздуха. При $d = 10$ г/кг: $c_{pm} \approx 1.025$ кДж/(кг·К).

**Пример (предпусковой нагрев):** $\dot{m}_{da} = 2$ кг/с, $t_1 = -10$°C, $t_2 = +20$°C, $d = 3$ г/кг:

{{< formula display="true" >}}
Q_s = 2 \times 1.006 \times 30 = 60.4 \text{ кВт}
{{< /formula >}}

### Чувствительное охлаждение (без осушения)

Охлаждение выше точки росы:

{{< formula display="true" >}}
d_2 = d_1; \quad q_s = \dot{m}_{da}\,(h_1 - h_2) = \dot{m}_{da}\,c_{pa}\,(t_1 - t_2)
{{< /formula >}}

Ограничение: процесс возможен только при $t_2 > t_{dp}$. При охлаждении ниже $t_{dp}$ начинается конденсация.

### Охлаждение с осушением (охлаждающий змеевик)

Основной процесс в системах кондиционирования: воздух охлаждается ниже $t_{dp}$, происходит конденсация влаги.

Балансы по энергии и массе:

{{< formula display="true" >}}
q_{total} = \dot{m}_{da}(h_1 - h_2)
{{< /formula >}}

{{< formula display="true" >}}
q_{s} = \dot{m}_{da}\,c_{pa}(t_1 - t_2)
{{< /formula >}}

{{< formula display="true" >}}
q_{l} = \dot{m}_{da}\,(d_1 - d_2)\,r_0 \approx \dot{m}_{da}(d_1 - d_2)\times 2501
{{< /formula >}}

{{< formula display="true" >}}
\dot{m}_{cond} = \dot{m}_{da}(d_1 - d_2)
{{< /formula >}}

Соотношение чувствительного и полного тепла:

{{< formula display="true" >}}
SHR = \frac{q_s}{q_{total}} = \frac{q_s}{q_s + q_l}
{{< /formula >}}

Типичные значения SHR: 0.65–0.75 (офисы, жильё); 0.55–0.65 (рестораны, бассейны).

Точка росы аппарата (Apparatus Dew Point, ADP) — эффективная температура поверхности змеевика. Коэффициент обхода:

{{< formula display="true" >}}
BF = \frac{t_2 - t_{ADP}}{t_1 - t_{ADP}}
{{< /formula >}}

Типичные значения: $BF = 0.05$–$0.15$ (чистый змеевик с 6–8 рядами); $BF = 0.20$–$0.30$ (загрязнённый или 2-рядный змеевик).

**Практический расчёт:** при $t_1 = 28$°C, $t_2 = 13$°C, $t_{ADP} = 8$°C:

{{< formula display="true" >}}
BF = \frac{13 - 8}{28 - 8} = \frac{5}{20} = 0.25
{{< /formula >}}

### Нагревание и увлажнение

Зимняя обработка приточного воздуха в два этапа:

{{< formula display="true" >}}
q_{heat} = \dot{m}_{da}(h_2 - h_1)
{{< /formula >}}

{{< formula display="true" >}}
\dot{m}_{steam} = \dot{m}_{da}(d_2 - d_1)
{{< /formula >}}

Энтальпия добавляемого пара (перегретый пар при 100°C): $h_{steam} \approx 2676$ кДж/кг.

Точный баланс энергии с учётом энтальпии пара:

{{< formula display="true" >}}
h_2 = h_1 + q_{heat}/\dot{m}_{da} + (d_2 - d_1) \cdot h_{steam}
{{< /formula >}}

### Адиабатическое смешивание воздушных потоков

Состояние после смешивания (по балансам массы пара и энергии):

{{< formula display="true" >}}
h_3 = \frac{\dot{m}_1 h_1 + \dot{m}_2 h_2}{\dot{m}_1 + \dot{m}_2}
{{< /formula >}}

{{< formula display="true" >}}
d_3 = \frac{\dot{m}_1 d_1 + \dot{m}_2 d_2}{\dot{m}_1 + \dot{m}_2}
{{< /formula >}}

На I-d диаграмме: точка 3 лежит на прямой, соединяющей точки 1 и 2 (правило рычага). Расстояние делится обратно пропорционально расходам.

**Рычажное правило:**

{{< formula display="true" >}}
\frac{\overline{1{-}3}}{\overline{2{-}3}} = \frac{\dot{m}_2}{\dot{m}_1}
{{< /formula >}}

**Особый случай — подмес наружного воздуха (рецируляция ниже точки росы):** смесь может оказаться в зоне насыщения ($\varphi > 100\%$). Это физически означает туман; на практике — конденсация в камере смешения. Инженерное решение: предварительный подогрев наружного воздуха до смешивания при $t_{OA} < 0$°C.

## Полный расчётный пример

### Задача: определение производительности центрального кондиционера

**Исходные данные:**
- Расход приточного воздуха: $L = 10\,000$ м³/ч
- Наружный воздух: $t_{OA} = 32$°C, $\varphi_{OA} = 60\%$
- Внутренние условия (помещение): $t_{r} = 26$°C, $\varphi_{r} = 50\%$
- Доля рециркуляции: 70% (30% наружного воздуха)
- Приточный воздух: $t_{supply} = 14$°C, $\varphi_{supply} = 90\%$ (расчётный)

**Шаг 1. Свойства наружного воздуха:**

{{< formula display="true" >}}
P_{ws}(32) = 0.61121 \exp\!\left(\frac{(18.678 - 32/234.5)\times32}{257.14+32}\right) = 0.61121 \times e^{3.697} = 0.61121\times40.34 = 24.67 \text{ кПа} \cdot 10^3 \cdot 10^{-3} = 4.747 \text{ кПа}
{{< /formula >}}

{{< formula display="true" >}}
P_{w,OA} = 0.60 \times 4.747 = 2.848 \text{ кПа}
{{< /formula >}}

{{< formula display="true" >}}
d_{OA} = 0.6220 \times \frac{2848}{101325 - 2848} = 0.6220 \times \frac{2848}{98477} = 0.01799 \text{ кг/кг} = 17.99 \text{ г/кг}
{{< /formula >}}

{{< formula display="true" >}}
h_{OA} = 1.006\times32 + 0.01799\times(2500.9+1.860\times32) = 32.2 + 0.01799\times2560.4 = 32.2 + 46.1 = 78.3 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
v_{OA} = \frac{287.05\times305.15}{101325 - 2848} = \frac{87621}{98477} = 0.890 \text{ м}^3/\text{кг}
{{< /formula >}}

**Шаг 2. Свойства рециркуляционного воздуха (= воздух помещения):**

{{< formula display="true" >}}
P_{ws}(26) = 3.360 \text{ кПа}; \quad P_{w,r} = 0.50\times3360 = 1.680 \text{ кПа}
{{< /formula >}}

{{< formula display="true" >}}
d_r = 0.6220\times\frac{1680}{99645} = 0.01050 \text{ кг/кг} = 10.50 \text{ г/кг}
{{< /formula >}}

{{< formula display="true" >}}
h_r = 1.006\times26 + 0.01050\times(2500.9+1.860\times26) = 26.16 + 0.01050\times2549.3 = 26.16 + 26.77 = 52.9 \text{ кДж/кг}
{{< /formula >}}

**Шаг 3. Состояние смеси (30% ОА + 70% РЦ):**

{{< formula display="true" >}}
h_{mix} = 0.30\times78.3 + 0.70\times52.9 = 23.49 + 37.03 = 60.52 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
d_{mix} = 0.30\times17.99 + 0.70\times10.50 = 5.40 + 7.35 = 12.75 \text{ г/кг}
{{< /formula >}}

{{< formula display="true" >}}
v_{mix} \approx 0.30\times0.890 + 0.70\times0.846 = 0.267 + 0.592 = 0.859 \text{ м}^3/\text{кг}
{{< /formula >}}

**Шаг 4. Массовый расход сухого воздуха:**

{{< formula display="true" >}}
\dot{m}_{da} = \frac{10000}{0.859 \times 3600} = \frac{10000}{3092} = 3.234 \text{ кг/с}
{{< /formula >}}

**Шаг 5. Свойства приточного воздуха:**

{{< formula display="true" >}}
P_{ws}(14) = 1.598 \text{ кПа}; \quad P_{w,s} = 0.90\times1598 = 1.438 \text{ кПа}
{{< /formula >}}

{{< formula display="true" >}}
d_{supply} = 0.6220\times\frac{1438}{99887} = 0.00896 \text{ кг/кг} = 8.96 \text{ г/кг}
{{< /formula >}}

{{< formula display="true" >}}
h_{supply} = 1.006\times14 + 0.00896\times(2500.9+1.860\times14) = 14.08 + 0.00896\times2526.9 = 14.08 + 22.64 = 36.7 \text{ кДж/кг}
{{< /formula >}}

**Шаг 6. Холодопроизводительность:**

{{< formula display="true" >}}
q_{total} = \dot{m}_{da}(h_{mix} - h_{supply}) = 3.234\times(60.52 - 36.7) = 3.234\times23.82 = 77.0 \text{ кВт}
{{< /formula >}}

{{< formula display="true" >}}
q_s = \dot{m}_{da}\times1.006\times(t_{mix} - t_{supply})
{{< /formula >}}

Определим $t_{mix}$: из $h_{mix} = 60.52$ кДж/кг и $d_{mix} = 12.75$ г/кг:

{{< formula display="true" >}}
t_{mix} = \frac{h_{mix} - 2501\,d_{mix}}{1.006 + 1.860\,d_{mix}} = \frac{60.52 - 2501\times0.01275}{1.006 + 1.860\times0.01275} = \frac{60.52 - 31.89}{1.006 + 0.02372} = \frac{28.63}{1.030} = 27.8 \text{°C}
{{< /formula >}}

{{< formula display="true" >}}
q_s = 3.234\times1.006\times(27.8 - 14) = 3.234\times1.006\times13.8 = 44.9 \text{ кВт}
{{< /formula >}}

{{< formula display="true" >}}
q_l = q_{total} - q_s = 77.0 - 44.9 = 32.1 \text{ кВт}; \quad SHR = 44.9/77.0 = 0.58
{{< /formula >}}

**Расход конденсата:**

{{< formula display="true" >}}
\dot{m}_{cond} = 3.234\times(12.75 - 8.96)\times10^{-3} = 3.234\times3.79\times10^{-3} = 12.3 \text{ г/с} = 44.2 \text{ кг/ч}
{{< /formula >}}

## Поправки на высоту над уровнем моря

Стандартное атмосферное давление по ГОСТ 4401-80 (ICAO):

{{< formula display="true" >}}
P(z) = 101.325 \left(1 - 2.25577\times10^{-5} z\right)^{5.2559} \text{ кПа}
{{< /formula >}}

{{< table title="Стандартное давление и поправочные коэффициенты для высокогорных городов" >}}
| Город | Высота (м) | $P$ (кПа) | $P/P_0$ | Поправка к расходу воздуха |
|---|:---:|:---:|:---:|:---:|
| Санкт-Петербург | 12 | 101.2 | 1.000 | 0% |
| Москва | 155 | 99.5 | 0.983 | +1.7% |
| Екатеринбург | 281 | 98.0 | 0.968 | +3.3% |
| Алматы | 900 | 90.8 | 0.897 | +11.5% |
| Бишкек | 800 | 91.9 | 0.908 | +10.1% |
| Тбилиси | 490 | 95.5 | 0.943 | +6.1% |
{{< /table >}}

На высоте $z$ при одинаковой ОВ влагосодержание $d$ выше:

{{< formula display="true" >}}
d(z) = 0.6220 \frac{\varphi\,P_{ws}(t)}{P(z) - \varphi\,P_{ws}(t)} > d(z=0)
{{< /formula >}}

**Практическое следствие:** при проектировании систем для высокогорных городов (Алматы, Ташкент) требуется пересчёт:
- расходов воздуха (по объёму, а не по массе);
- мощности вентиляторов (закон подобия: $P \propto \rho$);
- производительности охлаждающих змеевиков (больший $d$ при той же ОВ → выше скрытая нагрузка).

## Транспортные свойства влажного воздуха

### Динамическая вязкость (Sutherland, Vargaftik)

{{< formula display="true" >}}
\mu_{da}(T) = 1.458\times10^{-6} \frac{T^{3/2}}{T + 110.4} \quad [\text{Па·с}]
{{< /formula >}}

При 20°C: $\mu_{da} \approx 1.81\times10^{-5}$ Па·с.

### Теплопроводность

{{< formula display="true" >}}
k_{da}(T) = 2.41\times10^{-2} \left(\frac{T}{273.15}\right)^{0.82} \quad [\text{Вт/(м·К)}]
{{< /formula >}}

При 20°C: $k_{da} \approx 2.52\times10^{-2}$ Вт/(м·К).

### Число Прандтля

{{< formula display="true" >}}
Pr = \frac{\mu\, c_{pm}}{k} \approx \frac{1.81\times10^{-5}\times1025}{2.52\times10^{-2}} \approx 0.735
{{< /formula >}}
