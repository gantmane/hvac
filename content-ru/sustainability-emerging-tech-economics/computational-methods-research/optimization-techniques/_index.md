Методы оптимизации применяют математические алгоритмы для определения оптимальных конфигураций систем HVAC, параметров работы и стратегий управления. Эти методы балансируют конкурирующие цели, включая энергопотребление, тепловой комфорт, качество воздуха в помещении, срок службы оборудования и операционные затраты.

## Формулировка задачи оптимизации

Задачи оптимизации HVAC состоят из целевых функций, переменных решения и ограничений. Типичные формулировки включают:

**Целевая функция**:
- Минимизировать общую стоимость энергии: f(x) = Σ(E_i × C_i)
- Минимизировать максимальный спрос мощности
- Минимизировать выбросы CO2
- Максимизировать индексы теплового комфорта (PMV, PPD)
- Максимизировать эффективность системы

**Переменные решения**:
- Температура подаваемого воздуха (типичный диапазон 12-18°C)
- Расходы подаваемого воздуха (системы переменного расхода)
- Температура охлажденной воды (4-10°C)
- Температура воды конденсатора (18-32°C)
- Последовательность включения оборудования
- Установки температуры в зонах (20-26°C при занятости, ночной режим)

**Ограничения**:
- Пределы теплового комфорта: -0,5 ≤ PMV ≤ 0,5 (категория A согласно ISO 7730)
- Пределы мощности оборудования: 0 ≤ Q ≤ Q_max
- Влажность подаваемого воздуха: 30% ≤ RH ≤ 60%
- Минимальные требования наружного воздуха согласно ASHRAE 62.1
- Требования к перепаду давления для критических зон

## Генетические алгоритмы для HVAC

Генетические алгоритмы (GA) имитируют естественный отбор для эволюции оптимальных решений через поколения кандидатных конструкций.

**Структура алгоритма**:

1. **Инициализация популяции**: Генерирование N случайных решений (хромосом)
2. **Оценка пригодности**: Расчет целевой функции для каждого решения
3. **Отбор**: Выбор родителей на основе пригодности (турнир, рулетка)
4. **Кроссовер**: Комбинирование генов родителей для создания потомства (однотемный, равномерный)
5. **Мутация**: Случайное изменение генов (обычно вероятность 1-5%)
6. **Замена популяции**: Внедрение потомства в следующее поколение
7. **Завершение**: Остановка после сходимости или максимального количества поколений (обычно 100-1000)

**Применение в HVAC**:
- Оптимизация холодильной установки: последовательность нескольких холодильных машин, насосов, градирен
- Размеры воздуховодов и трубопроводов: минимизация стоимости материалов при соблюдении ограничений по потерям давления
- Выбор оборудования: баланс между капитальной стоимостью и эффективностью работы
- Оптимизация графика управления: разработка оптимальных времени включения/выключения оборудования

**Пример кодирования хромосомы**:
```
[T_supply, CFM_zone1, CFM_zone2, ..., Chiller_stages, Pump_speed]
```

**Параметры производительности**:
- Размер популяции: 50-200 особей
- Коэффициент кроссовера: 0,6-0,9
- Вероятность мутации: 0,01-0,05
- Критерий сходимости: < 0,1% улучшения за 20 поколений

## Градиентная оптимизация

Градиентные методы используют информацию о производной для итеративного движения к оптимальному решению. Эти детерминированные подходы хорошо работают для непрерывных дифференцируемых задач.

**Алгоритм градиентного спуска**:

x_{k+1} = x_k - α ∇f(x_k)

Где:
- x_k = текущий вектор решения
- α = размер шага (скорость обучения): типично 0,001-0,1
- ∇f(x_k) = градиент целевой функции

**Метод Ньютона**:

x_{k+1} = x_k - [H(x_k)]^(-1) ∇f(x_k)

Где H(x_k) — матрица Гессе (вторые производные). Сходится быстрее чем градиентный спуск, но требует больше вычислений.

**Применение в HVAC**:
- Оптимальный сброс температуры подачи на основе условий нагрузки
- Оптимизация управления экономайзером (положение смешивающей заслонки)
- Оптимизация уставки дифференциального давления охлажденной воды
- Управление положением заслонки VAV-бокса для температуры в зоне

**Преимущества**:
- Быстрая сходимость для выпуклых задач
- Низкие вычислительные затраты на итерацию
- Гарантированная сходимость для хорошо обусловленных функций

**Ограничения**:
- Может сходиться к локальным минимумам в невыпуклых задачах
- Требует дифференцируемые целевые функции
- Чувствителен к начальным условиям

## Последовательное квадратичное программирование (SQP)

SQP решает нелинейную оптимизацию с ограничениями путем аппроксимации задачи последовательностью квадратичных программ.

**Формулировка**:
Минимизировать f(x) при условии:
- g_i(x) ≤ 0 (ограничения неравенства)
- h_j(x) = 0 (ограничения равенства)

**Применение в HVAC**:
- Оптимизация центральной установки с ограничениями мощности оборудования
- Оптимальное распределение нагрузки между параллельными холодильными машинами
- Оптимизация скорости насоса с ограничениями давления
- Управление температурой и влажностью в пределах комфорта

**Типичная сходимость**: 10-50 итераций для задач средней сложности

## Многокритериальная оптимизация (MOO)

Системы HVAC по своей природе включают конкурирующие цели. MOO определяет фронт Парето: решения, где улучшение одной цели ухудшает другую.

**Распространенные пары целей в HVAC**:
- Стоимость энергии в сравнении с тепловым комфортом
- Капитальная стоимость в сравнении со стоимостью жизненного цикла
- Энергоэффективность в сравнении с пиковым спросом
- Качество воздуха в помещении в сравнении с энергопотреблением

**Оптимальность по Парето**:
Решение x* является оптимальным по Парето, если не существует другого решения y, такого что:
- f_i(y) ≤ f_i(x*) для всех целей i
- f_j(y) < f_j(x*) хотя бы для одной цели j

**Метод взвешенной суммы**:
F(x) = w_1·f_1(x) + w_2·f_2(x) + ... + w_n·f_n(x)

Где Σw_i = 1, w_i ≥ 0. Варьируя веса, находятся различные точки Парето.

## Алгоритм NSGA-II

Алгоритм неустойчивой сортировки генетических алгоритмов II является стандартным методом для многокритериальной оптимизации HVAC.

**Этапы алгоритма**:
1. **Неустойчивая сортировка**: Ранжирование решений по уровню доминирования
2. **Расстояние скученности**: Расчет плотности решений в пространстве целей
3. **Отбор**: Предпочтение более низкого ранга, большего расстояния скученности
4. **Генерирование потомства**: Применение кроссовера и мутации
5. **Объединение популяций**: Слияние родителей и потомства
6. **Усечение**: Выбор лучших N решений для следующего поколения

**Результаты практического применения HVAC**:
Для оптимизации VAV-системы (энергия в сравнении с комфортом):
- Фронт Парето содержит 50-100 недоминируемых решений
- Экономия энергии: 15-30% при приемлемом снижении комфорта
- Оптимальная температура подачи варьируется: 12,5-15,5°C
- Модуляция скорости вентилятора: 40-85% от максимума

## Оптимизация роем частиц (PSO)

PSO имитирует социальное поведение стаи птиц или косяка рыб при поиске в пространстве решений.

**Обновление скорости**:
v_{i,k+1} = w·v_{i,k} + c_1·r_1·(p_i - x_{i,k}) + c_2·r_2·(p_g - x_{i,k})

**Обновление положения**:
x_{i,k+1} = x_{i,k} + v_{i,k+1}

Где:
- w = вес инерции (0,4-0,9)
- c_1, c_2 = коэффициенты познания и социального поведения (обычно 2,0)
- r_1, r_2 = случайные числа [0,1]
- p_i = лучшее положение частицы
- p_g = глобальное лучшее положение

**Применение в HVAC**:
- Последовательность включения холодильных машин и распределение нагрузки
- Графики зарядки/разрядки тепловых аккумуляторов
- Оптимизация уставок температуры в зонах
- Расписание HVAC для управления спросом

**Параметры**:
- Размер роя: 20-50 частиц
- Максимальное количество итераций: 100-500
- Сходимость: Величина скорости < 0,01

## Имитация отжига

Имитация отжига имитирует металлургический процесс отжига, вероятностно принимая более худшие решения для выхода из локальных минимумов.

**Вероятность принятия**:
P(accept) = exp(-ΔE / T)

Где:
- ΔE = изменение целевой функции (положительное для более худших решений)
- T = параметр температуры (уменьшается со временем)

**График охлаждения**:
T_k = T_0 × α^k

Где α = 0,85-0,95 (скорость охлаждения)

**Применение в HVAC**:
- Оптимизация расположения оборудования (минимизация трубопроводов/воздуховодов)
- Планирование реконструкции (последовательность замены оборудования)
- Оптимизация расписания обслуживания
- Настройка параметров управления

## Планирование экспериментов (DOE)

DOE систематически варьирует входные параметры для понимания их влияния на производительность системы.

**Факторный дизайн**:
Полный факторный: N = L^k (L уровней, k факторов)
Для 3 факторов на 2 уровнях: 2^3 = 8 экспериментов

**Примеры факторов HVAC**:
- Температура подаваемого воздуха: [12°C, 16°C]
- Уставка охлажденной воды: [5°C, 8°C]
- Доля наружного воздуха: [15%, 30%]

**Дисперсионный анализ (ANOVA)**:
Количественно определяет вклад каждого фактора в общую дисперсию.

Основной эффект: E_i = Σ(y_high - y_low) / n

Эффект взаимодействия: I_ij измеряет неаддитивные эффекты между факторами i и j

## Методология поверхности отклика (RSM)

RSM создает полиномиальные аппроксимации сложных соотношений производительности HVAC.

**Модель второго порядка**:
y = β_0 + Σβ_i·x_i + Σβ_{ii}·x_i^2 + Σβ_{ij}·x_i·x_j + ε

**Пример HVAC**: Модель энергопотребления холодильной машины
P_chiller = β_0 + β_1·Q_load + β_2·T_chw + β_3·T_cw + β_{11}·Q_load^2 + β_{12}·Q_load·T_chw + ...

**Оптимизация на поверхности отклика**:
После подгонки, стандартные алгоритмы оптимизации быстро находят оптимальные режимы работы без запуска полных моделирований.

**Метрики точности**:
- R² > 0,95 для хорошей подгонки
- Среднеквадратическая ошибка (RMSE) < 5% от среднего отклика

## Латинская гиперкубическая выборка (LHS)

LHS эффективно выбирает многомерные пространства параметров для анализа неопределенности и оптимизации.

**Процедура**:
1. Разделение диапазона каждой переменной на N интервалов равной вероятности
2. Выборка один раз из каждого интервала
3. Случайное спаривание выборок по переменным

**Преимущество перед случайной выборкой**:
Достигает лучшего покрытия пространства с меньшим количеством выборок (обычно 1,5k до 2k выборок, где k = количество переменных).

**Применение в HVAC**:
- Количественная оценка неопределенности в моделях энергии
- Калибровка моделей моделирования зданий
- Анализ чувствительности параметров проекта

## Байесовская оптимизация

Байесовская оптимизация создает вероятностные модели (гауссовские процессы) дорогостоящих целевых функций.

**Функция приобретения**:
Ожидаемое улучшение (EI):
EI(x) = E[max(f(x*) - f(x), 0)]

Где x* — текущее лучшее решение.

**Алгоритм**:
1. Построение модели гауссовского процесса из существующих оценок
2. Максимизация функции приобретения для выбора следующей точки оценки
3. Оценка целевой функции в выбранной точке
4. Обновление модели
5. Повтор до сходимости

**Применение в HVAC**:
- Оптимизация при дорогостоящих моделированиях (CFD, моделирование всего здания)
- Настройка параметров управления, требующих физических экспериментов
- Оптимизация прогнозирующего управления моделью

**Типичная производительность**:
Сходится за 50-200 оценок по сравнению с тысячами для традиционных методов.

## Суррогатное моделирование

Суррогатные модели заменяют вычислительно дорогостоящие моделирования быстрыми аппроксимациями.

**Типы моделей**:
- Полиномиальная регрессия: быстрая, ограниченная точность для сложных соотношений
- Радиальные базисные функции (RBF): хороши для рассеянных данных
- Кригинг: предоставляет оценки неопределенности
- Искусственные нейронные сети: отличны для высоконелинейных систем

**Применение в HVAC**:
- Замена моделирований EnergyPlus (30-60 мин) предсказаниями нейронных сетей (< 1 сек)
- Включение в реальное время оптимизации сложных систем
- Поддержка реализации прогнозирующего управления моделью

**Требования валидации**:
- Набор обучения: 70-80% данных
- Набор тестирования: 20-30% данных
- Кросс-валидация R² > 0,90

## Оптимизация управления

Оптимизация управления настраивает параметры и стратегии для реальной работы HVAC.

**Оптимизация настройки PID**:
Цель: Минимизировать интеграл абсолютной ошибки (IAE)
IAE = ∫|SP(t) - PV(t)|dt

Переменные решения: K_p, K_i, K_d

Ограничения:
- Избегание колебаний: коэффициент затухания ζ > 0,7
- Ограничение перерегулирования: < 10% уставки
- Время установления: < 15 минут типично

**Прогнозирующее управление моделью (MPC)**:
Решение оптимизации на каждом временном шаге по горизонту предсказания.

min J = Σ[Q·(T_zone - T_setpoint)² + R·u²]

Где:
- Q = вес штрафа за комфорт
- R = вес стоимости энергии
- u = управляющее воздействие (положение заслонки, клапана и т.д.)

**Горизонт предсказания**: 1-24 часа
**Горизонт управления**: 15 минут до 2 часов

## Практические соображения по внедрению

**Вычислительные требования**:
- Генетические алгоритмы: 10³-10⁵ оценок функции
- Градиентные методы: 10¹-10³ оценок функции
- Байесовская оптимизация: 10²-10³ оценок функции

**Время решения**:
- Управление в реальном времени: < 1 минуты
- Ежедневная оптимизация: 10-60 минут приемлемо
- Оптимизация проекта: часы до дней

**Тестирование надежности**:
Проверка оптимизированных решений в следующих условиях:
- Метеорологические условия (годовые данные TMY3)
- Вариации занятости (±30%)
- Деградация оборудования (потеря мощности 10-20%)

**Методы валидации**:
- Сравнение оптимизированной и базовой операции
- Полевое тестирование за несколько сезонов
- Непрерывный мониторинг ключевых показателей производительности
