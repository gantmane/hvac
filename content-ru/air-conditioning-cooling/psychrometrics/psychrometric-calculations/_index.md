Психрометрические расчёты переводят термодинамические свойства влажного воздуха в технические параметры оборудования: холодопроизводительность, расход пара, мощность нагревателей. Все примеры выполнены в единицах СИ согласно ASHRAE Handbook — Fundamentals.

## Пример 1: Летняя нагрузка на охлаждающую секцию

**Задача.** Офис требует 3000 м³/ч приточного воздуха при 15 °C / 90 % ОВ. Наружные условия: 33 °C / 55 % ОВ. Возвратный воздух: 25 °C / 50 % ОВ. Доля наружного воздуха — 20 %. Определить нагрузку на охлаждающую секцию и удаление конденсата.

**Шаг 1.** Психрометрические свойства из диаграммы или расчёта:

| Поток | T, °C | ОВ, % | W, кг/кг | h, кДж/кг | v, м³/кг |
|---|---|---|---|---|---|
| Наружный (OA) | 33 | 55 | 0,0195 | 82,9 | 0,893 |
| Возвратный (RA) | 25 | 50 | 0,0099 | 50,4 | 0,860 |
| Приточный (SA) | 15 | 90 | 0,0095 | 39,1 | 0,826 |

**Шаг 2.** Массовый расход приточного воздуха:

{{< formula display="true" >}}
\dot{m}_{sa} = \frac{\dot{V}_{sa}}{v_{sa}} = \frac{3000/3600}{0{,}826} = 1{,}009 \text{ кг/с}
{{< /formula >}}

**Шаг 3.** Расходы по потокам:

{{< formula display="true" >}}
\dot{m}_{oa} = 0{,}20 \times 1{,}009 = 0{,}202 \text{ кг/с}; \quad \dot{m}_{ra} = 0{,}808 \text{ кг/с}
{{< /formula >}}

**Шаг 4.** Параметры смешанного воздуха (MA):

{{< formula display="true" >}}
h_{ma} = \frac{0{,}202 \times 82{,}9 + 0{,}808 \times 50{,}4}{1{,}009} = 41{,}9\cdot\frac{0{,}202}{1{,}009} \cdot ... \approx 55{,}9 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
W_{ma} = \frac{0{,}202 \times 0{,}0195 + 0{,}808 \times 0{,}0099}{1{,}009} = 0{,}01183 \text{ кг/кг}
{{< /formula >}}

**Шаг 5.** Тепловая нагрузка:

{{< formula display="true" >}}
Q_t = \dot{m}_{sa}(h_{ma} - h_{sa}) = 1{,}009 \times (55{,}9 - 39{,}1) = 16{,}9 \text{ кВт}
{{< /formula >}}

{{< formula display="true" >}}
Q_s = \dot{m}_{sa} \cdot c_{p,mix} \cdot (T_{ma} - T_{sa}) \approx 1{,}009 \times 1{,}02 \times (26{,}7 - 15) = 12{,}0 \text{ кВт}
{{< /formula >}}

{{< formula display="true" >}}
Q_l = Q_t - Q_s = 16{,}9 - 12{,}0 = 4{,}9 \text{ кВт}; \quad SHR = \frac{12{,}0}{16{,}9} = 0{,}71
{{< /formula >}}

**Шаг 6.** Удаление конденсата:

{{< formula display="true" >}}
\dot{m}_{cond} = \dot{m}_{sa}(W_{ma} - W_{sa}) = 1{,}009 \times (0{,}01183 - 0{,}0095) = 0{,}00235 \text{ кг/с} = 8{,}5 \text{ кг/ч}
{{< /formula >}}

## Пример 2: Зимний нагрев и увлажнение

**Задача.** Система приточной вентиляции подаёт 2500 м³/ч чистого наружного воздуха. Наружные условия: −5 °C / 70 % ОВ. Требуемые параметры приточного воздуха: 20 °C / 35 % ОВ. Определить мощность нагревателя и производительность увлажнителя.

**Шаг 1.** Свойства воздуха:

| Состояние | T, °C | ОВ, % | W, кг/кг | h, кДж/кг | v, м³/кг |
|---|---|---|---|---|---|
| Наружный | −5 | 70 | 0,00191 | −0,3 | 0,770 |
| Приточный | 20 | 35 | 0,00516 | 33,0 | 0,839 |

**Шаг 2.** Массовый расход:

{{< formula display="true" >}}
\dot{m} = \frac{2500/3600}{0{,}770} = 0{,}901 \text{ кг/с}
{{< /formula >}}

**Шаг 3.** Предварительный нагрев до 20 °C (W остаётся 0,00191 кг/кг):

{{< formula display="true" >}}
Q_{heat} = \dot{m} \cdot c_p \cdot (T_2 - T_1) = 0{,}901 \times 1{,}02 \times 25 = 23{,}0 \text{ кВт}
{{< /formula >}}

**Шаг 4.** Паровое увлажнение (вертикально вверх на диаграмме):

{{< formula display="true" >}}
\dot{m}_{steam} = \dot{m} \cdot (W_2 - W_1) = 0{,}901 \times (0{,}00516 - 0{,}00191) = 0{,}00293 \text{ кг/с} = 10{,}5 \text{ кг/ч}
{{< /formula >}}

{{< formula display="true" >}}
Q_{hum} = \dot{m}_{steam} \cdot h_{fg} = 0{,}00293 \times 2501 = 7{,}3 \text{ кВт}
{{< /formula >}}

**Итог:** нагреватель 23 кВт, увлажнитель 10,5 кг/ч пара (электрическая мощность ≈ 7,5 кВт с КПД 97 %).

## Пример 3: Анализ экономайзерного режима

**Задача.** Центральная установка обслуживает помещение с холодильной нагрузкой 60 кВт; расход воздуха 8000 м³/ч. Возвратный воздух: 24 °C / 50 % ОВ. Наружный воздух: 20 °C / 60 % ОВ. Минимальная доля наружного воздуха — 20 %. Оценить целесообразность экономайзерного режима (100 % наружного воздуха).

**Шаг 1.** Свойства воздуха:

- Возвратный (RA): $h_{ra} = 48{,}0$ кДж/кг; $v_{ra} = 0{,}855$ м³/кг
- Наружный (OA): $h_{oa} = 42{,}3$ кДж/кг; $v_{oa} = 0{,}842$ м³/кг

**Шаг 2.** Массовый расход:

{{< formula display="true" >}}
\dot{m} = \frac{8000/3600}{0{,}855} = 2{,}599 \text{ кг/с}
{{< /formula >}}

**Шаг 3.** Энтальпия смешанного воздуха в режиме минимального наружного воздуха (20 %):

{{< formula display="true" >}}
h_{ma,min} = 0{,}2 \times 42{,}3 + 0{,}8 \times 48{,}0 = 46{,}9 \text{ кДж/кг}
{{< /formula >}}

**Шаг 4.** Охлаждающий потенциал при переходе на 100 % наружного воздуха:

{{< formula display="true" >}}
Q_{free} = \dot{m} \cdot (h_{ma,min} - h_{oa}) = 2{,}599 \times (46{,}9 - 42{,}3) = 12{,}0 \text{ кВт}
{{< /formula >}}

**Вывод:** экономайзерный режим обеспечивает 12,0 кВт «бесплатного» охлаждения — 20 % от расчётной нагрузки. Режим целесообразен, если дополнительное потребление вентилятора при открытых воздушных заслонках не превышает 2–3 кВт.

## Пример 4: Прямое испарительное охлаждение

**Задача.** Склад в жарком сухом климате: наружные условия 43 °C / 15 % ОВ. Эффективность испарительного охладителя (direct evaporative cooler): $\varepsilon = 0{,}85$. Расход воздуха 10 000 м³/ч. Оценить достижимую температуру подачи и холодопроизводительность.

**Шаг 1.** Температура мокрого термометра при 43 °C / 15 % ОВ: $T_{wb} = 21{,}1$ °C.

**Шаг 2.** Достижимая температура подачи:

{{< formula display="true" >}}
T_{sa} = T_{db} - \varepsilon \cdot (T_{db} - T_{wb}) = 43 - 0{,}85 \times (43 - 21{,}1) = 43 - 18{,}6 = 24{,}4\,°\text{C}
{{< /formula >}}

**Шаг 3.** Холодопроизводительность (плотность воздуха $\rho = 1{,}08$ кг/м³ при 43 °C):

{{< formula display="true" >}}
\dot{m} = \frac{10000 \times 1{,}08}{3600} = 3{,}0 \text{ кг/с}
{{< /formula >}}

{{< formula display="true" >}}
Q_{cool} = \dot{m} \cdot c_p \cdot \Delta T = 3{,}0 \times 1{,}02 \times (43 - 24{,}4) = 56{,}9 \text{ кВт}
{{< /formula >}}

**Вывод:** прямое испарительное охлаждение обеспечивает 56,9 кВт охлаждения при потреблении только насоса воды ($\approx 0{,}5$ кВт) и вентилятора. Применимо исключительно в засушливых климатах (ОВ < 35–40 %).

## Пример 5: Коэффициент байпаса охлаждающей секции

**Задача.** ADP (apparatus dew point) охлаждающей секции — 8 °C. Входящий воздух: 28 °C / 60 % ОВ. Выходящий воздух: 14 °C / 90 % ОВ. Рассчитать коэффициент байпаса (bypass factor, BF) и оценить конструкцию секции.

**Шаг 1.** Коэффициент байпаса:

{{< formula display="true" >}}
BF = \frac{T_{out} - T_{ADP}}{T_{in} - T_{ADP}} = \frac{14 - 8}{28 - 8} = \frac{6}{20} = 0{,}30
{{< /formula >}}

**Шаг 2.** Анализ результата.

BF = 0,30 существенно превышает типичные значения для 4–8-рядных секций:

{{< table title="Типовые коэффициенты байпаса охлаждающих секций" >}}
| Число рядов | Шаг рёбер, мм | BF (типовой) |
|---|---|---|
| 2 ряда | 2,5 | 0,30–0,45 |
| 4 ряда | 2,5 | 0,10–0,15 |
| 6 рядов | 2,5 | 0,05–0,10 |
| 8 рядов | 2,5 | 0,02–0,05 |
{{< /table >}}

**Вывод:** при BF = 0,30 секция имеет недостаточное число рядов или завышена скорость воздуха. Рекомендуется увеличить число рядов до 6–8 или снизить фронтальную скорость воздуха до 2,0–2,5 м/с для достижения BF ≤ 0,10.

## Пример 6: Смешивание в многозонной системе VAV

**Задача.** Три зоны с общим возвратным воздухом:

- Зона A: 500 м³/ч, 24 °C / 45 % ОВ
- Зона B: 750 м³/ч, 26 °C / 50 % ОВ
- Зона C: 1000 м³/ч, 23 °C / 55 % ОВ

Определить параметры смешанного возвратного воздуха.

**Шаг 1.** Массовые расходы ($v \approx 0{,}850$ м³/кг):

{{< formula display="true" >}}
\dot{m}_A = \frac{500}{3600 \times 0{,}850} = 0{,}163\;\text{кг/с}; \quad
\dot{m}_B = 0{,}245\;\text{кг/с}; \quad
\dot{m}_C = 0{,}327\;\text{кг/с}
{{< /formula >}}

{{< formula display="true" >}}
\dot{m}_{total} = 0{,}163 + 0{,}245 + 0{,}327 = 0{,}735\;\text{кг/с}
{{< /formula >}}

**Шаг 2.** Свойства зон: $W_A = 0{,}0084$; $W_B = 0{,}0104$; $W_C = 0{,}0098$ кг/кг.

**Шаг 3.** Смешанные параметры:

{{< formula display="true" >}}
T_{mix} = \frac{0{,}163\times24 + 0{,}245\times26 + 0{,}327\times23}{0{,}735} = 24{,}3\,°\text{C}
{{< /formula >}}

{{< formula display="true" >}}
W_{mix} = \frac{0{,}163\times0{,}0084 + 0{,}245\times0{,}0104 + 0{,}327\times0{,}0098}{0{,}735} = 0{,}0096\;\text{кг/кг}
{{< /formula >}}

**Шаг 4.** Относительная влажность: при 24,3 °C значение $W_{sat} = 0{,}0191$ кг/кг:

{{< formula display="true" >}}
\phi_{mix} = \frac{0{,}0096}{0{,}0191} \approx 50{,}3\,\%
{{< /formula >}}

**Результат:** смешанный возвратный воздух — 24,3 °C / 50 % ОВ. Это входные условия для центрального воздухообрабатывающего агрегата.

## Рекомендации по точности расчётов

**Допустимые погрешности при ручных расчётах:**

- температура: ±0,5 °C;
- относительная влажность: ±3 % ОВ;
- влагосодержание: ±0,0002 кг/кг;
- энтальпия: ±0,5 кДж/кг.

**Частые ошибки:**

- Смешивание объёмных расходов без перевода в массовые через удельный объём.
- Использование диаграммы уровня моря для объектов выше 500 м (ошибка в $W$ и $h$ до 5–10 %).
- Пренебрежение скрытой составляющей при расчёте нагрузки на нагревательную секцию.
- Расчёт состояния смеси с применением объёмного, а не массового соотношения потоков.

**Проверки результатов:**

- Свойства смеси должны лежать в диапазоне свойств исходных потоков.
- Закон сохранения энергии: суммарная теплота на входе равна суммарной теплоте на выходе.
- Влагосодержание не может быть отрицательным.
- Точки состояния не могут находиться левее кривой насыщения.

Проиллюстрированные примеры охватывают основные расчётные задачи инженера HVAC согласно методологии ASHRAE Handbook — Fundamentals и обеспечивают освоение психрометрического метода для уверенного проектирования систем кондиционирования воздуха.
