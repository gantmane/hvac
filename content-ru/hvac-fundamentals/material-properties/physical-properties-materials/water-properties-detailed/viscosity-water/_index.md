## Определения и физический смысл

Вязкость — мера внутреннего сопротивления жидкости сдвиговой деформации.

**Динамическая (абсолютная) вязкость** (dynamic viscosity) $\mu$: отношение касательного напряжения к градиенту скорости:

{{< formula display="true" >}}
\tau = \mu\,\frac{du}{dy}
{{< /formula >}}

Единицы СИ: Па·с = 1000 мПа·с = 1000 сП (сантипуаз).

**Кинематическая вязкость** (kinematic viscosity) $\nu$: отношение динамической вязкости к плотности:

{{< formula display="true" >}}
\nu = \frac{\mu}{\rho}
{{< /formula >}}

Единицы: м²/с = 10⁶ мм²/с = 10⁶ сСт (сантистокс).

Вязкость воды убывает при нагреве примерно экспоненциально — от 1,787 мПа·с при 0 °C до 0,282 мПа·с при 100 °C (снижение на **84 %**). Это наиболее резко меняющееся из транспортных свойств воды в диапазоне HVAC.

## Зависимость от температуры

**Уравнение Фогеля–Фулчера–Таманна** (Vogel–Fulcher–Tammann) — наиболее точная корреляция для жидкой воды (погрешность ≤1 %):

{{< formula display="true" >}}
\mu(T) = A\,\exp\!\left[\frac{B}{T - C}\right]
{{< /formula >}}

где $T$ — температура в К; $A = 0{,}02939$ мПа·с; $B = 507{,}88$ К; $C = 149{,}3$ К; диапазон — 0–370 °C.

**Влияние давления.** При рабочих давлениях гидронных систем (до 1,5 МПа изб.) вязкость изменяется менее чем на 2 % — поправкой допустимо пренебречь.

## Применение в гидравлических расчётах

### Число Рейнольдса и режим течения

{{< formula display="true" >}}
Re = \frac{\rho\,w\,d_h}{\mu} = \frac{w\,d_h}{\nu}
{{< /formula >}}

Классификация режима:
- $Re < 2300$ — ламинарный;
- $2300 < Re < 4000$ — переходный;
- $Re > 4000$ — турбулентный (типично для HVAC).

### Потери давления по уравнению Дарси–Вейсбаха

{{< formula display="true" >}}
\Delta P = \lambda\,\frac{L}{d_h}\,\frac{\rho\,w^2}{2}
{{< /formula >}}

Коэффициент гидравлического трения $\lambda$:
- ламинарный режим: $\lambda = 64/Re$;
- турбулентный (уравнение Черчилля или Свами–Джейна):

{{< formula display="true" >}}
\frac{1}{\sqrt{\lambda}} = -2{,}0\,\log\!\left(\frac{\varepsilon/d}{3{,}7} + \frac{2{,}51}{Re\sqrt{\lambda}}\right)
{{< /formula >}}

Для ламинарного режима потери давления прямо пропорциональны $\mu$:

{{< formula display="true" >}}
\Delta P_{\text{лам}} = \frac{128\,\mu\,L\,Q}{\pi\,d^4} \quad \text{(уравнение Хагена–Пуазейля)}
{{< /formula >}}

## Числовые примеры

### Пример 1. Потери давления в контуре охлаждённой воды

**Условие.** Контур охлаждённой воды: диаметр трубы $d = 50$ мм (стальная труба, шероховатость $\varepsilon = 0{,}046$ мм), скорость потока $w = 1{,}5$ м/с, длина расчётного участка $L = 100$ м, температура подачи — 7 °C.

**Решение.**

При 7 °C: $\mu = 1{,}42 \times 10^{-3}$ Па·с; $\rho = 999{,}8$ кг/м³.

{{< formula display="true" >}}
Re = \frac{999{,}8 \times 1{,}5 \times 0{,}05}{1{,}42 \times 10^{-3}} = 52\,800 \quad (\text{турбулентный})
{{< /formula >}}

Относительная шероховатость: $\varepsilon/d = 0{,}046/50 = 0{,}00092$.

По диаграмме Муди (или формуле Свами–Джейна): $\lambda \approx 0{,}0208$.

{{< formula display="true" >}}
\Delta P = 0{,}0208 \times \frac{100}{0{,}05} \times \frac{999{,}8 \times 1{,}5^2}{2} = 0{,}0208 \times 2000 \times 1125 = 46\,800 \text{ Па} \approx 4{,}68 \text{ м вод. ст.}
{{< /formula >}}

---

### Пример 2. Сравнение потерь давления: охлаждённая vs. горячая вода

**Условие.** Та же труба, тот же объёмный расход. Охлаждённая вода 7 °C ($\mu = 1{,}42$ мПа·с) vs. горячая вода 70 °C ($\mu = 0{,}404$ мПа·с).

При постоянном объёмном расходе скорости одинаковы. Для турбулентного течения $\lambda \propto Re^{-0{,}2}$, $Re \propto 1/\mu$:

{{< formula display="true" >}}
\frac{\Delta P_{\text{хол}}}{\Delta P_{\text{гор}}} = \frac{\lambda_{\text{хол}}}{\lambda_{\text{гор}}} \times \frac{\rho_{\text{хол}}}{\rho_{\text{гор}}} \approx \left(\frac{\mu_{\text{хол}}}{\mu_{\text{гор}}}\right)^{0{,}2} \times \frac{\rho_{\text{хол}}}{\rho_{\text{гор}}}
{{< /formula >}}

{{< formula display="true" >}}
= \left(\frac{1{,}42}{0{,}404}\right)^{0{,}2} \times \frac{999{,}8}{977{,}8} = 1{,}285 \times 1{,}022 = 1{,}31
{{< /formula >}}

Контур охлаждённой воды имеет потери давления на **31 %** выше, чем контур горячей воды при тех же расходах — это обусловлено разницей вязкостей.

---

### Пример 3. Влияние гликоля на число Рейнольдса и режим течения

**Условие.** Та же труба $d = 50$ мм, скорость $w = 0{,}8$ м/с, теплоноситель — 30 % ЭГ при 0 °C ($\mu = 4{,}87$ мПа·с, $\rho = 1050$ кг/м³).

{{< formula display="true" >}}
Re_{\text{гл}} = \frac{1050 \times 0{,}8 \times 0{,}05}{4{,}87 \times 10^{-3}} = 8\,625 \quad (\text{турбулентный, но Re значительно ниже})
{{< /formula >}}

Для сравнения: вода при 7 °C и той же скорости:

{{< formula display="true" >}}
Re_{\text{вода}} = \frac{999{,}8 \times 0{,}8 \times 0{,}05}{1{,}42 \times 10^{-3}} = 28\,160
{{< /formula >}}

Число Рейнольдса снизилось в 3,3 раза. При проектировании систем с гликолем следует убедиться, что Re остаётся выше 4000 при минимальной рабочей температуре (максимальная вязкость — наихудший случай).

## Практические рекомендации для проектирования

**Подбор насоса.** Рассчитывать рабочую точку при максимальной вязкости (минимальная температура эксплуатации). Учитывать повышенную мощность при холодном пуске. Применять частотные преобразователи (ЧРП) для адаптации производительности при изменении вязкости в течение сезона.

**Подбор диаметров трубопровода.** Обеспечивать турбулентный режим ($Re > 4000$) во всём диапазоне расходов. Рекомендуемые скорости в гидронных системах: 0,6–2,4 м/с. При работе с гликолем допускать несколько большие скорости для поддержания Re.

**Гликолевые системы.** Использовать минимально необходимую концентрацию гликоля с запасом 3–5 °C ниже расчётной минимальной температуры. Проверять вязкость аналитически или рефрактометром каждые 2–3 года: деградированный гликоль (рост вязкости >50 % от паспортных значений) подлежит замене.

**Расходомеры.** Магнитно-индукционные и ультразвуковые расходомеры не зависят от вязкости и предпочтительны для гликолевых систем. Турбинные расходомеры требуют коррекции при $Re < 10\,000$.

**Регулирующие клапаны.** Коэффициент $K_v$ (расходная характеристика) нормирован при воде 15 °C. При существенно иных температурах или при использовании гликолей необходимо применять поправочные коэффициенты по данным производителя.
