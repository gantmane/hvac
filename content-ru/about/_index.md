## BIM + ИИ и BIM + Python для HVAC

Помимо традиционного проектирования HVAC и BIM-координации, я активно разрабатываю в развивающемся пересечении **цифровой инженерии, автоматизации Python и ИИ для рабочих процессов MEP/HVAC** — нишу, где мало практикующих инженеров HVAC могут достоверно работать.

**BIM + Python для HVAC — уже в промышленной эксплуатации на моих проектах:**

- Автоматизация Dynamo + Python (Revit API) ведомостей HVAC, списков оборудования и распространения параметров воздуховодов/трубопроводов
- Автоматическое создание отчетов о коллизиях и их маршрутизация в нужные дисциплины
- Скрипты контроля качества моделей: проверка недостающих параметров, орфанных семейств, смещения координат
- Массовое создание семейств и управление библиотеками через автоматизированные рабочие процессы
- Экспорт входных данных расчета HVAC из Revit во внешние инструменты расчета тепловых нагрузок и обратно

**BIM + ИИ — активное направление развития:**

- **Классификация коллизий с помощью ИИ** — использование LLM для классификации, кластеризации и приоритизации отчетов о коллизиях Navisworks, чтобы инженеры тратили время на реальные проблемы, а не дубликаты
- **Спецификации HVAC, генерируемые LLM** — преобразование заметок проектного замысла в черновой текст спецификации с окончательной проверкой человеком
- **Векторный поиск по архивам проектов** — семантический поиск по годам чертежей HVAC, спецификаций и расчетов для ускорения рецензирования и поиска аналогов
- **Ассистенты по соответствию кодам** — LLM, помогающие при поиске и сопоставлении SNiP / ASHRAE / местных норм при проверке проектов
- **Python + локальный вывод LLM** для закрытых проектных сред, где облачный ИИ не разрешен

Это ставит меня в редкий голубой океан: главный инженер HVAC с 20+ годами доставки проектов *и* работающий, практический стек для BIM-автоматизации и ИИ-поддержки. Большинство BIM-ИИ инструментов сегодня создаются разработчиками программного обеспечения без опыта инженерной области, а большинство инженеров HVAC не кодируют. Я делаю и то, и другое.
