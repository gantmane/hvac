Производительность охлаждающей секции (cooling coil) определяет способность системы кондиционирования обеспечить требуемые параметры приточного воздуха. Психрометрический анализ секции позволяет рассчитать распределение мощности между явным и скрытым охлаждением, определить точку росы аппарата (ADP), оценить коэффициент байпаса и выбрать оптимальные параметры хладоносителя.

## Режимы работы охлаждающей секции

### Сухой режим (t_surface > t_dp,воздуха)

При температуре поверхности выше точки росы воздуха конденсация отсутствует. Теплообмен — только конвективный. Для этого режима применяется стандартный метод LMTD или NTU-ε.

Условие сухого режима:

{{< formula display="true" >}}
t_{w,\text{вх}} > t_{dp,\text{вх}}
{{< /formula >}}

### Частично мокрый режим

При t_w,вх < t_dp,вх но t_w,вых > t_dp,вых часть секции работает в сухом режиме, часть — в мокром. Необходим комбинированный анализ.

### Полностью мокрый режим (wet coil)

Когда температура воды на выходе ниже точки росы, вся поверхность работает в режиме конденсации. Наиболее распространённый случай в летнем кондиционировании.

## Метод LMTD для сухой секции

{{< formula display="true" >}}
Q_s = U_{\text{сух}} \cdot A \cdot \text{LMTD}
{{< /formula >}}

{{< formula display="true" >}}
\text{LMTD} = \frac{(t_{a,1} - t_{w,2}) - (t_{a,2} - t_{w,1})}{\ln\!\left(\dfrac{t_{a,1}-t_{w,2}}{t_{a,2}-t_{w,1}}\right)}\quad(\text{противоток})
{{< /formula >}}

Общий коэффициент теплопередачи U для сухой секции (воздух-сторона + стенка + вода-сторона):

{{< formula display="true" >}}
\frac{1}{U_{\text{сух}} \cdot A} = \frac{1}{h_a \cdot A_a} + \frac{t_{\text{стенки}}}{\lambda \cdot A_m} + \frac{1}{h_w \cdot A_w}
{{< /formula >}}

## Метод LMED для мокрой секции

Для мокрой охлаждающей секции с конденсацией логарифмическая средняя разность температур (LMTD) не учитывает скрытую теплоту. Вместо неё применяется **метод логарифмической средней разности энтальпий (LMED — Logarithmic Mean Enthalpy Difference)**:

{{< formula display="true" >}}
Q_{\text{total}} = U_{\text{мок}} \cdot A \cdot \text{LMED} / c_{p,\text{пар}}^*
{{< /formula >}}

где c_p,пар* — эффективная теплоёмкость насыщенного воздуха (наклон линии насыщения на h–t диаграмме):

{{< formula display="true" >}}
c_p^* = \frac{h_s(t_{w,2}) - h_s(t_{w,1})}{t_{w,2} - t_{w,1}}\approx 2{,}5{-}4{,}0\;\text{кДж/(кг·К)}
{{< /formula >}}

{{< formula display="true" >}}
\text{LMED} = \frac{(h_{s,1} - h_{w,2}) - (h_{s,2} - h_{w,1})}{\ln\!\left(\dfrac{h_{s,1}-h_{w,2}}{h_{s,2}-h_{w,1}}\right)}
{{< /formula >}}

где h_s,1, h_s,2 — энтальпии насыщенного воздуха при температурах воды t_w,1 и t_w,2; h_w,1, h_w,2 — энтальпии воздуха на выходе из двух торцов секции.

Типовые значения c_p*:

{{< table title="Эффективная теплоёмкость насыщенного воздуха c_p*" >}}
| t_w, °C | c_p*, кДж/(кг·К) |
|---|---|
| 5 | 1,85 |
| 7 | 2,05 |
| 10 | 2,45 |
| 13 | 3,00 |
| 16 | 3,80 |
| 20 | 5,10 |
{{< /table >}}

## Метод NTU-ε для охлаждающих секций

Для мокрой секции метод NTU применяется в энтальпийном пространстве:

{{< formula display="true" >}}
\varepsilon = \frac{h_{a,1} - h_{a,2}}{h_{a,1} - h_s(t_{w,1})}
{{< /formula >}}

{{< formula display="true" >}}
\text{NTU} = \frac{U_{\text{мок}} \cdot A}{\dot{m}_a},\quad C^* = \frac{\dot{m}_a}{c_p^* \cdot \dot{m}_w \cdot c_{pw} / c_p^*}
{{< /formula >}}

Для противоточного теплообменника:

{{< formula display="true" >}}
\varepsilon = \frac{1 - \exp[-\text{NTU}(1-C^*)]}{1 - C^*\exp[-\text{NTU}(1-C^*)]}
{{< /formula >}}

## Расчёт конденсатообразования

### Скорость конденсации

{{< formula display="true" >}}
\dot{m}_{\text{конд}} = \dot{m}_a \cdot (W_1 - W_2)\quad[\text{кг/с}]
{{< /formula >}}

### Энергия конденсата

{{< formula display="true" >}}
q_{\text{конд}} = \dot{m}_{\text{конд}} \cdot h_w(t_{\text{конд}}) = \dot{m}_a(W_1-W_2) \cdot c_{pw} \cdot t_s
{{< /formula >}}

Полная мощность охлаждающей секции с учётом конденсата:

{{< formula display="true" >}}
Q_{\text{total}} = \dot{m}_a \bigl[(h_1 - h_2) - (W_1-W_2) \cdot c_{pw} \cdot t_s\bigr]
{{< /formula >}}

Поправка составляет: (W1−W2) × 4,186 × 12 ≈ 0,05–0,2 кДж/кг — обычно < 0,5 % от Q_total.

## Выбор параметров хладоносителя

### Температура холодной воды

Рекомендуемые параметры холодной воды (CHW):

{{< table title="Стандартные параметры температуры холодной воды для охлаждающих секций" >}}
| Приложение | t_вх/t_вых, °C | Δt_w, °C | t_ADP достижимый |
|---|---|---|---|
| Комфортное кондиционирование | 6/12 | 6 | 8–11 °C |
| Прецизионное охлаждение | 7/14 | 7 | 9–12 °C |
| Глубокое осушение | 4/8 | 4 | 6–9 °C |
| Высокотемпературный чиллер (HVAC+ВИЭ) | 14/18 | 4 | 16–19 °C (только явн.) |
{{< /table >}}

### Влияние температуры воды на SHR секции

Снижение t_w,вх позволяет достичь более низкого ADP и, следовательно, снизить SHR секции (увеличить долю скрытого охлаждения):

{{< formula display="true" >}}
\text{SHR}_{\text{секции}} = f(t_{w,\text{вх}}, G_w, v_{\text{face}},\;\text{геометрия})
{{< /formula >}}

Приблизительная зависимость: снижение t_w на 1 °C снижает SHR секции примерно на 0,02–0,05 (зависит от режима).

## Полный проектный расчёт охлаждающей секции

**Задание:** подобрать охлаждающую секцию для ПВУ производительностью 20 000 м³/ч.

**Входные данные:**
- Воздух на входе: t_db1 = 29 °C, φ1 = 60 %, W1 = 15,02 г/кг, h1 = 67,1 кДж/кг
- Воздух на выходе: t_db2 = 13 °C, φ2 = 90 %, W2 = 8,39 г/кг, h2 = 34,3 кДж/кг
- Холодная вода: 6/12 °C
- Допустимое падение давления воздуха: ≤ 150 Па

**Шаг 1. Нагрузки:**

{{< formula display="true" >}}
\dot{m}_a = \frac{20\,000}{3600} \times \frac{1}{v_1} = \frac{20\,000}{3600 \times 0{,}876} = 6{,}35\;\text{кг/с}
{{< /formula >}}

{{< formula display="true" >}}
Q_{\text{total}} = 6{,}35 \times (67{,}1 - 34{,}3) = 6{,}35 \times 32{,}8 = \mathbf{208\;\text{кВт}}
{{< /formula >}}

{{< formula display="true" >}}
Q_s = 6{,}35 \times 1{,}006 \times 16 = \mathbf{102\;\text{кВт}},\quad Q_l = 208 - 102 = \mathbf{106\;\text{кВт}}
{{< /formula >}}

{{< formula display="true" >}}
\text{SHR} = 102/208 = \mathbf{0{,}49}
{{< /formula >}}

**Шаг 2. ADP:**

Прямая через (29°C, 15,02 г/кг) и (13°C, 8,39 г/кг):  
Наклон: (8,39 − 15,02)/(13 − 29) = −6,63/−16 = 0,414 (г/кг)/°C  
Уравнение: W = 15,02 + 0,414(t − 29) = 0,414t + 2,93

Итерация до кривой насыщения: t_ADP ≈ **9,6 °C**, W_ADP ≈ 6,89 г/кг

**Шаг 3. BF:**

{{< formula display="true" >}}
\text{BF} = \frac{13 - 9{,}6}{29 - 9{,}6} = \frac{3{,}4}{19{,}4} = \mathbf{0{,}175}
{{< /formula >}}

По таблице: BF ≈ 0,175 → **6 рядов, шаг оребрения 2,5 мм** при v_face ≤ 2,5 м/с.

**Шаг 4. Площадь лицевого сечения:**

{{< formula display="true" >}}
A_{\text{face}} = \frac{\dot{V}}{v_{\text{face}}} = \frac{20\,000/3600}{2{,}5} = \mathbf{2{,}22\;\text{м}^2}
{{< /formula >}}

Стандартный типоразмер: 1,2 × 2,0 м = 2,4 м² (v_face = 2,31 м/с).

**Шаг 5. Расход холодной воды:**

{{< formula display="true" >}}
\dot{V}_w = \frac{Q_{\text{total}}}{c_{pw} \cdot \rho_w \cdot \Delta T_w} = \frac{208}{4{,}186 \times 1000 \times 6} = 0{,}00829\;\text{м}^3/\text{с} = \mathbf{29{,}8\;\text{м}^3/\text{ч}}
{{< /formula >}}

**Шаг 6. Конденсатообразование:**

{{< formula display="true" >}}
\dot{m}_{\text{конд}} = 6{,}35 \times (0{,}01502 - 0{,}00839) = \mathbf{0{,}042\;\text{кг/с}} = \mathbf{151\;\text{кг/ч}}
{{< /formula >}}

Поддон должен вмещать минимум 15-минутный запас: 151 × 15/60 = **37,8 кг = ~38 л**.

## Проверочный расчёт по каталожным данным

После подбора секции по каталогу производителя (AHRI 410) проводится проверочный расчёт:

1. Взять из каталога характеристику Q_total(t_db_вх, t_wb_вх, t_w_вх, Δt_w, v_face)
2. Проверить соответствие BF каталожному значению
3. Уточнить ADP из каталожных t_DB_вых и BF

Каталожные данные имеют приоритет над аналитическими методами, поскольку включают реальные геометрию и тепловое сопротивление.
