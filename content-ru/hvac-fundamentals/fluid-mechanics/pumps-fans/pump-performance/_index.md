Рабочая характеристика насоса — полное описание его гидравлического поведения: зависимость напора, КПД, потребляемой мощности и кавитационного запаса от расхода. Понимание этих кривых, их взаимного расположения и изменения при регулировании — базовая компетенция инженера ОВК при подборе насосного оборудования, наладке и диагностике.

## Полный динамический напор

Полный динамический напор (Total Dynamic Head, TDH) — приращение удельной полной механической энергии единицы массы жидкости при прохождении через насос:

{{< formula display="true" >}}
H = \frac{P_{\text{нагн}} - P_{\text{всас}}}{\rho g} + \frac{V_{\text{нагн}}^2 - V_{\text{всас}}^2}{2g} + (Z_{\text{нагн}} - Z_{\text{всас}})
{{< /formula >}}

Для замкнутых гидронических систем разница геодезических высот патрубков обычно незначительна (Z_нагн − Z_всас ≈ 0,1–0,5 м), а разница скоростных напоров мала. На практике H определяется как разность показаний манометра нагнетания и вакуумметра всасывания, приведённых к одной оси.

Гидравлическая мощность (полезная мощность, передаваемая жидкости):

{{< formula display="true" >}}
P_{\text{гидр}} = \rho \cdot g \cdot Q \cdot H = Q \cdot \Delta P
{{< /formula >}}

## Характеристические кривые

Полный набор кривых насоса включает:

{{< table title="Характеристические кривые центробежного насоса" >}}
| Кривая | Оси | Назначение |
|---|---|---|
| H-Q (напорная) | H [м] vs Q [м³/ч] | Основная характеристика; точка работы |
| η-Q (КПД) | η [%] vs Q [м³/ч] | Нахождение BEP; оценка потерь |
| P-Q (мощность) | P [кВт] vs Q [м³/ч] | Подбор двигателя |
| NPSH_r-Q | NPSH_r [м] vs Q [м³/ч] | Проверка кавитации |
{{< /table >}}

### Форма напорной кривой

Кривая H-Q центробежного насоса с радиальным колесом монотонно убывает от напора отсечки (H_0 при Q = 0) до нуля. Крутизна кривой определяется углом выходных лопаток (β₂):

- Лопатки загнутые назад (β₂ < 90°): крутая кривая, стабильная работа, мощность не растёт к нулевому расходу — предпочтительная геометрия для систем ОВК
- Лопатки радиальные (β₂ = 90°): умеренная крутизна
- Лопатки загнутые вперёд (β₂ > 90°): пологая или выпуклая кривая; риск нестабильности («помпаж»), нарастание мощности при малом расходе

Для систем ОВК промышленно выпускаемые насосы всегда имеют загнутые назад лопатки (β₂ = 15–35°).

### Точка наилучшего КПД (BEP)

BEP — точка на напорной кривой, в которой КПД насоса максимален. Гидравлические, объёмные и механические потери в сумме минимальны. ASHRAE Handbook и Hydraulic Institute ANSI/HI 9.6.3 рекомендуют выбор насоса так, чтобы расчётная рабочая точка находилась в диапазоне **0,80–1,10 · Q_BEP**:

- При Q < 0,70 · Q_BEP возникает рециркуляция на входе, турбулентность и кавитация, чрезмерный нагрев жидкости при малом расходе, высокие радиальные нагрузки на вал
- При Q > 1,15 · Q_BEP — перегрузка двигателя, кавитация на выходных кромках лопаток, ускоренный износ

Типичные значения η_BEP по мощности двигателя:

{{< table title="Типовые значения КПД насосов в BEP" >}}
| Мощность двигателя, кВт | Тип насоса | η_BEP, % |
|---|---|---|
| 0,1–1,5 | Циркуляционный (мокрый ротор) | 35–55 |
| 1,5–7,5 | Консольный | 60–75 |
| 7,5–37 | Консольный | 72–82 |
| 37–150 | Консольный / split-case | 78–86 |
| > 150 | Split-case | 82–88 |
{{< /table >}}

## Кавитационный запас NPSH

### Физика кавитации

Кавитация начинается, когда локальное статическое давление в потоке опускается ниже давления насыщенного пара жидкости при данной температуре. Образуются паровые полости (каверны), которые схлопываются при выходе в зону повышенного давления. Схлопывание сопровождается импульсами давления до 10² МПа и акустическим шумом (характерный «хруст» или «грохот»). Результат: эрозия лопаток, снижение напора и КПД, вибрация, отказ уплотнений.

### Кавитационный запас системы (NPSH_a)

{{< formula display="true" >}}
\text{NPSH}_a = \frac{P_{\text{атм}} + \rho g H_s - \rho g h_{f,s} - P_{\text{нас}}(T)}{\rho g}
{{< /formula >}}

где `H_s` — высота расположения всасывающего бака относительно оси насоса (положительная при расположении бака выше), `h_f,s` — потери на всасывающей линии, `P_нас(T)` — давление насыщенного пара при рабочей температуре.

Условие безопасной работы:

{{< formula display="true" >}}
\text{NPSH}_a \geq \text{NPSH}_r + \Delta\text{NPSH}_{\text{запас}}
{{< /formula >}}

Hydraulic Institute рекомендует запас Δ = 1,0–1,5 м (минимум 0,5 м). NPSH_r возрастает с расходом примерно как Q^1,5.

### Давление насыщенного пара воды при ключевых температурах

{{< table title="Давление насыщенного пара воды и NPSH-влияние" >}}
| Температура, °C | P_нас, кПа (абс) | P_нас/(ρg), м |
|---|---|---|
| 10 | 1,23 | 0,13 |
| 20 | 2,34 | 0,24 |
| 50 | 12,35 | 1,27 |
| 70 | 31,19 | 3,24 |
| 90 | 70,14 | 7,33 |
| 110 | 143,3 | 15,1 |
{{< /table >}}

При высоких температурах теплоносителя (`T > 70 °C`) кавитационный запас системы резко сокращается. Насосы систем высокотемпературного отопления (90–110 °C) должны устанавливаться на возврате (холодная сторона) или в заглублённых машинных залах с повышенным давлением заполнения.

## Параллельная работа насосов

При параллельном подключении двух насосов к общей системе их напорные кривые «складываются» по расходу при одинаковом напоре. Суммарная кривая строится как: для каждого значения H суммируются расходы обоих насосов.

{{< formula display="true" >}}
Q_{\text{сумм}}(H) = Q_1(H) + Q_2(H)
{{< /formula >}}

**Особенность:** суммарный расход при параллельной работе двух одинаковых насосов не равен двойному расходу одного насоса. Из-за роста сопротивления системы с расходом фактическое увеличение расхода составляет обычно 30–50 % (зависит от крутизны кривой системы).

**Требования при параллельной работе:**
- Кривые H-Q обоих насосов должны иметь монотонно убывающий характер без горбов — иначе возможна неустойчивая работа
- Для насосов с разными характеристиками необходимо, чтобы их напор отсечки (H при Q=0) не отличался более чем на 15 % — иначе насос с меньшим H₀ при малых расходах будет «запираться» и работать при отрицательном расходе
- Обратные клапаны на нагнетательных патрубках каждого насоса — обязательны

## Последовательная работа насосов

При последовательном включении напоры суммируются при одинаковом расходе:

{{< formula display="true" >}}
H_{\text{сумм}}(Q) = H_1(Q) + H_2(Q)
{{< /formula >}}

Применяется при высокой статической составляющей системы или больших протяжённых системах (тепловые сети). Расход определяется пересечением суммарной кривой с характеристикой системы — он не превышает расход одиночного насоса в той же системе более чем на 10–20 %.

## Регулирование производительности и экономия энергии

### Без регулирования (дросселирование)

Прикрытие задвижки увеличивает R_сист; рабочая точка смещается влево по кривой насоса. КПД падает, мощность изменяется незначительно (при пологой P-Q кривой может даже расти). Применяется только при временном снижении расхода или для пуска насоса в системе с открытым байпасом.

### Регулирование частоты вращения (ЧРП)

Оптимальный метод для систем с переменным расходом. Рабочая точка смещается по параболе подобия. Для закрытых гидронических систем (ΔP_стат = 0) потребляемая мощность уменьшается пропорционально кубу отношения скоростей.

Стратегии регулирования ЧРП в системах ОВК:

{{< table title="Стратегии управления ЧРП насосов" >}}
| Стратегия | Уставка | Точность | Применение |
|---|---|---|---|
| Постоянное давление (CP) | ΔP = const | ±5 % | Простые разводки, стояки |
| Пропорциональное давление (PP) | ΔP ~ Q (линейно) | ±5 % | Лучи с регуляторами расхода |
| Регулирование по наиболее нагружённому потребителю | ΔP_критич = const | ±2–3 % | Здания с датчиками ΔP |
| Сброс уставки давления по температуре наружного воздуха | ΔP = f(T_нар) | ±10 % | Системы отопления |
{{< /table >}}

Режим «Пропорциональное давление» (PP) обеспечивает наибольшую экономию в системах с балансировочными клапанами: при снижении расхода уставка давления автоматически снижается, что позволяет работать на ещё меньшей скорости, чем при постоянном давлении.

## Числовой пример: определение рабочей точки и оценка КПД

**Условие.** Система отопления. Насос с напорной кривой, аппроксимируемой:

{{< formula display="true" >}}
H = 25 - 0{,}018 \cdot Q^2 \quad [H \text{ в м, } Q \text{ в м}^3/\text{ч}]
{{< /formula >}}

Характеристика системы (закрытый контур): ΔP_сист = 900 · Q² Па (при Q в м³/с), что соответствует H_сист = ΔP/(ρg) = 900 Q² / (986 × 9,81) = 0,093 Q² (при Q в м³/с) или H_сист = 0,093 / 3600² · Q² = 7,17 · 10⁻⁶ · Q² при Q в м³/ч. При Q в м³/ч: H_сист = 0,0072 · Q² (м).

**Нахождение рабочей точки:**

{{< formula display="true" >}}
25 - 0{,}018 Q^2 = 0{,}0072 Q^2
{{< /formula >}}

{{< formula display="true" >}}
25 = Q^2 (0{,}018 + 0{,}0072) = 0{,}0252 Q^2
{{< /formula >}}

{{< formula display="true" >}}
Q = \sqrt{\frac{25}{0{,}0252}} = \sqrt{992} = 31{,}5 \text{ м}^3/\text{ч}
{{< /formula >}}

{{< formula display="true" >}}
H = 25 - 0{,}018 \cdot 992 = 25 - 17{,}9 = 7{,}1 \text{ м}
{{< /formula >}}

**Гидравлическая мощность:**

{{< formula display="true" >}}
P_{\text{гидр}} = \rho g Q H = 986 \times 9{,}81 \times \frac{31{,}5}{3600} \times 7{,}1 = 9672 \times 0{,}00875 \times 7{,}1 = 600 \text{ Вт} = 0{,}60 \text{ кВт}
{{< /formula >}}

При КПД насоса η = 0,72 (значение из кривой η-Q для Q = 31,5 м³/ч): P_вал = 0,60/0,72 = **0,83 кВт**.

**Проверка:** BEP данного насоса при n_s ≈ 80 обычно соответствует Q_BEP ≈ 28–35 м³/ч. Q_раб = 31,5 м³/ч находится вблизи BEP — выбор удачный.

## Приёмочные испытания

ГОСТ ISO 9906-2019 устанавливает два класса допусков для приёмочных испытаний насосов:

- **Класс 1** (строгий): ±4 % по напору, ±6 % по расходу, ±3 % по КПД
- **Класс 2** (стандартный): ±8 % по напору, ±10 % по расходу, ±5 % по КПД
- **Класс 3** (расширенный): ±10 % по напору, ±12 % по расходу, ±7 % по КПД

Испытание NPSH_r выполняется методом снижения входного давления при постоянном расходе до момента 3%-го снижения напора (NPSH₃ по ISO). Для критических установок (горячая вода, гликоль) рекомендуется класс 1.

## Диагностика по кривым характеристик

Сравнение фактических рабочих параметров с паспортными кривыми — основа диагностики насосного оборудования:

| Симптом | Вероятная причина |
|---|---|
| Q ниже паспортного при том же H | Износ рабочего колеса, засорение, несоответствие системы |
| H ниже паспортного при любом Q | Снижение скорости (ЧРП, пониженное напряжение), кавитация, засорение |
| Шум «хруст» или «грохот» | Кавитация — проверить NPSH_a |
| Повышенный ток двигателя | Работа правее BEP; проверить характеристику системы |
| Пульсации давления | Рабочая точка левее BEP (рециркуляция); помпаж у осевых насосов |
