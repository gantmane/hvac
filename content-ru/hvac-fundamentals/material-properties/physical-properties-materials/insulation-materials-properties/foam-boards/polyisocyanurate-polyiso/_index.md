## Обзор

Полиизоцианурат (polyisocyanurate, polyiso, PIR) — жёсткий вспененный синтетический изоляционный материал, получаемый реакцией полиола с избытком полиизоцианата в присутствии катализатора. Избыток изоцианата инициирует тримеризацию с образованием изоциануратных колец, обеспечивающих повышенную температурную стойкость и огнестойкость по сравнению с обычным полиуретаном (polyurethane). Доля замкнутых пор превышает 95 %, что определяет низкую теплопроводность и высокое паросопротивление.

Полиизоцианурат — один из наиболее теплоэффективных жёстких изоляционных материалов для систем ОВК. Начальная теплопроводность 0,021–0,023 Вт/(м·К) при 24 °C превосходит минеральную вату (mineral wool) и приближается к фенольной пене (phenolic foam). После стабилизации диффузии газа-вспенивателя (aging) через 5–10 лет расчётное значение составляет 0,024–0,026 Вт/(м·К). Стандарт ASTM C1289 нормирует долгосрочное тепловое сопротивление (Long-Term Thermal Resistance, LTTR) с учётом этого эффекта.

## Физические принципы и структура

### Формирование пены и ячеистая архитектура

В процессе вспенивания газ-вспениватель (гидрофторуглерод HFC-245fa или гидрофторолефин HFO-1233zd) заполняет замкнутые поры диаметром 100–300 мкм. Теплопроводность газа-вспенивателя (λ ≈ 0,010–0,014 Вт/(м·К)) значительно ниже воздуха (λ = 0,026 Вт/(м·К)), что и обеспечивает начальное преимущество материала. По мере диффузии атмосферного воздуха в ячейки и выхода вспенивателя теплопроводность возрастает и стабилизируется на уровне долгосрочного значения.

### Механизмы теплопередачи

{{< formula display="true" >}}
\lambda_{\text{эфф}} = \lambda_{\text{тв}} + \lambda_{\text{газ}} + \lambda_{\text{рад}}
{{< /formula >}}

- $\lambda_{\text{тв}} \approx 0{,}001$ Вт/(м·К) — перенос через полимерный каркас;
- $\lambda_{\text{газ}} \approx 0{,}010{-}0{,}014$ Вт/(м·К) — перенос через газ в ячейках (новый материал); возрастает до $0{,}020{-}0{,}024$ Вт/(м·К) при замещении воздухом;
- $\lambda_{\text{рад}} \approx 0{,}002{-}0{,}004$ Вт/(м·К) — радиационный перенос.

### Долгосрочное тепловое сопротивление и старение

Стабилизированное значение теплопроводности оценивается по модели диффузии ASTM C1289 / ISO 11561:

{{< formula display="true" >}}
\lambda_{\text{ст}} = \lambda_0 + \Delta\lambda_{\infty} \cdot \left(1 - e^{-k \cdot \sqrt{t}}\right)
{{< /formula >}}

где $\lambda_0$ — начальная теплопроводность; $\Delta\lambda_{\infty}$ — прирост при полном замещении газа воздухом (0,004–0,006 Вт/(м·К)); $k$ — коэффициент диффузии; $t$ — время, лет. Для плиты толщиной 25 мм стабилизация наступает через 3–5 лет, для 75 мм — через 15–20 лет.

На практике при проектировании принимают $\lambda_{\text{расч}} = 0{,}025{-}0{,}026$ Вт/(м·К) — значение LTTR согласно ASHRAE Handbook Fundamentals (гл. 33).

### Облицовочные слои

Полиизоцианурат поставляется с различными облицовками, определяющими паропроницаемость и механическую защиту:

- **Алюминиевая фольга (foil-faced)**: толщина 12–25 мкм; коэффициент паросопротивления μ > 100 000; ε ≈ 0,05 (отражение лучистого тепла). Применяется при температурах ниже точки росы окружающего воздуха.
- **Стеклоткань (glass-faced)**: повышает механическую прочность; сохраняет паропроницаемость для конструкций с предусмотренным высыханием.
- **Крафт-бумага с полиэтиленом (kraft-PE)**: экономичный вариант для температур выше +4 °C.

## Расчёт теплопотерь через изолированный воздуховод

### Расчётные зависимости

Тепловой поток через плоскую стенку воздуховода с изоляцией:

{{< formula display="true" >}}
q = \frac{T_i - T_e}{\dfrac{1}{h_i} + \dfrac{d}{\lambda} + \dfrac{1}{h_e}}
{{< /formula >}}

где $h_i$ — конвективный коэффициент со стороны воздуха в воздуховоде, Вт/(м²·К); $d$ — толщина изоляции, м; $\lambda$ — теплопроводность полиизоцианурата, Вт/(м·К); $h_e$ — конвективный коэффициент снаружи воздуховода, Вт/(м²·К).

Для круглого воздуховода (трубопровода) тепловой поток на единицу длины:

{{< formula display="true" >}}
q_L = \frac{2\pi\,(T_i - T_e)}{\dfrac{\ln(r_2/r_1)}{\lambda} + \dfrac{1}{h_e \cdot r_2}}
{{< /formula >}}

### Числовой пример

**Задача.** Прямоугольный воздуховод подачи охлаждённого воздуха: температура воздуха в канале $T_i = 8$ °C, температура помещения $T_e = 24$ °C. Изоляция из полиизоцианурата с алюминиевой облицовкой: $d = 25$ мм, $\lambda = 0{,}025$ Вт/(м·К). Конвективные коэффициенты: $h_i = 15$ Вт/(м²·К) (вынужденная конвекция), $h_e = 8$ Вт/(м²·К) (естественная конвекция). Определить тепловой поток $q$ и проверить температуру наружной поверхности для оценки риска конденсации.

**Решение:**

Суммарное тепловое сопротивление (на м² поверхности воздуховода):

$$R_{\text{total}} = \frac{1}{h_i} + \frac{d}{\lambda} + \frac{1}{h_e} = \frac{1}{15} + \frac{0{,}025}{0{,}025} + \frac{1}{8}$$

$$R_{\text{total}} = 0{,}067 + 1{,}000 + 0{,}125 = 1{,}192 \text{ м}^2\text{·К/Вт}$$

$$q = \frac{T_i - T_e}{R_{\text{total}}} = \frac{8 - 24}{1{,}192} = -13{,}4 \text{ Вт/м}^2$$

(отрицательный знак означает поступление тепла в воздуховод; абсолютная величина $|q| = 13{,}4$ Вт/м²).

Температура наружной поверхности изоляции:

$$T_{\text{нар}} = T_e - \frac{|q|}{h_e} = 24 - \frac{13{,}4}{8} = 24 - 1{,}7 = 22{,}3 \text{ °C}$$

При относительной влажности помещения 60 % точка росы составляет приблизительно 15,1 °C (ASHRAE Psychrometrics). Поскольку $T_{\text{нар}} = 22{,}3\text{ °C} > 15{,}1\text{ °C}$, конденсация на поверхности изоляции не возникает. Изоляция 25 мм обеспечивает достаточную защиту при данных условиях.

## Применение в системах ОВК

### Теплоизоляция воздуховодов

Полиизоцианурат применяется как в виде плит для наружного оборачивания жёстких воздуховодов из оцинкованной стали (galvanized steel ductwork), так и в виде двустороннего сэндвич-панельного воздуховода (pre-insulated ductwork). Нормы ASHRAE 90.1 устанавливают минимальное тепловое сопротивление изоляции воздуховодов в зависимости от климатической зоны и расположения (в кондиционируемом/некондиционируемом пространстве).

### Теплоизоляция трубопроводов

Используется для изоляции трубопроводов охлаждённой воды (chilled water), конденсата холодильных установок и теплоносителей со средними температурами (−40…+120 °C). Алюминиевая облицовка обязательна для трубопроводов при отрицательных температурах.

### Криогенные системы

При температурах ниже −40 °C применяют многослойные конструкции: полиизоцианурат + пенопластовый вкладыш (polystyrene) + вакуумный слой для сверхнизких температур. Полиизоцианурат сохраняет замкнутую структуру пор до −196 °C, однако становится хрупким и требует дополнительного механического крепежа.

**Учёт старения при проектировании.** Используйте LTTR-значение ($\lambda = 0{,}025{-}0{,}026$ Вт/(м·К)) вместо начального для расчётов срока службы более 5 лет. Запас по толщине 10–15 % нивелирует неопределённость в условиях монтажа.

**Транспортировка и хранение.** Прямое солнечное облучение деградирует полиуретановую матрицу; плиты хранят в укрытии. Механические повреждения (вмятины, трещины) нарушают замкнутость пор и увеличивают теплопроводность на повреждённом участке.

**Совместимость с хладагентами.** Полиизоцианурат совместим с хладагентами R-410A, R-134a, R-32 и гидрофторолефинами по ANSI/ASHRAE 34; не взаимодействует с аммиаком NH₃ в концентрациях до 30 % масс.
