Гидравлическая сеть — совокупность связанных трубопроводов, по которым теплоноситель или воздух распределяется от источника (насоса, вентилятора) к нескольким потребителям и возвращается обратно. Сложность анализа заключается в нелинейности: потеря давления на каждом участке пропорциональна квадрату расхода, поэтому расходы во всех ветвях взаимозависимы и должны определяться совместным решением системы уравнений. Ошибка в расчёте сети — прямая причина разбалансировки системы, перегрева и недогрева помещений или несоответствия воздухообмена проектным значениям.

## Законы Кирхгофа для гидравлических сетей

Гидравлические сети подчиняются двум законам, аналогичным электрическим цепям.

**Первый закон (баланс расходов в узле).** Для каждого узла сети алгебраическая сумма расходов равна нулю:

{{< formula display="true" >}}
\sum_{i} Q_i = 0
{{< /formula >}}

Входящие расходы берутся со знаком «+», исходящие — со знаком «–». Закон следует из уравнения неразрывности для несжимаемой жидкости.

**Второй закон (баланс давлений в контуре).** Для любого замкнутого контура алгебраическая сумма потерь давления равна нулю:

{{< formula display="true" >}}
\sum_{i \in \text{контур}} \Delta P_i = 0
{{< /formula >}}

При обходе контура против направления тока потери берутся с отрицательным знаком. Этот закон следует из того, что давление — однозначная функция координаты, и суммарное изменение давления вдоль замкнутого пути равно нулю.

Сопротивление каждого участка связывает давление с расходом квадратичной зависимостью:

{{< formula display="true" >}}
\Delta P = R \cdot Q^2, \quad R = \frac{\lambda L}{D} \cdot \frac{\rho}{2 A^2} + \frac{\sum K_j \cdot \rho}{2 A^2}
{{< /formula >}}

где `A = πD²/4` — площадь поперечного сечения, м². Гидравлическое сопротивление R, Па/(м³/с)², полностью определяет участок и не зависит от расхода при турбулентном режиме (формула Шези). При ламинарном течении ΔP ~ Q, и уравнения перестают быть квадратичными — это отдельный расчётный случай.

**Последовательное соединение участков.** Суммарное сопротивление — сумма сопротивлений при одном расходе:

{{< formula display="true" >}}
R_\text{посл} = R_1 + R_2 + \dots + R_n
{{< /formula >}}

**Параллельное соединение ветвей.** Перепад давления на параллельных ветвях одинаков; расходы делятся обратно пропорционально корню из сопротивления:

{{< formula display="true" >}}
\frac{Q_1}{Q_2} = \sqrt{\frac{R_2}{R_1}}
{{< /formula >}}

Суммарное сопротивление параллельного блока:

{{< formula display="true" >}}
\frac{1}{\sqrt{R_\text{пар}}} = \sum_{i=1}^{n} \frac{1}{\sqrt{R_i}}
{{< /formula >}}

Эти соотношения задают «естественное» распределение расходов без балансировки. Если сопротивления ветвей неодинаковы (что всегда так в реальной системе), расходы будут разными, и для нормирования необходима балансировочная арматура.

## Метод Харди–Кросса

Итерационный метод, разработанный Харди Кроссом (1936), остаётся стандартным ручным методом для кольцевых сетей.

**Алгоритм:**

1. Выделить независимые контуры; число независимых контуров: `L = E − N + 1`, где E — число ветвей, N — число узлов.
2. Задать начальное приближение расходов Q⁽⁰⁾, удовлетворяющее первому закону Кирхгофа.
3. Для каждого контура вычислить невязку:

{{< formula display="true" >}}
\varepsilon = \sum_{i \in \text{контур}} R_i Q_i |Q_i|
{{< /formula >}}

(знак учитывает направление обхода, квадратичная форма с модулем обеспечивает правильный знак при любом направлении потока).

4. Вычислить поправку расхода для контура:

{{< formula display="true" >}}
\delta Q = -\frac{\varepsilon}{2 \sum_{i \in \text{контур}} R_i |Q_i|}
{{< /formula >}}

5. Обновить расходы: `Q⁽ᵏ⁺¹⁾ = Q⁽ᵏ⁾ + δQ`. Для ветвей, принадлежащих двум контурам, добавляются поправки от обоих.
6. Повторять до |ε| < ε_доп (обычно 1 Па для трубопроводов, 0,1 Па для воздуховодов).

Метод сходится квадратично; 5–10 итераций достаточно для практических задач.

## Метод узловых давлений (Newton–Raphson)

Современные программные комплексы (Revit MEP, HAP, IDA ICE) используют метод узловых давлений. Неизвестные — давления в узлах P_j. Для каждого узла записывается уравнение баланса расходов:

{{< formula display="true" >}}
\sum_i \text{sign}(P_j - P_i)\sqrt{\frac{|P_j - P_i|}{R_{ij}}} = Q_{j,\text{внеш}}
{{< /formula >}}

Якобиан системы строится аналитически; при Newton–Raphson сходимость за 3–5 итераций. Метод допускает насосы с произвольной характеристикой, предохранительные клапаны и другие нелинейные элементы.

## Гидравлическая балансировка

### Необходимость балансировки

В разбалансированной системе поток идёт по пути наименьшего сопротивления — ближайший к насосу прибор получает избыток теплоносителя, дальние — недостаток. Дисбаланс 30–40 % расхода характерен для систем без балансировки даже при одинаковых приборах. Последствия: невыполнение тепловой нагрузки, шум в арматуре, повышенный расход тепловой энергии.

### Авторитет регулирующего клапана

Ключевой параметр — авторитет клапана `a`:

{{< formula display="true" >}}
a = \frac{\Delta P_{\text{кл,min}}}{\Delta P_{\text{кл,min}} + \Delta P_{\text{кольца}}}
{{< /formula >}}

где `ΔP_кл,min` — перепад давления на клапане при полном открытии, `ΔP_кольца` — суммарные потери в кольце без клапана. При `a < 0,25` характеристика клапана вырождается: регулировочный эффект стремится к нулевому, кривая расхода от хода шпинделя становится прямолинейной вместо логарифмической. СП 60.13330.2020 и ASHRAE HF рекомендуют `a ≥ 0,25–0,50` для трёхходовых клапанов и `a ≥ 0,50` для двухходовых.

### Типы балансировочной арматуры

| Тип арматуры | Функция | Особенности | Применение |
|---|---|---|---|
| Ручной балансировочный клапан (RBV) | Фиксированное сопротивление | Требует измерения расхода при наладке | Статическая балансировка стояков |
| Автоматический регулятор расхода (PICV) | Постоянный расход при переменном давлении | Диапазон авторитета ≥ 15 кПа перепада | Системы ВРН, фанкойлы |

| Регулятор перепада давления насоса | ΔP на насосе = const | Снижает уровень шума и потребление | Центральный тепловой пункт |

## Числовой пример: двухконтурная кольцевая сеть

**Условие.** Система отопления с двумя параллельными ветвями и общей подающей и обратной магистралью. Требуемые расходы: ветвь 1 — Q₁ = 1,2 м³/ч, ветвь 2 — Q₂ = 0,8 м³/ч. Гидравлические сопротивления (без балансировочных клапанов): R₁ = 18,0 кПа/(м³/ч)², R₂ = 8,0 кПа/(м³/ч)². Перепад давления насоса ΔP_н = 40 кПа.

**Шаг 1. Естественное распределение без балансировки.**

При параллельном подключении обе ветви имеют одинаковый перепад давления ΔP_ветви. Найдём его из условия: суммарный расход = 2,0 м³/ч.

{{< formula display="true" >}}
Q_1^0 = \sqrt{\frac{\Delta P}{R_1}}, \quad Q_2^0 = \sqrt{\frac{\Delta P}{R_2}}
{{< /formula >}}

{{< formula display="true" >}}
Q_1^0 + Q_2^0 = \sqrt{\Delta P}\left(\frac{1}{\sqrt{18{,}0}} + \frac{1}{\sqrt{8{,}0}}\right) = \sqrt{\Delta P} \cdot (0{,}236 + 0{,}354) = 2{,}0
{{< /formula >}}

{{< formula display="true" >}}
\sqrt{\Delta P} = \frac{2{,}0}{0{,}590} = 3{,}39 \Rightarrow \Delta P = 11{,}5 \text{ кПа}
{{< /formula >}}

{{< formula display="true" >}}
Q_1^0 = 3{,}39 \cdot 0{,}236 = 0{,}80 \text{ м}^3/\text{ч}, \quad Q_2^0 = 3{,}39 \cdot 0{,}354 = 1{,}20 \text{ м}^3/\text{ч}
{{< /formula >}}

Без балансировки расходы **перевёрнуты**: ветвь с меньшим сопротивлением (2) получает больше теплоносителя, ветвь с большим сопротивлением (1) — меньше. Ветвь 1 недополучает 1,2 − 0,8 = **0,4 м³/ч** (33 % дефицит).

**Шаг 2. Балансировка ветви 2.**

Для выравнивания расходов в соответствии с проектом необходимо добавить сопротивление в ветвь 2. Требуемый перепад давления на ветви 1 при Q₁ = 1,2 м³/ч:

{{< formula display="true" >}}
\Delta P_1 = R_1 \cdot Q_1^2 = 18{,}0 \cdot 1{,}44 = 25{,}9 \text{ кПа}
{{< /formula >}}

Перепад давления на ветви 2 должен быть тем же: 25,9 кПа. Естественные потери ветви 2 при Q₂ = 0,8 м³/ч:

{{< formula display="true" >}}
\Delta P_{2,\text{ест}} = R_2 \cdot Q_2^2 = 8{,}0 \cdot 0{,}64 = 5{,}1 \text{ кПа}
{{< /formula >}}

Требуемое сопротивление балансировочного клапана:

{{< formula display="true" >}}
\Delta P_{\text{кл}} = 25{,}9 - 5{,}1 = 20{,}8 \text{ кПа при } Q_2 = 0{,}8 \text{ м}^3/\text{ч}
{{< /formula >}}

{{< formula display="true" >}}
K_{vs} = \frac{Q_2}{\sqrt{\Delta P_{\text{кл}}/100}} = \frac{0{,}8}{\sqrt{20{,}8/100}} = \frac{0{,}8}{0{,}456} = 1{,}75 \text{ м}^3/\text{ч}
{{< /formula >}}

(K_vs — пропускная способность клапана при ΔP = 100 кПа; единицы по EN 60534 / ГОСТ Р ИСО 6358). Выбирается ближайший стандартный балансировочный клапан с K_vs = 2,0 м³/ч, который при необходимом расходе устанавливается в положение, обеспечивающее ΔP = 20,8 кПа.

**Шаг 3. Проверка авторитета клапана.**

{{< formula display="true" >}}
a = \frac{20{,}8}{20{,}8 + 5{,}1} = \frac{20{,}8}{25{,}9} = 0{,}80
{{< /formula >}}

Авторитет 0,80 — отличный результат, регулировочная характеристика не деградирует.

## Динамическое поведение: системы с переменным расходом

В современных системах с частотным регулированием насосов и двухходовыми клапанами на приборах расход постоянно меняется. При закрытии одной ветви перепад давления перераспределяется по оставшимся открытым ветвям, изменяя их расходы. Это требует применения автоматических регуляторов расхода (PICV) или дифференциальных регуляторов давления.

Характеристика PICV (pressure-independent control valve) компенсирует изменение перепада давления в диапазоне, например, 20–150 кПа, поддерживая постоянный расход с точностью ±5 %. Критерий выбора — максимальный рабочий расход должен соответствовать настройке клапана в диапазоне 40–80 % хода для сохранения регулировочного ресурса.

## Практические вопросы проектирования

**Выбор расчётного контура.** Расчётный (определяющий) контур — путь с наибольшим суммарным сопротивлением. Насос подбирается по суммарным потерям этого контура. Все остальные контуры должны быть забалансированы дополнительным сопротивлением.

**Попутная и тупиковая схемы разводки.** Попутная (Тихельмана) схема обеспечивает одинаковую суммарную длину пути для всех приборов, что упрощает балансировку. Тупиковая схема экономнее по металлоёмкости, но требует более точной балансировки. СП 60.13330.2020 п. 6.4.6 допускает тупиковую схему при установке регуляторов расхода на каждом приборе.

**Кольцевание насосных групп.** При нескольких насосами (рабочий + резервный) необходимо предусмотреть обратные клапаны или автоматические клапаны-отсекатели для исключения байпасного перетока через отключённый насос. Байпасный переток через остановленный насос в обратном направлении создаёт потерю давления, соответствующую полному сопротивлению насоса.

**Воздухоудаление.** В разветвлённых сетях мёртвые зоны (верхние точки ответвлений, петли без принудительной циркуляции) накапливают воздух. Проектирование должно предусматривать автоматические воздухоотводчики или ручные кран-вантузы во всех верхних точках; уклон трубопровода не менее 0,002 в направлении движения для попутного удаления воздуха (требование СП 60.13330.2020 п. 6.5.4).

**Давление в системе.** Статическое давление заполнения должно обеспечивать положительное избыточное давление не менее 0,05 МПа во всех точках сети при работающей системе. На высших этажах многоэтажных систем проверяется условие: P_min = P_статич − ΔP_динам > 50 кПа. Расширительный бак рассчитывается по объёму воды в системе и коэффициенту теплового расширения.
