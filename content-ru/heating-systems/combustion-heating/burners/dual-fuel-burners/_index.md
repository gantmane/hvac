Двухтопливные горелки (dual-fuel burners) обеспечивают эксплуатационную гибкость: сжигание природного газа или дизельного топлива № 2 без замены горелки. Это позволяет оптимизировать затраты на топливо, поддерживать надёжность теплоснабжения при прекращении подачи газа и создавать резервную мощность. Современные двухтопливные системы достигают сравнимой производительности на обоих видах топлива: термический КПД 80–88 %, выбросы NOx 40–120 ppm в зависимости от топлива и конфигурации, диапазон регулирования (turndown ratio) 4:1–10:1. Нормативная база: ASHRAE Handbook — HVAC Systems and Equipment, EN 303, NFPA 86, СП 60.13330.

## Сравнение свойств топлива

{{< table title="Критические параметры природного газа и дизельного топлива № 2" >}}
| Параметр | Природный газ | Дизельное топливо № 2 | Влияние на конструкцию |
|---|---|---|---|
| Физическое состояние | Газ | Жидкость | Масло требует системы распыления |
| HHV | 37,3 МДж/м³ | 38,6 МДж/л | Разные скорости подачи топлива |
| Стехиометрический воздух $A_s$ | 9,52 м³/м³ | 14,6 м³/л | Разные потребности в воздухе |
| Адиабатическая температура пламени | 1 982 °C | 2 066 °C | Масляное пламя чуть горячее |
| Тип пламени | Предварительно смешанное / диффузионное | Диффузионное | Разная геометрия пламени |
| Температура воспламенения | 649 °C | 260 °C | Разные требования к зажиганию |
| Светимость пламени | Низкая (синее) | Высокая (жёлто-оранжевое) | Разные доли радиационного теплообмена |
{{< /table >}}

### Расчёт разницы в потребности воздуха

Для тепловой нагрузки 10 ГДж/ч:

**Природный газ ($EA = 15\,\%$):**

{{< formula display="true" >}}
\dot{V}_{\text{газ}} = \frac{10 \times 10^9}{37{,}3 \times 10^6} = 268\;\frac{\text{м}^3}{\text{ч}}
\qquad
\dot{V}_{\text{воздух,газ}} = 268 \times 9{,}52 \times 1{,}15 = 2\,937\;\frac{\text{м}^3}{\text{ч}}
{{< /formula >}}

**Дизельное топливо № 2 ($EA = 20\,\%$):**

{{< formula display="true" >}}
\dot{V}_{\text{масло}} = \frac{10 \times 10^9}{38{,}6 \times 10^6} = 259\;\frac{\text{л}}{\text{ч}}
\qquad
\dot{V}_{\text{воздух,масло}} = 259 \times 14{,}6 \times 1{,}20 = 4\,537\;\frac{\text{м}^3}{\text{ч}}
{{< /formula >}}

Масло требует примерно на 55 % больше воздуха при том же тепловом вводе — это определяет принцип выбора вентилятора: по масляному режиму.

## Конструкция комбинированной горелки

### Интеграция распыления масла и подачи газа

**Концентрическая кольцевая конструкция (concentric ring design):**
- Масляная форсунка (oil nozzle) расположена по оси горелки.
- Газовые сопла (gas spuds) концентрическим кольцом вокруг форсунки.
- Газовый коллектор (gas manifold) с отдельными отверстиями.
- Каждая топливная система независима — минимальное взаимовлияние при переключении.

**Схема распыления масла:**
- Форсунка с распылением под давлением (pressure-atomizing nozzle): 690–2 070 кПа.
- Схема полого конуса (hollow cone): угол 60–80°.
- Средний диаметр Зотера (Sauter mean diameter, SMD): 40–80 мкм для дизельного № 2.

### Воздушная система

Один вентилятор подаёт воздух для обоих топлив; конструкция рассчитывается на более высокую потребность — масляный режим:

- Газовый дроссель воздуха (gas air damper): оптимизирован под $EA_{\text{газ}} = 10\text{–}20\,\%$.
- Масляный дроссель воздуха (oil air damper): оптимизирован под $EA_{\text{масло}} = 15\text{–}25\,\%$.
- Переключение выбором режима: привод переводит соответствующий дроссель в рабочее положение.
- Давление воздуха горения: 50–100 Па (газ), 100–150 Па (масло).

### Система зажигания

**Газовый режим:** пилотная горелка с искровым зажиганием → УФ-сканер подтверждает пилот → открывается основной газовый клапан.

**Масляный режим:** высоковольтная искра 10 000 В → воспламенение периферии масляного факела → УФ-сканер подтверждает пламя.

Рекомендуемый детектор пламени для обоих топлив — **УФ-сканер** (надёжно работает с газовым и масляным пламенем). Ионизационный электрод — только газ.

## Автоматическое переключение топлива

### Последовательность переключения газ → масло

```
1. Сигнал переключения (низкое давление газа / ручной выбор / расписание)
2. Закрытие основного газового клапана
3. Продувка горелки воздухом (15–30 с)
4. Подтверждение отсутствия пламени (сканер)
5. Включение масляного насоса → набор давления 690–2 070 кПа
6. Позиционирование масляного дросселя воздуха
7. Предварительная продувка (15–30 с)
8. Активация искры; открытие масляного клапана (10–15 с)
9. Подтверждение пламени УФ-сканером
10. Разгон до рабочей нагрузки
─────────────────────────────────────
Общее время переключения: 60–120 с
```

### Последовательность переключения масло → газ

```
1. Сигнал переключения (восстановление газа / оптимизация цены / ручной)
2. Закрытие масляного клапана
3. Расширенная продувка (30–60 с — для очистки масляных паров)
4. Отключение масляного насоса
5. Проверка давления газа
6. Позиционирование газового дросселя
7. Зажигание пилота → подтверждение
8. Открытие основного газового клапана → установление пламени
9. Разгон до рабочей нагрузки
```

### Логика блокировок безопасности

1. **Исключение топлива:** одновременная подача двух топлив невозможна (если не предусмотрено одновременное сжигание).
2. **Принудительная продувка:** между переключениями — полная продувка.
3. **Проверка давления:** достаточное давление топлива перед попыткой зажигания.
4. **Детектирование пламени:** правильный сканер активен для текущего топлива.
5. **Проверка воздуха:** правильное положение дросселя для режима топлива.

## Одновременное сжигание (simultaneous firing)

Некоторые установки сжигают оба топлива одновременно — пиковое усиление, утилизация отходящего масла:

{{< formula display="true" >}}
Q_{\text{суммарный}} = Q_{\text{газ}} + Q_{\text{масло}}
\qquad
\dot{m}_{\text{воздух,суммарный}} = \dot{m}_{\text{воздух,газ}} + \dot{m}_{\text{воздух,масло}}
{{< /formula >}}

Воздушная система рассчитывается на максимальный суммарный расход. Управление соотношением воздух-топливо для каждого контура — независимое.

## Характеристики производительности

### КПД по видам топлива

{{< table title="КПД и выбросы двухтопливной горелки" >}}
| Параметр | Газовый режим | Масляный режим |
|---|---|---|
| Термический КПД | 82–88 % | 80–85 % |
| Избыточный воздух (EA) | 10–20 % | 15–25 % |
| Температура уходящих газов | 149–232 °C | 176–260 °C |
| NOx (стандартная горелка) | 30–60 ppm | 80–150 ppm |
| NOx (с FGR) | 9–30 ppm | 50–100 ppm |
| CO | < 50 ppm | 50–150 ppm |
| SO₂ | 0 | 10–50 ppm |
| Диапазон регулирования | 5:1–10:1 | 3:1–6:1 |
{{< /table >}}

Разница КПД: газовый режим обычно на 2–4 % эффективнее масляного на той же горелке.

## Методология проектирования и подбора размеров

### Шаг 1. Определение тепловой мощности

{{< formula display="true" >}}
Q_{\text{горелка}} = \frac{Q_{\text{нагрузка}}}{\eta_{\text{котла}}} \times SF
{{< /formula >}}

$SF = 1{,}15$–$1{,}25$.

### Шаг 2. Расходы топлива

**Газовый режим** ($HHV = 37{,}3$ МДж/м³, $\eta_{\text{газ}} = 0{,}85$):

{{< formula display="true" >}}
\dot{V}_{\text{газ}} = \frac{Q_{\text{горелка}}}{37{,}3 \times 0{,}85} = \frac{Q}{31{,}7}\;\frac{\text{м}^3}{\text{ч}}
{{< /formula >}}

**Масляный режим** ($HHV = 38{,}6$ МДж/л, $\eta_{\text{масло}} = 0{,}82$):

{{< formula display="true" >}}
\dot{V}_{\text{масло}} = \frac{Q_{\text{горелка}}}{38{,}6 \times 0{,}82} = \frac{Q}{31{,}6}\;\frac{\text{л}}{\text{ч}}
{{< /formula >}}

### Шаг 3. Подбор воздушной системы

**Требование воздуха — газ** ($EA = 15\,\%$):

{{< formula display="true" >}}
\dot{V}_{\text{воздух,газ}} = \dot{V}_{\text{газ}} \times 9{,}52 \times 1{,}15 = \dot{V}_{\text{газ}} \times 10{,}95
{{< /formula >}}

**Требование воздуха — масло** ($EA = 20\,\%$):

{{< formula display="true" >}}
\dot{V}_{\text{воздух,масло}} = \dot{V}_{\text{масло}} \times 14{,}6 \times 1{,}20 = \dot{V}_{\text{масло}} \times 17{,}52
{{< /formula >}}

Вентилятор подбирается по максимальному требованию (масляный режим) при требуемом статическом давлении.

## Экономический анализ

### Стоимость энергии на ГДж

{{< formula display="true" >}}
C_{\text{газ}} = P_{\text{газ}}\;\text{[\$/ГДж]}
\qquad
C_{\text{масло}} = P_{\text{масло}} \times 25{,}9\;\text{[\$/ГДж, при HHV = 38,6 МДж/л]}
{{< /formula >}}

**Пример.** Газ: 8,00 $/ГДж; дизельное топливо: 0,79 $/л.

{{< formula display="true" >}}
C_{\text{масло}} = 0{,}79 \times 25{,}9 = 20{,}46\;\text{\$/ГДж}
{{< /formula >}}

Газ существенно дешевле. Порог переключения на масло с учётом разницы КПД:

{{< formula display="true" >}}
P_{\text{масло,безубыточность}} = P_{\text{газ}} \times \frac{HHV_{\text{масло}}}{HHV_{\text{газ}}} \times \frac{\eta_{\text{масло}}}{\eta_{\text{газ}}} = 8{,}00 \times \frac{38{,}6}{37{,}3} \times \frac{0{,}82}{0{,}85} \approx 7{,}97\;\text{\$/ГДж}
{{< /formula >}}

Масло конкурентоспособно при цене $\leq 0{,}31$ $/л.

## Критерии выбора

**Двухтопливная горелка целесообразна, когда:**
1. Надёжность подачи топлива критична (перебойная подача газа, критический технологический процесс).
2. Волатильность цен на топливо создаёт возможность экономии (сезонные различия > 20 %).
3. Нормативы выбросов допускают масло для аварийного использования.

**Однотопливная горелка предпочтительна, когда:**
1. Подача газа надёжна; цена топлива стабильна.
2. Нормативы по выбросам требуют газа во всех режимах.
3. Бюджет капитала ограничен (двухтопливные горелки на 40–80 % дороже однотопливных).
4. Ресурсы технического обслуживания ограничены (двухтопливная система сложнее).

**Диапазон мощности двухтопливных горелок:** 0,5–100 ГДж/ч (коммерческие и промышленные приложения).
