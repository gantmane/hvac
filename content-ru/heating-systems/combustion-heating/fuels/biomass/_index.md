Биомасса — органическое топливо растительного или животного происхождения, включающее древесные пеллеты, щепу, солому, сельскохозяйственные отходы и торф. В системах HVAC биомасса применяется в котлах прямого сгорания мощностью от 5 кВт до нескольких МВт. Ключевые достоинства: возобновляемость, углеродная нейтральность при надлежащем лесопользовании, локальная доступность в регионах с развитой деревопереработкой. Недостатки: более низкая энергетическая плотность по сравнению с ископаемыми топливами, требовательность к хранению, чувствительность к влажности. Нормативная база: ISO 17225 (серия), ГОСТ Р 56296-2014, ГОСТ Р 54597-2011, СП 89.13330.2016, Директива ЕС 2009/28/EC.

## Теплотворная способность биомассы

### Высшая и низшая теплотворная способность

**Высшая теплотворная способность (ВТС, $H_s$):** включает теплоту конденсации водяного пара в продуктах сгорания. Определяется в калориметрической бомбе согласно ISO 1928.

**Низшая теплотворная способность (НТС, $H_i$):** практически полезная энергия при условиях эксплуатации, когда водяной пар не конденсируется. Связь с ВТС:

{{< formula display="true" >}}
H_i = H_s - 2{,}44 \cdot \left(9 \cdot h + m_w\right)
{{< /formula >}}

где $h$ — содержание водорода в сухом веществе (доля); $m_w$ — влагосодержание, кг H₂O/кг сухого вещества; коэффициент 2,44 — теплота испарения воды при 25 °C, МДж/кг.

При влажности биомассы 10–30 % НТС составляет 12–18 МДж/кг. Каждый дополнительный процент влаги снижает НТС приблизительно на 0,2–0,3 МДж/кг.

### Тепловой выход котла на биомассе

Тепловой поток при сжигании:

{{< formula display="true" >}}
Q = \dot{m}_{\text{топлива}} \cdot H_i \cdot \eta_{\text{котла}}
{{< /formula >}}

где $Q$ — тепловая мощность, Вт; $\dot{m}_{\text{топлива}}$ — расход топлива, кг/с; $\eta_{\text{котла}}$ — КПД котла.

**Пример расчёта.** Котёл мощностью 20 кВт на пеллетах класса A2 ($H_i = 16{,}5$ МДж/кг, $\eta = 0{,}90$):

{{< formula display="true" >}}
\dot{m} = \frac{Q}{H_i \cdot \eta} = \frac{20 \times 3\,600}{16{,}5 \times 10^6 \times 0{,}90} = 4{,}85\,\text{кг/ч}
{{< /formula >}}

За отопительный сезон (2 000 ч): ~ 9,7 т пеллет.

## Древесные пеллеты

Стандартизованное топливо из прессованных высушенных опилок и стружки без связующих (роль связующего выполняет лигнин). Согласно ISO 17225-2 и ГОСТ Р 56296-2014 пеллеты подразделяют на классы:

{{< table title="Классификация древесных пеллет по ISO 17225-2" >}}
| Класс | Влажность, % | НТС, МДж/кг | Зола, % | Механическая прочность, % |
|---|---|---|---|---|
| A1 (премиум) | ≤ 8,0 | ≥ 17,5 | ≤ 0,5 | ≥ 97,5 |
| A2 | ≤ 8,0 | ≥ 16,5 | ≤ 1,0 | ≥ 97,5 |
| B | ≤ 10,0 | ≥ 15,5 | ≤ 2,0 | ≥ 97,5 |
| C | ≤ 12,0 | ≥ 14,5 | ≤ 3,0 | ≥ 97,0 |
{{< /table >}}

Типовые размеры: диаметр 6–8 мм, длина 10–25 мм. Насыпная плотность (bulk density): 600–800 кг/м³.

Пеллеты класса A1 применяют в жилых автоматических котлах мощностью 5–30 кВт. Классы A2 и B пригодны для коммерческих объектов. Класс C допустим в крупных промышленных котлах при наличии систем очистки дымовых газов.

## Древесная щепа

Неоднородный материал с фракцией 3–100 мм, получаемый механическим измельчением древесины. Применяется в крупных системах теплоснабжения с автоматизированными системами подачи топлива.

По ISO 17225-4 щепу классифицируют по размеру (P16–P100), влажности и зольности. Типовые характеристики:

- Влажность: 15–50 % (существенно влияет на качество горения)
- НТС при 30 % влажности: 10–16 МДж/кг
- Насыпная плотность: 200–400 кг/м³ в зависимости от фракции

Достоинства: низкая стоимость, широкая доступность в лесопромышленных регионах. Недостатки: нестабильность влажности, риск самовозгорания при неправильном хранении, более высокий зольный остаток.

## Сельскохозяйственные отходы

Солома, шелуха подсолнечника, костра льна и аналогичные материалы используются преимущественно в регионах их производства.

{{< table title="Характеристики сельскохозяйственных видов биомассы" >}}
| Вид биомассы | НТС, МДж/кг (при ~15 % влажности) | Зола, % | Особенности |
|---|---|---|---|
| Солома (straw) | 13–16 | 5–8 | Высокое содержание K и Cl, риск шлакообразования |
| Костра льна (flax shives) | 14–16 | 2–4 | Однородный состав |
| Шелуха подсолнечника | 17–19 | 4–6 | Высокая теплотворность, доступность на юге |
{{< /table >}}

Для сельскохозяйственных отходов требуются решётчатые колосниковые системы с механическим золоудалением и циклоны. Регулируется ГОСТ Р 54597-2011 (твёрдое биотопливо, требования к качеству).

## Влажность и её влияние на КПД

Влажность биомассы — наиболее критический эксплуатационный параметр. При превышении нормативного уровня КПД снижается:

{{< formula display="true" >}}
\eta = \eta_0 - k \cdot (w_{\text{факт}} - w_{\text{норм}})
{{< /formula >}}

где $\eta_0$ — номинальный КПД при нормативной влажности; $k \approx 1{-}2\,\%$ на каждый процент превышения.

{{< table title="Влияние влажности на характеристики горения" >}}
| Уровень влажности | Влияние на горение |
|---|---|
| Оптимум: 8–15 % (пеллеты), 20–30 % (щепа) | Стабильное горение, максимальный КПД |
| Повышенная: 30–40 % | Снижение температуры горения, рост выбросов CO |
| Критически высокая: > 40 % | Затруднённое воспламенение, температура горения ниже 800 °C |
| Пересушенная: < 5 % | Повышенная хрупкость, пылеобразование, риск взрывного горения |
{{< /table >}}

Сушка биомассы требует 0,5–1,5 МДж/кг испарённой воды. При естественной сушке продолжительность составляет 6–12 месяцев в зависимости от климата и условий хранения.

## Насыпная плотность и проектирование складской системы

Насыпная плотность $\rho_b$ определяет объём складских помещений и производительность топливоподающих систем:

{{< formula display="true" >}}
\rho_b = \frac{m_{\text{топлива}}}{V_{\text{контейнера}}}
{{< /formula >}}

{{< table title="Насыпная плотность видов биомассы" >}}
| Вид топлива | Насыпная плотность, кг/м³ |
|---|---|
| Пеллеты (pellets) | 600–800 |
| Щепа 10–30 мм (woodchips) | 200–350 |
| Щепа 30–100 мм | 150–250 |
| Солома прессованная (baled straw) | 100–150 |
{{< /table >}}

При проектировании бункеров добавляют 10–15 % запас объёма для обеспечения свободного хода топлива и исключения мостообразования (bridging) над выпускным отверстием.

**Пример проектирования склада.** Котёл 100 кВт на щепе ($H_i = 13$ МДж/кг, $\eta = 0{,}85$) при 2 000 ч отопительного сезона:

$$\dot{m}_{\text{сезон}} = \frac{100 \times 3\,600 \times 2\,000}{13 \times 10^6 \times 0{,}85} = 64{,}9\,\text{т}$$

При насыпной плотности 280 кг/м³ запас щепы на сезон: 64 900 / 280 ≈ 232 м³. Рекомендуется двойной запас (2 сезона) — около 460 м³.

## Системы подачи топлива

    A[Склад биомассы] --> B[Шнековый транспортёр]
    B --> C[Промежуточный бункер]
    C --> D[Дозирующий шнек]
    D --> E[Котёл / горелка]
    E --> F[Теплообменник]
    E --> G[Система золоудаления]
    E --> H[Очистка дымовых газов]
    H --> I[Дымоход]

Шнековые конвейеры (auger conveyors) применяются для пеллет и мелкой щепы. Гидравлические толкатели (hydraulic rams) используют в системах с крупной щепой и соломой. Для пеллет минимальный радиус поворота шнека — не менее 200 мм во избежание разрушения гранул.

## Применение в системах HVAC

Биомасса применяется в котельных мощностью 5–500 кВт:

- Частные жилые дома: пеллетные котлы 5–30 кВт, автоматическая шнековая подача, еженедельное обслуживание (чистка).
- Административные здания, школы: котлы на щепе 50–200 кВт, суточный бункер, автоматическое золоудаление.
- Животноводческие комплексы: котлы на соломе или навозе 100–500 кВт, решётчатые колосники.

Биомасса часто интегрируется в гибридные системы с природным газом или тепловыми насосами для обеспечения пиковой нагрузки. BREEAM и LEED требуют минимум 10–20 % доли возобновляемых источников — биомасса является одним из наиболее доступных решений для Центральной и Северной России.

## Выбросы при сжигании биомассы

{{< table title="Типовые удельные выбросы при сжигании биомассы (кг/ГДж)" >}}
| Загрязняющее вещество | Пеллеты A1 | Щепа (30 % влаж.) | Солома |
|---|---|---|---|
| CO₂ (биогенный) | ~ 0 (нейтральный) | ~ 0 | ~ 0 |
| CO | 0,5–2 | 5–20 | 10–30 |
| NOx | 0,05–0,15 | 0,1–0,3 | 0,2–0,5 |

Для котлов > 1 МВт обязательна система очистки дымовых газов (циклон или рукавный фильтр) в соответствии с Директивой ЕС 2015/2193 и ГОСТ Р 54826-2011.

## Практические рекомендации

1. **Хранение:** в закрытых сухих помещениях с относительной влажностью воздуха 60–70 %, исключить контакт с грунтом; настилы из поддонов или бетонный пол.
2. **Предварительная подготовка:** просеивание щепы для удаления посторонних предметов; контроль размерной фракции перед засыпкой в бункер.
3. **Выбор класса:** для автоматических котлов — не ниже класса B по ISO 17225-2; для крупных систем с очисткой дымовых газов допустим класс C.
4. **Контроль влажности:** портативный влагомер перед каждой загрузкой; целевое значение ≤ 12 % для пеллет, ≤ 35 % для щепы.
5. **Резервирование топлива:** запас не менее 1,5–2 отопительных сезона; для критичных объектов — возможность двухтопливной работы.
6. **Техническое обслуживание:** плановая чистка теплообменника и дымохода 1–2 раза в год; контроль зольного ящика по регламенту завода-изготовителя.

## Нормативная база

- **ISO 17225-1–6** — классификация и свойства твёрдого биотоплива;
- **ISO 1928** — определение теплоты сгорания в калориметрической бомбе;
- **ГОСТ Р 56296-2014** — топливо твёрдое из древесины, пеллеты;
- **ГОСТ Р 54597-2011** — биотопливо твёрдое, требования;
- **СП 89.13330.2016** — котельные установки (актуализированная редакция СНиП II-35-76);
- **СП 60.13330.2020** — отопление, вентиляция и кондиционирование;
- **EN 303-5** — котлы на твёрдом топливе до 500 кВт;
- **Директива ЕС 2009/28/EC** — продвижение возобновляемых источников энергии;
- **Директива ЕС 2015/2193** — установки сжигания средней мощности, нормы выбросов.
