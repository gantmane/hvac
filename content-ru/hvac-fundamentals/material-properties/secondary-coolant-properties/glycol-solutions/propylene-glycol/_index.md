## Характеристика вещества

Пропиленгликоль (propylene glycol, PG) — 1,2-пропандиол, двухатомный спирт с химической формулой C₃H₈O₂ (CH₃CH(OH)CH₂OH). Молярная масса 76,09 г/моль, регистрационный номер CAS 57-55-6.

**Ключевые физические константы чистого PG:**

{{< table title="Физические свойства чистого пропиленгликоля" >}}
| Свойство | Значение |
|:---------|:--------:|
| Точка кипения при 101,3 кПа, °C | 188,2 |
| Точка плавления, °C | −59 |
| Температура вспышки (закрытый сосуд), °C | 107 |
| Температура самовоспламенения, °C | 371 |
| Плотность при 20 °C, кг/м³ | 1 036 |
| Динамическая вязкость при 20 °C, мПа·с | 56 |
| Удельная теплоёмкость при 20 °C, кДж/(кг·°C) | 2,48 |
| Теплопроводность при 20 °C, Вт/(м·°C) | 0,20 |
{{< /table >}}

**Токсикологический профиль.** PG классифицирован FDA как GRAS (Generally Recognized As Safe) согласно 21 CFR 184.1666 для применения в прямом контакте с пищевыми продуктами. Пероральная LD₅₀ (крысы) — 20–32 г/кг. В организме метаболизируется до молочной и пировиноградной кислот — нормальных метаболитов. Допустимое суточное потребление по ВОЗ — 25 мг/кг массы тела. Сертифицирован по NSF/ANSI 60 для компонентов систем питьевого водоснабжения.

Низкая токсичность делает PG обязательным выбором в системах с возможным контактом с пищевыми продуктами, питьевой водой или при риске утечки в зоны доступа людей.

## Защита от замерзания: концентрация и температура

{{< table title="Точки замерзания растворов PG по ASHRAE Handbook Fundamentals Ch. 31" >}}

|----------------------:|--------------------:|:--------------------|
| 10 | −3,9 | Минимальная защита |
| 20 | −9,4 | Закрытые отапливаемые помещения |

| 30 | −16,7 | Умеренная защита |
| 35 | −21,1 | Холодный климат |
| 40 | −26,1 | Суровый холодный климат |
| 45 | −31,7 | Арктические применения |

**Эвтектика PG** — ~60 % масс., −52 °C. Выше этой концентрации точка замерзания растёт по мере приближения к чистому PG (−59 °C). Практические концентрации для ОВиК — 25–50 % масс.; оптимум большинства применений — 30–40 %.

Запас защиты от замерзания согласно ASHRAE 90.1: не менее 5,6 °C ниже минимальной ожидаемой температуры системы для стандартных объектов; 8,3–11,1 °C — для критических систем.

## Влияние на теплопередачу

### Снижение общего коэффициента теплопередачи

Совокупный эффект роста вязкости, снижения теплопроводности и изменения числа $Re$ приводит к снижению коэффициента теплопередачи $U$:

{{< table title="Ориентировочные множители коэффициента U для растворов PG (турбулентный режим)" >}}
| Концентрация, % масс. | Множитель $U / U_{\text{вода}}$ |
|----------------------:|:-------------------------------:|
| 20 | 0,88–0,93 |
| 30 | 0,82–0,87 |
| 40 | 0,75–0,82 |
| 50 | 0,68–0,75 |
{{< /table >}}

При переходе с воды на 40 % PG площадь поверхности теплообменника рекомендуется увеличивать на 15–25 %; оборудование подбирать по данным производителя с учётом поправочных коэффициентов для гликоля.

## Численный пример: подбор насоса при переходе на 40 % PG

**Условие.** Контур охлаждения фармацевтической линии. Тепловая нагрузка $Q = 150\ \text{кВт}$, $\Delta T = 5\ \text{°C}$, рабочая температура 7 °C. Исходный хладоноситель — вода, переход на 40 % PG.

**Расход воды:**

{{< formula display="true" >}}
\dot{m}_{\text{вода}} = \frac{150}{4{,}182 \times 5} = 7{,}17\ \text{кг/с} \approx 25{,}8\ \text{м}^3/\text{ч}
{{< /formula >}}

**Расход 40 % PG при 7 °C** ($c_p = 3{,}94\ \text{кДж/(кг·°C)}$, $\rho = 1\,033\ \text{кг/м}^3$):

{{< formula display="true" >}}
\dot{m}_{\text{PG}} = \frac{150}{3{,}94 \times 5} = 7{,}61\ \text{кг/с};\quad \dot{V}_{\text{PG}} = \frac{7{,}61}{1{,}033} = 7{,}37\ \text{л/с} \approx 26{,}5\ \text{м}^3/\text{ч}
{{< /formula >}}

Прирост объёмного расхода: +3 %. Значение $Re$ при диаметре трубы $d = 65\ \text{мм}$, $w \approx 0{,}62\ \text{м/с}$, $\mu_{\text{PG}} = 5{,}0\ \text{мПа·с}$:

{{< formula display="true" >}}
Re_{\text{PG}} = \frac{1033 \times 0{,}62 \times 0{,}065}{0{,}005} = 8\,322
{{< /formula >}}

Турбулентный режим сохраняется ($Re > 4\,000$). Оценка роста потерь давления:

{{< formula display="true" >}}
\frac{\Delta p_{\text{PG}}}{\Delta p_{\text{вода}}} \approx \left(\frac{\mu_{\text{PG}}}{\mu_{\text{вода}}}\right)^{0{,}2} = \left(\frac{5{,}0}{1{,}4}\right)^{0{,}2} \approx 1{,}29
{{< /formula >}}

Мощность насоса с учётом роста расхода (+3 %) и давления (+29 %) увеличится примерно на **+33 %**. Необходима проверка марки насоса и двигателя.

## Применения с требованиями пищевой безопасности

PG — единственный разрешённый вторичный хладоноситель при прямом контакте с пищевыми продуктами. Применяется в:

- системах охлаждения линий розлива напитков;
- холодильных установках мясо- и молокоперерабатывающих предприятий;
- фармацевтических производствах (GMP-контуры);
- контурах снеготаяния в зонах зелёных крыш (экологические требования);
- солнечных тепловых коллекторах с биологически разлагаемым хладоносителем.

## Ключевые выводы

1. PG — предпочтительный хладоноситель при любом риске контакта с пищевыми продуктами или питьевой водой; единственный вариант в GMP-производствах.
2. Более высокая удельная теплоёмкость PG по сравнению с EG снижает штраф по расходу; совокупная деградация теплопередачи при 40 % PG — 18–25 % относительно воды.
3. Оптимальная концентрация — 30–40 % масс. для большинства ОВиК-систем; превышение 50 % нецелесообразно из-за резкого роста вязкости.
4. При проектировании обязательна проверка числа Рейнольдса при минимальной рабочей температуре — переход в ламинарный режим существенно снижает теплоотдачу и меняет расчётную картину.
