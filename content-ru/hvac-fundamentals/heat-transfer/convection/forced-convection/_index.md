Вынужденная конвекция возникает, когда движение жидкости создаётся внешним источником — насосом, вентилятором или ветром. Это доминирующий механизм теплообмена в подавляющем большинстве активных систем HVAC: трубопроводные системы, воздухообрабатывающие установки, теплообменники, фанкойлы. Принципиально важно правильно определить режим течения и выбрать соответствующую корреляцию.

## Внутреннее течение в трубах и каналах

### Гидродинамическое и тепловое развитие потока

Поток в трубе становится полностью развитым только после некоторого входного участка.

**Длина гидравлического входа**:

{{< formula display="true" >}}
L_{h,lam} = 0{,}05 \, Re \cdot D \quad\text{(ламинарный)}
\qquad
L_{h,turb} \approx 10\text{–}60 \, D \quad\text{(турбулентный)}
{{< /formula >}}

**Длина теплового входа**:

{{< formula display="true" >}}
L_{t,lam} = 0{,}05 \, Re \cdot Pr \cdot D = Gz \cdot D
{{< /formula >}}

В области входа коэффициент теплообмена выше, чем в развитом потоке, поскольку тепловой пограничный слой тоньше. Для трубопроводов HVAC ($L/D > 30$) эффектом входа обычно пренебрегают.

### Ламинарный поток (Re < 2300)

Полностью развитое течение при постоянной температуре стенки: $Nu_D = 3{,}66$.
Полностью развитое течение при постоянном тепловом потоке: $Nu_D = 4{,}36$.

Корреляция для развивающегося потока (корреляция Зидера–Тейта):

{{< formula display="true" >}}
Nu_D = 1{,}86 \left(\frac{Re \cdot Pr \cdot D}{L}\right)^{1/3} \left(\frac{\mu_b}{\mu_s}\right)^{0,14}
{{< /formula >}}

**Применима при**: $0{,}48 < Pr < 16\,700$; $Re \cdot Pr \cdot D/L > 10$.

### Турбулентный поток: уравнение Диттуса–Бёлтера

{{< formula display="true" >}}
Nu_D = 0{,}023 \, Re_D^{0,8} Pr^n
\quad
\begin{cases} n = 0{,}4 & T_s > T_b \\ n = 0{,}3 & T_s < T_b \end{cases}
{{< /formula >}}

**Применима при**: $Re > 10\,000$; $0{,}7 < Pr < 160$; $L/D > 10$. Погрешность ±25%.

### Турбулентный поток: уравнение Гнилинского (рекомендуемое)

{{< formula display="true" >}}
Nu_D = \frac{(f/8)(Re_D - 1000) Pr}{1 + 12{,}7 \sqrt{f/8}\,(Pr^{2/3} - 1)}
\quad
f = (0{,}790 \ln Re_D - 1{,}64)^{-2}
{{< /formula >}}

**Применима при**: $3000 < Re < 5 \times 10^6$; $0{,}5 < Pr < 2000$. Погрешность ±10%.

Уравнение Гнилинского справедливо и в переходном режиме ($2300 < Re < 4000$), что особенно важно при частичных нагрузках.

## Числовой пример: трубопровод системы охлаждения

**Задача.** Рассчитать $h_i$ и проверить U-значение теплообменника. Медная труба Ø19×1 мм (наружный диаметр 19 мм, внутренний 17 мм). Вода-гликоль 30% при $T_b = 12°$С, расход $\dot{V} = 0{,}5$ л/с.

Свойства раствора при 12°С: $\rho = 1045$ кг/м³, $\mu = 1{,}85 \times 10^{-3}$ Па·с, $k = 0{,}510$ Вт/(м·К), $Pr = 20{,}5$.

{{< formula display="true" >}}
V = \frac{\dot{V}}{A} = \frac{0{,}5 \times 10^{-3}}{\pi (0{,}017)^2/4} = \frac{5 \times 10^{-4}}{2{,}27 \times 10^{-4}} = 2{,}20 \;\text{м/с}
{{< /formula >}}

{{< formula display="true" >}}
Re = \frac{\rho V D}{\mu} = \frac{1045 \times 2{,}20 \times 0{,}017}{1{,}85 \times 10^{-3}} = \frac{39{,}08}{1{,}85 \times 10^{-3}} = 21\,100 \quad\text{(турбулентный)}
{{< /formula >}}

{{< formula display="true" >}}
f = (0{,}790 \ln 21\,100 - 1{,}64)^{-2} = (7{,}87)^{-2} = 0{,}01613
{{< /formula >}}

{{< formula display="true" >}}
Nu_D = \frac{(0{,}01613/8)(21100 - 1000) \times 20{,}5}{1 + 12{,}7\sqrt{0{,}01613/8}(20{,}5^{2/3}-1)} = \frac{0{,}00202 \times 20100 \times 20{,}5}{1 + 12{,}7 \times 0{,}0449 \times 6{,}51}
{{< /formula >}}

{{< formula display="true" >}}
Nu_D = \frac{831}{1 + 3{,}71} = \frac{831}{4{,}71} = 176
{{< /formula >}}

{{< formula display="true" >}}
h_i = \frac{176 \times 0{,}510}{0{,}017} = 5281 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

## Некруглые сечения (прямоугольные воздуховоды)

Для некруглых сечений используют **гидравлический диаметр**:

{{< formula display="true" >}}
D_h = \frac{4 A_c}{P_{wет}}
{{< /formula >}}

Для прямоугольного воздуховода $a \times b$: $D_h = 2ab/(a+b)$.

{{< table title="Числа Нуссельта для ламинарного течения в прямоугольных каналах (постоянный тепловой поток)" >}}
| $a/b$ | $Nu$ (пост. $q''$) | $Nu$ (пост. $T_s$) |
|---|---|---|
| 1,0 (квадрат) | 3,61 | 2,98 |
| 2,0 | 4,12 | 3,39 |
| 4,0 | 5,33 | 4,44 |
| 8,0 | 6,49 | 5,60 |
| ∞ (плоский канал) | 8,23 | 7,54 |
{{< /table >}}

Для турбулентного течения в воздуховоде стандартные корреляции применимы с $D_h$ при отношении сторон $a/b < 8$; при $a/b > 8$ точность снижается.

## Внешнее обтекание: плоская пластина

### Ламинарный пограничный слой ($Re_x < 5 \times 10^5$)

Локальное и среднее числа Нуссельта:

{{< formula display="true" >}}
Nu_x = 0{,}332 \, Re_x^{1/2} Pr^{1/3}
\qquad
\overline{Nu}_L = 0{,}664 \, Re_L^{1/2} Pr^{1/3}
{{< /formula >}}

Применимо при $Pr > 0{,}6$.

### Смешанный пограничный слой (переход при $Re_c = 5 \times 10^5$)

{{< formula display="true" >}}
\overline{Nu}_L = (0{,}037 \, Re_L^{4/5} - 871) Pr^{1/3}
{{< /formula >}}

## Внешнее обтекание: пучки труб

Пучки труб — основной элемент воздухоохладителей, конденсаторов, нагревательных батарей. Параметры пучка: $S_T$ — поперечный шаг, $S_L$ — продольный шаг, оба отнесены к диаметру трубы $D$.

**Максимальная скорость** в пучке (для коридорного расположения):

{{< formula display="true" >}}
V_{max} = V \cdot \frac{S_T}{S_T - D}
{{< /formula >}}

### Корреляция Жукаускаса для пучков труб

{{< formula display="true" >}}
\overline{Nu}_D = C \, Re_{D,max}^m Pr^{0,36} \left(\frac{Pr}{Pr_s}\right)^{1/4}
{{< /formula >}}

{{< table title="Коэффициенты C и m для коридорного пучка труб (Жукаускас)" >}}
| $Re_{D,max}$ | $C$ | $m$ |
|---|---|---|
| 10–100 | 0,80 | 0,40 |
| 100–1000 | 0,51 | 0,50 |
| 1000–2·10⁵ | 0,27 | 0,63 |
| 2·10⁵–2·10⁶ | 0,021 | 0,84 |
{{< /table >}}

Для шахматного расположения коэффициент теплообмена на 10–20% выше, чем для коридорного, вследствие лучшего перемешивания.

**Поправка на малое число рядов** ($N_L < 20$): $Nu_{N_L} = F \cdot Nu_{N_L \geq 20}$, где $F$ меняется от 0,70 ($N_L = 1$) до 1,0 ($N_L \geq 20$).

## Числовой пример: воздухонагреватель с горячей водой

**Задача.** Ряды стальных труб Ø16 мм в шахматном расположении, $S_T = S_L = 32$ мм, 6 рядов. Воздух движется со скоростью $V_\infty = 3$ м/с при $T_\infty = 15°$С, стенки труб при $T_s = 80°$С. Найти $h_o$ со стороны воздуха.

Свойства воздуха при $T_f = 47{,}5°$С: $\rho = 1{,}094$ кг/м³, $\mu = 1{,}935 \times 10^{-5}$ Па·с, $k = 0{,}0277$ Вт/(м·К), $Pr = 0{,}710$.

{{< formula display="true" >}}
V_{max} = 3 \times \frac{32}{32 - 16} = 6{,}0 \;\text{м/с}
{{< /formula >}}

{{< formula display="true" >}}
Re_{D,max} = \frac{1{,}094 \times 6{,}0 \times 0{,}016}{1{,}935 \times 10^{-5}} = \frac{0{,}1050}{1{,}935 \times 10^{-5}} = 5425
{{< /formula >}}

Попадает в диапазон 1000–2·10⁵ шахматного расположения: $C = 0{,}35 (S_T/S_L)^{0,2}$, $m = 0{,}60$.

При $S_T/S_L = 1{,}0$: $C = 0{,}35 \times 1^{0,2} = 0{,}35$.

{{< formula display="true" >}}
Nu = 0{,}35 \times 5425^{0,60} \times 0{,}710^{0,36} \times (Pr/Pr_s)^{0,25}
{{< /formula >}}

При $T_s = 80°$С: $Pr_s = 0{,}706$; поправка $\approx 1{,}001 \approx 1$.

{{< formula display="true" >}}
Nu = 0{,}35 \times 160{,}8 \times 0{,}896 = 50{,}4
{{< /formula >}}

Поправка на 6 рядов: $F = 0{,}97$ (из таблиц). $Nu_{корр} = 50{,}4 \times 0{,}97 = 48{,}9$.

{{< formula display="true" >}}
h_o = \frac{48{,}9 \times 0{,}0277}{0{,}016} = 84{,}7 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

## Конвекция у поверхностей зданий

Для наружных стен здания ASHRAE Handbook рекомендует расчётное значение при скорости ветра 6,7 м/с:

{{< formula display="true" >}}
h_e = 34 \;\text{Вт/(м}^2\text{·К)}
\qquad\text{(зимнее расчётное значение по ASHRAE)}
{{< /formula >}}

Для более точного расчёта в зависимости от скорости ветра $V$ [м/с]:

{{< formula display="true" >}}
h_e = 5{,}7 + 3{,}8 V \quad [\text{Вт/(м}^2\text{·К)}]
{{< /formula >}}

Эти значения включают как конвекцию, так и радиационную составляющую с коэффициентом поверхностного теплообмена.
