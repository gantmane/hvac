# Теплофизические свойства материалов для инженеров HVAC

Точные данные о теплофизических свойствах являются основой расчетов теплопередачи, определения размеров изоляции и анализа энергоэффективности. Этот справочник содержит коэффициент теплопроводности, удельную теплоемкость, плотность и производные характеристики для распространенных материалов HVAC и строительных конструкций.

## Основные теплофизические свойства

**Коэффициент теплопроводности (k):** Тепловой поток через единицу толщины при единичной разности температур

$$k = \frac{q \cdot L}{A \cdot \Delta T}$$

Единицы измерения: Вт/(м·К)

**Удельная теплоемкость (c):** Энергия для повышения температуры единицы массы на один градус

Единицы измерения: кДж/(кг·К)

**Плотность (ρ):** Масса на единицу объема

Единицы измерения: кг/м³

**Коэффициент температуропроводности (α):** Скорость распространения температурного возмущения

$$\alpha = \frac{k}{\rho c}$$

Единицы измерения: м²/с

## Температурная зависимость

Коэффициент теплопроводности варьируется с температурой:

$$k(T) = k_0 [1 + \alpha(T - T_0)]$$

Где:
- $k_0$ = коэффициент при опорной температуре $T_0$
- $\alpha$ = температурный коэффициент (обычно 0.001-0.005 на °C)

**Пример:** Коэффициент теплопроводности стекловолокна увеличивается примерно на 5% при изменении температуры с -18°C до 38°C.

## Практические применения

**Тепловое сопротивление изоляции:**

$$R = \frac{L}{k}$$

Где L = толщина (см)

**U-коэффициент многослойной конструкции:**

$$U = \frac{1}{R_{total}} = \frac{1}{R_1 + R_2 + ... + R_n + R_{воздушные пленки}}$$

**Тепловая емкость:**

$$Q = m \cdot c \cdot \Delta T = \rho \cdot V \cdot c \cdot \Delta T$$
