Температура точки росы (dew-point temperature, T\_dp) — температура, до которой необходимо охладить воздух при неизменном давлении и влагосодержании, чтобы он достиг состояния насыщения. При дальнейшем охлаждении начинается конденсация: водяной пар переходит в жидкую фазу. Точка росы служит главным критерием при оценке риска поверхностной и межслойной конденсации в ограждающих конструкциях.

---

## Термодинамическое определение

Условие насыщения в точке росы:

{{< formula display="true" >}}
p_v = p_{\text{sat}}(T_{\text{dp}})
{{< /formula >}}

где p\_v — фактическое парциальное давление водяного пара, Па; p\_sat(T\_dp) — давление насыщенного пара при температуре точки росы, Па.

Относительная влажность (relative humidity) φ связана с точкой росы через:

{{< formula display="true" >}}
\varphi = \frac{p_v}{p_{\text{sat}}(T_{\text{db}})} = \frac{p_{\text{sat}}(T_{\text{dp}})}{p_{\text{sat}}(T_{\text{db}})}
{{< /formula >}}

где T\_db — температура сухого термометра, °C.

Ключевой факт: точка росы определяется исключительно влагосодержанием воздуха и давлением — не температурой сухого термометра. Два образца воздуха с одинаковым влагосодержанием d (г/кг с.в.) имеют одинаковую T\_dp независимо от температуры.

## Уравнения давления насыщенного пара

### Формула Магнуса–Тетенса

Наиболее употребительное приближение для диапазона −40°C … +60°C:

{{< formula display="true" >}}
p_{\text{sat}}(T) = 610{,}78 \cdot \exp\!\left(\frac{17{,}27 \cdot T}{T + 237{,}3}\right) \quad \text{[Па, } T \text{ в °C]}
{{< /formula >}}

Погрешность не превышает 0,5% в диапазоне −20°C … +50°C.

### Корреляции ASHRAE Fundamentals

ASHRAE Fundamentals (гл. 1) приводит полиномиальные корреляции с погрешностью < 0,1%:

Над водой (0°C … 200°C):

{{< formula display="true" >}}
\ln p_{\text{sat}} = \frac{C_8}{T_K} + C_9 + C_{10} T_K + C_{11} T_K^2 + C_{12} T_K^3 + C_{13} \ln T_K
{{< /formula >}}

Константы (T\_K в кельвинах, p\_sat в Па): C₈ = −5800,2206; C₉ = 1,3914993; C₁₀ = −4,864·10⁻²; C₁₁ = 4,1765·10⁻⁵; C₁₂ = −1,4452·10⁻⁸; C₁₃ = 6,5460.

Над льдом (−100°C … 0°C) используется аналогичное уравнение с константами C₁–C₇.

## Методы расчёта точки росы

### Из температуры и относительной влажности

Прямое обращение формулы Магнуса–Тетенса (уравнение Августа–Роше–Магнуса):

{{< formula display="true" >}}
T_{\text{dp}} = \frac{243{,}04 \cdot \left[\ln\!\left(\dfrac{\varphi}{100}\right) + \dfrac{17{,}625 \cdot T_{\text{db}}}{243{,}04 + T_{\text{db}}}\right]}{17{,}625 - \ln\!\left(\dfrac{\varphi}{100}\right) - \dfrac{17{,}625 \cdot T_{\text{db}}}{243{,}04 + T_{\text{db}}}}
{{< /formula >}}

### Из влагосодержания

Влагосодержание (humidity ratio) d, г/кг:

{{< formula display="true" >}}
p_v = \frac{d \cdot p_{\text{atm}}}{d + 621{,}945} \quad \text{[Па]}
{{< /formula >}}

Затем T\_dp находится обращением уравнения Магнуса–Тетенса:

{{< formula display="true" >}}
T_{\text{dp}} = \frac{237{,}3 \cdot \ln(p_v / 610{,}78)}{17{,}27 - \ln(p_v / 610{,}78)}
{{< /formula >}}

### По психрометрической диаграмме (графический метод)

1. Нанести точку состояния воздуха по T\_db и φ.
2. Провести горизонтальную линию (d = const) до кривой насыщения (φ = 100%).
3. Точка пересечения с кривой насыщения — температура точки росы.

Точность графического метода ±0,3°C; применяется для первичной оценки и учебных задач.

## Численный пример: оценка конденсации на внутренней поверхности стены (Москва)

### Исходные данные

Однослойная конструкция: минераловатная плита 150 мм (λ = 0,038 Вт/(м·K)), облицовка гипсокартоном изнутри. Полное тепловое сопротивление R\_total = 4,10 м²·K/Вт (включая поверхностные сопротивления R\_si = 0,13 м²·K/Вт, R\_se = 0,04 м²·K/Вт).

Расчётные условия января (СП 131.13330, Москва):
- Внутри: T\_i = +20°C, φ\_i = 45%
- Снаружи: T\_e = −26°C

### Расчёт точки росы внутреннего воздуха

{{< formula display="true" >}}
T_{\text{dp}} = \frac{243{,}04 \cdot \left[\ln\!\left(\dfrac{45}{100}\right) + \dfrac{17{,}625 \cdot 20}{263{,}04}\right]}{17{,}625 - \ln\!\left(\dfrac{45}{100}\right) - \dfrac{17{,}625 \cdot 20}{263{,}04}}
{{< /formula >}}

Числитель: 243,04 · [−0,799 + 1,340] = 243,04 · 0,541 = **131,5**

Знаменатель: 17,625 − (−0,799) − 1,340 = **17,084**

{{< formula display="true" >}}
T_{\text{dp}} = \frac{131{,}5}{17{,}084} = 7{,}7\ °\text{C}
{{< /formula >}}

### Температура внутренней поверхности

{{< formula display="true" >}}
T_{\text{si}} = T_{\text{i}} - \frac{(T_{\text{i}} - T_{\text{e}}) \cdot R_{si}}{R_{\text{total}}} = 20 - \frac{46 \cdot 0{,}13}{4{,}10} = 20 - 1{,}46 = 18{,}5\ °\text{C}
{{< /formula >}}

### Проверка условия конденсации

T\_si = 18,5°C > T\_dp = 7,7°C. Запас: 10,8°C. Конденсация на внутренней поверхности отсутствует.

Температурный коэффициент:

{{< formula display="true" >}}
f_{Rsi} = \frac{18{,}5 - (-26)}{20 - (-26)} = \frac{44{,}5}{46} = 0{,}967
{{< /formula >}}

Требуемый минимум по ISO 13788 для T\_dp = 7,7°C:

{{< formula display="true" >}}
f_{Rsi,\min} = \frac{7{,}7 - (-26)}{46} = \frac{33{,}7}{46} = 0{,}733
{{< /formula >}}

Условие выполнено: 0,967 ≥ 0,733.

## Применение в анализе конденсации ограждающих конструкций

### Профиль температур в многослойной конструкции

Температура на границе слоёв (установившийся режим):

{{< formula display="true" >}}
T_m = T_{\text{i}} - \frac{(T_{\text{i}} - T_{\text{e}}) \cdot \sum_{k=1}^{m} R_k}{R_{\text{total}}}
{{< /formula >}}

В каждой точке сравнивается фактическая температура T\_m с локальной точкой росы пара T\_dp,local(p\_v,m). Депрессия точки росы (dew-point depression):

{{< formula display="true" >}}
\Delta T_{\text{dp}} = T_m - T_{\text{dp, local}}(p_{v,m})
{{< /formula >}}

Проектная цель: ΔT\_dp ≥ 2,8°C на всём сечении конструкции.

### Метод Глазера (ISO 13788)

Для каждого месяца:
1. Линейное распределение температур по тепловому сопротивлению.
2. Линейное распределение давления пара по эквивалентной диффузионной толщине s\_d = μ·d.
3. Сравнение p\_v(x) с p\_sat(T(x)) на всех границах.
4. При p\_v > p\_sat — конденсация; расчёт скорости накопления влаги.

Детальный алгоритм Глазера с численным примером приведён в разделе «Межслойная конденсация».

### Критические узлы

**Тепловые мосты (thermal bridges):** Локальная температура поверхности у стальных стоек, бетонных обвязок и углов на 5–12°C ниже поля стены, что резко снижает запас до точки росы. Оценка — по ISO 10211 (двухмерный МКЭ).

**Откосы оконных проёмов:** Характерная точка конденсации при недостаточной тепловой развязке между рамой и стеной; требуется расчёт fRsi в углу притвора.

**Воздухонепроницаемость (EN 13829):** Экфильтрация тёплого влажного воздуха через трещины поставляет влагу непосредственно в холодную зону конструкции — конвективный перенос многократно превышает диффузию.

В летний период при активном охлаждении возникает обратная диффузия пара (reverse diffusion): наружный воздух с высоким влагосодержанием стремится внутрь, конденсируясь на охлаждённой внутренней поверхности конструкции. Этот режим анализируется отдельно.

## Влияние высоты над уровнем моря

На высоте z атмосферное давление:

{{< formula display="true" >}}
p_{\text{atm}}(z) = 101325 \cdot \left(1 - 2{,}2558 \times 10^{-5} \cdot z\right)^{5{,}2559} \quad \text{[Па]}
{{< /formula >}}

При неизменном влагосодержании d точка росы снижается с ростом высоты, поскольку парциальное давление пара падает вместе с общим давлением. На высотах до 3000 м поправка не превышает 1,5°C и в практических расчётах по СП 50.13330 не учитывается.

## Методы измерения

**Гигрометр с охлаждаемым зеркалом (chilled mirror hygrometer)** — первичный метод, точность ±0,1°C. Поверхность зеркала охлаждается элементом Пельтье; оптический датчик фиксирует момент конденсации. Применяется для калибровки, верификации и лабораторных испытаний.

**Ёмкостной датчик влажности** — косвенный метод: измеряет T\_db и φ, вычисляет T\_dp через уравнение Магнуса–Тетенса. Точность T\_dp ±1–2°C. Используется в системах мониторинга зданий.

**Инфракрасный термометр** позволяет измерить температуру поверхности для сравнения с T\_dp воздуха — быстрый полевой метод выявления зон риска конденсации.
