Анализ размерностей позволяет свести задачи с многими параметрами к минимальному числу безразмерных групп (π-критериев). Для инженера ОВК это означает: экспериментальные данные, полученные на модели одного масштаба и при одних условиях, применимы к объекту другого масштаба при выполнении условий подобия. Корреляции теплоотдачи (Nu = f(Re, Pr)) и гидравлического сопротивления (Eu = f(Re)) — прямое следствие анализа размерностей.

## Теорема Бакингема (π-теорема)

Если физическая зависимость включает `n` переменных, связанных через `m` независимых физических размерностей (длина L, масса M, время T, температура θ), то зависимость записывается через `k = n − m` безразмерных π-групп:

{{< formula display="true" >}}
f(q_1, q_2, \ldots, q_n) = 0 \quad \Rightarrow \quad F(\pi_1, \pi_2, \ldots, \pi_k) = 0
{{< /formula >}}

**Процедура построения π-групп:**

1. Перечислить все n физических переменных и их размерности
2. Выбрать m «повторяющихся» переменных (основной набор): они должны содержать все m физических размерностей и не образовывать π-группу между собой
3. Для каждой из (n − m) оставшихся переменных построить π-группу, умножая её на подходящие степени повторяющихся переменных для получения безразмерного выражения
4. Проверить независимость полученных групп

## Основные безразмерные критерии в задачах ОВК

### Число Рейнольдса

{{< formula display="true" >}}
Re = \frac{\rho V D}{\mu} = \frac{V D}{\nu} = \frac{\text{инерционные силы}}{\text{вязкие силы}}
{{< /formula >}}

Критерий определяет режим течения. Для круглой трубы: Re < 2300 — ламинарный; 2300 < Re < 4000 — переходный; Re > 4000 — турбулентный. Для воздуховода прямоугольного сечения характерный размер — гидравлический диаметр: `D_гидр = 4A/П`, где A — площадь сечения, П — смоченный периметр.

### Число Нуссельта

{{< formula display="true" >}}
Nu = \frac{h D}{\lambda} = \frac{\alpha D}{\lambda} = \frac{\text{конвективный теплоперенос}}{\text{кондуктивный теплоперенос}}
{{< /formula >}}

Nu — безразмерный коэффициент теплоотдачи. Из Nu извлекается размерный α. Все корреляции теплоотдачи (Дитус–Бёльтер, Гнелинский, Зукаускас) выражают Nu = f(Re, Pr).

### Число Прандтля

{{< formula display="true" >}}
Pr = \frac{\nu}{a} = \frac{\mu c_p}{\lambda} = \frac{\text{вязкостная диффузия импульса}}{\text{тепловая диффузия}}
{{< /formula >}}

Pr — свойство рабочего тела, не зависит от условий течения. Определяет относительную толщину теплового и скоростного пограничных слоёв.

### Число Грасгофа и Рэлея

{{< formula display="true" >}}
Gr = \frac{g \beta (T_w - T_\infty) L^3}{\nu^2}, \quad Ra = Gr \cdot Pr = \frac{g \beta (T_w - T_\infty) L^3}{\nu \cdot a}
{{< /formula >}}

где `β` — коэффициент объёмного теплового расширения (для идеального газа β = 1/T). Определяют интенсивность свободной (естественной) конвекции. При Ra > 10⁹ — турбулентная свободная конвекция.

**Применение в ОВК:** свободная конвекция от горизонтальных труб отопления, от поверхностей тёплых полов, у горячих поверхностей котлов и теплообменников с малой скоростью среды. При Ra < 10⁵ Nu_свобод < 3 — теплоотдача мала, принудительная конвекция предпочтительна.

### Число Эйлера (коэффициент давления)

{{< formula display="true" >}}
Eu = \frac{\Delta P}{\rho V^2 / 2} = K
{{< /formula >}}

Eu — коэффициент сопротивления (K-фактор), описывающий потери давления в безразмерном виде. Все таблицы местных сопротивлений — таблицы Eu = f(геометрия, Re).

### Число Архимеда (для задач с плотностными течениями)

{{< formula display="true" >}}
Ar = \frac{g L^3 (\rho_2 - \rho_1)}{\rho_1 \nu^2}
{{< /formula >}}

Применяется при расчёте истечения холодного воздуха из воздухораспределителей (ниспадающая струя), стратификации воздуха в высоких помещениях, дымоудаления. При Ar > 10⁴ — режим плавучести преобладает над инерцией; струя отклоняется гравитацией.

### Число Фруда

{{< formula display="true" >}}
Fr = \frac{V}{\sqrt{g L}}
{{< /formula >}}

Отношение инерционных к гравитационным силам. Важно при расчёте свободноповерхностных потоков (конденсат в дренажных поддонах, открытые каналы испарительных градирен). При Fr < 1 (подкритический поток) возможно образование гидравлического прыжка при изменении уклона канала.

## Вывод критериев для гидравлической машины

Рассмотрим процедуру на примере вентилятора. Переменные: Q (расход, м³/с), ΔP (давление, Па), n (частота вращения, об/с), D (диаметр, м), ρ (плотность, кг/м³), μ (вязкость, Па·с). Итого n = 6 переменных, m = 3 размерности (M, L, T) → k = 3 π-группы.

Повторяющиеся переменные: ρ, n, D (содержат M, L, T; не образуют π-группу между собой).

{{< formula display="true" >}}
\pi_1 = \frac{Q}{n D^3} \equiv \Phi \quad \text{(коэффициент подачи)}
{{< /formula >}}

{{< formula display="true" >}}
\pi_2 = \frac{\Delta P}{\rho n^2 D^2} \equiv \Psi \quad \text{(коэффициент давления)}
{{< /formula >}}

{{< formula display="true" >}}
\pi_3 = \frac{\rho n D^2}{\mu} \equiv Re_{\text{машина}} \quad \text{(число Рейнольдса машины)}
{{< /formula >}}

Функциональная связь: `Ψ = f(Φ, Re_маш)`. При больших Re (турбулентный режим в машине) зависимость от Re слабая: `Ψ ≈ f(Φ)` — это и есть **характеристическая кривая H-Q** в безразмерном виде. **Законы подобия** — следствие: при одинаковом Φ и Ψ машины геометрически подобны, поэтому изменение n или D пересчитывается по аффинным соотношениям.

## Применение к масштабированию теплообменников

Задача: предсказать теплоотдачу в реальном теплообменнике по экспериментальным данным, полученным на модели меньшего масштаба.

Переменные теплообмена в трубе: α (Вт/(м²·К)), D (м), V (м/с), ρ (кг/м³), μ (Па·с), c_p (Дж/(кг·К)), λ (Вт/(м·К)). n = 7, m = 4 → k = 3 π-группы:

{{< formula display="true" >}}
\pi_1 = \frac{\alpha D}{\lambda} = Nu, \quad \pi_2 = \frac{\rho V D}{\mu} = Re, \quad \pi_3 = \frac{\mu c_p}{\lambda} = Pr
{{< /formula >}}

Это обосновывает форму всех корреляций: Nu = C·Re^a·Pr^b. Коэффициенты C, a, b определяются из эксперимента — но форма уравнения заранее задана π-теоремой.

**Условия подобия модели и оригинала:**
- Геометрическое подобие: соотношения размеров одинаковы
- Кинематическое подобие: Re_модель = Re_оригинал
- Тепловое подобие: Pr_модель = Pr_оригинал (выполняется автоматически при том же рабочем теле)

## Числовой пример: пересчёт теплоотдачи трубки при изменении диаметра

**Условие.** Труба теплообменника D₁ = 22 мм, скорость V₁ = 1,5 м/с, Nu₁ = 180. Требуется найти Nu₂ для трубы D₂ = 16 мм при той же температуре и том же расходе жидкости (Q = const, не скорость).

**Скорость в трубе D₂** (равный расход):

{{< formula display="true" >}}
V_2 = V_1 \cdot \frac{D_1^2}{D_2^2} = 1{,}5 \times \frac{22^2}{16^2} = 1{,}5 \times \frac{484}{256} = 1{,}5 \times 1{,}891 = 2{,}837 \text{ м/с}
{{< /formula >}}

**Числа Рейнольдса** (ν = 1,0×10⁻⁶ м²/с, вода 20 °C):

{{< formula display="true" >}}
Re_1 = \frac{1{,}5 \times 0{,}022}{10^{-6}} = 33000, \quad Re_2 = \frac{2{,}837 \times 0{,}016}{10^{-6}} = 45400
{{< /formula >}}

**Пересчёт Nu** по соотношению Nu ~ Re^0,8 (турбулентный режим):

{{< formula display="true" >}}
\frac{Nu_2}{Nu_1} = \left(\frac{Re_2}{Re_1}\right)^{0{,}8} = \left(\frac{45400}{33000}\right)^{0{,}8} = 1{,}376^{0{,}8} = 1{,}291
{{< /formula >}}

{{< formula display="true" >}}
Nu_2 = 180 \times 1{,}291 = 232
{{< /formula >}}

**Коэффициент теплоотдачи** (вода, λ = 0,598 Вт/(м·К)):

{{< formula display="true" >}}
\alpha_1 = \frac{180 \times 0{,}598}{0{,}022} = 4889 \text{ Вт/(м}^2\text{·К)}, \quad \alpha_2 = \frac{232 \times 0{,}598}{0{,}016} = 8677 \text{ Вт/(м}^2\text{·К)}
{{< /formula >}}

Уменьшение диаметра с 22 до 16 мм при сохранении расхода увеличивает α в 8677/4889 = **1,77 раза** — за счёт роста скорости. Однако потери давления возрастают пропорционально V₂²/D₂ относительно V₁²/D₁: (2,837²/0,016)/(1,5²/0,022) = (20,07)/(4,75) = **4,2 раза**. Это типичный компромисс: компактность теплообменника и высокая теплоотдача достигаются ценой существенного роста гидравлического сопротивления.
