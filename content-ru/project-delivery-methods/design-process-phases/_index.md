Процесс проектирования HVAC progresses через определенные этапы, каждый из которых опирается на предыдущий для разработки полной рабочей документации. Понимание результатов этапов и требований координации обеспечивает эффективную реализацию проекта и высокое качество результатов.

## Обзор этапов

### Традиционные этапы проектирования

| Этап | Усилие | Ключевые результаты |
|-------|--------|----------|
| Программирование | 5-10% | Документ требований |
| Схематическое проектирование (SD) | 15-20% | Концепции систем, однолинейные схемы |
| Разработка проекта (DD) | 25-30% | Подбор оборудования, планировки |
| Рабочая документация (CD) | 35-40% | Полные тендерные документы |
| Администрирование строительства (CA) | 10-15% | Спецификации, полевая поддержка |

### Прогрессия этапов

Каждый этап уточняет детализацию проекта:

```
Программирование → SD → DD → CD → CA
[Концепции] → [Системы] → [Оборудование] → [Детали] → [Монтаж]
```

## Этап программирования

### Цель

Определить требования и ограничения проекта до начала проектирования.

### Деятельность

- Оценка объекта (существующие условия)
- Интервью с заказчиком (эксплуатационные требования)
- Обзор нормативов (применимые стандарты)
- Установление бюджета
- Разработка графика

### Результаты HVAC

- Предварительные оценки нагрузок
- Рекомендации по типу системы
- Оценка мощности коммунальных услуг
- Вопросы поэтапности
- Выявление специальных требований

## Схематическое проектирование (SD)

### Цель

Установить общие концепции и подходы к системе HVAC.

### Деятельность

- Концептуальные расчеты нагрузок
- Выбор системы
- Концепции размещения оборудования
- Предварительная трассировка воздуховодов/трубопроводов
- Подход к системам управления
- Энергетический анализ (предварительный)

### Результаты HVAC

| Документ | Содержание |
|----------|---------|
| Отчет SD | Описания систем, основы проектирования |
| Планы этажей | Размещение оборудования, основные трассы |
| Схемы систем | Однолинейные схемы потоков |
| Список оборудования | Предварительный подбор |
| Сводка по нормам | Применимые стандарты |

### Координация

- Выделение архитектурных помещений
- Координация нагрузок на конструкции
- Требования к электроснабжению
- Подключения к внешним коммуникациям

### Обзор SD

Ключевой этап утверждения заказчиком:
- Принятие концепции системы
- Соответствие бюджету
- Подтверждение графика
- Разрешение на переход к DD

## Разработка проекта (DD)

### Цель

Разработать выбранные системы с конкретным оборудованием и планировками.

### Деятельность

- Детальные расчеты нагрузок
- Выбор оборудования
- Подбор размеров воздуховодов/трубопроводов
- Последовательности управления
- Координационные чертежи
- Энергетическое моделирование
- Анализ стоимости жизненного цикла

### Результаты HVAC

| Документ | Содержание |
|----------|---------|
| Чертежи DD | Масштабированные планы этажей, разрезы |
| Таблицы оборудования | Данные по подобранному оборудованию |
| Схемы управления | Схемы систем |
| Спецификации | Предварительные спецификации |
| Энергетический отчет | Соответствие нормам, анализ |

### Комплект чертежей DD

**Механические планы**:
- Планировки оборудования
- Трассировка и подбор размеров воздуховодов
- Трассировка трубопроводов
- Размещение устройств

**Детали**:
- Типовые узлы монтажа
- Подключения оборудования
- Координационные разрезы

**Таблицы**:
- Данные оборудования
- Таблицы диффузоров
- Таблицы регулирующих клапанов

### Интенсивная координация

- Обнаружение коллизий (координация BIM)
- Координация с потолками
- Проверка размеров шахт
- Планирование доступа к оборудованию

## Рабочая документация (CD)

### Цель

Полные документы, пригодные для конкурентных торгов и строительства.

### Деятельность

- Финальная проверка размеров
- Полная детализация
- Завершение спецификаций
- Разрешение вопросов координации
- Подача на получение разрешений
- Проверка качества

### Результаты HVAC

**Чертежи**:
- Полные планы этажей
- Увеличенные планы (механические помещения)
- Разрезы и фасады
- Детали (все необходимые)
- Таблицы (полные)
- Схемы (управления, стояков)

**Спецификации**:
- Раздел 23 полный
- Спецификации продукции
- Требования к исполнению
- Положения о контроле качества

### Контроль качества

- Внутренний технический обзор
- Проверка координации
- Проверка соответствия нормам
- Обзор конструктивности
- Валидация сметы

### Этапы CD

Типичные стадии подачи:
- 50% CD: Основные системы завершены
- 90% CD: Почти завершено для проверки
- 100% CD: Документы готовы к торгам
- Комплект для разрешений: Подача в органы

## Администрирование строительства

### Цель

Поддержка строительства для обеспечения достижения замысла проектирования.

### Деятельность

- Обзор спецификаций поставщиков
- Ответы на RFI
- Полевые наблюдения
- Поддержка по изменению объема работ
- Координация пусконаладки
- Документация завершения

### Результаты

- Проверенные спецификации поставщиков
- Ответы на RFI
- Полевые отчеты
- Списки недоделок
- Поддержка по архивным чертежам

## Интеграция этапов

### Координация BIM

Разработка модели по этапам:
- SD: Концептуальное объемное моделирование
- DD: Трассировка систем, крупное оборудование
- CD: Детальные компоненты, отсутствие коллизий

### Контроль стоимости

Уточнение сметы:
- Программирование: Ориентировочная (±30%)
- SD: Концептуальная (±20%)
- DD: Детальная (±10%)
- CD: Цены подрядчика (±5%)

### Управление графиком

Отслеживание графика проектирования:
- Даты завершения этапов
- Длительность периодов проверки
- Этапы координации
- График получения разрешений

Понимание прогрессии этапов проектирования позволяет правильно распределить усилия, обеспечить своевременную выдачу результатов и достичь успешных результатов проекта через системную разработку систем HVAC от концепции до рабочей документации.
