## Основы термодинамики смесей

### Мольная и массовая доля

Для смеси из N компонентов:

**Молярная доля** компонента i:

{{< formula display="true" >}}
y_i = \frac{n_i}{\sum_j n_j} = \frac{n_i}{n_{total}}, \qquad \sum_i y_i = 1
{{< /formula >}}

**Массовая доля** (концентрация):

{{< formula display="true" >}}
w_i = \frac{m_i}{m_{total}} = \frac{y_i M_i}{\sum_j y_j M_j}, \qquad \sum_i w_i = 1
{{< /formula >}}

### Молярная масса смеси

{{< formula display="true" >}}
M_{mix} = \sum_i y_i M_i
{{< /formula >}}

Для смеси воздуха: M_air ≈ 28,97 кг/кмоль (N₂ 78 %, O₂ 21 %, Ar 1 % по молям).

---

## Идеальная смесь газов: закон Дальтона

Для смеси идеальных газов:

**Парциальное давление:**

{{< formula display="true" >}}
P_i = y_i P_{total}
{{< /formula >}}

**Свойства смеси:**

{{< formula display="true" >}}
v_{mix} = \sum_i y_i v_i(T, P), \quad h_{mix} = \sum_i y_i h_i(T), \quad s_{mix} = \sum_i y_i s_i(T, P_i)
{{< /formula >}}

### Энтропия смешения

При смешении двух идеальных газов при одинаковых T и P:

{{< formula display="true" >}}
\Delta s_{mix} = -R \sum_i y_i \ln y_i > 0
{{< /formula >}}

Энтропия смешения всегда положительна — смешение необратимо, даже для идеальных газов. Это является источником необратимости в системах с регенерацией воздуха, где возвратный и приточный потоки перемешиваются.

## Смесевые хладагенты

### Классификация

**Азеотропная смесь** (azeotropic mixture): при определённом составе ведёт себя как чистое вещество — испаряется и конденсируется при постоянной температуре. Пример: R-502, R-507A (близкий к азеотропу), R-410A (квазиазеотроп).

**Зеотропная смесь** (zeotropic mixture): компоненты испаряются при разных температурах → разный состав паровой и жидкой фаз → **температурное скольжение** (temperature glide). Примеры: R-407C, R-454B, R-32/R-1234yf.

### Температурное скольжение (temperature glide)

Разница между температурой начала испарения (bubble point) и концом испарения (dew point) при постоянном давлении:

{{< formula display="true" >}}
\Delta T_{glide} = T_{dew} - T_{bubble} \quad [\text{К}]
{{< /formula >}}

{{< table title="Температурное скольжение типичных хладагентов при P = 1,0 МПа" >}}
| Хладагент | Состав (масс. %) | Bubble point, °C | Dew point, °C | Glide, К |
|---|---|---|---|---|
| R-32 | 100 % | 13,5 | 13,5 | 0 |
| R-410A | R-32/R-125 (50/50) | 9,5 | 10,2 | 0,7 |
| R-407C | R-32/R-125/R-134a (23/25/52) | 5,3 | 16,0 | 10,7 |
| R-454B | R-32/R-1234yf (68,9/31,1) | 7,8 | 9,4 | 1,6 |
| R-290 | 100 % | −4,7 | −4,7 | 0 |
{{< /table >}}

### Инженерные последствия температурного скольжения

При заметном скольжении (ΔT > 3 К):

1. **Испаритель**: температура хладагента меняется вдоль теплообменника → нельзя задавать единую «температуру испарения». Средняя — между bubble и dew point.
2. **Конденсатор**: аналогично — скользящая температура конденсации. В противоточном теплообменнике скольжение может улучшить согласование температурных профилей (принцип matching).
3. **Заправка системы**: потери хладагента нарушают состав смеси → система должна заправляться только жидкостью.
4. **Диаграмма P-h**: не горизонтальные линии в двухфазной области, а наклонные «полосы» конденсации/испарения.

## Равновесие жидкость–пар для смесей

### Условие равновесия

При термодинамическом равновесии летучесть каждого компонента в жидкой и паровой фазах одинакова:

{{< formula display="true" >}}
f_i^l = f_i^v, \qquad i = 1, 2, \ldots, N
{{< /formula >}}

### Закон Рауля (идеальная смесь)

Для идеальных смесей жидкость–пар:

{{< formula display="true" >}}
P_i = x_i P_{sat,i}(T)
{{< /formula >}}

{{< formula display="true" >}}
y_i = \frac{x_i P_{sat,i}}{P}
{{< /formula >}}

Закон Рауля справедлив для химически близких компонентов при умеренных давлениях (например, R-32/R-125 при P < 1 МПа с погрешностью < 5 %).

### Константа фазового равновесия K

{{< formula display="true" >}}
K_i = \frac{y_i}{x_i}
{{< /formula >}}

Компонент с K > 1 предпочтительно переходит в паровую фазу (более летучий). При азеотропе: K_i = 1 для всех компонентов при азеотропном составе.

## Психрометрия: термодинамика влажного воздуха

Влажный воздух (moist air) — бинарная смесь сухого воздуха (dry air) и водяного пара (water vapour).

### Основные параметры

**Влагосодержание** (humidity ratio, specific humidity):

{{< formula display="true" >}}
W = \frac{m_v}{m_a} = \frac{M_v}{M_a} \frac{P_v}{P - P_v} = 0{,}622 \frac{P_v}{P - P_v} \quad [\text{кг}_v/\text{кг}_a]
{{< /formula >}}

**Относительная влажность:**

{{< formula display="true" >}}
\varphi = \frac{P_v}{P_{sat}(T)} = \frac{m_v}{m_{v,sat}} \qquad (0 \le \varphi \le 1)
{{< /formula >}}

**Удельная энтальпия влажного воздуха** (на кг сухого воздуха):

{{< formula display="true" >}}
h = h_a + W h_v = c_{p,a} t + W(h_{fg,0} + c_{p,v} t)
{{< /formula >}}

{{< formula display="true" >}}
h \approx 1{,}006\,t + W(2501 + 1{,}86\,t) \quad [\text{кДж/кг}_a]
{{< /formula >}}

где t — температура (°C), h_fg,0 = 2501 кДж/кг — теплота испарения при 0 °C.

### Температура мокрого термометра (wet-bulb temperature)

Итерационная связь с психрометрическим параметром:

{{< formula display="true" >}}
W = W_{sat}(t_{wb}) - \frac{c_{p,a}(t - t_{wb})}{h_{fg,wb}}
{{< /formula >}}

Психрометрическая постоянная (для стандартного аспирационного психрометра):

{{< formula display="true" >}}
W \approx W_{sat}(t_{wb}) - 6{,}6 \times 10^{-4}\,(t - t_{wb})\,(1 + 1{,}15 \times 10^{-3} t_{wb}) \quad \text{(по ASHRAE)}
{{< /formula >}}

### Температура точки росы

Температура, при которой воздух при данном W становится насыщенным:

{{< formula display="true" >}}
P_v = \frac{W P}{0{,}622 + W}
{{< /formula >}}

{{< formula display="true" >}}
t_{dp} = \text{T}_{sat}(P_v) \qquad \text{(из таблиц насыщения воды)}
{{< /formula >}}

Аппроксимация Мэгнуса (ошибка < 0,4 °C при 0–60 °C):

{{< formula display="true" >}}
t_{dp} = \frac{243{,}04\,\ln(P_v/0{,}61078)}{17{,}625 - \ln(P_v/0{,}61078)} \quad [°C,\; P_v \text{ в кПа}]
{{< /formula >}}

## Психрометрические процессы: балансы массы и энергии

### Охлаждение с осушением

При охлаждении ниже точки росы водяной пар конденсируется. Баланс массы и энергии:

**Баланс воды:**

{{< formula display="true" >}}
\dot{m}_a (W_1 - W_2) = \dot{m}_w
{{< /formula >}}

**Энергетический баланс змеевика:**

{{< formula display="true" >}}
\dot{Q}_{coil} = \dot{m}_a (h_1 - h_2) - \dot{m}_w h_w
{{< /formula >}}

где h_w — энтальпия конденсата ≈ c_p,w · t_coil_surface.

**Коэффициент явного тепла (Sensible Heat Ratio, SHR):**

{{< formula display="true" >}}
SHR = \frac{\dot{Q}_{sensible}}{\dot{Q}_{total}} = \frac{\dot{m}_a c_{p,a}(t_1 - t_2)}{\dot{m}_a(h_1 - h_2)}
{{< /formula >}}

### Адиабатное насыщение (увлажнение)

Процесс увлажнения воздуха водой при адиабатных условиях (теплообмен с окружающей средой отсутствует):

{{< formula display="true" >}}
h_1 + (W_{sat} - W_1) h_w = h_{sat}
{{< /formula >}}

Этот процесс соответствует движению по линии постоянного мокрого термометра на психрометрической диаграмме.

### Смешение двух потоков воздуха

Потоки 1 и 2 смешиваются в соотношении ṁ₁ : ṁ₂. Состояние смеси (точка 3):

{{< formula display="true" >}}
W_3 = \frac{\dot{m}_1 W_1 + \dot{m}_2 W_2}{\dot{m}_1 + \dot{m}_2}
{{< /formula >}}

{{< formula display="true" >}}
h_3 = \frac{\dot{m}_1 h_1 + \dot{m}_2 h_2}{\dot{m}_1 + \dot{m}_2}
{{< /formula >}}

На психрометрической диаграмме точка 3 лежит на прямой, соединяющей точки 1 и 2 (принцип рычага).

**Числовой пример: смешение приточного и рециркуляционного воздуха.**

Наружный воздух (40 %): t₁ = 35 °C, W₁ = 0,018 кг/кг, h₁ = 81,1 кДж/кг.
Рециркуляционный воздух (60 %): t₂ = 24 °C, W₂ = 0,010 кг/кг, h₂ = 49,5 кДж/кг.

{{< formula display="true" >}}
W_3 = 0{,}40 \times 0{,}018 + 0{,}60 \times 0{,}010 = 0{,}0072 + 0{,}0060 = 0{,}0132 \text{ кг/кг}
{{< /formula >}}

{{< formula display="true" >}}
h_3 = 0{,}40 \times 81{,}1 + 0{,}60 \times 49{,}5 = 32{,}44 + 29{,}70 = 62{,}1 \text{ кДж/кг}
{{< /formula >}}

## Правила смешения для уравнений состояния

Для применения уравнений состояния (PR, BWR) к смесям используются правила смешения:

**Правило Ван-дер-Ваальса:**

{{< formula display="true" >}}
a_{mix} = \sum_i \sum_j y_i y_j a_{ij}, \qquad a_{ij} = (1 - k_{ij})\sqrt{a_i a_j}
{{< /formula >}}

{{< formula display="true" >}}
b_{mix} = \sum_i y_i b_i
{{< /formula >}}

где k_ij — параметр бинарного взаимодействия (binary interaction parameter, BIP). Значения k_ij подбираются по экспериментальным данным VLE (vapour-liquid equilibrium) и хранятся в базах данных REFPROP.

## Смеси в системах холодоснабжения

### Эффект скольжения в испарителе с прямоточным потоком

В кожухотрубном испарителе с зеотропным хладагентом:
- При **прямотоке**: температура хладагента растёт от bubble до dew point, температура охлаждаемой воды падает — профили могут пересечься → «пинч»
- При **противотоке**: скольжение хладагента согласуется с охлаждением воды → меньший термодинамический перепад → меньше деструкции эксергии

Правило проектирования: для хладагентов с glide > 3 К применять противоточные теплообменники.

### Состав смеси при утечке

При утечке зеотропного хладагента из жидкостной линии выходит более богатая **жидкостью** смесь (с высоким содержанием менее летучего компонента). Оставшийся в системе состав изменяется → другие давления насыщения → необходима перезаправка чистым хладагентом (не дозаправка).

## Диаграмма Молье для влажного воздуха

На психрометрической диаграмме (диаграмма Молье для влажного воздуха):
- Ось X: влагосодержание W (кг/кг) или температура мокрого термометра
- Ось Y: удельная энтальпия h (кДж/кг) или температура сухого термометра
- Линии постоянной относительной влажности — параболические кривые
- Линия насыщения (φ = 100 %) — граница области конденсации

Все психрометрические процессы (охлаждение, нагрев, увлажнение, осушение, смешение) изображаются прямолинейно или по дугам на диаграмме.

## Правила для расчётов смесей в HVAC

1. **Всегда проверяйте тип смеси**: азеотроп или зеотроп — разные методы расчёта давления насыщения.
2. **Для зеотропов**: задавайте как bubble point pressure (давление начала испарения), так и dew point pressure — это разные значения при одинаковой температуре.
3. **При расчёте параметров системы**: используйте среднюю температуру между bubble и dew point как «эффективную» температуру испарения/конденсации.
4. **Для психрометрических расчётов**: применяйте правило рычага (lever rule) при смешении потоков на психрометрической диаграмме — быстрый графический метод.
5. **Не используйте упрощённые психрометрические формулы** при давлении, отличном от 101,325 кПа (высотные объекты, горные регионы): свойства влажного воздуха изменяются.
