## Цель и принцип действия

Ингибиторы коррозии (corrosion inhibitors) — химические добавки, защищающие металлические компоненты систем вторичного теплоносителя от электрохимической деградации. Без ингибиторов типичная скорость коррозии углеродистой стали в гликолевом растворе составляет 0,13–0,51 мм/год; при надлежащем ингибировании — менее 0,025 мм/год (критерий ASTM D1384).

**Три механизма коррозии в замкнутых гликолевых системах:**

1. Анодное растворение металла: $\text{Fe} \to \text{Fe}^{2+} + 2e^-$
2. Катодное восстановление кислорода: $\text{O}_2 + 2\text{H}_2\text{O} + 4e^- \to 4\text{OH}^-$
3. Кислотная деградация гликоля (при перегреве >175 °C или микробиологическом окислении) → образование гликолевой, щавелевой, уксусной кислот → снижение pH → ускорение коррозии.

## Типы ингибиторов

### Нитриты (ингибиторы на основе NaNO₂)

Традиционный анодный ингибитор для защиты чёрных металлов в замкнутых системах.

**Механизм:** нитрит-ионы окисляют ионы Fe²⁺ на анодных участках, образуя защитный слой γ-Fe₂O₃:

{{< formula display="true" >}}
2\text{Fe}^{2+} + 2\text{NO}_2^- + 3\text{H}_2\text{O} \to 2\text{Fe}(\text{OH})_3 + \text{N}_2\text{O} + 2\text{H}^+
{{< /formula >}}

Реакция потребляет нитрит — необходимо периодическое пополнение.

| Параметр | Значение |
|---|---|
| Начальный заряд | 2500–3000 ppm NaNO₂ |
| Минимальный рабочий уровень | 1200 ppm |
| Целевой рабочий уровень | 2000–3000 ppm |
| Скорость истощения | 10–30 % в год |
| Рабочий диапазон pH | 8,5–10,5 |
| Рабочая температура | −34 … +121 °C |

**Ограничения.** Риск образования нитрозаминов при контакте с аминосодержащими соединениями. Не применять в открытых системах или вблизи питьевого водоснабжения.

### Молибдаты (Na₂MoO₄)

Анодный ингибитор широкого спектра с более низкой токсичностью, чем нитриты.

**Механизм:** молибдат формирует защитный слой феррического молибдата:

{{< formula display="true" >}}
\text{Fe} + \text{MoO}_4^{2-} + \text{O}_2 \to \text{FeMoO}_4
{{< /formula >}}

Слой самовосстанавливается; скорость истощения 5–15 % в год (вдвое ниже нитритов).

| Параметр | Значение |
|---|---|
| Целевая концентрация | 400–800 ppm MoO₄²⁻ |
| Минимальный уровень | 200 ppm |
| Температурный диапазон | до +177 °C |
| Совместимость | алюминий, медь, чёрные металлы |

Предпочтителен для систем с алюминиевыми теплообменниками и для установок с минимальным доступом к обслуживанию.

### Органическая кислотная технология (OAT)

Ингибиторы на основе органических карбоксилатов (себацинат, 2-этилгексаноат и др.).

**Механизм:** органические анионы адсорбируются на металлической поверхности, образуя хемосорбционный защитный монослой:

{{< formula display="true" >}}
\text{R-COO}^- + \text{Fe}^{2+} \to \text{Fe(R-COO)}_2 \quad \text{(адсорбционный слой)}
{{< /formula >}}

Ингибитор не расходуется в реакции → срок службы 5–10 лет.

| Параметр | Значение |
|---|---|
| Рабочая концентрация | 1,0–2,0 % об. |
| Минимальный уровень | 0,5 % |
| Срок службы | 5–10 лет |
| pH | 7,5–9,0 |
| Совместимость | алюминий, медь, смешанные системы |

**Требование:** перед заправкой OAT-ингибитором система должна быть промыта от остатков нитритных ингибиторов. Несовместимость — источник осадков и отложений.

### Гибридная органическая кислотная технология (HOAT)

Комбинация OAT-базы (0,5–1,5 %) с низкоуровневыми неорганическими ингибиторами (молибдат, силикат или фосфат) и азолами.

| Параметр | Значение |
|---|---|
| Рабочая концентрация | 1,0–1,5 % |
| Срок службы | 3–5 лет |
| Температурный диапазон | −51 … +149 °C |
| Совместимость | смешанные системы (сталь + медь + алюминий) |

Предпочтителен при модернизации существующих систем с неоднородной металлургией.

### Азолы (защита меди и медных сплавов)

Толилтриазол (TTA) и бензотриазол (BTA) — специализированные ингибиторы для меди.

{{< formula display="true" >}}
\text{Cu} + \text{BTA} \to \text{Cu(I)-BTA комплекс (плёнка)}
{{< /formula >}}

Целевая концентрация: 100–200 ppm TTA. Применяются всегда в сочетании с основным ингибитором.

## Концентрации и критерии замены

{{< table title="Рабочие диапазоны концентраций ингибиторов (ASHRAE Handbook — Fundamentals, гл. 31)" >}}
| Тип ингибитора | Минимум | Оптимум | Максимум |
|---|:-:|:-:|:-:|
| Нитрит (NaNO₂) | 1200 ppm | 2000–3000 ppm | 4000 ppm |
| Молибдат (MoO₄²⁻) | 200 ppm | 400–800 ppm | 1500 ppm |
| OAT | 0,5 % | 1,0–2,0 % | 3,0 % |
| HOAT | 0,75 % | 1,0–1,5 % | 2,0 % |
| Толилтриазол (TTA) | 50 ppm | 100–200 ppm | 500 ppm |
{{< /table >}}

**Критерии замены теплоносителя:**
- pH < 7,0 (устойчивое снижение, не поддающееся коррекции);
- концентрация ингибитора < 50 % от минимального уровня после пополнения;
- Fe > 100 ppm или Cu > 20 ppm (активная коррозия);
- Cl⁻ > 100 ppm;
- вязкость > 150 % от паспортного значения (деградация гликоля).

## Числовой пример. Расчёт дозировки нитрита для системы

**Условие.** Замкнутая гликолевая система с 40 % ЭГ, общий объём системы — 5000 л, начальная концентрация нитрита — 0 ppm, целевая — 2500 ppm, ингибиторный концентрат содержит 35 % NaNO₂.

**Решение.**

Целевая масса NaNO₂ в системе:

{{< formula display="true" >}}
m_{\text{NaNO}_2} = V \times C_{\text{цел}} = 5000 \text{ л} \times 2500 \times 10^{-6} \text{ кг/л} = 12{,}5 \text{ кг}
{{< /formula >}}

Объём ингибиторного концентрата ($\rho_{\text{конц}} \approx 1100$ кг/м³ при 35 % раствора):

{{< formula display="true" >}}
V_{\text{конц}} = \frac{m_{\text{NaNO}_2}}{\rho_{\text{конц}} \times 0{,}35} = \frac{12{,}5}{1100 \times 0{,}35} = 0{,}0325 \text{ м}^3 = 32{,}5 \text{ л}
{{< /formula >}}

При добавлении 32,5 л концентрата в 5000 л системы объём системы возрастёт на 0,65 % — пренебрежимо мало.

**Ежегодное пополнение** (при скорости истощения 20 %):

{{< formula display="true" >}}
V_{\text{пополн}} = 32{,}5 \times 0{,}20 = 6{,}5 \text{ л/год}
{{< /formula >}}

## Протокол мониторинга

{{< table title="Регламент контроля качества теплоносителя" >}}
| Параметр | Метод | Периодичность | Норма |
|---|---|---|---|
| pH | pH-метр (калибровка 2 точки) | Ежеквартально | 7,5–10,5 |
| Нитрит | Колориметрия или ион. хроматография | Ежеквартально | 2000–3000 ppm |
| Молибдат | ICP-OES | 1 раз в год | 400–800 ppm |
| Железо | Атомная абсорбция | 1 раз в год | < 50 ppm |
| Медь | Атомная абсорбция | 1 раз в год | < 10 ppm |
| Хлориды | Ион-селективный электрод | 1 раз в год | < 25 ppm |
| Концентрация гликоля | Рефрактометр | 2 раза в год | По расчёту |
| Проводимость | Кондуктометр | Ежеквартально | 1000–3000 мкСм/см |
{{< /table >}}

**Оценка скорости коррозии по купоновому методу (ASTM D1384):**

{{< formula display="true" >}}
v_{\text{корр}} = \frac{0{,}01356 \times \Delta m}{D \times A \times \tau}
{{< /formula >}}

где $\Delta m$ — потеря массы, мг; $D$ — плотность металла, г/см³; $A$ — площадь купона, см²; $\tau$ — время экспозиции, ч; результат — мм/год.

Критерии (ASTM D1384): сталь < 0,025 мм/год; медь < 0,005 мм/год; алюминий < 0,025 мм/год; припой < 0,076 мм/год. Минимальный период экспозиции купона — 30 суток, предпочтительно 90 суток.
