Механика жидкостей — фундаментальный раздел инженерной физики, определяющий поведение воды, воздуха и хладагентов в системах HVAC. Грамотный гидравлический расчёт обеспечивает правильный выбор насосов и вентиляторов, экономичный подбор сечений трубопроводов и воздуховодов, балансировку разветвлённых сетей и предотвращение кавитации.

## Место механики жидкостей в проектировании HVAC

Практически каждый узел системы HVAC описывается законами механики жидкостей:

- **Гидронные системы** — циркуляция воды и растворов гликоля через котлы, чиллеры, змеевики и фэнкойлы.
- **Воздухораспределительные сети** — транспорт приточного и вытяжного воздуха через прямоугольные и круглые воздуховоды.
- **Холодильные контуры** — движение хладагента в жидкой и паровой фазах, дросселирование через расширительный клапан.
- **Системы конденсата** — самотёчное стекание конденсата с охлаждающих батарей.

Три закона сохранения управляют любым потоком жидкости:

{{< formula display="true" >}}
\text{Масса:}\quad \dot{m}_1 = \dot{m}_2 = \rho A V = \text{const}
{{< /formula >}}

{{< formula display="true" >}}
\text{Импульс:}\quad \sum \vec{F} = \dot{m}(\vec{V}_2 - \vec{V}_1)
{{< /formula >}}

{{< formula display="true" >}}
\text{Энергия:}\quad \frac{P_1}{\rho g} + \frac{V_1^2}{2g} + z_1 + h_\text{нас} = \frac{P_2}{\rho g} + \frac{V_2^2}{2g} + z_2 + h_L
{{< /formula >}}

## Режимы потока и число Рейнольдса

Определяющим безразмерным параметром является число Рейнольдса:

{{< formula display="true" >}}
Re = \frac{\rho V D_\text{г}}{\mu} = \frac{V D_\text{г}}{\nu}
{{< /formula >}}

где {{< formula >}}D_\text{г} = 4A/P{{< /formula >}} — гидравлический диаметр, {{< formula >}}\nu{{< /formula >}} — кинематическая вязкость.

{{< table title="Режимы потока по числу Рейнольдса" >}}
| Режим | Re | Профиль скорости | f | Типичные HVAC-применения |
|---|---|---|---|---|
| Ламинарный | < 2300 | Параболический (Пуазейль) | 64/Re | Капиллярные трубки, масляные цепи |
| Переходный | 2300–4000 | Нестабильный | — | Избегают проектированием |
| Турбулентный | > 4000 | Логарифмический, плоский | Муди/Коулбрук | Все основные трубопроводы и воздуховоды |
{{< /table >}}

В большинстве HVAC-трубопроводов Re = 20 000–200 000, поток турбулентный. Ламинарный режим встречается только в специальных узлах (капиллярные дроссели, микроканальные теплообменники).

## Потери давления: основные уравнения

### Линейные (по длине) потери — уравнение Дарси-Вейсбаха

{{< formula display="true" >}}
\Delta P_\text{лин} = \lambda \frac{L}{D} \cdot \frac{\rho V^2}{2}
{{< /formula >}}

Коэффициент гидравлического трения {{< formula >}}\lambda{{< /formula >}} определяется по диаграмме Муди или уравнению Коулбрука–Уайта:

{{< formula display="true" >}}
\frac{1}{\sqrt{\lambda}} = -2\lg\!\left(\frac{k_s}{3{,}7\,D} + \frac{2{,}51}{Re\sqrt{\lambda}}\right)
{{< /formula >}}

Явное приближение Свами–Джейна (погрешность ≤ 2 %):

{{< formula display="true" >}}
\lambda = \frac{0{,}25}{\left[\lg\!\left(\dfrac{k_s}{3{,}7D} + \dfrac{5{,}74}{Re^{0{,}9}}\right)\right]^2}
{{< /formula >}}

### Местные потери

{{< formula display="true" >}}
\Delta P_\text{мест} = \zeta \frac{\rho V^2}{2}
{{< /formula >}}

где {{< formula >}}\zeta{{< /formula >}} — коэффициент местного сопротивления (колено, тройник, клапан и т. д.).

### Суммарные потери системы

{{< formula display="true" >}}
\Delta P_\text{сист} = \sum_i \lambda_i \frac{L_i}{D_i} \frac{\rho V_i^2}{2} + \sum_j \zeta_j \frac{\rho V_j^2}{2}
{{< /formula >}}

Кривая системы параболична: {{< formula >}}\Delta P \propto Q^2{{< /formula >}}.

## Насосы и вентиляторы: базовые соотношения

Рабочая точка системы находится на пересечении кривой насоса (вентилятора) и кривой системы. Законы подобия при изменении частоты вращения:

{{< formula display="true" >}}
\frac{Q_2}{Q_1} = \frac{n_2}{n_1}, \quad \frac{\Delta P_2}{\Delta P_1} = \left(\frac{n_2}{n_1}\right)^{\!2}, \quad \frac{N_2}{N_1} = \left(\frac{n_2}{n_1}\right)^{\!3}
{{< /formula >}}

Кубическая зависимость мощности от частоты вращения обусловливает экономический эффект частотного регулирования: снижение скорости на 20 % сокращает потребляемую мощность примерно вдвое.

## Структура раздела

Раздел организован по нарастающей сложности:

1. **Свойства жидкостей** — плотность, вязкость, давление пара, поверхностное натяжение для воды, растворов гликоля, воздуха и хладагентов.
2. **Гидростатика** — распределение давления в покоящейся жидкости, манометрия, расширительные баки.
3. **Кинематика жидкостей** — поля скоростей, линии тока, завихрённость.
4. **Уравнения сохранения** — непрерывности, Навье–Стокса, Бернулли с выводами.
5. **Анализ размерности** — теорема Бакингема, число Рейнольдса, Фруда, Маха.
6. **Поток в трубопроводах** — ламинарный, турбулентный, местные сопротивления, расчёт сетей методом Харди–Кросса.
7. **Насосы и вентиляторы** — кривые производительности, законы подобия, NPSH, кавитация, частотное регулирование.
8. **Внешний поток** — обтекание тел, пограничный слой, аэродинамика здания.
9. **Сжимаемый поток** — число Маха, критические режимы, дросселирование хладагента.
