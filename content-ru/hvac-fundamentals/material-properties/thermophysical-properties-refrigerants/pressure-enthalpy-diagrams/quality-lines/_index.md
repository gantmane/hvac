Линии паросодержания (quality lines) — семейство кривых внутри купола насыщения на диаграмме P–h, соединяющих состояния с одинаковой массовой долей паровой фазы. Они являются ключевым инструментом для определения состояния хладагента в двухфазной зоне: на входе в испаритель после дросселирования, в процессе кипения, и на выходе испарителя перед всасыванием в компрессор.

## Определение паросодержания

**Паросодержание** (vapour quality, степень сухости) {{< formula >}}x{{< /formula >}} — безразмерная массовая доля паровой фазы в двухфазной смеси:

{{< formula display="true" >}}
x = \frac{m_{\text{пар}}}{m_{\text{жидк}} + m_{\text{пар}}} \in [0;\, 1]
{{< /formula >}}

При {{< formula >}}x = 0{{< /formula >}} — вся масса в жидкой фазе (насыщенная жидкость, линия кипения). При {{< formula >}}x = 1{{< /formula >}} — вся масса в паровой фазе (насыщенный пар, линия росы). В интервале {{< formula >}}0 < x < 1{{< /formula >}} жидкость и пар сосуществуют.

## Термодинамические соотношения

Все удельные свойства двухфазной смеси выражаются через паросодержание:

{{< formula display="true" >}}
h = h_f(P) + x \cdot h_{fg}(P)
{{< /formula >}}

{{< formula display="true" >}}
s = s_f(P) + x \cdot s_{fg}(P)
{{< /formula >}}

{{< formula display="true" >}}
v = v_f(P) + x \cdot v_{fg}(P) = v_f + x(v_g - v_f)
{{< /formula >}}

где {{< formula >}}h_f, s_f, v_f{{< /formula >}} — свойства насыщенной жидкости, {{< formula >}}h_g, s_g, v_g{{< /formula >}} — насыщенного пара, {{< formula >}}h_{fg} = h_g - h_f{{< /formula >}} — теплота парообразования (кДж/кг).

Обратная задача — определение {{< formula >}}x{{< /formula >}} по известной энтальпии при данном давлении:

{{< formula display="true" >}}
x = \frac{h - h_f}{h_{fg}} = \frac{h - h_f}{h_g - h_f}
{{< /formula >}}

## Геометрия линий паросодержания

На диаграмме lg P–h линии качества {{< formula >}}x = 0{,}1;\, 0{,}2;\, \ldots;\, 0{,}9{{< /formula >}} расположены между левой ветвью купола ({{< formula >}}x = 0{{< /formula >}}) и правой ветвью ({{< formula >}}x = 1{{< /formula >}}). Все линии сходятся в критической точке. Вблизи критической точки линии качества сближены — теплота парообразования {{< formula >}}h_{fg} \to 0{{< /formula >}}. Вдали от критической точки (при низких давлениях) линии расходятся — {{< formula >}}h_{fg}{{< /formula >}} велика.

Для каждого давления {{< formula >}}P_i{{< /formula >}} и заданного {{< formula >}}x{{< /formula >}} горизонтальная координата:

{{< formula display="true" >}}
h(P_i,\, x) = h_f(P_i) + x \cdot h_{fg}(P_i)
{{< /formula >}}

Эти точки при разных {{< formula >}}P_i{{< /formula >}} соединяются плавной кривой — линия качества {{< formula >}}x{{< /formula >}}.

## Паросодержание после дросселирования

При изоэнтальпийном дросселировании через ТРВ: {{< formula >}}h_4 = h_3{{< /formula >}}. Если жидкость перед ТРВ находится при давлении конденсации {{< formula >}}P_{\text{конд}}{{< /formula >}}, температуре {{< formula >}}T_3{{< /formula >}} (с переохлаждением {{< formula >}}\Delta T_{\text{пер.ох}}{{< /formula >}}), то:

{{< formula display="true" >}}
h_3 = h_f(P_{\text{конд}}) - c_{pl} \cdot \Delta T_{\text{пер.ох}}
{{< /formula >}}

Паросодержание на выходе ТРВ при давлении испарителя {{< formula >}}P_{\text{исп}}{{< /formula >}}:

{{< formula display="true" >}}
x_4 = \frac{h_3 - h_f(P_{\text{исп}})}{h_{fg}(P_{\text{исп}})}
{{< /formula >}}

Доля хладагента, мгновенно испаряющегося при дросселировании (**флэш-газ**, flash gas), равна {{< formula >}}x_4{{< /formula >}}. Оставшаяся жидкая доля {{< formula >}}(1 - x_4){{< /formula >}} поглощает теплоту в испарителе.

## Паросодержание в испарителе

По мере кипения в испарителе {{< formula >}}x{{< /formula >}} растёт от {{< formula >}}x_4{{< /formula >}} до {{< formula >}}x_{\text{вых}}{{< /formula >}}. Для идеального испарителя без перегрева: {{< formula >}}x_{\text{вых}} = 1{{< /formula >}} (насыщенный пар). На практике с участком перегрева: точка всасывания компрессора — за пределами купола ({{< formula >}}x > 1{{< /formula >}} формально не применяется; состояние — перегретый пар).

Удельная холодопроизводительность:

{{< formula display="true" >}}
q_e = h_1 - h_4 = (h_g - h_f) \cdot (1 - x_4) + c_{pv} \cdot \Delta T_{\text{пер}} = h_{fg}(1 - x_4) + c_{pv} \Delta T_{\text{пер}}
{{< /formula >}}

где первый член — теплота кипения жидкой фракции, второй — теплота перегрева пара.

## Численный пример — паросодержание в цикле R-407C

**Условие:** R-407C, конденсация при точке росы (dew point) 40 °C, переохлаждение жидкости 5 К. Испарение при точке кипения (bubble point) −5 °C. Определить паросодержание на входе в испаритель и холодопроизводительность.

По NIST REFPROP v10 для R-407C (смесь R-32/R-125/R-134a = 23/25/52 % мас.):

{{< table title="Свойства насыщения R-407C" >}}
| Параметр | При конденсации | При испарении |
|----------|----------------|---------------|
| Температура росы / кипения, °C | 40,0 / 35,6 | −5,0 / −11,1 |
| Давление, кПа | 1794 | 442 |
| {{< formula >}}h_f{{< /formula >}}, кДж/кг | 260,2 | 200,9 |
| {{< formula >}}h_g{{< /formula >}}, кДж/кг | 421,8 | 408,7 |
| {{< formula >}}h_{fg}{{< /formula >}}, кДж/кг | 161,6 | 207,8 |
| {{< formula >}}c_{pl}{{< /formula >}}, кДж/(кг·К) | 1,52 | — |
{{< /table >}}

Энтальпия жидкости перед ТРВ (переохлаждение 5 К от точки росы):

{{< formula display="true" >}}
h_3 = h_f(40\,°\text{C}) - c_{pl} \cdot \Delta T_{\text{пер.ох}} = 260{,}2 - 1{,}52 \times 5 = 252{,}6 \text{ кДж/кг}
{{< /formula >}}

Паросодержание на входе в испаритель:

{{< formula display="true" >}}
x_4 = \frac{h_3 - h_f(P_{\text{исп}})}{h_{fg}(P_{\text{исп}})} = \frac{252{,}6 - 200{,}9}{207{,}8} = \frac{51{,}7}{207{,}8} = 0{,}249
{{< /formula >}}

Около 25 % хладагента испаряется при дросселировании в виде флэш-газа. Эта фракция не участвует в полезном охлаждении в испарителе.

Если на выходе испарителя — перегрев 5 К (перегретый пар при {{< formula >}}T_1 = 0{{< /formula >}} °C, {{< formula >}}P_1 = 442{{< /formula >}} кПа):

{{< formula display="true" >}}
h_1 \approx 415{,}2 \text{ кДж/кг} \quad \text{(из REFPROP)}
{{< /formula >}}

Удельная холодопроизводительность:

{{< formula display="true" >}}
q_e = h_1 - h_4 = 415{,}2 - 252{,}6 = 162{,}6 \text{ кДж/кг}
{{< /formula >}}

Для сравнения: если бы переохлаждения не было ({{< formula >}}\Delta T_{\text{пер.ох}} = 0{{< /formula >}}, {{< formula >}}h_3 = 260{,}2{{< /formula >}} кДж/кг), то {{< formula >}}x_4 = 0{,}285{{< /formula >}} и {{< formula >}}q_e = 155{,}0{{< /formula >}} кДж/кг. Переохлаждение 5 К даёт прирост {{< formula >}}q_e{{< /formula >}} на 4,9 %.

## Линии паросодержания и зеотропные смеси

Для зеотропных смесей (R-407C, R-417A) паросодержание определяется через состав жидкой и паровой фаз, которые различаются. В двухфазной области температура не постоянна при постоянном давлении — изотермы не совпадают с изобарами. Линии паросодержания для смесей на диаграмме P–h рассчитываются по правилам смешивания (mixing rules) в REFPROP и наносятся относительно средневесовой (bulk) энтальпии смеси. При измерениях в системах с зеотропными смесями необходимо различать:

- **Точку кипения** (bubble point temperature): начало испарения при {{< formula >}}x = 0{{< /formula >}}.
- **Точку росы** (dew point temperature): конец конденсации при {{< formula >}}x = 1{{< /formula >}}.

Перегрев всасывания для ТРВ задаётся относительно точки росы при давлении испарителя.

## Ошибки при работе с линиями паросодержания

**Смешение P–h и T–s диаграмм.** На T–s диаграмме линии качества наклонены влево, на P–h — тоже наклонены, но в другом направлении. Нельзя читать количество с диаграммы неверного типа.

**Игнорирование флэш-газа.** Расчёт площади теплообмена испарителя только по {{< formula >}}h_{fg}{{< /formula >}} (полное испарение) без учёта начального {{< formula >}}x_4 > 0{{< /formula >}} приводит к занижению площади.

**Зеотропные смеси.** Для R-407C давление 1794 кПа соответствует точке росы 40 °C и точке кипения 35,6 °C. Использование единственной «температуры насыщения» ведёт к ошибке в определении {{< formula >}}x{{< /formula >}}.
