Критические пороги содержания влаги для конкретных материалов определяют количественные границы, выше которых начинается биологическое повреждение или деградация механических свойств. Эти пороги существенно различаются по материалам и определяют требования к паровому контролю, вентиляции и системе осушения в каждом конкретном узле ограждающей конструкции.

## Древесные материалы

Содержание влаги (moisture content, MC) в древесине выражается как отношение массы воды к массе абсолютно сухой древесины:

{{< formula display="true" >}}
MC\,(\%) = \frac{m_{wet} - m_{dry}}{m_{dry}} \times 100
{{< /formula >}}

### Критические пороги для массивной древесины

{{< table title="Критические состояния влажности массивной древесины" >}}
| Состояние | MC, % | Биологический риск | Состояние материала |
|---|---|---|---|
| Равновесие в помещении | 6–12 | Нет | Стабильное, нормальная эксплуатация |
| Повышенное | 16–19 | Зона наблюдения | Возможны деформации |
| Критический порог (CMC) | 19–22 | Низкий–умеренный | Начало грибкового риска |
| Активная деградация | 25–28 | Высокий | Активный рост белой/бурой гнили |
| Насыщение | >28–30 | Очень высокий | Точка насыщения волокна, свободная вода |
{{< /table >}}

**Точка насыщения волокна (fibre saturation point, FSP)** — MC при котором стенки клеток насыщены, а полости клеток ещё свободны. FSP большинства хвойных пород: 25–30 %. Ниже FSP изменение MC влечёт усушку/разбухание. Выше FSP — свободная вода в полостях клеток создаёт оптимальные условия для гнилостных грибов.

### Видовая вариативность

{{< table title="Сравнение критических показателей по видам древесины" >}}
| Порода | FSP, % | Природная стойкость | CMC, % | Примечание |
|---|---|---|---|---|
| Сосна обыкновенная (заболонь) | 27–29 | Низкая | 19–21 | Высокая восприимчивость к плесени |
| Ель европейская | 28–32 | Низкая | 20–22 | Высокая восприимчивость |
| Пихта Дугласа | 28–30 | Умеренная | 21–23 | Типовой каркасный материал СА |
| Дуб черешчатый | 24–26 | Высокая | 22–25 | Ядровая древесина устойчива |
| Лиственница сибирская | 25–27 | Высокая | 22–24 | Высокое содержание смол |
| Кедр западный красный | 22–25 | Очень высокая | 25–30 | Природные фунгициды (тujaplizин) |
| Тсуга западная | 26–30 | Низкая | 20–22 | Требует защитной обработки |
{{< /table >}}

Природная стойкость определяется по EN 350 / AWPA стандартам.

### Композитные деревянные материалы

{{< table title="Критические параметры влажности для деревянных композитов" >}}
| Материал | CMC, % | Режим отказа | Рекомендуемый максимум при эксплуатации |
|---|---|---|---|
| Фанера наружная (WBP-клей) | 25–28 | Расслоение, гниль | ≤18 % |
| Фанера внутренняя (MR-клей) | 18–22 | Расслоение | ≤16 % |
| OSB (oriented strand board) | 20–24 | Разбухание кромок, расслоение | ≤18 % |
| ДСП (particleboard, класс P2) | 16–19 | Необратимое разбухание | ≤13 % |
| МДФ (MDF, fibreboard) | 14–18 | Разбухание, потеря прочности | ≤12 % |
| LVL (laminated veneer lumber) | 22–26 | Расслоение клеевых швов | ≤16 % |
| CLT (cross-laminated timber) | 20–24 | Расслоение, деформация | ≤15 % |
| Клеёный брус (glulam) | 24–28 | Расслоение, трещины | ≤15 % |
{{< /table >}}

OSB и ДСП особенно чувствительны к влаге: кромочное разбухание начинается при MC ~20 % и часто необратимо. Деформация кромок ухудшает монтажные стыки и создаёт пути воздушной утечки.

### Численный пример: оценка риска для OSB

**Условие.** Плита OSB 11 мм находится при поверхностной ОВ 85 % и T = 15 °C в течение 45 суток (начало отопительного сезона).

По изотерме сорбции OSB: при ОВ 85 %, T = 15 °C → EMC ≈ 19,5 % (таблица ASHRAE Fundamentals гл. 26).

Критический CMC для OSB: 20–22 %.

EMC (19,5 %) < CMC (20–22 %) — технически ниже порога, но с запасом <1 %. С учётом неопределённости ±1,5 % при измерении ОВ — риск нельзя считать пренебрежимым.

30-дневное скользящее среднее ОВ > 80 % за 45 суток по критерию ASHRAE 160: **отказ** (превышение допустимых 30 суток для T_avg > 0 °C).

**Вывод.** Несмотря на то что EMC формально ниже CMC, критерий ASHRAE 160 нарушен. Это отражает консерватизм стандарта, учитывающего неопределённости реального монтажа.

## Гипсокартон

Поведение ГКЛ при увлажнении определяется раздельно для бумажной облицовки и гипсового ядра — из-за принципиально разных CMC.

### Компонентные пороги ГКЛ

{{< table title="Критические пороги влажности компонентов ГКЛ" >}}
| Компонент / тип ГКЛ | CMC, % | Последствие | Время до проявления плесени |
|---|---|---|---|
| Стандартная бумажная облицовка | >1,5–2,0 | Поверхностная плесень | 24–72 часа при постоянном намокании |
| Гипсовое ядро | >4–6 | Деградация прочности | 5–10 суток |
| ГКЛ тип X (огнестойкий) | >5–7 | Потеря огнестойкости | — |
| ГКЛ MR (влагостойкий, зелёный) | >7–9 | Отслоение покрытия | >14 суток |
| ГКЛ без бумаги (fibre-reinforced) | >9–12 | Ограниченный рост плесени | >21 суток |
| ГКЛ плесневостойкий (тип M) | >10–15 | Слабый рост на загрязнениях | >30 суток |
{{< /table >}}

Критическое различие: бумажная облицовка стандартного ГКЛ имеет CMC всего 1,5–2 %, что соответствует поверхностной ОВ 75–80 %. Это делает ГКЛ наиболее восприимчивым из распространённых строительных материалов.

### Равновесная влажность ГКЛ

{{< table title="EMC компонентов ГКЛ при различной ОВ (23 °C)" >}}
| ОВ, % | EMC ядра, % | EMC бумажной облицовки, % |
|---|---|---|
| 30 | 0,3 | 5,5 |
| 50 | 0,6 | 8,0 |
| 70 | 1,2 | 11,5 |
| 80 | 2,2 | 15,0 |
| 95 | 5,0 | 22,0 |
{{< /table >}}

При ОВ 80 % бумажная облицовка имеет EMC = 15 % — в 7 раз выше ядра. CMC бумаги (~1,5 %) достигается уже при ОВ 75–78 %. Гипсовое ядро при ОВ 80 % имеет EMC = 2,2 % — ниже своего CMC (4–6 %).

## Теплоизоляционные материалы

### Волокнистая теплоизоляция

{{< table title="Пороги влажности волокнистой изоляции" >}}
| Материал | CMC, % | Влияние на тепловые хар-ки | Биологический риск |
|---|---|---|---|
| Стекловата (необлицованная) | >1 | Рост λ ~4 % на 1 % MC | Низкий (неорганический субстрат) |
| Каменная вата | >2 | Рост λ ~3 % на 1 % MC | Низкий |
| Целлюлоза обработанная (борат) | >15 | Оседание, потеря R | Умеренный |
| Хлопковый войлок | >10 | Потеря теплоизоляции | Высокий |
{{< /table >}}

Стекловата и каменная вата не поддерживают прямой рост плесени, но удерживают влагу против соседних материалов (OSB, деревянные стойки). CMC волокнистой изоляции характеризует тепловую деградацию, не биологическую.

Увлажнение стекловаты с MC = 5 % (неполное насыщение) снижает эффективную теплопроводность с 0,036 до ~0,044 Вт/(м·К) (+22 %) согласно EN 12667.

### Жёсткая изоляция

{{< table title="Влагопоглощение и CMC жёсткой изоляции" >}}
| Материал | CMC, % | Влагопоглощение (по объёму) | Риск плесени |
|---|---|---|---|
| XPS (extruded polystyrene) | <3 | 0,2–0,4 % | Очень низкий |
| EPS (expanded polystyrene) | <5 | 2–5 % | Низкий |
| Полиизоцианурат, фольга | <2 | <0,05 % | Очень низкий |
| Полиизоцианурат, без облицовки | <4 | 0,5–1,5 % | Низкий |
| Плита минеральной ваты | >2 | <0,2 % | Очень низкий |
| Пробковая плита | >15 | 5–10 % | Умеренный |
{{< /table >}}

Закрытоячеистые пены (XPS, PIR с фольгой) поглощают минимум влаги. CMC для них характеризует стабильность размеров и R-значения, не биологический риск.

**Влияние влаги на R-значение EPS:** при увлажнении до 5 % объёма (тип EPS-100 в подземных условиях за 5 лет) λ возрастает с 0,034 до 0,040 Вт/(м·К) (+18 %). Это необходимо учитывать при долгосрочном проектировании подземных узлов.

## Бетон и каменная кладка

### Пороги влажности бетона

{{< table title="Критическая влажность бетона для специальных применений" >}}
| Применение | Критическая ОВ, % | CMC, % | Проблема |
|---|---|---|---|
| Укладка покрытия пола | >75 | >3,5 | Отслоение клея, разбухание покрытия |
| Структурный бетон (арматура) | >90 | >5,5 | Начало коррозии арматуры |
| Кладочные блоки (высолы) | >85 | >5,0 | Миграция солей, пятна |
| Фундаментные стены | >85 | >5,0 | Миграция влаги внутрь |
{{< /table >}}

Бетон измеряется методом зондов ОВ в соответствии с ASTM F2170. Зонды устанавливаются на глубине 40 % толщины перекрытия для плит, высыхающих с одной стороны. Критическая ОВ для укладки покрытия: большинство производителей требуют ≤75 % (некоторые ≤80 % для специальных клеёв).

|---|---|---|---|

## Равновесное содержание влаги древесины в зависимости от климата

Значения EMC (%) хвойной древесины по ASHRAE Fundamentals гл. 26 (таблица влажности воздуха):

{{< table title="EMC хвойной древесины при различных T и ОВ" >}}
| T, °C | ОВ 30 % | ОВ 50 % | ОВ 70 % | ОВ 80 % | ОВ 90 % |
|---|---|---|---|---|---|
| 4,4 | 6,3 | 9,5 | 13,5 | 16,5 | 20,5 |
| 15,6 | 6,0 | 9,0 | 12,8 | 15,8 | 19,5 |
| 26,7 | 5,7 | 8,5 | 12,2 | 15,0 | 18,5 |
| 37,8 | 5,3 | 8,0 | 11,5 | 14,2 | 17,5 |
{{< /table >}}

При повышении температуры EMC снижается: при T = 4,4 °C и ОВ 90 % → EMC = 20,5 % (выше CMC 19 %); при T = 26,7 °C и той же ОВ → EMC = 18,5 % (ниже CMC). Тёплые поверхности менее уязвимы при той же ОВ — важный аргумент в пользу тёплых стеновых пирогов.

## Методы измерения содержания влаги

{{< table title="Методы и точность измерения MC в строительных материалах" >}}
| Материал | Метод | Диапазон | Точность | Стандарт |
|---|---|---|---|---|
| Древесина | Резистивный влагомер | 6–30 % | ±2 % | — |
| Древесина | Ёмкостной влагомер | 5–30 % | ±1 % | — |
| Древесина | Гравиметрия (сушка в печи) | любой | ±0,1 % | ASTM D4442 |
| ГКЛ | Ёмкостной (спец. калибровка) | 0–15 % | ±1,5 % | — |
| ГКЛ | Гравиметрия | любой | ±0,2 % | — |
| Бетон | Зонды ОВ in situ | — | ±2 % ОВ | ASTM F2170 |
| Бетон | Тест CaCl₂ | — | качеств. | ASTM F1869 |
| Изоляция | Гравиметрия | любой | ±0,5 % | ASTM C1104 |
| Любой | Тепловизионное обследование | — | качеств. | ISO 6781 |
{{< /table >}}

**Тепловизионное обследование** (инфракрасная термография) по ISO 6781 / EN 13187 — неразрушающий метод обнаружения зон повышенной влажности по разнице в тепловой инерции материала. Влажные зоны проявляются как области с аномальной температурой поверхности. Метод применяется как скрининговый перед точечными измерениями.

## Рекомендации по проектированию

**Деревянные материалы:**
- Монтировать при MC ≤19 % (хвойные), ≤16 % (клеёный брус, CLT).
- Ориентировочный целевой MC при равновесии с климатом в ограждающей конструкции: 8–12 % (зависит от климатической зоны).
- Обеспечить вентиляцию полостей или паропроницаемость для высыхания строительной влаги за первый отопительный сезон.

**Гипсокартон:**
- Применять влагостойкий или плесневостойкий тип в ванных, подвалах, помещениях с повышенной влажностью.
- Обеспечить паровой контроль в соответствии с климатической зоной: в зонах 5–8 — паросдерживающий слой изнутри.
- Предохранять ГКЛ от намокания при строительстве: монтировать только в закрытом контуре.

**Теплоизоляция:**
- Волокнистая изоляция: предохранять от конденсации влаги. Если конструкция допускает конденсацию — применять закрытоячеистый ППУ или XPS.
- Жёсткая изоляция в контакте с грунтом: применять XPS или PIR с фольгой, не EPS без дренажа.

**Бетон:**
- Проверить MC перед укладкой покрытия по ASTM F2170 (зонды ОВ).
- Рассчитать время сушки по толщине и условиям вентиляции.
- Применять паросдерживающие плёнки под плитой для замедления поступления грунтовой влаги.

Пороги влажности, специфические для материалов, предоставляют количественные целевые показатели для стратегий управления влажностью. Поддержание MC ниже CMC обеспечивает долговечность конструкции, предотвращает биологическое повреждение и сохраняет тепловые и механические характеристики на протяжении расчётного срока службы здания.
