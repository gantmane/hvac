Диаграмма lg P–h (логарифм давления — энтальпия) является основным рабочим инструментом инженера систем ОВК для анализа холодильных циклов и расчёта параметров оборудования. По сравнению с T–s-диаграммой (диаграмма Молье в координатах температура–энтропия), диаграмма lg P–h позволяет непосредственно считывать работу компрессора и тепловые потоки в испарителе и конденсаторе как горизонтальные отрезки. Построение диаграммы основано на таблицах термодинамических свойств хладагента (NIST REFPROP v10, ASHRAE Handbook Fundamentals, гл. 30) и требует точного соблюдения координатных шкал, масштабов и семейств линий.

## Принципы выбора координатных осей

### Логарифмическая шкала давления

Давление насыщения хладагента меняется с температурой по закону, близкому к соотношению Клаузиуса–Клапейрона (Clausius–Clapeyron equation):

{{< formula display="true" >}}
\ln \frac{P_2}{P_1} = -\frac{h_{fg}}{R_{\text{уд}}} \left(\frac{1}{T_2} - \frac{1}{T_1}\right)
{{< /formula >}}

где {{< formula >}}h_{fg}{{< /formula >}} — теплота парообразования (кДж/кг), {{< formula >}}R_{\text{уд}}{{< /formula >}} — удельная газовая постоянная (Дж/(кг·К)), {{< formula >}}T{{< /formula >}} — абсолютная температура (К).

Это экспоненциальное соотношение означает, что на линейной шкале давления кривая насыщения была бы резко изогнута и плохо читаема при низких давлениях. Логарифмическая шкала преобразует её в удобную почти прямую линию и обеспечивает разрешение как для высоких давлений конденсатора (2–3 МПа), так и для низких давлений испарителя (0,1–0,5 МПа).

### Линейная шкала энтальпии

Ось энтальпии {{< formula >}}h{{< /formula >}} (кДж/кг) строится линейной. Это ключевое преимущество диаграммы lg P–h: изменение энтальпии при каждом процессе цикла пропорционально горизонтальному расстоянию, что позволяет непосредственно считывать удельную работу и теплоту как отрезки на оси.

По первому закону термодинамики для адиабатного компрессора:

{{< formula display="true" >}}
w_{\text{комп}} = h_2 - h_1
{{< /formula >}}

Горизонтальное расстояние между точками 1 и 2 на диаграмме прямо соответствует удельной работе (кДж/кг).

## Компоненты диаграммы

### Оси координат

**Горизонтальная ось — энтальпия h (кДж/кг):** диапазон охватывает от переохлаждённой жидкости до высокоперегретого пара. Для R-134a: 100–450 кДж/кг. Шаг основной сетки: 25–50 кДж/кг; промежуточных линий: 5–10 кДж/кг.

**Вертикальная ось — логарифм давления lg P (МПа):** диапазон включает рабочие давления испарителя и конденсатора с запасом. Пример для R-410A:

{{< table title="Пример шкалы давления для R-410A" >}}
| Давление, МПа | Соответствующая T_нас, °C |
|---------------|---------------------------|
| 0,30          | −40                       |
| 0,58          | −20                       |
| 1,08          | 0                         |
| 1,66          | 20                        |
| 2,42          | 40                        |
| 3,37          | 60                        |
| 4,90          | 70,1 (критическое)        |
{{< /table >}}

### Кривая насыщения (купол насыщения)

Купол (saturation dome) разделяет диаграмму на три области:

1. **Жидкостная область (слева)** — переохлаждённое жидкое состояние.
2. **Двухфазная область (внутри купола)** — жидкость и пар в равновесии; степень сухости {{< formula >}}x{{< /formula >}} от 0 до 1.
3. **Паровая область (справа)** — перегретый пар.

Левая граница купола — **линия кипения** ({{< formula >}}x = 0{{< /formula >}}, bubble line), правая — **линия росы** ({{< formula >}}x = 1{{< /formula >}}, dew line). Обе кривые сходятся в **критической точке** (critical point).

### Критическая точка

{{< table title="Критические параметры основных хладагентов" >}}
| Хладагент | {{< formula >}}T_c{{< /formula >}}, °C | {{< formula >}}P_c{{< /formula >}}, МПа | {{< formula >}}h_c{{< /formula >}}, кДж/кг | {{< formula >}}\rho_c{{< /formula >}}, кг/м³ |
|-----------|---------|---------|---------|---------|
| R-134a    | 101,1   | 4,059   | 389,6   | 511,9   |
| R-410A    | 70,1    | 4,901   | 282,6   | 459,0   |
| R-32      | 78,1    | 5,782   | 415,3   | 424,0   |
| R-407C    | 86,2    | 4,635   | 380,5   | 485,7   |
| R-744 (CO₂) | 31,1 | 7,377  | 332,3   | 467,6   |
{{< /table >}}

Выше критической точки купол заканчивается; вещество существует как однородная надкритическая (supercritical) фаза.

### Изотермы (T = const)

**В двухфазной области:** изотермы совпадают с изобарами — горизонтальные линии. Это следствие того, что {{< formula >}}T_{\text{нас}} = f(P){{< /formula >}} — однозначная зависимость.

**В жидкостной области:** изотермы почти вертикальны (слабая зависимость {{< formula >}}h{{< /formula >}} от {{< formula >}}P{{< /formula >}} для несжимаемой жидкости):

{{< formula display="true" >}}
\left(\frac{\partial h}{\partial P}\right)_T \approx v(1 - \beta T)
{{< /formula >}}

**В области перегрева:** изотермы изгибаются вправо и вниз; при низких давлениях приближаются к вертикали (поведение идеального газа, {{< formula >}}h = h(T){{< /formula >}}).

Изотермы наносятся с шагом 5 или 10 °C.

### Линии постоянной энтропии (изоэнтропы, s = const)

Изоэнтропы используются для построения пути идеального адиабатного сжатия. В области перегрева они имеют наклон вверх-вправо; в двухфазной области более крутые, чем изотермы.

Построение: по таблицам свойств при нескольких давлениях фиксируют состояние с данной энтропией {{< formula >}}s = \text{const}{{< /formula >}} и соединяют точки плавной кривой. Шаг нанесения: 0,05–0,1 кДж/(кг·К).

### Линии постоянного паросодержания (x = const)

Внутри купола наносятся линии {{< formula >}}x = 0{,}1;\, 0{,}2;\, \ldots;\, 0{,}9{{< /formula >}}. Каждая точка вычисляется как:

{{< formula display="true" >}}
h(P,\, x) = h_f(P) + x \cdot h_{fg}(P)
{{< /formula >}}

{{< formula display="true" >}}
s(P,\, x) = s_f(P) + x \cdot s_{fg}(P)
{{< /formula >}}

## Методика пошагового построения

### Шаг 1. Подготовка данных

Получить таблицы насыщения и перегрева из NIST REFPROP v10 или ASHRAE Handbook Fundamentals (гл. 30). Для каждого давления в диапазоне испарения–конденсации выписать:

- {{< formula >}}P, T_{\text{нас}}, h_f, h_g, s_f, s_g, \rho_f, \rho_g{{< /formula >}}.
- {{< formula >}}h_{fg} = h_g - h_f{{< /formula >}}.

Для перегретого пара при нескольких давлениях — {{< formula >}}h, s, v{{< /formula >}} при ряде температур.

### Шаг 2. Построение купола насыщения

1. На логарифмической оси давления разметить шкалу в МПа (декадные деления: 0,1; 1,0; 10,0 МПа).
2. Для каждого значения {{< formula >}}P{{< /formula >}} отложить точки насыщенной жидкости {{< formula >}}(h_f, P){{< /formula >}} и насыщенного пара {{< formula >}}(h_g, P){{< /formula >}}.
3. Соединить точки насыщенной жидкости плавной кривой (левая граница купола).
4. Соединить точки насыщенного пара (правая граница).
5. Обозначить критическую точку в вершине.

### Шаг 3. Нанесение изотерм

В двухфазной области изотермы — горизонтальные отрезки от левой до правой границы купола при данном {{< formula >}}P_{\text{нас}}(T){{< /formula >}}. В области перегрева: для каждой температуры {{< formula >}}T{{< /formula >}} при нескольких давлениях найти {{< formula >}}h(P, T){{< /formula >}} и соединить точки.

### Шаг 4. Нанесение изоэнтроп

Для значения {{< formula >}}s = s_1{{< /formula >}} при нескольких давлениях {{< formula >}}P{{< /formula >}} в области перегрева найти по таблицам {{< formula >}}T{{< /formula >}} и {{< formula >}}h{{< /formula >}}, соответствующие этой энтропии (интерполяция). Соединить точки кривой — это изоэнтропа.

### Шаг 5. Линии паросодержания

Для {{< formula >}}x = 0{,}1;\, 0{,}2;\, \ldots;\, 0{,}9{{< /formula >}} при нескольких давлениях вычислить {{< formula >}}h(P, x){{< /formula >}} и отметить точки внутри купола. Кривые проходят от критической точки вниз.

## Анализ цикла на построенной диаграмме

На готовой диаграмме lg P–h цикл парокомпрессионного холодильника строится как четырёхугольник. Геометрические соотношения:

{{< formula display="true" >}}
q_e = h_1 - h_4 \quad \text{(холодопроизводительность, кДж/кг)}
{{< /formula >}}

{{< formula display="true" >}}
w_{\text{комп}} = h_2 - h_1 \quad \text{(удельная работа, кДж/кг)}
{{< /formula >}}

{{< formula display="true" >}}
q_c = h_2 - h_3 \quad \text{(теплота конденсации, кДж/кг)}
{{< /formula >}}

{{< formula display="true" >}}
\text{COP} = \frac{q_e}{w_{\text{комп}}} = \frac{h_1 - h_4}{h_2 - h_1}
{{< /formula >}}

## Численный пример — построение и чтение цикла R-134a

**Исходные данные:** испарение при −10 °C, конденсация при 40 °C. По NIST REFPROP v10:

{{< table title="Данные насыщения R-134a" >}}
| T, °C | P, кПа | h_f, кДж/кг | h_g, кДж/кг | s_f, кДж/(кг·К) | s_g, кДж/(кг·К) |
|-------|--------|-------------|-------------|-----------------|-----------------|
| −10   | 200,7  | 186,7       | 392,3       | 0,951           | 1,733           |
| 40    | 1017   | 256,4       | 419,4       | 1,186           | 1,712           |
{{< /table >}}

**Точки цикла** (перегрев 5 К, переохлаждение 0 К, {{< formula >}}\eta_{is} = 1{,}0{{< /formula >}} для упрощения):

- Точка 1 (всасывание): {{< formula >}}P = 200{,}7{{< /formula >}} кПа, {{< formula >}}T = -5{{< /formula >}} °C, по REFPROP {{< formula >}}h_1 = 395{,}8{{< /formula >}} кДж/кг, {{< formula >}}s_1 = 1{,}734{{< /formula >}} кДж/(кг·К).
- Точка 2s (изоэнтропное нагнетание): {{< formula >}}P = 1017{{< /formula >}} кПа, {{< formula >}}s_2 = s_1 = 1{,}734{{< /formula >}} → {{< formula >}}h_{2s} = 432{,}1{{< /formula >}} кДж/кг.
- Точка 3: {{< formula >}}P = 1017{{< /formula >}} кПа, {{< formula >}}T = 40{{< /formula >}} °C, {{< formula >}}h_3 = 256{,}4{{< /formula >}} кДж/кг.
- Точка 4: {{< formula >}}h_4 = h_3 = 256{,}4{{< /formula >}} кДж/кг, {{< formula >}}P = 200{,}7{{< /formula >}} кПа.

Паросодержание на входе в испаритель:

{{< formula display="true" >}}
x_4 = \frac{h_4 - h_f}{h_{fg}} = \frac{256{,}4 - 186{,}7}{392{,}3 - 186{,}7} = \frac{69{,}7}{205{,}6} = 0{,}339
{{< /formula >}}

Расчёт цикла:

{{< formula display="true" >}}
q_e = 395{,}8 - 256{,}4 = 139{,}4 \text{ кДж/кг}, \quad w = 432{,}1 - 395{,}8 = 36{,}3 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
\text{COP}_{\text{идеал}} = \frac{139{,}4}{36{,}3} = 3{,}84
{{< /formula >}}

## Выбор масштаба и рекомендации по оформлению

**Диапазон давлений:** от 0,5{{< formula >}}P_c{{< /formula >}} (минимум) до {{< formula >}}P_c{{< /formula >}} для стандартных циклов; для низкотемпературных систем — включать давления ниже 100 кПа.

**Диапазон энтальпий:** минимум на 30–50 кДж/кг ниже {{< formula >}}h_f{{< /formula >}} при температуре испарения, максимум на 50 кДж/кг выше {{< formula >}}h_g{{< /formula >}} при максимальном перегреве.

**Размер диаграммы:** не менее 200×250 мм для удобства графических измерений.

**Контроль корректности:** левая и правая ветви купола не должны пересекаться ниже критической точки; изотермы в области пара монотонно возрастают слева направо; критическая точка совпадает с табличными данными.
