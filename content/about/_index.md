## BIM + AI and BIM + Python for HVAC

Beyond traditional HVAC design and BIM coordination, I actively develop in the emerging intersection of **digital engineering, Python automation, and AI for MEP / HVAC workflows** — a niche where few practicing HVAC engineers can credibly operate.

**BIM + Python for HVAC — already in production use on my projects:**

- Dynamo + Python (Revit API) automation of HVAC schedules, equipment lists, and duct / pipe parameter propagation
- Automated clash-report generation and routing to discipline owners
- Model QA scripts: checks for missing parameters, orphaned families, coordinate drift
- Bulk family creation and library management via scripted workflows
- Export of HVAC calculation inputs from Revit to external load-calculation tools and back

**BIM + AI — active development direction:**

- **AI-assisted clash triage** — using LLMs to classify, cluster, and prioritize Navisworks clash reports so engineers spend time on real issues, not duplicates
- **LLM-generated HVAC specifications** — turning design intent notes into draft specification text, with human review as the final step
- **Vector search over project archives** — semantic search across years of HVAC drawings, specs, and calculations to accelerate peer review and precedent lookup
- **Code-compliance copilots** — LLMs assisting with SNiP / ASHRAE / local code lookup and cross-referencing during design review
- **Python + local LLM inference** for confidential project environments where cloud AI is not permitted

This places me in a rare blue-ocean profile: a chief HVAC engineer with 20+ years of project delivery *and* a working, hands-on stack for BIM automation and AI assistance. Most BIM-AI tooling today is built by software developers without domain engineering experience, and most HVAC engineers do not code. I do both.
