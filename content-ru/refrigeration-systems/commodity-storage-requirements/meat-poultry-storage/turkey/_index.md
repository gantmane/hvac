Хранение индейки сопряжено с характерными особенностями: крупные туши (5–15 кг) требуют длительного времени охлаждения, высокое содержание влаги (73–75 %) ускоряет микробный рост, а разнообразие форм продукта — от целых тушек до фарша — требует дифференцированных режимов хранения. Надлежащий контроль температуры критически важен для управления *Salmonella spp.*, *Campylobacter jejuni* и *Listeria monocytogenes*. Нормативную базу составляют ASHRAE Handbook — Refrigeration (2022), ГОСТ 28547, СП 60.13330.2020, HACCP и ТР ТС 021/2011.

## Процессы охлаждения и замораживания

### Воздушное охлаждение (air chilling)

Воздушное охлаждение снижает температуру тушки с убойной до хранения без контакта с водой, что исключает микробное перекрёстное загрязнение в ванне охладителя.

{{< table title="Параметры воздушного охлаждения тушек индейки" >}}
| Параметр | Значение | Влияние |
|---|---|---|
| Температура воздуха | −2…+2 °C | При T < −2 °C риск поверхностного подмерзания |
| Скорость воздуха | 2–4 м/с | Более высокая — ускоряет охлаждение |
| Относительная влажность | 92–98 % | Потери массы < 2 % |
| Время охлаждения, целая тушка | 3–6 ч | Зависит от массы птицы |
| Время охлаждения, части | 1–2 ч | Геометрия благоприятна |
| Целевая финальная температура | 0–4 °C | Ниже 4 °C — обязательно |
{{< /table >}}

## Расчет холодильной нагрузки

**Суммарная тепловая нагрузка склада:**

{{< formula display="true" >}}
Q_{\text{общ}} = Q_{\text{прод}} + Q_{\text{стен}} + Q_{\text{инф}} + Q_{\text{освещ}} + Q_{\text{вент}} + K_{\text{зап}}
{{< /formula >}}

**Составляющие для типовой камеры:**

{{< table title="Составляющие тепловой нагрузки для типовой камеры хранения свежей индейки" >}}
| Составляющая | Типовое значение | Основание расчета |
|---|---|---|
| Охлаждение продукта | 80–120 Вт/м³ | По начальному ΔT |
| Теплопередача через ограждения | 15–25 Вт/м² | U × A × ΔT |
| Инфильтрация воздуха | 10–20 % от суммы | Дверные проемы |
| Освещение (LED) | 5–10 Вт/м² | Световая нагрузка |
| Персонал | 250 Вт/чел. | Явное + скрытое тепло |
| Коэффициент запаса | 1,10–1,15 | Проектный резерв |
{{< /table >}}

**Пример расчета холодильной нагрузки при скоростном замораживании тушки:**

Требуется заморозить 500 кг тушек индейки от 4 °C до −18 °C за 12 ч. $c_{p,+} = 3{,}45$ кДж/(кг·К), $L = 250$ кДж/кг, $c_{p,-} = 1{,}90$ кДж/(кг·К), $T_f = -2{,}2$ °C:

{{< formula display="true" >}}
Q = m\left[c_{p,+}(T_i - T_f) + L + c_{p,-}(T_f - T_{\text{fin}})\right]
{{< /formula >}}

{{< formula display="true" >}}
Q = 500\!\left[3{,}45\!\times\!(4{+}2{,}2) + 250 + 1{,}90\!\times\!(-2{,}2{+}18)\right]
= 500\,(21{,}4 + 250 + 30{,}0) = 500 \times 301{,}4 = 150\,700\;\text{кДж}
{{< /formula >}}

Средняя мощность за 12 ч: $P = 150\,700 / (12 \times 3600) \approx 3{,}5$ кВт. С учетом потерь через ограждения, вентиляторов (теплопритоки от электроприводов) и инфильтрации выбирается агрегат ≈ 6–7 кВт.

## Упаковка и деградация качества

{{< table title="Методы упаковки и влияние на срок хранения свежей и замороженной индейки" >}}
| Тип упаковки | Проницаемость по O₂ | Барьер по влаге | Расширение срока (свежее) | Расширение срока (заморозка) |
|---|---|---|---|---|
| Полиэтиленовая пленка | Высокая | Умеренная | 0–1 сут | 2–3× от базового |
| MAP (CO₂/N₂, < 0,5 % O₂) | Низкая | Высокая | 7–14 сут | 4–5× от базового |
| Вакуумная skin-упаковка | Очень низкая | Очень высокая | 10–21 сут | 6–8× от базового |
{{< /table >}}

Состав газовой смеси MAP для птицы:
- CO₂: 20–40 % — бактериостатический эффект;
- N₂: 60–80 % — вытеснение O₂, инертный заполнитель;
- O₂: < 0,5 % — минимизация окисления.

Морозный ожог (freezer burn) предотвращается поддержанием ОВ 90–95 %, скоростью воздуха < 1,0 м/с у продукта и барьерной упаковкой с проницаемостью по O₂ < 5 см³/(м²·сут·атм).
