## Основы управления

PID контроллеры регулируют процессы HVAC через обратные связи. Алгоритм объединяет три действия управления — пропорциональное, интегральное и дифференциальное — для минимизации ошибки между заданным значением и измеренным значением.

## Математическая основа

Уравнение управления PID в непрерывной форме:

{{< formula display="true" >}}
u(t) = K_p e(t) + K_i \int_0^t e(\tau) d\tau + K_d \frac{de(t)}{dt}
{{< /formula >}}

Где:
- $u(t)$ = выход контроллера (0-100%)
- $e(t)$ = сигнал ошибки = заданное значение - измерение
- $K_p$ = коэффициент пропорционального усиления
- $K_i$ = коэффициент интегрального усиления
- $K_d$ = коэффициент дифференциального усиления

### Дискретная реализация

Цифровые контроллеры используют дискретно-временную аппроксимацию:

{{< formula display="true" >}}
u_n = K_p e_n + K_i T_s \sum_{k=0}^n e_k + K_d \frac{e_n - e_{n-1}}{T_s}
{{< /formula >}}

Где:
- $T_s$ = время дискретизации (секунды)
- $n$ = индекс текущего образца

### Пропорциональное действие

Прямой ответ на текущую ошибку:

{{< formula display="true" >}}
u_P = K_p \cdot e
{{< /formula >}}

**Характеристики:**
- Немедленная коррекция
- Пропорциональная полоса: $PB = 100 / K_p$ (%)
- Неотъемлемое смещение в установившемся состоянии

**Пример:**
Если $K_p = 2,0$ и $e = 3°C$:

{{< formula display="true" >}}
u_P = 2,0 \times 3 = 6\% \text{ увеличение выхода}
{{< /formula >}}

### Интегральное действие

Накапливает ошибку во времени для устранения смещения:

{{< formula display="true" >}}
u_I = K_i \int_0^t e(\tau) d\tau
{{< /formula >}}

**Характеристики:**
- Устраняет ошибку в установившемся состоянии
- Медленнее, чем пропорциональное действие
- Может вызвать перерегулирование и колебания
- Время интегрирования: $T_i = K_p / K_i$ (секунды)

### Дифференциальное действие

Реагирует на скорость изменения:

{{< formula display="true" >}}
u_D = K_d \frac{de}{dt}
{{< /formula >}}

**Характеристики:**
- Прогностическое управление
- Затухает перерегулирование
- Чувствительно к шуму измерения
- Время дифференцирования: $T_d = K_d / K_p$ (секунды)

## Стандартная форма

Альтернативная формулировка PID с использованием постоянных времени:

{{< formula display="true" >}}
u(t) = K_p \left[ e(t) + \frac{1}{T_i} \int_0^t e(\tau) d\tau + T_d \frac{de(t)}{dt} \right]
{{< /formula >}}

Где:
- $T_i$ = время интегрирования (время сброса)
- $T_d$ = время дифференцирования (время скорости)

## Методы настройки

### Метод предельной чувствительности Циглера-Николса

1. Установите $K_i = 0$ и $K_d = 0$
2. Увеличивайте $K_p$ до появления устойчивых колебаний
3. Запишите предельный коэффициент усиления $K_u$ и период $P_u$
4. Вычислите параметры PID:

{{< formula display="true" >}}
\begin{aligned}
K_p &= 0,6 K_u \\
T_i &= 0,5 P_u \\
T_d &= 0,125 P_u
\end{aligned}
{{< /formula >}}

**Пример:**
- $K_u = 8,0$
- $P_u = 120$ секунд

{{< formula display="true" >}}
\begin{aligned}
K_p &= 0,6 \times 8,0 = 4,8 \\
K_i &= K_p / T_i = 4,8 / 60 = 0,08 \\
K_d &= K_p \times T_d = 4,8 \times 15 = 72
\end{aligned}
{{< /formula >}}

### Метод Коэна-Куна

Для процессов первого порядка с запаздыванием (FOPDT):

{{< formula display="true" >}}
G(s) = \frac{K e^{-\theta s}}{\tau s + 1}
{{< /formula >}}

Параметры PID:

{{< formula display="true" >}}
\begin{aligned}
K_p &= \frac{1,35 \tau}{K \theta} \left(1 + \frac{\theta}{4\tau}\right) \\
T_i &= \theta \left(\frac{2,5 + 0,5\theta/\tau}{1 + 0,6\theta/\tau}\right) \\
T_d &= \frac{0,37 \theta}{1 + 0,2\theta/\tau}
\end{aligned}
{{< /formula >}}

### Настройка лямбда

Укажите желаемую постоянную времени замкнутого цикла $\lambda$:

{{< formula display="true" >}}
\begin{aligned}
K_p &= \frac{\tau}{K(\lambda + \theta)} \\
T_i &= \tau \\
T_d &= 0
\end{aligned}
{{< /formula >}}

**Рекомендация:** $\lambda = 1,5\theta$ для хорошей производительности

### Метрики производительности

**Время нарастания ($t_r$):**
Время достижения 90% заданного значения

**Перерегулирование ($M_p$):**
{{< formula display="true" >}}
M_p = \frac{y_{max} - y_{ss}}{y_{ss}} \times 100\%
{{< /formula >}}

**Время установления ($t_s$):**
Время оставаться в пределах ±2% заданного значения

**Интегральная абсолютная ошибка (IAE):**
{{< formula display="true" >}}
IAE = \int_0^\infty |e(t)| dt
{{< /formula >}}

## Стратегии защиты от интегрального ветра

Интегральный ветер возникает, когда выход контроллера насыщается. Реализуйте защиту:

### Метод обратного расчета

{{< formula display="true" >}}
\frac{du_i}{dt} = K_i e + \frac{1}{T_t}(u_{sat} - u)
{{< /formula >}}

Где:
- $T_t$ = постоянная времени отслеживания (обычно $T_t = \sqrt{T_i T_d}$)
- $u_{sat}$ = насыщенный выход

### Условное интегрирование

Отключите интегральное действие, когда:
- Выход на пределах И
- Ошибка увеличила бы интегральное действие

{{< formula display="true" >}}
u_i(n+1) = \begin{cases}
u_i(n) + K_i T_s e(n) & \text{если не насыщено} \\
u_i(n) & \text{если насыщено и } e \cdot \text{sign}(u - u_{sat}) > 0
\end{cases}
{{< /formula >}}

## Фильтрация производной

Необработанная производная усиливает шум измерения. Применяют фильтр первого порядка:

{{< formula display="true" >}}
\frac{de_f}{dt} = \frac{1}{T_f}\left(\frac{de}{dt} - e_f\right)
{{< /formula >}}

Где $T_f = T_d / N$ и $N = 3$ до 10

Дискретная аппроксимация:

{{< formula display="true" >}}
u_{D,n} = \frac{K_d}{T_f + T_s}\left[T_f \cdot u_{D,n-1} + K_d(e_n - e_{n-1})\right]
{{< /formula >}}

## Каскадное управление

Внутренний быстрый цикл управляет положением клапана; внешний медленный цикл управляет температурой:

    PC --> SP2[Заданное значение клапана]
    SP2 --> SC[Вторичный контроллер<br/>Положение клапана]

**Последовательность настройки:**
1. Сначала настройте вторичный (быстрый) цикл
2. Настройте первичный (медленный) цикл с активным вторичным циклом
3. Время интегрирования первичного цикла: $T_{i,primary} \ge 4 \times T_{i,secondary}$

## Адаптация коэффициента усиления

Адаптируйте параметры PID к условиям работы:

{{< formula display="true" >}}
K_p(x) = K_{p,0} + \alpha x
{{< /formula >}}

Где $x$ = переменная адаптации (нагрузка, заданное значение и т.д.)

**Пример:** управление ящиком VAV
- Высокий расход: Низкий коэффициент усиления (быстрый клапан)
- Низкий расход: Высокий коэффициент усиления (вялый клапан)

## Практическая реализация

### Переход без толчков

При переключении с ручного на автоматический режим:

{{< formula display="true" >}}
u_i(t_0) = u_{manual} - K_p e(t_0) - K_d \frac{de(t_0)}{dt}
{{< /formula >}}

### Ограничение скорости выхода

Защитите исполнительные механизмы от чрезмерных скоростей изменения:

{{< formula display="true" >}}
\Delta u_{max} = \pm \frac{u_{range}}{t_{full-stroke}} \times T_s
{{< /formula >}}

## Устранение неисправностей

{{< table title="Проблемы управления PID и решения" >}}
| Симптом | Вероятная причина | Исправление |
|---------|---------------|------------|
| **Колебания** | Чрезмерное усиление | Снизьте $K_p$, увеличьте $T_i$ |
| **Медленный ответ** | Низкое усиление | Увеличьте $K_p$, снизьте $T_i$ |
| **Смещение** | Нет интегрирования | Включите интегральное действие |
| **Перерегулирование** | Быстрое интегрирование | Увеличьте $T_i$ |
| **Чувствительность к шуму** | Усиление производной | Добавьте фильтрацию, снизьте $K_d$ |
| **Интегральный ветер** | Насыщение | Реализуйте защиту от ветра |
{{< /table >}}

## Продвинутые темы

### Модельно-прогностическое управление (MPC)

Оптимизирует траекторию управления по горизонту прогноза:

{{< formula display="true" >}}
\min_{u} \sum_{k=1}^{N_p} \left[ Q(y_k - r_k)^2 + R(u_k - u_{k-1})^2 \right]
{{< /formula >}}

Где:
- $N_p$ = горизонт прогноза
- $Q$, $R$ = матрицы взвешивания
- $y_k$ = прогнозируемый выход
- $r_k$ = эталонная траектория

### Адаптивное PID

Алгоритмы самонастройки адаптируют параметры в режиме реального времени:

1. Рекурсивная оценка параметров
2. Проектирование контроллера по оцененной модели
3. Обновление коэффициентов PID
4. Повтор в каждом цикле

## Заключение

Управление PID остается доминирующей стратегией в автоматизации HVAC благодаря простоте и надежности. Надлежащая настройка согласует динамику контроллера с характеристиками процесса, достигая стабильного регулирования с минимальным перерегулированием.

Три действия управления служат различным целям: пропорциональное обеспечивает немедленную коррекцию, интегральное устраняет ошибку в установившемся состоянии, а дифференциальное затухает колебания. Понимание этих механизмов позволяет систематически устранять неисправности и оптимизировать производительность.

Современные реализации включают защиту от интегрального ветра, фильтрацию производной и адаптивные функции для обработки реальных ограничений и возмущений.
