Влагонакопительная ёмкость (moisture storage capacity) — способность строительного материала поглощать и удерживать влагу из паровой и жидкой фаз в зависимости от относительной влажности и температуры. Это свойство определяет переходное поведение конструкции: материал с высокой ёмкостью буферизует колебания влажности, временно поглощая избыточный пар и снижая риск поверхностной конденсации. Параметры влагонакопительной ёмкости необходимы для нестационарных HAM-расчётов (WUFI, DELPHIN) по ISO 15026 / EN 15026.

## Механизмы сорбции влаги

### Гигроскопический диапазон (φ = 0–98%)

**Мономолекулярная адсорбция (φ < 30%):** молекулы воды занимают гидрофильные поверхностные участки материала в один слой (BET-адсорбция). Характерна для всех пористых материалов.

**Многослойная адсорбция (φ = 30–70%):** на первичном монослое формируются дополнительные молекулярные слои.

**Капиллярная конденсация (φ = 70–98%):** конденсация пара в мелких порах (r < 0,1 мкм) по уравнению Кельвина:

{{< formula display="true" >}}
\ln\!\left(\frac{p_v}{p_{\text{sat}}}\right) = -\frac{2 \sigma M_w}{R T \rho_w r} \approx -\frac{0{,}106}{r} \quad \text{(r в нм)}
{{< /formula >}}

где σ = 0,0728 Н/м — поверхностное натяжение воды; r — радиус пор.

**Поглощение (absorption):** для гигроскопичных материалов (дерево, целлюлоза) молекулы воды встраиваются в структуру полимерных цепей целлюлозы и гемицеллюлозы.

### Капиллярный диапазон (φ > 98%, жидкая вода)

При прямом контакте с жидкой водой поры заполняются через капиллярное всасывание. Давление всасывания (suction pressure):

{{< formula display="true" >}}
p_c = \frac{2 \sigma \cos\theta}{r} \quad \text{[Па]}
{{< /formula >}}

Коэффициент капиллярного всасывания A\_w (водопоглощение), кг/(м²·ч^0,5), характеризует скорость капиллярного транспорта.

## Изотермы сорбции

Изотерма сорбции (sorption isotherm) связывает равновесное влагосодержание w (кг/м³) с относительной влажностью φ при постоянной температуре.

### Аппроксимация по модели Oswin

{{< formula display="true" >}}
w(\varphi) = A \cdot \left(\frac{\varphi}{1 - \varphi}\right)^B
{{< /formula >}}

где A, B — параметры аппроксимации для конкретного материала.

### Гистерезис

Кривая десорбции (высыхание) лежит выше кривой адсорбции (увлажнение): при одинаковом φ материал удерживает больше влаги при высыхании, чем поглощает при увлажнении. Разница достигает 20–40% в диапазоне φ = 40–70%. WUFI и DELPHIN учитывают гистерезис через раздельные изотермы адсорбции/десорбции.

## Буферизующая способность: значение MBV

Практическое значение буферизации влаги (Moisture Buffer Value, MBV) количественно определяет способность материала сглаживать суточные колебания влажности в помещении. Определяется по методу NORDTEST (2005):

{{< formula display="true" >}}
\text{MBV} = \frac{\Delta m}{A \cdot \Delta\varphi} \quad \text{[г/(м²·\%ОВ)]}
{{< /formula >}}

где Δm — масса поглощённой/выделенной влаги за цикл, г; A — площадь открытой поверхности, м²; Δφ — амплитуда изменения относительной влажности, %.

Стандартный цикл NORDTEST: 8 ч при φ = 75%, 16 ч при φ = 33%; Δφ = 42%.

{{< table title="Классификация буферизующей способности (NORDTEST, ASHRAE Fundamentals гл. 25)" >}}
| Класс | MBV, г/(м²·%ОВ) | Типичные материалы |
|---|---|---|
| Незначительная | < 0,2 | Алюминий, стекло, ПВХ, краска на поверхности |
| Ограниченная | 0,2–0,5 | Гипсокартон, бетон, кирпич |
| Умеренная | 0,5–1,0 | Дерево, гипсовая штукатурка, ГКЛ без покрытия |
| Хорошая | 1,0–2,0 | Целлюлозная изоляция, глиняная штукатурка |
| Отличная | > 2,0 | Древесные плиты (обнажённые), натуральные волокна |
{{< /table >}}

## Глубина проникновения влаги

Буферизация ограничена глубиной, на которую влага успевает проникнуть за период суточного цикла. Характерная глубина проникновения:

{{< formula display="true" >}}
d_p = \sqrt{\frac{\delta_p}{\xi \cdot \omega}} \quad \text{[м]}
{{< /formula >}}

где δ\_p — паропроницаемость материала, кг/(м·с·Па); ξ = dw/dφ · (p\_sat / ρ\_w) — дифференциальная влагоёмкость, кг/(м³·Па); ω = 2π/τ — круговая частота цикла (τ = 86 400 с для суточного).

Для деревянной панели (δ\_p = 2×10⁻¹¹ кг/(м·с·Па), dw/dφ = 1,2 кг/м³/% → ξ ≈ 5×10⁻⁵ кг/(м³·Па)):

{{< formula display="true" >}}
d_p = \sqrt{\frac{2 \times 10^{-11}}{5 \times 10^{-5} \cdot 7{,}27 \times 10^{-5}}} \approx \sqrt{5{,}5 \times 10^{-3}} \approx 74\ \text{мм}
{{< /formula >}}

Практический вывод: лишь верхние 50–75 мм деревянных панелей реально участвуют в суточной буферизации; более глубокие слои задействуются только в сезонных циклах.

## Численный пример: буферная ёмкость внутренней отделки (офис, Москва)

### Исходные данные

Помещение: 80 м², H = 3 м. Отделка: гипсокартон 12,5 мм (MBV = 0,4 г/(м²·%ОВ)), поверхность открыта (без краски).

Суточное изменение φ: от 40% (день, работа) до 60% (ночь, нет людей). Δφ = 20%.

Все поверхности (стены + потолок + пол): A = 2(80 + 160) + 80 ≈ 560 м².

### Масса буферизованной влаги

{{< formula display="true" >}}
\Delta m = \text{MBV} \cdot A \cdot \Delta\varphi = 0{,}4 \cdot 560 \cdot 20 = 4480\ \text{г} = 4{,}48\ \text{кг}
{{< /formula >}}

Если бы отделка имела нулевую буферизацию, для поддержания φ = 40% при тех же условиях потребовалась бы осушка 4,48 кг воды в сутки сверх штатной нагрузки.

При замене ГКЛ на глиняную штукатурку (MBV = 1,5):

{{< formula display="true" >}}
\Delta m = 1{,}5 \cdot 560 \cdot 20 = 16\,800\ \text{г} = 16{,}8\ \text{кг}
{{< /formula >}}

Буферизующая ёмкость возрастает в 3,75 раза — существенное снижение нагрузки на систему ОВК.

## Влияние на риск конденсации

Высокая влагонакопительная ёмкость снижает риск поверхностной конденсации, поглощая часть поступающего пара до того, как он достигнет точки насыщения на холодной поверхности. Но это буферизация временная: при длительном воздействии (недели) конструкция насыщается и буферное действие иссякает. По ASHRAE 160 критерий — скользящее среднее φ\_surf за 30 суток, а не мгновенное значение, что косвенно учитывает буферизующий эффект.

Материалы с высокой ёмкостью также увеличивают время, необходимое для высыхания: δm = ξ · Δφ — объём влаги, который нужно удалить при снижении φ. Это необходимо учитывать при расчёте времени высыхания строительной влаги.

## Параметры для WUFI-расчётов

Для нестационарного HAM-расчёта (EN 15026 / ISO 15026) необходимы:

{{< table title="Минимальный набор гигротермальных параметров для WUFI" >}}
| Параметр | Единицы | Метод определения |
|---|---|---|
| Изотерма сорбции w(φ) | кг/м³ | ASTM C1498, ISO 12571 (метод эксикатора) |
| Свободное влагонасыщение w\_sat | кг/м³ | ISO 10545-3 (вакуумное насыщение) |
| Коэффициент A\_w | кг/(м²·с^0,5) | ISO 15148 (капиллярное всасывание) |
| δ\_p(φ) — зависимость от влажности | кг/(м·с·Па) | EN ISO 12572 (метод чашки при разных ОВ) |
| λ(w) — зависимость от влажности | Вт/(м·K) | EN 12667, коэффициент b\_λ |
{{< /table >}}

**Начальные условия:** для расчётов по ASHRAE 160 принимают начальное влагосодержание, соответствующее равновесию при φ = 50% (80% RH для кирпичной кладки новостройки). Верификация начальной влажности — полевыми измерениями (резистивные датчики, микроволновой анализ).
