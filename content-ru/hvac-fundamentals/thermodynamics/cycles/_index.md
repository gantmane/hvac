## Цикл Карно как эталон эффективности

Цикл Карно (Carnot cycle) состоит из четырёх полностью обратимых процессов и задаёт теоретический максимум эффективности для любого цикла, работающего между двумя тепловыми резервуарами с температурами T_H и T_L (абсолютными).

### Холодильная машина Карно

{{< formula display="true" >}}
\text{COP}_{R,Carnot} = \frac{T_L}{T_H - T_L}
{{< /formula >}}

### Тепловой насос Карно

{{< formula display="true" >}}
\text{COP}_{HP,Carnot} = \frac{T_H}{T_H - T_L} = \text{COP}_{R,Carnot} + 1
{{< /formula >}}

### Числовой пример: влияние температуры конденсации

**Условие.** Холодильная машина: T_испарения = 5 °C (278 К). Рассчитать COP_Carnot при температурах конденсации 30, 40 и 50 °C. Оценить, как рост температуры конденсации снижает эффективность.

{{< table title="COP_Carnot в зависимости от температуры конденсации при T_evap = 5 °C" >}}
| T_cond, °C | T_H, К | T_H − T_L, К | COP_Carnot | Снижение COP, % |
|---|---|---|---|---|
| 30 | 303 | 25 | 11,12 | — |
| 40 | 313 | 35 | 7,94 | −29 |
| 50 | 323 | 45 | 6,18 | −44 |
{{< /table >}}

Вывод: снижение температуры конденсации на 10 К повышает максимально достижимый COP примерно на 30–40 %. Именно это обосновывает применение испарительных конденсаторов и охлаждаемых водой конденсаторов.

## Стандартный цикл паровой компрессии

### Идеальный цикл (1-2s-3-4)

Идеальный (теоретический) цикл паровой компрессии включает четыре процесса:

{{< diagram title="Идеальный цикл паровой компрессии на P-h диаграмме" >}}
```mermaid
graph LR
  A["1: насыщенный пар\n(вход компрессора)"] -->|"1→2s: изоэнтропное\nсжатие"| B["2s: перегретый пар\n(выход компрессора)"]
  B -->|"2s→3: изобарная\nконденсация"| C["3: насыщенная\nжидкость"]
  C -->|"3→4: изоэнтальпийное\nдросселирование"| D["4: двухфазная смесь\n(вход испарителя)"]
  D -->|"4→1: изобарное\nиспарение"| A
```
{{< /diagram >}}

### Уравнения идеального цикла

| Компонент | Уравнение |
|---|---|
| Испаритель | {{< formula >}}q_e = h_1 - h_4{{< /formula >}} |
| Компрессор | {{< formula >}}w_c = h_{2s} - h_1{{< /formula >}} |
| Конденсатор | {{< formula >}}q_c = h_{2s} - h_3{{< /formula >}} |
| Расширительный клапан | {{< formula >}}h_4 = h_3{{< /formula >}} |

Тепловой баланс (первый закон для всего цикла):

{{< formula display="true" >}}
q_c = q_e + w_c
{{< /formula >}}

COP охлаждения:

{{< formula display="true" >}}
\text{COP}_R = \frac{q_e}{w_c} = \frac{h_1 - h_4}{h_{2s} - h_1}
{{< /formula >}}

### Реальный цикл (1-2-3'-4)

Реальный цикл отличается от идеального:
- **Сжатие 1→2**: политропное с η_s = 0,72–0,85 вместо изоэнтропного
- **Конденсатор**: переохлаждение жидкости (3 К) повышает q_e; перепад давления снижает COP
- **Испаритель**: перегрев пара (5–8 К) защищает компрессор; перепад давления на стороне всасывания

{{< formula display="true" >}}
h_{2,real} = h_1 + \frac{h_{2s} - h_1}{\eta_s}
{{< /formula >}}

### Полный числовой пример: цикл на R-410A

**Условие.** Система кондиционирования на R-410A. Условия:
- T_исп = 7 °C, перегрев 6 К → P₁ = 1,128 МПа
- T_конд = 46 °C, переохлаждение 4 К → P₂ = 3,060 МПа  
- η_s (компрессор) = 0,78
- Холодопроизводительность: 35 кВт

По REFPROP (R-410A):

| Точка | T, °C | P, МПа | h, кДж/кг | s, кДж/(кг·К) |
|---|---|---|---|---|
| 1 | 13 | 1,128 | 437,2 | 1,749 |
| 2s | — | 3,060 | 477,4 | 1,749 |
| 2 | — | 3,060 | 488,7 | — |
| 3 | 42 | 3,060 | 274,6 | — |
| 4 | 7 | 1,128 | 274,6 | — |

{{< formula display="true" >}}
h_2 = h_1 + \frac{h_{2s} - h_1}{\eta_s} = 437{,}2 + \frac{477{,}4 - 437{,}2}{0{,}78} = 437{,}2 + 51{,}5 = 488{,}7 \text{ кДж/кг}
{{< /formula >}}

{{< formula display="true" >}}
\dot{m}_r = \frac{\dot{Q}_e}{h_1 - h_4} = \frac{35}{437{,}2 - 274{,}6} = \frac{35}{162{,}6} = 0{,}215 \text{ кг/с}
{{< /formula >}}

{{< formula display="true" >}}
\dot{W}_c = \dot{m}_r(h_2 - h_1) = 0{,}215 \times (488{,}7 - 437{,}2) = 0{,}215 \times 51{,}5 = 11{,}1 \text{ кВт}
{{< /formula >}}

{{< formula display="true" >}}
\text{COP}_R = \frac{35}{11{,}1} = 3{,}15
{{< /formula >}}

{{< formula display="true" >}}
\text{COP}_{Carnot} = \frac{T_L}{T_H - T_L} = \frac{280}{319 - 280} = 7{,}18
{{< /formula >}}

{{< formula display="true" >}}
\eta_{II} = \frac{3{,}15}{7{,}18} = 0{,}44 \quad (44\% \text{ от Карно})
{{< /formula >}}

## Цикл теплового насоса

Тепловой насос использует тот же цикл паровой компрессии, что и холодильная машина, но полезным эффектом является тепло конденсатора, а не холод испарителя. Переключение между режимами охлаждения и нагрева осуществляется четырёхходовым реверсивным клапаном.

{{< formula display="true" >}}
\text{COP}_{HP} = \frac{q_c}{w_c} = \frac{h_2 - h_3}{h_2 - h_1} = \text{COP}_R + 1
{{< /formula >}}

### Точка баланса (balance point)

Наружная температура, при которой производительность теплового насоса равна тепловой нагрузке здания. Ниже точки баланса требуется резервный нагрев.

{{< formula display="true" >}}
t_{bal} = t_{design} - \frac{\dot{Q}_{HP,rated}}{\dot{Q}_{design}} (t_{design} - t_{out,design})
{{< /formula >}}

**Числовой пример.** Тепловая нагрузка здания при −20 °C (расчётные условия) = 12 кВт. Тепловой насос при 7 °C (номинальные условия): Q_HP = 10 кВт; при −7 °C: Q_HP = 6 кВт. Точка баланса ≈ −8 °C — при более низкой наружной температуре включается дополнительный электронагреватель.

### Сезонная производительность

- **SCOP (Seasonal COP)** — средневзвешенный COP за отопительный сезон по EN 14825:2022
- **HSPF (Heating Seasonal Performance Factor)** — стандарт DOE/AHRI для рынка США
- Потери на оттайку снижают SCOP на 5–15 % в климатах с влажными зимами

## Абсорбционный цикл

В абсорбционном цикле механический компрессор заменён термохимическим «тепловым компрессором»: испаритель → абсорбер → насос раствора → генератор → конденсатор. Привод — теплота (пар, горячая вода, прямое сжигание газа).

### Распространённые рабочие пары

{{< table title="Рабочие пары абсорбционных машин" >}}
| Хладагент | Абсорбент | Применение | Ограничения |
|---|---|---|---|
| H₂O (вода) | LiBr (бромид лития) | Охлаждение воды (t > 0 °C) | Кристаллизация при t < 5 °C, коррозия |
| NH₃ (аммиак) | H₂O (вода) | Охлаждение до −60 °C, промышленность | Токсичность, сложность ректификации |
{{< /table >}}

### Энергетический баланс одноступенчатой машины LiBr–H₂O

{{< formula display="true" >}}
\text{COP}_{abs} = \frac{\dot{Q}_e}{\dot{Q}_g + \dot{W}_p} \approx \frac{\dot{Q}_e}{\dot{Q}_g}
{{< /formula >}}

Работа насоса раствора {{< formula >}}\dot{W}_p{{< /formula >}} составляет < 1 % от {{< formula >}}\dot{Q}_g{{< /formula >}} и обычно пренебрегается.

Тепловой баланс всей машины:

{{< formula display="true" >}}
\dot{Q}_g + \dot{Q}_e = \dot{Q}_c + \dot{Q}_a
{{< /formula >}}

где {{< formula >}}\dot{Q}_a{{< /formula >}} — теплота абсорбера, {{< formula >}}\dot{Q}_c{{< /formula >}} — теплота конденсатора.

### Типичные COP

{{< table title="COP абсорбционных машин по типам" >}}
| Тип | COP охлаждения | Температура привода |
|---|---|---|
| Одноступенчатая LiBr–H₂O | 0,65–0,75 | 80–110 °C |
| Двухступенчатая LiBr–H₂O | 1,0–1,35 | 140–180 °C |
| Трёхступенчатая LiBr–H₂O | 1,5–1,7 | 200–230 °C |
| Одноступенчатая NH₃–H₂O | 0,55–0,65 | 90–120 °C |
{{< /table >}}

### Анализ ограничений и применимость

Абсорбционный цикл экономически оправдан когда:
1. Доступна дешёвая тепловая энергия (отходящее тепло, ТЭЦ, сбросной пар)
2. Электроэнергия дорога или ограничена
3. Требуется тихая работа без вибраций (чувствительные производства)

Ограничения: COP ниже, чем у компрессионных машин; большие габариты; риск кристаллизации раствора LiBr при низкой нагрузке.

## Транскритический цикл CO₂ (R-744)

Диоксид углерода имеет критическую точку при T_cr = 31,0 °C и P_cr = 7,377 МПа. При работе в условиях высокой летней температуры конденсация выше T_cr невозможна — цикл становится транскритическим (transcritical).

### Особенности транскритического цикла

В транскритическом цикле вместо конденсатора используется **газовый охладитель** (gas cooler): хладагент охлаждается без фазового перехода при давлении выше P_cr (типично 80–120 бар). Процесс в газовом охладителе — изобарное охлаждение с большим скользящим температурным профилем.

{{< formula display="true" >}}
\text{COP}_{CO_2} = \frac{h_1 - h_4}{h_2 - h_1}
{{< /formula >}}

### Оптимальное давление газового охладителя

Для транскритического цикла существует оптимальное давление нагнетания P_opt, при котором COP максимален:

{{< formula display="true" >}}
P_{opt} \approx (2{,}778 - 0{,}0159\,t_{gc,out}) \cdot t_{gc,out} + a
{{< /formula >}}

Эмпирическая формула Liao et al. (аппроксимация): {{< formula >}}P_{opt} \approx 2{,}778 t_{gc,out} - 0{,}0159 t_{gc,out}^2 + C{{< /formula >}}, где t_gc,out — температура CO₂ на выходе газового охладителя (°C).

Внутренний теплообменник (IHX) между выходом газового охладителя и всасыванием компрессора значительно повышает COP транскритического цикла (типичный прирост 10–20 %).

### Области применения CO₂ в HVAC

- Тепловые насосы для нагрева воды (60–90 °C): COP = 3–5 (EcoCute — Япония, Европа)
- Коммерческое холодильное оборудование в супермаркетах
- Транспортные холодильные установки
- Контуры с вторичными хладоносителями

## Методы повышения эффективности цикла

### Переохлаждение (subcooling)

Дополнительное охлаждение жидкого хладагента ниже температуры насыщения увеличивает удельную холодопроизводительность q_e без изменения работы компрессора:

{{< formula display="true" >}}
\Delta q_e = c_{p,liq} \cdot \Delta T_{SC}
{{< /formula >}}

Прирост COP при переохлаждении на {{< formula >}}\Delta T_{SC}{{< /formula >}} К:

{{< formula display="true" >}}
\frac{\Delta\text{COP}}{\text{COP}} \approx \frac{c_{p,liq} \cdot \Delta T_{SC}}{q_e}
{{< /formula >}}

Для R-410A: c_p,liq ≈ 1,7 кДж/(кг·К); при q_e = 160 кДж/кг переохлаждение 5 К даёт прирост COP ≈ 5,3 %.

### Теплообменник жидкость–пар (IHX / суперегрев за счёт переохлаждения)

Тепло переохлаждения жидкой линии передаётся паровой линии всасывания. Выгодно для хладагентов с высоким значением {{< formula >}}\partial c_p / \partial T{{< /formula >}} (R-134a, R-1234yf); для R-410A практически нейтрально.

### Двухступенчатое сжатие с промежуточным охлаждением

Снижение работы сжатия и температуры нагнетания при степени давления π > 5–6:

{{< formula display="true" >}}
w_{2-stage} = w_{stage1} + w_{stage2} = \frac{k}{k-1}RT_1\left[\pi_1^{\frac{k-1}{k}} - 1\right] + \frac{k}{k-1}RT_m\left[\pi_2^{\frac{k-1}{k}} - 1\right]
{{< /formula >}}

Оптимальное распределение: {{< formula >}}\pi_1 = \pi_2 = \sqrt{\pi_{total}}{{< /formula >}}.

### Экономайзерный цикл (flash economizer)

Промежуточный сепаратор Flash позволяет испарить часть жидкости при среднем давлении; образовавшийся пар подаётся в промежуточную ступень компрессора. Применяется в спиральных и винтовых компрессорах.

Прирост холодопроизводительности ≈ 10–20 % без увеличения массового расхода через испаритель; улучшение COP ≈ 5–12 %.

### Компрессоры с переменной скоростью (VFD)

Инверторное управление скоростью компрессора позволяет оптимизировать работу при частичной нагрузке. Прирост сезонной эффективности по сравнению с односкоростным компрессором:

{{< formula display="true" >}}
\Delta\text{SEER} = \int_0^{8760} \left[\text{COP}(load_\tau, T_{out,\tau}) - \text{COP}_{1-speed}\right] \dot{Q}_{load,\tau}\, d\tau \Big/ \int_0^{8760} \dot{W}_{1-speed}\, d\tau
{{< /formula >}}

На практике: SEER инверторной системы на 30–60 % выше, чем фиксированной скорости.

## Анализ эффективности по второму закону

Эффективность второго закона (second-law efficiency):

{{< formula display="true" >}}
\eta_{II} = \frac{\text{COP}_{actual}}{\text{COP}_{Carnot}}
{{< /formula >}}

{{< table title="Типичные значения η_II для оборудования HVAC" >}}
| Тип оборудования | COP (типичный) | COP_Carnot (T_L=5°C, T_H=45°C) | η_II |
|---|---|---|---|
| Бытовой кондиционер | 2,5–3,5 | 6,95 | 0,36–0,50 |
| Коммерческий чиллер с воздушным конденсатором | 3,0–4,5 | 6,95 | 0,43–0,65 |
| Чиллер с водяным охлаждением | 4,5–6,5 | 6,95 | 0,65–0,94 |
| Абсорбционный чиллер (2-ступ.) | 1,1–1,3 | 6,95 | 0,16–0,19 |
| Транскритический CO₂ тепловой насос | 3,5–5,0 | (T_L=10°C, T_H=80°C) ≈ 4,9 | 0,71–1,02* |
{{< /table >}}

*При T_H = 80 °C и T_L = 10 °C COP_Carnot = 353/(353−283) = 5,04. Высокоэффективные CO₂ тепловые насосы приближаются к пределу Карно.

## Типичные ошибки проектирования

1. **Завышенная температура конденсации при расчёте.** Расчётные параметры должны соответствовать реальным условиям: наружная температура воздуха 97,5-% пиковой летней погоды (ASHRAE Handbook — Fundamentals, Chapter 14).
2. **Игнорирование падения давления в трубопроводах.** Перепад давления на стороне всасывания 50 кПа снижает COP на 2–5 %.
3. **Неоптимальный перегрев.** Слишком малый перегрев (< 3 К) — риск гидравлического удара; слишком большой (> 15 К) — избыточная перегрева нагнетания и снижение объёмной производительности.
4. **Отсутствие анализа частичной нагрузки.** Системы работают на полной нагрузке менее 5–10 % от числа часов работы; сезонная эффективность определяется работой при 25–75 % нагрузки.
