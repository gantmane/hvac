Естественная (свободная) конвекция возникает без внешнего принудительного движения жидкости. Её единственный движитель — разность плотностей в неоднородно нагретой жидкости, создающая архимедовые (подъёмные) силы. В HVAC естественная конвекция определяет поведение плинтусных и лучистых систем отопления, стратификацию воздуха в высоких помещениях, теплообмен у наружных стен и окон при слабом ветре.

## Физический механизм

Нагретый вблизи поверхности воздух расширяется ($\rho$ убывает) и поднимается. Этому препятствуют вязкие силы. Плотность жидкости в линейном приближении:

{{< formula display="true" >}}
\rho \approx \rho_0 [1 - \beta(T - T_0)]
{{< /formula >}}

**Коэффициент объёмного расширения** $\beta$ [1/К]: для идеального газа $\beta = 1/T_f$ (K⁻¹, где $T_f$ — абсолютная температура плёнки). Для воды: $\beta \approx 0{,}000207$ К⁻¹ при 20°С.

## Определяющие безразмерные числа

### Число Грасгофа

{{< formula display="true" >}}
Gr_L = \frac{g \beta (T_s - T_\infty) L^3}{\nu^2}
{{< /formula >}}

Физический смысл: отношение архимедовых сил к квадрату вязких сил. Аналог числа Рейнольдса для естественной конвекции.

Режимы течения:
- $Gr_L < 10^9$: ламинарное течение (пограничный слой)
- $Gr_L > 10^{10}$: турбулентное течение

### Число Рэлея

{{< formula display="true" >}}
Ra_L = Gr_L \cdot Pr = \frac{g \beta \Delta T L^3}{\nu \alpha}
{{< /formula >}}

Обобщает эффекты плавучести и тепловой диффузии. Критическое значение для перехода к турбулентности у вертикальной пластины: $Ra_L \approx 10^9$.

## Вертикальная пластина (стена)

### Корреляция Черчилля–Чу (весь диапазон Ra)

{{< formula display="true" >}}
\overline{Nu}_L = \left\{0{,}825 + \frac{0{,}387\,Ra_L^{1/6}}{\left[1 + (0{,}492/Pr)^{9/16}\right]^{8/27}}\right\}^2
{{< /formula >}}

Применима для: $10^{-1} < Ra_L < 10^{12}$, любое $Pr$.

Упрощённые формы:
- Ламинарная ($10^4 < Ra < 10^9$): $\overline{Nu}_L = 0{,}59\,Ra_L^{1/4}$
- Турбулентная ($10^9 < Ra < 10^{13}$): $\overline{Nu}_L = 0{,}10\,Ra_L^{1/3}$

### Числовой пример: теплопотери через наружную стену

**Задача.** Наружная стена высотой $L = 3$ м при $T_s = 5°$С (внутренняя поверхность при низком U-значении). Внутренний воздух $T_\infty = 20°$С, неподвижный.

Свойства воздуха при $T_f = 12{,}5°$С: $\nu = 14{,}82 \times 10^{-6}$ м²/с, $k = 0{,}0253$ Вт/(м·К), $Pr = 0{,}712$, $\beta = 1/285{,}5 = 3{,}504 \times 10^{-3}$ К⁻¹.

{{< formula display="true" >}}
Ra_L = \frac{9{,}81 \times 3{,}504 \times 10^{-3} \times 15 \times 3^3}{14{,}82 \times 10^{-6} \times \frac{14{,}82 \times 10^{-6}}{0{,}712}} = \frac{9{,}81 \times 3{,}504 \times 10^{-3} \times 15 \times 27}{14{,}82 \times 10^{-6} \times 20{,}81 \times 10^{-6}}
{{< /formula >}}

{{< formula display="true" >}}
Ra_L = \frac{13{,}95}{3{,}084 \times 10^{-10}} = 4{,}52 \times 10^{10} \quad\text{(турбулентная область)}
{{< /formula >}}

{{< formula display="true" >}}
\overline{Nu}_L = \left\{0{,}825 + \frac{0{,}387 \times (4{,}52 \times 10^{10})^{1/6}}{\left[1 + (0{,}492/0{,}712)^{9/16}\right]^{8/27}}\right\}^2
{{< /formula >}}

Вычислим знаменатель: $[1 + 0{,}691^{0,5625}]^{0,296} = [1 + 0{,}797]^{0,296} = 1{,}797^{0,296} = 1{,}173$.

$(4{,}52 \times 10^{10})^{1/6} = (45{,}2 \times 10^9)^{1/6} = 45{,}2^{1/6} \times 10^{1,5} = 1{,}870 \times 31{,}62 = 59{,}1$.

{{< formula display="true" >}}
\overline{Nu}_L = (0{,}825 + 0{,}387 \times 59{,}1 / 1{,}173)^2 = (0{,}825 + 19{,}50)^2 = (20{,}33)^2 = 413
{{< /formula >}}

{{< formula display="true" >}}
h = \frac{413 \times 0{,}0253}{3{,}0} = 3{,}48 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

Это типичное значение для медленного конвективного потока у холодной стены.

## Горизонтальные поверхности

### Нагретая поверхность лицом вверх / охлаждённая лицом вниз

{{< formula display="true" >}}
\overline{Nu}_L = 0{,}54\,Ra_L^{1/4} \quad (10^4 < Ra < 10^7)
\qquad
\overline{Nu}_L = 0{,}15\,Ra_L^{1/3} \quad (10^7 < Ra < 10^{11})
{{< /formula >}}

Характерная длина: $L = A_s/P$ (площадь поверхности / периметр).

### Нагретая поверхность лицом вниз / охлаждённая лицом вверх

{{< formula display="true" >}}
\overline{Nu}_L = 0{,}27\,Ra_L^{1/4} \quad (10^5 < Ra < 10^{10})
{{< /formula >}}

Нагретый потолок менее эффективен, так как подъёмные силы не способствуют отводу тепла. $h$ примерно в 3 раза меньше, чем для нагретого пола.

## Горизонтальный цилиндр (трубопроводы)

{{< formula display="true" >}}
\overline{Nu}_D = \left\{0{,}60 + \frac{0{,}387\,Ra_D^{1/6}}{\left[1 + (0{,}559/Pr)^{9/16}\right]^{8/27}}\right\}^2 \quad (Ra_D < 10^{12})
{{< /formula >}}

Применяется для расчёта естественной конвекции от неизолированных трубопроводов в воздухе.

## Замкнутые полости (воздушные прослойки в ограждениях)

### Вертикальная прямоугольная полость (стенная воздушная прослойка)

Для полости высотой $H$, шириной $\delta$ с горячей и холодной вертикальными стенками:

{{< formula display="true" >}}
Nu_\delta = 0{,}22 \left(\frac{Pr}{0{,}2 + Pr} Ra_\delta\right)^{0,28} \left(\frac{H}{\delta}\right)^{-1/4} \quad (10^3 < Ra_\delta < 10^{10})
{{< /formula >}}

Эффективная теплопроводность прослойки: $k_{eff} = Nu \cdot k$.

### Горизонтальная полость, нагрев снизу

{{< formula display="true" >}}
Nu = 1 + 1{,}44\left[1 - \frac{1708}{Ra}\right]^+ + \left[\frac{Ra^{1/3}}{18} - 1\right]^+
{{< /formula >}}

где $[X]^+ = \max(X, 0)$. Конвекция начинается при $Ra > 1708$ (условие Рэлея–Бенара).

## Естественная конвекция в помещениях

### Тепловые струи (плюмы)

Нагретые поверхности (радиаторы, люди, оборудование) создают восходящие тепловые струи. Скорость на оси и ширина плюма (заряд плавучести $B$ [м⁴/с³]):

{{< formula display="true" >}}
w_0 = 4{,}7 \left(\frac{B}{z}\right)^{1/3}, \quad \delta_T \propto z
{{< /formula >}}

Скорость воздуха в зоне обслуживания из-за тепловых плюмов обычно 0,1–0,3 м/с.

### Термическая стратификация

В высоких помещениях тёплый воздух скапливается под потолком. Градиент температуры:

{{< formula display="true" >}}
\frac{dT}{dz} \approx 0{,}5\text{–}2{,}0 \;\text{К/м}
{{< /formula >}}

Более высокий градиент при слабой вентиляции, больших теплопоступлениях, высоких помещениях. Неправильно запроектированная вентиляция может создать градиент 3–5 К/м, что снижает тепловой комфорт.

## Смешанная конвекция

Критерий доминирования режима:

{{< formula display="true" >}}
Ri = \frac{Gr}{Re^2} = \frac{\text{Архимедовы силы}}{\text{Инерционные силы}}
{{< /formula >}}

- $Ri < 0{,}1$: вынужденная конвекция доминирует (более 95%)
- $0{,}1 < Ri < 10$: смешанная конвекция
- $Ri > 10$: естественная конвекция доминирует

Для горизонтальных труб (помогающее течение):

{{< formula display="true" >}}
Nu_{mix}^n = Nu_{forced}^n + Nu_{natural}^n, \quad n \approx 3
{{< /formula >}}

## Области применения в HVAC

**Пассивное (естественное) охлаждение**: размер вентиляционных отверстий рассчитывают так, чтобы тепловая тяга обеспечивала необходимый воздухообмен.

**Радиаторное отопление**: конвективная составляющая радиатора определяется естественной конвекцией; при $h = 6$–$10$ Вт/(м²·К) мощность типового радиатора 500×600 мм — 500–800 Вт.

**Оконные конструкции**: холодное стекло ($T_s < 0°$С) создаёт нисходящий поток воздуха — «холодный сквозняк», ощущаемый жильцами как дискомфорт даже при нормативной температуре воздуха.

**Трассировка электрообогрева труб**: при расчёте мощности обогрева трубопроводов важно учитывать естественную конвекцию к воздуху.
