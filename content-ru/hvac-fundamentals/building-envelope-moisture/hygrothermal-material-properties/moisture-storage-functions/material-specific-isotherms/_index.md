## Общие положения

Изотерма сорбции — функциональная зависимость равновесного влагосодержания материала от относительной влажности воздуха при постоянной температуре. Каждый материал характеризуется уникальной изотермой, определяемой структурой пор, химией поверхности и составом.

Данные изотерм — фундаментальный входной параметр гигротермального моделирования (WUFI, DELPHIN) и необходимое условие корректного расчёта буферной ёмкости, рисков плесни и долговечности конструкций. Стандарты измерения: **ISO 12571**, ASTM C1498, ГОСТ 25898.

## Древесина и изделия на её основе

### Физика сорбции в древесине

Древесина поглощает влагу через гидроксильные группы целлюлозы, гемицеллюлозы и лигнина в клеточных стенках. При влагосодержании ниже точки насыщения волокон (FSP ≈ 28–32 %) гигроскопическое поглощение определяется химией клеточных стенок; выше FSP преобладает капиллярная конденсация в полостях клеток.

### Уравнение Хейлвуда–Хорробина

Классическая двухвидовая модель сорбции древесины:

{{< formula display="true" >}}
u = \frac{1800}{W}\left[\frac{K_1\,\varphi}{1 - K_1\,\varphi} + \frac{K_1\,K_2\,\varphi}{1 + K_1\,K_2\,\varphi}\right]
{{< /formula >}}

где {{< formula >}}W \approx 162{{< /formula >}} кг/кмоль — молекулярная масса вещества клеточной стенки; {{< formula >}}K_1{{< /formula >}}, {{< formula >}}K_2{{< /formula >}} — константы равновесия гидрата и растворения. Модель Симпсона (ASHRAE Fundamentals) — численно совместимая форма с температурно-зависимыми коэффициентами W, K₁–K₄ — подробно рассмотрена в разделе «Равновесное влагосодержание материалов».

### Гистерезис древесины

{{< formula >}}u_\text{des}/u_\text{ads}{{< /formula >}} при 65 % отн. вл. ≈ 1,15; при 80 % отн. вл. ≈ 1,20. Это определяет разницу между EMC при адсорбции и десорбции, существенную для расчётов циклических нагрузок HVAC.

## Бетон

### Физика сорбции в бетоне

Хранение влаги в бетоне определяется тремя зонами: межслойная вода в C-S-H (силикат гидрата кальция) геле, вода в гелевых порах и вода в капиллярных порах. Изотерма сильно зависит от В/Ц отношения, степени гидратации и возраста.

### Модель Си–Базан–Дженнингса

{{< formula display="true" >}}
u = \frac{G_1\bigl[\alpha_1\,\varphi + (1-\alpha_1)\,\varphi^{n_1}\bigr]}{1 + (G_1-1)\bigl[\alpha_1\,\varphi + (1-\alpha_1)\,\varphi^{n_1}\bigr]}
{{< /formula >}}

Упрощённая степенная аппроксимация: {{< formula >}}u = A\,\varphi^B{{< /formula >}}, где {{< formula >}}A = 140{-}180{{< /formula >}} кг/м³; {{< formula >}}B = 3{-}5{{< /formula >}}.

### Поправка на возраст

При продолжающейся гидратации ёмкость хранения влаги снижается:

{{< formula display="true" >}}
u(t) = u_{28}\,\bigl[1 + \beta\,\log(28/t)\bigr],\quad \beta = 0{,}10{-}0{,}15
{{< /formula >}}

(применимо при {{< formula >}}t < 28{{< /formula >}} суток).

## Гипсокартон

### Сорбция гипсового сердечника

Модель ГАБ для двуводного сульфата кальция:

{{< formula display="true" >}}
u = \frac{u_m\,C\,K\,\varphi}{(1 - K\varphi)\,[1 + (C-1)\,K\varphi]}
{{< /formula >}}

где {{< formula >}}u_m \approx 0{,}8{-}1{,}0\,\%{{< /formula >}}; {{< formula >}}C \approx 8{-}12{{< /formula >}}; {{< formula >}}K \approx 0{,}85{-}0{,}95{{< /formula >}}.

Бумажная облицовка (≈ 8 % массы листа) следует изотерме целлюлозы — аналогичной древесине.

## Численный пример: расчёт буферного значения материала

**Условие.** Сравнить буферную эффективность двух вариантов внутренней отделки для жилого помещения с суточным циклом RH 45→65 % (рабочий диапазон Δφ = 0,20):

- Вариант А: гипсокартон 12,5 мм, {{< formula >}}\rho_0 = 650{{< /formula >}} кг/м³.
- Вариант Б: глиняная штукатурка 15 мм, {{< formula >}}\rho_0 = 1600{{< /formula >}} кг/м³.

**Данные (из таблиц):**

- Гипсокартон: {{< formula >}}u(45\%) \approx 0{,}55\,\%{{< /formula >}}, {{< formula >}}u(65\%) \approx 1{,}05\,\%{{< /formula >}} → {{< formula >}}\Delta u = 0{,}005{{< /formula >}} кг/кг.
- Глиняная штукатурка: {{< formula >}}u(45\%) \approx 0{,}015{{< /formula >}}, {{< formula >}}u(65\%) \approx 0{,}022{{< /formula >}} кг/кг → {{< formula >}}\Delta u = 0{,}007{{< /formula >}} кг/кг.

**Хранимая влага на 1 м² за суточный цикл:**

Гипсокартон:
{{< formula display="true" >}}
\Delta m_A = \rho_0\,d\,\Delta u = 650\times 0{,}0125\times 0{,}005 = 0{,}041\;\text{кг/м}^2 = 41\;\text{г/м}^2
{{< /formula >}}

Глиняная штукатурка:
{{< formula display="true" >}}
\Delta m_Б = 1600\times 0{,}015\times 0{,}007 = 0{,}168\;\text{кг/м}^2 = 168\;\text{г/м}^2
{{< /formula >}}

**Буферное значение (MBV, г/(м²·% отн. вл.)):**

{{< formula display="true" >}}
\mathrm{MBV}_A = \frac{41}{20} = 2{,}1\;\text{г/(м}^2\text{·\%)};\quad \mathrm{MBV}_Б = \frac{168}{20} = 8{,}4\;\text{г/(м}^2\text{·\%)}
{{< /formula >}}

**Вывод.** Глиняная штукатурка поглощает в 4 раза больше влаги за суточный цикл, обеспечивая значительно более стабильный микроклимат. Для помещения с 200 м² стен разница буферной ёмкости составляет (168 − 41) × 200 = 25,4 кг в сутки — влага, которую иначе пришлось бы удалять системой кондиционирования.

## Температурная зависимость изотерм

Сдвиг изотермы с температурой описывается уравнением Клапейрона–Клаузиуса:

{{< formula display="true" >}}
\ln\!\frac{\varphi_2}{\varphi_1} = \frac{\Delta H_\text{ads}}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)
{{< /formula >}}

Типичные значения изостерической теплоты адсорбции {{< formula >}}\Delta H_\text{ads}{{< /formula >}}: древесина 45–60 кДж/моль; гипс 40–50 кДж/моль; бетон 50–65 кДж/моль; целлюлоза 45–55 кДж/моль.

Для практических расчётов в диапазоне 0–40 °C применяется линейная поправка (см. раздел «EMC материалов»).

## Требования к данным для гигротермального моделирования

Для корректной работы WUFI и DELPHIN необходимо:

1. Не менее 8–10 точек в диапазоне 0–98 % отн. вл. на изотерму.
2. Обе кривые (адсорбция и десорбция) или коэффициент гистерезиса.
3. Данные при минимум двух температурах (если диапазон T > 20 °C).
4. Значение свободного насыщения {{< formula >}}w_f{{< /formula >}} (насыщение жидкой водой).
5. Параметр формы b для уравнения Кюнцеля.

**Критерии равновесия при измерениях (ISO 12571):**

{{< formula display="true" >}}
\frac{\Delta m}{\Delta t} < 0{,}001\;\%\;\text{за 24 ч}
{{< /formula >}}

Типичное время выравнивания: при RH < 50 % — 7–14 суток; при RH > 80 % — 14–28 суток; для плотных материалов — дольше.

## Контроль качества данных изотерм

**Физические ограничения, которые должны выполняться:**
- Монотонный рост: {{< formula >}}\mathrm{d}u/\mathrm{d}\varphi > 0{{< /formula >}} при всех {{< formula >}}\varphi{{< /formula >}}.
- Начало координат: {{< formula >}}u(0) = 0{{< /formula >}}.
- {{< formula >}}u_\text{des}(\varphi) \geq u_\text{ads}(\varphi){{< /formula >}} при всех {{< formula >}}\varphi{{< /formula >}}.
- {{< formula >}}0 < u(\varphi) < w_\text{sat}/\rho_0{{< /formula >}} при {{< formula >}}\varphi < 1{{< /formula >}}.

**Типичные неопределённости измерений (ISO 12571):**
- Управление RH: ±2 % отн. вл.
- Взвешивание: ±0,1 % массы образца.
- Температура: ±0,2 °C.
- Суммарная неопределённость по влагосодержанию: ±5–15 %.

## Особые случаи

### Солевое загрязнение

Наличие гигроскопичных солей в кирпиче или бетоне кардинально изменяет изотерму при RH > DRH (deliquescence RH):

{{< formula display="true" >}}
u_\text{total} = u_\text{matrix}(\varphi) + u_\text{salt}(\varphi)
{{< /formula >}}

{{< formula >}}u_\text{salt}{{< /formula >}} может превысить {{< formula >}}u_\text{matrix}{{< /formula >}} в 2–10 раз при RH выше точки делиресценции соли.

### Долгосрочное старение

Изотермы могут изменяться при длительной эксплуатации:
- Карбонизация бетона снижает ёмкость хранения (меньше геля C-S-H).
- Деградация связующего в ДСП/МДФ приводит к росту поглощения.
- Необходимо обновлять данные для конструкций с расчётным сроком > 20 лет.

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — изотермы сорбции для типовых строительных материалов.
- **ASHRAE 160** — требования к данным по свойствам материалов для расчётного анализа контроля влаги.
- **ISO 12571** — определение гигроскопических свойств сорбции строительных материалов.
- **ASTM C1498** — гигроскопические изотермы сорбции методом динамической сорбции пара.
- **ГОСТ 25898** — паропроницаемость и сорбционное увлажнение строительных материалов и изделий.
- **СП 50.13330.2017** — тепловая защита зданий.
- **СП 23-101-2004** — проектирование тепловой защиты зданий.
