Холодильное оборудование для холодного хранения поддерживает готовые и готовые к употреблению (RTE) продукты при температурах, которые предотвращают рост патогенных бактерий во время обслуживания, выставки и краткосрочного хранения. Это представляет последний барьер в цепи безопасности пищевых продуктов перед потреблением.

## Нормативные требования к температуре

### Стандарты FDA Food Code

FDA Food Code устанавливает холодное хранение как критическую контрольную точку, требующую строгого управления температурой.

**Пределы температуры:**

| Применение | Требование по температуре | Временное ограничение | Ссылка |
|-------------|--------------------------|----------------------|--------|
| Холодное хранение (общее) | ≤5°C | Период обслуживания | FDA Food Code 3-501.16 |
| Витрина охлаждения | ≤5°C | Непрерывно | FDA Food Code 3-306.11 |
| Буфет/салат-бар | ≤5°C | Период обслуживания | FDA Food Code 3-306.14 |
| Модифицированная атмосфера | ≤3°C | Продленный срок хранения | FDA Food Code 3-502.12 |
| Продукты с повышенной восприимчивостью | ≤2°C | Максимальная безопасность | Местное законодательство |

**Критическая зона температуры:**

Зона опасности охватывает 5°C до 60°C, где патогенные бактерии быстро размножаются:

```
Время удвоения бактерий при различных температурах:
- 5°C:    Время генерации ≈ 12-24 часов
- 10°C:   Время генерации ≈ 3-6 часов
- 15°C:   Время генерации ≈ 1-2 часов
- 21°C:   Время генерации ≈ 20-30 минут
- 37°C:   Время генерации ≈ 15-20 минут (оптимальная)
```

### Соотношение между временем и температурой

Сроки холодного хранения зависят от первоначальной температуры продукта и теплонагрузки:

**Сроки хранения:**

| Категория продукта | Температура | Максимальное время хранения | Основной патоген |
|-------------------|-------------|---------------------------|-----------------|
| Предварительно приготовленные белки | ≤5°C | 3-5 дней | Listeria monocytogenes |
| Свежие овощи и фрукты (нарезанные) | ≤5°C | 1-3 дня | Salmonella, E. coli |
| Молочные готовые блюда | ≤3°C | 2-4 дня | Listeria, Staphylococcus |
| Морепродукты в салатах | ≤3°C | 1-2 дня | Vibrio, Listeria |
| Бутерброды (RTE) | ≤5°C | 24-48 часов | Множественные патогены |
| Колбасные изделия (нарезанные) | ≤3°C | 3-5 дней | Listeria monocytogenes |

**Требования по маркировке даты:**

Готовые к употреблению продукты, хранившиеся >24 часов, должны быть помечены датой согласно FDA Food Code 3-501.17:
- Дата использования = День приготовления + 6 дней при ≤5°C
- Маркировка даты начинается в день открытия/приготовления
- Утилизируйте после максимум 7 дней

## Типы оборудования для холодного хранения

### Витрины самообслуживания

**Холодильники с открытой витриной:**

Открытые или со стеклянной дверью блюда для приложений самообслуживания клиентами.

| Параметр | Спецификация | Основа конструкции |
|----------|-------------|-------------------|
| Температура продукта | ≤5°C | Соответствие FDA |
| Температура воздуха на входе | -1 до 2°C | Требуемый перепад |
| Температура воздуха на выходе | 8-10°C максимум | Приемлемый возврат |
| Цикл разморозки | 2-4 раза в сутки | Предотвращение ледяного налета |
| Тип хладагента | R-404A, R-452A, R-290 | Переход с низким потенциалом глобального потепления |
| Емкость испарителя | 150-250 Вт/°C | Требования нагрузки |

**Производительность воздушной завесы:**

Витрины с открытой витриной основаны на вертикальных воздушных завесах для поддержания температуры продукта.

Коэффициент эффективности воздушной завесы:

$$E_c = \frac{T_{ambient} - T_{product}}{T_{ambient} - T_{discharge}} \times 100\%$$

Где:
- E_c = Эффективность завесы (целевое значение ≥85%)
- T_ambient = Температура окружающего воздуха в магазине (°C)
- T_product = Температура в зоне продукта (°C)
- T_discharge = Температура выпускаемого воздуха (°C)

**Критические параметры конструкции:**

```
Скорость выпускаемого воздуха: 0,75-1,25 м/с
Скорость возвратного воздуха: 0,5-0,8 м/с
Угол выпуска: 10-15° от вертикали
Линия ограничения нагрузки: Не складывайте выше указанной высоты
Ночные шторы: Снижение инфильтрационной нагрузки на 60-75%
```

### Холодильное оборудование буфетных линий

**Охлаждаемые лотки:**

Охлаждаемые лотки, установленные в буфетных линиях обслуживания.

| Компонент | Спецификация | Цель |
|-----------|-------------|------|
| Глубина лотка | 150-300 мм | Размещение противней |
| Температура дна | ≤2°C | Зона контакта с продуктом |
| Метод охлаждения | Принудительный воздух или холодная пластина | Удаление тепла |
| Дренаж | Обязателен | Удаление конденсата |
| Изоляция | R-10 минимум | Энергоэффективность |
| Опора противня | Съемные решетки | Доступ для очистки |

**Расчет теплонагрузки:**

Общая холодильная нагрузка для охлаждаемого буфетного лотка:

$$Q_{total} = Q_{product} + Q_{transmission} + Q_{air} + Q_{lights} + Q_{people}$$

Где:

$$Q_{product} = m \times c_p \times \Delta T / t$$

- m = Масса продукта (кг)
- c_p = Удельная теплоемкость (3,5-4,0 кДж/кг·°C для готовых продуктов)
- ΔT = Снижение температуры (°C)
- t = Время охлаждения (часов)

$$Q_{transmission} = U \times A \times \Delta T$$

- U = Общий коэффициент теплопередачи (Вт/м²·°C)
- A = Площадь открытой поверхности (м²)
- ΔT = Разница температур (°C)

**Типичные значения:**

- Нагрузка продукта: 40-50% от общей
- Нагрузка передачи: 20-30% от общей
- Инфильтрация воздуха: 15-25% от общей
- Освещение и разное: 10-15% от общей

### Холодильное оборудование под столом

**Коммерческие единицы под столом:**

Компактные холодильники для хранения в зоне подготовки.

| Спецификация | Стандартный диапазон | Тяжелая работа |
|-------------|----------------------|----------------|
| Вместимость | 110-280 л | 280-565 л |
| Мощность компрессора | 1/6-1/4 HP | 1/4-1/3 HP |
| Диапазон температур | 0-5°C | -2-5°C |
| Время восстановления | 30-45 мин | 20-30 мин |
| Тип двери | Сплошная или стеклянная | Рекомендуется сплошная |
| Полки | Регулируемая сетка | Покрытая для санитарии |

**Требования к установке:**

```
Зазор (стороны): 50 мм минимум
Зазор (задняя часть): 100 мм минимум
Зазор (верх): 150 мм минимум
Электрическая сеть: Выделенная цепь 115В/20А
Пределы окружающей среды: 24°C макс, 40% RH макс
Вентиляция: Неограниченный поток воздуха к конденсатору
```

## Системы мониторинга температуры

### Требования размещения датчиков

**Критические места измерения:**

| Местоположение | Тип датчика | Цель | Частота |
|----------------|------------|------|---------|
| Центр продукта | Термопара или RTD | Фактическая температура пищи | Каждые 4 часа |
| Воздух витрины на входе | RTD зонд | Проверка подачи | Непрерывно |
| Возвратный воздух | RTD зонд | Указание нагрузки | Непрерывно |
| Катушка испарителя | RTD зонд | Производительность системы | Непрерывно |
| Окружающий воздух | RTD зонд | Инфильтрационная нагрузка | Непрерывно |

**Спецификации датчиков:**

- Точность: ±0,5°C в рабочем диапазоне
- Время отклика: T63 < 10 секунд в воздухе, < 5 секунд в жидкости
- Калибровка: Ежегодная проверка в соответствии со стандартом NIST
- Установка будильника: Высокий будильник при 7°C, критический при 10°C

### Требования к регистрации данных

**Соответствие HACCP:**

Системы автоматического мониторинга температуры должны обеспечивать:

```
Интервал записи: Не более чем каждые 15 минут
Сохранение данных: Минимум 6 месяцев (рекомендуется 12 месяцев)
Уведомление об аварии: Немедленное уведомление об отклонении температуры
Резервное питание: Резервное питание на 24 часа минимум
Защита от несанкционированного доступа: Защищенная, неуничтожаемая память
```

**Интерпретация графика температуры:**

Характеристики приемлемого профиля температуры:
- Базовая температура: 2-5°C
- Температурные выбросы: <7°C в течение <2 часов
- Время восстановления: Возврат к ≤5°C в течение 1 часа
- Скачки разморозки: Краткие (15-30 мин), продукт остается ≤5°C

## Критические контрольные точки HACCP

### Холодное хранение как CCP

Холодное хранение представляет CCP-2 (контроль после приготовления) в планах HACCP.

**Критические пределы:**

| Параметр | Критический предел | Метод мониторинга | Корректирующее действие |
|----------|-------------------|-------------------|------------------------|
| Температура продукта | ≤5°C | Проверка термометром каждые 4 часа | Утилизируйте, если >7°C более 2 часов |
| Температура оборудования | Воздух на входе ≤2°C | Непрерывный регистратор данных | Вызов сервиса, перемещение продукта |
| Время хранения | ≤7 дней с даты приготовления | Проверка видимой даты | Утилизируйте истекший продукт |
| Цикл разморозки | Продукт остается ≤5°C | Мониторинг температуры | Отрегулируйте параметры разморозки |

**Процедуры проверки:**

Еженедельные задачи проверки:
1. Калибруйте термометры в ледяной бане (0°C) или кипящей воде (100°C на уровне моря)
2. Просмотрите логи температуры на предмет тенденций и отклонений
3. Проверьте соответствие маркировки даты на всех продуктах
4. Проверьте правильность работы оборудования (отсутствие ледяного налета, адекватный поток воздуха)
5. Документируйте все результаты в записях HACCP

### Предотвращение роста патогенов

**Целевые организмы:**

| Патоген | Диапазон роста | Оптимальная температура | Беспокойство в RTE продуктах |
|---------|----------------|------------------------|------------------------------|
| Listeria monocytogenes | -0,4 до 45°C | 37°C | Высокий - растет при температуре охлаждения |
| Salmonella spp. | 5,2 до 46°C | 37°C | Умеренный - минимальный рост <7°C |
| Staphylococcus aureus | 7 до 48°C | 37°C | Производство токсина предотвращено <7°C |
| Clostridium perfringens | 12 до 50°C | 43°C | Низкий риск - отсутствие роста <12°C |
| E. coli O157:H7 | 7 до 46°C | 37°C | Низкий - минимальный рост <7°C |
| Bacillus cereus | 4 до 55°C | 30°C | Умеренный - медленный рост <7°C |

**Стратегия контроля Listeria:**

Listeria monocytogenes представляет уникальные проблемы, потому что она медленно растет при температуре охлаждения:

Скорость роста при температуре холодного хранения:
- 0°C: Время генерации ≈ 60-84 часов
- 3°C: Время генерации ≈ 30-40 часов
- 5°C: Время генерации ≈ 18-24 часов
- 7°C: Время генерации ≈ 10-14 часов

**Меры контроля:**
1. Поддерживайте ≤3°C для продуктов, чувствительных к Listeria (колбасы, морепродукты в салатах)
2. Ограничьте хранение до 3-5 дней максимум
3. Используйте пленки с антимикробными свойствами
4. Внедрите программу экологического мониторинга
5. Строгая санитария оборудования для нарезки и порционирования

## Спецификации конструкции оборудования

### Требования к катушке испарителя

**Определение емкости:**

Требуемая емкость испарителя:

$$Q_{evap} = \frac{Q_{total}}{COP \times \eta_{comp}}$$

Где:
- Q_evap = Емкость испарителя (Вт)
- Q_total = Общая холодильная нагрузка (Вт)
- COP = Коэффициент производительности (2,0-3,5 для холодного хранения)
- η_comp = Эффективность компрессора (0,70-0,85)

**Спецификации катушки:**

| Параметр | Приложение холодного хранения | Основа |
|----------|------------------------------|--------|
| Расстояние между ребрами | 4-6 ребер на дюйм | Баланс емкости/разморозки |
| Диаметр трубы | 9,5-12,7 мм | Поток хладагента |
| Скорость на входе | 1,5-2,5 м/с | Перепад давления на стороне воздуха |
| Глубина катушки | 3-6 рядов | Площадь теплопередачи |
| Перегрев | 5-8°C | Предотвращение возврата жидкости |
| Температура испарения | -8 до -4°C | Температура продукта + TD |

**Разница температур (TD):**

Для приложений холодного хранения:

$$TD = T_{product} - T_{evaporating}$$

Типичные значения:
- Витрины с открытой витриной: TD = 8-12°C
- Закрытые холодильники: TD = 6-10°C
- Прогулочные холодильники: TD = 5-8°C

Большее TD увеличивает емкость, но повышает энергопотребление и снижает контроль влажности.

### Конструкция системы разморозки

**Методы разморозки:**

| Метод | Применение | Частота | Продолжительность |
|-------|-----------|---------|------------------|
| Внецикловая | Низкий дифференциал температуры | Каждые 6-8 часов | 20-30 минут |
| Электрическая | Витрина средней грузоподъемности | Каждые 4-6 часов | 15-25 минут |
| Горячий газ | Коммерческая витрина тяжелой работы | Каждые 4-6 часов | 10-20 минут |
| Адаптивная | Управление по требованию | По мере необходимости | Переменная |

**Окончание разморозки:**

Надлежащее завершение предотвращает повышение температуры продукта:

```
Методы окончания:
1. Температура: Завершите при температуре катушки 10-15°C
2. Время: Максимальная продолжительность 20-30 минут
3. Давление: Давление хладагента указывает на таяние льда

Нагревание поддона: Требуется для предотвращения повторного замерзания
Нагревание сливной линии: Тепловое испытание в холодных условиях
Задержка после разморозки: 2-5 минут перед перезапуском вентилятора
```

### Выбор системы охлаждения

**Типы компрессоров:**

| Тип | Диапазон емкости | Эффективность | Применение |
|-----|-----------------|---------------|-----------|
| Поршневой | 0,5-15 HP | Умеренная | Витрины малого и среднего размера |
| Спиральный | 1-15 HP | Высокая | Витрины, холодильники |
| Роторный | 0,25-3 HP | Умеренная | Единицы под столом |
| Удаленная конденсация | 1-50 HP | Высокая | Несколько подключений витрин |

**Методы конденсации:**

- Воздушное охлаждение: Простые, автономные установки, требуют достаточной вентиляции
- Водяное охлаждение: Более высокая эффективность, требует подачи и обработки воды
- Удаленная: Отдельное расположение конденсатора, снижение шума и тепла на кухне
- Гликолевой контур: Централизованная система обслуживает несколько витрин

**Метрики энергоэффективности:**

Коэффициент энергоэффективности для холодильного оборудования:

$$EER = \frac{Q_{refrigeration}}{W_{input}}$$

Где:
- EER = Коэффициент энергоэффективности (Вт/Вт)
- Q_refrigeration = Емкость охлаждения (Вт)
- W_input = Входная мощность (Вт)

Целевые значения:
- Витрины: EER ≥ 8,0
- Холодильники: EER ≥ 10,0
- Прогулочные холодильники: EER ≥ 12,0

## Конструкция распределения воздуха

### Схемы потока воздуха

**Циркуляция в витрине:**

Надлежащее распределение воздуха обеспечивает однородную температуру продукта.

Расчет расхода воздуха:

$$\text{CFM} = \frac{Q_{sensible}}{1.08 \times \Delta T}$$

Где:
- CFM = Расход воздуха (фут³/мин)
- Q_sensible = Чувствительная холодильная нагрузка (BTU/ч)
- ΔT = Повышение температуры через испаритель (°F)
- 1,08 = Константа для стандартного воздуха (0,24 BTU/фунт·°F × 0,075 фунт/фут³ × 60 мин/ч)

**Метрический эквивалент:**

$$\text{м³/ч} = \frac{Q_{sensible}}{1.2 \times c_p \times \Delta T} \times 3.6$$

Где:
- м³/ч = Расход воздуха (кубических метров в час)
- Q_sensible = Чувствительная холодильная нагрузка (Вт)
- 1,2 = Плотность воздуха (кг/м³)
- c_p = Удельная теплоемкость воздуха (1,006 кДж/кг·°C)
- ΔT = Повышение температуры (°C)
- 3,6 = Коэффициент преобразования (1 м³/с = 3,6 м³/ч)

**Требования к скорости:**

| Зона | Диапазон скоростей | Цель |
|------|-------------------|------|
| Выпуск воздушной завесы | 0,75-1,25 м/с | Поддержание разделения |
| Возвратная решетка | 0,5-0,8 м/с | Минимизация турбулентности |
| Зона продукта | <0,2 м/с | Предотвращение потери влаги |
| Входное отверстие катушки | 1,5-2,5 м/с | Теплопередача |

### Контроль влажности

**Управление влажностью:**

Холодное хранение требует тщательного баланса влажности:
- Слишком высокая: Конденсация, рост плесени, деградация упаковки
- Слишком низкая: Высыхание продукта, потеря веса, ухудшение внешнего вида

**Целевые диапазоны относительной влажности:**

| Тип продукта | Относительная влажность | Причина |
|-------------|----------------------|---------|
| Свежие овощи | 85-95% | Предотвращение увядания |
| Готовые белки | 75-85% | Минимизация высыхания |
| Молочные продукты | 70-80% | Стабильность поверхности |
| Хлебобулочные изделия | 60-70% | Сохранение текстуры |
| Колбасные изделия (нарезанные) | 75-85% | Сохранение цвета |

**Методы контроля влажности:**

1. Управление температурой катушки: Более высокая температура испарения снижает осушающее воздействие
2. Оптимизация разморозки: Минимизировать введение влаги во время разморозки
3. Ночные шторы: Уменьшить миграцию влаги во время закрытия
4. Конструкция упаковки: Пленки, защищающие от влаги, или вакуумная упаковка
5. Конструкция воздушной завесы: Минимизировать инфильтрацию окружающего воздуха

## Соответствие безопасности пищевых продуктов

### Требования к проверкам

**Надзор регулирующих органов:**

| Органа | Юрисдикция | Фокус проверки | Частота |
|---------|-----------|--------------|---------|
| FDA | Торговля между штатами | Температура, маркировка даты, HACCP | На основе риска |
| Департамент здравоохранения штата | Внутригосударственные операции | Температуры холодного хранения, оборудование | Минимум ежегодно |
| Местный департамент здравоохранения | Розничная пищевая служба | Ежедневные проверки температуры | Переменная |
| USDA (на мясных объектах) | Мясо/птица | Непрерывный мониторинг | Ежедневно |

**Типичные нарушения:**

1. Температура продукта >5°C во время хранения
2. Неадекватная маркировка даты на готовых продуктах
3. Мониторинг температуры не проводится каждые 4 часа
4. Истекшие продукты не утилизируются после 7 дней
5. Оборудование не поддерживает надлежащую температуру
6. Калибровка термометра не документирована
7. Записи HACCP неполные или отсутствуют

### Стандартные рабочие процедуры

**Шаблон SOP холодного хранения:**

```
Цель: Поддерживать готовые продукты при безопасных температурах во время обслуживания

Процедура:
1. Проверьте, что оборудование работает при ≤5°C перед загрузкой продукта
2. Предварительно охладите продукты до ≤5°C перед помещением в холодное хранилище
3. Нанесите дату приготовления и дату использования (день 7)
4. Загружайте продукты ниже линии ограничения нагрузки на витринах
5. Проверяйте температуру продукта каждые 4 часа откалиброванным термометром
6. Записывайте температуры в форму мониторинга HACCP
7. Принимайте корректирующие меры, если температура превышает 5°C
8. Утилизируйте продукты после 7 дней или если температура >7°C более 2 часов
9. Очищайте и дезинфицируйте оборудование ежедневно
10. Еженедельно просматривайте логи температуры на предмет тенденций

Оборудование:
- Откалиброванный цифровой термометр (±0,5°C точность)
- Формы мониторинга HACCP
- Этикетки для маркировки даты или лента
- График регистрации температуры

Обучение:
- Все персонал, работающий с готовыми продуктами, должны пройти обучение холодному хранению
- Продемонстрируйте надлежащую технику измерения температуры
- Просмотрите корректирующие действия при отклонениях температуры
- Требуется ежегодное переподготовка
```

## Лучшие практики эксплуатации

### Процедуры загрузки

**Расположение продукта:**

Надлежащее размещение продукта обеспечивает адекватное охлаждение:

1. Предварительно охладите продукты до ≤5°C перед помещением в холодильное оборудование
2. Оставляйте пространство между продуктами для потока воздуха (минимум 25 мм)
3. Не блокируйте решетки возврата воздуха
4. Складывайте только до обозначенной линии ограничения нагрузки
5. Поместите самые теплые продукты в самые холодные зоны
6. Чередуйте запас - первый на входе, первый на выходе (FIFO)

**Плотность нагрузки:**

Максимальная рекомендуемая загрузка:

$$\rho_{load} = \frac{m_{product}}{V_{case}} \leq 0.6 \text{ (соотношение массы/объема)}$$

Перегрузка снижает циркуляцию воздуха и компрометирует температурный контроль.

### Оптимизация энергии

**Улучшения эффективности:**

| Стратегия | Экономия энергии | Внедрение |
|----------|-----------------|-----------|
| Ночные шторы на витринах | 30-40% | Установите изолированные шторы |
| Преобразование на светодиоды | 50-75% | Замените люминесцентные/лампы накаливания |
| Управление скоростью вентилятора испарителя | 15-25% | Установите VFD или ECM моторы |
| Управление давлением конденсации | 10-20% | Отрегулируйте температуру конденсации по окружающей среде |
| Адаптивная разморозка | 10-15% | Используйте инициирование разморозки по требованию |
| Управление нагревателем антипотока | 30-50% | Модулируйте на основе точки росы |
| Техническое обслуживание прокладок дверей | 5-10% | Регулярный осмотр/замена |

**Управление пиковой нагрузкой:**

Снижение платежей за спрос на коммунальные услуги во время пиковых периодов:
- Предварительно охладите продукты во время непиковых часов
- Увеличьте установку на 1-2°C во время пиковой нагрузки (если сохраняется безопасность продукта)
- Последовательно разморозьте циклы, чтобы избежать одновременной работы
- Используйте тепловую массу (материалы с фазовым переходом) для сдвига нагрузки

### График обслуживания

**Ежедневные задачи:**

- Визуальный осмотр работы оборудования
- Проверка температуры продукта (каждые 4 часа во время работы)
- Проверка надлежащего потока воздуха (отсутствие перекрытых решеток)
- Проверка прокладок и закрытия дверей
- Опорожнение и очистка поддонов

**Еженедельные задачи:**

- Очистка катушек конденсатора (или согласно графику производителя)
- Проверка индикаторов заряда хладагента
- Проверка калибровки управления температурой
- Просмотр и утверждение подписью логов температуры
- Очистка внутренних поверхностей и полок

**Ежемесячные задачи:**

- Проверка электрических соединений на герметичность
- Проверка уровня масла компрессора (если присутствует смотровое стекло)
- Тестирование функций систем сигнализации и регистратора данных
- Проверка работы цикла разморозки и завершения
- Смазка вентиляторных моторов (если не вечно смазанные)

**Ежеквартальные задачи:**

- Проведение теста на утечку хладагента
- Измерение потребления тока на компрессоре и вентиляторных двигателях
- Проверка прокладок дверей на надлежащее уплотнение (долларовый тест)
- Калибровка датчиков температуры в соответствии со стандартом NIST
- Проверка сливных линий на предмет засорения или замерзания

**Годовые задачи:**

- Всеобъемлющий осмотр холодильной системы квалифицированным техником
- Замена воздушных фильтров в удаленных конденсирующих установках
- Проверка давления хладагента и перегрева/переохлаждения
- Проверка работы системы управления и уставок
- Документирование всего обслуживания в журнале оборудования

## Устранение неисправностей распространенных проблем

### Проблемы отклонения температуры

**Проблема: Температура продукта превышает 5°C**

| Возможная причина | Диагностическая проверка | Корректирующее действие |
|------------------|----------------------|----------------------|
| Неисправность оборудования | Проверьте температуру воздуха на входе/выходе | Обслуживание холодильной системы |
| Перегрузка | Проверьте количество продукта | Удалите избыток продукта |
| Плохая циркуляция воздуха | Проверьте наличие заблокированных решеток | Переорганизуйте расположение продукта |
| Теплый продукт загружен | Измерьте температуру входящего продукта | Предварительно охладите перед загрузкой |
| Высокая температура окружающей среды | Проверьте HVAC магазина | Снизьте окружающую среду или переместите установку |
| Нагрузка инфильтрации | Наблюдайте воздушную завесу | Отрегулируйте выпуск, добавьте ночные шторы |
| Недостаток хладагента | Проверьте перегрев/переохлаждение | Добавьте хладагент, найдите утечку |
| Грязная катушка конденсатора | Проверьте чистоту катушки | Очистите конденсатор |

**Диагностические измерения:**

Требуемые измерения для устранения неисправностей:
- Температура центра продукта (несколько мест)
- Температура выпускаемого воздуха (воздух на входе)
- Температура возвратного воздуха (воздух на выходе)
- Температура катушки испарителя
- Температура и влажность окружающего воздуха
- Давление нагнетания и всасывания компрессора
- Перегрев (5-8°C типично) и переохлаждение (5-10°C типично)

### Проблемы качества пищевых продуктов

**Проблема: Высыхание продукта**

Причины и решения:
1. Относительная влажность слишком низкая: Немного повысьте температуру испарителя
2. Чрезмерная скорость воздуха над продуктом: Отрегулируйте диффузоры подачи
3. Продолжительное время хранения: Уменьшите размер партий, увеличьте оборот
4. Неадекватная упаковка: Используйте пленки, защищающие от влаги, или крышки

**Проблема: Конденсация на продукте или упаковке**

Причины и решения:
1. Колебания температуры: Стабилизируйте работу оборудования
2. Теплый продукт загружен: Предварительно охладите до ≤5°C перед загрузкой
3. Высокая влажность окружающей среды: Улучшить осушение здания
4. Влага разморозки не слита: Очистить поддон и линию
