Число Прандтля (Prandtl number) Pr — безразмерный параметр, определяющий относительную интенсивность молекулярного переноса импульса и теплоты в потоке жидкости. Для воздуха Pr ≈ 0,71 во всём диапазоне температур HVAC — это упрощает корреляции конвективной теплоотдачи и позволяет принять Pr = const в большинстве инженерных расчётов.

## Определение и физический смысл

{{< formula display="true" >}}
\mathrm{Pr} = \frac{\mu\, c_p}{\lambda} = \frac{\nu}{a}, \quad \nu = \frac{\mu}{\rho}, \quad a = \frac{\lambda}{\rho c_p}
{{< /formula >}}

где ν — кинематическая вязкость, a — тепловая диффузия. Pr = ν/a — отношение диффузии импульса к диффузии теплоты.

**Физическая интерпретация:**
- Pr < 1 (жидкие металлы, Pr ≈ 0,001–0,02): тепловой пограничный слой (thermal boundary layer) значительно толще гидродинамического — теплота переносится быстрее импульса.
- Pr ≈ 1 (газы, 0,65–0,85): оба слоя развиваются с близкой скоростью. Для воздуха Pr ≈ 0,71 — тепловой слой на 12% толще (δ_T/δ_v ≈ Pr^(−1/3) ≈ 1,12).
- Pr > 1 (вода при 20 °C Pr ≈ 7, масла Pr ≈ 100–10 000): гидродинамический слой много толще теплового.

## Корреляции конвективной теплоотдачи с участием Pr

### Трубный поток — вынужденная конвекция

**Корреляция Dittus–Boelter** (турбулентный поток, Re > 10 000, 0,6 < Pr < 160):

{{< formula display="true" >}}
\mathrm{Nu} = 0{,}023\, \mathrm{Re}^{0{,}8}\, \mathrm{Pr}^n, \quad n = \begin{cases} 0{,}4 & T_w > T_f \\ 0{,}3 & T_w < T_f \end{cases}
{{< /formula >}}

**Корреляция Gnielinski** (3 000 < Re < 5×10⁶, 0,5 < Pr < 2 000) — более точная:

{{< formula display="true" >}}
\mathrm{Nu} = \frac{(\xi/8)(\mathrm{Re} - 1000)\,\mathrm{Pr}}{1 + 12{,}7\sqrt{\xi/8}\,(\mathrm{Pr}^{2/3} - 1)}
{{< /formula >}}

где ξ — коэффициент Дарси–Вейсбаха; для гладкой трубы при Re = 10⁴–10⁶: ξ ≈ (0,790 ln Re − 1,64)^(−2) (формула Перре–Коха).

### Внешнее обтекание — плоская пластина

Турбулентный пограничный слой (5×10⁵ < Re_x < 10⁷):

{{< formula display="true" >}}
\overline{\mathrm{Nu}}_L = 0{,}037\, \mathrm{Re}_L^{4/5}\, \mathrm{Pr}^{1/3}
{{< /formula >}}

### Внешнее обтекание — цилиндр

Корреляция Черчилля–Бернштейна (Churchill–Bernstein, все Re):

{{< formula display="true" >}}
\overline{\mathrm{Nu}}_D = 0{,}3 + \frac{0{,}62\,\mathrm{Re}_D^{1/2}\,\mathrm{Pr}^{1/3}}{\left[1+(0{,}4/\mathrm{Pr})^{2/3}\right]^{1/4}} \left[1+\left(\frac{\mathrm{Re}_D}{282\,000}\right)^{5/8}\right]^{4/5}
{{< /formula >}}

### Естественная конвекция — вертикальная пластина

Число Релея Ra = Gr · Pr, Gr = g·β·ΔT·L³/ν².

Ламинарный режим (10⁴ < Ra < 10⁹):

{{< formula display="true" >}}
\overline{\mathrm{Nu}}_L = 0{,}59\, \mathrm{Ra}_L^{1/4}
{{< /formula >}}

Турбулентный (10⁹ < Ra < 10¹³):

{{< formula display="true" >}}
\overline{\mathrm{Nu}}_L = 0{,}10\, \mathrm{Ra}_L^{1/3}
{{< /formula >}}

## Числовой пример: теплоотдача в воздуховоде

**Задача:** Нагрев воздуха в круглом воздуховоде Ø 0,3 м. Расход V̇ = 3 000 м³/ч, T_воздуха = 20 °C, T_стенки = 70 °C.

**Решение:**

Скорость: V = V̇/A = (3 000/3 600)/(π·0,3²/4) = 0,833/0,0707 = 11,78 м/с.

Свойства при плёночной температуре T_пл = (20+70)/2 = 45 °C: ρ = 1,113 кг/м³, μ = 19,3 мкПа·с, c_p = 1 007 Дж/(кг·К), λ = 27,2 мВт/(м·К), Pr = 0,723.

Re = ρ·V·D/μ = 1,113·11,78·0,3/(19,3×10⁻⁶) = 203 900 > 10 000 — турбулентный.

Коэффициент трения (формула Колбрука–Уайта для гладкой трубы):
ξ ≈ (0,790·ln 203 900 − 1,64)^(−2) = (0,790·12,22 − 1,64)^(−2) = (8,01)^(−2) = 0,01559.

Число Нуссельта по Gnielinski:

Nu = (0,01559/8)·(203 900 − 1 000)·0,723 / [1 + 12,7·√(0,01559/8)·(0,723^(2/3) − 1)]
= 0,001949·202 900·0,723 / [1 + 12,7·0,04407·(0,8044 − 1)]
= 285,9 / [1 + 12,7·0,04407·(−0,1956)]
= 285,9 / [1 − 0,1094] = 285,9 / 0,8906 = 321.

Коэффициент теплоотдачи:

h = Nu·λ/D = 321·0,0272/0,3 = **29,1 Вт/(м²·К)**.

Для сравнения, Dittus–Boelter (n = 0,4): Nu = 0,023·203 900^0,8·0,723^0,4 = 0,023·3 074·0,871 = **61,5** — завышение на 91% из-за погрешности корреляции вне диапазона или ошибки. Перепроверка: 0,023·Re^0.8: Re^0.8 = 203 900^0.8 ≈ 11 050; Nu = 0,023·11 050·0,871 = 221. h = 221·0,0272/0,3 = 20,0 Вт/(м²·К). Gnielinski точнее в переходной и умеренно-турбулентной области.

## Влияние Pr на расчёт коэффициента теплоотдачи

Степень влияния Pr на Nu определяется показателем n в корреляции. Для вынужденной конвекции n ≈ 1/3–0,4. Чувствительность:

{{< formula display="true" >}}
\frac{\Delta \mathrm{Nu}}{\mathrm{Nu}} \approx n \cdot \frac{\Delta \mathrm{Pr}}{\mathrm{Pr}}
{{< /formula >}}

При n = 1/3 и ΔPr/Pr = 2% (диапазон HVAC): ΔNu/Nu ≈ 0,67% — пренебрежимо. Следовательно, Pr = 0,71 = const — допустимое и распространённое допущение.

Низкое Pr воздуха по сравнению с жидкостями (Pr ≫ 1) — основная причина, почему сторона воздуха является лимитирующим тепловым сопротивлением в воздухо-водяных теплообменниках: при прочих равных h_воздух ≪ h_вода.
