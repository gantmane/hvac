Критическое содержание влаги (critical moisture content, CMC) — минимальный уровень влаги в строительном материале, при котором начинается и поддерживается рост плесени. Этот порог определяется биологическими требованиями грибков к доступности воды (активности воды, a_w), физико-химическими свойствами субстрата и условиями среды. Знание CMC позволяет перейти от качественного критерия «нет конденсации» к количественному прогнозу риска плесени, необходимому для верификации конструкций по ASHRAE 160 и ISO 13788.

## Активность воды как физическая основа

Активность воды (water activity, a_w) — отношение фактического парциального давления пара на поверхности материала к давлению насыщения при той же температуре:

{{< formula display="true" >}}
a_w = \frac{P_v}{P_{sat}(T)} = \frac{ERH}{100}
{{< /formula >}}

где ERH — равновесная относительная влажность поверхности материала.

Биологический смысл: a_w количественно определяет доступность воды для метаболизма грибков. При a_w < 0,65 ни один известный строительный гриб не может расти. При a_w = 0,80 (80 % ОВ) большинство мезофильных видов начинают прорастать при температуре 15–25 °C.

{{< table title="Пороги активности воды для строительных плесеней" >}}
| Категория | Минимум a_w | Минимум ОВ, % | Скорость роста | Примеры видов |
|---|---|---|---|---|
| Ксерофилы | 0,65–0,70 | 65–70 | Медленная | Wallemia sebi, Eurotium |
| Мезофилы | 0,78–0,85 | 78–85 | Умеренная | Aspergillus, Penicillium, Cladosporium |
| Гидрофилы | 0,90–1,00 | 90–100 | Быстрая | Stachybotrys, Chaetomium |
| Консервативный порог | 0,80 | 80 | — | ASHRAE 160, ISO 13788 |
{{< /table >}}

## Равновесное содержание влаги (EMC)

Гигроскопические материалы обмениваются влагой с окружающим воздухом до равновесия. EMC — содержание влаги, при котором сорбция равна десорбции при данных T и ОВ. Кривая EMC от ОВ — изотерма сорбции.

EMC выражается в % по массе (отношение массы воды к массе сухого материала):

{{< formula display="true" >}}
EMC = \frac{m_{water}}{m_{dry}} \times 100\,\%
{{< /formula >}}

### Изотерма сорбции древесины (модель Хейлвуда–Хорробина)

{{< formula display="true" >}}
EMC = \frac{1800}{W} \left[\frac{KH}{1-KH} + \frac{K_1 KH + 2K_1 K_2 K^2 H^2}{1 + K_1 KH + K_1 K_2 K^2 H^2}\right]
{{< /formula >}}

где H = RH/100; W, K, K₁, K₂ — температурно-зависимые коэффициенты (ASHRAE Fundamentals гл. 26, таблица 2).

**Упрощённое линейное приближение** для диапазона 15–27 °C:

{{< formula display="true" >}}
EMC\,(\%) \approx 0{,}22 \times RH\,(\%)
{{< /formula >}}

Пример: при ОВ 80 % → EMC ≈ 17,6 %; при ОВ 90 % → EMC ≈ 19,8 %. Это вблизи традиционного строительного критерия «19 % по массе».

### EMC по материалам при критических условиях

{{< table title="Равновесное содержание влаги строительных материалов (23 °C)" >}}
| Материал | EMC при 50 % ОВ | EMC при 80 % ОВ | EMC при 95 % ОВ |
|---|---|---|---|
| Хвойная древесина (сосна, ель) | 9,0 % | 16–18 % | 24–28 % |
| Твёрдые породы (дуб, бук) | 8,5 % | 15–17 % | 22–26 % |
| OSB | 6–8 % | 17–19 % | 28–32 % |
| Фанера | 7–9 % | 16–18 % | 26–30 % |
| ГКЛ (бумажная облицовка) | 5–7 % | 12–15 % | 20–22 % |
| ГКЛ (гипсовое ядро) | 0,4–0,6 % | 1,8–2,5 % | 4–5 % |
| Целлюлоза обработанная | 8–10 % | 18–22 % | 30–35 % |
| Минеральная вата | 0,05–0,1 % | 0,2–0,4 % | 1,0–2,0 % |
| Бетон (лёгкий) | 3–4 % | 5–7 % | 8–10 % |
{{< /table >}}

Бумажная облицовка ГКЛ имеет EMC в 5–8 раз выше, чем гипсовое ядро — она является первичным местом инициирования роста плесени на гипсокартоне.

## Критическое содержание влаги по материалам

CMC — порог, выше которого при T > 5 °C возникает устойчивый рост плесени:

{{< table title="Критическое содержание влаги строительных материалов" >}}
| Материал | CMC, % по массе | Соответствующая ОВ | Основной риск |
|---|---|---|---|
| Хвойная древесина | 19–20 | 78–82 % | Бурая/белая гниль, мицелий |
| OSB, фанера | 19–22 | 80–85 % | Расслоение, гниль |
| ДСП (particleboard) | 14–16 | 75–80 % | Разбухание, разрушение |
| Бумажная облицовка ГКЛ | 1,5–2,0 | 75–80 % | Поверхностная плесень |
| ГКЛ (гипсовое ядро) | 4–6 | 85–90 % | Деградация ядра |
| Целлюлоза обработанная | 18–22 | 80–85 % | Плесень (умеренный риск) |
| Минеральная вата | нет прямого | >80 % (на пыли) | Плесень на загрязнениях |
| Бетон (нейтрализованный) | 8–10 | 85–90 % | Низкий риск из-за pH |
| ППУ закрытоячеистый | нет прямого | нет | Нет субстрата для питания |
{{< /table >}}

Промышленный стандарт для монтажа деревянных конструкций: влажность ≤19 % перед закрытием стены — именно это значение является критическим CMC для хвойных пород.

## Критерии ASHRAE 160 для содержания влаги

ASHRAE 160-2016 устанавливает критерии не через CMC напрямую, а через поверхностную ОВ, которая связана с CMC через изотерму сорбции:

**Климатические зоны с T_avg,month > 0 °C:**
- Поверхностная ОВ ≤80 % — незначительный риск.
- ОВ >80 % ≤30 последовательных дней — допустимо.
- ОВ >80 % >30 последовательных дней — неприемлемый риск.

**Климатические зоны с T_avg,month ≤0 °C:**
- ОВ >80 % ≤7 последовательных дней — допустимо.
- ОВ >80 % >7 последовательных дней — неприемлемый риск.

Расчёт по ASHRAE 160 требует почасового гигротермического моделирования с учётом:
- Генерации внутренней влажности (производство водяного пара жителями, готовкой).
- Наружного климата по справочному (влажному) году.
- Радиационного нагрева поверхности.
- Свойств гигроскопических материалов.
- Воздушных утечек и конвективного переноса.

### ISO 13788

ISO 13788 «Гигротермические характеристики строительных компонентов и элементов» использует:
- Минимальный температурный фактор f_Rsi для предотвращения поверхностной плесени.
- Метод Глейзера для проверки межслойной конденсации (упрощённый).

{{< formula display="true" >}}
f_{Rsi,min} = \frac{RH_{crit}/100 \cdot P_{sat}(T_i) - P_{v,e}}{P_{sat}(T_i) - P_{v,e}}
{{< /formula >}}

При RH_crit = 80 %, T_i = 20 °C, φ_i = 50 % и T_e = −10 °C типичный f_Rsi,min ≈ 0,72.

## Влияние температуры на CMC

Скорость роста плесени зависит от температуры даже при постоянной ОВ. Эффективный CMC снижается при оптимальных температурах роста:

{{< table title="Поправка критической ОВ на температуру" >}}
| T, °C | Корректировка критической ОВ | Пояснение |
|---|---|---|
| 5–10 | +5–10 % | Медленный рост, споры слабо активны |
| 10–20 | +0–5 % | Субоптимальная скорость роста |
| 20–30 | Эталон (0 %) | Оптимальный диапазон роста |
| 30–40 | +3–8 % | Тепловой стресс для большинства видов |
| >40 | >+15 % или рост невозможен | Термическая инактивация |
{{< /table >}}

Холодные поверхности (T = 10–15 °C) при высокой ОВ (90–95 %) представляют особый риск: ОВ критически высока, а температура всё ещё в диапазоне роста. Именно такие условия типичны для обшивки OSB в каркасной стене в начале отопительного сезона.

## Влияние pH поверхности

Щелочные материалы проявляют естественную устойчивость к грибкам:

- Свежий бетон pH 12–13: устойчив к большинству плесеней, несмотря на высокое EMC при твердении.
- Карбонизация снижает pH до 8–9 за 1–5 лет → восприимчивость к плесени возрастает.
- Гипсовое ядро pH 7–8: умеренная устойчивость. Бумажная облицовка pH 5–6: высокая восприимчивость.
- Необработанная хвойная древесина pH 4–5: оптимальная питательная среда для Penicillium, Aspergillus.

При оценке риска плесени для бетонных конструкций необходимо учитывать возраст и степень карбонизации.

## Доступность питательных веществ

CMC также зависит от наличия органических питательных веществ:

**Высокое содержание питательных веществ (CMC снижен):**
- Бумажная облицовка ГКЛ: целлюлоза + клейстер.
- Хвойная древесина, OSB: лигнин + гемицеллюлоза.
- Целлюлозная теплоизоляция.

**Низкое содержание питательных веществ (CMC повышен):**
- Гипсовое ядро: инертный субстрат.
- Минеральная вата: неорганический материал.
- Бетон и кладка.
- ППУ закрытоячеистый: химически инертный субстрат.

Накопление пыли на инертных поверхностях снижает эффективный CMC: органический слой пыли обеспечивает достаточно углерода для мезофильных плесеней даже при ОВ 80 %.

## Практическое применение в проектировании HVAC

### 1. Управление внутренней влажностью

Целевая внутренняя ОВ должна обеспечивать поверхностную ОВ ≤70–75 % с учётом тепловых мостиков. По ASHRAE 62.1 и СП 60.13330:

- Жилые здания: зима 30–40 % ОВ, лето ≤60 %.
- Помещения с повышенной влажностью (бассейны, прачечные): ОВ ≤50–55 % при принудительной вентиляции.

### 2. Размещение теплоизоляции

Основная задача — поддержание конденсирующих поверхностей выше точки росы. Оценочная формула минимального RSI наружной теплоизоляции для предотвращения конденсации на обшивке:

{{< formula display="true" >}}
R_{ext,min} = R_{total} \cdot \frac{T_i - T_{dp}}{T_i - T_e} - R_{int}
{{< /formula >}}

где T_dp — точка росы внутреннего воздуха.

### 3. Паросдерживающий слой

Правильный паросдерживающий слой ограничивает диффузионный поток до значений, при которых EMC в древесных элементах не превышает CMC. Рекомендуемый предельный диффузионный поток для хвойной древесины (по CM = 19 %, влагоёмкость до CMC ≈ 7 % от сухой массы):

{{< formula display="true" >}}
g_{limit} = \frac{0{,}07 \cdot \rho_{wood} \cdot d_{wood}}{t_{season}}
{{< /formula >}}

где ρ_wood ≈ 450 кг/м³ (сосна), d_wood — толщина, t_season — продолжительность сезона.

Для стойки 38 мм за 180-суточный сезон: g_limit = 0,07 × 450 × 0,038 / (180 × 86400) = 7,6 × 10⁻⁸ кг/(м²·с) = 6,6 г/(м²·сут).

### 4. Непрерывность воздушного барьера

Конвективный перенос влаги при утечках воздуха превышает диффузионный в 50–100 раз (ASHRAE Fundamentals гл. 25). Воздушный барьер с воздухопроницаемостью ≤0,02 л/(с·м²) при 75 Па (EN 13829, ASTM E779) — необходимое условие управления CMC в ограждающих конструкциях.

### 5. Выбор материалов устойчивых к плесени

В зонах повышенного риска (ванные, подвалы, подполья) применять материалы с высоким CMC или без субстрата для питания плесени. По ASTM D3273 (стойкость к плесени на внутренних покрытиях) и ASTM G21 (стойкость синтетических полимеров).
