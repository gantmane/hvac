Конденсация в строительных конструкциях возникает, когда парциальное давление водяного пара в данной точке превышает давление насыщения при температуре этой точки. Различают два вида: поверхностная конденсация (на внутренней поверхности ограждения) и межслойная (внутри конструктивного сечения). Оба вида прогнозируются аналитически методом Глейзера (стационарный анализ, ISO 13788) или численно нестационарным ГТ-моделированием (ISO 15026, EN 15026).

Нормативная база: ASHRAE 160-2021, ASHRAE Fundamentals (гл. 25–26), ISO 13788:2012, ISO 15026-2:2012, СП 50.13330.2017 (разд. 8.7), ГОСТ 30244.

## Давление насыщения водяного пара

Давление насыщения `p_sat(T)` (уравнение Магнуса-Тетенса):

{{< formula display="true" >}}
p_{sat}(T) = 610{,}5 \cdot \exp\!\left(\frac{17{,}27 \cdot T}{237{,}3 + T}\right), \quad \text{Па} \quad (T \text{ в }°C)
{{< /formula >}}

{{< table title="Давление насыщения водяного пара при ключевых температурах" >}}
| T, °C | p_sat, Па | T, °C | p_sat, Па |
|---|---|---|---|
| −26 | 163 | +5 | 872 |
| −18 | 126 | +10 | 1 228 |
| −10 | 260 | +15 | 1 705 |
| 0 | 611 | +20 | 2 338 |
| +2 | 705 | +21 | 2 487 |
{{< /table >}}

## Температура точки росы

Температура точки росы `T_dp` — температура, при охлаждении до которой воздух с данным парциальным давлением пара `p_v` достигает насыщения:

{{< formula display="true" >}}
T_{dp} = \frac{237{,}3 \cdot \beta}{17{,}27 - \beta}, \quad \text{где} \quad \beta = \ln\!\left(\frac{p_v}{610{,}5}\right)
{{< /formula >}}

**Пример:** внутри `T_i = +20 °C`, `φ_i = 55 %` → `p_v = 0,55 × 2338 = 1286 Па`;

{{< formula display="true" >}}
\beta = \ln(1286 / 610{,}5) = 0{,}748; \quad T_{dp} = \frac{237{,}3 \times 0{,}748}{17{,}27 - 0{,}748} = 10{,}7 \;°C
{{< /formula >}}

Любая внутренняя поверхность ограждения холоднее +10,7 °C будет конденсировать влагу при данных условиях.

## Поверхностная конденсация

### Температура внутренней поверхности

При одномерном установившемся тепловом потоке:

{{< formula display="true" >}}
T_{si} = T_i - \frac{T_i - T_e}{R_{total}} \cdot R_{si}
{{< /formula >}}

где `R_si = 0,13 м²·К/Вт` (внутреннее конвективное сопротивление по ISO 6946 для горизонтального потока); `R_total` — полное тепловое сопротивление конструкции, м²·К/Вт.

**Температурный коэффициент** (temperature ratio, ISO 13788):

{{< formula display="true" >}}
f_{Rsi} = \frac{T_{si} - T_e}{T_i - T_e} = 1 - \frac{R_{si}}{R_{total}}
{{< /formula >}}

Минимальное значение `f_Rsi,min`, при котором поверхностная конденсация отсутствует, определяется из условия `T_si ≥ T_dp`:

{{< formula display="true" >}}
f_{Rsi,min} = \frac{T_{dp} - T_e}{T_i - T_e}
{{< /formula >}}

**Пример:** `T_i = +20 °C`, `φ_i = 55 %` → `T_dp = 10,7 °C`; `T_e = −26 °C` (Москва, январь);

{{< formula display="true" >}}
f_{Rsi,min} = \frac{10{,}7 - (-26)}{20 - (-26)} = \frac{36{,}7}{46} = 0{,}797
{{< /formula >}}

Конструкция стены с `R_total = 4,27 м²·К/Вт`:

{{< formula display="true" >}}
f_{Rsi} = 1 - \frac{0{,}13}{4{,}27} = 0{,}970 > 0{,}797 \quad \checkmark
{{< /formula >}}

Поверхностная конденсация исключена. По СП 50.13330.2017 (п. 8.5) нормируемое значение `f_Rsi ≥ 0,8` при температурных условиях холодной пятидневки.

### Тепловые мостики

На тепловых мостиках (стальные стойки, железобетонные колонны, монолитные перемычки) `R_local` резко снижается. Для стальной стойки 100×50×3 мм с шагом 600 мм в каркасной стене с минеральной ватой:

`R_local(стойка) ≈ 0,8 м²·К/Вт`; `f_Rsi(стойка) = 1 - 0,13/0,8 = 0,84` — вблизи нормируемой границы. Устранение: наружная непрерывная теплоизоляция (CI) не менее RSI 1,0 поднимает `f_Rsi` до 0,95–0,98.

## Межслойная конденсация: метод Глейзера

### Алгоритм (ISO 13788:2012, разд. 6)

1. Задать расчётные внутренние (`T_i`, `φ_i`) и наружные (`T_e`, `φ_e`) условия.
2. Рассчитать температурный профиль через слои (пропорционально тепловым сопротивлениям).
3. Рассчитать `p_sat(T)` на каждом стыке слоёв.
4. Построить линейный профиль парциального давления пара `p_v` через слои (пропорционально `s_d = μ·d` — эквивалентной толщине воздушного слоя).
5. В точках, где `p_v > p_sat`, фиксировать конденсацию.
6. Рассчитать плотность потока конденсации и суммарное накопление за месяц.
7. Проверить годовой баланс: суммарное высыхание за тёплые месяцы ≥ суммарное накопление за холодные.

### Пример: стена Москвы, январь

**Конструкция (изнутри наружу):**

{{< table title="Слои стены и расчётные параметры" >}}
| Слой | d, м | λ, Вт/(м·К) | R, м²·К/Вт | μ | s_d, м |
|---|---|---|---|---|---|
| R_si | — | — | 0,13 | — | — |
| Пароизоляция п/э | 0,0002 | — | ≈ 0 | 100 000 | 20,0 |
| ГКЛ | 0,012 | 0,21 | 0,057 | 10 | 0,12 |
| Минеральная вата | 0,150 | 0,038 | 3,947 | 1 | 0,15 |
| OSB | 0,012 | 0,13 | 0,092 | 50 | 0,60 |
| Вентилируемый зазор | — | — | — | — | — |
| R_se | — | — | 0,04 | — | — |
{{< /table >}}

`R_total = 0,13 + 0 + 0,057 + 3,947 + 0,092 + 0,04 = 4,27 м²·К/Вт`.

Суммарная `s_d = 20,0 + 0,12 + 0,15 + 0,60 = 20,87 м` (наружу от пароизоляции до вентилируемого зазора).

**Условия:** `T_i = +20 °C`, `φ_i = 55 %` → `p_v,i = 1286 Па`; `T_e = −26 °C`, `φ_e = 84 %` → `p_v,e = 137 Па`.

**Температура и давление насыщения на стыках:**

{{< table title="Профиль температуры и давления насыщения в конструкции" >}}
| Стык | ΣR от внутренней, м²·К/Вт | T, °C | p_sat, Па |
|---|---|---|---|
| Внутренняя поверхность | 0,13 | 17,98 | 2 063 |
| ГКЛ / вата | 0,187 | 17,41 | 1 990 |
| Вата / OSB | 4,134 | −18,70 | 128 |
| OSB / зазор | 4,226 | −19,65 | 119 |
{{< /table >}}

**Давление пара на стыках** (после пароизоляции `s_d = 20,0` м; общая `s_d = 20,87 м`):

На стыке ГКЛ/вата (`Σs_d = 20,0 + 0,12 = 20,12 м`):

{{< formula display="true" >}}
p_v = 1286 - (1286 - 137) \cdot \frac{20{,}12}{20{,}87} = 1286 - 1106 = 180 \; \text{Па}
{{< /formula >}}

`p_v(180 Па) << p_sat(1990 Па)` — конденсации нет.

На стыке вата/OSB (`Σs_d = 20,27 м`):

{{< formula display="true" >}}
p_v = 1286 - 1149 \times \frac{20{,}27}{20{,}87} = 1286 - 1116 = 170 \; \text{Па}
{{< /formula >}}

`p_v(170 Па) > p_sat(128 Па)` — **конденсация на стыке вата/OSB**.

**Вывод:** пароизоляция класса I (`s_d = 20 м`) снижает поток пара до незначительного уровня (≈ 1149/20,87 = 55 нг/(м²·с)), однако в отсутствие пароизоляции или при её недостаточном `s_d` конденсация на холодной обшивке неизбежна при температурах ниже −18 °C.

### Ограничения метода Глейзера

Метод ISO 13788 предполагает:
- установившийся одномерный теплоперенос (нет учёта нестационарности);
- отсутствие накопления влаги в объёме материала (нет гистерезиса сорбции);
- отсутствие капиллярного переноса жидкой воды;
- отсутствие воздушного переноса.

Для конструкций с гигроскопичными материалами (дерево, бетон, кирпич), а также при наличии дождевой нагрузки необходимо нестационарное ГТ-моделирование по ISO 15026.

## Нестационарное ГТ-моделирование (ISO 15026)

Численное решение связанных уравнений переноса тепла и влаги учитывает:
- накопление влаги в порах материала (изотерма сорбции `w(φ)`);
- капиллярный транспорт жидкой воды (коэффициент жидкостной диффузии `D_w(w)`);
- солнечный нагрев и ветровой дождь (климатические граничные условия);
- гистерезис сорбции/десорбции.

Управляющее уравнение влагопереноса:

{{< formula display="true" >}}
\frac{\partial w}{\partial t} = \nabla \cdot \left( D_w(w)\,\nabla w + \delta_p \,\nabla p_v \right)
{{< /formula >}}

Инструменты: WUFI Pro (Fraunhofer IBP), MOISTURE-EXPERT (ORNL), Delphin (TU Dresden). Критерий по ASHRAE 160-2021: скользящее 30-суточное среднее относительной влажности на поверхности материала `≤ 80 %` при `T > 5 °C`.

## Стратегии предотвращения конденсации

{{< table title="Стратегии предотвращения конденсации по климатическим зонам" >}}
| Климат | Вид конденсации | Основная мера | Дополнительная мера |
|---|---|---|---|
| Холодный (зоны 5–8) | Межслойная (зима) | Паровой замедлитель класса I–II внутри | Наружная CI (RSI ≥ 1,5–2,5) |
| Жаркий влажный (зоны 1–3) | Поверхностная и межслойная (лето) | Паронепроницаемая наружная облицовка | Нет замедлителя класса I внутри |
| Смешанный (зона 4) | Сезонно меняющаяся | Умный замедлитель (hygrovariable) | CI снаружи |
| Арктический (зона 8) | Множественные плоскости конденсации | Класс I + наружная CI ≥ RSI 3,0 | Дренаж конденсата |
{{< /table >}}

**Принцип наружной теплоизоляции:** чем больше доля `R_total` расположена снаружи от плоскости возможной конденсации, тем выше температура в этой плоскости и ниже риск конденсации. Для Москвы доля наружной CI ≥ 30–40 % от `R_total` эффективно устраняет конденсацию на внешней обшивке каркасной стены.
