Жёсткие пенные теплоизоляционные плиты обеспечивают высокое RSI на единицу толщины — критически важное свойство для изоляции воздуховодов HVAC, трубопроводных систем и ограждающих конструкций при ограниченном пространстве. Три основных типа — вспененный полистирол (EPS, expanded polystyrene), экструдированный полистирол (XPS, extruded polystyrene) и полиизоцианурат (Polyiso) — различаются по структуре ячеек, тепловым характеристикам, паропроницаемости и противопожарным свойствам.

## Структура ячеек и механизм теплоизоляции

### EPS — вспененный полистирол

EPS производится вспениванием гранул полистирола (пропитанных пентаном) паровым нагревом с последующим спеканием. Образуется частично-открытая структура: 10–15 % открытых пор; 95–98 % объёма занимает воздух.

**Параметры структуры:**
- Диаметр ячеек: 0,2–0,5 мм.
- Диапазон плотностей: 11–45 кг/м³.
- Прочность соединения гранул: 103–172 кПа.

### XPS — экструдированный полистирол

XPS производится методом непрерывной экструзии: полистирол смешивается с вспенивающим агентом при контролируемых T и P. Получается равномерная замкнутоячеистая структура. Исторические вспениватели — ГХФУ; современные — ГФУ-134а и ГФО-1234ze (глобальный потенциал потепления GWP100 = 7).

**Параметры структуры:**
- Содержание замкнутых ячеек: > 95 %.
- Диаметр ячеек: 0,1–0,2 мм.
- Диапазон плотностей: 21–48 кг/м³.

### Полиизоцианурат (Polyiso)

Получается реакцией изоцианата с полиолом при катализировании. Жёсткий пенопласт с > 90 % замкнутых ячеек диаметром 0,05–0,15 мм. Современные вспениватели — пентан или вода.

**Параметры структуры:**
- Плотность: 29–48 кг/м³.
- Прочность на сжатие: 110–172 кПа.
- Размерная стабильность: ± 2 % при нормальных условиях.

## Теплопроводность и RSI

### Сравнительные характеристики

{{< table title="RSI-значения пенных плит (на сантиметр толщины) по ASTM C518 при средней температуре 24 °C" >}}
| Материал / Плотность | Начальное RSI/см, м²·К/Вт | Долгосрочное RSI/см | Период стабилизации |
|---|---|---|---|
| EPS 14 кг/м³ | 0,60–0,64 | 0,60–0,64 | Стабильное |
| EPS 24 кг/м³ | 0,64–0,68 | 0,64–0,68 | Стабильное |
| EPS 46 кг/м³ | 0,68–0,72 | 0,68–0,72 | Стабильное |
| XPS | 0,79–0,88 | 0,74–0,79 | 5–10 лет |
| Polyiso без облицовки | 0,93–1,06 | 0,86–0,91 | 5–10 лет |
| Polyiso с фольгой | 1,02–1,14 | 0,90–0,98 | 5–10 лет |
{{< /table >}}

**Тепловой дрейф** (thermal aging): у XPS и полиизо вспенивающие агенты диффундируют из ячеек и замещаются воздухом — долгосрочная k возрастает на 8–15 %. EPS стабилен, поскольку ячейки изначально содержат воздух.

### Температурная зависимость теплопроводности

{{< table title="Изменение k с температурой (Вт/м·К)" >}}
| Материал | При −7 °C | При 24 °C | При 66 °C |
|---|---|---|---|
| EPS | 0,033 | 0,039 | 0,046 |
| XPS | 0,025 | 0,030 | 0,036 |
| Polyiso | 0,040 | 0,025 | 0,027 |
{{< /table >}}

**Критическое свойство полиизо:** при температурах ниже 4 °C k резко возрастает. При −18 °C k ≈ 0,043 Вт/м·К — снижение RSI на 20–30 % по сравнению с номинальным значением. Это ограничивает применение полиизо в наружных воздуховодах и трубопроводах в климатических зонах 5–8 при низких зимних температурах.

## Паропроницаемость и влагостойкость

{{< table title="Паропроницаемость и водопоглощение пенных плит" >}}
| Материал | Паропроницаемость, нг/(м²·с·Па) | Водопоглощение (ASTM C272, 24 ч), % по объёму | Класс паробарьера |
|---|---|---|---|
| EPS | 31–79 | 2–4 | Класс III (полупроницаемый) |
| XPS | 10–19 | 0,1–0,3 | Класс III |
| Polyiso без облицовки | 24–47 | 1–2 | Класс III |
| Polyiso с фольгой | 0,31–0,79 | < 0,1 | Класс I (паробарьер) |
{{< /table >}}

**XPS** — наилучшая влагостойкость среди необлицованных пен благодаря равномерной замкнутоячеистой структуре. Предпочтителен для подземных применений и при прямом контакте с грунтом.

**EPS** поглощает воду на 2–4 % из-за частично открытоячеистой структуры (капиллярное действие между спечёнными гранулами).

**Полиизо с фольгой** — фактически паробарьер (снижение паропроницаемости на 98–99 %); обязателен для изоляции трубопроводов ниже температуры окружающей среды.

### Стойкость к замораживанию-оттаиванию

По результатам ASTM C666 (300 циклов):
- EPS: снижение прочности < 5 %.
- XPS: снижение прочности < 3 %.
- Polyiso: снижение прочности 5–10 % при наличии влаги во время замерзания.

## Противопожарные характеристики

### Индексы распространения пламени и задымления

{{< table title="Результаты ASTM E84 (туннельный тест Штейнера)" >}}
| Материал | Индекс распространения пламени (FSI) | Индекс задымления (SDI) | Классификация |
|---|---|---|---|
| EPS стандартный | 5–25 | 300–450 | Класс B–C |
| EPS огнестойкий | < 25 | 200–450 | Класс B |
| XPS стандартный | 5–15 | 100–300 | Класс B |
| XPS огнестойкий | < 25 | < 450 | Класс A–B |
| Polyiso с фольгой | < 25 | < 50 | Класс A |
| Polyiso без облицовки | 15–75 | 150–400 | Класс B–C |
{{< /table >}}

Полиизо с алюминиевой облицовкой достигает класса A благодаря негорючей фольге и свойствам коксообразования химии полиизоциануратов.

**Температуры воспламенения (принципиальные ограничения):**
- EPS: воспламенение 315–360 °C, плавление 93–116 °C.
- XPS: воспламенение 338–371 °C, плавление 74–85 °C.
- Polyiso: воспламенение 427–454 °C, коксование выше 204 °C.

Все пенные плиты требуют теплового барьера при использовании внутри зданий — как правило, гипсокартон 12,7 мм (15-минутный тепловой барьер) по разделу 2603 IBC / п. 6.10.4 NFPA 90A.

## Числовой пример: расчёт толщины изоляции воздуховода

**Условие.** Приточный воздуховод прямоугольного сечения, расположенный в механическом помещении с T_пом = 30 °C, φ = 55 % → T_точки_росы = 20,3 °C. Температура воздуха в воздуховоде: T_вод = 14 °C. Допустимый запас: 2 К.

Требуемая минимальная температура наружной поверхности изоляции: T_пов = 20,3 + 2 = 22,3 °C. Допустимый удельный тепловой поток через изоляцию: q = (T_пов − T_вод) / RSI_тр; α_нар = 10 Вт/м²·К.

Тепловой поток через наружную плёнку при T_пов = 22,3 °C: q = α_нар × (T_пом − T_пов) = 10 × (30 − 22,3) = 77 Вт/м².

Требуемое RSI изоляции:

{{< formula display="true" >}}
RSI_{\text{тр}} = \frac{T_{\text{пов}} - T_{\text{вод}}}{q} = \frac{22{,}3 - 14}{77} \approx 0{,}108 \; \text{м}^2\text{·К/Вт}
{{< /formula >}}

Минимальная толщина XPS (долгосрочная k = 0,036 Вт/м·К):

{{< formula display="true" >}}
d = RSI_{\text{тр}} \times k = 0{,}108 \times 0{,}036 \approx 0{,}004 \; \text{м} = 4 \; \text{мм}
{{< /formula >}}

Принимается к монтажу: 25 мм XPS (ASHRAE 90.1, таблица 6.8.2 — минимум для воздуховодов при ΔT > 10 К в помещениях с кондиционированием). Для φ = 80 % (T_точки_росы = 26,2 °C) требуемое RSI возрастает до 0,53 м²·К/Вт → толщина XPS: 53/36 = 19 мм, принимается 50 мм.

## Применение в системах HVAC

### Изоляция воздуховодов

{{< table title="Параметры применения пенных плит для изоляции воздуховодов" >}}
| Тип | Макс. T непрерывная, °C | Стандартная толщина, мм | Облицовка |
|---|---|---|---|
| EPS | 74 | 25–50 | ФСК (фольга-сетка-крафт) |
| XPS | 74 | 25–50 | ФСК или алюминий |
| Polyiso | 121 | 25–50 | Алюминиевая фольга |
{{< /table >}}

Полиизо предпочтителен для высокотемпературных применений: пароводяные трассы, воздуховоды дымоудаления, рекуперативные установки.

**Герметизация стыков:** алюминиевая лента шириной ≥ 50 мм или мастика; неадекватная герметизация снижает эффективное RSI на 15–25 % через тепловые мосты.

### Изоляция трубопроводов

Для трубопроводов ниже температуры окружающей среды (охлаждённая вода, хладагент):
- XPS и фольгированный полиизо — оптимальный выбор: минимальное влагопоглощение.
- Минимальный RSI: R-5 для трубопроводов охлаждённой воды (по ASHRAE 90.1, Table 6.8.3).
- Паробарьер на поверхности обязателен.

### Кожухи наружного оборудования

Конструкции из плит с мин. RSI = R-10–R-15:
- Водонепроницаемая наружная облицовка (алюминий, виниловые панели).
- Вентиляционные зазоры для предотвращения накопления влаги.
- Противопожарная сборка при близости к зданию.

## Химическая стойкость

EPS и XPS растворяются в органических растворителях (бензол, толуол, ацетон, дихлорметан, этилацетат) — прямой контакт недопустим. Полиизо несколько более стоек, но также деградирует при воздействии сильных растворителей.

**Совместимые материалы для прямого контакта:** портландцемент, гипс, акриловые и латексные клеи, водорастворимые покрытия, полиэтиленовые плёнки. Тестирование по ASTM C1338 рекомендуется для конкретных сочетаний материалов.
