Психрометрические расчёты образуют количественную основу любого проекта HVAC. Они позволяют определить тепловые и влажностные нагрузки, выбрать оборудование и проверить фактическую производительность системы. Точность расчётов определяется выбором математической модели: от простых линейных приближений, пригодных для грубых оценок, до высокоточных формулировок ASHRAE, рекомендуемых для компьютерных расчётов.

## Термодинамические основы

### Модель идеального газа

Атмосферный воздух при условиях HVAC (t = −40…+60 °C, p = 60–110 кПа) описывается уравнением состояния идеального газа с достаточной точностью. Для каждого компонента смеси:

{{< formula display="true" >}}
p_a V = m_a R_a T,\quad p_v V = m_v R_v T
{{< /formula >}}

{{< table title="Физические константы компонентов влажного воздуха" >}}
| Константа | Обозначение | Значение | Единица |
|---|---|---|---|
| Удельная газовая постоянная сухого воздуха | R_a | 287,042 | Дж/(кг·К) |
| Удельная газовая постоянная водяного пара | R_v | 461,52 | Дж/(кг·К) |
| Молярная масса сухого воздуха | M_a | 28,966 | г/моль |
| Молярная масса водяного пара | M_v | 18,015 | г/моль |
| Психрометрическая константа ε = M_v/M_a | ε | 0,6220 | — |
| Удельная теплоёмкость сухого воздуха | c_pa | 1,006 | кДж/(кг·К) |
| Удельная теплоёмкость водяного пара | c_pv | 1,860 | кДж/(кг·К) |
| Скрытая теплота испарения при 0 °C | h_fg0 | 2501,0 | кДж/кг |
| Скрытая теплота испарения при 25 °C | h_fg25 | 2441,7 | кДж/кг |
{{< /table >}}

### Закон Дальтона и закон Гиббса–Дальтона

По закону Дальтона давление смеси равно сумме парциальных давлений:

{{< formula display="true" >}}
p = p_a + p_v
{{< /formula >}}

Закон Гиббса–Дальтона: каждый компонент смеси ведёт себя так, как если бы он занимал весь объём при температуре смеси. Это позволяет складывать термодинамические функции компонентов:

{{< formula display="true" >}}
H = m_a h_a + m_v h_v,\quad S = m_a s_a + m_v s_v
{{< /formula >}}

## Давление насыщенного пара

### Уравнения Хайланда–Вексера (ASHRAE 2021)

Уравнения Хайланда–Вексера (Hyland–Wexler, 1983) — стандарт ASHRAE для расчёта давления насыщенного пара. Погрешность < 0,01 % в диапазоне −100 °C до +200 °C.

**Над жидкой водой (0 °C до 200 °C), T в К, p в Па:**

{{< formula display="true" >}}
\ln p_{ws} = \frac{C_1}{T} + C_2 + C_3 T + C_4 T^2 + C_5 T^3 + C_6 \ln T
{{< /formula >}}

{{< table title="Коэффициенты Хайланда–Вексера (жидкая вода)" >}}
| Коэффициент | Значение |
|---|---|
| C₁ | −5800,2206 |
| C₂ | 1,3914993 |
| C₃ | −4,8640239 × 10⁻² |
| C₄ | 4,1764768 × 10⁻⁵ |
| C₅ | −1,4452093 × 10⁻⁸ |
| C₆ | 6,5459673 |
{{< /table >}}

**Над льдом (−100 °C до 0 °C):**

{{< formula display="true" >}}
\ln p_{ws} = \frac{C_7}{T} + C_8 + C_9 T + C_{10} T^2 + C_{11} T^3 + C_{12} \ln T
{{< /formula >}}

{{< table title="Коэффициенты Хайланда–Вексера (лёд)" >}}

|---|---|
| C₇ | −5674,5359 |
| C₈ | 6,3925247 |
| C₉ | −9,6778430 × 10⁻³ |
| C₁₀ | 6,2215701 × 10⁻⁷ |
| C₁₁ | 2,0747825 × 10⁻⁹ |
| C₁₂ | −9,4840240 × 10⁻¹³ |
{{< /table >}}

### Приближение Магнуса–Тетенса

Для инженерных расчётов в диапазоне 0–60 °C:

{{< formula display="true" >}}
p_{ws}(t) = 0{,}61094 \cdot \exp\!\left(\frac{17{,}625\,t}{t + 243{,}04}\right)\quad[\text{кПа},\; t\text{ в °C}]
{{< /formula >}}

Погрешность < 0,3 % при 0–50 °C.

| −20 | 0,1034 | 15 | 1,705 |
| −10 | 0,2599 | 20 | 2,338 |
| 0 | 0,6113 | 25 | 3,169 |
| 5 | 0,8725 | 30 | 4,246 |
| 10 | 1,228 | 40 | 7,384 |
{{< /table >}}

## Алгоритмы расчёта психрометрических свойств

### Коэффициент влажности W

{{< formula display="true" >}}
W = \frac{0{,}6220 \cdot p_v}{p - p_v}\quad[\text{кг/кг}]
{{< /formula >}}

При известной φ и t_db:

{{< formula display="true" >}}
W = \frac{0{,}6220 \cdot \varphi \cdot p_{ws}(t_{db})}{p - \varphi \cdot p_{ws}(t_{db})}
{{< /formula >}}

### Относительная влажность φ

{{< formula display="true" >}}
\varphi = \frac{p_v}{p_{ws}(t_{db})} = \frac{W \cdot p}{p_{ws}(t_{db}) \cdot (0{,}6220 + W)}
{{< /formula >}}

### Температура точки росы t_dp

Инверсное уравнение Магнуса:

{{< formula display="true" >}}
t_{dp} = \frac{243{,}04 \cdot \ln(p_v / 0{,}61094)}{17{,}625 - \ln(p_v / 0{,}61094)}\quad[°\text{C}]
{{< /formula >}}

### Термодинамическая температура влажного термометра t_wb

t_wb определяется итерационно из уравнения адиабатического насыщения:

{{< formula display="true" >}}
W = W_s(t_{wb}) - \frac{c_{pa}}{h_{fg}(t_{wb})} \cdot (t_{db} - t_{wb})
{{< /formula >}}

Для аспирационного психрометра (психрометрическая формула, скорость > 3,5 м/с):

{{< formula display="true" >}}
W = W_s(t_{wb}) - A_\psi \cdot (t_{db} - t_{wb}),\quad A_\psi = 6{,}6 \times 10^{-4}\;\text{К}^{-1}
{{< /formula >}}

### Удельная энтальпия h

{{< formula display="true" >}}
h = 1{,}006\,t_{db} + W\,(2501 + 1{,}86\,t_{db})\quad[\text{кДж/кг сухого воздуха}]
{{< /formula >}}

Раздельные компоненты:
- Явная теплота сухого воздуха: {{< formula >}}h_a = c_{pa} \cdot t_{db} = 1{,}006\,t_{db}{{< /formula >}}
- Скрытая теплота пара: {{< formula >}}h_v = h_{fg,0} = 2501{{< /formula >}} кДж/кг (при 0 °C)
- Явная теплота пара: {{< formula >}}h_{pv} = c_{pv} \cdot t_{db} = 1{,}86\,t_{db}{{< /formula >}}

### Удельный объём v

{{< formula display="true" >}}
v = \frac{R_a \cdot T \cdot (1 + 1{,}6078 \cdot W)}{p} = \frac{0{,}287042\,(t_{db}+273{,}15)\,(1+1{,}6078 W)}{p}\quad[\text{м}^3/\text{кг}]
{{< /formula >}}

## Поправка на высоту над уровнем моря

Стандартное атмосферное давление уменьшается с высотой:

{{< formula display="true" >}}
p = 101{,}325\,\left(1 - 2{,}25577\times10^{-5}\,z\right)^{5{,}2559}\quad[\text{кПа},\; z\text{ в м}]
{{< /formula >}}

{{< table title="Стандартное давление и его влияние на психрометрические свойства" >}}
| Высота, м | p, кПа | W_s при 21 °C, г/кг | v при 21 °C/50%, м³/кг | Увеличение W_s |
|---|---|---|---|---|
| 0 | 101,325 | 15,73 | 0,832 | — |
| 500 | 95,47 | 16,78 | 0,883 | +6,7 % |
| 1000 | 89,88 | 17,94 | 0,938 | +14,1 % |
| 1500 | 84,55 | 19,22 | 0,997 | +22,2 % |
| 2000 | 79,50 | 20,67 | 1,060 | +31,4 % |
| 2500 | 74,70 | 22,33 | 1,128 | +41,9 % |
{{< /table >}}

### Влияние высоты на проектирование

1. **Производительность охлаждающей секции** остаётся неизменной в кВт, но объёмный расход воздуха возрастает пропорционально увеличению v.
2. **Коэффициент влажности насыщения** выше на больших высотах → скрытые нагрузки относительно выше при том же φ.
3. **Производительность вентиляторов:** при выборе необходимо применять поправочный коэффициент на плотность воздуха.

## Полный пример расчёта (уровень моря)

**Задание:** воздух t_db = 28 °C, φ = 65 %, p = 101,325 кПа. Определить все психрометрические свойства.

**Шаг 1. Давление насыщения:**

{{< formula display="true" >}}
p_{ws}(28°C) = 0{,}61094\,\exp\!\left(\frac{17{,}625 \times 28}{28+243{,}04}\right) = 0{,}61094\,\exp(1{,}820) = 3{,}782\;\text{кПа}
{{< /formula >}}

**Шаг 2. Давление пара:**

{{< formula display="true" >}}
p_v = 0{,}65 \times 3{,}782 = 2{,}458\;\text{кПа}
{{< /formula >}}

**Шаг 3. Коэффициент влажности:**

{{< formula display="true" >}}
W = \frac{0{,}6220 \times 2{,}458}{101{,}325 - 2{,}458} = \frac{1{,}529}{98{,}867} = 0{,}01547\;\text{кг/кг} = 15{,}47\;\text{г/кг}
{{< /formula >}}

**Шаг 4. Удельная энтальпия:**

{{< formula display="true" >}}
h = 1{,}006 \times 28 + 0{,}01547 \times (2501 + 1{,}86 \times 28) = 28{,}17 + 39{,}47 = \mathbf{67{,}6}\;\text{кДж/кг}
{{< /formula >}}

**Шаг 5. Удельный объём:**

{{< formula display="true" >}}
v = \frac{0{,}287042 \times 301{,}15 \times (1 + 1{,}6078 \times 0{,}01547)}{101{,}325} = \frac{88{,}33}{101{,}325} = \mathbf{0{,}872}\;\text{м}^3/\text{кг}
{{< /formula >}}

**Шаг 6. Температура точки росы:**

{{< formula display="true" >}}
t_{dp} = \frac{243{,}04 \times \ln(2{,}458/0{,}61094)}{17{,}625 - \ln(2{,}458/0{,}61094)} = \frac{243{,}04 \times 1{,}393}{17{,}625 - 1{,}393} = \mathbf{20{,}9}\;°\text{C}
{{< /formula >}}

**Шаг 7. Температура по влажному термометру** (итерация):

Начальное приближение t_wb = 22 °C:
- {{< formula >}}W_s(22°C) = 0{,}622 \times 2{,}645/(101{,}325-2{,}645) = 16{,}68{{< /formula >}} г/кг
- {{< formula >}}W_{\text{calc}} = 16{,}68 - 6{,}6\times10^{-4} \times 1000 \times (28-22) = 16{,}68 - 3{,}96 = 12{,}72{{< /formula >}} г/кг ≠ 15,47 г/кг

Уточнение: t_wb ≈ 23,4 °C (после 2–3 итераций). **Итог: t_wb ≈ 23,4 °C.**

|---|---|---|
| Температура по сухому термометру | 28,0 | °C |
| Температура по влажному термометру | 23,4 | °C |

## Пример расчёта охлаждающей секции

**Задание:** охлаждающая секция принимает воздух при t_db1 = 28 °C, φ1 = 65 %, расход {{< formula >}}\dot{V} = 10 000{{< /formula >}} м³/ч. Выходные условия: t_db2 = 13 °C, φ2 = 92 %. Определить тепловую нагрузку.

**Входные условия:** h1 = 67,6 кДж/кг, W1 = 15,47 г/кг (из предыдущего примера), v1 = 0,872 м³/кг.

**Массовый расход сухого воздуха:**

{{< formula display="true" >}}
\dot{m}_a = \frac{\dot{V}}{v_1} = \frac{10\,000/3600}{0{,}872} = 3{,}18\;\text{кг/с}
{{< /formula >}}

**Выходные условия:**
- {{< formula >}}p_{ws}(13°C) = 1{,}498{{< /formula >}} кПа
- {{< formula >}}p_v = 0{,}92 \times 1{,}498 = 1{,}378{{< /formula >}} кПа
- {{< formula >}}W_2 = 0{,}6220 \times 1{,}378 / (101{,}325 - 1{,}378) = 8{,}58{{< /formula >}} г/кг
- {{< formula >}}h_2 = 1{,}006 \times 13 + 0{,}00858 \times (2501+1{,}86\times13) = 13{,}08 + 21{,}79 = 34{,}87{{< /formula >}} кДж/кг

**Общая мощность охлаждения:**

{{< formula display="true" >}}
Q_{\text{total}} = \dot{m}_a \cdot (h_1 - h_2) = 3{,}18 \times (67{,}6 - 34{,}87) = 3{,}18 \times 32{,}73 = \mathbf{104\;\text{кВт}}
{{< /formula >}}

**Разбивка по компонентам:**

{{< formula display="true" >}}
Q_s = \dot{m}_a \cdot c_{pa} \cdot (t_{db,1} - t_{db,2}) = 3{,}18 \times 1{,}006 \times 15 = \mathbf{48{,}0\;\text{кВт}}
{{< /formula >}}

{{< formula display="true" >}}
Q_l = Q_{\text{total}} - Q_s = 104 - 48 = \mathbf{56\;\text{кВт}}
{{< /formula >}}

{{< formula display="true" >}}
\text{SHR} = \frac{Q_s}{Q_{\text{total}}} = \frac{48}{104} = 0{,}46
{{< /formula >}}

Количество конденсата:

{{< formula display="true" >}}
\dot{m}_{\text{конд}} = 3{,}18 \times (0{,}01547 - 0{,}00858) = 0{,}0219\;\text{кг/с} = \mathbf{78{,}8\;\text{кг/ч}}
{{< /formula >}}
