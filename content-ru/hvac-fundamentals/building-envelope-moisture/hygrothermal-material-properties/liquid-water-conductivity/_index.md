## Общие положения

Проводимость жидкой воды (liquid water conductivity, {{< formula >}}K_l{{< /formula >}}) количественно описывает скорость переноса жидкой влаги через пористый строительный материал под действием градиента капиллярного давления. Этот параметр определяет поведение конструкции при:

- проникновении атмосферных осадков через наружную облицовку;
- капиллярном подсосе влаги из грунта через фундамент;
- перераспределении конденсата внутри многослойной ограждающей конструкции.

В отличие от паропроницаемости, проводимость жидкой воды имеет значение при высоком влагосодержании материала — когда капиллярные пути в порах становятся непрерывными. При низком влагосодержании доминирует диффузия пара. Оба механизма учитываются совместно при гигротермальном моделировании по ASHRAE Fundamentals, гл. 26.

## Физика капиллярного переноса

### Уравнение переноса

Перенос жидкой воды в ненасыщенных пористых материалах описывается обобщённым законом Дарси:

{{< formula display="true" >}}
g_w = -K_l(w)\,\nabla p_c
{{< /formula >}}

где:
- {{< formula >}}g_w{{< /formula >}} — плотность потока жидкой воды, кг/(м²·с);
- {{< formula >}}K_l(w){{< /formula >}} — проводимость жидкой воды как функция влагосодержания, кг/(м·с·Па);
- {{< formula >}}\nabla p_c{{< /formula >}} — градиент капиллярного давления (давления всасывания), Па/м.

Знак «минус» указывает, что поток направлен из области высокого давления (влажной) в область низкого давления (сухой).

### Режимы жидкостного переноса

**Маятниковый режим (pendular regime).** При низком влагосодержании жидкость сосредоточена в точках контакта частиц в виде изолированных мениски. Непрерывных жидких путей нет — транспорт жидкостью пренебрежимо мал, доминирует диффузия пара.

**Фуникулярный режим (funicular regime).** С ростом влагосодержания жидкость образует непрерывные нити через поровые перехваты. {{< formula >}}K_l{{< /formula >}} резко возрастает. Это основной режим для большинства влагопереноса в строительных материалах.

**Капиллярно-насыщенный режим.** При влагосодержании, близком к насыщению, практически все поры заполнены. {{< formula >}}K_l{{< /formula >}} достигает максимума, определяемого связностью поровой сети.

## Математическое описание

### Степенной закон

Зависимость {{< formula >}}K_l{{< /formula >}} от влагосодержания аппроксимируется степенной функцией:

{{< formula display="true" >}}
K_l(w) = K_\text{sat}\left(\frac{w}{w_\text{sat}}\right)^n
{{< /formula >}}

где:
- {{< formula >}}K_\text{sat}{{< /formula >}} — проводимость при полном насыщении, кг/(м·с·Па);
- {{< formula >}}w{{< /formula >}} — объёмное влагосодержание, кг/м³;
- {{< formula >}}w_\text{sat}{{< /formula >}} — влагосодержание при насыщении, кг/м³;
- {{< formula >}}n{{< /formula >}} — эмпирический показатель (обычно 3–15).

При малом {{< formula >}}w{{< /formula >}} {{< formula >}}K_l \to 0{{< /formula >}}; при {{< formula >}}w \to w_\text{sat}{{< /formula >}} {{< formula >}}K_l \to K_\text{sat}{{< /formula >}}.

### Зависимость от капиллярного давления

Альтернативная форма через капиллярное давление:

{{< formula display="true" >}}
K_l(p_c) = K_\text{sat}\left(\frac{p_{c,\text{entry}}}{p_c}\right)^m
{{< /formula >}}

где {{< formula >}}p_{c,\text{entry}}{{< /formula >}} — давление входа воздуха (air entry pressure), Па; {{< formula >}}m{{< /formula >}} — параметр распределения размеров пор. Эта форма напрямую связывает {{< formula >}}K_l{{< /formula >}} с кривой удержания влаги (water retention curve).

### Формулировка WUFI

В программе WUFI Pro коэффициент жидкостного транспорта {{< formula >}}D_w{{< /formula >}} (м²/с) задаётся через влагосодержание:

{{< formula display="true" >}}
D_w(w) = D_{ww}\,\exp\!\left[n\,\frac{w - w_{80}}{w_\text{cap} - w_{80}}\right]
{{< /formula >}}

где {{< formula >}}w_{80}{{< /formula >}} — влагосодержание при 80 % отн. вл.; {{< formula >}}w_\text{cap}{{< /formula >}} — влагосодержание при капиллярном насыщении; {{< formula >}}D_{ww}{{< /formula >}} — коэффициент при насыщении. Связь между {{< formula >}}D_w{{< /formula >}} и {{< formula >}}K_l{{< /formula >}}:

{{< formula display="true" >}}
D_w = K_l\,\frac{\mathrm{d}p_c}{\mathrm{d}w}
{{< /formula >}}

## Методы измерения

**Капиллярный эксперимент (EN ISO 15148).** Образец насыщается снизу, профиль влаги регистрируется гамма-абсорбциометрией или ЯМР-томографией (NMR). {{< formula >}}D_w{{< /formula >}} определяется из переходного перераспределения влаги методом обратной задачи.

**Метод давления (pressure plate / centrifuge).** Объём вытекающей воды при ступенчатом приложении давления позволяет измерить {{< formula >}}K_l{{< /formula >}} при различных {{< formula >}}p_c{{< /formula >}}.

**Метод мгновенного профиля (instantaneous profile method).** Образец с начальным градиентом влажности изолируется, внутренние профили измеряются TDR-датчиками или гамма-лучами в процессе перераспределения.

**Обратный анализ (inverse analysis).** По результатам гигротермальных испытаний стеновых сборок параметры {{< formula >}}K_l(w){{< /formula >}} определяются калибровкой модели (WUFI, DELPHIN) на экспериментальных данных.

## Численный пример: капиллярный подсос в кирпичной стене

**Условие.** Кирпичная кладка (рядовой кирпич) толщиной 380 мм стоит на грунте. Нижняя грань постоянно в контакте с водой ({{< formula >}}w = w_\text{sat} = 260{{< /formula >}} кг/м³). На высоте 380 мм материал в равновесии с 60 % отн. вл. ({{< formula >}}w_{60} = 8{{< /formula >}} кг/м³). Оценить установившийся поток жидкой воды вверх по кладке.

**Данные.** {{< formula >}}K_\text{sat} = 2{,}0\times10^{-11}{{< /formula >}} кг/(м·с·Па); {{< formula >}}n = 5{{< /formula >}}; {{< formula >}}w_\text{sat} = 260{{< /formula >}} кг/м³.

**Среднее влагосодержание** вдоль пути:

{{< formula display="true" >}}
\bar{w} = \frac{w_\text{sat} + w_{60}}{2} = \frac{260 + 8}{2} = 134\;\text{кг/м}^3
{{< /formula >}}

**Средняя проводимость:**

{{< formula display="true" >}}
\bar{K}_l = K_\text{sat}\left(\frac{\bar{w}}{w_\text{sat}}\right)^n = 2{,}0\times10^{-11}\times\left(\frac{134}{260}\right)^5
{{< /formula >}}

{{< formula display="true" >}}
\bar{K}_l = 2{,}0\times10^{-11}\times(0{,}515)^5 = 2{,}0\times10^{-11}\times 0{,}037 = 7{,}4\times10^{-13}\;\text{кг/(м·с·Па)}
{{< /formula >}}

**Капиллярное давление** (уравнение Лапласа для пор радиуса {{< formula >}}r = 10^{-6}{{< /formula >}} м, {{< formula >}}\sigma = 0{,}0728{{< /formula >}} Н/м):

{{< formula display="true" >}}
\Delta p_c = \frac{2\sigma}{r} = \frac{2\times0{,}0728}{10^{-6}} = 145\,600\;\text{Па}
{{< /formula >}}

**Градиент капиллярного давления:**

{{< formula display="true" >}}
\nabla p_c = \frac{\Delta p_c}{L} = \frac{145\,600}{0{,}38} = 383\,000\;\text{Па/м}
{{< /formula >}}

**Поток жидкой воды:**

{{< formula display="true" >}}
g_w = \bar{K}_l\times\nabla p_c = 7{,}4\times10^{-13}\times 383\,000 \approx 2{,}8\times10^{-7}\;\text{кг/(м}^2\text{·с)} \approx 24\;\text{г/(м}^2\text{·сутки)}
{{< /formula >}}

**Вывод.** Суточный капиллярный подсос 24 г/м² через необработанную кирпичную кладку при постоянном контакте с грунтовой влагой — величина, сопоставимая с суточным потоком водяного пара в большинстве климатических условий. Это подчёркивает необходимость гидрофобизации цокольной части или устройства капиллярного разрыва.

## Температурная зависимость

Проводимость жидкой воды возрастает с температурой вследствие снижения динамической вязкости:

{{< formula display="true" >}}
K_l(T) = K_{l,\text{ref}}\,\frac{\mu(T_\text{ref})}{\mu(T)}
{{< /formula >}}

Вязкость воды: при 0 °C — 1,79 мПа·с, при 20 °C — 1,00 мПа·с, при 40 °C — 0,65 мПа·с. Следовательно, при изменении температуры от 0 °C до 40 °C {{< formula >}}K_l{{< /formula >}} возрастает в 2,7 раза. Этот эффект значим при сезонном анализе.

## Гистерезис проводимости

{{< formula >}}K_l{{< /formula >}} проявляет гистерезис между процессами смачивания и высыхания. При смачивании сначала заполняются крупные поры, формируя пути транспорта. При высыхании вода отступает из крупных пор, сохраняя непрерывность в мелких — кажущаяся проводимость при сушке в 2–5 раз выше, чем при смачивании при одном и том же {{< formula >}}w{{< /formula >}}. Большинство гигротермальных моделей используют единую усреднённую кривую.

## Анизотропия в древесине

Древесина и материалы на её основе характеризуются сильной анизотропией:

{{< formula display="true" >}}
\frac{K_{l,\text{вдоль волокон}}}{K_{l,\text{поперёк волокон}}} \approx 10{-}100
{{< /formula >}}

Это следствие клеточного строения: в продольном направлении сосуды образуют непрерывные каналы, а в поперечном — связность обеспечивается только через поровые мембраны. При гигротермальном моделировании деревянных конструкций необходимо задавать тензор проводимости.

## Проектные следствия

### Анализ проникновения атмосферных осадков

{{< formula >}}K_l{{< /formula >}} определяет скорость перераспределения влаги, проникшей через наружную облицовку. Материалы с высокой {{< formula >}}K_l{{< /formula >}} допускают быстрое распространение влаги вглубь конструкции; материалы с низкой {{< formula >}}K_l{{< /formula >}} задерживают влагу локально.

### Проектирование капиллярных разрывов

Эффективный капиллярный разрыв требует, чтобы {{< formula >}}K_l{{< /formula >}} прерывающего слоя была на 2–3 порядка величины ниже {{< formula >}}K_l{{< /formula >}} соседних материалов. Это препятствует миграции влаги из фундамента или через непрерывные материальные мостики (thermal bridges с влажностным мостиком).

### Потенциал высыхания

Даже один слой с очень низкой {{< formula >}}K_l{{< /formula >}} может действовать как влаголовушка: жидкая влага не достигает испарительной поверхности несмотря на достаточную паропроницаемость соседних слоёв. Анализ высыхания требует совместного учёта обоих механизмов.

### Критическое влагосодержание

Порог, при превышении которого {{< formula >}}K_l{{< /formula >}} становится существенной, соответствует приблизительно 70–80 % от равновесного при 95–100 % отн. вл. Конструкции должны обеспечивать, чтобы влагосодержание оставалось ниже этого порога при нормальных условиях эксплуатации.

## Требования к данным для гигротермального моделирования

При подготовке параметров {{< formula >}}K_l(w){{< /formula >}} для WUFI или DELPHIN необходимо выполнить следующие проверки:

1. {{< formula >}}K_l \to 0{{< /formula >}} при {{< formula >}}w \leq w_{80}{{< /formula >}} (влагосодержание в равновесии с 80 % отн. вл.).
2. {{< formula >}}K_l(w_\text{sat}){{< /formula >}} согласуется с измеренной водопроницаемостью материала.
3. Форма кривой {{< formula >}}K_l(w){{< /formula >}} согласована с кривой удержания влаги — несогласованность приводит к нефизическим результатам (накопление или исчезновение влаги в узле).
4. Результаты моделирования сопоставлены с лабораторными или полевыми данными.

## Взаимодействие со смежными свойствами

{{< formula >}}K_l{{< /formula >}} неотделима от других гигротермальных свойств:

- **Паропроницаемость** — при промежуточных влагосодержаниях оба механизма (жидкостный и паровой) вносят сопоставимый вклад.
- **Ёмкость хранения влаги** — более высокая ёмкость сглаживает изменения {{< formula >}}w{{< /formula >}} и градиентов {{< formula >}}p_c{{< /formula >}}.
- **Теплопроводность** — перераспределение влаги меняет температурное поле, которое в свою очередь влияет на транспорт влаги (испарение–конденсация внутри слоёв).
- **Воздухопроницаемость** — инфильтрационный воздух может переносить капли и откладывать конденсат, который затем перераспределяется капиллярным механизмом.

Корректный гигротермальный анализ требует совместного решения связанных уравнений переноса тепла, воздуха и влаги с согласованными свойствами для каждого слоя.

## Нормативная база

- **ASHRAE Fundamentals, глава 26** — теория и справочные данные по переносу влаги в строительных материалах.
- **EN ISO 15148** — определение коэффициента водопоглощения при капиллярном подсосе.
- **ISO 12572** — паропроницаемость (чашечный метод); дополняет данные по жидкостному транспорту.
- **ASTM C1794** — коэффициент водопоглощения при частичном погружении.
- **СП 50.13330.2017** — тепловая защита зданий (нормируемые требования к ограждающим конструкциям).
- **СП 23-101-2004** — проектирование тепловой защиты зданий (расчётные методы).
