Температура влажного термометра (wet-bulb temperature, t_wb) и температура точки росы (dew-point temperature, t_dp) — два фундаментальных психрометрических параметра, оба связанные с содержанием влаги в воздухе, но имеющие принципиально разную физическую природу. Их правильное понимание и применение критически важно для HVAC-инженерии: выбора метода управления влажностью, расчёта испарительного охлаждения, оценки теплового комфорта и предотвращения конденсации.

## Физические определения

### Температура влажного термометра

t_wb — равновесная температура поверхности воды, испаряющейся в движущийся воздух при адиабатических условиях. Это температура, которую устанавливает смоченная поверхность при балансе конвективного притока тепла от воздуха и потока скрытого тепла испарения:

{{< formula display="true" >}}
h_c (t_{db} - t_{wb}) = h_m \cdot \rho \cdot h_{fg}(t_{wb}) \cdot (W_s(t_{wb}) - W)
{{< /formula >}}

Это также температура адиабатического насыщения: предельная температура, до которой может охладиться воздух при испарительном увлажнении без внешнего теплообмена.

### Температура точки росы

t_dp — температура, при которой водяной пар в воздухе достигает давления насыщения при постоянных давлении и влагосодержании. Иными словами, температура начала конденсации:

{{< formula display="true" >}}
p_{ws}(t_{dp}) = p_v = \varphi \cdot p_{ws}(t_{db})
{{< /formula >}}

t_dp зависит **исключительно** от абсолютного содержания влаги (p_v или W), не завися от температуры по сухому термометру.

## Математические соотношения

### Вычисление t_wb из t_db и W

Психрометрическая формула (для аспирационного психрометра):

{{< formula display="true" >}}
W = W_s(t_{wb}) - 6{,}6 \times 10^{-4} \cdot (t_{db} - t_{wb})
{{< /formula >}}

Итерационное решение (начальное приближение t_wb = t_dp + (t_db − t_dp)/3):

{{< formula display="true" >}}
t_{wb,n+1} = t_{wb,n} - \frac{W_s(t_{wb,n}) - W - 6{,}6\times10^{-4}(t_{db}-t_{wb,n})}{W_s'(t_{wb,n}) + 6{,}6\times10^{-4}}
{{< /formula >}}

Сходимость достигается за 3–5 итераций.

### Вычисление t_dp из W и p

{{< formula display="true" >}}
p_v = \frac{W \cdot p}{0{,}6220 + W},\quad t_{dp} = \frac{243{,}04 \cdot \ln(p_v/0{,}611)}{17{,}625 - \ln(p_v/0{,}611)}
{{< /formula >}}

### Неравенство

{{< formula display="true" >}}
t_{dp} \leq t_{wb} \leq t_{db}
{{< /formula >}}

Равенство t_dp = t_wb = t_db достигается при φ = 100 % (точка насыщения).

## Сравнительный анализ

{{< table title="Сравнение температуры влажного термометра и точки росы" >}}
| Характеристика | t_wb | t_dp |
|---|---|---|
| Физическая природа | Равновесие тепло/массообмен | Температура начала конденсации |
| Зависит от t_db | Да (при φ < 100 %) | Нет |
| Зависит от W | Да | Да (только от W) |
| Прямое измерение | Смоченный термометр | Охлаждаемое зеркало |
| Изменяется при нагреве без добавления влаги | Да (растёт вместе с t_db) | Нет (остаётся const) |
| Применение | Испарит. охлаждение, адиабатика | Конденсация, абсолютная влажность |
| Комфорт-метрика | WBGT (тепловой стресс) | Абсолютный предел по влажности |
{{< /table >}}

### Числовой пример: различие при нагреве воздуха

**Воздух A:** t_db = 20 °C, φ = 50 %
- W = 7,25 г/кг; t_dp = 9,3 °C; t_wb ≈ 14,0 °C

**Нагреть воздух A до 30 °C без добавления влаги:**

- W = 7,25 г/кг (неизменно)
- t_dp = **9,3 °C** (неизменно — зависит только от W)
- t_wb ≈ **18,3 °C** (изменилась — следует за нагревом)
- φ = 7,25 × 101,325 / (4,246 × 634) = **27,2 %** (снизилась)

Вывод: нагревание изменяет t_wb и φ, но не изменяет t_dp.

## Применение в HVAC-инженерии

### Испарительное охлаждение: t_wb как предел

Предел прямого испарительного охлаждения:

{{< formula display="true" >}}
t_{db,\min} = t_{wb}
{{< /formula >}}

Потенциал охлаждения:

{{< formula display="true" >}}
\Delta t_{\max} = t_{db} - t_{wb}
{{< /formula >}}

Это позволяет быстро оценить целесообразность испарительного охлаждения по известным t_db и t_wb без полного психрометрического расчёта.

### Конденсация: t_dp как критерий

Конденсация на поверхности начинается при:

{{< formula display="true" >}}
T_{\text{surface}} < t_{dp}
{{< /formula >}}

Управление системами кондиционирования по t_dp обеспечивает предотвращение конденсации в воздуховодах, на потолочных балках, холодных трубопроводах.

### Управление влажностью: t_dp vs φ

Управление по постоянной φ невозможно реализовать инвариантно относительно температуры — при изменении t_db соответствующий абсолютный уровень влажности меняется. Управление по постоянной t_dp (или W) обеспечивает постоянное абсолютное влагосодержание независимо от температуры.

{{< table title="Сравнение стратегий управления влажностью" >}}
| Стратегия | Уставка | Преимущества | Недостатки |
|---|---|---|---|
| По ОВ | φ = const | Интуитивно понятна | Влагосодержание меняется с T |
| По точке росы | t_dp = const | Постоянное W, предотвращает конденсацию | Сложнее измерить |
| По W (коэффициент влажности) | W = const | Точная физическая мера | Требует расчёта |
| По t_wb | t_wb = const | Применимо для испарит. охлаждения | Зависит от t_db |
{{< /table >}}

### ASHRAE 55: ограничения по t_dp

Стандарт ASHRAE 55-2023 устанавливает ограничения на влажность через точку росы:

- Верхний предел: **t_dp ≤ 17 °C** (предотвращение теплового дискомфорта при высокой влажности)
- Нижний предел: **не задан строгим образом**, рекомендован диапазон для предотвращения сухости слизистых

Примечательно, что ASHRAE 55-2023 отказался от нижнего предела по ОВ (ранее 30 %) в пользу более гибкого подхода, признавая, что сухость воздуха при низкой t_dp вызывает дискомфорт в зависимости от индивидуальных особенностей.

## Тепловой комфорт и стресс

### WBGT (Wet Bulb Globe Temperature)

Индекс WBGT использует t_wb как один из компонентов:

{{< formula display="true" >}}
\text{WBGT}_{\text{наружный}} = 0{,}7 \cdot t_{wb} + 0{,}2 \cdot t_g + 0{,}1 \cdot t_{db}
{{< /formula >}}

{{< formula display="true" >}}
\text{WBGT}_{\text{внутренний}} = 0{,}7 \cdot t_{wb} + 0{,}3 \cdot t_g
{{< /formula >}}

где t_g — температура шарового термометра (учитывает лучистый теплообмен).

WBGT > 28 °C — риск теплового стресса; WBGT > 35 °C — смертельная опасность при физической работе.

### Точка росы и дискомфорт

{{< table title="Субъективное восприятие влажности в зависимости от t_dp" >}}
| t_dp, °C | Субъективная оценка |
|---|---|
| < 2 | Очень сухо, пересушивание слизистых |
| 2–10 | Комфортно-сухой |
| 10–13 | Комфортный диапазон ASHRAE 55 |
| 13–17 | Приемлемо влажно (верхняя граница ASHRAE 55) |
| 17–21 | Ощущается влажность, дискомфорт при активности |
| > 21 | Значительный дискомфорт, нарушение терморегуляции |
{{< /table >}}

## Измерение: практические аспекты

### Аспирационный психрометр (t_wb)

Аспирационный психрометр Асмана обеспечивает прямое измерение t_wb:
- Погрешность t_wb: ±0,2–0,3 °C при правильной эксплуатации
- Минимальная скорость аспирации: 3,5 м/с
- Требует чистого фитиля и дистиллированной воды

Вычисление t_dp из измеренных t_db и t_wb (через W):

{{< formula display="true" >}}
W = W_s(t_{wb}) - 6{,}6 \times 10^{-4}(t_{db} - t_{wb})
{{< /formula >}}

{{< formula display="true" >}}
p_v = W \cdot p / (0{,}622 + W) \Rightarrow t_{dp}
{{< /formula >}}

Погрешность t_dp при этом расчёте: ±0,5–1,0 °C.

### Гигрометр с охлаждаемым зеркалом (t_dp)

Обеспечивает прямое измерение t_dp с погрешностью ±0,1–0,2 °C. Является первичным эталоном. Не требует вычислений для получения t_dp.

Вычисление t_wb из t_dp (обратная задача) требует итерации и знания t_db.

### Ёмкостный датчик ОВ

Измеряет φ, из которой вычисляются t_dp и W:
- Погрешность t_dp, вычисленной из φ: ±1–3 °C (зависит от погрешности датчика)
- Требует периодической калибровки
