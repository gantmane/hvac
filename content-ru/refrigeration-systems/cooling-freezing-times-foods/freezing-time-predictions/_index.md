## Обзор

Прогнозирование времени замораживания является критическим параметром для проектирования холодильных систем, технологического планирования и обеспечения качества пищевых продуктов. Процесс замораживания включает три этапа: охлаждение продукта от начальной температуры до точки образования кристаллов льда, формирование ледяной корки (процесс максимального отвода скрытого тепла) и окончательное охлаждение замёрзшего продукта до требуемой температуры хранения (обычно −18…−20 °C).

Точное определение времени замораживания необходимо для выбора холодопроизводительности, типа морозильного оборудования (туннели, плиты, скоростные морозильники), расчёта производительности и оптимизации технологических процессов в пищевой промышленности. В практике холодильной техники используется набор эмпирических и полуэмпирических моделей, предложенных с 1920-х годов и уточняемых по мере накопления экспериментальных данных.

## Физические основы процесса замораживания

Теплопередача при замораживании определяется нестационарным процессом тепловыделения в ходе фазового перехода. Скорость замораживания лимитирована:

- **конвективной теплопередачей** на поверхности (коэффициент $h$, Вт/(м²·К));
- **теплопроводностью** материала продукта ($\lambda$, Вт/(м·К));
- **скрытой теплотой плавления** ($L$, кДж/кг), составляющей основную энергию, которую необходимо отвести.

Общее количество тепла, подлежащее отводу:

$$Q_{\text{общ}} = m \left[ c_p (T_0 - T_f) + L + c_f (T_f - T_c) \right]$$

где:
- $m$ — масса продукта, кг;
- $c_p$ — теплоёмкость продукта выше точки замерзания (≈ 3,5–3,8 кДж/(кг·К) для большинства продуктов);
- $T_0$ — начальная температура продукта, °C;
- $T_f$ — температура замерзания, °C (для большинства пищевых продуктов −1…−3 °C);
- $T_c$ — конечная температура, °C (−18…−20 °C);
- $c_f$ — теплоёмкость замёрзшего продукта (1,7–2,5 кДж/(кг·К));
- $L$ — скрытая теплота замораживания (≈ 250–280 кДж/кг).

## Классические модели расчёта времени замораживания

### Уравнение Планка (1921)

Простейшая полуэмпирическая модель:

$$t = \frac{\rho L}{h(T_0 - T_c)} \left[ \frac{P}{2} + \frac{R}{8} \right]$$

где:
- $\rho$ — плотность продукта, кг/м³;
- $P$ — полутолщина плиты или характерный размер, м;
- $R$ — коэффициент формы Бета (для пластины $R = 1$; для цилиндра $R = 2$; для сферы $R = 3$).

Уравнение Планка даёт приемлемую точность (±15 %) для изотермических граничных условий, но переоценивает время для небольших объектов и при интенсивной конвекции.

### Модифицированное уравнение Планка

Для учёта предварительного охлаждения введено поправочное слагаемое на явное тепло:

$$t = \frac{\rho}{h(T_0 - T_c)} \left[ P \cdot c_p(T_0 - T_f) + \frac{P}{2} L + \frac{R}{8} c_f(T_f - T_c) \right]$$

Эта форма более точно описывает реальные процессы при учёте конечной скорости охлаждения на предзамораживающем этапе.

### Модель Фэма (Клельген, 1981)

Двухпараметрическая модель, основанная на числах Фурье и Стефана:

$$t = \frac{\rho P^2}{k_{\text{eff}}} \left[ \frac{P}{2} + \text{Ste}^{-1} \right]$$

где $\text{Ste} = \frac{c_p(T_0 - T_f)}{L}$ — число Стефана (обычно 0,1–0,2 для продуктов).

Данный подход удобен для компьютерного моделирования и хорошо согласуется с экспериментальными данными при $\text{Ste} > 0,05$.

### Уравнения Кленда–Эрла

Трёхпараметрическая модель, аппроксимирующая аналитическое решение:

$$t = \frac{\rho P^2}{k} \left[ a + b \cdot \text{Fo} \right]$$

где:
- $\text{Fo} = \frac{k t}{\rho c_p P^2}$ — число Фурье;
- коэффициенты $a$, $b$ подбираются на основе экспериментальных данных для конкретных групп продуктов (мясо, рыба, овощи, фрукты).

Типичные значения: $a = 0,26$, $b = 0,20$ для говядины; $a = 0,28$, $b = 0,19$ для рыбы.

## Геометрические корректирующие коэффициенты

### Коэффициент формы (Бета)

| Форма продукта | Коэффициент $R$ | Характеристический размер |
|---|---|---|
| Бесконечная пластина | 1 | Полутолщина $P$ |
| Бесконечный цилиндр | 2 | Радиус $a$ |
| Шар | 3 | Радиус $a$ |
| Прямоугольный параллелепипед | 3–4 | Средний из полулиц |

### Эквивалентный диаметр сферы

Для нерегулярных форм используется преобразование в эквивалентную сферу:

$$d_{\text{экв}} = 2 \left( \frac{3V}{4\pi} \right)^{1/3}$$

где $V$ — объём продукта, м³.

### Эффективная толщина плиты

Для перевода всех форм к стандартной плите-шаблону:

$$P_{\text{eff}} = \frac{V}{A}$$

где $V$ — объём, м³; $A$ — площадь поверхности, м².

## Практические методики расчёта

### Метод Ханга–Томпсона

Используется при отсутствии точных сведений о теплофизических свойствах:

$$t[\text{ч}] = 0,30 \cdot P[\text{см}]^2 \quad \text{(для } h = 25 \text{ Вт/(м}^2\text{·К))}$$
$$t[\text{ч}] = 0,15 \cdot P[\text{см}]^2 \quad \text{(для } h = 50 \text{ Вт/(м}^2\text{·К))}$$

### Поправка на явное тепло предварительного охлаждения

$$\Delta t_{\text{пред}} = \frac{\rho P c_p (T_0 - T_f)}{h(T_0 - T_c)}$$

### Поправка на явное тепло темперирования

После снятия с морозильной установки продукт может прогреваться. Дополнительное время для охлаждения с $T_f$ до $T_c$ в шоковой заморозке (−40…−50 °C):

$$\Delta t_{\text{темп}} = \frac{\rho P c_f (T_f - T_c)}{h(T_{\text{шок}} - T_c)}$$

### Общее время замораживания

$$t_{\text{total}} = t_{\text{основное}} + \Delta t_{\text{пред}} + \Delta t_{\text{темп}}$$

Для обычной морозилки (−20 °C) поправки обычно составляют 15–25 % от основного времени.

## Применение в холодильных системах

**Туннельные морозильники** (конвекционные, жидкостные): $h = 20$–50 Вт/(м²·К), время замораживания говядины толщиной 5 см — 4–8 часов.

**Плиточные морозильники** (контактные): $h = 100$–300 Вт/(м²·К), то же самое — 1–2 часа.

**Спирально-ленточные установки**: $h = 30$–80 Вт/(м²·К), зависит от скорости воздуха 2–5 м/с.

Выбор конструкции определяется требуемой производительностью, качеством конечного продукта (минимизация потерь влаги и окисления) и инвестиционными затратами.

- **EN 13089:2011** — морозильные шкафы, энергоэффективность и методы испытаний.
- **ГОСТ Р 51121–97** — мороженое. Общие технические условия (содержит требования к режимам заморозки).
- **СП 60.13330.2020** (переизд. СНиП II-Л.5–75): проектирование холодильных предприятий.

## Практические рекомендации

1. **Уточнение геометрии**: используйте эквивалентный диаметр при работе с продуктами неправильной формы.
2. **Выбор коэффициента конвекции**: для воздуха при 5 м/с — $h ≈ 30$ Вт/(м²·К); для жидкого азота — $h ≈ 1000$ Вт/(м²·К).
3. **Допуск на производство**: добавьте 10–20 % к расчётному времени для гарантии полной заморозки.
4. **Валидация**: сравните расчёты с экспериментальными данными производителя оборудования для конкретной группы продуктов.
5. **Мониторинг**: используйте датчики температуры в геометрическом центре продукта для верификации фактического времени замораживания.
