Три закона сохранения — масса, импульс, энергия — образуют полную математическую систему для описания движения жидкости. Понимание их физического смысла и области применимости важнее, чем механическая подстановка в формулы.

## Сохранение массы: уравнение непрерывности

### Общая форма (дифференциальная)

{{< formula display="true" >}}
\frac{\partial\rho}{\partial t} + \nabla\cdot(\rho\vec{V}) = 0
{{< /formula >}}

### Несжимаемый стационарный поток

Для воды и воздуха при M < 0,3 плотность можно считать постоянной, тогда:

{{< formula display="true" >}}
\nabla\cdot\vec{V} = 0 \quad\Longrightarrow\quad A_1 V_1 = A_2 V_2 = Q
{{< /formula >}}

**Физический смысл:** то, что входит, должно выйти. Этим пользуются при расчёте скоростей в переходах трубопровода:

{{< formula display="true" >}}
V_2 = V_1\frac{A_1}{A_2} = V_1\left(\frac{D_1}{D_2}\right)^{\!2}
{{< /formula >}}

**Числовой пример.** Магистраль DN100 (D₁ = 0,1 м) разветвляется на три ветви DN65 (D₂ = 0,065 м). Скорость в магистрали V₁ = 2 м/с. Расход: Q₁ = π·0,1²/4 · 2 = 0,01571 м³/с. Если в каждую ветвь уходит Q₂ = Q₁/3 = 0,00524 м³/с, то скорость V₂ = 0,00524/(π·0,065²/4) = 1,58 м/с — корректная скорость для ответвлений.

### Уравнение непрерывности для сжимаемого потока (воздух при высоких скоростях)

При M > 0,3 необходимо учитывать изменение плотности:

{{< formula display="true" >}}
\rho_1 A_1 V_1 = \rho_2 A_2 V_2 = \dot{m} = \text{const}
{{< /formula >}}

Массовый расход постоянен, объёмный — нет.

## Сохранение импульса: уравнения Навье–Стокса

### Общая форма

{{< formula display="true" >}}
\rho\frac{D\vec{V}}{Dt} = -\nabla P + \mu\nabla^2\vec{V} + \rho\vec{g}
{{< /formula >}}

где материальная производная {{< formula >}}D/Dt = \partial/\partial t + (\vec{V}\cdot\nabla){{< /formula >}} учитывает как локальное (нестационарное), так и конвективное ускорение.

### Практическое применение: силы на изгиб трубы

Уравнение импульса в интегральной форме позволяет найти реакцию опоры на изгиб трубопровода:

{{< formula display="true" >}}
\vec{F} + P_1 A_1\hat{n}_1 + P_2 A_2\hat{n}_2 = \dot{m}(\vec{V}_2 - \vec{V}_1)
{{< /formula >}}

**Пример — колено 90° DN100:** скорость V = 2 м/с, P₁ = P₂ = 200 кПа изб., ṁ = 998·π·0,1²/4·2 = 15,68 кг/с.

Сила реакции в направлениях x и y:

{{< formula display="true" >}}
F_x = \dot{m}(-V) - P_1 A_1 = 15{,}68\times(-2) - 200\,000\times\pi\times0{,}01/4 = -31{,}4 - 1571 = -1602\text{ Н}
{{< /formula >}}

{{< formula display="true" >}}
F_y = \dot{m}\,V - P_2 A_2 = +1602\text{ Н}
{{< /formula >}}

Результирующая ≈ 2265 Н. Опора должна выдерживать эту нагрузку; при гидравлическом ударе сила возрастает в разы.

## Сохранение энергии: уравнение Бернулли

### Вывод из первого закона термодинамики

Для стационарного несжимаемого потока вязкой жидкости вдоль линии тока:

{{< formula display="true" >}}
\frac{P_1}{\rho g} + \frac{V_1^2}{2g} + z_1 = \frac{P_2}{\rho g} + \frac{V_2^2}{2g} + z_2 + h_L
{{< /formula >}}

Три слагаемых в каждой части — напоры давления, скоростной и геодезический. Потеря напора {{< formula >}}h_L{{< /formula >}} необратимо рассеивается в тепло за счёт вязкого трения и турбулентности.

### Расширенное уравнение Бернулли с насосом

{{< formula display="true" >}}
\frac{P_1}{\rho g} + \frac{V_1^2}{2g} + z_1 + H_\text{нас} = \frac{P_2}{\rho g} + \frac{V_2^2}{2g} + z_2 + h_L
{{< /formula >}}

{{< formula display="true" >}}
H_\text{нас} = \underbrace{\frac{P_2-P_1}{\rho g}}_{\text{напор давления}} + \underbrace{\frac{V_2^2-V_1^2}{2g}}_{\text{скоростной}} + \underbrace{(z_2-z_1)}_{\text{геодезический}} + \underbrace{h_L}_{\text{потери}}
{{< /formula >}}

Именно это уравнение лежит в основе выбора насоса: из него находят требуемый напор H_нас при заданном расходе Q.

Полный напор: {{< formula >}}H_\text{полн} = P/(\rho g) + V^2/(2g) + z{{< /formula >}}

Пьезометрический напор: {{< formula >}}H_\text{пьез} = P/(\rho g) + z{{< /formula >}}

Если пьезометрический напор опускается ниже уровня трубопровода — труба работает «на вакуум», что может привести к кавитации или подсосу воздуха через неплотности.

## Числовой пример: полный расчёт насосной системы

**Задача.** Насос перекачивает воду из нижнего резервуара (z₁ = 0) в верхний (z₂ = 12 м). Расход Q = 6 л/с = 0,006 м³/с. Трубопровод стальной DN80 (внутренний диаметр D = 0,077 м), длина L = 80 м, температура воды 20 °C. Фитинги: 2 колена 90°, 1 обратный клапан, 1 задвижка. Определить требуемый напор насоса.

**Решение.**

Площадь сечения: {{< formula >}}A = \pi\times0{,}077^2/4 = 4{,}657\times10^{-3}{{< /formula >}} м².

Скорость: {{< formula >}}V = Q/A = 0{,}006/4{,}657\times10^{-3} = 1{,}288{{< /formula >}} м/с.

Число Рейнольдса: {{< formula >}}Re = 1{,}288\times0{,}077/(1{,}004\times10^{-6}) = 98\,800{{< /formula >}} (турбулентный).

Относительная шероховатость: {{< formula >}}k_s/D = 0{,}046/77 = 5{,}97\times10^{-4}{{< /formula >}}.

По уравнению Свами–Джейна: {{< formula >}}\lambda = 0{,}25/[\lg(1{,}61\times10^{-4}+5{,}74/98800^{0{,}9})]^2 = 0{,}0206{{< /formula >}}.

Линейные потери: {{< formula >}}h_\text{лин} = 0{,}0206\times(80/0{,}077)\times(1{,}288^2/19{,}62) = 11{,}4{{< /formula >}} м.

Местные потери (коэф. ζ: 2 колена = 2×1,5, обратный клапан = 4, задвижка = 0,5 → Σζ = 8,5):

{{< formula display="true" >}}
h_\text{мест} = 8{,}5\times\frac{1{,}288^2}{19{,}62} = 0{,}72\text{ м}
{{< /formula >}}

Геодезический напор: {{< formula >}}z_2 - z_1 = 12{{< /formula >}} м.

Суммарный требуемый напор:

{{< formula display="true" >}}
H_\text{нас} = 12 + 11{,}4 + 0{,}72 = 24{,}12\text{ м}
{{< /formula >}}

Подбираем насос с характеристикой H = 25 м при Q = 22 м³/ч.

## Уравнение неразрывности для сетей трубопроводов

В узловых точках (коллекторах) применяется закон Кирхгофа первого рода:

{{< formula display="true" >}}
\sum_{k} Q_k = 0 \quad (\text{с учётом знака})
{{< /formula >}}

Для замкнутых контуров:

{{< formula display="true" >}}
\sum_{i\in\text{контур}} \Delta P_i = 0
{{< /formula >}}

Эти два условия образуют систему нелинейных уравнений, решаемую методом Харди-Кросса или узловых давлений (см. раздел о расчёте трубных сетей).

## Уравнение момента импульса

Для вращающихся машин (насосов, вентиляторов) второй закон Ньютона принимает форму уравнения момента:

{{< formula display="true" >}}
\sum M = \dot{m}(r_2 V_{\theta2} - r_1 V_{\theta1})
{{< /formula >}}

Это уравнение Эйлера для турбомашин — основа для вывода теоретической характеристики рабочего колеса. Из него следует, что напор насоса:

{{< formula display="true" >}}
H_\text{Эйлера} = \frac{u_2 V_{\theta2} - u_1 V_{\theta1}}{g}
{{< /formula >}}

где {{< formula >}}u = r\omega{{< /formula >}} — окружная скорость, {{< formula >}}V_\theta{{< /formula >}} — тангенциальная составляющая абсолютной скорости.

## Линейная и угловая неравномерность скорости

В реальных трубопроводах и воздуховодах скорость неравномерна по сечению. Это влияет на измерение расхода:

- Трубка Пито измеряет скоростной напор в одной точке; для получения Q нужен обход сечения (ГОСТ 8.361, ISO 3966).
- Диафрагма измеряет расход по перепаду давления, исходя из уравнения Бернулли с коэффициентом расхода.
- Ультразвуковой расходомер усредняет скорость по нескольким хордам.

## Граничные условия и корректная постановка задачи

Уравнения сохранения требуют граничных условий. Для системы трубопроводов типичные условия:

| Граница | Тип условия | Пример |
|---|---|---|
| Вход | Заданный расход Q или давление P₁ | Насос с заданной характеристикой |
| Выход | Заданное давление P₂ | Давление в верхнем резервуаре |
| Твёрдые стенки | Нулевая нормальная скорость | Стенки трубопровода |
| Контакт с воздухом | Атмосферное давление | Открытый расширительный бак |
