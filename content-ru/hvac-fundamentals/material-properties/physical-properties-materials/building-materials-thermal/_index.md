Тепловые свойства строительных материалов определяют интенсивность теплопередачи через ограждающие конструкции здания, тепловую инерцию помещений и комфорт жильцов. Для инженера HVAC эти данные необходимы при расчёте тепловых нагрузок, подборе толщины изоляции и энергетическом моделировании.

## Теплопроводность

Теплопроводность λ (Вт/(м·К)) — ключевой параметр для расчёта теплового сопротивления слоя:

{{< formula display="true" >}}
R = \frac{\delta}{\lambda}, \quad \left[\frac{\text{м}^2\text{·К}}{\text{Вт}}\right]
{{< /formula >}}

Для многослойной конструкции полное тепловое сопротивление:

{{< formula display="true" >}}
R_{total} = R_{si} + \sum_{i=1}^n \frac{\delta_i}{\lambda_i} + R_{se}
{{< /formula >}}

где R_si, R_se — поверхностные термические сопротивления.

## Тепловая масса

Объёмная теплоёмкость C_v = ρ · c_p, кДж/(м³·К), определяет способность материала аккумулировать теплоту:

{{< formula display="true" >}}
Q_{акк} = C_v \cdot V \cdot \Delta T = \rho\, c_p\, V\, \Delta T
{{< /formula >}}

{{< table title="Объёмная теплоёмкость строительных материалов" >}}
| Материал | ρ, кг/м³ | c_p, кДж/(кг·К) | C_v, кДж/(м³·К) |
|----------|----------|-----------------|-----------------|
| Вода (эталон) | 998 | 4,182 | 4 174 |
| Бетон тяжёлый | 2 300 | 0,88 | 2 024 |
| Кирпич | 1 800 | 0,84 | 1 512 |
| Дерево (сосна) | 500 | 1,70 | 850 |
| Гипсокартон | 800 | 1,09 | 872 |
| Минеральная вата | 50 | 0,84 | 42 |
| EPS | 20 | 1,40 | 28 |
{{< /table >}}

Тепловая диффузия a = λ/(ρ c_p) определяет скорость проникновения температурной волны:

{{< formula display="true" >}}
a = \frac{\lambda}{\rho\, c_p}, \quad [a] = \text{м}^2/\text{с}
{{< /formula >}}

Глубина проникновения суточной температурной волны (период t = 86 400 с):

{{< formula display="true" >}}
\delta_{проник} = \sqrt{\frac{a\, t}{\pi}}
{{< /formula >}}

Для бетона (a ≈ 0,7 × 10⁻⁶ м²/с): δ = √(0,7×10⁻⁶ · 86 400/π) = √(0,0192) = 0,139 м ≈ 140 мм. Плита перекрытия 200 мм полностью задействуется в суточном цикле. Для минваты (a ≈ 1,0 × 10⁻⁶ м²/с): δ ≈ 166 мм — изоляция практически не аккумулирует тепло из-за малого C_v = 42 кДж/(м³·К).

**Применение тепловой массы:**
- Климаты с большой суточной амплитудой температур → бетонные и кирпичные стены демпфируют колебания
- Смещение пиковых охладительных нагрузок на 2–6 часов → снижение установленной мощности кондиционеров
- Ночная вентиляция для охлаждения массива → утилизация ночного холода

## Тепловые мостики

Конструктивные элементы с высокой λ, проходящие через изоляцию, образуют тепловые мостики (thermal bridges). Эффективное U-значение рассчитывается методом параллельных путей:

{{< formula display="true" >}}
U_{eff} = f_{каркас} \cdot U_{каркас} + f_{полость} \cdot U_{полость}
{{< /formula >}}

Стальные стойки (λ = 50 Вт/(м·К)) проводят тепло в 1 400 раз интенсивнее минваты — несколько стальных стоек на фасаде могут удвоить эффективное U стены. Снижение тепловых мостиков: непрерывный наружный слой изоляции (continuous insulation), перекрывающий стойки.

## Паропроницаемость

Паропроницаемость μ_пар (нг/(Па·с·м²)) определяет риск конденсации внутри конструкции. Классификация по EN ISO 10456:

{{< table title="Паропроницаемость строительных материалов" >}}
| Материал | μ_пар, нг/(Па·с·м²) | Класс |
|----------|---------------------|-------|
| Полиэтиленовая плёнка 0,15 мм | 3–9 | Пароизоляция (класс I) |
| Алюминиевая фольга 0,025 мм | 0–0,3 | Пароизоляция (класс I) |
| XPS 50 мм | 29–86 | Паротормоз (класс II) |
| PIR 50 мм | 29–86 | Паротормоз (класс II) |
| Гипсокартон неокрашенный | 2 850–3 420 | Паропроницаемый |
| Фанера 12 мм | 171–400 | Полупроницаемый |
| ОСП 12 мм | 114–342 | Полупроницаемый |
{{< /table >}}

Паробарьер размещают с тёплой стороны изоляции (зимой — изнутри). В жарком климате с активным кондиционированием тёплая сторона — снаружи, поэтому паробарьер размещают снаружи.
