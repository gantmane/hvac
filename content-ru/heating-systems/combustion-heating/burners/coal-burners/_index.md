Угольные горелки — устройства для воспламенения и поддержания горения угольного топлива в котельных установках систем теплоснабжения. Несмотря на сокращение доли угля в энергобалансе большинства стран, угольное отопление остаётся значимым решением в регионах с развитой угледобычей и отсутствием газификации. Основная задача — обеспечить полное, эффективное сгорание при минимизации выбросов NOx, SOx, CO и твёрдых частиц (PM2,5) в соответствии с EN 303-5, ASHRAE 90.1, директивой 2015/2193/EU (средние установки сгорания 4–50 МВт) и СП 60.13330.

## Физика горения угля

Горение угля — гетерогенный процесс между твёрдой фазой (углерод, летучие вещества) и газовой фазой (кислород воздуха), протекающий в четыре стадии:

1. **Нагрев и сушка** — удаление влаги, начало выделения летучих при 100–300 °C.
2. **Дегазация (devolatilization)** — интенсивное выделение горючих газов (H₂, CO, CH₄, C₂H₄) при 300–500 °C.
3. **Воспламенение летучих** — горение выделившихся газов при 600–800 °C.
4. **Горение кокса (char combustion)** — окисление твёрдого углеродного остатка при температуре выше 800 °C.

Полнота сгорания определяется доступностью кислорода, температурой в топке (1 000–1 400 °C) и временем пребывания топлива в активной зоне. Недостаток воздуха ведёт к образованию CO и несгоревших частиц; избыток снижает температуру и КПД, увеличивая тепловые потери с уходящими газами.

## Типы угольных горелок

### Механические питатели (stokers)

Наиболее распространённый тип для котлов мощностью 50 кВт–5 МВт. Уголь подаётся механическим устройством на колосниковую решётку (grate), где происходит слоевое сжигание.

**Основные компоненты:**
- бункер угля объёмом 100–500 м³;
- винтовой или цепной конвейер с регулировкой производительности (0–20 т/ч для среднего котла);
- колосниковая решётка — неподвижная, качающаяся или вращающаяся — из чугуна или стали;
- система воздухораспределения под решёткой с зонной регулировкой расходов.

{{< table title="Типовые параметры механического питателя" >}}
| Параметр | Значение |
|---|---|
| Мощность котла | 50–5 000 кВт |
| Расход угля | 5–2 000 кг/ч |
| Глубина слоя на решётке | 50–200 мм |
| Давление воздуха под решёткой | 100–400 Па |
| КПД котла | 75–85 % |
| Избыток воздуха (EA) | 30–50 % |
{{< /table >}}

**Преимущества:** простота конструкции; возможность использования угля широкого гранулометрического состава (0–100 мм); низкие капитальные затраты.

**Недостатки:** повышенные выбросы золы и дыма; ограниченный диапазон регулирования нагрузки; высокие NOx при полной мощности.

### Пылеугольное сжигание (pulverized coal combustion, PCC)

Уголь измельчается до состояния пыли (80–90 % частиц < 75 мкм) и подаётся в топку как аэросуспензия с горячим первичным воздухом. Широко применяется в котлах мощностью > 1 МВт.

**Компоненты системы:**
- **Углемельница** — шаровая, вихревая или валковая, производительность 1–50 т/ч.
- **Сушилка** — снижение влажности угля до 8–12 % для эффективного размола.
- **Сепаратор** — циклон или воздушный классификатор; частицы > 75 мкм возвращаются на переразмол.
- **Система пневмотранспорта** — расход транспортирующего воздуха 10–50 м³/ч на 1 т/ч топлива.
- **Горелки** — вихревые или прямоточные, расположенные на стенках топки (обычно 4–12 шт. для крупных котлов).

{{< table title="Типовые параметры пылеугольной системы" >}}
| Параметр | Значение |
|---|---|
| Тонкость помола (d < 75 мкм) | 80–90 % |
| Концентрация пыли в первичном воздухе | 0,3–1,0 кг/м³ |
| Расход первичного воздуха | 0,5–2,0 кг/кг топлива |
| Расход вторичного воздуха | 2,0–3,0 кг/кг топлива |
| Температура вторичного воздуха | 150–250 °C |
| КПД котла | 82–90 % |
{{< /table >}}

**Преимущества:** полнота сгорания > 99 %; высокая тепловая мощность; точный контроль процесса; меньше золы в дымовых газах.

**Недостатки:** высокие капиталовложения; сложность эксплуатации; повышенный износ оборудования; высокие NOx (требуется дополнительная очистка).

### Псевдоожиженный слой (fluidized bed combustion, FBC)

Уголь сжигается в слое инертного материала — песка или зольного остатка, — поддерживаемом потоком воздуха снизу. При скорости воздуха 2,5–4,0 м/с частицы находятся во взвешенном состоянии, обеспечивая интенсивное перемешивание и теплообмен.

{{< table title="Типовые параметры котла с псевдоожиженным слоем" >}}
| Параметр | Значение |
|---|---|
| Температура в слое | 750–900 °C |
| Глубина слоя | 0,5–2,0 м |
| Скорость воздуха через решётку | 2,5–4,0 м/с |
| Размер частиц угля | 0–50 мм |
| КПД котла | 85–92 % |
{{< /table >}}

Низкая температура слоя (ниже порога термического NOx — 1 540 °C) и добавление известняка (CaCO₃) для связывания SO₂ обеспечивают снижение NOx на 40–60 % и SOx на 80–95 % по сравнению со стандартным слоевым сжиганием.

**Преимущества:** гибкость по составу топлива (в том числе биомасса, некондиционный уголь); низкие NOx и SOx; малые потери с недожогом.

**Недостатки:** сложность проектирования топки; повышенный износ из-за абразивного действия частиц; относительно высокая стоимость установки.

### Циклонные горелки (cyclone burners)

Уголь и первичный воздух подаются тангенциально в цилиндрическую камеру, создавая интенсивное вихревое движение. Тепловая нагрузка концентрируется в центре циклона.

{{< table title="Типовые параметры циклонной горелки" >}}
| Параметр | Значение |
|---|---|
| Диаметр камеры | 0,5–3,0 м |
| Тепловая нагрузка объёма | 2–5 МВт/м³ |
| Температура в зоне горения | 1 400–1 600 °C |
| КПД | 85–88 % |
{{< /table >}}

Высокая интенсивность горения и компактность — главные достоинства. Недостатки: высокие NOx из-за повышенной температуры; трудность регулирования нагрузки; значительный унос золы.

## Расчёт основных параметров

### Расход топлива

{{< formula display="true" >}}
\dot{m}_{\text{уголь}} = \frac{Q_{\text{котла}}}{H_i \cdot \eta_{\text{котла}}}
{{< /formula >}}

где $Q_{\text{котла}}$ — тепловая мощность котла, кВт; $H_i$ — низшая теплота сгорания угля, кДж/кг; $\eta_{\text{котла}}$ — КПД котла.

{{< table title="Низшая теплота сгорания углей" >}}
| Сорт угля | $H_i$, МДж/кг |
|---|---|
| Антрацит | 28–32 |
| Каменный уголь | 20–26 |
| Бурый уголь | 8–15 |
{{< /table >}}

**Пример.** Котёл мощностью 1 000 кВт на каменном угле ($H_i = 23$ МДж/кг), $\eta = 0{,}85$:

{{< formula display="true" >}}
\dot{m}_{\text{уголь}} = \frac{1\,000}{23\,000 \times 0{,}85} = 0{,}051\;\frac{\text{кг}}{\text{с}} \approx 184\;\frac{\text{кг}}{\text{ч}}
{{< /formula >}}

### Расход воздуха горения

Стехиометрический расход воздуха:

{{< formula display="true" >}}
\dot{m}_{\text{воздух, min}} = \dot{m}_{\text{уголь}} \cdot \bigl(8{,}9\,C + 26{,}7\,H - 3{,}3\,O\bigr)
{{< /formula >}}

где $C$, $H$, $O$ — массовые доли углерода, водорода и кислорода в угле (на сухую массу). Практический расход воздуха превышает стехиометрический на 15–30 % (коэффициент избытка воздуха $\alpha = 1{,}15$–$1{,}30$).

### Объём топки

Для камерных топок:

{{< formula display="true" >}}
V_{\text{топка}} = \frac{Q_{\text{котла}}}{\dot{q}_{\text{V}}}
{{< /formula >}}

где $\dot{q}_{\text{V}}$ — удельная тепловая нагрузка топочного объёма: 100–200 кВт/м³ для камерных топок, 200–500 кВт/м³ для водотрубных.

## Применение в системах теплоснабжения

{{< table title="Применение угольных горелок по мощности" >}}
| Мощность | Тип горелки | Особенности |
|---|---|---|
| < 50 кВт | Stoker (жилые) | Объём бункера 100–500 кг; ручная или полуавтоматическая загрузка |
| 50–5 000 кВт | Stoker с цепной решёткой | Автоматизация подачи; контроль давления и температуры дымовых газов |
| > 5 МВт | PCC с предварительной подготовкой | Многоступенчатая очистка: электрофильтры, рукавные фильтры, скрубберы |
| Любой при жёстких нормах | FBC + известняк | Снижение SOx; низконоксные горелки; при необходимости — SCR |
{{< /table >}}

## Снижение выбросов

**Первичные меры (primary measures).**
Ступенчатое горение (staged air или staged fuel); низконоксные горелки; оптимизация коэффициента избытка воздуха в первичной зоне.

**Вторичные меры (secondary measures).**
Впрыск восстановителя — аммиака (NH₃) или мочевины (urea) — в дымовой тракт при 870–1 090 °C (SNCR).

**Третичные меры (tertiary measures).**
- Электрофильтры (ESP, electrostatic precipitator) — улавливание PM (КПД > 99 %).
- Рукавные фильтры (bag filters) — тонкая очистка.
- Известняковые абсорберы (wet scrubbers) — улавливание SO₂.
- SCR-реакторы — снижение NOx на 80–95 %.

{{< table title="Типичные эксплуатационные параметры угольных котлов" >}}
| Параметр | Значение |
|---|---|
| Влажность угля (stoker) | До 25 % |
| Влажность угля (PCC) | 5–15 % |
| Тонкость помола (PCC) | 80–90 % < 75 мкм |
| Температура дымовых газов (с экономайзером) | 120–160 °C |
| Коэффициент избытка воздуха (α) | 1,15–1,30 |
| Давление воздуха под решёткой (stoker) | 150–300 Па |
| Сезонный КПД | 75–88 % |
{{< /table >}}

## Нормативные требования

- **EN 303-5:2012** — котлы на твёрдом топливе, требования безопасности и эффективности для мощности до 500 кВт.
- **ASHRAE 90.1** — минимальные требования к энергоэффективности систем отопления.
- **Директива 2015/2193/EU** — предельные выбросы для средних установок сгорания (4–50 МВт).
- **СП 60.13330** — проектирование систем теплоснабжения, требования к котельным установкам.

Угольные горелки остаются актуальным решением в регионах с доступными угольными ресурсами и требуют постоянного совершенствования технологий сжигания и дымоочистки для соответствия ужесточающимся нормам качества воздуха.
