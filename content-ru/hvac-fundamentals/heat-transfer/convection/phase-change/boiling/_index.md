Кипение — фазовый переход жидкость–пар на нагреваемой поверхности. Интенсивность теплообмена при кипении на 1–3 порядка выше, чем при однофазной конвекции. В системах HVAC кипение хладагента — основной процесс теплообмена в испарителях (DX-катушки, кожухотрубные испарители, пластинчатые теплообменники).

## Кривая кипения Нуссельта (pool boiling)

Зависимость плотности теплового потока $q''$ от перегрева поверхности $\Delta T_e = T_s - T_{sat}$:

### Режим пузырькового кипения (5 < ΔTe < 30°С)

Пузырьки пара зарождаются в центрах нуклеации (микронеровности, царапины), растут и отрываются. Перемешивание жидкости обеспечивает очень высокие коэффициенты теплообмена $h = 2500$–$100\,000$ Вт/(м²·К).

### Режим переходного кипения (30 < ΔTe < 120°С)

Паровая плёнка нестабильно покрывает поверхность. Тепловой поток **снижается** с ростом перегрева — нарушение привычной зависимости. Этот режим опасен для оборудования, так как поверхность может перегреться.

### Режим плёночного кипения (ΔTe > 120°С)

Стабильная паровая рубашка полностью изолирует стенку от жидкости. Тепловой поток мал. Температура стенки может достигать сотен градусов. Недопустим в холодильных системах HVAC.

## Критический тепловой поток (КТП)

КТП — максимальный тепловой поток при пузырьковом кипении перед переходом в плёночное (точка Лейденфроста).

**Корреляция Зубера** для горизонтальной поверхности:

{{< formula display="true" >}}
q''_{max} = 0{,}149 \, h_{fg} \, \rho_v \left[\frac{\sigma g (\rho_l - \rho_v)}{\rho_v^2}\right]^{1/4}
{{< /formula >}}

{{< table title="КТП для хладагентов при испарении 5°С" >}}
| Хладагент | $q''_{max}$, кВт/м² |
|---|---|
| R-22 | 260 |
| R-134a | 215 |
| R-410A | 290 |
| R-32 | 370 |
| R-717 (NH₃) | 520 |
| Вода при 1 атм | 1260 |
{{< /table >}}

Испарители HVAC проектируют при $q'' = 0{,}3$–$0{,}6 \cdot q''_{max}$.

## Корреляция Розенова для пузырькового кипения в объёме

{{< formula display="true" >}}
\frac{q''}{\mu_l h_{fg}} = \left[\frac{g(\rho_l - \rho_v)}{\sigma}\right]^{1/2} \left[\frac{c_{p,l} \Delta T_e}{C_{sf} h_{fg} Pr_l^n}\right]^3
{{< /formula >}}

где $C_{sf}$ — константа, зависящая от пары поверхность–жидкость; $n = 1$ для воды, $n = 1{,}7$ для хладагентов.

{{< table title="Значения C_sf по Розенову для пар хладагент–поверхность" >}}
| Пара | $C_{sf}$ |
|---|---|
| Вода–медь полированная | 0,013 |
| Вода–нержавеющая сталь | 0,013 |
| R-134a–медь | 0,003 |
| R-22–медь | 0,005 |
| NH₃–нержавеющая сталь | 0,004 |
{{< /table >}}

## Корреляция Купера (упрощённая, хладагенты)

{{< formula display="true" >}}
h = 55 \, P_r^{0,12} (-\log_{10} P_r)^{-0,55} M^{-0,5} (q'')^{0,67}
{{< /formula >}}

где $P_r = P/P_{cr}$ — приведённое давление, $M$ — молекулярная масса. Применима для хладагентов при $0{,}001 < P_r < 0{,}9$.

**Числовой пример для R-410A при испарении 5°С**:

$P_{cr} = 4{,}902$ МПа, $P_{5°С} = 1{,}076$ МПа, $P_r = 0{,}2196$, $M = 72{,}58$ г/моль. При $q'' = 10\,000$ Вт/м²:

{{< formula display="true" >}}
h = 55 \times 0{,}2196^{0,12} \times (-\log 0{,}2196)^{-0,55} \times 72{,}58^{-0,5} \times 10000^{0,67}
{{< /formula >}}

{{< formula display="true" >}}
h = 55 \times 0{,}837 \times 1{,}529^{-0,55} \times 0{,}1173 \times 464{,}2 = 55 \times 0{,}837 \times 0{,}832 \times 0{,}1173 \times 464{,}2 = 2477 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

## Кипение при течении (flow boiling)

В испарителях хладагент течёт в трубах. Теплообмен зависит от степени сухости $x$, массового потока $G$ [кг/(м²·с)], давления. Суперпозиция пузырькового кипения и конвективного вклада.

### Корреляция Чена (Chen correlation, 1966)

{{< formula display="true" >}}
h_{tp} = h_{nb} \cdot S + h_{conv} \cdot F
{{< /formula >}}

- $h_{nb}$ — компонента пузырькового кипения по Розенову
- $h_{conv} = 0{,}023 (k_l/D) Re_l^{0,8} Pr_l^{0,4}$ — конвективная компонента
- $S$ — коэффициент подавления ($0 < S < 1$): снижает вклад пузырькового кипения из-за высокой скорости течения
- $F$ — коэффициент усиления ($F > 1$): увеличивает конвективный вклад из-за двухфазного течения

Параметр Мартинелли: $X_{tt} = \left(\frac{1-x}{x}\right)^{0,9} \left(\frac{\rho_v}{\rho_l}\right)^{0,5} \left(\frac{\mu_l}{\mu_v}\right)^{0,1}$

$F = 2{,}35 (1/X_{tt} + 0{,}213)^{0,736}$ при $1/X_{tt} > 0{,}1$.

### Корреляция Шаха (1982) — упрощённая, рекомендованная

{{< formula display="true" >}}
h_{tp} = h_l \cdot \psi
\quad
h_l = 0{,}023 \frac{k_l}{D} Re_l^{0,8} Pr_l^{0,4}
{{< /formula >}}

{{< formula display="true" >}}
\psi = \max\left(\psi_{nb}, \psi_{cb}\right)
{{< /formula >}}

{{< formula display="true" >}}
\psi_{nb} = 230 Bo^{0,5} \quad\text{(пузырьковое)}, \quad Bo = \frac{q''}{G h_{fg}}
{{< /formula >}}

{{< formula display="true" >}}
\psi_{cb} = 1{,}8 \left(\frac{1}{X_{tt}}\right)^{0,8} \quad\text{(конвективное)}
{{< /formula >}}

**Числовой пример: DX-испаритель с R-410A**

$D = 9{,}52$ мм, $G = 300$ кг/(м²·с), $q'' = 12\,000$ Вт/м², $x = 0{,}5$, испарение при 5°С.

Свойства R-410A при 5°С: $\rho_l = 1089$ кг/м³, $\rho_v = 34{,}3$ кг/м³, $\mu_l = 143 \times 10^{-6}$ Па·с, $k_l = 0{,}0988$ Вт/(м·К), $Pr_l = 2{,}46$, $h_{fg} = 252{,}9$ кДж/кг.

$Re_l = G(1-x)D/\mu_l = 300 \times 0{,}5 \times 0{,}00952 / (143 \times 10^{-6}) = 10\,020$

$h_l = 0{,}023 \times (0{,}0988/0{,}00952) \times 10020^{0,8} \times 2{,}46^{0,4} = 0{,}023 \times 10{,}38 \times 1468 \times 1{,}442 = 506$ Вт/(м²·К)

$Bo = 12000/(300 \times 252900) = 1{,}58 \times 10^{-4}$

$\psi_{nb} = 230 \times (1{,}58 \times 10^{-4})^{0,5} = 230 \times 0{,}01257 = 2{,}89$

$X_{tt} = (0{,}5/0{,}5)^{0,9} \times (34{,}3/1089)^{0,5} \times (143/16)^{0,1} = 1 \times 0{,}1775 \times 1{,}247 = 0{,}221$

$\psi_{cb} = 1{,}8 \times (1/0{,}221)^{0,8} = 1{,}8 \times 4{,}52^{0,8} = 1{,}8 \times 3{,}73 = 6{,}72$

$\psi = \max(2{,}89;\;6{,}72) = 6{,}72$ → доминирует конвективное кипение

$h_{tp} = 506 \times 6{,}72 = 3400$ Вт/(м²·К)

## Повреждающее действие кризиса кипения (burnout)

Превышение КТП приводит к переходу в плёночное кипение. Температура поверхности скачкообразно возрастает на 300–600°С. В холодильных системах это вызывает деградацию смазки, разрушение компрессора. Системы защиты:

- Реле высокого давления (отключение компрессора при $T_{evap}$ ниже уставки)
- Датчики перегрева
- Электронные расширительные клапаны с алгоритмами защиты от «сухого хода»
