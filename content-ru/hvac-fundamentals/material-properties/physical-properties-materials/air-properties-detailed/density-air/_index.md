Плотность воздуха (air density) — масса воздуха на единицу объёма, кг/м³ — определяет генерацию давления вентилятором, потери давления в воздуховодах, расчёт скорости теплообмена и измерение расхода воздуха. Без знания плотности невозможен корректный подбор вентилятора или расчёт его потребляемой мощности.

## Уравнение состояния и расчётная формула

Сухой воздух в условиях HVAC описывается уравнением идеального газа:

{{< formula display="true" >}}
\rho = \frac{p}{R_{уд}\, T}, \quad R_{уд} = 287{,}05\ \text{Дж/(кг·К)}, \quad T\ \text{[К]}
{{< /formula >}}

Производная форма для пересчёта от стандартных условий к фактическим:

{{< formula display="true" >}}
\rho_{факт} = \rho_{ст} \cdot \frac{p_{факт}}{p_{ст}} \cdot \frac{T_{ст}}{T_{факт}}
{{< /formula >}}

**Стандартные условия ASHRAE:** T_ст = 293,15 К (20 °C), p_ст = 101 325 Па → ρ_ст = 1,204 кг/м³.

{{< table title="Стандартные условия воздуха по различным нормам" >}}
| Стандарт | T, °C | p, кПа | ρ, кг/м³ |
|----------|-------|--------|----------|
| ASHRAE Handbook | 20 | 101,325 | 1,204 |
| AMCA 210 | 21,1 | 101,325 | 1,200 |
| ISO 5011 | 25 | 100,000 | 1,184 |
| ISA (уровень моря) | 15 | 101,325 | 1,225 |
{{< /table >}}

## Зависимость от давления и высоты

Давление убывает с высотой по формуле стандартной атмосферы ISA:

{{< formula display="true" >}}
p(H) = 101{,}325 \left(1 - 2{,}2558 \times 10^{-5}\, H\right)^{5{,}256}\ \text{[кПа, м]}
{{< /formula >}}

| H, м | p, кПа | ρ, кг/м³ | σ = ρ/ρ₀ |
|------|--------|----------|----------|
| 0 | 101,33 | 1,204 | 1,000 |
| 300 | 97,71 | 1,161 | 0,964 |
| 600 | 94,22 | 1,120 | 0,930 |
| 900 | 90,87 | 1,080 | 0,897 |
| 1 200 | 87,65 | 1,042 | 0,866 |
| 1 500 | 84,56 | 1,005 | 0,835 |
| 2 000 | 79,50 | 0,945 | 0,785 |
| 2 500 | 74,68 | 0,888 | 0,737 |
| 3 000 | 70,12 | 0,834 | 0,693 |
{{< /table >}}

**Пример:** Объект в Алматы (H ≈ 850 м), летний день T = 35 °C.
p = 101,325 · (1 − 2,2558×10⁻⁵ · 850)^5,256 = 91,6 кПа
ρ = 91 600 / (287,05 · 308,15) = 1,035 кг/м³ → σ = 0,860 от стандарта.

## Влажный воздух

Водяной пар (M = 18,015 г/моль) легче сухого воздуха (M = 28,965 г/моль), поэтому влажный воздух менее плотный. Строгая формула:

{{< formula display="true" >}}
\rho_{вл} = \frac{p_{сух}}{R_{сух}\, T} + \frac{p_{пар}}{R_{пар}\, T}
{{< /formula >}}

где R_сух = 287,05 Дж/(кг·К), R_пар = 461,52 Дж/(кг·К), p_сух + p_пар = p_барометр.

Эквивалентная формула через влагосодержание d (kg/kg):

{{< formula display="true" >}}
\rho_{вл} = \rho_{сух} \cdot \frac{1 + d}{1 + 1{,}6078\, d}
{{< /formula >}}

{{< table title="Плотность влажного воздуха при p = 101 325 Па" >}}
| T, °C | φ, % | d, г/кг | ρ, кг/м³ | Δρ от сухого |
|-------|------|---------|----------|-------------|
| 20 | 0 | 0,0 | 1,204 | 0,0% |
| 20 | 50 | 7,3 | 1,196 | −0,7% |
| 20 | 100 | 14,7 | 1,187 | −1,4% |
| 30 | 50 | 13,5 | 1,150 | −1,2% |
| 30 | 100 | 27,3 | 1,136 | −2,4% |
{{< /table >}}

Для большинства расчётов подбора вентиляторов влияние влажности незначительно (< 2%) и обычно не учитывается. В психрометрических расчётах влажность важна, так как определяет влагосодержание и теплоёмкость воздуха.

## Применение в расчётах HVAC

### Динамическое давление

{{< formula display="true" >}}
p_{дин} = \frac{\rho V^2}{2}
{{< /formula >}}

В стандартных условиях: p_дин [Па] = 0,602 · V² [м/с]². При σ = 0,83: p_дин = 0,499 · V² — давление ниже на 17% при той же скорости.

### Законы вентилятора при изменении плотности

Для вентилятора при постоянных оборотах n:

{{< formula display="true" >}}
\dot{V} = \text{const}, \quad \Delta p \propto \rho, \quad N_{вент} \propto \rho
{{< /formula >}}

Если вентилятор подобран по каталогу (стандартные условия) и устанавливается на высоте со σ < 1:

{{< formula display="true" >}}
\Delta p_{факт} = \sigma \cdot \Delta p_{каталог}
{{< /formula >}}

**Пересчёт каталожных данных на высоту:** Требуемое фактическое Δp_факт = 600 Па, σ = 0,83. Каталожное значение для подбора: Δp_кат = 600/0,83 = 723 Па. Выбираем вентилятор на Δp_кат = 723 Па в стандартных условиях.

### Расчёт чувствительного тепла

Тепловая нагрузка через объёмный расход:

{{< formula display="true" >}}
\dot{Q} = \rho\, \dot{V}\, c_p\, \Delta T
{{< /formula >}}

На высоте H = 1 500 м: ρ = 1,005 кг/м³ вместо 1,204. При том же V̇ и ΔT тепловая производительность снижается на 17% — необходимо увеличить объёмный расход на 1/0,835 = 1,197, т.е. на 20%.

### Скорость по трубке Пито

Показание трубки Пито Δp_пито зависит от ρ:

{{< formula display="true" >}}
V = \sqrt{\frac{2\, \Delta p_{пито}}{\rho}}
{{< /formula >}}

При использовании номограмм, построенных для ρ₀ = 1,204 кг/м³, вводится поправка:

{{< formula display="true" >}}
V_{факт} = V_{номограмма} \cdot \sqrt{\frac{\rho_0}{\rho_{факт}}}
{{< /formula >}}
