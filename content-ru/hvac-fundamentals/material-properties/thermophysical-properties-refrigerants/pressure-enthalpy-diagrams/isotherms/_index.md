Изотермы (isotherms) — линии постоянной температуры на диаграмме давление–энтальпия (P–h). Их поведение кардинально различается в трёх областях диаграммы: в жидкостной — почти вертикальные; в двухфазной — строго горизонтальные (совпадающие с изобарами); в области перегретого пара — изогнутые с наклоном вправо-вниз. Знание геометрии изотерм необходимо для определения фазового состояния хладагента, расчёта степени перегрева и переохлаждения, а также для диагностики работающей системы по измеренным давлениям и температурам.

## Физические основы изотерм

Изотерма — геометрическое место точек {{< formula >}}(h, P){{< /formula >}} состояния вещества при {{< formula >}}T = \text{const}{{< /formula >}}. Наклон изотермы на диаграмме P–h:

{{< formula display="true" >}}
\left(\frac{\partial P}{\partial h}\right)_T
{{< /formula >}}

определяется уравнением состояния. Для однофазных областей из термодинамического тождества:

{{< formula display="true" >}}
\left(\frac{\partial h}{\partial P}\right)_T = v - T\left(\frac{\partial v}{\partial T}\right)_P = v(1 - \beta T)
{{< /formula >}}

где {{< formula >}}v{{< /formula >}} — удельный объём (м³/кг), {{< formula >}}\beta{{< /formula >}} — изобарный коэффициент теплового расширения (К⁻¹). Это выражение показывает, насколько сильно энтальпия зависит от давления при постоянной температуре.

### Изотерма в жидкостной области

Для переохлаждённой жидкости {{< formula >}}\beta T \approx 0{,}1\text{–}0{,}4{{< /formula >}} (зависит от хладагента и температуры), поэтому {{< formula >}}(\partial h/\partial P)_T{{< /formula >}} мало. Изотерма почти вертикальна. Типичный наклон:

{{< formula display="true" >}}
\left(\frac{\partial h}{\partial P}\right)_T \approx v_l (1 - \beta T) \approx (0{,}5\text{–}2) \times 10^{-3} \text{ м}^3\text{/кг}
{{< /formula >}}

При масштабе осей диаграммы это соответствует практически вертикальной линии.

### Изотерма в двухфазной области

Внутри купола насыщения температура и давление однозначно связаны через кривую давления насыщения {{< formula >}}P_{\text{нас}}(T){{< /formula >}}. Следовательно, при {{< formula >}}T = \text{const}{{< /formula >}} давление тоже постоянно — изотерма совпадает с изобарой и является **горизонтальным отрезком**. Длина горизонтального участка равна теплоте парообразования (latent heat of vaporisation):

{{< formula display="true" >}}
\Delta h_{l \to g} = h_g(P) - h_f(P) = h_{fg}
{{< /formula >}}

Для R-134a: {{< formula >}}h_{fg} = 215{,}4{{< /formula >}} кДж/кг при 0 °C и {{< formula >}}h_{fg} = 163{,}0{{< /formula >}} кДж/кг при 40 °C — горизонтальные участки изотерм наглядно сокращаются по мере приближения к критической точке.

### Изотерма в области перегретого пара

В паровой фазе {{< formula >}}v{{< /formula >}} велико (низкая плотность пара), поэтому {{< formula >}}(\partial h/\partial P)_T{{< /formula >}} заметно. Для приближения идеального газа:

{{< formula display="true" >}}
\left(\frac{\partial h}{\partial P}\right)_T \approx \frac{RT^2}{P} \cdot \frac{dB}{dT} \quad (\text{первый вириальный член})
{{< /formula >}}

Изотерма изгибается вправо-вниз; при высоком перегреве стремится к вертикали (идеальный газ: {{< formula >}}h = h(T){{< /formula >}}).

### Критическая изотерма

При {{< formula >}}T = T_c{{< /formula >}} изотерма проходит через критическую точку — вершину купола. Выше {{< formula >}}T_c{{< /formula >}} изотермы описывают надкритическое состояние (supercritical state): нет разделения на жидкость и пар, нет горизонтального двухфазного участка. Для CO₂ (R-744) {{< formula >}}T_c = 31{,}1{{< /formula >}} °C — многие летние режимы работы вентиляции и кондиционирования воздуха попадают выше критической температуры.

## Поведение изотерм и определение состояния хладагента

По измеренным давлению и температуре фазовое состояние хладагента определяется сравнением с давлением насыщения:

{{< table title="Определение фазового состояния хладагента" >}}
| Условие | Фазовое состояние | Положение на диаграмме |
|---------|-------------------|----------------------|
| {{< formula >}}P < P_{\text{нас}}(T){{< /formula >}} | Перегретый пар | Справа от купола |
| {{< formula >}}P = P_{\text{нас}}(T){{< /formula >}} | Насыщение (двухфазное) | На куполе или внутри |
| {{< formula >}}P > P_{\text{нас}}(T){{< /formula >}} | Переохлаждённая жидкость | Слева от купола |
{{< /table >}}

Степень сухости при насыщении:

{{< formula display="true" >}}
x = \frac{h - h_f(P)}{h_{fg}(P)}
{{< /formula >}}

Степень перегрева:

{{< formula display="true" >}}
\Delta T_{\text{пер}} = T - T_{\text{нас}}(P) \quad (T > T_{\text{нас}})
{{< /formula >}}

Степень переохлаждения:

{{< formula display="true" >}}
\Delta T_{\text{пер.ох}} = T_{\text{нас}}(P) - T \quad (T < T_{\text{нас}})
{{< /formula >}}

## Численный пример — определение состояния и перегрева

**Условие:** манометр на всасывании компрессора показывает {{< formula >}}P_1 = 350{{< /formula >}} кПа (абс.), термометр на линии всасывания — {{< formula >}}T_1 = 10{{< /formula >}} °C. Хладагент — R-134a. Определить состояние, степень перегрева и энтальпию.

Шаг 1. По NIST REFPROP v10 (или ASHRAE Handbook Fundamentals, гл. 30) найти температуру насыщения при 350 кПа:

{{< formula display="true" >}}
T_{\text{нас}}(350 \text{ кПа}) = -0{,}1 \text{ °C}
{{< /formula >}}

Шаг 2. Сравнить с измеренной температурой:

{{< formula display="true" >}}
T_1 = 10 \text{ °C} > T_{\text{нас}} = -0{,}1 \text{ °C} \quad \Rightarrow \quad \text{перегретый пар}
{{< /formula >}}

Шаг 3. Степень перегрева:

{{< formula display="true" >}}
\Delta T_{\text{пер}} = 10{,}0 - (-0{,}1) = 10{,}1 \text{ К}
{{< /formula >}}

Шаг 4. Энтальпия из REFPROP при {{< formula >}}P = 350{{< /formula >}} кПа, {{< formula >}}T = 10{{< /formula >}} °C:

{{< formula display="true" >}}
h_1 = 411{,}7 \text{ кДж/кг}, \quad s_1 = 1{,}763 \text{ кДж/(кг·К)}
{{< /formula >}}

Если задано давление конденсации {{< formula >}}P_2 = 1017{{< /formula >}} кПа ({{< formula >}}T_{\text{конд}} = 40{{< /formula >}} °C), то по изоэнтропе {{< formula >}}s_{2s} = s_1 = 1{,}763{{< /formula >}} кДж/(кг·К):

{{< formula display="true" >}}
h_{2s}(1017 \text{ кПа}, 1{,}763 \text{ кДж/(кг·К)}) = 437{,}2 \text{ кДж/кг}
{{< /formula >}}

Идеальная работа сжатия: {{< formula >}}w_{is} = 437{,}2 - 411{,}7 = 25{,}5{{< /formula >}} кДж/кг.

## Влияние изотерм на КПД конденсатора

При конденсации горизонтальный участок изотермы соответствует постоянной температуре конденсации {{< formula >}}T_{\text{конд}}{{< /formula >}}. Разность между температурой воздуха (или воды) на входе в конденсатор и {{< formula >}}T_{\text{конд}}{{< /formula >}} — **напор конденсации** (condensing approach temperature). Чем меньше напор, тем ниже давление конденсации, тем меньше работа компрессора и выше COP. Снижение {{< formula >}}T_{\text{конд}}{{< /formula >}} на 5 °C повышает COP примерно на 10–15 % (ASHRAE Handbook Fundamentals, гл. 2).

## Изотерма при работе теплового насоса в умеренном климате

Для теплового насоса воздух–воздух в климатической зоне по СП 131.13330 при {{< formula >}}T_{\text{нар}} = -15{{< /formula >}} °C и {{< formula >}}T_{\text{обогрева}} = 45{{< /formula >}} °C (R-410A):

- Испарение: {{< formula >}}T_{\text{исп}} \approx -25{{< /formula >}} °C, {{< formula >}}P_{\text{исп}} \approx 0{,}374{{< /formula >}} МПа.
- Конденсация: {{< formula >}}T_{\text{конд}} \approx 50{{< /formula >}} °C, {{< formula >}}P_{\text{конд}} \approx 3{,}06{{< /formula >}} МПа.
- Степень давления: {{< formula >}}P_{\text{конд}}/P_{\text{исп}} \approx 8{,}2{{< /formula >}} — граница применимости одноступенчатого компрессора; требуется двухступенчатое сжатие или впрыск пара.

Изотермы на диаграмме наглядно показывают: горизонтальная изотерма при −25 °C (испаритель) смещается к самому низу диаграммы, горизонтальная при 50 °C — к верху. Вертикальная протяжённость цикла (работа компрессора) резко возрастает.
