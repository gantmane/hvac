Непрерывная наружная изоляция (continuous insulation, CI) размещается с внешней стороны несущего каркаса или кладки без разрывов на стойках и перемычках. Это принципиально меняет гигротермические характеристики стены: обшивка (sheathing) и каркас переходят в тёплую зону, риск конденсации снижается, тепловые мосты через стойки компенсируются. Данный раздел анализирует физику, расчётные методы и практические аспекты применения систем CI.

## Тепловые мосты и эффективное R стены

### Метод параллельных путей (modified zone method)

Суммарный коэффициент теплопередачи стены с полостным и наружным утеплителем:

{{< formula display="true" >}}
U_\mathrm{assembly} = \frac{FF}{R_\mathrm{frame}} + \frac{1 - FF}{R_\mathrm{cavity}}
{{< /formula >}}

где FF — доля площади стоек (0,15–0,25 для дерева, 0,05–0,10 для стального каркаса). При добавлении CI суммарное R:

{{< formula display="true" >}}
R_\mathrm{total} = R_\mathrm{ci} + \frac{1}{U_\mathrm{assembly}}
{{< /formula >}}

**Числовой пример (Москва, зона 5):** Стена 50×150 мм с шагом 600 мм, полостная минвата 150 мм (R = 4,2 м²·К/Вт). FF = 50/600 = 0,083. R_frame = 0,12 (дерево) + 0,13 + 0,11 = 0,36 м²·К/Вт.

{{< formula display="true" >}}
U = \frac{0{,}083}{0{,}36} + \frac{0{,}917}{4{,}2 + 0{,}24} = 0{,}231 + 0{,}206 = 0{,}437 \text{ Вт/(м}^2\text{·К)}
{{< /formula >}}

R_cavity_eff = 1/0,437 = 2,29 м²·К/Вт (снижение 45% от номинала полостного утеплителя 4,2 м²·К/Вт).

После добавления CI 60 мм минвата (R_ci = 1,6 м²·К/Вт):

{{< formula display="true" >}}
R_\mathrm{total} = 1{,}6 + 2{,}29 = 3{,}89 \text{ м}^2\text{·К/Вт}
{{< /formula >}}

Теперь доля R_ci = 1,6/3,89 = 41% — тепловые мосты через стойки менее значимы.

### Эффективность снижения тепловых мостов

{{< formula display="true" >}}
\eta_\mathrm{bridge} = \frac{R_\mathrm{total,ci} - R_\mathrm{cavity,eff}}{R_\mathrm{ci}}
{{< /formula >}}

При R_ci = 1,6 м²·К/Вт: η = (3,89 − 2,29)/1,6 = 1,0 (100%). Каждый м²·К/Вт CI добавляет ровно 1,0 м²·К/Вт к суммарному R — значительно эффективнее полостного утеплителя, который снижается тепловыми мостами.

## Контроль конденсации на обшивке

### Расчёт температуры обшивки

Температура поверхности, где полость встречается с CI (внутренняя поверхность обшивки):

{{< formula display="true" >}}
T_\mathrm{sheathing} = T_\mathrm{ext} + \frac{R_\mathrm{ci} + R_\mathrm{ext,surf}}{R_\mathrm{total}} \cdot (T_\mathrm{int} - T_\mathrm{ext})
{{< /formula >}}

Условие защиты от конденсации:

{{< formula display="true" >}}
T_\mathrm{sheathing} > T_{dp,\mathrm{int}} + \Delta T_\mathrm{safety} \quad (\Delta T = 2\text{–}3 \ ^\circ\mathrm{C})
{{< /formula >}}

### Числовой пример: минимальная толщина CI (Москва)

**Данные:** T_int = 21 °C, ОВ = 40% → T_dp = 7,2 °C; T_ext = −26 °C. Полостная минвата 150 мм (R = 4,2 м²·К/Вт), ОСП обшивка 12 мм (R = 0,15 м²·К/Вт), поверхностные сопротивления 0,24 м²·К/Вт. R_cavity = 4,59 м²·К/Вт.

Требуемое соотношение: R_ci / R_total ≥ (21 − 7,2) / (21 − (−26)) = 13,8/47 = 0,294.

Из условия: R_ci / (R_ci + R_cavity) ≥ 0,294 → R_ci ≥ 0,294 × R_cavity / (1 − 0,294) = 0,294 × 4,59 / 0,706 = 1,91 м²·К/Вт.

Для минеральной ваты CI (λ = 0,038 Вт/(м·К)): d = 1,91 × 0,038 = 73 мм. Принимаем 80 мм.

Проверка: R_ci = 2,1 м²·К/Вт, R_total = 6,7 м²·К/Вт:

{{< formula display="true" >}}
T_\mathrm{sheathing} = -26 + \frac{2{,}1 + 0{,}12}{6{,}7} \times 47 = -26 + 15{,}6 = -10{,}4 \ ^\circ\mathrm{C}
{{< /formula >}}

Это — температура наружной поверхности обшивки. Внутренняя поверхность обшивки (граница с полостью):

{{< formula display="true" >}}
T_\mathrm{sheathing,int} = -26 + \frac{0{,}12}{6{,}7} \times 47 = -26 + 0{,}84 = -25{,}2 \ ^\circ\mathrm{C}
{{< /formula >}}

Нет, пересчитываем от внутренней стороны: R_inner = поверхн. сопр. + гипсокартон + полость = 0,13 + 0,05 + 4,2 = 4,38 м²·К/Вт:

{{< formula display="true" >}}
T_\mathrm{sheathing,int} = 21 - \frac{4{,}38}{6{,}7} \times 47 = 21 - 30{,}7 = -9{,}7 \ ^\circ\mathrm{C}
{{< /formula >}}

T_sheathing,int = −9,7 °C >> T_dp = 7,2 °C. Запас огромный. Конденсация полностью исключена.

## Материалы наружной непрерывной изоляции

{{< /table >}}

### Сравнительный анализ материалов

**XPS:** умеренная паропроницаемость (класс II) — обеспечивает некоторое высыхание. Хорошая прочность на сжатие. Стабильное R при низких температурах.

**EPS:** выше паропроницаемость — лучший потенциал высыхания. Ниже стоимость. Требует защиты от УФ.

**PIR без фольги:** наивысшее R/толщину. Снижение R при низких температурах (поправочный коэффициент):

{{< formula display="true" >}}
R_\mathrm{eff,PIR} = R_\mathrm{24°C} \times \left[1 - 0{,}008 \times (24 - T_\mathrm{avg})\right]
{{< /formula >}}

При T_avg = −10 °C: R_eff = R_24°C × 0,728 — снижение 27%. Критично для холодного климата.

**PIR с фольгой:** паропроницаемость < 0,05 перм — паровой барьер класса I. Высыхание через этот слой исключено. Требует обеспечить потенциал высыхания с другой стороны.

**Минеральная вата:** паропроницаемость > 30 перм — не ограничивает высыхание ни в одном направлении. Огнестойкость. Выше стоимость и вес.

## Стратегия паровой защиты с наружной CI

### Принцип: CI повышает температуру обшивки

С достаточным R_ci обшивка и каркас находятся в тёплой зоне — риск конденсации снижается. Это позволяет ослабить требования к внутреннему паровому замедлителю.

{{< table title="Класс внутреннего парового замедлителя в зависимости от R_ci (зоны 5–7 по ASHRAE)" >}}
| Климатическая зона | Мин. R_ci | Допустимый класс внутренней защиты |
|---|---|---|
| Зона 5 (Москва) | 1,32 м²·К/Вт | Класс III (латексная краска) |
| Зона 6 (Екатеринбург) | 1,98 м²·К/Вт | Класс III или «умный» замедлитель |
| Зона 7 (Новосибирск) | 2,64 м²·К/Вт | Класс II–III |
| Зона 8 (Якутск) | 3,52 м²·К/Вт | Класс II |
{{< /table >}}

«Умные» (smart) паровые замедлители: зимой ≤ 1 перм (защита от паровой диффузии), летом ≥ 10 перм (высыхание внутрь). Оптимальны для смешанного климата.

### Конфигурации WRB и CI

**Конфигурация A — WRB снаружи CI:** изоляция защищена от жидкой воды, дренаж по наружной поверхности CI, вентзазор между CI и облицовкой. Рекомендуется для большинства случаев.

**Конфигурация B — WRB между стеной и CI:** изоляция может намокнуть. Требуется паропроницаемый CI (минвата или EPS). Применяется в системах вентфасада с изоляцией в два слоя.

## Крепёжные системы и тепловые мосты от крепежа

### Тепловой мост стального крепежа

Каждый стальной болт или шуруп, пронизывающий CI, создаёт точечный тепловой мост. Снижение эффективного R:

{{< formula display="true" >}}
R_\mathrm{eff} = R_\mathrm{ci} \times \left(1 - \frac{A_\mathrm{fastener}}{A_\mathrm{total}} \cdot \frac{\lambda_\mathrm{steel}}{\lambda_\mathrm{insul}}\right)
{{< /formula >}}

При λ_steel = 52 Вт/(м·К), λ_insul (EPS) = 0,038 Вт/(м·К), диаметре болта 6 мм, шаге 600 × 400 мм (A_fastener/A_total = π × 0,003² / 0,24 = 1,18 × 10⁻⁴): снижение R менее 0,5% — несущественно для типичных крепежей малого диаметра.

Однако при стальных шпильках большого сечения или частом шаге снижение может достигать 5–10% — необходим расчёт.

### Методы крепления CI

- **Механические метизы:** длинные саморезы через CI в стойки. Шаг определяется ветровой нагрузкой. Пластиковые шайбы распределяют нагрузку.
- **Контробрешётка:** деревянная или алюминиевая контробрешётка крепится через CI к стойкам; создаёт вентзазор для облицовки. Тепловой мост через обрешётку рассчитывается отдельно.
- **Термически развязанные системы:** композитные или пластиковые дистанционные элементы — минимизируют тепловой мост.

## Детали монтажа

### Стыки плит CI

- Разбежка стыков между слоями при многослойной укладке (смещение ≥ 150 мм).
- Проклейка стыков совместимой лентой (проверить адгезию к конкретному материалу плиты).
- Смещение стыков от стоек каркаса на ≥ 150 мм.

### Критические примыкания

**Примыкание к фундаменту:** WRB перекрывает верхний торец CI с напуском ≥ 150 мм; зазор между CI и цоколем заполнен герметиком или закрыт отделочным уголком.

**Примыкание к оконному проёму:** CI возвращается в откос (thermal return) или применяется изолированная оконная коробка; перемычка выполняется без сквозного стального элемента — иначе тепловой мост через перемычку.

**Примыкание кровля–стена:** CI стены стыкуется с CI кровли (при возможности) без разрыва; воздушный барьер непрерывен через переход.

## Проверка производительности

### Инфракрасная термография

Условия съёмки: перепад температур ≥ 8 °C, состояние равновесия не менее 4 ч. Выявляет: пропуски в CI, тепловые мосты у крепежа, воздушные утечки.

### Влагосодержание обшивки

После первого отопительного сезона — измерение влажности деревянной обшивки:
- ≤ 15%: норма.
- 16–19%: повышенное, анализ причин.
- ≥ 20%: критическое, необходимо вскрытие.
