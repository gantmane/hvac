Внешнее вынужденное обтекание охватывает ситуации, когда жидкость течёт над поверхностью без ограничения боковых сторон. Пограничный слой развивается свободно. В HVAC это обтекание наружных стен зданий ветром, поперечное обтекание труб в теплообменниках и конденсаторах, обдув конденсаторных блоков.

## Пограничный слой на плоской пластине

### Ламинарный пограничный слой

Толщина гидродинамического пограничного слоя:

{{< formula display="true" >}}
\delta(x) = \frac{5{,}0 \, x}{\sqrt{Re_x}}, \quad Re_x = \frac{V x}{\nu}
{{< /formula >}}

Толщина теплового пограничного слоя:

{{< formula display="true" >}}
\delta_T = \frac{\delta}{Pr^{1/3}} \quad\text{при } Pr > 0{,}6
{{< /formula >}}

Локальное число Нуссельта (самоподобное решение Блазиуса–Пуальхаузена):

{{< formula display="true" >}}
Nu_x = 0{,}332 \, Re_x^{1/2} Pr^{1/3} \quad (Re_x < 5 \times 10^5, \; Pr > 0{,}6)
{{< /formula >}}

Среднее по длине $L$:

{{< formula display="true" >}}
\overline{Nu}_L = 0{,}664 \, Re_L^{1/2} Pr^{1/3}
{{< /formula >}}

### Турбулентный пограничный слой ($Re_x > 5 \times 10^5$)

{{< formula display="true" >}}
Nu_x = 0{,}0296 \, Re_x^{4/5} Pr^{1/3}
{{< /formula >}}

### Смешанный пограничный слой (переход при $Re_c = 5 \times 10^5$)

{{< formula display="true" >}}
\overline{Nu}_L = (0{,}037 \, Re_L^{4/5} - 871) Pr^{1/3}
{{< /formula >}}

Для жидких металлов ($Pr \ll 1$): $\overline{Nu}_L = 0{,}565 (Re_L Pr)^{1/2}$.

## Цилиндр в поперечном потоке

### Режимы обтекания и отрыв пограничного слоя

{{< table title="Режимы обтекания цилиндра в зависимости от Re" >}}
| Диапазон $Re$ | Характер течения |
|---|---|
| $Re < 4$ | Ползущее течение, нет отрыва |
| $4 < Re < 40$ | Симметричный вихревой пузырь за цилиндром |
| $40 < Re < 150$ | Начало вихревого срыва (дорожка Кармана) |
| $150 < Re < 3 \times 10^5$ | Ламинарный ПС, турбулентный след |
| $Re > 3 \times 10^5$ | Кризис сопротивления, турбулентный ПС |
{{< /table >}}

### Корреляция Черчилля–Бернштейна (рекомендуемая)

Применима для любых $Re$ при $Re \cdot Pr > 0{,}2$:

{{< formula display="true" >}}
\overline{Nu}_D = 0{,}3 + \frac{0{,}62 \, Re_D^{1/2} Pr^{1/3}}{\left[1 + (0{,}4/Pr)^{2/3}\right]^{1/4}} \left[1 + \left(\frac{Re_D}{282\,000}\right)^{5/8}\right]^{4/5}
{{< /formula >}}

Свойства жидкости при $T_f = (T_s + T_\infty)/2$.

### Упрощённые степенные корреляции

{{< formula display="true" >}}
Nu_D = C \, Re_D^m Pr^{1/3}
{{< /formula >}}

{{< table title="Коэффициенты C и m для одиночного цилиндра в поперечном потоке" >}}
| Диапазон $Re_D$ | $C$ | $m$ |
|---|---|---|
| 0,4–4 | 0,989 | 0,330 |
| 4–40 | 0,911 | 0,385 |
| 40–4000 | 0,683 | 0,466 |
| 4000–40 000 | 0,193 | 0,618 |
| 40 000–400 000 | 0,027 | 0,805 |
{{< /table >}}

## Пучки труб в поперечном потоке

### Геометрические параметры

Для пучка труб $D$ — наружный диаметр. $S_T$ — поперечный шаг (перпендикулярно потоку), $S_L$ — продольный шаг (вдоль потока).

**Максимальная скорость** (коридорное расположение):

{{< formula display="true" >}}
V_{max} = V_\infty \frac{S_T}{S_T - D}
{{< /formula >}}

**Максимальная скорость** (шахматное расположение, надо брать минимум):

{{< formula display="true" >}}
V_{max} = V_\infty \frac{S_T}{S_T - D}
\quad\text{или}\quad
V_{max} = V_\infty \frac{S_T}{2(S_D - D)}, \quad S_D = \sqrt{S_L^2 + (S_T/2)^2}
{{< /formula >}}

### Корреляция Жукаускаса для пучков труб (полностью развитый поток, $N_L \geq 20$)

{{< formula display="true" >}}
\overline{Nu}_D = C \, Re_{D,max}^m Pr^{0,36} \left(\frac{Pr}{Pr_s}\right)^{1/4} \quad (0{,}7 < Pr < 500, \; 1 < Re < 10^6)
{{< /formula >}}

{{< table title="Коэффициенты C и m для пучков труб (Жукаускас)" >}}
| Расположение | $Re_{D,max}$ | $C$ | $m$ |
|---|---|---|---|
| Коридорное | 100–1000 | 0,51 | 0,50 |
| Коридорное | 1000–2·10⁵ | 0,27 | 0,63 |
| Шахматное ($S_T/S_L < 2$) | 1000–2·10⁵ | 0,35 $(S_T/S_L)^{0,2}$ | 0,60 |
| Шахматное ($S_T/S_L > 2$) | 1000–2·10⁵ | 0,40 | 0,60 |
{{< /table >}}

**Поправка на число рядов** ($N_L < 20$):

{{< table title="Поправочный коэффициент F на число рядов" >}}
| $N_L$ | 1 | 2 | 3 | 5 | 7 | 10 | 13 | 16 | ≥20 |
|---|---|---|---|---|---|---|---|---|---|
| Коридорное $F$ | 0,70 | 0,80 | 0,86 | 0,90 | 0,92 | 0,95 | 0,98 | 0,99 | 1,00 |
| Шахматное $F$ | 0,64 | 0,76 | 0,84 | 0,89 | 0,93 | 0,96 | 0,98 | 0,99 | 1,00 |
{{< /table >}}

### Числовой пример: конденсатор воздушного охлаждения

**Задача.** Медные трубы Ø9{,}52 мм, шахматное расположение, $S_T = 25$ мм, $S_L = 21{,}65$ мм (равносторонний треугольник). 8 рядов. Воздух: $V_\infty = 3{,}5$ м/с, $T_\infty = 35°$С. Стенки труб при $T_s = 50°$С.

Свойства воздуха при $T_f = 42{,}5°$С: $\rho = 1{,}113$ кг/м³, $\mu = 1{,}92 \times 10^{-5}$ Па·с, $k = 0{,}0276$ Вт/(м·К), $Pr = 0{,}710$, $Pr_s$ при 50°С = 0,709.

{{< formula display="true" >}}
S_D = \sqrt{21{,}65^2 + 12{,}5^2} = \sqrt{468{,}7 + 156{,}25} = \sqrt{624{,}9} = 25{,}0 \;\text{мм} = S_T
{{< /formula >}}

{{< formula display="true" >}}
V_{max} = 3{,}5 \times \frac{25}{25 - 9{,}52} = 3{,}5 \times 1{,}616 = 5{,}66 \;\text{м/с}
{{< /formula >}}

{{< formula display="true" >}}
Re_{D,max} = \frac{1{,}113 \times 5{,}66 \times 0{,}00952}{1{,}92 \times 10^{-5}} = \frac{5{,}994 \times 10^{-2}}{1{,}92 \times 10^{-5}} = 3122
{{< /formula >}}

$S_T/S_L = 25/21{,}65 = 1{,}155 < 2$, поэтому $C = 0{,}35 \times 1{,}155^{0,2} = 0{,}35 \times 1{,}029 = 0{,}360$.

{{< formula display="true" >}}
Nu = 0{,}360 \times 3122^{0,60} \times 0{,}710^{0,36} \times (0{,}710/0{,}709)^{0,25} = 0{,}360 \times 138{,}6 \times 0{,}895 \times 1{,}000 = 44{,}7
{{< /formula >}}

Поправка для 8 рядов (шахматное): $F \approx 0{,}96$.

{{< formula display="true" >}}
h_o = \frac{44{,}7 \times 0{,}96 \times 0{,}0276}{0{,}00952} = \frac{1{,}184}{0{,}00952} = 124 \;\text{Вт/(м}^2\text{·К)}
{{< /formula >}}

## Перепад давления в пучке труб

{{< formula display="true" >}}
\Delta P = N_L \, f \, \frac{\rho V_{max}^2}{2}
{{< /formula >}}

где $f$ — коэффициент трения из диаграмм Якоби (зависит от $Re$ и геометрии пучка). Падение давления определяет мощность вентилятора.

## Конвекция на наружных поверхностях зданий

На практике конвективный коэффициент наружной поверхности вычисляют с учётом ветрового воздействия:

{{< formula display="true" >}}
h_e = \begin{cases}
5{,}7 + 3{,}8 V & V < 5 \;\text{м/с} \;(\text{в Вт/(м}^2\text{·К)}) \\
6{,}47 V^{0,78} & V > 5 \;\text{м/с}
\end{cases}
{{< /formula >}}

Для расчётных условий ASHRAE (скорость ветра 6,7 м/с): $h_e = 34$ Вт/(м²·К), $R_{se} = 1/34 = 0{,}029$ м²·К/Вт (несколько отличается от ISO 6946 $R_{se} = 0{,}04$).

## Вихревое срывание с трубопроводов (эффект Кармана)

Вихревое срывание вызывает поперечные колебания трубопроводов и воздуховодов. Частота срывания:

{{< formula display="true" >}}
f_{vortex} = \frac{St \cdot V}{D}, \quad St \approx 0{,}21 \;\text{(для } 250 < Re < 2 \times 10^5\text{)}
{{< /formula >}}

Число Струхаля $St = f D / V \approx 0{,}21$. Резонанс наступает, когда $f_{vortex}$ совпадает с собственной частотой конструкции.
